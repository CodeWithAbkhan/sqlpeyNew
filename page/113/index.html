GOOGLE BIGQUERY: Converting Timestamp to Seconds in BigQuery Standard SQL

Converting Timestamp to Seconds in BigQuery Standard SQL In BigQuery Standard SQL, we can use the UNIX_SECONDS() function to convert a timestamp to seconds. This function returns the UNIX timestamp in seconds, which counts the number of seconds since January 1, 1970, 00:00:00 UTC. Converting Current Timestamp to Seconds Let’s consider an example of converting the current timestamp to seconds using the UNIX_SECONDS() function in BigQuery Standard SQL: SELECT UNIX_SECONDS(CURRENT_TIMESTAMP()) AS current_timestamp_in_seconds In the above code, we are selecting the current timestamp using the CURRENT_TIMESTAMP() function, and then using the UNIX_SECONDS() function to convert it to seconds.
