GOOGLE BIGQUERY: Ilike Expression Support in BigQuery: Enhancing Query Flexibility

Alternative for the ‘ilike’ expression in BigQuery Summary BigQuery does not support the ‘ilike’ expression for case-insensitive search. The alternative for this is using either the UPPER() function or the REGEXP_CONTAINS() function. Using the UPPER() function SELECT id FROM `performance_last30days` WHERE UPPER(device) LIKE '%DESKTOP%' The above query uses the UPPER() function to convert the device column to uppercase and then applies the LIKE operator for case-insensitive search. The % sign is used as a wild card character to match any number of characters before and after the keyword ‘DESKTOP’.
