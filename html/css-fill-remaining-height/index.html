“Top 15 CSS Solutions: How to Make Content Fill Remaining Page Height”

Achieving a layout where content dynamically fills the remaining vertical space on a webpage is a common requirement in web development. Whether you’re creating a dashboard, a blog, or any application, ensuring your content area stretches to accommodate the viewport, while respecting fixed headers and footers, is crucial for a polished user experience. This comprehensive guide explores numerous CSS techniques to accomplish this, from modern Flexbox and Grid to older, but still relevant, methods.

Solution 1: The Flexbox Approach (2015 Update)

Flexbox offers a robust and adaptable solution for creating dynamic layouts. While its specification has matured, it’s important to note browser compatibility. All major browsers and IE11+ support Flexbox. For older versions, a shim like FlexieJS might be necessary. You can check current support at caniuse.com/#feat=flexbox .

This method allows for easy switching between row and column layouts, with elements adapting to their content, fixed dimensions, or available space.

Example:

<div class="box">
  <div class="row header">
    <p><b>header</b><br/><br/>(sized to content)</p>
  </div>
  <div class="row content">
    <p>
      <b>content</b>
      (fills remaining space)
    </p>
  </div>
  <div class="row footer">
    <p><b>footer</b> (fixed height)</p>
  </div>
</div>

CSS:

html,
body {
  height: 100%;
  margin: 0;
}

.box {
  display: flex;
  flex-flow: column;
  height: 100%;
}

.box .row {
  border: 1px dotted grey;
}

.box .row.header {
  flex: 0 1 auto; /* Shorthand for flex-grow: 0, flex-shrink: 1, flex-basis: auto */
}

.box .row.content {
  flex: 1 1 auto;
}

.box .row.footer {
  flex: 0 1 40px; /* Example: fixed height of 40px */
}

Solution 2: JavaScript for Dynamic Height

For complex layouts or when precise control is needed, JavaScript can be used to dynamically calculate and set element heights. The core idea is:

Element Height = Viewport Height - Element.offsetTop - Desired Bottom Margin

This approach requires attaching event handlers for window.onload and window.onresize to ensure the heights are updated correctly. If the content can exceed the viewport, setting overflow-y to scroll is advisable.

Solution 3: Absolute Positioning with CSS

This method uses absolute positioning to achieve an app-like layout with fixed headers and footers. It’s compatible with IE7+.

Example:

<div class="header row" style="background:yellow;">
    <h2>My header</h2>
</div>
<div class="body row scroll-y" style="background:lightblue;">
    <p>The body</p>
</div>
<div class="footer row" style="background:#e9e9e9;">
    My footer
</div>

CSS:

@media screen {
  /* Generic pane rules */
  body { margin: 0 }
  .row, .col { overflow: hidden; position: absolute; }
  .row { left: 0; right: 0; }
  .col { top: 0; bottom: 0; }
  .scroll-x { overflow-x: auto; }
  .scroll-y { overflow-y: auto; }

  .header.row { height: 75px; top: 0; }
  .body.row { top: 75px; bottom: 50px; }
  .footer.row { height: 50px; bottom: 0; }
}

Solution 4: CSS Tables for Layout

Emulating table behavior with CSS offers a robust layout solution with good semantic clarity and wide browser support (IE8+).

Example:

<body>
    <div>hello </div>
    <div>there</div>
</body>

CSS:

body {
    display:table;
    width:100%;
}
div {
    display:table-row;
}
div + div { /* Targets the second div, assuming it's the content */
    height:100%;
}

For reference, here are CSS properties mapped to their equivalent HTML table elements:

  • table: display: table
  • tr: display: table-row
  • thead: display: table-header-group
  • tbody: display: table-row-group
  • tfoot: display: table-footer-group
  • col: display: table-column
  • colgroup: display: table-column-group
  • td, th: display: table-cell
  • caption: display: table-caption

See related examples at jsfiddle.net/Lq3jN and jsfiddle.net/Lq3jN/1 .

Solution 5: calc() with Fixed Header/Footer

If your header and footer have known, fixed heights, CSS3’s calc() function is an elegant solution.

Example:

<header>100px</header>
<section>Expand me for remaining space</section>
<footer>150px</footer>

CSS:

html,
body {
  height: 100%;
}

header {
  height: 100px;
  background: grey;
}

section {
  height: calc(100% - (100px + 150px)); /* Subtract header and footer heights */
  background: tomato;
}

footer {
  height: 150px;
  background-color: blue;
}

Ensure parent elements also have height: 100%.

Solution 6: Simplified Flexbox for Content Growth

A minimal Flexbox implementation can achieve the desired effect.

Example:

<body>
  <div>header</div>
  <div class="content"></div>
</body>

CSS:

html,
body {
  height: 100%;
}

body {
  display: flex;
  flex-direction: column;
}

.content {
  flex-grow: 1; /* Allows this div to grow and fill remaining space */
}

A Codepen sample is available for demonstration.

Solution 7: calc() with Viewport Height

This approach uses calc() in conjunction with viewport height units (vh).

Example:

<div class="header">
    <h2>My header</h2>
</div>
<div class="body">
    <p>The body</p>
</div>
<div class="footer">
    My footer
</div>

CSS:

.header { height: 60px; top: 0; background-color: green; }
.body {
    height: calc(100vh - 110px); /* Combines footer (50px) + header (60px) */
    background-color: gray;
}
.footer { height: 50px; bottom: 0; }

Solution 8: The Power of 100vh

Viewport height units (vh) are a straightforward way to make an element span the full height of the viewport.

Example:

<div class="full-height"></div>

CSS:

body {
  padding: 0;
  margin: 0;
}

.full-height {
  width: 100px; /* Example width */
  height: 100vh; /* 100% of viewport height */
  background: red;
}

This method supports IE9+.

Solution 9: CSS Tables for Scrollable Content

When the middle content needs to scroll independently, a table-like structure with overflow: auto is effective.

Example:

<div class="table container">
  <div class="table-row header">
    <div>This is the header whose height is unknown</div>
  </div>
  <div class="table-row body">
    <div class="table-cell body-content-outer-wrapper">
      <div class="body-content-inner-wrapper">
        <div class="body-content">
          <div>This is the scrollable content...</div>
          <!-- More content to demonstrate scrolling -->
        </div>
      </div>
    </div>
  </div>
</div>

CSS:

.table { display: table; }
.table-row { display: table-row; }
.table-cell { display: table-cell; }

.container { width: 400px; height: 300px; } /* Example dimensions */

.header { background: cyan; }
.body { background: yellow; height: 100%; }
.body-content-outer-wrapper { height: 100%; }
.body-content-inner-wrapper {
  height: 100%;
  position: relative;
  overflow: auto; /* Enables scrolling */
}
.body-content {
  position: absolute;
  top: 0;
  bottom: 0;
  left: 0;
  right: 0;
}

A live preview is available via JSFiddle .

Solution 10: calc() for Simple Heights

A concise CSS3 calc() approach for when you know the combined height of other elements.

height: calc(100% - 10px); /* Subtracting 10px for a preceding div */

This is well-supported in modern browsers.

Solution 11: Modern Flexbox with flex: 1

A clean, modern Flexbox solution utilizing flex: 1 for the expanding element.

Example:

<body>
    <header>Header with an arbitrary height</header>
    <main>
        This container will grow to take the remaining height
    </main>
</body>

CSS:

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh; /* Ensures body takes the full viewport height */
}

main {
  flex: 1; /* Makes the main element take up all available free space */
}

This works in IE10+ with vendor prefixes. More examples at Codepen and another Codepen .

Solution 12: vh with overflow: scroll

Using vh units combined with overflow: scroll for content that might exceed the available height.

CSS:

#page {
    display:block;
    width:100%;
    height:95vh !important; /* Using vh and important for direct application */
    overflow:hidden;
}
#tdcontent {
    float:left;
    width:100%;
    display:block;
}
#content {
    float:left;
    width:100%;
    height:100%;
    display:block;
    overflow:scroll; /* Scrollable content */
}

HTML:

<div id="page">
   <div id="tdcontent"></div>
   <div id="content"></div>
</div>

This method is cross-browser compatible.

Solution 15: CSS Grid Layout

For modern browsers, CSS Grid offers a powerful and semantic way to define layouts, including distributing space.

Example (Grid):

<header>Header content</header>
<main>Main content which should be centered and the content length may change.</main>
<footer>Footer content</footer>

CSS:

html, body {
  min-height: 100vh;
  padding: 0;
  margin: 0;
}

body {
  display: grid;
  grid:
    "myheader" auto
    "mymain" minmax(0,1fr) /* Main content takes remaining space */
    "myfooter" auto /
    minmax(10rem, 90rem); /* Example: constrained width */
}

header { grid-area: myheader; background: yellow; }
main {
  grid-area: mymain;
  background: pink;
  align-self: center; /* Centers content vertically */
}
footer { grid-area: myfooter; background: cyan; }

Example (Flexbox):

<main>Main content which should be centered and the content length may change.</main>

CSS:

html, body {
  min-height: 100vh;
  padding: 0;
  margin: 0;
}

body {
  display: flex;
}

main {
  background: pink;
  align-self: center; /* Centers content vertically */
}

Modern browser support for Grid and Flexbox is excellent.

Solution 18: Floating Header with Absolute Content

A method for older browsers, especially IE7-, involving absolute positioning.

HTML & CSS:

Note: For IE7-, the header might need to be nested within the content div. overflow: auto on the content div is crucial for handling overflowing content.

Solution 19: CSS Grid with 1fr Unit

A clean CSS Grid approach using grid-template-rows to define the layout.

Example:

<header>HEADER</header>
<main>MAIN</main>
<footer>FOOTER</footer>

CSS:

* { margin: 0; padding: 0; }
html { height: 100%; }
body {
  min-height: 100%;
  display: grid;
  grid-template-rows: auto 1fr auto; /* auto for header/footer, 1fr for main */
}

header { padding: 1em; background: pink; }
main { padding: 1em; background: lightblue; }
footer { padding: 2em; background: lightgreen; }

A guide to CSS Grids can be found at CSS-Tricks .

Solution 20: Flexbox with flex-grow: 1 (Minimalist)

A very minimal Flexbox setup for modern browsers.

Example:

<body>
  <section>
    <div>FIT</div>
    <div>GROW</div>
  </section>
</body>

CSS:

html { height: 100%; }
body { height: 100%; margin: 0; }
section {
  display: flex;
  flex-direction: column;
  height: 100%;
}
div:first-child { background: gold; }
div:last-child {
  background: plum;
  flex-grow: 1; /* This div grows to fill available space */
}

This is tested and works across major browsers.

Solution 22: Absolute Positioning with Padding

An alternative using absolute positioning where the content div is padded to appear below the header.

CSS:

body {
    padding: 0;
    margin: 0;
    height: 100%;
    overflow: hidden; /* Prevents overall page scroll */
}

    position: absolute;

    left: 0;
    height: 50px; /* Fixed header height */

    top: 0;
    left: 0;

    height: 100%; /* Content fills remaining height */
}

Solution 28: JavaScript for Footer Padding

A JavaScript solution to dynamically adjust footer padding based on available space.

var sizeFooter = function(){
    $(".webfooter")
        .css("padding-bottom", "0px") // Reset first
        .css("padding-bottom", $(window).height() - $("body").height())
}
$(window).resize(sizeFooter);

Solution 30: min-height: calc() for Dynamic Content

Using min-height with calc() is beneficial when content might dynamically change or be rendered by JavaScript, ensuring the footer stays at the bottom.

CSS:

.content {
    /* Example: 100% minus fixed header (50px + 20px padding) and footer (50px + 20px padding) */
    min-height: calc(100% - (50px + 20px + 50px + 20px));
}

This allows the content to grow if needed, pushing the footer down.

FAQs on CSS Fill Remaining Page Height

Q: What is the most modern and recommended way to make content fill remaining height?

ANS: Modern CSS Flexbox (Solution 1, 11) and CSS Grid (Solution 15) are the most recommended methods due to their flexibility, power, and excellent browser support in current versions.

Q: How can I support older browsers like IE8 or IE9?

ANS: For older browsers, CSS Tables (Solution 4, 14, 25) and Absolute Positioning with careful padding (Solution 3, 18, 22) are reliable options. JavaScript can also be used as a fallback (Solution 2).

Q: What does 'vh' unit represent in CSS?

ANS: ‘vh’ stands for “viewport height.” 1vh is equal to 1% of the viewport’s height. So, height: 100vh; makes an element occupy the full height of the browser window.

Q: Can I make the content scrollable if it exceeds the available height?

ANS: Yes, for layouts where the content might be extensive, you can use overflow: auto; or overflow-y: auto; on the content container. Solutions 3, 9, 12, and 18 demonstrate this.

Q: Is there a way to achieve this without relying on fixed header/footer heights?

ANS: Yes, solutions using Flexbox (like 1, 6, 11, 20, 21) and Grid (like 15, 19) are inherently designed to manage space dynamically, even if header/footer heights are not explicitly fixed, by allowing elements to grow or shrink based on available space.
