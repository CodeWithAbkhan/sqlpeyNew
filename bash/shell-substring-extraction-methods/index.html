“Shell Scripting: Multiple Methods to Extract Substring by Delimiter or Position”

When processing filenames or complex strings in a shell environment, extracting a specific segment—such as a numeric ID situated between two underscores—is a frequent requirement. How can one efficiently achieve this substring extraction using various shell tools and built-in features, ensuring high performance and adaptability?

This discussion details numerous accepted solutions for isolating parts of a string, ranging from zero-cost native shell operations to powerful external utilities like cut, sed, and grep.

Pure Bash Techniques: Parameter Expansion and Regex Matching

For maximum execution speed, avoiding external process spawning is ideal. Bash provides powerful built-in mechanisms for string manipulation.

1. Substring Expansion by Offset and Length

Parameter expansion allows direct slicing, similar to array indexing. This method is zero-overhead.

If the string is held in variable a, and you require a segment starting at offset 12 (zero-based) with a length of 5:

a="prefix_data_123456789012345_suffix"
b=${a:12:5}
echo "Extracted segment: $b" # Output: 12345

2. Stripping Prefixes and Suffixes

When the target is bounded by unique characters, such as the first and last underscores in someletters_12345_moreleters.ext, sequential stripping operations are very fast:

a="someletters_12345_moreleters.ext"
# Remove prefix up to and including the first underscore
tmp=${a#*_}
# Remove suffix starting from the first underscore found from the right
b=${tmp%_*}
echo "Stripped result: $b" # Output: 12345

3. Bash Regular Expression Matching (=~)

Bash versions 3.0+ support the =~ operator for powerful, built-in regex extraction, storing results in the ${BASH_REMATCH} array. This is excellent for structured data extraction without spawning utilities.

To extract five digits bounded by underscores (_12345_):

FN="someletters_12345_moreleters.ext"
# Match: underscore, then capture group (5 digits), then underscore
if [[ ${FN} =~ _([[:digit:]]{5})_ ]]; then
    NUM=${BASH_REMATCH[1]}
    echo "Regex Match Result: $NUM" # Output: 12345
fi

For extracting the first sequence of one or more digits ([0-9]+):

input="someletters_12345_moreleters_323_end.ext"
[[ $input =~ _([0-9]+)_ ]]
echo ${BASH_REMATCH[1]} # Extracts 12345, matching the first occurrence between underscores

4. Setting IFS (Internal Field Separator)

If the fields are consistently separated by a single delimiter (like _), temporarily changing IFS and using read is clean:

input='someletters_12345_moreleters.ext'
# The first, second, and subsequent fields are captured.
IFS="_" read -r _ digs _ <<< "$input"
echo "IFS Read Result: $digs" # Output: 12345

Self-Correction Note: Remember to manage the scope of IFS modification, as it affects subsequent commands.

5. Extended Globbing (extglob)

Extended globbing offers expressive pattern matching capabilities directly within parameter expansion:

shopt -s extglob
filename="someletters_12345_moreletters.ext"
# Remove leading part: anything up to the last underscore before letters/dot
substring=${filename//@(+([a-z])_|_+([a-z]).*)}
echo "Extglob Result: $substring" # Output: 12345

External Utility Solutions

While slower due to process overhead, tools like cut, sed, and grep offer broad compatibility and are syntactically intuitive for many users.

6. Using cut Based on Delimiter

The cut command excels at field-based extraction when the delimiter is simple and consistent.

echo 'someletters_12345_moreleters.ext' | cut -d'_' -f 2
# Output: 12345

To store this in a variable:

INPUT='someletters_12345_moreleters.ext'
SUBSTRING=$(echo "$INPUT" | cut -d'_' -f 2)
echo "Cut Variable: $SUBSTRING"

7. Extracting by Fixed Character Position (cut -c)

If the position is absolute (e.g., characters 12 through 19), cut -c is the direct tool.

str="2020-08-08T07:40:00.000Z"
echo "$str" | cut -c12-19 # Extracts the time part, e.g., '07:40:00'

8. Utilizing sed for Substitution and Capture Groups

sed allows substituting the entire line, keeping only the desired captured group.

To capture content between two underscores:

var="someletters_12345_moreletters.ext"
digits=$(echo "$var" | sed -n "s/.*_\([0-9]\+\).*/\1/p")
echo "Sed Extraction: $digits" # Output: 12345

9. Using grep with PCRE Lookarounds

Modern grep (especially with -P for PCRE support) can use lookbehind assertions to select content precisely where delimiters are present, avoiding capture groups for the delimiters themselves:

echo "someletters_12345_moreleters.ext" | grep -Po '(?<=_)\d{5}'
# Output: 12345

10. Isolating the First Sequence of Digits (General Purpose)

If the goal is to find the first contiguous block of digits, regardless of what surrounds it:

filename="log_file_12345_backup_321.tmp"
# Extract 5 consecutive digits if present, or just the first sequence of digits
number=$(echo "$filename" | egrep -o '[[:digit:]]{5}' | head -n1)
echo "Egrep 5-digit match: $number"

# Alternative to extract the very first contiguous sequence of digits
number_general=$(echo "$filename" | egrep -o '[[:digit:]]+' | head -n1)
echo "Egrep first digit sequence: $number_general"

Alternative Approaches: awk and expr

11. awk Field Processing

awk is highly effective when field separation is used, similar to cut, but with more programmatic control:

filename='someletters_12345_moreleters.ext'
number=$(echo "$filename" | awk -F _ '{ print $2 }')
echo "Awk Field 2: $number" # Output: 12345

12. expr for Pattern Matching

The older expr command can perform basic regex matching to extract text inside parentheses.

INPUT="someletters_12345_moreleters.ext"
# Note: expr output is often captured via backticks or $()
SUBSTRING=$(expr match "$INPUT" '.*_\([[:digit:]]*\)_.*')
echo "Expr Match Result: $SUBSTRING" # Output: 12345 (Note: expr match returns the whole match if parentheses are present without a preceding command to extract only the group)

# Better usage of expr for capture group extraction:
# This is often simpler with sed or bash =~
# Example extracting content between the last two underscores:
echo `expr "$INPUT" : '.*_\(.*\)_'` # Output: 12345

13. Manual Iteration (Least Efficient)

For didactic purposes, character-by-character iteration using loops, potentially combined with sed to space out characters, exists but is resource-intensive compared to built-ins:

# Example based on Solution 26 logic (character iteration)
chars='someletters_12345_moreleters.ext'
start=8  # 0-indexed offset for '1' in 12345
length=5
o=""
for (( i=0; i<${#chars}; i++ )); do
    if [[ $i -ge $start ]] && [[ $((i - start)) -lt $length ]]; then
        o="$o${chars:$i:1}"
    fi
done
echo "Manual Iteration: $o" # Output: 12345

FAQs on Shell Substring Extraction Methods

Q: What is the fastest method for substring extraction in Bash

ANS: Pure Bash Parameter Expansion, such as ${parameter:offset:length} or prefix/suffix stripping (${var#pattern}), avoids spawning external processes and is generally the fastest approach for variable manipulation.

Q: Can I extract content between two specific characters reliably

ANS: Yes, using Bash regex ([[ \$var =~ pattern ]]) with capture groups or using sed substitution (sed 's/.*DELIM1\(.*\)DELIM2.*/\1/p') provides reliable extraction between specified delimiters.

Q: How to extract all digits from a string regardless of position

ANS: Use grep -o with the digit character class or tr. For instance: echo "$filename" | tr -cd '[[:digit:]]' will concatenate all digits found in the string.
