C++ Implementation via Edge Detection and Contour Analysis (Solution 1)

One initial approach involves modifying existing OpenCV square detection demos written in C++. The core idea is to enhance edges through blurring and then iterate through color planes to find suitable contours that approximate a four-sided polygon.

The provided C++ function, find_squares, preprocesses the image to improve edge detection:

void find_squares(Mat& image, vector<vector<Point> >& squares)
{
    // Blur to enhance edge detection
    Mat blurred(image);
    medianBlur(image, blurred, 9);

    Mat gray0(blurred.size(), CV_8U), gray;
    vector<vector<Point> > contours;

    // Process each color plane
    for (int c = 0; c < 3; c++)
    {
        int ch[] = {c, 0};
        mixChannels(&blurred, 1, &gray0, 1, ch, 1);

        // Try several threshold levels
        const int threshold_level = 2;
        for (int l = 0; l < threshold_level; l++)
        {
            // Use Canny for gradient shading robustness
            if (l == 0)
            {
                Canny(gray0, gray, 10, 20, 3); 

                // Dilate to close potential gaps in edges
                dilate(gray, gray, Mat(), Point(-1,-1));
            }
            else
            {
                    gray = gray0 >= (l+1) * 255 / threshold_level;
            }

            // Find contours
            findContours(gray, contours, CV_RETR_LIST, CV_CHAIN_APPROX_SIMPLE);

            // Test contours for square properties
            vector<Point> approx;
            for (size_t i = 0; i < contours.size(); i++)
            {
                    // Approximate contour polygon
                    approxPolyDP(Mat(contours[i]), approx, arcLength(Mat(contours[i]), true)*0.02, true);

                    // Check if it's a quadrilateral, large enough, and convex
                    if (approx.size() == 4 &&
                            fabs(contourArea(Mat(approx))) > 1000 &&
                            isContourConvex(Mat(approx)))
                    {
                            double maxCosine = 0;

                            for (int j = 2; j < 5; j++)
                            {
                                    double cosine = fabs(angle(approx[j%4], approx[j-2], approx[j-1]));
                                    maxCosine = MAX(maxCosine, cosine);
                            }

                            // Filter based on corner sharpness (angles close to 90 degrees)
                            if (maxCosine < 0.3)
                                    squares.push_back(approx);
                    }
            }
        }
    }
}

Once this routine executes, the largest element found within the squares vector is assumed to be the sheet of paper. A subsequent function would be required to iterate through the resulting contours to isolate the one with the greatest area.

Alternative Image Processing Pipeline (Solution 2)

An alternative simplification suggests focusing on grayscale conversion first, bypassing multi-channel processing if contrast is sufficient. This method prioritizes morphological operations and statistical thresholding.

Key steps involve:

  1. Grayscale Conversion: Simplify the image.
  2. Downscaling: Process a smaller image size if the original is large, reducing noise impact.
  3. Median Filter: Remove minor details.
  4. Morphological Gradient: Use Dilation - Erosion to isolate strong edges.
  5. Binarization: Apply Otsu’s method for adaptive thresholding.
  6. Thinning: Narrow down the resulting components.
  7. Filtering by Shape Ratio: Examine the ratio between the convex hull area and the bounding box area; a ratio around 0.7 is suggested for distinguishing rectangles from other shapes.

This technique was demonstrated using Mathematica syntax:

f = Import["...image_url..."]
f = ImageResize[f, ImageDimensions[f][[1]]/4]
g = MedianFilter[ColorConvert[f, "Grayscale"], 2]
h = DeleteSmallComponents[Thinning[
     Binarize[ImageSubtract[Dilation[g, 1], Erosion[g, 1]]]]]
convexvert = ComponentMeasurements[SelectComponents[
     h, {"ConvexArea", "BoundingBoxArea"}, #1 / #2 > 0.7 &], 
     "ConvexVertices"][[All, 2]]

HSV Thresholding on Saturation Channel (Solution 3 - Python)

If the paper is distinctively white against a colored background, utilizing the HSV color space can be highly effective. The saturation (S) channel often provides good separation for achromatic objects like white paper.

This Python OpenCV solution focuses on thresholding the S channel:

#!/usr/bin/python3

import cv2
import numpy as np

##(1) read into  bgr-space
img = cv2.imread("test2.jpg")

##(2) convert to hsv-space, then split the channels
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
h,s,v = cv2.split(hsv)

##(3) threshold the S channel using fixed threshold (e.g., below 50)
th, threshed = cv2.threshold(s, 50, 255, cv2.THRESH_BINARY_INV)

##(4) find all the external contours on the threshed S
# The [-2] indexing is common for retrieving contours list depending on OpenCV version
cnts = cv2.findContours(threshed, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)[-2]

canvas  = img.copy()

## sort and choose the largest contour
cnts = sorted(cnts, key = cv2.contourArea)
cnt = cnts[-1]

## approx the contour to get the corner points
arclen = cv2.arcLength(cnt, True)
approx = cv2.approxPolyDP(cnt, 0.02 * arclen, True)
cv2.drawContours(canvas, [cnt], -1, (255,0,0), 1, cv2.LINE_AA)
cv2.drawContours(canvas, [approx], -1, (0, 0, 255), 1, cv2.LINE_AA)

cv2.imwrite("detected.png", canvas)

For robustness across different OpenCV versions, checking the return tuple length for findContours is vital, as indicated in Solution 5.

Achieving a True Bird’s Eye View (Solution 5 - Perspective Transform)

After identifying a four-sided contour (displayCnt), the next logical step for paper detection is correcting the perspective distortion to get a flat, top-down view. This requires a four-point perspective transformation.

This Python example uses imutils for the transformation utility:

from imutils.perspective import four_point_transform
import cv2
import numpy

# Load image, grayscale, Gaussian blur, Otsu's threshold
image = cv2.imread("1.png")
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (7,7), 0)
thresh = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)[1]

# Find contours and sort for largest contour
cnts = cv2.findContours(thresh, cv2.RETR_EXTERNAL,cv2.CHAIN_APPROX_SIMPLE)
# Handle version differences in findContours return structure
cnts = cnts[0] if len(cnts) == 2 else cnts[1] 
cnts = sorted(cnts, key=cv2.contourArea, reverse=True)
displayCnt = None

for c in cnts:
    # Perform contour approximation
    peri = cv2.arcLength(c, True)
    approx = cv2.approxPolyDP(c, 0.02 * peri, True)
    if len(approx) == 4:
        displayCnt = approx
        break

# Obtain birds' eye view of image
# Ensure displayCnt has 4 points and is correctly shaped for the transform
if displayCnt is not None:
    warped = four_point_transform(image, displayCnt.reshape(4, 2))

    cv2.imshow("thresh", thresh)
    cv2.imshow("warped", warped)
    cv2.imshow("image", image)
    cv2.waitKey()

Considering Advanced Robustness (Solution 6)

For highly complex scenarios, such as detecting white paper on a near-white background (low contrast), relying purely on thresholding edges might fail. A suggestion here is to transition from simple shape detection to text line detection to robustly estimate the skew angle. By finding the primary orientations of text lines, one can deduce the skew, apply correction, and then crop the relevant area.

For extreme robustness in low-contrast environments, training a machine learning classifier, like a Random Forest, specifically on paper edges offers a powerful, albeit resource-intensive, alternative.

Quadrangle Class Implementation (Solution 4)

Another conceptual approach emphasizes creating a dedicated Quadrangle class to manage the conversion from an approximate contour to a geometrically correct quadrilateral, followed by applying a perspective projection based on calculated corner points and aspect ratios. This often involves intersecting lines formed by the largest edge segments detected.

FAQs on Paper Shape Detection

Q: What is the primary benefit of using the HSV Saturation channel for paper detection

ANS: The Saturation channel effectively separates color information from brightness. White objects, which have low saturation, can be isolated easily from typically more saturated colored backgrounds using appropriate thresholding.

Q: Why does Solution 1 use Canny followed by dilation

ANS: Canny is used to find sharp edges, which are crucial for polygons. Dilating the result helps to bridge small gaps or breaks in the edges that might occur due to minor image imperfections, ensuring the contour finder connects the shape properly.

Q: How is the largest square identified in the C++ solution

ANS: After detecting contours that meet the criteria (4 vertices, sufficient area, convexity, and acute corner angles), they are added to a vector. The paper is assumed to be the contour possessing the maximum area within that final vector.

Q: What is the purpose of the ratio check in Solution 2

ANS: The ratio of the convex hull area to the bounding box area helps filter out non-rectangular shapes. For a perfect rectangle, this ratio is 1.0; for shapes with significant deviations or concavities, the ratio drops, allowing for discrimination.
