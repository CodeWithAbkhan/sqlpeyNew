“Optimizing Function Root Finding: Approximation Search vs. Regula Falsi”

When faced with the challenge of finding an input $x_0$ for a known function $y = f(x)$ that yields a specific target output $y_0$, particularly when the inverse function $f^{-1}(y)$ is unavailable or difficult to compute, iterative numerical methods become essential. How can we efficiently zero in on $x_0$ within a bounded interval $[a_0, a_1]$?

This exploration details two distinct approaches: an approximation search method conceptually related to binary search but without strict monotonicity requirements, and a more robust bracketing method known as the double false position (or Regula Falsi augmented with bisection).

Method 1: Approximation Search – Iterative Probing and Refinement

This technique iteratively probes points within the current search interval, identifies the point yielding the minimum error, and then recursively narrows the search space around that best point, decreasing the step size dramatically at each recursion level. It achieves logarithmic complexity $O(\log(n))$ similar to binary search, despite lacking the monotonicity constraint.

The Core Process

  1. Initialization: Define the search interval $[a_0, a_1]$, an initial step size $da$, and the desired recursion depth $n$ (which dictates final precision).
  2. Probing: Systematically evaluate $x_i = a_0 + i \cdot da$ across the current range.
  3. Error Metric: Calculate the error $e_e = |f(x_i) - y_0|$. Track the point $a_a$ corresponding to the minimal observed error $e_e$.
  4. Termination: Halt when the probe $x_i$ exceeds $a_1$. The best found point is $a_a$.
  5. Recursion/Refinement: If not terminated, restrict the next search to a tighter band around the best point found: $a’_0 = a_a - da$ and $a’_1 = a_a + da$.
  6. Precision Increase: Decrease the step size for the next iteration, typically by a factor of 10: $da’ = 0.1 \cdot da$. Repeat the process until the recursion count limit ($n$) is reached or $da’$ becomes negligibly small.
