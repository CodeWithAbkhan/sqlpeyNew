When managing a MySQL database, especially one that uses different storage engines (such as MyISAM and InnoDB), it’s essential to be able to identify which engine is used by each table. Here’s how you can check the storage engine type for your tables in MySQL, using multiple methods.

How Can You Check the Engine Type for a Specific Table?

If you need to check the storage engine used by a specific table in MySQL, there are several methods available, from simple SQL queries to GUI tools. Below are various solutions you can apply depending on your situation and preferences.

Solution 1: Query Information Schema for Table Engines

You can use the information_schema database to find the engine type of a specific table. Here’s how you do it:

SELECT TABLE_NAME, ENGINE
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'dbname';

Replace dbname with your actual database name. This will return a list of all the tables within the specified database, along with their corresponding storage engine types (e.g., InnoDB, MyISAM).

Solution 2: Using SHOW CREATE TABLE

The SHOW CREATE TABLE statement gives you the full creation statement for a table, including its storage engine. To use it:

SHOW CREATE TABLE <tablename>;

This command provides detailed information about the table, including the engine type, but it’s less parseable compared to other methods like SHOW TABLE STATUS.

Solution 3: Show Table Status

For a quick overview of all tables and their details, including the engine type, you can use:

SHOW TABLE STATUS;

This will display the status for all tables in the current database, including information about the storage engine used.

Solution 4: Filter Out Views and Show Non-Null Engines

To filter out views and only show tables with an engine, you can tweak the previous query as follows:

SELECT TABLE_NAME, ENGINE
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'database' AND ENGINE IS NOT NULL;

This command ensures you only see tables with engines, excluding views (which don’t have an engine).

Solution 5: Formatting with \G

If you prefer to see the table creation output in a more readable format, use the \G format modifier after the SHOW CREATE TABLE command:

SHOW CREATE TABLE <tablename>\G

This method displays the output vertically, making it easier to read when there’s a lot of information.

Solution 6: List All Tables from a Specific Database

You can run a query that shows the storage engine for all tables in a specific database:

SHOW TABLE STATUS FROM database_name;

This will give you detailed information about every table in the specified database, including the engine type.

Solution 7: Using mysqlshow Command

The mysqlshow command-line tool can also be used to display table information:

mysqlshow -i <database_name>

For information about a single table, use:

mysqlshow -i <database_name> <table_name>

This shows detailed information about the tables within the specified database.

Solution 8: MySQL Workbench (GUI)

If you’re using MySQL Workbench, you can easily check the engine type via the GUI. Right-click on a table, select Alter Table, and in the window that opens, you’ll be able to see and modify the engine type for that table.

For more details on MySQL Workbench, visit MySQL Workbench Official Site .

Solution 9: Using SHOW TABLE STATUS LIKE

If you want to quickly check the engine type of a specific table, you can use the SHOW TABLE STATUS LIKE query:

SHOW TABLE STATUS LIKE 'table';

You can also use wildcards to match multiple tables:

SHOW TABLE STATUS LIKE 'field_data_%';

This will filter out tables that match the pattern you specify and show their status.

Solution 10: Linux Users: Listing Engines for All Databases

If you’re using Linux, you can run the following command to list the engine types for all tables across all databases (excluding information_schema, mysql, and performance_schema):

less < <({ for i in $(mysql -e "show databases;" | cat | grep -v -e Database-e information_schema -e mysql -e performance_schema); do echo "--------------------$i--------------------"; mysql -e "use $i; show table status;"; done } | column -t)

This command will display information for all tables across all databases in a less pager, which you can scroll through and search.

Solution 11: Use information_schema Tables Directly

You can directly query the information_schema database for table engines. Here’s the command:

USE information_schema;
SELECT table_name, engine FROM tables;

This will give you the engine type for each table in the database.

Solution 12: PhpMyAdmin (GUI)

For those who prefer using a graphical interface like PhpMyAdmin, navigate to the Operations tab for a table. Under Table Options, you’ll find the storage engine type, and you can even change it from there.

Solution 13: INNODB Specific Query

If you’re using the InnoDB storage engine, you can query the INNODB_TABLES table in information_schema:

USE information_schema;
SELECT NAME FROM INNODB_TABLES WHERE NAME LIKE 'db_name%';

This will show all tables using InnoDB in the specified database.

FAQs on Solved: How to Check MySQL Engine Type for a Specific Table

Q: What is the easiest way to check MySQL engine type?

A: The simplest method is to use the SHOW TABLE STATUS or SHOW CREATE TABLE commands, which provide the engine information directly. For a more compact query, use SHOW TABLE STATUS LIKE 'table_name';.

Q: Can I change the engine type of a table?

A: Yes, if you’re using MySQL Workbench or PhpMyAdmin, you can change the engine type easily from the interface. Otherwise, you can use the ALTER TABLE SQL command to modify the engine type.

Q: How can I list engines for all tables across multiple databases?

A: On Linux, you can use a bash script to loop through all databases and show the status of all tables, excluding certain system databases. For example:

less < <({ for i in $(mysql -e "show databases;" | cat | grep -v -e Database-e information_schema -e mysql -e performance_schema); do echo "--------------------$i--------------------"; mysql -e "use $i; show table status;"; done } | column -t)

Q: How do I see the engine type in PhpMyAdmin?

A: In PhpMyAdmin, go to the Operations tab of a table. Under Table options, you’ll see the Storage Engine section, which shows the engine used by the table.
