Install MySQL Server on Windows

In this tutorial, you’ll discover the step-by-step process of installing MySQL Server and its related products on a Windows operating system using the MySQL Installer. By the end of the tutorial, you’ll have a MySQL Server or XAMPP Control Panel (You can either Install MySQL Server or Xampp, One of the choose is compulsory ) and its tools installed on your system, ready for learning and practice.

Note: For users on other operating systems like Linux and Ubuntu, alternative link are available:

  • Install Xampp 8 on CentOS 7
  • Install Xampp 8 on Ubuntu

Download MySQL Installer

To install MySQL on Windows, leverage the MySQL Installer. This tool offers an easy-to-use wizard, streamlining the installation process for various MySQL products, including:

  • MySQL Server
  • MySQL Workbench
  • MySQL Shell
  • MySQL Documentation
  • All Available Connectors

Step 1: Download MySQL Installer from the official MySQL Community Downloads page.

Then donwload mysql community installer: Navigate to the MySQL Installer download page to access the installer. For this tutorial, we’ll use MySQL Installer 8.0.36.

Then open install form folder, where your installer is downloaded.

Install MySQL Server & Related Products

Follow these steps to install MySQL Server and related products using the MySQL Installer:

Step 1: Selecting Products

  • Expand the MySQL Servers category and select MySQL Server 8.0.34 – x64.
  • Navigate to Applications and choose MySQL Workbench 8.0.34 – X64.
  • Under Applications, select MySQL Shell 8.0.34 – X64.

Please wait while windows configures mysql installer community.

Step 2: Choosing a Setup Type

  • Open the MySQL Installer file.
  • In the setup type selection, choose “MySQL Server” for tutorial purposes.

Click the Next button to proceed with the installation.

Step 3: Installation Tab Configuration Mysql installer next installation step windows

Click the Next button to proceed with the installation.

Step 4: Product Configuration

  • Choose the configuration type. For simplicity, you can select the “Development” option.

Click the Next button to proceed.

Step 5: Type and Networking

  • Select the default type and networking options.

Click the Next button to proceed.

Step 6: Authentication Method

  • Select the recommended authentication method, “Use Strong Password Encryption.”

Click the Next button to continue.

Step 7: Root Account Password

  • Enter a secure password for the MySQL root account.

Click the Next button to proceed.

Step 8: MySQL Server Name

  • Keep the default server name (MySQL80).

Click the Next button to continue.

Step 9: Server File Permission

  • Review the Server File Permission and SELECT Yes Grant Full Access click the Next button to apply the configuration.

Step 10: Apply Configuration

  • Review the configuration settings and click the Execute button to apply the configuration.

Wait for the configuration to complete and click the Finish button.

Step 11: Installation Completed

  • Finaly You Installed MySQL Server Sucessfully, Copy log to clipboard for future used step click finaly windows.

Now you have MySQL Server installed on your Windows system.

To complement your MySQL installation, you can use XAMPP, a free and open-source cross-platform web server solution. Follow these steps to install XAMPP on Windows:

Step 1: Visit https://apachefriends.org and download XAMPP for Windows.

Step 2: Once the download completes, locate the installer in your Downloads folder and double-click to initiate the installation.

Step 3: Follow the on-screen instructions to complete the XAMPP installation.

Step 4: To start XAMPP, type “XAMPP” into the search bar and select the XAMPP Control Panel.

Step 5: Start MySQL server from the XAMPP Control Panel.

How to Install Visual Studio Code

Visual Studio Code is a free source-code editor developed by Microsoft for Linux, Windows, and macOS. It offers robust features such as debugging, syntax highlighting, intelligent code completion, snippets, code refactoring, and embedded Git support.

About Visual Studio Code

  • Developed by: Microsoft Corporation
  • Developer(s): Microsoft
  • Written in: TypeScript, JavaScript, CSS
  • Platforms: x86-32 (32-bit Intel x86), x86-64, AArch64

How to Install Visual Studio Code

Step 1: Download Visual Studio Code from Download Visual Studio Code from .

Step 2: Download the Visual Studio Code installer for Windows. Once downloaded, run the installer (VSCodeUserSetup-{version}.exe) and follow these steps:

  • Accept the agreement.
  • Click “Next.”
  • Complete the installation by clicking “Finish.”

FAQs on Installing MySQL Server on Windows

Q: What products can I install using MySQL Installer?

MySQL Installer allows you to install MySQL Server, MySQL Workbench, MySQL Shell, MySQL Documentation, and all available connectors.

Q: Why use XAMPP alongside MySQL Server?

XAMPP complements MySQL Server by providing a convenient cross-platform web server solution, facilitating comprehensive web development and testing.

Q: Why should I use Visual Studio Code for coding?

Visual Studio Code offers a powerful and customizable environment for coding, with features such as debugging, syntax highlighting, and Git integration.
