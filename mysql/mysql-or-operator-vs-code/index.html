Introduction to the MySQL OR Operator

The MySQL OR operator is a logical operator that combines two Boolean expressions using the syntax A OR B.

-- Example: Returns 1 as one operand is non-zero
SELECT 1 OR 0, 0 OR 1, 1 OR 1;

Output:

+--------+--------+--------+
| 1 OR 0 | 0 OR 1 | 1 OR 1 |
+--------+--------+--------+
|      1 |      1 |      1 |
+--------+--------+--------+

-- Example: Returns 0 as both operands are zero
SELECT 0 OR 0;

Output:

+--------+
| 0 OR 0 |
+--------+
|      0 |
+--------+

-- Example: Returns NULL as one operand is NULL
SELECT 1 OR NULL, 0 OR NULL, NULL OR NULL;

Output:

+-----------+-----------+--------------+
| 1 OR NULL | 0 OR NULL | NULL OR NULL |
+-----------+-----------+--------------+
|         1 |      NULL |         NULL |
+-----------+-----------+--------------+

The OR operator is commonly used in the WHERE clause of SELECT statements to filter data based on multiple conditions.

MySQL OR Operator and Short-Circuit Evaluation

Similar to the AND operator, the OR operator in MySQL is short-circuited. This means that if the result can be determined by evaluating only part of the expression, MySQL will not evaluate the remaining parts.

-- Short-circuit evaluation example
SELECT 1 = 1 OR 1 / 0;

Output:

+----------------+
| 1 = 1 OR 1 / 0 |
+----------------+
|              1 |
+----------------+

In this example, MySQL stops evaluating the expression as soon as it determines that the result is 1. It avoids evaluating the division by zero part, which would result in an error.

Operator Precedence in MySQL OR Operator

When an expression contains both AND and OR operators, MySQL uses operator precedence to determine the order of evaluation. The AND operator has higher precedence than the OR operator.

-- Example: Returns 1 as OR is evaluated after AND
SELECT 1 OR 0 AND 0;

Output:

+--------------+
| 1 OR 0 AND 0 |
+--------------+
|            1 |
+--------------+

To change the order of evaluation, parentheses can be used.

-- Example: Returns 0 as AND is evaluated first
SELECT (1 OR 0) AND 0;

Output:

+----------------+
| (1 OR 0) AND 0 |
+----------------+
|              0 |
+----------------+

Example 1: Selecting Employees in HR or IT Departments

SELECT 
    first_name, 
    last_name, 
    dept_name
FROM
    employees
JOIN
    dept_emp ON employees.emp_no = dept_emp.emp_no
JOIN
    departments ON dept_emp.dept_no = departments.dept_no
WHERE
    departments.dept_name = 'Human Resources' OR
    departments.dept_name = 'Information Technology';

This query retrieves employees currently assigned to either the ‘Human Resources’ or ‘Information Technology’ departments.

Example 2: Using OR in WHERE Clause for Multiple Conditions

SELECT 
    first_name, 
    last_name, 
    dept_name
FROM
    employees
JOIN
    dept_emp ON employees.emp_no = dept_emp.emp_no
JOIN
    departments ON dept_emp.dept_no = departments.dept_no
WHERE
    departments.dept_name = 'Finance' OR
    (departments.dept_name = 'Sales' AND dept_emp.to_date  <= NOW());

This query selects employees in the ‘Finance’ department or employees in the ‘Sales’ department with assignments before the current date.

These examples illustrate how the MySQL OR operator is used to combine Boolean expressions for effective data filtering.

FAQs on MySQL OR Operator - VS Code

What is the purpose of the MySQL OR operator?

Answer: The MySQL OR operator is used to combine two Boolean expressions, returning true if either expression is true, and false otherwise.

How does the MySQL OR operator handle different values and NULL?

Answer: If both operands are not NULL, the OR operator returns 1 if either operand is non-zero. If both operands are zero, it returns 0. If one operand is NULL, it returns 1 if the other operand is non-zero; otherwise, it returns NULL.

Is the MySQL OR operator short-circuited like the AND operator?

Answer: Yes, the OR operator is short-circuited in MySQL. It stops evaluating the remaining parts of the expression as soon as it can determine the result.

How does operator precedence affect the evaluation of expressions with both AND and OR operators?

Answer: MySQL evaluates the AND operator with higher precedence than the OR operator. To change the order of evaluation, parentheses can be used in the expression.

Recap

The MySQL OR operator combines Boolean expressions, returning true if at least one expression is true. It returns false if both expressions are false. MySQL uses short-circuit evaluation with the OR operator, stopping evaluation once the result is determined. Operator precedence affects the order of evaluation when an expression contains both AND and OR operators; use parentheses to change the order.
