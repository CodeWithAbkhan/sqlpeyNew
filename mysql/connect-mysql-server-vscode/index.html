Connect to MySQL Database Server using VS Code

Launch VS Code

Step 1: Install MySQL Extension for VS Code

  1. Open VS Code, go to the Extension tab, and search for the MySQL extension. Select “MySQL” with Jun Han and install.

Step 2: Add New MySQL Connection

  1. Go to File Explorer, Expend MySQL Tab and cick on plus button to Add new connection.

After clicking on the plus icon, add “localhost” as the hostname for the database to add a new MySQL connection.

Step 3: Provide User Details

  1. After adding “localhost,” add “root” as the user and add a new MySQL connection.

Step 4: Add Password for MySQL Connection

  1. After adding “root” as the user, add a password for the new MySQL connection. Skip the password if using MySQL with XAMPP Control Panel. Make sure XAMPP Control is running, and MySQL is started for the new MySQL connection.

Step 5: Add Port for MySQL Connection

  1. After adding the password, add port “3306” for the new MySQL connection.

Step 6: Skip SSL Certificate Path

  1. Hit Enter to skip the SSL Certificate path for the new MySQL connection.

Step 7: New MySQL Connection Added Successfully

  1. The new MySQL connection is added successfully.

  1. If you the Failed Connection Error Message that you received, (in case of MySQL Server instead of mysql with Xampp server):
ER_NOT_SUPPORTED_AUTH_MODE: Client does not support authentication
protocol requested by server. Consider upgrading MariaDB client.

the you can run following command in sql server client:

ALTER USER 'root'@'localhost' 
IDENTIFIED WITH mysql_native_password 
BY 'Admin@654321'

In my case, the mysql native password is “Admin@654321”, which was sent while installing My Sql Server.

Step 8: Write Query to Create Database

  1. In the new query editor window, write a query to create a database (e.g., employee-db).

Step 10: Execute Query and Check Output

  1. After executing the query, you should see the output with no errors. Refresh the localhost connection, and you will see the new database (employee-db) in the localhost list.

Now you have successfully connected to MySQL Server using both the mysql command-line client and Visual Studio Code.

FAQs on Connect to MySQL - VS Code

Q: How do I install MySQL extension in VS Code?

ANS: To install the MySQL extension in VS Code, go to the Extensions tab in VS Code, search for “MySQL” by Jun Han, and click “Install.” Once installed, you can easily manage MySQL connections directly within VS Code.

Q: How do I connect MySQL to VS Code?

ANS: After installing the MySQL extension in VS Code, open the File Explorer, expand the MySQL tab, and click the plus icon to add a new connection. Enter the hostname, user details, password, and port number (typically 3306) to connect to your MySQL server.

Q: What is the default MySQL port for connecting in VS Code?

ANS: The default port for MySQL is 3306. When connecting to MySQL via VS Code, ensure that this port is specified unless you’ve configured MySQL to use a different port.

Q: How can I fix the 'ER_NOT_SUPPORTED_AUTH_MODE' error in MySQL?

ANS: You can fix the ‘ER_NOT_SUPPORTED_AUTH_MODE’ error by running the following command in MySQL:

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'your_password';

This resolves the issue by setting MySQL to use the native password authentication method.

Q: How do I execute a query in MySQL using VS Code?

ANS: Once connected to a MySQL server in VS Code, you can execute queries by right-clicking on the connected database in the File Explorer, selecting “New Query,” and writing your SQL commands. Execute the query and see the results in the output panel.
