Removing duplicate rows in MySQL tables is a common need, especially for databases that store repetitive data entries. Knowing how to remove duplicates while retaining a single, unique instance of each entry can optimize storage and improve query performance. This guide provides solutions for handling duplicates and ensures that only unique rows remain in the database.

Problem Statement

Suppose you have a names table in MySQL with entries like the following:

SELECT * FROM names;

+----+--------+
| id | name   |
+----+--------+
| 1  | google |
| 2  | yahoo  |
| 3  | msn    |
| 4  | google |
| 5  | google |
| 6  | yahoo  |
+----+--------+

Here, the goal is to delete duplicate rows (e.g., multiple occurrences of “google” and “yahoo”) while keeping just one row for each unique value in the name column.

Solution 1: Retaining the Row with the Lowest id Value

If you want to retain the duplicate entry with the lowest id, you can use the following query:

DELETE FROM names
WHERE id NOT IN (
    SELECT * 
    FROM (
        SELECT MIN(id) 
        FROM names 
        GROUP BY name
    ) AS unique_ids
);

Explanation

  1. SELECT MIN(id) FROM names GROUP BY name: This inner query selects the lowest id for each unique name.
  2. Subquery Wrapping: Wrapping this query in an additional subquery (i.e., SELECT * FROM (...) AS unique_ids) is necessary to avoid MySQL error 1093, which prevents a table from being modified and selected from in a single query.
  3. Delete Condition: The main DELETE query removes any row where id is not in the list of minimum ids obtained from the subquery.

This method will retain the entry with the smallest id for each unique name.

Solution 2: Retaining the Row with the Highest id Value

If you prefer to retain the row with the highest id value, the query can be modified as follows:

DELETE FROM names
WHERE id NOT IN (
    SELECT * 
    FROM (
        SELECT MAX(id) 
        FROM names 
        GROUP BY name
    ) AS unique_ids
);

Explanation

This solution is similar to the previous one, but instead of MIN(id), it uses MAX(id). This keeps the row with the highest id value for each unique name.

Solution 3: Deleting Duplicate Rows Using ROW_NUMBER() for MySQL 8.0+

If you are using MySQL 8.0 or later, the ROW_NUMBER() window function can provide a simpler and more efficient solution:

WITH ranked_names AS (
    SELECT 
        id,
        name,
        ROW_NUMBER() OVER(PARTITION BY name ORDER BY id) AS row_num
    FROM names
)
DELETE FROM names 
WHERE id IN (
    SELECT id 
    FROM ranked_names 
    WHERE row_num > 1
);

Explanation

  1. ROW_NUMBER(): This assigns a unique sequential integer to rows within a partition of name, starting with 1 for the row with the lowest id.
  2. Delete Condition: Rows with row_num > 1 are deleted, which effectively keeps the first occurrence of each name.

This method leverages modern SQL functions for cleaner, more readable code.

Solution 4: Using Temporary Table for Duplicate Removal

If subqueries or window functions are not available, you can use a temporary table to remove duplicates:

CREATE TEMPORARY TABLE unique_names AS 
SELECT MIN(id) AS id, name 
FROM names 
GROUP BY name;

DELETE FROM names 
WHERE id NOT IN (SELECT id FROM unique_names);

Explanation

  1. Temporary Table Creation: A temporary table, unique_names, stores the minimum id for each unique name.
  2. Main Delete Query: The DELETE operation removes rows where id is not in the unique_names table.

This approach provides an alternative for MySQL versions that lack advanced window functions.

Solution 5: Directly Deleting Duplicates in MySQL Query

For users who want to avoid using PHP or external scripts, MySQL offers the DISTINCT keyword in SELECT statements, which can be combined with a DELETE operation:

DELETE n1 
FROM names n1, names n2 
WHERE n1.name = n2.name 
AND n1.id > n2.id;

Explanation

  1. Self-Join: The query uses a self-join to compare each row (n1) with every other row (n2) that has the same name.
  2. Delete Condition: If n1.id is greater than n2.id, it indicates a duplicate, which is then deleted.

This self-join method is straightforward but can be resource-intensive for larger tables.

Alternative Methods for Removing Duplicates

1. Using PHP to Filter Duplicates

Another approach is to retrieve the entire table in PHP, filter duplicates in code, and reinsert only unique rows. However, this can be less efficient for large datasets. Learn more about PHP array filtering .

2. MySQL Triggers to Avoid Duplicate Inserts

MySQL triggers can enforce uniqueness at the insertion stage by rejecting duplicate entries. This preventive measure helps maintain data integrity. For more on MySQL triggers, check out the official MySQL documentation .

FAQs on Solved: Delete Duplicate Rows in MySQL While Retaining One Unique Row

Q: Why does MySQL return error 1093 during deletion?

A: Error 1093 occurs when trying to modify and select from the same table in a single query. To avoid this, use a subquery or temporary table.

Q: Can I use MySQL to remove duplicates without using PHP?

A: Yes, you can use SQL queries alone, as shown in Solutions 1–5, without relying on PHP for data cleanup.

Q: Is there a way to prevent duplicates during data entry?

A: Enforcing unique constraints or using MySQL triggers are effective ways to prevent duplicate entries.
