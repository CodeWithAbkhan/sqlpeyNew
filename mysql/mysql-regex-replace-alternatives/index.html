“MySQL REGEXP_REPLACE Alternative: Efficient String Manipulation”

When working with databases, particularly MySQL, the need to manipulate strings using regular expressions for replacements is frequent. While MySQL 8.0+ offers the convenient REGEXP_REPLACE function, users on older versions or those seeking alternative approaches often look for different methods. This post delves into several effective strategies for achieving regular expression-based string replacements in MySQL, covering native functions, user-defined functions (UDFs), and procedural techniques.

Solution 1: Leveraging REGEXP_REPLACE in MariaDB and MySQL 8.0+

For modern database systems, REGEXP_REPLACE is the most direct and efficient solution. It allows for sophisticated pattern matching and replacement.

Syntax:

REGEXP_REPLACE(string, pattern, replacement)

Example with Grouping:

This example demonstrates how to use capturing groups within the pattern to reorder parts of the string.

SELECT REGEXP_REPLACE("stackoverflow", "(stack)(over)(flow)", '\\2 - \\1 - \\3');

Output:

over - stack - flow

This function is particularly powerful when combined with PCRE regular expression enhancements, offering extensive capabilities for pattern matching.

Solution 2: Using User-Defined Functions (UDFs) for Older MySQL Versions

If you are operating on a MySQL version prior to 8.0, the native REGEXP_REPLACE is unavailable. In such cases, employing a User-Defined Function (UDF) is a common and effective workaround. A popular option is mysql-udf-regexp.

Solution 3: Advanced REGEXP_REPLACE Usage in MySQL 8.0+

MySQL 8.0+ provides enhanced regular expression support through the International Components for Unicode (ICU) library. This includes functions like REGEXP_INSTR, REGEXP_REPLACE, and REGEXP_SUBSTR, offering full Unicode and multibyte safety.

Function Signature:

REGEXP_REPLACE(expr, pat, repl[, pos[, occurrence[, match_type]]])
  • expr: The input string.
  • pat: The regular expression pattern to search for.
  • repl: The replacement string.
  • pos (optional): The starting position for the search.
  • occurrence (optional): Specifies which occurrence to replace (0 means all).
  • match_type (optional): Modifiers like ‘c’ for case-sensitive, ‘i’ for case-insensitive.

Example with Match Type:

This example replaces all uppercase letters with a hyphen, starting from the first character, and performs a case-sensitive match.

SELECT REGEXP_REPLACE('Stackoverflow','[A-Z]','-',1,0,'c');

Output:

-tackover-low

Solution 4: Scripting with mysqldump, sed, and mysqlimport

For a more manual but robust approach, especially for bulk operations, you can export your data, perform replacements using external tools like sed, and then re-import it.

  1. Dump the table: 
    mysqldump -u user -p database table > dump.sql
  2. Find and replace using sed: 
    find /path/to/dump.sql -type f -exec sed -i 's/old_string/new_string/g' {} \;
    This command uses sed to perform a global replacement (s/old/new/g) on the dump file. You can also use Perl-compatible regular expressions for more complex patterns.
  3. Import the table: 
    mysqlimport -u user -p database table < dump.sql
    Before executing, it’s wise to create a backup of your data and run verification queries to ensure the replacements are as intended and haven’t corrupted data.

Solution 5: Creating a Custom MySQL regex_replace Function

If you require more control or wish to replicate advanced REGEXP_REPLACE behavior on older versions, you can define your own stored function. The following example implements a function that iterates through the string, character by character, to perform replacements based on a pattern.

Function Code:

DELIMITER $$

CREATE FUNCTION `regex_replace`(pattern VARCHAR(1000), replacement VARCHAR(1000), original VARCHAR(1000))
RETURNS VARCHAR(1000)
DETERMINISTIC
BEGIN
 DECLARE temp VARCHAR(1000);
 DECLARE ch VARCHAR(1);
 DECLARE i INT;
 SET i = 1;
 SET temp = '';
 IF original REGEXP pattern THEN
  loop_label: LOOP
   IF i > CHAR_LENGTH(original) THEN
    LEAVE loop_label;
   END IF;
   SET ch = SUBSTRING(original,i,1);
   IF NOT ch REGEXP pattern THEN
    SET temp = CONCAT(temp,ch);
   ELSE
    SET temp = CONCAT(temp,replacement);
   END IF;
   SET i=i+1;
  END LOOP;
 ELSE
  SET temp = original;
 END IF;
 RETURN temp;
END$$

DELIMITER ;

Example Execution:

This example removes all characters that are not alphanumeric, hyphens, or periods.

SELECT regex_replace('[^a-zA-Z0-9\-]', '', '2my test3_text-to. check \\ my- sql (regular) ,expressions ._,');

Output:

2mytest3text-to check my-sql expressions

Solution 6: Non-Regex Replacement for Exact Matches

For simple, exact string replacements without the complexity of regular expressions, the REPLACE function combined with CONCAT and TRIM can be very effective. This method is often more performant for direct string substitutions.

Example:

This query replaces the exact string ’ jay ’ with ’ abc ’ for the employee_firstname column, ensuring whole word replacement by padding with spaces.

UPDATE employee
SET employee_firstname = TRIM(REPLACE(CONCAT(' ', employee_firstname, ' '), ' jay ', ' abc '));

Solution 7: A More Sophisticated UDF with Match Lengths

This advanced UDF implementation, inspired by Stevettt’s blog post , offers greater control over the replacement process, including greedy and non-greedy matching, and minimum/maximum match lengths for efficiency.

Function Definition:

--

-- USAGE
--

DELIMITER $$

CREATE FUNCTION regex_replace(pattern VARCHAR(1000),replacement VARCHAR(1000),original VARCHAR(1000)) RETURNS VARCHAR(1000) DETERMINISTIC BEGIN DECLARE temp VARCHAR(1000); DECLARE ch VARCHAR(1); DECLARE i INT; SET i = 1; SET temp = ‘’; IF original REGEXP pattern THEN loop_label: LOOP IF i>CHAR_LENGTH(original) THEN LEAVE loop_label;
END IF; SET ch = SUBSTRING(original,i,1); IF NOT ch REGEXP pattern THEN SET temp = CONCAT(temp,ch); ELSE SET temp = CONCAT(temp,replacement); END IF; SET i=i+1; END LOOP; ELSE SET temp = original; END IF; RETURN temp; END$$

-- SELECT reg_replace(<subject>,
--                    <pattern>,
--                    <replacement>,
--                    <greedy>,
--                    <minMatchLen>,
--                    <maxMatchLen>);
-- where:
-- <subject> is the string to look in for doing the replacements
-- <pattern> is the regular expression to match against
-- <replacement> is the replacement string
-- <greedy> is TRUE for greedy matching or FALSE for non-greedy matching
-- <minMatchLen> specifies the minimum match length
-- <maxMatchLen> specifies the maximum match length
-- (minMatchLen and maxMatchLen are used to improve efficiency but are
--  optional and can be set to 0 or NULL if not known/required)
-- Example:
-- SELECT reg_replace(txt, '^[Tt][^ ]* ', 'a', TRUE, 2, 0) FROM tbl;
DROP FUNCTION IF EXISTS reg_replace;
DELIMITER //
CREATE FUNCTION reg_replace(subject VARCHAR(21845), pattern VARCHAR(21845),
  replacement VARCHAR(21845), greedy BOOLEAN, minMatchLen INT, maxMatchLen INT)
RETURNS VARCHAR(21845) DETERMINISTIC BEGIN
  DECLARE result, subStr, usePattern VARCHAR(21845);
  DECLARE startPos, prevStartPos, startInc, len, lenInc INT;
  IF subject REGEXP pattern THEN
    SET result = '';
    -- Sanitize input parameter values
    SET minMatchLen = IF(minMatchLen IS NULL OR minMatchLen < 1, 1, minMatchLen);
    SET maxMatchLen = IF(maxMatchLen IS NULL OR maxMatchLen < 1
                         OR maxMatchLen > CHAR_LENGTH(subject),
                         CHAR_LENGTH(subject), maxMatchLen);
    -- Set the pattern to use to match an entire string rather than part of a string
    SET usePattern = IF (LEFT(pattern, 1) = '^', pattern, CONCAT('^', pattern));
    SET usePattern = IF (RIGHT(pattern, 1) = '$', usePattern, CONCAT(usePattern, '$'));
    -- Set start position to 1 if pattern starts with ^ or doesn't end with $.
    IF LEFT(pattern, 1) = '^' OR RIGHT(pattern, 1) <> '$' THEN
      SET startPos = 1, startInc = 1;
    -- Otherwise (i.e. pattern ends with $ but doesn't start with ^): Set start pos
    -- to the min or max match length from the end (depending on "greedy" flag).
    ELSEIF greedy THEN
      SET startPos = CHAR_LENGTH(subject) - maxMatchLen + 1, startInc = 1;
    ELSE
      SET startPos = CHAR_LENGTH(subject) - minMatchLen + 1, startInc = -1;
    END IF;
    WHILE startPos >= 1 AND startPos <= CHAR_LENGTH(subject)
      AND startPos + minMatchLen - 1 <= CHAR_LENGTH(subject)
      AND !(LEFT(pattern, 1) = '^' AND startPos <> 1)
      AND !(RIGHT(pattern, 1) = '$'
            AND startPos + maxMatchLen - 1 < CHAR_LENGTH(subject)) DO
      -- Set start length to maximum if matching greedily or pattern ends with $.
      -- Otherwise set starting length to the minimum match length.
      IF greedy OR RIGHT(pattern, 1) = '$' THEN
        SET len = LEAST(CHAR_LENGTH(subject) - startPos + 1, maxMatchLen), lenInc = -1;
      ELSE
        SET len = minMatchLen, lenInc = 1;
      END IF;
      SET prevStartPos = startPos;
      lenLoop: WHILE len >= 1 AND len <= maxMatchLen
                 AND startPos + len - 1 <= CHAR_LENGTH(subject)
                 AND !(RIGHT(pattern, 1) = '$'
                       AND startPos + len - 1 <> CHAR_LENGTH(subject)) DO
        SET subStr = SUBSTRING(subject, startPos, len);
        IF subStr REGEXP usePattern THEN
          SET result = IF(startInc = 1,
                          CONCAT(result, replacement), CONCAT(replacement, result));
          SET startPos = startPos + startInc * len;
          LEAVE lenLoop;
        END IF;
        SET len = len + lenInc;
      END WHILE;
      IF (startPos = prevStartPos) THEN
        SET result = IF(startInc = 1, CONCAT(result, SUBSTRING(subject, startPos, 1)),
                        CONCAT(SUBSTRING(subject, startPos, 1), result));
        SET startPos = startPos + startInc;
      END IF;
    END WHILE;
    IF startInc = 1 AND startPos <= CHAR_LENGTH(subject) THEN
      SET result = CONCAT(result, RIGHT(subject, CHAR_LENGTH(subject) + 1 - startPos));
    ELSEIF startInc = -1 AND startPos >= 1 THEN
      SET result = CONCAT(LEFT(subject, startPos), result);
    END IF;
  ELSE
    SET result = subject;
  END IF;
  RETURN result;
END//
DELIMITER ;

Solution 8: Using lib_mysqludf_preg

The lib_mysqludf_preg package is a powerful UDF library that provides enhanced regular expression capabilities, including a PREG_REPLACE function, which is highly compatible with Perl’s regular expression syntax.

Sample SQL:

SELECT PREG_REPLACE('/(.*?)(fox)/' , 'dog' , 'the quick brown fox' ) AS demo;

This package is often cited as a superior alternative for complex regex operations in MySQL. You can find more information and installation instructions through community resources.

Solution 9: Conditional Replacement with REPLACE and REGEXP

For scenarios where you need to apply replacements only to rows matching a specific pattern, a CASE statement within an UPDATE query can be employed. This approach uses REGEXP for conditional matching and REPLACE for the substitution.

Example:

This query updates rows where column contains the whole word ‘WORD_TO_REPLACE’, replacing it with ‘REPLACEMENT’.

UPDATE db.tbl
SET column =
CASE
WHEN column REGEXP '[[:<:]]WORD_TO_REPLACE[[:>:]]'
THEN REPLACE(column, 'WORD_TO_REPLACE', 'REPLACEMENT')
END
WHERE column REGEXP '[[:<:]]WORD_TO_REPLACE[[:>:]]';

The [[:<:]] and [[:>:]] are word boundary anchors, ensuring that only whole words are matched.

Solution 10: Direct UPDATE with REGEXP_REPLACE (MySQL 8.0+)

For MySQL 8.0 and later, the most straightforward way to update rows using regular expression replacements is to directly use the REGEXP_REPLACE function within the UPDATE statement.

Syntax:

UPDATE `table_name`
SET column_name_to_find = REGEXP_REPLACE(column_name_to_find, 'string-to-find', 'string-to-replace')
WHERE column_name_to_find REGEXP 'string-to-find';

Solution 11: Using IF and REGEXP in SELECT Statements

You can conditionally modify string outputs in SELECT statements using the IF function combined with REGEXP. This is useful for data presentation or transformation without altering the stored data.

Syntax:

SELECT IF(column_name REGEXP 'pattern','replacement',column_name)
FROM table1
WHERE column_name LIKE 'prefix%';

Example:

This selects ‘ABC’ if the string matches ‘ABC’ followed by a digit at the end, otherwise it returns the original string.

SELECT IF('ABC1' REGEXP 'ABC[0-9]$','ABC','ABC1');

Output:

ABC

Solution 12: Custom REGEX_REPLACE with REGEX_CAPTURE_LEFTMOST

This approach involves creating two UDFs: one to capture the leftmost matching substring (REGEX_CAPTURE_LEFTMOST) and another to iteratively replace all occurrences using the first function.

Function Implementations:

-- Function to capture the leftmost matching substring
DELIMITER $$
CREATE FUNCTION REGEX_CAPTURE_LEFTMOST(
  var_original VARCHAR(1000),
  var_pattern VARCHAR(1000)
  ) RETURNS
    VARCHAR(1000)
  COMMENT '
  Captures the leftmost substring that matches the [var_pattern]
  IN [var_original], OR NULL if no match.
  '
BEGIN
  DECLARE var_temp_l VARCHAR(1000);
  DECLARE var_temp_r VARCHAR(1000);
  DECLARE var_left_trim_index INT;
  DECLARE var_right_trim_index INT;
  SET var_left_trim_index = 1;
  SET var_right_trim_index = 1;
  SET var_temp_l = '';
  SET var_temp_r = '';
  WHILE (CHAR_LENGTH(var_original) >= var_left_trim_index) DO
    SET var_temp_l = LEFT(var_original, var_left_trim_index);
    IF var_temp_l REGEXP var_pattern THEN
      WHILE (CHAR_LENGTH(var_temp_l) >= var_right_trim_index) DO
        SET var_temp_r = RIGHT(var_temp_l, var_right_trim_index);
        IF var_temp_r REGEXP var_pattern THEN
          RETURN var_temp_r;
          END IF;
        SET var_right_trim_index = var_right_trim_index + 1;
        END WHILE;
      END IF;
    SET var_left_trim_index = var_left_trim_index + 1;
    END WHILE;
  RETURN NULL;
END $$
DELIMITER ;

-- Function to perform iterative replacement
DELIMITER $$
CREATE FUNCTION REGEX_REPLACE(
  var_original VARCHAR(1000),
  var_pattern VARCHAR(1000),
  var_replacement VARCHAR(1000)
  ) RETURNS
    VARCHAR(1000)
  COMMENT 'Based on https://techras.wordpress.com/2011/06/02/regex-replace-for-mysql/'
BEGIN
  DECLARE var_replaced VARCHAR(1000) DEFAULT var_original;
  DECLARE var_leftmost_match VARCHAR(1000) DEFAULT
    REGEX_CAPTURE_LEFTMOST(var_original, var_pattern);
    WHILE var_leftmost_match IS NOT NULL DO
      IF var_replacement <> var_leftmost_match THEN
        SET var_replaced = REPLACE(var_replaced, var_leftmost_match, var_replacement);
        SET var_leftmost_match = REGEX_CAPTURE_LEFTMOST(var_replaced, var_pattern);
        ELSE
          SET var_leftmost_match = NULL;
        END IF;
      END WHILE;
  RETURN var_replaced;
END $$
DELIMITER ;

Solution 13: Replacing Non-Alphanumeric Characters

A common use case is cleaning strings by removing unwanted characters. This UPDATE statement targets column entries containing characters outside the typical alphanumeric, underscore, dot, hyphen, and parenthesis set.

UPDATE table_name
  SET column_name = 'seach_str_name' -- Replace 'seach_str_name' with your desired cleaning character or empty string
  WHERE column_name REGEXP '[^a-zA-Z0-9()_ .\-]';

Considerations for Performance:

  • For very large datasets, UDFs or scripting solutions might be more performant than complex character-by-character iteration within stored procedures.
  • Ensure your regular expressions are optimized to avoid excessive backtracking.
  • MySQL 8.0+’s native REGEXP_REPLACE is generally the most efficient option.

FAQs on MySQL REGEXP_REPLACE Alternatives

Q: What is the primary advantage of using MySQL 8.0's REGEXP_REPLACE function

ANS: MySQL 8.0’s REGEXP_REPLACE offers native, efficient, and often more readable syntax for regular expression replacements, supporting advanced features like Unicode and multibyte characters directly.

Q: Can I use REGEXP_REPLACE in older MySQL versions

ANS: No, REGEXP_REPLACE is available starting from MySQL version 8.0. For older versions, you would typically use User-Defined Functions (UDFs) or external scripting methods.

Q: What are some common alternatives to REGEXP_REPLACE for older MySQL versions

ANS: Common alternatives include creating custom stored functions that mimic REGEXP_REPLACE behavior, using UDF libraries like lib_mysqludf_preg, or employing external tools like sed with database dumps.

Q: Is it possible to replace exact string matches without regex in MySQL

ANS: Yes, for exact string matches, the standard REPLACE() function in MySQL is sufficient and generally more performant than using regular expressions.

Q: How do UDFs improve regex replacement in MySQL

ANS: UDFs extend MySQL’s functionality by allowing you to write custom functions, often in languages like C or C++, that can implement complex logic like advanced regular expression parsing and replacement, which might not be natively supported.
