“Top 12 Ways to Filter Pandas DataFrames Using ‘IN’ and ‘NOT IN’”

When working with data in Python, particularly using the powerful Pandas library, filtering rows based on whether a column’s value exists within a specific list or set of values is a common operation. This is often referred to as an ‘IN’ or ‘NOT IN’ query. Pandas provides several elegant and efficient ways to accomplish this, catering to various scenarios and performance considerations.

This comprehensive guide explores twelve distinct methods to filter your Pandas DataFrames, covering both inclusion (‘IN’) and exclusion (‘NOT IN’) logic. We’ll provide clear explanations and practical code examples for each, enabling you to choose the best approach for your specific needs. For those interested in the underlying data structures, delve into the introduction to Pandas and explore the fundamentals of what is SQL .

Filtering by Inclusion (‘IN’) and Exclusion (‘NOT IN’)

The core task involves selecting rows where a column’s value matches any in a given list, or conversely, selecting rows where it does not. Let’s explore the methods.

Solution 1: Using pandas.Series.isin()

The most idiomatic and frequently used method for this task is pandas.Series.isin(). It directly checks for membership of each element in a Series against a provided list or iterable.

For ‘IN’ operation:

import pandas as pd
import numpy as np

df = pd.DataFrame({'country': ['US', 'UK', 'Germany', 'China', np.nan]})
countries_to_keep = ['UK', 'China']

# Filter rows where 'country' is in countries_to_keep
filtered_df = df[df.country.isin(countries_to_keep)]
print(filtered_df)

Output:

  country
1      UK
3   China

For ‘NOT IN’ operation:

The negation operator ~ can be used to invert the boolean mask generated by isin().

# Filter rows where 'country' is NOT in countries_to_keep
not_in_df = df[~df.country.isin(countries_to_keep)]
print(not_in_df)

Output:

   country
0       US
2  Germany
4      NaN

Solution 2: Using DataFrame.query()

The query() method offers a more SQL-like syntax for filtering DataFrames. It can be particularly readable for complex conditions.

For ‘IN’ operation:

# Filter using query for 'IN'
query_in_df = df.query("country in @countries_to_keep")
print(query_in_df)

Output:

  country
1      UK
3   China

For ‘NOT IN’ operation:

# Filter using query for 'NOT IN'
query_not_in_df = df.query("country not in @countries_to_keep")
print(query_not_in_df)

Output:

   country
0       US
2  Germany
4      NaN

Solution 3: Filtering on Multiple Columns with DataFrame.isin()

When you need to check for membership across multiple columns, you can use DataFrame.isin().

Consider a DataFrame df2:

df2 = pd.DataFrame({
    'A': ['x', 'y', 'z', 'q'],
    'B': ['w', 'a', np.nan, 'x'],
    'C': np.arange(4)
})
filter_list = ['x', 'w', 'p']

Applying isin to specific columns:

# Check for 'x' or 'w' or 'p' in columns 'A' and 'B'
isin_multiple_cols = df2[['A', 'B']].isin(filter_list)
print(isin_multiple_cols)

Output:

       A      B
0   True   True
1  False  False
2  False  False
3  False   True

Retaining rows where at least one column matches (using any()):

# Retain rows where at least one of the selected columns matches
any_match_df = df2[df2[['A', 'B']].isin(filter_list).any(axis=1)]
print(any_match_df)

Output:

   A  B  C
0  x  w  0
3  q  x  3

Retaining rows where all selected columns match (using all()):

# Retain rows where all of the selected columns match
all_match_df = df2[df2[['A', 'B']].isin(filter_list).all(axis=1)]
print(all_match_df)

Output:

   A  B  C
0  x  w  0

To apply this to all columns, simply omit the column selection:

# Apply to all columns
all_columns_match_df = df2[df2.isin(filter_list).any(axis=1)]
print(all_columns_match_df)

Output:

   A  B  C
0  x  w  0
3  q  x  3

Solution 4: Using numpy.isin()

NumPy’s isin function can also be leveraged, often offering performance benefits for large datasets due to lower overhead.

For ‘IN’ operation:

# Using numpy.isin for 'IN'
numpy_in_df = df[np.isin(df['countries'], countries_to_keep)]
print(numpy_in_df)

Output:

  countries
1        UK
4     China

For ‘NOT IN’ operation:

The invert=True parameter in np.isin handles the ‘NOT IN’ logic.

# Using numpy.isin for 'NOT IN'
numpy_not_in_df = df[np.isin(df['countries'], countries_to_keep, invert=True)]
print(numpy_not_in_df)

Output:

  countries
0        US
2   Germany
3       NaN

Solution 5: List Comprehensions with ‘in’ (for String Data)

For string data, list comprehensions can be an alternative, especially when combined with sets for efficiency.

countries_set = set(countries_to_keep)

# Using list comprehension for 'IN'
list_comp_in_df = df[
    [x in countries_set for x in df['countries']]
]
print(list_comp_in_df)

# Using list comprehension for 'NOT IN'
list_comp_not_in_df = df[
    [x not in countries_set for x in df['countries']]
]
print(list_comp_not_in_df)

Output for ‘IN’:

  countries
1        UK
4     China

Output for ‘NOT IN’:

  countries
0        US
2   Germany
3       NaN

Solution 6: Using DataFrame.apply() with a Lambda Function

While generally less performant than vectorized methods for large datasets, apply() can be useful for more complex row-wise logic.

# Using apply for 'NOT IN'
criterion = lambda row: row['countries'] not in countries_to_keep
not_in_apply_df = df[df.apply(criterion, axis=1)]
print(not_in_apply_df)

Output:

  countries
0        US
2   Germany
3       NaN

Solution 7: Combining Filtering Methods

This section illustrates various ways to express ‘NOT IN’ logic, often using negation with isin.

# Various 'NOT IN' expressions
df_not_in_1 = df[~df["countries"].isin([3, 6])]
df_not_in_2 = df[df["countries"].isin([3, 6]) == False]
df_not_in_3 = df[np.logical_not(df["countries"].isin([3, 6]))]

Solution 10: Using query() with isin() and Comparison Operators

The query() method can also directly use .isin() or standard comparison operators.

Using .isin() within query():

# Using isin within query
query_isin_values_df = df.query('country.isin(@countries_to_keep).values')
print(query_isin_values_df)

# Negating the query
query_not_isin_values_df = df.query('~country.isin(@countries_to_keep).values')
print(query_not_isin_values_df)

Using comparison operators within query():

# Using comparison operators within query
query_equal_df = df.query('country == @countries_to_keep')
print(query_equal_df)

# Negating with !=
query_not_equal_df = df.query('country != @countries_to_keep')
print(query_not_equal_df)

Solution 11: Filtering with Unique Values

This method constructs a ‘NOT IN’ condition by identifying unique values not present in the target list.

df_unique = pd.DataFrame({'countries':['US','UK','Germany','China']})
countries_filter = ['UK','China']

# 'IN' operation
in_unique_df = df_unique[df_unique.countries.isin(countries_filter)]
print(in_unique_df)

# 'NOT IN' operation using unique values
not_in_unique_df = df_unique[df_unique.countries.isin(
    [x for x in np.unique(df_unique.countries) if x not in countries_filter]
)]
print(not_in_unique_df)

Output for ‘IN’:

  countries
1        UK
3     China

Output for ‘NOT IN’:

  countries
0        US
2   Germany

Solution 12: Preserving Order and Splitting DataFrames

Preserving order with reindex:

df_reindex = pd.DataFrame({'country': ['US', 'UK', 'Germany', 'China']})
countries_order = ['Germany', 'US']

# Get indices and reindex
indices = [df_reindex.index[df_reindex['country'] == i].tolist() for i in countries_order]
flat_indices = [item for sublist in indices for item in sublist]
ordered_df = df_reindex.reindex(flat_indices)
print(ordered_df)

Output:

   country
2  Germany
0       US

Splitting into two DataFrames using groupby():

The boolean mask from isin() can split a DataFrame.

df_split = pd.DataFrame({'country': ['US', 'UK', 'Germany', 'China'], 'value': range(4)})
countries_split = ['UK', 'China']

df_have, df_have_not = [g for _, g in df_split.groupby(df_split['country'].isin(countries_split))]
print("DataFrame with selected countries:")
print(df_have)
print("\nDataFrame without selected countries:")
print(df_have_not)

Output:

DataFrame with selected countries:
  country  value
1      UK      1
3   China      3

DataFrame without selected countries:
   country  value
0       US      0
2  Germany      2

Using eval() for memory efficiency:

eval() can be more memory-efficient than query() for certain operations, especially when filtering a single column.

# Using eval for filtering a single column efficiently

FAQs on Top 12 Ways to Filter Pandas DataFrames Using ‘IN’ and ‘NOT IN’

Q: What is the most efficient way to filter a Pandas DataFrame by a list of values

ANS: For most cases, pandas.Series.isin() is highly efficient and readable. For very large datasets, benchmarking your specific use case might reveal marginal differences with numpy.isin() or optimized query() usage. Consider reading about Pandas performance tips .

Q: How to filter rows that do not contain specific values in Pandas

ANS: Use the negation operator ~ with pandas.Series.isin(). For example: df[~df['column_name'].isin(list_of_values)]. Alternatively, df.query('column_name not in @list_of_values') is also effective. Learn more about Pandas filtering .

Q: Can I filter based on values present in another DataFrame's column

ANS: Yes, you can extract the column from the second DataFrame into a list or Series and then use it with isin() or query() on the first DataFrame. For instance, df1[df1['col_a'].isin(df2['col_b'])]. Check out solutions for fixing common Pandas errors .

Q: How does DataFrame.query perform compared to Series.isin

ANS: Both DataFrame.query() and Series.isin() are generally performant. Benchmarks often show isin() to be slightly faster for simple membership checks, while query() can offer better readability for complex conditional logic and may leverage optimized execution engines like numexpr. Explore solutions for handling Pandas errors .

Q: Is there a way to filter a DataFrame and keep the original order of the filter list

ANS: Yes, you can achieve this by first identifying the indices of the rows that match your desired order and then using DataFrame.reindex() to reorder the filtered DataFrame. This is demonstrated in Solution 10. You might also find Pandas index manipulation helpful.
