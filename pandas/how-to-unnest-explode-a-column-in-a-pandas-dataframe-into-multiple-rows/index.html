Top 10 Pandas Dataframe Unnesting Techniques

Working with data often involves dealing with columns that contain list-like structures or nested objects. Transforming these into a more “flat” format, where each element of the list gets its own row, is a common data wrangling task. This process, often referred to as unnesting or exploding, can be achieved using various methods within the Python ecosystem, primarily with the powerful pandas library.

When encountering object dtype columns containing complex data structures, the immediate thought is to “flatten” or unnest them. This guide explores multiple techniques to achieve this, catering to different scenarios and offering insights into performance. We’ll cover solutions using pandas, numpy, and combinations thereof.

Method 0: Using pandas.DataFrame.explode (Pandas >= 0.25)

For pandas versions 0.25 and later, the explode() method provides a direct and elegant solution for unnesting a single column.

Consider a DataFrame like this:

import pandas as pd
import numpy as np

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})
print("Original DataFrame:")
print(df)

Output:

Original DataFrame:
   A       B
0  1  [1, 2]
1  2  [1, 2]

To “explode” column ‘B’:

df_exploded = df.explode('B')
print("\nDataFrame after exploding 'B':")
print(df_exploded)

Output:

DataFrame after exploding 'B':
   A  B
0  1  1
0  1  2
1  2  1
1  2  2

Handling NaNs and Empty Lists: The explode() method gracefully handles empty lists. However, NaN values in list columns require pre-processing. You should replace NaN with an empty list to avoid issues.

df_with_nan = pd.DataFrame({'A': [1, 2, 3, 4],'B': [[1, 2], [1, 2], [], np.nan]})
print("\nDataFrame with NaN and empty list:")
print(df_with_nan)

df_with_nan.loc[:, 'B'] = df_with_nan.loc[:, 'B'].apply(lambda x: [] if pd.isna(x) else x)
print("\nDataFrame after filling NaN with []:")
print(df_with_nan.explode('B'))

Output:

DataFrame with NaN and empty list:
   A             B
0  1        [1, 2]
1  2        [1, 2]
2  3            []
3  4           NaN

DataFrame after filling NaN with []:
   A    B
0  1    1
0  1    2
1  2    1
1  2    2
2  3  NaN
3  4  NaN

Note: The output for NaN rows can vary slightly depending on pandas version; typically, NaN will remain NaN after exploding an empty list.

Method 1: apply + pd.Series

This method is conceptually straightforward but can be less performant for very large datasets. It involves converting the list-like column into a Series of Series, then stacking it.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Set 'A' as index, apply pd.Series to 'B', stack, reset index, and rename
result = df.set_index('A').B.apply(pd.Series).stack().reset_index(level=0).rename(columns={0:'B'})
print("\nResult using apply + pd.Series:")
print(result)

Output:

Result using apply + pd.Series:
   A  B
0  1  1
1  1  2
0  2  1
1  2  2

Method 2: repeat with DataFrame Constructor

This approach is effective, particularly when dealing with a single list-like column. It leverages numpy.repeat to expand the non-list column based on the length of the lists, then concatenates the list values.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Repeat 'A' based on the length of list in 'B', then concatenate flattened 'B'
result = pd.DataFrame({'A':df.A.repeat(df.B.str.len()), 'B':np.concatenate(df.B.values)})
print("\nResult using repeat and DataFrame constructor:")
print(result)

Output:

Result using repeat and DataFrame constructor:
   A  B
0  1  1
0  1  2
1  2  1
1  2  2

Method 2.1: Handling Multiple Non-List Columns with repeat

If you have multiple columns to keep that are not list-like, Method 2 becomes cumbersome as you need to repeat each one individually. A better approach is to create a temporary DataFrame with the flattened list and then join it back.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Create a temporary DataFrame for the flattened 'B' column
s = pd.DataFrame({'B': np.concatenate(df.B.values)}, index=df.index.repeat(df.B.str.len()))

# Join with the original DataFrame, dropping the original 'B' column
result = s.join(df.drop('B', axis=1), how='left')
print("\nResult of Method 2.1 (joining after repeat):")
print(result)

# To maintain original column order:
print("\nResult maintaining original column order:")
print(result.reindex(columns=df.columns))

Output:

Result of Method 2.1 (joining after repeat):

0  1  1
0  2  1
1  1  2
1  2  2

Result maintaining original column order:
   A  B
0  1  1
0  2  1
1  1  2

Method 3: List Comprehension with DataFrame Creation

This method uses a list comprehension to restructure the data into a new DataFrame. It’s quite Pythonic and can be efficient.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Recreate the list structure using list comprehension
result = pd.DataFrame([[x] + [z] for x, y in df.values for z in y], columns=df.columns)
print("\nResult using list comprehension:")
print(result)

Output:

Result using list comprehension:

0  1  1
1  1  2
2  2  1

For multiple list-like columns, you can adapt the comprehension:

df_multi = pd.DataFrame({'A':[1,2],'B':[[1,2],[3,4]],'C':[[1,2],[3,4]]})

# Modified comprehension for multiple columns
temp_list = []
for index, row in df_multi.iterrows():

    b_vals = row['B']
    c_vals = row['C']
    for b_item, c_item in zip(b_vals, c_vals):
        temp_list.append([a_val, b_item, c_item])

result_multi = pd.DataFrame(temp_list, columns=df_multi.columns)

Method 4: Using reindex or loc with assign

This approach expands the DataFrame index based on the lengths of the lists in the target column and then assigns the concatenated list values.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Repeat index, then assign concatenated 'B' values
result = df.reindex(df.index.repeat(df.B.str.len())).assign(B=np.concatenate(df.B.values))

Method 5: collections.ChainMap (for unique values)

This method is particularly neat when the lists within the column contain unique values and you want to pair them up. It uses ChainMap to create a dictionary-like structure.

from collections import ChainMap

df = pd.DataFrame({'A':[1,2],'B':[[1,2],[3,4]]})

# Create a dictionary mapping values from 'B' to 'A'
# dict.fromkeys ensures unique keys if 'B' had duplicates
d = dict(ChainMap(*map(dict.fromkeys, df['B'], df['A'])))

# Convert the dictionary back to a DataFrame, reversing columns for desired order
result = pd.DataFrame(list(d.items()), columns=df.columns[::-1])
print("\nResult using ChainMap (for unique values):")
print(result)

Output:

Result using ChainMap (for unique values):

0  1  1
1  2  1
2  3  2
3  4  2

Method 6: High-Performance Unnesting with NumPy

Leveraging NumPy’s array manipulation capabilities can yield significant performance gains. np.dstack is used here to create a 3D array and then reshape it.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Use np.dstack for efficient array stacking and concatenation
newvalues = np.dstack((np.repeat(df.A.values, list(map(len, df.B.values))), np.concatenate(df.B.values)))
result = pd.DataFrame(data=newvalues[0], columns=df.columns)
print("\nResult using NumPy dstack:")
print(result)

Method 7: Pure Python with itertools.cycle and chain

For those who appreciate pure Python solutions, itertools offers powerful tools. This method uses cycle to repeat elements and chain to flatten nested iterables.

from itertools import cycle, chain

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})

# Convert DataFrame to list and process using itertools
l = df.values.tolist()
l1 = [list(zip([x[0]], cycle(x[1])) if len([x[0]]) > len(x[1]) else list(zip(cycle([x[0]]), x[1]))) for x in l]
result = pd.DataFrame(list(chain.from_iterable(l1)), columns=df.columns)
print("\nResult using itertools cycle and chain:")
print(result)

Output:

Result using itertools cycle and chain:
   A  B
0  1  1
1  1  2
2  2  1
3  2  2

Generalizing to Multiple Columns

When you need to unnest multiple columns simultaneously, custom functions are often necessary. The core idea is to replicate the rows based on the lengths of the lists in the columns to be unnested and then combine the data.

Consider a DataFrame with multiple list-like columns:

df_multi = pd.DataFrame({'A':[1,2],'B':[[1,2],[3,4]],'C':[[1,2],[3,4]]})
print("\nDataFrame with multiple list columns:")
print(df_multi)

Output:

DataFrame with multiple list columns:
   A       B       C
0  1  [1, 2]  [1, 2]
1  2  [3, 4]  [3, 4]

A function to handle this:

def unnest_multiple(df, explode_columns):
    # Repeat the index for each element in the first column to explode
    idx = df.index.repeat(df[explode_columns[0]].str.len())

    # Concatenate the unnested columns
    df_unnested_cols = pd.concat(
        [pd.DataFrame({col: np.concatenate(df[col].values)}) for col in explode_columns],
        axis=1
    )
    df_unnested_cols.index = idx

    # Join back with the rest of the DataFrame
    return df_unnested_cols.join(df.drop(explode_columns, axis=1), how='left')

result_multi_unnest = unnest_multiple(df_multi, ['B', 'C'])
print("\nResult of unnesting multiple columns:")
print(result_multi_unnest)

Output:

Result of unnesting multiple columns:
   B  C  A
0  1  1  1
0  2  2  1
1  3  3  2
1  4  4  2

Column-wise Expansion (Horizontal Explode)

If the goal is to expand lists into separate columns rather than rows, you can use pd.DataFrame constructor on the list column and then join.

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [3, 4]]})

# Expand 'B' into new columns and join
result_horizontal = df.join(pd.DataFrame(df.B.tolist(), index=df.index).add_prefix('B_'))
print("\nResult of horizontal expansion:")
print(result_horizontal)

Output:

Result of horizontal expansion:
   A       B  B_0  B_1
0  1  [1, 2]    1    2
1  2  [3, 4]    3    4

Performance Considerations

When choosing a method, performance is a key factor, especially for large datasets. Generally:

  • pandas.DataFrame.explode: Often the most performant and idiomatic for pandas versions >= 0.25.
  • NumPy-based methods (Method 6, Solution 2 options): Can be very fast due to vectorized operations.
  • List comprehensions (Method 3): Typically perform well but might be slower than optimized NumPy or pandas functions.
  • apply + pd.Series (Method 1): Usually the slowest due to row-wise iteration.

Solution 2: NumPy with column_stack

This method utilizes NumPy’s array capabilities, handling both equal and unequal sublist lengths.

Option 1 (Equal Lengths):

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2]]})
vals = np.array(df.B.values.tolist())
a = np.repeat(df.A, vals.shape[1])
result = pd.DataFrame(np.column_stack((a, vals.ravel())), columns=df.columns)
print("\nNumPy column_stack (equal lengths):")

Option 2 (Unequal Lengths):

df = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [1, 2, 3]]})

rs = [len(r) for r in vals]

Solution 4: itertools.product for Cartesian Product

When you need the Cartesian product of elements across list columns, itertools.product is the tool.

from itertools import product

def xplode_product(df, explode_columns):
    # Get the non-list columns
    rest_columns = list(set(df.columns) - set(explode_columns))

    # Create iterables for product
    iterables = [df[col] for col in explode_columns]
    
    # Calculate the Cartesian product
    cartesian_product = product(*iterables)
    
    # Build the new DataFrame
    df_exploded = pd.DataFrame(cartesian_product, columns=explode_columns)

    # Repeat the non-list columns
    num_rows = df_exploded.shape[0]
    df_rest = pd.concat([df[rest_columns]] * (num_rows // len(df)), ignore_index=True)
    
    # Combine and reorder
    final_df = pd.concat([df_rest, df_exploded], axis=1)
    return final_df[[*df.columns]]

df_prod = pd.DataFrame({'A': [1, 2], 'B': [[1, 2], [3, 4]]})
result_prod = xplode_product(df_prod, ['B'])
print("\nResult using itertools.product:")
print(result_prod)

Solution 6: Custom Recursive Explode Function

For complex scenarios involving multiple list-like columns with varying nesting levels, a recursive function can be a robust solution.

df = pd.DataFrame({'A': ['A1','A2','A3'], 'B': ['B1','B2','B3'], 'C': [ ['C1.1','C1.2'],['C2.1','C2.2'],'C3'], 'columnD': [ 'D1',['D2.1','D2.2', 'D2.3'],['D3.1','D3.2']]})

def dfListExplode(df, explodeKeys):
    if not isinstance(explodeKeys, list):
        explodeKeys=[explodeKeys]
    if len(explodeKeys)==0:
        return df
    elif len(explodeKeys)==1:
        explodeKey=explodeKeys[0]
    else:
        # Recursively call for the first key, then for the rest
        return dfListExplode( dfListExplode(df, explodeKeys[:1]), explodeKeys[1:])
    
    # Cast all elements in the explodeKey column to a list
    dfPrep=df[explodeKey].apply(lambda x: x if isinstance(x,list) else [x])
    
    # Create a DataFrame with exploded indices and values
    dfIndExpl=pd.DataFrame([[x] + [z] for x, y in zip(dfPrep.index,dfPrep.values) for z in y ], columns=['explodedIndex',explodeKey])
    
    # Merge with the rest of the DataFrame
    dfMerged=dfIndExpl.merge(df.drop(explodeKey, axis=1), left_on='explodedIndex', right_index=True)
    
    # Reindex to maintain original column order
    dfReind=dfMerged.reindex(columns=list(df))
    return dfReind

result_recursive = dfListExplode(df,['C','columnD'])
print("\nResult from recursive explode function:")
print(result_recursive)

Solution 9: Separate explode calls with join

For multiple columns to explode, applying explode sequentially and then joining can be an effective strategy.

df = pd.DataFrame({'A':[1,2],'B':[[1,2],[1,2]], 'C':[[1,2,3],[1,2,3]]})

# Explode B, then C, drop original columns, and join
explode_b = df.explode('B')['B']
explode_c = df.explode('C')['C']
df_temp = df.drop(['B', 'C'], axis=1)
result_join_explode = df_temp.join([explode_b, explode_c])

print("\nResult of sequential explodes and join:")
print(result_join_explode)

Solution 10: Horizontal Explode

This method expands list elements into new columns, useful for transforming array-like data horizontally.

def horizontal_explode(df: pd.DataFrame, col_name: str, new_columns: list = None) -> pd.DataFrame:
    # Create a new DataFrame from the list column
    t = pd.DataFrame(df[col_name].tolist(), columns=new_columns, index=df.index)
    # Concatenate with the original DataFrame
    return pd.concat([df, t], axis=1)

items = [["1", ["a", "b", "c"]], ["2", ["d", "e", "f"]]]
df_horizontal = pd.DataFrame(items, columns=["col1", "col2"])

# Explode 'col2' horizontally without specifying new column names
t_auto_cols = horizontal_explode(df=df_horizontal, col_name="col2")
t_auto_cols = t_auto_cols.drop("col2", axis=1) # Drop original list column
print("\nHorizontal explode (auto columns):")
print(t_auto_cols)

# Explode 'col2' horizontally with specified new column names
t_named_cols = horizontal_explode(df=df_horizontal, col_name="col2", new_columns=["new_col1", "new_col2", "new_col3"])
t_named_cols = t_named_cols.drop("col2", axis=1) # Drop original list column
print("\nHorizontal explode (named columns):")
print(t_named_cols)

FAQs on Pandas Dataframe Unnesting

Q: How to unnest a column containing lists in pandas

ANS: The most straightforward method for pandas versions 0.25 and later is using the df.explode('column_name') function. For older versions or more complex scenarios, methods involving apply(pd.Series).stack(), numpy.repeat, or list comprehensions are effective.

Q: What is the fastest way to unnest a pandas column

ANS: Generally, pandas.DataFrame.explode() (for recent pandas versions) or optimized NumPy-based solutions tend to be the fastest due to their vectorized operations. Performance can vary based on data size and structure.

Q: How to handle NaN values in a column when unnesting

ANS: Before unnesting, replace NaN values in the list-like column with an empty list (e.g., df['col'].fillna(value=[], inplace=True) or using .apply(lambda x: [] if pd.isna(x) else x)).

Q: Can I unnest multiple columns at once

ANS: Yes, custom functions that iterate through the specified columns and apply unnesting logic (often involving index repetition and joins) can handle multiple columns simultaneously. Solutions like Method 6’s recursive approach or others involving multiple explode calls followed by joins are suitable.

Q: What if the lists in my column have different lengths
