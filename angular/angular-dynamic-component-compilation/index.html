“Angular Dynamic Component Compilation: Methods and Examples”

Q: How to create a dynamic Angular component from a string template

ANS: You can create a dynamic component by defining a class with the @Component decorator using a provided template string. This class can then be compiled into a ComponentFactory using Angular’s compiler. This approach involves creating a temporary NgModule that declares your dynamically created component. The compiled factory can then be used to instantiate the component. For example, a function createNewComponent can take a template string and return a component class. This class is then used in a dynamically created NgModule. The compiler.compileModuleAndAllComponentsAsync method is key here, returning ComponentFactory instances. Caching these factories is a good practice for performance. See Solution 1 for a detailed code example.

Q: What is the role of ComponentFactoryResolver in dynamic component loading

ANS: ComponentFactoryResolver is Angular’s mechanism for obtaining a ComponentFactory for a given component type. This factory is essential for creating instances of components at runtime. You typically inject ComponentFactoryResolver into your component or service. By using resolveComponentFactory(componentType), you get the factory needed to instantiate your component, often within a ViewContainerRef to place it in the DOM. This is demonstrated in Solution 3 .

Q: Can I load components dynamically using the deprecated DynamicComponentLoader

ANS: Yes, but it’s important to note that DynamicComponentLoader is deprecated. While it was used in earlier versions of Angular (like Angular 2 RC versions) for dynamic component loading, it’s no longer the recommended approach. Solution 2 shows how it was used, but for modern Angular development, alternatives like ComponentFactoryResolver are preferred.

Q: How to load a component dynamically into a specific host element

ANS: To load a component into a specific host element, you first need a directive that provides a ViewContainerRef to that host element. This directive, often named like WidgetHostDirective, is applied to an <ng-template> or another element in your template. In your component’s logic, you obtain a reference to this directive using @ViewChild. Then, you use the ViewContainerRef from the directive to create the component instance using a ComponentFactory. Solution 3 provides a clear illustration of this pattern.

Q: Are there npm packages that simplify dynamic component creation

ANS: Yes, there are npm packages designed to streamline the process of dynamic component creation and template rendering. For instance, ngx-dynamic-template offers a directive (dynamic-template) that simplifies injecting dynamic HTML content, template variables, and even other Angular components. Another option is p3x-angular-compile, which facilitates runtime compilation with support for both AOT and JIT compilation. Solution 4 and Solution 6 point to these packages. The @codehint-ng/html-compiler package also offers capabilities for compiling dynamic Angular components from HTML. Solution 7 mentions this package.

Q: What are the principals for creating dynamic components

ANS: The core principles for creating dynamic components involve: 1. Defining the template for the dynamic component. 2. Creating a component class that uses this template. 3. Encapsulating this component within an NgModule. 4. Compiling this NgModule asynchronously. 5. Generating and potentially caching the ComponentFactory. 6. Using the factory to create an instance of the component. Solution 1 outlines these steps.

Q: How can I compile and execute existing components within dynamically generated HTML

ANS: To execute existing components within dynamically generated HTML, you can create a directive that intercepts the HTML content. This directive can then iterate through known ComponentFactory instances and locate elements matching their selectors within the provided HTML. Upon finding a match, it can create and attach the component to that element. This process requires access to the NgModuleRef and ComponentFactoryResolver. Solution 8 offers a detailed implementation for this scenario, handling component instantiation and cleanup.

When working with Angular, there are situations where you need to render components that are not known at build time. This could be due to user-defined templates, configurable dashboards, or plugin architectures. Dynamically compiling and rendering Angular components at runtime allows for greater flexibility and adaptability in your applications.

Approaches to Dynamic Component Compilation

Several methods exist to achieve dynamic component compilation in Angular, each with its nuances and suitability depending on the Angular version and specific requirements.

Solution 1: Compile-Time Compilation with Factory Caching

This approach leverages Angular’s compiler to create ComponentFactory instances from component class definitions and templates provided as strings.

Key Steps:

  1. Create Dynamic Component Class: Define a component class that uses a template string. This class can implement an interface to define expected inputs.

    import { Component, Input } from '@angular/core';

// Define an interface for components expecting dynamic data
export interface IHaveDynamicData {
    entity: any;
}

function createNewComponent(template: string): any {
    @Component({
        selector: 'dynamic-component',
        template: template,
    })
    class CustomDynamicComponent implements IHaveDynamicData {
        @Input() public entity: any;
    }
    return CustomDynamicComponent;
}

  2. Create Dynamic Module: Wrap the dynamic component class within a dynamically created NgModule. This NgModule should import necessary modules and declare the dynamic component.

    import { NgModule } from '@angular/core';
import { CommonModule } from '@angular/common'; // Example import
// Assuming PartsModule is available for common UI elements
import { PartsModule } from './parts.module';

function createComponentModule(componentType: any): any {
    @NgModule({
        imports: [
            CommonModule,
            PartsModule, // Include any required feature modules
        ],
        declarations: [
            componentType
        ],
    })
    class RuntimeComponentModule {}
    return RuntimeComponentModule;
}

  3. Compile and Cache Factory: Use compiler.compileModuleAndAllComponentsAsync to compile the dynamic module. Extract the ComponentFactory for your dynamic component and cache it.

    import { Compiler, ComponentFactory, Injectable } from '@angular/core';
import * as _ from 'lodash'; // Using lodash for find, ensure it's installed

@Injectable({ providedIn: 'root' })
export class ComponentFactoryResolverService {
    private _cacheOfFactories: { [template: string]: ComponentFactory<IHaveDynamicData> } = {};

    constructor(private compiler: Compiler) {}

    public createComponentFactory(template: string): Promise<ComponentFactory<IHaveDynamicData>> {
        let factory = this._cacheOfFactories[template];

        if (factory) {
            console.log("Module and Type are returned from cache");
            return Promise.resolve(factory);
        }

        // Unknown template, create a new component type
        let type = createNewComponent(template);
        let module = createComponentModule(type);

        return new Promise((resolve) => {
            this.compiler.compileModuleAndAllComponentsAsync(module)
                .then((moduleWithFactories) => {
                    factory = _.find(moduleWithFactories.componentFactories, { componentType: type });
                    this._cacheOfFactories[template] = factory;
                    resolve(factory);
                })
                .catch(error => {
                    console.error("Error compiling module:", error);
                    // Handle compilation errors appropriately
                    resolve(null); // Resolve with null or throw
                });
        });
    }
}

  4. Instantiate Component: Obtain the factory and use it to create a component instance, injecting necessary data.

import { ViewContainerRef, ComponentRef } from '@angular/core';
import { ComponentFactoryResolverService } from './component-factory-resolver.service'; // Adjust path

// Assume dynamicComponentTarget is a ViewContainerRef obtained via ViewChild or dependency injection

Solution 2: Using DynamicComponentLoader (Deprecated)

This method was used in earlier Angular versions (like Angular 2 RC) and relied on DynamicComponentLoader to insert components.

import { Component, DynamicComponentLoader, ElementRef, OnInit } from 'angular2/core'; // Note: Angular 2 specific imports

function compileToComponent(template: string, directives: any[]): any {
  @Component({
    selector: 'fake',
    template: template,
    directives: directives // Directives needed for the template
  })
  class FakeComponent {};
  return FakeComponent;
}

@Component({
  selector: 'hello',
  template: '<h1>Hello, Angular!</h1>'
})
class Hello {}

@Component({
  selector: 'my-app',
  template: '<div #container></div>', // Host element
})
export class App implements OnInit {
  constructor(
    private loader: DynamicComponentLoader,
    private elementRef: ElementRef,
  ) {}

  ngOnInit() {
    const someDynamicHtml = '<hello></hello><h2>Dynamic Content</h2>';

    this.loader.loadIntoLocation(
      compileToComponent(someDynamicHtml, [Hello]), // Component to load
      this.elementRef,
      'container' // Target element by name
    );
  }
}

Solution 3: ComponentFactoryResolver with a Host Directive (Angular 4+)

This is a robust method for Angular versions 4 and above, utilizing ComponentFactoryResolver and a dedicated directive to pinpoint the insertion location.

  1. Create a Host Directive: This directive will inject ViewContainerRef to serve as a placeholder.

    import { Directive, ViewContainerRef } from '@angular/core';

@Directive({
  selector: '[widget-host]', // Selector to apply to the host element
})
export class DashboardTileWidgetHostDirective {
  constructor(public viewContainerRef: ViewContainerRef) {}
}

  2. Create a Placeholder Component: This component hosts the dynamic content using the directive.

    import { Component, Input, OnInit, ViewChild, ComponentFactoryResolver } from '@angular/core';
import { DashboardTileWidgetHostDirective } from './DashbardWidgetHost.Directive'; // Adjust path
import { TileModel } from './Tile.Model'; // Example model
import { WidgetComponentService } from "./WidgetComponent.Service"; // Service to map names to components

@Component({
  selector: 'dashboard-tile',
  template: `
    <div class="col-md-2 col-lg-2 col-sm-2 col-default-margin col-default">
      <ng-template widget-host></ng-template>
    </div>
  ` // Apply directive to ng-template
})
export class DashboardTileComponent implements OnInit {
  @Input() tile: any; // Input data defining the component to load
  @ViewChild(DashboardTileWidgetHostDirective) widgetHost!: DashboardTileWidgetHostDirective;

  constructor(
    private _componentFactoryResolver: ComponentFactoryResolver,
    private widgetComponentService: WidgetComponentService
  ) {}

  ngOnInit() {}

  ngAfterViewInit() {
    this.renderComponents();
  }

  renderComponents() {
    const componentType = this.widgetComponentService.getComponent(this.tile.componentName);
    if (!componentType) {
      console.error(`Component ${this.tile.componentName} not found.`);
      return;
    }

    const componentFactory = this._componentFactoryResolver.resolveComponentFactory(componentType);
    const viewContainerRef = this.widgetHost.viewContainerRef;
    const componentRef = viewContainerRef.createComponent(componentFactory);

    // Pass data to the dynamically created component instance
    (componentRef.instance as TileModel).data = this.tile;
    componentRef.changeDetectorRef.detectChanges(); // Trigger change detection
  }
}

  3. Create a Service for Component Mapping: This service maps string names to actual component classes.

    import { Injectable } from '@angular/core';
import { ImageTextWidgetComponent } from "../templates/ImageTextWidget.Component"; // Example component

@Injectable({ providedIn: 'root' })
export class WidgetComponentService {
  getComponent(componentName: string): any {
    switch (componentName) {
      case "ImageTextWidgetComponent":
        return ImageTextWidgetComponent;
      // Add other component mappings here
      default:
        return null;
    }
  }
}

  4. Register Components: Ensure your dynamic components are listed in entryComponents within your NgModule.

    import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { DashboardTileComponent } from './tile/DashboardTile.Component';
import { DashboardTileWidgetHostDirective } from './tile/DashbardWidgetHost.Directive';
import { ImageTextWidgetComponent } from './templates/ImageTextWidget.Component';
import { WidgetComponentService } from "./WidgetComponent.Service";
// ... other components

@NgModule({
  imports: [BrowserModule],
  providers: [WidgetComponentService],
  declarations: [
    // ... other components
    DashboardTileComponent,
    DashboardTileWidgetHostDirective,
    ImageTextWidgetComponent
  ],
  entryComponents: [ImageTextWidgetComponent], // Crucial for dynamic loading
  bootstrap: [/* Your main app component */]
})
export class AppModule {}

Solution 5: loadAsRoot with DynamicComponentLoader

Similar to Solution 2, this uses DynamicComponentLoader but with loadAsRoot to directly load a component into a specified DOM element.

import { WidgetMeteoComponent } from './widget-meteo'; // Example components

    elementRef: ElementRef,

Solution 8: Manual DOM Manipulation with Component Factories

This advanced technique involves manipulating the DOM directly and then using ComponentFactory instances to instantiate and attach components. It’s useful when you need fine-grained control over how existing components are integrated into arbitrary HTML.

import { Component, Input, OnDestroy, ViewContainerRef, Injector, NgModuleRef, ComponentFactory } from '@angular/core';

@Component({
    selector: "compile",
    template: "", // Initial template is empty, filled by the input
    inputs: ["html"]
})
export class CompileHtmlComponent implements OnDestroy {
    private _ComponentRefCollection: any[] = [];
    private _Html: string = '';

    constructor(
        private content: ViewContainerRef,
        private injector: Injector,
        private ngModRef: NgModuleRef<any> // Reference to the module
    ) {}

    ngOnDestroy() {
        this.DestroyComponents();
    }

    @Input("html") set Html(val: string) {
        this._Html = (val || "") + "";
        this.TemplateHTMLCompile(this._Html);
    }

    private DestroyComponents() {
        this._ComponentRefCollection.forEach((c) => {
            c.destroy();
        });
        this._ComponentRefCollection = [];
    }

    private TemplateHTMLCompile(html: string) {
        this.DestroyComponents();
        this.content.element.nativeElement.innerHTML = html;
        const ref = this.content.element.nativeElement;
        const factories = (this.ngModRef.componentFactoryResolver as any)._factories;

        factories.forEach((comp: ComponentFactory<unknown>) => {
            const list = ref.querySelectorAll(comp.selector); // Find elements matching selector
            list.forEach((item: HTMLElement) => {
                const parent = item.parentNode;
                const next = item.nextSibling;
                const ngContentNodes: any[][] = [];

                comp.ngContentSelectors.forEach((sel) => {
                    let ngContentList: any[] = [];
                    if (sel === "*") { // All children
                        Array.from(item.childNodes).forEach(c => ngContentList.push(c));
                    } else {
                        Array.from(item.querySelectorAll(sel)).forEach(l => ngContentList.push(l));
                    }
                    ngContentNodes.push(ngContentList);
                });

                // Create and attach component
                let component = comp.create(this.injector, ngContentNodes, item, this.ngModRef);
                this._ComponentRefCollection.push(component);

                if (next) parent.insertBefore(component.location.nativeElement, next);
                else parent.appendChild(component.location.nativeElement);

                component.hostView.detectChanges(); // Update component
            });
        });
    }
}
