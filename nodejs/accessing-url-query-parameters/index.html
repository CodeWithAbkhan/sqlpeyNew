“Accessing URL Query Parameters in Nodejs and Expressjs”

When building web applications, especially with Node.js and its popular framework Express.js, you often need to retrieve data passed in the URL’s query string. These parameters, following a ? and separated by &, are crucial for filtering data, pagination, and more. For example, a URL like https://example.com/items?category=electronics&sort=price contains query parameters category with a value of electronics and sort with a value of price.

This post explores various effective methods for accessing these parameters in your Node.js and Express.js applications.

Using req.query in Express.js

The most straightforward and recommended method within an Express.js application is to use the req.query object. Express automatically parses the query string for you.

For instance, if you have a route defined as:

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  const category = req.query.category;
  const sortOrder = req.query.sort;
  res.send(`Displaying items from category: ${category}, sorted by: ${sortOrder}`);
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});

Accessing http://localhost:3000/?category=books&sort=name will result in the response: “Displaying items from category: books, sorted by: name”.

Distinguishing req.query from req.params

It’s important to note the difference between req.query and req.params:

  • req.params: Used for capturing route parameters, defined in the route path itself. For example, in /users/:id, :id is a route parameter.

    app.get('/users/:id', (req, res) => {
  const userId = req.params.id;
  res.send(`Fetching user with ID: ${userId}`);
});

    Accessing http://localhost:3000/users/123 would set req.params.id to "123".

  • req.query: Used for capturing query string parameters appended after the ? in the URL.

ES6 Destructuring with req.query

You can leverage ES6 destructuring for a more concise way to extract query parameters:

const express = require('express');
const app = express();

app.get('/products', (req, res) => {
  const { category, limit = 10 } = req.query; // Default limit to 10 if not provided
  res.send(`Showing products in category: ${category} with a limit of ${limit}`);
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});

Visiting http://localhost:3000/products?category=electronics will output “Showing products in category: electronics with a limit of 10”. If you visit http://localhost:3000/products?category=electronics&limit=20, the output will be “Showing products in category: electronics with a limit of 20”.

Using Node.js url Module

If you are working with a plain Node.js HTTP server without Express, you can utilize the built-in url module to parse the request URL and extract query parameters.

Here’s how you can do it:

const http = require('http');
const url = require('url');

const server = http.createServer((req, res) => {
  const parsedUrl = url.parse(req.url, true);
  const queryParams = parsedUrl.query;

  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end(`User name: ${queryParams.user_name}`);
});

server.listen(3000, () => {
  console.log('Node.js server listening on port 3000');
});

To test this, use curl http://localhost:3000?user_name=tester. The response will be “User name: tester”.

Handling Multiple Parameters with the Same Name

By default, if a query parameter appears multiple times in the URL (e.g., /items?tag=A&tag=B), req.query (and url.parse) will typically return the last value encountered or an array of values depending on the parser’s configuration. The querystring module, which Express uses internally, can parse these into arrays.

Consider this example demonstrating the array behavior:

const express = require('express');
const app = express();

app.get('/tags', (req, res) => {
  const tags = req.query.tag; // This might be a string or an array
  console.log('Tags:', tags);
  res.send(`Received tags: ${Array.isArray(tags) ? tags.join(', ') : tags}`);
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});
  • Accessing http://localhost:3000/tags?tag=frontend&tag=backend will log Tags: [ 'frontend', 'backend' ] and respond with “Received tags: frontend, backend”.
  • Accessing http://localhost:3000/tags?tag=frontend will log Tags: frontend and respond with “Received tags: frontend”.

Customizing Query String Parsing

Express allows customization of the query string parser. You can configure it to always return values as arrays, for example, by using the querystring module.

const express = require('express');
const querystring = require('querystring');
const app = express();

// Configure query parser to always return values as arrays
app.set('query parser', (qs) => {
  const parsed = querystring.parse(qs);
  return Object.entries(parsed).reduce((acc, [key, value]) => {
    acc[key] = Array.isArray(value) ? value : [value];
    return acc;
  }, {});
});

app.get('/items', (req, res) => {
  const ids = req.query.id; // Now guaranteed to be an array
  console.log('Item IDs:', ids);
  res.send(`Processing items with IDs: ${ids.join(', ')}`);
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});

Visiting http://localhost:3000/items?id=101&id=102 will consistently log Item IDs: [ '101', '102' ] and respond with “Processing items with IDs: 101, 102”.

Handling Both Route and Query Parameters

It’s common to combine route parameters with query parameters in your URLs. For instance, fetching a specific user’s posts might look like /users/:userId/posts?status=published.

const express = require('express');
const app = express();

app.get('/users/:userId/posts', (req, res) => {
  const userId = req.params.userId;
  const status = req.query.status;
  res.send(`Fetching posts for user ${userId} with status: ${status}`);
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});

Accessing http://localhost:3000/users/abc/posts?status=draft will yield the response “Fetching posts for user abc with status: draft”.

Alternatives and Considerations

While req.query is the standard in Express, and url.parse for basic Node.js, the queryString npm package offers a robust alternative for parsing query strings, especially when dealing with complex scenarios or when you need finer control over the parsing logic.

npm install query-string

// Example using query-string
const express = require('express');
const queryString = require('query-string');
const app = express();

app.get('/search', (req, res) => {
  const parsedQuery = queryString.parse(req.url.split('?')[1]); // Manually get query string
  const searchTerm = parsedQuery.q;
  res.send(`Searching for: ${searchTerm}`);
});

app.listen(3000, () => {
  console.log('Server listening on port 3000');
});

When using http.get for making requests, you can construct URLs with query parameters as shown in Solution 24 . This is useful for client-side requests made from your Node.js application.

Type Coercion

Remember that query parameters are always received as strings. If you expect a number, boolean, or other data type, you’ll need to perform explicit type conversion, for example, using parseInt(), parseFloat(), or Boolean().

app.get('/filter', (req, res) => {
  const maxPrice = parseInt(req.query.maxPrice, 10); // Convert to integer
  const isActive = req.query.active === 'true'; // Convert to boolean
  res.send(`Max Price: ${maxPrice}, Is Active: ${isActive}`);
});

FAQs on Accessing URL Query Parameters

Q: How do I get query parameters in Expressjs

ANS: In Express.js, you can access query parameters using req.query.parameterName. For example, for a URL like /?id=123, you would use req.query.id.

Q: What is the difference between req query and req params in Expressjs

ANS: req.params are used for route parameters defined in the URL path (e.g., /users/:id), while req.query is used for parameters in the query string (e.g., ?id=123).

Q: How to access query parameters in plain Nodejs without Express

ANS: In plain Node.js, you can use the built-in url module. Parse the request URL using url.parse(req.url, true) and access the query object via parsedUrl.query.

Q: Can query parameters be arrays in Expressjs

ANS: Yes, if a query parameter appears multiple times in the URL (e.g., ?tag=a&tag=b), Express will typically parse it as an array. You can also configure the query parser for consistent array handling.

Q: How do I handle missing query parameters

ANS: You can provide default values using object destructuring in ES6 (e.g., const { id = 'defaultId' } = req.query;) or use conditional checks (e.g., req.query.id || 'defaultId').
