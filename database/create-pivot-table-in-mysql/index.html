How to Create a PIVOT Table in MySQL Using Aggregate Functions

1. Begin by creating a table and inserting some dummy data. For example:

CREATE TABLE sales_data (
region VARCHAR(255),
product VARCHAR(255),
sales INT
);

INSERT INTO sales_data (region, product, sales)
VALUES ('North', 'Car', 1000),
('North', 'Bus', 2000),
('West', 'Car', 3000),
('West', 'Bus', 4000);
  1. Once you have your data in the table, you can create a PIVOT table using an aggregate function such as SUM. For example:
SELECT region, SUM(IF(product = 'Car', sales, 0)) as Car_sales,
SUM(IF(product = 'Bus', sales, 0)) as Bus_sales
FROM sales_data
GROUP BY region;

Understanding the Syntax of a PIVOT Table Query in MySQL

The syntax for a PIVOT Table in MySQL query is as follows:

SELECT [Columns to Display]
FROM [Table Name]
PIVOT (
[Aggregation Function]
FOR [Column to Pivot]
IN ([Values for Column to Pivot])
) AS [Alias for Pivot Table]

The SELECT statement defines the columns to be displayed in the PIVOT Table in MySQL query. The FROM statement defines the table to be used. The PIVOT keyword indicates that the query is a PIVOT table query. The Aggregation Function defines the type of calculation that will be performed on the data (e.g., SUM, AVG, COUNT, etc.).

The Column to Pivot defines the column that is used to create the PIVOT table. The Values for Column to Pivot defines the values that should be used in the PIVOT table. Finally, the Alias for Pivot Table statement defines the alias for the PIVOT table.
