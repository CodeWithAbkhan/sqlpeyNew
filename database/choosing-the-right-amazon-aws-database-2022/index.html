Amazon RDS:

Amazon Relational Database Service (Amazon RDS) is a fully managed and scalable relational database service from Amazon. It supports popular databases like MySQL, PostgreSQL, Oracle, Microsoft SQL Server, and Amazon Aurora. Amazon RDS simplifies the process of setting up, operating, and scaling a relational database in the cloud. With Amazon RDS, you can quickly create a database instance and connect it to your application.

Amazon Aurora:

Amazon Aurora is a fully managed, MySQL and PostgreSQL-compatible, relational database engine. It offers the performance and availability of commercial databases with the cost effectiveness and simplicity of open source databases. Amazon Aurora provides up to five times better performance than the standard MySQL and PostgreSQL databases.

Amazon DynamoDB:

Amazon DynamoDB is a fully managed, NoSQL database service. It is a highly scalable, fast, and flexible database solution. It supports both document and key-value data models, allowing you to store and retrieve data with low latency. With Amazon DynamoDB, you can quickly create, update, delete, and query your data
