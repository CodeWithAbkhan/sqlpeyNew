“Solved: How to Convert Date Formats in PHP”

Method 1: Leveraging date() with strtotime() (PHP 5.3+ recommended for specific formats)

The date() function in PHP requires a proper timestamp (seconds since January 1, 1970) as its second parameter. A common mistake is passing a date string directly, which date() cannot inherently parse. To overcome this, strtotime() proves invaluable as it converts a human-readable date string into a Unix timestamp.

However, strtotime() has limitations and might not recognize highly unconventional date string formats like y-m-d-h-i-s with dashes as time separators. For such specific parsing needs, PHP 5.3 and newer versions offer a more robust solution: DateTime::createFromFormat.

For older PHP versions (5.2 and lower), a manual parsing approach using string manipulation functions like substr() combined with mktime() would be necessary to extract year, month, day, hour, minute, and second components before constructing a timestamp. This is generally more involved.

A more straightforward approach, especially with strtotime(), is to ensure the input date string is in a format strtotime() can easily interpret. For instance:

<?php
// An initial date string in a readable format
$initialDateString = 'Sunday, February 25 24 11:30:15'; // Example: Sunday, February 25 2024 11:30:15

// Convert the initial date string to a Unix timestamp
$parsedTimestamp = strtotime($initialDateString);

// Format the timestamp into a new desired date string
$formattedNewDate = date('Y-m-d H:i:s', $parsedTimestamp);

echo "Original Date String: " . $initialDateString . "\n";
echo "Converted Timestamp: " . $parsedTimestamp . "\n";
echo "Formatted New Date: " . $formattedNewDate . "\n";
?>

Method 2: The Elegant DateTime Class and createFromFormat()

Introduced in PHP 5.2, the DateTime class provides an object-oriented interface for date and time operations, offering greater control and flexibility compared to procedural functions.

The DateTime::createFromFormat() static method is exceptionally useful when you need to parse a date string that is in a specific, non-standard, or potentially ambiguous format. You explicitly define the input format mask, and then you can convert the resulting DateTime object into any other format using its format() method.

<?php
// Scenario 1: Converting a date string from one format to another
$inputDateString = '2023-11-20'; // Input format is YYYY-MM-DD

// Create a DateTime object by specifying the exact input format
$dtObject = DateTime::createFromFormat('Y-m-d', $inputDateString);

// Format the DateTime object into the desired output format (e.g., MM/DD/YYYY)
$outputDateString = $dtObject->format('m/d/Y');

echo "Original: " . $inputDateString . " | Converted: " . $outputDateString . "\n";

// Scenario 2: Getting the current date/time in a specific format
$currentDt = new DateTime(); // Creates a DateTime object for the current moment

// Format the current DateTime object
$currentFormattedTime = $currentDt->format('Y-m-d h:i:s A'); // Example: 2025-07-23 03:45:00 PM

echo "Current Date/Time: " . $currentFormattedTime . "\n";
?>

This approach avoids the potential pitfalls of strtotime() with less common date strings, providing more reliable parsing.

Method 3: Comprehensive Date Manipulation with strtotime() and DateTime()

This method delves deeper into using both strtotime() and the DateTime class for various conversion scenarios, including handling Unix timestamps and non-standard formats.

The Basics with strtotime() and date()

The simplest way to convert between formats is to pipe the output of strtotime() directly into date():

<?php
// Example: Convert ISO 8601-like string to Y-m-d H:i:s
$rawIsoDate = '2008-07-01T22:35:17.02';
$convertedDateTime = date('Y-m-d H:i:s', strtotime($rawIsoDate));
echo "Converted via strtotime/date: " . $convertedDateTime . "\n";

// One-liner approach
$oneLinerConverted = date('Y-m-d H:i:s', strtotime('2008-07-01T22:35:17.02'));
echo "One-liner result: " . $oneLinerConverted . "\n";
?>

Important Consideration: strtotime() requires a date string in a valid and recognizable format. If an invalid format is supplied, strtotime() may return false, which often results in date() outputting “1969-12-31” (or similar, depending on timezone) because false evaluates to 0 in a numeric context, corresponding to the Unix epoch.

Leveraging the DateTime Class

For more robust date and time operations, the DateTime class, available since PHP 5.2, is highly recommended:

<?php
$dateTimeInstance = new DateTime('2008-07-01T22:35:17.02');
$formattedFromObject = $dateTimeInstance->format('Y-m-d H:i:s');
echo "Formatted using DateTime object: " . $formattedFromObject . "\n";
?>

Working with Unix Timestamps

Both date() and DateTime can work directly with Unix timestamps:

<?php
$unixEpochVal = '1234567890'; // A sample Unix timestamp

// Using date() function
$unixFormatted = date('Y-m-d H:i:s', (int)$unixEpochVal); // Cast to int for clarity
echo "From Unix timestamp (date func): " . $unixFormatted . "\n";

// Using DateTime class (prefix with '@')
$dtFromUnix = new DateTime('@' . $unixEpochVal);
$dtFromUnixFormatted = $dtFromUnix->format('Y-m-d H:i:s');
echo "From Unix timestamp (DateTime): " . $dtFromUnixFormatted . "\n";
?>

Handling Millisecond Timestamps: If your timestamp is in milliseconds (often 13 characters long, ending in ‘000’), you must convert it to seconds before processing:

<?php
$msTimestamp = '1234567899000'; // Example 13-digit millisecond timestamp

// Method A: Trim last three digits using substr
$unixSecondsSubstr = substr($msTimestamp, 0, -3);
echo "Milliseconds trimmed: " . $unixSecondsSubstr . "\n";

// Method B: Divide by 1000 using BCMath for large numbers
// BCMath is crucial for handling large integers that might exceed PHP's standard integer limits
// This prevents potential overflow issues on 32-bit systems.
$unixSecondsBcdiv = bcdiv($msTimestamp, '1000');
echo "Milliseconds divided (BCMath): " . $unixSecondsBcdiv . "\n";
?>

Retrieving Unix Timestamps

To convert a date string or DateTime object back into a Unix timestamp:

<?php
// Using strtotime for a date string
$dateForTimestamp = '1973-04-18';
$timestampFromStrtotime = strtotime($dateForTimestamp);
echo "Timestamp from date string: " . $timestampFromStrtotime . "\n";

// Using DateTime::getTimestamp() (PHP 5.3+)
$dtForTimestamp = new DateTime('2008-07-01T22:35:17.02');
$timestampFromDtObject = $dtForTimestamp->getTimestamp();
echo "Timestamp from DateTime object (getTimestamp): " . $timestampFromDtObject . "\n";

// Using DateTime::format('U') (PHP 5.2+)
$timestampFromDtFormatU = $dtForTimestamp->format('U');
echo "Timestamp from DateTime object (format 'U'): " . $timestampFromDtFormatU . "\n";
?>

Working with Non-Standard Formats using DateTime::createFromFormat()

For dates that strtotime() struggles with, DateTime::createFromFormat() is the definitive solution:

<?php
// Parsing a custom date string like "April-18-1973 9:48 AM"
$customSourceDate = 'April-18-1973 9:48 AM';
$customFormatDate = DateTime::createFromFormat('F-d-Y h:i A', $customSourceDate);

// Check if parsing was successful before formatting
if ($customFormatDate !== false) {
    $newFormattedCustomDate = $customFormatDate->format('Y-m-d H:i:s');
    echo "Converted custom date: " . $newFormattedCustomDate . "\n";
} else {
    echo "Failed to parse custom date: " . $customSourceDate . "\n";
}
?>

PHP 5.4+ One-Liners

PHP 5.4 introduced class member access on instantiation, allowing for more concise code:

<?php
// One-liner for direct DateTime object formatting
$directFormatDate = (new DateTime('2008-07-01T22:35:17.02'))->format('Y-m-d H:i:s');
echo "Direct DateTime one-liner: " . $directFormatDate . "\n";

// One-liner for createFromFormat and immediate formatting
$createFromFormatOneLiner = DateTime::createFromFormat('F-d-Y h:i A', 'April-18-1973 9:48 AM')->format('Y-m-d H:i:s');
echo "createFromFormat one-liner: " . $createFromFormatOneLiner . "\n";
?>

This method is a quick and effective way to convert an existing date format to a new one, particularly when the initial format is somewhat standard.

<?php

Method 5: MySQL Datetime Format Conversion

When dealing with database systems like MySQL that prefer Y-m-d H:i:s format, you can use DateTime::createFromFormat() to parse an input string (e.g., dd-mm-yyyy hh:mm:ss) and then format it for the database:

<?php
$inputForDb = '25-12-2023 14:30:00'; // Example date from UI
$mysqlFormattedDate = DateTime::createFromFormat('d-m-Y H:i:s', $inputForDb)->format('Y-m-d H:i:s');
echo "For MySQL: " . $mysqlFormattedDate . "\n";
?>

This illustrates how DateTime::createFromFormat() can be used to parse a single input date and then output it in various desired formats.

Method 7: Manual Parsing with preg_match_all() or explode() (for specific structured inputs)

If your date string has a very particular, consistent pattern that strtotime() struggles with (e.g., y-m-d-h-i-s where ‘y’ is a 2-digit year and time components are also separated by dashes), you might resort to manual parsing.

<?php
$dashedDateTime = '24-02-25-11-30-15'; // Example input: yy-mm-dd-hh-ii-ss
$newlyFormattedDate = '';

// Option A: Using regular expressions (more robust for complex patterns)
if (preg_match_all('/(\d+)-(\d+)-(\d+)-(\d+)-(\d+)-(\d+)/', $dashedDateTime, $matches, PREG_SET_ORDER)) {
    $parts = $matches[0];
    // mktime(hour, minute, second, month, day, year)
    $parsedTime = mktime($parts[4], $parts[5], $parts[6], $parts[2], $parts[3], $parts[1]);
    $newlyFormattedDate = date('Y-m-d H:i:s', $parsedTime);
    echo "Regex parsed: " . $newlyFormattedDate . "\n";
} else {
    echo "Regex parsing failed for: " . $dashedDateTime . "\n";
}


// Option B: Using explode (simpler for consistent delimiters)
$explodedParts = explode('-', $dashedDateTime);
if (count($explodedParts) === 6) {
    // mktime(hour, minute, second, month, day, year)
    $parsedTimeExplode = mktime($explodedParts[3], $explodedParts[4], $explodedParts[5], $explodedParts[1], $explodedParts[2], $explodedParts[0]);
    $newlyFormattedDateExplode = date('Y-m-d H:i:s', $parsedTimeExplode);
    echo "Explode parsed: " . $newlyFormattedDateExplode . "\n";
} else {
    echo "Explode parsing failed for: " . $dashedDateTime . "\n";
}
?>

It’s worth noting that if the original date() call was $old_date = date('y-m-d-h-i-s');, the h:i:s part should indeed use colons for time, not dashes. So, $old_date = date('y-m-d H:i:s'); is a more typical and easily parsable format generated by date().

Method 10: Ensuring date() Receives a Timestamp

This is a key reminder: The date() function’s second argument must be a timestamp. If you have a date string, convert it to a timestamp first using strtotime() or by creating a DateTime object.

Method 11: Easy Text-Based Date Format Changes with strtotime()

For common text-based date formats, strtotime() combined with date() offers a very simple solution.

<?php
// Convert a date into Day, Date Month Year format
$rawDateForDisplay = "2020-11-16";
$prettyDate = date("D, d M Y", strtotime($rawDateForDisplay));
echo "Pretty Date: " . $prettyDate . "\n"; // Outputs something like Mon, 16 Nov 2020

// Convert datetime (e.g., from SQL) into a readable format with time

$prettyDatetime = date("D, d M Y H:i:s", strtotime($sqlDatetimeFormat));
echo "Pretty Datetime: " . $prettyDatetime . "\n"; // Outputs something like Sun, 15 Nov 2020 16:26:00
?>

Method 14: Universal Date/Time Converter Function

For applications requiring extreme flexibility in handling diverse date and time inputs (including various standard datetime formats with or without milliseconds, and Epoch time representations), a custom universal converter function can be highly beneficial. This function can parse nearly any input and convert it to a specified output format or Epoch/Unix time.

<?php
/**
 * Converts various date/time strings or Unix timestamps to a specified format or Epoch time.
 *
 * @param string|int|null $inputDateTime The date/time string or Unix timestamp to convert.
 * @param string|null $outputFormat The desired output format (e.g., 'Y-m-d H:i:s', 'c', or '.u' for milliseconds).
 *                                   If null, returns Epoch time (seconds since 1970-01-01 UTC).
 * @return string|int The converted date/time string or Epoch timestamp.
 */
function convertUniversalDateTime($inputDateTime, $outputFormat = null)
{
    if (!isset($inputDateTime) || $inputDateTime === '') {
        return "";
    }

    $millisecondParts = [];
    $parsedUnixTime = null;

    if (is_numeric($inputDateTime)) {
        // If it's a numeric value, assume it's an Epoch timestamp (seconds or milliseconds)
        if (strlen($inputDateTime) > 10) { // Likely milliseconds
            $millisecondParts[1] = substr($inputDateTime, -3); // Get last 3 digits for potential milliseconds
            $parsedUnixTime = substr($inputDateTime, 0, -3); // Convert milliseconds to seconds
        } else {
            $parsedUnixTime = $inputDateTime;
        }
    } else {
        // Attempt to parse string using strtotime
        $parsedUnixTime = strtotime($inputDateTime);

        // Check for milliseconds in the string if strtotime didn't capture them
        if (strpos($inputDateTime, ".") !== false) {
            $dotPos = strpos($inputDateTime, ".");
            $nextDashPos = strpos($inputDateTime, "-", $dotPos);

            if ($nextDashPos > 0) { // Milliseconds followed by timezone offset or another dash
                $millisecondSegment = substr($inputDateTime, $dotPos, $nextDashPos - $dotPos);
                preg_match('/([0-9]+)/', $millisecondSegment, $millisecondMatches);
                if (!empty($millisecondMatches[1])) {
                    $millisecondParts[1] = $millisecondMatches[1];
                }
            } else { // Milliseconds at the end of the string
                preg_match('/([0-9]+)([^0-9]+)?/', substr($inputDateTime, $dotPos) . " ", $millisecondMatches);
                if (!empty($millisecondMatches[1])) {
                    $millisecondParts[1] = $millisecondMatches[1];
                }
            }
        }
    }

    if ($outputFormat !== null) {
        // Return in a specific date format
        if (strpos($outputFormat, ".u") !== false) { // Handle milliseconds if requested
            $formattedOutput = date($outputFormat, (int)$parsedUnixTime);
            // Append milliseconds, ensuring we have some if the input had them
            if (!empty($millisecondParts[1])) {
                $formattedOutput = substr($formattedOutput, 0, strripos($formattedOutput, ".") + 1) . $millisecondParts[1];
            } else {
                // If .u is requested but no milliseconds were parsed, append .000 (or similar)
                $formattedOutput = substr($formattedOutput, 0, strripos($formattedOutput, ".") + 1) . '000';
            }
        } else { // No milliseconds wanted
            $formattedOutput = date($outputFormat, (int)$parsedUnixTime);
        }
    } else {
        // Return Epoch Time (seconds since 1970-01-01 UTC)
        $formattedOutput = $parsedUnixTime;
        if (!empty($millisecondParts[1])) {
            $formattedOutput .= "." . $millisecondParts[1];
        }
    }
    return $formattedOutput;
}
