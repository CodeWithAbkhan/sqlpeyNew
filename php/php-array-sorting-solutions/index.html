“PHP Array Sorting: Flexible Multi-Column & Custom Sort Solutions”

When dealing with complex datasets in PHP, sorting multi-dimensional arrays based on various criteria and with specific ordering can become a challenge. While built-in functions like usort and array_multisort are powerful, they often require intricate callback functions or data manipulation for anything beyond simple sorting. This inquiry delves into advanced methods for sorting PHP arrays, focusing on flexibility, reusability, and handling diverse data types.

How can we create a robust sorting mechanism in PHP that supports multiple sort columns, allows for ascending or descending order per column, and can even handle custom data transformations for comparison? Let’s explore various approaches that go beyond basic sorting functions.

Solution 1: The make_comparer Function for Flexible Sorting

This generalized solution, compatible with PHP 5.3+, offers significant advantages for sorting arrays:

  • Reusability: Define sort columns as variables, avoiding hardcoded values.
  • Flexibility: Sort by multiple columns, using subsequent columns as tiebreakers.
  • Reversibility: Specify descending order for individual columns independently.
  • Extensibility: Incorporate projection functions to handle incomparable data types (e.g., date strings) by converting them to a comparable format.
  • Associative Sorting: The code sorts items while allowing you to choose the actual sort function, such as usort or uasort.
  • Efficiency: It avoids array_multisort, which can be memory-intensive and slow for large datasets due to the need to create data projections beforehand.

Here’s the core make_comparer function:

function make_comparer() {
    // Normalize criteria up front for efficient comparison
    $criteria = func_get_args();
    foreach ($criteria as $index => $criterion) {
        // Pad array with default sort order (ASC) and no projection if not specified
        $criteria[$index] = is_array($criterion)
            ? array_pad($criterion, 3, null)
            : array($criterion, SORT_ASC, null);
    }

    return function($first, $second) use (&$criteria) {
        foreach ($criteria as $criterion) {
            // Determine comparison parameters
            list($column, $sortOrder, $projection) = $criterion;
            $sortOrder = $sortOrder === SORT_DESC ? -1 : 1;

            // Apply projection if defined
            if ($projection) {
                $lhs = call_user_func($projection, $first[$column]);
                $rhs = call_user_func($projection, $second[$column]);
            }
            else {
                $lhs = $first[$column];
                $rhs = $second[$column];
            }

            // Perform the comparison
            if ($lhs < $rhs) {
                return -1 * $sortOrder;
            }
            else if ($lhs > $rhs) {
                return 1 * $sortOrder;
            }
        }

        return 0; // All tiebreakers exhausted; elements are considered equal
    };
}

Example Usage:

Consider this sample data:

$data = array(
    array('id' => 'zz', 'name' => 'Jack', 'number' => 22, 'birthday' => '12/03/1980'),
    array('id' => 'xx', 'name' => 'Adam', 'number' => 16, 'birthday' => '01/12/1979'),
    array('id' => 'aa', 'name' => 'Paul', 'number' => 16, 'birthday' => '03/11/1987'),
    array('id' => 'cc', 'name' => 'Helen', 'number' => 44, 'birthday' => '24/06/1967'),
);

  • Basic Sort by Name:

    usort($data, make_comparer('name'));

  • Sort by Numeric ID (first element):

    usort($data, make_comparer(0));

  • Multiple Columns: Sort by ’number’, then by ‘id’ (index 0):

    usort($data, make_comparer('number', 0));

  • Reverse Sort by Name:

    usort($data, make_comparer(['name', SORT_DESC]));

  • Multi-Column Reverse Sort: ’number’ descending, then ’name’ descending:

    usort($data, make_comparer(['number', SORT_DESC], ['name', SORT_DESC]));

  • Custom Projection for Dates: Sorting by birthday requires date parsing. We use date_create as a projection:

    usort($data, make_comparer(['birthday', SORT_ASC, 'date_create']));

  • Combined Advanced Sorting: Sort by number descending, then by birthday ascending using a date projection:

    usort($data, make_comparer(
    ['number', SORT_DESC],
    ['birthday', SORT_ASC, 'date_create']
));

Solution 2: Leveraging array_multisort

For PHP 5.5.0 and later, array_multisort offers a more direct way to sort if you can easily extract the column to sort by:

// For PHP >= 5.5.0, you can use array_column directly
$numeric_column_data = array_column($mdarray, 0); // Sort by the first column (index 0)
array_multisort($numeric_column_data, SORT_DESC, $mdarray);

If you are using an older PHP version or need more granular control before sorting, a loop is still applicable:

// For older PHP versions or when more manual control is needed
foreach ($mdarray as $key => $row) {
    // Replace 0 with the actual field's index or key
    $dates[$key] = $row[0];
}
array_multisort($dates, SORT_DESC, $mdarray);

Solution 3: A Class-Based Approach with usort

A class-based structure can encapsulate sorting logic effectively. This TableSorter class provides a clean way to sort by a specified column:

class TableSorter {
  protected $column;

  function __construct($column) {
    $this->column = $column;
  }

  function sort($table) {
    // Use usort with the class's compare method
    usort($table, array($this, 'compare'));
    return $table;
  }

  // Comparison callback for usort
  function compare($a, $b) {
    if ($a[$this->column] == $b[$this->column]) {
      return 0; // Elements are equal
    }
    // Return -1 if $a < $b, 1 if $a > $b
    return ($a[$this->column] < $b[$this->column]) ? -1 : 1;
  }
}

// Example usage:
$sorter = new TableSorter(0); // Sort by the first column
$mdarray = $sorter->sort($mdarray);

Solution 4: Multi-Row Sorting with Closures

PHP 5.3+ allows for anonymous functions (closures), enabling flexible multi-column sorting directly within uasort:

/**
 * Sorts an array of associative arrays by specified fields using closures.
 *
 * @param array $data The input array to sort.
 * @param string|array $fields The field(s) to sort by.
 * @return array The sorted array.
 */
function sortArray( $data, $field ) {
    $field = (array) $field; // Ensure $field is an array
    uasort( $data, function($a, $b) use($field) {
        $retval = 0;
        foreach ($field as $fieldname) {
            // Use strnatcmp for natural string comparison
            if ($retval == 0) $retval = strnatcmp($a[$fieldname], $b[$fieldname]);
        }
        return $retval;
    } );
    return $data;
}

Solution 5: Generic Multi-Array Sorter Function

This function allows sorting a two-dimensional array by multiple keys, compatible with PHP 5.3+:

function sort_multi_array($array, $key)
{
  $keys = array();
  // Collect all sort keys passed as arguments
  for ($i = 1; $i < func_num_args(); $i++) {
    $keys[$i - 1] = func_get_arg($i);
  }

  // Create a custom comparison function for usort
  $func = function ($a, $b) use ($keys) {
    foreach ($keys as $k) {
      if ($a[$k] != $b[$k]) {
        // Return -1 if $a < $b, 1 if $a > $b
        return ($a[$k] < $b[$k]) ? -1 : 1;
      }
    }
    return 0; // Elements are equal
  };

  usort($array, $func);
  return $array;
}

Solution 7: A Versatile Sorter Class

This class provides flexibility for sorting by one or more fields, with options for ascending/descending order and numeric vs. string comparisons, compatible with PHP 4 and PHP 5:

// Sorter class for flexible array sorting
class Sorter {

  var $sort_fields;
  var $backwards = false; // Default to ascending
  var $numeric = false;   // Default to string comparison

  /**
   * Sorts the array based on specified fields.
   * @param array $array The array to sort.
   * @param string ...$sort_fields One or more field names to sort by.
   * @return array The sorted array.
   */
  function sort() {
    $args = func_get_args();
    $array = $args[0];
    if (!$array) return array(); // Return empty if no array is provided

    $this->sort_fields = array_slice($args, 1);
    if (!$this->sort_fields) return $array; // Return original if no sort fields

    // Use the appropriate comparison method based on $numeric flag
    if ($this->numeric) {
      usort($array, array($this, 'numericCompare'));
    } else {
      usort($array, array($this, 'stringCompare'));
    }
    return $array;
  }

  /**
   * Numeric comparison handler for usort.
   */
  function numericCompare($a, $b) {
    foreach ($this->sort_fields as $sort_field) {
      if ($a[$sort_field] == $b[$sort_field]) {
        continue; // Move to the next field if values are equal
      }
      // Return comparison result, respecting the $backwards flag
      return ($a[$sort_field] < $b[$sort_field]) ? ($this->backwards ? 1 : -1) : ($this->backwards ? -1 : 1);
    }
    return 0; // All fields compared and found equal
  }

  /**
   * String comparison handler for usort (case-insensitive).
   */
  function stringCompare($a, $b) {
    foreach ($this->sort_fields as $sort_field) {
      $cmp_result = strcasecmp($a[$sort_field], $b[$sort_field]);
      if ($cmp_result == 0) continue; // Move to the next field if strings are equal

      // Return comparison result, respecting the $backwards flag
      return ($this->backwards ? -$cmp_result : $cmp_result);
    }
    return 0; // All fields compared and found equal
  }
}

/* Usage Examples */
$start_data = array(
  array('first_name' => 'John', 'last_name' => 'Smith', 'age' => 10),
  array('first_name' => 'Joe', 'last_name' => 'Smith', 'age' => 11),
  array('first_name' => 'Jake', 'last_name' => 'Xample', 'age' => 9),
);

$sorter = new Sorter();
// Sort by last_name, then first_name
print_r($sorter->sort($start_data, 'last_name', 'first_name'));

$sorter = new Sorter();
// Sort by first_name, then last_name
print_r($sorter->sort($start_data, 'first_name', 'last_name'));

$sorter = new Sorter();
$sorter->backwards = true; // Set for descending order
// Sort by last_name, then first_name (backwards)
print_r($sorter->sort($start_data, 'last_name', 'first_name'));

$sorter = new Sorter();
$sorter->numeric = true; // Enable numeric comparison
// Sort numerically by age

Solution 8: array_multisort with Header Handling

This function specifically addresses sorting multi-dimensional arrays while optionally preserving a header row:

/**
 * Sorts a 2D array by a specified column using array_multisort.
 *
 * @param array $array The multi-dimensional array to sort.
 * @param string $column The column key/index to sort by.
 * @param int $method The sort method (e.g., SORT_DESC, SORT_ASC).
 * @param bool $has_header True if the first row is a header to be preserved.
 * @return array The sorted array.
 */
function sort2d_bycolumn($array, $column, $method, $has_header) {
  if ($has_header) {
    $header = array_shift($array); // Temporarily remove header
  }
  // Extract the column to sort by
  foreach ($array as $key => $row) {
    $narray[$key] = $row[$column];
  }
  // Perform the sort
  array_multisort($narray, $method, $array);
  if ($has_header) {
    array_unshift($array, $header); // Re-add header
  }
  return $array;
}

Solution 10: A “Dirty” but Simple String Concatenation Method

While not recommended for production environments due to potential delimiter issues, this method offers a quick, albeit hacky, way to sort by concatenating values:

// Example data structure
$names_stuff = array(
    array('NameA', 'Stuff1A', 'Stuff2A'),
    array('NameC', 'Stuff1C', 'Stuff2C'),
    array('NameB', 'Stuff1B', 'Stuff2B')
);

// Sort by name, bringing other data along
$sorted_names = [];
foreach ($names_stuff as $name_stuff) {
    // Concatenate values, using a delimiter that won't appear in the data
    $sorted_names[] = implode(',', $name_stuff);
}
sort($sorted_names, SORT_STRING); // Sort the concatenated strings

// Reconstruct the original array structure
$reconstructed_array = [];
foreach ($sorted_names as $sorted_name) {
    $reconstructed_array[] = explode(',', $sorted_name);
}

// $reconstructed_array is now sorted by the first element (name)

This approach is simple but fragile. Ensure your data does not contain the delimiter used for concatenation.

FAQs on PHP Array Sorting

Q: How do I sort a PHP array by multiple columns

ANS: You can sort a PHP array by multiple columns using usort with a custom comparison function that checks subsequent columns if the primary ones are equal. The make_comparer function and the sortArray function (Solution 4) demonstrate this effectively. You can also use array_multisort by creating separate arrays for each sort column.

Q: Can I sort arrays in descending order in PHP

ANS: Yes, you can sort arrays in descending order. For usort, your comparison function should return 1 when the first argument is less than the second, and -1 when it’s greater. For array_multisort, you use the SORT_DESC constant. The make_comparer function also supports specifying SORT_DESC for individual columns.

Q: How do I sort an array of objects in PHP

ANS: Sorting an array of objects is similar to sorting an array of associative arrays. You would use usort and define a comparison function that accesses the object properties using the arrow operator (->), for example, $a->property instead of $a['key']. The make_comparer function can be adapted for objects if you modify how it accesses data.

Q: What is the difference between usort and array_multisort

ANS: usort sorts an array using a user-defined comparison function, giving you full control over the sorting logic. array_multisort can sort multiple arrays simultaneously or sort a multi-dimensional array based on one or more of its dimensions. usort is more flexible for custom sorting, while array_multisort is efficient for sorting based on extracted columns or related arrays.

Q: How can I sort by dates in PHP arrays

ANS: To sort by dates within PHP arrays, you typically need to convert date strings into a comparable format, such as Unix timestamps or DateTime objects. You can achieve this by using a projection function within usort or make_comparer, like strtotime or date_create, to transform the date strings into a sortable value.

    $criteria = func_get_args();

        $criteria[$index] = is_array($criterion)

    return function($first, $second) use (&amp;$criteria) {
        foreach ($criteria as $criterion) {
            // How will we compare this round?
            list($column, $sortOrder, $projection) = $criterion;
            $sortOrder = $sortOrder === SORT_DESC ? -1 : 1;

            // If a projection was defined project the values now
            if ($projection) {
                $lhs = call_user_func($projection, $first[$column]);
                $rhs = call_user_func($projection, $second[$column]);
            }
            else {
                $lhs = $first[$column];
                $rhs = $second[$column];

            // Do the actual comparison; do not return if equal
            if ($lhs &lt; $rhs) {
                return -1 * $sortOrder;
            }
            else if ($lhs &gt; $rhs) {
                return 1 * $sortOrder;
            }
        }

        return 0; // tiebreakers exhausted, so $first == $second
    };
}
