PHP: How to Check if a String Contains a Substring

Determining if one string exists within another is a fundamental task in programming. PHP offers several functions to achieve this, each with its own nuances regarding performance, case sensitivity, and whether it matches whole words or just sequences of characters. Let’s delve into the most effective methods.

Solution 1: str_contains() (PHP 8+)

Introduced in PHP 8, str_contains() provides a clear and concise way to check for substring presence.

Key Points:

  • It is case-sensitive.
  • If the needle (substring) is empty, it always returns true.

Example:

<?php
// Case-sensitive check
if (str_contains('How are you', 'are')) {
    echo 'Substring "are" found.'; // This will be echoed
} else {
    echo 'Substring "are" not found.';
}

echo "\n";

// Handling empty needle
$haystack = 'Hello World';
$needle = '';

if ($needle !== '' && str_contains($haystack, $needle)) {
    echo "This returned true!";
} else {
    echo "This returned false!"; // This will be echoed because of the empty needle check
}

echo "\n";

// Case sensitivity demonstration
$haystack_case = 'How are you?';
$needle_case = 'how'; // Lowercase 'h'

if (str_contains($haystack_case, $needle_case)) {
    echo 'Found (case-sensitive).';
} else {
    echo 'Not found (case-sensitive).'; // This will be echoed
}
?>

Output:

Substring "are" found.
This returned false!
Not found (case-sensitive).

Important Consideration: Always ensure your needle is not empty before using str_contains() if you expect meaningful results.

Solution 2: strpos() (All PHP Versions)

This function finds the position of the first occurrence of a substring within another string. Crucially, it returns the numeric position (starting from 0) or false if the substring is not found.

Key Points:

  • It is case-sensitive.
  • You must use the strict comparison !== false because 0 (the position of a substring at the start) is evaluated as false in loose comparisons.

Example:

<?php
$haystack = 'How are you?';
$needle = 'are';

if (strpos($haystack, $needle) !== false) {
    echo 'Substring "are" found.'; // This will be echoed
} else {
    echo 'Substring "are" not found.';
}

echo "\n";

// Demonstrating why !== false is critical
$haystack_start = 'apple';
$needle_start = 'a';

if (strpos($haystack_start, $needle_start)) { // Incorrect comparison
    echo 'Found (incorrect comparison).';
} else {
    echo 'Not found (incorrect comparison).'; // This will be echoed
}

echo "\n";

if (strpos($haystack_start, $needle_start) !== false) { // Correct comparison
    echo 'Found (correct comparison).'; // This will be echoed
} else {
    echo 'Not found (correct comparison).';
}
?>

Output:

Substring "are" found.
Not found (incorrect comparison).
Found (correct comparison).

Alternative: A more compact way using strpos() is with a ternary operator:

<?php
$haystack = 'How are you?';
$needle = 'are';
$result = false === strpos($haystack, $needle) ? 'false' : 'true';
echo $result; // Outputs: true
?>

Solution 3: stripos() (All PHP Versions)

This is the case-insensitive version of strpos().

Key Points:

  • It is case-insensitive.
  • Similar to strpos(), you must use strict comparison !== false.

Example:

<?php
$haystack = 'This is a test String';
$needle = 'string'; // Lowercase

if (stripos($haystack, $needle) !== false) {
    echo 'Substring "string" found (case-insensitive).'; // This will be echoed
} else {
    echo 'Substring "string" not found (case-insensitive).';
}
?>

Output:

Substring "string" found (case-insensitive).

Solution 4: strstr() and stristr()

strstr() finds the first occurrence of a substring and returns the rest of the string starting from that substring. stristr() does the same but is case-insensitive.

Key Points:

  • strstr() is case-sensitive.
  • stristr() is case-insensitive.
  • They return false if the substring is not found. You can check the boolean result of the function directly or by checking its length.

Example:

<?php
$haystack = 'I know programming';
$needle = 'know';

if (strstr($haystack, $needle)) { // Returns the rest of the string if found, otherwise false
    echo "'{$needle}' found in '{$haystack}'."; // This will be echoed
} else {
    echo "'{$needle}' not found.";
}

echo "\n";

// Using stristr for case-insensitive search
$haystack_case = 'Hello World';
$needle_case = 'wORLd';

if (stristr($haystack_case, $needle_case)) {
    echo "'{$needle_case}' found (case-insensitive)."; // This will be echoed
} else {
    echo "'{$needle_case}' not found (case-insensitive).";
}
?>

Output:

'know' found in 'I know programming'.
'wORLd' found (case-insensitive).

Solution 5: substr_count()

This function counts all occurrences of a substring within a string.

Key Points:

  • It is case-sensitive.
  • If the count is greater than zero, the substring is present.

Example:

<?php
$haystack = 'banana bandana';
$needle = 'ana';

if (substr_count($haystack, $needle) > 0) {
    echo "Substring '{$needle}' appears " . substr_count($haystack, $needle) . " times."; // This will be echoed
} else {
    echo "Substring '{$needle}' not found.";
}

echo "\n";

// Shorthand check
if (substr_count($haystack, 'band')) { // Non-zero count is truthy
    echo "Substring 'band' is present."; // This will be echoed
}
?>

Output:

Substring 'ana' appears 3 times.
Substring 'band' is present.

Solution 6: preg_match() (Regular Expressions)

For more complex pattern matching, including whole word searches or case-insensitive searches without specific functions like stripos(), regular expressions are powerful.

Key Points:

  • Offers flexibility for intricate patterns.
  • Can be slower than dedicated string functions for simple checks.
  • preg_match('/pattern/i', $string) provides case-insensitivity.

Example (Simple Match):

<?php
$haystack = 'How are you?';
$pattern = '/are/'; // Simple pattern

if (preg_match($pattern, $haystack)) {
    echo "Pattern 'are' found."; // This will be echoed
} else {
    echo "Pattern 'are' not found.";
}
?>

Output:

Pattern 'are' found.

Example (Word Boundaries for Whole Word Matching):

To ensure you’re matching a whole word and not just a sequence of characters within another word (like “are” in “fare”), use word boundaries (\b).

<?php
$haystack = 'The fare is fair.';
$word = 'are';

// Matches 'are' only as a whole word
if (preg_match('/\b' . preg_quote($word, '/') . '\b/i', $haystack)) {
    echo "'{$word}' found as a whole word."; // This will NOT be echoed
} else {
    echo "'{$word}' not found as a whole word."; // This will be echoed
}

echo "\n";

$haystack_whole = 'How are you?';
if (preg_match('/\b' . preg_quote($word, '/') . '\b/i', $haystack_whole)) {
    echo "'{$word}' found as a whole word."; // This will be echoed
} else {
    echo "'{$word}' not found as a whole word.";
}
?>

Output:

'are' not found as a whole word.
'are' found as a whole word.

Note: The \b word boundary might not work as expected with non-ASCII characters. For Unicode support, specific regex patterns might be necessary, as shown in this resource .

Example (Searching for Multiple Words):

<?php
$badWords = ["dette", "capitale", "rembourser", "ivoire", "mandat"];
$string = "a string with the word ivoire";

// Combine words with '|' for OR condition, use \b for whole words, 'i' for case-insensitivity
$pattern = "/\b(" . implode($badWords, "|") . ")\b/i";

if (preg_match_all($pattern, $string, $matches)) {
    echo "A prohibited word has been found."; // This will be echoed
} else {
    echo "Your string is clean.";
}
?>

Output:

A prohibited word has been found.

Solution 7: Custom Function for Robust Checks

You can create your own utility function to handle variations in case sensitivity and provide a clear boolean output.

Example:

<?php
function contains($haystack, $needle, $caseSensitive = false) {
    return $caseSensitive
        ? (strpos($haystack, $needle) === FALSE ? FALSE : TRUE)
        : (stripos($haystack, $needle) === FALSE ? FALSE : TRUE);
}

// Demonstrating usage
var_dump(contains('bare', 'are'));            // bool(true)
var_dump(contains('stare', 'Are', true));     // bool(false) - case sensitive fails
var_dump(contains('stare', 'Are', false));    // bool(true) - case insensitive succeeds
var_dump(contains('hair', 'are'));            // bool(false)
?>

Output:

bool(true)
bool(false)
bool(true)
bool(false)

Performance Considerations

  • For simple substring checks, strpos() and str_contains() (PHP 8+) are generally faster than preg_match().
  • preg_match() is more flexible but comes with a performance overhead for basic tasks.
  • When dealing with multi-byte characters (e.g., UTF-8 encoded strings with accents), consider using the mb_ prefixed functions like mb_strpos() or mb_stripos() for accurate results.

Which Method to Choose?

  • PHP 8+: str_contains() is the most readable for simple, case-sensitive checks.
  • Older PHP / Case-Insensitive: stripos() is ideal for case-insensitive checks.
  • Whole Word Matching: preg_match() with \b word boundaries is the most reliable for ensuring you match entire words.
  • Counting Occurrences: substr_count() is specific for counting.
  • Complex Patterns: Regular expressions (preg_match()) are necessary.

FAQs on PHP String Contains

Q: What is the best way to check if a string contains another string in PHP

ANS: For PHP 8 and above, str_contains() is recommended for its clarity. For older versions or case-insensitive checks, stripos() is efficient. If you need to match whole words or complex patterns, preg_match() with regular expressions is the most robust option.

Q: Is str_contains case sensitive in PHP

ANS: Yes, str_contains() is strictly case-sensitive. ‘apple’ will not match ‘Apple’. Use stripos() for case-insensitive comparisons if needed.

Q: How to perform a case insensitive check for a substring in PHP

ANS: Use the stripos() function. It works similarly to strpos() but ignores the case of the characters during the search. Remember to use the !== false comparison.

Q: Why should I use !== false with strpos or stripos

ANS: The strpos() and stripos() functions return the starting position of the substring, which can be 0 if the substring is at the very beginning. In PHP, 0 evaluates to false in loose comparisons (== or !=). Using strict comparison (=== or !==) ensures that you correctly distinguish between finding the substring at position 0 and not finding it at all.

Q: Can preg_match be used to check for substrings

ANS: Yes, preg_match() can be used. For a simple substring check, it’s generally less performant than dedicated functions like strpos() or str_contains(). However, it’s invaluable for pattern matching, including finding whole words using word boundaries (\b) or performing complex searches.

Q: What is the difference between strpos and strstr

ANS: strpos() returns the numeric position of the first occurrence of a substring. strstr() returns the portion of the haystack string starting from the first occurrence of the needle, or false if not found.

Q: How do I check for multiple words in a string using PHP

ANS: You can use preg_match() with a pattern that combines multiple words using the OR operator (|). For example, preg_match('/(word1|word2|word3)/', $string) checks if any of the specified words exist. Using preg_match_all() can help find all occurrences.

Q: How to check for a word, not just a substring, in PHP

ANS: Use preg_match() with word boundaries (\b). For example, preg_match('/\bare\b/', $string) will find “are” as a standalone word but not within “fare” or “care”. Be mindful of Unicode characters, which may require different boundary definitions.
