“PHP Array Grouping by Key: Effective Methods & Examples”

When working with datasets in PHP, it’s common to encounter situations where you need to organize an array of associative arrays based on the value of a specific key. This process, often referred to as “grouping by key,” transforms a flat list into a more structured, often nested, representation. This can be invaluable for reporting, data analysis, or simply making your data more manageable.

Let’s dive into several effective ways to achieve array grouping in PHP, each with its own nuances and use cases.

Common Scenario: Grouping by an Identifier

Imagine you have an array of data, perhaps representing items with unique identifiers. You want to group these items so that all items sharing the same identifier are collected together.

Consider this sample data structure:

$data = [
    ['id' => 96, 'shipping_no' => '212755-1', 'part_no' => 'reterty', 'description' => 'tyrfyt', 'packaging_type' => 'PC'],
    ['id' => 96, 'shipping_no' => '212755-1', 'part_no' => 'dftgtryh', 'description' => 'dfhgfyh', 'packaging_type' => 'PC'],
    ['id' => 97, 'shipping_no' => '212755-2', 'part_no' => 'ZeoDark', 'description' => 's%c%s%c%s', 'packaging_type' => 'PC'],
];

Our goal is to group this $data array by the 'id' key.

Solution Approaches

Here are several methods to accomplish this task, ranging from basic loops to more advanced functional programming techniques.

Solution 1: Iterative Grouping (Basic Loop)

This is a straightforward approach using a foreach loop. You iterate through the array, and for each element, you use its 'id' value as a key in a new result array. If the key doesn’t exist, it’s created, and the current element is added to its sub-array.

$result = [];
foreach ($data as $element) {
    $result[$element['id']][] = $element;
}

This approach is clear and efficient for most use cases.

Solution 2: Using array_reduce (Functional Style)

For those who prefer a functional programming paradigm, array_reduce offers a concise way to achieve grouping. It iterates over the array and accumulates a single result value.

$groupedById = array_reduce($data, function (array $accumulator, array $element) {
  $accumulator[$element['id']][] = $element;
  return $accumulator;
}, []);

Here, $accumulator holds the gradually built grouped array, starting with an empty array [].

Solution 3: foreach with var_dump for Inspection

This solution is similar to the first but includes a var_dump to visualize the structure of the grouped array. It demonstrates how the data is organized.

$group = [];
foreach ($data as $value) {
    $group[$value['id']][] = $value;
}
var_dump($group);

The output clearly shows elements grouped under their respective 'id' keys.

Solution 4: Custom array_group_by Function

This method involves creating a reusable function that takes the array and a callback function to define the grouping key. This is inspired by the .NET LINQ GroupBy functionality.

<?php
// The callable type hint might need to be "closure" depending on the PHP version.
function array_group_by(array $arr, callable $key_selector): array
{
  $result = [];
  foreach ($arr as $item) {
    $key = call_user_func($key_selector, $item);
    $result[$key][] = $item;
  }
  return $result;
}

$sampleData = [
    [1, "Andy", "PHP"],
    [1, "Andy", "C#"],
    [2, "Josh", "C#"],
    [2, "Josh", "ASP"],
    [1, "Andy", "SQL"],
    [3, "Steve", "SQL"],
];

$grouped = array_group_by($sampleData, function ($item) {
    return $item[0];
});

var_dump($grouped);
?>

This custom function enhances reusability and can be adapted for more complex grouping criteria.

Solution 5: Grouping and Removing the Grouping Column

This function groups the data and then removes the specified grouping column from the sub-arrays.

function array_group(array $data, string $by_column): array
{
    $result = [];
    foreach ($data as $item) {
        $column = $item[$by_column];
        unset($item[$by_column]); // Remove the grouping column from the sub-array
        $result[$column][] = $item;
    }
    return $result;
}

This is useful when the grouping key itself is not needed within the grouped sub-items.

Solution 11: Utility Functions for Unique Rows and Identifiers

This set of functions provides utilities for identifying unique rows based on all columns, unique rows based on specific identifiers, and removing duplicate columns.

// Function to group by a single identifier, keeping unique IDs
function arrayUniqueByIdentifier(array $array, string $identifier): array
{
    $ids = array_column($array, $identifier);
    $ids = array_unique($ids);
    // Filter to keep only elements whose keys are in the unique IDs
    $array = array_filter($array,
        function ($key, $value) use ($ids) {
            return in_array($value, array_keys($ids));
        }, ARRAY_FILTER_USE_BOTH);
    return $array;
}

// Function to ensure rows are unique based on all column values
function arrayUniqueByRow(array $table = [], string $implodeSeparator = '|'): array
{
    $elementStrings = [];
    foreach ($table as $row) {
        $elementPreparedForImplode = array_map(
            function ($field) {
                $valueType = gettype($field);
                $simpleTypes = ['boolean', 'integer', 'double', 'float', 'string', 'NULL'];
                // Use type name for non-simple types to ensure comparison
                return in_array($valueType, $simpleTypes) ? $field : $valueType;
            }, $row
        );
        $elementStrings[] = implode($implodeSeparator, $elementPreparedForImplode);
    }
    $elementStringsUnique = array_unique($elementStrings);
    // Intersect keys to keep only the unique rows
    $table = array_intersect_key($table, $elementStringsUnique);
    return $table;
}

// Function to ensure rows are unique based on a specified set of identifiers
function arrayUniqueByMultipleIdentifiers(array $table, array $identifiers, string $implodeSeparator = '|'): array
{
    $arrayForMakingUniqueByRow = removeArrayColumns($table, $identifiers, true);
    $arrayUniqueByRow = arrayUniqueByRow($arrayForMakingUniqueByRow, $implodeSeparator);
    // Keep only the original rows that correspond to the unique filtered rows
    $arrayUniqueByMultipleIdentifiers = array_intersect_key($table, $arrayUniqueByRow);
    return $arrayUniqueByMultipleIdentifiers;
}

// Helper to remove or keep specific columns for uniqueness checks
function removeArrayColumns(array $table, array $columnNames, bool $isWhitelist = false): array
{
    foreach ($table as $rowKey => $row) {
        if (is_array($row)) {
            if ($isWhitelist) { // Keep only specified columns
                foreach ($row as $fieldName => $fieldValue) {
                    if (!in_array($fieldName, $columnNames)) {
                        unset($table[$rowKey][$fieldName]);
                    }
                }
            } else { // Remove specified columns
                foreach ($row as $fieldName => $fieldValue) {
                    if (in_array($fieldName, $columnNames)) {
                        unset($table[$rowKey][$fieldName]);
                    }
                }
            }
        }
    }
    return $table;
}

These functions offer granular control over uniqueness criteria.

Solution 12: Custom groupBy Function with Specific Output Structure

This custom function groups data and structures the output with the grouping key at the top level and the remaining data in a nested ‘data’ array.

function groupBy($array, $key): array
{
    $groupedData = [];
    $data = [];
    $_id = ""; // Variable to track the current group ID

    for ($i = 0; $i < count($array); $i++) {
        $row = $array[$i];
        if ($row[$key] != $_id) {
            // If a new group starts and the previous one had data, add it to the result
            if (count($data) > 0) {
                $groupedData[] = $data;
            }

            // Initialize for the new group
            $_id = $row[$key];
            $data = [
                $key => $_id
            ];
        }

        // Add the current row's data (excluding the grouping key) to the group
        unset($row[$key]);
        $data["data"][] = $row;

        // Ensure the last group is added
        if ($i == count($array) - 1) {
            $groupedData[] = $data;
        }
    }

    return $groupedData;
}

Solution 13: Simple Key-Value Grouping (Associative or Object)

This approach uses helper functions to group data, creating an associative array where the keys are the values from the specified grouping column. It handles both arrays and objects.

// For arrays
function array_group_by(array $arr, string $fldName): array
{
    $groups = [];
    foreach ($arr as $rec) {
        $groups[$rec[$fldName]] = $rec; // Overwrites if keys are identical
    }
    return $groups;
}

// For objects
function object_group_by(array $obj, string $fldName): array
{
    $groups = [];
    foreach ($obj as $rec) {
        $groups[$rec->$fldName] = $rec; // Overwrites if keys are identical
    }
    return $groups;
}

Note that this method will only keep the last encountered row for any given group key due to array overwriting behavior.

Solution 15: Custom Grouping Function with Specified Fields

This function, groupeByPHP, is designed for more complex grouping scenarios, allowing you to specify which fields to keep and which to group by.

function groupeByPHP($array, $indexUnique, $assoGroup, $keepInOne): array
{
    $retour = [];
    $id = $array[0][$indexUnique]; // Initialize with the first element's ID

    // Populate the initial structure for the first group
    foreach ($keepInOne as $keep) {
        $retour[$id][$keep] = $array[0][$keep];
    }

    // Process based on associated groups
    foreach ($assoGroup as $cle => $arrayKey) {
        $arrayGrouped = [];
        foreach ($array as $data) {
            // If the unique identifier changes, start a new group
            if ($data[$indexUnique] != $id) {
                $id = $data[$indexUnique];
                // Populate the new group's structure
                foreach ($keepInOne as $keep) {
                    $retour[$id][$keep] = $data[$keep];
                }
            }
            // Collect data for the current group's sub-array
            foreach ($arrayKey as $val) {
                $arrayGrouped[$val] = $data[$val];
            }
            // Add the collected data to the group and ensure uniqueness
            $retour[$id][$cle][] = $arrayGrouped;
            $retour[$id][$cle] = array_unique($retour[$id][$cle], SORT_REGULAR);
        }
    }
    return $retour;
}

// $yourArray = ...; // Your data array
// $groupedResult = groupeByPHP($yourArray, 'id', ['desc' => ['part_no', 'packaging_type']], ['id', 'shipping_no']);

This function offers fine-grained control over the grouping process.

Solution 16: Recursive Grouping

This approach uses a recursive function to group arrays by multiple keys, creating a nested structure.

function getGroupedArray($array, $keyFieldsToGroup): array
{
    $newArray = [];
    foreach ($array as $record) {
        $newArray = getRecursiveArray($record, $keyFieldsToGroup, $newArray);
    }
    return $newArray;
}

function getRecursiveArray($itemArray, $keys, $newArray) {
    if (count($keys) > 1) {
        // If more keys exist, recurse into the next level
        $newArray[$itemArray[$keys[0]]] = getRecursiveArray($itemArray, array_splice($keys, 1), $newArray[$itemArray[$keys[0]]]);
    } else {
        // Base case: add the item to the lowest level group
        $newArray[$itemArray[$keys[0]]][] = $itemArray;
    }
    return $newArray;
}

Solution 17: Recursive Grouping with Associative Keys

Similar to Solution 16, this function array_group_by recursively groups data, using the grouping key’s values as associative keys at each level.

function array_group_by($arr, array $keys): array
{
    // Input validation
    if (!is_array($arr)) {
        trigger_error('array_group_by(): The first argument should be an array', E_USER_ERROR);
    }
    if (count($keys) == 0) {
        trigger_error('array_group_by(): The Second argument Array can not be empty', E_USER_ERROR);
    }

    $grouped = [];
    // Initial grouping by the first key
    foreach ($arr as $value) {
        $grouped[$value[$keys[0]]][] = $value;
    }

    // Recursive grouping for subsequent keys
    if (count($keys) > 1) {
        foreach ($grouped as $key => $value) {
            // Prepare arguments for the recursive call
            $params = array_merge([$value], [array_slice($keys, 1, count($keys))]);
            $grouped[$key] = call_user_func_array('array_group_by', $params);
        }
    }
    return $grouped;
}

// var_export(array_group_by($data, ['id', 'shipping_no']));

This function is robust for multi-level grouping with associative keys.

Solution 18: Recursive Key Shifting and Grouping

This function array_group_by_keys recursively groups an array by shifting keys. It modifies the array in place.

function array_group_by_keys(&$arr, $keys) {
    if (count($arr) < 2) { // Base case for recursion
        if (isset($arr[0])) { // Ensure $arr[0] exists
            $arr = array_shift($arr[0]);
        } else {
            // Handle cases where $arr might be empty or malformed
            // For example, set $arr to null or an empty array
            $arr = null; // Or $arr = [];
        }
        return;
    }

    // Process the current level of grouping
    foreach ($arr as $k => $item) {
        if (!is_array($item) || count($item) === 0) {
             // Skip if item is not a non-empty array (e.g., scalar values)
             // Or handle as needed. For this function, we expect arrays.
             continue;
        }
        $fvalue = array_shift($item); // Get the value for the current grouping key
        if ($fvalue !== null) { // Only proceed if we got a value
            $arr[$fvalue][] = $item; // Add the rest of the item to the new group
        }
        unset($arr[$k]); // Remove the original item
    }

    // Recurse into the next level of grouping
    if (!empty($keys)) { // Check if there are more keys to group by
        array_shift($keys); // Move to the next key
        foreach ($arr as &$sub_arr) { // Use reference for in-place modification
            if (is_array($sub_arr)) { // Ensure we are recursing into an array
                array_group_by_keys($sub_arr, $keys);
            }
        }
    }
}

Solution 19: Multi-level Grouping with array_reduce

This groupBy function utilizes array_reduce for elegant multi-level grouping, supporting grouping by multiple keys successively.

function groupBy($rows, ...$keys)
{
    if ($key = array_shift($keys)) { // Get the current key to group by
        $groups = array_reduce($rows, function ($groups, $row) use ($key) {
            // Determine the group value (handles both objects and arrays)
            $group = is_object($row) ? $row->{$key} : $row[$key];
            $groups[$group][] = $row; // Add the row to the corresponding group
            return $groups;
        }, []);

        // If there are more keys, recurse for sub-grouping
        if ($keys) {
            foreach ($groups as $subKey => $subRows) {
                // Pass the remaining keys for the next level of grouping
                $groups[$subKey] = groupBy($subRows, ...$keys);
            }
        }
    }
    return $groups;
}

// $rows = [ ... ]; // your data
// $groups = groupBy($rows, 'country', 'city', 'surname');

This is a powerful recursive solution for complex hierarchical grouping.

Solution 21: array_combine for Single-Row Groups

This method uses array_column to extract keys and array_combine to create a new array where keys are the grouped values. It results in only one row per group (the last one encountered).

// Assuming $source is your data array and $groupByColumn is 'id'
$result = array_combine(
    array_column($source, $groupByColumn), // Keys for the new array
    $source // Values for the new array
);

This is a shortcut if you only need one representative row per group.

Choosing the Right Method

The best approach depends on your specific needs:

  • Simplicity and Readability: The basic foreach loop (Solution 1) is often the most straightforward.
  • Functional Style: array_reduce (Solution 2) appeals to functional programming enthusiasts.
  • Reusability: Custom functions (Solutions 4, 5, 12, 15, 16, 17, 18) are excellent for repeated tasks.
  • Advanced Features: Libraries like webfactory/array-group-by (Solution 6) or YaLinqo (Solution 10) offer powerful capabilities.
  • Specific Output Formats: Some solutions (e.g., 12, 21) are tailored for particular output structures.
  • Laravel Users: mapToGroups (Solution 20) integrates seamlessly with Laravel’s collection API.

Exploring these diverse methods should equip you with the tools to effectively manage and structure your array data in PHP.

FAQs on PHP Array Grouping by Key

Q: What is the most straightforward way to group an array in PHP

ANS: The most straightforward method is typically using a foreach loop. You iterate through your array, using the value of the grouping key to build keys in a new result array, appending each element to the appropriate sub-array.

Q: Can I group an array by multiple keys in PHP

ANS: Yes, you can group by multiple keys. This usually involves nesting groups. Solutions using recursive functions (like Solution 16, 17, 19) or libraries designed for multi-level grouping are well-suited for this.

Q: How do I handle non-unique keys when grouping

ANS: When grouping, if multiple elements share the same key value, they are typically collected into an array under that key. Most of the provided solutions handle this naturally by appending elements to an existing sub-array. If you only want one row per group, methods like Solution 21 using array_combine can be used, which overwrites previous entries for duplicate keys.

Q: Is there a built-in PHP function for array grouping

ANS: PHP does not have a single built-in function that directly performs array grouping by key in the way that array_reduce or custom functions do. However, array_reduce can be creatively used for this purpose, and functions like array_column and array_combine can achieve specific grouping outcomes.

Q: What are the advantages of using a library for array grouping

ANS: Libraries often provide optimized performance, robust error handling, and advanced features like multi-level grouping or complex callback support that might be tedious to implement from scratch. They also adhere to established coding standards.
