“WooCommerce Order Data Access: Pre-3.0 vs. Post-3.0 Methods”

With the major update to WooCommerce version 3.0+, the way developers interact with order data has significantly shifted. Previously, properties of the WC_Order object could be accessed directly. However, these direct property accesses are no longer supported and will result in errors. The current approach mandates the use of new getter and setter methods for the WC_Order and WC_Abstract_Order objects. Furthermore, new classes have been introduced for handling different types of order items. The WC_Data abstract class now provides standardized methods like get_data(), get_meta_data(), and get_meta() for accessing order and order item details. This fundamental change means that order item properties are not directly accessible within loops as before, requiring the adoption of these specific methods. The implementation of CRUD (Create, Read, Update, Delete) methods is now a requirement, especially with the High-Performance Order Storage (HPOS) feature.

What are the key changes and new classes in WooCommerce 3.0+ for order data retrieval?

Since WooCommerce version 3.0+, the structure for handling order data has been revamped. Direct property access on WC_Order objects is deprecated. Instead, you must utilize getter and setter methods. Additionally, specific classes are now used for each type of order item:

  • WC_Order_Item
  • WC_Order_Item_Product
  • WC_Order_Item_Tax
  • WC_Order_Item_Shipping
  • WC_Order_Item_Coupon
  • WC_Order_Item_Fee

The WC_Data abstract class plays a crucial role, offering methods like get_data() to retrieve order and order item data as an associative array, and get_meta() for specific meta information. This structure ensures consistent data access.

What are the recommended methods for retrieving order data in WooCommerce 3.0+?

For WooCommerce versions 3.0 and later, direct property access is discouraged. The preferred method involves using the getter and setter methods provided by the WC_Order and WC_Abstract_Order classes. You can also retrieve all order data as an array using the get_data() method.

Here’s an example of fetching basic order information:

// Obtain an instance of the WC_Order object
$order = wc_get_order( $order_id );

// Retrieve order ID
$order_id_retrieved = $order->get_id();

// Retrieve parent order ID (useful for subscriptions)
$parent_id = $order->get_parent_id();

// Get customer ID
$user_id = $order->get_user_id();

// Get the WP_User object for the customer
$user = $order->get_user();

// Get order status
$order_status = $order->get_status();

// Check if the order has a specific status
if ( $order->has_status('completed') ) {
    // Execute actions for completed orders
}

// Get currency used
$currency = $order->get_currency();

// Get payment method identifier
$payment_method = $order->get_payment_method();

// Get payment method title
$payment_title = $order->get_payment_method_title();

// Get order creation date (WC_DateTime object)
$date_created = $order->get_date_created();

// Get order modification date (WC_DateTime object)
$date_modified = $order->get_date_modified();

// Get the URL for the order received page
$order_received_url = $order->get_checkout_order_received_url();

// Get customer's billing country
$billing_country = $order->get_billing_country();

// Many other details can be accessed similarly...

How do I retrieve and iterate through order items in WooCommerce 3.0+?

When working with order items in WooCommerce 3.0+, you’ll iterate through the results of $order->get_items(). Each item within the loop is an instance of WC_Order_Item or its subclasses (like WC_Order_Item_Product). You then use methods on these item objects to retrieve specific details.

// Obtain an instance of the WC_Order object
$order = wc_get_order( $order_id );

// Iterate through each order item
foreach ( $order->get_items() as $item_key => $item ) :

    // Get the item ID
    $item_id = $item->get_id();

    // Check if it's a product item to use product-specific methods
    if ( $item->is_type( 'line_item' ) ) :
        $product = $item->get_product(); // Get the WC_Product object

        // Get product details
        $product_id = $item->get_product_id();
        $variation_id = $item->get_variation_id();

        // Get item details
        $item_type = $item->get_type(); // Typically 'line_item'
        $item_name = $item->get_name();
        $quantity = $item->get_quantity();
        $tax_class = $item->get_tax_class();
        $line_subtotal = $item->get_subtotal(); // Non-discounted subtotal
        $line_subtotal_tax = $item->get_subtotal_tax(); // Non-discounted subtotal tax
        $line_total = $item->get_total(); // Discounted total
        $line_total_tax = $item->get_total_tax(); // Discounted total tax

        // Access order item data properties as an array
        $item_data = $item->get_data();

        $product_name_from_data = $item_data['name'];
        $product_id_from_data = $item_data['product_id'];
        $variation_id_from_data = $item_data['variation_id'];
        $quantity_from_data = $item_data['quantity'];
        $tax_class_from_data = $item_data['tax_class'];
        $line_subtotal_from_data = $item_data['subtotal'];
        $line_subtotal_tax_from_data = $item_data['subtotal_tax'];
        $line_total_from_data = $item_data['total'];
        $line_total_tax_from_data = $item_data['total_tax'];

        // Get data from the WC_Product object
        if ( $product ) {
            $product_type = $product->get_type();
            $product_sku = $product->get_sku();
            $product_price = $product->get_price();
            $stock_quantity = $product->get_stock_quantity();
        }
    endif;

endforeach;

Can I access order details by directly creating a WC_Order object?

Yes, you can instantiate a WC_Order object directly using the order ID. This is another valid approach for retrieving order details, and it remains consistent across recent WooCommerce versions.

// Obtain an instance of the WC_Order object by direct instantiation
$order = new WC_Order( $order_id );

// Retrieve the order total
$order_total = $order->get_total();

// Retrieve the order status
$order_status = $order->get_status();

// Retrieve the order billing address (as a formatted string)
$order_billing_address = $order->get_billing_address();

// Retrieve the order shipping address (as a formatted string)
$order_shipping_address = $order->get_shipping_address();

// Retrieve all order data as an array
$order_data = $order->get_data();

What other methods are available for accessing order information?

Several other methods and properties can be accessed directly from the WC_Order object to retrieve various details. These include:

  • $order->get_id(): Retrieves the order ID.
  • $order->get_order_key(): Retrieves the unique order key.
  • $order->get_formatted_order_total(): Gets the formatted total amount.
  • $order->get_currency(): Retrieves the order currency.
  • $order->get_total(): Gets the order’s grand total.
  • $order->get_total_discount(): Gets the total discount applied.
  • $order->get_shipping_total(): Retrieves the shipping cost.
  • $order->get_shipping_tax(): Gets the tax applied to shipping.
  • $order->get_tax_totals(): Retrieves an array of tax totals.
  • $order->get_customer_note(): Fetches any customer notes.
  • $order->is_download_permitted(): Checks if download permissions are granted.

You can also access billing and shipping details individually using methods like:

  • $order->get_billing_first_name()
  • $order->get_billing_last_name()
  • $order->get_billing_address_1()
  • $order->get_billing_city()
  • $order->get_billing_country()
  • $order->get_shipping_first_name()
  • $order->get_shipping_address_2()
  • $order->get_shipping_postcode()
  • $order->get_shipping_state()

There are also methods related to refunds and item quantities:

  • $order->get_total_refunded(): Total amount refunded.
  • $order->get_total_tax_refunded(): Total tax refunded.
  • $order->get_item_count_refunded(): Number of items refunded.
  • $order->get_qty_refunded_for_item(): Quantity refunded for a specific item.

Is there a way to fetch order details using the WordPress REST API?

Yes, you can leverage the WordPress REST API to retrieve WooCommerce order details, especially when integrating with external applications or building custom interfaces. This involves making a GET request to the appropriate endpoint.

// Construct the REST API request
$request = new WP_REST_Request('GET', '/wc/v3/orders/<YOUR_ORDER_ID>'); // Replace <YOUR_ORDER_ID>

// Execute the request
$response = rest_do_request($request);
$server = rest_get_server();

FAQs on WooCommerce Order Data Access

Q: How to get order ID in WooCommerce 3.0+

ANS: You can get the order ID by calling the get_id() method on the WC_Order object. For example: $order_id = $order->get_id();.

Q: Can I access order items directly in a loop post WooCommerce 3.0

ANS: No, direct property access for order items is deprecated. You should use methods like $item->get_name(), $item->get_quantity(), and $item->get_data() to retrieve item details.

Q: What happened to direct property access in WC_Order object

ANS: Direct property access on WC_Order objects is no longer supported in WooCommerce 3.0+. You must use the provided getter and setter methods (e.g., $order->get_status()) instead.

Q: How do I get billing address from a WooCommerce order

ANS: You can retrieve the billing address using methods like $order->get_billing_first_name(), $order->get_billing_address_1(), $order->get_billing_city(), etc., or get the complete formatted address with $order->get_billing_address().

Q: What are the new classes for order items

ANS: The new classes for order items are WC_Order_Item, WC_Order_Item_Product, WC_Order_Item_Tax, WC_Order_Item_Shipping, WC_Order_Item_Coupon, and WC_Order_Item_Fee.
