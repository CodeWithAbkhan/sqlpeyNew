“PHP Excel Integration: Read, Write, and Format Spreadsheets”

Working with spreadsheets in PHP involves selecting the right tools for reading and writing different Excel file formats. Several libraries and extensions offer varying levels of functionality, from basic data import/export to complex formatting and workbook manipulation. This exploration covers popular options and practical considerations.

Solutions for Writing Excel Files in PHP

When it comes to generating Excel files from PHP, a diverse set of tools is available, each with its own strengths and supported formats:

  • PEAR’s PHP_Excel_Writer: A classic option primarily supporting the older .xls format.
  • php_writeexcel (from Bettina): Another library focused on the .xls format.
  • Attack: This is a commercial solution specifically for .xls files.
  • XLS File Generator: A commercial tool also dedicated to .xls output.
  • Excel Writer for PHP (from Sourceforge): This library specializes in generating SpreadsheetML, which is the XML-based format used by Excel 2003.
  • Ilia Alshanetsky’s Excel extension (on GitHub): This extension supports both .xls and .xlsx formats. However, it requires a commercial libXL component.
  • PHP’s COM extension: For this to work, you need a COM-enabled spreadsheet application, such as Microsoft Excel or OpenOffice Calc, running on the server. This method offers extensive control but relies on external software.
  • The Open Office alternative to COM (PUNO): Similar to the COM extension, this requires OpenOffice to be installed on the server with Java support enabled. It’s an alternative for leveraging OpenOffice’s capabilities.
  • PHP-Export-Data by Eli Dickinson: This library is excellent for generating SpreadsheetML (Excel 2003 XML format) and also supports CSV output. You can find it at http://github.com/elidickinson/php-export-data .
  • Oliver Schwarz’s php-excel: Another option for generating SpreadsheetML.
  • Oliver Schwarz’s original version of php-excel: The initial release of Oliver Schwarz’s php-excel library, also for SpreadsheetML.
  • excel_xml: As the name suggests, this library targets SpreadsheetML, though a reported link for it is broken.
  • The tiny-but-strong (tbs) project: This project includes OpenTBS, a tool specifically designed for creating OfficeOpenXML documents, supporting OpenDocument and OfficeOpenXML formats.
  • SimpleExcel: This library claims to handle a wide array of formats, including Microsoft Excel XML, CSV, TSV, HTML, and JSON.
  • KoolGrid: Primarily for .xls spreadsheets, but it also supports .doc and .pdf exports.
  • PHP_XLSXWriter: A robust library for generating OfficeOpenXML (.xlsx) files.
  • PHP_XLSXWriter_plus: A fork of PHP_XLSXWriter, also focused on OfficeOpenXML.
  • php_writeexcel (from GitHub): Appears to be based on PEAR SEW and supports .xls files.
  • spout: A modern library supporting OfficeOpenXML (.xlsx) and CSV formats.
  • Slamdunk/php-excel: This library focuses on the .xls format and seems to be an updated version of the older PEAR Spreadsheet Writer.

Many of these libraries claim superior performance compared to older solutions like PHPExcel. However, a key differentiator is often the breadth of features: few offer both reading and writing capabilities, or support for both .xls and .xlsx formats simultaneously, with exceptions like COM, PUNO, Ilia’s extension (dependent on libXL), and spout. For granular control over the created workbook, COM and PUNO are often cited as offering the most comprehensive options.

Solutions for Reading Excel Files in PHP

Reading data from Excel files in PHP also presents several choices, catering to different file types and requirements:

  • php-spreadsheet-reader: This library is versatile, capable of reading various formats including .xls, .ods, and .csv.
  • PHP-ExcelReader: A dedicated reader for the older .xls format.
  • PHP_Excel_Reader: Another library specifically for reading .xls files.
  • PHP_Excel_Reader2: A variation of the .xls reader.
  • XLS File Reader: A commercial tool exclusively for .xls files.
  • SimpleXLSX: Despite the author’s frequent references to .xls, its description indicates it reads .xlsx files.
  • PHP Excel Explorer: A commercial option for reading .xls files.
  • Ilia Alshanetsky’s Excel extension (on GitHub): Supports both .xls and .xlsx, but requires the commercial libXL component.
  • PHP’s COM extension: As mentioned for writing, this requires a COM-enabled spreadsheet program on the server and offers broad compatibility.
  • The Open Office alternative to COM (PUNO): Leverages OpenOffice on the server for reading various spreadsheet formats.
  • Nuovo’s spreadsheet-reader: A capable reader supporting .csv, .xls, .xlsx, and .ods formats.
  • SimpleExcel: As noted for writing, this library also claims to read Microsoft Excel XML, CSV, TSV, HTML, and JSON.
  • PHPExcleReader: This appears to be a simple ZIP archive containing an older version of PHPExcel.
  • Akeneo Labs Spreadsheet Parser: Handles OfficeOpenXML (.xlsx) and CSV files.
  • spout: Supports reading OfficeOpenXML (.xlsx) and CSV formats.
  • xhook’s php-spreadsheetreader: Claims to process most Excel formats.

A notable entry is phpexcellib from SIMITGROUP, a C++ Excel extension for PHP. While it promises performance, it requires manual building, and its documentation is sparse regarding supported formats and functionalities for both reading and writing.

When comparing these options, many are positioned as faster than the well-known PHPExcel. However, the trade-offs often involve a narrower feature set, such as lacking both read and write capabilities, or limited format support. Libraries like COM and PUNO provide extensive control, while others like spout offer modern support for .xlsx and CSV.

Practical Example: Writing Data to XLSX using PHP_XLSXWriter

Let’s illustrate writing data to an .xlsx file using the PHP_XLSXWriter library.

First, ensure you have the library installed. You can typically do this via Composer:

composer require setasign/phpxlsxwriter

Then, you can use it like this:

<?php

require 'vendor/autoload.php';

use XLSXWriter;

// Sample data
$data = [
    ['Name', 'Department', 'Salary'],
    ['John Doe', 'Engineering', '70000'],
    ['Jane Smith', 'Marketing', '65000'],
    ['Peter Jones', 'Sales', '72000'],
];

$writer = new XLSXWriter();
$writer->writeSheetHeader('Employee Data', ['Name' => 'string', 'Department' => 'string', 'Salary' => 'integer'], $col_options = ['widths' => [20, 20, 15]]);

foreach ($data as $row) {
    $writer->writeSheetRow($row);
}

// Set the output file name
$filename = 'employee_salaries.xlsx';

// Write the file to the browser
header('Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet');
header('Content-Disposition: attachment;filename="' . $filename . '"');
header('Cache-Control: max-age=0');

$writer->writeToStdOut(); // Outputs the XLSX content to the browser

?>

This script creates an Excel file named employee_salaries.xlsx with employee data, including header formatting and column widths.

Alternative Solution: SimpleXML for SpreadsheetML

For older Excel versions or when SpreadsheetML is preferred, you can construct the XML directly. This approach requires a good understanding of the SpreadsheetML schema but offers fine-grained control without external libraries.

Here’s a simplified conceptual example of generating SpreadsheetML:

<?php

// Sample data
$data = [
    ['Product', 'Price'],
    ['Laptop', '1200'],
    ['Mouse', '25'],
];

$xml = new SimpleXMLElement('<?xml version="1.0"?><Workbook xmlns="urn:schemas-microsoft-com:office:spreadsheet" xmlns:o="urn:schemas-microsoft-com:office:office" xmlns:x="urn:schemas-microsoft-com:office:excel" xmlns:ss="urn:schemas-microsoft-com:office:spreadsheet" xmlns:html="http://www.w3.org/TR/REC-html40"><Worksheet ss:Name="Sheet1"><Table></Table></Worksheet></Workbook>');

$table = $xml->Worksheet->Table;

// Add rows and cells
foreach ($data as $rowIndex => $row) {
    $newRow = $table->addChild('Row');
    foreach ($row as $colIndex => $cellValue) {
        $newCell = $newRow->addChild('Cell');
        $dataNode = $newCell->addChild('Data', htmlspecialchars($cellValue));
        // Specify data type (e.g., String, Number)
        $dataNode->addAttribute('ss:Type', 'String'); 
    }
}

// Set headers for download
$filename = 'product_list.xml';
header('Content-Type: application/vnd.ms-excel');
header('Content-Disposition: attachment;filename="' . $filename . '"');
header('Cache-Control: max-age=0');

// Output the XML
echo $xml->asXML();

?>

This snippet demonstrates how to build the XML structure for a basic spreadsheet. Real-world SpreadsheetML generation can be more complex, involving namespaces, cell styles, and other attributes.

FAQs on PHP Excel Integration

Q: Which PHP libraries are best for writing .xlsx files

ANS: For writing .xlsx files in PHP, PHP_XLSXWriter is a highly recommended, modern library. spout is another excellent option that supports .xlsx and CSV formats.

Q: Can PHP read .ods files

ANS: Yes, php-spreadsheet-reader and Nuovo's spreadsheet-reader are capable of reading .ods files, alongside other formats like .xls and .csv.

Q: What is SpreadsheetML in PHP context

ANS: SpreadsheetML refers to the XML-based format that Microsoft Excel used for its spreadsheets before the introduction of OfficeOpenXML (.xlsx). Libraries like PHP-Export-Data and Oliver Schwarz’s php-excel are designed to work with this format in PHP.

Q: Are there commercial PHP libraries for Excel

ANS: Yes, there are commercial options available for reading and writing Excel files in PHP, such as ‘Attack’ and ‘XLS File Generator’ for .xls files, and ‘XLS File Reader’ also for .xls. Ilia Alshanetsky’s extension requires a commercial libXL component.

Q: How to handle large Excel files in PHP

ANS: For very large Excel files, consider libraries that process data in chunks or use streaming capabilities to avoid memory exhaustion. spout is designed with performance and memory efficiency in mind for large datasets. Avoid loading the entire file into memory if possible.
