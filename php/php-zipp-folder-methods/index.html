“PHP ZipArchive: Methods for Zipping Folders Recursively and Conditionally”

How does one effectively create a compressed ZIP archive containing all files and subdirectories from a specified source folder using PHP, particularly when advanced requirements like conditional file exclusion or maintaining directory structure within the archive are necessary? The built-in ZipArchive class offers several paths to achieve this, ranging from classic recursive iteration to leveraging specialized methods or even external shell commands.

Recursive Directory Zipping with ZipArchive Iterators

A standard approach involves using PHP’s SPL iterators to traverse the directory structure recursively.

Solution 1: Zipping a Whole Folder Recursively

To zip an entire folder while preserving its internal hierarchy within the resulting archive, employ RecursiveDirectoryIterator and RecursiveIteratorIterator.

<?php
$rootPath = 'folder-to-zip';

// Clean path separators and get the absolute path
$rootPath = rtrim($rootPath, '\\/');
$rootPath = realpath($rootPath);

// Initialize archive object
$zip = new ZipArchive();
$zip->open('file_recursive.zip', ZipArchive::CREATE | ZipArchive::OVERWRITE);

/** @var SplFileInfo[] $files */
$files = new RecursiveIteratorIterator(
    new RecursiveDirectoryIterator($rootPath),
    RecursiveIteratorIterator::LEAVES_ONLY
);

foreach ($files as $file) {
    // Only process files, directories are handled implicitly by the structure
    if (!$file->isDir()) {
        // Determine real and relative paths
        $filePath = $file->getRealPath();
        // Relative path calculation is crucial for maintaining structure inside the zip
        $relativePath = substr($filePath, strlen($rootPath) + 1);

        // Add file to archive
        $zip->addFile($filePath, $relativePath);
    }
}

// Finalize archive creation
$zip->close();
?>

Solution 1 (Extension): Zipping and Excluding Specific Files

If the goal is to archive everything except certain files (e.g., keeping only important.txt in the source folder), a delete list must be managed carefully because file deletion must happen after the ZipArchive object releases its file locks upon closing.

<?php
$rootPath = 'folder-to-zip';
$rootPath = rtrim($rootPath, '\\/');
$rootPath = realpath($rootPath);

$zip = new ZipArchive();
$zip->open('file_selective_delete.zip', ZipArchive::CREATE | ZipArchive::OVERWRITE);

$filesToDelete = array();

$files = new RecursiveIteratorIterator(
    new RecursiveDirectoryIterator($rootPath),
    RecursiveIteratorIterator::LEAVES_ONLY
);

foreach ($files as $file) {
    if (!$file->isDir()) {
        $filePath = $file->getRealPath();
        $relativePath = substr($filePath, strlen($rootPath) + 1);

        $zip->addFile($filePath, $relativePath);

        // Build list of files to remove *after* zipping, unless it's the kept file
        if ($file->getFilename() !== 'important.txt') {
            $filesToDelete[] = $filePath;
        }
    }
}

// Archive creation completes here
$zip->close();

// Execute deletions
foreach ($filesToDelete as $file) {
    unlink($file);
}
?>

Alternative Methods for Directory Archiving

Several other techniques offer different trade-offs regarding simplicity, recursion depth, and control.

Solution 2: Utilizing addGlob() for Simpler Inclusion

The ZipArchive::addGlob() method provides a wildcard-based way to add files matching a pattern. While convenient, it often requires careful path specification for deep recursion.

<?php
$zipFile = "./testGlobZip.zip";
$zipArchive = new ZipArchive();

if ($zipArchive->open($zipFile, (ZipArchive::CREATE | ZipArchive::OVERWRITE)) !== true) {
    die("Failed to create archive\n");
}

// Note: addGlob() behavior regarding recursion depends on the underlying system/PHP version.
// './* .txt' typically only includes files in the current directory.
$zipArchive->addGlob("./*.txt"); 

if ($zipArchive->status != ZIPARCHIVE::ER_OK) {
    echo "Failed to write files to zip\n";
}

$zipArchive->close();
// See official documentation for detailed glob pattern usage: https://www.php.net/manual/en/ziparchive.addglob.php
?>

Solution 3: External Shell Execution (exec)

If direct PHP iteration is too slow or complex, executing the native zip command-line utility can be faster, especially for large archives. Security note: Input paths must be rigorously sanitized when using exec().

<?php
$folderToZip = '"My folder"'; // Use quotes to handle spaces
$archiveName = 'archive_shell.zip';

// Command to recursively zip the folder
$command = "zip -r {$archiveName} {$folderToZip}";
exec($command);

// Example of selective deletion via shell command (requires careful path handling)
unlink('My folder/index.html'); 
?>

For dealing with time constraints during execution, shell commands are sometimes preferred, but they rely on the zip utility being present in the system’s path. If you encounter issues with execution time limits, solutions relying on external processes might bypass them, as noted in Solution 8 discussions.

Solution 4: Simple Non-Recursive Zipping with Conditional Deletion

If only the immediate contents of a directory are needed (no deep recursion), glob() simplifies the initial file listing.

<?php
$zip = new ZipArchive;
$zip->open('myzip_shallow.zip', ZipArchive::CREATE);
$targetDir = "target_folder/*";

foreach (glob($targetDir) as $file) {
    $zip->addFile($file);
    // Conditionally delete file immediately after adding to the zip
    if ($file !== 'target_folder/important.txt') {
        unlink($file);
    }
}
$zip->close();
// This method does not handle subdirectories recursively.
?>

Solution 5: Extending ZipArchive for Directory Handling

One can extend ZipArchive to introduce a dedicated addDir method that handles recursion internally using standard PHP file system functions like opendir and readdir.

<?php
class FlxZipArchive extends ZipArchive 
{
    public function addDir($location, $name) 
    {
        $this->addEmptyDir($name);
        $this->addDirDo($location, $name);
    } 
    private function addDirDo($location, $name) 
    {
        $name .= '/';
        $location .= '/';
        $dir = opendir ($location);
        while ($file = readdir($dir))
        {
            if ($file == '.' || $file == '..') continue;
            $do = (filetype( $location . $file) == 'dir') ? 'addDir' : 'addFile';
            $this->$do($location . $file, $name . $file);
        }
        closedir($dir); // Ensure directory handle is closed
    } 
}

// Usage Example:
$the_folder = '/path/to/folder/to/be/zipped';
$zip_file_name = '/path/to/zip/archive.zip';
$za = new FlxZipArchive;
$res = $za->open($zip_file_name, ZipArchive::CREATE);
if($res === TRUE) 
{
    $za->addDir($the_folder, basename($the_folder));
    $za->close();
}
else{
    echo 'Could not create a zip archive';
}
?>

Solution 7: Recursive Iteration with addFromString

This approach iterates recursively but adds file content directly using addFromString rather than addFile. It involves reading the file content into memory first.

<?php
function zipDirectoryRecursive($source, $destination)
{
    if (!extension_loaded('zip') || !file_exists($source)) {
        return false;
    }

    $zip = new ZipArchive();
    if (!$zip->open($destination, ZIPARCHIVE::CREATE)) {
        return false;
    }

    // Normalize path separators
    $source = str_replace('\\', '/', realpath($source));

    if (is_dir($source) === true) {
        $files = new RecursiveIteratorIterator(
            new RecursiveDirectoryIterator($source), 
            RecursiveIteratorIterator::SELF_FIRST
        );

        foreach ($files as $file) {
            $file = str_replace('\\', '/', $file);

            // Skip . and .. entries
            if (in_array(substr($file, strrpos($file, '/')+1), array('.', '..'))) {
                continue;
            }               

            $file = realpath($file);

            if (is_dir($file) === true) {
                // Add directory entry, removing the source path prefix
                $zip->addEmptyDir(str_replace($source . '/', '', $file . '/'));
            } elseif (is_file($file) === true) {
                // Add file content directly
                $zip->addFromString(
                    str_replace($source . '/', '', $file), 
                    file_get_contents($file)
                );
            }
        }
    } elseif (is_file($source) === true) {
        // If source is a file, add it directly
        $zip->addFromString(basename($source), file_get_contents($source));
    }

    return $zip->close();
}

zipDirectoryRecursive('/folder/to/compress/', './compressed_from_string.zip');
?>

Solution 9: Laravel Framework Example (Preserving Relative Paths)

For developers using frameworks like Laravel, helper functions simplify path management, ensuring the relative path structure inside the ZIP matches the source structure.

<?php
// Assuming this code runs within a Laravel context supporting Facades/response helpers
$zip = new \ZipArchive();
$fileName = "my-package.zip";
$sourcePath = public_path('/MY_FOLDER_PATH/'); // Source directory path

if ($zip->open(public_path($fileName), \ZipArchive::CREATE) === true)
{
    // Use File::allFiles to get file info objects
    $files = \Illuminate\Support\Facades\File::allFiles($sourcePath);

    foreach ($files as $file) {
        // Use getPathname (full path) and getRelativePathname (structure inside source)
        $zip->addFile($file->getPathname(), $file->getRelativePathname());
    }

    $zip->close();
    
    // Example of serving the generated file directly to the user
    return response()
        ->download(public_path($fileName))
        ->deleteFileAfterSend(true); // Cleanup file after sending
}
?>

Solution 18: Class-Based Archiving with Exclusion List

Encapsulating the logic within a class allows for configuration, such as defining files or directories that should not be included in the final backup.

<?php
class FolderCompressor {
    
    public static $EXCLUDED_PATHS = array(
        'error_log',
        'cgi-bin',
        'temp/cache'
    );
        
    public function compress_folder( $dir, $version, $archive_dest ) {

        if( !is_dir($dir) ){ exit('Source directory not found.'); }

        $zip = new ZipArchive;
        $zip->open( $archive_dest, ZipArchive::CREATE | ZipArchive::OVERWRITE );

        // SKIP_DOTS ignores '.' and '..' during iteration
        $it = new RecursiveIteratorIterator(
               new RecursiveDirectoryIterator( $dir, RecursiveDirectoryIterator::SKIP_DOTS )
              );
        
        foreach( $it as $file ){

            // Check against the exclusion list using sub-path name
            foreach( self::$EXCLUDED_PATHS as $excluded_path ) {
                if( preg_match( '/^('.preg_quote($excluded_path,'/').')/', $it->getSubPathName() ) == true ){
                    continue 2; // Skip this file and continue outer loop
                }
            }
    
            // Add file, using getSubPathName() to ensure correct relative path within the zip
            $zip->addFile( $it->getPathname(),  $it->getSubPathName() );
        }
    
        $zip->close();
    }
}

// Usage:
$version = '1.2.0';
$dirToBackup = $_SERVER['DOCUMENT_ROOT'].'/SOURCES';
$destinationZip = $_SERVER['DOCUMENT_ROOT'].'/ARCHIVES/'.$version.'.zip';

$compressor = new FolderCompressor();
$compressor->compress_folder( $dirToBackup, $version, $destinationZip );
?>

FAQs on PHP Zipping Folder Methods

Q: How to zip a folder recursively in PHP

ANS: Use RecursiveDirectoryIterator combined with RecursiveIteratorIterator to traverse the directory tree, and inside the loop, use $zip->addFile($filePath, $relativePath) to ensure the internal structure mirrors the source.

Q: Is exec command safe for creating zip files

ANS: Using exec() with shell commands like zip -r can be efficient, but it requires strict validation and sanitization of input directory names to prevent shell injection vulnerabilities.

Q: Why does my ZipArchive creation fail

ANS: Common reasons include missing write permissions for the PHP execution user in the destination directory, or the zip extension not being enabled in your PHP installation. Check file permissions first.

Q: Can I zip a folder and delete source files simultaneously

ANS: Yes, but you must complete the $zip->close() operation before attempting to delete any files, as the ZipArchive object holds a lock on the files during creation.
