“Top 15 Ways to Sort Multi-Dimensional Arrays in PHP”

Sorting multi-dimensional arrays is a fundamental task in PHP development. Whether you need to order data by a specific key, handle multiple sorting criteria, or maintain key associations, PHP offers a variety of powerful functions. This guide delves into numerous techniques, providing clear explanations and practical code examples to help you master array sorting.

Solution 1: Using usort with Custom Comparison Functions

The usort function is a versatile tool for sorting arrays by values using a user-defined comparison function. This is particularly useful for multi-dimensional arrays where you need to define the sorting logic explicitly.

Sorting by a Single Key

For simple sorting based on a single key, you can create a callback function that compares the values of that key.

PHP 5.2 and earlier:

<?php
function sortByOrder($a, $b) {
    if ($a['order'] > $b['order']) {
        return 1;
    } elseif ($a['order'] < $b['order']) {
        return -1;
    }
    return 0;
}

usort($myArray, 'sortByOrder');
?>

PHP 5.3 and later (Anonymous Functions):

<?php
usort($myArray, function($a, $b) {
    if ($a['order'] > $b['order']) {
        return 1;
    } elseif ($a['order'] < $b['order']) {
        return -1;
    }
    return 0;
});
?>

PHP 7 and later (Spaceship Operator):

The spaceship operator (<=>) simplifies comparison logic.

<?php
usort($myArray, function($a, $b) {
    return $a['order'] <=> $b['order'];
});
?>

PHP 7.4 and later (Arrow Functions):

Arrow functions offer a more concise syntax.

<?php
usort($myArray, fn($a, $b) => $a['order'] <=> $b['order']);
?>

Multi-Dimensional Sorting

You can extend this to multi-dimensional sorting by chaining comparisons. If the primary comparison results in equality (0), the next comparison is evaluated.

<?php
usort($myArray, function($a, $b) {
    $retval = $a['order'] <=> $b['order'];
    if ($retval === 0) {
        $retval = $a['suborder'] <=> $b['suborder'];
        if ($retval === 0) {
            $retval = $a['details']['subsuborder'] <=> $b['details']['subsuborder'];
        }
    }
    return $retval;
});
?>

For scenarios where you need to retain key associations, consider using uasort(). You can find a comparison of array sorting functions in the official PHP manual .

Solution 2: Using uasort for Key-Preserving Sorting

uasort sorts an array by its values using a user-defined comparison function while maintaining index association. This is useful when the original keys of your array are significant.

<?php
function aasort(&$array, $key) {
    $sorter = array();
    $ret = array();
    reset($array);
    foreach ($array as $ii => $va) {
        $sorter[$ii] = $va[$key];
    }
    asort($sorter);
    foreach ($sorter as $ii => $va) {
        $ret[$ii] = $array[$ii];
    }
    $array = $ret;
}

aasort($your_array, "order");
?>

Solution 3: Using array_multisort with a Helper Function

The array_multisort function is powerful for sorting multiple arrays or a multi-dimensional array by one or more of its dimensions.

<?php
function array_sort_by_column(&$arr, $col, $dir = SORT_ASC) {
    $sort_col = array();
    foreach ($arr as $key => $row) {
        $sort_col[$key] = $row[$col];
    }

    array_multisort($sort_col, $dir, $arr);
}

array_sort_by_column($array, 'order');
?>

This method works by creating a temporary array ($sort_col) containing the values of the key you want to sort by. array_multisort then uses this temporary array to reorder the original array, ensuring that the keys remain aligned.

Solution 4: Using array_multisort Directly

You can leverage array_multisort directly by first extracting the column you want to sort by using array_column.

<?php
$new = [
    [
        'hashtag' => 'a7e87329b5eab8578f4f1098a152d6f4',
        'title' => 'Flower',
        'order' => 3,
    ],
    [
        'hashtag' => 'b24ce0cd392a5b0b8dedc66c25213594',
        'title' => 'Free',
        'order' => 2,
    ],
    [
        'hashtag' => 'e7d31fc0602fb2ede144d18cdffd816b',
        'title' => 'Ready',
        'order' => 1,
    ],
];
$keys = array_column($new, 'order');
array_multisort($keys, SORT_ASC, $new);
var_dump($new);
?>

This approach is clean and efficient for sorting based on a single column.

Solution 5: Using usort with Simple Comparison

A straightforward way to use usort is with a simple comparison function that returns the difference between values.

<?php
function compareOrder($a, $b) {
  return $a['order'] - $b['order'];
}
usort($array, 'compareOrder');

// PHP 7 using the spaceship operator:
usort($array, function($a, $b) {
    return $a['order'] <=> $b['order'];
});
?>

Solution 6: Sorting by String Values with strcmp

When sorting based on string values in a multi-dimensional array, strcmp is the appropriate function to use with uasort to maintain key associations.

<?php
uasort($myArray, function($a, $b) {
    return strcmp($a['title'], $b['title']);
});
?>

Solution 7: Using array_multisort with array_map

This method combines array_multisort with array_map to extract the sorting key.

<?php
array_multisort(array_map(function($element) {
      return $element['order'];
  }, $array), SORT_ASC, $array);

print_r($array);
?>

Solution 8: Case-Insensitive Sorting

For case-insensitive sorting, you can convert array values to lowercase before using array_multisort.

<?php
$sort = array();
$array_lowercase = array_map('strtolower', $array_to_be_sorted);
array_multisort($array_lowercase, SORT_ASC, SORT_STRING, $alphabetically_ordered_array);

Solution 9: Multi-Column Sorting with Spaceship Operator

The spaceship operator (<=>) shines when sorting by multiple columns. You can create an array of values to compare, allowing for complex sorting logic.

<?php
// Sort by column1 ASC, then column2 ASC
usort($myArray, function($a, $b) {
    return [$a['column1'],$a['column2']] <=> [$b['column1'],$b['column2']];
});

// Sort by column2 ASC, then column1 ASC
usort($myArray, function($a, $b) {
    return [$a['column2'],$a['column1']] <=> [$b['column2'],$b['column1']];
});

// Sort by column1 ASC, then column2 DESC
usort($myArray, function($a, $b) {
    return [$a['column1'],$b['column2']] <=> [$b['column1'],$a['column2']];
});
?>

Solution 12: Using build_sorter Callback

A helper function like build_sorter can create reusable sorting callbacks.

<?php
function build_sorter($key) {
   return function ($a, $b) use ($key) {
      return strnatcmp($a[$key], $b[$key]);
   };
}

usort($array, build_sorter('order'));
?>

Solution 13: Chained Comparisons with Spaceship Operator

This advanced technique uses chained comparisons with the spaceship operator within a usort callback for sophisticated multi-key sorting, including mixed ascending and descending orders.

<?php
usort($in,function($a,$b){
  return $a['first']   <=> $b['first']  // first asc
      ?: $a['second']  <=> $b['second'] // second asc
      ?: $b['third']   <=> $a['third'];  // third desc (a and b swapped!)
});

// Example: Order by rank asc, surname asc
usort($in,function($a,$b){
  return $a['rank'] <=> $b['rank']
      ?: $a['surname'] <=> $b['surname'];
});

// Example: Order by rank desc, surname asc, firstname asc
usort($in,function($a,$b){
  return $b['rank'] <=> $a['rank']
      ?: $a['surname'] <=> $b['surname']
      ?: $a['firstname'] <=> $b['firstname'];
});

// Example: Order by rank desc, birthdate asc (date requires conversion)
usort($in,function($a,$b){
  return $b['rank'] <=> $a['rank']
      ?: strtotime($a['birthdate']) <=> strtotime($b['birthdate']);
});
?>

Solution 14: usort with Simple Arithmetic

A simple arithmetic difference can be used with usort for ascending order. Swapping operands achieves descending order.

<?php
usort($new, fn($a, $b) => $a['order'] - $b['order']);
?>

Solution 15: Combining usort and array_multisort

Both usort and array_multisort can be used independently or together for efficient sorting.

<?php
// Using usort
usort($dataArray, function($a, $b) {
    return $a['order'] <=> $b['order'];
});
print_r($dataArray);

// Using array_multisort with array_column
$orders = array_column($dataArray, 'order');
array_multisort($orders, SORT_ASC, $dataArray);
print_r($dataArray);
?>

Solution 16: Sorting with Class Objects

You can define a class with an __invoke method to create sortable objects.

<?php
class user
{
    private $key;

    public function __construct(string $key)
    {
        $this->key = $key;
    }

    public function __invoke($a, $b)
    {
        return $a[$this->key] <=> $b[$this->key];
    }
}

$user = [
    ['id' => 1, 'name' => 'Oliver', 'id_card' => 4444],
    ['id' => 3, 'name' => 'Jack', 'id_card' => 5555],
    ['id' => 2, 'name' => 'Harry', 'id_card' => 6666]
];

// sort user by id
usort($user, new user('id'));
var_dump($user);
?>

Solution 17: Generic Multi-Column Sort Function

A flexible function can be created to handle multi-column sorting with specified directions.

<?php
function multi_column_sort(&$a, array $column_names) {
    usort($a, function($a, $b) use($column_names) {
        foreach ($column_names as $column_name => $order) {
            $result = ($a[$column_name] <=> $b[$column_name]) * ($order === SORT_DESC ? -1 : 1);
            if ($result) return $result;
        }
        return 0;
    });
}

$data[] = array('volume' => 67, 'edition' => 2);
$data[] = array('volume' => 86, 'edition' => 1);
$data[] = array('volume' => 85, 'edition' => 6);
$data[] = array('volume' => 98, 'edition' => 2);
$data[] = array('volume' => 86, 'edition' => 6);
$data[] = array('volume' => 67, 'edition' => 7);

var_dump($data);
// Sort by volume ascending, then edition descending
multi_column_sort($data, ['volume' => SORT_ASC, 'edition' => SORT_DESC]);
var_dump($data);
?>

FAQs on Sorting Multi-Dimensional Arrays in PHP

Q: What is the most efficient way to sort a multi-dimensional array by a single key

ANS: For sorting a multi-dimensional array by a single key, usort with the spaceship operator (<=>) in PHP 7+ offers a very efficient and readable solution. For example: usort($myArray, fn($a, $b) => $a['order'] <=> $b['order']);.

Q: How can I sort an array by multiple keys with different orders

ANS: You can achieve multi-key sorting with mixed orders by chaining comparisons using the spaceship operator within a usort callback. For instance, to sort by ‘column1’ ascending and ‘column2’ descending, use: usort($myArray, function($a, $b) { return [$a['column1'],$b['column2']] <=> [$b['column1'],$a['column2']]; });.

Q: Does `uasort` maintain the original keys of the array

ANS: Yes, uasort is specifically designed to sort an array by its values while preserving the association of keys. This is different from usort which re-indexes the array numerically.

Q: When should I use `array_multisort` instead of `usort`

ANS: array_multisort is particularly useful when you need to sort multiple arrays simultaneously or when sorting a multi-dimensional array based on the values of one or more columns extracted into separate arrays, often in conjunction with array_column. usort is more direct for sorting a single array based on a custom comparison logic.

Q: How do I perform a case-insensitive sort on an array of strings

ANS: To perform a case-insensitive sort, you can use array_map to convert the relevant string values to lowercase before applying a sorting function like array_multisort or usort with strcasecmp. For example: $array_lowercase = array_map('strtolower', $array_to_be_sorted); array_multisort($array_lowercase, SORT_ASC, $sorted_array);.
