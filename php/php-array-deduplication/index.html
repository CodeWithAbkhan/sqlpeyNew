How can I efficiently remove duplicate elements from a PHP array?

Encountering duplicate entries within PHP arrays is a common scenario, particularly when dealing with data from various sources or complex query results. Effectively de-duplicating these arrays ensures data integrity and optimizes processing. PHP offers several approaches to achieve this, ranging from built-in functions with specific flags to custom solutions for multidimensional arrays.

Solution 1: Leveraging array_map, array_unique, and serialize

A widely adopted method for de-duplicating multidimensional arrays involves transforming each inner array into a serialized string, applying array_unique to these strings, and then unserializing them back into arrays. This technique avoids intermediate variable storage.

<?php
$input = [
    ['abc', 'def'],
    ['ghi', 'jkl'],
    ['abc', 'def'], // Duplicate
    ['mno', 'pql'],
    ['ghi', 'jkl'], // Duplicate
];

// Serialize, make unique, then unserialize
$input = array_map("unserialize", array_unique(array_map("serialize", $input)));

print_r($input);
?>

This approach is particularly useful when dealing with results from multiple overlapping queries where de-duplication is necessary.

Solution 2: Using array_unique with SORT_REGULAR

For arrays where elements can be directly compared for equality, the array_unique function can be employed with the SORT_REGULAR flag, available since PHP 5.2.9. This flag instructs the function to compare elements using the standard equality check (==).

<?php
$array = [
    ['abc', 'def'],
    ['ghi', 'jkl'],
    ['abc', 'def'],
    ['mno', 'pql'],
];

$unique_array = array_unique($array, SORT_REGULAR);

print_r($unique_array);
?>

Output:

Array
(
    [0] => Array
        (
            [0] => abc
            [1] => def
        )

    [1] => Array
        (
            [0] => ghi
            [1] => jkl
        )

    [3] => Array
        (
            [0] => mno
            [1] => pql
        )
)

While effective for many cases, the PHP documentation notes that array_unique() is not intended for deeply nested multidimensional arrays.

Solution 3: Preserving Keys with a Custom Function

If preserving the original keys of the array is a requirement, a custom function can be developed that combines serialization, array_unique, and array_intersect_key.

<?php
function array_unique_multidimensional($input) {
    $serialized = array_map('serialize', $input);
    $unique = array_unique($serialized);
    return array_intersect_key($input, $unique);
}

$input = [
    0 => ['abc', 'def'],
    1 => ['ghi', 'jkl'],
    2 => ['abc', 'def'],
    3 => ['mno', 'pql'],
];

print_r(array_unique_multidimensional($input));
?>

Solution 4: De-duplicating Based on a Specific Key

When you need to remove duplicates based on the value of a particular key within an array of associative arrays, a custom function like super_unique can be implemented.

<?php
function super_unique($array, $key) {
    $temp_array = [];
    foreach ($array as &$v) {
        if (!isset($temp_array[$v[$key]])) {
            $temp_array[$v[$key]] = &$v;
        }
    }
    return array_values($temp_array);
}

$arr = [
    ['id' => 0, 'titel' => "ABC"],
    ['id' => 1, 'titel' => "DEF"],
    ['id' => 2, 'titel' => "ABC"], // Duplicate 'titel'
    ['id' => 3, 'titel' => "XYZ"],
];

print_r(super_unique($arr, 'titel'));
?>

This function efficiently identifies and retains only the first occurrence of an element based on the specified key.

Solution 5: Utilizing array_column and array_intersect_key

For de-duplicating based on a specific column (key), you can first extract the column values using array_column, find the unique values, and then use array_intersect_key to filter the original array.

<?php
$array = [
    ['id' => 1, 'name' => 'john'],
    ['id' => 2, 'name' => 'smith'],
    ['id' => 3, 'name' => 'john'], // Duplicate 'name'
    ['id' => 4, 'name' => 'robert'],
];

$temp = array_unique(array_column($array, 'name'));
$unique_arr = array_intersect_key($array, $temp);

print_r($unique_arr);
?>

Solution 6: Filtering Based on Unique Identifiers

When dealing with structures where a unique identifier like ‘id’ exists, you can first extract all identifiers, find the unique ones, and then filter the original array to keep only elements whose identifiers are present in the unique set.

<?php
$array = [
    ['id' => '123', 'foo' => 'aaa', 'bar' => 'bbb'],
    ['id' => '123', 'foo' => 'ccc', 'bar' => 'ddd'], // Duplicate 'id'
    ['id' => '567', 'foo' => 'eee', 'bar' => 'fff'],
];

$ids = array_column($array, 'id');
$ids = array_unique($ids);

$array = array_filter($array, function ($key, $value) use ($ids) {
    return in_array($value['id'], $ids);
}, ARRAY_FILTER_USE_BOTH);

print_r($array);
?>

Solution 7: Recursive De-duplication with Serialization

For deeply nested or variably structured multidimensional arrays, a recursive approach using serialization can be effective. This involves iterating through the array, serializing its elements, making them unique, and then unserializing them back.

<?php
function multi_unique($array) {
    $new = [];
    foreach ($array as $k => $na) {
        $new[$k] = serialize($na);
    }
    $uniq = array_unique($new);
    $new1 = [];
    foreach ($uniq as $k => $ser) {
        $new1[$k] = unserialize($ser);
    }
    return $new1;
}

$arr = [
    ['a', 'b', 'c'],
    ['x', 'b', 'a', 'p'],
    ['y', 'b', ['x', 'm', 'a']],
    'z',
    'v'
];

print_r(multi_unique($arr));
?>

Solution 8: Compacted Array Search by Key

A straightforward function can be created to de-duplicate an array based on a specified key by iterating through the data and adding elements to a temporary array only if their key’s value hasn’t been encountered before.

<?php
function search_array_compact($data, $key) {
    $compact = [];
    foreach ($data as $row) {
        if (!in_array($row[$key], $compact)) {
            $compact[] = $row;
        }
    }
    return $compact;
}

$users = [
    ['user' => 'john', 'age' => '23'],
    ['user' => 'jane', 'age' => '20'],
    ['user' => 'john', 'age' => '23'], // Duplicate 'user'
];

print_r(search_array_compact($users, 'user'));
?>

Solution 9: Iterative Uniqueness Check

For arrays where you need to track unique values of a specific key, you can iterate through the array and maintain a list of encountered values.

<?php
$users = [
    ['user' => 'john', 'age' => '23'],
    ['user' => 'jane', 'age' => '20'],
    ['user' => 'john', 'age' => '23'],
];

$serialized = [];
$unique_users = [];
for ($i = 0; $i < sizeof($users); $i++) {
    if (!in_array($users[$i]['user'], $serialized)) {
        $serialized[] = $users[$i]['user'];
        $unique_users[] = $users[$i];
    }
}

print_r($unique_users);
?>

Solution 10: Step-by-Step Serialization and Unserialization

This method elaborates on the serialization technique, breaking down why it works:

  1. Serialize to One-Dimensional: serialize() converts each element (even nested arrays) into a byte stream, effectively creating a one-dimensional array.
  2. Unique Values: array_unique() is then applied to this one-dimensional array of byte streams.
  3. Unserialize Back: Finally, unserialize() converts the unique byte streams back into their original array structures.
<?php
$input = [
    ['a', 'b'],
    ['c', 'd'],
    ['a', 'b'], // Duplicate
];
$input = array_map("unserialize", array_unique(array_map("serialize", $input)));
print_r($input);
?>

Solution 11: Using array_filter with a Static Variable or Key Remapping

Two alternative approaches for de-duplicating based on the first element of inner arrays:

Method 1: array_filter with Static Variable

<?php
$list = [
    ['abc', 'def'],
    ['ghi', 'jkl'],
    ['mno', 'pql'],
    ['abc', 'def'], // Duplicate
    ['ghi', 'jkl'], // Duplicate
];

$list = array_filter($list, function ($item) {
    static $values = [];
    if (!in_array($item[0], $values)) {
        $values[] = $item[0];
        return true;
    } else {
        return false;
    }
});

print_r($list);
?>

Method 2: Key Remapping

This method uses the value to be de-duplicated as an array key, which automatically handles uniqueness.

<?php
$list = [
    ['abc', 'def'],
    ['ghi', 'jkl'],
    ['mno', 'pql'],
    ['abc', 'def'], // Duplicate
];

$unique = [];
foreach ($list as $item) {
    $unique[$item[0]] = $item; // Use first element as key
}

// Re-map keys to sequential integers
$unique = array_values($unique);

print_r($unique);
?>

Solution 12: Readable Custom Array Unique Function

A simple, readable custom function that encapsulates the serialization, unique, and unserialization process.

<?php
function arrayUnique($myArray) {
    if (!is_array($myArray)) {
        return $myArray;
    }

    foreach ($myArray as &$myvalue) {
        $myvalue = serialize($myvalue);
    }

    $myArray = array_unique($myArray);

    foreach ($myArray as &$myvalue) {
        $myvalue = unserialize($myvalue);
    }

    return $myArray;
}

$input = [
    ['id' => 1, 'name' => 'test'],
    ['id' => 2, 'name' => 'dev'],
    ['id' => 1, 'name' => 'test'], // Duplicate
];

print_r(arrayUnique($input));
?>

Solution 13: Efficient Multidimensional Uniqueness with Keys

An efficient method for one-level multidimensional arrays, leveraging serialization and key extraction.

<?php
$input = [
    ['key' => 'A', 'val' => 1],
    ['key' => 'B', 'val' => 2],
    ['key' => 'A', 'val' => 1], // Duplicate
];

$serialized_array = array_map("serialize", $input);

$result = [];
foreach ($serialized_array as $key => $val) {
     $result[$val] = true;
}

$output = array_map("unserialize", array_keys($result));

print_r($output);
?>

Solution 14: De-duplicating Inner Arrays

If your requirement is to make each inner array unique within a larger array, you can iterate through the main array and apply array_unique to each sub-array.

<?php
$array = [
    'Key1' => ['Value1', 'Value2', 'Value1', 'Value3'],
    'Key2' => ['Value1', 'Value2', 'Value1', 'Value4'],
];

foreach ($array as $k => $v) {
    $unique = array_unique($v);
    $array[$k] = $unique; // Keeps original keys
}
print_r($array);

// To re-index inner arrays numerically:
foreach ($array as $k => $v) {
    $unique = array_values(array_unique($v));
    $array[$k] = $unique;
}
print_r($array);
?>

Solution 15: array_reduce for Simplicity

An alternative to serialization, array_reduce can be used to build a new array by checking for the existence of each item before pushing.

<?php
$test = [
    ['abc', 'def'],
    ['ghi', 'jkl'],
    ['mno', 'pql'],
    ['abc', 'def'], // Duplicate
];

$result = array_reduce(
    $test,
    function($carry, $item) {
        if (!in_array($item, $carry)) {
            array_push($carry, $item);
        }
        return $carry;
    },
    [] // Initial value for $carry
);

print_r($result);
?>

Solution 16: In-place Modification for Scalability

For very large arrays, modifying the array in place can be more efficient. This involves nested loops to compare elements and unset duplicates. Note that this can lead to non-sequential keys.

<?php
$input = [
    ['id' => '123', 'checksum' => 'hash1'],
    ['id' => '456', 'checksum' => 'hash2'],
    ['id' => '789', 'checksum' => 'hash1'], // Duplicate checksum
];

$count_array = count($input);
for ($i = 0; $i < $count_array; $i++) {
    if (isset($input[$i])) {
        for ($j = $i + 1; $j < $count_array; $j++) {
            if (isset($input[$j])) {
                // Compare based on a specific key, e.g., 'checksum'
                if ($input[$i]['checksum'] == $input[$j]['checksum']) {
                    unset($input[$j]);
                }
            }
        }
    }
}

// Optional: re-index keys if sequential keys are needed
$input = array_values($input);

print_r($input);
?>

Solution 17: Recursive Flattening and Uniqueness

This method handles arbitrarily nested arrays by recursively traversing them, collecting all scalar values, and then finding unique values.

<?php
$arr = [
    ['a', 'b', 'c'],
    ['x', 'b', 'a', 'p'],
    ['y', 'b', ['x', 'm', 'a']],
    'z',
    'v'
];

$ar2 = []; // To track seen values
$ar3 = []; // To store unique values

function test($arr) {
    global $ar2, $ar3;
    if (is_array($arr)) {
        return array_map("test", $arr);
    }
    if (!isset($ar2[$arr])) {
        $ar2[$arr] = 1;
        $ar3[] = $arr;
    }
}

array_map("test", $arr);
print_r($ar3);
?>

Solution 18: Resetting Indices After Uniqueness

This is a refinement of the serialization method, ensuring that the resulting array has sequential, zero-based integer keys.

<?php
$inputArray = [
    ['value' => 'apple'],
    ['value' => 'banana'],
    ['value' => 'apple'], // Duplicate
];

$input = array_values(array_map("unserialize", array_unique(array_map("serialize", $inputArray))));

print_r($input);
?>

FAQs on PHP Array De-duplication

Q: Can array_unique handle multidimensional arrays directly

ANS: No, array_unique() is designed for scalar values. For multidimensional arrays, you typically need to serialize them first, as shown in several solutions.

Q: How to remove duplicates based on a specific key in an associative array

ANS: You can use custom functions that iterate through the array and check for the existence of a value associated with a specific key, or use combinations like array_column and array_intersect_key. Solutions 4, 5, and 8 demonstrate these techniques.

Q: Will serialize/unserialize affect data types

ANS: serialize() and unserialize() generally preserve data types, but it’s always good practice to test with your specific data to confirm.

Q: What is the most efficient method for large arrays

ANS: For very large arrays, methods that modify the array in-place or those that avoid excessive function calls (like Solution 16 or optimized custom loops) might offer better performance. Profiling your specific use case is recommended.

Q: How to preserve original keys when removing duplicates

ANS: Use methods like array_intersect_key with serialized unique values (Solution 3) or custom functions designed to retain keys during the de-duplication process.
