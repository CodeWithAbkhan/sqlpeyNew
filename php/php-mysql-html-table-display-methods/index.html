“PHP MySQLi vs PDO: Effective Methods for Displaying Query Results in HTML Tables”

Developing dynamic web applications frequently requires executing SQL queries against a MySQL database and presenting the resultant data within an HTML table structure. This task involves careful connection handling, query execution, data fetching, and secure output rendering to prevent cross-site scripting (XSS) vulnerabilities. Various established patterns exist, utilizing both the older mysql_* functions (for legacy context), MySQLi, and the modern PDO extension.

What are the most effective and secure ways to achieve this dynamic table generation in PHP? Several approaches offer different levels of abstraction and flexibility.

Strategy 1: Fetch All Data First, Then Iterate for Display (MySQLi)

A common pattern involves fetching the entire result set into a PHP array immediately after executing the query, and then iterating over this array to build the HTML table. This separates data retrieval from presentation logic.

Consider fetching the first 50 records from a Persons table:

<?php
// Establish connection (using traditional arguments)
$con = mysqli_connect("localhost", "peter", "abc123", "my_db");

// Execute query
$result = mysqli_query($con, "SELECT first_name, last_name FROM Persons LIMIT 50");

// Fetch all results into an associative array
$data = $result->fetch_all(MYSQLI_ASSOC);
?>

<table border="1">
  <tr>
    <th>Firstname</th>
    <th>Lastname</th>
  </tr>
  <?php foreach($data as $row): ?>
  <tr>
    <td><?= htmlspecialchars($row['first_name']) ?></td>
    <td><?= htmlspecialchars($row['last_name']) ?></td>
  </tr>
  <?php endforeach; ?>
</table>

Alternative Data Fetching: If you prefer not to load everything at once, you can iterate directly over the result object in the view layer, as demonstrated in other solutions below.

Strategy 2: Dynamic Table Generation Based on Field Names (MySQLi)

This method dynamically constructs both the table headers and the rows by inspecting the metadata of the result set, making it robust to schema changes without code modification. It’s crucial to set error reporting strictly.

<?php
$host = "localhost";
$user = "username_here";
$pass = "password_here";
$db_name = "database_name_here";

// Configure strict error reporting
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$connection = mysqli_connect($host, $user, $pass, $db_name);

// Execute query on 'products' table
$result = mysqli_query($connection, "SELECT product_id, name, price FROM products");

echo '<table class="data-table">';
echo '<tr class="data-heading">';  // Initialize table header row

// 1. Output Column Headers Dynamically
while ($property = mysqli_fetch_field($result)) {
    echo '<td>' . htmlspecialchars($property->name) . '</td>';  // Get field name
}
echo '</tr>'; 

// 2. Output All Data Rows
while ($row = mysqli_fetch_row($result)) {
    echo "<tr>";
    foreach ($row as $item) {
        echo '<td>' . htmlspecialchars($item) . '</td>'; // Output cell content
    }
    echo "</tr>";
}
echo "</table>";
?>

Strategy 3: Iterative Row Fetching with MySQLi Object-Oriented Style

When working with the OOP style of MySQLi, you can establish the connection using the new mysqli() constructor, set error reporting, execute the query, and then iterate through rows one by one using fetch_row():

<?php
$servername = "localhost";
$username = "root";
$password = "yourPassword";
$database = "world";

mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$conn = new mysqli($servername, $username, $password, $database);

// Define query string, limiting to 100 records for performance
$query = "SELECT id, name, population FROM city LIMIT 100;";

// Execute the query
$queryResult = $conn->query($query);

echo "<table>";
// Fetch and display data row by row
while ($queryRow = $queryResult->fetch_row()) {
    echo "<tr>";
    foreach($queryRow as $value) {
        echo "<td>" . htmlspecialchars($value) . "</td>";
    }
    echo "</tr>";
}
echo "</table>";
?>

Strategy 4: Utilizing PDO for Data Access and Object Fetching

PDO offers a database-agnostic approach. This example uses constants for configuration, establishes a connection, executes a query, sets the fetch mode to objects (PDO::FETCH_OBJ), and concatenates the HTML output into a single string variable before echoing it once.

<?php
define("DB_HOST", "localhost");
define("DB_USER", "YourUsername");
define("DB_PASS", "YourPassword");
define("DB_NAME", "Yourdbname");

try {
    // Connection using DSN and UTF-8 charset
    $dbc = new PDO("mysql:host=" . DB_HOST . ";dbname=" . DB_NAME . ";charset=utf8mb4", DB_USER, DB_PASS);
    $dbc->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    die("DB Connection Error: " . $e->getMessage());
}

$print = ""; // Initialize output string

$stmt = $dbc->query("SELECT firstname, lastname FROM PersonsTable"); // Fetch data
$stmt->setFetchMode(PDO::FETCH_OBJ);

$print .= '<table border="1px">';
$print .= '<tr><th>First name</th>';
$print .= '<th>Last name</th></tr>';

while ($names = $stmt->fetch()) { // Loop and display data
    $print .= '<tr>';
    $print .= "<td>" . htmlspecialchars($names->firstname) . "</td>";
    $print .= "<td>" . htmlspecialchars($names->lastname) . "</td>";
    $print .= '</tr>';
}

$print .= "</table>";
echo $print;
?>

Strategy 5: Working with Deprecated mysql_* Functions (Use Only for Legacy Context)

Warning: The mysql_* extension is deprecated and removed in PHP 7. This solution is provided strictly for referencing older codebases. Modern development must use MySQLi or PDO. This example shows fetching a single record or listing all matching records based on a URL parameter ($_GET["sequence"]).

<?php
// Legacy Connection - DO NOT USE IN NEW PROJECTS
$conn = mysql_connect("hostname", "username", "password");
mysql_select_db("databasename", $conn);

$sequence_id = isset($_GET["sequence"]) ? intval($_GET["sequence"]) : 1; // Basic input sanitization

$sql = "SELECT forename, surname FROM user_table WHERE sequence = '{$sequence_id}'";
$rs = mysql_query($sql, $conn) or die(mysql_error());

echo '<table>';
echo '<tr><td>Forename</td><td>Surname</td></tr>';

// Listing multiple matching records
while ($result = mysql_fetch_array($rs)) {
    echo '<tr>';
    echo '<td>' . htmlspecialchars($result["forename"]) . '</td>';
    echo '<td>' . htmlspecialchars($result["surname"]) . '</td>';
    echo '</tr>';
}
echo '</table>';
?>

Strategy 6: Fully Dynamic Table Creation (MySQLi Associative Fetch)

This method dynamically reads column names from the first row and then loops through all subsequent rows, making it extremely flexible as it requires no prior knowledge of column structure.

<?php
$server_hostname = "db.example.com";
$server_username = "webapp_user";
$server_password = "secure_pwd";
$server_database = "live_data";

$conn = new mysqli($server_hostname, $server_username, $server_password, $server_database);

// Run the query, limiting output for safety/performance
$result = $conn->query("SELECT * FROM system_logs LIMIT 10");

// 1. Fetch all results into an associative array format
$query = [];
while($query[] = mysqli_fetch_assoc($result));
array_pop($query); // Remove the trailing null entry

if (empty($query)) {
    echo "<p>No records retrieved.</p>";
    exit;
}

// 2. Output dynamic table structure
echo '<table border="1">';
echo '<tr>';

// Generate Headers from the keys of the first record
foreach($query[0] as $key => $value) {
    echo '<td>' . htmlspecialchars($key) . '</td>';
}
echo '</tr>';

// Output Data Rows
foreach($query as $row) {
    echo '<tr>';
    foreach($row as $column) {
        echo '<td>' . htmlspecialchars($column) . '</td>';
    }
    echo '</tr>';
}
echo '</table>';
?>

Strategy 7: Dynamic Headers using mysql_num_fields (Legacy)

This older approach retrieves headers by iterating through the field count and using mysql_field_name(). Note the unusual while loop structure intended to unpack results.

<?php
// Legacy Connection - AVOID USING
mysql_connect("localhost", "root", "");
mysql_select_db("database");

$query = mysql_query("SELECT id, name, role FROM studenti");
$rowCount = @mysql_num_rows($query);
$fieldCount = mysql_num_fields($query);

echo "<table>";
echo "<tr>";

// Output dynamic headers
for($i = 0; $i < $fieldCount; $i++) {
  $values = mysql_field_name($query, $i);
  echo "<th>" . htmlspecialchars($values) . "</th>";
}
echo "</tr>";

// Output data rows (Note: specific unpacking required for list())
while(list($p, $n, $r) = mysql_fetch_row($query)) // Assumes exactly 3 columns: id, name, role
{
  print("<tr>\n" .
        "<td>$p</td>" . // id
        "<td>$n</td>" . // name
        "<td>$r</td>" . // role
        "</tr>\n");
}
echo "</table>";
?>

Strategy 9: Encapsulating Logic in Functions using PDO

For code reuse and improved readability, abstracting the connection preparation and the table output into dedicated functions is a professional method. This requires an established global connection object ($con).

<?php
// Assume $con is a valid, configured PDO connection object

function makeStatment($query, $array = null)
{
    try {
        global $con;
        $stmt = $con->prepare($query);
        $stmt->execute($array);
        return $stmt;
    } catch (Exception $e) {
        // Return error object or handle exception appropriately
        return $e;
    }
}

function outputMySQLToHTMLTable($stmt)
{    
    $data = $stmt->fetchAll(PDO::FETCH_ASSOC);
    $columnCount = $stmt->columnCount();
    
    echo '<table class="data-display-table">';
    echo '<thead><tr>';
    
    // Get metadata for column names
    for ($i = 0; $i < $columnCount; $i++) {
        $columnMeta = $stmt->getColumnMeta($i);
        echo '<th>' . htmlspecialchars($columnMeta['name']) . '</th>';
    }
    echo '</tr></thead>';
    
    echo '<tbody>';
    if ($data) {
        foreach ($data as $row) {
            echo '<tr>';
            foreach ($row as $cell) {
                echo '<td>' . htmlspecialchars($cell) . '</td>';
            }
            echo '</tr>';
        }
    } else {
        echo '<tr><td colspan="' . $columnCount . '">No records found in the result set!</td></tr>';
    }
    echo '</tbody>';
    echo '</table>';
}

// Usage Example:
$query = 'SELECT product_id, product_name FROM inventory WHERE stock > 0';
$statement = makeStatment($query);
outputMySQLToHTMLTable($statement);
?>

Strategy 10: Object-Oriented Database Class with MySQLi

Encapsulating database logic within a class promotes better organization. This approach defines a database class handling connection and query execution, which is then used to fetch results suitable for array processing.

<?php
class DatabaseConnector
{
    public $host = "localhost";
    public $user = "root";
    public $pass = "";
    public $db   = "db_schema";
    public $link;

    public function __construct()
    {
        $this->connect();
    }

    private function connect()
    {
        $this->link = new mysqli($this->host, $this->user, $this->pass, $this->db);
        if ($this->link->connect_error) {
            die("Connection failed: " . $this->link->connect_error);
        }
    }

    public function select($query)
    {
        $result = $this->link->query($query);
        if ($result === false) {
            // In a real app, log the error instead of dying
            die("Query execution error: " . $this->link->error);
        }
        return $result;
    }
}

// Execution:
$db = new DatabaseConnector();

$query = "SELECT name, roll_number FROM student_records";
$result = $db->select($query);

echo "<table>";
echo "<tr><th>Student Name</th><th>Roll Number</th></tr>";

while($row = mysqli_fetch_array($result)) 
{
    echo "<tr>";
    echo "<td>" . htmlspecialchars($row['name']) . "</td>";
    echo "<td>" . htmlspecialchars($row['roll_number']) . "</td>";
    echo "</tr>";
}
echo "</table>";
?>

Security Note on Data Output

Crucially, always use htmlspecialchars() when outputting raw data retrieved from the database into HTML elements (like table cells <td>). This step prevents malicious scripts embedded in the data from executing in the user’s browser.

FAQs on PHP MySQL Table Display Methods

Q: Which method is the most modern way to display query results

ANS: Using PDO (Strategy 4 or 9) is generally recommended over MySQLi for database abstraction and modern PHP development practices.

Q: Why is separating data fetching and HTML necessary

ANS: Separating logic promotes cleaner code architecture, making debugging and maintenance simpler. Strategies 1 and 9 exemplify this separation.

Q: How to display headers automatically without knowing column names

ANS: Strategies 2 and 6 show how to use mysqli_fetch_field or iterating over the keys of the first mysqli_fetch_assoc result to dynamically generate table headers.
