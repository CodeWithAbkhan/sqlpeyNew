“PHP Query String to Array Conversion: Best Practices with parse_str”

The conversion of URL query strings (like key1=value1&key2=value2) into structured PHP arrays is a routine yet critical task. The built-in function parse_str() is the primary tool, but its nuances and potential pitfalls—especially with complex or encoded strings—require awareness of alternative implementations.

Utilizing parse_str() for Query String Decomposition

The standard PHP function parse_str() is designed for this exact purpose. It parses a string composed of URL-encoded data, typically retrieved from a URL query section, and populates a specified variable as an array.

Key Usage Requirement: parse_str() operates by reference. You must pass the array variable as the second argument; it does not return the array directly.

Example 1: Basic Key-Value Parsing

To ensure that parameters without explicit values (like document in the example below) are still included in the resulting array (often as an empty string or null depending on the environment), setting the second parameter correctly is vital.

If the requirement is to place all parsed data into an array structure, ensure you pass an array variable for the second argument.

<?php
$queryString = "pg_id=2&parent_id=2&document&video";
 
// The parsed data is stored in $queryArray
parse_str($queryString, $queryArray);

print_r($queryArray);
?>

This typically yields:

Array
(
    [pg_id] => 2
    [parent_id] => 2
    [document] => 
    [video] => 
)

A less common but sometimes necessary variant for older PHP versions (pre-5.4) involved call-time pass-by-reference, though this syntax is deprecated and removed in modern PHP: parse_str($str, &$array);. For modern PHP, simply providing the variable name is the standard.

Handling Full URLs vs. Query Fragments

A frequent issue arises when parse_str() is applied directly to a string that contains the entire URL structure, not just the query part.

Problematic Scenario: Applying parse_str() to a full URL string may incorrectly include parts of the URL path or protocol in the resulting keys.

$url = "somepage?id=123&lang=gr&size=300";

// Incorrect application might yield keys like "somepage?id"
parse_str($url, $arrayIncorrect); 
print_r($arrayIncorrect);

Robust Solution: Combining parse_url() and parse_str()

To isolate only the query component before parsing, first extract the query string using parse_url() with the PHP_URL_QUERY constant.

$url = "https://example.com/page?id=123&lang=gr&size=300";
$queryFragment = parse_url( $url, PHP_URL_QUERY);

parse_str($queryFragment, $parsedArray);
print_r($parsedArray);
// Output: Array ( [id] => 123 [lang] => gr [size] => 300 )

Addressing Encoded Delimiters (&amp;amp;)

When query strings are doubly encoded (e.g., within another HTML attribute or serialization process), the standard delimiter & might appear as &amp; or even &amp;amp;. parse_str() cannot process these raw entities directly.

Method: Decoding Before Parsing

Use html_entity_decode() to revert the encoded ampersands back to the standard delimiter before passing the string to parse_str().

// Input string with doubly encoded ampersands
$input = 'pg_id=2&amp;amp;parent_id=2&amp;amp;document&amp;amp;video';

// Decode entities first, then parse
parse_str(html_entity_decode($input), $out);

print_r($out);
// Output: Array ( [pg_id] => 2 [parent_id] => 2 [document] => [video] => )

Accessing the Current Request Query String

If you need to parse the query string associated with the current execution context (e.g., from the URL in a web request), utilize the superglobal $_SERVER['QUERY_STRING'].

// Parses the query string from the current request URL directly into $query
parse_str($_SERVER['QUERY_STRING'], $query);
var_dump($query);

Alternative: Manual Parsing for Complex Scenarios (Handling Duplicates)

While parse_str() is efficient, it overwrites values if a parameter appears multiple times (e.g., e=1&e=2 results in e being 2). If you need to capture all values for repeating keys, manual splitting is preferable.

This involves splitting by the primary delimiter (&) and then by the assignment delimiter (=).

// Example URL string with repeating key 'e'
$_SERVER['QUERY_STRING'] = 'a=2&b=2&c=5&d=4&e=100&e=200&e=300'; 

$url_qry_str  = explode('&', $_SERVER['QUERY_STRING']);

// Initialize arrays to hold values for specific keys
$e_values =  array();

foreach( $url_qry_str as $param )
{
  // Split only on the first occurrence of '='
  $var =  explode('=', $param, 2);
  
  if (count($var) === 2 && $var[0] === "e") {
      $e_values[] = $var[1];
  }
}

var_dump($e_values); 
// Output: array(3) { [0]=> string(3) "100" [1]=> string(3) "200" [2]=> string(3) "300" }

Streamlined Iteration and Display

If the goal is to parse the string and immediately iterate over the results, you can combine parse_str() with a foreach loop. Note that for a direct display of key/value pairs, PHP’s $_GET superglobal often achieves the same result as parsing the current request query string, as it’s automatically populated by the server environment.

$str="pg_id=2&parent_id=2&document&video";
parse_str($str, $my_arr);

// Displaying each pair
foreach($my_arr as $key => $value){
  echo "Key: $key => Value: $value<br>";
}

FAQs on PHP Query String to Array Conversion

Q: What is the primary function for query string to array conversion in PHP

ANS: The primary function is parse_str(), which populates a specified array variable with the parsed key-value pairs from the string.

Q: Does parse_str return the array directly

ANS: No, parse_str() modifies the array variable passed as its second argument by reference; it does not return a value.

Q: How to handle URLs that contain encoded ampersands like &amp;amp;

ANS: Use html_entity_decode() on the input string before passing it to parse_str() to correctly interpret the delimiters.

Q: What happens if a key is repeated in the query string

ANS: By default, parse_str() overwrites previous values, retaining only the last encountered value for that key. Manual parsing is needed to capture all occurrences.

Q: How to parse only the query part of a full URL

ANS: Use parse_url($fullUrl, PHP_URL_QUERY) to extract the query segment first, and then apply parse_str() to that segment.
