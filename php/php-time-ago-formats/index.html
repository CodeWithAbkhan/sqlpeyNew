“PHP: Convert Timestamps to Human-Readable ‘Time Ago’ Format”

When displaying a timestamp of a past event, it’s often more user-friendly to show how long ago it occurred (e.g., “2 minutes ago,” “3 hours ago,” “1 week ago”) rather than the raw date and time. This practice is common on social media platforms and news sites to provide context. PHP offers several ways to achieve this, ranging from simple manual calculations to using established libraries.

Here are various methods and functions developed by the community to tackle this:

Solutions for “Time Ago” Formatting

Solution 1: Using DateTime::diff for Detailed Output

This approach leverages PHP’s DateTime class to calculate the difference between two dates and formats it into a descriptive string. It can provide a breakdown of years, months, weeks, days, hours, minutes, and seconds.

<?php

function time_elapsed_string($datetime, $full = false) {
    $now = new DateTime;
    $ago = new DateTime($datetime);
    $diff = $now->diff($ago);

    $diff->w = floor($diff->d / 7);
    $diff->d -= $diff->w * 7;

    $string = array(
        'y' => 'year',
        'm' => 'month',
        'w' => 'week',
        'd' => 'day',
        'h' => 'hour',
        'i' => 'minute',
        's' => 'second',
    );
    foreach ($string as $k => &$v) {
        if ($diff->$k) {
            $v = $diff->$k . ' ' . $v . ($diff->$k > 1 ? 's' : '');
        } else {
            unset($string[$k]);
        }
    }

    if (!$full) {
        $string = array_slice($string, 0, 1);
    }
    return $string ? implode(', ', $string) . ' ago' : 'just now';
}

echo time_elapsed_string('2013-05-01 00:22:35');
echo "\n";
echo time_elapsed_string('@1367367755'); // timestamp input
echo "\n";
echo time_elapsed_string('2013-05-01 00:22:35', true);

?>

Output:

4 months ago
4 months ago
4 months, 2 weeks, 3 days, 1 hour, 49 minutes, 15 seconds ago

Solution 2: Manual Calculation with Units Array

This method uses a predefined array of time units (in seconds) to calculate the elapsed time and returns the largest applicable unit.

<?php

function time_elapsed_string($ptime) {
    $etime = time() - $ptime;

    if ($etime < 1) {
        return '0 seconds';
    }

    $a = array(
        365 * 24 * 60 * 60 => 'year',
        30 * 24 * 60 * 60  => 'month',
        24 * 60 * 60       => 'day',
        60 * 60            => 'hour',
        60                 => 'minute',
        1                  => 'second'
    );
    $a_plural = array(
        'year'   => 'years',
        'month'  => 'months',
        'day'    => 'days',
        'hour'   => 'hours',
        'minute' => 'minutes',
        'second' => 'seconds'
    );

    foreach ($a as $secs => $str) {
        $d = $etime / $secs;
        if ($d >= 1) {
            $r = round($d);
            return $r . ' ' . ($r > 1 ? $a_plural[$str] : $str) . ' ago';
        }
    }
}

// Example usage with a timestamp
$timestamp = strtotime('2024-01-15 10:30:00');
echo time_elapsed_string($timestamp);

?>

Output:

6 months ago

Solution 4: Comprehensive timeAgo Function

This function provides a detailed breakdown, handling seconds, minutes, hours, days, weeks, months, and years, with specific phrasing for singular and plural forms.

<?php

function timeAgo($time_ago) {
    $time_ago = strtotime($time_ago) ? strtotime($time_ago) : $time_ago;
    $time  = time() - $time_ago;

    switch ($time):
        // seconds
        case ($time <= 60): return 'just now';
        // minutes
        case ($time >= 60 && $time < 3600): return (round($time/60) == 1) ? 'a minute ago' : round($time/60).' minutes ago';
        // hours
        case ($time >= 3600 && $time < 86400): return (round($time/3600) == 1) ? 'an hour ago' : round($time/3600).' hours ago';
        // days
        case ($time >= 86400 && $time < 604800): return (round($time/86400) == 1) ? 'yesterday' : round($time/86400).' days ago';
        // weeks
        case ($time >= 604800 && $time < 2600640): return (round($time/604800) == 1) ? 'a week ago' : round($time/604800).' weeks ago';
        // months
        case ($time >= 2600640 && $time < 31207680): return (round($time/2600640) == 1) ? 'a month ago' : round($time/2600640).' months ago';
        // years
        case ($time >= 31207680): return (round($time/31207680) == 1) ? 'a year ago' : round($time/31207680).' years ago';

Solution 6: Refined Formatting with Plurals and Levels

This solution enhances readability by handling plurals correctly and allowing control over the output detail level. It also includes a mechanism for localization.

<?php

function since($timestamp, $level = 6) {
    global $lang; // Assuming $lang is defined elsewhere for localization
    $date = new DateTime();
    $date->setTimestamp($timestamp);
    $date = $date->diff(new DateTime());
    
    // build array
    $since = array_combine(array('year', 'month', 'day', 'hour', 'minute', 'second'), explode(',', $date->format('%y,%m,%d,%h,%i,%s')));
    // remove empty date values
    $since = array_filter($since);
    // output only the first x date values
    $since = array_slice($since, 0, $level);
    
    // build string
    $last_key = key(array_slice($since, -1, 1, true));
    $string = '';
    foreach ($since as $key => $val) {
        // separator
        if ($string) {
            $string .= $key != $last_key ? ', ' : ' ' . $lang['and'] . ' ';
        }
        // set plural
        $key .= $val > 1 ? 's' : '';
        // add date value
        $string .= $val . ' ' . $lang[$key];
    }
    return $string;
}

Solution 7: Simplified humanTiming Function

A concise function that iterates through predefined time units to find the most appropriate representation.

<?php

function humanTiming ($time) {
    $time = time() - $time; // to get the time since that moment
    $time = ($time < 1) ? 1 : $time;
    $tokens = array (
        31536000 => 'year',
        2592000 => 'month',
        604800 => 'week',
        86400 => 'day',
        3600 => 'hour',
        60 => 'minute',
        1 => 'second'
    );

    foreach ($tokens as $unit => $text) {
        if ($time < $unit) continue;
        $numberOfUnits = floor($time / $unit);

Solution 9: Recursive Time Calculation

This function calculates time differences recursively, allowing for a precise display like “X time Y time ago.”

// display "X time" ago, $rcs is precision depth
function time_ago ($tm, $rcs = 0) {
  $cur_tm = time(); 
  $dif = $cur_tm - $tm;
  $pds = array('second','minute','hour','day','week','month','year','decade');
  $lngh = array(1,60,3600,86400,604800,2630880,31570560,315705600);

  for ($v = count($lngh) - 1; ($v >= 0) && (($no = $dif / $lngh[$v]) <= 1); $v--);
    if ($v < 0) $v = 0;
  $_tm = $cur_tm - ($dif % $lngh[$v]);

  $no = ($rcs ? floor($no) : round($no)); // if last denomination, round

  if ($no != 1) $pds[$v] .= 's';
  $x = $no . ' ' . $pds[$v];

  if (($rcs > 0) && ($v >= 1)) $x .= ' ' . time_ago($_tm, $rcs - 1);

  return $x;
}

function getDateTimeDifferenceString($datetime){
    $currentDateTime = new DateTime(getCurrentDateTime());
    $passedDateTime = new DateTime($datetime);
    $interval = $currentDateTime->diff($passedDateTime);
    
    $day = $interval->format('%a'); // Total days
    $hour = $interval->format('%h'); // Hours within the current day
    $min = $interval->format('%i'); // Minutes within the current hour
    $seconds = $interval->format('%s'); // Seconds within the current minute

    if($day > 7) {
        return getDateString(date('Y/m/d', strtotime($datetime)));
    } else if($day >= 1 && $day <= 7) {
        return ($day == 1) ? $day . " day ago" : $day . " days ago";
    } else if($hour >= 1 && $hour <= 24){ // Note: day > 0 check implicitly handles this boundary
        return ($hour == 1) ? $hour . " hour ago" : $hour . " hours ago";
    } else if($min >= 1 && $min <= 60){ // Note: hour > 0 check implicitly handles this boundary
        return ($min == 1) ? $min . " minute ago" : $min . " minutes ago";
    } else if($seconds >= 1 && $seconds <= 60){ // Note: min > 0 check implicitly handles this boundary
        return ($seconds == 1) ? $seconds . " second ago" : $seconds . " seconds ago";

Solution 11: Detailed Time Elapsed String

This function constructs a string by calculating and accumulating time differences for years, months, days, hours, minutes, and seconds.

<?php

private function timeElapsedString($ptime){
    $diff = time() - $ptime;
    $calc_times = array();
    $timeleft   = array();

    // Prepare array, depending on the output we want to get.
    $calc_times[] = array('Year',   'Years',   31557600);
    $calc_times[] = array('Month',  'Months',  2592000);
    $calc_times[] = array('Day',    'Days',    86400);
    $calc_times[] = array('Hour',   'Hours',   3600);
    $calc_times[] = array('Minute', 'Minutes', 60);
    $calc_times[] = array('Second', 'Seconds', 1);

    foreach ($calc_times AS $timedata){
        list($time_sing, $time_plur, $offset) = $timedata;

        if ($diff >= $offset){
            $left = floor($diff / $offset);
            $diff -= ($left * $offset);
            $timeleft[] = "{$left} " . ($left == 1 ? $time_sing : $time_plur);
        }
    }

    return $timeleft ? (time() > $ptime ? null : '-') . implode(' ', $timeleft) : 0;
}

// Example usage
$past_timestamp = strtotime('2024-07-01 12:00:00');
echo timeElapsedString($past_timestamp);

?>

Solution 14: ago Function with strtotime and switch

This function efficiently handles various time differences using strtotime and a switch statement, providing accurate phrasing for seconds, minutes, hours, days, weeks, months, and years.

<?php
function ago($datefrom, $dateto = -1) {
    if ($datefrom == 0) { return "A long time ago"; }
    if ($dateto == -1) { $dateto = time(); }
    $datefrom = strtotime($datefrom);
    $difference = $dateto - $datefrom;

    switch (true) {
        case (strtotime('-1 min', $dateto) < $datefrom):
            $datediff = $difference;
            $res = ($datediff == 1) ? $datediff . ' second' : $datediff . ' seconds';
            break;
        case (strtotime('-1 hour', $dateto) < $datefrom):
            $datediff = floor($difference / 60);
            $res = ($datediff == 1) ? $datediff . ' minute' : $datediff . ' minutes';
            break;
        case (strtotime('-1 day', $dateto) < $datefrom):
            $datediff = floor($difference / 60 / 60);
            $res = ($datediff == 1) ? $datediff . ' hour' : $datediff . ' hours';
            break;
        case (strtotime('-1 week', $dateto) < $datefrom):
            $day_difference = 1;
            while (strtotime('-' . $day_difference . ' day', $dateto) >= $datefrom) { $day_difference++; }
            $datediff = $day_difference;
            $res = ($datediff == 1) ? 'yesterday' : $datediff . ' days';
            break;
        case (strtotime('-1 month', $dateto) < $datefrom):
            $week_difference = 1;
            while (strtotime('-' . $week_difference . ' week', $dateto) >= $datefrom) { $week_difference++; }
            $datediff = $week_difference;
            $res = ($datediff == 1) ? 'last week' : $datediff . ' weeks';
            break;
        case (strtotime('-1 year', $dateto) < $datefrom):
            $months_difference = 1;
            while (strtotime('-' . $months_difference . ' month', $dateto) >= $datefrom) { $months_difference++; }
            $datediff = $months_difference;
            $res = ($datediff == 1) ? $datediff . ' month' : $datediff . ' months';
            break;
        case (strtotime('-1 year', $dateto) >= $datefrom):
            $year_difference = 1;
            while (strtotime('-' . $year_difference . ' year', $dateto) >= $datefrom) { $year_difference++; }
            $datediff = $year_difference;
            $res = ($datediff == 1) ? $datediff . ' year' : $datediff . ' years';
            break;
    }
    return $res;
}

echo ago('2024-07-15 10:00:00');
?>

Output:

2 days

Solution 15: Iterative Time Calculation

This function iterates through time units, calculates the duration, and subtracts it to accurately determine the remaining time for the next unit.

<?php
function time_elapsed_string($ptime) {
    $ptime = strtotime($ptime);
    $ctime = time(); 
    $etime = $ctime - $ptime;

    if ($etime < 1) { return '0 seconds'; }

    $a = array( 365 * 24 * 60 * 60 => 'year', 30 * 24 * 60 * 60 => 'month', 24 * 60 * 60 => 'day', 60 * 60 => 'hour', 60 => 'minute', 1 => 'second');
    $a_plural = array( 'year' => 'years', 'month' => 'months', 'day' => 'days', 'hour' => 'hours', 'minute' => 'minutes', 'second' => 'seconds');

    foreach ($a as $secs => $str){
        $d = $etime / $secs;
        if ($d >= 1){
            $r = floor($d);
            $rtime = $r * $secs;
            if(($etime - $rtime) < 0){ $etime -= ($r - 1) * $secs; } else { $etime -= $rtime; }
            $estring = $estring . $r . ' ' . ($r > 1 ? $a_plural[$str] : $str) . ' ';
        }
    }
    return $estring . ' ago';
}

        'arabic' => ['y' => ['سنة','سنتين','سنوات'], 'm' => ['شهر','شهرين','شهور'], 'd' => ['يوم','يومين','أيام']]
    ];
    $formats = $formats[$format];
    $string = [];
    foreach($periods as $period=>$value) {
        if(!isset($formats[$period])) continue;
        $string[$period] = $value.' ';
        if($format == 'arabic') {
            if($value == 2) $string[$period] = $formats[$period][1];
            elseif($value > 2 && $value <= 10) $string[$period] .= $formats[$period][2];
            else $string[$period] .= $formats[$period][0];
        } elseif($format == 'latin') {
            $string[$period] .= ($value > 1) ? $formats[$period][1] : $formats[$period][0];
        }
    }
    return implode($separator, $string);
}

FAQs on PHP Time Ago Formats

Q: How can I display 'just now' for very recent times

ANS: Many solutions include a condition to check if the time difference is less than a minute (or a few minutes) and display “just now” or a similar phrase. For example, if ($timeDiff < 2) { $timeDiff = "Just now"; } in Solution 30.

Q: Can these functions handle future dates

ANS: Some functions, like the one using the Carbon library (Solution 3) with diffForHumans(), are designed to handle future dates and will display phrases like “in 2 months.” Others might need adjustments to support future date calculations.

Q: How do I localize these 'time ago' strings

ANS: Localization typically involves creating arrays of translated strings for different time units (e.g., ‘year’, ‘years’, ‘month’, ‘months’) and using conditional logic to select the correct phrase based on the language setting and the calculated time difference. Solution 6 and Solution 21 demonstrate approaches to localization.

Q: What's the best way to handle pluralization

ANS: Pluralization is handled by checking if the calculated number of units is greater than 1. If it is, a plural form of the word is used; otherwise, the singular form is used. Many solutions implement this check within their string formatting logic, such as ($diff->$k > 1 ? 's' : '') in Solution 1 or ($r > 1 ? $a_plural[$str] : $str) in Solution 2.

Q: Is there a performance difference between these methods

ANS: Methods using built-in PHP classes like DateTime (Solutions 1, 3, 16) are generally well-optimized. Manual calculations (Solutions 2, 4, 7, 8, 13, 18, 23, 24, 25, 29, 30) can vary in efficiency depending on their implementation. Libraries like Carbon offer robust performance alongside added features. For most web applications, the performance difference is negligible unless dealing with extremely high-volume operations.
