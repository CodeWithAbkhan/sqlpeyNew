Top Ways to Flatten PHP Arrays

Flattening a multi-dimensional array in PHP means transforming it into a single-dimensional array. This process is essential for simplifying data structures, preparing them for certain operations, or making them compatible with various formats. This guide provides a deep dive into numerous effective techniques for achieving this, offering clear explanations and practical code examples.

function flatten(array $array) {
    $return = array();
    array_walk_recursive($array, function($a) use (&amp;$return) { $return[] = $a; });
    return $return;
}

Solution 1: array_walk_recursive with Closures (PHP 5.3+)

This method leverages array_walk_recursive along with a closure to efficiently gather all scalar values from a nested array structure.

<?php
function flattenWithWalkRecursive(array $array): array {
    $return = [];
    array_walk_recursive($array, function ($value) use (&$return) {
        $return[] = $value;
    });
    return $return;
}

$nestedArray = [1, 2, [3, 4, [5, 6, 7], 8], 9];
$flattened = flattenWithWalkRecursive($nestedArray);
print_r($flattened);
?>

function array_flatten(array $array)
{
    $flat = array(); // initialize return array
    $stack = array_values($array); // initialize stack
    while($stack) // process stack until done
    {
        $value = array_shift($stack);
        if (is_array($value)) // a value to further process
        {
            array_unshift($stack, ...$value);
        }
        else // a value to take
        {
            $flat[] = $value;
        }
    }
    return $flat;
}

Solution 5: Stack-Based Non-Recursive Flattening

This method avoids recursion by using a stack data structure to manage the elements to be processed.

<?php
function flattenWithStack(array $array): array {
    $flat = [];
    $stack = array_values($array); // Use array_values to ensure numeric keys for stack

    while ($stack) {
        $value = array_shift($stack); // Take the first element
        if (is_array($value)) {
            // If it's an array, prepend its elements to the stack
            array_unshift($stack, ...$value);
        } else {
            // If it's a scalar value, add it to the result
            $flat[] = $value;
        }
    }
    return $flat;
}

$nestedArray = [1, 2, [3, 4, [5, 6, 7], 8], 9];
$flattened = flattenWithStack($nestedArray);
print_r($flattened);

Solution 12: Iterative Shifting (Non-Recursive)

This approach avoids recursion by iteratively shifting elements from the array.

<?php
function flattenIterativeShift(array $array): array {
    $return = [];
    while (count($array)) {
        $value = array_shift($array); // Remove and return the first element
        if (is_array($value)) {
            // If it's an array, add its elements to the end of the main array
            foreach ($value as $subElement) {
                $array[] = $subElement;
            }
        } else {
            $return[] = $value; // Add scalar value to the result
        }
    }
    return $return;
}

Solution 14: Custom Loop-Based Flattening

This function iteratively processes the array, moving nested elements up.

<?php
function flattenLoopBased(array $inputArray): array {
    $output = [];
    while ($inputArray) {
        list($key, $value) = each($inputArray); // Get the current key/value pair
        unset($inputArray[$key]); // Remove it from the source array

        if (is_array($value)) {
            // If it's an array, merge its contents back into the input array for processing
            $inputArray = array_merge($inputArray, $value);
        } else {
            // If it's a scalar, add it to the output
            $output[$key] = $value;
        }
    }
    return $output;
}

function flatten($array, $level = 0) {

    foreach ($array as $i =&gt; $v) {

Solution 23: Level-Specific Flattening

This versatile function allows flattening to a specific depth.

<?php
/**
 * Flattens an array to a specified depth.
 *
 * @param  array|object $array  The array to flatten.
 * @param  int|boolean  $level  0: deep flatten, 1: shallow, 2: two levels, etc.
 * @return array
 */
function flattenByLevel($array, $level = 0): array {
    $level = (int) $level;
    $result = [];
    foreach ($array as $i => $v) {
        // If $level is non-negative and $v is an array, recurse.
        // Adjust level: if $level is 0 (deep), keep it 0. If > 1, decrement. If 1, make it -1 (stop).
        if ($level >= 0 && is_array($v)) {
            $v = flattenByLevel($v, $level > 1 ? $level - 1 : -$level); // $level > 1 ? $level - 1 : 0 - $level
            $result = array_merge($result, $v);
        } elseif (is_int($i)) { // If the key is an integer, it's a value to add
            $result[] = $v;
        } else { // Preserve non-integer keys
            $result[$i] = $v;
        }
    }
    return $result;
}

/**
 * Flattens a multi demensional array into a one dimensional
 * to be compatible with hidden html fields.
 *
 * @param array $array
 *  Array in the form:
 *  array(
 *    'a' =&gt; array(
 *      'b' =&gt; '1'
 *    )
 *  )
 *
 * @return array
 *  Array in the form:
 *  array(
 *    'a[b]' =&gt; 1,
 *  )
 */
function flatten_array($array) {
  // Continue until $array is a one-dimensional array.
  $continue = TRUE;
  while ($continue) {
    $continue = FALSE;

    // Walk through top and second level of $array and move 
    // all values in the second level up one level.
    foreach ($array as $key =&gt; $value) {
      if (is_array($value)) {
        // Second level found, therefore continue.
        $continue = TRUE;

        // Move each value a level up.
        foreach ($value as $child_key =&gt; $child_value) {
          $array[$key . '[' . $child_key . ']'] = $child_value;
        }

        // Remove second level array from top level.
        unset($array[$key]);
      }
    }
  }

  return $array;
}

            );
            unset($node-&gt;$childField);
        }

    }
    return $result;
}

Solution 28: Object Array Flattening

This function is specifically designed to flatten an array of objects, based on a child field property.

<?php
function objectArrayFlatten($array, $childField) {
    $result = [];
    foreach ($array as $node) {
        $result[] = $node; // Add the current object
        // If the object has the specified child field and it's an array, recurse
        if (isset($node->$childField) && is_array($node->$childField)) {
            $result = array_merge(
                $result,
                objectArrayFlatten($node->$childField, $childField)
            );
            // Optionally unset the child field from the node after processing
            unset($node->$childField);
        }
    }
    return $result;
}
