“PHP Methods for Retrieving Remote File Size Without Downloading”

How can a developer efficiently ascertain the size of a file hosted remotely using PHP, specifically avoiding the overhead of downloading the entire file body? Several established methods leverage HTTP headers, primarily the Content-Length field, obtainable via HEAD requests or specialized functions.

The core concept across most accepted solutions is executing an HTTP request that retrieves only the response headers, as these headers often contain the Content-Length indicating the file size in bytes.

PHP Solution Approaches

We examine several distinct implementations provided by the community to tackle this requirement.

Method 1: Using cURL with Explicit HEAD Request and Header Parsing

This approach employs the cURL library to issue a deliberate HEAD request, instructing the server not to send the body content. It then manually parses the raw headers returned to extract the HTTP status and Content-Length.

<?php
/**
 * Retrieves the size of a remote file via cURL HEAD request, returning -1 on failure.
 *
 * @param string $url The remote file location.
 * @return int The file size in bytes, or -1 if determination fails.
 */
function curl_fetch_remote_size( $url ) {
  $result = -1;
  $curl = curl_init( $url );

  // Configure cURL for a HEAD request, retrieving headers only, and following redirects.
  curl_setopt( $curl, CURLOPT_NOBODY, true );
  curl_setopt( $curl, CURLOPT_HEADER, true );
  curl_setopt( $curl, CURLOPT_RETURNTRANSFER, true );
  curl_setopt( $curl, CURLOPT_FOLLOWLOCATION, true );
  // A robust user agent is recommended for reliable server interaction
  curl_setopt( $curl, CURLOPT_USERAGENT, 'CustomPHPFileProbe/1.0' );

  $data = curl_exec( $curl );
  curl_close( $curl );

  if ( $data ) {
    $content_length = "unknown";
    $status = "unknown";

    // Extract HTTP Status Code (handles HTTP/1.x)
    if ( preg_match( "/^HTTP\/1\.[01] (\d\d\d)/", $data, $matches ) ) {
      $status = (int)$matches[1];
    }

    // Extract Content-Length
    if ( preg_match( "/Content-Length: (\d+)/", $data, $matches ) ) {
      $content_length = (int)$matches[1];
    }

    // Check for success (200 OK) or redirections (3xx codes)
    if ( $status == 200 || ($status > 300 && $status <= 308) ) {
      $result = $content_length;
    }
  }

  return $result;
}

// Example application:
$file_size_bytes = curl_fetch_remote_size( "https://example.com/some/resource.zip" );
echo "File size (bytes): " . $file_size_bytes . "\n";

} elseif( preg_match( "/content-length: (\d+)/", $data, $matches ) ) { // Added lowercase check

}

Method 2: Leveraging cURL’s curl_getinfo

A cleaner way when using cURL is to rely on built-in functions to retrieve known information about the request rather than manual string parsing of the response body.

/**
 * Retrieves remote file size using cURL and CURLINFO_CONTENT_LENGTH_DOWNLOAD.
 *
 * @param string $url The resource URL.
 * @return float|int|bool The content length or false if unavailable/error.
 */
function retrieve_remote_file_size_via_getinfo($url){
     $ch = curl_init($url);

     curl_setopt($ch, CURLOPT_RETURNTRANSFER, TRUE);
     curl_setopt($ch, CURLOPT_HEADER, TRUE);
     curl_setopt($ch, CURLOPT_NOBODY, TRUE);
     // Generally good practice to set a timeout
     curl_setopt($ch, CURLOPT_TIMEOUT, 10); 

     // Execute request to fetch headers
     curl_exec($ch); 
     
     // Get content length directly
     $size = curl_getinfo($ch, CURLINFO_CONTENT_LENGTH_DOWNLOAD);

     curl_close($ch);
     return $size;
}

echo "Size via getinfo: " . retrieve_remote_file_size_via_getinfo('https://example.com/document.pdf') . "\n";

Method 3: Utilizing PHP’s get_headers() for Simplicity (KISS Principle)

The built-in get_headers() function is often preferred for its conciseness, adhering to the Keep It Simple, Stupid (KISS) principle. It can be configured to issue a HEAD request if desired, although it defaults to GET if HEAD fails or isn’t supported.

/**
 * Gets the file size using get_headers(), optionally forcing a HEAD request 
 * and formatting the output.
 *
 * @param string $url The remote object URL.
 * @param bool $formatSize Return human-readable format (default: true).
 * @param bool $useHead Attempt to force HEAD request (default: true).
 * @return string|int Returns formatted size, raw bytes, or -1 if size is missing.
 */
function getRemoteFilesize_Headers( $url, $formatSize = true, $useHead = true)
{
    if ( $useHead ) {
        // Attempt to set context to force HEAD method for efficiency
        stream_context_set_default(array('http' => array('method' => 'HEAD')));
    }
    
    // Get headers, returning an associative array (1 parameter)
    $head = array_change_key_case(get_headers($url, 1));
    
    // Content-length of download (in bytes)
    $clen = isset($head['content-length']) ? (int)$head['content-length'] : 0;

    if ( !$clen ) {
        return -1; // Cannot retrieve file size
    }

    if ( !$formatSize ) {
        return $clen; // Return size in bytes
    }

    // Conversion to human-readable format
    $size = $clen;
    if ( $clen < 1024 ) {
        $size = $clen . ' B'; 
    } elseif ( $clen < 1048576 ) { // 1024*1024
        $size = round($clen / 1024, 2) . ' KiB'; 
    } elseif ( $clen < 1073741824 ) { // 1024^3
        $size = round($clen / 1048576, 2) . ' MiB'; 
    } elseif ( $clen < 1099511627776 ) { // 1024^4
        $size = round($clen / 1073741824, 2) . ' GiB';
    }

    return $size; // return formatted size
}

// Usage Example:
$url_to_check = 'https://releases.ubuntu.com/22.04/ubuntu-22.04.4-desktop-amd64.iso';
echo "Formatted File Size: " . getRemoteFilesize_Headers($url_to_check) . "\n";
echo "Raw Byte Size: " . getRemoteFilesize_Headers($url_to_check, false) . "\n";

A very short variation using get_headers():

// One-liner to get raw byte size (returns null/error if 'content-length' is missing)
$raw_size = array_change_key_case(get_headers("http://some.server/data.dat", 1))['content-length'];
echo "One-liner size: " . $raw_size . "\n";

Method 5: Advanced cURL for Range Requests (Fallback/Supplement)

If a server actively rejects HEAD requests (returns 405 Method Not Allowed), an alternative is to request only the first byte (Range: bytes=0-1) and inspect the Content-Range header, which usually indicates the total size, or fall back to Content-Length. This allows aborting the transfer immediately upon receiving the size information.

This is more complex but handles servers less compliant with standard HEAD protocols:

/**
 * Determines remote file size using Range header request (0-1 byte) and aborts transfer once size is read.
 *
 * @param string $url The file URL.
 * @return int|null Size in bytes, or null if undeterminable.
 */
function getRemoteFileSize_RangeCheck($url)
{
    $ch = curl_init($url);
    
    $headers_sent = [
        'Range: bytes=0-1',
        'Connection: close',
    ];

    $transfer_aborted = false;
    $size = null;

    curl_setopt($ch, CURLOPT_HEADER, 1);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
    curl_setopt($ch, CURLOPT_HTTPHEADER, $headers_sent);
    // Suppress verification errors for demo, production requires proper SSL handling
    curl_setopt($ch, CURLOPT_SSL_VERIFYPEER, 0);
    curl_setopt($ch, CURLOPT_SSL_VERIFYHOST, 0); 
    curl_setopt($ch, CURLOPT_USERAGENT, 'SizeProbeClient/1.0');

    // Custom callback to process headers and potentially abort transfer
    curl_setopt($ch, CURLOPT_HEADERFUNCTION, function($curl, $line) use (&$transfer_aborted, &$size) {
        if (trim($line) == '') {
            // End of headers reached, stop processing headers logic
            return strlen($line);
        }

        list($header, $content) = explode(':', $line, 2);
        $header = strtolower(trim($header));

        if ($header == 'content-range') {
            // Example: bytes 0-0/12345
            if (preg_match('/\/(\d+)$/', $content, $matches)) {
                $size = (int)$matches[1];
                $transfer_aborted = true;
                return 0; // Signal cURL to abort transfer
            }
        } else if ($header == 'content-length' && 206 != curl_getinfo($curl, CURLINFO_HTTP_CODE)) {
            // Standard Content-Length, unless it's a partial response (206)
            $size = (int)$content;
            $transfer_aborted = true;
            return 0; // Signal cURL to abort transfer
        }
        
        return strlen($line);
    });

    // Custom callback to handle body data (should rarely execute if headers provide size)
    curl_setopt($ch, CURLOPT_WRITEFUNCTION, function($curl, $data) use (&$transfer_aborted) {
        if ($transfer_aborted) {
            return 0; // Abort immediately if size was found in header callback
        }
        // If we reach here without aborting, it means size wasn't in headers. Abort anyway.
        return 0;
    });

    curl_exec($ch);
    curl_close($ch);

    return $size;
}

$range_size = getRemoteFileSize_RangeCheck('http://example.com/large_media.bin');
echo "Size via Range Check: " . ($range_size ?? "Failed to determine") . "\n";

function getRemoteFilesize($url, $formatSize = true, $useHead = true)
{
    if (false !== $useHead) {
        stream_context_set_default(array('http' =&gt; array('method' =&gt; 'HEAD')));
    }
    $head = array_change_key_case(get_headers($url, 1));

    $clen = isset($head['content-length']) ? $head['content-length'] : 0;

    if (!$clen) {
        return -1;
    }

    if (!$formatSize) {
        return $clen; // return size in bytes

    switch ($clen) {

        case $clen &lt; 1099511627776:

    }

    return $size; // return formatted size

The fundamental requirement is accessing the Content-Length header associated with a successful response (200) or a redirect (3xx). For general reliability, using get_headers() (Method 3) or cURL with explicit HEAD requests (Method 1/2) are the most common and effective routes.

FAQs on Determining Remote File Size in PHP Without Downloading

Q: Why is Content-Length sometimes missing for a remote file

ANS: The Content-Length header is optional. Servers might omit it for dynamic content, streaming services, or if they are not configured to calculate the size before sending the response headers.

Q: Can I use fopen instead of cURL or get_headers

ANS: Yes, you can use stream functions like fopen combined with stream_context_create to set the request method to HEAD. However, get_headers() often abstracts this process more cleanly for simple header retrieval.

Q: What HTTP status codes indicate a successful size retrieval

ANS: Status codes 200 (OK) or any redirect code in the 300-308 range (since we follow redirects) imply the final resource size is likely provided in the headers.

Q: Is it possible to get the size using standard filesize function

ANS: In specific PHP configurations where allow_url_fopen is on and stream wrappers correctly interpret HEAD requests, filesize('http://example.com/file.zip') might succeed, but this is less reliable than explicit HTTP client methods.
