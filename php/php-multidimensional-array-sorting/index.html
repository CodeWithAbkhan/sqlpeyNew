“PHP Multi-Dimensional Array Sorting: Techniques and Examples”

Sorting a multi-dimensional array in PHP based on several criteria, potentially in different orders (ascending or descending), is a common task. This query delves into various effective methods to achieve this, providing clear code examples and explanations.

Solution 1: Using array_multisort

The array_multisort function is a powerful tool for sorting arrays based on one or more dimensions. For multi-dimensional arrays, you typically extract the columns you want to sort by and then pass them along with the main array to array_multisort.

Example Scenario: Sorting an array of events by event_type in descending order, and then by title in ascending order.

<?php
$eventList = [
    ['ID' => 1, 'title' => 'Boring Meeting', 'event_type' => 'meeting'],
    ['ID' => 2, 'title' => 'Find My Stapler', 'event_type' => 'meeting'],
    ['ID' => 3, 'title' => 'Mario Party', 'event_type' => 'party'],
    ['ID' => 4, 'title' => 'Duct Tape Party', 'event_type' => 'party']
];

// Prepare data for array_multisort
$eventTypes = [];
$titles = [];
foreach ($eventList as $key => $row) {
    $eventTypes[$key] = $row['event_type'];
    $titles[$key] = $row['title'];
}

// Sort by event_type DESC, then title ASC
array_multisort(
    $eventTypes, SORT_DESC,
    $titles, SORT_ASC,
    $eventList
);

// Display sorted array
print_r($eventList);
?>

Solution 2: Leveraging the Spaceship Operator (<=>) with usort (PHP 7+)

PHP 7 introduced the “spaceship operator” (<=>), which greatly simplifies multi-column sorting within a custom comparison function passed to usort.

Example Scenario: Sorting by state ASC, then event_type ASC, then date_start ASC.

<?php
$eventData = [
    ['ID' => 1, 'title' => 'Boring Meeting', 'date_start' => '2010-07-30', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 2, 'title' => 'Find My Stapler', 'date_start' => '2010-07-22', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 3, 'title' => 'Mario Party', 'date_start' => '2010-07-22', 'event_type' => 'party', 'state' => 'new-york'],
    ['ID' => 4, 'title' => 'Duct Tape Party', 'date_start' => '2010-07-28', 'event_type' => 'party', 'state' => 'california']
];

usort($eventData, function($a, $b) {
    // Sort by state ASC, then event_type ASC, then date_start ASC
    return [$a['state'], $a['event_type'], $a['date_start']]
           <=>
           [$b['state'], $b['event_type'], $b['date_start']];
});

var_export($eventData);
?>

Solution 3: Custom Comparison Functions with usort

For more intricate sorting logic or compatibility with older PHP versions, defining custom comparison functions for usort provides great flexibility.

Example Scenario: Sorting by state (ASC), then event_type (ASC), then date_start (ASC).

<?php
$eventData = [
    ['ID' => 1, 'title' => 'Boring Meeting', 'date_start' => '2010-07-30', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 2, 'title' => 'Find My Stapler', 'date_start' => '2010-07-22', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 3, 'title' => 'Mario Party', 'date_start' => '2010-07-22', 'event_type' => 'party', 'state' => 'new-york'],
    ['ID' => 4, 'title' => 'Duct Tape Party', 'date_start' => '2010-07-28', 'event_type' => 'party', 'state' => 'california']
];

function customEventSorter($a, $b) {
    // Compare states
    $stateComparison = strcmp($a['state'], $b['state']);
    if ($stateComparison !== 0) {
        return $stateComparison;
    }

    // Compare event types
    $eventTypeComparison = strcmp($a['event_type'], $b['event_type']);
    if ($eventTypeComparison !== 0) {
        return $eventTypeComparison;
    }

    // Compare dates
    return strcmp($a['date_start'], $b['date_start']);
}

usort($eventData, 'customEventSorter');
print_r($eventData);
?>

Dynamic Comparison Function Generator:

A more advanced approach involves creating a factory function to build comparison functions dynamically.

<?php
function createComparisonFunction(array $fields, string $defaultComparison = 'strcmp') {
    $comparisons = [];
    foreach ($fields as $field => $cmp) {
        if (is_int($field) && !is_callable($cmp)) { // If field is an integer, use default comparison
            $field = $cmp;
            $cmp = $defaultComparison;
        }
        $comparisons[$field] = $cmp;
    }

    return function ($a, $b) use (&$comparisons) {
        foreach ($comparisons as $field => $cmp) {
            $diff = call_user_func($cmp, $a[$field], $b[$field]);
            if ($diff !== 0) {
                return $diff;
            }
        }
        return 0;
    };
}

function numericComparator($a, $b) {
    return $a - $b;
}

function dateStringComparator($a, $b) {
    return strtotime($a) - strtotime($b);
}

// Example for sorting by event priority
function createEventPriorityComparator(array $priorities, int $defaultPriority = 0) {
    return function($a, $b) use (&$priorities, $defaultPriority) {
        $prioA = $priorities[$a['event_type']] ?? $defaultPriority;
        $prioB = $priorities[$b['event_type']] ?? $defaultPriority;
        // Higher priority number means it comes first (descending order of priority value)
        return $prioB - $prioA;
    };
}

$eventData = [
    ['ID' => 1, 'title' => 'Boring Meeting', 'date_start' => '2010-07-30', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 2, 'title' => 'Find My Stapler', 'date_start' => '2010-07-22', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 3, 'title' => 'Mario Party', 'date_start' => '2010-07-22', 'event_type' => 'party', 'state' => 'new-york'],
    ['ID' => 4, 'title' => 'Duct Tape Party', 'date_start' => '2010-07-28', 'event_type' => 'party', 'state' => 'california']
];

$eventPriorities = ['meeting' => 5, 'party' => 10, 'concert' => 7];
$eventPriorityCmp = createEventPriorityComparator($eventPriorities);

$fieldsToSort = [
    'state' => 'strcmp',
    'event_type' => $eventPriorityCmp, // Use custom event priority comparator
    'date_start' => 'dateStringComparator', // Use custom date comparator
    'ID' => 'numericComparator' // Use custom numeric comparator
];

usort($eventData, createComparisonFunction($fieldsToSort));

print_r($eventData);
?>

Solution 4: A Reusable Sorting Function

Creating a dedicated function for sorting sub-values offers a clean way to handle this.

Example Scenario: Sorting a list of songs by artist.

<?php
$songList = [
    '1' => ['artist' => 'Smashing Pumpkins', 'songname' => 'Soma'],
    '2' => ['artist' => 'The Decemberists', 'songname' => 'The Island'],
    '3' => ['artist' => 'Fleetwood Mac', 'songname' => 'Second-hand News']
];

function sortBySubValue($array, $subKey, $sortOrder = 'asc') {
    $tempArray = [];
    foreach ($array as $key => $row) {
        $tempArray[$key] = strtolower($row[$subKey]);
    }

    if ($sortOrder === 'asc') {
        asort($tempArray); // Ascending sort, maintain index association
    } else {
        arsort($tempArray); // Descending sort, maintain index association
    }

    $sortedArray = [];
    foreach ($tempArray as $key => $val) {
        $sortedArray[] = $array[$key];
    }
    return $sortedArray;
}

// Sort by artist ascending
$sortedSongsAsc = sortBySubValue($songList, 'artist', 'asc');
print_r($sortedSongsAsc);

// Sort by artist descending (example of reverse sorting function)
function sortBySubValueReverse($array, $subKey) {
    $tempArray = [];
    foreach ($array as $k => $v) {
        $tempArray[$k] = strtolower($v[$subKey]);
    }
    arsort($tempArray); // Use arsort for descending
    $sortedArray = [];
    foreach ($tempArray as $key => $val) {
        $sortedArray[] = $array[$key];
    }
    return $sortedArray;
}

?>

Solution 5: Object-Oriented Sorting Class

Encapsulating sorting logic within a class can be beneficial for reusability and maintainability.

<?php
class ArraySorter {
    private string $sortField;
    private string $sortOrder;

    public function __construct(string $field, string $order = 'asc') {
        $this->sortField = $field;
        $this->sortOrder = $order;
    }

    public function compareItems($item1, $item2): int {
        if ($item1[$this->sortField] == $item2[$this->sortField]) {
            return 0;
        }
        $comparisonResult = $item1[$this->sortField] > $item2[$this->sortField] ? 1 : -1;
        return ($this->sortOrder === 'asc' ? $comparisonResult : -$comparisonResult);
    }

    public function sort(array &$array): void {
        usort($array, [$this, 'compareItems']);
    }
}

// Example Usage:
$eventData = [
    ['ID' => 1, 'title' => 'Boring Meeting', 'date_start' => '2010-07-30', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 2, 'title' => 'Find My Stapler', 'date_start' => '2010-07-22', 'event_type' => 'meeting', 'state' => 'new-york'],
    ['ID' => 3, 'title' => 'Mario Party', 'date_start' => '2010-07-22', 'event_type' => 'party', 'state' => 'new-york'],
    ['ID' => 4, 'title' => 'Duct Tape Party', 'date_start' => '2010-07-28', 'event_type' => 'party', 'state' => 'california']
];

$stateSorter = new ArraySorter("state", "asc");
$stateSorter->sort($eventData);
print_r($eventData); // Sorted by state ASC
?>

Solution 6: Advanced Multi-Criteria Sort Function

This pragmatic approach defines a function that accepts an array of sorting criteria, allowing for flexible multi-column sorting with specified directions.

<?php
$data = [
    ['volume' => 67, 'edition' => 2],
    ['volume' => 86, 'edition' => 1],
    ['volume' => 85, 'edition' => 6],
    ['volume' => 98, 'edition' => 2],
    ['volume' => 86, 'edition' => 6],
    ['volume' => 67, 'edition' => 7]
];

function createFlexibleComparator(array $sortCriteria): callable {
    return function ($a, $b) use (&$sortCriteria) {
        foreach ($sortCriteria as $column => $direction) {
            // Using strcmp for general comparison, can be adapted for numeric/date types
            $diff = strcmp($a[$column], $b[$column]);
            if ($diff !== 0) {
                return ($direction === "asc" ? $diff : $diff * -1);
            }
        }
        return 0; // Items are equal based on all criteria
    };
}

// Sort by volume DESC, then edition ASC
usort($data, createFlexibleComparator(['volume' => "desc", 'edition' => "asc"]));

print_r($data);
?>

Solution 7: Programmatic Multi-Column, Multi-Direction Sort

This method allows defining sort orders programmatically, making it adaptable for dynamic sorting requirements.

<?php
$outputData = [
    ['ID' => 1, 'title' => 'Boring Meeting', 'event_type' => 'meeting'],
    ['ID' => 2, 'title' => 'Find My Stapler', 'event_type' => 'meeting'],
    ['ID' => 3, 'title' => 'Mario Party', 'event_type' => 'party'],
    ['ID' => 4, 'title' => 'Duct Tape Party', 'event_type' => 'party']
];

$sortInstructions = [
    ["field" => "event_type", "order" => "desc"],
    ["field" => "title", "order" => "asc"],
    ["field" => "ID", "order" => "asc"],
];

function multiColumnMultiDirectionSort(array $sortConfig, array &$dataArray): array {
    if (empty($sortConfig) || !is_array($sortConfig)) {
        return $dataArray;
    }

    $sortParameters = [];
    $extractedColumns = [];

    foreach ($sortConfig as $config) {
        $field = $config['field'];
        $orderDirection = strtoupper($config['order']) === "DESC" ? SORT_DESC : SORT_ASC;
        
        // Extract the column data
        foreach ($dataArray as $key => $row) {
            $extractedColumns[$field][$key] = $row[$field];
        }

        $sortParameters[] = $extractedColumns[$field];
        $sortParameters[] = $orderDirection;
        // Optionally add SORT_REGULAR or other flags if needed
    }

    // Add the array to be sorted by reference
    $sortParameters[] = &$dataArray;

    // Use call_user_func_array to pass parameters dynamically
    call_user_func_array("array_multisort", $sortParameters);

    return $dataArray;
}

$sortedOutput = multiColumnMultiDirectionSort($sortInstructions, $outputData);
print_r($sortedOutput);
?>

Solution 8: Sorting Multiple Related Arrays

When you have multiple arrays that need to be sorted in parallel (e.g., sales figures and corresponding counts), array_multisort can handle this efficiently.

Example Scenario: Sorting sales figures (quote_po) and quote counts (quote_count) in descending order simultaneously.

<?php
$results = [
    'total_quote_sales_person_wise' => [
        'quote_po' => [1500, 1200, 1800, 1000],
        'quote_count' => [5, 7, 6, 8]
    ]
];

// Sort quote_po descending and quote_count descending
array_multisort(
    $results['total_quote_sales_person_wise']['quote_po'], SORT_DESC,
    $results['total_quote_sales_person_wise']['quote_count'], SORT_DESC
);

print_r($results);
?>

FAQs on PHP Multi-Dimensional Array Sorting

Q: How do I sort a PHP array by multiple columns

ANS: You can use array_multisort by preparing the columns to sort and then passing them, or use usort with a custom comparison function that checks columns sequentially.

Q: Can I sort in ascending and descending order simultaneously

ANS: Yes, both array_multisort and usort with a custom comparator allow you to specify different sort orders (e.g., SORT_ASC, SORT_DESC) for each column.

Q: What is the spaceship operator in PHP sorting

ANS: The spaceship operator (<=>) introduced in PHP 7 provides a concise way to compare two values. When used within a usort comparison function for arrays, it simplifies multi-column sorting by comparing elements positionally.

Q: How to sort a multi-dimensional array using a custom function

ANS: Define a PHP function that takes two array elements ($a, $b) and returns -1, 0, or 1 based on their comparison. Pass this function name as the second argument to usort.

Q: Is there a way to sort arrays based on specific priorities

ANS: Yes, you can create a custom comparison function or use a comparator factory that maps values to priority levels, allowing for sorts based on custom ordering logic.
