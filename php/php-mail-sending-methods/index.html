How Can I Send Emails Using PHP?

Sending emails from a PHP application can be achieved through several methods, each with its own set of advantages and configurations. The most direct approach utilizes PHP’s built-in mail() function, but for more complex requirements like sending HTML emails, attachments, or utilizing SMTP servers, dedicated libraries offer greater flexibility and reliability.

Solution 1: Using the PHP mail() Function

The fundamental way to send emails in PHP is via the mail() function. It’s straightforward but has limitations, notably that it doesn’t function on local servers and offers minimal control over headers or delivery.

<?php
$to = 'recipient@example.com';
$subject = 'Test Subject';
$message = 'Hello from PHP!';
$headers = 'From: sender@example.com' . "\r\n" .
           'Reply-To: sender@example.com' . "\r\n" .
           'X-Mailer: PHP/' . phpversion();

if (mail($to, $subject, $message, $headers)) {
    echo 'Email sent successfully using mail()';
} else {
    echo 'Email sending failed.';
}
?>

For sending HTML content, you need to set the Content-type header.

<?php
// Multiple recipients
$to = 'mary@example.com, kelly@example.com'; // note the comma

// Subject
$subject = 'Birthday Reminders for August';

// Message
$message = '
<html>
<head>
  <title>Birthday Reminders for August</title>
</head>
<body>
  <p>Here are the birthdays upcoming in August!</p>
  <table>
    <tr>
      <th>Person</th><th>Day</th><th>Month</th><th>Year</th>
    </tr>
    <tr>
      <td>Joe</td><td>3rd</td><td>August</td><td>1970</td>
    </tr>
    <tr>
      <td>Sally</td><td>17th</td><td>August</td><td>1973</td>
    </tr>
  </table>
</body>
</html>
';

// To send HTML mail, the Content-type header must be set
$headers  = 'MIME-Version: 1.0' . "\r\n";
$headers .= 'Content-type: text/html; charset=iso-8859-1' . "\r\n";

// Additional headers
$headers .= 'To: Mary <mary@example.com>, Kelly <kelly@example.com>' . "\r\n";
$headers .= 'From: Birthday Reminder <reminder@example.com>' . "\r\n";
$headers .= 'Cc: cc@example.com' . "\r\n";
$headers .= 'Bcc: bcc@example.com' . "\r\n";

// Mail it
if (mail($to, $subject, $message, $headers)) {
    echo 'HTML email sent successfully.';
} else {
    echo 'HTML email sending failed.';
}
?>

You can also include CC and BCC recipients directly within the headers.

<?php
$to = "recipient@example.com";
$subject = "My subject";
$txt = "Hello world!";
$headers = "From: sender@example.com" . "\r\n" .
"CC: cc_recipient@example.com";

if (mail($to,$subject,$txt,$headers)) {
    echo 'Email sent with CC recipient.';
} else {
    echo 'Email sending failed.';
}
?>

A basic plain text email can be sent like this:

<?php
session_start();
$to = 'recipient@example.com';
$subject = 'This is the subject';
$message = 'This is the email body';
$from = "From: Your Name <sender@example.com>";

if (mail($to, $subject, $message, $from)) {
    echo 'Plain text email sent.';
} else {
    echo 'Plain text email sending failed.';
}
?>

Solution 2: Utilizing the PHPMailer Library

PHPMailer is a widely adopted, feature-rich library for sending emails in PHP. It supports SMTP, HTML emails, attachments, and various authentication methods.

To use PHPMailer, you first need to include its autoloader. A common way to integrate it is by downloading the library and requiring the necessary files.

<?php
// Ensure you have PHPMailer classes accessible
// require 'path/to/PHPMailer/src/Exception.php';
// require 'path/to/PHPMailer/src/PHPMailer.php';
// require 'path/to/PHPMailer/src/SMTP.php';

use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\Exception;

$mail = new PHPMailer(true); // Passing `true` enables exceptions

try {
    // Server settings
    // $mail->SMTPDebug = 2; // Enable verbose debug output
    $mail->isSMTP();                                      // Set mailer to use SMTP
    $mail->Host = 'smtp.example.com';                     // Specify main and backup SMTP servers
    $mail->SMTPAuth = true;                               // Enable SMTP authentication
    $mail->Username = 'your_email@example.com';           // SMTP username
    $mail->Password = 'your_email_password';              // SMTP password
    $mail->SMTPSecure = 'tls';                            // Enable TLS encryption, `ssl` also accepted
    $mail->Port = 587;                                    // TCP port to connect to

    // Recipients
    $mail->setFrom('sender@example.com', 'Mailer');
    $mail->addAddress('recipient@example.com', 'Joe User'); // Add a recipient
    $mail->addAddress('another_recipient@example.com');    // Name is optional
    $mail->addReplyTo('reply_to@example.com', 'Information');
    $mail->addCC('cc_recipient@example.com');
    $mail->addBCC('bcc_recipient@example.com');

    // Content
    $mail->WordWrap = 50;                                 // Set word wrap to 50 characters
    $mail->addAttachment('/var/tmp/file.tar.gz');         // Add attachments
    $mail->addAttachment('/tmp/image.jpg', 'new.jpg');    // Optional name
    $mail->isHTML(true);                                  // Set email format to HTML

    $mail->Subject = 'Here is the subject';
    $mail->Body    = 'This is the HTML message body <b>in bold!</b>';
    $mail->AltBody = 'This is the body in plain text for non-HTML mail clients';

    if ($mail->send()) {
        echo 'Message has been sent';
    } else {
        echo 'Message could not be sent.';
        echo 'Mailer Error: ' . $mail->ErrorInfo;
    }
} catch (Exception $e) {
    echo 'Message could not be sent. Mailer Error: ', $mail->ErrorInfo;
}
?>

For sending emails via Gmail, you’ll need to configure your Google account by disabling two-factor authentication and enabling “less secure app access” if you are using older methods, or generate an app password.

A more modern approach with PHPMailer and Gmail:

<?php
// PHPMailer classes into the global namespace
use PHPMailer\PHPMailer\PHPMailer;
use PHPMailer\PHPMailer\Exception;

// Base files for PHPMailer
require 'PHPMailer/src/Exception.php';
require 'PHPMailer/src/PHPMailer.php';
require 'PHPMailer/src/SMTP.php';

// Create object of PHPMailer class with boolean parameter which sets/unsets exception.
$mail = new PHPMailer(true);

try {
    $mail->isSMTP();                                      // Use SMTP protocol
    $mail->Host = 'smtp.gmail.com';                       // SMTP host for Gmail
    $mail->SMTPAuth = true;                               // Enable SMTP authentication
    $mail->Username = 'your_gmail_address@gmail.com';     // Sender's Gmail address
    $mail->Password = 'your_gmail_app_password';          // Sender's Gmail app password
    $mail->SMTPSecure = 'tls';                            // For encrypted connection
    $mail->Port = 587;                                    // Port for SMTP

    $mail->setFrom('your_gmail_address@gmail.com', "Sender Name"); // Sender's email and name
    $mail->addAddress('recipient@example.com', "Receiver Name");  // Receiver's email and name

    $mail->Subject = 'Test Subject from Gmail';
    $mail->Body    = 'This is a test email body sent using Gmail SMTP.';

    $mail->send();
    echo 'Message has been sent successfully via Gmail';
} catch (Exception $e) { // Handle errors
    echo 'Message could not be sent. Mailer Error: ', $mail->ErrorInfo;
}
?>

Solution 3: Employing Swift Mailer

Swift Mailer offers an object-oriented approach to sending emails, praised for its elegance and flexibility, often used in conjunction with frameworks like Symfony.

<?php
require 'swift_required.php'; // Ensure swift_required.php is in your include path

// Create the message
$message = Swift_Message::newInstance()
    // Subject of the email
    ->setSubject('A Message from Swift Mailer')
    // From address(es)
    ->setFrom(array('sender@example.com' => 'Jane Doe'))
    // To address(es)
    ->setTo(array('recipient@example.com' => 'Frank Stevens'))
    // Email content
    ->setBody('<h3>New message</h3><p>Here goes the rest of my message.</p>', 'text/html');

// Create the transport
$transport = Swift_MailTransport::newInstance(); // Uses PHP's mail() by default
// For SMTP:
// $transport = Swift_SmtpTransport::newInstance('smtp.example.com', 25, 'tls')
//     ->setUsername('your_email@example.com')
//     ->setPassword('your_email_password');

// Create the Mailer using your created Transport
$mailer = Swift_Mailer::newInstance($transport);

// Send the message
if ($mailer->send($message)) {
    echo json_encode([
        "status" => "OK",
        "message" => 'Your message has been sent!'
    ], JSON_PRETTY_PRINT);
} else {
    echo json_encode([
        "status" => "error",
        "message" => 'Oops! Something went wrong!'
    ], JSON_PRETTY_PRINT);
}
?>

Solution 4: Using PEAR Mail Package

The PEAR Mail package provides a robust alternative to the native mail() function, offering more advanced features.

<?php
include('Mail.php'); // Assumes Mail.php is in your include path

$recipients = 'recipient@example.com';

$headers['From']    = 'sender@example.com';
$headers['To']      = 'recipient@example.com';
$headers['Subject'] = 'Test message via PEAR Mail';

$body = 'This is a test message sent using the PEAR Mail package.';

// SMTP server details
$smtpinfo["host"] = "smtp.server.com";
$smtpinfo["port"] = "25";
$smtpinfo["auth"] = true;
$smtpinfo["username"] = "smtp_user";
$smtpinfo["password"] = "smtp_password";

// Create the mail object using the Mail::factory method
$mail_object =& Mail::factory("smtp", $smtpinfo);

if (PEAR::isError($mail_object)) {
    echo "Error creating mail object: " . $mail_object->getMessage();
} else {
    $send_status = $mail_object->send($recipients, $headers, $body);
    if (PEAR::isError($send_status)) {
        echo "Error sending email: " . $send_status->getMessage();
    } else {
        echo "Email sent successfully via PEAR Mail.";
    }
}
?>

Solution 5: Leveraging Email Services APIs

For applications requiring high deliverability, advanced tracking, or handling large volumes of emails, integrating with email service providers like SendGrid, Postmark, or Amazon SES via their APIs is a recommended practice. These services often bypass the complexities of direct SMTP server configuration. You can also use services like Google Workspace’s Gmail API for transactional emails.

FAQs on PHP Mail Sending

Q: What is the primary PHP function for sending emails

ANS: The primary PHP function for sending emails is mail(). It allows you to send simple text emails, and with specific header configurations, it can also handle HTML content.

Q: Why might the PHP mail function not work on a local server

ANS: The PHP mail() function typically relies on a configured mail transfer agent (MTA) on the server to actually send emails. Local development environments often lack a properly configured MTA, leading to the mail() function appearing to fail or not sending emails at all.

Q: When should I use PHPMailer instead of the mail function

ANS: You should consider PHPMailer when you need to send HTML emails, attach files, use SMTP authentication for sending via external mail servers (like Gmail or a dedicated mail server), or require more control over email headers and delivery.

Q: How does PHPMailer handle different email formats

ANS: PHPMailer allows you to send plain text emails using isHTML(false) (default) or HTML formatted emails using isHTML(true). It also supports setting an alternative plain text body using AltBody for email clients that don’t render HTML.

Q: Can PHPMailer send emails using Gmail

ANS: Yes, PHPMailer can effectively send emails using Gmail’s SMTP server. This typically involves enabling “less secure app access” or, preferably, generating an “App Password” for your Google account and using it for authentication within PHPMailer.

Q: What are some common issues when sending emails with PHP

ANS: Common issues include the mail() function not working on local servers, emails being marked as spam (requiring proper SPF, DKIM records, and avoiding spam trigger words), incorrect SMTP server configurations, and character encoding problems, especially with non-ASCII characters.

Q: How do I send an email with an attachment using PHP

ANS: Libraries like PHPMailer and Swift Mailer provide methods to attach files. For PHPMailer, you would use $mail->addAttachment('/path/to/your/file.pdf');. Swift Mailer has a similar attach() method.

Q: What is the role of SMTP in sending emails

ANS: SMTP (Simple Mail Transfer Protocol) is the standard protocol used for sending emails between mail servers. When you use an SMTP server in PHP (via libraries like PHPMailer), your script connects to that server to handle the email transmission, which is often more reliable than the basic mail() function.
