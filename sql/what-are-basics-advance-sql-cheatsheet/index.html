A SQL cheatsheet is a reference guide or document that lists the most commonly used SQL commands and statements. It is intended to help users quickly look up and reference the syntax and usage of various SQL statements and functions.

SQL cheatsheets can be useful for both beginners who are learning SQL for the first time, as well as experienced developers who need a quick reference when writing complex queries. A SQL cheat sheet can save time and improve productivity by providing a quick reference for commonly used commands and functions.

SQL cheatsheets may include a wide range of information, such as the syntax and usage of different SQL commands, tips and best practices for writing efficient queries, and examples of common SQL queries and their results. Some SQL cheatsheets may also include information on database design, normalization, and other related topics.

List of Complete Basics SQL CheatSheet:

Here is a list of common queries that you might find useful as a SQL cheatsheet:

  1. SELECT: retrieves data from a database table

  2. INSERT: adds new data to a database table

  3. UPDATE: modifies existing data in a database table

  4. DELETE: removes data from a database table

  5. CREATE TABLE: creates a new database table

  6. ALTER TABLE: modifies an existing database table

  7. DROP TABLE: deletes a database table

  8. TRUNCATE TABLE: removes all data from a table, but leaves the table structure intact

  9. CREATE INDEX: creates an index on a database table to improve search performance

  10. DROP INDEX: removes an index from a database table

  11. SELECT DISTINCT: retrieves unique rows from a database table

  12. WHERE: filters the results of a SELECT, INSERT, UPDATE, or DELETE statement based on specified conditions

  13. GROUP BY: groups the results of a SELECT statement based on specified columns

  14. HAVING: filters the results of a SELECT statement based on specified conditions applied to grouped rows

  15. ORDER BY: sorts the results of a SELECT statement in ascending or descending order

  16. LIMIT: limits the number of rows returned by a SELECT statement

  17. INNER JOIN: combines rows from two or more tables based on a matching column in each table

  18. LEFT JOIN: combines rows from two or more tables, with all rows from the left table and matching rows from the right table

  19. RIGHT JOIN: combines rows from two or more tables, with all rows from the right table and matching rows from the left table

  20. FULL JOIN: combines rows from two or more tables, with all rows from both tables and matching rows from either table

  21. UNION: combines the results of two or more SELECT statements into a single result set

  22. UNION ALL: combines the results of two or more SELECT statements into a single result set, including duplicate rows

  23. INTERSECT: returns only the rows that are common to the results of two or more SELECT statements

  24. MINUS: returns only the rows that are in the first SELECT statement but not in the second SELECT statement

Types of SQL Commands with Query Examples

Here is the Types of SQL commands, along with single-line examples of each type of query (Learn Types of SQL Queries with SQL CheatSheet:

1. Data Definition Language (DDL) queries:

  • CREATE TABLE: creates a new table. Example: CREATE TABLE employees (id INT PRIMARY KEY, name TEXT, salary NUMERIC);

  • ALTER TABLE: modifies the structure of a table. Example: ALTER TABLE employees ADD hire_date DATE;

  • DROP TABLE: deletes a table. Example: DROP TABLE employees;

  • TRUNCATE TABLE: empties the contents of a table. Example: TRUNCATE TABLE employees;

2. Data Manipulation Language (DML) queries:

  • SELECT: retrieves data from a table. Example: SELECT * FROM employees WHERE salary > 50000;

  • INSERT: adds new rows to a table. Example: INSERT INTO employees (id, name, salary) VALUES (1, 'John Smith', 55000);

  • UPDATE: modifies existing data in a table. Example: UPDATE employees SET salary = 60000 WHERE id = 1;

  • DELETE: deletes rows from a table. Example: DELETE FROM employees WHERE id = 1;

3. Data Control Language (DCL) queries:

  • GRANT: gives a user certain permissions. Example: GRANT SELECT ON employees TO user1;

  • REVOKE: removes a user’s permissions. Example: REVOKE SELECT ON employees FROM user1;

4. Transaction Control Language (TCL) queries:

  • COMMIT: saves the changes made in a transaction. Example: COMMIT;

  • ROLLBACK: cancels the changes made in a transaction. Example: ROLLBACK;

  • SAVEPOINT: creates a point within a transaction to which you can roll back. Example: SAVEPOINT savepoint1;

6. Query optimization queries:

  • EXPLAIN: shows how a query will be executed by the database. Example: EXPLAIN SELECT * FROM employees WHERE salary > 50000;

  • ANALYZE: collects statistics about the contents of a table, which the query optimizer can use to choose the most efficient execution plan. Example: ANALYZE TABLE employees;

7. System Control Language (SCL) queries:

  • SET: configures runtime options for the current session. Example: SET time_zone = '+00:00';

  • SHOW: displays current runtime options. Example: SHOW time_zone;

Complete List of Advance SQL CheatSheet

Here is an advanced SQL cheat sheet that includes some common categories of queries:

1. Subqueries:

  • SELECT * FROM (SELECT * FROM table1 WHERE condition1) AS subquery WHERE condition2;

  • SELECT * FROM table1 WHERE column1 IN (SELECT column2 FROM table2 WHERE condition);

2. Joins:

  • INNER JOIN: returns rows that have matching values in both tables. Example: SELECT * FROM table1 INNER JOIN table2 ON table1.column1 = table2.column2;

  • LEFT JOIN: returns all rows from the left table, and any matching rows from the right table. Example: SELECT * FROM table1 LEFT JOIN table2 ON table1.column1 = table2.column2;

  • RIGHT JOIN: returns all rows from the right table, and any matching rows from the left table. Example: SELECT * FROM table1 RIGHT JOIN table2 ON table1.column1 = table2.column2;

  • FULL OUTER JOIN: returns all rows from both tables, whether there is a match or not. Example: SELECT * FROM table1 FULL OUTER JOIN table2 ON table1.column1 = table2.column2;

3. Set operations:

  • UNION: combines the results of two or more SELECT statements, removing duplicates. Example: SELECT * FROM table1 UNION SELECT * FROM table2;

  • INTERSECT: returns rows that are present in both SELECT statements. Example: SELECT * FROM table1 INTERSECT SELECT * FROM table2;

  • EXCEPT: returns rows that are present in the first SELECT statement, but not in the second. Example: SELECT * FROM table1 EXCEPT SELECT * FROM table2;

4. Aggregate functions:

  • COUNT: returns the number of rows in a result set. Example: SELECT COUNT(*) FROM table1;

  • SUM: returns the sum of a set of values. Example: SELECT SUM(column1) FROM table1;

  • AVG: returns the average of a set of values. Example: SELECT AVG(column1) FROM table1;

  • MIN: returns the minimum value in a set of values. Example: SELECT MIN(column1) FROM table1;

  • MAX: returns the maximum value in a set of values. Example: SELECT MAX(column1) FROM table1;

5. Grouping and aggregation:

  • GROUP BY: groups the results of a SELECT statement by one or more columns. Example: SELECT column1, COUNT(*) FROM table1 GROUP BY column1;

  • HAVING: filters the results of a SELECT statement based on an aggregate function. Example: SELECT column1, COUNT(*) FROM table1 GROUP BY column1 HAVING COUNT(*) > 10;

6. Window functions:

  • DENSE_RANK: assigns a rank to each row within a result set, based on the values in one or more columns, without any gaps in the ranking. Example: SELECT DENSE_RANK() OVER (ORDER BY column1) AS dense_rank, column1, column2 FROM table1;

  • NTILE: divides a result set into a specified number of groups, and assigns a group number to each row. Example: SELECT NTILE(4) OVER (ORDER BY column1) AS ntile, column1, column2 FROM table1;

  • LAG: retrieves a value from a previous row in the same result set, based on a specified ordering. Example: SELECT LAG(column1, 1) OVER (ORDER BY column2) AS prev_value, column1, column2 FROM table1;

  • LEAD: retrieves a value from a subsequent row in the same result set, based on a specified ordering. Example: SELECT LEAD(column1, 1) OVER (ORDER BY column2) AS next_value, column1, column2 FROM table1;

6. Common table expressions (CTEs):

  • WITH clause: defines a named temporary result set that can be referenced within a SELECT, INSERT, UPDATE, DELETE, or CREATE VIEW statement. Example:

  • WITH cte1 AS (SELECT * FROM table1 WHERE condition1) SELECT * FROM cte1 WHERE condition2; Learn about What are CTEs in SQL

7. Pivot and unpivot:

  • PIVOT: converts rows into columns, based on a specified column and values. Example: SELECT * FROM (SELECT column1, column2, value FROM table1) AS src PIVOT (SUM(value) FOR column2 IN (col1, col2, col3)) AS pivot;

  • UNPIVOT: converts columns into rows, based on a specified column and values. Example: SELECT column1, column2, value FROM table1 UNPIVOT (value FOR column2 IN (col1, col2, col3)) AS unpivot;
