“SQL Update Based on Another Table: Best Practices & Solutions”

When working with relational databases, a frequent requirement involves synchronizing or enriching data in one table by referencing values from another. This often leads to the need for updating records in a target table based on matching criteria in a source table. This post delves into various SQL techniques to achieve this, offering solutions tailored for different database systems and scenarios.

Updating Records Based on a Matching Key

A common task is to update a column in a table (e.g., Sales_Import) with values from a corresponding column in another table (e.g., RetrieveAccountNumber), based on a shared identifier like LeadID.

Solution 1: MS SQL - UPDATE FROM with INNER JOIN

This is a widely accepted and clear method for MS SQL Server. It directly joins the tables and specifies the update.

UPDATE SI
SET SI.AccountNumber = RAN.AccountNumber
FROM Sales_Import AS SI
INNER JOIN RetrieveAccountNumber AS RAN
ON SI.LeadID = RAN.LeadID;
Solution 2: MySQL and MariaDB - Multi-table UPDATE Syntax

MySQL and MariaDB offer a distinct syntax for updating multiple tables simultaneously, often using a comma-separated list in the UPDATE clause.

UPDATE Sales_Import SI, RetrieveAccountNumber RAN
SET SI.AccountNumber = RAN.AccountNumber
WHERE SI.LeadID = RAN.LeadID;
Solution 3: PostgreSQL - UPDATE FROM Syntax

PostgreSQL utilizes a specific UPDATE FROM clause, which is both readable and efficient.

UPDATE Sales_Import SI
SET AccountNumber = RAN.AccountNumber
FROM RetrieveAccountNumber RAN
WHERE RAN.LeadID = SI.LeadID;
Solution 4: Generic UPDATE FROM (MS SQL Style)

A more generic representation often seen for MS SQL Server, using table aliases for clarity.

UPDATE t1
SET t1.column = t2.column
FROM Table1 t1
INNER JOIN Table2 t2
ON t1.id = t2.id;
Solution 5: Oracle and MS SQL - Comma-separated FROM Clause

For Oracle and some older MS SQL versions, a comma-separated FROM clause with a WHERE condition achieves a similar outcome.

UPDATE t1
SET t1.column = t2.column
FROM Table1 t1, Table2 t2
WHERE t1.ID = t2.ID;
Solution 6: MS SQL - Explicit Schema and Table Names

When dealing with specific database contexts, it’s sometimes necessary to qualify table names with schema information.

UPDATE [Sales_Lead].[dbo].[Sales_Import]
SET [AccountNumber] = RetrieveAccountNumber.AccountNumber
FROM RetrieveAccountNumber
WHERE [Sales_Lead].[dbo].[Sales_Import].LeadID = RetrieveAccountNumber.LeadID;
Solution 7: Oracle - UPDATE with Subquery and EXISTS

In Oracle, an UPDATE statement can leverage a correlated subquery combined with EXISTS to selectively update rows.

UPDATE foo
SET foo.new = (SELECT bar.new
              FROM bar
              WHERE foo.key = bar.key)
WHERE EXISTS (SELECT 1
              FROM bar
              WHERE foo.key = bar.key);
Solution 8: MS SQL - Updating Multiple Columns

This example demonstrates updating multiple columns in one statement using a join.

UPDATE AspNetUsers
SET
    AspNetUsers.OrganizationId = UserProfile.OrganizationId,
    AspNetUsers.Name = UserProfile.Name
FROM AspNetUsers, UserProfile
WHERE AspNetUsers.Id = UserProfile.Id;
Solution 9: MySQL - Simple Multi-table Update

A concise way for MySQL to perform updates based on another table.

UPDATE Sales_Import SI, RetrieveAccountNumber RAN
SET SI.AccountNumber = RAN.AccountNumber
WHERE SI.LeadID = RAN.LeadID;
Solution 10: Using a Subquery in SET and WHERE

This approach uses a scalar subquery to fetch the value for the update, often suitable when a direct join syntax is less preferred or unavailable.

UPDATE Sales_Import
SET AccountNumber = (SELECT RetrieveAccountNumber.AccountNumber
                     FROM RetrieveAccountNumber
                     WHERE Sales_Import.leadid = RetrieveAccountNumber.LeadID)
WHERE Sales_Import.leadid = (SELECT RetrieveAccountNumber.LeadID
                             FROM RetrieveAccountNumber
                             WHERE Sales_Import.leadid = RetrieveAccountNumber.LeadID);
Solution 11: Cross-Database Updates (MSSQL)

When tables reside in different databases, a qualified path is necessary for the join.

UPDATE database1..Ciudad
SET CiudadDistrito = c2.CiudadDistrito
FROM database1..Ciudad c1
INNER JOIN database2..Ciudad c2 ON c2.CiudadID = c1.CiudadID;
Solution 12: Basic Update with Comma-separated Tables (MySQL/Similar)

A straightforward method often used in MySQL for basic updates.

UPDATE Sales_Import, RetrieveAccountNumber
SET Sales_Import.AccountNumber = RetrieveAccountNumber.AccountNumber
WHERE Sales_Import.LeadID = RetrieveAccountNumber.LeadID;
Solution 13: Complex Updates with Joins and Calculations

This example shows updating a calculated value, involving multiple joins and a specific WHERE condition.

-- MS SQL
UPDATE c4
SET Price = cp.Price * p.FactorRate
FROM TableNamea_A c4
INNER JOIN TableNamea_B p ON c4.Calcid = p.calcid
INNER JOIN TableNamea_A cp ON c4.Calcid = cp.calcid
WHERE c4.Name = 'MyName';

-- Oracle 11g (using MERGE)
MERGE INTO TableNamea_A u
USING (
    SELECT c4.TableName_A_ID, (cp.Price * p.FactorRate) AS CalcTot
    FROM TableNamea_A c4
    INNER JOIN TableNamea_B p ON c4.Calcid = p.calcid
    INNER JOIN TableNamea_A cp ON c4.Calcid = cp.calcid
    WHERE p.Name = 'MyName'
) rt
ON (u.TableNamea_A_ID = rt.TableNamea_B_ID)
WHEN MATCHED THEN
UPDATE SET Price = CalcTot;
Solution 14: Generic Update with Aliases

A common and clean way to update using aliases for tables, applicable across many SQL dialects.

UPDATE TABLE1 t1
SET t1.column_name = t2.column_name
WHERE t1.id = t2.id;
Solution 15: SQL Server UPDATE with FROM and Implicit Join

A reiteration of the MS SQL Server approach, emphasizing the need for a join in the FROM clause for UPDATE statements involving multiple tables.

UPDATE table2
SET table2.col1 = table1.col1,
    table2.col2 = table1.col2
FROM table1, table2
WHERE table1.memberid = table2.memberid;
Solution 16: Summarized Update Variants

This summarizes common patterns: subquery with EXISTS, INNER JOIN, cross join (implicitly), and MERGE (for systems supporting it).

-- Subquery with EXISTS (SQL Server like)
UPDATE si
SET si.AccountNumber = (
    SELECT ran.AccountNumber
    FROM RetrieveAccountNumber ran
    WHERE si.LeadID = ran.LeadID
)
FROM Sales_Import si
WHERE EXISTS (SELECT * FROM RetrieveAccountNumber ran WHERE ran.LeadID = si.LeadID);

-- INNER JOIN (SQL Server like)
UPDATE si
SET si.AccountNumber = ran.AccountNumber
FROM Sales_Import si
INNER JOIN RetrieveAccountNumber ran ON si.LeadID = ran.LeadID;

-- Cross Join (MySQL like)
UPDATE si
SET si.AccountNumber = ran.AccountNumber
FROM Sales_Import si, RetrieveAccountNumber ran
WHERE si.LeadID = ran.LeadID;

-- MERGE (SQL Server, Oracle)
MERGE INTO Sales_Import si
USING RetrieveAccountNumber ran ON si.LeadID = ran.LeadID
WHEN MATCHED THEN UPDATE SET si.accountnumber = ran.accountnumber;
Solution 17: MySQL/MariaDB Safe Update Mode

When dealing with MySQL’s safe update mode, you might need to disable it temporarily or ensure a WHERE clause on a keyed column.

SET SQL_SAFE_UPDATES = 0;
UPDATE table2, table1
SET table2.by_department = table1.department
WHERE table1.id = table2.by_id;
Solution 18: PostgreSQL - Subquery in SET

A common pattern in PostgreSQL to update a column based on a scalar subquery.

UPDATE application
SET omts_received_date = (
    SELECT date_created
    FROM application_history
    WHERE application.id = application_history.application_id
    AND application_history.application_status_id = 8
);
Solution 19: MS SQL - Updating Temporary Tables

Demonstrates updating a temporary table (@TB1) based on another temporary table (@TB2) using an INNER JOIN.

DECLARE @TB1 TABLE (No INT, Name NVarchar(50), linkNo INT);
DECLARE @TB2 TABLE (No INT, Name NVarchar(50), linkNo INT);

INSERT INTO @TB1 VALUES (1, 'changed person data', 0);
INSERT INTO @TB1 VALUES (2, 'old linked data of person', 1);

INSERT INTO @TB2 SELECT * FROM @TB1 WHERE linkNo = 0;

UPDATE @TB1
SET Name = T2.Name
FROM @TB1 T1
INNER JOIN @TB2 T2 ON T2.No = T1.linkNo;

SELECT * FROM @TB1;
Solution 20: MS SQL - Simple Update with Temporary Tables

Another example showing an INNER JOIN between temporary tables for updating.

DECLARE @TB1 TABLE (No INT, Name NVarchar(50));
DECLARE @TB2 TABLE (No INT, Name NVarchar(50));

INSERT INTO @TB1 VALUES (1, 'asdf');
INSERT INTO @TB1 VALUES (2, 'awerq');

INSERT INTO @TB2 VALUES (1, ';oiup');
INSERT INTO @TB2 VALUES (2, 'lkjhj');

UPDATE @TB1 SET Name = S.Name
FROM @TB1 T
INNER JOIN @TB2 S
    ON S.No = T.No;

SELECT * FROM @TB1;
Solution 21: MS SQL - UPDATE with INNER JOIN and FROM Clause

A slightly different syntactical structure for MS SQL, using aliases.

UPDATE Table_A
SET Table_A.AccountNumber = Table_B.AccountNumber
FROM dbo.Sales_Import AS Table_A
INNER JOIN dbo.RetrieveAccountNumber AS Table_B
    ON Table_A.LeadID = Table_B.LeadID
WHERE Table_A.LeadID = Table_B.LeadID;
Solution 22: MySQL - UPDATE with INNER JOIN and Aliases

A preferred method for MySQL when updating specific columns based on a join.

UPDATE `site` AS destination
INNER JOIN `site_copy` AS backupOnTuesday
      ON backupOnTuesday.`id` = destination.`id`
SET destination.`reasonId` = backupOnTuesday.`reasonId`;
Solution 23: Updating Based on Value Presence or Absence

These examples showcase updating records where a value exists in one table but not another (using LEFT JOIN and IS NULL), or where it exists in both (using JOIN). This is useful for data validation and synchronization.

-- Update where value is NOT found in table2
UPDATE table1 SET table1.column = 'some_new_val' WHERE table1.id IN (
        SELECT table1.id
        FROM  table1
        LEFT JOIN table2 ON ( table2.column = table1.column )
        WHERE table1.column = 'some_expected_val'
        AND table2.column IS NULL
);

-- Update where value IS found in both tables
UPDATE table1 SET table1.column = 'some_new_val' WHERE table1.id IN (
        SELECT table1.id
        FROM  table1
        JOIN table2 ON ( table2.column = table1.column )
        WHERE table1.column = 'some_expected_val'
);
Solution 24: Oracle - MERGE Statement

The MERGE statement in Oracle is a powerful tool for performing conditional updates, inserts, or deletes based on matching records.

MERGE INTO Sales_Import
USING RetrieveAccountNumber
ON (Sales_Import.LeadId = RetrieveAccountNumber.LeadId)
WHEN MATCHED THEN
UPDATE SET Sales_Import.AccountNumber = RetrieveAccountNumber.AccountNumber;
Solution 25: Oracle - UPDATE with Subquery and Alias

Similar to other RDBMS, Oracle supports updating with a subquery, often made cleaner with aliases.

UPDATE Sales_Lead.dbo.Sales_Import SI
SET SI.AccountNumber = (SELECT RAN.AccountNumber FROM RetrieveAccountNumber RAN WHERE RAN.LeadID = SI.LeadID);
Solution 26: Optimizing Updates - Avoiding Redundant Writes

An important optimization: only perform the update if the value is actually changing. This reduces logging and processing overhead.

-- Sample data setup
DROP TABLE #TMP1;
DROP TABLE #TMP2;
CREATE TABLE #TMP1(LeadID Int, AccountNumber NVarchar(50));
CREATE TABLE #TMP2(LeadID Int, AccountNumber NVarchar(50));

INSERT INTO #TMP1 VALUES (147,'5807811235');
INSERT INTO #TMP1 VALUES (150,'5807811326');
INSERT INTO #TMP1 VALUES (185,'7006100100007267039');

INSERT INTO #TMP2 VALUES (147,'7006100100007266957');
INSERT INTO #TMP2 VALUES (150,'7006100100007267039'); -- Different value
INSERT INTO #TMP2 VALUES (185,'7006100100007267039'); -- Same value

UPDATE A
SET A.AccountNumber = B.AccountNumber
FROM #TMP1 A
INNER JOIN #TMP2 B
    ON A.LeadID = B.LeadID
WHERE A.AccountNumber <> B.AccountNumber; -- Condition to only update if values differ

SELECT * FROM #TMP1;
Solution 27: Oracle - UPDATE with Correlated Subquery and WHERE EXISTS

Another Oracle pattern for updating based on the existence of a matching record.

UPDATE suppliers
SET supplier_name = (SELECT customers.customer_name
                     FROM customers
                     WHERE customers.customer_id = suppliers.supplier_id)
WHERE EXISTS (SELECT customers.customer_name
              FROM customers
              WHERE customers.customer_id = suppliers.supplier_id);
Solution 28: Generic Update Syntax

A concise syntax that’s often seen, especially in SQL Server, using aliases and a FROM clause.

UPDATE dpm
SET col1 = dpu.col1
FROM table1 dpm
INNER JOIN table2 dpu ON dpm.parameter_master_id = dpu.parameter_master_id;
Solution 29: LEFT JOIN for Update with Condition

Using a LEFT JOIN and then specifying the condition in the WHERE clause can also achieve the update, though care is needed to ensure it behaves as intended.

UPDATE Sales_Import A
LEFT JOIN RetrieveAccountNumber B ON A.LeadID = B.LeadID
SET A.AccountNumber = B.AccountNumber
WHERE A.LeadID = B.LeadID; -- The WHERE clause here effectively makes it an INNER JOIN logic

FAQs on SQL Update Based on Another Table

Q: What is the most common way to update a SQL table using data from another table

ANS: The most common approach involves using an UPDATE statement combined with a JOIN clause. This allows you to link records from your target table to a source table based on matching criteria and then set the values in the target table accordingly. Specific syntax varies slightly between database systems like SQL Server, MySQL, and PostgreSQL.

Q: Can I update multiple columns from another table in a single SQL query

ANS: Yes, most SQL database systems allow you to update multiple columns within a single UPDATE statement. You typically list the target columns and their new values, fetched from the joined source table, separated by commas.

Q: How do I handle cases where there is no match in the source table when updating

ANS: If you only want to update records that have a match in the source table, use an INNER JOIN. If you want to update records that don’t have a match, you might use a LEFT JOIN and check for NULL values in the source table’s columns within your WHERE clause, or use NOT EXISTS or NOT IN clauses, though joins are often more performant.

Q: What is MERGE statement used for in SQL

ANS: The MERGE statement (available in SQL Server, Oracle, and some other systems) is a powerful command that allows you to perform conditional INSERT, UPDATE, or DELETE operations on a target table based on the results of a join with a source table. It’s particularly useful for synchronizing data, handling inserts of new records, and updates of existing ones in a single operation.

Q: How can I update a table from another table in different databases

ANS: To update a table from another table residing in a different database (typically on the same server), you need to qualify the table names with their respective database names. For instance, in SQL Server, you might use database1.schema.table or database1..table syntax. Ensure the user executing the query has appropriate permissions across both databases.
