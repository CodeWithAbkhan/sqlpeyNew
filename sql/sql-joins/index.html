JOIN clauses play a pivotal role in combining rows from two or more tables based on related columns. This article delves into the world of SQL joins, exploring their types, syntax, and real-world applications.

INNER JOIN: Unveiling Data Relationships

INNER JOIN is the cornerstone of SQL joins, bringing together rows that have matching values in both tables. Let’s explore the power of INNER JOIN with a practical example.

INNER JOIN Syntax

SELECT column_name(s)
FROM table1
INNER JOIN table2 ON table1.column_name = table2.column_name;

INNER JOIN Example

Consider linking orders with customer details using the following SQL:

[SELECT Orders.OrderID, Customers.CustomerName, Orders.OrderDate
FROM Orders
INNER JOIN Customers ON Orders.CustomerID=Customers.CustomerID;](https://sqlpey.com/sql/Full-SQL-Tutorial-Beginners)

Various Types of SQL Joins

SQL offers multiple types of joins to cater to diverse data linking scenarios. Let’s dive into the main types:

1. LEFT (OUTER) JOIN: Bridging Gaps on the Left

LEFT JOIN returns all records from the left table and matching records from the right table. If no match is found, the result from the right is NULL.

LEFT JOIN Syntax

SELECT column_name(s)
FROM table1
LEFT JOIN table2 ON table1.column_name = table2.column_name;

LEFT JOIN Example

Explore customer details and their corresponding orders:

[SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID
ORDER BY Customers.CustomerName;](https://sqlpey.com/sql/Full-SQL-Tutorial-Beginners)

2. RIGHT (OUTER) JOIN: Focusing on the Right

RIGHT JOIN returns all records from the right table and matching records from the left table. Unmatched records from the left result in NULL values.

RIGHT JOIN Syntax

SELECT column_name(s)
FROM table1
RIGHT JOIN table2 ON table1.column_name = table2.column_name;

RIGHT JOIN Example

Retrieve order details along with employee names:

[SELECT Orders.OrderID, Employees.LastName, Employees.FirstName
FROM Orders
RIGHT JOIN Employees ON Orders.EmployeeID = Employees.EmployeeID
ORDER BY Orders.OrderID;](https://sqlpey.com/sql/sql-joins)

3. FULL OUTER JOIN: Embracing Both Sides

FULL OUTER JOIN returns all records when there is a match in either the left or right table. Unmatched records from either side result in NULL values.

FULL OUTER JOIN Syntax

SELECT column_name(s)
FROM table1
FULL OUTER JOIN table2 ON table1.column_name = table2.column_name;

FULL OUTER JOIN Example

Select all customers and their orders:

[SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
FULL OUTER JOIN Orders ON Customers.CustomerID=Orders.CustomerID
ORDER BY Customers.CustomerName;](https://sqlpey.com/sql/Full-SQL-Tutorial-Beginners)

4. SQL Self JOIN: Connecting a Table with Itself

A self JOIN is a regular JOIN, but the table is joined with itself. This powerful technique finds applications in scenarios where a table’s rows need to be compared or related within the same table.

Self JOIN Syntax

SELECT column_name(s)
FROM table1 T1, table1 T2
WHERE condition;

Self JOIN Example

Discover customers sharing the same city:

[SELECT A.CustomerName AS CustomerName1, B.CustomerName AS CustomerName2, A.City
FROM Customers A, Customers B
WHERE A.CustomerID <> B.CustomerID
AND A.City = B.City 
ORDER BY A.City;](https://sqlpey.com/sql/Full-SQL-Tutorial-Beginners)
