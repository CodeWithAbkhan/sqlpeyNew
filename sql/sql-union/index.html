Learn SQL: Understanding the UNION Operator

SQL UNION operator, a versatile tool for combining result sets from two or more SELECT statements.

Key Features of SQL UNION

  • Each SELECT statement within the UNION must have the same number of columns.
  • Columns should share similar data types.
  • The order of columns in each SELECT statement must align.

SQL UNION Syntax

SELECT column_name(s) FROM table1
UNION
SELECT column_name(s) FROM table2;

SQL UNION ALL Syntax

To allow duplicate values, use UNION ALL:

SELECT column_name(s) FROM table1
UNION ALL
SELECT column_name(s) FROM table2;

Note: The column names in the result set typically match those of the first SELECT statement in the UNION.

SQL UNION Example

Consider the following SQL statement, selecting all distinct cities from ‘Customers’ and ‘Suppliers’:

SELECT City FROM Customers
UNION
SELECT City FROM Suppliers
ORDER BY City;

Note: If some customers or suppliers share the same city, the UNION operator selects unique values, listing each city once. Use UNION ALL to include duplicate values!

SQL UNION With WHERE

Filter results with WHERE conditions. This example selects distinct German cities from ‘Customers’ and ‘Suppliers’:

SELECT City, Country FROM Customers
WHERE Country='Germany'
UNION
SELECT City, Country FROM Suppliers
WHERE Country='Germany'
ORDER BY City;

SQL UNION ALL With WHERE

Include duplicates in the results. This example selects all German cities from ‘Customers’ and ‘Suppliers’:

SELECT City, Country FROM Customers
WHERE Country='Germany'
UNION ALL
SELECT City, Country FROM Suppliers
WHERE Country='Germany'
ORDER BY City;

Another UNION Example

Combine information from ‘Customers’ and ‘Suppliers,’ categorizing them as either customers or suppliers:

SELECT 'Customer' As Type, ContactName, City, Country
FROM Customers
UNION
SELECT 'Supplier', ContactName, City, Country
FROM Suppliers;

Frequently Asked Questions (FAQs) on SQL UNION

Q: What is the purpose of the SQL UNION operator?

A: The SQL UNION operator is used to combine the results of two or more SELECT statements, providing a way to merge data sets while removing duplicates.

Q: Can I include duplicate values using the SQL UNION operator?

A: By default, the SQL UNION operator selects only unique values. To include duplicates, you can use the UNION ALL option in your SQL statement.

Q: Do the columns in each SELECT statement of a UNION need to have the same data types?

A: Yes, for a successful UNION operation, the columns in each SELECT statement must have similar data types. It’s essential for proper alignment of the result sets.

Q: What happens if the number of columns or their order differs in the SELECT statements within a UNION?

A: The number of columns and their order must be the same in each SELECT statement of a UNION. Any mismatch may result in an error during execution.
