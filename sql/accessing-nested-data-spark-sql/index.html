“Accessing Nested Data in Spark SQL: Arrays Maps and Structs Query Techniques”

When working with modern big data workloads in Spark, schemas frequently involve complex, nested structures like ArrayType, MapType, and StructType. How do expert practitioners efficiently retrieve specific elements or perform transformations within these intricate column types using both the DataFrame API and raw SQL?

This discussion outlines several proven techniques for navigating and extracting data from these complex fields, accompanied by practical Scala examples built upon a representative schema.

Setting Up Representative Complex Data

To demonstrate the access patterns effectively, let’s establish a sample DataFrame incorporating all three complex types.

import org.apache.spark.sql.functions.{udf, lit, transform, filter, aggregate, array_distinct, array_max, flatten, arrays_zip, array_union, slice, map_keys, map_values, explode}
import scala.util.Try

case class SubRecord(x: Int)
case class ArrayElement(foo: String, bar: Int, vals: Array[Double])
case class Record(
  an_array: Array[Int], 
  a_map: Map[String, String], 
  a_struct: SubRecord, 
  an_array_of_structs: Array[ArrayElement]
)

val spark = SparkSession.builder.appName("NestedAccess").getOrCreate()
import spark.implicits._

val dataFrame = spark.sparkContext.parallelize(Seq(
  Record(Array(1, 2, 3), Map("k_one" -> "v_one", "k_two" -> "v_two"), SubRecord(101),
         Array(
           ArrayElement("item_a", 10, Array(1.1, 2.2, 2.2)),
           ArrayElement("item_b", 20, Array(3.3, 4.4, 5.5))
         )
       ),
  Record(Array(4, 5, 6), Map("k_one" -> "v_new", "k_three" -> "v_three"), SubRecord(202),
         Array(ArrayElement("item_c", 30, Array(5.5, 6.6)), 
               ArrayElement("item_d", 40, Array(7.7, 8.8))
         )
       )
)).toDF()

dataFrame.registerTempTable("complex_data_table")

Techniques for Accessing ArrayType Columns

Retrieving elements from an ArrayType column depends on whether you need a specific index, need to operate on all elements, or desire a calculated result. Spark uses 0-based indexing.

1. DataFrame API Index Access (.getItem(index))

The .getItem(index) method on a Column object is the programmatic way to fetch an element by its position.

// Retrieve the second element (index 1) from 'an_array'
dataFrame.select($"an_array".getItem(1).alias("second_array_element")).show()
