Determining Oracle Database Size How to Find the Size of a Database in Oracle
If you are using Oracle and need to find out the size of a database, whether it’s to check on disk space availability or to monitor growth, you can easily do so using SQL queries. In this Q&A Session, we will show you how to find the size of an Oracle database step by step.

Step 1: Learn Your Oracle Database

Before digging into Oracle queries, it’s important to know what makes up an Oracle database. An Oracle database includes:

  • Data files, which hold the actual data of your database
  • Redo log files, which record all changes to the database since the last backup
  • Control files, which contain information about the physical structure of the database and location of data files and redo log files
  • Temporary files, used for sorts and joins or other temporary tasks

The size of your database is the sum of all these files.

Step 2: Find Data File Sizes

To find the size of your data files, use the following SQL query:

SELECT TABLESPACE_NAME "Tablespace",  
       FILE_NAME "Filename",  
       BYTES/1024/1024 "Size MB", 
       MAXBYTES/1024/1024 "Maximum Size MB", 
       AUTOEXTENSIBLE "Autoextensible"
FROM   SYS.DBA_DATA_FILES;

This query selects the tablespace name, file name, size in MB, maximum size in MB, and whether the file can autoextend from the DBA_DATA_FILES view.

Step 3: Find Total Database Size

To find the total size of your database, use the following SQL query:

SELECT (SELECT SUM(bytes)/1024/1024/1024 data_size FROM dba_data_files) +
       (SELECT NVL(SUM(bytes),0)/1024/1024/1024 temp_size FROM dba_temp_files) +
       (SELECT SUM(bytes)/1024/1024/1024 redo_size FROM sys.v_$log) +
       (SELECT SUM(BLOCK_SIZE*FILE_SIZE_BLKS)/1024/1024/1024 controlfile_size FROM v$controlfile) "Size in GB"
FROM   dual;

This query selects the sum of data file size, temporary file size, redo log file size, and control file size in GB from the DBA_DATA_FILES, DBA_TEMP_FILES, V_$LOG, and V$CONTROFILE views, respectively.

Step 4: Alternative Ways to Find Database Size

There are other SQL queries you can use to find the size of an Oracle database:

SELECT SUM(bytes)/1024/1024/1024 FROM dba_segments;

This query selects the sum of bytes used by all segments (tables, indexes, etc.) in the database from the DBA_SEGMENTS view.

SELECT SUM(bytes)/1024/1024/1024 FROM dba_objects;

This query selects the sum of bytes used by all objects (tables, indexes, etc.) in the database from the DBA_OBJECTS view.

Recap

In this Q&A Session, we showed you how to find the size of an Oracle database using SQL queries. By knowing the different components that make up a database and using the appropriate queries from Oracle views, you can easily monitor the size of your database and ensure that it doesn’t exceed your available disk space. ]]>
