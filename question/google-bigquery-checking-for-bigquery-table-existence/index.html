Alternative Way

Another way to check if a table exists in BigQuery would be to use the BigQuery API directly:

from google.cloud import bigquery
from google.api_core.exceptions import NotFound

def table_exists(client, table_ref):
    try:
        client.get_table(table_ref)
        return True
    except NotFound:
        return False

client = bigquery.Client()
table_ref = client.dataset('dataset_id').table('table_id')
if table_exists(client, table_ref):
    # Do something here
else:
    # Do something else here

The “table_exists” function does the same thing as our original function, but uses the BigQuery API to check if the table exists. It returns “True” if the table exists, else “False”.

Recap

The above function can be used to determine whether a table exists in a BigQuery dataset without throwing a 404 error.
