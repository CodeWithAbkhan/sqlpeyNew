Run command-line SQLite query and exit Running SQLite Query from the Command Line and Exiting
We often use sqlite3 to run queries from the command line. However, when we use the -cmd option in sqlite3, it opens the database and waits in there for interactive input. This can be inconvenient if we want to run a query on sqlite3 from the command line and exit.

Running a Query

To run a query from the command line and exit, we can simply include the command in quotes after the database file argument. For example, the following creates a table called abc:

sqlite3 test.db 'create table abc (col0 int)'

Exiting Gracefully

We can use the .exit command (1 ) to exit gracefully:

sqlite3 test.db "select * from abc;" ".exit"

Using the ‘-cmd’ Option

If we are stuck in a situation where we must use the -cmd flag when running SQLiteÂ 3 from the command line, we can use successive blank commands to exit. For example:

sqlite3 test.db "select * from urls;" "" > test.txt

In this example, the "" will cause the SQLiteÂ 3 process to exit (at least it does for me on OSÂ X).

Using Multiline Queries

It might also be useful to have multiline queries. We can do this by using the shell:

sqlite3 ./database.db <<EOF
    SELECT *
    FROM something
    LIMIT 5
EOF

Using the ‘-cmd’ Option and Shell ‘Magic’

We can also make use of the ‘-cmd’ option and apply some shell ‘magic’ at the end (to imitate user manual ’exit’). To evaluate a sql expression, we can use the following:

#!/bin/sh
sqlite3 -cmd "select 5.0/2;" < `echo " .exit"`

To Summarize

We have discussed various ways to run a SQLite query from the command line and exit. We can include the command in quotes after the database file argument, use the .exit command, use successive blank commands to exit if we must use the -cmd flag, and use multiline queries. We can also use the ‘-cmd’ option and apply some shell ‘magic’ at the end to imitate user manual ’exit’.
