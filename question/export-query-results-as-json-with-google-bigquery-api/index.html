Exporting BigQuery Query Results as JSON to GCS

Summary

In this Q&A Session, we will learn how to export BigQuery query results as JSON to Google Cloud Storage (GCS) using the BigQuery API. We will use Python and the Google Cloud SDK to create a script that will take a BigQuery query as input and export the results to a JSON file stored in GCS.

Prerequisites

Before we begin, make sure you have the following:

  • A Google Cloud Platform (GCP) account
  • A GCP project with billing enabled
  • The Google Cloud SDK installed
  • A text editor of your choice

Step-by-Step Guide

Step 1: Create a Service Account and Download the Key

First, we need to create a service account that will have access to BigQuery and GCS. Go to the GCP Console and navigate to IAM & Admin > Service Accounts. Click on Create Service Account and fill in the required information. Make sure you select the BigQuery User and Storage Object Creator roles. After creating the service account, click on the three dots on the right side of the account row and select Manage Keys. Click on Add Key > JSON and download the key to your local machine. Make sure to keep this key secure, as it grants access to your resources.

Step 2: Authenticate the SDK with the Service Account Key

Open a terminal window and run the following command to authenticate the SDK with the service account key:

gcloud auth activate-service-account --key-file=[path-to-key-file]

Make sure to replace [path-to-key-file] with the actual path to the downloaded key file.

Step 3: Install the Required Python Libraries

We will be using the google-cloud-bigquery and google-cloud-storage Python libraries to interact with the BigQuery and GCS APIs, respectively. Run the following pip commands to install them:

pip install google-cloud-bigquery
pip install google-cloud-storage

Step 4: Write the Script

Open your text editor and create a new file called export_bigquery_to_gcs.py. Paste the following code:

from google.cloud import bigquery
from google.cloud import storage
import json
import os

# Set up environment variables
os.environ['GOOGLE_APPLICATION_CREDENTIALS'] = '[path-to-key-file]'
project_name = '[project-name]'
bucket_name = '[bucket-name]'

# Set up BigQuery and GCS clients
bigquery_client = bigquery.Client(project=project_name)
storage_client = storage.Client(project=project_name)

def export_query_to_gcs(query, destination_blob, file_format):
    job_config = bigquery.QueryJobConfig()
    job_config.destination_format = file_format

    # Set up GCS destination and export job
    destination_uri = 'gs://{}/{}'.format(bucket_name, destination_blob)
    job_config.destination = destination_uri
    query_job = bigquery_client.query(query, job_config=job_config)

    # Wait for job to complete
    query_job.result()

    # Download JSON file from GCS
    bucket = storage_client.bucket(bucket_name)
    blob = bucket.blob(destination_blob)
    file_content = blob.download_as_string()

    # Parse JSON file and write to local file
    file_path = '{}.{}'.format(destination_blob, file_format.lower())
    with open(file_path, 'w') as f:
        json.dump(json.loads(file_content), f)

    return file_path

if __name__ == '__main__':
    query = '[your-query]'
    destination_blob = '[destination-blob-name]'
    file_format = 'JSON'

    file_path = export_query_to_gcs(query, destination_blob, file_format)
    print('Exported query results to {}'.format(file_path))

Make sure to replace the placeholders in brackets with your own values. The query should be a valid SQL query that you want to export to JSON. The destination_blob_name should be the name of the file (without the .json extension) that you want]]>
