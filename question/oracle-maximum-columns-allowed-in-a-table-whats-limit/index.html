ORACLE: Maximum Columns Allowed in a Table: What’s the Limit? Maximum Number of Columns Allowed in Oracle Table
Oracle is a popular relational database management system used by businesses to effectively manage and organize their data. Although, there are limits as to how much data can be stored in Oracle tables. One such limit is the maximum number of columns allowed in a table. This Q&A Session will explore the maximum number of columns permitted in an Oracle table across various versions.

Maximum Number of Columns in Oracle

According to Oracle documentation, a limit of 1000 columns per table applies for versions 8i, 9i, 10g, 11g, 12c, 18c, and 19c. Prior to that, Oracle 7 had a limit of 254 columns. Therefore, regardless of the Oracle version you are using, you can store a maximum of 1000 columns in a table.

Column Limits in Oracle 11g

For Oracle 11g, there is a limit of 1000 columns per table, 32 columns per index, and 30 columns per bitmapped index. You can specify column width up to 4000 bytes in a table. Oracle 11g also allows storing large objects (LOBs) like text, image, video, and audio files in tables. A LOB can be one of four types: Binary Large Object (BLOB), Character Large Object (CLOB), National Character Large Object (NCLOB), and External LOB (BFILE). The size of a LOB column can be up to 4 gigabytes (GB).

Example:

CREATE TABLE employees (
  id NUMBER(10),
  name VARCHAR2(50),
  email VARCHAR2(255),
  address VARCHAR2(1000),
  phone VARCHAR2(20)
);

In the above example, we have created a table called “employees” with five columns named “id”, “name”, “email”, “address”, and “phone”. We have specified the data type and size for each column. The “id” column has a maximum width of 10, “name” and “email” columns have a maximum width of 50 and 255, respectively. The “address” column has a maximum width of 1000, and the “phone” column can hold a maximum of 20 characters.

Alternative Ways

If storing such a vast number of columns in one table seems overwhelming, you can split the table into multiple smaller tables, which will also increase the performance of your queries. Another approach is to use partitioning, which allows you to distribute large tables into smaller and more manageable pieces called partitions. Partitioning improves query performance by allowing you to access only the required partition instead of scanning the entire table.

Summary

In recap, the maximum number of columns allowed in an Oracle table is 1000, regardless of the Oracle version. Oracle 11g also has limits on the number of columns per index and bitmapped index. You can specify up to 4000 bytes width for a column in Oracle 11g. Splitting large tables into smaller ones or using partitioning can improve query performance and make data management more manageable. ]]>
