ORACLE: Optimizing Queries: The Select * Subquery Rewrite Summing Multiple Columns in SQL: Exploring Sub-Queries and Aliases
SQL is a amazing language commonly used for managing and querying relational databases. One of the most common tasks in SQL is to sum multiple columns, such as finding the total sales or revenue for a business. Although, this task can become cumbersome when dealing with multiple columns or tables.

In this post, we will explore how to sum multiple columns in SQL using sub-queries and aliases. We will use a PostgreSQL and Oracle examples to illustrate the syntax and concepts.

The Problem: Summing Multiple Columns in SQL

Let’s say we have a table called “sales” with the following columns:

sales (id, name, date, product, price, quantity)

We want to find the total revenue, total quantity sold and the overall total sum. In PostgreSQL, we can sum multiple columns using a sub-query and an asterisk(*) with the following code:

SELECT *, price * quantity AS total_sum 
FROM 
(
   SELECT SUM(price * quantity) AS revenue, SUM(quantity) AS quantity 
   FROM sales
)

This code calculates the sum of the “price x quantity” for every row in the “sales” table as the “revenue” column and the sum of the “quantity” column individually. Then, it multiplies the “price” and “quantity” columns for every row to calculate the total sum.

Although, this code will not work in Oracle as it does not support the use of an asterisk(*) with columns. Instead, we have to use aliases and specify each column individually as follows:

SELECT t.*, t.price * t.quantity AS total_sum 
FROM 
(
   SELECT SUM(price * quantity) AS revenue, SUM(quantity) AS quantity, SUM(price) AS price 
   FROM sales
) t

In this code, we are assigning aliases to each calculated column in the sub-query and then using those aliases to calculate the total sum in the outer query. We also have to specify the “price” column individually in the sub-query to use it later in the alias calculation.

The Solution: Using Aliases and Sub-Queries

Now, let’s dive into the details of how to use aliases and sub-queries to sum multiple columns in SQL.

Step 1: Creating the Sub-Query

First, we need to create a sub-query that will calculate the sum of the desired columns.

SELECT SUM(price * quantity) AS revenue, SUM(quantity) AS quantity, SUM(price) AS price 
FROM sales

In this example, we are calculating the sum of “price x quantity” as “revenue”, the sum of “quantity” as “quantity”, and the sum of “price” as “price” columns.

Step 2: Assigning Aliases

Next, we need to assign aliases to each calculated column in the sub-query to make it easier to reference them later.

SELECT SUM(price * quantity) AS revenue, SUM(quantity) AS quantity, SUM(price) AS price 
FROM sales

Here, we have assigned aliases “revenue”, “quantity”, and “price” to the individual calculated columns.

Step 3: Adding Aliases to the Main Query

Lastly, we need to add those aliases to the main query to calculate the total sum.

In PostgreSQL:
SELECT *, price * quantity AS total_sum 
FROM 
(
   SELECT SUM(price * quantity) AS revenue, SUM(quantity) AS quantity 
   FROM sales
)

In this code, we have added the alias “price x quantity” as “total_sum” to the main query using the asterisk(*) symbol. We can do this because we already defined the “revenue” and “quantity” aliases in the sub-query.

In Oracle:
SELECT t.*, t.price * t.quantity AS total_sum 
FROM 
(
   SELECT SUM(price * quantity) AS revenue, SUM(quantity) AS quantity, SUM(price) AS price 
   FROM sales
) t

In this code, we have added the “t.” prefix to the “price” and “quantity” columns to reference them in the alias calculation. We have also created an alias “t” for the sub-query to reference it later.

Examples of Summing Multiple Columns in SQL

To illustrate the use of sub-queries and aliases for summing multiple columns in SQL, let’s consider examples from different scenarios:

Example 1: Finding Total Revenue and Quantity Sold by Product

Suppose we want to find the total revenue and quantity sold for each product. We can use the following code:

SELECT product, SUM(price * quantity) AS revenue, SUM(quantity) AS quantity
FROM sales
GROUP BY product

This code groups the sales data by the product column and calculates the sum of “price x quantity” and “quantity” for each product.
