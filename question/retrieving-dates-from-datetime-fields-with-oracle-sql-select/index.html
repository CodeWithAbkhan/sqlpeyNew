Retrieving Dates from DateTime Fields with Oracle SQL SELECT Summary: In SQL Developer, a datetime field can be displayed in a specific format, but to perform queries based on only the date component, the field needs to be converted to a date format using SQL’s TO_DATE function. Although, there are other ways to extract the date component and display it in a specific format.

One simple way is to use the TRUNC function to truncate the time component from the datetime field. The resulting value is still in the datetime format but only contains the date information. To display the date in a specific format, the TO_CHAR function can be used.

Explanation: The code snippet “cast(datetimevariable as date)” cannot be used to extract the date component from a datetime field. It is simply a data type conversion that converts the datetime variable to a date variable, which might be useful in certain scenarios such as joining tables with different data types.

To extract the date component, the TRUNC function can be used as follows:

SELECT TRUNC(REPORTDATE, 'DD') AS my_date
FROM TABLE1

				 The first argument of the TRUNC function is the datetime field, and the second argument specifies the level of truncation. In this case, 'DD' means truncate everything below the day level, effectively removing the time component.  To display the date in a specific format, the TO\_CHAR function can be used as follows: 
				  

SELECT TO_CHAR(REPORTDATE, 'DD.MM.YYYY') AS my_date
FROM TABLE1

The first argument of the TO_CHAR function is the datetime field, and the second argument specifies the format mask. In this case, ‘DD.MM.YYYY’ means display the day component followed by a dot, the month component followed by a dot, and the year component. Practical Examples: Suppose we have a table named ORDERS with a datetime field named ORDERDATE. We want to extract the date component and display it in the format ‘YYYY-MM-DD’. Here are some sample queries:

SELECT TRUNC(ORDERDATE, 'DD') AS ORDER_DATE
FROM ORDERS;

SELECT TO_CHAR(ORDERDATE, 'YYYY-MM-DD') AS ORDER_DATE
FROM ORDERS;

Alternative Ways: Another way to extract the date component is to use the EXTRACT function as follows:

SELECT EXTRACT(YEAR FROM ORDERDATE) AS ORDER_YEAR,
       EXTRACT(MONTH FROM ORDERDATE) AS ORDER_MONTH,
       EXTRACT(DAY FROM ORDERDATE) AS ORDER_DAY
FROM ORDERS;

This query extracts the year, month, and day components separately and displays them in separate columns. These values can be concatenated to form a date string in the desired format. Another way to display the date in a specific format is to use the FORMAT built-in function as follows:

SELECT FORMAT(ORDERDATE, 'yyyy-MM-dd') AS ORDER_DATE
FROM ORDERS;

This syntax is specific to Oracle SQL and is not available in other SQL dialects.
