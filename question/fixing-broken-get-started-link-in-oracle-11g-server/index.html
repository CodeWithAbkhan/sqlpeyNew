Fixing the Broken ‘Get Started’ Link in Oracle 11g Server Oracle 11g Server: How to Fix “Get Started” Link not Working Error

If you are using Oracle database server and encountered an error message stating, “Error- Windows cannot find ‘http://127.0.0.1:%HTTPPORT%/apex/f?p=4950’. Make sure you typed the name correctly, and then try again,” then this Q&A Session will guide you through the process of resolving the issue.

Reason behind the Error The error message appears because the shortcut link provided in the Oracle Database software is unable to resolve the HTTP port number. Therefore, you need to specify the HTTP port number explicitly to fix it.

Steps to fix the Error

Follow these steps to resolve the “Get Started” link not working error:

Method 1: Editing the Get_Started file properties

  • First, navigate to the folder where your Oracle is stored, which is usually in C:\Oracle\oraclexe\app\oracle\product\11.2.0\server.
  • Right-click on the Get_Started file and choose Properties.
  • Manually add the HTTP port number which is usually 8080, in the following format: http://127.0.0.1:8080/apex/f?p=4950.

Method 2: Create a new shortcut

  • Create a new shortcut for the address: http://127.0.0.1:8080/apex/f?p=4950.
  • Assign a name to it, and you are all set.

Method 3: System level Environment Variable

  • Create a SYSTEM level environment variable named HTTPPORT with a value of 8080.
  • Restart the system.
  • Click on the Get Started link, and it will resolve the HTTP port number.

Common Alternate Approaches

Unlock Anonymous Account to Start Apex

In some cases, you may need to unlock the anonymous account to start Apex. To do so, follow these steps:

  • Open command prompt and type sqlplus / as sysdba.
  • Enter the following command: alter user anonymous account unlock;.
  • Restart the system and try accessing the link again.

Check for Working Services

Make sure that the following services are working fine:

  • OracleJobSchedulerXE
  • OracleMTSRecoveryService
  • OracleServiceXE
  • OracleXEClrAgent
  • OracleXETNSListener

Code Syntax and Practical Examples

Here is the sample code syntax to unlock the anonymous account for Oracle 11g:

C:\oracle\product\11.2.0\db_1>sqlplus / as sysdba

SQL> alter user anonymous account unlock; 
User altered.

Recap

The error message “Get Started” link not working in Oracle 11g may occur when the HTTP port number is not specified correctly. You can easily resolve this issue by following the methods mentioned above. Unlocking the anonymous account and checking for working services are additional steps that can help fix the issue.]]>
