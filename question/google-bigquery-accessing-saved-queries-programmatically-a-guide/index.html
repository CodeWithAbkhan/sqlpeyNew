How to Access “Saved Queries” Programmatically in BigQuery
If you are working with BigQuery, you may have come across the “Saved Queries” section in the Web UI. While this feature is convenient for storing frequently used queries, it is not accessible programmatically using an API.

Update 2021: Google now recommends using scripts to save and share queries in BigQuery.

Why Can’t Saved Queries be Accessed Programmatically in BigQuery?

Saved Queries are a UI-only feature in BigQuery, with no public or private interface for programmatic access. In other words, there is no API that allows you to read or write saved queries.

How Can You Save and Share Queries in BigQuery?

Although you cannot access Saved Queries programmatically, there are alternative ways to save and share your queries in BigQuery.

1. Use Scripts

Using scripts is the recommended way to save and share queries in BigQuery. You can write scripts in SQL or JavaScript and save them to a project or dataset. This allows you to reuse queries, automate tasks, and collaborate with other team members.

To save a query as a script in BigQuery, you can use the following syntax:

CREATE OR REPLACE PROCEDURE `project.dataset.script_name`(param1 INT64, param2 STRING)
BEGIN
  -- Your SQL or JavaScript code here
  SELECT * FROM `project.dataset.table_name` WHERE column = param2;
END;

In the above example, we are creating a stored procedure named script_name in the project.dataset location. The procedure accepts two input parameters, param1 and param2, and contains SQL code to select data from a table based on a condition.

2. Use Views

Another way to save queries in BigQuery is to use views. A view is a virtual table that represents the results of a query. You can create a view in the Web UI or using SQL syntax, and then refer to it in other queries.

To create a view in BigQuery, you can use the following syntax:

CREATE OR REPLACE VIEW `project.dataset.view_name`
AS
SELECT column1, column2, column3
FROM `project.dataset.table_name`
WHERE column3 = 'value';

In the above example, we are creating a view named view_name in the project.dataset location. The view selects three columns from a table based on a condition.

3. Use External Tools

If you need to share queries outside of BigQuery, you can use external tools such as Google Sheets or Data Studio. These tools allow you to connect to BigQuery and run queries, and then present the results in a visual format.

Recap

While saved queries in BigQuery cannot be accessed programmatically using an API, you can use scripts, views, and external tools to save and share your queries. It’s important to choose the method that best suits your needs and working environment, and to follow best practices for storing and managing your queries in BigQuery. ]]>
