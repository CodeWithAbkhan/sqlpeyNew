How to Refresh Datasets/Resources in the New Google BigQuery Web UI?

Introduction

Google BigQuery is a cloud-based serverless data warehouse solution. Its new Web UI allows users to run queries, manage datasets, and visualise data. Although, some users may encounter problems when trying to refresh the datasets/resources after creating a table via the Big Query command-line utility. This can be particularly frustrating since the old UI used to have a “refresh” drop-down menu item next to the dataset name.

Problem Statement

After creating a table via the CLI, how do you refresh the datasets/resources section in the new Google BigQuery Web UI so that you can see the newly-created table?

Solution

The BigQuery team is already considering adding a “Refresh” button to the New UI in order to be able to reload the datasets and tables on a project without the need of reloading the entire page. In the meantime, here are some solutions:

Solution 1: Reloading the Entire Webpage

One solution to refresh datasets/resources is to reload the entire webpage. This is not ideal since it removes the text you have in the query editor and requires you to search for the tables again.

Solution 2: Using Chrome Developer Tools

Another solution is to use Chrome Developer Tools. Follow these steps:

  1. Open the BigQuery Web UI in Chrome
  2. Press F12 to open the Chrome Developer Tools
  3. Click on the “Network” tab
  4. Click on the “XHR” sub-tab
  5. Click on the refresh button in the BigQuery Web UI
  6. Look for the request that ends in “/tables” in Chrome Developer Tools
  7. Click on this request to select it
  8. Right-click on this request and select “Copy” -> “Copy as cURL”
  9. Open a terminal window on your machine
  10. Paste the cURL command into the terminal window and run it

This should refresh the datasets/resources section in the BigQuery Web UI.

Solution 3: Use the BigQuery API

Alternatively, you can use the BigQuery API to refresh datasets/resources. Follow these steps:

  1. Open the Google Cloud Console

  2. Select your project

  3. Open the Cloud Shell

  4. Run the following command:

    gcloud auth login

  5. Log in to your Google account

  6. Run the following command:

    bq ls –format=pretty

This should refresh the datasets/resources section in the BigQuery Web UI.

Solution 4: Use the Public Issue Tracker

You can also use the Public Issue Tracker to report this issue to the BigQuery team. Go to the following link and star the issue to highlight its importance: https://issuetracker.google.com/issues/112586996

Summary

In summary, the New Google BigQuery Web UI does not currently have a “Refresh” button to reload the datasets and tables on a project. You can use Chrome Developer Tools or the BigQuery API to work around this issue. Alternatively, you can use the Public Issue Tracker to report this issue to the BigQuery team.
