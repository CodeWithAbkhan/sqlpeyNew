Getting the Primary Key Column in Oracle: A Quick Guide How to Retrieve Primary Key Column in Oracle?
When working with a database, you may need to retrieve the name of the primary key column for a table in Oracle. In this guide, we will show you how to do that step by step.

Retrieving the Primary Key Column in Oracle

The following SQL query can be used to retrieve the name of the primary key column for a table in Oracle:

SELECT cols.table_name, cols.column_name, cols.position, cons.status, cons.owner
FROM all_constraints cons, all_cons_columns cols
WHERE cols.table_name="TABLE_NAME"
AND cons.constraint_type="P"
AND cons.constraint_name = cols.constraint_name
AND cons.owner = cols.owner
ORDER BY cols.table_name, cols.position;

Make sure to replace ‘TABLE_NAME’ with the name of the table you want to retrieve the primary key column for. Oracle stores table names in uppercase, so be sure to use uppercase for the table name in the query as well.

Let’s break down the query to know how it works:

  1. SELECT cols.table_name, cols.column_name, cols.position, cons.status, cons.owner: This part of the query selects the table name, column name, column position, constraint status, and owner from the all_constraints and all_cons_columns tables.
  2. FROM all_constraints cons, all_cons_columns cols: This part of the query retrieves data from two tables: all_constraints, which stores information about all constraints in the database, and all_cons_columns, which stores information about columns that are part of a constraint.
  3. WHERE cols.table_name="TABLE_NAME": This part of the query filters the results to only include data for the specific table name we’re looking for.
  4. AND cons.constraint_type="P": This part of the query further filters the results to only include primary key constraints.
  5. AND cons.constraint_name = cols.constraint_name AND cons.owner = cols.owner: This part of the query joins the all_constraints and all_cons_columns tables on their respective constraint_name and owner columns.
  6. ORDER BY cols.table_name, cols.position: This part of the query sorts the results by table name and column position.

Alternative Ways to Retrieve Primary Key Column

Here are a couple of other ways to retrieve the primary key column:

Using user_constraints and user_cons_columns

You can use the user_constraints and user_cons_columns tables to retrieve the primary key column for a table in Oracle:

SELECT column_name FROM user_cons_columns WHERE constraint_name = (
  SELECT constraint_name FROM user_constraints 
  WHERE UPPER(table_name) = UPPER('tableName') AND CONSTRAINT_TYPE = 'P'
);

Replace ’tableName’ with the name of the actual table you want to retrieve the primary key column for.

Using all_constraints and all_cons_columns

The following query retrieves data from the all_constraints and all_cons_columns tables to retrieve the primary key column:

SELECT column_name FROM all_cons_columns WHERE constraint_name = (
  SELECT constraint_name FROM all_constraints 
  WHERE UPPER(table_name) = UPPER('tableName') AND CONSTRAINT_TYPE = 'P'
);

As before, replace ’tableName’ with the name of the actual table you want to retrieve the primary key column for.
