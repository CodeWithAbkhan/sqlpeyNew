Android - Pulling SQlite database android device Pulling an SQlite Database from an Android Device without Rooting
If you’re looking to extract data from an Android device’s SQlite database without rooting it, you’ve come to the right place. In this article, we’ll explain how to do this using the adb backup command. We’ll also look at alternative methods you can use to achieve the same result.

Using the ADB Backup Command

If your device is running Android v4 or above, you can pull app data, including its database, without root by using the adb backup command. This will allow you to extract the data and access the SQlite database.

The first step is to backup the app data to your PC via USB cable using the following command. Replace app.package.name with the actual package name of the application:

adb backup -f ~/data.ab -noapk app.package.name

This will prompt you to “unlock your device and confirm the backup operation”. Do not provide a password for backup encryption, so you can extract it later. Click on the “Back up my data” button on your device. The screen will display the name of the package you’re backing up, then close by itself upon successful completion.

The resulting data.ab file in your home folder contains application data in android backup format. To extract it use the following command:

dd if=data.ab bs=1 skip=24 | openssl zlib -d | tar -xvf -

If the above ended with openssl:Error: 'zlib' is an invalid command. error, try the below.

dd if=data.ab bs=1 skip=24 | python -c "import zlib,sys;sys.stdout.write(zlib.decompress(sys.stdin.read()))" | tar -xvf -

The result is the apps/app.package.name/ folder containing application data, including the SQlite database.

Alternative Methods

A common way to achieve what you desire is to use the ADB pull command. This will allow you to copy the database from the device to your PC.

Another way, which I prefer in most cases, is to copy the database by code to the SD card. This can be done with the following code:

try {
    File sd = Environment.getExternalStorageDirectory();

    if (sd.canWrite()) {
        String currentDBPath = "/data/data/" + getPackageName() + "/databases/yourdatabasename";
        String backupDBPath = "backupname.db";
        File currentDB = new File(currentDBPath);
        File backupDB = new File(sd, backupDBPath);

        if (currentDB.exists()) {
            FileChannel src = new FileInputStream(currentDB).getChannel();
            FileChannel dst = new FileOutputStream(backupDB).getChannel();
            dst.transferFrom(src, 0, src.size());
            src.close();
            dst.close();
        }
    }
} catch (Exception e) {}
