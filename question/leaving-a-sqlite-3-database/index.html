Exit a SQLite 3 database How to Exit a SQLite 3 Database
SQLite is a popular open-source database that can be used for applications such as web and mobile apps. It is a lightweight, serverless database that is easy to install and use.

When working with a SQLite 3 database, you may need to exit out of it. This can be done easily by following these steps.

Using the Command Line Interface

The most common way to exit a SQLite 3 database is to use the command line interface (CLI). To do this, you need to type ; + Enter to terminate the current statement. Then, type .quit + Enter.

Note that in SQLite 3, SQL statements must be terminated with a delimiter, which is ; by default. The non-SQL commands, which start with a ., do not need to be terminated this way, but they are considered complete as soon as Enter is pressed.

If a command does not start with a . and Enter is pressed without the SQL termination character, the CLI client displays the “continuation prompt” (...> in your case) and expects the SQL command to be continued on the following line(s) until it is properly terminated.

See also Command Line Shell For SQLite .

Using Shortcut Keys

Another way to exit a SQLite 3 database is to use shortcut keys. To do this, press Ctrl + D at the same time and you will exit the SQLite 3 command prompt.

The Invincible Trap

You may have entered multiline command input. To exit the command multiline input use a semicaolon (;) to complete your command. And then use .exit to exit from sqlite commandline or continue with what you want to do.

sqlite>
sqlite> cd
   ...>
   ...> .exit
   ...> .exit
   ...> exit()
   ...> ;  # This semicolon completes the incomplete cd command
Error: near "cd": syntax error
sqlite> .exit

You can terminate the SQLite 3 program by typing your system’s end-of-file character (usually a Ctrl + D). Use the interrupt character (usually a Ctrl + C) to stop a long-running SQL statement.

To Summarize

To exit out of a SQLite 3 database, use a ; (semicolon) press enter then use .exit. Alternatively, you can press Ctrl + D to exit the SQLite 3 command prompt. However, if you have entered multiline command input, you need to use a semicolon (;) to complete your command before you can exit. ]]>
