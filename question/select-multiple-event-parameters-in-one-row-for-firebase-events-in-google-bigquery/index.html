Selecting Multiple Event Params in Firebase Events Stored in Google BigQuery
If you are using Firebase Analytics to log events in your Android app, Firebase allows you to store these events in Google BigQuery, which you can then query to analyze your app’s usage. In this Q&A Session, we will learn how to select several event params in a single row for Firebase events stored in Google BigQuery.

The Firebase Event Logging Code

Let’s first take a look at the code used for logging a Firebase event in Android:

Bundle params = new Bundle();
params.putInt("productID", productId);
params.putInt(FirebaseAnalytics.Param.VALUE, value);
firebaseAnalytics.logEvent("productEvent", params);

When recording an event, Firebase allows you to pass additional information in the form of parameters (key-value pairs). In the code above, we are creating a Bundle object and adding two integer values to it as parameters. We then use that Bundle object when invoking the logEvent() method to log the “productEvent” event in Firebase.

The BigQuery Dataset Schema

When you log an event with Firebase, it creates a table in your BigQuery dataset with a schema that looks like this:

event_dim.name             STRING
event_dim.timestamp_micros INTEGER
event_dim.params.key        STRING
event_dim.params.value.int_value INTEGER
event_dim.params.value.string_value STRING

For each event logged, Firebase creates one row. If the event includes parameters, Firebase creates additional rows for each parameter, using the same event name and timestamp. This can result in multiple rows with the same event name and timestamp, but with different parameters.

Selecting Multiple Event Params in a Single Row

To select multiple event params in a single row, we need to use a GROUP BY clause in our query. Here’s an example:

SELECT 
  event_dim.name AS event_name,
  MAX(CASE WHEN event_dim.params.key = "productID" THEN event_dim.params.value.int_value END) AS product_id,
  MAX(CASE WHEN event_dim.params.key = "value" THEN event_dim.params.value.int_value END) AS value
FROM
  `your_dataset.your_table`
WHERE
  event_dim.name = "productEvent"
GROUP BY
  event_name

In the example above, we are selecting three columns: the event name, the product ID, and the value. The MAX() function is used in conjunction with a CASE statement to extract the values of the corresponding param keys. By grouping by the event name, we ensure that all the parameter values are combined into a single row.

Keep in mind that you will need to replace your_dataset and your_table with the actual names of your BigQuery dataset and table.

Recap

By following the steps outlined in this Q&A Session, you can select multiple event params in a single row for Firebase events stored in Google BigQuery. This can be useful in analyzing your app’s usage and gaining insights into how users are interacting with your app. ]]>
