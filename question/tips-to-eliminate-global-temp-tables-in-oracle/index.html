Tips to Eliminate Global Temp Tables in Oracle In this blog post, we will discuss the use of global temporary tables (GTTs) in Oracle Stored Procedures, and explore alternative ways to avoid using them.

Summary After converting SQL Server stored procedures to Oracle procedures, the use of global temporary tables (GTTs) became a common practice. Although, working with GTTs in Oracle is considered a last option due to performance and other issues. This post will discuss how to avoid using GTTs and when it is appropriate to use them.

Alternative Ways

Subquery Factoring (WITH Clause) We can use subquery factoring (also known as the WITH clause) to create temporary result sets that can be used multiple times in a single query. This can improve query performance as it avoids the need to create temporary tables. Here’s an example: sql WITH temp_table AS ( SELECT someA, someB, someC FROM TABLE_A WHERE condition_1 = 'YN756' AND type_cd = 'P' AND TO_NUMBER(TO_CHAR(m_date, 'MM')) = '12' AND (lname LIKE (v_LnameUpper || '%') OR lname LIKE (v_searchLnameLower || '%')) AND (e_flag = 'Y' OR it_flag = 'Y' OR fit_flag = 'Y') ) UPDATE some_table_b a SET column_a = ( SELECT b.data_a FROM some_table_b b, temp_table c WHERE a.column_b = b.data_b AND a.column_c = 'C' AND b.someA = c.someA AND b.someB = c.someB AND b.someC = c.someC ) WHERE column_a IS NULL OR column_a = ' '; 2.
