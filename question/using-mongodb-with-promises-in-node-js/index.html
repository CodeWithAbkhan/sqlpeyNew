How to use MongoDB with promises in Node.js?

Using MongoDB with Node.js can be tricky, especially when it comes to using promises. While the official documentation suggests using callbacks, many developers prefer using promises for their asynchronous operations.

In this tutorial, we’ll explore how to use MongoDB with promises in Node.js. We’ll cover the basics of setting up a MongoDB connection, and then demonstrate how to use promises with MongoDB.

Setting Up MongoDB Connection

To use MongoDB with Node.js, we’ll need to install the MongoDB Node.js driver. The driver can be installed using the following command:

npm install mongodb

Once the MongoDB Node.js driver is installed, we can connect to an instance of MongoDB by creating a MongoClient object and passing it the MongoDB server URL. For example, the following code creates a MongoClient object and connects it to a local MongoDB server:

var MongoClient = require('mongodb').MongoClient;
var url = "mongodb://localhost:27017/example";
MongoClient.connect(url, function(err, db) {
  if (err) throw err;
  console.log("Database created!");
  db.close();
});

Once a connection is established, we can use the MongoClient object to access the various collections in the database. For example, the following code creates a collection named “users”:

db.createCollection("users", function(err, res) {
  if (err) throw err;
  console.log("Collection created!");
  db.close();
});

Now that we have a basic understanding of how to connect to and use MongoDB with Node.js, let’s look at how to use promises with MongoDB.

Using Promises with MongoDB

Using promises with MongoDB is relatively straightforward. The MongoClient object has a connect() method that returns a promise which resolves with a db object. This db object can then be used to access the various collections in the database. For example, the following code connects to a MongoDB instance and creates a collection named “users”:

MongoClient.connect(url)
  .then(function(db) {
    db.createCollection("users", function(err, res) {
      if (err) throw err;
      console.log("Collection created!");
      db.close();
    });
  })
  .catch(function(err) {
    console.log(err);
  });
