Using Subquery in Oracle ALTER Statement: Possible or Not? How to Dynamically Drop an Oracle Constraint
Have you ever needed to dynamically drop an Oracle constraint, but didn’t know the name of the constraint ahead of time? In this Q&A Session, we will show you how to do just that, including a breakdown of the code line by line.

The Problem

Let’s say you have a table named “MyTable” and a column named “MyColumn” in your Oracle database. Your task is to drop a constraint on the table based on these parameters, but you don’t know the name of the constraint.

You can find the constraint name using the following SQL query:

SELECT CONSTRAINT_NAME 
FROM USER_CONS_COLUMNS 
WHERE TABLE_NAME = 'MyTable' AND 
COLUMN_NAME='MyColumn' AND POSITION IS NULL

Although, in order to drop the constraint, you would need to know the name of the constraint to include it in the ALTER statement.

At first glance, using a subquery may seem like a logical solution:

ALTER TABLE MyTable 
  DROP CONSTRAINT (
   SELECT CONSTRAINT_NAME 
   FROM USER_CONS_COLUMNS 
   WHERE TABLE_NAME = 'MyTable' AND 
   COLUMN_NAME='MyColumn' AND POSITION IS NULL)

Although, this would result in an ORA-02250 error as subqueries are not allowed in ALTER statements.

The Solution

The correct solution is to use PL/SQL to dynamically generate the ALTER statement:

DECLARE 
  statement VARCHAR2(2000);
  constr_name VARCHAR2(30);
BEGIN
  SELECT CONSTRAINT_NAME INTO constr_name 
  FROM USER_CONS_COLUMNS 
  WHERE TABLE_NAME='MyTable' AND 
  COLUMN_NAME='MyColumn' AND POSITION IS NULL;
  
  statement := 'ALTER TABLE MyTable DROP CONSTRAINT '|| constr_name;
  EXECUTE IMMEDIATE (statement); 
END;
/

Let’s take a closer look at each line of the code:

DECLARE 
  statement VARCHAR2(2000);
  constr_name VARCHAR2(30);
BEGIN

First, we use the DECLARE keyword to declare two variables: statement and constr_name. We will be assigning values to these variables later in the code.

SELECT CONSTRAINT_NAME INTO constr_name 
FROM USER_CONS_COLUMNS 
WHERE TABLE_NAME='MyTable' AND 
COLUMN_NAME='MyColumn' AND POSITION IS NULL;

Next, we use the SELECT statement to retrieve the constraint name by querying the USER_CONS_COLUMNS table. We store the result in the “constr_name” variable.

statement := 'ALTER TABLE MyTable DROP CONSTRAINT '|| constr_name;

We assign the ALTER statement to the “statement” variable. We concatenate the constraint name with the ALTER statement using the double pipe (||) operator.

EXECUTE IMMEDIATE (statement);

Lastly, we use the EXECUTE IMMEDIATE statement to execute the dynamically generated ALTER statement.

Alternative Ways

While the above solution works, it can feel unnecessarily complex. If you do not want to use PL/SQL, you can also use a SQL*Plus script to achieve the same result:

SPOOL drop_constraint.sql

SELECT 'ALTER TABLE MyTable DROP CONSTRAINT ' || constraint_name || ';' 
FROM user_cons_columns 
WHERE table_name = 'MyTable' AND column_name = 'MyColumn' AND position IS NULL;

SPOOL OFF

@drop_constraint.sql

With this solution, you will create a SQL script named “drop_constraint.sql” that generates the desired ALTER statement. Then you use the “@” symbol to execute the SQL script.

Recap

While subqueries are not allowed in Oracle ALTER statements, you can use PL/SQL to dynamically generate the ALTER statement based on the constraint name retrieved from the USER_CONS_COLUMNS table. Alternatively, a SQL*Plus script can also be used to achieve the same result. ]]>
