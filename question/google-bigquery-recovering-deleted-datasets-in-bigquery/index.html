How to Recover a Deleted Dataset in BigQuery
Have you accidentally deleted a dataset with all its tables in BigQuery and looking for a way to recover it? Unfortunately, there is no recovery mechanism for datasets in BigQuery. Although, you can schedule backups and restore them later in case of any failure. In this post, we will learn how to backup and restore a lost dataset in BigQuery.

Backing up a Dataset in BigQuery

In order to backup a dataset in BigQuery, you need to use the bq extract command. This command allows you to extract data from a BigQuery table and save it to Cloud Storage. Here is an example of the bq extract command:

bq extract \
  --destination_format=AVRO \
  --use_avro_logical_types \
  --compression=SNAPPY \
  "my-project:my-dataset.my-table" \
  "gs://my-bucket/extract.avro"

Let’s know each parameter of the bq extract command:

  • --destination_format=AVRO: The destination format for the extracted data. In this case, we are using the AVRO format.
  • --use_avro_logical_types: This parameter is used to convert BigQuery logical types to their corresponding AVRO logical types.
  • --compression=SNAPPY: This parameter is used to compress the extracted data. In this case, we are using the SNAPPY compression algorithm which is faster than other algorithms.
  • "my-project:my-dataset.my-table": This is the ID of the BigQuery table that you want to extract. You can get this ID from the BigQuery UI or by using the bq ls command.
  • "gs://my-bucket/extract.avro": This is the Cloud Storage URI where you want to save the extracted data. You need to provide the path to a new or existing bucket and file name. Make sure that the bucket is in the same project as the BigQuery table.

Restoring a Dataset in BigQuery

If you have lost a dataset in BigQuery, you can restore it using the bq load command. This command allows you to load data from Cloud Storage and create a new table in BigQuery. Here is an example of the bq load command:

bq load \
  --source_format=AVRO \
  "my-project:my-dataset.my-table" \
  "gs://bucket/extract.avro"

Let’s know each parameter of the bq load command:

  • --source_format=AVRO: The source format for the data being loaded. In this case, we are using the AVRO format.
  • "my-project:my-dataset.my-table": This is the ID of the new BigQuery table that will be created. The table is created in the specified dataset. If the dataset does not exist, then the bq load command will fail.
  • "gs://bucket/extract.avro": This is the Cloud Storage URI where you saved the extracted data using the bq extract command.

Let’s consider a practical example. Suppose you have a BigQuery table named “my_table” in a dataset named “my_dataset” in your project “my_project”.
