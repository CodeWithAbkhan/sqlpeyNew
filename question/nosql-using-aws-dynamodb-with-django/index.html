NOSQL: Using AWS DynamoDB with Django

Using AWS’s DynamoDB with Django

Introduction

When developing web applications, APIs, and backends using the Django MVC framework, a major aspect of Django is its implementation of an ORM for models. Typically, when using Django, one utilizes an existing interface that maps one’s Django model to a specific DBMS like Postgres, MySQL or Oracle, for example.

Although, there are specific needs and requirements regarding performance and scalability that may require the use of AWS’s DynamoDB instead. DynamoDB is highly cost-efficient, very performant and scales really well.

While Django does not have native NoSQL DBMS support, there are third-party packages available that allow for the use of DynamoDB database with Django. One such package is PynamoDB, but we will use boto3 to work with DynamoDB in this Q&A Session.

Connecting to the DynamoDB Database

To connect to the DynamoDB database, we need to configure the AWS credentials, region and table name to be used. We will use boto3 to interact with DynamoDB.

import boto3

table_name = "my_table"
aws_access_key_id = "your_access_key"
aws_secret_access_key = "your_secret_key"
region_name = "your_region"

dynamodb = boto3.resource('dynamodb', aws_access_key_id=aws_access_key_id, aws_secret_access_key=aws_secret_access_key, region_name=region_name)
table = dynamodb.Table(table_name)

We pass our AWS credentials, region name and table name to the connection string.

Retrieving Data from DynamoDB

To retrieve data from DynamoDB, we can use the get_item method of the Table object. We pass the partition key and its value to the method.

def get_data_from_dynamodb(partition_key_value):
    response = table.get_item(Key={
        'partition_key_name': partition_key_value
    })
    item = response.get('Item')
    if not item:
        return None
    return item

We can then parse the response into a Python dictionary using the json_util module of the dynamodb_json package.

from dynamodb_json import json_util as dynamodb_json

def get_data(request, partition_key_value):
    item = get_data_from_dynamodb(partition_key_value)
    if not item:
        return None
    # deserialize the response
    data = dynamodb_json.loads(item)
    return data

Storing Data in DynamoDB

To store data in DynamoDB, we simply use the put_item method of the Table object. We pass the partition key and its value along with the data to be stored.

def store_data_in_dynamodb(partition_key_value, data):
    item = {'partition_key_name': partition_key_value}
    item.update(data)
    table.put_item(Item=item)

We can then use this function to store data in the DynamoDB database.

data = {'name': 'John Doe', 'age': 30}
store_data_in_dynamodb('1234', data)

Using DynamoDB with the Django ORM

Once we have retrieved or stored data in the DynamoDB database, we can use the Django ORM to store or retrieve data in our model.

For example, to store data in a Django model using data retrieved from DynamoDB, we can do the following:

from myapp.models import MyModel

def store_data_in_django(request, partition_key_value):
    item = get_data_from_dynamodb(partition_key_value)
    if not item:
        return None
    data = dynamodb_json.loads(item)
    my_model = MyModel.objects.create(**data)
    return my_model

We can then call this function to store data in the Django model.

Recap

AWS’s DynamoDB is a highly cost-efficient, performant and scalable NoSQL database that can be used with Django using third-party packages like PynamoDB or by directly interacting with the database using boto3. By following the steps outlined in this Q&A Session, you can easily connect and interact with DynamoDB in your Django projects. ]]>
