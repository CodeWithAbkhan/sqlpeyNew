NOSQL: HyperDex in Production: Who’s Using It? HyperDex in Production: A Q&A Style Overview

Introduction

HyperDex is a relatively new open source NoSQL database that offers high performance, fault tolerance, and ease of deployment. In this blog post, we will discuss some of the practical aspects of using HyperDex in production.

What is HyperDex?

HyperDex is a distributed key-value store that offers ACID transactions, consistency, and availability. It is designed to be highly scalable, fault-tolerant, and to provide low-latency queries. HyperDex uses a novel data model called hyperspace hashing that leverages data partitioning to provide efficient query processing.

How Does HyperDex Compare to Other NoSQL Databases?

According to the HyperDex performance benchmarks, HyperDex offers higher throughput and lower latency than other popular NoSQL systems such as MongoDB and Cassandra. HyperDex is also easier to deploy, as demonstrated in the HyperDex Q&A Sessions.

Who is Using HyperDex in Production?

HyperDex is being used by various organizations in production environments. Some notable examples include:

  • LinkedIn: HyperDex is being used to power some of LinkedIn’s custom analytics applications.
  • Startups: HyperDex is being used to build applications on top of the platform.

To stay up-to-date on how people are using HyperDex in production, you can join the HyperDex discuss list.

What Are Some Gotchas When Deploying HyperDex in Production?

As with any database deployment, there are some gotchas to keep in mind when deploying HyperDex in production. Some of the most common issues include load balancing and optimal subspace scheme. Although, HyperDex provides extensive documentation on how to address these issues.

How Can I Start Using HyperDex?

The HyperDex QuickStart Q&A Session provides a step-by-step guide on how to get started with HyperDex on a single node. To deploy HyperDex in a distributed environment, you can follow the HyperDex Fault-Tolerant Cluster Q&A Session.

Here is an example of using HyperDex in Python:

import hyperdex.admin
import hyperdex.client

# Connect to the cluster
admin = hyperdex.admin.Admin('127.0.0.1', 1982)
client = hyperdex.client.Client('127.0.0.1', 1982)

# Create a space
admin.add_space('''
    space test_data
    key id
    attributes
        string name,
        int age,
        float balance
''')

# Insert data
client.put('test_data', 'john', {'name': 'John', 'age': 22, 'balance': 100.50})

# Query data
results = client.search('test_data', {'age': 22})

This example demonstrates how to create a space, insert data, and query data using the HyperDex Python client.

Alternative Ways to Use HyperDex

HyperDex can be used with various programming languages and frameworks such as Java, Ruby, and Node.js. HyperDex also provides a REST interface that can be used with any programming language that supports HTTP requests.

Recap

HyperDex is a amazing NoSQL database that offers high performance, fault tolerance, and ease of deployment. It is being used in production environments by various organizations for custom analytics applications and other use cases. If you are looking for a scalable, high-performance NoSQL solution, HyperDex might be the right choice for you.
