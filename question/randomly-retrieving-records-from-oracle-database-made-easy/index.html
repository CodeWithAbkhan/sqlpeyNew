Randomly Retrieving Records From Oracle Database Made Easy

sql database
4 min read · Nov 22, 2024

Table of Contents

Randomly Retrieving Records from Oracle Database Made Easy In this blog post, we will be discussing how to select rows randomly from an Oracle database. This is useful when you need to retrieve a random sample of data from a large dataset. We will cover the following topics in this post:

  • Using ORDER BY and DBMS_RANDOM.RANDOM to select rows randomly
  • Using the SAMPLE() function to select a random sample of rows
  • Efficiently selecting random rows from large tables

Using ORDER BY and DBMS_RANDOM.RANDOM to select rows randomly

To select rows randomly using SQL, you can use the ORDER BY clause with the DBMS_RANDOM.RANDOM function. This function generates a random number between 0 and 1 for each row in the table, which can then be used for sorting. Here’s an example query:

SELECT *
FROM   (
    SELECT *
    FROM   table
    ORDER BY DBMS_RANDOM.RANDOM)
WHERE  rownum < 21;

In this query, we first select all rows from the table and sort them randomly using the ORDER BY clause with the DBMS_RANDOM.RANDOM function. We then use the WHERE clause to limit the results to the first 20 rows using the ROWNUM pseudo column.

Using the SAMPLE() function to select a random sample of rows

Another way to select a random sample of rows in Oracle is to use the SAMPLE() function. This function returns a random sample of rows from a table based on a percentage of the total rows. Here’s an example query:

SELECT *
FROM   table SAMPLE(20);

In this query, we select a 20% random sample of rows from the table using the SAMPLE() function. Note that the percentage is approximate and not guaranteed to give you exactly 20 rows. Although, this method can be more efficient for large tables than using the ORDER BY and DBMS_RANDOM.RANDOM method.

Efficiently selecting random rows from large tables

For large tables, the ORDER BY and DBMS_RANDOM.RANDOM method can be slow and inefficient, as it requires scanning the entire table and generating random numbers for each row. To address this, there are three additional methods you can use:

  1. Use the SAMPLE() function with the ROWNUM pseudo column:
SELECT * FROM table SAMPLE(10) WHERE ROWNUM <= 20;

In this query, we first select a 10% random sample of rows from the table using the SAMPLE() function. We then use the ROWNUM pseudo column to limit the result set to the first 20 rows.

  1. Use the DBMS_SQL package to generate a random set of rowids:
DECLARE
  TYPE rowid_table_type IS TABLE OF ROWID INDEX BY BINARY_INTEGER;
  rowids rowid_table_type;
  l_query VARCHAR2(32767);
BEGIN
  -- Generate a list of random rowids
  l_query := 'SELECT ROWID FROM table TABLESAMPLE(10 PERCENT) WHERE ROWNUM <= 20';
  DBMS_SQL.PARSE(CURSOR, l_query, DBMS_SQL.NATIVE);
  DBMS_SQL.DEFINE_COLUMN_ROWID(CURSOR, 1, rowids);
  l_result := DBMS_SQL.EXECUTE(CURSOR);
  DBMS_SQL.FETCH_ROWS(CURSOR);
  DBMS_SQL.COLUMN_VALUE_ROWID(CURSOR, 1, rowids);
  DBMS_SQL.CLOSE_CURSOR(CURSOR);

  -- Use the rowids to select the corresponding rows from the table
  FOR i IN 1..20 LOOP
    SELECT * INTO l_record FROM table WHERE ROWID = rowids(i);
    -- Do something with the selected rows
  END LOOP;
END;

In this example, we use the DBMS_SQL package to execute a query that selects a 10% random sample of rows from the table and limits the result set to the first 20 rows. We then use the rowids returned by the query to select the corresponding rows from the table using a loop.

  1. Use the DBMS_PARALLEL_EXECUTE package to parallelize the query:
DECLARE
  l_task_name     VARCHAR2(100) := 'random_select';
  l_sql_stmt      VARCHAR2(32767);
  l_parallel_stat SYS_REFCURSOR;
BEGIN
  -- Generate a list of random rowids
  l_sql_stmt := 'SELECT ROWID FROM table TABLESAMPLE(10 PERCENT) WHERE ROWNUM <= 20';
  DBMS_PARALLEL_EXECUTE.RUN_TASK(l_task_name, l_sql_stmt);

  -- Use the rowids to select the corresponding rows from the table in parallel
  l_sql_stmt := 'SELECT * FROM table WHERE ROWID = :rowid';
  DBMS_PARALLEL_EXECUTE.CREATE_CHUNKS_BY_ROWID(l_task_name, '', 100, 'BY_ROWID');
  DBMS_PARALLEL_EXECUTE.OPEN_PARALLEL_CURSOR(l_task_name, l_sql_stmt, 'BY_ROWID', 1, 100);
  DBMS_PARALLEL_EXECUTE.FETCH_ROWS(l_task_name, TRUE, l_parallel_stat);
  DBMS_PARALLEL_EXECUTE.CLOSE_PARALLEL_CURSOR(l_task_name);
  DBMS_PARALLEL_EXECUTE.DROP_TASK(l_task_name);
END;

In this example, we use the DBMS_PARALLEL_EXECUTE package to parallelize the query and improve performance. First, we generate a list of random rowids using the SAMPLE() function and limit the result set to the first 20 rows. We then use the DBMS_PARALLEL_EXECUTE package to create chunks of rowids and open a parallel cursor to execute the query against each chunk in parallel. This method can significantly improve performance for large tables.
