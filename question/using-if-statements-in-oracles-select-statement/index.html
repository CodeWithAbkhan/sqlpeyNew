Using If Statements in Oracle’s Select Statement Summary:

The user has a query that selects data from two tables and wants to add a column that checks whether two other columns have the same value or not. If the two columns have the same value, the new column should have a value of 1, otherwise, it should be 0.

Solution:

To add the new column to the query, the user can use a CASE expression that checks whether the ISSUE_DIVISION and ISSUE_DIVISION_2 columns are equal or not. The syntax of the CASE expression is as follows:

CASE
   WHEN condition_1 THEN result_1
   [WHEN condition_2 THEN result_2]
   [ELSE result_n]
END

In this case, the condition is whether the two columns are equal, and the result is 1 if they are equal, and 0 if they are not equal. The CASE expression can be added to the SELECT clause of the query as follows:

SELECT 
  'CARAT Issue Open' AS issue_comment, 
   i.issue_id, 
   i.issue_status, 
   i.issue_title, 
   i.ISSUE_summary, 
   i.issue_description, 
   i.severity,
   gcrs.Area_name, 
   gcrs.sector_name,
   substr(gcrs.stream_name,1,
       case when instr(gcrs.stream_name,' (')=0 then 100 
            else instr(gcrs.stream_name,' (')-1 end
   ) ISSUE_DIVISION,
   CASE 
      WHEN gcrs.STREAM_NAME like 'NON-GT%' 
      THEN 'NON-GT' 
      ELSE gcrs.STREAM_NAME 
   END AS ISSUE_DIVISION_2,
   CASE 
      WHEN ISSUE_DIVISION = ISSUE_DIVISION_2 
      THEN 1 
      ELSE 0 
   END AS ISSUES
FROM 
   table(f_carat_issues_as_of('31/MAR/2013')) i
   INNER JOIN v_gcrs_with_stream gcrs ON i.segment_id = gcrs.segment_id
WHERE 
   UPPER(ISSUE_STATUS) LIKE '%OPEN%'

In this query, the new column is named ISSUES, and it contains the value 1 if ISSUE_DIVISION is equal to ISSUE_DIVISION_2, and 0 otherwise.

Alternative Solution:

Another way to add the new column to the query is by using the DECODE function. The DECODE function takes a column or expression and compares it to a set of values. If the column or expression matches a value, the function returns the corresponding result. If no match is found, the function returns the default result.

The syntax of the DECODE function is as follows:

DECODE(expression, value_1, result_1, [value_2, result_2], ..., default_result)

In this case, the expression is the concatenation of the two columns, and the values are the different possible combinations of the two columns. The results are 1 if the two columns are equal, and 0 if they are not.

The DECODE function can be used as follows:

SELECT 
  'CARAT Issue Open' AS issue_comment, 
   i.issue_id, 
   i.issue_status, 
   i.issue_title, 
   i.ISSUE_summary, 
   i.issue_description, 
   i.severity,
   gcrs.Area_name, 
   gcrs.sector_name,
   substr(gcrs.stream_name,1,
       case when instr(gcrs.stream_name,' (')=0 then 100 
            else instr(gcrs.stream_name,' (')-1 end
   ) ISSUE_DIVISION,
   CASE 
      WHEN gcrs.STREAM_NAME like 'NON-GT%' 
      THEN 'NON-GT' 
      ELSE gcrs.STREAM_NAME 
   END AS ISSUE_DIVISION_2,
   DECODE(ISSUE_DIVISION||ISSUE_DIVISION_2, 
         ISSUE_DIVISION||ISSUE_DIVISION, 1, 
         ISSUE_DIVISION_2||ISSUE_DIVISION, 1, 
         0) AS ISSUES
FROM 
   table(f_carat_issues_as_of('31/MAR/2013')) i
   INNER JOIN v_gcrs_with_stream gcrs ON i.segment_id = gcrs.segment_id
WHERE 
   UPPER(ISSUE_STATUS) LIKE '%OPEN%'

In this query, the new column is named ISSUES, and it is calculated using the DECODE function that compares the concatenation of the two columns to different combinations of the same concatenation. If a match is found, the function returns 1, otherwise, it returns 0.

Recap:

To add a new column that checks whether two other columns have the same value or not, the user can use a CASE expression or the DECODE function. Both methods are effective and can produce the desired result. The choice between the two methods depends on personal preference and the specific requirements of the query.]]>
