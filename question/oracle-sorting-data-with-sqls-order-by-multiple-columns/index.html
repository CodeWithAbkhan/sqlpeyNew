ORACLE: Sorting Data with SQL’s Order By and Multiple Columns How to Order by on Multiple Columns in SQL

In SQL, the ORDER BY keyword is used to sort the rows in a result set in ascending or descending order. The ORDER BY clause typically contains the column name by which the result set is sorted. Although, in some cases, you might need to sort the result set by multiple columns. In this case, you can use the ORDER BY clause with multiple columns to sort the result set in the desired order.

Suppose you have a table with the following columns: VendorName, IncidentID, IncidentStatus, and IncidentDate. You want to sort the result set firstly by the vendor name with the latest incident, and then by the incident date in descending order. To achieve this, you can use the following SQL query:

SELECT *
FROM (
  SELECT 
    VendorName, 
    IncidentID, 
    IncidentStatus, 
    IncidentDate, 
    MAX(IncidentDate) OVER (PARTITION BY VendorName) maxDate
  FROM yourTable
) t
ORDER BY t.maxDate DESC, t.VendorName ASC, t.IncidentDate DESC

Now, let’s take a closer look at how the query works:

  • The inner SELECT statement uses an analytic function MAX() to calculate the maximum incident date for each vendor. The function is applied to the IncidentDate column and partitioned by the VendorName column. This means that the maximum date value is calculated separately for each vendor. The result of the MAX() function is stored in a new column named maxDate.
  • The outer SELECT statement selects all columns from the subquery and orders the result set firstly by maxDate in descending order, then by VendorName in ascending order, and lastly by IncidentDate in descending order.

The ORDER BY clause is applied to the result set of the subquery. You can see that the subquery is enclosed in parentheses and aliased as t. This is because you cannot use the column aliases defined in the SELECT statement in the ORDER BY clause. Instead, you need to refer to the column aliases in the outer SELECT statement.

You can also sort the result set by multiple columns without using a subquery. For example, you can use the following SQL query:

SELECT *
FROM yourTable
ORDER BY 
  MAX(IncidentDate) OVER (PARTITION BY VendorName) DESC,
  VendorName ASC,
  IncidentDate DESC

In this case, the ORDER BY clause applies the MAX() function directly to the IncidentDate column, which means that it is calculated based on the vendor name for each row. Although, this method might not be allowed in some SQL databases, so the subquery method can be a more general solution.

In summary, to order by multiple columns in SQL, you can use the ORDER BY clause with multiple column names or aliases, separated by commas. If you need to sort the result set by a calculated value, such as the maximum value of a column, you can use analytic functions and subqueries.]]>
