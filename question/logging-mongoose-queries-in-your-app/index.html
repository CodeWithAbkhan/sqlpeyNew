log all queries that mongoose fire in the application How To Log Mongoose Queries In A Node.js Application?
If you are developing an application with Node.js and MongoDB, it is essential to keep track of the queries that are fired from Mongoose. In this article, we will be discussing how to log all the queries that Mongoose fires during your application.

Enabling Debug Mode

The first step is to enable the debug mode in Mongoose. This can be done with the following code.

mongoose.set('debug', true);

Adding Your Own Debug Callback

You can also add your own debug callback that will log all executed collection methods and their arguments to the console.

mongoose.set('debug', function (coll, method, query, doc [, options]) {
 //do your thing
});

You can use the following format for the log:

mongoose.set("debug", (collectionName, method, query, doc) => {
    console.log(`${collectionName}.${method}`, JSON.stringify(query), doc);
});

Or, you can use any other logger of your choice:

mongoose.set("debug", (collectionName, method, query, doc) => {
    logger(`${collectionName}.${method}`, JSON.stringify(query), doc);
});

Using Node Bunyan

You can also use Node Bunyan to debug and track queries. Bunyan is a micro-library for creating and managing loggers. Here is an example of using Bunyan:

function serializer(data) {
    let query = JSON.stringify(data.query);
    let options = JSON.stringify(data.options || {});

    return `db.${data.coll}.${data.method}(${query}, ${options});`;
}

let log = bunyan.createLogger({
    name: 'AppName',
    src: false,
    serializers: {
        // ...
        dbQuery: querySerializer
        // ...
    },
    // ...
});

mongoose.set('debug', function(coll, method, query, doc, options) {
    let set = {
        coll: coll,
        method: method,
        query: query,
        doc: doc,
        options: options
    };

    log.info({
        dbQuery: set
    });
});

Setting Debug Logger Parameters

You can also set the debug logger parameters with the following command:

node index.js DEBUG=mquery

However, this will only log queries, not insert or update statements.

To Summarize

In this article, we discussed how to log all the queries that Mongoose fires during a Node.js application. We discussed how to enable debug mode and how to add your own debug callback. We also discussed how to use Node Bunyan for tracking queries, and how to set the debug logger parameters.
