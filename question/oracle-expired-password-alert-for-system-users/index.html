ORACLE: Expired Password Alert for System Users How to Reset an Expired Password for System Users in Oracle Database?

Problem

While trying to access the Oracle database via SQL Developer, you may encounter an error message saying that the password for the System user has expired. This can be a frustrating experience, and you may not know how to reset the password to gain access to the database.

Solution

There are a few ways you can reset an expired password for System Users in Oracle Database:

Method 1: Using SQLPLUS

You can use the following steps to reset an expired password using SQLPLUS:

  1. Open up the command prompt (cmd.exe).
  2. Type SQLPLUS and press Enter.
  3. You will see a prompt asking you to enter your username. Enter SYSTEM and press Enter.
  4. You will see another prompt asking you to enter your password. Enter the expired password and press Enter.
  5. You will now be prompted to enter a new password for the SYSTEM user. Enter a new password and press Enter.

The above steps should allow you to reset the expired password for the SYSTEM user and gain access to the database.

If SQLPLUS is not available, you can also reset an expired password from within SQL Developer:

Alternative Way: Using IntelliJ

If someone uses IntelliJ, you can reset the system password in the connection properties’ “Advanced” tab. There you can set the new password as a value for the oracle.jdbc.newPassword key.
