How to Select the Most Recent Date Record in Oracle

If you need to retrieve the most recent record in a table based on a date field, there are several ways to achieve this in Oracle SQL. In this Q&A Session, we will cover three methods for selecting the most recent date record.

Method 1: Using MAX()

The first method involves using the MAX() function to find the most recent date for each unique group of records. Here’s an example:

SELECT staff_id, max(date)
FROM owner.table
GROUP BY staff_id

This query selects the staff_id and the maximum date for each unique group of records in owner.table. The GROUP BY clause groups the records by staff_id, while the MAX() function determines the maximum date for each group.

Although, this query only returns the staff_id and date fields. If you need to retrieve other fields from the most recent record, you can use this query as a subquery and join it to the original table:

SELECT t.*
FROM owner.table t
JOIN (
  SELECT staff_id, max(date) latest_date
  FROM owner.table
  GROUP BY staff_id
) latest
ON t.staff_id = latest.staff_id AND t.date = latest.latest_date

This query joins the original table with the subquery that selects the most recent date for each staff_id group. The ON clause ensures that the staff_id and date fields match between the two tables, retrieving all fields from the most recent record.

Method 2: Using RANK()

The second method involves using the RANK() function to rank the records within each staff_id group based on their date field. Here’s an example:

SELECT staff_id, site_id, pay_level, date
FROM (
  SELECT staff_id, site_id, pay_level, date,
         RANK() OVER (PARTITION BY staff_id ORDER BY date DESC) r
  FROM owner.table
  WHERE end_enrollment_date IS NULL
) ranked
WHERE r = 1

This query selects the staff_id, site_id, pay_level, and date fields from the original table, using the RANK() function to assign a rank to each record within each staff_id group based on their date field. The WHERE clause selects only records with a rank of 1, which represents the most recent record within each group.

Method 3: Using MAX() and a Correlated Subquery

The third method involves using the MAX() function in a correlated subquery to find the most recent date for each record in the original table. Here’s an example:

SELECT staff_id, site_id, pay_level, date
FROM owner.table t1
WHERE end_enrollment_date IS NULL
AND date = (
  SELECT MAX(date)
  FROM owner.table t2
  WHERE t1.staff_id = t2.staff_id
)

This query retrieves all fields from the original table, using a correlated subquery to select the maximum date for each staff_id group. The subquery compares the staff_id fields between t1 and t2 tables and selects the maximum date for that group. The WHERE clause then selects only records where the date field matches the maximum date for that group.
