How to create a “materialized view” of the latest records in BigQuery?

Introduction

As new rows are continually added to a BigQuery table, you may want to create a “materialized view” of the latest row for each unique id. This will enable anyone querying the view to easily access the latest record without having to scan the entire table. Unfortunately, BigQuery does not support materialized views. Although, you can use the following solution to achieve a similar outcome.

The Solution

For this example, we will use a table containing Wikipedia logs and create a view with the latest rows for all English pages starting with the letter ‘A’. First, we will create a new table to hold the latest rows:

CREATE TABLE `wikipedia_vt.just_latest_rows` AS

We will then select the latest row for each id using the following subquery:

SELECT ARRAY_AGG(a ORDER BY datehour DESC LIMIT 1)[OFFSET(0)] latest_row

This aggregates all rows for each unique id, sorts them by date, and selects the latest record. Next, we will select only English pages starting with the letter ‘A’:

FROM `fh-bigquery.wikipedia_v3.pageviews_2018` a
WHERE datehour BETWEEN "20/03/01" AND "20/04/30" 
AND a.page_title LIKE "A%" 
AND a.country_code="US" 
AND a.is_pageview IS NOT NULL

Lastly, we will select only the latest row for each unique id:

SELECT latest_row.* 
FROM (
  SELECT ARRAY_AGG(a ORDER BY datehour DESC LIMIT 1)[OFFSET(0)] latest_row
  FROM `fh-bigquery.wikipedia_v3.pageviews_2018` a
  WHERE datehour BETWEEN "20/03/01" AND "20/04/30" 
  AND a.page_title LIKE "A%" 
  AND a.country_code="US" 
  AND a.is_pageview IS NOT NULL
  GROUP BY a.page_title
) AS latest_rows

This selects the latest record for each unique page_title.

Scheduled Queries

To keep the view up-to-date, you can schedule the query to run periodically using BigQuery’s Scheduled Queries feature. This will replace the existing table with the latest data.

Recap

By following these steps, you can create a “materialized view” of the latest records in a BigQuery table. This will enable faster and more efficient querying of large data sets.
