How to Delete Duplicates from BigQuery Table using Standard SQL

Summary

In BigQuery, we can use Standard SQL to delete duplicate rows from a table. We can achieve this task using the ROW_NUMBER() function and the DELETE statement. In this case, we can use either of the two options:

  1. Create a new table with the non-duplicate rows
  2. Delete the duplicate rows from the original table

Approach 1: Create a new table with the non-duplicate rows

The following code creates a new table with the non-duplicate rows:

CREATE OR REPLACE TABLE `project.dataset.your_table` AS
SELECT * EXCEPT(rn)
FROM (
  SELECT *, ROW_NUMBER() OVER(PARTITION BY CallRailCallId ORDER BY CallRailCallId) rn
  FROM `project.dataset.your_table`
) 
WHERE rn = 1

The above code uses the CREATE TABLE DDL (Data Definition Language) statement to create a new table with the non-duplicate rows of the original table. In this code, we are selecting all the columns except the rn column. The rn column is created using the ROW_NUMBER() function, which assigns a row number to each row within its partition based on the specified order. In this case, the partition is the CallRailCallId column and the order is also by the CallRailCallId column. The WHERE clause filters out all rows where the rn column is greater than 1. This means that only the first row within each partition (or group) of CallRailCallId will be selected.

Approach 2: Delete the duplicate rows from the original table

The following code deletes the duplicate rows from the original table:

CREATE OR REPLACE TABLE `project.dataset.your_table` AS
SELECT row.*
FROM (
  SELECT ARRAY_AGG(t ORDER BY CallRailCallId LIMIT 1)[OFFSET(0)] row
  FROM `project.dataset.your_table` t
  GROUP BY CallRailCallId
)

The above code also uses the CREATE TABLE DDL statement. In this case, we are selecting all the columns of the original table by using the row.* syntax. The subquery within the parentheses is used to identify the non-duplicate rows. The ARRAY_AGG() function aggregates the rows into an array, and the ORDER BY clause within this function specifies the column that should be used to sort the rows within each array. The LIMIT clause within the ARRAY_AGG() function limits the number of rows within each array to 1. Lastly, the GROUP BY clause groups the rows by the CallRailCallId column.
