Update Table with Data from Another Table using Oracle SQL Updating a table with data from another table in Oracle SQL
When dealing with relational databases, at times it may be necessary to update data in one table based on data from another table. This can be achieved with an SQL update query. In this post, we will explore how to update a Oracle SQL table with data from another table.

Learning the basic syntax of an SQL update query

The basic syntax for an SQL update query is as follows:

    UPDATE table_name
    SET column1 = value1, column2 = value2, ...
    WHERE condition;
  • table_name is the table you want to update
  • column1, column2, etc. are the columns you want to update in the table
  • value1, value2, etc. are the new values that you want to set for the columns that you are updating
  • condition is a condition that specifies which rows you want to update

Updating a table’s data with data from another table in Oracle SQL

To update data in Table 1 with data from Table 2 in Oracle SQL, we can use a correlated update. The syntax for a correlated update is:

    UPDATE table1 t1
    SET (name, desc) = (SELECT t2.name, t2.desc
                        FROM table2 t2
                        WHERE t1.id = t2.id)
    WHERE EXISTS (
      SELECT 1
      FROM table2 t2
      WHERE t1.id = t2.id);
  • table1 t1 specifies the table and alias that we want to update
  • (name, desc) specifies the columns in Table 1 that we want to update with data from Table 2
  • SELECT t2.name, t2.desc FROM table2 t2 WHERE t1.id = t2.id fetches the name and desc columns for the rows in Table 2 that share the same id as the corresponding rows in Table 1
  • WHERE EXISTS (SELECT 1 FROM table2 t2 WHERE t1.id = t2.id) ensures that the update only applies to rows in Table 1 that have a matching id in Table 2

Breaking down the correlated update

To know how the correlated update works, let’s break it down line by line:

    UPDATE table1 t1
    SET (name, desc) = (SELECT t2.name, t2.desc
                        FROM table2 t2
                        WHERE t1.id = t2.id)
    WHERE EXISTS (
      SELECT 1
      FROM table2 t2
      WHERE t1.id = t2.id);

The first line specifies that we want to update Table 1 using the alias t1.

In the second line, we use the SET keyword to specify the columns that we want to update in Table 1. We use parentheses to group the columns together, and we use a subquery to fetch the corresponding values from Table 2. We specify that we want to fetch the name and desc columns from Table 2 for rows where the id in Table 2 matches the id in Table 1.

The third line specifies that we only want to update rows in Table 1 where a matching row exists in Table 2. We use the EXISTS keyword to specify a subquery that checks for the existence of a row in Table 2 with a matching id.

Alternative method for updating a table’s data with data from another table in Oracle SQL

An alternative method for updating a table’s data with data from another table in Oracle SQL is to use a relational update query. The syntax for a relational update query is:

    UPDATE (SELECT t1.id, 
                   t1.name name1,
                   t1.desc desc1,
                   t2.name name2,
                   t2.desc desc2
            FROM Table1 t1,
                 Table2 t2
            WHERE t1.id = t2.id)
    SET name1 = name2,
        desc1 = desc2;
  • (SELECT t1.id, t1.name name1, t1.desc desc1, t2.name name2, t2.desc desc2 FROM Table1 t1, Table2 t2 WHERE t1.id = t2.id) specifies a subquery that joins Table 1 and Table 2 using the id column and fetches the name and desc columns for each table
  • SET name1 = name2, desc1 = desc2; updates Table 1 using the fetched values from Table 2

Breaking down the relational update query

To know how the relational update query works, let’s break it down line by line:

    UPDATE (SELECT t1.id, 
                   t1.name name1,
                   t1.desc desc1,
                   t2.name name
                   ...2,
                   t2.desc desc2
            FROM Table1 t1,
                 Table2 t2
            WHERE t1.id = t2.id)
    SET name1 = name2,
        desc1 = desc2;

This SQL statement demonstrates a way to update multiple columns in one table with the corresponding values from another table using a join. By using a subquery to create a virtual table where data from both Table1 and Table2 is accessible, you can then update the columns in Table1 with the corresponding values from Table2.

The relational update query allows you to achieve similar results as a correlated update but provides a more readable structure when dealing with multiple columns.

Performance considerations for updating tables in Oracle SQL

When updating tables with data from other tables in Oracle SQL, you should consider performance implications, especially when working with large datasets. Here are a few key points to keep in mind:

  1. Indexes: Ensure that the columns used in the WHERE clause (e.g., t1.id = t2.id) are indexed to speed up the search and join operations.

  2. Batch updates: If you need to update a large number of rows, consider breaking the update operation into smaller batches to avoid running out of resources.

  3. Use the MERGE statement: For complex updates where you might also want to insert new data (i.e., an “upsert” operation), Oracle provides the MERGE statement. This can be more efficient than running separate INSERT and UPDATE operations.

Example of using the MERGE statement in Oracle SQL

The MERGE statement allows you to perform updates or inserts depending on whether a condition is met. Here’s an example of using the MERGE statement to update data in Table1 with data from Table2:

MERGE INTO table1 t1
USING table2 t2
ON (t1.id = t2.id)
WHEN MATCHED THEN
    UPDATE SET t1.name = t2.name,
               t1.desc = t2.desc
WHEN NOT MATCHED THEN
    INSERT (id, name, desc)
    VALUES (t2.id, t2.name, t2.desc);
  • MERGE INTO table1 t1: This specifies that we want to merge data into table1.
  • USING table2 t2: This specifies that we are using table2 as the source for the merge.
  • ON (t1.id = t2.id): This defines the condition to match rows between table1 and table2.
  • WHEN MATCHED THEN: If a match is found based on the condition, it updates the matching rows in table1 with values from table2.
  • WHEN NOT MATCHED THEN: If no match is found, it inserts a new row into table1 with values from table2.

The MERGE statement is highly efficient for scenarios where you need to update existing records and insert new records simultaneously. It’s widely used in data warehousing and other scenarios where you need to synchronize tables.

Conclusion

Updating tables with data from other tables in Oracle SQL is a common task in database management. Whether you choose to use a correlated update, a relational update, or the MERGE statement, it’s important to understand the syntax and performance considerations.

  • The correlated update works well for simple updates where you want to update a table based on matching data from another table.
  • The relational update is useful for updating multiple columns in a clean and readable manner.
  • The MERGE statement is a powerful tool for performing both updates and inserts, offering a flexible solution for data synchronization.

By understanding these techniques and applying best practices, you can efficiently manage and update your Oracle SQL databases.
