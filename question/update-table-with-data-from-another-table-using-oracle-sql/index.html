When dealing with relational databases, at times it may be necessary to update data in one table based on data from another table. This can be achieved with an SQL update query. In this post, we will explore how to update a Oracle SQL table with data from another table.

Learning the basic syntax of an SQL update query

The basic syntax for an SQL update query is as follows:

UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;
  • table_name is the table you want to update
  • column1, column2, etc. are the columns you want to update in the table
  • value1, value2, etc. are the new values that you want to set for the columns that you are updating
  • condition is a condition that specifies which rows you want to update

Updating a table’s data with data from another table in Oracle SQL

To update data in Table 1 with data from Table 2 in Oracle SQL, we can use a correlated update. The syntax for a correlated update is:

UPDATE table1 t1
SET (name, desc) = (SELECT t2.name, t2.desc
                    FROM table2 t2
                    WHERE t1.id = t2.id)
WHERE EXISTS (
  SELECT 1
  FROM table2 t2
  WHERE t1.id = t2.id);
  • table1 t1 specifies the table and alias that we want to update
  • (name, desc) specifies the columns in Table 1 that we want to update with data from Table 2
  • SELECT t2.name, t2.desc FROM table2 t2 WHERE t1.id = t2.id fetches the name and desc columns for the rows in Table 2 that share the same id as the corresponding rows in Table 1
  • WHERE EXISTS (SELECT 1 FROM table2 t2 WHERE t1.id = t2.id) ensures that the update only applies to rows in Table 1 that have a matching id in Table 2

Breaking down the correlated update

To know how the correlated update works, let’s break it down line by line:

UPDATE table1 t1
SET (name, desc) = (SELECT t2.name, t2.desc
                    FROM table2 t2
                    WHERE t1.id = t2.id)
WHERE EXISTS (
  SELECT 1
  FROM table2 t2
  WHERE t1.id = t2.id);

The first line specifies that we want to update Table 1 using the alias t1.

In the second line, we use the SET keyword to specify the columns that we want to update in Table 1. We use parentheses to group the columns together, and we use a subquery to fetch the corresponding values from Table 2. We specify that we want to fetch the name and desc columns from Table 2 for rows where the id in Table 2 matches the id in Table 1.

The third line specifies that we only want to update rows in Table 1 where a matching row exists in Table 2. We use the EXISTS keyword to specify a subquery that checks for the existence of a row in Table 2 with a matching id.
