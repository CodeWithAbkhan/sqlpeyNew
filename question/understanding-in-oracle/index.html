Understanding <> in Oracle Learning the <> Operator in Oracle SQL
The <> operator is a comparison operator used in Oracle SQL to test whether two expressions are not equal to each other. It is equivalent to the != operator used in other programming languages.

Code Explanation

The provided SQL code is using the <> operator to filter out records where the value of the ordid column is equal to 605. The SELECT statement retrieves an ordid, prodid, and qty from the item table where:

  • the prodid is in the list of prodids related to order 605
  • the qty is in the list of qtys related to order 605
  • the ordid is NOT equal to 605 ( 605)

The idea behind this code is to find records that have the same prodid and qty values as those assigned to order 605, but which are for a different order.

Code Rewrite

To make the provided code more unique, we can assign aliases to the table and column names:

SELECT i.ordid,
       i.prodid,
       i.qty
FROM   item i
WHERE  i.prodid IN (SELECT prodid
                    FROM   item
                    WHERE  ordid = 605)
       AND i.qty IN (SELECT qty
                     FROM   item
                     WHERE  ordid = 605)
       AND i.ordid  605;

Code Syntax

The SQL code follows a standard syntax:

  • The SELECT statement lists the columns to be retrieved from the item table.
  • The FROM clause specifies the table name (with alias) to retrieve data from.
  • The WHERE clause sets the conditions for the data to be selected. It includes a subquery to find related prodid and qty values for order 605, and the <> operator to filter out records with ordid equal to 605.

Practical Example

A practical example of using the <> operator is to find all customers who have placed orders but have not ordered a particular product. The code for this could be:

SELECT c.custname
FROM   customer c
       LEFT JOIN orders o ON c.custid = o.custid
       LEFT JOIN order_detail od ON o.orderid = od.orderid
       LEFT JOIN product p ON od.prodid = p.prodid
WHERE  p.prodid IS NULL;

This code uses a LEFT JOIN to retrieve all customers from the customer table, along with their orders and order details. It then joins the product table to filter out customers who have not ordered a specific product (prodid IS NULL). The <> operator can also be used to filter out specific customers or products.

Alternative Ways

The <> operator can also be written as != or NOT EQUAL. For example:

SELECT * FROM orders WHERE total != 100;
SELECT * FROM orders WHERE total NOT EQUAL TO 100;

Both of these statements are equivalent to:

SELECT * FROM orders WHERE total  100;

It is best to use the operator that is most commonly used in your organization or programming language to maintain consistency and readability.

Recap
