Generating Random UUIDs on Oracle: A Quick Guide How to generate a random UUID in Oracle using SYS_GUID

To generate a version 4 (random) UUID on Oracle, you can use the SYS_GUID function. Although, the output of SYS_GUID may not be entirely random for every system, as explained in this blog post .

If you need to ensure that you get a random UUID, you can use a Java function to generate it. Here’s an example of how to create and use a Java function to generate a random UUID:

  1. Create a Java source named “RandomUUID” and define a static method that generates a random UUID using the java.util.UUID class:

    CREATE OR REPLACE AND COMPILE JAVA SOURCE NAMED "RandomUUID" AS
import java.util.UUID;

public class RandomUUID {
    public static String generate() {
        return UUID.randomUUID().toString();
    }
}
/

  2. Create a PL/SQL function that calls the Java function:

    CREATE OR REPLACE FUNCTION random_uuid RETURN VARCHAR2 
AS LANGUAGE JAVA NAME 'RandomUUID.generate() return java.lang.String';
/

  3. Use the random_uuid function to generate a random UUID:

    SELECT random_uuid FROM dual;

    The output should be a randomly generated UUID.

Note that using SYS_GUID may already be sufficient for your needs, especially if you’re using a version of Oracle that has fixed the sequential GUID issue (as mentioned in My Oracle Support ID 1371805.1). Although, if you need to ensure that your UUIDs are completely random, using a Java function is a reliable option.

In terms of performance, the Java function may be slightly faster when used in SQL contexts, but the PL/SQL function is about twice as fast when used in a PL/SQL context. Consider your use case when deciding which method to use.

Example code

Here’s the complete example code for creating and using the random_uuid function:

-- Create Java source
CREATE OR REPLACE AND COMPILE JAVA SOURCE NAMED "RandomUUID" AS
import java.util.UUID;

public class RandomUUID {
    public static String generate() {
        return UUID.randomUUID().toString();
    }
}
/

-- Create PL/SQL function
CREATE OR REPLACE FUNCTION random_uuid RETURN VARCHAR2 
AS LANGUAGE JAVA NAME 'RandomUUID.generate() return java.lang.String';
/

-- Use function to generate random UUID
SELECT random_uuid FROM dual;

Alternative approach

If you’re unable to use Java in your Oracle environment, another option is to generate a random number and convert it to a UUID format. Here’s an example of how to do that:

-- Generate random number (between 0 and 2^32-1)
WITH random_num AS (
    SELECT DBMS_RANDOM.VALUE(0, POWER(2, 32) - 1) AS num
    FROM dual
)
-- Convert random number to UUID format
SELECT 
    TO_CHAR(UPPER(HEXTORAW(RPAD(RPAD(LTRIM(TO_CHAR(num, 'XXXXXX')), 8, '0'), 32, '0'))), 'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX') AS random_uuid
FROM random_num;

This approach converts a randomly generated number into a UUID format following the guidelines in RFC 4122 . Although, note that this approach may not be as reliable as using a Java function or SYS_GUID. Also note that performance-wise, generating a random number and converting it to a UUID format may be slower than using SYS_GUID or a Java function.]]>
