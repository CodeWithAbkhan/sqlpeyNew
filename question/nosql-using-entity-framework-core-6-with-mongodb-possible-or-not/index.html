Is it possible to use Entity Framework Core 6 with MongoDb?

As of now, there is no official MongoDb provider implementation for EF Core 6, therefore it’s not possible to use EF Core 6 with MongoDb without any workaround.

What is the Alternative Approach?

There are different approaches that you can use to work with MongoDb in .NET Core.

Using the Official MongoDB.Driver

The simplest way to work with MongoDB in .NET Core is to use the Official MongoDB.Driver that provides a low-level API for communicating with MongoDb. With this driver, you can create, read, update, and delete data from your MongoDb database.

You can install the Official MongoDB.Driver using the package manager or the .NET CLI:

dotnet add package MongoDB.Driver

The following code illustrates how to connect to a MongoDB database and create a new document:

using MongoDB.Driver;

var client = new MongoClient("mongodb://localhost:27017");
var database = client.GetDatabase("mydatabase");
var collection = database.GetCollection("mycollection");

var document = new BsonDocument
{
    { "name", "John Doe" },
    { "age", 30 }
};

collection.InsertOne(document);

This code establishes a connection to a MongoDB database on the localhost, gets the “mydatabase” database, and the “mycollection” collection. It then creates a new document and inserts it into the collection.

Using a Third-Party Provider

There are several third-party providers that you can use to work with MongoDb in .NET Core, some of which have their own Object-Document Mapping (ODM) frameworks. These providers make it easier to work with MongoDb by providing a higher-level API that abstracts away some of the low-level details.

Using Azure Cosmos DB

An alternative to MongoDB is the use of Azure Cosmos DB which is a fully managed NoSQL database service that provides support for MongoDB API.

Using Azure Cosmos DB with EF Core 6 you can design a highly available, highly performant, and globally distributed database.

You can access Azure Cosmos DB from your .NET Core application by adding the Entity Framework Core Cosmos provider using the .NET CLI or Package Manager:

dotnet add package Microsoft.EntityFrameworkCore.Cosmos

Then you can add the Cosmos DB provider to your DbContext:

services.AddDbContext(
    options => options.UseCosmos(
        "https://mycosmosaccount.documents.azure.com:443/",
        "mydatabase",
        "mycollection",
        "myaccountkey"
    )
);

This code configures the Cosmos DB provider to connect to a database and collection. The connection string includes the Cosmos DB account URI, database name, collection name, and account key.

Recap

As of now, there is no official Entity Framework Core 6 provider for MongoDB. Although, you can use the Official MongoDB.Driver, a third-party provider or Azure Cosmos DB to work with MongoDB in .NET Core.

Using Azure Cosmos DB with EF Core 6, you can design a globally distributed database with high scalability and availability.
