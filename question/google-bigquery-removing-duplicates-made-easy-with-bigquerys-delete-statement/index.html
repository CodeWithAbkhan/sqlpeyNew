In this post, we will explore how to use the DELETE statement in BigQuery to remove duplicates from a table. We will also discuss the use of the ROW_NUMBER function and the WITH clause in standard SQL.

To remove duplicates from a table in BigQuery, we can use the DELETE statement. The basic syntax of the DELETE statement is as follows:

DELETE FROM table_name WHERE condition;

Here, table_name is the name of the table from which we want to delete data, and condition is the condition that specifies the rows to be deleted. The DELETE statement can be used in standard SQL and legacy SQL.

To remove duplicates from a table, we need to identify the non-unique rows and delete them from the table. One way to do this is to use the ROW_NUMBER function with the WITH clause. The ROW_NUMBER function assigns a unique number to each row within a specified group. We can then select the rows with a row number greater than one and delete them from the table.

Here is an example of using the ROW_NUMBER function and the WITH clause to remove duplicates from a table:

WITH dup_events AS (
  SELECT
    *,
    ROW_NUMBER() OVER (PARTITION BY id ORDER BY loadTime DESC) AS rowNum
  FROM `duplicates`
)
DELETE FROM
  dup_events
WHERE rowNum > 1; ```  In this example, we first use the WITH clause to create a temporary table called `dup\_events`. We select all columns from the `duplicates` table and use the ROW_NUMBER function to add a unique row number to each row within each group of `id`. The `PARTITION BY` clause specifies the column to partition the data by (in this case, `id`), and the `ORDER BY` clause specifies the column to order the data by (in this case, `loadTime` in descending order).  We then use the DELETE statement to delete all rows from the `dup\_events` table where the row number (`rowNum`) is greater than one. This keeps only the first occurrence of each group of `id`, which is the unique value.  Although, when we try to execute the above query in the BigQuery console, we get a syntax error stating that the keyword DELETE is not expected. This is because BigQuery does not support the use of the DELETE statement with the WITH clause.  To work around this issue, we can use a different approach that uses a subquery to identify the unique rows to keep and delete the rest. Here is the revised code:  ```sql DELETE FROM `yourproject.yourdataset.duplicates` WHERE STRUCT(id, loadTime) NOT IN (         SELECT AS STRUCT id, MAX(loadTime) loadTime          FROM `yourproject.yourdataset.duplicates`          GROUP BY id); ```  In this example, we use the `NOT IN` operator to select the rows to delete. We first create a subquery that groups the data by `id` and selects the maximum `loadTime` value for each group. We then use the `STRUCT` function to combine the `id` and `loadTime` values into a single structure. We use the `AS STRUCT` keyword to ensure that the subquery returns a single row with two columns (`id` and `loadTime`) rather than two separate rows.  Lastly, we use the `NOT IN` operator to select all rows from the `duplicates` table whose `id` and `loadTime` values are not in the subquery result. This effectively removes all duplicate rows from the table, leaving only the unique rows.  In recap, we can use the DELETE statement in BigQuery to remove duplicates from a table.
