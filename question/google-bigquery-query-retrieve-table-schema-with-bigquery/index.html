How to Get BigQuery Table Schema Info via Query?
If you’re working with BigQuery, you may need to get a table schema info via query to perform some incremental updates between two tables. In this post, we’ll explore how to get BigQuery table schema info via query and generate a SQL query for incremental updates.

Query for Getting BigQuery Table Schema Info

You can get BigQuery table schema info via query by using the INFORMATION_SCHEMA.COLUMNS table. Here’s the query:

SELECT 
 TO_JSON_STRING(
    ARRAY_AGG(STRUCT( 
      IF(is_nullable="YES", 'NULLABLE', 'REQUIRED') AS mode,
      column_name AS name,
      data_type AS type)
    ORDER BY ordinal_position), TRUE) AS schema
FROM
  .INFORMATION_SCHEMA.COLUMNS
WHERE
  table_name =

This query will return the schema of the specified table in JSON format. Here’s how it works:

  • The TO_JSON_STRING function converts the result to a JSON string.
  • The ARRAY_AGG function aggregates the schema info for all columns in the table.
  • The STRUCT function defines the schema for each column.
  • The IF function sets the column mode to “NULLABLE” if the column is nullable, otherwise it sets it to “REQUIRED”.
  • The column_name and data_type columns provide the column name and data type, respectively.
  • The ORDER BY clause orders the columns by their ordinal position in the table.
  • The WHERE clause filters the results to the specified table.

Generating a SQL Query for Incremental Updates

Once you have the table schema info, you can generate a SQL query for incremental updates between two tables. The query should join the two tables on the key column and update the non-key columns based on their hash values.

Here’s an example SQL query:

UPDATE
  
SET
  column1 = staging.column1_hashed,
  column2 = staging.column2_hashed,
  column3 = staging.column3_hashed,
  ...
FROM
   AS target
JOIN (
  SELECT
    key_column,
    MD5(CONCAT(IFNULL(column1,''), IFNULL(column2,''), IFNULL(column3,''), ...)) AS column1_hashed,
    MD5(CONCAT(IFNULL(column1,''), IFNULL(column2,''), IFNULL(column3,''), ...)) AS column2_hashed,
    MD5(CONCAT(IFNULL(column1,''), IFNULL(column2,''), IFNULL(column3,''), ...)) AS column3_hashed,
    ...

ON target.key_column = staging.key_column
WHERE
  target.key_column =

Here’s how it works:

  • The UPDATE statement updates the non-key columns in the target table.
  • The SET clause assigns the hashed values from the staging table to the corresponding columns in the target table.
  • The FROM clause joins the target table with a subquery that generates the hashed values for the staging table.
  • The SELECT statement in the subquery generates the hashed values for each column by concatenating their values and hashing the result.
  • The WHERE clause filters the results to the specified key value.
