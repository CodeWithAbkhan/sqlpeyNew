How to Retrieve Records from a Database Based on Similarity of Hashes

What is the Problem?

The problem at hand is to retrieve records from a database based on the similarity between their 32-bit perceptual hashes.

What is the Solution?

The solution involves dividing the hash bit string into smaller chunks and querying for an exact match on these chunks. The returned results are then subjected to a bitwise hamming distance computation to determine the actual similarity between the queried hash and the records in the database.

How does the Solution Work?

The solution works in the following way:

  1. Create a table with four columns: each will contain an 8 bits (as a string or int) slice of the 32 bits hashes, islice 1 to 4.
  2. Slice your query hash the same way in qslice 1 to 4.
  3. Query this table such that any of qslice1=islice1 or qslice2=islice2 or qslice3=islice3 or qslice4=islice4. This gives you every DB hash that are within 3 bits (4 - 1) of the query hash. It may contain more results, and this is why there is a step 4.
  4. For each returned hash, compute the exact hamming distance pair-wise with you query hash (reconstructing the index-side hash from the four slices)

The number of operations in step 4 should be much less than a full pair-wise hamming computation of your whole table.

What is Simhash?

The approach presented is based on a technique called simhash, which was first described by Moses Charikar in a paper. Simhash is a way to construct a hash function for sets or multisets that produces a 64-bit hash value. The technique is based on the idea of shingling, which means partitioning a string into all possible substrings of a specified length called k-grams.

Alternative Ways

An alternative solution to the problem would be to use a specialized database system like Elasticsearch, which has built-in support for fuzzy search based on the Levenshtein distance or Elasticsearch’s own Damerau-Levenshtein distance. These distance metrics can be used to search for similar strings in a database.

Practical Examples

Here is an example Python code to compute the hamming distance between two 32-bit hashes:

def hamming_distance(hash1, hash2):
    """
    Compute the Hamming distance between two 32-bit hashes
    """
    x = (hash1 ^ hash2) & 0xffffffff
    set_bits = 0
    while x:
        set_bits += 1
        x &= x - 1
    return set_bits

Here is an example SQL query to retrieve all hashes within a 4-bit hamming distance from a query hash:

SELECT * FROM hashes
WHERE ((h1 & 15) = (query_h1 & 15))
OR ((h2 & 15) = (query_h2 & 15))
OR ((h3 & 15) = (query_h3 & 15))
OR ((h4 & 15) = (query_h4 & 15))
