ORACLE: Printing Variable Value in SQL Developer Printing the value of a variable in Oracle SQL Developer

If you want to print the value of a variable inside an anonymous block using Oracle SQL Developer, you can use dbms_output.put_line. Although, you need to enable the DBMS Output window to see the output.

Here’s an explanation of the code line by line:

  1. SET SERVEROUTPUT ON - turns on the DBMS Output

  2. DECLARE - starts the declaration of variables and the anonymous block

  3. CTABLE USER_OBJECTS.OBJECT_NAME%TYPE; - declares a variable named CTABLE with the same data type as OBJECT_NAME in the USER_OBJECTS table

  4. CCOLUMN ALL_TAB_COLS.COLUMN_NAME%TYPE; - declares a variable named CCOLUMN with the same data type as COLUMN_NAME in the ALL_TAB_COLS table

  5. V_ALL_COLS VARCHAR2(500); - declares a variable named V_ALL_COLS with a maximum size of 500 characters

  6. CURSOR CURSOR_TABLE - declares a cursor named CURSOR_TABLE to select table names from the USER_OBJECTS table that have a specific format in the name

  7. CURSOR CURSOR_COLUMNS - declares a cursor named CURSOR_COLUMNS to select column names from the ALL_TAB_COLS table for a specific table name

  8. BEGIN - starts the anonymous block

  9. OPEN CURSOR_TABLE - opens the CURSOR_TABLE cursor

  10. LOOP - starts a loop to fetch each table name from the CURSOR_TABLE cursor

  11. FETCH CURSOR_TABLE INTO CTABLE - fetches a table name into the CTABLE variable

  12. EXIT WHEN CURSOR_TABLE%NOTFOUND - exits the loop when there are no more table names to fetch

  13. OPEN CURSOR_COLUMNS (CTABLE); - opens the CURSOR_COLUMNS cursor for the current table name

  14. V_ALL_COLS := NULL; - resets the V_ALL_COLS variable to null

  15. LOOP - starts a loop to fetch each column name from the CURSOR_COLUMNS cursor

  16. FETCH CURSOR_COLUMNS INTO CCOLUMN; - fetches a column name into the CCOLUMN variable

  17. V_ALL_COLS := V_ALL_COLS || CCOLUMN; - concatenates the column name to the V_ALL_COLS variable

  18. IF CURSOR_COLUMNS%FOUND THEN - checks if there are more column names to fetch

  19. V_ALL_COLS := V_ALL_COLS || ‘, ‘; - adds a comma and a space to the V_ALL_COLS variable if there are more column names to fetch

  20. ELSE - exits the inner loop if there are no more column names to fetch

  21. EXIT; - exits the inner loop

  22. END IF; - ends the if statement

  23. END LOOP; - ends the inner loop

  24. DBMS_OUTPUT.PUT_LINE(V_ALL_COLS); - prints the concatenated column names for the current table using the DBMS_OUTPUT function

  25. END LOOP; - ends the outer loop

  26. CLOSE CURSOR_TABLE; - closes the CURSOR_TABLE cursor

  27. END; - ends the anonymous block

To make the code unique, you can modify the cursor queries to select tables and columns based on your specific criteria. You can also change the output format to match your requirements.

Here’s an example of how to modify the code to select tables and columns based on a specific owner:

SET SERVEROUTPUT ON

DECLARE
  CTABLE ALL_TABLES.TABLE_NAME%TYPE;
  CCOLUMN ALL_TAB_COLS.COLUMN_NAME%TYPE;
  V_ALL_COLS VARCHAR2(500);

  CURSOR CURSOR_TABLE
    IS
    SELECT TABLE_NAME 
    FROM ALL_TABLES 
    WHERE OWNER = 'MY_OWNER'
    AND TABLE_NAME LIKE 'tb_prm_%';

  CURSOR CURSOR_COLUMNS (V_TABLE_NAME IN VARCHAR2)
    IS
    SELECT COLUMN_NAME
    FROM ALL_TAB_COLS
    WHERE OWNER = 'MY_OWNER'
    AND TABLE_NAME = V_TABLE_NAME;

BEGIN
  OPEN CURSOR_TABLE;

  LOOP
    FETCH CURSOR_TABLE INTO CTABLE;
    EXIT WHEN CURSOR_TABLE%NOTFOUND;

    OPEN CURSOR_COLUMNS (CTABLE);

    V_ALL_COLS := NULL;

    LOOP
      FETCH CURSOR_COLUMNS INTO CCOLUMN;
      V_ALL_COLS := V_ALL_COLS || CCOLUMN;
      IF CURSOR_COLUMNS%FOUND THEN
        V_ALL_COLS := V_ALL_COLS || ', ';
      ELSE
        EXIT;
      END IF;
    END LOOP;

    DBMS_OUTPUT.PUT_LINE('Columns for table ' || CTABLE || ': ' || V_ALL_COLS);

  END LOOP;
  CLOSE CURSOR_TABLE;
END;

Alternative Ways:  Another way to see the output is to use a SELECT statement to query a table that stores the output. You can create a table to store the output and use the DBMS\_OUTPUT.PUT\_LINE function to insert rows in the table. Then, you can query the table to see the output.  Here's an example:  
				  

CREATE TABLE MY_OUTPUT (ID NUMBER, MESSAGE VARCHAR2(500));

DECLARE
  V_MY_MESSAGE VARCHAR2(500);
BEGIN
  V_MY_MESSAGE := 'Hello, World!';
  DBMS_OUTPUT.PUT_LINE(V_MY_MESSAGE);
  INSERT INTO MY_OUTPUT (ID, MESSAGE) VALUES (1, V_MY_MESSAGE);
  COMMIT;
END;

SELECT MESSAGE FROM MY_OUTPUT WHERE ID = 1;

This code creates a table named MY_OUTPUT to store the output and inserts a row with the output message. Then, it queries the table to see the output.
