Repeated Error Message on Tab Opening in BigQuery

Problem Description

The user is facing a recurring error message while opening new tabs or when moving between tabs in BigQuery. The error message states- “Not found: Job xxx-xx-xxxxx:EU.bquxjob_4ee13939_17b074e777e”. The error message has been persisting for the past few months, and the user is seeking a solution to resolve it.

Possible Solution

The error message indicates that the BigQuery API is not able to locate a specific job that was previously executed. This may be happening due to a local cache/setting issue on the user’s device. The following steps can be tried to resolve the issue:

  1. Clear the browser cache and cookies by going to settings and clearing browsing data.
  2. Close all the tabs and restart the browser.
  3. If the issue persists, try disabling extensions one by one and reloading the page to identify if any extension is causing the problem.
  4. If the issue still persists, try logging out and logging back into BigQuery to refresh the session.

Analysis

BigQuery is a web-based interface provided by Google for querying massive datasets in real-time using SQL-like syntax. It allows users to analyze data using familiar SQL language without the need for advanced programming skills. When a query is executed in BigQuery, the backend creates a job that gets executed asynchronously. Once the job is completed, the results get displayed on the front end. In this case, the user is encountering an error message that indicates that the BigQuery API backend is not able to find a job that was previously executed. The job ID (xxx-xx-xxxxx) that is causing the error seems to be associated with a European dataset (EU) and starts with the prefix “bquxjob_”. This indicates that the job was executed in the recent past, and the API is still trying to locate it. The fact that none of the user’s colleagues is facing the same issue indicates that it could be a local browser cache/setting issue specific to the user’s device. Clearing the cache and cookies, closing the browser, and disabling extensions may help in resolving this issue. If the problem persists, logging out and logging back in may refresh the session and resolve the issue.

Alternative Solutions

Along with the above steps, the following approaches may also help in resolving the issue:

  • Try using a different browser and see if the problem persists.
  • Try using the command-line interface of BigQuery instead of the web-based interface.
  • Contact the BigQuery support team for further assistance if the issue still persists.

Recap

The error message “Not found: Job xxx-xx-xxxxx:EU.bquxjob_4ee13939_17b074e777e” in BigQuery indicates that the API is not able to locate a previously executed job. This could be due to a local cache/setting issue on the user’s device. Clearing cache/cookies, disabling extensions, and logging out/in can help in resolving this issue. Alternately, using a different browser or command-line interface, or reaching out to support can also help in resolving the issue. ]]>
