Selecting Records from Last 24 Hours with SQL: A Guide Summary: This SQL query is used to retrieve records for the last 24 hours from a table. The specific syntax used in the query may vary depending on the database management system being used.

MySQL:

SELECT * 
FROM table_name
WHERE table_name.the_date > DATE_SUB(NOW(), INTERVAL 24 HOUR)

This query selects all columns from the table “table_name” where the “the_date” column is greater than the current date and time minus 24 hours. The query uses the DATE_SUB function to subtract 24 hours from the current date and time which is retrieved using the NOW function.

SQL Server:

SELECT * 
FROM mytable
WHERE record_date >= DATEADD(day, -1, GETDATE())

This query selects all columns from the table “mytable” where the “record_date” column is greater than or equal to the current date and time minus 24 hours. The query uses the DATEADD function to subtract 1 day (equivalent to 24 hours) from the current date and time which is retrieved using the GETDATE function.

Oracle:

SELECT * 
FROM mytable
WHERE record_date >= SYSDATE - 1

This query selects all columns from the table “mytable” where the “record_date” column is greater than or equal to the current date and time minus 24 hours. The query uses the SYSDATE function to retrieve the current date and time and subtracts 1 from it, which represents 1 day or 24 hours.

PostgreSQL:

SELECT * 
FROM mytable
WHERE record_date >= NOW() - '1 day'::INTERVAL

This query selects all columns from the table “mytable” where the “record_date” column is greater than or equal to the current date and time minus 24 hours. The query uses the NOW function to retrieve the current date and time and subtracts 1 day using the INTERVAL keyword and the ‘::’ operator.

SQLite:

SELECT * 
FROM mytable
WHERE record_date >= datetime('now','-1 day')

This query selects all columns from the table “mytable” where the “record_date” column is greater than or equal to the current date and time minus 24 hours. The query uses the datetime function to retrieve the current date and time and subtracts 1 day from it using the ‘-1 day’ parameter.

MS Access:

SELECT * 
FROM mytable
WHERE record_date >= (Now - 1)

This query selects all columns from the table “mytable” where the “record_date” column is greater than or equal to the current date and time minus 24 hours. The query uses the Now function to retrieve the current date and time and subtracts 1 day from it using the ‘-1’ parameter.

Alternative:

SELECT * 
FROM table_name
WHERE table_name.the_date >= getdate()-1

This alternative query selects all columns from the table “table_name” where the “the_date” column is greater than or equal to the current date and time minus 24 hours. The query uses the getdate function to retrieve the current date and time and subtracts 1 day from it using the ‘-1’ parameter.
