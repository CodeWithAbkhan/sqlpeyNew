How to return BigQuery table rows with a max value
If you have a BigQuery table with multiple rows and columns and you want to return the values with the max value for a specific column, you can accomplish this by grouping the data by the desired column, finding the max value for each group, and returning the rows with that max value. Here’s how to do it:

Step 1: Group the data by the desired column

The first step is to group the data by the column you want to find the max value for. This can be achieved using the GROUP BY clause in your SQL query. In our example, we want to group the data by the “Name” column:

SELECT Name, Time, Value
FROM my_table
GROUP BY Name, Time, Value

Step 2: Find the max value for each group

Next, you’ll want to find the max value for each group. You can use the MAX() function to accomplish this. In our example, we want to find the max “Time” value for each group:

SELECT Name, MAX(Time) AS max_time
FROM my_table
GROUP BY Name

Step 3: Identify the row with the max value

Lastly, you’ll want to identify the row(s) that contain the max value for each group. You can accomplish this by joining the results of Step 1 and Step 2 and comparing the “Time” column to the “max_time” column. Here’s the final SQL query:

SELECT t.Name, t.Time, t.Value
FROM my_table t
JOIN (
  SELECT Name, MAX(Time) AS max_time
  FROM my_table
  GROUP BY Name
) sq ON sq.Name = t.Name AND sq.max_time = t.Time

This query will return the row(s) with the max “Time” value for each group, grouped by the “Name” column.

Alternative Method

If you prefer to do this without the JOIN statement you can use the RANK() function to assign a rank to each row based on the “Time” column, and then only select the rows with a rank of 1 (i.e., the row with the max value). Here’s the SQL query for this alternative method:

SELECT Name, Time, Value
FROM (
  SELECT Name, Time, Value, RANK() OVER (PARTITION BY Name ORDER BY Time DESC) as rank
  FROM my_table
) t
WHERE t.rank = 1

This will return the same result as the previous method, but without the JOIN statement. ]]>
