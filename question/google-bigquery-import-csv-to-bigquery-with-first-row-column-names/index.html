GOOGLE BIGQUERY: Import CSV to BigQuery with First Row Column Names

Summary: Nick, an appscript user, wants to import a CSV file to BigQuery using columns names from the first row. Although, he is unable to specify the schema for the destination table. He asks for guidance on how to create a schema based on the column names in the first row.

Solution: There are a few ways to generate a schema from the first row of a CSV file in Google Sheets.

  1. Make a raw HTTP Request: One option is to make a raw HTTP request from AppScript to Google Cloud Storage (GCS) to read the first row of the data, split it on commas, and generate a schema from that. Although, GCS doesn’t have AppScript integration, so you need to build the requests by hand.

Apps Script does have utilities to enable making HTTP requests (e.g. UrlFetchApp.fetch()) and OAuth functionalities. Although, you need to invest a decent amount of work to get it right.

  1. Import data to a temporary table: Another option is to import the data to a temporary table as a single field and set the field delimiter to something that doesn’t exist (e.g. \r). You can then read the header row via tabledata.list() and run a query that splits up the single field up into columns with a regular expression. Setting allow_large_results and a destination table, you can get a schema.

  2. Use a dummy schema: You can also use a dummy schema with more columns than you’ll ever have and JSON.stringify() the CSV data with headers included. Then, when inserting the data into BigQuery, you can set the skipInvalidRows, ignoreUnknownValues, and maxBadRecords options.

Here’s an example code snippet for generating a schema from a CSV file using a dummy schema:

function getCSVSchema() {
  var csv = "//CSV content";
  var csvData = Utilities.parseCsv(csv);
  var header = csvData[0];
  // Generate dummy schema with more columns than you'll have
  var schema = [];
  for (var i = 0; i < header.length + 10; i++) {
    schema.push({name: "field" + i, type: "STRING"});
  }
  // JSON.stringify the CSV data with headers included
  var rows = [];
  for (var row = 1; row < csvData.length; row++) {
    var csvRow = csvData[row];
    var obj = {};
    for (var col = 0; col < header.length; col++) {
      obj[header[col]] = csvRow[col];
    }
    rows.push(obj);
  }
  var csvString = JSON.stringify(rows);
  return schema;
}

This method generates a dummy schema with more columns than the actual data will have. Then, using Utilities.parseCsv(), you can parse the CSV data and get header from the first row. You can use a for loop to push the name (e.g. field0) and type (e.g. STRING) object to the schema array. Lastly, using JSON.stringify() and a for loop with obj[header[col]] = csvRow[col], you can push the rows into an array and stringify it, which gives the CSV data including headers.

Alternative Ways: Instead of generating a schema from scratch, you can manually specify the schema using BigQuery.Schema() method, which sets the column names, types, descriptions, and modes. Although, this method requires prior knowledge of the dataset.

Another option is to use Google’s Dataflow, which can automatically detect the schema from the CSV headers. This option might be more suitable for bigger projects with larger datasets.

In Recap: Generating a schema from the first row of a CSV file is possible using a few different methods. Using a dummy schema, importing data to a temporary table, and making a raw HTTP request are some of the most common ways to do so. You can choose the one that works best for you based on your requirements.]]>
