ORACLE: Oracle DATE vs TIMESTAMP: Understanding the Differences Difference between Oracle DATE and TIMESTAMP

Introduction

Oracle database offers several datatypes for storing date and time values. Two of the most commonly used types are DATE and TIMESTAMP. While both data types can store date and time, there are differences between them. In this Q&A Session, we will explore the differences between Oracle DATE and TIMESTAMP data types, their corresponding types in Java and some sample code for better knowing.

Oracle DATE vs TIMESTAMP

DATE and TIMESTAMP are both used for storing date and time components. Although, TIMESTAMP has an additional feature of storing fractional seconds and fractional seconds with timezone, which is not available in DATE. TIMESTAMP was introduced by ANSI as the standard datatype for date and time in Oracle databases. Therefore, if precision in time is a requirement, use TIMESTAMP, otherwise, use DATE.

Corresponding Data Types in Java

The java.sql package provides classes that represent DATE, TIME, and TIMESTAMP data types. The oracle.sql.DATE class from Oracle JDBC driver provides conversion methods between the Oracle DATE/Timestamp data type and Java classes java.sql.Date, java.sql.Time, and java.sql.Timestamp.

Java Code Example

Here is an example of how we can retrieve values of DATE and TIMESTAMP columns from an Oracle database table in Java:

import java.sql.*;

public class OracleDateExample {

   public static void main(String[] args) {

      Connection conn = null;
      Statement stmt = null;
      ResultSet rs = null;

      try {
         Class.forName("oracle.jdbc.driver.OracleDriver");
         conn = DriverManager.getConnection("jdbc:oracle:thin:@localhost:1521:ORCL", "username", "password");

         stmt = conn.createStatement();
         rs = stmt.executeQuery("SELECT ORDER_DATE, DELIVERY_DATE FROM ORDERS");

         while(rs.next()) {
            java.sql.Date orderDate = rs.getDate("ORDER_DATE");
            java.sql.Timestamp deliveryDate = rs.getTimestamp("DELIVERY_DATE");

            System.out.println("Order Date: " + orderDate.toString());
            System.out.println("Delivery Date: " + deliveryDate.toString());
         }
      } 
      catch (ClassNotFoundException e) {
         System.out.println("Driver not found: " + e.getMessage());
      } 
      catch (SQLException e) {
         System.out.println("SQL Exception: " + e.getMessage());
      } 
      finally {
         try {
            if (rs != null) rs.close();
            if (stmt != null) stmt.close();
            if (conn != null) conn.close();
         } 
         catch (SQLException e) {}
      }
   }
}

Here, we are connecting to an Oracle database using JDBC driver and retrieving values of ORDER_DATE and DELIVERY_DATE columns from the ORDERS table. The getDate() method returns a java.sql.Date object representing the DATE column value, while the getTimestamp() method returns a java.sql.Timestamp object representing the TIMESTAMP column value.

Supported Functions

Oracle provides several functions for manipulating date and time values. Here are some of the supported functions:

ADD_MONTHS(date, n) - Adds n months to the given date

LAST_DAY(date) - Returns the last day of the given month

MONTHS_BETWEEN(date1, date2) - Returns the number of months between two dates

SYSDATE - Returns the current system date and time

SQL Code Example

Here is an example of how we can use the above functions in SQL:

SELECT ADD_MONTHS(SYSDATE, 3) AS "THREE_MONTHS_LATER" FROM DUAL;
SELECT MONTHS_BETWEEN('01-JAN-2022', '01-JAN-2021') AS "MONTHS_DIFFERENCE" FROM DUAL;
SELECT LAST_DAY('01-JAN-2022') AS "LAST_DAY_OF_MONTH" FROM DUAL;

These queries will return the respective output of each function.

Recap

Oracle DATE and TIMESTAMP data types offer several features for storing date and time values. While both data types have their advantages, TIMESTAMP is preferred when precision in time is a requirement. In Java, we can use the corresponding classes from the java.sql package to retrieve and manipulate these values. We can also use Oracle’s built-in functions to perform date and time operations. ]]>
