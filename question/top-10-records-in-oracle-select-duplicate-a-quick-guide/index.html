Solution: To select the top 10 records ordered by STORAGE_DB and not in the list from another select statement, you can use a subquery. The subquery will contain the current query, and the outer query will limit the result to the top 10 records and order them by STORAGE_DB.

Here’s the modified query:

SELECT *
FROM (
    SELECT DISTINCT 
        APP_ID, 
        NAME, 
        STORAGE_GB, 
        HISTORY_CREATED, 
        TO_CHAR(HISTORY_DATE, 'DD.MM.YYYY') AS HISTORY_DATE  
    FROM HISTORY
    WHERE STORAGE_GB IS NOT NULL 
        AND APP_ID NOT IN (SELECT APP_ID
                           FROM HISTORY
                           WHERE TO_CHAR(HISTORY_DATE, 'DD.MM.YYYY') = '06.02.2009') 
    ORDER BY STORAGE_GB DESC
)
WHERE ROWNUM <= 10

Since the subquery has the ORDER BY clause, the records will be ordered by STORAGE\_GB before limiting the result to the top 10 records. - Line 11: This limits the result to the top 10 records.  Alternatively, you can use the RANK() function to get the top 10 records. Here's how the query would look like:  
				  

SELECT APP_ID, NAME, STORAGE_GB, HISTORY_CREATED, HISTORY_DATE
FROM (
    SELECT APP_ID, NAME, STORAGE_GB, HISTORY_CREATED, TO_CHAR(HISTORY_DATE, 'DD.MM.YYYY') AS HISTORY_DATE,
        RANK() OVER (ORDER BY STORAGE_GB DESC) rnk
    FROM HISTORY
    WHERE STORAGE_GB IS NOT NULL 
        AND APP_ID NOT IN (SELECT APP_ID
                           FROM HISTORY
                           WHERE TO_CHAR(HISTORY_DATE, 'DD.MM.YYYY') = '06.02.2009') 
)
WHERE rnk <= 10

In this query, we’re using the RANK() function to assign a rank to each record based on the order of STORAGE_GB. The outer query then selects the top 10 records by filtering the records with ranks less than or equal to 10. Recap: To select the top 10 records ordered by a specific field, you can use a subquery or RANK() function. The subquery approach works well when you have a large dataset since it only retrieves what’s needed. On the other hand, the RANK() function is useful when you need more control over how the records are ranked.
