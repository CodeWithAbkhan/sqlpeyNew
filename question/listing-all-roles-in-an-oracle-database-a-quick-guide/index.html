Listing All Roles in an Oracle Database: A Quick Guide Listing All Roles in Oracle Database
Listing all roles in an Oracle database is an essential requirement for database administrators as it helps them to manage the granted privileges and roles of the users. In this blog post, we will discuss how to list all the roles existing in an Oracle database.

Using SQL Commands to List All Roles

There are a few SQL commands that can be used to retrieve a list of all the roles in an Oracle database:

  • SELECT * FROM DBA_ROLES;
  • SELECT * FROM ROLE_TAB_PRIVS;
  • SELECT * FROM ROLE_SYS_PRIVS;
  • SELECT * FROM ROLE_ROLE_PRIVS;

These commands can be executed in SQLPlus or any other SQL client. Although, if you want to see a more detailed list of roles and their granted privileges, you can use the following script:

The all_roles.sql Script

SELECT SUBSTR(TRIM(rtp.role),1,12) AS ROLE
     , SUBSTR(rp.grantee,1,16)        AS GRANTEE
     , SUBSTR(TRIM(rtp.privilege),1,12)     AS PRIVILEGE
     , SUBSTR(TRIM(rtp.owner),1,12)         AS OWNER
     , SUBSTR(TRIM(rtp.table_name),1,28)    AS TABLE_NAME
     , SUBSTR(TRIM(rtp.column_name),1,20)   AS COLUMN_NAME
     , SUBSTR(rtp.common,1,4)               AS COMMON
     , SUBSTR(rtp.grantable,1,4)            AS GRANTABLE
     , SUBSTR(rp.default_role,1,16)         AS DEFAULT_ROLE
     , SUBSTR(rp.admin_option,1,4)          AS ADMIN_OPTION
  FROM role_tab_privs rtp
  LEFT JOIN dba_role_privs rp
    ON (rtp.role = rp.granted_role)
 WHERE ('&1' IS NULL OR UPPER(rtp.role) LIKE UPPER('%&1%'))
   AND ('&2' IS NULL OR UPPER(rp.grantee) LIKE UPPER('%&2%'))
   AND ('&3' IS NULL OR UPPER(rtp.table_name) LIKE UPPER('%&3%'))
   AND ('&4' IS NULL OR UPPER(rtp.owner) LIKE UPPER('%&4%'))
 ORDER BY 1,2,3,4;

Script Explanation:

The script above retrieves a detailed list of roles, privileges, and grants in an Oracle database. Here is an explanation of each line:

  • SUBSTR(TRIM(rtp.role),1,12) AS ROLE: Retrieves the name of the role and removes any trailing spaces.
  • SUBSTR(rp.grantee,1,16) AS GRANTEE: Retrieves the name of the user to whom the role is granted and limits it to 16 characters.
  • SUBSTR(TRIM(rtp.privilege),1,12) AS PRIVILEGE: Retrieves the privilege granted to the role and removes any trailing spaces.
  • SUBSTR(TRIM(rtp.owner),1,12) AS OWNER: Retrieves the owner of the object to which the privilege was granted and removes any trailing spaces.
  • SUBSTR(TRIM(rtp.table_name),1,28) AS TABLE_NAME: Retrieves the name of the table associated with the privilege and limits it to 28 characters.
  • SUBSTR(TRIM(rtp.column_name),1,20) AS COLUMN_NAME: Retrieves the name of the column associated with the privilege and limits it to 20 characters.
  • SUBSTR(rtp.common,1,4) AS COMMON: Retrieves whether the privilege is common to all schemas in the database as a Y or N value.
  • SUBSTR(rtp.grantable,1,4) AS GRANTABLE: Retrieves whether the privilege is grantable as a Y or N value.
  • SUBSTR(rp.default_role,1,16) AS DEFAULT_ROLE: Retrieves the default role of the user to whom the role was granted and limits it to 16 characters.
  • SUBSTR(rp.admin_option,1,4) AS ADMIN_OPTION: Retrieves whether the user has administrative options as a Y or N value.
  • FROM role_tab_privs rtp: Specifies the role_tab_privs table from where to retrieve role privileges.
  • LEFT JOIN dba_role_privs rp ON (rtp.role = rp.granted_role): Specifies the dba_role_privs table and joins it with role_tab_privs to retrieve the user to whom the role has been granted.
  • WHERE ('&1' IS NULL OR UPPER(rtp.role) LIKE UPPER('%&1%')): Filters based on the role name, which is retrieved as the first parameter. The parameter can have a value, or it can be null.
  • AND ('&2' IS NULL OR UPPER(rp.grantee) LIKE UPPER('%&2%')): Filters based on the grantee name, which is retrieved as the second parameter. The parameter can have a value, or it can be null. ]]>
