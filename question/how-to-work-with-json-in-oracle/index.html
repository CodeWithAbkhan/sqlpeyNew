How to Work with JSON in Oracle

If you want to work with JSON within Oracle, there are several options available. One way is to use Oracle’s built-in JSON features supported from version 12.1.0.2 onwards. Alternatively, you can use third-party libraries such as APEX_JSON, JSON_OBJECT_T, and JSON_TABLE. In this Q&A Session, we will discuss how to use Oracle’s built-in JSON features to work with JSON data.

Converting CLOB to JSON Object

Suppose you have a CLOB response from a URI, and you want to convert it to a JSON object to work with it easily. Here’s how you can do it:

DECLARE
   l_clob CLOB := '{"name": "John", "age": 30, "city": "New York"}';
   l_json JSON_OBJECT_T;
BEGIN
   l_json := JSON_OBJECT_T.PARSE(l_clob);
   DBMS_OUTPUT.PUT_LINE(l_json.getString('name'));
   DBMS_OUTPUT.PUT_LINE(l_json.getNumber('age'));
   DBMS_OUTPUT.PUT_LINE(l_json.getString('city'));
END;
/

In the above code, we first declare a CLOB variable named “l_clob” and initialize it with the JSON data. Then we create a JSON_OBJECT_T object “l_json” and parse the CLOB data using the “PARSE” method. This method parses the CLOB data and returns a JSON_OBJECT_T object.

Once we have the JSON object, we can use various methods to extract values from it. In this example, we use the “getString” method to get the value of the “name” element, the “getNumber” method to get the value of the “age” element, and the “getString” method to get the value of the “city” element.

Converting JSON Object to CLOB

If you want to convert a JSON object to a CLOB, you can use the “STRINGIFY” method of the JSON_OBJECT_T object. Here’s an example:

DECLARE
   l_json JSON_OBJECT_T := JSON_OBJECT_T();
   l_clob CLOB;
BEGIN
   l_json.PUT('name', 'John');
   l_json.PUT('age', 30);
   l_json.PUT('city', 'New York');
   l_clob := l_json.STRINGIFY;
   DBMS_OUTPUT.PUT_LINE(l_clob);
END;
/

In this example, we first create an empty JSON object “l_json” using the JSON_OBJECT_T constructor. Then we add elements to it using the “PUT” method. Lastly, we convert the JSON object to a CLOB using the “STRINGIFY” method and assign it to the “l_clob” variable.

Working with JSON Arrays

JSON arrays are similar to regular arrays in programming languages. You can use the JSON_ARRAY_T object to work with JSON arrays in Oracle. Here’s an example:

DECLARE
   l_json JSON_OBJECT_T := JSON_OBJECT_T();
   l_array JSON_ARRAY_T := JSON_ARRAY_T();
BEGIN
   l_array.append('John');
   l_array.append('Doe');
   l_array.append('New York');
   l_json.PUT('name', l_array);
   DBMS_OUTPUT.PUT_LINE(l_json.getString('name[0]'));
   DBMS_OUTPUT.PUT_LINE(l_json.getString('name[1]'));
   DBMS_OUTPUT.PUT_LINE(l_json.getString('name[2]'));
END;
/

In this example, we first create a JSON_OBJECT_T object “l_json” and a JSON_ARRAY_T object “l_array”. Then we add three elements to the array using the “append” method. Lastly, we add the array to the JSON object using the “PUT” method.

To access elements of the array, we use the square brackets notation with the element index. For example, “name[0]” represents the first element of the array.

FAQs of Working with JSON in Oracle:

What are the options for working with JSON in Oracle?

Answer: In Oracle, you can work with JSON using built-in features introduced from version 12.1.0.2 onwards. Additionally, third-party libraries such as APEX_JSON, JSON_OBJECT_T, and JSON_TABLE are available.

How do I convert a CLOB to a JSON object in Oracle?

Answer: To convert a CLOB to a JSON object in Oracle, you can use the JSON_OBJECT_T.PARSE method. This method parses the CLOB data and returns a JSON_OBJECT_T object that can be further processed.

How can I convert a JSON object to a CLOB in Oracle?

Answer: To convert a JSON object to a CLOB in Oracle, you can use the STRINGIFY method of the JSON_OBJECT_T object. This method returns the JSON object as a CLOB.

How do I work with JSON arrays in Oracle?

Answer: JSON arrays in Oracle can be handled using the JSON_ARRAY_T object. You can use methods like append to add elements to the array and access elements using the square brackets notation with the element index.

What is the significance of the '/' at the end of the code block in Oracle?

Answer: In Oracle, the ‘/’ symbol is often used to execute the SQL or PL/SQL command entered so far. It acts as a statement terminator and executes the previous command or block.

Are there alternative ways to work with JSON in Oracle?

Answer: Yes, besides Oracle’s built-in JSON features, you can explore third-party libraries such as APEX_JSON, JSON_OBJECT_T, and JSON_TABLE for additional functionalities and flexibility.
