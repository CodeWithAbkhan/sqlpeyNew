BigQuery Merge - Insert new rows if not matched with NULL values handling

Introduction

Google BigQuery is a amazing cloud-based data warehouse that can handle large amounts of data. It provides a simple SQL-like language to insert, update, and delete data. One of the operations that is commonly used in ETL pipelines is a merge operation. This merge operation is used to update existing rows or insert new rows based on certain conditions.

In this post, we will explore how to perform a merge operation in BigQuery to insert new rows if they are not matched. We will also see how to handle NULL values in the merge condition.

Code Explanation

Let’s start by looking at the merge query to insert new rows if they are not matched:

MERGE DS.Target T
USING DS.Source S
ON T.A = S.A and T.B = S.B and T.C = S.C
WHEN NOT MATCHED THEN
INSERT ROW

In the above query, we are merging the DS.Target table with the DS.Source table. We are specifying the merge condition in the ON clause. The merge condition is used to match the rows in the DS.Target table with the rows in the DS.Source table.

The WHEN NOT MATCHED THEN INSERT ROW clause is used to insert a new row in the DS.Target table when there is no match found for the merge condition.

Now let’s see how we can handle NULL values in the merge condition. We cannot use the standard comparison operator (=) to compare NULL values. We can use the IS NULL operator to check if a value is NULL.

One way to handle NULL values is to check if both values are NULL in the ON clause. Here is an example:

MERGE DS.Target T
USING DS.Source S
ON ((T.A IS NULL AND S.A IS NULL) OR T.A = S.A) AND ((T.B IS NULL AND S.B IS NULL) OR T.B = S.B) AND ((T.C IS NULL AND S.C IS NULL) OR T.C = S.C)
WHEN NOT MATCHED THEN
INSERT ROW

In the above query, we are checking if the values of columns A, B, and C are both NULL or equal in the merge condition. If both values are NULL, then we consider them as a match.

Although, this code can be lengthy and difficult to modify. An alternative way is to use the COALESCE function to replace NULL values with a default value before comparing them. For example:

MERGE DS.Target T
USING DS.Source S
ON COALESCE(T.A, 'NA') = COALESCE(S.A, 'NA') AND COALESCE(T.B, 'NA') = COALESCE(S.B, 'NA') AND COALESCE(T.C, 'NA') = COALESCE(S.C, 'NA')
WHEN NOT MATCHED THEN
INSERT ROW

In the above query, we are using the COALESCE function to replace NULL values in columns A, B, and C with the default value ‘NA’ before comparing them. This makes the code simpler and easier to read.
