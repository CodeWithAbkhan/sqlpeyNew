How to impersonate a user outside your domain in BigQuery

Problem

As a BigQuery service account, you want to impersonate a user outside your domain, but you are getting “Client is unauthorized to retrieve access tokens using this method, or client not authorized for any of the scopes requested” error.

Solution

To impersonate a user outside your domain in BigQuery, you need to delegate domain-wide authority to the service account.

Step 1:

Create a service account in the Google Cloud Console and give it the “Service Account User” role.

Step 2:

Add the service account to the IAM permissions of the user’s BigQuery account with “BigQuery Editor” and “BigQuery Job User” roles.

Step 3:

Go to https://admin.google.com/ac/owl/domainwidedelegation and delegate domain-wide authority to the service account by following these steps:

  1. Click on “Add new” button.
  2. Enter the Client ID of your service account. You can find it in the Google Cloud Console in the “Service Accounts” section.
  3. Select the OAuth scopes you need. For example, select “https://www.googleapis.com/auth/bigquery" to access BigQuery data.
  4. Save changes.

Once you have delegated domain-wide authority to the service account, you can impersonate any user outside your domain using the service account’s credentials.

Here’s the code to authenticate a BigQuery service account and impersonate a user:

from google.oauth2 import service_account
from google.cloud import bigquery

# Path to the service account key file.
KEY_PATH = "/path/to/service-account-key.json"

# User email to impersonate
USER_EMAIL = "user@example.com"

# Authenticate the service account.
creds = service_account.Credentials.from_service_account_file(
    KEY_PATH,
    scopes=["https://www.googleapis.com/auth/bigquery"],
)

# Impersonate a user.
creds = creds.with_subject(USER_EMAIL)

# Create a BigQuery client.
client = bigquery.Client(credentials=creds, project=creds.project_id)

# Use the BigQuery client to access the user's data.
query = "SELECT COUNT(*) AS count FROM mydataset.mytable"
query_job = client.query(query)
results = query_job.result()

for row in results:
    print(row.count)

In this code, you first authenticate the service account using the key file and OAuth scopes. Then you impersonate the user by calling creds.with_subject(USER_EMAIL), where USER_EMAIL is the email address of the user you want to impersonate.

Lastly, you create a BigQuery client using the authenticated and impersonated credentials, and use it to run a query and retrieve the results.

Alternative
