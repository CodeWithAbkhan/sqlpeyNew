How to Shard a BigQuery Table?

Introduction

If you are working with BigQuery, you may have come across situations where you need to split or shard a large table. Sharding, in simple terms, is the process of dividing a large table into smaller, more manageable ones. In this post, we will look at two examples of how to shard a BigQuery table, and the various ways to do it efficiently.

Example 1: Sharding by Date

Let’s assume we have a table named ‘TableAll’ with timestamped data (UNIX timestamp), and we want to split this table into smaller tables by day:

Row a   b   c        timestamp
1   1   11  12       1564546800
2   1   13  14       1564546801 
3   1   15  16       1564633200
4   1   17  18       1564633201
5   2   21  22       1564719600
6   2   23          1564719601

The naive approach would be to load the data into the table and then run queries to get all the data for each day and append it into the appropriate shard. Although, this method is inefficient, as it results in queries that touch N x [size of the whole table] data, where N is the number of days in the table.

The better approach is to use table partitioning by date. To do this, follow these steps:

Step 1: Create a Partitioned Table

Create a new partitioned table using the ‘TableAll’ table schema:

CREATE TABLE mydataset.TableByDay
PARTITION BY DATE(timestamp)
OPTIONS(
  expiration_timestamp=TIMESTAMP_ADD(CURRENT_TIMESTAMP(), INTERVAL 10 YEAR),
  description="One day partitioned table")
AS
SELECT *
FROM mydataset.TableAll
WHERE 1=2

In the above code, we create a new partitioned table ‘TableByDay’, partitioned by date (the PARTITION BY DATE(timestamp) clause). We also set an expiration timestamp to ensure that the table is deleted automatically after 10 years. We select all the columns from the ‘TableAll’ table and use the WHERE clause to ensure that we do not copy any data into the new table.

Step 2: Copy Data into the Partitioned Table

Next, we can copy the data from ‘TableAll’ into ‘TableByDay’ using the INSERT statement:

INSERT INTO mydataset.TableByDay (a,b,c,timestamp)
SELECT a,b,c,timestamp
FROM mydataset.TableAll

In the above code, we insert data into the ‘TableByDay’ table and select the columns from the ‘TableAll’ table that we want to copy.

Once the data is inserted, the ‘TableByDay’ table is automatically partitioned by date. We can run queries on the table for each day without having to scan the entire table.

Step 3: Delete the Old Table

Lastly, we can delete the old ‘TableAll’ table:

DROP TABLE mydataset.TableAll

Once the old table is deleted, we can run queries on the new ‘TableByDay’ table efficiently.
