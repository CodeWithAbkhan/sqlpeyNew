Changing the datatype of a field in a Bigquery table
When working with data, it is common to have a need to change the datatype of a field in a Bigquery table. For example, you may need to convert an Integer field to a String or a Float field, etc.

Learning the current and required table structure

Before converting datatypes, it’s important to know the current and required table structure. In this example, our current table structure is as follows:

Name:String , FlatNumber:Integer,Address:String, Amount:Integer

And we want to upgrade our table to the following structure:

Name:String , FlatNumber:String, Address:String, Amount:Float

Transforming data to new table structure

In order to convert the data, we need to transform the values in the table and write the results to a new table. Below is the SQL query to accomplish this:

#standardSQL
SELECT
  Name,
  CAST(FlatNumber AS STRING) AS FlatNumber,
  Address,
  CAST(Amount AS FLOAT64) AS Amount
FROM YourTable;

This query will SELECT all values from the YourTable and perform the following actions:

  • Keep the Name and Address columns
  • Use CAST function to convert FlatNumber to String datatype
  • Use CAST function to convert Amount to Float64 datatype

Copying table to overwrite the original table

Once the data has been transformed and written to a new table, we need to copy it back to overwrite the original table. We can use bq cp command to do this.

Example:

If the name of the new table is “YourTableNew”, the command to copy the table would look like:

bq cp YourTableNew YourTable --overwrite

This command will copy the data from YourTableNew and overwrite the original data in YourTable.

Alternative Way

If you have more columns than just Name, FlatNumber, Address, and Amount, you can use SELECT * with EXCEPT or REPLACE to avoid listing all the columns:

#standardSQL
SELECT * EXCEPT(FlatNumber, Amount),
  CAST(FlatNumber AS STRING) AS FlatNumber,
  CAST(Amount AS FLOAT64) AS Amount
FROM YourTable;

This query will SELECT all values from the YourTable and perform the following actions:

  • Use SELECT * to keep all columns except for FlatNumber and Amount
  • Use CAST function to convert FlatNumber to String datatype
  • Use CAST function to convert Amount to Float64 datatype

Recap

Changing the datatype of a field in a Bigquery table is a common task when dealing with data. In this example, we have seen how to convert the datatype of a field from Integer to String or Float using the CAST() function and how to copy the data to a new table to overwrite the original data using bq cp
