Retrieving Month and Year from SQL Date How to Extract Month and Year Only from a SQL DATE Field?

To extract only month and year from a SQL DATE field, there are several ways to achieve this. We will discuss some of the popular methods to solve this problem.

Method 1: Using MONTH() and YEAR() Functions

The simplest and most straightforward method to get the month and year from a SQL DATE field is to use the MONTH() and YEAR() functions. Here, we will use these functions to extract the month and year separately from the date field.

Syntax:

SELECT MONTH(DateField) as Month, YEAR(DateField) as Year FROM TableName

Example:

SELECT MONTH(DateOfBirth) as Month, YEAR(DateOfBirth) as Year FROM EmployeesTable

Output:

Month   |   Year
-----------------
3       |   1990
6       |   1988
9       |   1995

Method 2: Using DATEPART() Function

The DATEPART() function is another way to extract the year and month from a SQL DATE field. This function returns the specified part of the date.

Syntax:

SELECT DATEPART(year, DateField) as Year, DATEPART(month, DateField) as Month FROM TableName

Example:

SELECT DATEPART(year, HireDate) as Year, DATEPART(month, HireDate) as Month FROM EmployeesTable

Output:

Year    |   Month
------------------
2010    |   6
2009    |   3
2012    |   9

Method 3: Using CONVERT() Function

The CONVERT() function is another way to extract month and year from a SQL DATE field. We can use the CONVERT() function to convert the date into a specific format and then extract month and year from it.

Syntax:

SELECT CONVERT(nvarchar(7), DateField, 126) as 'Year-Month' FROM TableName

Example:

SELECT CONVERT(nvarchar(7), OrderDate, 126) as 'Year-Month' FROM OrdersTable

Output:

Year-Month
----------
2012-06
2013-08
2014-01

Method 4: Using DATEADD() and DATEDIFF() Functions

The DATEADD() and DATEDIFF() functions are also used to extract the year and month from a SQL DATE field. Here, we will use the DATEADD() function to add the difference between the month and year dates and the base date (0) and then extract only the year and month part from it.

Syntax:

SELECT DATEADD(Month, DATEDIFF(Month, 0, DateField), 0) as YearMonth FROM TableName

Example:

SELECT DATEADD(Month, DATEDIFF(Month, 0, SaleDate), 0) as YearMonth FROM SalesTable

Output:

YearMonth
---------
2012-11-01
2013-05-01
2014-02-01

Recap

We have discussed several methods to extract only month and year from a SQL DATE field. Each method has its advantages, and the choice of method depends on the specific requirements and database system. But the most common and straightforward method is to use the MONTH() and YEAR() functions.]]>
