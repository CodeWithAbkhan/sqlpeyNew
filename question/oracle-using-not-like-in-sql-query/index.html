ORACLE: Using ‘NOT LIKE’ in SQL Query Learning the ‘NOT LIKE’ Operator in SQL Query
When querying a database, we often need to search for specific data that matches certain criteria. We may also need to exclude certain data that does not meet our criteria. This is where the SQL ‘NOT LIKE’ operator comes into play. The ‘NOT LIKE’ operator allows us to search for data that does not match a specific pattern or string.

How to Use the ‘NOT LIKE’ Operator in SQL

The syntax for using the ‘NOT LIKE’ operator in SQL is as follows:

SELECT column_name(s)
FROM table_name
WHERE column_name NOT LIKE pattern;

In this syntax, ‘column_name’ represents the column you want to search, ’table_name’ represents the table you want to search within, and ‘pattern’ represents the pattern or string you want to exclude.

For example, let’s say we have a “transactions” table with an “id” column, and we want to exclude any transactions with an ID that begins with “1” or “2”. We can use the following SQL query:

SELECT * FROM transactions WHERE id NOT LIKE '1%' AND id NOT LIKE '2%'

In this query, we’re selecting all columns and data from the “transactions” table where the “id” column does not begin with “1” or “2”.

Explanation of the Query Line by Line

Let’s break down the SQL query we used as an example:

SELECT * FROM transactions WHERE id NOT LIKE '1%' AND id NOT LIKE '2%'
  • SELECT: This command selects the columns you want to retrieve from the table. In this case, we’re selecting all columns and data from the “transactions” table.
  • *: The asterisk (*) is a wildcard that represents all columns in the table.
  • FROM: This command specifies the table you want to query. In this case, it’s the “transactions” table.
  • WHERE: This command filters the data based on a specific condition. In our case, we’re filtering data based on whether or not it matches the ‘NOT LIKE’ pattern we specified.
  • id: This is the name of the column we’re searching within the “transactions” table.
  • NOT LIKE: This operator specifies that we want to exclude any data that matches a specific pattern.
  • ‘1%’: This is the pattern we want to exclude. Specifically, we want to exclude any data that begins with the number 1.
  • AND: This operator joins multiple conditions together. In our case, we want to exclude data that begins with both 1 AND 2, so we use the AND operator to connect the two conditions together.
  • ‘2%’: This is the second pattern we want to exclude. Specifically, we’re excluding any data that begins with the number 2.

Alternative Ways to Use ‘NOT LIKE’ in SQL

There are a few other ways you can use the ‘NOT LIKE’ operator in SQL:

  • Using ‘NOT’ with ‘LIKE’: Instead of using ‘NOT LIKE’, you can use the ‘NOT’ operator followed by the ‘LIKE’ operator to achieve the same results. For example:

      SELECT * FROM transactions WHERE NOT (id LIKE '1%' OR id LIKE '2%')

  • Using ‘!=’: You can also use the ‘!=’ operator to exclude certain values. For example:

      SELECT * FROM transactions WHERE id != '100'

Recap

The ‘NOT LIKE’ operator in SQL is a useful way to exclude data that does not match a specific pattern or string. By using this operator, you can refine your SQL queries to find only the data that meets your specific criteria. ]]>
