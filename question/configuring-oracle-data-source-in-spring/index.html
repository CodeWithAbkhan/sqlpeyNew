Configuring Oracle Data-Source in Spring Oracle Data-Source Configuration for Spring Framework
In this blog post, we will discuss how to configure Oracle data-source in a Spring framework project. Oracle is one of the most popular and widely used RDBMS (Relational Database Management System) which plays a vital role in modern enterprise applications.

Oracle JDBC Driver

Before diving into the data-source configuration process, let’s discuss how to add the Oracle JDBC driver to the project. Unlike many other Java libraries, the Oracle driver is not available in the Maven repository. So, we have to download it from the official Oracle website.

To download the Oracle JDBC driver, visit the following link: http://www.oracle.com/technetwork/database/features/jdbc/default-2280470.html . On this page, you will see a list of available driver versions. Select the appropriate version and download it.

Once the driver is downloaded, you have to install it into your local Maven repository. To do this, open the command prompt and run the following command:

mvn install:install-file -Dfile=path/to/ojdbc.jar -DgroupId=com.oracle -DartifactId=ojdbc -Dversion=19.3.0.0 -Dpackaging=jar

Here, replace the path/to/ojdbc.jar with the actual path of the downloaded driver. Also, modify the version number according to the downloaded driver version.

Now, let’s move into the discussion of configuring the Oracle data-source in the Spring framework.

Oracle Data-Source Configuration Steps

We can configure the data-source in two ways - using XML configuration and using properties file configuration. Let’s discuss both approaches one by one.

Oracle Data-Source Configuration using XML

The URL property is the most important property here. It contains the Oracle database connection URL, which has the following syntax:

Oracle Data-Source Configuration using Properties File

In this approach, we have to define the Oracle data-source properties in the application.properties file. Here’s an example:

spring.datasource.url=jdbc:oracle:thin:@localhost:1521:xe
spring.datasource.username=hr
spring.datasource.password=hr
spring.datasource.driver-class-name=oracle.jdbc.driver.OracleDriver

Here, the url property contains the same connection URL we used in the previous approach. The username and password properties contain the login credentials for the Oracle database. The driver-class-name property is optional and specifies the Oracle driver class name (which is required if the driver is not found automatically).

To use this data-source in our Spring application, we have to inject it in the application configuration class as follows:

@Configuration
@EnableTransactionManagement
public class AppConfig {
 
    @Autowired
    private Environment env;
 
    @Bean
    public DataSource dataSource() {
        DriverManagerDataSource dataSource = new DriverManagerDataSource();
        dataSource.setDriverClassName(env.getProperty("spring.datasource.driver-class-name"));
        dataSource.setUrl(env.getProperty("spring.datasource.url"));
        dataSource.setUsername(env.getProperty("spring.datasource.username"));
        dataSource.setPassword(env.getProperty("spring.datasource.password"));
        return dataSource;
    }
}

Here, the dataSource bean is defined using the DriverManagerDataSource implementation class. We can inject the Oracle data-source properties using the Environment object auto-wiring. Lastly, we can set the properties to the data-source bean using the set* methods.
