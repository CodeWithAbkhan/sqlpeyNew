Is there a performance difference between using a BETWEEN clause or using <= AND >= comparisons?

When querying a database, sometimes we need to retrieve records within a specific range. There are multiple ways to achieve this, such as using a BETWEEN clause or using <= AND >= comparisons. In this Q&A Session, we’ll discuss the performance difference between them.

The Queries:

Let’s take an example to demonstrate this:

SELECT *  
  FROM table  
 WHERE year BETWEEN '2005' AND '2010';

…and

SELECT *  
  FROM table  
 WHERE year >= '2005' AND year <= '2010';

Here, we are retrieving records from the table where the ‘year’ column falls between 2005 and 2010.

The Performance:

In terms of performance, there is no difference between these two queries. When Oracle parses the BETWEEN condition, it automatically expands out into separate comparison clauses.

For example:

SELECT *  
  FROM table
 WHERE column BETWEEN :lower_bound AND :upper_bound

…will automatically become:

SELECT *  
  FROM table
 WHERE :lower_bound <= column
   AND :upper_bound >= column

Therefore, Oracle computes the same expression twice in both the queries, once for each comparison, and only once when using BETWEEN.

Although, the BETWEEN clause is sensitive to the order of the arguments and is always inclusive of both the boundaries. Whereas, with <= AND >= comparisons, we have to specify both boundaries separately. So, performance-wise, the BETWEEN clause is a better option.

Alternative Ways:

Some database management systems may have different behavior regarding the performance of these methods. Therefore, it’s always a good idea to run an explain plan to see what the optimizer wants.

Also, if the expression can have a non-deterministic result, the BETWEEN clause will have a different behavior. For example:

WHERE RANDOM() BETWEEN x AND y -- one random value generated

WHERE RANDOM() >= x AND RANDOM() <= y -- two distinct random values generated

This can be time-consuming if the expression is a subquery.

Recap:

In recap, there is no performance difference between using the BETWEEN clause or using <= AND >= comparisons. Although, the BETWEEN clause is a more concise and readable way to write these types of queries, but you should always check the behavior of your database management system before selecting an option.
