Query latest table in a BigQuery dataset

Problem:

You have a dataset in BigQuery containing tables with similar names that end in yyyymmdd. For example:

myproject:mydataset.Sales20140815
myproject:mydataset.Sales20140816
myproject:mydataset.Sales20140817
myproject:mydataset.Sales20140818
...
myproject:mydataset.Sales20140903
myproject:mydataset.Sales20140904

You need to write a BigQuery query to retrieve data from the latest table in the dataset.

Solution:

You can use table wildcard functions and the _TABLE_SUFFIX pseudo column in BigQuery Standard SQL to get data from the latest table in the dataset. The _TABLE_SUFFIX pseudo column represents the suffix of the table name, which is useful for filtering tables based on a date or other criterion.

The following query retrieves data from the latest table in the dataset:

#standardSQL
SELECT *
FROM `myproject.mydataset.*`
WHERE _TABLE_SUFFIX = (
  SELECT MAX(_TABLE_SUFFIX)
  FROM `myproject.mydataset.*`
)

Let’s break down the query:

  • The #standardSQL tag sets the query syntax mode to Standard SQL, the recommended syntax for BigQuery.
  • The SELECT * statement retrieves all columns from the latest table.
  • The FROM myproject.mydataset.*`` statement specifies the dataset containing the tables. The wildcard character (*) specifies that all tables in the dataset should be searched.
  • The WHERE _TABLE_SUFFIX = statement filters the tables based on their suffix, which represents the date part of the table names.
  • The (SELECT MAX(_TABLE_SUFFIX) FROM myproject.mydataset.*) subquery retrieves the maximum value of the suffix of all tables in the dataset. This is the latest table.

The result of the query will be the data from the latest table in the dataset.

Alternative solution:

If you prefer to use the legacy SQL syntax, you can use the TABLE_QUERY function and the table_id pseudo column to retrieve data from the latest table:

SELECT *
FROM TABLE_QUERY(myproject:mydataset, "
  SELECT table_id
  FROM __TABLES_SUMMARY__
  WHERE table_id LIKE 'Sales%'
  ORDER BY table_id DESC
  LIMIT 1")

Let’s break down the query:

  • The SELECT * statement retrieves all columns from the latest table.
  • The FROM TABLE_QUERY(myproject:mydataset, "") statement specifies the dataset containing the tables and the query to retrieve the latest table.
  • The SELECT table_id FROM __TABLES_SUMMARY__ WHERE table_id LIKE 'Sales%' ORDER BY table_id DESC LIMIT 1 subquery retrieves the ID of the latest table using the __TABLES_SUMMARY__ pseudo table. The LIKE operator filters the tables based on their prefix. The ORDER BY and LIMIT clauses select the latest table.

Note that the legacy SQL syntax may no longer be supported in the future, so it’s recommended to use Standard SQL instead.

Recap:

You can use the _TABLE_SUFFIX pseudo column in BigQuery Standard SQL or the table_id pseudo column and the __TABLES_SUMMARY__ pseudo table in legacy SQL to retrieve data from the latest table in a dataset. Standard SQL is recommended over legacy SQL for future-proofing your queries. ]]>
