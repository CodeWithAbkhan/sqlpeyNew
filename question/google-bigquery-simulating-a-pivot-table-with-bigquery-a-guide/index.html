How to Simulate a Pivot Table with BigQuery
If you need to organize the results of a query into columns, as if it were a pivot table, you can use conditional statements in BigQuery. In this example, we’ll simulate a pivot table to display the revision counts of the most revised Wikipedia Q&A Sessions that start with the value ‘Google’.

Step 1: Subselect Top Revised Q&A Sessions

The first step is to subselect the top revised Q&A Sessions containing ‘Google’ followed by additional text. We’ll use the TOP() function to return the top 5 Q&A Sessions, and the COUNT() function to count the number of revisions.

SELECT TOP(title, 5) as page_title, COUNT(*) as total
FROM [publicdata:samples.wikipedia]
WHERE REGEXP_MATCH (title, r'^Google.+') AND wp_namespace = 0

This query returns the page_title and total columns, which represent the Q&A Session title and revision count, respectively. This subquery will be used as the input for our pivot table simulation.

Step 2: Use Conditional Statements to Create Pivot Table

Next, we’ll use conditional statements to organize the results of our subquery into rows and columns, as if it was a pivot table. In this example, we’ll create columns for the revision counts of Q&A Sessions containing certain keywords, such as ‘search’ and ‘geo’.

SELECT
  page_title,
  IF(page_title CONTAINS 'search', INTEGER(total), 0) AS search,
  IF(page_title CONTAINS 'Earth' OR page_title CONTAINS 'Maps', INTEGER(total), 0) AS geo
FROM
  (SELECT TOP(title, 5) as page_title, COUNT(*) as total
   FROM [publicdata:samples.wikipedia]
   WHERE REGEXP_MATCH (title, r'^Google.+') AND wp_namespace = 0
  );

This code generates the following table:

| page\_title | search | geo |

| — | — | — |

| Google search | 4261 | 0 |

| Google Earth | 0 | 3874 |

| Google Chrome | 0 | 0 |

| Google Maps | 0 | 3854 |

| Google Drive | 0 | 0 |

Each column in the pivot table represents a different condition, and the rows represent the Q&A Session titles. The conditional statements use the CONTAINS function to check if the Q&A Session title contains a certain keyword, such as ‘search’ or ‘geo’. If the Q&A Session meets the condition, the revision count is displayed in the respective column.

Practical Example

If you want to create a pivot table of sales data, you can use the same technique to organize your data into rows and columns. For example, you could use the IF() function to create columns for different product categories, and display the total sales for each product in the corresponding column. You could also use nested conditional statements to create more complex pivot tables, such as displaying the average sales by region and month.
