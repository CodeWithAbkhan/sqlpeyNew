How to Overwrite a Table with BigQuery Client copy_table() Method

Summary

This post explains how to use the BigQuery Client copy_table() method to overwrite an existing table in BigQuery. The code example is taken from the official Google Cloud documentation, which copies a table from a source dataset to a destination dataset, but when the destination table already exists, it raises an “Already Exists” error.

Code Explanation

The following is the code example to copy a table from a source dataset to a destination dataset using the BigQuery Client copy_table() method:

source_dataset = client.dataset('samples', project="bigquery-public-data")
source_table_ref = source_dataset.table('shakespeare')
dest_table_ref = client.dataset(dataset_id).table('destination_table')

job = client.copy_table(
    source_table_ref,
    dest_table_ref,
    location='US')

In the code above, the source_dataset is defined as the ‘samples’ dataset in the ‘bigquery-public-data’ project, and the source_table_ref is the ‘shakespeare’ table in the ‘samples’ dataset. The destination table is referred to as dest_table_ref in the ‘dataset_id’ dataset with the table name ‘destination_table’. Lastly, the copy_table() method is called with the source_table_ref, dest_table_ref, and location as arguments. Although, if the destination table already exists, the copy_table() method will raise an “Already Exists” error. Therefore, we need to specify the job configuration to overwrite the existing table. Here’s how to do it: First, we need to create a CopyJobConfig object and define the write_disposition as “WRITE_TRUNCATE”:

job_config = bigquery.CopyJobConfig()
job_config.write_disposition = "WRITE_TRUNCATE"

Using the job_config object, we can pass it as an argument to the copy_table() method to specify the job configuration:

job = client.copy_table(
    source_table_ref,
    dest_table_ref,
    location='US',
    job_config=job_config)

By specifying the write_disposition as “WRITE_TRUNCATE”, it will overwrite the existing table if it already exists.

Practical Examples

Here’s the modified code example that overwrites the existing ‘destination_table’ if it already exists:

source_dataset = client.dataset('samples', project="bigquery-public-data")
source_table_ref = source_dataset.table('shakespeare')
dest_table_ref = client.dataset(dataset_id).table('destination_table')

job_config = bigquery.CopyJobConfig()
job_config.write_disposition = "WRITE_TRUNCATE"

job = client.copy_table(
    source_table_ref,
    dest_table_ref,
    location='US',
    job_config=job_config)
