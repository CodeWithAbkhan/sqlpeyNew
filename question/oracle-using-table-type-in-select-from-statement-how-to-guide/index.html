Oracle: Using Table Type in SELECT FROM Statement

In this post, we will delve into the usage of a table type in a SELECT FROM statement in Oracle. We will walk through the code line by line, elucidating each segment’s purpose, and present a practical example.

Defining Table Types

Firstly, let’s define our table type. We will create two types:

CREATE OR REPLACE TYPE exch_row AS OBJECT(
    currency_cd VARCHAR2(9),
    exch_rt_eur NUMBER,
    exch_rt_usd NUMBER);

CREATE OR REPLACE TYPE exch_tbl AS TABLE OF exch_row;

With this in place, we can now incorporate our table type into SQL statements.

Using Table Type in SQL

Assuming we have a table named ‘item’ with a column ‘currency’ that corresponds to the ‘currency_cd’ column in our ’exch_tbl’, we can perform a join:

SELECT i.*, rt.exch_rt_eur, rt.exch_rt_usd
FROM item i, TABLE(exch_rt) rt
WHERE i.currency = rt.currency_cd;

Here, we select columns from the ‘item’ table along with ’exch_rt_eur’ and ’exch_rt_usd’ columns from our ’exch_tbl,’ referencing it using the TABLE function. The join is based on the ‘currency’ and ‘currency_cd’ fields.

Utilizing Table Type in a Package

To use our table type in a package, we can define a variable of type ’exch_tbl’ and incorporate it into our procedures:

CREATE OR REPLACE PACKAGE my_package AS
  exch_rt exch_tbl;
  PROCEDURE fill_exch_rt;
  FUNCTION get_item(currency_cd IN VARCHAR2) RETURN item%ROWTYPE;
END my_package;
/

The ‘fill_exch_rt’ procedure populates our table with data, and ‘get_item’ selects an item record based on a given currency code, using the TABLE function to reference our ’exch_rt’ table type.

Practical Example

Suppose we are building an e-commerce application with items priced in multiple currencies. We can create a package function to return all items priced in a given currency, along with their prices converted to USD and EUR:

CREATE OR REPLACE PACKAGE item_pricing AS
  exch_rt exch_tbl;
  PROCEDURE fill_exchange_rates;
  FUNCTION get_items(currency_cd IN VARCHAR2) RETURN SYS_REFCURSOR;
END item_pricing;
/

The ‘fill_exchange_rates’ procedure populates our ’exch_rt’ table type with conversion rates, and ‘get_items’ selects items from the ‘item’ table, joining it with ’exch_rt’ using the TABLE function. We also calculate the USD and EUR prices based on the exchange rates.

Alternative Ways

Before Oracle 12C, selecting from PL/SQL-defined tables was not possible; only tables based on SQL types were supported. In older versions, you could define nested tables:

CREATE TYPE exch_row AS OBJECT (
    currency_cd VARCHAR2(9),
    exch_rt_eur NUMBER,
    exch_rt_usd NUMBER);

CREATE TYPE exch_tbl AS TABLE OF exch_row;

You could then use this nested table similarly to the ’exch_tbl’ defined in our previous examples.

FAQs about Using Table Type in SELECT FROM Statement in Oracle:

What is a table type in Oracle?

Answer: In Oracle, a table type is a user-defined type that represents a collection of data, often used to pass sets of data between PL/SQL procedures or functions.

How can I create a table type in Oracle?

Answer: You can create a table type using the CREATE OR REPLACE TYPE statement, defining the structure of the type, such as its attributes and methods.

What is the purpose of the TABLE function in Oracle?

Answer: The TABLE function in Oracle is used to treat a nested table or a varray (variable-size array) as a relational table, allowing you to use it in SQL queries.

Can I join a table type with a regular table in Oracle?

Answer: Yes, you can join a table type with a regular table in Oracle using the TABLE function in the FROM clause of a SQL query, specifying the table type.

How do I use a table type in a PL/SQL package?

Answer: To use a table type in a PL/SQL package, you declare a variable of that table type, and then you can manipulate and query it within the package procedures or functions.

What are alternative ways to handle collections prior to Oracle 12C?

Answer: Prior to Oracle 12C, you could use nested tables defined with the CREATE TYPE statement to handle collections in a way similar to the examples shown in this guide.

Can I use table types in a SELECT FROM statement for older versions of Oracle?

Answer: For older versions of Oracle, you can use nested tables defined with the CREATE TYPE statement and handle them similarly to the examples shown in this guide.
