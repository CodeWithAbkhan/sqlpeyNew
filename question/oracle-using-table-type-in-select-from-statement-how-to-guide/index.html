ORACLE: Using Table Type in SELECT FROM Statement: How-To Guide In this post, we will discuss how to use a table type in a SELECT FROM statement in Oracle. We will go through the code line by line, explaining what each part does, and provide a practical example.

Firstly, let’s define our table type. We will create two types: exch_row, which is a record type that contains three fields (currency_cd, exch_rt_eur, exch_rt_usd), and exch_tbl, which is a table of type exch_row.

CREATE OR REPLACE TYPE exch_row AS OBJECT(
currency_cd VARCHAR2(9),
exch_rt_eur NUMBER,
exch_rt_usd NUMBER);

CREATE OR REPLACE TYPE exch_tbl AS TABLE OF exch_row;

				  With this in place, we can now use our table type in SQL statements. For example, let's say we have a table called 'item' that contains a column 'currency' that matches with the 'currency\_cd' column in our exch\_tbl. We can join these tables together like so:  
				  

SELECT i.*, rt.exch_rt_eur, rt.exch_rt_usd
FROM item i, TABLE(exch_rt) rt
WHERE i.currency = rt.currency_cd;

In this query, we are selecting all columns from the ‘item’ table, plus the ’exch_rt_eur’ and ’exch_rt_usd’ columns from our exch_tbl (which we are referencing using the TABLE function). We then join the two tables together using the ‘currency’ and ‘currency_cd’ fields. To use our table type in a package, we can define a variable of type exch_tbl, then use it in our procedures. For example:

CREATE OR REPLACE PACKAGE my_package AS
  exch_rt exch_tbl;
  PROCEDURE fill_exch_rt;
  FUNCTION get_item(currency_cd IN VARCHAR2) RETURN item%ROWTYPE;
END my_package;
/
CREATE OR REPLACE PACKAGE BODY my_package AS
  PROCEDURE fill_exch_rt IS
  BEGIN
    exch_rt := exch_tbl();
    -- add data to table here
  END fill_exch_rt;

  FUNCTION get_item(currency_cd IN VARCHAR2) RETURN item%ROWTYPE IS
    result item%ROWTYPE;
  BEGIN
    SELECT *
    INTO result
    FROM item i, TABLE(exch_rt) rt
    WHERE i.currency = rt.currency_cd
      AND rt.currency_cd = currency_cd;

    RETURN result;
  END get_item;
END my_package;
/

In this package, we define a variable ’exch_rt’ of type exch_tbl, then create two procedures: ‘fill_exch_rt’ to populate our table with data, and ‘get_item’ to select an item record based on a given currency code. In the ‘get_item’ procedure, we use the TABLE function again to reference our exch_rt table type. Practical Example: Let’s say we are building a simple e-commerce application with items priced in multiple currencies. We have a table called ‘item’ with a ‘currency’ column, and a table called ’exchange_rates’ with columns ‘currency_cd’, ’exch_rt_eur’, and ’exch_rt_usd’. We want to create a package function that will return all items priced in a given currency, along with their prices converted to USD and EUR. We can do this using our exch_tbl table type like so:

CREATE OR REPLACE PACKAGE item_pricing AS
  exch_rt exch_tbl;
  PROCEDURE fill_exchange_rates;
  FUNCTION get_items(currency_cd IN VARCHAR2) RETURN SYS_REFCURSOR;
END item_pricing;
/

CREATE OR REPLACE PACKAGE BODY item_pricing AS
  PROCEDURE fill_exchange_rates IS
  BEGIN
    exch_rt := exch_tbl();

    INSERT INTO TABLE(exch_rt) 
    VALUES(exch_row('USD', 1, 1.17));
    INSERT INTO TABLE(exch_rt) 
    VALUES(exch_row('EUR', 0.85, 1));
  END fill_exchange_rates;

  FUNCTION get_items(currency_cd IN VARCHAR2) RETURN SYS_REFCURSOR IS
    result SYS_REFCURSOR;

  BEGIN
    OPEN result FOR
    SELECT item.*, 
           CASE
             WHEN exch_rt_eur IS NULL THEN NULL
             ELSE item.price * exch_rt_eur
           END AS price_eur,
           CASE
             WHEN exch_rt_usd IS NULL THEN NULL
             ELSE item.price * exch_rt_usd
           END AS price_usd
    FROM item, TABLE(exch_rt)
    WHERE item.currency = exch_currency_cd
      AND exch_currency_cd = currency_cd;

    RETURN result;
  END get_items;
END item_pricing;
/

The ‘fill_exchange_rates’ procedure populates our exch_rt table type with conversion rates, while the ‘get_items’ function selects items from the ‘item’ table and joins it with exch_rt using the TABLE function. We also calculate the USD and EUR prices based on the exchange rates. Alternative Ways: Prior to Oracle 12C, it was not possible to select from PL/SQL-defined tables, only from tables based on SQL types. If you are using an older version of Oracle, you can define nested tables like so:

CREATE TYPE exch_row AS OBJECT (
    currency_cd VARCHAR2(9),
    exch_rt_eur NUMBER,
    exch_rt_usd NUMBER);

CREATE TYPE exch_tbl AS TABLE OF exch_row;

You can then use this nested table in the same way as the exch_tbl defined in our previous examples. Recap: In this post, we learned how to use a table type in a SELECT FROM statement in Oracle. We showed how to define a table type, join it with other tables using the TABLE function, and use it in a package to pass data between procedures. We also provided a practical example of how to use table types in an e-commerce application.
