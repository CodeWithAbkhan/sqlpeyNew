How to Import Data from Oracle to Pandas Dataframe with CX_Oracle Importing data from an Oracle database to a Pandas dataframe is a common task in data analysis. This process involves establishing a connection to the database, querying the required data, and loading it into a Pandas dataframe.

In this Q&A Session, we’ll look at how to use the cx_Oracle library to accomplish this task. We’ll start by installing the required libraries and establishing a connection to our Oracle database. Then, we’ll write a SQL query that we want to execute and load the data into a Pandas dataframe.

Installing cx_Oracle and Pandas Libraries Before we start, we need to install the cx_Oracle and Pandas libraries. You can install these libraries using pip, a package manager for Python. Type the following command in your command prompt or terminal to install these libraries:

pip install cx_Oracle pandas

Once the installation is complete, we can start importing these libraries in our code.

Establishing a Connection to the Oracle Database

We can use the cx_Oracle library to establish a connection to our Oracle database. Here’s how to do it:

import cx_Oracle

ip = 'XX.XX.X.XXX'  # IP or hostname of the Oracle database server
port = YYYY  # port number of the Oracle database server
SID = 'DW'  # Service ID or database name
dsn_tns = cx_Oracle.makedsn(ip, port, SID)

connection = cx_Oracle.connect('BA', 'PASSWORD', dsn_tns)

In the above code, we first import the cx_Oracle library. We then provide the IP or hostname of the Oracle database server, the port number of the server, and the Service ID or database name for establishing the connection. We then use the cx_Oracle.makedsn() method to create a data source name (DSN) for the connection. Next, we use the cx_Oracle.connect() method to establish a connection to the database. We pass in the username and password for connecting to the database as arguments to the method.

Executing a SQL Query and Loading Data into a Pandas Dataframe

Now that we have established a connection to the Oracle database, we can execute a SQL query and load the data into a Pandas dataframe. Here’s an example of how to do it:

import pandas as pd

query = "SELECT * FROM TRANSACTION WHERE DIA_DAT >= to_date('15.02.28 00:00:00',  'YY.MM.DD HH24:MI:SS') AND (locations  'PUERTO RICO' OR locations  'JAPAN') AND CITY = 'LONDON'"

df = pd.read_sql(query, con=connection)

In the above code snippet, we first import the Pandas library. We then write our SQL query and store it in a variable called query. We then use the pd.read_sql() function from the Pandas library to execute the SQL query and load the data into a Pandas dataframe. We pass in the query and the connection object as arguments to this function. The resulting dataframe is stored in a variable called df.

Explaining the SQL Query

Let’s break down the SQL query used in the above code snippet:

SELECT * 
FROM TRANSACTION 
WHERE DIA_DAT >= to_date('15.02.28 00:00:00', 'YY.MM.DD HH24:MI:SS') 
AND (locations  'PUERTO RICO' OR locations  'JAPAN') 
AND CITY = 'LONDON'

This SQL query selects all columns from the TRANSACTION table where the following conditions are met: - DIA_DAT >= to_date('15.02.28 00:00:00', 'YY.MM.DD HH24:MI:SS') - Filters the records where the DIA_DAT column is greater than or equal to the date ‘15.02.28 00:00:00’. - (locations 'PUERTO RICO' OR locations 'JAPAN') - Filters the records where the locations column is not equal to ‘PUERTO RICO’ or ‘JAPAN’. The `` operator is the equivalent of the != operator. - CITY = 'LONDON' - Filters the records where the CITY column is equal to ‘LONDON’.

Alternative Ways

Another way to execute a SQL query and load data into a Pandas dataframe is by using the sqlalchemy library. Here’s an example of how to do it:

import sqlalchemy as sa

ip = 'XX.XX.X.XXX'  # IP or hostname of the Oracle database server
port = YYYY  # port number of the Oracle database server
SID = 'DW'  # Service ID or database name
dsn_tns = f'oracle://{username}:{password}@{ip}:{port}/{SID}'

engine = sa.create_engine(dsn_tns)
conn = engine.connect()

query = "SELECT * FROM TRANSACTION WHERE DIA_DAT >= to_date('15.02.28 00:00:00',  'YY.MM.DD HH24:MI:SS') AND (locations  'PUERTO RICO' OR locations  'JAPAN') AND CITY = 'LONDON'"

df = pd.read_sql_query(query, con=conn)

In this example, we first import the sqlalchemy library. We then use the f-string syntax to create a DSN string that contains the username, password, IP address, port number, and service ID of the Oracle database. We then use the sa.create_engine() function to create an engine object, and the engine.connect() method to establish a connection to the database. After that, we use the pd.read_sql_query() function to execute the SQL query and load the data into a Pandas dataframe. We pass in the query and the connection object as arguments to this function. The resulting dataframe is stored in a variable called df.
