Backing up all view definitions in BigQuery

Problem

You have a large number of views in BigQuery, and you want to make a backup of their definition queries before deleting them.

Solution

You can automate this process by using a script that calls the bq command-line tool and jq to parse the output and save the definition queries to files.

Step-by-step guide

Step 1: Install bq and jq

If you haven’t installed the bq and jq command-line tools, you can do so using the following commands:

sudo apt-get install google-cloud-sdk
sudo apt-get install jq

For more information on installing the Google Cloud SDK and bq, see the official documentation .

Step 2: Write the backup script

Copy the following script into a file and save it somewhere in your path with a name like bq-backup-views.sh:

#!/bin/bash

DATASETS=$(bq ls --format=sparse | tail -n+3)
for d in $DATASETS; do
  TABLES=$(bq ls --format=prettyjson "$d" | jq '.[] | "(.id), (.type)"')
  IFS=$'n'
  for table in $TABLES; do
    [[ ! "$table" == *VIEW* ]] && continue
    view=$(echo "$table" | sed -e 's/"//g' | cut -d , -f 1)
    query=$(bq show --format=prettyjson "$view" | jq -r '.view.query')
    echo -e "$query" > "$view.sql"
  done
done

This script does the following:

  • Lists all datasets in the default project using bq ls.
  • Lists all tables in each dataset using bq ls --format=prettyjson.
  • Finds all views by filtering the table type using jq.
  • Gets the query for each view using bq show and extracts the query field with jq.
  • Saves the query to a file with the same name as the view.

Step 3: Run the script

To run the script, simply execute it from the command line:

bq-backup-views.sh

This will create a .sql file for each view in your current working directory. The files will have the same names as the views, so be sure to use a unique naming convention if you have views with the same names in different datasets.

Alternative solutions

If you prefer to use a GUI to manage your views, you can use the BigQuery web console to export each view’s definition as a SQL file. Simply select a view from the left-hand panel, click the “Query settings” button, and then click “Export as SQL”. ]]>
