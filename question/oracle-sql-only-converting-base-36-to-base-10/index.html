ORACLE: SQL Only: Converting Base 36 to Base 10 In this blog post, we will look at how to perform a base 36 to base 10 conversion using only SQL. This issue is common in situations where the data stored, or input, uses a different numbering system than the one needed for processing. For example, in situations where a user ID or a product code is encoded in base 36, but the requirement is to use base 10 for processing or analysis.

Most modern programming languages come with in-built functionality to convert between number systems. Although, the same can’t be said for SQL. Therefore, we will look at a solution that uses only SQL to achieve the conversion.

Let’s get into it.

Learning Base 36 and Base 10 Number Systems

Before we dive into the code, let’s know what the base 36 and base 10 number systems are.

A number system is a way of representing numbers using symbols. The base of a number system represents the number of symbols that it uses. For example, the base-2 system uses only two symbols, 0 and 1, while the base-10 system uses ten symbols, 0 to 9.

The base 36 system, as the name suggests, uses 36 symbols. It uses the numbers 0 to 9 and the letters A to Z to represent numbers. Therefore, the next number after 9 is A, followed by B, and so on until Z, which represents the number 35.

The base 10 system, on the other hand, uses 10 symbols from 0 to 9 to represent numbers. Each position in the number represents the multiplication of the base to the power of the position. For example, the number 123 is represented as 1 * 10^2 + 2 * 10^1 + 3 * 10^0 in base 10.

Converting Base 36 to Base 10 Using SQL

Now that we have understood the number systems let’s look at how to convert base 36 to base 10 using SQL.

Due to the lack of built-in functionality for base conversion, we will create a SQL query to achieve the conversion. The query will use only basic SQL functionality to achieve the required result.

Let’s take the following example, where we need to convert the value “01Z” (base 36) to “71” (base 10).

WITH
Base36Values AS
(
    SELECT '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ' myBase36 FROM DUAL
),
TestValues AS
(
    SELECT '01Z' BASE36_VALUE,
            71   BASE10_VALUE FROM DUAL
)
SELECT *
FROM Base36Values,
     TestValues

                                     else 10 + ascii(digit) - ascii('A')

                 level position
            from (select '01Z' input_string from dual)
            connect by level &lt;= length(input_string)
         )
)

The subquery calculates the position value for each digit in the input string.

The power function is used to calculate the power of 36 for the current position. The case statement is used to determine whether the current digit is a number or a letter. If it is a number, then the digit is converted to a number using the to_number function. If it is a letter, then the ASCII value of the letter is subtracted from the ASCII value of ‘A’ and then added to 10.

The substr function is used to select each digit from the input string using its position. The level column is used to determine the position of each digit in the string. The connect by clause is used to generate a result set with the number of rows equal to the length of the input string.

Lastly, the outer sum function is used to sum up the position values for each digit in the input string to get the final value.

That’s all there is to it! We have successfully converted a base 36 value to a base 10 value using SQL only.

Alternative Ways

While the above solution is effective, other solutions exist for base conversion. One such solution is using a user-defined function in the database to perform the conversion. This approach has the advantage of being reusable and more modular, making it easier to maintain and extend.

Another alternative is to use programming languages that have built-in functions for base conversion, such as Python or C#. For example, in Python, we can use the int function with the base parameter to convert between bases as follows:
