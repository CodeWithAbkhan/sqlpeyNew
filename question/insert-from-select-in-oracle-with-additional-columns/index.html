Insert from Select in Oracle with Additional Columns Oracle insert from select into table with more columns
If you want to insert data from a select statement into a table with extra columns, and add a default value for the extra column in every row, you can use the following SQL query:

INSERT INTO table_name (col1, col2, col3, extra_col)
    SELECT
       other_table.col1 AS col1,
       other_table.col2 AS col2,
       other_table.col3 AS col3,
       '0' AS extra_col
    FROM other_table

Explanation line by line

The above query is inserting data into the table_name table with four columns: col1, col2, col3, and extra_col. Here’s what each line does:

  1. The INSERT INTO statement specifies the table into which data will be inserted.
  2. The column names inside parentheses after the table name are the names of the columns into which data will be inserted.
  3. The SELECT statement is used to retrieve data from another table (in this case, other_table).
  4. The AS keyword is used to give each column in the SELECT statement an alias (a different name). This is done to make the column names in the SELECT statement match the column names in the INSERT INTO statement.
  5. The ‘0’ AS extra_col line adds a default value of 0 for every row in the extra_col column.
  6. The FROM keyword is used to specify the source table (other_table) for the SELECT statement.

Practical Examples

Here are a few examples of how you might use the above INSERT INTO…SELECT statement:

Example 1

You want to insert data into a table called customers from another table called orders. The customers table has an extra column called notes, and you want to add the value ‘None’ to this column for every row:

INSERT INTO customers (customer_id, name, email, notes)
    SELECT
       orders.customer_id AS customer_id,
       orders.name AS name,
       orders.email AS email,
       'None' AS notes
    FROM orders

In this example, the INSERT INTO statement specifies the customers table as the destination table, and the SELECT statement retrieves data from the orders table. The ‘None’ AS notes line adds the value ‘None’ to the notes column in the customers table for every row.

Example 2

You want to insert data from a subquery into a table called employees. The employees table has an extra column called department that you want to fill with the value ‘Sales’. The subquery retrieves data from a table called temp_employees:

INSERT INTO employees (employee_id, first_name, last_name, department)
    SELECT
       temp_employees.employee_id AS employee_id,
       temp_employees.first_name AS first_name,
       temp_employees.last_name AS last_name,
       'Sales' AS department
    FROM (
       SELECT *
       FROM temp_employees
       WHERE department = 'Sales'
    ) temp_employees

In this example, the SELECT statement is actually a subquery that retrieves data from the temp_employees table. The WHERE clause is used to limit the data returned by the subquery to only those rows where the department is ‘Sales’. The outer INSERT INTO statement is then used to insert this data into the employees table, with the extra column department specified and the value ‘Sales’ added to it for every row.

Alternative Ways

Another way to insert a default value into a table with an extra column is to use the DEFAULT keyword. For example:

INSERT INTO table_name (col1, col2, col3, extra_col)
    SELECT
       other_table.col1 AS col1,
       other_table.col2 AS col2,
       other_table.col3 AS col3,
       DEFAULT AS extra_col
    FROM other_table

In this example, the DEFAULT keyword is used instead of ‘0’ to insert a default value into the extra_col column. This will insert the default value specified in the table definition. ]]>
