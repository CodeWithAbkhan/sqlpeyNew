Issue
I am developing an app that requires access to the Google BigQuery API via server-to-server communication. I have followed the Google guide for constructing a JWT in C# and Base64Url encoded everything necessary. Although, when I attempt to request the access token, Google returns a 400 Bad Request error message with the description “invalid_request.”

Solution

Step 1: Verify JWT Encoding

To ensure that the JWT signature is properly encrypted using RSA and SHA256, verify that the encoding process is correctly implemented in the code.

// Get RSA private key
RSA privateKey = RSA.FromXmlString(privateKeyXml);

// Create RS256 signature
var header = new { alg = "RS256", typ = "JWT" };
var payload = new
{
    iss = SERVICE_ACCOUNT_EMAIL,
    scope = "https://www.googleapis.com/auth/bigquery",
    aud = "https://www.googleapis.com/oauth2/v4/token",
    exp = (int)(DateTime.UtcNow.AddMinutes(55) - new DateTime(1970, 1, 1)).TotalSeconds,
    iat = (int)(DateTime.UtcNow - new DateTime(1970, 1, 1)).TotalSeconds
};
string stringifiedHeader = JsonConvert.SerializeObject(header);
string stringifiedPayload = JsonConvert.SerializeObject(payload);
string headerBase64Url = Base64UrlEncoder.Encode(stringifiedHeader);
string payloadBase64Url = Base64UrlEncoder.Encode(stringifiedPayload);
string signatureInput = $"{headerBase64Url}.{payloadBase64Url}";
byte[] signatureBytes = Encoding.UTF8.GetBytes(signatureInput);
byte[] crypt = privateKey.SignData(signatureBytes, HashAlgorithmName.SHA256, RSASignaturePadding.Pkcs1);
string jwt = $"{signatureInput}.{Base64UrlEncoder.Encode(crypt)}";

Step 2: Use Correct Content Type and HTTP Method

Since this is a server-to-server communication, ensure that you are using the POST HTTP method and application/x-www-form-urlencoded content type.

Step 3: Escaping Backslashes in the Claim Set

Ensure that you have escaped all the backslashes in the claim set.

Step 4: Verify POST Data

Try various grant_type and assertion values in the POST data to see if that fixes the issue.

Step 5: Check for Errors Using Fiddler

Use Fiddler to replicate the request and check for any errors.
