ORACLE: Fixing ORA-00988 Error: Invalid or Missing Passwords

When attempting to change an Oracle password using the alter user command, encountering the error message ORA-00988: missing or invalid password(s) indicates a syntax mistake in the command.

Solution

When changing an Oracle user password, keep the following in mind:

  • Do not enclose the password in single quotes.
  • Use double quotes if the password contains special characters.
  • Avoid attempting to alter multiple users in a single script file.

Here’s an example of the correct syntax:

alter user FOO identified by BAR;
alter user FOO identified by "BAR";
alter user davidl identified by "newpassword" replace "oldpassword";

The first line assumes a simple password without special characters, the second line shows the use of double quotes for passwords with special characters, and the third line demonstrates how to replace an existing password with a new one.

Attempting to alter multiple users in a single script file will not work; ensure a separate file for each user modification.

Practical Example

Suppose you need to change the password for the Oracle user “JANE” to “JSU753.” Follow these steps:

  1. Create a new text file named “jane.sql.”
  2. Type the following command in the file and save it:
alter user JANE identified by JSU753;
  1. Open the command prompt, navigate to the file directory, and execute the SQL script:
sqlplus username/password @jane.sql

Replace “username” and “password” with your Oracle credentials.

  1. Press Enter, wait for the command to execute, and if successful, the password for “JANE” will be changed to “JSU753.”

Alternative

If you prefer a graphical interface, use Oracle SQL Developer to change an Oracle user password:

  1. Open Oracle SQL Developer and connect to the database.
  2. Expand the “Security” folder in the connection navigator.
  3. Right-click the user, choose “Edit,” go to the “Account” tab, and enter the new password.
  4. Click “Apply” and then “OK” to save the changes.

Using Oracle SQL Developer offers a more user-friendly approach, especially for those unfamiliar with the command line.

Recap

When changing an Oracle user password, adhere to correct syntax, and avoid common mistakes like enclosing the password in single quotes. If encountering the “ORA-00988” error, double-check the syntax and ensure single script files are dedicated to each user alteration. Following these guidelines ensures a smooth password change without errors.
