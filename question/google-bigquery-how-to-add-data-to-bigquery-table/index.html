How to insert data into a BigQuery table using the Java Client Library?

Summary

This guide explains how to insert data into a BigQuery table using the Google Cloud Java Client Library. It covers how to create a TableRow, set data types for fields, and insert the data into a table.

Prerequisites

  • A Google Cloud project with the BigQuery API enabled
  • A BigQuery dataset and table
  • Google Cloud SDK or Maven

Create a TableRow

To insert data into a BigQuery table, we first create a TableRow object using the com.google.api.services.bigquery.model.TableRow class. In this example, we will create a TableRow with two fields, type and timestamp. java TableRow data = new TableRow(); data.set("type", "myEventType"); data.set("timestamp", new DateTime(System.currentTimeMillis())); Notice that the timestamp field is set using a DateTime object from the com.google.api.client.util.DateTime package. This is because the BigQuery Java Client Library does not support the Date class.

Insert Data into a Table

Once we have our TableRow object, we can insert the data into a BigQuery table using the tabledata().insertAll() method from the com.google.api.services.bigquery.Bigquery.Tabledata class. In this example, we will insert the data into a table called myTable in a dataset called myDataset. java TableDataInsertAllRequest.Rows row = new TableDataInsertAllRequest.Rows(); row.setInsertId(String.valueOf(System.currentTimeMillis())); // Set a unique insert ID for deduplication row.setJson(data); TableDataInsertAllRequest request = new TableDataInsertAllRequest().setRows(Arrays.asList(row)); TableDataInsertAllResponse response = bigquery.tabledata().insertAll(projectId, datasetId, "myTable", request).execute(); for (TableDataInsertAllResponse.InsertErrors err: response.getInsertErrors()) { for (ErrorProto ep: err.getErrors()) { System.err.println(ep.getReason() + " : " + ep.getMessage() + " at " + ep.getLocation()); } } First, we create a TableDataInsertAllRequest.Rows object, set the insert ID for deduplication, and add the JSON data using row.setJson(data). Next, we create a TableDataInsertAllRequest object, add the Rows object to it using setRows(), and then pass the request to the tabledata().insertAll() method. Lastly, we check for any insert errors using the response object’s getInsertErrors() method.

Alternative Way

Instead of creating a TableRow manually, we can use the com.google.api.services.bigquery.model.TableDataInsertAllRequest.RowsContent class to create and set field values dynamically. For instance, to insert a new row with the fields name and age, we can use the following code: java TableDataInsertAllRequest.RowsContent content = new TableDataInsertAllRequest.RowsContent(); content.set("name", "John"); content.set("age", 35); TableDataInsertAllRequest.Rows row = new TableDataInsertAllRequest.Rows().setContent(content); TableDataInsertAllRequest request = new TableDataInsertAllRequest().setRows(Arrays.asList(row)); TableDataInsertAllResponse response = bigquery.tabledata().insertAll(projectId, datasetId, tableId, request).execute();

Recap
