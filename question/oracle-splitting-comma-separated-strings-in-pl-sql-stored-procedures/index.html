ORACLE: Splitting Comma-Separated Strings in PL/SQL Stored Procedures Splitting comma separated string in a PL/SQL stored proc
When working with PL/SQL stored procedures in Oracle, it is common to encounter situations where you need to split a comma-separated string and insert the values into a database table. In this Q&A Session, we will explore a solution that allows you to split two CSV strings and insert each value into two different columns in a table.

Approach

The approach we will use involves passing two CSV strings as parameters to a PL/SQL stored procedure. Within the stored procedure, we will use a function to split the CSV strings into arrays. Lastly, we will insert each value from the arrays into separate columns in the target table.

(
  P_STRING1 IN VARCHAR2,
  P_STRING2 IN VARCHAR2
)
AS
BEGIN
  NULL;
END;

This procedure has two input parameters, P_STRING1 and P_STRING2.

Step 2 - Create the function to split each CSV string and return an array

Next, we will create a function that will split each CSV string into an array using the SQL connect by level approach.

CREATE OR REPLACE FUNCTION SPLIT_CSV_STRING
(
  P_STRING IN VARCHAR2
)
RETURN DBMS_SQL.NUMBER_TABLE
IS
  V_STRING VARCHAR2(4000);
  V_INDEX NUMBER;
  V_ARRAY DBMS_SQL.NUMBER_TABLE;
BEGIN
  -- Remove any leading or trailing spaces
  V_STRING := TRIM(P_STRING);

  -- Initialize V_INDEX to 1
  V_INDEX := 1;

  -- Loop through the string
  WHILE INSTR(V_STRING, ',', V_INDEX) > 0
  LOOP
    -- Get the index of the next comma
    V_ARRAY(V_INDEX) := TO_NUMBER(SUBSTR(V_STRING, V_INDEX, INSTR(V_STRING, ',', V_INDEX) - V_INDEX));

    -- Set the index to the character after the comma
    V_INDEX := INSTR(V_STRING, ',', V_INDEX) + 1;
  END LOOP;

  -- Get the last value in the string
  V_ARRAY(V_INDEX) := TO_NUMBER(SUBSTR(V_STRING, V_INDEX, LENGTH(V_STRING) - V_INDEX + 1));

  -- Return the resulting array
  RETURN V_ARRAY;
EXCEPTION
  WHEN NO_DATA_FOUND THEN
    RETURN NULL;
END;

This function takes a CSV string and returns an array of DBMS_SQL.NUMBER_TABLE. The function works by looping through the string, finding each comma, and extracting the substring up to the comma. The function then converts the substring to a number and inserts it into the array. After the loop, the function extracts the last value in the string and inserts it into the array. Lastly, the function returns the resulting array.

Step 3 - Use the function to split the CSV strings and insert each value into separate columns in the table

Lastly, we will use the SPLIT_CSV_STRING function to split each CSV string and insert each value into separate columns in the target table. Here is the updated code for the INSERT_TWO_CSV_STRINGS procedure:

CREATE OR REPLACE PROCEDURE INSERT_TWO_CSV_STRINGS
(
  P_STRING1 IN VARCHAR2,
  P_STRING2 IN VARCHAR2
)
AS
  V_STRING1_ARRAY DBMS_SQL.NUMBER_TABLE;
  V_STRING2_ARRAY DBMS_SQL.NUMBER_TABLE;
BEGIN
  -- Split the first CSV string
  V_STRING1_ARRAY := SPLIT_CSV_STRING(P_STRING1);

  -- Split the second CSV string
  V_STRING2_ARRAY := SPLIT_CSV_STRING(P_STRING2);

  -- Loop through the arrays and insert each value into separate columns in the target table
  FOR I IN 1..V_STRING1_ARRAY.COUNT
  LOOP
    INSERT INTO TARGET_TABLE (COLUMN_A, COLUMN_B) VALUES (V_STRING1_ARRAY(I), V_STRING2_ARRAY(I));
  END LOOP;
END;

The updated INSERT_TWO_CSV_STRINGS procedure first calls the SPLIT_CSV_STRING function to split each CSV string into arrays. The procedure then loops through the arrays and inserts each value into separate columns in the target table.
