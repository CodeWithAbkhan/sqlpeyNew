Reliable Ways to Write/Update Oracle Blob How to write/update Oracle blobs in a reliable way? Oracle blobs are used to store binary data (images, audio, video, pdf, etc.) in a database. Blob columns can be initialized by calling the empty_blob() function. Although, updating blobs can be a tricky task as it can result in corrupted data if not done correctly. This Q&A style post discusses how to write/update Oracle blobs in a reliable way:

What are the prerequisites for updating Oracle blobs?

Before updating Oracle blobs, the following prerequisites must be met:

  1. A table with a blob column must exist in the database. For example:

     create table x (i number, j blob);

  2. The blob column must be initialized with empty_blob(). For example:

     insert into x (i, j) values (1, empty_blob());

  3. The data to be updated must be in binary format.

What is the correct way to update Oracle blobs?

To update Oracle blobs:

  1. Connect to the database using a Connection object.
  2. Retrieve the blob column using a PreparedStatement object.
  3. Read the binary data to be updated from a file into a byte array.
  4. Write the byte array to the blob column using the setBytes() method of the blob object.
  5. Commit the changes using the commit() method of the connection object.
  6. Clean up by closing the connection, prepared statement, and result set objects.

How to update blobs without worrying about binary data size?

To update blobs without worrying about binary data size, we can use the Apache Commons IO library. We can read the binary data from a file using a FileInputStream and write it to the blob column using a OutputStream obtained from the blob object. This ensures that the data is written in chunks, regardless of its size. Here’s an example:

import java.io.File;
import java.io.FileInputStream;
import java.io.OutputStream;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;

import org.apache.commons.io.IOUtils;

public class BlobUpdater {
  public static void updateBlob(Connection conn, int id, File file) throws Exception {
    String sql = "UPDATE my_table SET my_blob = ? WHERE id = ?";
    try (PreparedStatement pstmt = conn.prepareStatement(sql)) {
      pstmt.setBinaryStream(1, new FileInputStream(file));
      pstmt.setInt(2, id);
      pstmt.executeUpdate();
    }
  }
  
  public static void main(String[] args) throws Exception {
    String dbUrl = "jdbc:oracle:thin:@localhost:1521:mydb";
    String dbUser = "myuser";
    String dbPass = "mypass";
    Connection conn = DriverManager.getConnection(dbUrl, dbUser, dbPass);
    File file = new File("path/to/file.pdf");
    updateBlob(conn, 1, file);
    conn.close();
  }
}

What if I need to retrieve the blob data?

To retrieve the blob data, we can use the getBlob() method of the ResultSet object to obtain a Blob object. Then, we can get an InputStream from the Blob object to read the binary data as shown below:

public static void main(String[] args) throws Exception {
  String dbUrl = "jdbc:oracle:thin:@localhost:1521:mydb";
  String dbUser = "myuser";
  String dbPass = "mypass";
  Connection conn = DriverManager.getConnection(dbUrl, dbUser, dbPass);
  String sql = "SELECT my_blob FROM my_table WHERE id = ?";
  try (PreparedStatement pstmt = conn.prepareStatement(sql)) {
    pstmt.setInt(1, 1);
    try (ResultSet rs = pstmt.executeQuery()) {
      if (rs.next()) {
        Blob blob = rs.getBlob("my_blob");
        try (InputStream in = blob.getBinaryStream()) {
          byte[] bytes = IOUtils.toByteArray(in);
          // do something with the binary data
        }
      }
    }
  }
  conn.close();

Are there any alternative ways to update blobs?

Yes, Oracle provides two other ways to update blobs:

  1. setBinaryStream() - This method can be used to update a blob using a ByteArrayInputStream instead of a byte array. Although, it suffers from the same size limitation as setBytes().
  2. setBlob() - This method can be used to update a blob using a java.sql.Blob object instead of a byte array. Although, this method can be slower than the other methods, especially for large blobs.

Recap

Updating Oracle blobs involves writing binary data to a blob column. To update blobs reliably, we must ensure that the data is written in chunks, regardless of its size.
