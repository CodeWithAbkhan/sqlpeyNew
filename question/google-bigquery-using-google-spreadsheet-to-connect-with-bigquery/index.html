In this post, we will discuss how to access BigQuery data inside a Google Spreadsheet using Apps Script. We will also provide a code snippet that demonstrates how to do so.

First, let’s start with some background information. BigQuery is a fully-managed, serverless data warehouse that enables super-fast SQL queries using the processing power of Google’s infrastructure. Google Spreadsheet, on the other hand, is a web-based spreadsheet application that allows users to create and edit spreadsheets online.

Now, to import BigQuery data into a Google Spreadsheet using Apps Script, you can use the following code snippet:

function runQuery() {
  var projectId = ;   var request = {     query: ,
    useLegacySql: false
  };
  var queryResults = BigQuery.Jobs.query(request, projectId);
  var jobId = queryResults.jobReference.jobId;
  var job = BigQuery.Jobs.get(projectId, jobId);
  var rows = job.statistics.query.results.totalRows;
  var pageToken, startRow;
  var headers = [];
  var data = [];
  do {
    request.pageToken = pageToken;
    request.startIndex = startRow;
    queryResults = BigQuery.Jobs.query(request, projectId);
    rows = queryResults.totalRows;
    if (rows > 0) {
      var newHeaders = queryResults.schema.fields.map(function(field) {
        return field.name;
      });
      if (startRow == 0) {
        headers = newHeaders;
      }
      var page = queryResults.rows;
      page.forEach(function(row) {
        var values = row.f.map(function(field) {
          return field.v;
        });
        data.push(values);
      });
      pageToken = queryResults.pageToken;
      startRow = queryResults.startIndex + queryResults.rows.length;
    }
  } while (pageToken);
  var sheet = SpreadsheetApp.getActiveSheet();
  sheet.getRange(1, 1, 1, headers.length).setValues([headers]);
  sheet.getRange(2, 1, data.length, headers.length).setValues(data);
}

  1. The runQuery() function is called to import the data from BigQuery to the Google Spreadsheet.

  2. In the first line of the function, the projectId variable is set to your project ID.

  3. In the next line, a request object is created with the query and useLegacySql is set to false.

  4. The BigQuery.Jobs.query function is then called with the request object and projectId. This returns a queryResults object.

  5. The jobId variable is set to queryResults.jobReference.jobId.

  6. The BigQuery.Jobs.get function is then called with the projectId and jobId variables. This returns a job object.

  7. The rows variable is set to job.statistics.query.results.totalRows.

  8. The pageToken, startRow, headers, and data variables are initialized.

  9. A loop is started that will continue until there are no more pages of data to retrieve.

  12. If startRow is equal to 0, then headers is set to newHeaders.

  15. Inside this loop, a values array is created that maps each field value to its respective value.

  16. The data array is then pushed with the values array.

  17. The pageToken variable is set to queryResults.pageToken.

  18. The startRow variable is set to queryResults.startIndex + queryResults.rows.length.
