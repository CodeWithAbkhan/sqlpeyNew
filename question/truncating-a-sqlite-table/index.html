Truncate a SQLite table if it exists?

Truncating a table in SQLite requires using a specific syntax. In this article, we’ll discuss how to truncate a SQLite table only if it exists and discuss some alternative methods for achieving the same result.

Using the DELETE FROM Syntax

The syntax for truncating an existing table in SQLite is as follows:

DELETE FROM someTable

However, this syntax won’t work if the table doesn’t exist. In that case, an error will be thrown.

The following syntax won’t work either:

DELETE FROM someTable IF EXISTS

Nor will this syntax:

DELETE IF EXISTS FROM someTable

The Two-Step Process

The two-step process for truncating a SQLite table if it exists is as follows:

  1. Delete all data from the table using:

     Delete from TableName

  2. Then:

     DELETE FROM SQLITE_SEQUENCE WHERE name="TableName";

It is more efficient to drop the table and re-create it, and you can use “IF EXISTS” in this case.

Using the SQLite Truncate Optimization

When the WHERE clause is omitted from a DELETE statement and the table being deleted has no triggers, SQLite uses an optimization to erase the entire table content without having to visit each row of the table individually. This “truncate” optimization makes the delete run much faster.

Prior to SQLite version 3.6.5, the truncate optimization also meant that the sqlite3_changes() and sqlite3_total_changes() interfaces and the count_changes pragma will not actually return the number of deleted rows. This problem has been fixed as of version 3.6.5.

Using SQLiteDatabase.delete()

You can also use the following syntax to delete a table in SQLite:

SQLiteDatabase db= this.getWritableDatabase();
        db.delete(TABLE_NAME, null, null);

Checking if a Table Exists

If you want to check if a table exists, you can use the following syntax:

SELECT name FROM sqlite_master where name=""

If the table name does not exist then there would not be any records returned.

You can also use the following syntax to check if a table exists:

SELECT count(name) FROM sqlite_master where name=""

If the count is 1, it means that the table exists. Otherwise, it will return 0.

Using the VACUUM Command

After deleting, it is also recommended to use the VACUUM command. To achieve a full truncate equivalent, use the following code:

DELETE FROM ;
UPDATE SQLITE_SEQUENCE SET seq = 0 WHERE name="";
VACUUM;

Conclusion
