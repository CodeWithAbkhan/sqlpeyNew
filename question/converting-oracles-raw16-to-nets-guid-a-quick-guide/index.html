Introduction

As a developer, you might come across scenarios where you need to debug an application that involves GUID data. Although, you may notice that the GUID values differ between .NET and Oracle, making it challenging to debug. In this post, we will explore how to manually debug an application where the GUID values differ between .NET and Oracle and how to convert from Oracle’s RAW(16) to .NET’s GUID.

The Problem

Let us consider the following example -

  • C# reads: 17D89D326C2142D69B989F5201288DBF

  • Oracle reads: 329DD817216CD6429B989F5201288DBF

    As we can see, the first 9 bytes of the .NET GUID and Oracle’s RAW(16) are switched around, and the last 7 bytes remain the same.

Solution

To convert from Oracle’s RAW(16) to .NET’s GUID, we need to switch the first 9 bytes of the Oracle’s RAW(16) bytes with the .NET GUID bytes. We can rewrite the above example by rewriting each pair in the .NET as 00, 11, 22, etc., and switching the relevant byte of Oracle as well:

  • Oracle:

      33221100554477668899AABBCCFFEEFF

Summary

Practical Example

Consider a scenario where you have an application that uses a database with Oracle’s RAW(16) data type to store GUIDs. You would like to convert these GUIDs to .NET’s GUID data type. Here’s an example code snippet that demonstrates this:

using Oracle.DataAccess.Client;
using System;

class Program
{
    static void Main()
    {
        string oracleGuid = "329DD817216CD6429B989F5201288DBF";
        byte[] bytes = new byte[16];
        for (int i = 0; i < 16; i++)
        {
            bytes[i] = Convert.ToByte(oracleGuid.Substring(i * 2, 2), 16);
        }
        Guid guid = new Guid(bytes);

        Console.WriteLine("Oracle GUID: " + oracleGuid);
        Console.WriteLine("Converted to .NET GUID: " + guid);
    }
}

In this example, we are first fetching the Oracle GUID as a string, and then we are initializing a byte array of length 16. Next, we are looping through each character of the Oracle GUID and converting it to a byte. Lastly, we are using the Guid constructor to create a GUID from the byte array. The output of the above code will be:

Oracle GUID: 329DD817216CD6429B989F5201288DBF
Converted to .NET GUID: 17d89d32-6c21-42d6-9b98-9f5201288dbf

As we can see, the Oracle GUID has been successfully converted to .NET GUID.
