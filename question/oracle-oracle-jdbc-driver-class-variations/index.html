Summary

Oracle provides JDBC Driver classes for Java developers to connect their Java application with Oracle database. The two JDBC driver classes provided by Oracle are oracle.jdbc.driver.OracleDriver and oracle.jdbc.OracleDriver, but the use of oracle.jdbc.driver.OracleDriver class is deprecated and it will be discontinued in the future releases. Hence, developers are advised to use the oracle.jdbc.OracleDriver class for connections with Oracle 9i onwards.

What is JDBC Driver?

Java Database Connectivity (JDBC) is a Java-based API provided by JDBC driver vendors that allow Java developers to connect and execute SQL queries with various databases including Oracle, MySQL, MS SQL Server, etc. A JDBC driver is a software component that enables Java applications to interact with the database via JDBC API calls.

Difference between oracle.jdbc.driver.OracleDriver vs. oracle.jdbc.OracleDriver

oracle.jdbc.driver.OracleDriver

This JDBC driver class is provided by Oracle for versions up to Oracle 8i. Although, Oracle has deprecated the use of this driver class from Oracle 9i onwards and it will be discontinued in the future releases. Despite that, it is still being used in many applications.

oracle.jdbc.OracleDriver

This is the new driver class provided by Oracle for Oracle 9i onwards. It is recommended to use this JDBC driver class for connecting a Java application with Oracle database. This driver class is a part of the oracle.jdbc package which provides additional functionality to connect with the database like connection pooling, distributed transactions, and high-availability features.

Why should you use oracle.jdbc.OracleDriver?

The oracle.jdbc.driver.OracleDriver class is deprecated in later versions of Oracle and will be discontinued in future releases. Oracle recommends using oracle.jdbc.OracleDriver instead, as it provides more features and functionality and is also more compatible with newer versions of Oracle. Using it will improve the performance, security and stability of the application.

How to use oracle.jdbc.OracleDriver?

To connect a Java application with Oracle database using oracle.jdbc.OracleDriver the following steps need to be followed: 1. Download the Oracle JDBC driver from Oracle’s website. 2. Add the Oracle JDBC driver jar file (such as ojdbc10.jar) to your project’s classpath. 3. Write a Java program to connect with the database using the following code snippet:

try {
  Class.forName("oracle.jdbc.OracleDriver");
  Connection connection = DriverManager.getConnection("jdbc:oracle:thin:@localhost:1521:orcl", "username", "password");
  // perform database operations here
  connection.close();
} catch (ClassNotFoundException | SQLException e) {
  e.printStackTrace();
}

In line 2, we are registering the oracle.jdbc.OracleDriver class with the help of the Class.forName() method. In line 3, we are establishing a connection to the database using the DriverManager class’s getConnection() method with the database URL, username and password. In line 4, we can perform database operations using the connection object and then close it using the close() method in line 6.

Practical Example

Suppose we want to connect to Oracle Database using oracle.jdbc.OracleDriver and execute a SQL query in Java, then we can use the following code snippet:

try {
    Class.forName("oracle.jdbc.OracleDriver");
    Connection connection = DriverManager.getConnection("jdbc:oracle:thin:@localhost:1521:orcl", "username", "password");
    Statement statement = connection.createStatement();
    ResultSet resultSet = statement.executeQuery("SELECT * FROM Employees");
    while (resultSet.next()) {
        System.out.println(resultSet.getString("EmployeeID") + " | " +
                resultSet.getString("FirstName") + " | " +
                resultSet.getString("LastName"));
    }
    resultSet.close();
    statement.close();
    connection.close();
} catch (ClassNotFoundException | SQLException e) {
    e.printStackTrace();
}

In the code above, we are retrieving data from the Employees table and printing the EmployeeID, FirstName, and LastName columns of each record.

Alternative Ways

Apart from using the oracle.jdbc.OracleDriver class, developers can use other third-party JDBC drivers such as MySQL Connector/J, PostgreSQL JDBC driver, or Microsoft SQL Server JDBC Driver to connect with their respective databases.

Recap

In recap, Oracle provides two JDBC driver classes for Java developers to connect their Java application with Oracle database, oracle.jdbc.driver.OracleDriver and oracle.jdbc.OracleDriver.
