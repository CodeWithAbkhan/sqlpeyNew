SQL: Maximizing Collaboration: Key Metrics for Optimal User Engagement How to Dump Data from SQLite3 Tables?
If you have an SQLite3 database and you want to extract only the data from some specific tables and not the entire database schema, you can achieve this using the command line tool called sqlite3. This Q&A Session will show a step-by-step guide on how to dump data from SQLite3 tables.

Prerequisites

  • An SQLite3 database with data
  • Command line interface

Steps to Dump Data from Selected Tables

The following commands will allow you to dump data only from selected tables:

  1. Open the command line interface and navigate to the directory containing your database file.

  2. Enter the command below:

     sqlite3 myDatabase.db

    Note: Replace myDatabase.db with the name of your database file.

  3. You will now see the SQLite3 command prompt, which looks like this:

     SQLite>

  4. To list all the tables in the database, enter the following command:

     .tables

  5. Select the tables you want to extract data from. Let’s assume you want to extract data from two tables - “employees” and “projects”.

  6. Now, run the following command to extract data from the selected tables:

     .dump employees projects > myDump.sql

    Note: This command writes the SQL commands that recreate the specified tables and its data into the file myDump.sql. You can specify any file name you want as long as it has the .sql extension.

  7. The dump file myDump.sql will now be created in the current directory, containing the SQL commands to recreate only the specified tables and their data.

  8. Exit the SQLite3 command prompt by typing:

     .exit

Code Explanation

The command .dump is used to generate a full SQL dump of the database, including both schema and data. Although, if we specify table names after the .dump command, it only generates SQL dump for those tables that we specified, thus dumping only the data from the selected tables.

The symbol > is used to redirect the dump output to the file myDump.sql. The file name can be any desired name or extension.

Practical Example

Let’s say we have an SQLite database named “myDatabase.db” with two tables - “employees” and “projects”. The following are the steps to dump data from these tables:

  1. Open a command prompt and navigate to the directory containing myDatabase.db.
  2. Enter the command “sqlite3 myDatabase.db”.
  3. At the SQLite3 prompt, enter “.tables” to see a list of all tables in the database.
  4. Enter the command “.dump employees projects > myDump.sql” to generate the data dump and redirect it to a file “myDump.sql”.
  5. The data dump file “myDump.sql” will now be created in the current directory.
  6. Exit the SQLite3 prompt by typing “.exit”.

Alternative Ways

Another way to dump data from selected tables in SQLite3 is to write a SELECT statement that retrieves all records for the specified tables and save that output as a CSV file. Here is an example:

.mode csv
.headers on
.output myData.csv
SELECT * FROM employees;
SELECT * FROM projects;
.output stdout

This command exports the data in CSV format instead of SQL format. The data is saved to “myData.csv” file in current working directory.

Recap

Dumping data from selected tables in SQLite3 database can be done easily using the command-line tool. You can use the .dump command followed by the table names you want to export, and the output can be redirected to a file. More, exporting data in CSV format is an alternative option if you want to export to other tools that support CSV files. ]]>
