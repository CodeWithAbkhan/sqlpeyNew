Disabling Oracle Password Expiration: A Quick Guide How to Disable Password Expiration in Oracle?
Working with Oracle for development can be a hassle if you have to keep resetting passwords due to expiration. Password expiration is enabled by default in Oracle 11g, but it can be turned off to avoid the inconvenience. In this Q&A Session, we will explain how to turn off the password expiration in Oracle in a simple Q&A style.

How do I check which user profile is being used?

You can check the profile being used by a specific user with the following SQL query:

SELECT profile FROM DBA_USERS WHERE username = '';

Replace <username> with the name of the user you want to check.

How to turn off password expiration for a user profile?

To disable password expiration for a profile in Oracle, first, check the limit with the following SQL query:

SELECT resource_name, limit FROM dba_profiles WHERE profile = '';

Here, <profile_name> is the name of the profile you want to edit.

Then, alter the profile limit to never expire with:

ALTER PROFILE  LIMIT PASSWORD_LIFE_TIME UNLIMITED;

This will turn off the password expiration limit for that specific profile.

How to disable the password policy for development purposes?

If you want to disable the password policy for development purposes, you can alter the ‘DEFAULT’ profile with the following SQL query:

ALTER PROFILE "DEFAULT" LIMIT PASSWORD_VERIFY_FUNCTION NULL;

This will disable the password expiration limit for all users using the ‘DEFAULT’ profile.

After disabling the password expiration limit, you may reset the user’s password and unlock the account with the following SQL command:

ALTER USER  IDENTIFIED BY  ACCOUNT UNLOCK;

Replace <user_name> with the name of the user account you want to modify, and <new_password> with the new password you want to set. This command will reset the password and unlock the user account, ensuring it no longer expires.

Alternative way to unlock accounts with expired password but not locked

If the account is in the grace period and the password is expired but not yet locked, using the above SQL query will not be effective. In that case, you will need to use the following command to unlock the user’s account:

ALTER USER  ACCOUNT UNLOCK;

This will unlock the user’s account, even if the password is expired but not locked. Note that this should only be used when necessary, as it does not reset the password.

Example: Disabling Password Expiration for the ‘DEFAULT’ Profile

Here is an example of how to disable password expiration for the ‘DEFAULT’ profile:

ALTER PROFILE "DEFAULT" LIMIT PASSWORD_VERIFY_FUNCTION NULL;

This command will disable the password expiration limit for all users using the ‘DEFAULT’ profile.
