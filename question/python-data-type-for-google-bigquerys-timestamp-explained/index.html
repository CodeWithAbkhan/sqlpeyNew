Python Data Type for Google Bigquery’s TIMESTAMP
If you are loading data into Google’s BigQuery using the google-cloud-python library, you may need to check the data types of the data you are importing to ensure they match the datatypes in the schema for the target table. To do this you can convert a python object type to the GBQ equivalent, but you may be wondering what the equivalent data type is in Python for Google Bigquery’s TIMESTAMP.

To find the equivalent data type, you can consult the Google Cloud Python library documentation (http://google-cloud-python.readthedocs.io/en/latest/index.html ).

Python Data Types for Google Bigquery Supported Datatypes

For reference, here are the Python data types for the supported Google Bigquery datatypes:

  • STRING - str, unicode
  • BYTES - bytes
  • INTEGER - int, long
  • FLOAT - float
  • BOOLEAN - bool
  • DATE - datetime.date
  • TIME - datetime.time
  • DATETIME - datetime.datetime
  • TIMESTAMP - datetime.datetime with timezone

Python Code to Convert Data Types for Google Bigquery

To convert a Python object type to the GBQ equivalent, you can use the following code:

import datetime 

def convert_type_to_bigquery(object_type):
    if isinstance(object_type, str):
        return 'STRING'
    elif isinstance(object_type, bytes):
        return 'BYTES'
    elif isinstance(object_type, int):
        return 'INTEGER'
    elif isinstance(object_type, float):
        return 'FLOAT'
    elif isinstance(object_type, bool):
        return 'BOOLEAN'
    elif isinstance(object_type, datetime.date):
        return 'DATE'
    elif isinstance(object_type, datetime.time):
        return 'TIME'
    elif isinstance(object_type, datetime.datetime):
        if isinstance(object_type, datetime.datetime with timezone):
            return 'TIMESTAMP'
        else:
            return 'DATETIME'
    else:
        return None

Note that to check for the Python data type equivalent for Google Bigquery’s TIMESTAMP, you can use the isinstance() method with the datetime.datetime with timezone object type.

Here is an example of how to use the convert_type_to_bigquery() function in a practical setting:

from google.cloud import bigquery

def load_data_to_bigquery(dataset_id, table_id, rows_to_insert):
    client = bigquery.Client()
    dataset_ref = client.dataset(dataset_id)
    table_ref = dataset_ref.table(table_id)
    table = client.get_table(table_ref)
    errors = 0
    
    for row in rows_to_insert:
        row_data = []
        for value in row:
            row_data.append(value)
            # Convert Python data type to Bigquery data type
            converted_type = convert_type_to_bigquery(value)
        try:
            errors += client.insert_rows(table, [row_data])
        except:
            errors += 1

    if errors > 0:
        print('Failed to insert {} rows into table {}.{}.'.format(
            errors, dataset_id, table_id))
    else:
        print('Successfully inserted {} rows into table {}.{}.'.format(
            len(rows_to_insert), dataset_id, table_id))

In this example, we are inserting rows of data into a Google Bigquery table. We first establish a connection to the client, dataset, and table using the google-cloud-python library. We then iterate through each row of data to insert and convert the Python data type to the equivalent Google Bigquery data type. We insert the rows of data into the table and handle any errors.
