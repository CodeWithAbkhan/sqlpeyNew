ORACLE: Configuring Glassfish Server in Eclipse Manually Summary:

This blog post will explain how to manually configure GlassFish Server in Eclipse Luna. It will guide you through the steps to set it up using Eclipse WTP and how to download and install GlassFish tools in Eclipse. It will also provide alternative methods if needed.

Step-by-Step Guide:

  1. Download Eclipse IDE for Java EE developers:

To start, you need to download the Eclipse IDE for Java EE Developers version. You can download the latest version which is Luna 4.4 from the official Eclipse website.

  1. Open Server View:

To open the server view, go to the menu “Windows\Show view\Other”. From the list of options, select the “Server” folder and click on the “Servers” option.

  1. Create a New Server:

In the Servers view, right-click on any blank area to use the context menu, and select “New\Server”. This action will open the “New Server” wizard.

  1. Download GlassFish Tools:

In the “New Server” wizard, you will see a link that says “Download additional server adapters.” Click on this link to download the GlassFish tools.

  1. Choose GlassFish Tools:

From the list of available server adapters, choose “GlassFish Tools” from the Oracle vendor.

  1. Restart Eclipse:

After completing the installation of GlassFish tools, restart your Eclipse IDE to ensure that the configuration process is complete.

Alternative Ways:

If you don’t want to use the “Download additional server adapters” option, you can install GlassFish tools manually.

To do so, follow these steps:

  1. Download GlassFish Tools:

You can download GlassFish tools from the Eclipse marketplace or directly from the developer’s website.

  1. Install GlassFish Tools:

After downloading the GlassFish tools, go to the Eclipse IDE and select “Help\Install New Software.” In the “Work with” text field, paste the link from where GlassFish tools were downloaded. Check the “GlassFish Tools” option and click “Next” to complete the installation process.

Practical Examples:

Once you have completed the server configuration process in Eclipse, you can start deploying your web applications to GlassFish. For example, you can create a new Dynamic Web project in Eclipse and select “GlassFish Server” as the target runtime.

You can also create a database connection and deploy it to GlassFish using Eclipse’s database tools.

Recap:

In recap, configuring GlassFish Server in Eclipse Luna is a simple process that can be done manually. You can use the “Download additional server adapters” option or install GlassFish tools manually to complete the setup process. With this setup, you can deploy web applications to GlassFish in Eclipse and manage the server easily.
