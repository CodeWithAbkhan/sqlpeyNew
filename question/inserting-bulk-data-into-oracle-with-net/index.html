Inserting Bulk Data into Oracle with NET Fastest Way to Perform a Bulk Insert to Oracle Using .NET If you need to transfer a large number of records (e.g., 160K) from a MySQL database to an Oracle database using .NET, using an insert statement and executing it 160K times will take about 25 minutes. A better way to do this is by using bulk insert. The following Q&A style post will show you how to perform a bulk insert to Oracle using .NET and how to make your code efficient and unique.

What is Bulk Insert?

Bulk insert is a process of inserting large amounts of data into a database at once instead of executing an insert statement multiple times. It is a faster way of transferring large amounts of data from one database to another.

How to Perform Bulk Insert to Oracle Using .NET?

The fastest way to perform a bulk insert to Oracle using .NET is by using the Array Binding feature in ODP.NET. Here’s an example of how to do it:

// Create a connection to Oracle
using (OracleConnection connection = new OracleConnection(connectionString))
{
    connection.Open();

    // Create a command that will call a stored procedure
    using (OracleCommand command = new OracleCommand("insert_data", connection))
    {
        // Set the command type to stored procedure
        command.CommandType = CommandType.StoredProcedure;

        // Create parameters for the stored procedure
        command.Parameters.Add("param1", OracleDbType.Int32, ParameterDirection.Input);
        command.Parameters.Add("param2", OracleDbType.Varchar2, ParameterDirection.Input);

        // Create a DataTable that will hold the data to be inserted
        DataTable dataTable = new DataTable();
        dataTable.Columns.Add(new DataColumn("param1", typeof(int)));
        dataTable.Columns.Add(new DataColumn("param2", typeof(string)));

        // Add data to the DataTable
        for (int i = 0; i < 160000; i++)
        {
            DataRow dataRow = dataTable.NewRow();
            dataRow["param1"] = i;
            dataRow["param2"] = "Some text " + i;
            dataTable.Rows.Add(dataRow);
        }

        // Bind the DataTable to the command
        command.ArrayBindCount = dataTable.Rows.Count;
        command.Parameters[0].Value = dataTable.Columns[0].ToArray();
        command.Parameters[1].Value = dataTable.Columns[1].ToArray();

        // Execute the command
        command.ExecuteNonQuery();
    }
}

In the above code, we first create a connection to Oracle and open it. Then, we create an OracleCommand that will call a stored procedure named “insert_data”. We create two parameters for the stored procedure – “param1” of type Int32 and “param2” of type Varchar2.

Next, we create a DataTable that will hold the data to be inserted. We add 160K records to the DataTable. The next step is to bind the DataTable to the command using the ArrayBindCount property and set the values of the parameters using the ToArray() method.

Lastly, we execute the command using the ExecuteNonQuery() method.

Why Use Array Binding?

Array binding is faster than executing multiple insert statements because it reduces network traffic by sending the data in bulk. When we use an insert statement, the data is sent row by row, which can take a lot of time for large data sets.

Alternative Way to Perform Bulk Insert to Oracle Using .NET

Another alternative way to perform a bulk insert to Oracle using .NET is by using OracleBulkCopy, a specialized class in ODP.NET. Here’s how to do it:

// Create a connection to Oracle
using (OracleConnection connection = new OracleConnection(connectionString))
{
    connection.Open();

    // Create an OracleBulkCopy object
    using (OracleBulkCopy bulkCopy = new OracleBulkCopy(connection))
    {
        // Set the destination table
        bulkCopy.DestinationTableName = "MyTable";

        // Create a DataTable that will hold the data to be inserted
        DataTable dataTable = new DataTable();
        dataTable.Columns.Add(new DataColumn("col1", typeof(int)));
        dataTable.Columns.Add(new DataColumn("col2", typeof(string)));

        // Add data to the DataTable
        for (int i = 0; i < 160000; i++)
        {
            DataRow dataRow = dataTable.NewRow();
            dataRow["col1"] = i;
            dataRow["col2"] = "Some text " + i;
            dataTable.Rows.Add(dataRow);
        }

        // Write the DataTable to Oracle
        bulkCopy.WriteToServer(dataTable);
    }
}

In the above code, we first create a connection to Oracle and open it. We then create an OracleBulkCopy object and set the destination table. Next, we create a DataTable and add 160K records to it. Lastly, we use the WriteToServer() method of the OracleBulkCopy object to write the DataTable to Oracle.

Summary

Bulk insert is a faster way of transferring large amounts of data from one database to another. In .NET, the fastest way to perform a bulk insert to Oracle is by using the Array Binding feature in ODP.NET. Alternatively, you can use OracleBulkCopy to write a DataTable to Oracle. Both methods reduce network traffic by sending data in bulk, which results in faster data transfer. ]]>
