ORACLE: Enabling SQL Statement Logging with JDBC Enabling Logging for SQL Statements when using JDBC
When using JDBC, it is often helpful to enable logging for SQL statements in order to debug and optimize queries. In this blog post, we will go through the steps to enable logging for SQL statements when connecting to an Oracle database using JDBC in Eclipse IDE.

Step 1: Add Required Libraries

First, we need to ensure that we have the required JDBC driver library for the Oracle database. We can download the latest version of the Oracle JDBC driver from the Oracle website and add it to our project’s build path. We also need to add the logging framework that we will be using. In this example, we will be using Java’s built-in logging framework.

Step 2: Create Logging Configuration File

We need to create a logging configuration file to configure the settings for our logging framework. In this example, we will create a file named OracleLog.properties in our project’s root directory. Here is the contents of the file:

handlers=java.util.logging.FileHandler
.level=FINE
java.util.logging.FileHandler.pattern=log/OracleLog.log
java.util.logging.FileHandler.limit=1000000
java.util.logging.FileHandler.count=10
java.util.logging.FileHandler.formatter=java.util.logging.SimpleFormatter

oracle.jdbc.level=FINE
oracle.jdbc.handlers=java.util.logging.FileHandler
oracle.jdbc.formatter=java.util.logging.SimpleFormatter
oracle.jdbc.FileHandler.pattern=log/oracle.log
oracle.jdbc.FileHandler.limit=1000000
oracle.jdbc.FileHandler.count=10

This configuration file sets the logging level to FINE and specifies that log files should be stored in a subdirectory named “log”. It also configures logging for the Oracle JDBC driver specifically.

Step 3: Enable Logging in JDBC Program

We need to enable logging within our JDBC program code in order for the logging configuration to take effect. Here is an example program:

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;
import java.util.logging.Level;
import java.util.logging.Logger;

public class LoggingDemo {
    public static void main(String[] args) {
        Logger logger = Logger.getLogger(LoggingDemo.class.getName());
        logger.setLevel(Level.FINE);
        String url = "jdbc:oracle:thin:@localhost:1521:XE";
        String user = "yourUsername";
        String password = "yourPassword";
        try {
            DriverManager.registerDriver(new oracle.jdbc.driver.OracleDriver());
            Connection conn = DriverManager.getConnection(url, user, password);
            logger.info("Connected to database successfully");
            conn.close();
            logger.info("Connection closed successfully");
        } catch (SQLException ex) {
            logger.log(Level.SEVERE, ex.getMessage(), ex);
        }
    }
}

Here, we set the logging level to FINE and create a logger object. We then connect to the Oracle database using the DriverManager class and log the successful connection. Lastly, we close the connection and log the successful closure. If any SQLExceptions occur, we log the error using the logger object.

Step 4: View Log Output

After running the JDBC program, we can view the log output in the log files specified in the logging configuration file. In this example, we set the log files to be stored in a subdirectory named “log”. We can open the log files in a text editor or IDE to view the logged SQL statements and other information.

Alternative Method: Using Log4j

Another popular logging framework that can be used instead of Java’s built-in logging framework is Log4j. To use Log4j for logging in JDBC, we would need to add the Log4j library to our project’s build path and configure a Log4j configuration file instead of a Java logging configuration file. Here is an example Log4j configuration file:

# Log4j configuration file
log4j.rootLogger=INFO, console, file

# Console appender
log4j.appender.console=org.apache.log4j.ConsoleAppender
log4j.appender.console.layout=org.apache.log4j.PatternLayout
log4j.appender.console.layout.ConversionPattern=%-4r [%t] %-5p %c %x - %m%n

# File appender
log4j.appender.file=org.apache.log4j.RollingFileAppender
log4j.appender.file.File=log/logfile.log
log4j.appender.file.MaxFileSize=100KB
log4j.appender.file.MaxBackupIndex=10
log4j.appender.file.layout=org.apache.log4j.PatternLayout
log4j.appender.file.layout.ConversionPattern=%d{ABSOLUTE} %5p - %m%n
