ORACLE: Comparing Strings in SQL: Ignoring Case How to Compare Strings in SQL Ignoring Case
When comparing strings in SQL, it is sometimes necessary to ignore the case of the strings being compared. This is useful in scenarios where the strings may be capitalized differently or in situations where users may input data in various case formats.

Using UPPER Keyword in Oracle

In an Oracle database, you can use the UPPER keyword to convert all characters in a string to uppercase. When performing a comparison, you can convert both strings to uppercase before comparing them. This ensures that the comparison is case-insensitive.

For example, the following query will return all records where the LastName column is equal to “ANGEL” regardless of the case format of the text:

SELECT *
FROM Customers
WHERE UPPER(LastName) = UPPER('AnGel')

The UPPER keyword can also be used in a LIKE statement to perform case-insensitive pattern matching. The following query will return all records containing the string “ANGEL” regardless of the case format of the text:

SELECT *
FROM Customers
WHERE UPPER(LastName) LIKE '%ANGEL%'

Using NLS_COMP and NLS_SORT Settings in Oracle

Another method of performing case-insensitive comparisons in Oracle is by setting the NLS_COMP and NLS_SORT session parameters. These settings specify the linguistic and sorting rules used to compare strings. By setting the parameters to LINGUISTIC and BINARY_CI respectively, you can enable case-insensitive comparisons.

You can set the NLS_COMP and NLS_SORT session parameters using the ALTER SESSION command. Here’s how you can set these parameters:

ALTER SESSION SET NLS_COMP=LINGUISTIC;
ALTER SESSION SET NLS_SORT=BINARY_CI;

After setting these parameters, you can compare strings using standard comparison operators such as =, .

For example, you can compare two strings like this:

SELECT *
FROM customers
WHERE name = 'Angel';

This query will return all records where the Name column is equal to “Angel” regardless of the case format of the text.

Using LOWER Keyword in MS SQL Server

In MS SQL Server, you can use the LOWER keyword to convert all characters in a string to lowercase. This keyword works similarly to the UPPER keyword in Oracle.

For example, the following query will return all records where the LastName column is equal to “angel” regardless of the case format of the text:

SELECT *
FROM Customers
WHERE LOWER(LastName) = LOWER('AnGel')

Like the UPPER keyword in Oracle, the LOWER keyword can also be used in a LIKE statement to perform case-insensitive pattern matching.

Example

Suppose you have the following table called “Students”:

| Id | Name |

| — | — |

| 1 | John Smith |

| 2 | Jane Doe |

| 3 | john smith |

| 4 | JANE DOE |

You can use the following query to retrieve all the students where the name is equal to “John Smith” regardless of the case format of the text:

SELECT *
FROM Students
WHERE UPPER(Name) = UPPER('john smith')

This will return the first and third row.

Recap

Comparing strings in a case-insensitive manner can be helpful in ensuring that your queries work accurately regardless of the case format of the text. Oracle and MS SQL Server provide their own methods to perform case-insensitive comparisons.
