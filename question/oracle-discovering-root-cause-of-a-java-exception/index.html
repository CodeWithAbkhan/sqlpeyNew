ORACLE: Discovering the root cause of a Java exception How to Find the First Cause of an Exception in Java

Introduction

When working with exceptions in Java, it is sometimes necessary to find the root cause of an exception. This is particularly useful when dealing with nested exceptions. If an exception is caused by a problem with a database, for example, foremost to identify this so that appropriate action can be taken. In this Q&A Session, we will discuss how to find the first cause of an exception in Java.

Code Explanation

The following code shows a method for finding the first cause of an exception:

private String getErrorOracle(Throwable e){
        final String ORACLE = "ORA";
        if (e.getCause() != null && e.getCause().toString().contains(ORACLE)){
            return e.getCause().toString();
        } else if(e.getCause() != null){
            return getErrorOracle(e.getCause());
        } else {
            return null;
        }
    }

The method takes a Throwable object as a parameter and checks if it has a cause. If it does, it checks if the cause contains the string “ORA”. If it does, it returns the cause as a string. If it doesn’t, it recursively calls itself with the cause as the parameter until a cause with no cause is found. If no cause contains the string “ORA”, it returns null.

Alternative Ways

If you are using Apache Commons Lang, you can use the ExceptionUtils.getRootCause() method to find the root cause:

Throwable rootCause = ExceptionUtils.getRootCause(exception);

If you are using Guava, you can use the Throwables.getRootCause() method to find the root cause:

Both methods return the root cause as a Throwable object.
