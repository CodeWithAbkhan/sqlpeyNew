ORACLE: Setting Auto Increment Column with SQL Developer How to Set Auto-Increment Column with SQL Developer

Oracle SQL Developer is a free graphical tool used by Oracle developers and database administrators. If you want to make your primary key (PK) auto-increment, you can follow these steps:

  1. Right-click on the table you want to edit and select “Edit” from the dropdown menu.

  2. In the “Edit” Table window, select “Columns” and then select the PK column that you want to auto-increment.

  3. Go to the “ID Column” tab and select “Column Sequence” as the Type. This will create a trigger and a sequence and associate the sequence with the PK.

  4. Save your changes, and your PK column will now auto-increment whenever a new row is added to the table.

To better know this process, let’s take a closer look at each step:

Step 1: Right-click on the table and select “Edit.” In the Oracle SQL Developer tool, you can edit existing tables by right-clicking on them in the left-hand panel and selecting “Edit” from the dropdown menu. This will open the “Edit” Table window.

Step 2: Select the PK column. Once you are in the “Edit” Table window, select “Columns” from the tabs at the top, and then select the PK column that you want to make auto-increment.

Step 3: Go to the “ID Column” tab and select “Column Sequence” as the Type. After selecting your PK column, go to the “ID Column” tab at the bottom of the window. From there, select “Column Sequence” as the Type. This will create a sequence object and a trigger object that will associate the sequence with the PK column.

Step 4: Save your changes. Once you have selected “Column Sequence,” you can save your changes to the table. From now on, whenever a new row is inserted into this table, the PK column will automatically increment by one.

Alternative Method: Creating a Sequence and Trigger Object If you prefer to create the sequence and trigger objects manually, you can use the following SQL code:

CREATE SEQUENCE my_sequence START WITH 1 INCREMENT BY 1 CACHE 10;

CREATE OR REPLACE TRIGGER my_trigger BEFORE INSERT ON my_table FOR EACH ROW BEGIN SELECT my_sequence.nextval INTO :new.id FROM dual; END; /

This code creates a sequence named “my_sequence” that starts at 1 and increments by 1 with a cache size of 10. The trigger “my_trigger” is created to fire before an insert into “my_table.” The trigger selects the next value from the “my_sequence” sequence and assigns it to the “id” column of the inserted row.

Summary Auto-incrementing a column in Oracle SQL Developer requires a sequence object and a trigger object to be associated with the PK column. You can create these objects manually or use the built-in features of Oracle SQL Developer to set up auto-incrementing columns. Either way, the result is the same: the PK column will automatically increment by one for each new row inserted into the table.]]>
