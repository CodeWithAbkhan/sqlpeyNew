Calculating Average Time to Get a Reply on Stack Overflow using BigQuery SQL
In this post, we will discuss how to calculate the average time to get a reply on Stack Overflow using BigQuery SQL. We will also explore various techniques such as calculating average, geometric mean, removing outliers, and median.

Learning the Code

The code uses the public dataset bigquery-public-data.stackoverflow which contains information related to Stack Overflow questions and answers. It calculates the average time taken to get the first reply to a question on Stack Overflow.

The code can be divided into three parts:

Part 1: Data Preparation

WITH question_answers AS (
  SELECT * 
    , timestamp_diff(answers.first, creation_date, minute) minutes
  FROM (
    SELECT creation_date
      , (SELECT AS STRUCT MIN(creation_date) first, COUNT(*) c
         FROM `bigquery-public-data.stackoverflow.posts_answers` b
         WHERE a.id=b.parent_id
        ) answers
      , SPLIT(tags, '|') tags
    FROM `bigquery-public-data.stackoverflow.posts_questions` a
    WHERE EXTRACT(year FROM creation_date) > 2015
  ), UNNEST(tags) tag
  WHERE tag IN ('java', 'javascript', 'google-bigquery', 'firebase', 'php')
  AND answers.c > 0
)

The code uses a common table expression (CTE) named question_answers to prepare the data. The CTE is created using the following steps:

  • Select the creation_date field from the posts_questions table and calculate the time difference between the earliest answer to the question and the question’s creation date using the timestamp_diff function. This value is stored in the minutes field.
  • Filter the questions based on the tags ‘java’, ‘javascript’, ‘google-bigquery’, ‘firebase’, and ‘php’ and select only those questions that have at least one answer.

Part 2: Data Aggregation

SELECT tag
  , COUNT(*) questions
  , ROUND(AVG(minutes), 2) first_reply_avg_minutes
FROM question_answers
GROUP BY tag

The code calculates the average time taken to get the first reply for each tag. It uses the AVG(minutes) function to calculate the average time taken and the ROUND(x,2) function to round off the value to 2 decimal places. The code also counts the number of questions for each tag using the COUNT(*) function and groups the data by the tag.

Calculating Alternative Metrics

Median

To calculate the median, we can use the MEDIAN(x) function. Although, this function is not available in BigQuery SQL. We can use a user-defined function (UDF) to calculate the median. Here’s an example:

CREATE TEMPORARY FUNCTION median(x ARRAY) AS (
  (SELECT 
     IF(MOD(ARRAY_LENGTH(x), 2) = 0, 
        (x[OFFSET(DIV(ARRAY_LENGTH(x), 2) - 1)] + x[OFFSET(DIV(ARRAY_LENGTH(x), 2))]) / 2,
        x[OFFSET(DIV(ARRAY_LENGTH(x), 2))]
      ) AS median_value 
   FROM (SELECT ARRAY(SELECT x ORDER BY x) AS x)
  )
);
