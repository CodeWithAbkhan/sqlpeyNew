ORACLE: Efficient Database Management with PLSQL INSERT, Subquery, and Returning PL/SQL Insert Into with Subquery and Returning Clause
In this post, we will explore how to use the INSERT INTO statement along with a subquery and RETURNING clause to insert data into a table and retrieve the generated ID in Oracle PL/SQL.

Syntax

The basic syntax for inserting data into a table using a subquery and returning the generated ID in PL/SQL is as follows:

INSERT INTO table_name (column1, column2, ...)
     SELECT value1, value2, ...
       FROM other_table
      WHERE condition
RETURNING id_column INTO local_variable;

Here, we start with the INSERT INTO statement and specify the table name and the columns we want to insert data into. Next, we use a subquery to select the values to be inserted into the table. We can use the WHERE clause to add conditions to the subquery to limit the data that is selected.

The RETURNING clause is used to retrieve the generated ID column from the inserted row. We specify the name of the ID column and the name of the local variable where we want to store the retrieved ID value.

Example

Let’s see an example of how to use this syntax to insert data into a table and retrieve the generated ID in PL/SQL.

CREATE TABLE users (
  id NUMBER GENERATED ALWAYS AS IDENTITY,
  name VARCHAR2(50),
  email VARCHAR2(100),
  phone VARCHAR2(20)
);

DECLARE
  v_id users.id%TYPE;
BEGIN
  INSERT INTO users (name, email, phone)
       SELECT 'John Doe', 'john.doe@example.com', '555-555-1234'
         FROM dual
   RETURNING id INTO v_id;
   DBMS_OUTPUT.PUT_LINE('New User ID: ' || v_id);
END;

In this example, we first create a table called users with an ID column that is generated automatically using the IDENTITY clause. We then use the INSERT INTO statement with a subquery to insert data into the table. We specify the values to be inserted in the subquery using the VALUES clause. We also use the dual table in the subquery to specify a constant value for the new row.

The RETURNING clause is used to retrieve the value of the generated ID column from the inserted row. We use the INTO keyword to specify the local variable where we want to store the retrieved ID value.

Lastly, we use the DBMS_OUTPUT.PUT_LINE procedure to display the retrieved ID value to the console.

Alternative Ways

There are a few alternative ways to achieve the same result using PL/SQL.

One way is to use a procedure or function with an OUT parameter to insert data into the table and retrieve the generated ID. We can then call the procedure or function and pass in the values to be inserted. The generated ID value will be stored in the OUT parameter.

CREATE PROCEDURE insert_user (
  p_name VARCHAR2,
  p_email VARCHAR2,
  p_phone VARCHAR2,
  p_id OUT NUMBER
) AS
BEGIN
  INSERT INTO users (name, email, phone)
  VALUES (p_name, p_email, p_phone)
  RETURNING id INTO p_id;
END;

DECLARE
  v_id NUMBER;
BEGIN
  insert_user('Jane Doe', 'jane.doe@example.com', '555-555-5678', v_id);
  DBMS_OUTPUT.PUT_LINE('New User ID: ' || v_id);
END;

In this example, we create a procedure called insert_user that takes in three input parameters for the name, email, and phone columns of the users table. We also specify an OUT parameter to store the generated ID value.

Inside the procedure, we use the INSERT INTO statement with the VALUES clause to insert data into the table. We use the RETURNING clause to retrieve the generated ID value, and we use the INTO keyword to store the value in the OUT parameter.

Lastly, we call the insert_user procedure and pass in the values to be inserted. The generated ID value is stored in the v_id local variable, which we display to the console using the DBMS_OUTPUT.PUT_LINE procedure.

Another way to achieve the same result is to use a cursor to loop through the inserted rows and retrieve the generated ID values. We can then process the retrieved IDs as needed.

DECLARE
  CURSOR c_users IS
    SELECT id FROM users;
  v_id users.id%TYPE;
BEGIN
  INSERT INTO users (name, email, phone)
       SELECT 'Alice Cooper', 'alice.cooper@example.com', '555-555-1234'
         FROM dual
   RETURNING id INTO v_id;
   
   FOR r_user IN c_users LOOP
     IF r_user.id = v_id THEN
       DBMS_OUTPUT.PUT_LINE('New User Found: ' || r_user.id);
     END IF;
   END LOOP;
END;

In this example, we create a cursor called c_users to select all the IDs from the users table. We also create a local variable called v_id to store the generated ID value.

Inside the PL/SQL block, we use the INSERT INTO statement with a subquery to insert a new row into the users table. We use the RETURNING clause and the INTO keyword to store the generated ID value in the v_id variable.

We then loop through the rows in the c_users cursor and check if the generated ID matches the ID of any of the existing rows. If we find a match, we display the ID value to the console using the DBMS_OUTPUT.PUT_LINE procedure.

Recap

In recap, the INSERT INTO statement along with a subquery and RETURNING clause is a amazing mechanism to insert data into a table and retrieve the generated ID in Oracle PL/SQL. We can use the basic syntax for this operation or explore alternative ways, such as using procedures or cursors, to achieve the same result more efficiently. ]]>
