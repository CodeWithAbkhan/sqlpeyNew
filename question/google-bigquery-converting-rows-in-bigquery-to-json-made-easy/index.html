Converting BigQuery Rows to JSON with Standard SQL
Converting rows in BigQuery to JSON can be useful when you need to reduce the data size for integration with other systems or APIs that only accept data in JSON format. In this post, we will explore how to convert rows in BigQuery to JSON using Standard SQL and different methods to achieve this goal.

Using TO_JSON_STRING Function

The easiest way to convert rows in BigQuery to JSON is by using the TO_JSON_STRING function, which converts a single row to JSON format.

The following example demonstrates how to convert the rows in the MyTable table to JSON using TO_JSON_STRING:

#standardSQL
WITH MyTable AS (
  SELECT 1 AS x, 'foo' AS y, true AS z UNION ALL
  SELECT 2, 'bar', false
)
SELECT TO_JSON_STRING(t) AS json
FROM MyTable AS t;

The above query will return two JSON strings that represent each row in the MyTable table. The output will be as follows:

+------------------------------------------------+
|                   json                         |
+------------------------------------------------+
| {"x":1,"y":"foo","z":true}                      |
| {"x":2,"y":"bar","z":false}                     |
+------------------------------------------------+

Converting BigQuery Table to a Single JSON Blob

If you want to convert the entire table to a JSON blob, you can use the STRING_AGG function to concatenate all the JSON strings together.

The following example demonstrates how to convert the entire MyTable table to a single JSON blob :

SELECT CONCAT("[", STRING_AGG(TO_JSON_STRING(t), ","), "]")
FROM `project.dataset.table` t

The above query will transform the rows in the MyTable table into a JSON blob with square brackets enclosing all the rows’ JSON strings. The output will look like this:

[
  {"x":1,"y":"foo","z":true},
  {"x":2,"y":"bar","z":false}
]

Alternative Ways

Besides using the TO_JSON_STRING function, another option to convert rows in BigQuery to JSON is by using a user-defined function (UDF).

Although, UDFs require that you declare the input types explicitly. Thus it might not be easy to generalize the function to work with different tables or schemas.

Recap

In recap, BigQuery provides a straightforward way to convert rows to JSON using the TO_JSON_STRING function. You can also transform the entire table into a single JSON blob using the STRING_AGG function. Both methods are useful when integrating BigQuery with other systems, APIs, or data pipelines. ]]>
