ORACLE: Discover Available Table Space for Free Summary:
This blog post will guide you on how to find the free space on a tablespace in Oracle database server using SQL statements. The post includes code snippets and descriptions explaining each line of code used to accomplish this task.

How to Find Free Space on Tablespace:

Step 1: Determine the Space Allocated to the Tablespace

The first step to determine the free space on a tablespace is to calculate the total space allocated to the tablespace. This can be done using the dba_data_files view, which contains information about all data files associated with the database.

SELECT tablespace_name, ROUND(SUM(bytes)/1024/1024) space_allocated
FROM dba_data_files
GROUP BY tablespace_name;

The SELECT statement retrieves the tablespace name and allocates space in megabytes by summing up the individual bytes for each data file. The GROUP BY clause ensures that each tablespace name appears only once in the result set.

Step 2: Determine the Space Used in the Tablespace

The second step is to determine the amount of space used in the tablespace. This can be done using the dba_free_space view, which provides information about the free space available in each data file associated with the database.

SELECT tablespace_name, ROUND(SUM(bytes)/1024/1024) space_used
FROM dba_free_space
GROUP BY tablespace_name;

The SELECT statement retrieves the tablespace name and the total amount of space used in megabytes by summing up the individual bytes for each data file. The GROUP BY clause ensures that each tablespace name appears only once in the result set.

Step 3: Determine the Space Free in the Tablespace

The third step is to determine the amount of free space in the tablespace. This can be calculated by subtracting the space used from the space allocated, as shown below.

SELECT a.tablespace_name,
    ROUND ((b.bytes/c.bytes)*100, 2) percentage_used,
    c.bytes/1024/1024 space_allocated,
    ROUND ((c.bytes/1024/1024) - (b.bytes/1024/1024), 2) space_used,
    ROUND (b.bytes/1024/1024, 2) space_free
FROM dba_tablespaces a,
     (   
         SELECT tablespace_name, SUM(bytes) bytes
         FROM dba_free_space
         GROUP BY tablespace_name
      ) b,
     (
         SELECT COUNT(1) datafiles, SUM(bytes) bytes, tablespace_name
         FROM dba_data_files
         GROUP BY tablespace_name
      ) c
WHERE a.tablespace_name = b.tablespace_name(+)
AND a.tablespace_name = c.tablespace_name;

This SQL statement retrieves all tablespace names, their percentage used, space allocated, space used, and space free. It uses the three views: dba_tablespaces, dba_free_space, and dba_data_files to calculate the free space on a tablespace. Along with, the statement performs an outer join between the dba_tablespaces and dba_free_space to ensure that all tablespace names are listed, regardless of whether there is free space in the tablespace or not.

Alternative Ways:

Another approach to determine the free space on a tablespace is by using the USER_TS_QUOTAS and USER_FREE_SPACE views. Although, this method has been known to produce inaccurate results. The USER_TS_QUOTAS view lists the quota limits set on tablespaces for each user, while USER_FREE_SPACE provides information about free space in each user’s default tablespace.

SELECT max_bytes - bytes AS free_space
FROM user_ts_quotas;

				

				  

SELECT SUM(NVL(bytes, 0)) AS free_space
FROM user_free_space;

The above two SQL statements are used to calculate the free space on a tablespace using the USER_TS_QUOTAS and USER_FREE_SPACE views. Although, as mentioned earlier, these views can produce inaccurate results, and thus, the recommended approach is to use the dba_tablespaces, dba_free_space, and dba_data_files views. Recap:
Database administrators can monitor the free space on tablespaces to prevent errors, and the SQL statements discussed above provide a reliable method of determining the free space on a tablespace in Oracle database servers.
