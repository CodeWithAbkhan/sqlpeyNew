Fixing Missing Artifact Error with Oracle JDBC Driver as it is already included in the question.

Problem

The user is getting an error “Missing artifact com.oracle:ojdbc6:jar:11.2.0.3” in their Maven project. Although, the jar file is present in the repository at the correct folder location.

Solution

There are a couple of ways to resolve this issue:

1. Add Jar File Manually

Since the binary license for the Oracle Driver JAR does not allow it to be added to the public Maven repository, you can download ojdbc6.jar manually from here .

Once downloaded, create a folder (let’s name it lib) in your project and add the ojdbc6.jar file to it.

Then, add the following dependency in your pom.xml file:

    com.oracle
    ojdbc
    11.2.0
    system
    ${basedir}/lib/ojdbc6.jar

This will add the ojdbc6.jar file to your project as a system dependency and the error should be resolved.

2. Install Jar File Locally

You can also install the ojdbc6.jar file in your local Maven repository using the following command:

mvn install:install-file -Dfile=path/to/ojdbc6.jar -DgroupId=com.oracle -DartifactId=ojdbc6 -Dversion=11.2.0 -Dpackaging=jar

Once installed, add the following dependency in your pom.xml file:

    com.oracle
    ojdbc6
    11.2.0

This will add the ojdbc6.jar file to your project from your local repository and the error should be resolved.

3. Remove the OJDBC6 Folder and Maven Update Project

If you are still facing the issue, you can try removing the ojdbc6 folder from the .m2 repository completely and then updating the project in Eclipse using Maven. This may resolve the issue for you.

4. Add Spring Repository

If you are using Spring Boot and none of the above solutions work, you can try adding the Spring repository to your pom.xml file:

        spring-releases
        https://repo.spring.io/libs-release

This may resolve the issue for you. ]]>
