Problem The user is trying to schedule a query to run intraday in Google BigQuery UI but encountering issues with the scheduler not accepting the correct cron syntax.

Solution

The documentation for the allowed cron syntax can be found directly on the Google Cloud Platform documentation, which provides a precise description of the allowed syntax. There are three different kinds of intervals that can be used: end-time intervals, start-time intervals, and custom intervals. The kind of interval is chosen implicitly by the schedule provided.

Allowed Syntax

The general syntax for the schedule should be of the following form:

[TYPE] [INTERVAL_VALUE] [INTERVAL_SCOPE]

End-Time Intervals

End-time intervals are intervals implemented from when the transfer is first created until a specific end time. There are two ways of specifying the end time:

EndTimeStartTime

EndTime specifies the end time of the interval, while StartTime specifies the time at which the transfer begins on the first day of the interval (in the UTC time zone). Examples of this include:

"every day 10:00"

				

				  

"every month 01,15 00:00"

Start-Time Intervals

Start-time intervals are intervals implemented from a fixed start time until a series of fixed end times. Examples of this include:

"every 2 hours from 10:00 to 16:00"

				

				  

"every day from 08:00 to 16:00 except weekends"

Custom Intervals

Custom intervals use a cron-like syntax for more complicated schedules. The syntax for this custom interval follows the cron syntax guidelines.

For example, the cron syntax below can be used to run every 6 hours:

0 */6 * * *

Practical Example

Suppose you want to schedule a query to run every weekday (Monday through Friday) at 9:00 am and 4:00 pm. The custom syntax for this would be:

0 9,16 * * 1-5

This will run the query at 9:00 am and 4:00 pm, from Monday to Friday.

Alternative Ways

Other alternative ways to schedule jobs in BigQuery include:

  • Scheduling jobs in the BigQuery API using one of the following: REST, JSON, or command line interface (CLI).
  • Scheduling jobs using third-party applications and tools like Airflow or Apache NiFi.
