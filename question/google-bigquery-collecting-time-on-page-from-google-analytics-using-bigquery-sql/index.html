Query for Collecting Time on Page from Google Analytics Data using BigQuery SQL
Are you looking for a way to extract the time on page for a specific page from Google Analytics data? This can be done using a BigQuery SQL query. In this post, we will provide a step-by-step guide on how to achieve this.

Overview

The goal is to get the time a user spends on a specific page. We can achieve this by subtracting the hits.time for the hit where the page was viewed from the hits.time of the following hit.

We will use the following dimensions: fullVisitorId, hits.hitsNumber, and hits.time.

The SQL Query

We can use the following SQL query to extract the time spent by each visitor on a particular page:

SELECT 
  fullVisitorId,
  hits.page.hostname,
  hits.page.pagePath,
  hits.hitNumber,
  hits.time,
  nextTime,
  (nextTime - hits.time) as timeOnPage
FROM(
  SELECT
    fullVisitorId, 
    hits.page.hostname,
    hits.page.pagePath,
    hits.hitNumber,
    hits.time,
    LEAD(hits.time, 1) OVER (PARTITION BY fullVisitorId, visitNumber ORDER BY hits.time ASC) as nextTime
  FROM [PROJECTID:DATASETID.ga_sessions_YYYYMMDD]
  WHERE hits.type = "PAGE"
)

Explanation of Code Line by Line

SELECT Statement

The first part of the code is the SELECT statement. It selects the following dimensions:

  • fullVisitorId: This is a unique identifier for each visitor to your website.
  • hits.page.hostname: This is the hostname of the page viewed by the visitor.
  • hits.page.pagePath: This is the page path of the page viewed by the visitor.
  • hits.hitNumber: This is the hit number of the hit when the page was viewed.
  • hits.time: This is the timestamp of the hit when the page was viewed.
  • nextTime: This is the timestamp of the next hit for each visitor.
  • timeOnPage: This is the calculated time spent by each visitor on the specific page.
FROM Statement

The FROM statement specifies the table we are querying. In this case, we are querying a Google Analytics session table:

FROM [PROJECTID:DATASETID.ga_sessions_YYYYMMDD]

The YYYYMMDD at the end of the table name represents the date range for which data will be retrieved.

WHERE Statement

The WHERE statement specifies the type of hit we want to retrieve. In this case, we are only interested in “PAGE” hits:

WHERE hits.type = "PAGE"
LEAD Function

The key to this code is the LEAD() function, which grabs the specified value from the next row in the partition, based on the PARTITION BY and ORDER BY qualifiers:

LEAD(hits.time, 1) OVER (PARTITION BY fullVisitorId, visitNumber ORDER BY hits.time ASC) as nextTime

This function allows us to get the next hit timestamp for each visitor. We can then subtract this value from the hit timestamp of the page viewed to get the time spent on that page.
