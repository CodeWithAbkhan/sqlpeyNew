Paginating BigQuery Results using Python

Introduction

Google’s BigQuery provides an option to paginate results using the tabledata.list() API. Although, if we want to run specific queries, there is no option to paginate the data directly. This can be a problem if we have a large dataset and need to fetch specific rows depending on query criteria. In this Q&A Session, we will explore ways to paginate BigQuery results using Python.

Paginating using tabledata.list() API

The tabledata.list() API allows us to specify a start index or a page token to fetch results in pages. Here’s an example of how we can use this API to fetch data from a specific table:

from google.cloud import bigquery

client = bigquery.Client()
dataset_ref = client.dataset('my_dataset')
table_ref = dataset_ref.table('my_table')

page_token = None
while True:
    rows, total_rows, page_token = client.list_rows(table_ref,
                                             max_results=100,
                                             page_token=page_token)
                                             
    for row in rows:
        # Do something with the row data
        print(row)
    
    if not page_token:
        break

In the code above, we first create a reference to our dataset and table using the bigquery client. We then set the page_token to None to start the pagination process. Inside the while loop, we call the list_rows() method to fetch the data. We set the max_results value to 100, which means that 100 rows will be fetched in each iteration. We also pass the page_token if it exists to fetch the next page of data. After fetching the data, we can perform any actions on the rows that were fetched.

Paginating specific queries using a LIMIT

If we want to run queries that return specific rows from the table, we can use the LIMIT clause in the SQL query to paginate the data. Here’s an example of how we can do this:

from google.cloud import bigquery

client = bigquery.Client()

query_job = client.query(
        'SELECT * FROM my_dataset.my_table LIMIT 500',
        project='my_project')

rows = list(query_job)
for row in rows:
    # Do something with the row data
    print(row)

In the code above, we create a QueryJob using the query() method from the bigquery client. We set the SQL query to select all rows from a specific table in our dataset and use the LIMIT clause to fetch only 500 rows at a time. We then iterate over the rows returned by our query and perform any actions that are required.

Paginating using a custom OFFSET

If we want to run queries that return specific rows from the table and we need to skip some rows, we can use the OFFSET clause in the SQL query to skip rows. Although, foremost to note that using OFFSET can be slow for large datasets as it has to scan through all the rows before it can get to the rows we are interested in. Here’s an example of how we can use the OFFSET clause to paginate the data:

from google.cloud import bigquery

client = bigquery.Client()

query_job = client.query(
        'SELECT * FROM my_dataset.my_table ORDER BY column1 OFFSET 500 LIMIT 500',
        project='my_project')

rows = list(query_job)
for row in rows:
    # Do something with the row data
    print(row)

In the code above, we create a QueryJob using the same query as before. Although, we add the ORDER BY clause to specify the column to sort the results based on. We set the OFFSET to 500 to skip the first 500 rows, and use the LIMIT clause to fetch only 500 rows at a time. We then iterate over the rows returned by our query and perform any actions required.
