Grouping Data in Oracle: Ranges Made Easy Grouping Data by Age Ranges in Oracle: A Practical Approach
Grouping data is a common requirement in SQL queries. It allows us to summarize data and extract meaningful information from large datasets. One of the most common examples of grouping data is grouping by age.

Suppose we have a table named “tbl” with two columns: “pkey” and “age.” We want to group the data by age ranges like this:

  age  n
-----  -
 1-10  2
11-20  2
20+    1

In this blog post, we will discuss a practical approach to group data by age ranges in Oracle SQL.

Approach 1: Using the CASE Statement

The most straightforward approach to group data by age ranges in Oracle SQL is to use the CASE statement. The idea is to create ranges of age values and group the data based on these ranges.

Here’s how the code looks:

SELECT 
  CASE 
    WHEN age <= 10 THEN '1-10' 
    WHEN age <= 20 THEN '11-20' 
    ELSE '21+' 
  END AS age_range, 
  COUNT(*) AS n
FROM tbl
GROUP BY 
  CASE 
    WHEN age <= 10 THEN '1-10' 
    WHEN age <= 20 THEN '11-20' 
    ELSE '21+' 
  END;

Let’s break down this code line by line:

  • SELECT CASE WHEN age <= 10 THEN '1-10' WHEN age <= 20 THEN '11-20' ELSE '21+' END AS age_range, COUNT(*) AS n
    • We’re using the CASE statement to create age ranges. If the age is less than or equal to 10, we assign it to the “1-10” age range. If it’s between 11 and 20, we assign it to the “11-20” age range. Otherwise, we assign it to the “21+” age range.
    • We’re also using the COUNT function to count the number of records in each age range.
    • We’re aliasing the age range as “age_range” and the count as “n.”
  • FROM tbl
    • We’re selecting data from the “tbl” table.
  • GROUP BY CASE WHEN age <= 10 THEN '1-10' WHEN age <= 20 THEN '11-20' ELSE '21+' END;
    • We’re grouping the data by age range using the same CASE statement used in the SELECT statement.

This approach works well if we have a small number of age ranges. Although, if we have many ranges, we would need to write many WHEN statements, which can be tedious and error-prone.

Approach 2: Using Arithmetic Operators

To avoid writing many WHEN statements, we can use arithmetic operators to calculate the age range. The idea is to divide the age by the range size (e.g., 10) and round down the result to the nearest integer. We can then multiply the result by the range size to get the lower bound of the age range.

Here’s how the code looks:

SELECT 
  TO_CHAR(FLOOR(age / 10) * 10) || '-' || TO_CHAR(CEIL(age / 10) * 10 - 1) AS age_range, 
  COUNT(*) AS n
FROM tbl
GROUP BY FLOOR(age / 10);

Let’s break down this code line by line:

  • SELECT TO_CHAR(FLOOR(age / 10) * 10) || '-' || TO_CHAR(CEIL(age / 10) * 10 - 1) AS age_range, COUNT(*) AS n
    • We’re using the FLOOR and CEIL functions to calculate the lower and upper bounds of the age range.
    • We’re using the TO_CHAR function to concatenate the lower and upper bounds of the age range with a hyphen separator.
    • We’re using the COUNT function to count the number of records in each age range.
    • We’re aliasing the age range as “age_range” and the count as “n.”
  • FROM tbl
    • We’re selecting data from the “tbl” table.
  • GROUP BY FLOOR(age / 10);
    • We’re grouping the data by the integer division of the age by the range size (e.g., 10).
    • The FLOOR function returns the largest integer less than or equal to the age divided by the range size.

This approach is more concise and works well if we have many age ranges. Although, it may not be immediately clear how the age range is calculated, and we need to be careful to handle edge cases properly (e.g., when the age is zero).
