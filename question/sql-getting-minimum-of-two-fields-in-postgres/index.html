SQL: Getting the Minimum of Two Fields in Postgres How to Get the Minimum of Two Fields in PostgreSQL?
In PostgreSQL, we can easily find the minimum value between two fields using the LEAST() function. This function selects the smallest value from a list of any number of expressions.

Steps to Get the Minimum of Two Fields

Let’s know the code line by line.

Step 1: Create a table with sample data.

CREATE TABLE score_table (
   name VARCHAR(100),
   score_a INTEGER,
   score_b INTEGER
);

INSERT INTO score_table (name, score_a, score_b)
VALUES 
   ('Joe', 100, 24),
   ('Sam', 96, 438),
   ('Bob', 76, 101);

Here, we’ve created a table named score_table with three columns: name, score_a, and score_b. Then, we’ve inserted some sample data into the table.

Step 2: Use the LEAST() function to get the minimum value.

SELECT name, LEAST(score_a, score_b) AS min_score
FROM score_table;

Here, we select the name column and the minimum value between score_a and score_b using the LEAST() function. We also give the alias name min_score to the column that stores the minimum value.

Step 3: Output the result.

 name | min_score
------+-----------
 Joe  |        24
 Sam  |        96
 Bob  |        76

The output would be the name column along with the minimum value between score_a and score_b.

Alternative Ways

Another function that is used to get the minimum value is the MIN() function. It is used to get the minimum value from a column or expression.

SELECT name, MIN(score_a, score_b) AS min_score
FROM score_table;

In this case, we’ve used the MIN() function instead of the LEAST() function. The output would be the same.
