Accessing an SQLite Database in Swift Accessing an SQLite Database in Swift
Are you looking for a way to access an SQLite database in your app with Swift code? There are many SQLite wrappers available, but if you want to call the SQLite library yourself, there are a few steps you need to take.

Configure Your Swift Project

If youâ€™re using Xcode 9 or later, you can simply do the following:

import SQLite3

Create/Open Database

The following code will create/open a database:

let fileURL = try! FileManager.default
    .url(for: .applicationSupportDirectory, in: .userDomainMask, appropriateFor: nil, create: true)
    .appendingPathComponent("test.sqlite")

// open database

var db: OpaquePointer?
guard sqlite3_open(fileURL.path, &db) == SQLITE_OK else {
    print("error opening database")
    sqlite3_close(db)
    db = nil
    return
}

Note that if the database fails to open, it must be closed to avoid memory leakage. The documentation makes this explicit:

Whether or not an error occurs when it is opened, resources associated with the database connection handle should be released by passing it to sqlite3_close() when it is no longer required.

Use sqlite3_exec to Perform SQL

You can use the sqlite3_exec function to perform SQL commands, such as creating a table:

if sqlite3_exec(db, "create table if not exists test (id integer primary key autoincrement, name text)", nil, nil, nil) != SQLITE_OK {
    let errmsg = String(cString: sqlite3_errmsg(db)!)
    print("error creating table: \(errmsg)")
}

Use sqlite3_prepare_v2 to Prepare SQL

You can use the sqlite3_prepare_v2 function to prepare SQL with ? placeholder to which you can bind value. For example:

var statement: OpaquePointer?

if sqlite3_prepare_v2(db, "insert into test (name) values (?)", -1, &statement, nil) != SQLITE_OK {
    let errmsg = String(cString: sqlite3_errmsg(db)!)
    print("error preparing insert: \(errmsg)")
}

if sqlite3_bind_text(statement, 1, "foo", -1, SQLITE_TRANSIENT) != SQLITE_OK {
    let errmsg = String(cString: sqlite3_errmsg(db)!)
    print("failure binding foo: \(errmsg)")
}

if sqlite3_step(statement) != SQLITE_DONE {
    let errmsg = String(cString: sqlite3_errmsg(db)!)
    print("failure inserting foo: \(errmsg)")
}

Retrieve Rows

To retrieve rows, you can use the following query:

// select

var statement: OpaquePointer? = nil

if sqlite3_prepare_v2(db, "select id, name from test", -1, &statement, nil) == SQLITE_OK {
    while sqlite3_step(statement) == SQLITE_ROW {
        let id = sqlite3_column_int64(statement, 0)
        let queryResultCol1 = sqlite3_column_text(statement, 1)
        let name = String(cString: queryResultCol1!)

        print("query result: \(id), \(name)")
    }
} else {
    print("SELECT statement could not be prepared")
}

sqlite3_finalize(statement)
