Joining Multiple Tables in BigQuery
Joining tables is a common task in SQL. It allows you to combine data from several tables into one result set. In BigQuery, joining two tables is pretty trivial but what if you want to join three or more tables? In this post, we will explore how to join multiple tables in BigQuery and some alternative ways to accomplish this.

Using the JOIN Clause

Using the JOIN clause is the most common way to combine data from multiple tables in SQL. In BigQuery, you can use the JOIN clause to join two or more tables. Here’s an example of how to join three tables:

SELECT
  t1.field1 AS field1,
  t2.field2 AS field2,
  t1.field3 AS field3,
  t3.field4 AS field4
FROM [datasetName.tableA] t1
JOIN [datasetName.tableB] t2 ON t1.somefield = t2.anotherfield
JOIN [datasetName.tableC] t3 ON t1.somefield = t3.yetanotherfield

In this query, we are joining three tables: tableA, tableB, and tableC. We are using the JOIN clause to join tableA with tableB on the field somefield, and then joining the result with tableC on the same field.

We are using table aliases t1, t2, and t3 to avoid typing the full table name each time we reference a field. Using table aliases improves readability and reduces the amount of code you need to write.

Using the USING Clause

In the example above, we used the ON clause to specify the join condition. Another way to write the same query is to use the USING clause:

SELECT
  t1.field1 AS field1,
  t2.field2 AS field2,
  t1.field3 AS field3,
  t3.field4 AS field4
FROM [datasetName.tableA] t1
JOIN [datasetName.tableB] t2 USING(somefield)
JOIN [datasetName.tableC] t3 USING(somefield)

Using the USING clause, we can simplify our query by specifying the join condition as a single field that is present in both tables.

Alternative Ways to Join Multiple Tables

There are other ways to join multiple tables in BigQuery, but they are not as common as using the JOIN or USING clauses. Here are some examples:

Subquery

We can use a subquery to join multiple tables:

SELECT
  t12.field1 AS field1,
  t12.field2 AS field2,
  t3.field3 AS field3,
FROM
  (SELECT
     t1.field1 AS field1,
     t2.field2 AS field2,
     t1.field3 AS field3
   FROM [datasetName.tableA] t1
   JOIN [datasetName.tableB] t2
     ON t1.somefield = t2.anotherfield) t12
JOIN [datasetName.tableC] t3 ON t12.field1 = t3.field1

In this query, we are using a subquery to join tableA with tableB. We then join the result of the subquery with tableC on the field field1.
