Updating Table Values From Another Table With the Same User Name
Table data can be updated with values from another table with the same column name, such as a user_name, using SQL statements. This article will take a look at how to do this in a few different ways, and provide practical examples of SQL queries that can be used.

Using the UPDATE Statement

The most straightforward way to update table values from another table is to use the SQL UPDATE statement. The syntax for this statement requires that you specify the table you want to update, the columns to update, and the values to update them with. The following example shows how to use the UPDATE statement to copy values from one table to another:

    UPDATE table_a
    SET
          column_a_1 = (SELECT table_b.column_b_1 
                                FROM table_b
                                WHERE table_b.user_name = table_a.user_name )
        , column_a_2 = (SELECT table_b.column_b_2
                                FROM table_b
                                WHERE table_b.user_name = table_a.user_name )
    WHERE
        EXISTS (
            SELECT *
            FROM table_b
            WHERE table_b.user_name = table_a.user_name
        )

The UPDATE statement in sqlite3 did not support a FROM clause for a long time, so the query had to be written in a more complicated way. However, UPDATE from was implemented in SQLite 3.33 (2020-08-14). This means that the query can now be written in a much simpler way, as shown below:

    UPDATE table_a
    SET column_a_1 = table_b.column_b_1
       ,column_a_2 = table_b.column_b_2
    FROM table_b
    WHERE table_b.user_name = table_a.user_name;

This is a much simpler and faster way of updating the values from one table to another. It is important to note, however, that this syntax only works for sqlite3 version 3.15 and above. For earlier versions, the more complex syntax is still required.

Using a Temporary Table

If the performance of the UPDATE statement is not satisfactory, another option is to build up new rows for the destination table using a SELECT and JOIN with the source table into a temporary table. Then, the data from the destination table can be deleted and repopulated from the temporary table.

Practical Example: Updating Employee Salaries Based on a Reference Table

Let’s see an example with using Sample database structure . To better align with your structure, let’s create a hypothetical title_changes table that represents changes in employee job titles and their corresponding new salaries.

-- Creating the 'title_changes' table to store changes in employee job titles and new salaries
CREATE TABLE title_changes (
    emp_no      INT             NOT NULL,        -- Employee number (foreign key referencing 'employees' table)
    new_title   VARCHAR(50)     NOT NULL,        -- New job title
    new_salary  INT             NOT NULL,        -- New salary amount
    change_date DATE            NOT NULL,        -- Date of the title and salary change
    PRIMARY KEY (emp_no, change_date),            -- Composite primary key
    FOREIGN KEY (emp_no) REFERENCES employees (emp_no) ON DELETE CASCADE  -- Foreign key constraint
);

-- Inserting data into 'title_changes' table
INSERT INTO title_changes VALUES
(1, 'Lead Developer', 85000, '2015-08-18'),
(2, 'HR Manager', 70000, '2017-11-25'),
(3, 'Senior Sales Manager', 90000, '2020-06-15'),
(4, 'Senior Financial Analyst', 80000, '2022-01-08'),
(5, 'Senior Marketing Manager', 75000, '2023-06-25');

Now, let’s consider the scenario where you want to update the salaries in the salaries table based on changes in job titles from the title_changes table. Here’s an example SQL query:

-- Updating employee salaries based on changes in job titles
UPDATE salaries AS s
SET s.salary = (
    SELECT tc.new_salary 
    FROM title_changes AS tc
    WHERE tc.emp_no = s.emp_no
      AND s.from_date <= tc.change_date -- You can add More conditions
      AND s.to_date >= tc.change_date
)
WHERE EXISTS (
    SELECT 1 
    FROM title_changes AS tc
    WHERE tc.emp_no = s.emp_no
);

This query updates the salaries table with the new salary from the title_changes table based on the corresponding employee number and the date range.

FAQs on Updating Table Values With The Same Username

Q: Can I use the UPDATE statement to copy values from one table to another based on a common user name?

Yes, the UPDATE statement allows you to update values in one table based on the values from another table using a common user name. The example query provided demonstrates how to achieve this by updating columns in table_a with values from table_b where the user names match.

Q: Is the UPDATE statement the only way to update values from another table?

No, besides the UPDATE statement, another option is to use a temporary table. If the performance of the UPDATE statement is not satisfactory, you can build up new rows for the destination table using a SELECT and JOIN with the source table into a temporary table. Then, the data from the destination table can be deleted and repopulated from the temporary table.

Q: Is there a difference in syntax between different database systems?

Yes, there can be differences in syntax between different database systems. For example, the UPDATE statement syntax provided is suitable for MySQL. In SQLite, the syntax might be different, and the article notes the implementation of the UPDATE statement with a FROM clause in SQLite version 3.33 and above.
