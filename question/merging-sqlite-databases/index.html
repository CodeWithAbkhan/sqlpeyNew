How can I merge many SQLite databases?

If you have a large number of SQLite databases, all with the same schema, what is the best way to merge them together in order to perform a query on all databases?

Luckily, there are various methods available to merge SQLite databases. In this guide, we’ll explore the most efficient and effective methods for merging many SQLite databases.

Using ATTACH

The ATTACH command in SQLite can be used to attach multiple databases together and perform a query on all databases. However, this method has a limit of 32 and 64 databases depending on the memory system on the machine.

To use ATTACH to merge multiple databases, you can use the following code:

    attach 'c:\test\b.db3' as toMerge;           
    BEGIN; 
    insert into AuditRecords select * from toMerge.AuditRecords; 
    COMMIT; 
    detach toMerge;

Example Merging SQLite Databases - Commandline Tool

1. Exit and Attach in New Database:

    sqlite> .exit
    sqlite3 new_database.db;
    sqlite> attach "d:\chinook\chinook.db" as toMerge;

2. Create Table Customer SQLite:

    CREATE TABLE "Customer"
    (
        "CustomerId" INT NOT NULL,
        "FirstName" VARCHAR(40) NOT NULL,
        "LastName" VARCHAR(20) NOT NULL,
        "Company" VARCHAR(80),
        "Address" VARCHAR(70),
        "City" VARCHAR(40),
        "State" VARCHAR(40),
        "Country" VARCHAR(40),
        "PostalCode" VARCHAR(10),
        "Phone" VARCHAR(24),
        "Fax" VARCHAR(24),
        "Email" VARCHAR(60) NOT NULL,
        "SupportRepId" INT
    );

3. Commit and Detach in New Database:

    sqlite> BEGIN;
    sqlite> INSERT INTO customer SELECT * FROM toMerge.customers;
    sqlite> COMMIT;
    sqlite> detach toMerge;

This code will attach the database b.db3 to the current one, and then insert all of the data from the attached database into the AuditRecords table. After finishing, it will detach the database from the current one. You can repeat this process as needed for each database.

Using an SQLite GUI

If the ATTACH method isn’t suitable for you, you can use an SQLite GUI such as SQLiteStudio to merge multiple databases. To do this, you can add all of your database files using the Ctrl + O keyboard shortcut. Then, double-click each now-loaded db file to open/activate/expand them all.

You can then simply right-click on each of the tables and click on Copy, and then go to the target database in the list of the loaded database files (or create new one if required) and right-click on the target db and click on Paste. This will copy all of the data from one database to the other.

Using Python

Lastly, if you’re comfortable with Python, you can use the following code to either merge two database files or scan a directory to find all database files and merge them all together (by simply inserting all data in other files to the first database file found). Note that this code just attaches the databases with the same schema.

import sqlite3
import os

def merge_databases(db1, db2):
    con3 = sqlite3.connect(db1)

    con3.execute("ATTACH '" + db2 +  "' as dba")

    con3.execute("BEGIN")
    for row in con3.execute("SELECT * FROM dba.sqlite_master WHERE type="table""):
        combine = "INSERT OR IGNORE INTO "+ row[1] + " SELECT * FROM dba." + row[1]
        print(combine)
        con3.execute(combine)
    con3.commit()
    con3.execute("detach database dba")

def read_files(directory):
    file_list = os.listdir(directory)
    databases = []

    for file in file_list:
        if file.endswith('.db'):
            databases.append(os.path.join(directory, file))

    if len(databases) == 0:
        print("No databases found in the directory")
    elif len(databases) == 1:
        print("Only one database found, nothing to merge")
    else:
        for i in range(len(databases)-1):
            merge_databases(databases[0], databases[i+1])

read_files('/path/to/database/files')

This code will attach each of the databases in the specified directory to the first database, and then insert all of the data from the attached databases into the first one. After finishing, it will detach the databases from the first one.

FAQs on

What is the ATTACH command in SQLite?

Answer: The ATTACH command in SQLite is used to attach multiple databases together. It allows you to perform queries that involve tables from multiple attached databases. However, it has a limit of 32 and 64 databases, depending on the memory system on the machine.

How can I use ATTACH to merge SQLite databases?

Answer: To use ATTACH for merging SQLite databases, you can execute commands like the following:

attach 'c:\test\b.db3' as toMerge;
BEGIN;
insert into AuditRecords select * from toMerge.AuditRecords;
COMMIT;

This code attaches a database (b.db3 in this case), inserts all data from the attached database into a target table (AuditRecords), and then detaches the database. You can repeat this process for each database.

Answer: An SQLite GUI, such as SQLiteStudio, provides a graphical interface for managing SQLite databases. To merge databases using an SQLite GUI:

  1. Open SQLiteStudio and load all database files.
  2. Copy tables from one database and paste them into another. This method involves a simple copy-and-paste process for merging databases.

How can Python be used to merge SQLite databases?

Answer: Python can be used to merge SQLite databases by attaching multiple databases to a target database and inserting data from the attached databases. The provided Python code demonstrates how to merge databases in a specified directory.

Is there a limit to the number of databases that can be attached using ATTACH in SQLite?

Answer: Yes, there is a limit to the number of databases that can be attached using the ATTACH command in SQLite. The limit is 32 or 64 databases, depending on the memory system on the machine.
