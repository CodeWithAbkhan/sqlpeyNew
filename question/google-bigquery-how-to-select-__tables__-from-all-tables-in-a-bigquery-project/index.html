How to select __TABLES__ from all tables within a BigQuery project?
If you’re working on a project in BigQuery, you might need to get a list of all the tables within each dataset. The most common way is to use the __TABLES__ meta-table, which is a table that contains information about all the tables in a dataset. Although, selecting __TABLES__ from every dataset within a project isn’t as simple as you might expect. But don’t worry, we’ve got you covered.

The Solution

You can use this SQL query to generate the list of datasets in your project:

SELECT 
    STRING_AGG(
        CONCAT('SELECT * FROM `', 
               SCHEMA_NAME, '.__TABLES__`'
        ), 
        ' UNION ALLn'
    )
FROM `[PROJECT ID].INFORMATION_SCHEMA.SCHEMATA`;

This query will create a single query that selects the __TABLES__ from each dataset in your project. The output will look something like this:

SELECT * FROM `[PROJECT ID].[DATASET ID 1].__TABLES__` UNION ALL 
SELECT * FROM `[PROJECT ID].[DATASET ID 2].__TABLES__` UNION ALL 
SELECT * FROM `[PROJECT ID].[DATASET ID 3].__TABLES__` UNION ALL 
SELECT * FROM `[PROJECT ID].[DATASET ID 4].__TABLES__` 
...

Once you have this list, you can run the following query to get information about each table:

SELECT 
    TABLE_ID,
    DATE(TIMESTAMP_MILLIS(CREATION_TIME)) AS CREATION_DATE,
    DATE(TIMESTAMP_MILLIS(LAST_MODIFIED_TIME)) AS LAST_MODIFIED_DATE,
    ROW_COUNT,
    SIZE_BYTES,
    ROUND(SAFE_DIVIDE(SIZE_BYTES, (1000*1000)),1) AS SIZE_MB,
    ROUND(SAFE_DIVIDE(SIZE_BYTES, (1000*1000*1000)),2) AS SIZE_GB,
    CASE
        WHEN TYPE = 1 THEN 'table'
        WHEN TYPE = 2 THEN 'view'
        WHEN TYPE = 3 THEN 'external'
        ELSE '?'
     END AS TYPE,
    TIMESTAMP_MILLIS(CREATION_TIME) AS CREATION_TIME,
    TIMESTAMP_MILLIS(LAST_MODIFIED_TIME) AS LAST_MODIFIED_TIME,
    FORMAT_TIMESTAMP('%Y-%m', TIMESTAMP_MILLIS(CREATION_TIME)) AS CREATED_MONTH
FROM ({{YOUR LIST OF TABLES HERE}});

This query will return various information about each table, such as the table ID, creation date, size, and type. You can customize this query to fit your needs and get only the columns you’re interested in.

Explanation

The first query creates a list of SQL statements that select __TABLES__ from each dataset in your project using the INFORMATION_SCHEMA.SCHEMATA table. Here’s how it breaks down:

  1. The SELECT statement selects all the schema names from the INFORMATION_SCHEMA.SCHEMATA table.
  2. The STRING_AGG function concatenates the schema names into a single string with a UNION ALL clause between them.
  3. The CONCAT function adds each schema name to a SQL statement that selects __TABLES__ from that schema.
  4. The resulting string is a list of SQL statements that select __TABLES__ from each schema in your project.

The second query selects various columns from the __TABLES__ table for each table in the list generated by the first query. Here’s what each column represents:

  1. TABLE_ID: The name of the table.
