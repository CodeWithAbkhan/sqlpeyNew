ORACLE: Max Size of VARCHAR2 in PL/SQL and SQL

What is the maximum size of VARCHAR2 in PL/SQL and SQL?

In Oracle 10g, the maximum size for VARCHAR2 in SQL is 4000 bytes or characters, and the maximum size in PL/SQL is 32767 bytes or characters. Although, if you are using Oracle Database 12c, the maximum size for VARCHAR2 is 32767 bytes or characters if MAX_STRING_SIZE = EXTENDED, and 4000 bytes or characters if MAX_STRING_SIZE = STANDARD.

Can the size of VARCHAR2 be increased without worrying about the SQL limit?

In Oracle 10g, the maximum size for VARCHAR2 in SQL is 4000 bytes or characters, which means that you cannot increase the size of the VARCHAR2 variable beyond this limit. Although, if you are using a higher version of Oracle, such as Oracle 12c, you can increase the size of the VARCHAR2 variable up to 32767 bytes or characters if MAX_STRING_SIZE = EXTENDED is set.

To set MAX_STRING_SIZE = EXTENDED in Oracle 12c, follow these steps:

  1. Login as sysdba (sqlplus / as sysdba).
  2. SHUT DOWN IMMEDIATELY or ALTER SYSTEM SET max_string_size = EXTENDED SCOPE=SPFILE;
  3. STARTUP UPGRADE
  4. ALTER DATABASE CHARACTER SET INTERNAL_USE AL32UTF8;
  5. ALTER DATABASE CHARACTER SET AL32UTF8;
  6. ALTER DATABASE OPEN;
