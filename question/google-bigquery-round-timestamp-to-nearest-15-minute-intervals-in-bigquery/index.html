Question: How can I round a timestamp to the nearest 15-minute interval using BigQuery standard SQL?

Solution:

To round a timestamp to the nearest 15-minute interval in BigQuery standard SQL, you can use the following formula:

TIMESTAMP_SECONDS(900 * DIV(UNIX_SECONDS(dt_from) + 450, 900))

This formula works by converting the timestamp to Unix time (the number of seconds since January 1, 1970), adding 450 seconds (7.5 minutes) to it, dividing the result by 900 (the number of seconds in 15 minutes), rounding down to the nearest integer, and then multiplying by 900 to get the Unix time of the nearest 15-minute interval. Lastly, the Unix time is converted back to a timestamp using the TIMESTAMP_SECONDS function.

Step-by-Step Explanation:

Let’s break down the formula line by line:

  1. UNIX_SECONDS(dt_from): This function converts the input timestamp to Unix time (the number of seconds since January 1, 1970).
  2. UNIX_SECONDS(dt_from) + 450: We add 450 seconds (7.5 minutes) to the Unix time of the input timestamp. This is because we want to round to the nearest 15-minute interval, not just truncate to the nearest 15-minute boundary. By adding 450 seconds, we ensure that timestamps with seconds 0 through 449 round down to the previous 15-minute interval, while timestamps with seconds 450 through 899 round up to the next 15-minute interval.
  3. DIV(UNIX_SECONDS(dt_from) + 450, 900): This function divides the adjusted Unix time by 900, the number of seconds in 15 minutes, rounding down to the nearest integer. This gives us the number of 15-minute intervals that have passed since January 1, 1970, up to the input timestamp.
  4. 900 * DIV(UNIX_SECONDS(dt_from) + 450, 900): Now we multiply the number of 15-minute intervals by 900, the number of seconds in 15 minutes, to get the Unix time of the nearest 15-minute interval that has elapsed since January 1, 1970, up to the input timestamp.
  5. TIMESTAMP_SECONDS(900 * DIV(UNIX_SECONDS(dt_from) + 450, 900)): Lastly, we convert the Unix time of the nearest 15-minute interval back to a timestamp using the TIMESTAMP_SECONDS function.

Example:

Let’s say we have a table named my_table with a timestamp column named my_timestamp, and we want to round the timestamps to the nearest 15-minute interval:

SELECT my_timestamp, TIMESTAMP_SECONDS(900 * DIV(UNIX_SECONDS(my_timestamp) + 450, 900)) AS rounded_timestamp
FROM my_table

This will give us a new column named rounded_timestamp with the rounded timestamps:

| my\_timestamp | rounded\_timestamp |

| — | — |

| 2018-10-24 01:05:00 | 2018-10-24 01:00:00 |

| 2018-10-24 01:08:00 | 2018-10-24 01:15:00 |

| 2018-10-24 01:12:00 | 2018-10-24 01:15:00 |
