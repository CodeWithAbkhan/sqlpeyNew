SQL: Inner Joining Multiple Columns: A Guide How to Perform SQL INNER JOIN on Multiple Columns - Explained with Examples

If you are working with databases, you might face the need for joining multiple tables on multiple columns. This can be quite challenging, but it is essential to retrieve the desired data. In this blog post, we will be discussing how to perform an INNER JOIN on multiple columns with the help of examples.

Let’s assume you have two tables:

  • Flights Table: This table contains information about flights such as airline and arrival/departure times. It has the following columns: airline, flt_no, fairport, tairport, depart, arrive, fare.
  • Airports Table: This table contains information about airports such as airport codes and city names. It has the following columns: code, city.

Problem Statement: You need to find flights based on the city name or airport code. Although, the flights table only contains airport codes. Therefore, you need to perform an INNER JOIN on the fairport and tairport columns with the airports table.

Solution:

To achieve this, you can use the following query:

SELECT airline, flt_no, fairport, tairport, depart, arrive, fare 
FROM (SELECT * FROM flights 
      INNER JOIN airports 
      ON flights.fairport = airports.code 
      WHERE (airports.code="?" OR airports.city='?')) AS matches 
INNER JOIN airports 
ON matches.tairport = airports.code 
WHERE (airports.code="?" OR airports.city = '?')

Let’s break down this query and know each part of it.

In the first join, we join the flights table with the airports table where the fairport column of the flights table matches the code column of the airports table. This way, we can retrieve the corresponding city names for departure airports.

SELECT * FROM flights 
INNER JOIN airports 
ON flights.fairport = airports.code 
WHERE (airports.code="?" OR airports.city='?')

Then, we wrap this join with a subquery called matches. This subquery stores the results of the previous join.

SELECT airline, flt_no, fairport, tairport, depart, arrive, fare 
FROM (SELECT * FROM flights 
      INNER JOIN airports 
      ON flights.fairport = airports.code 
      WHERE (airports.code="?" OR airports.city='?')) AS matches

In the second join, we join the matches subquery with the airports table again where the tairport column of the matches subquery matches the code column of the airports table. This way, we can retrieve the corresponding city names for arrival airports.

INNER JOIN airports 
ON matches.tairport = airports.code 
WHERE (airports.code="?" OR airports.city = '?')

Lastly, we filter the results where either the departure code or city name matches the given parameter and either the arrival code or city name matches the given parameter.

Let’s take a look at some examples to know it better:

Example 1: Retrieve all flights from San Francisco (SFO) to New York (JFK).

SELECT airline, flt_no, fairport, tairport, depart, arrive, fare 
FROM (SELECT * FROM flights 
      INNER JOIN airports 
      ON flights.fairport = airports.code 
      WHERE (airports.code="SFO" OR airports.city='San Francisco')) AS matches 
INNER JOIN airports 
ON matches.tairport = airports.code 
WHERE (airports.code="JFK" OR airports.city = 'New York')

Example 2: Retrieve all flights from Houston (IAH) to Los Angeles (LAX).

SELECT airline, flt_no, fairport, tairport, depart, arrive, fare 
FROM (SELECT * FROM flights 
      INNER JOIN airports 
      ON flights.fairport = airports.code 
      WHERE (airports.code="IAH" OR airports.city='Houston')) AS matches 
INNER JOIN airports 
ON matches.tairport = airports.code 
WHERE (airports.code="LAX" OR airports.city = 'Los Angeles')

In the above examples, we first join the flights table with the airports table on the fairport column from the flights table and the code column from the airports table to retrieve the departure city name. Then, we wrap this join within a subquery called matches. In the second join, we join the matches subquery with the airports table on the tairport column from the matches table and the code column from the airports table to retrieve the arrival city name. Lastly, we filter the results based on the input parameters, either the airport code or city name.

Alternative Ways:

Another way to perform an INNER JOIN on multiple columns is by using the AND operator in the ON clause, like this:

SELECT * FROM flights 
INNER JOIN airports AS dep 
ON flights.fairport = dep.code AND dep.city = '?' 
INNER JOIN airports AS arr 
ON flights.tairport = arr.code AND arr.city = '?'

This query is simpler and more straightforward than the previous one. In this query, we are joining the flights table with two instances of the airports table, renamed as dep (for departure) and arr (for arrival). In each join, we use both the code and city columns to retrieve the corresponding airport information.
