How to Get Day of Week in SQL Server 2005/2008

If you have a date and want to find out what day of the week it is, SQL Server 2005/2008 provides built-in functions to do so. In this Q&A Session, we will discuss two ways to get the day of the week in SQL Server and an important SET option to keep in mind while using these functions.

Method 1: Using DATENAME and DATEPART Functions

The DATENAME function returns a specified part of a given date in character format. The DATEPART function returns the specified date part of a given date as an integer.

Syntax:

DATENAME(datepart, date) DATEPART(datepart, date)

Here’s an example code to get the day of the week using DATENAME and DATEPART functions:

SELECT DATENAME(dw, GETDATE()) – Returns the day of the week in character format (e.g: Friday) SELECT DATEPART(dw, GETDATE()) – Returns the day of the week as an integer (e.g: 6)

Method 2: Using CASE Statement with DATEPART Function

The CASE statement evaluates a list of conditions and returns one among several possible result expressions. We can use the CASE statement with the DATEPART function to get the day of the week in SQL Server.

Syntax:

SELECT CASE expression WHEN condition1 THEN result1 WHEN condition2 THEN result2 … ELSE resultN END

Here’s an example code to get the day of the week using the CASE statement with DATEPART function:

SELECT CASE DATEPART(WEEKDAY, GETDATE())
WHEN 1 THEN ‘SUNDAY’ WHEN 2 THEN ‘MONDAY’ WHEN 3 THEN ‘TUESDAY’ WHEN 4 THEN ‘WEDNESDAY’ WHEN 5 THEN ‘THURSDAY’ WHEN 6 THEN ‘FRIDAY’ WHEN 7 THEN ‘SATURDAY’ END

Important SET Option: SET DATEFIRST

The SET DATEFIRST statement sets the first day of the week to a specified value. By default, SQL Server sets it to Sunday (a value of 7). Although, in different locales or cultures, Monday (a value of 1) or some other day might be set as the first day of the week.

Therefore, while using the DATENAME or DATEPART functions, the first day of the week can affect the result. For example, if the first day of the week has been changed to Monday, then a date falling on Sunday will have a DATEPART of 7 (not 1). To handle such instances, we can use the SET DATEFIRST statement to set the first day of the week to our desired value.

Here’s an example code to demonstrate the effect of SET DATEFIRST:

– Returns the default value of first day of the week declare @DefaultDateFirst int set @DefaultDateFirst = @@datefirst select [@DefaultDateFirst] = @DefaultDateFirst

set datefirst @DefaultDateFirst

– Returns the day of the week as though the first day of the week is Sunday select datename(dw, getdate()) – Returns the day of the week in character format (e.g: Friday) select datepart(dw, getdate()) – Returns the day of the week as an integer (e.g: 6)

– Set the first day of the week to Tuesday set datefirst 2 select datename(dw, getdate()) – Returns the day of the week in character format (e.g: Friday) select datepart(dw, getdate()) – Returns an integer value different from the default (e.g: 5)

set datefirst @DefaultDateFirst – Restore the default value

Alternative Ways

We have discussed two methods to get the day of the week in SQL Server. Although, there are more ways to achieve the same result, depending on the requirements. For example, in Europe, people start their week on Monday, and they might use a different method to get the day of the week.

Here’s an example code to get the day of the week in Europe:

declare @d datetime; set @d = getdate(); set @dow = ((datepart(dw,@d) + @@DATEFIRST-2) % 7+1);
