Viewing the Table Schema

The first step in exporting a BigQuery table’s schema is to view the schema in the web UI. This can be done by selecting the table in the BigQuery console, then clicking the Schema tab. This will display the table’s columns and data types.

Updating the Table Schema

Once the table schema has been viewed, it can be updated if necessary. This can be done by selecting the table in the BigQuery console and clicking the Edit Schema button. This will open an editor window where the table’s columns and data types can be updated.

Loading Data with the BigQuery Tool

The BigQuery tool can be used to load data into BigQuery tables. This can be done by using a JSON file which contains the table’s schema as well as the data. This JSON file can be created using the bq tool with the following command:

bq load --schema [SCHEMA_FILE] [TABLE_NAME] [DATA_FILE]

The table schema can also be exported as a JSON file for use with the bq tool. This can be done by running the following command:

bq show --schema --format=prettyjson [PROJECT_ID]:[DATASET].[TABLE] > [SCHEMA_FILE]
