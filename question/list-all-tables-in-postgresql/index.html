What is the equal to Show all tables in PostgreSQL (from Oracle ) in PostgreSQL ?

Admin Answer:

In PostgreSQL, you can use the \d or \dt command to list all the tables in a database. This can be useful if you want to see what tables are available in the database, or if you need to check the structure of a particular table.

In Oracle, you can use the SHOW TABLES command to list all the tables in a database. In PostgreSQL, the equivalent command is \d or \dt.

\dt

This will list all the tables in the current database. If you want to list the tables in a specific schema, you can use the \dt command followed by the schema name:

\dt schema_name.*

You can also use the pg_catalog.pg_tables system catalog to list all the tables in a database. This can be useful if you want to query the table names and metadata, such as the owner and creation date. Here’s an example:

How do I see the structure of a table in PostgreSQL?

To see the structure of a table in PostgreSQL, you can use the \d command followed by the name of the table. For example, to see the structure of a table called “customers”, you can use the following command:
\d customers

Can I list the tables in a specific schema?

Yes, you can use the \dt command followed by the schema name to list the tables in a specific schema. For example, to list the tables in a schema called “sales”, you can use the following command:
\dt sales.*

Is there a way to list all tables in PostgreSQL and metadata in a PostgreSQL database?

SELECT * FROM pg_catalog.pg_tables;
