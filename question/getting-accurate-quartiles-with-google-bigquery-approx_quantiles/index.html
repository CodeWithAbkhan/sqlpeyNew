Learning Google BigQuery APPROX_QUANTILES and obtaining true quartiles

Summary

This post will discuss the functionality of Google BigQuery’s APPROX_QUANTILES function and how to obtain true quartiles using this function.

Introduction

APPROX_QUANTILES is a function in Google BigQuery that returns an array of approximate boundaries for a group of expression values. This function is useful for finding quartiles, which are values that divide a set of data into four groups, each containing an equal number of observations.

Using APPROX_QUANTILES to find quartiles

According to the documentation, using the syntax APPROX_QUANTILES(values, 4) will return an array of five elements, where the first and last elements are the approximate minimum and maximum values of the data, and the second, third, and fourth elements are the approximate quartiles. Although, the quartiles returned by this function may not be the true quartiles, as they may include the minimum and/or maximum values of the data. To obtain true quartiles, one solution is to first sort the data in ascending order and then use the APPROX_QUANTILES function with the middle 50% of the data. Specifically, one would use the syntax APPROX_QUANTILES(SORT(values)[OFFSET(N)] TO (SORT(values)[OFFSET(M)]), 3), where N is the index of the first value in the middle 50% of the sorted data and M is the index of the last value in the middle 50% of the sorted data. Here is an example implementation of this solution using BigQuery’s GENERATE_ARRAY function to generate an array of numbers from 1 to 100:

WITH data AS (
  SELECT CAST(NUMBER AS INT64) AS value
  FROM UNNEST(GENERATE_ARRAY(1, 100)) AS NUMBER
),
sorted_data AS (
  SELECT value
  FROM data
  ORDER BY value ASC
),
quartiles AS (
  SELECT
    APPROX_QUANTILES(
      value,
      3
    ) AS quartiles
  FROM sorted_data
  OFFSET (
    SELECT
      COUNT(value) / 4
    FROM data
  )
  LIMIT (
    SELECT
      COUNT(value) / 2
    FROM data
  )
)
SELECT
  quartiles[SAFE_OFFSET(0)] AS min_value,
  quartiles[SAFE_OFFSET(1)] AS first_quartile,
  quartiles[SAFE_OFFSET(2)] AS second_quartile,
  quartiles[SAFE_OFFSET(3)] AS third_quartile,
  quartiles[SAFE_OFFSET(4)] AS max_value
FROM quartiles

The above code first generates an array of numbers, sorts them in ascending order, and then obtains the middle 50% of the sorted data using the OFFSET and LIMIT clauses based on the number of observations. The APPROX_QUANTILES function is then applied to this middle 50% of data, returning an array of four elements corresponding to the true quartiles. Lastly, the quartiles are selected and returned in a single row with column names for each quartile.

Alternative solution

The NTILE function divides the data into equal-sized buckets based on the specified number of buckets.
