ORACLE: Duplicate Error: Column Not Allowed with ORA-00984 Why am I getting an ORA-00984 error with Oracle INSERT query?
If you are trying to insert data into an Oracle table and are encountering an ORA-00984 error, it means that you are trying to use a column name in an invalid way.

What does ORA-00984 error mean?

The ORA-00984 error occurs when you try to use a column name in a place where it is not allowed. This can happen if you try to use the column name as a reserved word, or if you use it in an incorrect syntax.

How can I fix the ORA-00984 error?

To fix the ORA-00984 error, you need to ensure that you are using the correct syntax for your INSERT query. One common mistake that can lead to this error is using double quotes instead of single quotes to enclose string values.

Example code:

INSERT INTO MY.LOGFILE
(id,severity,category,logdate,appendername,message,extrainfo)
VALUES
(
"dee205e29ec34",
"FATAL",
"facade.uploader.model",
"2013-06-11 17:16:31",
"LOGDB",
NULL,
NULL
)

In the above example, the double quotes used to enclose string values should be replaced with single quotes. The corrected code would look like this:

Corrected code:

INSERT INTO MY.LOGFILE
(id,severity,category,logdate,appendername,message,extrainfo)
VALUES
(
'dee205e29ec34',
'FATAL',
'facade.uploader.model',
'2013-06-11 17:16:31',
'LOGDB',
NULL,
NULL
)

Notice how single quotes are used to enclose the string values instead of double quotes.

Summary

The ORA-00984 error can occur when you use a column name in an incorrect way in your Oracle INSERT query. To fix this error, ensure that you are using the correct syntax and using single quotes to enclose string values.

Practical Examples

Here’s an example of a corrected INSERT query:

INSERT INTO STUDENTS
(ID, NAME, AGE, ADDRESS)
VALUES
(1, 'John', 23, '123 Main St.')

Notice how the string value ‘123 Main St.’ is enclosed in single quotes, not double quotes.
