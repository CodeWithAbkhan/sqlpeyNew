Exporting data from BigQuery into a local PostgreSQL/MySql database

Introduction

As a beginner to BigQuery and the Python API for BigQuery, you are tasked with pulling data from a Google open dataset using BigQuery and Python API and loading the data into a local MySQL/PostgreSQL database installed on your PC. You have found a sample code that exports data from BigQuery into a CSV file and plan to load the data from the file into the database. Although, you are unsure if this is the right approach and would like advice and instruction.

Solution

Yes, the approach you have outlined is correct. In summary, you will need to perform the following steps:

  1. Pull data from BigQuery using the Python API and write it to a local CSV file using the google-cloud-bigquery library.
  2. Connect to the local database and load the data from the CSV file into the database using the pandas library.

Here is an example code that outlines these steps:

Step 1: Pull data from BigQuery into a CSV file

from google.cloud import bigquery

# Create a client object to connect to the BigQuery API
client = bigquery.Client()

# Query BigQuery to extract the data you need and write it to a file
query = """
SELECT *
FROM `bigquery-public-data.samples.natality`
WHERE year=2000
"""

job_config = bigquery.QueryJobConfig()
job_config.destination_format = bigquery.DestinationFormat.CSV
job_config.write_disposition = bigquery.WriteDisposition.WRITE_TRUNCATE

query_job = client.query(query, job_config=job_config)

with open('natality.csv', 'wb') as file:
    query_job.result().to_storage(file)

Explanation: - First, you import the bigquery library and create a client object to connect to the BigQuery API. - Next, you write a SQL query to extract the data you need from the bigquery-public-data.samples.natality dataset. In this example, the query is extracting data from the year 2000. - Then, you create a QueryJobConfig object and specify that the destination format should be CSV and the write disposition should be WRITE_TRUNCATE. - You then execute the query using the query method of the client object and pass in the job_config object. This will create a job in BigQuery to extract the data and write it to a CSV file in Google Cloud Storage. - Lastly, you open a local file and write the contents of the CSV file in Google Cloud Storage to it using the to_storage method of the query job result object.

Step 2: Load data from CSV file into local database

import pandas as pd
from sqlalchemy import create_engine

# Connect to the local MySQL/PostgreSQL database
engine = create_engine('postgresql://user:password@localhost:5432/mydatabase')

# Load data from the CSV file into a pandas dataframe
df = pd.read_csv('natality.csv')

# Load the data from the dataframe into the database
df.to_sql(name='natality', con=engine, if_exists='replace')

Explanation: - First, you import the pandas library and the create_engine function from the sqlalchemy library which will help you connect to the local MySQL/PostgreSQL database. - You create a connection to the database by specifying the database type, username, password, and database name in the create_engine function. - You then use the read_csv function of pandas to load the data from the CSV file into a dataframe. - Lastly, you write the data from the dataframe to the database using the to_sql method, specifying the name of the table, the database connection object, and the if_exists parameter which determines what to do if the table already exists in the database.
