SQL: Calculate Workdays for Date Range How to Count Work Days Between Two Dates in SQL Server?
Counting workdays between two dates is a common requirement in SQL Server. In this Q&A Session, we will discuss how to calculate the number of workdays between two dates in SQL Server.

Calculating Work Days: Monday to Friday

If you want to calculate the number of workdays between two dates, assuming that workdays are Monday to Friday, you can use the following T-SQL code.

DECLARE @StartDate DATETIME
DECLARE @EndDate DATETIME
SET @StartDate = '2008/10/01'
SET @EndDate = '2008/10/31'

SELECT
   (DATEDIFF(dd, @StartDate, @EndDate) + 1)
  - (DATEDIFF(wk, @StartDate, @EndDate) * 2)
  - (CASE WHEN DATENAME(dw, @StartDate) = 'Sunday' THEN 1 ELSE 0 END)
  - (CASE WHEN DATENAME(dw, @EndDate) = 'Saturday' THEN 1 ELSE 0 END)

Let’s go over this code line by line.

  • DECLARE @StartDate DATETIME and DECLARE @EndDate DATETIME: These two statements declare two variables of type DATETIME to store the start and end dates.
  • SET @StartDate = '2008/10/01' and SET @EndDate = '2008/10/31': These two statements assign the start and end dates values to the variables.
  • DATEDIFF(dd, @StartDate, @EndDate) + 1: This expression calculates the number of calendar days between the start and end dates, including the end date as a whole day.
  • DATEDIFF(wk, @StartDate, @EndDate) * 2: This expression calculates the number of weekends (Saturdays and Sundays) between the start and end dates and subtracts twice this number (since there are two weekend days in each weekend) from the total number of days.
  • CASE WHEN DATENAME(dw, @StartDate) = 'Sunday' THEN 1 ELSE 0 END and CASE WHEN DATENAME(dw, @EndDate) = 'Saturday' THEN 1 ELSE 0 END: These two expressions check whether the start and end dates fall on a weekend day (Sunday or Saturday, respectively) and, if so, subtract one additional day from the total number of days.

Calculating Work Days: Monday to Friday, Including Holidays

If you want to include holidays in your calculation, you will need to create a user-defined function to check whether a given date is a holiday. Here’s an example function:

--Change current database to the Master database allows function to be shared by everyone.
USE MASTER
GO

--If the function already exists, drop it.
IF EXISTS (
    SELECT * FROM dbo.SYSOBJECTS
    WHERE ID = OBJECT_ID(N'[dbo].[fn_WorkDays]')
    AND xtype IN (N'FN', N'IF', N'TF')
)
DROP FUNCTION [dbo].[fn_WorkDays]
GO

CREATE FUNCTION dbo.fn_WorkDays (

    --Define the input parameters (OK if reversed by mistake).
    @StartDate DATETIME,
    @EndDate   DATETIME = NULL

)
--Define the output data type.
RETURNS INT

AS

BEGIN

    --Declare local variables
    DECLARE @Swap DATETIME

    --If the Start Date is null, return a NULL and exit.
    IF @StartDate IS NULL
        RETURN NULL

    --If the End Date is null, populate with Start Date value so will have two dates (required by DATEDIFF below).
    IF @EndDate IS NULL
        SELECT @EndDate = @StartDate

    --Strip the time element from both dates (just to be safe) by converting to whole days and back to a date.
    SELECT @StartDate = DATEADD(dd, DATEDIFF(dd, 0, @StartDate), 0),
           @EndDate   = DATEADD(dd, DATEDIFF(dd, 0, @EndDate), 0)

    --If the inputs are in the wrong order, reverse them.
    IF @StartDate > @EndDate
        SELECT @Swap      = @EndDate,
               @EndDate   = @StartDate,
               @StartDate = @Swap

    --Calculate and return the number of workdays between the start and end dates.
    RETURN (
        SELECT COUNT(*)
        FROM (
            --Generate a series of dates starting from the start date and ending on the end date.
            SELECT DATEADD(dd, ROW_NUMBER() OVER (ORDER BY (SELECT NULL)) - 1, @StartDate) AS [Date]
            FROM (
                --Use a tally table to generate a series of numbers starting from 1 and ending on the number of days between the start and end dates.
                SELECT TOP (DATEDIFF(dd, @StartDate, @EndDate) + 1) ROW_NUMBER() OVER (ORDER BY (SELECT NULL)) AS n
                FROM [master]..spt_values
            ) AS Numbers
            WHERE [Date] <= @EndDate
        ) AS Dates
        --Exclude weekends.
        WHERE DATENAME(dw, [Date]) NOT IN ('Saturday', 'Sunday')
        --Exclude holidays.
        AND [Date] NOT IN (
            --Add your holiday dates here.
            '2022-07-04', -- Independence Day
            '2022-09-05'  -- Labor Day
        )
    )

END

  • IF EXISTS ... DROP FUNCTION ... GO: These statements drop the function if it already exists, so we can create a new one from scratch.
