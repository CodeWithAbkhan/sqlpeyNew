Recommendations using R with SimpleDB or BigQuery or using PHP with SimpleDB

What is the current scenario?

The author is working on a system that generates product recommendations similar to Amazon’s “People who bought this also bought this.”

  • Data is extracted from Google Analytics and inserted into a database.
  • On the client’s website, an API call is made to get recommendations when a product page loads.
  • The API retrieves recommended product IDs from the database using association rules.
  • The list of product IDs is then processed to get product details and displayed on the website.
  • Currently, PHP and MySQL with gapi package and REST api storage are used on Amazon EC2.

What are the choices?

  • PHP with SimpleDB or BigQuery
  • R language with BigQuery
  • RHIPE - R and Hadoop with SimpleDB
  • Apache Mahout

Which choice is the best?

It is difficult to give a definitive answer as the choice depends on several factors.

The following are some considerations:

  1. BIGQuery is currently not publicly available. Even if you are in the preview population, it will be difficult to access it with a small user base.
  2. Using R and BigQuery can be a great choice if you are looking for a fast, scalable, and cost-effective solution.
  3. If you are more comfortable with PHP, you can use SimpleDB, but you might face scalability issues.
  4. Apache Mahout is a good solution, but it might require more infrastructure and resources.

Which solution has better scalability and performance?

R with BigQuery is a great choice when it comes to scalability and performance. With BigQuery, you can process massive datasets in seconds, and R provides a amazing interface to BigQuery.

What is RHIPE?

RHIPE is an R and Hadoop package designed for large-scale data analysis. It provides a high-level interface for running R on Hadoop, allowing you to perform statistical analysis and machine learning tasks on large datasets.

What is SimpleDB?

Amazon SimpleDB is a highly scalable and available NoSQL data store that offloads the work of database administration. SimpleDB is designed to handle large amounts of structured data.

Can Apache Mahout be used for recommendations?

Yes, Apache Mahout can be used for recommendations. It provides a set of algorithms for collaborative filtering, content-based filtering, and hybrid recommendations.

Alternative ways to implement the recommendations system

One alternative way to implement the recommendations system could be to use a combination of Python and Scikit-Learn. Scikit-Learn provides a amazing set of algorithms for machine learning, including those for recommendations.
