How to Round Up Results to 4 Digits After Decimal Point in Google BigQuery
If you are working with decimal numbers in Google BigQuery, you might need to round up your results to a certain number of decimal places. This can be done using the ROUND() function or by using the NUMERIC data type.

Rounding Float values

By default, float division in BigQuery might result in numbers with many decimal places. For example, the division of 0.029 by 50 and then multiplied by 100 will result in 0.014500000000000002 instead of 0.0145. To round up the value, you can use the ROUND() function as follows:

SELECT ROUND(0.029*50/100, 4) AS rounded_value

The ROUND() function takes two arguments: the first argument is the number to be rounded, and the second argument is the number of decimal places to round to. In this example, we rounded the value to four decimal places.

Another alternative is to add 0.00005 before using ROUND(). This will force the number to be rounded up instead of rounded down.

Using NUMERIC Data Type

BigQuery now supports the NUMERIC data type, which allows you to store numbers with high precision and scale. To use the NUMERIC data type, you need to cast your float values to the NUMERIC data type. For example:

SELECT CAST(0.029 AS NUMERIC)*50/100

This will return the value 0.0145 with high precision and scale.

Alternative Ways

Along with the ROUND() function and the NUMERIC data type, you can use the TRUNCATE() and FLOOR() functions to round up numbers.

SELECT TRUNCATE(0.029*50/100, 4) AS truncated_value

The TRUNCATE() function takes two arguments: the first argument is the number to be truncated, and the second argument is the number of decimal places to truncate to. This function simply removes the digits after the specified number of decimal places.

SELECT FLOOR(0.029*50*10000)/10000 AS floored_value

The FLOOR() function rounds down to the closest integer that is less than or equal to the input. In this example, we multiplied the value by 10000, rounded down to an integer, and then divided by 10000 to get the rounded value.

Practical Examples

Let’s consider a situation where we have a table with sales data, and we want to round up the values of the total sales column to two decimal places.

SELECT customer_name, ROUND(total_sales, 2) AS rounded_sales
FROM sales_data_table;

This query will return a list of all the customers and their total sales rounded up to two decimal places.

Recap

Rounding up numbers in Google BigQuery can be done using various methods, including the ROUND() function, the NUMERIC data type, and the TRUNCATE() and FLOOR() functions. The choice of method depends on your specific needs and preferences.
