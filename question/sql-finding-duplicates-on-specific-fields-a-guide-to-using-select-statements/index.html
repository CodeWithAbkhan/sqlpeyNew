SQL: Finding Duplicates on Specific Fields: A Guide to Using Select Statements How to Find and Remove Duplicates in SQL

Duplicates in a database can affect the accuracy of data and slow down its performance. Therefore, it’s important to remove them to maintain a clean and efficient database. In this Q&A Session, we will discuss how to find and remove duplicates in SQL using the UNION operator, DISTINCT keyword, and inner join.

Finding Duplicates Using UNION Operator

One way to find duplicates in SQL is to use the UNION operator. The UNION operator combines the results of two or more SELECT statements into a single result set. Although, it removes duplicates by default.

To find duplicates using the UNION operator, we need to perform the following steps:

Step 1: Consider two tables with the same structure, such as sales and sales_copy, as shown below:

sales table:

id product_name quantity price
1 apple 5 1.5
2 orange 3 2.0
3 banana 2 1.0
4 watermelon 1 5.0
5 grapes 4 3.0

sales_copy table:

id product_name quantity price
6 apple 4 1.5
7 orange 3 2.0
8 kiwi 2 1.0
9 watermelon 2 5.0
10 grapes 4 3.0

Step 2: Use the UNION operator to combine the results of the two tables as shown below:

SELECT * FROM sales UNION SELECT * FROM sales_copy;

This SQL statement combines the results of the two tables and removes duplicates by default. The result set will be:

id product_name quantity price
1 apple 5 1.5
2 orange 3 2.0
3 banana 2 1.0
4 watermelon 1 5.0
5 grapes 4 3.0
6 apple 4 1.5
8 kiwi 2 1.0
9 watermelon 2 5.0

As we can see from the result set, there are duplicates in the product_name column.

Step 3: Use the GROUP BY clause to group the rows by the product_name column and count the number of occurrences as shown below:

SELECT product_name, COUNT() FROM (SELECT product_name FROM sales UNION SELECT product_name FROM sales_copy) AS sales_total GROUP BY product_name HAVING COUNT() > 1; This SQL statement groups the rows by the product_name column and counts the number of occurrences for each product_name. The HAVING clause filters the result set to only show the product_names that have more than one occurrence. The result set will be: | product_name | COUNT(*) | | ———— | ——– | | apple | 2 | | grapes | 2 | | orange | 2 | | watermelon | 2 | This query helps to identify the duplicates in the product_name column. Step 4: To select every record except the first one for each duplicate combination of the fields product_name, quantity, and price, use the following SQL statement: WITH CTE AS ( SELECT id, product_name, quantity, price, ROW_NUMBER() OVER(PARTITION BY product_name, quantity, price ORDER BY id) AS rn FROM ( SELECT id, product_name, quantity, price FROM sales UNION SELECT id, product_name, quantity, price FROM sales_copy ) AS sales_total ) SELECT CTE.id, CTE.product_name, CTE.quantity, CTE.price FROM CTE WHERE rn > 1; This SQL statement creates a common table expression (CTE) using the ROW_NUMBER() function to assign a unique number to each row within a partition of rows with the same product_name, quantity, and price values. The rn column is used to identify the duplicates by selecting every record except the first one. Running this SQL statement will return the following result set: | id | product_name | quantity | price | | – | ———— | ——– | —– | | 1 | apple | 5 | 1.5 | | 6 | apple | 4 | 1.5 | | 2 | orange | 3 | 2.0 | | 7 | orange | 3 | 2.0 | | 4 | watermelon | 1 | 5.0 | | 9 | watermelon | 2 | 5.0 | | 5 | grapes | 4 | 3.0 | | 10 | grapes | 4 | 3.0 | Removing Duplicates Using DISTINCT Keyword Another way to find duplicates is to use the DISTINCT keyword. The DISTINCT keyword is used to retrieve unique values in a table. To remove duplicates using the DISTINCT keyword, we need to perform the following steps: Step 1: Use the SELECT DISTINCT statement to retrieve unique values in the table as shown below: SELECT DISTINCT product_name, quantity, price FROM sales; The SQL statement retrieves unique product_name, quantity, and price values in the sales table. The result set will be: | product_name | quantity | price | | ———— | ——– | —– | | apple | 5 | 1.5 | | orange | 3 | 2.0 | | banana | 2 | 1.0 | | watermelon | 1 | 5.0 | | grapes | 4 | 3.0 | Step 2: If we want to remove the duplicates from the sales table, we can create a new table without the duplicates as shown below: CREATE TABLE sales_new AS SELECT DISTINCT * FROM sales; This SQL statement creates a new table called sales_new and inserts the unique rows from the sales table into it.
