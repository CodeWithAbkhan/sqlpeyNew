Plugins for Mongoose like ElMongo, mongoose-full-text, Mongoosastic, etc. are not well documented, making it difficult to perform a full text search.

This article will discuss how to create a full text search with MongoDB and Mongoose. We will look at how to create a text index to support text search, perform a paged text search query, and some alternatives methods.

Creating a Text Index

We can add a text index to our Mongoose schema definition that lets us use the $text operator in our find queries to search all fields included in the text index.

For example, if we want to create an index to support text search on name and profile.something, we can do this:

var schema = new Schema({
  name: String,
  email: String,
  profile: {
    something: String,
    somethingElse: String
  }
});
schema.index({name: 'text', 'profile.something': 'text'});

Or if we want to include all string fields in the index, we can use the '$**' wildcard:

schema.index({'$**': 'text'});

Performing a Paged Text Search Query

Once we have created our text index, we can perform a paged text search query like this:

MyModel.find({$text: {$search: searchString}})
       .skip(20)
       .limit(10)
       .exec(function(err, docs) { ... });

Alternative Methods

Along with using text indexes, there are other alternatives to perform a full text search in MongoDB. For example, you can use the $regex operator or you can use the Text Query Language .
