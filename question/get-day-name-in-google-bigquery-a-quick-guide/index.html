How to Get Day Name in Google BigQuery
Getting the name of a day from a date is a common requirement in data analysis. In Google BigQuery, there are many ways to achieve this. In this post, we will go through two methods for standard SQL and legacy SQL.

Method 1: Using FORMAT_DATE() Function (Standard SQL)

In standard SQL, one way to get the name of the day from a date is to use the FORMAT_DATE() function. This function formats a date according to a specified format string.

The syntax of the FORMAT_DATE() function is as follows:

FORMAT_DATE(format_string, date_expression)

where:

  • format_string: The format string specifying the format of the output date string. In our case, we use ‘%A’ to get the full weekday name in the output.
  • date_expression: The input date expression, which can be a DATE, DATETIME or TIMESTAMP object.

Example Query:

#standardSQL
SELECT
  CURRENT_DATE() AS date,
  FORMAT_DATE('%A', CURRENT_DATE()) AS day_name

In this query, we first retrieve the current date using the CURRENT_DATE() function. We then use the FORMAT_DATE() function to format the date as the full weekday name, which we assign to the alias ‘day_name’.

Method 2: Using STRFTIME_UTC_USEC() Function (Legacy SQL)

In legacy SQL, we can use the STRFTIME_UTC_USEC() function to get the name of the day from a date. This function formats a UTC timestamp in microseconds to a specified format string.

To use this function in legacy SQL, we need to convert our date to a UTC timestamp in microseconds first using the TIMESTAMP_TO_USEC() function.

The syntax of the STRFTIME_UTC_USEC() function is as follows:

STRFTIME_UTC_USEC(timestamp_usec, format)

where:

  • timestamp_usec: The input timestamp in microseconds.
  • format: The format string specifying the format of the output string. In our case, we use ‘%A’ to get the full weekday name in the output.

Example Query:

#legacySQL
SELECT
  CURRENT_DATE() AS date,
  STRFTIME_UTC_USEC(TIMESTAMP_TO_USEC(TIMESTAMP(CURRENT_DATE())), '%A') AS day_name

In this query, we first retrieve the current date using the CURRENT_DATE() function. We then convert the date to a UTC timestamp in microseconds using the TIMESTAMP_TO_USEC() function. Lastly, we use the STRFTIME_UTC_USEC() function to format the timestamp as the full weekday name, which we assign to the alias ‘day_name’.

Alternative Ways

Both methods above are effective to get the name of the day from a date in BigQuery. Although, other alternative ways exist that you can use depending on your needs.

  • DAYOFWEEK() Function: This function returns the day of the week from a date as an integer value (1-7), where 1 represents Sunday, 2 represents Monday, and so on. You can use a CASE statement to map the integer value to the corresponding weekday name. Example query:
