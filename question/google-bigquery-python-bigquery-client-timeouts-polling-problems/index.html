BigQuery Client using Python | Timeout and Polling issues

Introduction

When working with Google Cloud’s BigQuery service in Python, you may face issues when executing SQL statements using the BigQuery Client. This can happen when waiting for the query to return results, which could result in a timeout or polling error. In this Q&A Session, we will discuss the causes of these errors and how to resolve them.

Issues with BigQuery Client

When executing a SQL statement on BigQuery using the BigQuery Client, you may encounter the following error: python File "/opt/conda/default/lib/python3.7/site-packages/google/api_core/future/polling.py", line xxx, in result self._blocking_poll(timeout=timeout, retry=retry, polling=polling) TypeError: _blocking_poll() got an unexpected keyword argument 'retry' This error occurs because of the version of Google libraries that are installed automatically with the google-cloud-bigquery library.

Version Compatibility Issues

If you are using version 1.x of the google-cloud-bigquery library, you need to ensure that the google-api-core library is less than version 1.34.0. This is because version 1.34.0 of google-api-core is not compatible with certain versions of the BigQuery Client. So, if you are using this version of the library or higher, you may face the above error.

Solutions

Here are some solutions to resolve these issues:

Update google-api-core

One solution is to update the google-api-core library to a version that is compatible with your version of the google-cloud-bigquery library. You can do this using the following command: console pip install --upgrade google-api-core Alternatively, you can specify the version of google-api-core in your requirements.txt file as follows: text google-api-core<1.34.0 This will ensure that you have a compatible version of google-api-core installed.

Wait for Query Results

Another solution is to add a timeout parameter to the result() method to wait for the query to return results. Here is an example of how to use this method: python query_job = client.query(QUERY) db_rslt = query_job.result(timeout=30) # Wait for the query to return results for a maximum of 30 seconds This will wait for the query to return results for a maximum of 30 seconds, and if there is no response after that period, it will raise a google.api_core.exceptions.TimeoutError.

Practical Examples

Here is an example of how to use the result() method with a timeout: python from google.cloud import bigquery client = bigquery.Client() QUERY = """ SELECT * FROM `bigquery-public-data.samples.gsod` WHERE stn = '725030' """ query_job = client.query(QUERY) results = query_job.result(timeout=30) for row in results: # Do something with the returned data print(row) In this example, we are querying the bigquery-public-data.samples.gsod dataset for weather data. We are then using the result() method to wait for the query to return results for a maximum of 30 seconds.

Alternative Ways

If you are still facing issues with the result() method, you can also try using the done() method to check if the query is complete, and then use the result() method to get the results. python query_job = client.query(QUERY) while not query_job.done(): time.sleep(1) results = query_job.result() This method will check if the query is complete every second until it is complete, and then get the results.

Recap
