Retrieve Last N Rows in SQL Server with SELECT statement How to select the last N rows in SQL Server without using ORDER BY?

If you have a table with a large number of rows, using ORDER BY to select the last N rows can take a lot of time. Here are some alternative ways to select the last N rows without using ORDER BY:

Method 1: Using TOP and ORDER BY

The most common way to select the last N rows in SQL Server is by using TOP and ORDER BY as follows:

SELECT TOP N *
FROM MyTable
ORDER BY Id DESC

Although, if your table has a large number of rows, this method can take a lot of time to execute.

Method 2: Using LIMIT

If you are using MySQL, you can use the LIMIT clause to get SQL server to select the last N rows with the following query:

SELECT * FROM tbl_name ORDER BY id DESC LIMIT N;

Method 3: Using ROW_NUMBER()

You can use the ROW_NUMBER() function to select the last N rows based on a condition. Here is an example that retrieves the last 5 orders placed by Employee 5:

SELECT ORDERID, CUSTOMERID, OrderDate
FROM
(
    SELECT ROW_NUMBER() OVER (PARTITION BY EmployeeID ORDER BY OrderDate DESC) AS OrderedDate, *
    FROM Orders
) AS ordlist
WHERE ordlist.EmployeeID = 5
AND ordlist.OrderedDate <= 5

Method 4: Using IN and TOP

If you want to select the last N rows from a table, you can use the following syntax:

SELECT *
FROM table_name
WHERE id IN (
    SELECT TOP N id
    FROM table_name
    ORDER BY id DESC
)

Method 5: Using EXCEPT and TOP

You can combine the EXCEPT operator with TOP to select the last N rows from a table:

SELECT *
FROM table_name
EXCEPT
SELECT TOP (total_rows - N) *
FROM table_name

Recap:

These are some alternative ways to select the last N rows in SQL Server without using ORDER BY. Each method has its advantages and disadvantages, and the performance may vary depending on the size of the table and the complexity of the query.
