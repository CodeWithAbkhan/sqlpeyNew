How to use the Int64 Pandas object when saving to a Parquet file for use in BigQuery?

Problem

You have data in CSV format that needs to be converted to Parquet for storing in Google BigQuery. Some of the columns contain missing values, which is resolved by using the Int64 data type in Pandas 0.24.0. Although, when trying to save the data to a Parquet file, the following error occurs:

pyarrow.lib.ArrowTypeError: ('Did not pass numpy.dtype object', 'Conversion failed for column id with type Int64')

You need to find a solution where the integer columns with missing values can still be stored as INTEGER in BigQuery.

Solution

To solve this issue, you need to use the PyArrow library to save the Parquet file instead of relying on Pandas. The following steps will guide you through the process:

Step 1: Import Required Libraries

Use the following code to import the required libraries:

import pandas as pd
import pyarrow as pa
import pyarrow.parquet as pq

Step 2: Load Data from CSV

Use the pd.read_csv() method to load data from a CSV file. The following code loads data from “test_file.csv” and prints information about the “id” column:

df = pd.read_csv("test_file.csv")
print(df["id"].info())

The output should display:

id                      8 non-null float64

Step 3: Convert Data Types to Int64

Use the astype() method to convert the data type of integer columns with missing values to Int64:

df["id"] = df["id"].astype('Int64')

The following code verifies that the data type conversion was successful:

print(df["id"].info())

The output should display:

id                      8 non-null Int64

Step 4: Save Data to Parquet using PyArrow

You can now use PyArrow to save the data to a Parquet file. Use the following code:

table = pa.Table.from_pandas(df)
pq.write_table(table, 'test.parquet')

The first line converts the Pandas DataFrame to a PyArrow Table. The second line uses the pq.write_table() method to save the data to a Parquet file named “test.parquet”.

Step 5: Load Parquet File into BigQuery

You can now load the Parquet file into BigQuery. The integer columns with missing values will still be stored as INTEGER.

Alternative Solution

If you prefer to use Pandas to save the Parquet file, you can write a custom pyarrow.interop extension to support the new Int64 column. The following code demonstrates how you can save the data to a Parquet file with Pandas:

def pandas_to_arrow_type(dtype):
    if dtype == 'Int64':
        return pa.int64()
    else:
        return pa.from_numpy_dtype(dtype)

pa.types.pandas_type = pandas_to_arrow_type

df.to_parquet("test.parquet", engine='pyarrow', compression='snappy')

The pandas_to_arrow_type() function maps the Int64 data type to pyarrow.int64(). The pandas_types.pandas_type attribute is then set to the new function. Lastly, you can use the to_parquet() method to save the data to a Parquet file using the PyArrow engine.
