Failed to start mongod.service: Unit mongod.service not found How to Solve Failed to Start Mongod.service on Ubuntu 16.04
MongoDB is a document-oriented NoSQL database used for high volume data storage. It is an open-source document database, which stores data in flexible, JSON-like documents. In this article, we will learn how to solve “Failed to start mongod.service” on Ubuntu 16.04.

Steps to Install MongoDB on Ubuntu 16.04

The following steps are required to install MongoDB on Ubuntu 16.04.

Step 1: Importing the MongoDB public GPG Key

sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv 2930ADAE8CAF5059EE73BB4B58712A2291FA4AD5

Step 2: Create a list file

echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu xenial/mongodb-org/3.6 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-3.6.list

Step 3: Update the packages list

sudo apt-get update

Step 4: Install the MongoDB packages

sudo apt-get install -y mongodb-org

Step 5: Start MongoDB

sudo service mongod start

Error Message: Failed to Start Mongod.service

When you try to start MongoDB, you may get the following error message:

Failed to start mongod.service: Unit mongod.service not found.

Solution

The most likely cause of this problem is that the unit mongodb.service is masked. To unmask it, use the following command:

sudo systemctl unmask mongod

Then re-run the start command:

sudo service mongod start

If this does not work, the following steps may be necessary to completely uninstall and reinstall MongoDB.

Step 1: Uninstall the current MongoDB installation

To uninstall MongoDB Community Edition, follow the instructions from the official MongoDB documentation:

  • Stop the MongoDB service: sudo service mongod stop
  • Purge the MongoDB packages: sudo apt-get purge mongodb-org*
  • Remove the MongoDB log files: sudo rm -r /var/log/mongodb
  • Remove the MongoDB data files: sudo rm -r /var/lib/mongodb

Step 2: Reinstall MongoDB

To reinstall MongoDB Community Edition, follow the instructions from the official MongoDB documentation:

  • Import the public key: sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv 2930ADAE8CAF5059EE73BB4B58712A2291FA4AD5
  • Create a list file for Ubuntu 16.04: echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu xenial/mongodb-org/3.6 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-3.6.list
  • Update the packages list: sudo apt-get update
  • Install the latest version of MongoDB: sudo apt-get install -y mongodb-org

Step 3: Try to start MongoDB

Once MongoDB is reinstalled, try to start it again with the following command:

sudo service mongod start
