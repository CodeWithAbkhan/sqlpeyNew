TSQL Pivot with No Aggregate Function Summary: This blog post explains how to pivot a table without an aggregate function in TSQL. The post includes an example table and desired output, as well as three different ways to achieve the desired output, including code explanations and syntax.

Example Table and Desired Output:

The example table consists of CustomerID, DBColumnName, and Data columns. The desired output is to pivot the DBColumnName column into separate columns, with the values under each corresponding column. Here is the example table and desired output: Example Table:

| CustomerID | DBColumnName | Data | | | | | |

| 1 | Joe | S | Smith | 12/12/2009 |

| 2 | Sam | S | Freddrick | 1/12/2009 |

| 3 | Jaime | S | Carol | 12/1/2009 |

Three Ways to Pivot a Table without Aggregate Function:

Option 1: GROUP BY and CASE WHEN

One way to pivot the table without an aggregate function is to use GROUP BY and CASE WHEN statements. Here is the code:

   Select CustomerID,
     Min(Case DBColumnName When 'FirstName' Then Data End) FirstName,
     Min(Case DBColumnName When 'MiddleName' Then Data End) MiddleName,
     Min(Case DBColumnName When 'LastName' Then Data End) LastName,
     Min(Case DBColumnName When 'Date' Then Data End) Date
   From table
   Group By CustomerId

Explanation: The code selects the CustomerID and uses a CASE WHEN statement to pivot the DBColumnName column into separate columns, with the values under each corresponding column. The MIN function is used as a workaround for a lack of actual aggregate function, as it only returns the single value for each record. The code then groups the results by CustomerID.

Option 2: PIVOT Function with MAX Aggregate

Another way to pivot without an aggregate function is to use the PIVOT function with the MAX aggregate. This may be more efficient than Option 1. Here is the code:

WITH pivot_data AS
(
SELECT customerid, -- Grouping Column
dbcolumnname, -- Spreading Column
data -- Aggregate Column
FROM pivot2 
)
SELECT customerid, [firstname], [middlename], [lastname]
FROM pivot_data
PIVOT (max(data) FOR dbcolumnname IN ([firstname],[middlename],[lastname])) AS p;

Explanation: The code uses a CTE (Common Table Expression) to select the columns needed to pivot. The PIVOT function is then used to pivot the DBColumnName column into separate columns, with the values under each corresponding column. The MAX function is used as a workaround for a lack of actual aggregate function, as it only returns the single value for each record. The code then selects the CustomerID and pivoted columns, and renames the pivoted columns to match the desired output.

Option 3: Self-Joining the Table

A third way to pivot the table is to self-join the table multiple times, with each self-join filtering by DBColumnName per table reference. This option is less efficient than the other options, but may be useful in some cases. Here is the code:

SELECT t1.CustomerID,
       t1.Data AS FirstName,
       t2.Data AS MiddleName,
       t3.Data AS LastName,
       t4.Data AS Date
FROM #temp t1
JOIN #temp t2 ON t1.CustomerID = t2.CustomerID AND t2.DBColumnName = 'MiddleName'
JOIN #temp t3 ON t1.CustomerID = t3.CustomerID AND t3.DBColumnName = 'LastName'
JOIN #temp t4 ON t1.CustomerID = t4.CustomerID AND t4.DBColumnName = 'Date'
WHERE t1.DBColumnName = 'FirstName'

Explanation: The code self-joins the table multiple times to create separate columns for the DBColumnName values. Each self-join is filtered by the appropriate DBColumnName per table reference. The code then selects the CustomerID and pivoted columns, and renames the pivoted columns to match the desired output.

Alternate Ways:

There are not many alternative ways to pivot a table without an aggregate function. The three options presented in this post are currently the most efficient and effective ways to pivot a table without an aggregate function.
