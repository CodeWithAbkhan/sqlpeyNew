GOOGLE BIGQUERY: Joining on Multiple Conditions in BigQuery with Subqueries and OR Statements

Summary:

The user is trying to join two tables on multiple conditions in BigQuery, but is getting an error message that a LEFT OUTER JOIN cannot be used without a condition that is an equality of fields from both sides of the join. They are migrating code from Postgres to BigQuery and previously solved this issue by using subqueries and OR statements to join on multiple potential conditions, then filtering out duplicates. The user is asking if there is a similar solution in BigQuery.

Solution:

In BigQuery, there is a way to join on multiple conditions using subqueries and COALESCE. The COALESCE function returns the first non-null value in a list of expressions, and can be used to check multiple fields for a match.

Here is an example query that achieves the desired result:

SELECT
  *
FROM
  (
    SELECT
      offer_table.offer_id,
      customer_table.customer_name,
      customer_table.visit_count,
      ROW_NUMBER() OVER (PARTITION BY offer_table.offer_id ORDER BY customer_table.visit_count DESC) AS customer_visit_rank
    FROM
      offer_table
    LEFT JOIN
      (
        SELECT customer_id, customer_name, visit_count FROM customer_table
        UNION ALL
        SELECT customer_id, customer_name, visit_count FROM customer_table WHERE email IS NOT NULL
        UNION ALL
        SELECT customer_id, customer_name, visit_count FROM customer_table WHERE phone IS NOT NULL
      ) customer_table
    ON
      offer_table.customer_id = customer_table.customer_id
      OR offer_table.email = customer_table.email
      OR offer_table.phone = customer_table.phone
  ) dummy
WHERE
  customer_visit_rank = 1

In this example, the customer_table is split into three separate subqueries that check for matches on the customer_id, email, and phone fields. These subqueries are then combined using UNION ALL and joined with the offer_table using OR statements. The COALESCE function is not needed in this case because the subqueries ensure that there is only one row for each customer.

Alternative Solution:

Another way to join on multiple conditions in BigQuery is to use the OR operator in the JOIN clause and specify the conditions in parentheses. Although, this will only work if the conditions are an equality of fields from both sides of the join.

Here is an example query that joins the offer_table and customer_table on the customer_id and email fields:

SELECT
  *
FROM
  offer_table
LEFT JOIN customer_table
ON
  offer_table.customer_id = customer_table.customer_id
  OR offer_table.email = customer_table.email

The above query will only return rows where there is a match on either the customer_id or email field. To filter out duplicates, you can use the ROW_NUMBER function and specify an ORDER BY clause that ranks the rows based on the visit_count field.

Recap:

In BigQuery, there are multiple ways to join on multiple conditions, depending on the specific requirements of the query. Using subqueries and COALESCE is one solution that works well for cases where there are multiple potential matching fields. Alternatively, using the OR operator in the JOIN clause can be used for cases where there is only one set of matching fields.]]>
