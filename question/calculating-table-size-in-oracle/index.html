Calculating Table Size in Oracle Database

If you’re wondering how to calculate the size of tables in Oracle, especially considering indexes and LOBs, this guide is here to help. Unlike MSSQL’s sp_spaceused command, Oracle requires a specific query. Let’s explore the details.

The Query

To retrieve the table size in Oracle, use the following query:

COLUMN TABLE_NAME FORMAT A32
COLUMN OBJECT_NAME FORMAT A32
COLUMN OWNER FORMAT A10

SELECT
   owner, 
   table_name, 
   TRUNC(sum(bytes)/1024/1024) Meg,
   ROUND( ratio_to_report( sum(bytes) ) over () * 100) Percent
FROM
(SELECT segment_name table_name, owner, bytes
 FROM dba_segments
 WHERE segment_type IN ('TABLE', 'TABLE PARTITION', 'TABLE SUBPARTITION')
 UNION ALL
 SELECT i.table_name, i.owner, s.bytes
 FROM dba_indexes i, dba_segments s
 WHERE s.segment_name = i.index_name
 AND   s.owner = i.owner
 AND   s.segment_type IN ('INDEX', 'INDEX PARTITION', 'INDEX SUBPARTITION')
 UNION ALL
 SELECT l.table_name, l.owner, s.bytes
 FROM dba_lobs l, dba_segments s
 WHERE s.segment_name = l.segment_name
 AND   s.owner = l.owner
 AND   s.segment_type IN ('LOBSEGMENT', 'LOB PARTITION')
 UNION ALL
 SELECT l.table_name, l.owner, s.bytes
 FROM dba_lobs l, dba_segments s
 WHERE s.segment_name = l.index_name
 AND   s.owner = l.owner
 AND   s.segment_type="LOBINDEX")
WHERE owner in UPPER('&owner')
GROUP BY table_name, owner
HAVING SUM(bytes)/1024/1024 > 10  /* Ignore really small tables */
ORDER BY SUM(bytes) desc;

The Explanation

Breaking down the query step by step:

  • Columns are formatted for readability.
  • The query starts by selecting the owner, table name, and the sum of bytes of the table or index.
  • The FROM clause uses a subquery to gather information from several DBA views, including dba_segments, dba_indexes, and dba_lobs.
  • The UNION ALL operator combines the results of multiple queries into a single result set, considering tables, indexes, and LOBs.
  • The WHERE clause filters on the table owner, prompted for at runtime.
  • The GROUP BY clause aggregates the data by table and owner.
  • The HAVING clause filters out small tables by checking that their size is greater than 10 MB.
  • The result set is ordered by the sum of bytes in descending order.

Practical Example

To find the size of the SALES table in the ACME schema, including indexes, run the following query:

SELECT
   owner, 
   table_name, 
   TRUNC(sum(bytes)/1024/1024) Meg,
   ROUND( ratio_to_report( sum(bytes) ) over () * 100) Percent
FROM
(SELECT segment_name table_name, owner, bytes
 FROM dba_segments
 WHERE segment_type IN ('TABLE', 'TABLE PARTITION', 'TABLE SUBPARTITION')
 UNION ALL
 SELECT i.table_name, i.owner, s.bytes
 FROM dba_indexes i, dba_segments s
 WHERE s.segment_name = i.index_name
 AND   s.owner = i.owner
 AND   s.segment_type IN ('INDEX', 'INDEX PARTITION', 'INDEX SUBPARTITION')
 UNION ALL
 SELECT l.table_name, l.owner, s.bytes
 FROM dba_lobs l, dba_segments s
 WHERE s.segment_name = l.segment_name
 AND   s.owner = l.owner
 AND   s.segment_type IN ('LOBSEGMENT', 'LOB PARTITION')
 UNION ALL
 SELECT l.table_name, l.owner, s.bytes
 FROM dba_lobs l, dba_segments s
 WHERE s.segment_name = l.index_name
 AND   s.owner = l.owner
 AND   s.segment_type="LOBINDEX")
WHERE owner = 'ACME'
AND table_name = 'SALES'
GROUP BY table_name, owner;

The result would show the size of the SALES table and its indexes.

Alternative Ways

If you lack access to DBA views, consider the following alternative query:

-- Tables + Size MB
select owner, table_name, round((num_rows*avg_row_len)

FAQs on Calculating Table Size in Oracle

Q: How do I calculate the size of tables in Oracle?

To calculate the size of tables in Oracle, use a comprehensive query that considers indexes and LOBs. The guide provides a detailed explanation and practical examples.

Q: What does the query for calculating table size in Oracle include?

The query includes considerations for tables, indexes, and LOBs. It aggregates data by table and owner, filtering out small tables, and provides the result in descending order of size.

Q: How can I find the size of a specific table, including indexes?

To find the size of a specific table, including indexes, modify the query and specify the owner and table name in the WHERE clause.

Q: Can I use alternative methods to calculate table size in Oracle?

Yes, an alternative query is provided in the guide for those who don’t have access to DBA views. It offers a different approach to calculate table size.

Q: Is there a threshold for excluding small tables in the calculation?

Yes, the query includes a condition (HAVING SUM(bytes)/1024/1024 > 10) to exclude tables smaller than 10 MB from the result.
