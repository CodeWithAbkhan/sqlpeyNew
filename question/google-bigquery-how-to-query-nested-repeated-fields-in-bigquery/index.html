Summary: The author wants to set up a BigQuery table that contains a message column and a metadata column (repeated) to enable querying for messages that match certain metadata parameters. The author came up with a schema that includes a metadata record with key/value pairs.

Setting up BigQuery table with nested/repeated fields To set up a BigQuery table with nested/repeated fields, you will need to define the schema for the table. In this case, we will have a message column (string) and a metadata column (repeated), where each metadata entry will have a key (string) and a value (string).

[
  {"name": "message", "type": "string", "mode": "required"},
  {"name": "metadata", "type": "record", "mode": "repeated", "fields": [
    {"name": "key", "type": "string", "mode": "required"},
    {"name": "value", "type": "string", "mode": "required"}
  ]}
]

The metadata column is defined as a repeated record field, which means that it can contain multiple metadata entries for each message. Each metadata entry has a key and a value, both of which are required fields.

Querying BigQuery nested/repeated fields

Once you have set up your BigQuery table with nested/repeated fields, you can query it based on the metadata entries. For example, to retrieve all messages with a category of “personal”, you can use the following query:

SELECT message FROM mytable
WHERE "personal" IN (
  SELECT value FROM UNNEST(metadata)
  WHERE key = "category"
)

This query uses the UNNEST function to extract the values from the metadata entries that have a key of “category”. It then checks if “personal” is in the list of values and returns the corresponding messages. You can also use the metadata key as a parameter in the query:

SELECT message FROM mytable
WHERE "favorite_color" IN (
  SELECT key FROM UNNEST(metadata)
)

This query retrieves all messages that have a metadata entry with a key of “favorite_color”.

Practical Examples

Suppose we have the following data:

[
  {
    "message": "Hi honey, I'm home!",
    "metadata": [
      {"key": "category", "value": "personal"},
      {"key": "message_type", "value": "salutation"}
    ]
  },
  {
    "message": "What's up, doc?",
    "metadata": [
      {"key": "category", "value": "work"},
      {"key": "priority", "value": "high"}
    ]
  }
]

To retrieve all messages with a category of “personal”:

SELECT message FROM mytable
WHERE "personal" IN (
  SELECT value FROM UNNEST(metadata)
  WHERE key = "category"
)

This query will return the first message: “Hi honey, I’m home!”. To retrieve all messages with a priority of “high”:

SELECT message FROM mytable
WHERE "high" IN (
  SELECT value FROM UNNEST(metadata)
  WHERE key = "priority"
)

This query will return the second message: “What’s up, doc?”.
