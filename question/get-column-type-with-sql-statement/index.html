Get Column Type with SQL Statement How to Get Column Type in SQL Server
Have you ever needed to retrieve the type of a specific column in your SQL Server database? There are several ways you can achieve this, and in this blog post, we will provide you with some practical examples and explain each line of code.

Using INFORMATION_SCHEMA.COLUMNS

One way to retrieve the type of a column is to use the INFORMATION_SCHEMA.COLUMNS system view. The following code demonstrates how to use it:

SELECT DATA_TYPE 
FROM INFORMATION_SCHEMA.COLUMNS
WHERE 
     TABLE_SCHEMA = 'yourSchemaName' AND
     TABLE_NAME   = 'yourTableName' AND 
     COLUMN_NAME  = 'yourColumnName'

Let’s examine this code line by line:

  • SELECT DATA_TYPE: We are selecting the DATA_TYPE column from the INFORMATION_SCHEMA.COLUMNS system view.
  • FROM INFORMATION_SCHEMA.COLUMNS: We are retrieving information about columns from the INFORMATION_SCHEMA.COLUMNS system view.
  • WHERE TABLE_SCHEMA = 'yourSchemaName' AND TABLE_NAME = 'yourTableName' AND COLUMN_NAME = 'yourColumnName': We are specifying the name of the schema, table, and column that we want to retrieve information for.

Using sp_help

Another way to retrieve column information is to use the sp_help system stored procedure. Here is an example:

exec sp_help YOURTABLENAME

This code will return all table information, including column datatypes. Here is what each line means:

  • exec sp_help: This is how you call a system stored procedure in SQL Server.
  • YOURTABLENAME: Replace this with the name of your table to retrieve its information.

Using sys.tables and sys.columns

A third way to retrieve column information is to use the sys.tables and sys.columns system views. Here is an example:

SELECT t.name, c.name 
FROM sys.tables t 
JOIN sys.columns c ON t.object_id = c.object_id
JOIN sys.types y ON y.user_type_id = c.user_type_id
WHERE t.name=""

Here is what this code does:

  • SELECT t.name, c.name: We are selecting the name columns from the sys.tables and sys.columns system views, respectively.
  • FROM sys.tables t JOIN sys.columns c ON t.object_id = c.object_id JOIN sys.types y ON y.user_type_id = c.user_type_id: We are joining the sys.tables, sys.columns, and sys.types system views together to retrieve the column information.
  • WHERE t.name="": We are specifying the name of the table that we want to retrieve column information for.

Retrieving Column Information in a Specific Format

Sometimes you might want to retrieve the column information in a specific format that would be useful when declaring columns. Here is an example of how to do that:

SELECT 
  [Name]         = c.[name]
, [Type]         = 
    CASE 
      WHEN tp.[name] IN ('varchar', 'char', 'varbinary') THEN tp.[name] + '(' + IIF(c.max_length = -1, 'max', CAST(c.max_length AS VARCHAR(25))) + ')' 
      WHEN tp.[name] IN ('nvarchar','nchar') THEN tp.[name] + '(' + IIF(c.max_length = -1, 'max', CAST(c.max_length / 2 AS VARCHAR(25)))+ ')'      
      WHEN tp.[name] IN ('decimal', 'numeric') THEN tp.[name] + '(' + CAST(c.[precision] AS VARCHAR(25)) + ', ' + CAST(c.[scale] AS VARCHAR(25)) + ')'
      WHEN tp.[name] IN ('datetime2') THEN tp.[name] + '(' + CAST(c.[scale] AS VARCHAR(25)) + ')'
      ELSE tp.[name]
    END
, [RawType]      = tp.[name]
, [MaxLength]    = c.max_length
, [Precision]    = c.[precision]
, [Scale]        = c.scale
, [IsNullable]   = c.is_nullable
FROM sys.tables t 
JOIN sys.schemas s ON t.schema_id = s.schema_id
JOIN sys.columns c ON t.object_id = c.object_id
JOIN sys.types tp ON c.user_type_id = tp.user_type_id
WHERE s.[name] = 'dbo' AND t.[name] = 'MyTable'

This code will retrieve the column information and format it in a way that can be used to declare columns in SQL Server. Let’s examine the code line by line:

  • [Name] = c.[name]: We are selecting the name of the column and aliasing it as [Name].
  • [Type] = CASE ... END: We are using a CASE statement to select the column type and format it in a way that can be used to declare columns in SQL Server. This is aliased as [Type].
  • [RawType] = tp.[name]: We are also selecting the raw column type and aliasing it as [RawType].
  • [MaxLength] = c.max_length: We are selecting the maximum length of the column and aliasing it as [MaxLength].
  • [Precision] = c.[precision]: We are selecting the precision of the column and aliasing it as [Precision].
  • [Scale] = c.scale: We are selecting the scale of the column and aliasing it as [Scale].
  • [IsNullable] = c.is_nullable: We are selecting whether the column is nullable or not and aliasing it as [IsNullable].
