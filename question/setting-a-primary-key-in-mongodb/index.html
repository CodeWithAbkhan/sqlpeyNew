How to set a primary key in MongoDB? How to Set a Primary Key in MongoDB?
A primary key is an essential element of a database. It is a unique identifier used to distinguish each element of the database and helps to ensure the integrity of the data. In MongoDB, the _id field is reserved for primary key, and it should be a unique value.

What is a MongoDB Id?

MongoDB uses an internal ObjectId for the _id field if you do not define it in your object. This ObjectId is automatically generated and is used as an index to ensure performance. The ObjectId is a 12-byte BSON type and is composed of:

  • A 4-byte timestamp value, representing the ObjectIdâ€™s creation time in seconds
  • A 3-byte machine identifier
  • A 2-byte process id
  • A 3-byte counter, starting with a random value

Can I Use My Own Unique Value for _id?

Yes, you can put your own unique value for _id and MongoDB will use it instead of making one for you. This can be a string, number, or other data type.

What if I Need to Use Multiple Fields for Primary Key?

You can also use an object for the _id field to use multiple fields for a primary key. For example,

{ _id : { a : 1, b: 1} }

Just be careful when using objects as ids, as the order of the keys (in this example, a and b) matters. If you swap them, it is considered a different id.

Creating Unique Indexes

Another way to ensure a unique value is to create unique indexes in your collection. A unique index prevents the insertion of documents whose index key values match an existing document’s index key value. In other words, you can set a unique index on any field in your collection to prevent duplicate values.

You can find more information about creating a unique index in the MongoDB documentation here .

Creating an Index on _id

When you create a collection, MongoDB automatically creates an index on the _id field. This index is a unique index and ensures that each document in the collection has a unique _id value. This index also helps to ensure the performance of queries and updates on the _id field.

Using a Custom _id Value with Indexes

If you are using a custom value for the _id field, you should also create an index on the field to ensure performance and uniqueness. You can do this by using the following command:

db.collectionName.createIndex({urfield:1},{unique:true});

This will create a unique index on the urfield field in the collectionName collection.
