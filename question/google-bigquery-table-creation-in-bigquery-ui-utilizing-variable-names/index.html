Creating a Dynamic Table Name in BigQuery UI using Variables
BigQuery is a cloud data warehouse offered by Google Cloud Platform. It allows you to store structured and unstructured data into tables and run SQL-like queries on them. The tables in BigQuery are used to store data that is structured similarly to spreadsheets.

In some cases, you might need to create tables dynamically, with names that vary based on the input data or other factors. In such cases, you can’t hardcode the table name, which would be inefficient and prone to errors. Instead, you can use variables in your queries to generate the table name dynamically based on your needs.

Creating a Table Dynamically Using a Variable in BigQuery UI

Suppose you want to write a BigQuery script that creates a table where the table name is derived from a variable value. Here’s an example:

DECLARE id STRING;
SET id = '123';

CREATE OR REPLACE TABLE test.id AS(
SELECT * FROM dataset.table
)

In this example, the query will create a table with the name id instead of the value of the “id” variable (which is 123). To dynamically generate the table name, you can use the Concatenate function within the Execute Immediate statement:

EXECUTE IMMEDIATE CONCAT('CREATE TABLE `', id, '` (column_name STRING)');

In this query, the “id” variable value is concatenated with the CREATE TABLE statement to create a unique table name. The table schema is defined after the table name, using standard SQL syntax.

The backticks around the table name are necessary to escape special characters that might be included in the table name, such as spaces or hyphens. This ensures that the query runs without errors.

Limitations of Using Variables for Dynamic Table Names in BigQuery

It’s important to remember that SQL object identifiers, such as table names, cannot be replaced with variables in BigQuery. Parameters can be used as placeholders for values in queries, but you can’t use them to substitute table or column names.

Although, by using the Concatenate function and Execute Immediate statement, you can create dynamic table names based on variable values and still run your queries successfully.

Practical Example of Creating a Table with Dynamic Name in BigQuery UI

Suppose your company has multiple branches in different cities, and you want to create a table in BigQuery for each branch that contains information about employees in that branch. You have a list of branch names in a spreadsheet and want to use them to create the table names dynamically.

Here’s an example code snippet for accomplishing this:

DECLARE branch_name STRING;
DECLARE query_string STRING;

-- loop through each branch in the spreadsheet
FOR branch IN (SELECT * FROM `project.dataset.branches`) DO
  -- assign the branch name to a variable
  SET branch_name = branch.branch_name;
  
  -- create a query string with the dynamic table name
  SET query_string = CONCAT("CREATE OR REPLACE TABLE `project.dataset.", branch_name, "_employees` AS (
                              SELECT * FROM `project.dataset.employees` WHERE branch = '", branch_name, "')");
  
  -- execute the query using the dynamic table name
  EXECUTE IMMEDIATE query_string;
END FOR;

In this example, a loop is used to iterate through each branch name in the “branches” table of the dataset. The branch name is assigned to a variable, and a query string is created with the dynamic table name by concatenating the branch name with “_employees”.

The SELECT statement within the query retrieves data for the particular branch from the “employees” table, which has a column called “branch” with the name of the branch each employee is assigned to.

The Execute Immediate statement is used to execute the query with the dynamically generated table name. This creates a new table for each branch, with the name “branch_name_employees”, that contains data only for employees assigned to that branch.
