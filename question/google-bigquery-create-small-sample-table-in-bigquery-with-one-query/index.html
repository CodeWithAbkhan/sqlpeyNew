Creating Small Tables in BigQuery Using Sample Data

Summary

In BigQuery, you can create small sample tables using various methods. The most common ones include using the CREATE TABLE ... AS SELECT syntax with predefined values or the UNNEST function to unnest an array of structures.

Creating Small Sample Tables Using Predefined Values

To create a small table with predefined values, you can use the CREATE TABLE ... AS SELECT syntax. Here is an example of how to create a table with two columns named A and B. The A column takes values 1,2,3,4, and the B column takes values "Alpha", "Bravo", "Charlie", "Delta":

CREATE TABLE `PROJECT_ID.DATASET_NAME.NEW_TABLE_NAME` AS  
SELECT 1 AS a, 'Alpha' AS b UNION ALL
SELECT 2 AS a, 'Bravo' AS b UNION ALL
SELECT 3 AS a, 'Charlie' AS b UNION ALL
SELECT 4 AS a, 'Delta' AS b;

In this example, the query creates a new table called NEW_TABLE_NAME in the specified BigQuery project and dataset with columns A and B that have the predefined values.

Alternative Way

Another less verbose method is:

CREATE TABLE `PROJECT_ID.DATASET_NAME.NEW_TABLE_NAME` AS  
SELECT * FROM UNNEST([
  STRUCT(1 AS a, 'Alpha' AS b),
  (2, 'Bravo'),
  (3, 'Charlie'),
  (4, 'Delta')
]);

In this case, the predefined values are defined within an array of structures, and the UNNEST function is used to flatten the array.

Creating Small Sample Tables Using the UNNEST Function

You can also create small tables using the UNNEST function to unnest an array of structures. Here is an example of how to create a table with two columns that correspond to a CSV file’s columns:

CREATE TABLE `PROJECT_ID.DATASET_NAME.NEW_TABLE_NAME` AS  
SELECT * FROM UNNEST([
  STRUCT(NULL AS a, '' AS b),
  (1, 'Alpha'),
  (2, 'Bravo'),
  (3, 'Charlie'),
  (4, 'Delta')
])
WHERE NOT a IS NULL;

In this example, the query creates a new table called NEW_TABLE_NAME in the specified BigQuery project and dataset with columns A and B that correspond to the CSV file’s columns.

Alternative Way

An alternative, less verbose, but more easily reusable method is:

CREATE TABLE `PROJECT_ID.DATASET_NAME.NEW_TABLE_NAME` AS  
SELECT * FROM UNNEST([
  STRUCT(1 AS a, 'Alpha' AS b),
  (2, 'Bravo'),
  (3, 'Charlie'),
  (4, 'Delta')
])

This query creates a similar table as the first example but uses the UNNEST function with an array of structures.

Recap

Creating small sample tables in BigQuery is easy using a variety of methods. You can use predefined values with the CREATE TABLE ... AS SELECT syntax or the UNNEST function to unnest an array of structures. Choose the method that best fits your needs.
