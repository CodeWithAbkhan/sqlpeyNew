How to create a DB for MongoDB container on start up? How to Create a DB for MongoDB Container on Start Up?
If you are working with Docker and need to add MongoDB to your existing stack with PHP, MySQL, Apache and Redis, then you need to create a DB for MongoDB container on start up. In this article, we will look at a clean solution to achieve this using docker-compose and a JavaScript script.

What Do You Need?

Before we get started, make sure you have the following things ready:

  • A docker-compose.yml file
  • A JavaScript script (mongo-init.js)

How To Set Up A Default DB For MongoDB Container?

The easiest way to set up a default DB for MongoDB container is to use the Dockerfile and docker-entrypoint.sh file from the MongoDB Dockerhub. You can find them here and here .

In MySQL, you can set up some environment variables in the docker-compose.yml file, like this:

db:
    image: mysql:5.7
    env_file: .env
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE}
      MYSQL_USER: ${MYSQL_USER}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}

This will set up the DB and user/password as the root password.

Clean Solution Using Docker-Compose and JavaScript Script

Here is a cleaner solution that uses docker-compose and a JavaScript script. The example assumes that both files (docker-compose.yml and mongo-init.js) are in the same folder.

docker-compose.yml

version: '3.7'

services:
    mongodb:
        image: mongo:latest
        container_name: mongodb
        restart: always
        environment:
            MONGO_INITDB_ROOT_USERNAME: 
            MONGO_INITDB_ROOT_PASSWORD: 
            MONGO_INITDB_DATABASE: 
        ports:
            - 27017:27017
        volumes:
            - ./mongo-init.js:/docker-entrypoint-initdb.d/mongo-init.js:ro

mongo-init.js

db.createUser(
        {
            user: "",
            pwd: "",
            roles: [
                {
                    role: "readWrite",
                    db: ""
                }
            ]
        }
);

Once you have the files ready, you can start the service by running the following docker-compose command:

docker-compose up --build -d mongodb

Note: The code in the docker-entrypoint-init.d folder is only executed if the database has never been initialized before.

Conclusion

In this article, we looked at how to create a DB for MongoDB container on start up using docker-compose and a JavaScript script. This is a cleaner solution than using the Dockerfile and docker-entrypoint.sh file from the MongoDB Dockerhub. We also discussed why the code in the docker-entrypoint-init.d folder is only executed if the database has never been initialized before. ]]>
