List of Free Products of AWS

Build your own database solutions with  AWS Free Tier.

1. Amazon DynamoDB

Amazon DynamoDB is a AWS NoSQL Database Service, Which is Serverless, cloud based lifetime Free database for applications that need high performance at any scale. Free available storage of 25 GB of storage with 25 units of write capacity and can handle up to 200 million requests per month. Get Know about free AWS NoSQL Database

2. Amazon RDS

AWS RDS is fully Managed Relational Database with 20 GB of SSD data storage. Amazon RDS also have free capability of 20 DB storage for database backups and database snapshots. it also comes with free relational database service for MySQL, PostgreSQL, MariaDB, Oracle BYOL, or SQL Server free with duration of 12 Months.

3. Amazon Redshift

Which is a fast, simple, cost-effective data warehouse with 2 months of FREE TRIAL and can handle up to 750 DC2 large node hours per month.

4. Amazon Neptune

Neptune Is a Graph Database Service available free with 30 Days Trial with 1 GB of Storage and Backup, which is Fully managed, high-performance graph database. Amazon AWS have comes with open-source APIs such as Gremlin, SPARQL and openCypher. In Free Trail it have capability to handle up to 10 million of 1/O requests.

5. AWS Database Migration Service

It is another Amazon AWS lifetime free service with 50 GB of SSD Storage, It is Database Migration with minimal downtime along with single Availability Zone dms.t2.micro instance usage.

6.Amazon ElastiCache

Amazon ElasticCache is In-Memory Data Store with 12 Months of free availability. which make easy for you to deploy and operate large scale data with popular open source compatible in memory data stores. it has 750 hours of cache.t2micro node usage.

7. Amazon MemoryDB

Another In-Memory Database with 2 months free trail is Amazon MemoryDB with ultra fast performance, durable and have Redis compatibility. it comes with 20 GB of free data per month.

8. Amazon DocumentDB

Amazon DocumentDB is comes with 30 Day free trail (5 Gb of Data Storage and Backup) with 30 Million I/O operations for 30 days. It is fully managed document database service with high scalability and durability and it can handle any critical situation with mission-critical MonogDB.
