When working with MongoDB, it is sometimes necessary to perform a case insensitive search. In this article, we will discuss how to do this, as well as provide some examples of queries for performing case insensitive searches.

Case Insensitive Search Using Regex

The most common way to do a case insensitive search in MongoDB is to use a regular expression (regex) in the query. For instance, if you wanted to find documents that contain the word “win”, you could use the following regex:

{"SearchWord" : { '$regex' : 'win', $options: '-i' }}

This will return documents that contain the word “win”, regardless of the case. However, if you wanted to restrict the search to only return documents that contain the exact word “win”, you would need to use a slightly different regex:

{"SearchWord" : { '$regex' : '^win$', $options: '-i' }}

This regex will only match documents that contain the exact word “win”, regardless of the case. To get a better understanding of how regex works, you can refer to this cheat sheet .

Using Text Indexes (MongoDB 2.4+)

As of MongoDB 2.4, you can use a text index and a full text search query to perform a case insensitive search. This is more efficient than using a regex, as it can leverage the index to quickly find documents that match the query. However, if you are using an older version of MongoDB, the regex approach is still valid.

Examples

Here are a few examples of queries for performing case insensitive searches in MongoDB:

  • Exact case insensitive string:

      db.collection.find({name:{'$regex' : '^string$', '$options' : 'i'}})

  • Contains string:

      db.collection.find({name:{'$regex' : 'string', '$options' : 'i'}})

  • Start with string:

      db.collection.find({name:{'$regex' : '^string', '$options' : 'i'}})

  • End with string:

      db.collection.find({name:{'$regex' : 'string$', '$options' : 'i'}})

  • Doesn’t Contains string:

      db.collection.find({name:{'$regex' : '^((?!string).)*$', '$options' : 'i'}})

Conclusion

To summarize, case insensitive searches in MongoDB can be done using either a regex or a text index and full text search query. Depending on what version of MongoDB you are using, you may want to choose one approach over the other.
