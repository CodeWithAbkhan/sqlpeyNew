Summary:

Exporting BigQuery table data to Google Cloud Storage (GCS) can be done easily using Python. Although, if you need to export data from a specific date range, you need to build a result table first and then export the result to GCS. In this post, we will go through the Python code to export data from a BigQuery table to GCS while using a “where” clause to limit the data.

Step-by-step Guide:

Step 1: Import Required Libraries

First, we need to import the Google Cloud BigQuery and GCS libraries.

from google.cloud import bigquery
from google.oauth2 import service_account
from google.cloud import storage
import time

Step 2: Authenticate with Service Account Credentials

Next, you need to authenticate by passing the path of your service account key JSON file while creating an object of the BigQuery client and GCS client.

key_path = 'path-to-service-account-key.json'
credentials = service_account.Credentials.from_service_account_file(key_path)
client = bigquery.Client(credentials=credentials, project=credentials.project_id)
storage_client = storage.Client.from_service_account_json(key_path)

Step 3: Create Query to Extract Required Data

Now, create a query to extract the required data from BigQuery by updating the where clause as per your requirement.

job_config = bigquery.QueryJobConfig()
gcs_filename="file_*.gzip"

table_ref = client.dataset(dataset_id).table('my_temp_table')
job_config.destination = table_ref

job_config.write_disposition = bigquery.WriteDisposition.WRITE_TRUNCATE

# Start the query, passing in the extra configuration.
query_job = client.query(
    """#standardSql
    select * from `project.dataset.table` where  ;""",     location='US',     job\_config=job\_config)  while not query\_job.done():     time.sleep(1) ```  Step 4: Check if Query Job Completed  Wait for the query job to complete and check if the table is successfully written.   ```python print("query completed") ```  Step 5: Export Table to GCS  Next, export the result table to GCS in the desired format using the BigQuery extract method.  ```python destination\_uri = 'gs://my-bucket/result-table.csv' extract\_job = client.extract\_table(     table\_ref,     destination\_uri,     # Location must match that of the source table.     location='US')  # API request extract\_job.result()   ```  Step 6: Check if Export Job is Successful  Wait for the export job to complete and check if the file is successfully written in the GCS bucket.  ```python bucket\_name = 'my-bucket' bucket = storage\_client.get\_bucket(bucket\_name) blob = bucket.blob('result-table.csv')  if blob.exists():     print("Table export successful!") else:     print("Table export failed!") ```  Alternative Way:  If you want to avoid creating a result table, you can also export data directly from the BigQuery table to GCS by adding the `destination\_ur\_format` parameter in the `job\_config` object and passing the GCS URI as per your requirement. This method does not include the where clause filtering and is not recommended if you want to limit the data based on a specific date range.  ```python job\_config = bigquery.ExtractJobConfig() job\_config.compression = bigquery.Compression.GZIP job\_config.destination\_format = (     bigquery.DestinationFormat.CSV) destination\_uri = 'gs://my-bucket/table-export.csv'  # Export the table to GCS extract\_job = client.extract\_table(     table\_ref,     destination\_uri,     location='US',     job\_config=job\_config) extract\_job.result() ```  Recap:  Exporting data from a BigQuery table to GCS is straightforward with Python and the BigQuery and GCS libraries. By following the above steps, you can extract, filter, and export your required data to GCS.
