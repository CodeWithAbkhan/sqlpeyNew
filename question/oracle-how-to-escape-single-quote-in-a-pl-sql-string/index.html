ORACLE: How to Escape Single Quote in a PL/SQL String In Oracle PL/SQL, there are a few ways to escape a single quote in a string. Below are some of the common methods:

  1. Literal Quoting: You can use the ‘q’ syntax to quote strings. This makes it easier to escape single quotes within the string. Here’s an example:
stmt := q'[insert into MY_TBL (Col) values('ER0002')]';

In this example, we used the ‘q’ syntax to quote the string. The opening and closing brackets indicate the start and end of the quoted string. Inside the brackets, you can use any character to delimit the string. We used ‘[’ and ‘]’ in this case. This makes it easier to escape single quotes within the string because you don’t have to use backslashes.

  1. Double Quotes: You can double up the single quotes in a string to escape them. Here’s an example:
stmt := 'insert into MY_TBL (Col) values(''ER0002'')';

In this example, we used two single quotes to escape a single quote. This can get confusing if you have a lot of single quotes in your string.

  1. CHR(39): You can use the CHR function to get the ASCII value of a single quote. The ASCII value of a single quote is 39. Here’s an example:
stmt := 'insert into MY_TBL (Col) values(' || chr(39) || 'ER0002' || chr(39) || ')';

In this example, we concatenated the single quote character to the string using the concatenation operator ‘||’. The CHR function returns the ASCII value of the single quote character, which we used to concatenate the single quote to the string.

declare
  stmt varchar2(2000);
begin
  for i in 1021 .. 6020
  loop
    stmt := q'[insert into MY_TBL (Col) values('ER0002')]';

    dbms_output.put_line(stmt);
    execute immediate stmt;
    commit;
  end loop;
exception
  when others then
    rollback;
    dbms_output.put_line(sqlerrm);
end;
/

This code is using the Literal Quoting method to escape the single quote in the string. The ‘q’ syntax is used to quote the string which makes it easier to escape the single quote.

Let’s try to rewrite this code to make it unique:

DECLARE
  stmt VARCHAR2(2000);
  value VARCHAR2(50) := 'ER0002';
BEGIN
  FOR i IN 1021 .. 6020 LOOP
    stmt := q'[INSERT INTO MY_TBL (COL) VALUES(']'||value||q'[')]';

    COMMIT;
  END LOOP;
EXCEPTION
  WHEN OTHERS THEN
    ROLLBACK;

END;
/

In this example, we used a variable to store the value we want to insert into the table. This makes it easier to reuse the variable in multiple places. We concatenated the value variable to the string using the concatenation operator ‘||’. We also used the ‘q’ syntax with a different delimiter to make the code unique.
