Insert results of a stored procedure into a temporary table

It is possible to insert the results of a stored procedure into a temporary table. To do so, the INSERT statement can be used along with the EXECUTE command. This is an answer to a slightly modified version of the question: â€œHow do I do a SELECT * INTO [temp table] FROM [stored procedure]? Not FROM [Table] and without defining [temp table]?â€

The following code provides an example of how to select all data from BusinessLine into tmpBusLine. This works fine:

select *
into tmpBusLine
from BusinessLine

However, if the same is tried using a stored procedure that returns data, it is not quite the same. The following code will produce an incorrect syntax error:

select *
into tmpBusLine
from
exec getBusinessLineHistory '16 Mar 2009'

Output message:

Msg 156, Level 15, State 1, Line 2 Incorrect syntax near the keyword ’exec'.

It is possible to create a temporary table with the same structure as the output stored procedure. However, it would be nice to not supply any columns. To do this, it is possible to use the OPENROWSET command. This command is used to access data from an OLE DB data source. The following code provides an example of how to use OPENROWSET to execute the stored procedure, getBusinessLineHistory:

CREATE PROC getBusinessLineHistory
AS
BEGIN
    SELECT * FROM sys.databases
END
GO

sp_configure 'Show Advanced Options', 1
GO
RECONFIGURE
GO
sp_configure 'Ad Hoc Distributed Queries', 1
GO
RECONFIGURE
GO

SELECT * INTO #MyTempTable FROM OPENROWSET('SQLNCLI', 'Server=(local)\SQL2008;Trusted_Connection=yes;',
     'EXEC getBusinessLineHistory')

SELECT * FROM #MyTempTable

If a user-defined function is used rather than a stored procedure, this can return a table. Alternatively, if the stored procedure is used, the following code can be tried:

CREATE TABLE #tmpBus
(
   COL1 INT,
   COL2 INT
)

INSERT INTO #tmpBus
Exec SpGetRecords 'Params'

In SQL Server 2005, the INSERT INTO ... EXEC command can be used to insert the result of a stored procedure into a table. This is demonstrated in the example below, taken from the MSDN documentation:

--INSERT...EXECUTE procedure example
INSERT author_sales EXECUTE get_author_sales

To summarize, it is possible to insert the results of a stored procedure into a temporary table. This can be achieved using the INSERT statement and the EXECUTE command, or by using the OPENROWSET command. It is also possible to create a user-defined function rather than a stored procedure, or to use the INSERT INTO ... EXEC command, if using SQL Server 2005. ]]>
