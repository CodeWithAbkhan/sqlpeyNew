ORACLE: ORA-00904: Invalid Identifier - An Error You Don’t Want to See on Your Database How to Fix ORA-00904 Invalid Identifier Error in Oracle SQL?

Introduction

If you are working with an Oracle database and trying to execute an SQL query that involves joining tables, you may encounter the ORA-00904 error. This error occurs when the database engine cannot recognize a column name or variable in the SQL statement. One such example of this error is “ORA-00904: invalid identifier.” In this blog post, we will discuss the causes of the ORA-00904 error, its solution, and provide practical examples of how to fix it.

Learning the ORA-00904 Error

The ORA-00904 error occurs when there is a typo or incorrect column name used in your SQL query. This error could happen in several scenarios:

  • Misspelled column or table name

  • Incorrectly used reserved words or special characters

  • Quoted and un-quoted identifiers

    The ORA-00904 error can occur in many different Oracle SQL versions, including Oracle 18c, Oracle 12c, and Oracle 11g.

An Example Case: Resolving ORA-00904 Error in a Query

Consider the following SQL query, which intends to join Employee and Department tables.

SELECT Employee.EMPLID as EmpID, 
        Employee.FIRST_NAME AS Name,
        Team.DEPARTMENT_CODE AS TeamID, 
        Team.Department_Name AS teamname
FROM PS_TBL_EMPLOYEE_DETAILS Employee
INNER JOIN PS_TBL_DEPARTMENT_DETAILS Team ON Team.DEPARTMENT_CODE = Employee.DEPTID

Executing this query would return the ORA-00904 error, with the following message:

INNER JOIN PS_TBL_DEPARTMENT_DETAILS Team ON Team.DEPARTMENT_CODE = Employee.DEPTID
                                              *
ERROR at line 4:
ORA-00904: "TEAM"."DEPARTMENT_CODE": invalid identifier

This error occurs because the column “DEPARTMENT_CODE” is either misnamed, does not exist, or is spelled differently, leading to an “invalid identifier” error in the query.

Fixing the ORA-00904 Error

To fix the ORA-00904 error, it is essential to identify the cause of the error first. Here are a few ways to identify and fix the problem:

1. Correcting the spelling mistake

If the ORA-00904 error was due to a spelling mistake, the solution is as simple as correcting the error. Check table and column names for typos or grammatical errors, and ensure that the names used match the column names in the database. For example, instead of using “Department_Code,” you might have used “Departmet_Code” or “Deparment_Code.”

2. Using Quoted Identifiers

The ORA-00904 error can also occur when using quoted identifiers, as such identifiers are case-sensitive and must be entered exactly as they are in the database. In the example below, we’ll use the ALTER session command to set the identifier_quote_character to double quotes, as follows:

ALTER SESSION SET "_ORACLE_SCRIPT"=true; -- For security purposes
ALTER SESSION SET identifier_quote_character='"';

SELECT Employee."EMPLID" as EmpID, 
        Employee."FIRST_NAME" AS Name,
        Team."DEPARTMENT_CODE" AS TeamID, 
        Team."DEPARTMENT_NAME" AS teamname
FROM PS_TBL_EMPLOYEE_DETAILS Employee
INNER JOIN PS_TBL_DEPARTMENT_DETAILS Team ON Team."DEPARTMENT_CODE" = Employee."DEPTID"

With this solution, the query should run successfully without the ORA-00904 error.

3. Avoid using Keywords and Special Characters

ORA-00904 error can occur when you use reserved keywords or special characters in the SQL query. In this case, you will need to wrap the column name with either double or single quotes (depending on the oracle configuration). Here’s an example of how to modify the SQL query to fix an ORA-00904 error caused by a reserved keyword. In this example, we will use “DATE” as a column name, which is a reserved keyword in SQL:

SELECT Employee."EMPLID" as EmpID, 
        Employee."FIRST_NAME" AS Name,
        Employee."HIRE_DATE" AS "Date",
        Team."DEPARTMENT_CODE" AS TeamID, 
        Team."DEPARTMENT_NAME" AS teamname
FROM PS_TBL_EMPLOYEE_DETAILS Employee
INNER JOIN PS_TBL_DEPARTMENT_DETAILS Team ON Team."DEPARTMENT_CODE" = Employee."DEPTID"

Here, we fixed the “DATE” column name by wrapping it in double quotes.

Practical Examples

Let’s consider a few practical examples to solve the ORA-00904 error:

Example 1 - Using Upper case identifiers

SELECT * FROM "PERSONS" WHERE "COUNTRY" = 'INDIA';

With the above query, the ORA-00904 error would occur, stating that “COUNTRY” is an invalid identifier. After analyzing the error, we realized that the column’s actual name is “Country,” and we used it instead of “COUNTRY.” Hence, updating the query by using the column name in uppercase solved the error.

SELECT * FROM "PERSONS" WHERE "COUNTRY" = 'INDIA';
