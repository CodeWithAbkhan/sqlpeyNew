ORACLE: Discover PL/SQL Procedure Name In Oracle, can a PL/SQL procedure know its own name?

The answer is yes, it’s possible to know the name of a PL/SQL procedure in Oracle, and there are several ways to achieve that. Here are a few options:

Using $$PLSQL_UNIT and $$PLSQL_LINE:

CREATE OR REPLACE procedure some_procedure is
    v_procedure_name varchar2(32);
begin
    v_procedure_name := $$PLSQL_UNIT;
end;

In this example, $$PLSQL_UNIT will return the name of the current procedure, and the value will be assigned to the variable v_procedure_name.

More, $$PLSQL_LINE can be used to get the line number of the code.

Using owa_util.get_procedure:

CREATE OR REPLACE procedure some_procedure is
    v_procedure_name varchar2(32);
begin
    v_procedure_name := owa_util.get_procedure;
end;

In this case, the function owa_util.get_procedure returns the name of the current procedure, including nested procedures and functions in packages.

Using regular expressions with REGEXP_SUBSTR:

FUNCTION SET_PROC RETURN VARCHAR2 IS
BEGIN
  RETURN NVL(REGEXP_SUBSTR(DBMS_UTILITY.FORMAT_CALL_STACK, 
             'procedure.+\.(.+)\s', 1,1,'i',1), 'UNDEFINED');
END SET_PROC;

This example uses REGEXP_SUBSTR to extract the procedure name from the output of DBMS_UTILITY.FORMAT_CALL_STACK, which provides a stack trace of the current execution context.

There are also other ways to achieve this, such as parsing the output of DBMS_UTILITY.FORMAT_CALL_STACK manually, but the options above are generally more convenient and reliable.

It’s worth noting that knowing the name of the current procedure can be helpful for debugging and error handling, such as providing more information in exception messages or logs.

Overall, there are various methods to get the name of a PL/SQL procedure in Oracle, and the choice will depend on the specific use case and context.]]>
