How to Obtain the Size of a Specific Database Row in Oracle How to Get the Actual Size of a Specific ROW in Oracle
If you are working with Oracle database and want to get the actual size of a specific row or have a list of the size of all rows in a table, you can use the following SQL query:

SELECT vsize(col1) + vsize(col2) + vsize(col3) + 
long_raw_length_function(long_col) + DBMS_LOB.GETLENGTH(blob_col) 
FROM table 
WHERE id_col = id_val;

The vsize function returns the size in bytes of a column, while the long_raw_length_function function returns the length of a LONG RAW column. The DBMS_LOB.GETLENGTH function returns the length of a BLOB column. By adding the sizes of all columns, you can obtain the actual size of a row in bytes.

If you want to get the average row length of a table, you can use the ALL_TABLES.avg_row_len column. To get this value, you first need to analyze the table using the DBMS_STATS package.

Sample Code to Get Table Row Length When You Don’t Have Any Data

This is a modified version of the above query to get the size of all rows in a table even if you don’t have any data. This can also help with capacity planning for environment setup:

SET serveroutput ON linesize 300
DECLARE
  v_max_size       NUMBER := 0;
  v_owner          VARCHAR2(30);
  v_table_name     VARCHAR2(30);
  v_data_type      VARCHAR2(30);
  v_data_length    NUMBER := 0;
  v_data_precision NUMBER := 0;
  
  CURSOR CUR_TABLE
  IS
    SELECT DISTINCT table_name
    FROM all_tab_columns
    WHERE owner="TMS_OWNER"
    AND table_name NOT LIKE 'VIEW%'
    ORDER BY table_name;
    
BEGIN
  FOR Tab IN CUR_TABLE
  LOOP
    v_table_name := Tab.table_name;
    v_max_size   := 0;
    FOR i        IN
    (SELECT owner,
      table_name,
      data_type,
      data_length,
      data_precision
    FROM all_tab_columns
    WHERE owner="TMS_OWNER"
    AND table_name = v_table_name
    )
    LOOP
      IF i.data_type="NUMBER" THEN
        v_max_size  := (v_max_size + i.data_precision);
      ELSE
        v_max_size := (v_max_size + i.data_length);
      END IF;
    END LOOP;
    dbms_output.put_line(chr(10));
    dbms_output.put_line('Table="||v_table_name||", Max Record Size="||v_max_size||" bytes');
  END LOOP;
  
END;
/

This code retrieves all table names from the database schema with owner “TMS_OWNER” and not starting with “VIEW”. It then iterates through all tables, retrieves the data type, data length, and data precision of all columns in the table and calculates the maximum size of a record by adding the sizes of all columns. The result is displayed for each table.

Recap

By using the vsize, long_raw_length_function, and DBMS_LOB.GETLENGTH functions, you can get the actual size of a specific row in Oracle. To get the average row length of a table, you can use the ALL_TABLES.avg_row_len column.
