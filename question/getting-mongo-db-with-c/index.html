How to get the Mongo database specified in connection string in C# How to Get the Mongo Database Specified in Connection String in C#
It is possible to connect to the database specified in the connection string without specifying it again in GetDatabase.

Example Connection String

For example, if you have the following connection string;

mongodb://localhost/mydb

You would like to be able to db.GetCollection("mycollection") from mydb. This allows the database name to be configured easily in the app.config file.

Update

MongoServer.Create is now obsolete. Instead, use the following code:

var _server = new MongoClient(connectionString).GetServer();

Getting the Database Name from the Connection String

It’s easy. You should first take the database name from the connection string and then get the database by name. Here is a complete example:

var connectionString = "mongodb://localhost:27020/mydb";

//take database name from connection string
var _databaseName = MongoUrl.Create(connectionString).DatabaseName;
var _server = MongoServer.Create(connectionString);

//and then get database by database name:
_server.GetDatabase(_databaseName);

Important: If your database and authentication database are different, you can add an authSource= query parameter to specify a different authentication database. (thank you to @chrisdrobison )

From the docs:

NOTE If you are using the database segment as the initial database to use, but the username and password specified are defined in a different database, you can use the authSource option to specify the database in which the credential is defined. For example, mongodb://user:pass@hostname/db1?authSource=userDb would authenticate the credential against the userDb database instead of db1.

Using the Latest Version of the C# Driver

In the latest version of the C# driver (2.3.0) the only way to get the database name specified in the connection string is to use the following code:

var connectionString = @"mongodb://usr:pwd@srv1.acme.net,srv2.acme.net,srv3.acme.net/dbName?replicaSet=rset";
var mongoUrl = new MongoUrl(connectionString);
var dbname = mongoUrl.DatabaseName;
var db = new MongoClient(mongoUrl).GetDatabase(dbname);
db.GetCollection("myCollectionName");

With version 1.7 of the official 10gen driver, this is the current (non-obsolete) API:

const string uri = "mongodb://localhost/mydb";
var client = new MongoClient(uri);
var db = client.GetServer().GetDatabase(new MongoUrl(uri).DatabaseName);
var collection = db.GetCollection("myCollectionName");

Summary

To summarize, it is possible to get the database name specified in the connection string in C# by using the MongoUrl.Create and GetDatabase methods. The exact method may vary depending on which version of the C# driver you are using. ]]>
