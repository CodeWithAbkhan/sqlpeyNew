How to Change Column Data Types in Oracle Changing the data type of a column in Oracle
In Oracle, you can change the data type of a column in an existing table using the ALTER TABLE statement.

Syntax:

ALTER TABLE table_name
MODIFY column_name datatype;

The ALTER TABLE statement allows you to modify the structure of an existing table in Oracle. The MODIFY clause lets you change the data type of a column. You need to specify the column_name whose data type you want to change, followed by the new data type using the datatype keyword.

Let’s say you have a table named PLACE with the following structure:

CREATE TABLE PLACE(
  POSTCODE VARCHAR(10) PRIMARY KEY,
  STREET_NAME VARCHAR(10),
  COUNTY VARCHAR(10),
  CITY VARCHAR(10));

To change the name, county and city columns from varchar(10) to varchar(20), you can use the following SQL statement:

ALTER TABLE PLACE
MODIFY (
  STREET_NAME VARCHAR2(20),
  COUNTY VARCHAR2(20),
  CITY VARCHAR2(20)
 );

Note that we are also changing the data type from VARCHAR to VARCHAR2 to be more conventional. There is no functional difference at present between the two though the behavior of VARCHAR may change in the future to match the SQL standard. If you want to change only the data type of one column, you can use the following syntax:

ALTER TABLE table_name
MODIFY (column_name new_data_type);

For example, if you only want to change the data type of the STREET_NAME column in the PLACE table to VARCHAR2(20), you would use the following syntax:

ALTER TABLE PLACE
MODIFY (STREET_NAME VARCHAR2(20));

Changing data type with data in the table

If your table has data, it’s important to be careful when changing the data type of a column. In order to preserve the data, you need to follow these steps:

  1. Add a temporary column to the table with the new data type.
  2. Copy the data from the old column to the temporary column.
  3. Remove the old column.
  4. Rename the temporary column to the old column name.

Here’s an example of how to change the data type of the COLUMN_NAME column in the TABLE_NAME table from NUMBER to VARCHAR2(20):

--Step 1: Add a temp column COLUMN_NAME_TEMP in table TABLE_NAME to hold data temporarily
ALTER TABLE TABLE_NAME
ADD COLUMN_NAME_TEMP VARCHAR2(20);

--Step 2: Update temp column COLUMN_NAME_TEMP with Old columns COLUMN_NAME data
UPDATE TABLE_NAME
SET COLUMN_NAME_TEMP = TO_CHAR(COLUMN_NAME);

--Step 3: Remove NOT NULL constraint from old column COLUMN_NAME
ALTER TABLE TABLE_NAME
MODIFY COLUMN_NAME NULL;

--Step 4: Remove old column COLUMN_NAME
ALTER TABLE TABLE_NAME
DROP COLUMN COLUMN_NAME;

--Step 5: Rename COLUMN_NAME_TEMP to COLUMN_NAME
ALTER TABLE TABLE_NAME
RENAME COLUMN COLUMN_NAME_TEMP TO COLUMN_NAME;
