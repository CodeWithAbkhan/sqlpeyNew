Finding All Tables Containing a Specified Column Name in MS SQL Server

Do you need to quickly find which tables in your database contain a specific column name? If so, you can do this using a simple query in Microsoft SQL Server.

The following query will return the names of the tables and columns that contain a given column name:

SELECT      c.name  AS 'ColumnName'
            ,t.name AS 'TableName'
FROM        sys.columns c
JOIN        sys.tables  t   ON c.object_id = t.object_id
WHERE       c.name LIKE '%MyName%'
ORDER BY    TableName
            ,ColumnName;

The query above will return the names of the tables and columns that contain a column name that is like the provided string. In this case, the string is %MyName%.

If you need to search for tables and views, you can use the following query:

SELECT      COLUMN_NAME AS 'ColumnName'
            ,TABLE_NAME AS  'TableName'
FROM        INFORMATION_SCHEMA.COLUMNS
WHERE       COLUMN_NAME LIKE '%MyName%'
ORDER BY    TableName
            ,ColumnName;

In SQL Server, you can also use the following syntax to find the tables and columns containing a specified column name:

SELECT Table_Name, Column_Name 
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_CATALOG = 'YOUR_DATABASE'
AND COLUMN_NAME LIKE '%YOUR_COLUMN%'

Oracle

In Oracle, you can use the following query to search for tables and columns containing a specified column name:

SELECT owner, table_name, column_name 
FROM all_tab_columns 
WHERE column_name LIKE '%YOUR_COLUMN_NAME%'
AND OWNER IN ('YOUR_SCHEMA_NAME');

Summary
