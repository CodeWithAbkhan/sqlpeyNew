Problem: How to join by closest timestamp in BigQuery? Let’s say there are two tables, Class and Student, with columns as StartTime, Class and DesiredStartTime, Student respectively. The task is to join the two tables by matching the closest Class.StartTime with Student.DesiredStartTime.

Example:

Class
------------------------------------|---------|
|               StartTime           |   Class |
------------------------------------|---------|
| 07/01/19 08:00                    | English |
| 07/01/19 09:00                    | Chemistry |
| 07/01/19 10:30                    | Math |
------------------------------------|---------|

Student
------------------------------------|---------|
|               DesiredStartTime    |  Student|
------------------------------------|---------|
| 07/01/19 08:45                    | Jimmy |
| 07/01/19 09:15                    | Bobby |
| 07/01/19 10:00                    | Buddy |
------------------------------------|---------|

[Query Results]
-----------------------------------------------------------------
|               StartTime           |    Class      |  Student   |
-----------------------------------------------------------------
| 07/01/19 09:00                    | Chemistry     | Jimmy   |
| 07/01/19 09:00                    | Chemistry     | Bobby   |

Solution:

BigQuery doesn’t have any special features to solve this problem, however, one approach is to use the ABS and ROW_NUMBER functions to find the closest timestamp.

 WITH ClassRanked AS (
    SELECT *,
        ROW_NUMBER() OVER (PARTITION BY '' ORDER BY 
            ABS(EXTRACT(EPOCH FROM CAST(Student.DesiredStartTime AS TIMESTAMP)) - 
            EXTRACT(EPOCH FROM CAST(Class.StartTime AS TIMESTAMP)))) AS Rank
    FROM Class, Student
)
SELECT Class.StartTime, Class.Class, ClassRanked.Student
FROM ClassRanked
WHERE ClassRanked.Rank=1;

The code above first creates a WITH clause called ClassRanked, which creates a Cartesian product between Class and Student tables. With this resulting table, ROW_NUMBER and ABS functions are used to identify the closest timestamp between Class.StartTime and Student.DesiredStartTime, grouped by a empty partition and ordered by the time difference using the Epoch format. Lastly, the resulting table is filtered by the Rank column to extract the closest matching record.

Explanation:

  • ABS function returns the absolute value of the timestamp difference between Class.StartTime and Student.DesiredStartTime.
  • EXTRACT function is used to convert the string timestamp into an Epoch format for subtracting the timestamp differences.
  • CAST function is used to convert the string timestamp into a TIMESTAMP format, which allows the subtraction of timestamps.
  • ROW_NUMBER function is used to give each record a unique rank based on the partition and order provided, in this case, the empty partition is used to give the whole table a unique rank.
  • WHERE condition is used to filter the records to only keep the records with Rank=1, which is equivalent to getting the closest timestamp match.

Alternative Solution:

Another solution to this problem is to use a CROSS JOIN and sub-SELECT to identify the closest matching record.

 SELECT Class.StartTime, Class.Class, 
    (SELECT Student.Student FROM Student 
    ORDER BY ABS(EXTRACT(EPOCH FROM CAST(Student.DesiredStartTime AS TIMESTAMP)) 
    - EXTRACT(EPOCH FROM CAST(Class.StartTime AS TIMESTAMP))) 
    LIMIT 1) AS Student
FROM Class;

The code above first cross-joins Class and Student tables. With this Cartesian product table, a sub-SELECT is used to identify the closest matching student record for each class record. The ABS and EXTRACT functions are used in a similar way to the first solution.

Explanation:

  • CROSS JOIN is used to create a Cartesian product from the two tables.
  • A sub-query is used to select the closest matching Student record for each Class record.
