Summary

We have a collection of stories where each story has one or more tags. We want to query all tags to create a tag cloud. In a relational database, we would use a join operation on the stories and tags table. Although, in a NoSQL database like MongoDB, we can use the aggregation framework to achieve the same result.

Schema Design

Before we dive into querying all subdocuments, let’s discuss schema design for our collection. Based on the requirement, we can create a collection called “stories”. Each document in the “stories” collection will represent a story and will have a “tags” field which will be an array of objects. Each object in the “tags” array will have two fields - “tagname” and “user”.

Querying all Subdocuments

To query all tags in MongoDB using Mongoose, we can use the aggregation framework. The aggregation framework allows us to perform advanced operations on our data, similar to the join operation in a relational database.

Let’s see how we can achieve this using the aggregation framework.

db.stories.aggregate(
[
    {
        "$unwind" : "$tags"
    },
    {
        "$group" : {
            "_id" : "$tags.tagname",
            "total" : {
                "$sum" : 1
            }
        }
    },
    {
        "$sort" : {
            "total" : -1
        }
    }
])

The first operation in the aggregation pipeline is “$unwind”. This operation “deconstructs” the “tags” array field from the input documents to output a document for each element in the array. This means that if a story has three tags, it will output three documents, each with one tag.

The second operation in the pipeline is “$group”. This operation groups the documents by the “tagname” field and applies the “$sum” operator to calculate the total count of each tag.

The third operation is “$sort”, which sorts the output by the total count in descending order.

Lastly, the output is returned in an array, where each element represents a tag and its total count.

Alternative Ways

An alternative way to query all subdocuments is by using the “find” method. We can use the dot notation to reach into the array of objects to search for a specific field. For example, to find all documents that have “fairytale” as the tagname, we can use the following code:

db.stories.find({ "tags.tagname": "fairytale"});

To find all documents that have a “tagname” field, we can use the “$exists” operator as follows:

db.stories.find({ "tags.tagname": { $exists : true }});
