Learning Oracle’s “Partition By” Keyword

Oracle’s “Partition By” keyword is used in SQL queries to divide a result set into partitions, or groups, based on one or more columns. It is most commonly used with the “OVER” clause to perform calculations within each partition.

The “Partition By” Clause

The “Partition By” clause is used in a SQL query to divide the result set into partitions, or groups, based on one or more columns. This allows you to perform calculations, such as sums, averages, and counts, within each partition.

For example:

SELECT deptno, COUNT(*) 
OVER (PARTITION BY deptno) DEPT_COUNT
FROM emp

In the above example, we are selecting the department number (deptno) and the count(*) of employees for each department as a separate column, using the “Partition By” clause.

The “OVER” Clause

The “OVER” clause is used in combination with the “Partition By” clause to perform calculations within each partition.

For example:

SELECT deptno, COUNT(*) 
OVER (PARTITION BY deptno) DEPT_COUNT
FROM emp

In the above example, the “OVER (PARTITION BY deptno)” clause is used to perform the “COUNT(*)” calculation within each department partition.

Practical Examples

Here are some practical examples of how the “Partition By” keyword can be used in SQL queries:

Example 1: Total Sales by Region and Month

We want to calculate the total sales for each region and month in a sales table

SELECT region, month, SUM(sales_amount)
    OVER(PARTITION BY region, month) AS total_sales
FROM sales_table;

The “Partition By” clause is used to group the data by region and month, and the “SUM” function is used to calculate the total sales for each partition.

Example 2: Rank Employees by Department and Salary

We want to rank employees within each department by salary

SELECT emp_name, dept_name, salary, 
    RANK() OVER (PARTITION BY dept_name ORDER BY salary DESC) AS rank
FROM employees 
ORDER BY dept_name, rank;

The “Partition By” clause is used to group employees by department, and the “ORDER BY” clause is used to order the employees within each department by salary. The “RANK” function is used to assign a rank to each employee within their department based on their salary.

Alternative Ways

While “Partition By” is a amazing tool, there are alternative ways to achieve similar results depending on the specific use case.

One alternative is to use a subquery to group the data and perform the calculation, then join it back to the original table. This can be useful if the calculations are more complex than what can be achieved using the “Partition By” clause.

Another alternative is to use a window function without the “Partition By” clause to perform calculations across the entire result set. For example:

SELECT emp_name, salary, 
    AVG(salary) OVER () AS avg_salary
FROM employees;

In the above example, the “AVG” function is used to calculate the average salary across the entire result set, rather than within partitions.

Recap

It is most commonly used with the “OVER” clause to achieve these calculations.
