Querying Google BigQuery in Apache Airflow and Returning Results as a Pandas Dataframe

Problem Description

The problem is to save a BigQuery query to a Pandas dataframe in a custom Apache Airflow operator. The goal is to accomplish this task without hard coding the authentication credentials of the account.

Solution

To save the BigQuery query result to a Pandas dataframe, we can use the BigQueryHook and get_pandas_df method. Although, this method prompts the user to authenticate manually. We can avoid this manual authentication by hard coding the authentication credentials. But this is not an ideal solution due to security concerns. Another solution to this problem is to use the BigQuery client library for Python. Here is the code:

def execute(self, context):
    """
    An Apache Airflow operator to run a query on Google BigQuery and return the results as a Pandas dataframe
    
    :param context: Airflow context variables
    :type context: dict
    """
    
    # Import libraries
    from google.cloud import bigquery
    from google.oauth2 import service_account
    import pandas as pd
    
    # Get the path of the authentication credentials
    credentials_path = '/path/to/credentials.json'
    
    # Create a credentials object using the authentication credentials
    credentials_obj = service_account.Credentials.from_service_account_file(credentials_path)
    
    # Create a client object using the credentials object
    client = bigquery.Client(credentials=credentials_obj)
    
    # Construct the BigQuery query job
    job_config = bigquery.QueryJobConfig()
    job_config.use_legacy_sql = True
    
    # Run the BigQuery query and get the results as a Pandas dataframe
    df = client.query(self.query, job_config=job_config).to_dataframe()

The code imports the required libraries and gets the path of the authentication credentials. The credentials object is created using the authentication credentials file. Then, the client object is created using the credentials object. In the next step, the BigQuery query job is constructed, and the query job configuration is set. Lastly, the BigQuery query is run, and the result is obtained as a Pandas dataframe.

Practical Examples

The code can be customized according to the specific requirements of the project. For example, we can set the location of the BigQuery dataset by passing the ’location’ parameter to the BigQuery client constructor. Also, we can set the project ID by passing the ‘project’ parameter to the BigQuery client constructor. Here is the modified code:

def execute(self, context):
    """
    An Apache Airflow operator to run a query on Google BigQuery and return the results as a Pandas dataframe
    
    :param context: Airflow context variables
    :type context: dict
    """
    
    # Import libraries
    from google.cloud import bigquery
    from google.oauth2 import service_account
    import pandas as pd
    
    # Get the path of the authentication credentials
    credentials_path = '/path/to/credentials.json'
    
    # Create a credentials object using the authentication credentials
    credentials_obj = service_account.Credentials.from_service_account_file(credentials_path)
    
    # Set the location of the BigQuery dataset
    location = 'US'
    
    # Set the project ID
    project_id = 'my-project-id'
    
    # Create a client object using the credentials object, location, and project ID
    client = bigquery.Client(credentials=credentials_obj, location=location, project=project_id)
    
    # Construct the BigQuery query job
    job_config = bigquery.QueryJobConfig()
    job_config.use_legacy_sql = True
    
    # Run the BigQuery query and get the results as a Pandas dataframe
    df = client.query(self.query, job_config=job_config).to_dataframe()
