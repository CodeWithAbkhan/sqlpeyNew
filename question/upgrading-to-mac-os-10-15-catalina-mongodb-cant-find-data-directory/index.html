Are you having trouble running mongod in the terminal after upgrading to Mac OS 10.15 (Catalina)? Read on to learn more about this issue and how to resolve it.

The error states that the data directory /data/db could not be found. If you try to install MongoDB with brew, you will get an error stating Error: mongodb: unknown version :mountain_lion.

What is the cause of this issue?

The cause of this issue is that Catalina does not allow changes to the root directory. If you try to create a new directory in the root directory, you will get an error saying mkdir: /data/db: Read-only file system.

How to resolve the issue?

The best way to resolve this issue is to create a new directory in your home directory and then use that directory as the data directory for MongoDB. To do this, you can use the following command:

mkdir ~/data
mongod --dbpath ~/data

This will create a new directory in your home directory and then use it as the data directory for MongoDB. You can then start the MongoDB server using the mongod command.

You can also use the --dbpath option to specify a custom data directory for MongoDB. For example, if you want to use the /var/db directory, you can use the following command:

mongod --dbpath /var/db

This will start the MongoDB server using the /var/db directory as the data directory. Make sure that the directory has the correct permissions so that MongoDB can access it.
