Detailed BigQuery Error Message in Python
When working with BigQuery in Python, errors can occur during various operations such as uploading a file to a table. In order to efficiently debug these errors, it is crucial to have access to detailed error messages. The following steps will show you how to retrieve a detailed error message in Python when an error occurs during a BigQuery operation.

Step 1: Import Required Libraries

In order to retrieve the detailed error message, you will need to import the following libraries:

import google.auth
from google.cloud import bigquery
from google.cloud.bigquery import LoadJobConfig, SourceFormat

The google.auth library is used to authenticate with the Google Cloud Platform. The bigquery library provides the necessary methods for interacting with BigQuery datasets and tables. The LoadJobConfig and SourceFormat classes are used to configure the loading of data into a table.

Step 2: Load Data into Table

In this step, you will define a function that loads data from a file into a BigQuery table:

def load_data_to_table(file_path, table_id):
    credentials, project = google.auth.default()

    client = bigquery.Client(credentials=credentials, project=project)
    dataset_ref = client.dataset(dataset_id)
    table_ref = dataset_ref.table(table_id)

    job_config = LoadJobConfig()
    job_config.source_format = SourceFormat.CSV
    job_config.skip_leading_rows = 1

    with open(file_path, "rb") as source_file:
        job = client.load_table_from_file(source_file, table_ref, job_config=job_config)

    result = job.result()

    if job.errors:
        for error in job.errors:
            print(f"Error: {error['message']}")

This function takes in the file path and table ID as its parameters. It then uses these parameters along with the BigQuery API to load the data from the file into the specified table. If an error occurs during the job, the function prints out the error message using the job errors property.

Step 3: Call the Function

Lastly, you can call the function and pass in the file path and table ID:

if __name__ == "__main__":
    file_path = "data.csv"
    table_id = "my_table"
    load_data_to_table(file_path, table_id)

When the function is called, it loads the data from the file into the specified table. If an error occurs during the job, the function prints out the error message. This method provides detailed error messages that can be used to debug any issues that occur.

Alternative Method

Another way to obtain a detailed error message during a BigQuery operation is to catch the exception raised during the operation, and then access the errors attribute. Here is an example:

def upload(FILE_NAME, TABLE_ID):
    client = bigquery.Client()
    dataset_ref = client.dataset(config.DATASET_ID)
    table_ref = dataset_ref.table(TABLE_ID)
    job_config = bigquery.LoadJobConfig()
    job_config.source_format = bigquery.SourceFormat.NEWLINE_DELIMITED_JSON
    job_config.autodetect = False

    with open(FILE_NAME, "rb") as source_file:
        job = client.load_table_from_file(
            source_file,
            table_ref,
            location="EU",
            job_config=job_config,
        )

    try:
        job.result()  # Waits for table load to complete.
    except Exception as e:
        for error in job.errors:
            print(f"Error: {error['reason']} - {error['message']}")

In this method, an exception is caught when the job result is returned. The error messages for the job are then accessed through the errors attribute of the job object.
