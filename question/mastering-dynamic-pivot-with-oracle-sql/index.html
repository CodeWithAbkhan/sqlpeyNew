Mastering Dynamic Pivot with Oracle SQL In this blog post, we will discuss how to create a dynamic pivot in Oracle’s SQL. This is useful when the values to pivot on are not fixed and can change over time. We will go through an example of how to set up the pivot and explain each step along the way.

To begin, let’s first create a sample table that we will be working with:

CREATE TABLE myTable (
    myNumber NUMBER,
    myValue NUMBER,
    myLetter VARCHAR2(1)
);

INSERT INTO myTable VALUES (1, 2, 'A');
INSERT INTO myTable VALUES (1, 4, 'B');
INSERT INTO myTable VALUES (2, 6, 'C');
INSERT INTO myTable VALUES (2, 8, 'A');
INSERT INTO myTable VALUES (2, 10, 'B');
INSERT INTO myTable VALUES (3, 12, 'C');
INSERT INTO myTable VALUES (3, 14, 'A');

Now, let’s say we want to pivot on the distinct values of the myLetter column. We can begin by using a subquery to select the distinct values:

SELECT DISTINCT myLetter
FROM myTable;

This will give us the distinct values of myLetter: 'A', 'B', and 'C'.

Next, we can use the LISTAGG function to concatenate these values into a string separated by commas. We will also add an alias to each value to use in the PIVOT statement later. To do this, we will use the COLUMN NEW_VALUE command to store the result of the LISTAGG function into a substitution variable called str_in_statement:

CLEAR COLUMNS
COLUMN temp_in_statement NEW_VALUE str_in_statement

SELECT DISTINCT 
    LISTAGG('''' || myLetter || ''' AS ' || myLetter, ',')
        WITHIN GROUP (ORDER BY myLetter) AS temp_in_statement 
FROM myTable;

-- Output: 'A' AS A,'B' AS B,'C' AS C

Notice that we are wrapping each myLetter value in single quotes (''') and using AS to give each value an alias that matches the original value.

We can then use this string in our PIVOT statement by using the &str_in_statement substitution variable:

SELECT *
FROM (
    SELECT myNumber, myLetter, myValue
    FROM myTable
)
PIVOT (
    SUM(myValue) AS val
    FOR myLetter IN (&str_in_statement)
);

This will pivot the myValue column for each distinct myLetter value and display the result in columns with the same name as the myLetter value. The output should look like this:

 MYNUMBER   A_VAL   B_VAL   C_VAL
---------- ------- ------- -------
         1       2       4        
         2       8      10       6
         3      14             12

And that’s it! With this method, our pivot is able to include new values that are added to the myLetter column without having to modify the query each time.

In summary, to create a dynamic pivot in Oracle’s SQL, follow these steps:

  1. Use a subquery to select the distinct values of the column you want to pivot on.
  2. Use LISTAGG to concatenate these values into a string with aliases.
  3. Use a substitution variable to store the string from step 2.
  4. Use the substitution variable in your PIVOT statement.

While this method works well for simple cases, it may not be the best option for more complex pivots. In those cases, you may want to consider using dynamic SQL or pivot XML instead.

Alternative Ways:

Instead of using a string of aliases, you could also use a CURSOR to loop through the distinct values and manually create the PIVOT statement. This method may be preferable for more complex pivots but can become lengthy and difficult to maintain.

Practical Examples:

For example, let’s say we have a table of sales data with columns product, region, year, and sales. We want to pivot the data by product and year, but we don’t know all the values of product. We can use a dynamic pivot to include all product values without modifying the query each time a new product is added:

-- Select distinct product values
SELECT DISTINCT product
FROM sales;

-- Use LISTAGG to create a string of aliases
CLEAR COLUMNS
COLUMN temp_in_statement NEW_VALUE str_in_statement

SELECT DISTINCT 
    LISTAGG('''' || product || ''' AS ' || product, ',')
        WITHIN GROUP (ORDER BY product) AS temp_in_statement 
FROM sales;

-- Use the string in the PIVOT statement
SELECT *
FROM (
    SELECT product, year, sales
    FROM sales
)
PIVOT (
    SUM(sales) AS sales
    FOR product IN (&str_in_statement)
);

Alternative Method:

-- Use a cursor to loop through distinct product values
DECLARE
    str_pivot_query VARCHAR2(32767);
    v_product sales.product%TYPE;
    CURSOR c_products IS SELECT DISTINCT product FROM sales;
BEGIN
  str_pivot_query := 'SELECT * FROM (SELECT product, year, sales FROM sales) PIVOT (SUM(sales) AS sales FOR year IN (';
  
  -- Loop through each distinct product value and add to pivot statement
  FOR p IN c_products LOOP
    v_product := p.product;
    IF str_pivot_query NOT LIKE '%"' || v_product || '"%' THEN
      str_pivot_query := str_pivot_query || '"' || v_product || '",';
    END IF;
  END LOOP;
  
  -- Remove trailing comma and complete pivot statement
  str_pivot_query := RTRIM(str_pivot_query, ',') || ')';
  
  -- Execute the pivot statement
  EXECUTE IMMEDIATE str_pivot_query;
END;
