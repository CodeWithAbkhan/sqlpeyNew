If you are working with Django, there may come a time when you need to see the actual SQL query being executed by your application. This can help you debug issues with your code and ensure that your database is functioning properly. In this Q&A Session, we will show you how to see SQL query during Django tests.

Using CaptureQueriesContext One way to see SQL queries when running tests is to use the CaptureQueriesContext method in the Django test suite. This method captures all SQL queries made within a certain block of code and saves them to a list. Here’s how to use it: from django.db import connection from django.test.utils import CaptureQueriesContext def test_foo(): with CaptureQueriesContext(connection) as ctx: # code that runs SQL queries print(ctx.captured_queries) This method will capture all SQL queries made within the with block and print them to the console. You can then use this information to debug any issues with your code.
