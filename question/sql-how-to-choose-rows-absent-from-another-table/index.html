SQL: How to Choose Rows Absent from Another Table In this Q&A Session, we will discuss how to select rows that are not present in another table using SQL queries in PostgreSQL. We will explore various methods to achieve this, including the use of NOT EXISTS, LEFT JOIN / IS NULL, and EXCEPT. More, we will examine each method code line-by-line and provide practical examples.

Let’s begin by knowing the problem statement. Suppose we have two tables named login_log and ip_location in PostgreSQL. The login_log table contains columns like IP address, login time, and other details. The ip_location table contains IP addresses, location, hostname, and other details. We want to select every IP address from the login_log table that does not have a corresponding row in the ip_location table.

Method 1: Using NOT EXISTS

The NOT EXISTS function is often the fastest method to achieve this task in PostgreSQL. We will use two subqueries to implement this method.

SELECT ip 
FROM login_log l 
WHERE NOT EXISTS (
   SELECT *
   FROM ip_location
   WHERE ip = l.ip
);

Let’s know the steps involved in the above query:

  1. We select IP addresses from the login_log table using the SELECT statement.
  2. We use the WHERE clause and the NOT EXISTS function to filter out those IP addresses that have a match in the ip_location table.
  3. We use a subquery to select all rows from the ip_location table where the IP address is equal to the IP address from the login_log table.
  4. If no matching rows are found, the NOT EXISTS function returns a true value, and the IP address is selected.

Method 2: Using LEFT JOIN / IS NULL

The LEFT JOIN / IS NULL method is an alternative to the NOT EXISTS method and often the shortest method to achieve this task. We will use the LEFT JOIN clause to combine the login_log and ip_location tables and filter out rows where the IP address is NULL.

SELECT l.ip 
FROM login_log l 
LEFT JOIN ip_location i USING (ip) 
WHERE i.ip IS NULL;

Let’s know the steps involved in the above query:

  1. We select IP addresses from the login_log table using the SELECT statement.
  2. We use the LEFT JOIN clause and the USING keyword to combine the login_log and ip_location tables on the common column ip.
  3. We use the WHERE clause to filter out the rows where the IP address is NULL in the ip_location table.
  4. If no matching rows are found in the ip_location table, the ip column from the left table (login_log) will contain NULL values.

Method 3: Using EXCEPT

The EXCEPT method is a short and concise method to select rows that are not present in another table. We will use the EXCEPT operator to select IP addresses from the login_log table, excluding those that have a match in the ip_location table.

SELECT ip
FROM login_log
EXCEPT ALL 
SELECT ip
FROM ip_location;

Let’s know the steps involved in the above query:

  1. We select IP addresses from the login_log table using the SELECT statement.
  2. We use the EXCEPT operator to exclude IP addresses that are present in the ip_location table.
  3. If there are any duplicate IP addresses in the result, they will be removed by using the ALL keyword.

Suppose we have the following tables:

login_log

Using the NOT EXISTS method, the output would be:

ip
192.168.0.2
192.168.0.3

Using the LEFT JOIN / IS NULL method, the output would be:

ip
192.168.0.2

Using the EXCEPT method, the output would be:

ip
192.168.0.2
192.168.0.3
