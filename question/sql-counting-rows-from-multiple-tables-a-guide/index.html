SQL: Counting Rows from Multiple Tables: A Guide

How to Select Count(*) from Multiple Tables

When working with SQL databases, you may need to retrieve the count of rows in multiple tables. One common method is to use subqueries to select the count from each table and display the results side by side. This post will explain how to select count(*) from two different tables and display them in a single query.

The SQL Query

The SQL query to select count(*) from two different tables is:

SELECT
  (SELECT COUNT(*) FROM table1) AS count1,
  (SELECT COUNT(*) FROM table2) AS count2
FROM
  dual;

The SELECT COUNT(*) statements are subqueries that return the count of rows in each table. The AS count1 and AS count2 aliases are used to label the output columns. The FROM dual clause is needed in some database systems (like Oracle) to generate a row for the query to return results.

Explanation of the Code

The code is divided into two parts: the subqueries to count the rows and the FROM dual clause to generate a dummy row for the query to return results.

The subqueries use the COUNT(*) aggregation function to count the number of rows in the specified table. The SELECT COUNT(*) FROM table1 query returns the count of rows in table1 and the SELECT COUNT(*) FROM table2 query returns the count of rows in table2.

The AS count1 and AS count2 aliases are used to label the output columns. These aliases are optional, but they make the output more readable by providing a descriptive name for each count.

The FROM dual clause is necessary in some database systems (like Oracle) to generate a dummy row for the query to return results. In other systems (like SQL Server), this clause is not needed.

Alternative Methods

There are several alternative methods to select count(*) from multiple tables:

  • Use a UNION to combine the counts from each table into a single result set
  • Use a WITH clause to define subqueries that return the counts
  • Use a SELECT statement that concatenates multiple SELECT statements with the UNION operator to get the counts of different tables.

These methods are useful when you need to get information from more than two tables, or when you want to display the counts differently.

Example Query

Suppose you have two tables named employees and departments, and you need to get the counts of the rows in each table. Here’s an example query:

SELECT
  (SELECT COUNT(*) FROM employees) AS emp_count,
  (SELECT COUNT(*) FROM departments) AS dept_count
FROM
  dual;

This query returns the counts of rows in the employees and departments tables:

EMP_COUNT | DEPT_COUNT
----------|-----------
  100     |    5
