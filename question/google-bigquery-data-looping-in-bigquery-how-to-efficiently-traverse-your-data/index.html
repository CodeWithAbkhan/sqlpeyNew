Looping over data in BigQuery
Looping over data in BigQuery can be a bit tricky but not impossible. In this post, we will explore how to loop over data in BigQuery with the help of the standard SQL functionality. We will be using a table of events as an example to demonstrate the concept.

The Sample Data

Assuming we have a table named events with two columns: id and dt. Each row represents an event where the id column is the user id and dt column is the date the event occurred. The table looks like this:

id    | dt
------+-----------
user1 | 2022-01-01
user2 | 2022-01-01
user1 | 2022-01-02
user3 | 2022-01-02
user1 | 2022-01-03
user3 | 2022-01-03
user4 | 2022-01-03
user2 | 2022-01-04
user1 | 2022-01-05
user2 | 2022-01-05
user3 | 2022-01-06
user2 | 2022-01-07
user3 | 2022-01-08

The Problem

The problem we want to solve is how to count the number of distinct users who generated events for a given period of time. We can accomplish this by using the COUNT and DISTINCT operators in SQL. For example, if we want to count the number of distinct users who generated events in the last four months, we can use this SQL query:

SELECT COUNT(DISTINCT id) AS total
FROM events
WHERE dt BETWEEN DATE_ADD(CURRENT_DATE(), INTERVAL -4 MONTH) AND CURRENT_DATE();

The Solution

Now, let’s say we want to count the number of distinct users who generated events for the same four-month period but for each day between yesterday and three months ago. In other words, we want to repeat the previous SQL query for each day between two dates.

One way to achieve this is to use a SQL subquery. We can create a subquery that generates a list of dates between the two given dates, and then we can use a CROSS JOIN to join the subquery with the events table. Then we can group by the date and count the distinct users. The SQL query looks like this:

SELECT
  subquery.date,
  COUNT(DISTINCT events.id) AS total_users
FROM (
  SELECT
    GENERATE_DATE_ARRAY(
      DATE_SUB(CURRENT_DATE(), INTERVAL 3 MONTH),
      CURRENT_DATE(),
      INTERVAL 1 DAY
    ) AS date
) subquery
CROSS JOIN events
WHERE events.dt BETWEEN DATE_SUB(subquery.date, INTERVAL 4 MONTH) AND subquery.date
GROUP BY subquery.date
ORDER BY subquery.date DESC;

The above SQL query does the following:

  1. The subquery generates a list of dates between three months ago and today using the GENERATE_DATE_ARRAY function. This function returns an array of dates as a single column with the name date.
  2. The CROSS JOIN joins the subquery with the events table by matching all rows with the date between the given four-month period.
  3. The WHERE clause filters out events that occurred outside the four-month period for each date.
  4. The COUNT and DISTINCT operators count the number of distinct users for each date, and we group the result by the date.
  5. Lastly, we sort the result in descending order by date.
