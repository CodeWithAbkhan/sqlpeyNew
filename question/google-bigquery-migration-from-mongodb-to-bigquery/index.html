Exporting MongoDB Data to Google BigQuery
If you are planning to move data from MongoDB hosted in mlab to Google BigQuery, the best way to do it is by building a custom exporter script. Although it might be time-consuming, building a custom exporter will give you more control over the data extraction process. Although, if you have a small amount of data that can fit into one server, you can use the mongoexport command-line tool to export your data as CSV or JSON and import it into BigQuery.

Exporting Data Using mongoexport

If you choose to use mongoexport, here’s how to export data from MongoDB to BigQuery:

  • Assuming you have a simple document structure as shown below:

    { “_id” : “tdfMXH0En5of2rZXSQ2wpzVhZ”, “statuses” : [ { “status” : “dc9e5511-466c-4146-888a-574918cc2534”, “score” : 53.24388894 } ], “stored_at” : ISODate(“2017-04-12T07:04:23.545Z”) }

  • You need first to define your BigQuery schema. You can define your schema in a separate file, say mongodb_schema.json.

    $ cat > mongodb_schema.json «EOF [ { “name”:"_id", “type”: “STRING” }, { “name”:“stored_at”, “type”: “record”, “fields”: [ { “name”:“date”, “type”: “STRING” } ]}, { “name”:“statuses”, “type”: “record”, “mode”: “repeated”, “fields”: [ { “name”:“status”, “type”: “STRING” }, { “name”:“score”, “type”: “FLOAT” } ]} ] EOF

  • The mongoexport command-line tool can be used to export data from MongoDB. The command below exports data to a CSV file format:

    mongoexport –host –db –collection –fields _id,stored_at.date,statuses.status,statuses.score –type=csv –out .csv

The command exports data from the specified hostname, database_name, and collection_name to a CSV file named file_name.csv. The fields to extract are specified using the --fields flag.

  • You can also export your data directly to JSON using the command shown below:

    mongoexport –host –db –collection –fields _id,stored_at.date,statuses.status,statuses.score –type=json –out .json

Importing Data into BigQuery

Once you have exported your data to a CSV or JSON file, you can import it into BigQuery using the Google Cloud Console or the command-line tool, bq. Assuming you have exported your data to a CSV format, here’s how to import it into BigQuery:

  • Create a new BigQuery dataset:

    bq mk

  • Create a new BigQuery table with the same schema as the CSV file:

    bq mk –table .
