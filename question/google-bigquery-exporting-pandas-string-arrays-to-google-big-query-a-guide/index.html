Summary:

I have a Pandas Dataframe with a column containing an array of string values that I want to write to Google Big Query as a nested table structure. I am using the google-cloud-bigquery library to convert the dataframe to the Parquet format, which supports nested array values.

I am encountering a BadRequest error message while trying to write the data to Big Query, and I need help resolving this issue.

Code Explanation:

First, I import the bigquery module from the google.cloud library and create a Client object to interact with Big Query:

from google.cloud import bigquery
client = bigquery.Client()

Next, I specify the ID of the Big Query table I want to write the data to:

table_id = 'dataset.table'

I create a LoadJobConfig object and set the schema of the table I want to write the data to. The schema consists of two fields: route_id (an integer) and types (an array of strings). I also specify the write disposition, which determines how to handle existing data in the table (in this case, append new rows to the existing data).

job_config = bigquery.LoadJobConfig(
    schema = [
            bigquery.SchemaField('route_id', 'INTEGER'),
            bigquery.SchemaField('types', 'STRING', mode="REPEATED")
    ], 
    writeDisposition="WRITE_APPEND"
)

Lastly, I use the load_table_from_dataframe() method to load the Pandas Dataframe into Big Query. I pass the dataframe, table ID, and the LoadJobConfig object to this method. I then wait for the load job to complete by calling the result() method on the job object.

job = client.load_table_from_dataframe(
    df, 
    table_id, 
    job_config=job_config,
)

job.result()

Issue:

The load_table_from_dataframe() method is failing with a BadRequest error message:

BadRequest: 400 Error while reading data, error message: Provided schema is not compatible w

This error message indicates that there is a problem with the schema definition I am using for the Big Query table.

Solution:

The schema definition needs to be updated to match the nested structure of the data in the types column of the Pandas Dataframe. The types column contains an array of strings, so the corresponding field in the Big Query schema needs to be of type RECORD with a nested field of type STRING.

job_config = bigquery.LoadJobConfig(
    schema = [
            bigquery.SchemaField('route_id', 'INTEGER'),
            bigquery.SchemaField('types', 'RECORD', mode="REPEATED", 
              fields=[
                  bigquery.SchemaField('type', 'STRING')
              ])
    ], 
    writeDisposition="WRITE_APPEND"
)

With this updated schema, the load_table_from_dataframe() method should be able to handle the nested array structure of the data in the types column and successfully load the Pandas Dataframe into Big Query.

Alternative Solution:

Another way to write a Pandas Dataframe to Big Query is to use the to_gbq() method from the pandas library. This method directly writes the dataframe to Big Query without needing to use the google-cloud-bigquery library and convert the dataframe to the Parquet format.

import pandas as pd

# write dataframe to Big Query
pd.DataFrame.to_gbq(df, destination_table=table_id, project_id=project_id, if_exists='append')

The to_gbq() method takes the dataframe, destination table ID, project ID, and an if_exists parameter that determines how to handle existing data in the table (in this case, append new rows to the existing data).
