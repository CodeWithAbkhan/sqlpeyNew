How to join multiple collections with $lookup in mongodb Joining Multiple MongoDB Collections with $lookup
Do you want to join more than two collections together in MongoDB? It is possible to join multiple collections through the use of the MongoDB Aggregate $lookup. In this article I will show you how to join multiple collections in MongoDB using $lookup and provide examples of how to do it.

Example Collections

In this example, I have three collections:

users:

{    
    "_id" : ObjectId("5684f3c454b1fd6926c324fd"),
    "email" : "admin@gmail.com",
    "userId" : "AD",
    "userName" : "admin"
}

userinfo:

{
    "_id" : ObjectId("56d82612b63f1c31cf906003"),
    "userId" : "AD",
    "phone" : "0000000000"
}

userrole:

{
    "_id" : ObjectId("56d82612b63f1c31cf906003"),
    "userId" : "AD",
    "role" : "admin"
}

Using Aggregate to Join Multiple Collections

The join feature is supported by MongoDB 3.2 and later versions. You can join multiple collections by using the aggregate query. The following example code shows how to join multiple collections:

db.users.aggregate([

    // Join with user_info table
    {
        $lookup:{
            from: "userinfo",       // other table name
            localField: "userId",   // name of users table field
            foreignField: "userId", // name of userinfo table field
            as: "user_info"         // alias for userinfo table
        }
    },
    {   $unwind:"$user_info" },     // $unwind used for getting data in object or for one record only

    // Join with user_role table
    {
        $lookup:{
            from: "userrole", 
            localField: "userId", 
            foreignField: "userId",
            as: "user_role"
        }
    },
    {   $unwind:"$user_role" },

    // define some conditions here 
    {
        $match:{
            $and:[{"userName" : "admin"}]
        }
    },

    // define which fields are you want to fetch
    {   
        $project:{
            _id : 1,
            email : 1,
            userName : 1,
            userPhone : "$user_info.phone",
            role : "$user_role.role",
        } 
    }
]);

This will give the following result:

{
    "_id" : ObjectId("5684f3c454b1fd6926c324fd"),
    "email" : "admin@gmail.com",
    "userName" : "admin",
    "userPhone" : "0000000000",
    "role" : "admin"
}

You can also chain multiple $lookup stages if you have more than two collections that you want to join. For example, if you have the collections sivaUserInfo, sivaUserRole, and sivaUserInfo, you can join them with the following code:

db.sivaUserInfo.aggregate([
    {
        $lookup: {
           from: "sivaUserRole",
           localField: "userId",
           foreignField: "userId",
           as: "userRole"
        }
    },
    {
        $unwind: "$userRole"
    },
    {
        $lookup: {
            from: "sivaUserInfo",
            localField: "userId",
            foreignField: "userId",
            as: "userInfo"
        }
    },
    {
        $unwind: "$userInfo"
    },
    {
        $match:{
            $and:[{"userName" : "admin"}]
        }
    },
    {   
        $project:{
            _id : 1,
            email : 1,
            userName : 1,
            userPhone : "$userInfo.phone",
            role : "$userRole.role",
        } 
    }
]);
