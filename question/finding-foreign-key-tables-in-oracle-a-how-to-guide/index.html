Finding Foreign Key Tables in Oracle: A How-To Guide How to Find Foreign Key References to a Table in Oracle

If you want to delete data from a table in Oracle, you need to know which tables have a foreign key reference to this table. You also need to set the foreign keys to null before deleting the data. This can be achieved by using the following SQL query:

SELECT
  FK.OWNER||'.'||FK.TABLE_NAME AS CHILD_TABLE,
  SRC.OWNER||'.'||SRC.TABLE_NAME AS PARENT_TABLE,
  FK.CONSTRAINT_NAME AS FK_CONSTRAINT,
  SRC.CONSTRAINT_NAME AS REFERENCED_CONSTRAINT
FROM ALL_CONSTRAINTS FK
JOIN ALL_CONSTRAINTS SRC ON FK.R_CONSTRAINT_NAME = SRC.CONSTRAINT_NAME
WHERE
  FK.CONSTRAINT_TYPE = 'R'
  AND SRC.OWNER = 'MY_SCHEMA'
  AND SRC.TABLE_NAME = 'MY_TABLE';

Let’s go through this query line by line to know what it’s doing:

  • SELECT: This clause selects the columns we want to retrieve: OWNER and TABLE_NAME of the tables with foreign keys, the foreign key constraint name FK_CONSTRAINT, and the referenced constraint name REFERENCED_CONSTRAINT.
  • FROM: This clause specifies the tables we want to retrieve the data from: ALL_CONSTRAINTS table twice, where one is to obtain the foreign key constraints (FK), and the other to obtain the referenced constraints.
  • JOIN: This clause performs a join operation between FK and SRC tables using R_CONSTRAINT_NAME in FK and CONSTRAINT_NAME in SRC, which creates a mapping between the foreign key and referenced constraints.
  • WHERE: This clause filters the rows based on the given conditions: CONSTRAINT_TYPE is “R” (meaning that it is a foreign key constraint), the OWNER of the referenced constraint is “MY_SCHEMA” (replace it with your schema name), and the TABLE_NAME of the referenced constraint is “MY_TABLE” (replace it with the table name you want to check).

If the table you are interested in does not belong to your schema and you want to use ALL_CONSTRAINTS instead of USER_CONSTRAINTS, you can use the following modified query:

SELECT 
  FK.owner ||'.'||FK.table_name AS CHILD_TABLE, 
  SRC.owner ||'.'||SRC.TABLE_NAME AS PARENT_TABLE,
  FK.CONSTRAINT_NAME AS FK_CONSTRAINT,
  SRC.CONSTRAINT_NAME AS REFERENCED_CONSTRAINT
FROM ALL_CONSTRAINTS FK
JOIN ALL_CONSTRAINTS SRC ON FK.R_CONSTRAINT_NAME = SRC.CONSTRAINT_NAME
WHERE
  FK.CONSTRAINT_TYPE = 'R'
  AND SRC.TABLE_NAME = 'MY_TABLE';

Alternatively, you can use the following query to get foreign key constraints on a specific table:

SELECT d.table_name,
       d.constraint_name "Primary Constraint Name",
       b.constraint_name "Referenced Constraint Name"
FROM user_constraints d,
     (SELECT c.constraint_name,
             c.r_constraint_name,
             c.table_name
      FROM user_constraints c 
      WHERE table_name="TABLE_NAME" --replace with your table name
      AND constraint_type="R") b
WHERE d.constraint_name=b.r_constraint_name;

This query joins user_constraints table with itself on the column r_constraint_name and constraint_name to get the referenced constraint name and foreign key constraint name, respectively. It then filters the rows by the table name and constraint type, as mentioned above.

In recap, there are different ways to find tables having a foreign key reference to a table in Oracle. Using ALL_CONSTRAINTS table and joining it with itself is one of the most versatile options that can be adjusted based on your requirements.]]>
