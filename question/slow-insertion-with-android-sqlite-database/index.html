Android SQLite database: slow insertion How to Optimize SQLite Database Insertion Performance on Android
Parsing a fairly large XML file (varying between about a hundred kilobytes and several hundred kilobytes) and inserting the data into an SQLite database can take a significant amount of time. During testing with a 152KB file, this process took about 80 seconds. However, when the insert statements were commented out, the same file took only 23 seconds.

Is it normal for the database operations to have such a big overhead? Can I do anything about that?

Batch Inserts

The best way to optimize SQLite database insertion performance on Android is to use batch inserts. Batch inserts are a method of inserting multiple rows of data into the database with a single statement, instead of a separate statement for each row.

Using the batch inserts method, the overhead of the database operations can be greatly reduced. Here is the pseudocode for this method:

db.beginTransaction();
for (entry : listOfEntries) {
    db.insert(entry);
}
db.setTransactionSuccessful();
db.endTransaction();

Using this method can significantly increase the speed of inserts in apps. During testing with a 152KB file, the same process that previously took 80 seconds was reduced to 270 ms.

Using SQLiteStatement

The method described above uses the database insert method, similar to this statement:

database.insert(table, null, values);

Google recommends using SQLiteStatement instead. Here is the code for using SQLiteStatement:

private void insertTestData() {
    String sql = "insert into producttable (name, description, price, stock_available) values (?, ?, ?, ?);";

    dbHandler.getWritableDatabase();
    database.beginTransaction();
    SQLiteStatement stmt = database.compileStatement(sql);

    for (int i = 0; i < NUMBER_OF_ROWS; i++) {
        //generate some values

        stmt.bindString(1, randomName);
        stmt.bindString(2, randomDescription);
        stmt.bindDouble(3, randomPrice);
        stmt.bindLong(4, randomNumber);

        long entryID = stmt.executeInsert();
        stmt.clearBindings();
    }

    database.setTransactionSuccessful();
    database.endTransaction();

    dbHandler.close()

Using this method will increase the speed of inserts in apps. During testing with a 500 row file, the same process that previously took 14.5 sec was reduced to only 270 ms.

Conclusion

The best way to optimize SQLite database insertion performance on Android is to use batch inserts. This method involves using a single statement to insert multiple rows of data into the database, instead of a separate statement for each row.
