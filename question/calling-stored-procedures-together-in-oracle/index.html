Calling Stored Procedures Together in Oracle How to Call a Stored Procedure with Another in Oracle

In Oracle, calling a stored procedure from another procedure is possible. There are three ways to invoke a stored procedure - using the CALL statement, an anonymous PL/SQL block, or the EXEC statement.

Letâ€™s look at an example where we will create two stored procedures and call one from another.

SET SERVEROUTPUT ON;

DROP PROCEDURE test_sp_1;
DROP PROCEDURE test_sp;

CREATE PROCEDURE test_sp
AS
BEGIN
    DBMS_OUTPUT.PUT_LINE('Test works');
END;
/

CREATE PROCEDURE test_sp_1
AS
BEGIN
    DBMS_OUTPUT.PUT_LINE('Testing');
    test_sp;
END;
/

In the above code, we have created two stored procedures - test_sp and test_sp_1. The test_sp procedure will print “Test works” on the console, and the test_sp_1 procedure will print “Testing” on the console and will call the test_sp procedure.

To invoke test_sp_1 from SQL*Plus, we can use the following syntax:

CALL test_sp_1();

This will invoke the test_sp_1 procedure, which will print “Testing” and then invoke the test_sp procedure, which will print “Test works”.

Alternatively, we can use an anonymous PL/SQL block to call the test_sp_1 procedure:

BEGIN
    test_sp_1;
END;
/

This will have the same effect as the CALL statement.

Lastly, we can use the EXEC statement, which is a shortcut for the anonymous PL/SQL block:

EXEC test_sp_1;

This will invoke the test_sp_1 procedure and print “Testing” and “Test works” on the console.

In summary, calling a stored procedure from another is possible in Oracle. We can use the CALL statement, an anonymous PL/SQL block, or the EXEC statement to accomplish this.

Note: It’s essential to use parentheses to execute the stored procedure, even if no arguments are passed.

Practical Example:

Let’s say we have an employee table that needs to be updated with a new hire’s details. We can create a stored procedure to insert the record and call it from another stored procedure that will handle the validation and other business rules.

CREATE OR REPLACE PROCEDURE add_employee(
    pId IN NUMBER,
    pName IN VARCHAR2,
    pSalary IN NUMBER
)
AS
BEGIN
    INSERT INTO employee(id, name, salary)
    VALUES(pId, pName, pSalary);
    COMMIT;
END;
/

CREATE OR REPLACE PROCEDURE validate_and_add_employee(
    pId IN NUMBER,
    pName IN VARCHAR2,
    pSalary IN NUMBER
)
AS
BEGIN
    IF (pId IS NULL OR pName IS NULL OR pSalary IS NULL) THEN
        DBMS_OUTPUT.PUT_LINE('All fields are required');
    ELSE
        add_employee(pId, pName, pSalary);
        DBMS_OUTPUT.PUT_LINE('Employee added successfully');
    END IF;
END;
/

In this example, we have created two stored procedures - add_employee and validate_and_add_employee. The add_employee procedure will insert a new record in the employee table with the given details, and the validate_and_add_employee procedure will validate the input parameters and call the add_employee procedure.

Alternative Ways:

Apart from the CALL statement, an anonymous PL/SQL block, and the EXEC statement, we can also use the DBMS_SQL package to call a stored procedure from another. Although, this is a more complex method and is generally not recommended unless there is a compelling reason to use it.
