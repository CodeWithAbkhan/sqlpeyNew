Finding the Mode in BigQuery When working with a large dataset, it’s common to need to find the value that appears most often in a given set. This value is known as the mode and can be easily calculated in BigQuery using the MODE function. In this post, we will walk through an example of how to find the mode of a set of values in BigQuery.

Example Dataset

Let’s start with a simple dataset of prices for different product groups, where we want to find the mode of prices for each group.

WITH prices AS (
  SELECT 18 AS length, 'HIGH' AS amps, 99.95 AS price UNION ALL
  SELECT 18, 'HIGH', 99.95 UNION ALL
  SELECT 18, 'HIGH', 5.95 UNION ALL
  SELECT 18, 'LOW', 33.95 UNION ALL
  SELECT 18, 'LOW', 33.95 UNION ALL
  SELECT 18, 'LOW', 4.5 UNION ALL
  SELECT 3, 'HIGH', 77.95 UNION ALL
  SELECT 3, 'HIGH', 77.95 UNION ALL
  SELECT 3, 'LOW', 45.95
)

In this example, we have three different groups: length/high, length/low, and amps/high. We want to find the mode price for each of these groups.

Finding the Mode

To find the mode of each group, we will use the MODE function in a subquery to calculate the frequency of each price and then join it back to the original table to get the mode price.

WITH prices AS (
  SELECT 18 AS length, 'HIGH' AS amps, 99.95 AS price UNION ALL
  SELECT 18, 'HIGH', 99.95 UNION ALL
  SELECT 18, 'HIGH', 5.95 UNION ALL
  SELECT 18, 'LOW', 33.95 UNION ALL
  SELECT 18, 'LOW', 33.95 UNION ALL
  SELECT 18, 'LOW', 4.5 UNION ALL
  SELECT 3, 'HIGH', 77.95 UNION ALL
  SELECT 3, 'HIGH', 77.95 UNION ALL
  SELECT 3, 'LOW', 45.95
)

SELECT 
  length, 
  amps, 
  mode_price.price AS mode_price
FROM (
  SELECT length, amps, price, COUNT(*) AS frequency
  FROM prices
  GROUP BY length, amps, price
) AS price_frequency
JOIN (
  SELECT length, amps, MAX(price) AS price 
  FROM (
    SELECT length, amps, price, COUNT(*) AS frequency
    FROM prices
    GROUP BY length, amps, price
  )
  GROUP BY length, amps
) AS mode_price
ON price_frequency.length = mode_price.length
  AND price_frequency.amps = mode_price.amps
  AND price_frequency.price = mode_price.price
  AND price_frequency.frequency = (
    SELECT MAX(frequency) 
    FROM (
      SELECT length, amps, price, COUNT(*) AS frequency
      FROM prices
      GROUP BY length, amps, price
    )
    WHERE length = price_frequency.length
      AND amps = price_frequency.amps
  )

In the above code, we first calculate the frequency of each price for each group using a subquery with the COUNT function. We then join this subquery to another subquery that calculates the maximum price for each group. The final step is to filter the results by selecting only the rows where the frequency is equal to the maximum frequency for that group.
