ORACLE: Getting Week Day Name from Date - Quick Guide How to Get the Week Day Name from a Date in Oracle SQL
When working with dates in Oracle SQL, it can be useful to know the day of the week a date falls on. Fortunately, Oracle SQL provides several built-in functions for working with dates, including getting the week day name from a date. In this Q&A Session, we will explore how to get the week day name from a date in Oracle SQL and provide some practical examples.

Using TO_CHAR Function

The simplest way to get the week day name from a date in Oracle SQL is by using the TO_CHAR function with the appropriate format specifier. The format specifier ‘DY’ returns the abbreviated week day name (e.g. ‘MON’, ‘TUE’, ‘WED’, etc.), while the format specifier ‘DAY’ returns the full week day name (e.g. ‘MONDAY’, ‘TUESDAY’, ‘WEDNESDAY’, etc.).

Here is an example query:

SELECT TO_CHAR(date '1982-03-09', 'DAY') AS day_name FROM dual;

This query will return the full week day name ‘TUESDAY’ for the date ‘1982-03-09’.

If you prefer abbreviated week day names, you can use the ‘DY’ format specifier instead:

SELECT TO_CHAR(date '1982-03-09', 'DY') AS day_name FROM dual;

This query will return the abbreviated week day name ‘TUE’ for the same date.

Please note that the result of these queries may depend on the language of the client. If you need to ensure consistent results regardless of language settings, you can specify the language explicitly like so:

SELECT TO_CHAR(date '1982-03-09', 'DAY', 'NLS_DATE_LANGUAGE = ENGLISH') AS day_name FROM dual;

This query will return the full week day name ‘TUESDAY’ for the same date, regardless of the client’s language settings.

Using a Case Statement

If you need greater control over how the week day name is displayed, you can use a case statement to translate the numeric day of the week returned by the TO_CHAR function into a textual week day name.

Here is an example query:

SELECT 
    TO_CHAR(date '1982-03-09', 'MM/DD/YYYY') AS start_date,
    CASE TO_CHAR(date '1982-03-09', 'D') 
        WHEN 1 THEN 'MONDAY'
        WHEN 2 THEN 'TUESDAY'
        WHEN 3 THEN 'WEDNESDAY'
        WHEN 4 THEN 'THURSDAY'
        WHEN 5 THEN 'FRIDAY'
        WHEN 6 THEN 'SATURDAY'
        WHEN 7 THEN 'SUNDAY'
    END AS day_name
FROM dual;

This query will return the start date ‘03/09/1982’ and the week day name ‘TUESDAY’ for the same date.

The TO_CHAR function with the format specifier ‘D’ returns the numeric day of the week, with 1 representing Monday and 7 representing Sunday. The case statement then translates this number into a textual week day name using a series of when-then clauses.

Alternative Case Statement

You may find it more convenient to define a lookup table for day names, rather than using a when-then clause in your case statement. Here is an example of how you can achieve this:

SELECT 
    TO_CHAR(date '1982-03-09', 'MM/DD/YYYY') AS start_date,
    day_names.day_name
FROM 
    dual
    JOIN (
        SELECT 1 AS day_of_week, 'MONDAY' AS day_name FROM dual UNION ALL
        SELECT 2 AS day_of_week, 'TUESDAY' AS day_name FROM dual UNION ALL
        SELECT 3 AS day_of_week, 'WEDNESDAY' AS day_name FROM dual UNION ALL
        SELECT 4 AS day_of_week, 'THURSDAY' AS day_name FROM dual UNION ALL
        SELECT 5 AS day_of_week, 'FRIDAY' AS day_name FROM dual UNION ALL
        SELECT 6 AS day_of_week, 'SATURDAY' AS day_name FROM dual UNION ALL
        SELECT 7 AS day_of_week, 'SUNDAY' AS day_name FROM dual
    ) day_names ON TO_CHAR(date '1982-03-09', 'D') = day_names.day_of_week;

This query will return the start date ‘03/09/1982’ and the week day name ‘TUESDAY’ for the same date.

The query joins the ‘dual’ table with a lookup table for day names, based on the numeric day of the week returned by the TO_CHAR function with the format specifier ‘D’. This allows you to define your table of day names in a more convenient format, rather than using a verbose when-then clause.

Recap

Oracle SQL provides several built-in functions for working with dates, including getting the week day name from a date. You can use the TO_CHAR function with the appropriate format specifier to retrieve the week day name, or use a case statement to translate the numeric day of the week into a textual week day name.
