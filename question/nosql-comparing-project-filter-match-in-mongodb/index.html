NOSQL: Comparing $project, $filter and $match in MongoDB Differences between MongoDB’s $project, $filter, and $match

Summary

MongoDB’s $project, $filter, and $match are operators used in aggregation pipelines. $project is used to project specific fields or expressions from the documents to be displayed in the results. $filter is an operator used to select a subset of elements from an array that meet a specific condition. $match, on the other hand, is used to filter the documents based on specific criteria.

What are $project, $filter, and $match?

$project and $match are Aggregation Pipeline Stages, while $filter is an Aggregation Pipeline Operator. One key difference is that a Pipeline Stage can be used independently, whereas a Pipeline Operator can be used only inside a Pipeline Stage.

$project

The $project operator used in MongoDB projection is a stage in the aggregation pipeline that selects specific fields or transformations from the input documents and produces an output document stream.

The syntax for $project pipeline stage is:

{ $project: {  } }

The operation uses the following syntax inside { specification(s) }

{ field:  | , field2: , ... }

Where:

  • 1 - includes the field in the output document
  • 0 - excludes the field from the output document
  • true - includes the field in the output document
  • false - excludes the field from the output document

For instance, if you want to display only the first name, last name, and the email address fields of the documents, you can write:

db.collection.aggregate([
  { $project : { first_name : 1, last_name:1, email:1, _id:0 } }
])

Running this code will only display the designated fields, without the _id field.

$match

$match in MongoDB is a pipeline stage that filters the documents, and only the matching documents are processed to the next stage of the pipeline. The operator follows the syntax:

{ $match : {  } }

The query can be any valid MongoDB Query filter, such as a basic query, comparison query, logical query, or an element query. For example, if you want to select only the documents where the status is “active”:

db.sales.aggregate([
  { $match : { status : "active" } }
])

$filter

$filter in MongoDB is an operator that filters the contents of an array based on a specific condition or expression.

The operator is used as follows:

{ $filter : { input : , as : , cond :  } }

The input field specifies the array to filter, while the as field associates the filtered results with a variable. cond is the expression used as the filter condition.

For instance, suppose you have a collection of sales documents, each containing an array of products with various properties such as name, quantity, and price. To filter out only the products with quantities greater than 5, you could write the following aggregation query:

db.sales.aggregate([
  { $unwind : "$products" },
  { $project : { _id : 0, name : "$products.name", quantity : "$products.quantity" } },
  { $filter : { input : "$quantity", as : "qty", cond : { $gt : ["$$qty", 5] } } }
])

This will display the name and quantity of all products that have a quantity greater than 5.

Practical Examples

Suppose we have a collection of students with fields such as name, age, gender, and grades.

In order to display only the name and the average of all the grades, you can use the following pipeline:

db.students.aggregate([
  { $project: { name: 1, grades: { $avg: "$grades" }, _id: 0 } }
])

Here, we’re using the $avg operator to calculate the average of all the grades for a give student. The output will be the names of the students along with their average grades, excluding the _id field.

Another example is when you want to display only the males in the collection. In this case, you can use a $match operator to filter the document, as in:

db.students.aggregate([
  { $match: { gender: "male" } },
  { $project: { name: 1, gender: 1, _id: 0 } }
])

Here, we’re filtering the collection to show only the documents where the gender field is equal to “male”, and then we’re projecting the name and gender fields.

Alternative Ways

While there aren’t any alternative ways to these operators, there are different stages and operators that you can use to achieve desired results. For instance, one can use $group instead of $project to group collection into subsets, and perform aggregate functions on them.
