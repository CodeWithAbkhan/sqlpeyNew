ORACLE: Display Column Comments in Descending Order: A Guide How to Show Comments of a Column with DESC Operation
If you want to show the comments of the columns when using the DESC operation, here’s how you can achieve it:

Step 1: Use Oracle SQL Developer Tool

The DESC command is interpreted differently for different tools. Oracle SQL Developer tool is one of the most popular tools to connect with the Oracle database. In this guide, we’ll be using this tool.

Step 2: Learn Oracle Views

DESC command provides information about the columns of a table. To get the comments of the columns, we need to join multiple Oracle views. Here are the views that we can use:

user_col_comments

user_tab_columns

The user_col_comments view stores column comments for all tables owned by the user. The user_tab_columns view contains information about columns of a table.

Step 3: Use SQL Query to Get Column Data

Here is a SQL query that will provide the desired column data:

SELECT tc.column_name,
       tc.nullable,
       tc.data_type || 
          CASE 
             WHEN tc.data_type = "NUMBER" AND tc.data_precision IS NOT NULL 
                THEN "(" || tc.data_precision || "," || tc.data_scale || ")"
             WHEN tc.data_type LIKE "%CHAR%" 
                THEN "(" || tc.data_length || ")"
             ELSE NULL
          END AS type,
       cc.comments
FROM   user_col_comments cc
JOIN   user_tab_columns tc 
ON     cc.column_name = tc.column_name
AND    cc.table_name = tc.table_name
WHERE  cc.table_name = UPPER(:tablename)

This query joins both user_col_comments and user_tab_columns views to get the column name, data type, nullable, and comment of the specified table. The query uses the parameter :tablename to specify the name of the table whose information you want to retrieve.

Step 4: Run the Query to Get Column Data

Run the SQL query in Oracle SQL Developer tool. The result will show you the column name, data type, nullable, and comment of the specified table.

Example

Suppose you have a table named “customers”. You can use the following query to get the column data:

SELECT tc.column_name,
       tc.nullable,
       tc.data_type || 
          CASE 
             WHEN tc.data_type = "NUMBER" AND tc.data_precision IS NOT NULL 
                THEN "(" || tc.data_precision || "," || tc.data_scale || ")"
             WHEN tc.data_type LIKE "%CHAR%" 
                THEN "(" || tc.data_length || ")"
             ELSE NULL
          END AS type,
       cc.comments
FROM   user_col_comments cc
JOIN   user_tab_columns tc 
ON     cc.column_name = tc.column_name
AND    cc.table_name = tc.table_name
WHERE  cc.table_name = 'CUSTOMERS';

The above query will give you the following result:

Name      Nullable Type            Comments
--  -- --
ID        NOT NULL NUMBER(38)        Customer ID
NAME               VARCHAR2(100)      Name of the Customer
DOB                DATE              Date of Birth of the Customer
PHONE              VARCHAR2(12)       Contact Number of the Customer
EMAIL              VARCHAR2(100)      Email ID of the Customer

Alternative Ways

You can also use the following command to get the information for all columns of a table in a single line:

SELECT dbms_metadata.get_ddl('TABLE', 'TABLE_NAME', 'OWNER_NAME') 
FROM dual;

This command will provide the column information along with the table creation script. Although, the information will not be presented in a tabular form as in the previous example.

Another way to get column information is to select all columns from the user_tab_columns view:

SELECT * 
FROM   user_tab_columns 
WHERE  table_name = 'TABLE_NAME';

Although, this method will not provide the comments of the columns, so it’s not the ideal solution if you need the comment information.

Recap

By following the above steps, you can retrieve the comments of the columns when using the DESC operation. Using Oracle SQL Developer tool and the SQL query mentioned in this guide, you can quickly and easily get the desired column information. ]]>
