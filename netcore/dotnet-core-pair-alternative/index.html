What is a C#’s analog of std::pair in C++? I found System.Web.UI.Pair class, but I’d prefer something template-based.

Method 1

Tuples are available since .NET4.0 and support generics:

Tuple<string, int> t = new Tuple<string, int>("Hello", 4);

In previous versions you can use System.Collections.Generic.KeyValuePair<K, V> or a solution like the following:

public class Pair<T, U> {
 public Pair() {
 }

 public Pair(T first, U second) {
 this.First = first;
 this.Second = second;
 }

 public T First { get; set; }
 public U Second { get; set; }
};

And use it like this:

Pair<String, int> pair = new Pair<String, int>("test", 2);
Console.WriteLine(pair.First);
Console.WriteLine(pair.Second);

This outputs:

test
2

Or even this chained pairs:

Pair<Pair<String, int>, bool> pair = new Pair<Pair<String, int>, bool>();
pair.First = new Pair<String, int>();
pair.First.First = "test";
pair.First.Second = 12;
pair.Second = true;

Console.WriteLine(pair.First.First);
Console.WriteLine(pair.First.Second);
Console.WriteLine(pair.Second);

That outputs:

test
12
true

**What is C#’s analog of std::pair in C++?**

When searching for a template-based equivalent of std::pair in C# , you may be led to System.Web.UI.Pair, but what about something more flexible and generic?

Method 1

One option is to utilize **Tuples**, which have been available since .NET 4.0. Tuples support generics, making them an excellent choice for pairing values of different types.

Here’s an example:

Tuple<string, int> t = new Tuple<string, int>("Hello", 4);

Alternative Approach

For earlier versions of .NET, you can use System.Collections.Generic.KeyValuePair<k, v> or create your own custom class. Here’s a sample implementation:

public class Pair<t, u>
{
 public Pair()
 {
 }

 public Pair(T first, U second)
 {
 First = first;
 Second = second;
 }

 public T First { get; set; }
 public U Second { get; set; }
}

You can then use it like this:

Pair<string, int> pair = new Pair<string, int>("test", 2);
Console.WriteLine(pair.First);
Console.WriteLine(pair.Second);

This would output:

test
2

And if you want to chain pairs together, you can do so as well:

Pair<><string, int>, bool> pair = new Pair<><string, int>, bool>();
pair.First = new Pair<string, int>();
pair.First.First = "test";
pair.First.Second = 12;
pair.Second = true;

Console.WriteLine(pair.First.First);
Console.WriteLine(pair.First.Second);
Console.WriteLine(pair.Second);

This would output:

test
12

<p>Here is my pair class<br><br>

<pre><code>public class Pair&lt;X, Y&gt;
{
 private X _x;
 private Y _y;

 public Pair(X first, Y second)
 {
 _x = first;
 _y = second;
 }

 public X first { get { return _x; } }

 public Y second { get { return _y; } }

 public override bool Equals(object obj)
 {
 if (obj == null)
 return false;
 if (obj == this)
 return true;
 Pair&lt;X, Y&gt; other = obj as Pair&lt;X, Y&gt;;
 if (other == null)
 return false;

 return
 (((first == null) &amp;&amp; (other.first == null))
 || ((first != null) &amp;&amp; first.Equals(other.first)))
 &amp;&amp;
 (((second == null) &amp;&amp; (other.second == null))
 || ((second != null) &amp;&amp; second.Equals(other.second)));
 }

 public override int GetHashCode()
 {
 int hashcode = 0;
 if (first != null)
 hashcode += first.GetHashCode();
 if (second != null)
 hashcode += second.GetHashCode();

 return hashcode;
 }
}
