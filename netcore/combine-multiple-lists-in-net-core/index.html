Is it possible to convert two or more lists into one single list, in .NET using C#?

For example,

public static List<Product> GetAllProducts(int categoryId){ …. } . . . var productCollection1 = GetAllProducts(CategoryId1); var productCollection2 = GetAllProducts(CategoryId2); var productCollection3 = GetAllProducts(CategoryId3);

Method 1

You can use the LINQ Concat and ToList methods:

var allProducts = productCollection1.Concat(productCollection2)
 .Concat(productCollection3)
 .ToList();

Note that there are more efficient ways to do this - the above will basically loop through all the entries, creating a dynamically sized buffer. As you can predict the size to start with, you don’t need this dynamic sizing… so you could use:

var allProducts = new List<Product>(productCollection1.Count +
 productCollection2.Count +
 productCollection3.Count);
allProducts.AddRange(productCollection1);
allProducts.AddRange(productCollection2);
allProducts.AddRange(productCollection3);

(AddRange is special-cased for ICollection<T> for efficiency.)

I wouldn’t take this approach unless you really have to though.

**Merging Multiple Lists into One in .NET Core using C#**

Suppose you need to combine multiple lists of products into a single list, where each list represents a specific category. How can you achieve this in your .NET Core application written in C#?

**Method 1: Using LINQ’s Concat and ToList Methods**

One way to merge the lists is by using the Concat method from LINQ, which concatenates two or more sequences into one. You can then use the ToList method to convert the concatenated sequence into a list.

Here’s an example:

var allProducts = productCollection1.Concat(productCollection2).Concat(productCollection3).ToList();

This approach works, but it may not be the most efficient way to merge the lists, especially if you’re working with large datasets. The Concat method needs to create a dynamically sized buffer to store the results, which can lead to performance issues.

**Method 2: Using AddRange and Pre-allocating the List**

A more efficient approach is to pre-allocate the list with the total count of products across all categories, and then use the AddRange method to add each product collection to the list. This approach avoids the need for dynamic buffering.

var allProducts = new List<product>(productCollection1.Count + productCollection2.Count + productCollection3.Count);
allProducts.AddRange(productCollection1);
allProducts.AddRange(productCollection2);
allProducts.AddRange(productCollection3);

This method is more efficient, but it may still be slow if you’re working with very large datasets. Additionally, this approach requires that the AddRange method is called on a list that implements ICollection<t>.

Conclusion

While both methods can be used to merge multiple lists into one, the second method using AddRange and pre-allocating the list is generally more efficient and scalable. However, if you don’t need to worry about performance issues, the first method using LINQ’s Concat and ToList methods can still be a viable option.
