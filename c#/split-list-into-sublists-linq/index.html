“How to Split a List into Sublists with LINQ in C#”

When working with collections in C#, a common requirement is to divide a large list into smaller, more manageable sublists or “chunks.” This is particularly useful for processing data in batches, improving performance, or simply organizing data more logically. LINQ (Language Integrated Query) offers several elegant ways to achieve this. Let’s explore different approaches to splitting a list into sublists.

Solution 1: Grouping by Index

One effective method involves using LINQ’s GroupBy with an index. By grouping elements based on their index divided by the desired chunk size, you can create sublists.

public static List<List<T>> Split<T>(IList<T> source)
{
    return source
        .Select((x, i) => new { Index = i, Value = x }) // Pair each element with its index
        .GroupBy(x => x.Index / 3)                    // Group by index divided by chunk size (3 in this example)
        .Select(x => x.Select(v => v.Value).ToList()) // Select the values from each group and convert to a list
        .ToList();                                     // Convert the collection of lists to a list of lists
}

This approach generates lists where each sublist contains a maximum of three elements.

Solution 2: Using Take and Skip with a while loop

This solution iterates through the source collection, taking a specified number of elements for each chunk and then skipping those elements for the next iteration.

public static IEnumerable<IEnumerable<T>> Chunk<T>(this IEnumerable<T> source, int chunksize)
{
    while (source.Any()) // Continue as long as there are elements in the source
    {
        yield return source.Take(chunksize); // Return the next chunk
        source = source.Skip(chunksize);    // Move to the next chunk
    }
}

This method is efficient as it processes elements lazily.

Solution 3: Optimized Take and Skip

A slight variation on the previous approach uses an offset to manage the iteration, potentially reducing overhead in some scenarios.

public static IEnumerable<IEnumerable<T>> ChunkTrivialBetter<T>(this IEnumerable<T> source, int chunksize)
{
   var pos = 0;
   while (source.Skip(pos).Any()) // Check if there are remaining elements after skipping
   {
      yield return source.Skip(pos).Take(chunksize); // Yield the current chunk
      pos += chunksize;                             // Advance the position
   }
}

This version aims to prevent issues with large collections by avoiding repeated skips on the entire source.

Solution 4: .NET 6.0 Native Chunk Method

Starting with .NET 6.0, the System.Linq namespace includes a built-in Chunk method, offering a concise and performant way to split collections.

This is often the preferred method for its simplicity and efficiency when targeting modern .NET versions.

Solution 5: Custom Iterator with IEnumerator

For granular control, you can implement a custom iterator using IEnumerator. This allows for fine-tuning how chunks are created and consumed.

public static IEnumerable<IEnumerable<T>> ChunkInternal<T>(this IEnumerable<T> source, int chunkSize)
{
    using (IEnumerator<T> enumerator = source.GetEnumerator())
    do
    {
        if (!enumerator.MoveNext()) yield break; // Exit if no more elements
        yield return ChunkSequence(enumerator, chunkSize); // Yield the current chunk
    } while (true);
}

private static IEnumerable<T> ChunkSequence<T>(IEnumerator<T> enumerator, int chunkSize)
{
    int count = 0;
    do
    {
        yield return enumerator.Current; // Yield the current item
    } while (++count < chunkSize && enumerator.MoveNext()); // Continue until chunk size reached or end of source
}

This solution is robust and handles edge cases well. For more details on its implementation, refer to related C# discussions .

Solution 6: Lazy and Efficient Chunking

This approach prioritizes being completely lazy, working with infinite enumerables, and avoiding intermediate copying.

public static IEnumerable<IEnumerable<T>> Chunks<T>(this IEnumerable<T> enumerable, int chunkSize)
{
    if (chunkSize < 1) throw new ArgumentException("chunkSize must be positive");

    using (var e = enumerable.GetEnumerator())
    while (e.MoveNext())
    {
        var remaining = chunkSize;
        var innerMoveNext = new Func<bool>(() => --remaining > 0 && e.MoveNext());

        yield return e.GetChunk(innerMoveNext); // Yield the current chunk
        while (innerMoveNext()) { /* discard elements skipped by inner iterator */ } // Discard unconsumed elements
    }
}

private static IEnumerable<T> GetChunk<T>(this IEnumerator<T> e, Func<bool> innerMoveNext)
{
    do yield return e.Current;
    while (innerMoveNext());
}

This implementation is praised for its performance characteristics and ability to handle large datasets efficiently.

Solution 7: Simple Iterator Split

A straightforward iterator method for splitting lists.

public static IEnumerable<IEnumerable<T>> Split<T>(this IEnumerable<T> source, int len)
{
    if (len == 0)
       throw new ArgumentNullException();

    var enumer = source.GetEnumerator();
    while (enumer.MoveNext())
    {
        yield return Take(enumer.Current, enumer, len); // Yield each chunk
    }
}

private static IEnumerable<T> Take<T>(T head, IEnumerator<T> tail, int len)
{
    while (true)
    {
        yield return head;
        if (--len == 0) break; // Stop if chunk size reached
        if (tail.MoveNext()) head = tail.Current; // Get next item
        else break; // Stop if end of source reached
    }
}

This provides a clean way to iterate and split elements.

Solution 8: Array.Copy for Performance

When dealing with arrays or collections that can be efficiently converted to arrays, using Array.Copy can offer significant performance benefits.

public static IEnumerable<T[]> Chunk<T>(this IEnumerable<T> items, int size)
{
    T[] array = items as T[] ?? items.ToArray(); // Convert to array if not already
    for (int i = 0; i < array.Length; i += size)
    {
        T[] chunk = new T[Math.Min(size, array.Length - i)]; // Create chunk array
        Array.Copy(array, i, chunk, 0, chunk.Length);      // Copy elements
        yield return chunk;
    }
}

This method is particularly effective for large, contiguous data sets.

Solution 9: Clump Extension Method

A custom extension method named Clump for grouping items into lists of a specified size.

public static IEnumerable<IEnumerable<T>> Clump<T>(this IEnumerable<T> source, int size)
{
    if (source == null)
        throw new ArgumentNullException("source");
    if (size < 1)
        throw new ArgumentOutOfRangeException("size", "size must be greater than 0");

    return ClumpIterator<T>(source, size); // Call the iterator
}

private static IEnumerable<IEnumerable<T>> ClumpIterator<T>(IEnumerable<T> source, int size)
{
    T[] items = new T[size]; // Buffer for current chunk
    int count = 0;
    foreach (var item in source)
    {
        items[count] = item;
        count++;

        if (count == size) // If chunk is full
        {
            yield return items; // Yield the chunk
            items = new T[size]; // Reset buffer
            count = 0;
        }
    }
    if (count > 0) // Handle any remaining items
    {
        if (count == size) yield return items;
        else
        {
            T[] tempItems = new T[count];
            Array.Copy(items, tempItems, count);
            yield return tempItems;
        }
    }
}

This provides a clear and reusable way to segment collections.

Solution 14: List.GetRange for List Types

If your source is specifically a List<T>, GetRange provides a clean way to extract sublists.

public static IEnumerable<List<T>> Chunked<T>(this List<T> source, int chunkSize)
{
    var offset = 0;

    while (offset < source.Count)
    {
        yield return source.GetRange(offset, Math.Min(source.Count - offset, chunkSize)); // Get a range of elements
        offset += chunkSize; // Advance the offset
    }
}

This is a direct and readable solution for List<T>.

Solution 15: GroupBy with Index for Lists

Similar to Solution 1, this applies the GroupBy by index logic specifically to List<T>.

public static List<List<T>> Chunk<T>(List<T> theList, int chunkSize)
{
    List<List<T>> result = theList
        .Select((x, i) => new { data = x, indexgroup = i / chunkSize }) // Pair data with indexed group
        .GroupBy(x => x.indexgroup, x => x.data) // Group by the calculated index group
        .Select(g => new List<T>(g))             // Convert each group to a List<T>
        .ToList();                                // Collect all lists into a List<List<T>>

    return result;
}

This is another variation of the index-based grouping strategy.

Solution 18: Single Enumeration with Partition

This custom Partition method ensures the source enumerable is traversed only once, creating lists for each partition.

public static IEnumerable<IEnumerable<T>> Partition<T>(IEnumerable<T> source, int chunkSize)
{
    if (source == null) throw new ArgumentNullException("source");
    if (chunkSize < 1) throw new ArgumentException("Invalid chunkSize: " + chunkSize);

    using (IEnumerator<T> sourceEnumerator = source.GetEnumerator())
    {
        IList<T> currentChunk = new List<T>();
        while (sourceEnumerator.MoveNext())
        {
            currentChunk.Add(sourceEnumerator.Current);
            if (currentChunk.Count == chunkSize)
            {
                yield return currentChunk; // Yield the filled chunk
                currentChunk = new List<T>(); // Start a new chunk
            }
        }

        if (currentChunk.Any()) yield return currentChunk; // Yield any remaining items
    }
}

This approach balances efficiency and correctness.

Solution 19: InSetsOf Extension Method

A straightforward extension method to yield lists of a specified maximum size.

public static IEnumerable<List<T>> InSetsOf<T>(this IEnumerable<T> source, int max)
{
    var toReturn = new List<T>(max);
    foreach (var item in source)
    {
        toReturn.Add(item);
        if (toReturn.Count == max)
        {
            yield return toReturn; // Yield the complete set
            toReturn = new List<T>(max); // Prepare for the next set
        }
    }
    if (toReturn.Any()) yield return toReturn; // Yield any remaining items
}

This is a concise way to segment collections.

Solution 20: Compact O(n) Chunking

This compact solution achieves O(n) performance by converting the source to a list if necessary.

public static IEnumerable<T[]> Chunk<T>(IEnumerable<T> source, int chunksize)
{
    var list = source as IList<T> ?? source.ToList(); // Convert to list if needed
    for (int start = 0; start < list.Count; start += chunksize)
    {
        T[] chunk = new T[Math.Min(chunksize, list.Count - start)]; // Create chunk array
        for (int i = 0; i < chunk.Length; i++) chunk[i] = list[start + i]; // Populate chunk

        yield return chunk;
    }
}

This method efficiently handles chunk creation.

Solution 22: Skip and Take with Enumerable.Range

This approach leverages Enumerable.Range to generate indices for chunks, then uses Skip and Take to extract them.

public static IEnumerable<IEnumerable<T>> Chunk<T>(this IEnumerable<T> source, int chunkSize)
{
    if (chunkSize <= 0) throw new ArgumentOutOfRangeException($"{nameof(chunkSize)} should be > 0");

    var nbChunks = (int)Math.Ceiling((double)source.Count() / chunkSize); // Calculate number of chunks

    return Enumerable.Range(0, nbChunks)
                     .Select(chunkNb => source.Skip(chunkNb * chunkSize) // Skip to chunk start
                                             .Take(chunkSize));          // Take chunk elements
}

This is a functional approach to chunking. For more on LINQ, see What is LINQ? .

Solution 24: Memory<T> for Reference Chunks

This method creates chunks that are references to the original array, allowing modifications to reflect in the source.

public static IEnumerable<Memory<T>> RefChunkBy<T>(this T[] array, int size)
{
    if (size < 1 || array is null) throw new ArgumentException("chunkSize must be positive");

    var index = 0;
    var counter = 0;

    for (int i = 0; i < array.Length; i++)
    {
        if (counter == size)
        {
            yield return new Memory<T>(array, index, size); // Yield reference chunk
            index = i; // Update start index
            counter = 0; // Reset counter
        }
        counter++;

        if (i + 1 == array.Length) // Handle last chunk
        {
            yield return new Memory<T>(array, index, array.Length - index);
        }
    }
}

This is useful when you need to work with slices of the original data.

Solution 26: Buckets for Visual Distribution

This method distributes items into a specified number of buckets.

public static List<List<T>> Buckets<T>(this List<T> source, int numberOfBuckets)
{
    List<List<T>> result = new List<List<T>>();
    for (int i = 0; i < numberOfBuckets; i++) result.Add(new List<T>()); // Initialize buckets

    int count = 0;
    while (count < source.Count())
    {
        result[count % numberOfBuckets].Add(source[count]); // Add item to appropriate bucket
        count++;
    }
    return result;
}

This is useful for distributing data evenly across a fixed number of groups.

Solution 27: GetSplitItemsList Helper

A helper method for splitting lists into a specified number of sublists.

public static List<List<T>> GetSplitItemsList<T>(List<T> originalItemsList, short number)
{
    var listGroup = new List<List<T>>();
    int j = number;
    for (int i = 0; i < originalItemsList.Count; i += number)
    {
        var cList = originalItemsList.Take(j).Skip(i).ToList(); // Extract sublist
        j += number;
        listGroup.Add(cList);
    }
    return listGroup;
}

This provides a straightforward way to divide a list.

Solution 28: Compact List Chunking

A compact solution for chunking lists, using GetRange and RemoveRange.

public static IEnumerable<IEnumerable<TSource>> Chunk<TSource>(this IEnumerable<TSource> source, int chunkSize)
{
    var chunkList = source.ToList(); // Copy source to a list

    while (chunkList.Count > chunkSize)
    {
        yield return chunkList.GetRange(0, chunkSize); // Yield chunk
        chunkList.RemoveRange(0, chunkSize); // Remove chunk from list
    }

    yield return chunkList; // Yield remaining items
}

Solution 29: SplitOn with a Predicate

This flexible method allows splitting based on a custom condition defined by a predicate.

public static List<List<T>> SplitOn<T>(List<T> main, Func<T, bool> splitOn)
{
    int groupIndex = 0;

    return main.Select(item => new
    {
        Group = (splitOn.Invoke(item) ? ++groupIndex : groupIndex), // Determine group index
        Value = item
    })
    .GroupBy(it2 => it2.Group) // Group by the determined index
    .Select(x => x.Select(v => v.Value).ToList()) // Select values and convert to list
    .ToList();
}

This provides high customizability for splitting logic.

Choosing the Right Method

The best approach depends on your specific needs:

  • .NET 6+: The native Chunk method is usually the most straightforward and performant.
  • Large Collections/Laziness: Solutions using IEnumerator, custom iterators, or Rx’s Buffer are excellent for handling large or infinite sequences efficiently.
  • Performance Critical: Methods involving Array.Copy or optimized iterator patterns can offer the best speed.
  • List Specific: GetRange or GroupBy on index are clean options for List<T>.
  • Custom Logic: SplitOn provides flexibility for unique splitting criteria.
