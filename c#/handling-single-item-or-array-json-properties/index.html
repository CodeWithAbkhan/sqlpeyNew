“Handling Single Item or Array JSON Properties in C#”

When working with JSON APIs or data feeds, it’s common to encounter situations where a single property can be represented as either a single value (e.g., a string) or an array of values (e.g., an array of strings). This inconsistency can cause deserialization errors if not handled properly. Fortunately, C# provides flexible mechanisms to address this, primarily through custom JsonConverter implementations. This allows you to tailor the deserialization process to accommodate these variations.

Handling Single Item or Array JSON Properties in C#

The core challenge is to create a C# class that accurately maps to JSON data where a field can be a single string or a list of strings. The most effective approach involves creating a custom JsonConverter that intelligently interprets the incoming JSON token.

Solution 1: Generic Custom JsonConverter with Newtonsoft.Json

A widely adopted and highly effective method is to create a generic JsonConverter. This converter can be applied to a property defined as a List<T> and handles both single values and arrays during deserialization.

1. Define the Data Model:

First, define your C# class that represents the JSON structure. For properties that can be single or an array, declare them as List<T> and apply the custom converter using the [JsonConverter] attribute. It’s also good practice to use [JsonProperty] to map JSON property names to your C# properties, ensuring clarity and flexibility.

using Newtonsoft.Json;

public class EventItem
{
    [JsonProperty("email")]
    public string Email { get; set; }

    [JsonProperty("timestamp")]
    public int Timestamp { get; set; }

    [JsonProperty("event")]
    public string Event { get; set; }

    [JsonProperty("category")]
    // Apply the custom converter to handle single string or array of strings
    [JsonConverter(typeof(SingleOrArrayConverter<string>))]
    public List<string> Categories { get; set; }
}

2. Implement the Custom JsonConverter:

The SingleOrArrayConverter<T> class is designed to read JSON tokens and convert them into a List<T>, whether the source is a single value or an array.

using Newtonsoft.Json;
using Newtonsoft.Json.Linq;
using System;
using System.Collections.Generic;

public class SingleOrArrayConverter<T> : JsonConverter
{
    // Determines if the converter can handle a specific object type.
    public override bool CanConvert(Type objectType)
    {
        // This converter is designed for List<T> types.
        return (objectType == typeof(List<T>));
    }

    // Reads the JSON token and deserializes it.
    public override object ReadJson(JsonReader reader, Type objectType, object existingValue, JsonSerializer serializer)
    {
        // Load the current JSON token.
        JToken token = JToken.Load(reader);

        // If the token is an array, deserialize it directly into a List<T>.
        if (token.Type == JTokenType.Array)
        {
            return token.ToObject<List<T>>();
        }
        // If the token is null, return null.
        if (token.Type == JTokenType.Null)
        {
            return null;
        }
        // If it's a single value, create a new List<T> containing that single value.
        return new List<T> { token.ToObject<T>() };
    }

    // Indicates whether the converter can write JSON.
    // Set to false if serialization in the reverse direction (List<T> to single/array) is not needed.
    public override bool CanWrite
    {
        get { return false; }
    }

    // WriteJson is not implemented as we are focusing on deserialization.
    public override void WriteJson(JsonWriter writer, object value, JsonSerializer serializer)
    {
        throw new NotImplementedException("This converter is for read-only operations.");
    }
}

Solution 2: Handling Other Generic Collections

This variation enhances the SingleOrArrayConverter to work with various generic collections like ObservableCollection<T>, not just List<T>.

using Newtonsoft.Json;
using Newtonsoft.Json.Linq;
using System;
using System.Collections;
using System.Collections.Generic;
using System.Net.Http; // For HttpRequest example

public class SingleOrArrayListConverter : JsonConverter
{
    // ... (Implementation details for CanConvert, ReadJson, CanWrite, WriteJson as provided in the original content) ...
    // Adapted from https://stackoverflow.com/a/18997172
    // Original author: Brian Rogers
    readonly bool canWrite;
    readonly IContractResolver resolver;

    public SingleOrArrayListConverter() : this(false) { }
    public SingleOrArrayListConverter(bool canWrite) : this(canWrite, null) { }
    public SingleOrArrayListConverter(bool canWrite, IContractResolver resolver)
    {
        this.canWrite = canWrite;
        this.resolver = resolver ?? new JsonSerializer().ContractResolver;
    }

    static bool CanConvert(Type objectType, IContractResolver resolver, out Type itemType, out JsonArrayContract contract)
    {
        if ((itemType = objectType.GetListItemType()) == null)
        {
            itemType = null;
            contract = null;
            return false;
        }
        if ((contract = resolver.ResolveContract(objectType) as JsonArrayContract) == null)
            return false;
        var itemContract = resolver.ResolveContract(itemType);
        if (itemContract is JsonArrayContract)
            return false;
        return true;
    }

    public override bool CanConvert(Type objectType) { return CanConvert(objectType, resolver, out _, out _); }

    public override object ReadJson(JsonReader reader, Type objectType, object existingValue, JsonSerializer serializer)
    {
        Type itemType;
        JsonArrayContract contract;

        if (!CanConvert(objectType, serializer.ContractResolver, out itemType, out contract))
            throw new JsonSerializationException($"Invalid type for {GetType()}: {objectType}");
        if (reader.MoveToContent().TokenType == JsonToken.Null)
            return null;
        var list = (IList)(existingValue ?? contract.DefaultCreator());
        if (reader.TokenType == JsonToken.StartArray)
            serializer.Populate(reader, list);
        else
            list.Add(serializer.Deserialize(reader, itemType));
        return list;
    }

    public override bool CanWrite { get { return canWrite; } }

    public override void WriteJson(JsonWriter writer, object value, JsonSerializer serializer)
    {
        var list = value as ICollection;
        if (list == null)
            throw new JsonSerializationException($"Invalid type for {GetType()}: {value.GetType()}");
        if (list.Count == 1)
        {
            foreach (var item in list) { serializer.Serialize(writer, item); break; }
        }
        else
        {
            writer.WriteStartArray();
            foreach (var item in list) serializer.Serialize(writer, item);
            writer.WriteEndArray();
        }
    }
}

// Helper extension for GetListItemType
public static class JsonExtensions
{
    public static JsonReader MoveToContent(this JsonReader reader)
    {
        while ((reader.TokenType == JsonToken.Comment || reader.TokenType == JsonToken.None) && reader.Read());
        return reader;
    }

    internal static Type GetListItemType(this Type type)
    {
        if (type.IsPrimitive || type.IsArray || type == typeof(string)) return null;
        while (type != null)
        {
            if (type.IsGenericType)
            {
                var genType = type.GetGenericTypeDefinition();
                if (genType == typeof(List<>)) return type.GetGenericArguments()[0];
            }
            type = type.BaseType;
        }
        return null;
    }
}

// Example for ObservableCollection<T>
public class SingleOrArrayCollectionConverter<TCollection, TItem> : JsonConverter
    where TCollection : ICollection<TItem>
{
    // ... (Similar implementation as SingleOrArrayListConverter, adapted for specific TCollection and TItem) ...
    // Adapted from https://stackoverflow.com/a/18997172
    // Original author: Brian Rogers
    readonly bool canWrite;

    public SingleOrArrayCollectionConverter() : this(false) { }
    public SingleOrArrayCollectionConverter(bool canWrite) { this.canWrite = canWrite; }

    public override bool CanConvert(Type objectType) { return typeof(TCollection).IsAssignableFrom(objectType); }

    static void ValidateItemContract(IContractResolver resolver)
    {
        var itemContract = resolver.ResolveContract(typeof(TItem));
        if (itemContract is JsonArrayContract)
            throw new JsonSerializationException($"Item contract type {itemContract} not supported.");
    }

    public override object ReadJson(JsonReader reader, Type objectType, object existingValue, JsonSerializer serializer)
    {
        ValidateItemContract(serializer.ContractResolver);
        if (reader.MoveToContent().TokenType == JsonToken.Null) return null;
        var list = (ICollection<TItem>)(existingValue ?? serializer.ContractResolver.ResolveContract(objectType).DefaultCreator());
        if (reader.TokenType == JsonToken.StartArray) serializer.Populate(reader, list);
        else list.Add(serializer.Deserialize<TItem>(reader));
        return list;
    }

    public override bool CanWrite { get { return canWrite; } }

    public override void WriteJson(JsonWriter writer, object value, JsonSerializer serializer)
    {
        ValidateItemContract(serializer.ContractResolver);
        var list = value as ICollection<TItem>;
        if (list == null) throw new JsonSerializationException($"Invalid type for {GetType()}: {value.GetType()}");
        if (list.Count == 1)
        {
            foreach (var item in list) { serializer.Serialize(writer, item); break; }
        }
        else
        {
            writer.WriteStartArray();
            foreach (var item in list) serializer.Serialize(writer, item);
            writer.WriteEndArray();
        }
    }
}

Imports Newtonsoft.Json

' Converter for handling single values or arrays
Public Class SingleValueArrayConverter(Of T)
    Inherits JsonConverter

    ' WriteJson is not implemented in this example.
    Public Overrides Sub WriteJson(writer As JsonWriter, value As Object, serializer As JsonSerializer)
        Throw New NotImplementedException()
    End Sub

    ' Reads JSON and deserializes appropriately.
    Public Overrides Function ReadJson(reader As JsonReader, objectType As Type, existingValue As Object, serializer As JsonSerializer) As Object
        Dim retVal As Object
        If reader.TokenType = JsonToken.StartObject Then
            ' Deserialize as a single object and wrap in a List.
            Dim instance As T = DirectCast(serializer.Deserialize(reader, GetType(T)), T)
            retVal = New List(Of T)() From {instance}
        ElseIf reader.TokenType = JsonToken.StartArray Then
            ' Deserialize directly as a List.
            retVal = serializer.Deserialize(reader, objectType)
        Else
             ' Handle unexpected token types or nulls.
            retVal = Nothing
        End If
        Return retVal
    End Function

    ' Specifies if the converter can convert the given type.
    Public Overrides Function CanConvert(objectType As Type) As Boolean
        ' This converter is designed for List<T>, but this implementation focuses on ReadJson.
        ' For broader applicability, more robust type checking might be needed.
        Return True ' Simplified for example; refine if necessary.
    End Function
End Class

Solution 4: Using System.Text.Json

For projects utilizing the built-in System.Text.Json library (available in .NET Core 3.0+ and .NET 5+), a similar converter can be implemented.

using System;
using System.Collections.Generic;
using System.Text.Json;
using System.Text.Json.Serialization;

public class SystemTextSingleOrArrayConverter : JsonConverter<List<string>>
{
    // Reads JSON and handles single value or array.
    public override List<string> Read(
        ref Utf8JsonReader reader,
        Type typeToConvert,
        JsonSerializerOptions options)
    {
        switch (reader.TokenType)
        {
            case JsonTokenType.Null:
                return null; // Handle null values.
            case JsonTokenType.StartArray:
                // If it's an array, deserialize it normally.
                var list = new List<string>();
                while (reader.Read())
                {
                    if (reader.TokenType == JsonTokenType.EndArray)
                        break;
                    list.Add(JsonSerializer.Deserialize<string>(ref reader, options));
                }
                return list;
            default:
                // If it's a single value, deserialize it and put it into a list.
                return new List<string> { JsonSerializer.Deserialize<string>(ref reader, options) };
        }
    }

    // Writes the List<string> back to JSON.
    // This implementation simply serializes the list as an array.
    public override void Write(
        Utf8JsonWriter writer,
        List<string> objectToWrite,
        JsonSerializerOptions options)
    {
        // Serialize the list as an array. For single-item array to single value serialization,
        // a more complex Write implementation would be needed.
        JsonSerializer.Serialize(writer, objectToWrite, options);
    }
}

Solution 5: Custom Converter for Flexible Collection Handling

This solution provides a SafeCollectionConverter that can handle conversion to IEnumerable types, offering flexibility when the exact collection type isn’t known beforehand or when dealing with specific scenarios like REST or OData responses.

using Newtonsoft.Json;
using Newtonsoft.Json.Linq;
using System;
using System.Collections;
using System.Collections.Generic;

public class SafeCollectionConverter : JsonConverter
{
    // Allows conversion for any type.
    public override bool CanConvert(Type objectType)
    {
        return true;
    }

    // Reads the JSON and converts it safely.
    public override object ReadJson(JsonReader reader, Type objectType, object existingValue, JsonSerializer serializer)
    {
        // Deserialize into a JToken first for flexible handling.
        var jToken = JToken.Load(reader);
        return jToken.ToObjectCollectionSafe(objectType, serializer);
    }

    // Writing is not implemented in this version.
    public override bool CanWrite => false;

    public override void WriteJson(JsonWriter writer, object value, JsonSerializer serializer)
    {
        throw new NotImplementedException();
    }
}

// Extension methods for safe conversion.
namespace Newtonsoft.Json.Linq
{
    public static class SafeJsonConvertExtensions
    {
        public static object ToObjectCollectionSafe(this JToken jToken, Type objectType, JsonSerializer jsonSerializer)
        {
            // Check if the target type is an enumerable.
            var expectsArray = typeof(IEnumerable).IsAssignableFrom(objectType);

            if (jToken is JArray jArray)
            {
                if (!expectsArray) // Target is not an array, but JSON is an array.
                {
                    if (jArray.Count == 0) return JValue.CreateNull().ToObject(objectType, jsonSerializer);
                    if (jArray.Count == 1) return jArray.First.ToObject(objectType, jsonSerializer);
                }
            }
            else if (expectsArray) // Target is an array, but JSON is a single value.
            {
                return new JArray(jToken).ToObject(objectType, jsonSerializer);
            }
            // Default case: direct conversion.
            return jToken.ToObject(objectType, jsonSerializer);
        }

        // Overload for default serializer.
        public static object ToObjectCollectionSafe(this JToken jToken, Type objectType)
        {
            return ToObjectCollectionSafe(jToken, objectType, JsonSerializer.CreateDefault());
        }

        // Generic overloads for convenience.
        public static T ToObjectCollectionSafe<T>(this JToken jToken) => (T)ToObjectCollectionSafe(jToken, typeof(T));
        public static T ToObjectCollectionSafe<T>(this JToken jToken, JsonSerializer jsonSerializer) => (T)ToObjectCollectionSafe(jToken, typeof(T), jsonSerializer);
    }
}

Solution 6: HTTP Client Stream Deserialization

This snippet demonstrates how to adapt the SingleOrArrayConverter for use with HttpClient when reading JSON streams, a common pattern in asynchronous operations.

using Newtonsoft.Json;
using System.Collections.Generic;
using System.IO;
using System.Net.Http;
using System.Threading;
using System.Threading.Tasks;

public class HttpClientHelper
{
    // Method to perform an HTTP request and deserialize the response.
    public async Task<IList<T>> HttpRequestAsync<T>(HttpClient httpClient, string requestUrl, CancellationToken cancellationToken)
    {
        using var request = new HttpRequestMessage(HttpMethod.Get, requestUrl);
        using var httpResponseMessage = await httpClient.SendAsync(request, HttpCompletionOption.ResponseHeadersRead, cancellationToken);

        if (httpResponseMessage.IsSuccessStatusCode)
        {
            using var stream = await httpResponseMessage.Content.ReadAsStreamAsync();
            using var streamReader = new StreamReader(stream);
            using var jsonTextReader = new JsonTextReader(streamReader);

            var settings = new JsonSerializerSettings
            {
                // Apply the converter for handling single item vs. array.
                Converters = { new SingleOrArrayListConverter(true) }, // Assuming SingleOrArrayListConverter is defined as in Solution 2
            };
            var jsonSerializer = JsonSerializer.Create(settings);
            return jsonSerializer.Deserialize<List<T>>(jsonTextReader);
        }
        return null; // Or throw an exception for non-success status codes.
    }
}

Solution 7: Handling Unknown JSON Structures with AnonymObjectConverter

When the JSON structure is largely unknown, but you know it contains an objectId and key-value pairs that could be strings or arrays, a custom converter like AnonymObjectConverter can map these into a dictionary and a list.

using Newtonsoft.Json;
using System;
using System.Collections.Generic;
using System.Text;

public class AnonymObject
{
    public AnonymObject()
    {
        Fields = new Dictionary<string, string>();
        ListValues = new List<string>();
    }

    public string ObjectId { get; set; }
    public Dictionary<string, string> Fields { get; set; }
    public List<string> ListValues { get; set; }
}

public class AnonymObjectConverter : JsonConverter
{
    public override bool CanConvert(Type objectType)
    {
        return objectType == typeof(AnonymObject);
    }

    public override object ReadJson(JsonReader reader, Type objectType, object existingValue, JsonSerializer serializer)
    {
        AnonymObject anonym = existingValue as AnonymObject ?? new AnonymObject();
        bool isProcessingList = false;
        StringBuilder currentListValues = new StringBuilder();

        while (reader.Read())
        {
            // Skip EndObject token if encountered prematurely.
            if (reader.TokenType == JsonToken.EndObject) continue;

            if (isProcessingList)
            {
                // Process values within an array.
                while (reader.TokenType != JsonToken.EndArray)
                {
                    // Append values, separated by comma and space.
                    currentListValues.Append(reader.Value?.ToString() ?? "" + ", ");
                    reader.Read();
                }
                // Add the collected list values to the object.
                anonym.ListValues.Add(currentListValues.ToString().TrimEnd(", ".ToCharArray()));
                isProcessingList = false;
                currentListValues.Clear(); // Reset for the next list.
                continue;
            }

            var currentKey = reader.Value?.ToString();
            if (string.IsNullOrEmpty(currentKey)) continue;

            switch (currentKey.ToLower())
            {
                case "objectid":
                    // Read the ObjectId value.
                    anonym.ObjectId = reader.ReadAsString();
                    break;
                default:
                    // Read the value associated with a field.
                    reader.Read(); // Move to the value token.
                    if (reader.TokenType == JsonToken.StartArray)
                    {
                        // If the value is an array, flag to process it.
                        isProcessingList = true;
                        // Use a placeholder or dummy value; the actual list is processed separately.
                        anonym.Fields.Add(currentKey, "PLACEHOLDER_FOR_LIST");
                    }
                    else
                    {
                        // Add the single value to the dictionary.
                        anonym.Fields.Add(currentKey, reader.Value?.ToString() ?? "");
                    }
                    break;
            }
        }
        return anonym;
    }

    public override bool CanWrite => false; // Writing is not supported.

    public override void WriteJson(JsonWriter writer, object value, JsonSerializer serializer)
    {
        throw new NotImplementedException("Writing not implemented.");
    }
}

In this setup, when an array is encountered for a field, a placeholder is added to the Fields dictionary, and the actual array values are collected into ListValues.

Solution 9: Alternative Deserialization Methods

Beyond custom converters, other methods can achieve similar results:

  • Helper Method with JArray.Select: Parse the JSON as a JArray and use LINQ’s Select to process each element, ensuring the category property is always an array before deserializing into your model.

    using Newtonsoft.Json;
using Newtonsoft.Json.Linq;
using System.Collections.Generic;
using System.Linq;

// Assume Item class with List<string> Category property is defined.
public Item GetItemFromToken(JToken itemToken)
{
    // Ensure 'category' is always an array.
    if (itemToken["category"]?.Type != JTokenType.Array)
    {
        itemToken["category"] = new JArray(itemToken["category"]);
    }
    return itemToken.ToObject<Item>();
}

List<Item> items = JArray.Parse(jsonPayload).Select(GetItemFromToken).ToList();

    public int Timestamp { get; set; }
    public string Event { get; set; }
    public List<string> Category { get; set; }

    [JsonConstructor]
    public Item(JToken categoryToken) // Constructor that accepts the potentially mixed type.
    {
        if (categoryToken.Type == JTokenType.Array)
            Category = categoryToken.ToObject<List<string>>();
        else
            Category = new List<string> { categoryToken.ToString() };
    }

    // Default constructor is still needed for deserialization when no problematic property is passed.
    public Item() { }
}

public class SystemTextStringToListConverter : System.Text.Json.Serialization.JsonConverter<List<string>>
{
    public override List<string> Read(ref Utf8JsonReader reader, Type typeToConvert, JsonSerializerOptions options)
    {
        using var jsonDoc = JsonDocument.ParseValue(ref reader);
        var element = jsonDoc.RootElement;

            ? new List<string> { element.GetString() }
            : System.Text.Json.JsonSerializer.Deserialize<List<string>>(element.GetRawText());

FAQs on Handling Single Item or Array JSON Properties in C#

Q What is the main challenge when deserializing certain JSON properties

ANS The main challenge arises when a JSON property can be represented as either a single value (like a string) or an array of values (like an array of strings), leading to potential deserialization errors if not handled correctly.

Q Which C# library is commonly used for JSON manipulation

ANS Newtonsoft.Json (Json.NET) is a very popular and powerful library for JSON manipulation in C#. System.Text.Json is the built-in, high-performance JSON library available in modern .NET versions.

Q How can I apply a custom JSON converter in C#

ANS You can apply a custom JSON converter by decorating the target property in your C# class with the [JsonConverter(typeof(YourConverterClass))] attribute. Alternatively, you can pass an instance of your converter to the JsonSerializerOptions when using System.Text.Json or to JsonConvert.DeserializeObject with Newtonsoft.Json.

Q Can a single JSON converter handle both single values and arrays

ANS Yes, a custom JsonConverter can be implemented to inspect the incoming JSON token’s type and deserialize it accordingly, whether it’s a single value or an array. The SingleOrArrayConverter<T> is a prime example of this.

Q What is the purpose of the CanConvert method in a JsonConverter

ANS The CanConvert method in a JsonConverter is used to determine if the converter instance can handle a specific .NET type. This allows for more granular control over which types a converter should process.

Q Is it possible to serialize a List with one item as a single JSON value

ANS Yes, by implementing the WriteJson method in your custom converter and checking the count of the list. If the list contains only one item, you can serialize that single item instead of the entire list.

Q How does System.Text.Json handle mixed types for a property

ANS Similar to Newtonsoft.Json, System.Text.Json allows you to create custom JsonConverter classes that inherit from System.Text.Json.Serialization.JsonConverter<T> to manage complex deserialization scenarios, including mixed types like single values or arrays.

Q What are some alternatives to using a custom JsonConverter

ANS Alternatives include using helper methods with LINQ to transform the JSON before deserialization, defining constructors with [JsonConstructor] to handle type variations, or leveraging JToken manipulation for more dynamic parsing.
