“Efficient C# Image Resizing Techniques: Best Practices and Code Examples”

When dealing with image manipulation in C#, resizing is a frequent requirement. Achieving high-quality results, maintaining aspect ratio, and optimizing performance are key considerations. This post explores various C# code solutions and techniques to accomplish image resizing effectively.

Solution 1: High-Quality Resizing with Detailed Graphics Settings

This approach leverages the System.Drawing.Graphics class to provide fine-grained control over the resizing process, ensuring superior visual output.

/// <summary>
/// Resizes an image to the specified width and height with high quality.
/// </summary>
/// <param name="image">The image to resize.</param>
/// <param name="width">The target width.</param>
/// <param name="height">The target height.</param>
/// <returns>The resized image.</returns>
public static Bitmap ResizeImageHighQuality(Image image, int width, int height)
{
    // Creates a destination rectangle defining the new image dimensions.
    var destRect = new Rectangle(0, 0, width, height);
    // Initializes a new Bitmap object with the specified width and height.
    var destImage = new Bitmap(width, height);

    // Preserves the original image's DPI settings for better quality.
    destImage.SetResolution(image.HorizontalResolution, image.VerticalResolution);

    // Utilizes a Graphics object for drawing operations on the destination image.
    using (var graphics = Graphics.FromImage(destImage))
    {
        // CompositingMode.SourceCopy ensures that the source pixels overwrite the destination pixels.
        graphics.CompositingMode = CompositingMode.SourceCopy;
        // CompositingQuality.HighQuality ensures the best possible blending of pixels.
        graphics.CompositingQuality = CompositingQuality.HighQuality;
        // InterpolationMode.HighQualityBicubic determines how intermediate pixel values are calculated, resulting in smoother scaling.
        graphics.InterpolationMode = InterpolationMode.HighQualityBicubic;
        // SmoothingMode.HighQuality applies antialiasing to lines and curves, improving edge clarity.
        graphics.SmoothingMode = SmoothingMode.HighQuality;
        // PixelOffsetMode.HighQuality ensures precise pixel positioning, which can enhance detail.
        graphics.PixelOffsetMode = PixelOffsetMode.HighQuality;

        // ImageAttributes can control various aspects of image drawing, like wrap modes.
        using (var wrapMode = new ImageAttributes())
        {
            // WrapMode.TileFlipXY mirrors the image at its edges, preventing a "ghosting" effect.
            // This is particularly useful for scaling when transparent pixels might otherwise bleed into the resized area.
            wrapMode.SetWrapMode(WrapMode.TileFlipXY);
            // Draws the original image onto the destination bitmap with the specified settings.
            graphics.DrawImage(image, destRect, 0, 0, image.Width, image.Height, GraphicsUnit.Pixel, wrapMode);
        }
    }

    return destImage;
}

Key Graphics Settings Explained:

  • wrapMode.SetWrapMode(WrapMode.TileFlipXY): Prevents artifacts by mirroring edge pixels, improving samples from areas outside the visible image boundary.
  • destImage.SetResolution(): Maintains the original DPI, which can be crucial for print quality or when reducing image dimensions.
  • graphics.CompositingMode: Controls how pixels blend. SourceCopy overwrites existing pixels.
  • graphics.CompositingQuality: Determines the rendering quality for layered images, with HighQuality offering the best results.
  • graphics.InterpolationMode: Affects how colors between pixels are calculated during scaling. HighQualityBicubic is generally preferred for sharp, smooth results.
  • graphics.SmoothingMode: Applies antialiasing to edges, making them appear smoother.
  • graphics.PixelOffsetMode: Influences rendering quality for pixel positioning.

Note: Maintaining the aspect ratio is left as an exercise for the caller of this function, as its primary goal is precise resizing to given dimensions. For guidance on handling image resizing pitfalls, refer to this article .

Solution 3: Resizing with Aspect Ratio and Centering (C#)

This solution provides logic to resize an image while considering its orientation (portrait vs. landscape) and centering it within the target dimensions, filling empty space with black.

/// <summary>
/// Resizes an image, maintaining aspect ratio and centering within target dimensions,
/// filling with black.
/// </summary>
/// <param name="newWidth">The target width.</param>
/// <param name="newHeight">The target height.</param>
/// <param name="stPhotoPath">The path to the image file.</param>
/// <returns>The resized image.</returns>
public Image ResizeImageWithCentering(int newWidth, int newHeight, string stPhotoPath)
{
    Image imgPhoto = Image.FromFile(stPhotoPath);

    int sourceWidth = imgPhoto.Width;
    int sourceHeight = imgPhoto.Height;

    // Adjust target dimensions if the source is taller than it is wide.
    if (sourceWidth < sourceHeight)
    {
        int buff = newWidth;
        newWidth = newHeight;
        newHeight = buff;
    }

    int sourceX = 0, sourceY = 0, destX = 0, destY = 0;
    float nPercent = 0, nPercentW = 0, nPercentH = 0;

    // Calculate scaling percentages based on target dimensions.
    nPercentW = ((float)newWidth / (float)sourceWidth);
    nPercentH = ((float)newHeight / (float)sourceHeight);

    // Determine the best scaling factor to fit the image without distortion.
    if (nPercentH < nPercentW)
    {
        nPercent = nPercentH;
        // Calculate horizontal offset to center the image.
        destX = System.Convert.ToInt16((newWidth - (sourceWidth * nPercent)) / 2);
    }
    else
    {
        nPercent = nPercentW;
        // Calculate vertical offset to center the image.
        destY = System.Convert.ToInt16((newHeight - (sourceHeight * nPercent)) / 2);
    }

    // Calculate the dimensions of the resized image portion.
    int destWidth = (int)(sourceWidth * nPercent);
    int destHeight = (int)(sourceHeight * nPercent);

    // Create a new Bitmap with the target dimensions and 24bppRgb format.
    Bitmap bmPhoto = new Bitmap(newWidth, newHeight, PixelFormat.Format24bppRgb);

    // Preserve original resolution.
    bmPhoto.SetResolution(imgPhoto.HorizontalResolution, imgPhoto.VerticalResolution);

    Graphics grPhoto = Graphics.FromImage(bmPhoto);
    // Fill the background with black.
    grPhoto.Clear(Color.Black);
    // Set high-quality interpolation for scaling.
    grPhoto.InterpolationMode = System.Drawing.Drawing2D.InterpolationMode.HighQualityBicubic;

    // Draw the scaled image onto the new bitmap.
    grPhoto.DrawImage(imgPhoto,
        new Rectangle(destX, destY, destWidth, destHeight),
        new Rectangle(sourceX, sourceY, sourceWidth, sourceHeight),
        GraphicsUnit.Pixel);

    grPhoto.Dispose(); // Clean up Graphics object.
    imgPhoto.Dispose(); // Clean up original image.
    return bmPhoto;
}

Solution 6: Basic Resizing with Graphics.DrawImage

A fundamental approach uses Graphics.DrawImage with specified target dimensions.

/// <summary>
/// Resizes an image to new dimensions.
/// </summary>
/// <param name="image">The source image.</param>
/// <param name="new_height">The target height.</param>
/// <param name="new_width">The target width.</param>
/// <returns>The resized image.</returns>
public static Image ResizeImageBasic(Image image, int new_height, int new_width)
{
    // Creates a new Bitmap for the output.
    Bitmap new_image = new Bitmap(new_width, new_height);
    Graphics g = Graphics.FromImage((Image)new_image);
    // Sets interpolation mode for scaling quality.
    g.InterpolationMode = InterpolationMode.High; // Note: Consider HighQualityBicubic for better results.
    // Draws the source image onto the new bitmap at the target dimensions.
    g.DrawImage(image, 0, 0, new_width, new_height);
    return new_image;
}

Solution 7: Resizing While Respecting Max Dimensions

This method resizes an image so that neither its width nor its height exceeds specified maximums, preserving the aspect ratio.

/// <summary>
/// Resizes an image to fit within specified maximum width and height, maintaining aspect ratio.
/// </summary>
/// <param name="img">The image object (assuming it has a property like 'Source.Width' etc.).</param>
/// <param name="maxWidth">The maximum allowed width.</param>
/// <param name="maxHeight">The maximum allowed height.</param>
private void ResizeImageWithMaxDimensions(dynamic img, double maxWidth, double maxHeight)
{
    double resizeWidth = img.Source.Width;
    double resizeHeight = img.Source.Height;

    // Calculate the aspect ratio.
    double aspect = resizeWidth / resizeHeight;

    // Adjust width if it exceeds the maximum.
    if (resizeWidth > maxWidth)
    {
        resizeWidth = maxWidth;
        resizeHeight = resizeWidth / aspect;
    }
    // Adjust height if it exceeds the maximum.
    if (resizeHeight > maxHeight)
    {
        aspect = resizeWidth / resizeHeight; // Recalculate aspect ratio based on new width.
        resizeHeight = maxHeight;
        resizeWidth = resizeHeight * aspect;
    }

    // Apply the new dimensions.
    img.Width = resizeWidth;
    img.Height = resizeHeight;
}

Solution 9: Resizing to Fit Landscape Destination Bounds

This solution is tailored for resizing an image to fit within a specified destination rectangle, prioritizing a landscape orientation for the output.

/// <summary>
/// Resizes a source image to fit within destination bounds, prioritizing landscape output.
/// </summary>
/// <param name="source">The source image.</param>
/// <param name="destinationBounds">The target rectangle for the resized image.</param>
/// <returns>The resized image.</returns>
public Image ResizeImageToLandscape(Image source, RectangleF destinationBounds)
{
    RectangleF sourceBounds = new RectangleF(0.0f, 0.0f, (float)source.Width, (float)source.Height);
    Image destinationImage = new Bitmap((int)destinationBounds.Width, (int)destinationBounds.Height);
    Graphics graph = Graphics.FromImage(destinationImage);
    graph.InterpolationMode = System.Drawing.Drawing2D.InterpolationMode.HighQualityBicubic;

    // Fill the destination with a white background.
    graph.FillRectangle(new SolidBrush(System.Drawing.Color.White), destinationBounds);

    float resizeRatio, sourceRatio;
    float scaleWidth, scaleHeight;

    sourceRatio = (float)source.Width / (float)source.Height;

    if (sourceRatio >= 1.0f) // Landscape source
    {
        resizeRatio = destinationBounds.Width / sourceBounds.Width;
        scaleWidth = destinationBounds.Width;
        scaleHeight = sourceBounds.Height * resizeRatio;
        float trimValue = destinationBounds.Height - scaleHeight;
        // Draw image centered vertically.
        graph.DrawImage(source, 0, (trimValue / 2), destinationBounds.Width, scaleHeight);
    }
    else // Portrait source
    {
        resizeRatio = destinationBounds.Height / sourceBounds.Height;
        scaleWidth = sourceBounds.Width * resizeRatio;
        scaleHeight = destinationBounds.Height;
        float trimValue = destinationBounds.Width - scaleWidth;
        // Draw image centered horizontally.
        graph.DrawImage(source, (trimValue / 2), 0, scaleWidth, destinationBounds.Height);
    }

    return destinationImage;
}

Solution 10: Flexible Resizing with Aspect Ratio and Center Crop Options

This function offers significant flexibility, allowing resizing from a file path with options to maintain aspect ratio and crop to the center.

/// <summary>
/// Resizes an image from a file path with options for aspect ratio and center cropping.
/// </summary>
/// <param name="OriginalFileLocation">Path to the source image.</param>
/// <param name="newHeight">Target height.</param>
/// <param name="newWidth">Target width.</param>
/// <param name="keepAspectRatio">Whether to maintain aspect ratio.</param>
/// <param name="getCenter">Whether to crop to the center.</param>
/// <returns>The resized image.</returns>
public Image ResizeImageFromFile(String OriginalFileLocation, int newHeight, int newWidth, Boolean keepAspectRatio, Boolean getCenter)
{
    int calculatedHeight = newHeight;
    System.Drawing.Image FullsizeImage = System.Drawing.Image.FromFile(OriginalFileLocation);

    // Rotate and then rotate back to ensure internal thumbnail data is not used.
    FullsizeImage.RotateFlip(System.Drawing.RotateFlipType.Rotate180FlipNone);
    FullsizeImage.RotateFlip(System.Drawing.RotateFlipType.Rotate180FlipNone);

    if (keepAspectRatio || getCenter)
    {
        int bmpY = 0;
        // Calculate resize factor.
        double resize = (double)FullsizeImage.Width / (double)newWidth;
        if (getCenter)
        {
            // Calculate the Y offset to crop the center.
            bmpY = (int)((FullsizeImage.Height - (newHeight * resize)) / 2);
            Rectangle section = new Rectangle(new Point(0, bmpY), new Size(FullsizeImage.Width, (int)(newHeight * resize)));
            Bitmap orImg = new Bitmap((Bitmap)FullsizeImage);
            FullsizeImage.Dispose(); // Release original image resource.
            using (Bitmap tempImg = new Bitmap(section.Width, section.Height))
            {
                Graphics cutImg = Graphics.FromImage(tempImg);
                // Crop the image section.
                cutImg.DrawImage(orImg, 0, 0, section, GraphicsUnit.Pixel);
                FullsizeImage = tempImg; // Use cropped image for further processing.
                orImg.Dispose();
                cutImg.Dispose();
                // Generate thumbnail from the cropped image.
                return FullsizeImage.GetThumbnailImage(newWidth, newHeight, null, IntPtr.Zero);
            }
        }
        else
        {
            // Adjust height to maintain aspect ratio.
            calculatedHeight = (int)(FullsizeImage.Height / resize);
        }
    }
    // Return the image resized to the given dimensions.
    return FullsizeImage.GetThumbnailImage(newWidth, calculatedHeight, null, IntPtr.Zero);
}

Solution 11: Creating Thumbnails with Ratio Calculation

This function generates a thumbnail by calculating the appropriate ratio to fit within maximum dimensions.

/// <summary>
/// Creates a thumbnail of an image, fitting within maximum dimensions.
/// </summary>
/// <param name="maxWidth">Maximum width for the thumbnail.</param>
/// <param name="maxHeight">Maximum height for the thumbnail.</param>
/// <param name="path">Path to the original image.</param>
/// <returns>Relative path to the saved thumbnail.</returns>
public string CreateThumbnail(int maxWidth, int maxHeight, string path)
{
    using (var image = System.Drawing.Image.FromFile(path))
    {
        // Calculate scaling ratios for both width and height.
        var ratioX = (double)maxWidth / image.Width;
        var ratioY = (double)maxHeight / image.Height;
        // Use the minimum ratio to ensure the image fits within both dimensions.
        var ratio = Math.Min(ratioX, ratioY);
        var newWidth = (int)(image.Width * ratio);
        var newHeight = (int)(image.Height * ratio);
        var newImage = new Bitmap(newWidth, newHeight);
        Graphics thumbGraph = Graphics.FromImage(newImage);

        // Set high-quality graphics rendering modes.
        thumbGraph.CompositingQuality = CompositingQuality.HighQuality;
        thumbGraph.SmoothingMode = SmoothingMode.HighQuality;

        // Draw the image onto the new bitmap at the calculated dimensions.
        thumbGraph.DrawImage(image, 0, 0, newWidth, newHeight);
        image.Dispose(); // Release original image resource.

        // Define the save path for the thumbnail.
        string fileRelativePath = "newsizeimages/" + maxWidth + Path.GetFileName(path);
        // Save the thumbnail.
        newImage.Save(Server.MapPath(fileRelativePath), newImage.RawFormat);
        return fileRelativePath;
    }
}

Solution 14: Calculating Resized Display Rectangle

This utility function calculates the appropriate SizeF for displaying an image within a given initial size, maintaining aspect ratio.

public static class ResizeImageCalculator
{
    /// <summary>
    /// Calculates the new size for displaying an image within a target area.
    /// </summary>
    /// <param name="sourceRectangle">The source image's dimensions.</param>
    /// <param name="targetSize">The initial display size.</param>
    /// <returns>The calculated display size.</returns>
    public static SizeF GetResizedRectangle(RectangleF sourceRectangle, SizeF targetSize)
    {
        float sourceWidth = sourceRectangle.Width;
        float sourceHeight = sourceRectangle.Height;
        float targetWidth = targetSize.Width;
        float targetHeight = targetSize.Height;
        float finalHeight, finalWidth;
        float sourceRatio = sourceWidth / sourceHeight;
        float targetRatio = targetWidth / targetHeight;

        if (sourceRatio >= targetRatio) // Source is wider or same aspect ratio as target
        {
            finalWidth = targetWidth;
            float ratio = sourceWidth / targetWidth;
            finalHeight = (sourceHeight / ratio);
        }
        else // Source is taller than target
        {
            finalHeight = targetHeight;
            float ratio = sourceHeight / targetHeight;
            finalWidth = (sourceWidth / ratio);
        }
        // Note: The original code returned finalHeight for both dimensions, this corrected version returns finalWidth, finalHeight.
        return new SizeF(finalWidth, finalHeight);
    }
}

Solution 15: Proportional Resizing and Saving

This method resizes an image to fit within specified width and height constraints, maintaining proportionality and saving the result.

namespace Infra.Files
{
    public static class ThumbnailGenerator
    {
        /// <summary>
        /// Resizes and saves an image to fit within width and height, keeping proportions.
        /// </summary>
        /// <param name="originalImagePath">Path to the source image.</param>
        /// <param name="thumbImagePath">Path to save the thumbnail.</param>
        /// <param name="newWidth">Target width.</param>
        /// <param name="newHeight">Target height.</param>
        public static void GenerateThumbnailImage(string originalImagePath, string thumbImagePath, int newWidth, int newHeight)
        {
            using (Bitmap srcBmp = new Bitmap(originalImagePath))
            {
                float ratio = 1;
                float minSize = Math.Min(newHeight, newHeight); // Note: This seems redundant, should likely be Math.Min(newWidth, newHeight) or similar.

                if (srcBmp.Width > srcBmp.Height)
                {
                    ratio = minSize / (float)srcBmp.Width;
                }
                else
                {
                    ratio = minSize / (float)srcBmp.Height;
                }

                SizeF newSize = new SizeF(srcBmp.Width * ratio, srcBmp.Height * ratio);
                Bitmap target = new Bitmap((int)newSize.Width, (int)newSize.Height);

                using (Graphics graphics = Graphics.FromImage(target))
                {
                    graphics.CompositingQuality = CompositingQuality.HighSpeed;
                    graphics.InterpolationMode = InterpolationMode.HighQualityBicubic;
                    graphics.CompositingMode = CompositingMode.SourceCopy;
                    graphics.DrawImage(srcBmp, 0, 0, newSize.Width, newSize.Height);

                    // Save the resized image.
                    target.Save(thumbImagePath);
                }
            }
        }
    }
}

Solution 16: Basic Image Formatting with Graphics.DrawImage

A simple function to resize an image to specific output dimensions.

// Example usage:
// System.Drawing.Image newImage = System.Drawing.Image.FromFile("SampImag.jpg");

/// <summary>
/// Formats an image to specified output dimensions.
/// </summary>
/// <param name="img">The source image.</param>
/// <param name="outputWidth">Target width.</param>
/// <param name="outputHeight">Target height.</param>
/// <returns>The formatted image, or original if an error occurs.</returns>
public static System.Drawing.Image FormatImage(System.Drawing.Image img, int outputWidth, int outputHeight)
{
    Bitmap outputImage = null;
    Graphics graphics = null;
    try
    {
        // Using PixelFormat.Format16bppRgb555 might limit color depth. Consider RGB formats.
        outputImage = new Bitmap(outputWidth, outputHeight, System.Drawing.Imaging.PixelFormat.Format16bppRgb555);
        graphics = Graphics.FromImage(outputImage);
        // Draws the image, stretching or shrinking to fit the output rectangle.
        graphics.DrawImage(img, new Rectangle(0, 0, outputWidth, outputHeight),
            new Rectangle(0, 0, img.Width, img.Height), GraphicsUnit.Pixel);

        return outputImage;
    }
    catch (Exception ex)
    {
        // Log the exception if necessary.
        return img; // Return original image on error.
    }
    finally
    {
        // Ensure resources are released.
        if (graphics != null) graphics.Dispose();
        if (outputImage != null) outputImage.Dispose();
    }
}

ANS: To maintain an image’s aspect ratio during resizing in C#, you need to calculate the scaling factor based on either the width or height, whichever is the limiting dimension. For instance, if you’re resizing to a maximum width, calculate the scaling factor based on that width and apply the same factor to the height. Solutions 3, 10, and 11 demonstrate methods that incorporate aspect ratio preservation. You can also explore libraries like ImageSharp or PhotoSauce for more advanced control. Q: What is the best interpolation mode for image resizing in C#

ANS: For the highest quality image resizing in C#, System.Drawing.Drawing2D.InterpolationMode.HighQualityBicubic is generally recommended. public static Bitmap ResizeImage(Image image, int width, int height)
{
    var destRect = new Rectangle(0, 0, width, height);
    var destImage = new Bitmap(width, height);

    destImage.SetResolution(image.HorizontalResolution, image.VerticalResolution);

    using (var graphics = Graphics.FromImage(destImage))
    {
        graphics.CompositingMode = CompositingMode.SourceCopy;
        graphics.CompositingQuality = CompositingQuality.HighQuality;
        graphics.InterpolationMode = InterpolationMode.HighQualityBicubic;
        graphics.SmoothingMode = SmoothingMode.HighQuality;
        graphics.PixelOffsetMode = PixelOffsetMode.HighQuality;

        using (var wrapMode = new ImageAttributes())
        {
            wrapMode.SetWrapMode(WrapMode.TileFlipXY);
            graphics.DrawImage(image, destRect, 0, 0, image.Width,image.Height, GraphicsUnit.Pixel, wrapMode);
        }
    }

    return destImage;
}
