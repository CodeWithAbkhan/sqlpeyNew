“How to Deserialize JSON to Dynamic Objects in C#”

Working with JSON data in C# often involves parsing it into structured objects. However, there are scenarios where using dynamic objects provides greater flexibility, especially when the JSON structure is not known beforehand or is subject to frequent changes. This guide explores various techniques and libraries to effectively deserialize JSON strings into dynamic objects in C#.

Methods for JSON to Dynamic Deserialization

Several approaches can be employed to achieve this, ranging from leveraging third-party libraries to utilizing built-in .NET functionalities.

Solution 1: Using Json.NET (Newtonsoft.Json)

The Newtonsoft.Json library, widely known as Json.NET, is a popular and robust choice for JSON serialization and deserialization in .NET. It offers straightforward ways to handle dynamic deserialization.

Using JsonConvert.DeserializeObject<dynamic>:

This is a common and concise method.

using Newtonsoft.Json;

// Your JSON string
string json = @"{
  'Name': 'Jon Smith',
  'Address': {
    'City': 'New York',
    'State': 'NY'
  },
  'Age': 42
}";

// Deserialize to dynamic
dynamic stuff = JsonConvert.DeserializeObject<dynamic>(json);

// Access properties dynamically
string name = stuff.Name; // "Jon Smith"
string city = stuff.Address.City; // "New York"
int age = stuff.Age; // 42

Console.WriteLine($"Name: {name}, City: {city}, Age: {age}");

Using JObject.Parse:

Another approach with Json.NET is to use JObject.Parse, which provides a flexible way to navigate and query JSON structures.

using Newtonsoft.Json.Linq;

string json = @"{
  'Name': 'Jon Smith',
  'Address': {
    'City': 'New York',
    'State': 'NY'
  },
  'Age': 42
}";

// Parse into JObject
dynamic stuff = JObject.Parse(json);

// Access properties
string name = stuff.Name;
string city = stuff.Address.City;
int age = stuff.Age;

Console.WriteLine($"Name: {name}, City: {city}, Age: {age}");

You can also deserialize directly to dynamic using JsonConvert.DeserializeObject<dynamic>.

string json = @"{ ""ID"":123,""Name"":""Jack"",""Numbers"":[1, 2, 3] }";
dynamic data = JsonConvert.DeserializeObject<dynamic>(json);

// Accessing properties
Console.WriteLine(data.ID); // 123
Console.WriteLine(data.Name); // "Jack"
Console.WriteLine(data.Numbers[0]); // 1

For unit tests, converting to ExpandoObject is quite useful:

using Newtonsoft.Json;
using System.Dynamic;
using System.Collections.Generic;

string json = @"{ ""ExpectedProperty"": ""value"" }";
var dict = JsonConvert.DeserializeObject<ExpandoObject>(json) as IDictionary<string, object>;

if (dict.ContainsKey("ExpectedProperty"))
{
    Console.WriteLine("Property found!");
}

When dealing with JSON that might have property names starting with ‘$’, JsonProperty attribute can be utilized with Newtonsoft.Json.

public class InvalidNameProperty
{
    [JsonProperty(PropertyName = "$id")]
    public string Id { get; set; }
    public string Message { get; set; }
}

Solution 2: Using System.Web.Script.Serialization.JavaScriptSerializer

The JavaScriptSerializer class, part of the System.Web.Extensions assembly, provides built-in capabilities for JSON deserialization.

using System.Web.Script.Serialization;

string json = @"{
  'Items':[
    { 'Name':'Apple', 'Price':12.3 },
    { 'Name':'Grape', 'Price':3.21 }
  ],
  'Date':'21/11/2010'
}";

var serializer = new JavaScriptSerializer();
// Register a custom converter if needed for more complex scenarios
// serializer.RegisterConverters(new[] { new DynamicJsonConverter() }); 

dynamic data = serializer.Deserialize(json, typeof(object));

// Accessing data
Console.WriteLine(data.Date); // "21/11/2010"
Console.WriteLine(data.Items.Count); // 2
Console.WriteLine(data.Items[0].Name); // "Apple"
Console.WriteLine(data.Items[0].Price); // 12.3 (as a decimal)

A custom converter can be implemented to deserialize into ExpandoObject for better compatibility with serialization back into JSON using Json.NET.

using System;
using System.Collections;
using System.Collections.Generic;
using System.Collections.ObjectModel;
using System.Dynamic;
using System.Web.Script.Serialization;

public static class DynamicJsonParser
{
    public static dynamic Parse(string json)
    {
        JavaScriptSerializer jss = new JavaScriptSerializer();
        jss.RegisterConverters(new JavaScriptConverter[] { new DynamicJsonConverter() });
        return jss.Deserialize(json, typeof(object));
    }

    class DynamicJsonConverter : JavaScriptConverter
    {
        public override object Deserialize(IDictionary<string, object> dictionary, Type type, JavaScriptSerializer serializer)
        {
            if (dictionary == null) throw new ArgumentNullException(nameof(dictionary));
            var result = ToExpando(dictionary);
            return type == typeof(object) ? result : null;
        }

        private static ExpandoObject ToExpando(IDictionary<string, object> dictionary)
        {
            var result = new ExpandoObject();
            var expandoDict = result as IDictionary<string, object>;
            foreach (var item in dictionary)
            {
                if (item.Value is IDictionary<string, object> valueAsDic)
                {
                    expandoDict.Add(item.Key, ToExpando(valueAsDic));
                }
                else if (item.Value is ArrayList arrayList && arrayList.Count > 0)
                {
                    expandoDict.Add(item.Key, ToExpando(arrayList));
                }
                else
                {
                    expandoDict.Add(item.Key, item.Value);
                }
            }
            return result;
        }

        private static ArrayList ToExpando(ArrayList obj)
        {
            var result = new ArrayList();
            foreach (var item in obj)
            {
                if (item is IDictionary<string, object> valueAsDic)
                {
                    result.Add(ToExpando(valueAsDic));
                }
                else if (item is ArrayList arrayList && arrayList.Count > 0)
                {
                    result.Add(ToExpando(arrayList));
                }
                else
                {
                    result.Add(item);
                }
            }
            return result;
        }

        public override IDictionary<string, object> Serialize(object obj, JavaScriptSerializer serializer)
        {
            throw new NotImplementedException();
        }

        public override IEnumerable<Type> SupportedTypes => new ReadOnlyCollection<Type>(new List<Type> { typeof(object) });
    }
}

You can then use it like:

string json = @"{ ""Name"": ""Jon Smith"", ""Address"": { ""City"": ""New York"", ""State"": ""NY"" }, ""Age"": 42 }";
dynamic value = DynamicJsonParser.Parse(json);
string name = value.Name; // "Jon Smith"
string city = value.Address.City; // "New York"

Solution 3: Using System.Text.Json (for .NET Core and later)

For .NET Core and later versions, System.Text.Json is the built-in, high-performance JSON serializer. It can be used with ExpandoObject for dynamic deserialization.

using System.Text.Json;
using System.Dynamic;

string jsonText = @"{ ""name"": ""Alice"", ""age"": 30 }";

// Deserialize to ExpandoObject
dynamic json = JsonSerializer.Deserialize<ExpandoObject>(jsonText);

Console.WriteLine(json.name); // "Alice"
Console.WriteLine(json.age);  // 30

This method is efficient and doesn’t require external dependencies for .NET Core applications. However, deep nesting might present challenges.

Solution 4: Using JsonFx

JsonFx is another library that facilitates JSON deserialization into dynamic types.

// Assuming JsonFx is installed via NuGet
// using JsonFx.Json;

string input = @"{ ""foo"": true, ""array"": [ 42, false, ""Hello!"", null ] }";

// Using JsonReader to read into a dynamic object
var reader = new JsonReader();
dynamic output = reader.Read(input);

// Accessing elements
Console.WriteLine(output.array[0]); // 42
Console.WriteLine(output.foo);       // true

Solution 6: Using System.Web.Helpers.Json

The System.Web.Helpers assembly, often found with ASP.NET Web Pages, includes a Json class with a Decode method that returns dynamic objects.

// Ensure you have a reference to System.Web.Helpers.dll
// using System.Web.Helpers;

string json = @"{ ""Members"": { ""NumberTen"": 10 } }";
dynamic data = Json.Decode(json);

// Access properties dynamically
var numberTen = data.Members.NumberTen;
Console.WriteLine(numberTen); // 10

// Access via indexer if property names require it
var anotherValue = data.Members["10"];

Solution 7: Custom Dynamic JSON Parser with ExpandoObject

For greater control and to serialize dynamic objects back into JSON using libraries like Json.NET, you can create a custom deserializer that leverages ExpandoObject.

using System.Collections.Generic;
using System.Collections.ObjectModel;
using System.Dynamic;

public static class CustomDynamicJson
{

    {
        JavaScriptSerializer jss = new JavaScriptSerializer();
        jss.RegisterConverters(new JavaScriptConverter[] { new DynamicJsonConverter() });
        return jss.Deserialize(json, typeof(object));
    }

    class DynamicJsonConverter : JavaScriptConverter
    {
        public override object Deserialize(IDictionary<string, object> dictionary, Type type, JavaScriptSerializer serializer)
        {
            if (dictionary == null) throw new ArgumentNullException(nameof(dictionary));
            return type == typeof(object) ? ToExpando(dictionary) : null;
        }

        private ExpandoObject ToExpando(IDictionary<string, object> dictionary)
        {
            var result = new ExpandoObject();
            var expandoDict = result as IDictionary<string, object>;
            foreach (var item in dictionary)
            {
                if (item.Value is IDictionary<string, object> valueAsDic) expandoDict.Add(item.Key, ToExpando(valueAsDic));
                else if (item.Value is ArrayList arrayList && arrayList.Count > 0) expandoDict.Add(item.Key, ToExpando(arrayList));
                else expandoDict.Add(item.Key, item.Value);
            }
            return result;
        }

        private ArrayList ToExpando(ArrayList obj)
        {
            var result = new ArrayList();
            foreach (var item in obj)
            {
                if (item is IDictionary<string, object> valueAsDic) result.Add(ToExpando(valueAsDic));
                else if (item is ArrayList arrayList && arrayList.Count > 0) result.Add(ToExpando(arrayList));
                else result.Add(item);
            }
            return result;
        }

        public override IEnumerable<Type> SupportedTypes => new ReadOnlyCollection<Type>(new List<Type> { typeof(object) });
    }
}

Solution 9: Using Cinchoo ETL

Cinchoo ETL is an open-source library that simplifies ETL processes, including parsing JSON into dynamic objects.

// Install Cinchoo ETL via NuGet: Install-Package Cinchoo.etl

string json = @"{
    ""key1"": [
        {
            ""action"": ""open"",
            ""timestamp"": ""2018-09-05 20:46:00"",
            ""ip"": ""66.102.6.98""
        }
    ]
}";

// Using ChoJSONReader to process the JSON
using (var p = ChoJSONReader.LoadText(json).WithJSONPath("$..key1"))
{
    foreach (var rec in p)
    {
        Console.WriteLine($"Action: {rec.action}");
        Console.WriteLine($"Timestamp: {rec.timestamp}");
        Console.WriteLine($"IP Address: {rec.ip}");
    }
}

Solution 10: Deserializing JSON arrays with JavaScriptSerializer

When your JSON is an array, JavaScriptSerializer can deserialize it into a dynamic object, which you can then iterate over.

using System.Web.Script.Serialization;

var jsonText = @"[
    { ""id"": 140, ""text"": ""xxx"" },
    { ""id"": 141, ""text"": ""xxxx"" }
]";

var jss = new JavaScriptSerializer();
dynamic objects = jss.Deserialize<dynamic>(jsonText);

foreach (var o in objects)
{
    Console.WriteLine($"ID: {o.id}");
}

FAQs on Deserializing JSON to Dynamic Objects in C#

FAQs on Deserializing JSON to Dynamic Objects in C#

Q: What is the most common way to deserialize JSON to a dynamic object in C#

ANS: The most common and recommended way is to use the Newtonsoft.Json library with JsonConvert.DeserializeObject<dynamic>(jsonString). It’s robust and widely adopted.

Q: Can I deserialize JSON to a dynamic object without using external libraries

ANS: Yes, you can use the built-in System.Web.Script.Serialization.JavaScriptSerializer. For .NET Core and later, System.Text.Json with ExpandoObject is also an option.

Q: How do I handle nested JSON objects when deserializing to dynamic

ANS: Most dynamic deserialization methods, including Newtonsoft.Json and JavaScriptSerializer, handle nested objects automatically. You can access nested properties using dot notation (e.g., data.Address.City).

Q: What if my JSON property names are not valid C# identifiers

ANS: Libraries like Newtonsoft.Json allow you to use the [JsonProperty(PropertyName = "$invalidName")] attribute to map invalid names to valid C# property names when deserializing into strongly-typed classes. For dynamic deserialization, accessing properties using indexers like data["$invalidName"] might be necessary if direct dot notation fails.

Q: How can I deserialize JSON to an ExpandoObject

ANS: You can deserialize to ExpandoObject using System.Text.Json in modern .NET, or by creating a custom converter for JavaScriptSerializer that maps JSON objects to ExpandoObject. Newtonsoft.Json also supports this with ExpandoObjectConverter.
