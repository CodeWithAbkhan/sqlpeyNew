“Interacting with File System Extended Properties in .NET Applications”

Accessing and modifying file system metadata, such as Author, Title, or File Version, requires interacting with the underlying Windows Shell infrastructure. Several methods exist, ranging from direct COM interop with Shell32.dll to leveraging helper libraries or modern asynchronous APIs.

Utilizing Shell32.dll via COM Interop (C# Example)

One direct approach involves referencing the Microsoft Shell Controls and Automation component via COM and using its objects (Shell, Folder, FolderItem2). This method is effective for listing all available properties or retrieving specific details by index.

Prerequisite: A reference to Microsoft Shell Controls and Automation must be added through the COM tab in the project’s References dialog.

The following C# code demonstrates iterating through all properties of items within a specific directory (C:\temp\testprop) to retrieve headers and then their corresponding values:

Alternative for Legacy/Server Environments (Dynamic Invocation)

If direct static referencing of Shell32 objects causes issues, particularly on older Windows Server versions where casting COM objects might fail (e.g., “Unable to cast COM object…”), dynamic invocation via Type.GetTypeFromProgID("Shell.Application") offers a more robust pathway for reading properties:

public static string GetSpecificPropertyValue(string filePath, string targetPropertyName)
{
    string value = string.Empty;
    string baseFolder = Path.GetDirectoryName(filePath);
    string fileName = Path.GetFileName(filePath);

    // Use dynamic invocation to load Shell object
    Type shellAppType = Type.GetTypeFromProgID("Shell.Application");
    Object shell = Activator.CreateInstance(shellAppType);
    
    // Use InvokeMember to call NameSpace and cast the result dynamically
    Shell32.Folder shellFolder = (Shell32.Folder)shellAppType.InvokeMember(
        "NameSpace", 
        System.Reflection.BindingFlags.InvokeMethod, 
        null, 
        shell, 
        new object[] { baseFolder });

    Shell32.FolderItem folderitem = shellFolder.ParseName(fileName);
    
    if (folderitem != null)
    {
        for (int i = 0; i < short.MaxValue; i++)
        {
            string property = shellFolder.GetDetailsOf(null, i);

            if (string.IsNullOrEmpty(property)) break;

            if (property == targetPropertyName)
            {
                value = shellFolder.GetDetailsOf(folderitem, i);
                break; // Found the requested property, exit loop
            }
        }
    }
    return value;
}
// Example usage: string fileVersion = GetSpecificPropertyValue(@"C:\path\to\file.exe", "File version");

Leveraging FolderItem.ExtendedProperty (Simpler Read Access)

For accessing named properties directly without relying on index numbers, the FolderItem2.ExtendedProperty method is available if the COM reference is set up correctly.

// Requires Shell32 reference and FolderItem2 interface
var folder = new Shell().NameSpace(folderPath);
foreach (FolderItem2 item in folder.Items())
{
    // Access properties directly by name (case sensitive or follow Windows standard)
    var company = item.ExtendedProperty("Company");
    var author = item.ExtendedProperty("Author");
    // Note: This might return null if the property index lookup fails internally.
}

If static reference is problematic, dynamic access can substitute:

// Dynamic invocation approach for ExtendedProperty
var shellAppType = Type.GetTypeFromProgID("Shell.Application");
dynamic shellApp = Activator.CreateInstance(shellAppType);
var folder = shellApp.NameSpace(folderPath);

foreach (var item in folder.Items())
{
    // Invokes item.ExtendedProperty("Company") dynamically
    var company = item.ExtendedProperty("Company");
    var author = item.ExtendedProperty("Author");
}

Using the WindowsAPICodePack for Read/Write Operations

The Microsoft WindowsAPICodePack provided a higher-level, managed solution for interacting with shell properties, although the project is often considered legacy or less actively maintained than modern alternatives. It requires adding NuGet packages: Microsoft.WindowsAPICodePack-Shell and Microsoft.WindowsAPICodePack-Core.

This package allows reading and writing specific, known properties directly:

using Microsoft.WindowsAPICodePack.Shell;
using Microsoft.WindowsAPICodePack.Shell.PropertySystem;

string filePath = @"C:\temp\document.docx";
var file = ShellFile.FromFilePath(filePath);

// Reading Properties
string[] oldAuthors = file.Properties.System.Author.Value;
string oldTitle = file.Properties.System.Title.Value;

// Writing Properties
file.Properties.System.Author.Value = new string[] { "New Writer One", "New Writer Two" };
file.Properties.System.Title.Value = "Updated Document Title";

// Alternate Write using PropertyWriter
using (ShellPropertyWriter propertyWriter = file.Properties.GetPropertyWriter())
{
    propertyWriter.WriteProperty(SystemProperties.System.Author, new string[] { "Writer X" });
}

Important Note on Writable Properties: Modification is only possible if the file type handler supports writing that specific metadata. If the property is read-only in the Windows Explorer properties pane, code modification will fail or be ignored. Always implement robust error handling.

public static string GetExtendedFileProperty(string filePath, string propertyName)
{
    string value = string.Empty;
    string baseFolder = Path.GetDirectoryName(filePath);
    string fileName = Path.GetFileName(filePath);

    //Method to load and execute the Shell object for Windows server 8 environment otherwise you get "Unable to cast COM object of type 'System.__ComObject' to interface type 'Shell32.Shell'"
    Type shellAppType = Type.GetTypeFromProgID("Shell.Application");
    Object shell = Activator.CreateInstance(shellAppType);
    Shell32.Folder shellFolder = (Shell32.Folder)shellAppType.InvokeMember("NameSpace", System.Reflection.BindingFlags.InvokeMethod, null, shell, new object[] { baseFolder });

    //Parsename will find the specific file I'm looking for in the Shell32.Folder object
    Shell32.FolderItem folderitem = shellFolder.ParseName(fileName);
    if (folderitem != null)
    {
        for (int i = 0; i &lt; short.MaxValue; i++)
        {
            //Get the property name for property index i
            string property = shellFolder.GetDetailsOf(null, i);

            //Will be empty when all possible properties has been looped through, break out of loop
            if (String.IsNullOrEmpty(property)) break;

            //Skip to next property if this is not the specified property
            if (property != propertyName) continue;    

            //Read value of property
            value = shellFolder.GetDetailsOf(folderitem, i);
        }
    }
    //returns string.Empty if no value was found for the specified property
    return value;
}
