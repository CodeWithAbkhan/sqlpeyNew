“C# String Encryption: Implementations and Best Practices”

When dealing with sensitive data in C#, robust string encryption and decryption are paramount. Several algorithms and approaches can be employed, each with its own considerations regarding security, performance, and implementation complexity. This post delves into various methods for achieving secure string manipulation, offering practical code examples and highlighting key aspects for effective implementation.

Core Concepts in String Encryption

Before diving into specific methods, it’s important to grasp fundamental cryptographic concepts:

  • Symmetric Encryption: Uses a single key for both encryption and decryption. Algorithms like AES and TripleDES fall into this category. They are generally faster than asymmetric methods.
  • Asymmetric Encryption: Employs a pair of keys: a public key for encryption and a private key for decryption. RSA is a common example, often used for key exchange or encrypting small amounts of data.
  • Key Derivation: Functions like Rfc2898DeriveBytes (PBKDF2) are crucial for generating cryptographic keys from passwords or passphrases, adding a layer of security against brute-force attacks by incorporating salts and iteration counts.
  • Initialization Vector (IV): A random or pseudorandom value used in block cipher modes (like CBC) to ensure that even identical plaintext blocks produce different ciphertext blocks, enhancing security against certain attacks.
  • Salt: Random data added to a password or passphrase before hashing or key derivation. It helps prevent rainbow table attacks and ensures unique keys are generated even for identical passwords.
  • Padding: Ensures that data being encrypted conforms to the block size requirements of the cipher. PKCS7 is a common and secure padding scheme.
  • Authenticated Encryption (AEAD): A more advanced approach that combines confidentiality (encryption) with integrity and authenticity (using MACs or GCM modes), ensuring data hasn’t been tampered with.

Diverse Encryption Implementations in C#

Here are several well-regarded approaches to string encryption in C#, ranging from built-in .NET functionalities to third-party libraries.

Solution 1: RijndaelManaged with Salt and IV Prepended

This solution, derived from original documentation, demonstrates a common pattern for symmetric encryption. It utilizes RijndaelManaged (an implementation of AES) and prepends the Initialization Vector (IV) to the encrypted output. A salt is used with Rfc2898DeriveBytes to derive the encryption key from a shared secret.

using System;
using System.IO;
using System.Security.Cryptography;
using System.Text;

public static class CryptoManaged
{
    // A salt is crucial for key derivation. An app-specific salt is generally okay for
    // password-based encryption if it's uncommon. For better security, consider generating
    // a unique salt per application or instance.
    private static readonly byte[] _salt = Encoding.ASCII.GetBytes("MyAppSecureSalt123"); // Ensure this is kept secret and is unique if possible.

    /// <summary>
    /// Encrypts a given string using AES. The string can be decrypted using DecryptStringAES.
    /// The sharedSecret parameters must match for successful decryption.
    /// </summary>
    /// <param name="plainText">The text to encrypt.</param>
    /// <param name="sharedSecret">A password used to generate a key for encryption.</param>
    /// <returns>The Base64 encoded encrypted string.</returns>
    public static string EncryptStringAES(string plainText, string sharedSecret)
    {
        if (string.IsNullOrEmpty(plainText))
            throw new ArgumentNullException(nameof(plainText));
        if (string.IsNullOrEmpty(sharedSecret))
            throw new ArgumentNullException(nameof(sharedSecret));

        byte[] encryptedBytes;
        RijndaelManaged aesAlg = null;

        try
        {
            // Derive the key from the shared secret and the salt.
            Rfc2898DeriveBytes key = new Rfc2898DeriveBytes(sharedSecret, _salt);

            // Initialize RijndaelManaged object for AES encryption.
            aesAlg = new RijndaelManaged();
            aesAlg.Key = key.GetBytes(aesAlg.KeySize / 8); // Set key based on AES key size.
            aesAlg.IV = key.GetBytes(aesAlg.BlockSize / 8); // Use derived IV from Rfc2898DeriveBytes for consistency.

            // Create an encryptor to perform the stream transformation.
            ICryptoTransform encryptor = aesAlg.CreateEncryptor(aesAlg.Key, aesAlg.IV);

            // Use MemoryStream for efficient byte manipulation.
            using (MemoryStream msEncrypt = new MemoryStream())
            {
                // Prepend the IV length and the IV itself to the encrypted data.
                // This is necessary for decryption.
                msEncrypt.Write(BitConverter.GetBytes(aesAlg.IV.Length), 0, sizeof(int));
                msEncrypt.Write(aesAlg.IV, 0, aesAlg.IV.Length);

                // Encrypt the data using CryptoStream.
                using (CryptoStream csEncrypt = new CryptoStream(msEncrypt, encryptor, CryptoStreamMode.Write))
                using (StreamWriter swEncrypt = new StreamWriter(csEncrypt))
                {
                    swEncrypt.Write(plainText);
                }
                encryptedBytes = msEncrypt.ToArray();
            }
        }
        finally
        {
            // Ensure the RijndaelManaged object is cleared securely.
            if (aesAlg != null)
                aesAlg.Clear();
        }

        // Convert the encrypted bytes to a Base64 string for easier transport.
        return Convert.ToBase64String(encryptedBytes);
    }

    /// <summary>
    /// Decrypts a given string. Assumes the string was encrypted using EncryptStringAES
    /// with an identical sharedSecret.
    /// </summary>
    /// <param name="cipherText">The Base64 encoded text to decrypt.</param>
    /// <param name="sharedSecret">The password used to generate the key for decryption.</param>
    /// <returns>The original decrypted string.</returns>
    public static string DecryptStringAES(string cipherText, string sharedSecret)
    {
        if (string.IsNullOrEmpty(cipherText))
            throw new ArgumentNullException(nameof(cipherText));
        if (string.IsNullOrEmpty(sharedSecret))
            throw new ArgumentNullException(nameof(sharedSecret));

        byte[] inputBytes;
        RijndaelManaged aesAlg = null;
        string decryptedText = null;

        try
        {
            // Derive the key using the same shared secret and salt.
            Rfc2898DeriveBytes key = new Rfc2898DeriveBytes(sharedSecret, _salt);

            // Convert the Base64 string back to bytes.
            inputBytes = Convert.FromBase64String(cipherText);

            using (MemoryStream msDecrypt = new MemoryStream(inputBytes))
            {
                // Initialize RijndaelManaged for decryption.
                aesAlg = new RijndaelManaged();
                aesAlg.Key = key.GetBytes(aesAlg.KeySize / 8);
                aesAlg.IV = ReadByteArray(msDecrypt); // Retrieve the IV from the stream.

                // Create a decryptor.
                ICryptoTransform decryptor = aesAlg.CreateDecryptor(aesAlg.Key, aesAlg.IV);

                // Decrypt the data.
                using (CryptoStream csDecrypt = new CryptoStream(msDecrypt, decryptor, CryptoStreamMode.Read))
                using (StreamReader srDecrypt = new StreamReader(csDecrypt))
                {
                    decryptedText = srDecrypt.ReadToEnd();
                }
            }
        }
        finally
        {
            // Securely clear the RijndaelManaged object.
            if (aesAlg != null)
                aesAlg.Clear();
        }

        return decryptedText;
    }

    /// <summary>
    /// Reads a byte array from a stream, preceded by its length.
    /// </summary>
    /// <param name="s">The stream to read from.</param>
    /// <returns>The byte array read from the stream.</returns>
    private static byte[] ReadByteArray(Stream s)
    {
        // Read the length of the byte array.
        byte[] rawLength = new byte[sizeof(int)];
        if (s.Read(rawLength, 0, rawLength.Length) != rawLength.Length)
        {
            throw new SystemException("Stream did not contain properly formatted byte array");
        }

        // Create a buffer for the array based on its length.
        byte[] buffer = new byte[BitConverter.ToInt32(rawLength, 0)];
        if (s.Read(buffer, 0, buffer.Length) != buffer.Length)
        {
            throw new SystemException("Did not read byte array properly");
        }
        return buffer;
    }
}

Solution 2: AES-GCM with Bouncy Castle

The Bouncy Castle Crypto API offers robust cryptographic primitives, including Authenticated Encryption with Associated Data (AEAD) modes like AES-GCM. This approach provides both confidentiality and integrity.

using System;
using System.IO;
using System.Text;
using Org.BouncyCastle.Crypto;
using Org.BouncyCastle.Crypto.Engines;
using Org.BouncyCastle.Crypto.Generators;
using Org.BouncyCastle.Crypto.Modes;
using Org.BouncyCastle.Crypto.Parameters;
using Org.BouncyCastle.Security;

public static class AesGcmCrypto
{
    private static readonly SecureRandom Random = new SecureRandom();

    // Key and Nonce sizes are critical for AES-GCM security.
    private const int KeyBitSize = 256; // AES-256
    private const int NonceBitSize = 128; // Recommended nonce size
    private const int MacBitSize = 128; // GCM tag size

    // Parameters for password-based key derivation.
    private const int SaltBitSize = 128;
    private const int Iterations = 10000;
    private const int MinPasswordLength = 12;

    /// <summary>
    /// Generates a new random key for AES-GCM encryption.
    /// </summary>
    /// <returns>A cryptographically secure random key.</returns>
    public static byte[] NewKey()
    {
        var key = new byte[KeyBitSize / 8];
        Random.NextBytes(key);
        return key;
    }

    /// <summary>
    /// Encrypts a UTF8 string using AES-GCM.
    /// </summary>
    /// <param name="secretMessage">The message to encrypt.</param>
    /// <param name="key">The encryption key.</param>
    /// <param name="nonSecretPayload">(Optional) Associated data that is authenticated but not encrypted.</param>
    /// <returns>Base64 encoded encrypted message.</returns>
    public static string SimpleEncrypt(string secretMessage, byte[] key, byte[] nonSecretPayload = null)
    {
        if (string.IsNullOrEmpty(secretMessage))
            throw new ArgumentException("Secret Message Required!", nameof(secretMessage));

        var plainTextBytes = Encoding.UTF8.GetBytes(secretMessage);
        var cipherTextBytes = EncryptData(plainTextBytes, key, nonSecretPayload);
        return Convert.ToBase64String(cipherTextBytes);
    }

    /// <summary>
    /// Decrypts a UTF8 message encrypted with AES-GCM.
    /// </summary>
    /// <param name="encryptedMessage">The Base64 encoded encrypted message.</param>
    /// <param name="key">The encryption key.</param>
    /// <param name="nonSecretPayloadLength">Length of the optional non-secret payload.</param>
    /// <returns>The original decrypted message, or null if decryption fails (e.g., bad MAC).</returns>
    public static string SimpleDecrypt(string encryptedMessage, byte[] key, int nonSecretPayloadLength = 0)
    {
        if (string.IsNullOrEmpty(encryptedMessage))
            throw new ArgumentException("Encrypted Message Required!", nameof(encryptedMessage));

        var cipherTextBytes = Convert.FromBase64String(encryptedMessage);
        var plainTextBytes = DecryptData(cipherTextBytes, key, nonSecretPayloadLength);
        return plainTextBytes == null ? null : Encoding.UTF8.GetString(plainTextBytes);
    }

    /// <summary>
    /// Encrypts a UTF8 string using AES-GCM with a key derived from a password (PBKDF2).
    /// </summary>
    /// <param name="secretMessage">The message to encrypt.</param>
    /// <param name="password">The password for key derivation.</param>
    /// <param name="nonSecretPayload">(Optional) Associated data.</param>
    /// <returns>Base64 encoded encrypted message.</returns>
    public static string SimpleEncryptWithPassword(string secretMessage, string password, byte[] nonSecretPayload = null)
    {
        if (string.IsNullOrEmpty(secretMessage))
            throw new ArgumentException("Secret Message Required!", nameof(secretMessage));
        if (string.IsNullOrWhiteSpace(password) || password.Length < MinPasswordLength)
            throw new ArgumentException($"Password must be at least {MinPasswordLength} characters.", nameof(password));

        var plainTextBytes = Encoding.UTF8.GetBytes(secretMessage);
        var cipherTextBytes = EncryptDataWithPassword(plainTextBytes, password, nonSecretPayload);
        return Convert.ToBase64String(cipherTextBytes);
    }

    /// <summary>
    /// Decrypts a UTF8 message encrypted with AES-GCM using a key derived from a password (PBKDF2).
    /// </summary>
    /// <param name="encryptedMessage">The Base64 encoded encrypted message.</param>
    /// <param name="password">The password for key derivation.</param>
    /// <param name="nonSecretPayloadLength">Length of the non-secret payload.</param>
    /// <returns>The original decrypted message, or null if decryption fails.</returns>
    public static string SimpleDecryptWithPassword(string encryptedMessage, string password, int nonSecretPayloadLength = 0)
    {
        if (string.IsNullOrEmpty(encryptedMessage))
            throw new ArgumentException("Encrypted Message Required!", nameof(encryptedMessage));
        if (string.IsNullOrWhiteSpace(password) || password.Length < MinPasswordLength)
            throw new ArgumentException($"Password must be at least {MinPasswordLength} characters.", nameof(password));

        var cipherTextBytes = Convert.FromBase64String(encryptedMessage);
        var plainTextBytes = DecryptDataWithPassword(cipherTextBytes, password, nonSecretPayloadLength);
        return plainTextBytes == null ? null : Encoding.UTF8.GetString(plainTextBytes);
    }

    /// <summary>
    /// Performs AES-GCM encryption on raw byte data.
    /// </summary>
    /// <param name="secretMessageBytes">The data to encrypt.</param>
    /// <param name="key">The encryption key.</param>
    /// <param name="nonSecretPayload">Optional associated data.</param>
    /// <returns>The combined ciphertext including nonce and MAC.</returns>
    private static byte[] EncryptData(byte[] secretMessageBytes, byte[] key, byte[] nonSecretPayload = null)
    {
        if (key == null || key.Length != KeyBitSize / 8)
            throw new ArgumentException($"Key must be {KeyBitSize} bits.", nameof(key));
        if (secretMessageBytes == null || secretMessageBytes.Length == 0)
            throw new ArgumentException("Secret Message Required!", nameof(secretMessageBytes));

        nonSecretPayload = nonSecretPayload ?? new byte[] { }; // Use empty array if null.

        // Generate a random nonce (number used once) for GCM mode.
        var nonce = new byte[NonceBitSize / 8];
        Random.NextBytes(nonce, 0, nonce.Length);

        var cipher = new GcmBlockCipher(new AesFastEngine());
        var parameters = new AeadParameters(new KeyParameter(key), MacBitSize, nonce, nonSecretPayload);
        cipher.Init(true, parameters); // Initialize for encryption.

        // Process the data to get ciphertext and authentication tag.
        var cipherText = new byte[cipher.GetOutputSize(secretMessageBytes.Length)];
        var len = cipher.ProcessBytes(secretMessageBytes, 0, secretMessageBytes.Length, cipherText, 0);
        cipher.DoFinal(cipherText, len);

        // Combine nonce, payload, and ciphertext into a single output.
        using (var combinedStream = new MemoryStream())
        using (var binaryWriter = new BinaryWriter(combinedStream))
        {
            binaryWriter.Write(nonSecretPayload); // Write associated data first.
            binaryWriter.Write(nonce);              // Then write the nonce.
            binaryWriter.Write(cipherText);         // Finally, write the ciphertext.
            return combinedStream.ToArray();
        }
    }

    /// <summary>
    /// Performs AES-GCM decryption on raw byte data.
    /// </summary>
    /// <param name="encryptedMessageBytes">The encrypted data.</param>
    /// <param name="key">The encryption key.</param>
    /// <param name="nonSecretPayloadLength">Length of the non-secret payload.</param>
    /// <returns>The decrypted data, or null if authentication fails.</returns>
    private static byte[] DecryptData(byte[] encryptedMessageBytes, byte[] key, int nonSecretPayloadLength = 0)
    {
        if (key == null || key.Length != KeyBitSize / 8)
            throw new ArgumentException($"Key must be {KeyBitSize} bits.", nameof(key));
        if (encryptedMessageBytes == null || encryptedMessageBytes.Length == 0)
            throw new ArgumentException("Encrypted Message Required!", nameof(encryptedMessageBytes));

        using (var cipherStream = new MemoryStream(encryptedMessageBytes))
        using (var cipherReader = new BinaryReader(cipherStream))
        {
            // Extract associated data, nonce, and ciphertext.
            var nonSecretPayload = cipherReader.ReadBytes(nonSecretPayloadLength);
            var nonce = cipherReader.ReadBytes(NonceBitSize / 8);

            var cipher = new GcmBlockCipher(new AesFastEngine());
            var parameters = new AeadParameters(new KeyParameter(key), MacBitSize, nonce, nonSecretPayload);
            cipher.Init(false, parameters); // Initialize for decryption.

            // Extract ciphertext and prepare for decryption.
            var cipherText = cipherReader.ReadBytes(encryptedMessageBytes.Length - nonSecretPayloadLength - nonce.Length);
            var plainText = new byte[cipher.GetOutputSize(cipherText.Length)];

            try
            {
                // Decrypt and verify the authentication tag.
                var len = cipher.ProcessBytes(cipherText, 0, cipherText.Length, plainText, 0);
                cipher.DoFinal(plainText, len);
            }
            catch (InvalidCipherTextException)
            {
                // Authentication failed; return null.
                return null;
            }

            return plainText;
        }
    }

    /// <summary>
    /// Encrypts data using AES-GCM with a key derived from a password.
    /// </summary>
    /// <param name="secretMessageBytes">The data to encrypt.</param>
    /// <param name="password">The password for key derivation.</param>
    /// <param name="nonSecretPayload">Optional associated data.</param>
    /// <returns>The combined ciphertext.</returns>
    private static byte[] EncryptDataWithPassword(byte[] secretMessageBytes, string password, byte[] nonSecretPayload = null)
    {
        var pkcs5Generator = new Pkcs5S2ParametersGenerator();

        // Generate a random salt for password-based key derivation.
        var salt = new byte[SaltBitSize / 8];
        Random.NextBytes(salt);

        // Initialize PBKDF2 with password, salt, and iteration count.
        pkcs5Generator.Init(
            PbeParametersGenerator.Pkcs5PasswordToBytes(password.ToCharArray()),
            salt,
            Iterations);

        // Derive the key.
        var keyParameter = (KeyParameter)pkcs5Generator.GenerateDerivedMacParameters(KeyBitSize);

        // Construct the full non-secret payload, including the salt.
        var payload = new byte[(SaltBitSize / 8) + (nonSecretPayload?.Length ?? 0)];
        Array.Copy(nonSecretPayload ?? Array.Empty<byte>(), payload, nonSecretPayload?.Length ?? 0);
        Array.Copy(salt, 0, payload, nonSecretPayload?.Length ?? 0, salt.Length);

        return EncryptData(secretMessageBytes, keyParameter.GetKey(), payload);
    }

    /// <summary>
    /// Decrypts data using AES-GCM with a key derived from a password.
    /// </summary>
    /// <param name="encryptedMessageBytes">The encrypted data.</param>
    /// <param name="password">The password for key derivation.</param>
    /// <param name="nonSecretPayloadLength">Length of the non-secret payload (excluding salt).</param>
    /// <returns>The decrypted data, or null if authentication fails.</returns>
    private static byte[] DecryptDataWithPassword(byte[] encryptedMessageBytes, string password, int nonSecretPayloadLength = 0)
    {
        // Extract the salt from the non-secret payload.
        var salt = new byte[SaltBitSize / 8];
        Array.Copy(encryptedMessageBytes, nonSecretPayloadLength, salt, 0, salt.Length);

        var pkcs5Generator = new Pkcs5S2ParametersGenerator();
        pkcs5Generator.Init(
            PbeParametersGenerator.Pkcs5PasswordToBytes(password.ToCharArray()),
            salt,
            Iterations);

        // Derive the key.
        var keyParameter = (KeyParameter)pkcs5Generator.GenerateDerivedMacParameters(KeyBitSize);

        // Calculate the total length of the payload to exclude during decryption.
        var payloadToExcludeLength = nonSecretPayloadLength + salt.Length;

        return DecryptData(encryptedMessageBytes, keyParameter.GetKey(), payloadToExcludeLength);
    }
}

Solution 3: RSA Encryption

RSA is an asymmetric encryption algorithm, suitable for encrypting small amounts of data or for key exchange. It’s important to note the limitation on plaintext size: KeySize - MinimumPadding.

using System;
using System.Text;
using System.Security.Cryptography;

public static class RsaCrypto
{
    /// <summary>
    /// Encrypts data using RSA. Be mindful of plaintext size limitations.
    /// </summary>
    /// <param name="plainText">The data to encrypt.</param>
    /// <param name="rsaKey">Your RSA public key parameters.</param>
    /// <returns>Base64 encoded encrypted data.</returns>
    public static string EncryptWithRsa(string plainText, RSAParameters rsaKey)
    {
        using (var rsaProvider = new RSACryptoServiceProvider())
        {
            rsaProvider.ImportParameters(rsaKey); // Load your RSA public key.

            // Encrypt the data. The 'true' parameter enables OAEP padding, which is recommended.
            var encryptedBytes = rsaProvider.Encrypt(Encoding.UTF8.GetBytes(plainText), true);
            return Convert.ToBase64String(encryptedBytes);
        }
    }

    /// <summary>
    /// Decrypts data using RSA. Requires the corresponding private key.
    /// </summary>
    /// <param name="cipherText">The Base64 encoded data to decrypt.</param>
    /// <param name="rsaKey">Your RSA private key parameters.</param>
    /// <returns>The original decrypted string.</returns>
    public static string DecryptWithRsa(string cipherText, RSAParameters rsaKey)
    {
        using (var rsaProvider = new RSACryptoServiceProvider())
        {
            rsaProvider.ImportParameters(rsaKey); // Load your RSA private key.

            var encryptedBytes = Convert.FromBase64String(cipherText);
            // Decrypt the data. Use the same padding scheme as encryption.
            var decryptedBytes = rsaProvider.Decrypt(encryptedBytes, true);
            return Encoding.UTF8.GetString(decryptedBytes);
        }
    }
}

Solution 4: ASP.NET MachineKey

For applications within the ASP.NET ecosystem, the System.Web.Security.MachineKey class provides built-in encryption and decryption capabilities. This is particularly useful for securing data like session state or view state.

using System;
using System.Text;
using System.Web; // Required for HttpServerUtility
using System.Web.Security; // Required for MachineKey

public static class MachineKeyCrypto
{
    private static readonly UTF8Encoding Encoder = new UTF8Encoding();

    /// <summary>
    /// Encrypts a string using MachineKey.Protect, suitable for ASP.NET applications.
    /// </summary>
    /// <param name="unencrypted">The string to encrypt.</param>
    /// <returns>URL-safe Base64 encoded encrypted string, or empty string on failure.</returns>
    public static string EncryptWithMachineKey(string unencrypted)
    {
        if (string.IsNullOrEmpty(unencrypted))
            return string.Empty;

        try
        {
            // MachineKey.Protect handles key generation and management based on configuration.
            var encryptedBytes = MachineKey.Protect(Encoder.GetBytes(unencrypted));

            if (encryptedBytes != null && encryptedBytes.Length > 0)
                // HttpServerUtility.UrlTokenEncode ensures the output is URL-safe.
                return HttpServerUtility.UrlTokenEncode(encryptedBytes);
        }
        catch (Exception)
        {
            // Log the exception for debugging.
            return string.Empty;
        }
        return string.Empty;
    }

    /// <summary>
    /// Decrypts a string encrypted with MachineKey.Unprotect.
    /// </summary>
    /// <param name="encrypted">The URL-safe Base64 encoded encrypted string.</param>
    /// <returns>The original decrypted string, or empty string on failure.</returns>
    public static string DecryptWithMachineKey(string encrypted)
    {
        if (string.IsNullOrEmpty(encrypted))
            return string.Empty;

        try
        {
            // Decode the URL-safe Base64 string.
            var bytes = HttpServerUtility.UrlTokenDecode(encrypted);
            if (bytes != null && bytes.Length > 0)
            {
                // MachineKey.Unprotect decrypts and verifies the data.
                var decryptedBytes = MachineKey.Unprotect(bytes);
                if (decryptedBytes != null && decryptedBytes.Length > 0)
                    return Encoder.GetString(decryptedBytes);
            }
        }
        catch (Exception)
        {
            // Log the exception for debugging.
            return string.Empty;
        }
        return string.Empty;
    }
}

Important Note: The MachineKey class relies on configuration settings typically found in web.config. For multi-server deployments or explicit control, you might need to configure encryption and decryption keys manually in the web.config file. Keys can be generated using IIS or online tools.

Solution 5: Bouncy Castle with Generic Encryptor (Twofish, AES, TripleDES)

Bouncy Castle is a versatile cryptographic library. This example shows a generic Encryptor class that can use various block ciphers (like Twofish, AES, TripleDES) and digest algorithms for HMAC.

using System;
using System.Security.Cryptography;
using System.Text;
using Org.BouncyCastle.Crypto;
using Org.BouncyCastle.Crypto.Macs;
using Org.BouncyCastle.Crypto.Modes;
using Org.BouncyCastle.Crypto.Paddings;
using Org.BouncyCastle.Crypto.Parameters;

public sealed class GenericEncryptor<TBlockCipher, TDigest> : IDisposable
    where TBlockCipher : IBlockCipher, new()
    where TDigest : IDigest, new()
{
    private readonly Encoding _encoding;
    private readonly IBlockCipher _blockCipher;
    private readonly BufferedBlockCipher _cipher;
    private readonly HMac _mac;
    private readonly byte[] _key;

    /// <summary>
    /// Initializes the encryptor with default PKCS7 padding.
    /// </summary>
    /// <param name="encoding">Text encoding to use.</param>
    /// <param name="key">The symmetric encryption key.</param>
    /// <param name="macKey">The key for HMAC generation.</param>
    public GenericEncryptor(Encoding encoding, byte[] key, byte[] macKey)
        : this(encoding, key, macKey, new Pkcs7Padding()) { }

    /// <summary>
    /// Initializes the encryptor with a specified padding scheme.
    /// </summary>
    /// <param name="encoding">Text encoding to use.</param>
    /// <param name="key">The symmetric encryption key.</param>
    /// <param name="macKey">The key for HMAC generation.</param>
    /// <param name="padding">The block cipher padding scheme.</param>
    public GenericEncryptor(Encoding encoding, byte[] key, byte[] macKey, IBlockCipherPadding padding)
    {
        _encoding = encoding;
        _key = key;
        Init(key, macKey, padding);
    }

    private void Init(byte[] key, byte[] macKey, IBlockCipherPadding padding)
    {
        // CBC mode is common, requires an IV.
        _blockCipher = new CbcBlockCipher(new TBlockCipher());
        // BufferedBlockCipher handles padding and final block processing.
        _cipher = new PaddedBufferedBlockCipher(_blockCipher, padding);
        // HMAC for data integrity.
        _mac = new HMac(new TDigest());
        _mac.Init(new KeyParameter(macKey));
    }

    /// <summary>
    /// Encrypts a string and returns the Base64 encoded result.
    /// </summary>
    /// <param name="plainText">The string to encrypt.</param>
    /// <returns>Base64 encoded encrypted string.</returns>
    public string Encrypt(string plainText) => Convert.ToBase64String(EncryptBytes(plainText));

    /// <summary>
    /// Encrypts a string to a byte array.
    /// </summary>
    /// <param name="plainText">The string to encrypt.</param>
    /// <returns>Encrypted data as a byte array.</returns>
    public byte[] EncryptBytes(string plainText)
    {
        byte[] plainBytes = _encoding.GetBytes(plainText);
        var iv = GenerateIV(); // Generate a random IV.

        // Encrypt the data using the cipher, IV, and key.
        var cipherBytes = BouncyCastleCrypto(true, plainBytes, new ParametersWithIV(new KeyParameter(_key), iv));
        byte[] messageWithIv = CombineArrays(iv, cipherBytes); // Prepend IV.

        // Calculate and append HMAC for integrity.
        _mac.Reset();
        _mac.BlockUpdate(messageWithIv, 0, messageWithIv.Length);
        byte[] digest = new byte[_mac.GetUnderlyingDigest().GetDigestSize()];
        _mac.DoFinal(digest, 0);

        return CombineArrays(digest, messageWithIv); // Combine HMAC, IV, and ciphertext.
    }

    /// <summary>
    /// Decrypts a byte array and returns the original string.
    /// </summary>
    /// <param name="encryptedBytes">The encrypted data.</param>
    /// <returns>Decrypted string.</returns>
    /// <exception cref="CryptoException">Thrown if HMAC validation fails.</exception>
    public string Decrypt(byte[] encryptedBytes) => _encoding.GetString(DecryptBytes(encryptedBytes));

    /// <summary>
    /// Decrypts a Base64 encoded string.
    /// </summary>
    /// <param name="cipherText">Base64 encoded encrypted string.</param>
    /// <returns>Decrypted string.</returns>
    /// <exception cref="CryptoException">Thrown if HMAC validation fails.</exception>
    public string Decrypt(string cipherText) => Decrypt(Convert.FromBase64String(cipherText));

    /// <summary>
    /// Decrypts a byte array to a byte array. Performs HMAC validation.
    /// </summary>
    /// <param name="encryptedBytes">The encrypted data.</param>
    /// <returns>Decrypted data as a byte array, or null if validation fails.</returns>
    public byte[] DecryptBytes(byte[] encryptedBytes)
    {
        // Extract HMAC, IV, and ciphertext.
        var digestSize = _mac.GetUnderlyingDigest().GetDigestSize();
        var digest = new byte[digestSize];
        var messageWithIv = new byte[encryptedBytes.Length - digestSize];

        // Split the input buffer.
        Array.Copy(encryptedBytes, 0, digest, 0, digestSize);
        Array.Copy(encryptedBytes, digestSize, messageWithIv, 0, messageWithIv.Length);

        // Validate HMAC.
        if (!IsValidHMac(digest, messageWithIv))
            throw new CryptoException("HMAC validation failed."); // Or return null, depending on desired behavior.

        // Extract IV and ciphertext.
        var ivSize = _blockCipher.GetBlockSize();
        var iv = new byte[ivSize];
        var cipherBytes = new byte[messageWithIv.Length - ivSize];
        Array.Copy(messageWithIv, 0, iv, 0, ivSize);
        Array.Copy(messageWithIv, ivSize, cipherBytes, 0, cipherBytes.Length);

        // Decrypt the data.
        return BouncyCastleCrypto(false, cipherBytes, new ParametersWithIV(new KeyParameter(_key), iv));
    }

    /// <summary>
    /// Validates the HMAC of the message.
    /// </summary>
    /// <param name="expectedDigest">The expected HMAC value.</param>
    /// <param name="messageData">The data to compute HMAC over.</param>
    /// <returns>True if the HMAC is valid, false otherwise.</returns>
    private bool IsValidHMac(byte[] expectedDigest, byte[] messageData)
    {
        _mac.Reset();
        _mac.BlockUpdate(messageData, 0, messageData.Length);
        byte[] computedDigest = new byte[_mac.GetUnderlyingDigest().GetDigestSize()];
        _mac.DoFinal(computedDigest, 0);

        return AreEqual(expectedDigest, computedDigest); // Use constant-time comparison.
    }

    /// <summary>
    /// Performs a constant-time byte array comparison to mitigate timing attacks.
    /// </summary>
    /// <param name="digest1">First byte array.</param>
    /// <param name="digest2">Second byte array.</param>
    /// <returns>True if arrays are equal, false otherwise.</returns>
    private static bool AreEqual(byte[] digest1, byte[] digest2)
    {
        if (digest1.Length != digest2.Length)
            return false;

        int result = 0;
        for (int i = 0; i < digest1.Length; i++)
            result |= digest1[i] ^ digest2[i]; // XOR each byte, sum up differences.

        return result == 0; // If result is 0, all bytes matched.
    }

    /// <summary>
    /// Encrypts or decrypts data using Bouncy Castle primitives.
    /// </summary>
    /// <param name="forEncrypt">True for encryption, false for decryption.</param>
    /// <param name="inputBytes">The input data.</param>
    /// <param name="parameters">Cipher parameters (key, IV, etc.).</param>
    /// <returns>The processed byte array.</returns>
    private byte[] BouncyCastleCrypto(bool forEncrypt, byte[] inputBytes, ICipherParameters parameters)
    {
        try
        {
            _cipher.Init(forEncrypt, parameters);
            return _cipher.DoFinal(inputBytes);
        }
        catch (CryptoException)
        {
            throw; // Re-throw cryptographic exceptions.
        }
    }

    /// <summary>
    /// Generates a cryptographically secure random Initialization Vector (IV).
    /// </summary>
    /// <returns>A random IV byte array.</returns>
    private byte[] GenerateIV()
    {
        using (var provider = new RNGCryptoServiceProvider())
        {
            byte[] iv = new byte[_blockCipher.GetBlockSize()];
            provider.GetBytes(iv);
            return iv;
        }
    }

    /// <summary>
    /// Combines two byte arrays into a single one.
    /// </summary>
    /// <param name="source1">First byte array.</param>
    /// <param name="source2">Second byte array.</param>
    /// <returns>A new byte array containing the concatenated data.</returns>
    private static byte[] CombineArrays(byte[] source1, byte[] source2)
    {
        byte[] result = new byte[source1.Length + source2.Length];
        Buffer.BlockCopy(source1, 0, result, 0, source1.Length);
        Buffer.BlockCopy(source2, 0, result, source1.Length, source2.Length);
        return result;
    }

    public void Dispose()
    {
        // Dispose of managed resources.
        _cipher?.Dispose();
        _mac?.Dispose();
    }
}

Solution 8: AES CBC with Salt and IV Prepended

This solution demonstrates a robust AES CBC implementation that generates a random salt and IV for each encryption, prepending them to the ciphertext. This ensures that each encryption is unique and requires the salt and IV for decryption.

using System;
using System.IO;
using System.Linq; // Required for LINQ methods
using System.Security.Cryptography;
using System.Text;

public static class RobustAesCrypto
{
    // Key size in bits. AES supports 128, 192, and 256 bits.
    private const int Keysize = 128;
    // Number of iterations for the password derivation function. Higher values increase security but slow down the process.
    private const int DerivationIterations = 1000;

    /// <summary>
    /// Encrypts plaintext using AES CBC mode, deriving keys from a passphrase.
    /// Includes salt and IV prepended to the ciphertext.
    /// </summary>
    /// <param name="plainText">The text to encrypt.</param>
    /// <param name="passPhrase">The passphrase used for key derivation.</param>
    /// <returns>Base64 encoded ciphertext including salt and IV.</returns>
    public static string Encrypt(string plainText, string passPhrase)
    {
        if (string.IsNullOrEmpty(plainText)) return string.Empty;

        // Generate random salt and IV. These are prepended to the ciphertext.
        var saltBytes = GenerateRandomBytes(Keysize / 8);
        var ivBytes = GenerateRandomBytes(Keysize / 8);
        var plainTextBytes = Encoding.UTF8.GetBytes(plainText);

        // Derive the key using PBKDF2.
        using (var passwordDeriveBytes = new Rfc2898DeriveBytes(passPhrase, saltBytes, DerivationIterations))
        {
            var keyBytes = passwordDeriveBytes.GetBytes(Keysize / 8);
            using (var symmetricKey = new RijndaelManaged())
            {
                symmetricKey.BlockSize = 128; // AES block size.
                symmetricKey.Mode = CipherMode.CBC; // CBC mode requires an IV.
                symmetricKey.Padding = PaddingMode.PKCS7; // Standard padding.

                using (var encryptor = symmetricKey.CreateEncryptor(keyBytes, ivBytes))
                using (var memoryStream = new MemoryStream())
                {
                    using (var cryptoStream = new CryptoStream(memoryStream, encryptor, CryptoStreamMode.Write))
                    {
                        cryptoStream.Write(plainTextBytes, 0, plainTextBytes.Length);
                        cryptoStream.FlushFinalBlock(); // Ensure all data is written.

                        // Combine salt, IV, and ciphertext into a single byte array.
                        var combinedBytes = saltBytes
                            .Concat(ivBytes)
                            .Concat(memoryStream.ToArray())
                            .ToArray();

                        return Convert.ToBase64String(combinedBytes);
                    }
                }
            }
        }
    }

    /// <summary>
    /// Decrypts ciphertext using AES CBC mode, using the provided passphrase.
    /// </summary>
    /// <param name="cipherText">Base64 encoded ciphertext including salt and IV.</param>
    /// <param name="passPhrase">The passphrase used for key derivation.</param>
    /// <returns>The original decrypted plaintext.</returns>
    public static string Decrypt(string cipherText, string passPhrase)
    {
        if (string.IsNullOrEmpty(cipherText)) return string.Empty;

        var cipherTextBytesWithSaltAndIv = Convert.FromBase64String(cipherText);

        // Extract salt, IV, and ciphertext.
        var saltBytes = cipherTextBytesWithSaltAndIv.Take(Keysize / 8).ToArray();
        var ivBytes = cipherTextBytesWithSaltAndIv.Skip(Keysize / 8).Take(Keysize / 8).ToArray();
        var cipherBytes = cipherTextBytesWithSaltAndIv.Skip((Keysize / 8) * 2).ToArray();

        // Derive the key using PBKDF2.
        using (var passwordDeriveBytes = new Rfc2898DeriveBytes(passPhrase, saltBytes, DerivationIterations))
        {
            var keyBytes = passwordDeriveBytes.GetBytes(Keysize / 8);
            using (var symmetricKey = new RijndaelManaged())
            {
                symmetricKey.BlockSize = 128;
                symmetricKey.Mode = CipherMode.CBC;
                symmetricKey.Padding = PaddingMode.PKCS7;

                using (var decryptor = symmetricKey.CreateDecryptor(keyBytes, ivBytes))
                using (var memoryStream = new MemoryStream(cipherBytes))
                using (var cryptoStream = new CryptoStream(memoryStream, decryptor, CryptoStreamMode.Read))
                {
                    // Read the decrypted bytes.
                    var plainTextBytes = new byte[cipherBytes.Length];
                    var decryptedByteCount = cryptoStream.Read(plainTextBytes, 0, plainTextBytes.Length);
                    return Encoding.UTF8.GetString(plainTextBytes, 0, decryptedByteCount);
                }
            }
        }
    }

    /// <summary>
    /// Generates a cryptographically secure random byte array.
    /// </summary>
    /// <param name="size">The number of bytes to generate.</param>
    /// <returns>A byte array of random bytes.</returns>
    private static byte[] GenerateRandomBytes(int size)
    {
        var randomBytes = new byte[size];
        using (var rngCsp = new RNGCryptoServiceProvider())
        {
            rngCsp.GetBytes(randomBytes);
        }
        return randomBytes;
    }
}

Solution 12: AES CBC with HMAC for Integrity

This example provides a foundational structure for AES CBC encryption, incorporating HMAC (Hash-based Message Authentication Code) using SHA256 to ensure data integrity. It also demonstrates deriving two keys (one for encryption, one for HMAC) from a password.

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Security.Cryptography;

public static class AesHmacCrypto
{
    // Key size in bits. AES supports 128, 192, 256 bits.
    private const int KeyBitSize = 128;
    // Number of iterations for PBKDF2.
    private const int KdfIterations = 10000;

    /// <summary>
    /// Encrypts plaintext bytes using AES CBC mode.
    /// </summary>
    /// <param name="key">The encryption key.</param>
    /// <param name="plaintextBytes">The plaintext as bytes.</param>
    /// <returns>IV prepended to ciphertext.</returns>
    private static byte[] EncryptBytes(byte[] key, byte[] plaintextBytes)
    {
        using (var cipher = new RijndaelManaged { Key = key, Mode = CipherMode.CBC, Padding = PaddingMode.PKCS7 })
        {
            // IV is generated by the cipher and prepended to the ciphertext.
            using (var encryptor = cipher.CreateEncryptor())
            {
                var ciphertext = encryptor.TransformFinalBlock(plaintextBytes, 0, plaintextBytes.Length);
                return cipher.IV.Concat(ciphertext).ToArray();
            }
        }
    }

    /// <summary>
    /// Decrypts AES CBC ciphertext.
    /// </summary>
    /// <param name="key">The encryption key.</param>
    /// <param name="packedBytes">IV prepended to ciphertext.</param>
    /// <returns>Decrypted plaintext bytes.</returns>
    private static byte[] DecryptBytes(byte[] key, byte[] packedBytes)
    {
        using (var cipher = new RijndaelManaged { Key = key, Mode = CipherMode.CBC, Padding = PaddingMode.PKCS7 })
        {
            int ivSize = cipher.BlockSize / 8; // IV size in bytes.
            var iv = packedBytes.Take(ivSize).ToArray(); // Extract IV.
            cipher.IV = iv;

            using (var decryptor = cipher.CreateDecryptor())
            {
                // Decrypt the ciphertext part.
                return decryptor.TransformFinalBlock(packedBytes, ivSize, packedBytes.Length - ivSize);
            }
        }
    }

    /// <summary>
    /// Appends an HMAC to the data for integrity.
    /// </summary>
    /// <param name="key">The HMAC key.</param>
    /// <param name="data">The data to authenticate.</param>
    /// <returns>Data with HMAC appended.</returns>
    private static byte[] AddMac(byte[] key, byte[] data)
    {
        using (var hmac = new HMACSHA256(key))
        {
            var macBytes = hmac.ComputeHash(data);
            return data.Concat(macBytes).ToArray(); // Append HMAC.
        }
    }

    /// <summary>
    /// Removes and verifies the HMAC from the data.
    /// </summary>
    /// <param name="key">The HMAC key.</param>
    /// <param name="dataWithMac">Data including the HMAC.</param>
    /// <returns>The original data without HMAC.</returns>
    /// <exception cref="Exception">Thrown if MAC verification fails.</exception>
    private static byte[] RemoveMac(byte[] key, byte[] dataWithMac)
    {
        using (var hmac = new HMACSHA256(key))
        {
            int macSize = hmac.HashSize / 8;
            var packedData = dataWithMac.Take(dataWithMac.Length - macSize).ToArray();
            var foundMac = dataWithMac.Skip(packedData.Length).ToArray();
            var computedMac = hmac.ComputeHash(packedData);

            if (!BadMac(foundMac, computedMac)) // Use constant-time comparison.
                throw new Exception("Bad MAC");

            return packedBytes;
        }
    }

    /// <summary>
    /// Compares two byte arrays in constant time to prevent timing attacks.
    /// </summary>
    /// <param name="foundMac">The found MAC.</param>
    /// <param name="computedMac">The computed MAC.</param>
    /// <returns>True if MACs are equal, false otherwise.</returns>
    private static bool BadMac(byte[] foundMac, byte[] computedMac)
    {
        int mismatch = 0;
        for (int i = 0; i < foundMac.Length; i++)
            mismatch |= foundMac[i] ^ computedMac[i]; // XOR each byte.
        return mismatch != 0;
    }

    /// <summary>
    /// Derives two 128-bit keys from a password using PBKDF2.
    /// </summary>
    /// <param name="password">The password.</param>
    /// <returns>A list containing two derived keys.</returns>
    private static List<byte[]> DeriveTwoKeys(string password)
    {
        // A fixed salt is used here for simplicity; ideally, a random salt should be generated and stored.
        var salt = new byte[] { 1, 2, 3, 4, 5, 6, 7, 8 }; // Example salt.
        var kdf = new Rfc2898DeriveBytes(password, salt, KdfIterations);

        var derivedBytes = kdf.GetBytes(32); // Get 32 bytes (256 bits) for two 128-bit keys.

        // Split into two keys.
        return new List<byte[]> { derivedBytes.Take(16).ToArray(), derivedBytes.Skip(16).ToArray() };
    }

    /// <summary>
    /// Encrypts a message string using AES CBC and HMAC, with keys derived from a password.
    /// </summary>
    /// <param name="password">The password for key derivation.</param>
    /// <param name="message">The message to encrypt.</param>
    /// <returns>Encrypted data with HMAC.</returns>
    public static byte[] EncryptString(string password, string message)
    {
        var keys = DeriveTwoKeys(password);
        var plaintextBytes = Encoding.UTF8.GetBytes(message);

        var encryptedWithIv = EncryptBytes(keys[0], plaintextBytes); // Encrypt with the first key.
        return AddMac(keys[1], encryptedWithIv); // Authenticate with the second key.
    }

    /// <summary>
    /// Decrypts AES CBC and HMAC encrypted data using a password.
    /// </summary>
    /// <param name="password">The password for key derivation.</param>
    /// <param name="secretBytes">The encrypted data with HMAC.</param>
    /// <returns>The original decrypted message string.</returns>
    public static string DecryptString(string password, byte[] secretBytes)
    {
        var keys = DeriveTwoKeys(password);

        var packedData = RemoveMac(keys[1], secretBytes); // Verify and remove HMAC.
        var plaintextBytes = DecryptBytes(keys[0], packedData); // Decrypt with the first key.

        return Encoding.UTF8.GetString(plaintextBytes);
    }
}

Cryptographic Best Practices

Regardless of the specific algorithm chosen, adhering to these best practices is crucial:

  1. Use Strong, Unique Keys: Avoid hardcoding keys directly in your source code. Securely store them, perhaps in configuration files that are themselves encrypted, or utilize secure key management systems. For password-based encryption, use strong, unique passwords and robust key derivation functions (like PBKDF2 with a unique salt and sufficient iterations).
  2. Employ Random IVs and Salts: Always use unique, cryptographically secure random values for Initialization Vectors (IVs) and salts. Prepend the IV to the ciphertext so it can be reused during decryption.
  3. Utilize Authenticated Encryption (AEAD): Modes like AES-GCM provide both confidentiality and integrity, protecting against tampering. If not using AEAD, implement a separate Message Authentication Code (MAC) like HMAC-SHA256.
  4. Choose Appropriate Padding: Use standard padding schemes like PKCS7. Ensure that decryption correctly handles padding removal.
  5. Keep Libraries Updated: Use well-maintained cryptographic libraries (like Bouncy Castle or up-to-date .NET Framework/Core) and apply security patches promptly.
  6. Avoid ECB Mode for Block Ciphers: Electronic Codebook (ECB) mode is generally insecure as identical plaintext blocks produce identical ciphertext blocks, revealing patterns. Prefer CBC, GCM, or other secure modes.
  7. Protect Against Timing Attacks: Implement comparisons of sensitive data (like keys or MACs) using constant-time comparison methods to prevent attackers from inferring information based on response times.

Conclusion

Selecting the right encryption method depends on your specific security requirements, performance needs, and the environment in which your application operates. For most general-purpose symmetric encryption tasks in C#, AES (particularly with GCM or CBC mode and proper key management) is a strong and recommended choice. Always prioritize secure key generation and storage, and stay informed about current cryptographic best practices.

FAQs on C# String Encryption

Q: What is the most secure way to encrypt strings in C#

ANS: The most secure method typically involves using AES in GCM mode (like AesGcm in Bouncy Castle or potentially newer .NET features) or AES CBC mode with a securely generated random IV, a strong key derived from a password using PBKDF2 with a unique salt and sufficient iterations, and a MAC for integrity. Avoid hardcoding keys or using weak encryption algorithms like DES or RC4.

Q: How do I generate a secure encryption key in C#

ANS: For symmetric encryption, use RijndaelManaged.KeySize or AES-GCM parameters to determine the key length (e.g., 256 bits). Generate keys using RNGCryptoServiceProvider or SecureRandom (from Bouncy Castle) for random keys, or derive them from strong passwords using Rfc2898DeriveBytes (PBKDF2) with a unique salt and high iteration count.

Q: Is it safe to encrypt data with ECB mode

ANS: No, ECB mode is generally considered insecure for most applications because it encrypts identical blocks of plaintext into identical blocks of ciphertext, revealing patterns in the data. It’s best to use modes like CBC, CTR, or GCM which incorporate an IV to randomize the output.

Q: What is the purpose of an Initialization Vector (IV)

ANS: An Initialization Vector (IV) is used in block cipher modes like CBC to ensure that even if the same plaintext is encrypted multiple times, the resulting ciphertext is different. It’s crucial for security, and it must be unique for each encryption operation using the same key. The IV does not need to be secret but must be unique.

Q: Can I use a password directly as an encryption key

ANS: It is highly discouraged to use a password directly as an encryption key. Passwords are often too short and predictable for direct cryptographic use. Use a key derivation function like Rfc2898DeriveBytes (PBKDF2) to securely transform a password into a strong cryptographic key, incorporating a salt and a high iteration count.

Q: What is the difference between encryption and hashing

ANS: Encryption is a two-way process used to protect data confidentiality; data can be encrypted and then decrypted back to its original form using a key. Hashing, on the other hand, is a one-way process used for data integrity and password storage. A hash function produces a fixed-size output (digest) from an input, and it’s computationally infeasible to reverse the process or find two inputs that produce the same hash output.

Q: How important is data integrity in encryption

ANS: Data integrity is critically important. Encryption alone only ensures confidentiality (preventing unauthorized access). Without integrity checks, an attacker could potentially modify the encrypted data in transit, and the recipient might unknowingly decrypt corrupted or malicious information. Authenticated encryption modes (like AES-GCM) or combining encryption with a MAC (like HMAC-SHA256) provide both confidentiality and integrity.

    /// &lt;summary&gt;
    /// Encrypt the given string using AES.  The string can be decrypted using 
    /// DecryptStringAES().  The sharedSecret parameters must match.
    /// &lt;/summary&gt;
    /// &lt;param name="plainText"&gt;The text to encrypt.&lt;/param&gt;
    /// &lt;param name="sharedSecret"&gt;A password used to generate a key for encryption.&lt;/param&gt;
    public static string EncryptStringAES(string plainText, string sharedSecret)
    {
        if (string.IsNullOrEmpty(plainText))
            throw new ArgumentNullException("plainText");
        if (string.IsNullOrEmpty(sharedSecret))
            throw new ArgumentNullException("sharedSecret");

        string outStr = null;                       // Encrypted string to return
        RijndaelManaged aesAlg = null;              // RijndaelManaged object used to encrypt the data.

        try
        {
            // generate the key from the shared secret and the salt
            Rfc2898DeriveBytes key = new Rfc2898DeriveBytes(sharedSecret, _salt);

            // Create a RijndaelManaged object
            aesAlg = new RijndaelManaged();
            aesAlg.Key = key.GetBytes(aesAlg.KeySize / 8);

            // Create a decryptor to perform the stream transform.
            ICryptoTransform encryptor = aesAlg.CreateEncryptor(aesAlg.Key, aesAlg.IV);

            // Create the streams used for encryption.
            using (MemoryStream msEncrypt = new MemoryStream())
            {
                // prepend the IV
                msEncrypt.Write(BitConverter.GetBytes(aesAlg.IV.Length), 0, sizeof(int));
                msEncrypt.Write(aesAlg.IV, 0, aesAlg.IV.Length);
                using (CryptoStream csEncrypt = new CryptoStream(msEncrypt, encryptor, CryptoStreamMode.Write))
                {
                    using (StreamWriter swEncrypt = new StreamWriter(csEncrypt))
                    {
                        //Write all data to the stream.
                        swEncrypt.Write(plainText);
                    }
                }
                outStr = Convert.ToBase64String(msEncrypt.ToArray());
            }
        }
        finally
        {
            // Clear the RijndaelManaged object.
            if (aesAlg != null)
                aesAlg.Clear();
        }

        // Return the encrypted bytes from the memory stream.
        return outStr;
    }

    /// &lt;summary&gt;
    /// Decrypt the given string.  Assumes the string was encrypted using 
    /// EncryptStringAES(), using an identical sharedSecret.
    /// &lt;/summary&gt;
    /// &lt;param name="cipherText"&gt;The text to decrypt.&lt;/param&gt;
    /// &lt;param name="sharedSecret"&gt;A password used to generate a key for decryption.&lt;/param&gt;
    public static string DecryptStringAES(string cipherText, string sharedSecret)
    {
        if (string.IsNullOrEmpty(cipherText))
            throw new ArgumentNullException("cipherText");
        if (string.IsNullOrEmpty(sharedSecret))
            throw new ArgumentNullException("sharedSecret");

        // Declare the RijndaelManaged object
        // used to decrypt the data.
        RijndaelManaged aesAlg = null;

        // Declare the string used to hold
        // the decrypted text.
        string plaintext = null;

        try
        {
            // generate the key from the shared secret and the salt
            Rfc2898DeriveBytes key = new Rfc2898DeriveBytes(sharedSecret, _salt);

            // Create the streams used for decryption.                
            byte[] bytes = Convert.FromBase64String(cipherText);
            using (MemoryStream msDecrypt = new MemoryStream(bytes))
            {
                // Create a RijndaelManaged object
                // with the specified key and IV.
                aesAlg = new RijndaelManaged();
                aesAlg.Key = key.GetBytes(aesAlg.KeySize / 8);
                // Get the initialization vector from the encrypted stream
                aesAlg.IV = ReadByteArray(msDecrypt);
                // Create a decrytor to perform the stream transform.
                ICryptoTransform decryptor = aesAlg.CreateDecryptor(aesAlg.Key, aesAlg.IV);
                using (CryptoStream csDecrypt = new CryptoStream(msDecrypt, decryptor, CryptoStreamMode.Read))
                {
                    using (StreamReader srDecrypt = new StreamReader(csDecrypt))

                        // Read the decrypted bytes from the decrypting stream
                        // and place them in a string.
                        plaintext = srDecrypt.ReadToEnd();
                }
            }
        }
        finally
        {
            // Clear the RijndaelManaged object.
            if (aesAlg != null)
                aesAlg.Clear();
        }

        return plaintext;
    }

    private static byte[] ReadByteArray(Stream s)
    {
        byte[] rawLength = new byte[sizeof(int)];
        if (s.Read(rawLength, 0, rawLength.Length) != rawLength.Length)
        {
            throw new SystemException("Stream did not contain properly formatted byte array");
        }

        byte[] buffer = new byte[BitConverter.ToInt32(rawLength, 0)];
        if (s.Read(buffer, 0, buffer.Length) != buffer.Length)
        {
            throw new SystemException("Did not read byte array properly");
        }

        return buffer;
    }
