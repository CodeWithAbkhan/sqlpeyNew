“C# Enum to String JSON Serialization Strategies with Newtonsoft and System.Text.Json”

A frequent requirement in modern API development is ensuring that C# enumeration values serialize to their string names (e.g., “Male”) in JSON output rather than their underlying integer values (e.g., 0). This requirement often arises when interfacing with JavaScript clients or external systems that expect descriptive string representations.

What methods exist to achieve this string serialization for enums using popular .NET JSON serializers like Newtonsoft.Json and the modern System.Text.Json?

Approaches Utilizing Newtonsoft.Json

When working with the ubiquitous Newtonsoft.Json library, several avenues allow you to dictate that enums appear as strings in the resulting JSON payload.

1. Direct Property Decoration with JsonConverter

Applying the [JsonConverter(typeof(StringEnumConverter))] attribute directly to the enum property offers precise control over individual serialization instances.

Example Implementation:

using Newtonsoft.Json;
using Newtonsoft.Json.Converters;

public enum GenderValue
{
    Male,
    Female
}

public class UserProfile
{
    public int UserId { get; set; }

    [JsonConverter(typeof(StringEnumConverter))]
    public GenderValue Gender { get; set; } // Serializes as "Male" or "Female"
}

Alternative: Decoration can also be placed directly onto the enum definition to enforce string serialization universally for that type.

[JsonConverter(typeof(StringEnumConverter))]  
public enum GenderValue { Male, Female }

2. Global Configuration for All Serializations

To avoid decorating every single enum property, you can register the StringEnumConverter globally.

A. Via JsonSerializerSettings Instance

You can instantiate JsonSerializerSettings and explicitly add the converter before serializing an object. This scope controls the serialization process initiated with these settings.

using Newtonsoft.Json;
using Newtonsoft.Json.Converters;

// Alternative serialization method specific to this operation
var myObjectInstance = new { /* ... data ... */ };

string serializedData = JsonConvert.SerializeObject(
    myObjectInstance, 
    new JsonSerializerSettings
    {
        Converters = new List<JsonConverter> { new StringEnumConverter() }
    }
);
// This method provides serialization control without altering the model or global settings.

B. Setting Default Settings (Application Start)

For ASP.NET applications (like older Web API setups), you might configure this in the Application_Start event (e.g., Global.asax):

// Global setup often done in Application_Start or Startup configuration
JsonConvert.DefaultSettings = () =>
{
    var settings = new JsonSerializerSettings();
    // Configure casing if needed, e.g., CamelCaseText
    settings.Converters.Add(new StringEnumConverter { CamelCaseText = true }); 
    return settings;
};

C. ASP.NET Core Configuration

In modern ASP.NET Core projects, global configuration is often managed within Startup.cs or Program.cs:

// In Startup.cs ConfigureServices method for MVC configuration
public void ConfigureServices(IServiceCollection services)
{
    services.AddMvc().AddJsonOptions(options =>
    {
        options.SerializerSettings.Converters.Add(new Newtonsoft.Json.Converters.StringEnumConverter());
    });
}

Or, in later versions using AddNewtonsoftJson:

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllers()
.AddNewtonsoftJson(opt =>
{
    opt.SerializerSettings.Converters.Add(new Newtonsoft.Json.Converters.StringEnumConverter());
});

3. Customizing Enum String Values with [EnumMember]

If you need the JSON string to be specific text that differs from the C# enum member name (e.g., serializing EuropeLondon to "Europe/London"), combine StringEnumConverter with the [EnumMember(Value = "...")] attribute.

using System.Runtime.Serialization;
using Newtonsoft.Json;
using Newtonsoft.Json.Converters;

public enum TimeZoneEnum
{
    [EnumMember(Value = "Europe/London")] 
    EuropeLondon,

    [EnumMember(Value = "US/Alaska")] 
    USAlaska
}

// Apply the standard StringEnumConverter to use the EnumMember values
[JsonConverter(typeof(StringEnumConverter))]
public TimeZoneEnum CurrentZone { get; set; } 
// Serializes as "Europe/London" if CurrentZone is TimeZoneEnum.EuropeLondon

4. Custom Converter for DescriptionAttribute Support

For scenarios requiring serialization based on the [Description] attribute rather than the member name or [EnumMember], a custom Newtonsoft.Json.JsonConverter implementation is necessary to inspect attributes during writing.

(See Solution 17 in the source content for the implementation details of CustomStringEnumConverter)

Approaches Utilizing System.Text.Json (Built-in .NET Core/.NET 5+)

For projects using the default .NET JSON serializer, the mechanism is similar but utilizes the System.Text.Json.Serialization namespace.

1. Attribute Decoration with JsonStringEnumConverter

The built-in serializer supports attribute decoration on properties or the enum itself using [JsonConverter(typeof(JsonStringEnumConverter))].

using System.Text.Json.Serialization;

[JsonConverter(typeof(JsonStringEnumConverter))] 
public enum DeviceStatus { Online, Offline, Maintenance }

public class Device
{
    public int DeviceId { get; set; }
    [JsonConverter(typeof(JsonStringEnumConverter))]
    public DeviceStatus Status { get; set; } // Serializes as string name
}

2. Global Configuration in ASP.NET Core

When configuring services, you add the converter to the JsonSerializerOptions associated with the JSON formatters:

// In ConfigureServices or Program.cs setup
public void ConfigureServices(IServiceCollection services)
{
    services
        .AddControllers()
        .AddJsonOptions(options => 
           options.JsonSerializerOptions.Converters.Add(new JsonStringEnumConverter())
        );
}

Alternative Strategy: Manual Projection

If modifying the model or globally configuring the serializer is undesirable, a straightforward alternative is projecting the enum into a separate string property during serialization. This works irrespective of the underlying serializer used.

Example using Manual Projection:

using System.Text.Json.Serialization; // Or Newtonsoft equivalent

public enum DataState { Active, Pending, Archived }

public class DataRecord
{
    public int Id { get; set; }
    public DataState State { get; set; }

    // The property exposed for serialization, containing the string name
    [JsonIgnore] // Prevent the raw enum from serializing numerically (if using System.Text.Json)
    public string StateString => State.ToString(); 
}

Note: If using Newtonsoft, you would use [JsonIgnore] on the actual enum property and expose the string property, or use [ScriptIgnore] if working with JavaScriptSerializer.

If the goal is only serialization (not deserialization back to enum), this projection strategy is robust. If deserialization is needed, the projection property must handle parsing the incoming string back to the enum value (see Solution 10 for a similar pattern using DataMember).

Handling Complex Scenarios: Bitwise Enums and Safe Deserialization

For enums utilizing bitwise flags where integer values are complex sums (Solution 16), or where clients might send unknown string values during deserialization (which causes exceptions with standard converters), custom solutions are required:

  1. Bitwise Enums: Project the enum into an anonymous type containing both the string name and the explicit integer value on the server side before serialization (Solution 16).
  2. Future-Proofing Deserialization: Implement a custom StringEnumConverter subclass (like SafeEnumConverter in Solution 25) that attempts string conversion but falls back to a defined default value if the incoming JSON string is not recognized, preventing deserialization failure.

FAQs on CSharp Enum to String JSON Serialization Strategies

Q: How do I make C# enums always serialize as strings using NewtonsoftJson

ANS: Apply the [JsonConverter(typeof(StringEnumConverter))] attribute to the enum definition or the property, or register StringEnumConverter globally within your JsonSerializerSettings.

Q: Is there a way to use SystemTextJson to serialize enums as strings

ANS: Yes, use the [JsonConverter(typeof(JsonStringEnumConverter))] attribute on the enum or property, or add new JsonStringEnumConverter() to the JsonSerializerOptions.Converters collection when configuring AddJsonOptions in ASP.NET Core.

Q: What attribute lets me control the exact string output for an enum member

ANS: Use the [EnumMember(Value = "DesiredString")] attribute on the enum member and ensure you are using a serializer converter (like StringEnumConverter) configured to read this value during serialization.

Q: Can I serialize enums as strings without modifying my model class

ANS: Yes, you can pass new JsonSerializerSettings { Converters = { new StringEnumConverter() } } directly to the JsonConvert.SerializeObject call, applying the string conversion dynamically only for that specific serialization operation.

Q: What if the StringEnumConverter throws an error on unknown enum strings during deserialization

ANS: Implement a custom converter, such as a SafeEnumConverter, which inherits from StringEnumConverter and overrides ReadJson to catch the exception and return a predefined default enum value instead of failing the entire deserialization process.
