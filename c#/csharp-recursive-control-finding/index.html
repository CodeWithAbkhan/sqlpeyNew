“C# How to Recursively Find Controls of Specific Type”

When developing Windows Forms applications in C#, a common requirement involves iterating through a form’s control hierarchy to find all instances of a specific control type, such as TextBox, Button, or CheckBox. This often involves searching through nested containers like GroupBox or Panel controls. Effectively traversing this structure requires a recursive approach.

Here are several methods that accomplish this task, leveraging C# features like LINQ, extension methods, and recursion.

Solution 1: Recursive Control Search with LINQ

This approach utilizes LINQ and recursion to efficiently find all controls of a specified type. It iterates through a control’s direct children and then recursively calls itself for any child controls that also have children.

public static IEnumerable<Control> GetAll(Control control, Type type)
{
    var controls = control.Controls.Cast<Control>();

    return controls.SelectMany(ctrl => GetAll(ctrl, type))
                   .Concat(controls)
                   .Where(c => c.GetType() == type);
}

To test this, you can call it within the form’s Load event:

private void Form1_Load(object sender, EventArgs e)
{
    var textboxes = GetAll(this, typeof(TextBox));
    MessageBox.Show("Total TextBoxes: " + textboxes.Count());
}

Solution 2: Recursive Control Search with LINQ (Alternative)

Another variation using LINQ and recursion, this method collects controls into a List<Control> and then recursively populates it.

List<Control> ControlList = new List<Control>();
private void GetAllControls(Control container)
{
    foreach (Control c in container.Controls)
    {
        GetAllControls(c); // Recursive call
        if (c is TextBox) ControlList.Add(c);
    }
}

A more refined version that returns a collection:

private IEnumerable<Control> GetAllTextBoxControls(Control container)
{
    List<Control> controlList = new List<Control>();
    foreach (Control c in container.Controls)
    {
        controlList.AddRange(GetAllTextBoxControls(c)); // Recursive call
        if (c is TextBox)
            controlList.Add(c);
    }
    return controlList;
}

Solution 3: Recursive Control Search for Private Variables

This method enhances the recursive approach to also find private controls.

private List<Control> GetAllControls(Control container, List<Control> list)
{
    foreach (Control c in container.Controls)
    {
        if (c is TextBox) list.Add(c);
        if (c.Controls.Count > 0)
            list = GetAllControls(c, list); // Recursive call
    }
    return list;
}

// Overload for initial call
private List<Control> GetAllControls(Control container)
{
    return GetAllControls(container, new List<Control>());
}

Usage:

private void Test()
{
     List<Control> allTextboxes = GetAllControls(this);
}

Solution 4: Extension Method with LINQ

This provides a reusable extension method that simplifies the process of finding controls of a specific type, correctly handling inheritance.

public static class ControlExtensions
{
    public static IEnumerable<T> FindAllChildrenByType<T>(this Control control) where T : Control
    {
        IEnumerable<Control> controls = control.Controls.Cast<Control>();
        return controls
            .OfType<T>()
            .Concat<T>(controls.SelectMany<Control, T>(ctrl => FindAllChildrenByType<T>(ctrl)));
    }
}

Usage:

// Find all CheckBox controls within tableLayoutPanel1
var checkBoxes = tableLayoutPanel1.FindAllChildrenByType<CheckBox>();
foreach (var checkBox in checkBoxes)
{
    checkBox.Checked = false;
}

Solution 5: LINQ Query for Specific Controls

A straightforward LINQ query can select specific control types directly from the Controls collection.

var textBoxes = from Control ctrl in this.Controls where ctrl is TextBox select ctrl;

Or using lambda expressions:

IEnumerable<Control> textboxes = this.Controls.Cast<Control>().Where(c => c is TextBox);

Solution 6: Recursive Control Traversal for Actions

This method recursively traverses controls to perform an action, such as changing the ForeColor of Label controls.

internal static void ChangeControlColour(Control parentControl, Color color)
{
    foreach (Control c in parentControl.Controls)
    {
        if (c.HasChildren)
        {
            ChangeControlColour(c, color); // Recursive call
        }
        else if (c is Label)
        {
            Label lbl = (Label)c;
            lbl.ForeColor = color;
        }
    }
}

Solution 7: Generic Extension Method for Control Collection

This generic extension method collects controls of a specified type, including those in nested containers.

public static class Utilities
{
    public static List<T> GetAllControls<T>(this Control container) where T : Control
    {
        List<T> controls = new List<T>();
        if (container.Controls.Count > 0)
        {
            controls.AddRange(container.Controls.OfType<T>());
            foreach (Control c in container.Controls)
            {
                controls.AddRange(c.GetAllControls<T>()); // Recursive call
            }
        }
        return controls;
    }
}

Usage:

// Get all TextBox controls from myControl
List<TextBox> textboxes = myControl.GetAllControls<TextBox>();

Solution 8: Generic Recursive Control Finder

This method uses generics and recursion to return controls of a specified type.

public IEnumerable<T> FindControls<T>(Control control) where T : Control
{
    var controls = control.Controls.Cast<Control>();

    return controls.SelectMany(ctrl => FindControls<T>(ctrl))
                   .Concat(controls)
                   .Where(c => c.GetType() == typeof(T)).Cast<T>();
}

Usage:

var textboxes = FindControls<TextBox>(this);
MessageBox.Show("Total TextBoxes: " + textboxes.Count());

Solution 9: VB.NET Recursive Control Retrieval

A VB.NET equivalent using extension methods to retrieve all child controls of a specific type.

Imports System.Runtime.CompilerServices

Module ControlExt

    <Extension()>
    Public Function GetAllChildren(Of T As Control)(parentControl As Control) As IEnumerable(Of T)
        Dim controls = parentControl.Controls.Cast(Of Control)()
        Return controls.SelectMany(Function(ctrl) _
            GetAllChildren(Of T)(ctrl)) _
            .Concat(controls) _
            .Where(Function(ctrl) ctrl.GetType() = GetType(T)) _
        .Cast(Of T)
    End Function

End Module

Usage:

' Get the first checked radio button
Dim firstCheckedRadioButton = myControl.GetAllChildren(Of HtmlInputRadioButton)().FirstOrDefault(Function(rb) rb.Checked)

Solution 10: General Purpose Control Traversal

This solution offers a flexible way to traverse all controls, with an optional filter function.

public static IEnumerable<Control> AllControls(
    this Control control,
    Func<Control, Boolean> filter = null)
{
    if (control == null)
        throw new ArgumentNullException("control");
    if (filter == null)
        filter = (c => true);

    var list = new List<Control>();

    foreach (Control c in control.Controls)
    {
        list.AddRange(AllControls(c, filter)); // Recursive call
        if (filter(c))
            list.Add(c);
    }
    return list;
}

Solution 11: Generic Recursive Yield Return

This method uses yield return for a more memory-efficient, lazy evaluation of controls.

public static IEnumerable<T> GetAllControls<T>(this Control control) where T : Control
{
    foreach (Control c in control.Controls)
    {
        if (c is T)
            yield return (T)c;
        foreach (T c1 in c.GetAllControls<T>()) // Recursive call
            yield return c1;
    }
}

Solution 12: Using Reflection for Private Fields

While not directly traversing the Controls collection, reflection can access private fields that might hold controls.

List<T> GetAllControlsWithTypeFromControl<T>(Control parentControl)
{
    List<T> retValue = new List<T>();
    System.Reflection.FieldInfo[] fields = parentControl.GetType().GetFields(System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance);
    foreach (System.Reflection.FieldInfo field in fields)
    {
      if (field.FieldType == typeof(T))
        retValue.Add((T)field.GetValue(parentControl));
    }
    return retValue;
}

// Usage: Get all TextBox controls
List<TextBox> controls = GetAllControlsWithTypeFromControl<TextBox>(this);

Solution 13: Filtering by Multiple Types

This extension method allows you to filter controls based on a collection of types in a single pass.

public static IEnumerable<Control> GetAll(this Control control, IEnumerable<Type> filteringTypes)
{
    var ctrls = control.Controls.Cast<Control>();

    return ctrls.SelectMany(ctrl => GetAll(ctrl, filteringTypes)) // Recursive call
                .Concat(ctrls)
                .Where(ctl => filteringTypes.Any(t => ctl.GetType() == t));
}

Usage:

var typesToFind = new List<Type> { typeof(TextBox), typeof(MaskedTextBox), typeof(Button) };
var specificControls = MyContainerControl.GetAll(typesToFind);
foreach(var ctrl in specificControls)
{
    ctrl.Enabled = true;
}

Solution 14: VB.NET Extension for Multiple Types

A VB.NET extension method that allows filtering by type or base type.

''' <summary>Collects child controls of the specified type or base type within the passed control.</summary>
''' <typeparam name="T">The type of child controls to include. Restricted to objects of type Control.</typeparam>
''' <param name="Parent">Required. The parent form control.</param>
''' <returns>An object of type IEnumerable(Of T) containing the control collection.</returns>
''' <remarks>This method recursively calls itself passing child controls as the parent control.</remarks>
<Extension()>
Public Function [GetControls](Of T As Control)(
    ByVal Parent As Control) As IEnumerable(Of T)

    Dim oControls As IEnumerable(Of Control) = Parent.Controls.Cast(Of Control)()
    Return oControls.SelectMany(Function(c) GetControls(Of T)(c)).Concat(oControls.Where(Function(c) c.GetType() Is GetType(T) Or c.GetType().BaseType Is GetType(T)))
End Function

Usage:

Dim buttons As IEnumerable(Of Button) = Me.GetControls(Of Button)()

Solution 15: Utility for Clearing Controls

This recursive function can clear various types of controls like TextBoxes, ComboBoxes, CheckBoxes, and RadioButtons.

private void ClearControls(Control.ControlCollection controlsCollection)
{
    foreach (Control control in controlsCollection)
    {
        if (control.HasChildren)
        {
            ClearControls(control.Controls); // Recursive call
        }
        else
        {
            if (control is TextBox txtBox)
                txtBox.Clear();
            if (control is ComboBox combo)
            {
                if (combo.Items.Count > 0) combo.SelectedIndex = -1;
            }
            if (control is CheckBox chkBox)
                chkBox.Checked = false;
            if (control is RadioButton radBtn)
                radBtn.Checked = false;
            if (control is ListBox lstBox)
                lstBox.ClearSelected();
        }
    }
}

private void btnClear_Click(object sender, EventArgs e)
{
    ClearControls(this.Controls);
}

FAQs on C# Recursive Control Finding

Q: How can I find all TextBox controls within a form recursively in C#?

ANS: You can achieve this by creating a recursive method that iterates through the Controls collection of a Control. For each control, if it has children, you recursively call the method on its children. If a control is of the desired type (e.g., TextBox), you add it to a list. Many of the provided C# solutions demonstrate this pattern using LINQ or explicit recursion.

For example, Solution 1 offers a method GetAll(Control control, Type type) which can be used as: var textboxes = GetAll(this, typeof(TextBox));

Q: Is there a way to find controls of multiple types at once?

ANS: Yes, some methods are designed to handle this. Solution 13 provides an extension method GetAll(this Control control, IEnumerable<Type> filteringTypes) that accepts a list of types to search for. This allows you to find TextBoxes, Buttons, and other controls in a single operation.

Q: Can these methods find controls that are deeply nested inside panels or group boxes?

ANS: Absolutely. The core of these solutions relies on recursion. This means that if a GroupBox contains TextBox controls, and that GroupBox is itself nested within a Panel, the recursive traversal will correctly locate all the TextBox instances at any level of nesting.

Q: Are there performance considerations when searching through many controls?

ANS: For forms with a very large number of controls or very deep nesting, performance can be a factor. Solutions that use yield return (like Solution 11) are generally more memory-efficient as they process controls lazily. However, for typical WinForms applications, most of the provided recursive methods offer acceptable performance.

Q: Can I use these methods to modify controls, not just find them?

ANS: Yes, once you have retrieved a collection of controls, you can easily iterate through them and perform any desired action, such as changing their properties, enabling/disabling them, or clearing their contents. Solution 6 demonstrates changing control colors, and Solution 15 shows clearing various control types.
