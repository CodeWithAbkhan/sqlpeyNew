“C# JSON Serialization: How to Exclude Null Values in Output”

When serializing C# objects to JSON, it is frequently desirable to omit properties that hold a null value to create leaner, more efficient payloads. Whether utilizing the widely adopted Newtonsoft.Json (Json.NET) or the built-in .NET Core System.Text.Json , several effective strategies exist to control this serialization behavior.

How can developers reliably prevent null values from appearing in the resulting JSON string across different .NET environments and serialization libraries?

Controlling Serialization with Newtonsoft.Json Attributes

For projects relying on Newtonsoft.Json, attributes offer a declarative way to specify serialization rules directly on the model classes.

Applying Null Value Handling per Property

You can instruct the serializer to ignore a specific property if its value is null by using the JsonProperty attribute with NullValueHandling.Ignore.

using Newtonsoft.Json;

public class DataModel
{
    public string EssentialField { get; set; }

    [JsonProperty(NullValueHandling = NullValueHandling.Ignore)]
    public string OptionalField { get; set; }

    // Alternatively, specify a custom JSON property name alongside the setting
    [JsonProperty("custom_name", NullValueHandling = NullValueHandling.Ignore)]
    public string AnotherOptionalField { get; set; }
}

Applying Null Value Handling Globally to a Class

To enforce this rule across all properties within a specific class, use the JsonObject attribute:

using Newtonsoft.Json;

[JsonObject(ItemNullValueHandling = NullValueHandling.Ignore)]
public class GlobalIgnoreModel
{
    public string FieldA { get; set; } // Will be ignored if null
    public string FieldB { get; set; } // Will be ignored if null
}

Utilizing DataMemberAttribute with EmitDefaultValue

If avoiding Newtonsoft-specific attributes is preferred, the System.Runtime.Serialization.DataMemberAttribute can sometimes influence the outcome, specifically by setting EmitDefaultValue=false. This setting typically targets default values (like 0 for int or false for bool), but it can also affect nulls for reference types in some configurations.

using System.Runtime.Serialization;

public class DataMemberModel
{
    [DataMember(Name = "property_name", EmitDefaultValue = false)]
    public string ValueToControl { get; set; }
}

Leveraging DefaultValueHandling for Strict Omission

For scenarios where you want to ignore properties that match their declared default value (which includes null for reference types or nullable types), DefaultValueHandling = DefaultValueHandling.Ignore is powerful. This requires the use of DefaultValue attribute on the property.

Consider this example demonstrating how default values (false, null, specific numbers) are omitted when DefaultValueHandling.Ignore is applied during serialization:

using Newtonsoft.Json;
using System.ComponentModel; // For DefaultValue

public class Invoice
{
    public string Company { get; set; }
    public decimal Amount { get; set; }
    public bool Paid { get; set; } // Default is false

    public DateTime? PaidDate { get; set; } // Default is null

    [DefaultValue(30)]
    public int FollowUpDays { get; set; } // Custom default

    [DefaultValue("")]
    public string FollowUpEmailAddress { get; set; } // Custom default
}

var invoice = new Invoice
{
  Company = "Acme Ltd.",
  Amount = 50.0m,
  Paid = false, // Default value
  FollowUpDays = 30, // Default value
  FollowUpEmailAddress = string.Empty, // Default value
  PaidDate = null // Default value
};

// Serialization including defaults
string included = JsonConvert.SerializeObject(invoice,
  Formatting.Indented,
  new JsonSerializerSettings { });
/* Output (Includes defaults):
{
  "Company": "Acme Ltd.",
  "Amount": 50.0,
  "Paid": false,
  "PaidDate": null,
  "FollowUpDays": 30,
  "FollowUpEmailAddress": ""
}
*/

// Serialization ignoring defaults
string ignored = JsonConvert.SerializeObject(invoice,
  Formatting.Indented,
  new JsonSerializerSettings { DefaultValueHandling = DefaultValueHandling.Ignore });
/* Output (Ignores defaults):
{
  "Company": "Acme Ltd.",
  "Amount": 50.0
}
*/

Controlling Serialization via JsonSerializerSettings

Instead of decorating models, you can configure the serializer instance itself to ignore nulls globally for that operation.

Method 1: Instantiating and Setting NullValueHandling

This approach involves creating a custom JsonSerializer or setting the options when calling JsonConvert.SerializeObject.

using Newtonsoft.Json;

var myObject = new { Prop1 = "Value", Prop2 = (string)null };

// Directly set NullValueHandling on the serializer instance
JsonSerializer _jsonWriter = new JsonSerializer {
    NullValueHandling = NullValueHandling.Ignore
};
// Then use _jsonWriter.Serialize(...)

// OR, configuring settings for SerializeObject
var settings = new JsonSerializerSettings {
    NullValueHandling = NullValueHandling.Ignore,
    Formatting = Formatting.None // Useful for minimizing output size
};

string resultJson = JsonConvert.SerializeObject(myObject, settings);
// resultJson will only contain {"Prop1": "Value"}

Method 2: Creating a Reusable Settings Class (VB.NET Example Provided)

For code reuse, defining a custom settings class inheriting from JsonSerializerSettings is an alternative:

Public Class DefaultJsonSerializerSettings
    Inherits JsonSerializerSettings

    Public Sub New()
        Me.NullValueHandling = NullValueHandling.Ignore
    End Sub
End Class

' Usage:
' Dim jsonOutput As String = JsonConvert.SerializeObject(postObj, New DefaultJsonSerializerSettings())

Method 3: Combining Settings with Other Modifiers

Null handling can be combined with other serialization controls, such as using a CamelCasePropertyNamesContractResolver:

using Newtonsoft.Json;
using Newtonsoft.Json.Serialization;

var settings = new JsonSerializerSettings();
settings.ContractResolver = new CamelCasePropertyNamesContractResolver();
settings.NullValueHandling = NullValueHandling.Ignore;

var bodyAsJson = JsonConvert.SerializeObject(bodyObject, Formatting.Indented, settings);

Alternative for VB.NET Users

For Visual Basic developers using Json.NET, the settings can be applied using object initializers:

Dim JSONOut As String = JsonConvert.SerializeObject(
           myContainerObject,
           New JsonSerializerSettings With {
                 .NullValueHandling = NullValueHandling.Ignore
               }
  )

Controlling Serialization with System.Text.Json (.NET Core/5+)

The modern System.Text.Json library uses different properties and naming conventions for configuration.

Option 1: Using JsonSerializerOptions.IgnoreNullValues

This is the direct equivalent for ignoring nulls globally when serializing:

using System.Text.Json;

var myObject = new { Prop1 = "Data", Prop2 = (int?)null };

var jsonSerializerOptions = new JsonSerializerOptions()
{
    IgnoreNullValues = true
};

var myJson = JsonSerializer.Serialize(myObject, jsonSerializerOptions);
// myJson will be {"Prop1":"Data"}

Option 2: Using JsonIgnoreCondition.WhenWritingNull Attribute

Similar to Json.NET attributes, this can be applied to properties for per-field control:

using System.Text.Json.Serialization;

public class SystemTextModel
{
    public string RequiredProp { get; set; }

    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string ConditionalProp { get; set; }
}

This can also be applied globally via options, especially relevant in ASP.NET Core configuration:

using System.Text.Json.Serialization;

var jsonString = JsonSerializer.Serialize(
    myObject,
    new JsonSerializerOptions
    {
        DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
    });

Option 3: Configuring Global Options in ASP.NET Core Startup

In newer .NET versions (e.g., .NET 6+ Program.cs setup), global configuration simplifies things:

// In Program.cs or Startup.cs ConfigureServices
builder.Services.AddControllers()
.AddJsonOptions(opts =>
{
    // Setting default ignore condition for all controllers returning JSON
    opts.JsonSerializerOptions.DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingDefault | JsonIgnoreCondition.WhenWritingNull;
});

Advanced Technique: Dynamic Object Generation for Conditional Patching

For scenarios like HTTP PATCH requests where you only want to send properties that have been explicitly set (and exclude those left as default/null), dynamically building an object using ExpandoObject is highly effective. This ensures that properties not explicitly assigned a non-default value do not appear in the JSON structure at all.

using Newtonsoft.Json;
using System.Dynamic;

public class SampleObject 
{
    public string Name { get; set; }
    public string Company { get; set; }
    
    public object CreateDynamicForPatch()
    {
        dynamic x = new ExpandoObject();
        
        // Only include fields that have meaningful values
        if (!string.IsNullOrWhiteSpace(Name))
        {
            x.name = Name; // Note: Key casing may differ based on final serializer settings
        }
        
        if (!string.IsNullOrEmpty(Company))
        {
            x.Company = Company;
        }
        
        return x;
    }
}

var noCompany = new SampleObject { Name = "Fred Foo" };
// Serialization of ExpandoObject excludes properties that were never assigned keys
string patchJson = JsonConvert.SerializeObject(noCompany.CreateDynamicForPatch());
// Result: {"name":"Fred Foo"}

FAQs on CSharp JSON Serialization Exclude Null Values

Q: Which method is best for ignoring nulls in Json.NET

ANS: For quick, operation-specific control, setting NullValueHandling = NullValueHandling.Ignore within JsonSerializerSettings during the call to JsonConvert.SerializeObject is very common. For permanent, model-level control, use the [JsonProperty(NullValueHandling = NullValueHandling.Ignore)] attribute.

Q: How do I ignore nulls using System Text Json globally in ASPNET Core

ANS: You typically configure this in Program.cs or Startup.cs within AddJsonOptions by setting opts.JsonSerializerOptions.IgnoreNullValues = true; or setting DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull;.

Q: Can I ignore nulls and default primitive values simultaneously

ANS: Yes, with Newtonsoft.Json, using DefaultValueHandling = DefaultValueHandling.Ignore in your JsonSerializerSettings combined with appropriate [DefaultValue] attributes on your properties will achieve this.

Q: What is the System Text Json equivalent of JsonProperty NullValueHandling Ignore

ANS: The equivalent for System.Text.Json is using the attribute [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)] on the property, or setting the global option IgnoreNullValues = true.
