“C# Screenshot Capture: Capture Screen or Active Window”

There are multiple approaches to capturing screen content in C#, primarily utilizing the System.Drawing namespace and P/Invoke calls to Windows API functions. These methods allow you to either capture the entire desktop or focus on the currently active window.

Capturing the Entire Screen

Several solutions focus on grabbing the full screen. A common technique involves obtaining the screen bounds and then using Graphics.CopyFromScreen to transfer the pixel data to a Bitmap object.

Solution 1: Using Screen.GetBounds

This approach directly captures the entire screen’s dimensions and then copies the screen content.

using System.Drawing;
using System.Drawing.Imaging;

// ...

Rectangle screenBounds = Screen.GetBounds(Point.Empty);
using (Bitmap screenshot = new Bitmap(screenBounds.Width, screenBounds.Height))
{
    using (Graphics graphicsHandle = Graphics.FromImage(screenshot))
    {
        graphicsHandle.CopyFromScreen(Point.Empty, Point.Empty, screenBounds.Size);
    }
    screenshot.Save("entire_screen_capture.jpg", ImageFormat.Jpeg);
}

Solution 13: Capturing to File and Clipboard

This method provides flexibility to save the full screen capture to a file and/or copy it to the clipboard.

using System.Drawing;
using System.Drawing.Imaging;
using System.Windows.Forms;
using System.IO;

// ...

public static void CaptureFullScreen(string filePath, bool saveToFile, bool saveToClipboard, out string errorMessage)
{
    errorMessage = string.Empty;

    int screenLeft = SystemInformation.VirtualScreen.Left;
    int screenTop = SystemInformation.VirtualScreen.Top;
    int screenWidth = SystemInformation.VirtualScreen.Width;
    int screenHeight = SystemInformation.VirtualScreen.Height;

    using (Bitmap screenshot = new Bitmap(screenWidth, screenHeight))
    {
        using (Graphics graphicsHandle = Graphics.FromImage(screenshot))
        {
            graphicsHandle.CopyFromScreen(screenLeft, screenTop, 0, 0, screenshot.Size);
        }

        if (saveToFile)
        {
            try
            {
                screenshot.Save(filePath, ImageFormat.Jpeg);
            }
            catch (Exception ex)
            {
                errorMessage = $"Error saving to file: {ex.Message}";
            }
        }

        if (saveToClipboard)
        {
            try
            {
                using (MemoryStream ms = new MemoryStream())
                {
                    screenshot.Save(ms, ImageFormat.Png);
                    Clipboard.SetImage(screenshot);
                }
            }
            catch (Exception ex)
            {
                errorMessage += $"; Error saving to clipboard: {ex.Message}";
            }
        }
    }
}

Solution 3: P/Invoke for Window Capture

This solution defines a ScreenCapture class utilizing P/Invoke to interact with the Windows API.

using System;
using System.Drawing;
using System.Runtime.InteropServices;

public static class ScreenCapture
{
    [DllImport("user32.dll")]
    private static extern IntPtr GetForegroundWindow();

    [DllImport("user32.dll", CharSet = CharSet.Auto, ExactSpelling = true)]
    public static extern IntPtr GetDesktopWindow();

    [StructLayout(LayoutKind.Sequential)]
    private struct Rect
    {
        public int Left;
        public int Top;
        public int Right;
        public int Bottom;
    }

    [DllImport("user32.dll")]
    private static extern IntPtr GetWindowRect(IntPtr hWnd, ref Rect rect);

    public static Image CaptureDesktop()
    {
        return CaptureWindow(GetDesktopWindow());
    }

    public static Bitmap CaptureActiveWindow()
    {
        return CaptureWindow(GetForegroundWindow());
    }

    public static Bitmap CaptureWindow(IntPtr handle)
    {
        var rect = new Rect();
        GetWindowRect(handle, ref rect);
        var bounds = new Rectangle(rect.Left, rect.Top, rect.Right - rect.Left, rect.Bottom - rect.Top);
        var result = new Bitmap(bounds.Width, bounds.Height);

        using (var graphics = Graphics.FromImage(result))
        {
            graphics.CopyFromScreen(new Point(bounds.Left, bounds.Top), Point.Empty, bounds.Size);
        }

        return result;
    }
}

Solution 4: Enhanced Screen Capturer with Mode Selection

This ScreenCapturer class allows specifying capture mode (Screen or Window) and also tracks cursor position relative to the capture.

using System.Drawing;
using System.Windows.Forms; // Required for Cursor and Screen
using System.Runtime.InteropServices; // Required for DllImport

public enum CaptureMode { Screen, Window }

public class ScreenCapturer
{
    [DllImport("user32.dll")]
    private static extern IntPtr GetForegroundWindow();

    [DllImport("user32.dll")]
    private static extern IntPtr GetWindowRect(IntPtr hWnd, ref Rect rect);

    [StructLayout(LayoutKind.Sequential)]
    private struct Rect
    {
        public int Left;
        public int Top;
        public int Right;
        public int Bottom;
    }

    public Bitmap Capture(CaptureMode captureMode = CaptureMode.Window)
    {
        Rectangle captureArea;

        if (captureMode == CaptureMode.Screen)
        {
            captureArea = Screen.GetBounds(Point.Empty);
            CursorPosition = Cursor.Position;
        }
        else
        {
            var foregroundWindowHandle = GetForegroundWindow();
            var rect = new Rect();
            GetWindowRect(foregroundWindowHandle, ref rect);
            captureArea = new Rectangle(rect.Left, rect.Top, rect.Right - rect.Left, rect.Bottom - rect.Top);
            CursorPosition = new Point(Cursor.Position.X - rect.Left, Cursor.Position.Y - rect.Top);
        }

        var screenshotBitmap = new Bitmap(captureArea.Width, captureArea.Height);

        using (var graphicsContext = Graphics.FromImage(screenshotBitmap))
        {
            graphicsContext.CopyFromScreen(new Point(captureArea.Left, captureArea.Top), Point.Empty, captureArea.Size);
        }

        return screenshotBitmap;
    }

    public Point CursorPosition { get; protected set; }
}

Solution 5: Flexible ScreenCapturer with Overloads

This ScreenCapturer class offers methods to capture the screen, active window, a specific window by handle, or even a specific .NET control, with options to save to files with various formats.

using System;
using System.Drawing;
using System.Drawing.Imaging;
using System.IO;
using System.Runtime.InteropServices;
using System.Windows.Forms;

namespace MosaiqPerformanceMonitor
{
    public enum CaptureMode { Screen, Window }

    public static class ScreenCapturer
    {
        [DllImport("user32.dll")] private static extern IntPtr GetForegroundWindow();
        [DllImport("user32.dll")] private static extern IntPtr GetWindowRect(IntPtr hWnd, ref Rect rect);
        [DllImport("user32.dll", CharSet = CharSet.Auto, ExactSpelling = true)] public static extern IntPtr GetDesktopWindow();

        [StructLayout(LayoutKind.Sequential)]
        private struct Rect { public int Left; public int Top; public int Right; public int Bottom; }

        public static void CaptureAndSave(string filename, CaptureMode mode = CaptureMode.Window, ImageFormat format = null)
        {
            ImageSave(filename, format, Capture(mode));
        }

        public static void CaptureAndSave(string filename, IntPtr handle, ImageFormat format = null)
        {
            ImageSave(filename, format, Capture(handle));
        }

        public static void CaptureAndSave(string filename, Control controlToCapture, ImageFormat format = null)
        {
            ImageSave(filename, format, Capture(controlToCapture));
        }

        public static Bitmap Capture(CaptureMode mode = CaptureMode.Window)
        {
            return Capture(mode == CaptureMode.Screen ? GetDesktopWindow() : GetForegroundWindow());
        }

        public static Bitmap Capture(Control controlToCapture)
        {
            return Capture(controlToCapture.Handle);
        }

        public static Bitmap Capture(IntPtr windowHandle)
        {
            var rect = new Rect();
            GetWindowRect(windowHandle, ref rect);
            var bounds = new Rectangle(rect.Left, rect.Top, rect.Right - rect.Left, rect.Bottom - rect.Top);
            var screenshot = new Bitmap(bounds.Width, bounds.Height);

            using (var graphicsContext = Graphics.FromImage(screenshot))
                graphicsContext.CopyFromScreen(new Point(bounds.Left, bounds.Top), Point.Empty, bounds.Size);

            return screenshot;
        }

        public static Point CursorPosition;

        static void ImageSave(string filename, ImageFormat format, Image image)
        {
            format = format ?? ImageFormat.Png;
            if (!filename.Contains("."))
                filename = filename.Trim() + "." + format.ToString().ToLower();

            if (!filename.Contains(@"\"))
                filename = Path.Combine(Environment.GetEnvironmentVariable("TEMP") ?? @"C:\Temp", filename);

            filename = filename.Replace("%NOW%", DateTime.Now.ToString("yyyyMMddHHmmss"));
            image.Save(filename, format);
        }
    }
}

Solution 12: Capturing Specific Controls and Flexible Saving

This ScreenshotUtils class extends capture capabilities to .NET controls and provides a more user-friendly way to save screenshots using SaveFileDialog.

using System.Drawing;
using System.Windows.Forms;
using System.Drawing.Imaging; // For ImageFormat

namespace WebCapture
{
    public static class ScreenshotUtils
    {
        public static Rectangle Offseted(this Rectangle r, Point p) { r.Offset(p); return r; }

        public static Bitmap GetScreenshot(this Control controlToCapture)
        {
            return GetScreenshot(new Rectangle(controlToCapture.PointToScreen(Point.Empty), controlToCapture.Size));
        }

        public static Bitmap GetScreenshot(Rectangle bounds)
        {
            Bitmap screenshotBitmap = new Bitmap(bounds.Width, bounds.Height);
            using (Graphics g = Graphics.FromImage(screenshotBitmap))
                g.CopyFromScreen(new Point(bounds.Left, bounds.Top), Point.Empty, bounds.Size);
            return screenshotBitmap;
        }

        public static void ShowSaveFileDialog(this Image image, IWin32Window owner = null)
        {
            using (SaveFileDialog dialog = GetImageSaveFileDialog())
                if (dialog.ShowDialog(owner) == DialogResult.OK)
                    image.Save(dialog.FileName);
        }

        public static SaveFileDialog GetImageSaveFileDialog(string title = "Save image", string filter = "PNG Image (*.png)|*.png|JPEG Image (*.jpg)|*.jpg|Bitmap Image (*.bmp)|*.bmp|GIF Image (*.gif)|*.gif")
        {
            return new SaveFileDialog { Title = title, Filter = filter };
        }
    }
}

FAQs on C# Screenshot Capture

Q: How can I capture the entire computer screen in C

ANS: You can use Screen.GetBounds(Point.Empty) to get the dimensions of the entire screen and then Graphics.CopyFromScreen to capture the pixels into a Bitmap. See Solution 1 and Solution 9 for examples.

Q: What is the best way to capture the currently active window in C

ANS: Utilize P/Invoke to call GetForegroundWindow to get the handle of the active window, then use GetWindowRect to determine its position and size. Finally, use Graphics.CopyFromScreen with these bounds. Solutions 3, 4, and 5 provide robust implementations for this.

Q: Can I capture a specific control within my application window

ANS: Yes, you can capture a specific control by getting its handle and then its screen coordinates using methods like Control.PointToScreen, similar to how you capture a window. Solution 12 provides an example of capturing controls.

Q: How do I save a screenshot to a file in C

ANS: After obtaining the screenshot as a Bitmap object, you can use its Save() method, specifying the file path and the desired ImageFormat (e.g., ImageFormat.Jpeg, ImageFormat.Png). Solution 5 and Solution 10 offer methods for saving, with Solution 10 incorporating a SaveFileDialog.

Q: Is it possible to capture the screen and copy it to the clipboard simultaneously in C

ANS: Yes, after capturing the screen to a Bitmap, you can use Clipboard.SetImage() to place it onto the clipboard. Solution 13 demonstrates this combined functionality.

Q: How does display scaling affect screenshot capture in C

ANS: High DPI settings or display scaling can alter the perceived dimensions of windows and screens. Solution 11 shows how to account for scaling factors using P/Invoke to adjust the capture bounds correctly.
