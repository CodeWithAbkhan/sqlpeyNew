“Solved: How to Handle JSON Serialization and Deserialization in Unity”

Q: What is Unity's JsonUtility and its limitations

ANS: Unity’s JsonUtility is a built-in API designed for simple JSON serialization and deserialization. It excels with basic data types and supports List<T>, but it has limitations. It does not directly support Dictionary or complex types that require custom handling. For more intricate JSON structures, third-party libraries might be necessary. It’s crucial to remember that JsonUtility only works with public fields; private fields or properties with { get; set; } are not serialized. Ensure your classes intended for serialization are decorated with the [System.Serializable] attribute.

Q: How to serialize and deserialize a single JSON object in Unity

ANS: To serialize a single object, you can use JsonUtility.ToJson(objectInstance). For deserialization, JsonUtility.FromJson<YourClass>(jsonString) is used to create a new instance, or JsonUtility.FromJsonOverwrite(jsonString, existingObject) to populate an existing object, which is more memory-efficient.

Q: How can I serialize and deserialize JSON arrays in Unity

ANS: JsonUtility doesn’t directly support JSON arrays. You need a helper class to bridge this gap. Create a wrapper class, for instance, JsonHelper, with a nested Wrapper<T> class that holds an array of your target type. Then, use JsonHelper.ToJson for serialization and JsonHelper.FromJson for deserialization. If your JSON array comes directly from a server without a root element, you’ll need to prepend {"Items": and append } to the JSON string before passing it to JsonHelper.FromJson.

Q: What should I do if my JSON properties start with numbers or are not directly compatible with class names

ANS: Unity’s JsonUtility cannot handle JSON properties that begin with numbers or have invalid C# identifier characters. For such cases, a robust third-party library like SimpleJSON.cs is recommended. This allows you to parse and access these properties dynamically using dictionary-like access.

Q: What are common troubleshooting steps for Unity's JsonUtility

ANS: If JsonUtility.ToJson returns an empty string or {}, ensure your class is marked with [System.Serializable] and that you are serializing public fields, not properties. For JsonUtility.FromJson returning null or NullReferenceException, verify the JSON structure, especially if it’s an array (use the JsonHelper class), and confirm the [System.Serializable] attribute is present. Always validate your JSON using an online validator.

Q: When should I consider using Newtonsoft.Json in Unity

ANS: If your JSON data is complex, involves dictionaries, or requires advanced formatting, consider using Newtonsoft.Json . It’s a powerful and widely-used library that offers more flexibility than JsonUtility. You can add it to your project via the Unity Package Manager using the identifier com.unity.nuget.newtonsoft-json.

Solutions

When working with game development in Unity, handling data exchange and configuration often involves JSON. Unity’s built-in JsonUtility provides a straightforward way to serialize C# objects to JSON and deserialize JSON strings back into C# objects. However, its capabilities are limited, especially when dealing with more complex data structures or specific JSON formats. This guide will walk you through various scenarios and solutions for effective JSON handling in Unity.

Utilizing Unity’s JsonUtility

Unity introduced JsonUtility in version 5.3.3, offering a lightweight and efficient API for JSON operations. It’s particularly well-suited for simple data types and structures.

Serializing Single Data Objects

To convert a C# object into a JSON string, you can use JsonUtility.ToJson().

Example: Basic Serialization

Let’s define a simple Player class:

[System.Serializable]
public class Player
{
    public string playerId;
    public string playerLoc;
    public string playerNick;
}

Now, serialize an instance of this class:

Player playerInstance = new Player();
playerInstance.playerId = "8484239823";
playerInstance.playerLoc = "Powai";
playerInstance.playerNick = "Random Nick";

// Convert to JSON
string playerToJson = JsonUtility.ToJson(playerInstance);
Debug.Log(playerToJson);

Output:

{"playerId":"8484239823","playerLoc":"Powai","playerNick":"Random Nick"}

You can also format the JSON for better readability using the prettyPrint parameter:

// Convert to JSON with pretty printing
string playerToJsonPretty = JsonUtility.ToJson(playerInstance, true);
Debug.Log(playerToJsonPretty);

Output:

{
    "playerId": "8484239823",
    "playerLoc": "Powai",
    "playerNick": "Random Nick"
}

Deserializing Single Data Objects

To convert a JSON string back into a C# object, you have a couple of options:

Deserializing to a New Instance

Use JsonUtility.FromJson<T>(jsonString) to create a new instance of your class:

string jsonString = "{\"playerId\":\"8484239823\",\"playerLoc\":\"Powai\",\"playerNick\":\"Random Nick\"}";
Player player = JsonUtility.FromJson<Player>(jsonString);
Debug.Log(player.playerLoc); // Output: Powai
Deserializing to an Existing Instance (Overwrite)

For efficiency, you can populate an existing object using JsonUtility.FromJsonOverwrite(jsonString, objectToOverwrite). This avoids creating a new object, reducing garbage collection overhead.

Player playerInstance = new Player(); // Create an instance once

void DeserializePlayer()
{
    string jsonString = "{\"playerId\":\"8484239823\",\"playerLoc\":\"Powai\",\"playerNick\":\"Random Nick\"}";
    JsonUtility.FromJsonOverwrite(jsonString, playerInstance); // Overwrite values in the existing instance
    Debug.Log(playerInstance.playerLoc); // Output: Powai
}

Handling JSON Arrays

Directly serializing or deserializing arrays with JsonUtility is not supported. You’ll need a helper class to manage this.

The JsonHelper Class

Create a static class to act as a utility for array serialization and deserialization.

public static class JsonHelper
{
    public static T[] FromJson<T>(string json)
    {
        Wrapper<T> wrapper = JsonUtility.FromJson<Wrapper<T>>(json);
        return wrapper.Items;
    }

    public static string ToJson<T>(T[] array)
    {
        Wrapper<T> wrapper = new Wrapper<T>();
        wrapper.Items = array;
        return JsonUtility.ToJson(wrapper);
    }

    public static string ToJson<T>(T[] array, bool prettyPrint)
    {
        Wrapper<T> wrapper = new Wrapper<T>();
        wrapper.Items = array;
        return JsonUtility.ToJson(wrapper, prettyPrint);
    }

    [System.Serializable]
    private class Wrapper<T>
    {
        public T[] Items;
    }
}

Serializing JSON Arrays

When you have an array of Player objects, use JsonHelper.ToJson():

Player[] players = new Player[2];

players[0] = new Player { playerId = "8484239823", playerLoc = "Powai", playerNick = "Random Nick" };
players[1] = new Player { playerId = "512343283", playerLoc = "User2", playerNick = "Rand Nick 2" };

// Convert to JSON array
string playersToJson = JsonHelper.ToJson(players, true);
Debug.Log(playersToJson);

Output:

{
    "Items": [
        {
            "playerId": "8484239823",
            "playerLoc": "Powai",
            "playerNick": "Random Nick"
        },
        {
            "playerId": "512343283",
            "playerLoc": "User2",
            "playerNick": "Rand Nick 2"
        }
    ]
}

Deserializing JSON Arrays

To deserialize an array, use JsonHelper.FromJson<T>():

string jsonArrayString = @"{
    ""Items"": [
        {
            ""playerId"": ""8484239823"",
            ""playerLoc"": ""Powai"",
            ""playerNick"": ""Random Nick""
        },
        {
            ""playerId"": ""512343283"",
            ""playerLoc"": ""User2"",
            ""playerNick"": ""Rand Nick 2""
        }
    ]
}";

Player[] players = JsonHelper.FromJson<Player>(jsonArrayString);
Debug.Log(players[0].playerLoc); // Output: Powai
Debug.Log(players[1].playerLoc); // Output: User2

Handling Server-Provided Arrays: If the JSON array from a server doesn’t have the {"Items": [...]} structure, you’ll need to wrap it:

string yourJsonFromServer = "[{\"playerId\":\"1\",\"playerLoc\":\"Powai\"},{\"playerId\":\"2\",\"playerLoc\":\"Andheri\"}]";

// Fix the JSON structure
string fixedJson = "{\"Items\":" + yourJsonFromServer + "}";

Player[] players = JsonHelper.FromJson<Player>(fixedJson);

Dealing with Complex JSON Structures and Limitations

JSON with Numeric Property Names

Properties starting with numbers, like "15m", are not directly supported by JsonUtility because they are invalid C# identifiers.

Example JSON:
{
    "USD": {"15m": 1740.01, "last": 1740.01, "buy": 1740.01, "sell": 1744.74, "symbol": "$"},
    "ISK": {"15m": 179479.11, "last": 179479.11, "buy": 179479.11, "sell": 179967, "symbol": "kr"},
    "NZD": {"15m": 2522.84, "last": 2522.84, "buy": 2522.84, "sell": 2529.69, "symbol": "$"}
}

Solution: Use a parsing library like SimpleJSON.cs .

// Assuming yourJsonString holds the JSON above
var N = SimpleJSON.JSON.Parse(yourJsonString);

// Accessing properties
string usdPrice = N["USD"]["15m"].Value;
Debug.Log($"USD 15m Price: {usdPrice}"); // Output: USD 15m Price: 1740.01

string iskPrice = N["ISK"]["15m"].Value;
Debug.Log($"ISK 15m Price: {iskPrice}"); // Output: ISK 15m Price: 179479.11

Serializing Lists

JsonUtility can serialize List<T> if it’s a field within a serializable class.

using System.Collections.Generic;

[System.Serializable]
public class JsonableListWrapper<T>
{
    public List<T> list;

    public JsonableListWrapper(List<T> list) => this.list = list;
}

// Example usage:
List<string> stringList = new List<string>() { "one", "two", "three" };

// To Json
string stringListAsJson = JsonUtility.ToJson(new JsonableListWrapper<string>(stringList));
Debug.Log(stringListAsJson);

// From Json
List<string> stringListFromJson = JsonUtility.FromJson<JsonableListWrapper<string>>(stringListAsJson).list;
Debug.Log($"Deserialized list count: {stringListFromJson.Count}"); // Output: Deserialized list count: 3

Output:

{"list":["one","two","three"]}

Handling Nested Arrays (e.g., QR Code Data)

If your JSON structure is nested, such as an array of results, you might need to wrap it appropriately during deserialization.

Example JSON:

[
    {
        "type": "qrcode",
        "symbol": [
            {
                "seq": 0,
                "data": "HelloWorld9887725216",
                "error": null
            }
        ]
    }
]

Define Corresponding Classes:

[System.Serializable]
public class QRCodeResult
{
    public QRCodeData[] result;
}

[System.Serializable]
public class Symbol
{
    public int seq;
    public string data;
    public string error;
}

[System.Serializable]
public class QRCodeData
{
    public string type;
    public Symbol[] symbol;
}

Deserialization: Wrap the JSON string with a root element that matches your deserialization class.

string jsonString = @"[
    {
        ""type"": ""qrcode"",
        ""symbol"": [
            {
                ""seq"": 0,
                ""data"": ""HelloWorld9887725216"",
                ""error"": null
            }
        ]
    }
]";

// Wrap the JSON to match the QRCodeResult class structure
string wrappedJson = "{\"result\":" + jsonString + "}";
QRCodeResult myObject = JsonUtility.FromJson<QRCodeResult>(wrappedJson);

Debug.Log($"QR Code Data: {myObject.result[0].symbol[0].data}"); // Output: QR Code Data: HelloWorld9887725216

Troubleshooting Common JSON Issues

  • Empty JSON ({} or ""):
    • Ensure your class has the [System.Serializable] attribute.
    • Verify that only public fields are being serialized. Properties with { get; set; } are ignored.
    • If serializing an array, use the JsonHelper class.
  • NullReferenceException or JsonUtility.FromJson returns null:
    • The JSON string might be malformed or not match the C# class structure. Use an online JSON validator.
    • If it’s an array, ensure you are using the JsonHelper correctly, including the {"Items": [...]} wrapper if necessary.
    • Double-check the [System.Serializable] attribute on all classes involved in the deserialization.
  • Properties starting with numbers: As mentioned, use a library like SimpleJSON or Newtonsoft.Json.

Alternative Solutions: Newtonsoft.Json

For more advanced JSON needs, Newtonsoft.Json is a powerful alternative.

Installation

Add the Newtonsoft.Json package via the Unity Package Manager using the identifier com.unity.nuget.newtonsoft-json.

Usage Example

using System;
using Newtonsoft.Json;
using UnityEngine;

public class NewtonsoftJsonExample : MonoBehaviour
{
    [System.Serializable]
    public class Person
    {
        public string id;
        public string name;
    }

    public Person[] people;

    void Start()
    {
        // Serialize an object
        string json = JsonConvert.SerializeObject(people, Formatting.Indented);
        Debug.Log("Serialized JSON:\n" + json);

        // Deserialize JSON
        string jsonToDeserialize = "[{\"id\":\"1\",\"name\":\"Alice\"},{\"id\":\"2\",\"name\":\"Bob\"}]";
        Person[] deserializedPeople = JsonConvert.DeserializeObject<Person[]>(jsonToDeserialize);

        if (deserializedPeople != null)
        {
            Debug.Log($"Deserialized Person 1 Name: {deserializedPeople[0].name}");
        }
    }
}

This provides a more flexible approach, especially when dealing with dictionaries or custom converters.

Reading JSON Files

You can read JSON data directly from files, often stored in Application.streamingAssetsPath.

using System.IO;
using UnityEngine;

public class ReadJsonFile : MonoBehaviour
{
    [System.Serializable]
    public class PlayerInfo
    {
        public string Name;
        public int Level;
    }

    public void LoadPlayerData(string filename = "Player.json")
    {
        string path = Path.Combine(Application.streamingAssetsPath, filename);
        if (File.Exists(path))
        {
            string JSONString = File.ReadAllText(path);
            PlayerInfo player = JsonUtility.FromJson<PlayerInfo>(JSONString);
            Debug.Log($"Loaded Player: Name={player.Name}, Level={player.Level}");
        }
        else
        {
            Debug.LogError($"File not found: {path}");
        }
    }

    void Start()
    {
        LoadPlayerData(); // Assumes Player.json exists in StreamingAssets
    }
}

Example Player.json content:

{
    "Name": "MyName",
    "Level": 4
}
