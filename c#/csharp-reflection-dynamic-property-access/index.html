How can I access an object’s property dynamically using a string that represents its name or a path to a nested property in C#?

When working with objects in C#, you often need to access properties based on a string name or a hierarchical path. This is particularly useful when dealing with configurations, serialization, or when the property you need to access isn’t known until runtime. Reflection in .NET provides powerful mechanisms to achieve this. Here, we examine several effective methods and their nuances for dynamic property retrieval.

Solution 1: Basic Property Value Retrieval

A straightforward approach involves using Type.GetProperty and PropertyInfo.GetValue to retrieve a property’s value. This is suitable for directly accessing a single property.

using System.Reflection;

public static object GetPropValue(object src, string propName)
{
    // Basic validation can be added here for src and propName
    return src.GetType().GetProperty(propName)?.GetValue(src, null);
}

Example Usage:

public class SampleObject {
    public string MyProperty { get; set; } = "Hello Reflection!";
}

SampleObject obj = new SampleObject();
string propValue = (string)GetPropValue(obj, "MyProperty");
// propValue will be "Hello Reflection!"

Solution 2: Accessing Nested Properties via String Path

To navigate through nested objects using a string path like "Object.NestedObject.Property", you can extend the reflection logic to split the path and traverse the object hierarchy.

using System.Reflection;

public static object GetPropValue(this object obj, string name)
{
    // Handles null objects gracefully and splits the property path
    foreach (string part in name.Split('.'))
    {
        if (obj == null) { return null; }

        Type type = obj.GetType();
        PropertyInfo info = type.GetProperty(part);
        if (info == null) { return null; } // Property not found

        obj = info.GetValue(obj, null);
    }
    return obj;
}

// Generic version for type casting
public static T GetPropValue<T>(this Object obj, String name)
{
    Object retval = GetPropValue(obj, name);
    if (retval == null) { return default(T); }

    // Safely cast to the desired type
    return (T)retval;
}

Example Usage:

public class Address {
    public string City { get; set; } = "Metropolis";
}

public class Person {
    public string Name { get; set; } = "Clark Kent";
    public Address HomeAddress { get; set; } = new Address();
}

Person person = new Person();
string personName = (string)person.GetPropValue("Name"); // "Clark Kent"
string city = person.GetPropValue<string>("HomeAddress.City"); // "Metropolis"

Solution 3: Using Indexers for Dynamic Property Access

You can implement an indexer on a class to allow accessing its properties using string keys, similar to dictionary access.

using System.Reflection;

public class DynamicPropertyAccessor
{
    public object this[string propertyName]
    {
        get
        {
            // Safely get the property value
            return this.GetType().GetProperty(propertyName)?.GetValue(this, null);
        }
        set
        {
            // Safely set the property value
            this.GetType().GetProperty(propertyName)?.SetValue(this, value, null);
        }
    }

    public string SampleProperty { get; set; } = "Dynamic Value";
}

Example Usage:

DynamicPropertyAccessor accessor = new DynamicPropertyAccessor();
accessor["SampleProperty"] = "New Dynamic Value";
string retrievedValue = (string)accessor["SampleProperty"]; // "New Dynamic Value"

Solution 5: Handling Collections and Arrays within Paths

For scenarios where your string path needs to access elements within collections or arrays (e.g., "MyList[0].Name"), you can extend the reflection logic to parse array indices.

using System.Reflection;
using System.Collections;

public static object GetPropertyValue(object srcobj, string propertyName)
{
    if (srcobj == null) return null;

    object obj = srcobj;
    string[] propertyNameParts = propertyName.Split('.');

    foreach (string propertyNamePart in propertyNameParts)
    {
        if (obj == null) return null;

        if (!propertyNamePart.Contains('['))
        {
            // Standard property access
            PropertyInfo pi = obj.GetType().GetProperty(propertyNamePart);
            if (pi == null) return null;
            obj = pi.GetValue(obj, null);
        }
        else
        {
            // Array or List element access, e.g., "CollectionName[index]"
            int indexStart = propertyNamePart.IndexOf('[') + 1;
            string collectionPropertyName = propertyNamePart.Substring(0, indexStart - 1);
            int collectionElementIndex = int.Parse(propertyNamePart.Substring(indexStart, propertyNamePart.Length - indexStart - 1));

            PropertyInfo pi = obj.GetType().GetProperty(collectionPropertyName);
            if (pi == null) return null;
            object collection = pi.GetValue(obj, null);

            if (collection is System.Array array)
            {
                obj = array.GetValue(collectionElementIndex);
            }
            else if (collection is IList list)
            {
                obj = list[collectionElementIndex];
            }
            else
            {
                // Handle unsupported collection types
            }
        }
    }
    return obj;
}

Example Usage:

public class Item {
    public string ItemName { get; set; } = "Sample Item";
}

public class Container {
    public Item[] ItemsArray { get; set; } = new Item[] { new Item() };
}

Container container = new Container();
string firstItemName = (string)GetPropertyValue(container, "ItemsArray[0].ItemName");
// firstItemName will be "Sample Item"

Solution 6: Targeting Specific Frameworks (e.g., Xamarin.Forms)

In environments like Xamarin.Forms, Type.GetProperty might be restricted. In such cases, Type.GetRuntimeProperties() is the preferred method, often combined with LINQ for filtering.

using System.Linq;
using System.Reflection;

public static object GetPropValue(object source, string propertyName)
{
    // Use GetRuntimeProperties for broader compatibility, especially in PCLs
    var property = source.GetType().GetRuntimeProperties().FirstOrDefault(p => string.Equals(p.Name, propertyName, StringComparison.OrdinalIgnoreCase));
    return property?.GetValue(source);
}

Solution 9: Retrieving All Properties and Values

If you need to iterate through all public properties of an object and get their string representations, this method is useful.

using System.Collections.Generic;
using System.Reflection;

public static List<KeyValuePair<string, string>> GetProperties(object item)
{
    var result = new List<KeyValuePair<string, string>>();
    if (item != null)
    {
        Type type = item.GetType();
        // Get public instance properties
        var properties = type.GetProperties(BindingFlags.Public | BindingFlags.Instance);
        foreach (var pi in properties)
        {
            var value = pi.GetValue(item, null);
            result.Add(new KeyValuePair<string, string>(pi.Name, value?.ToString()));
        }
    }
    return result;
}

Solution 12: Recursive Property Value Display

This method recursively traverses an object’s entire property hierarchy, displaying property names and their values.

using System.Reflection;
using System.Text; // For string building

public static object GetPropertyValue(object srcObj, string propertyName)
{
    if (srcobj == null) return null;
    // Simplified GetPropertyValue to get a single property
    PropertyInfo pi = srcObj.GetType().GetProperty(propertyName.Replace("[]", ""));
    return pi?.GetValue(srcobj);
}

public static void DisplayAllProperties(string parentPath, object parentObj, bool showNullValues = false)
{
    if (parentObj == null) return;

    foreach (PropertyInfo pi in parentObj.GetType().GetTypeInfo().GetProperties())
    {
        string currentPath = string.IsNullOrEmpty(parentPath) ? pi.Name : $"{parentPath}.{pi.Name}";
        object myPropertyValue = GetPropertyValue(parentObj, pi.Name);

        if (myPropertyValue == null)
        {
            if (showNullValues) Console.WriteLine($"{currentPath} = null");
        }
        else if (myPropertyValue.GetType().IsArray)
        {
            // Handle arrays recursively
            var array = myPropertyValue as Array;
            for (int i = 0; i < array.Length; i++)
            {
                DisplayAllProperties($"{currentPath}[{i}]", array.GetValue(i), showNullValues);
            }
        }
        else if (myPropertyValue.GetType().IsClass && myPropertyValue.GetType() != typeof(string))
        {
            // Recurse into nested objects
            DisplayAllProperties(currentPath, myPropertyValue, showNullValues);
        }
        else
        {
            // Display simple property value
            Console.WriteLine($"{currentPath} = {myPropertyValue}");
        }
    }
}

// Call like: DisplayAllProperties("RootObject", yourInstance);

Solution 13: Accessing Fields and Properties (Public/Non-Public)

This solution provides generic methods to get field or property values, supporting non-public members.

using System.Linq;
using System.Reflection;

public static TValue GetFieldValue<TValue>(this object instance, string name)
{
    var field = instance.GetType().GetFields(BindingFlags.NonPublic | BindingFlags.Static | BindingFlags.Instance)
                       .FirstOrDefault(e => typeof(TValue).IsAssignableFrom(e.FieldType) && e.Name == name);
    return (TValue)field?.GetValue(instance);
}

public static TValue GetPropertyValue<TValue>(this object instance, string name)
{
    var property = instance.GetType().GetProperties(BindingFlags.NonPublic | BindingFlags.Static | BindingFlags.Instance)
                         .FirstOrDefault(e => typeof(TValue).IsAssignableFrom(e.PropertyType) && e.Name == name);
    return (TValue)property?.GetValue(instance);
}

Solution 15: Nested Property Search

This approach iterates through properties of a model, attempting to find a specific nested property value.

using System.Reflection;

public static T FindNestedPropertyValue<T, N>(N model, string propName)
{
    T retVal = default(T);
    bool found = false;

    PropertyInfo[] properties = typeof(N).GetProperties();

    foreach (PropertyInfo property in properties)
    {
        var currentProperty = property.GetValue(model, null);
        if (!found && currentProperty != null)
        {
            try {
                // Helper to get a single property
                retVal = GetPropValue<T>(currentProperty, propName);
                found = true;
            } catch { /* Ignore exceptions if property not found */ }
        }
    }

    if (!found) throw new Exception($"Unable to find property: {propName}");
    return retVal;
}

// Helper method (from Solution 2)
public static T GetPropValue<T>(object srcObject, string propName)
{
    return (T)srcObject.GetType().GetProperty(propName).GetValue(srcObject, null);
}

Solution 16: Static Property Access

This method is designed to access static properties by deriving the type from the property path string.

using System.Reflection;

public static object GetStaticPropValue(string propPath) // e.g., "Namespace.ClassName.StaticPropertyName"
{
    int splitPoint = propPath.LastIndexOf('.');
    if (splitPoint < 0) return null; // Invalid path

    string typeName = propPath.Substring(0, splitPoint);
    string propertyName = propPath.Substring(splitPoint + 1);

    // Try to get the type from the current assembly or referenced assemblies
    Type type = Assembly.GetEntryAssembly()?.GetType(typeName);
    if (type == null)
    {
        // Fallback to searching all loaded assemblies
        foreach(var assembly in AppDomain.CurrentDomain.GetAssemblies())
        {
            type = assembly.GetType(typeName);
            if (type != null) break;
        }
    }

    if (type == null) return null; // Type not found

    // Access the static property
    PropertyInfo propInfo = type.GetProperty(propertyName, BindingFlags.Public | BindingFlags.Static);
    return propInfo?.GetValue(null); // Pass null for static property access
}

Solution 18: Type-Safe Property Access with Expressions

Using lambda expressions provides compile-time safety, ensuring the property exists and the type is correct.

using System.Linq.Expressions;
using System.Reflection;

public static class ExpressionUtils
{
    // Concise version (may throw NRE on invalid property)
    public static TVal GetPropertyValue<T, TVal>(T t, Expression<Func<T, TVal>> x)
        => (TVal)((x.Body as MemberExpression)?.Member as PropertyInfo)!.GetValue(t);

    // Safer, more readable version with error handling
    public static TVal GetPropertyValue<T, TVal>(T t, Expression<Func<T, TVal>> x)
    {
        var memberExpression = x.Body as MemberExpression;
        if (memberExpression == null)
            throw new ArgumentException("Expression body must be a MemberExpression.");

        var propertyInfo = memberExpression.Member as PropertyInfo;
        if (propertyInfo == null)
            throw new ArgumentException($"Member '{memberExpression.Member.Name}' is not a property.");

        // Ensure the return type is compatible
        if (!typeof(TVal).IsAssignableFrom(propertyInfo.PropertyType))
             throw new InvalidCastException($"Cannot convert property type '{propertyInfo.PropertyType.Name}' to '{typeof(TVal).Name}'.");

        return (TVal)propertyInfo.GetValue(t);
    }
}

Solution 21: Robust Property Value Retrieval with Error Handling

This method offers detailed error handling and logging for property retrieval.

using System.Reflection;
// Assuming a Log class exists for logging errors

public static T GetPropertyValue<T>(object sourceInstance, string targetPropertyName, bool throwExceptionIfNotExists = false)
{
    string errorMsg = null;
    try
    {
        if (sourceInstance == null || string.IsNullOrWhiteSpace(targetPropertyName))
        {
            errorMsg = $"Source object is null or property name is null/whitespace. '{targetPropertyName}'";
            // Log.Warn(errorMsg); // Use your logging mechanism
            if (throwExceptionIfNotExists) throw new ArgumentException(errorMsg);
            else return default(T);
        }

        Type sourceType = sourceInstance.GetType();
        // Try to get property matching the target type
        PropertyInfo propertyInfo = sourceType.GetProperty(targetPropertyName, typeof(T));
        if (propertyInfo == null)
        {
            errorMsg = $"Property '{targetPropertyName}' of type '{typeof(T).Name}' not found for object of type '{sourceType.Name}'.";
            // Log.Warn(errorMsg);
            if (throwExceptionIfNotExists) throw new ArgumentException(errorMsg);
            else return default(T);
        }

        return (T)propertyInfo.GetValue(sourceInstance, null);
    }
    catch (Exception ex)
    {
        errorMsg = $"Problem getting property '{targetPropertyName}' from instance.";
        // Log.Error(errorMsg, ex);
        if (throwExceptionIfNotExists) throw;
    }
    return default(T);
}

Solution 22: Handling COM Objects with CallByName

This solution extends dynamic property access to include COM objects, parsing array indices within the property name.

using System.Reflection;
using Microsoft.VisualBasic; // For CallByName

public static object GetPropValueWithCom(this object obj, string name)
{
    foreach (string part in name.Split('.'))
    {
        if (obj == null) return null;
        Type type = obj.GetType();

        if (type.Name == "__ComObject") // Check if it's a COM object
        {
            if (part.Contains('['))
            {
                string partWithoutIndex = part;
                int index = ParseIndex(ref partWithoutIndex);
                obj = Versioned.CallByName(obj, partWithoutIndex, CallType.Get, index);
            }
            else
            {
                obj = Versioned.CallByName(obj, part, CallType.Get);
            }
        }
        else // Standard .NET object
        {
            PropertyInfo info = type.GetProperty(part);
            if (info == null) return null;
            obj = info.GetValue(obj, null);
        }
    }
    return obj;
}

private static int ParseIndex(ref string name) // Helper to parse index like "[0]"
{
    int index = -1;
    int s = name.IndexOf('[') + 1;
    int e = name.IndexOf(']');
    if (e < s) throw new ArgumentException("Invalid index format.");
    string tmp = name.Substring(s, e - s);
    index = Convert.ToInt32(tmp);
    name = name.Substring(0, s - 1); // Remove index part from name
    return index;
}

Solution 24: Recursive Property Access with Error Handling

This recursive approach handles nested properties and includes a try-catch block for robustness.

public static object GetPropValueRecursive(object src, string propName)
{
    try
    {
        // Split the property path
        var path = propName.Split(new[] { '.' }, 2);

        if (path.Length > 1)
        {
            // Recursively call for the next level
            object nextObject = src.GetType().GetProperty(path[0])?.GetValue(src, null);
            return GetPropValueRecursive(nextObject, path[1]);
        }
        else
        {
            // Base case: return the property value
            return src.GetType().GetProperty(propName)?.GetValue(src, null);
        }
    }
    catch
    {
        // Return null if the path is invalid or property not found
        return null;
    }
}

FAQs on C# Reflection Dynamic Property Access

Q: How do I access a property using a string name in C#?

ANS: You can use System.Reflection.PropertyInfo and its GetValue method. Get the PropertyInfo object using object.GetType().GetProperty("PropertyName") and then call GetValue(objectInstance, null).

Q: What if the property I need to access is nested, like 'Object.Nested.Property'?

ANS: You can split the property name string by the dot (.) character and iterate through the parts, calling GetValue at each level to traverse the object graph. Solutions 2 and 24 demonstrate this.

Q: Can I access properties that are private?

ANS: Yes, by using BindingFlags.NonPublic when calling GetType().GetProperty() or GetType().GetProperties(), and ensuring you have the correct reflection context. Solution 13 shows how to access non-public members.

Q: What is the difference between `GetProperty` and `GetRuntimeProperty`?

ANS: GetProperty is part of the older reflection model, while GetRuntimeProperty is part of the .NET Core/modern reflection API and is generally preferred for broader compatibility, especially in portable libraries.

Q: Is accessing properties via reflection slower than direct access?

ANS: Yes, reflection involves overhead for discovering types and members at runtime, making it slower than directly accessing properties. For performance-critical sections, consider caching reflection results or using expression trees (Solution 18) which can be compiled into delegates for better performance.

Q: How can I access elements of an array or list using a string path?

ANS: You need to parse the index from the string (e.g., MyArray[0]) and use appropriate methods like Array.GetValue() or IList.get_Item() after retrieving the collection property. Solution 5 provides an example of handling this.
