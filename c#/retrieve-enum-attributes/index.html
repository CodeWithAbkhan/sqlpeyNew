“Retrieve Enum Attributes Dynamically in C#: Code Examples & Solutions”

When working with enumerations in C#, you often need to associate metadata with enum members. This metadata, typically stored in attributes like DescriptionAttribute or DisplayAttribute, provides richer information than just the enum member’s name or value. This can be useful for displaying user-friendly names, serializing enums, or configuring application behavior.

Accessing these attributes dynamically at runtime usually involves using reflection. This post presents various methods and code examples to effectively retrieve attributes from enum members.

Solution 1: Basic Reflection Approach

This fundamental method uses Type.GetMember to get member information and then GetCustomAttributes to retrieve the desired attribute. A try-catch block is included for robustness.

// Assuming FunkyAttributesEnum and DescriptionAttribute are defined
// For demonstration purposes, let's imagine:
// public enum FunkyAttributesEnum { [Description("Name With Spaces1")] NameWithoutSpaces1, ... }

try
{
    var enumType = typeof(FunkyAttributesEnum);

    // Get member information for a specific enum value
    var memberInfos = enumType.GetMember(FunkyAttributesEnum.NameWithoutSpaces1.ToString());

    // Ensure we're looking at the correct member information
    var enumValueMemberInfo = memberInfos.FirstOrDefault(m => m.DeclaringType == enumType);

    // Retrieve custom attributes of type DescriptionAttribute
    var valueAttributes = enumValueMemberInfo.GetCustomAttributes(typeof(DescriptionAttribute), false);

    // Extract the Description string
    var description = ((DescriptionAttribute)valueAttributes[0]).Description;

    Console.WriteLine($"Description: {description}");
}
catch (Exception ex)
{
    Console.WriteLine($"Error retrieving description: {ex.Message}");
    // Fallback to the enum's string representation if attribute is not found or an error occurs
    Console.WriteLine(FunkyAttributesEnum.NameWithoutSpaces1.ToString());
}

Solution 2: Extension Method for Simplicity

This approach encapsulates the reflection logic into an extension method for any Enum type. It makes retrieving attributes cleaner and more reusable.

public static class EnumHelper
{
    /// <summary>
    /// Gets a custom attribute of a specified type from an enum value.
    /// </summary>
    /// <typeparam name="T">The type of the attribute to retrieve.</typeparam>
    /// <param name="enumVal">The enum value.</param>
    /// <returns>The attribute of type T, or null if not found.</returns>
    /// <example>string desc = myEnumVariable.GetAttributeOfType<DescriptionAttribute>().Description;</example>
    public static T GetAttributeOfType<T>(this Enum enumVal) where T : System.Attribute
    {
        var type = enumVal.GetType();
        var memInfo = type.GetMember(enumVal.ToString());

        if (memInfo.Length == 0)
        {
            return null;
        }

        var attributes = memInfo[0].GetCustomAttributes(typeof(T), false);
        return attributes.Length > 0 ? (T)attributes[0] : null;
    }
}

// Usage:
// string desc = myEnumVariable.GetAttributeOfType<DescriptionAttribute>().Description;

Solution 3: Generic Attribute Value Retrieval

This flexible solution allows you to retrieve a specific value from any attribute using a lambda expression.

public static class EnumExtensions
{
    /// <summary>
    /// Retrieves a specific value from a custom attribute applied to an enum member.
    /// </summary>
    /// <typeparam name="TAttribute">The type of the attribute.</typeparam>
    /// <typeparam name="TValue">The type of the value to retrieve from the attribute.</typeparam>
    /// <param name="enumeration">The enum value.</param>
    /// <param name="expression">A lambda expression to select the desired property from the attribute.</param>
    /// <returns>The attribute value, or the default for TValue if the attribute is not found.</returns>
    public static TValue GetAttributeValue<TAttribute, TValue>(this Enum enumeration, Func<TAttribute, TValue> expression)
        where TAttribute : Attribute
    {
        var attribute = enumeration
            .GetType()
            .GetMember(enumeration.ToString())
            .Where(member => member.MemberType == MemberTypes.Field)
            .FirstOrDefault()?
            .GetCustomAttributes(typeof(TAttribute), false)
            .Cast<TAttribute>()
            .SingleOrDefault();

        return attribute == null ? default : expression(attribute);
    }
}

// Usage:
// string description = targetLevel.GetAttributeValue<DescriptionAttribute, string>(x => x.Description);

Solution 7: Robust Reflection with FieldInfo

This addresses potential issues with GetMember by specifically using GetField for more reliable attribute retrieval, especially in cases with enum values that might have unusual member names.

using System;
using System.Linq;
using System.Reflection;

public static class AttributeExtensions
{
    /// <summary>
    /// Safely retrieves a custom attribute of type T from an enum value.
    /// </summary>
    public static T GetAttribute<T>(this Enum enumValue) where T : Attribute
    {
        var type = enumValue.GetType();
        // Use GetField for more reliable access to the enum member
        FieldInfo field = type.GetField(enumValue.ToString());
        if (field == null) return null;

        return (T)Attribute.GetCustomAttribute(field, typeof(T), false);
    }

    // Alternative using GetField directly for attribute retrieval
    public static T GetAttributeViaField<T>(this Enum value) where T : Attribute
    {
        Type type = value.GetType();
        FieldInfo field = type.GetField(value.ToString());
        if (field == null) return null;

        Attribute attr = Attribute.GetCustomAttribute(field, typeof(T), false);
        return (T)attr;
    }
}

Solution 8: DisplayName and ShortName Retrieval

This solution focuses on extracting Name and ShortName from the DisplayAttribute, with a fallback to a title-cased string representation of the enum value.

using System;
using System.ComponentModel.DataAnnotations;
using System.Globalization;
using System.Reflection;
using System.Text.RegularExpressions;

public static class EnumHelper
{
    /// <summary>
    /// Gets the DisplayAttribute's Name, or a title-cased version of the enum value if the attribute is missing.
    /// </summary>
    public static string GetDisplayName<TEnum>(this TEnum value) where TEnum : struct, IConvertible
    {
        var attr = value.GetAttributeOfType<TEnum, DisplayAttribute>();
        return attr == null ? value.ToString().ToSpacedTitleCase() : attr.Name;
    }

    /// <summary>
    /// Gets the DisplayAttribute's ShortName, or a title-cased version of the enum value if the attribute is missing.
    /// </summary>
    public static string GetDisplayShortName<TEnum>(this TEnum value) where TEnum : struct, IConvertible
    {
        var attr = value.GetAttributeOfType<TEnum, DisplayAttribute>();
        return attr == null ? value.ToString().ToSpacedTitleCase() : attr.ShortName;
    }

    /// <summary>
    /// Helper to get an attribute of a specific type for an enum value.
    /// </summary>
    private static TAttribute GetAttributeOfType<TEnum, TAttribute>(this TEnum value)
        where TEnum : struct, IConvertible
        where TAttribute : Attribute
    {
        var type = value.GetType();
        var memInfo = type.GetMember(value.ToString());
        if (memInfo.Length == 0) return null;

        return memInfo[0].GetCustomAttributes(false).OfType<TAttribute>().LastOrDefault();
    }

    /// <summary>
    /// Converts camel or pascal case strings to spaced title case.
    /// </summary>
    public static string ToSpacedTitleCase(this string s)
    {
        // Adapted from: https://stackoverflow.com/a/155486/150342
        CultureInfo cultureInfo = Thread.CurrentThread.CurrentCulture;
        TextInfo textInfo = cultureInfo.TextInfo;
        return textInfo.ToTitleCase(Regex.Replace(s, "([a-z](?=[A-Z0-9])|[A-Z](?=[A-Z][a-z]))", "$1 "));
    }
}

Solution 9: Concise Description Retrieval with Exception Handling

A compact, single-line method is provided, along with a more readable version that throws an exception if the DescriptionAttribute is missing. It also includes a method to get an enum value from its description.

using System;
using System.ComponentModel;
using System.Reflection;

public static class EnumExtensions
{
    /// <summary>
    /// Gets the DescriptionAttribute's Description, throwing an exception if not found.
    /// </summary>
    public static string GetDescription(this Enum value)
    {
        return value.GetType()
            .GetMember(value.ToString())
            .First()?
            .GetCustomAttribute<DescriptionAttribute>() is DescriptionAttribute attribute
            ? attribute.Description
            : throw new Exception($"Enum member '{value.GetType()}.{value}' doesn't have a [DescriptionAttribute]!");
    }

    /// <summary>
    /// Retrieves an enum value based on its DescriptionAttribute.
    /// </summary>
    public static T GetEnum<T>(this string description) where T : Enum
    {
        foreach (FieldInfo fieldInfo in typeof(T).GetFields())
        {
            if (fieldInfo.GetCustomAttribute<DescriptionAttribute>() is DescriptionAttribute attribute && attribute.Description == description)
                return (T)fieldInfo.GetRawConstantValue();
        }

        throw new Exception($"Enum '{typeof(T)}' doesn't have a member with a [DescriptionAttribute('{description}')]!");
    }
}

Solution 10: Performance-Optimized Enum Attribute Retrieval

This solution focuses on performance by optimizing the reflection process, particularly for frequent attribute lookups.

using System;
using System.Globalization;
using System.Linq;
using System.Reflection;

public static class AdvancedEnumExtensions
{
    /// <summary>
    /// Efficiently gets a custom attribute of type T from an enum value.
    /// </summary>
    public static T GetCustomAttribute<T>(this Enum value) where T : Attribute
    {
        return GetField(value)?.GetCustomAttribute<T>(inherit: false);
    }

    /// <summary>
    /// Gets the FieldInfo for an enum constant.
    /// </summary>
    public static FieldInfo GetField(this Enum value)
    {
        ulong u64 = ToUInt64(value);
        return value.GetType()
            .GetFields(BindingFlags.Public | BindingFlags.NonPublic | BindingFlags.Static)
            .Where(f => ToUInt64(f.GetRawConstantValue()) == u64)
            .FirstOrDefault();
    }

    /// <summary>
    /// Checks if an enum constant is defined.
    /// </summary>
    public static bool IsDefined(this Enum value)
    {
        return GetField(value) != null;
    }

    /// <summary>
    /// Converts an enum value to UInt64.
    /// </summary>
    public static ulong ToUInt64(this Enum value) => ToUInt64((object)value);

    private static ulong ToUInt64(object value)
    {
        switch (Convert.GetTypeCode(value))
        {
            case TypeCode.SByte:
            case TypeCode.Int16:
            case TypeCode.Int32:
            case TypeCode.Int64:
                return unchecked((ulong)Convert.ToInt64(value, CultureInfo.InvariantCulture));

            case TypeCode.Byte:
            case TypeCode.UInt16:
            case TypeCode.UInt32:
            case TypeCode.UInt64:
            case TypeCode.Char:
            case TypeCode.Boolean:
                return Convert.ToUInt64(value, CultureInfo.InvariantCulture);

            default: throw new InvalidOperationException("UnknownEnumType");
        }
    }
}

Solution 11: Creating a Dictionary from Enum Descriptions

This method generates a dictionary mapping enum descriptions to their integer values, which can be useful for UI elements or data mapping.

using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Linq;
using System.Reflection;

public static class EnumExtensions
{
    /// <summary>
    /// Creates a dictionary from enum values, mapping their descriptions to their integer values.
    /// </summary>
    public static IDictionary<string, int> ToDictionary(this Type enumType)
    {
        if (!enumType.IsEnum)
        {
            throw new ArgumentException("Type must be an enumerated type.");
        }

        return Enum.GetValues(enumType)
            .Cast<object>()
            .ToDictionary(v => ((Enum)v).ToEnumDescription(), k => (int)k);
    }

    /// <summary>
    /// Helper extension method to get the description of an enum value.
    /// </summary>
    public static string ToEnumDescription(this Enum en)
    {
        Type type = en.GetType();
        MemberInfo[] memInfo = type.GetMember(en.ToString());
        if (memInfo.Length > 0)
        {
            object[] attrs = memInfo[0].GetCustomAttributes(typeof(DescriptionAttribute), false);
            if (attrs.Length > 0)
                return ((DescriptionAttribute)attrs[0]).Description;
        }
        return en.ToString();
    }
}

public enum ActivityType
{
    [Description("Drip Plan Email")] DripPlanEmail = 1,
    [Description("Modification")] Modification = 2,
    [Description("View")] View = 3,
    [Description("E-Alert Sent")] EAlertSent = 4,
    [Description("E-Alert View")] EAlertView = 5
}

Solution 12: Enum to Description and Back

This solution provides methods to display enum descriptions and also to retrieve an enum value from its description string, handling missing attributes gracefully.

using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.Reflection;

public static class EnumExtensions
{
    /// <summary>
    /// Retrieves any custom attribute of type T from an enum value.
    /// </summary>
    public static T GetAttribute<T>(this Enum value) where T : Attribute
    {
        var type = value.GetType();
        var memberInfo = type.GetMember(value.ToString());
        if (memberInfo.Length == 0) return null;

        var attributes = memberInfo[0].GetCustomAttributes(typeof(T), false);
        return attributes.Length > 0 ? (T)attributes[0] : null;
    }

    /// <summary>
    /// Retrieves the Description attribute's Description property from an enum value.
    /// </summary>
    public static string ToName(this Enum value)
    {
        var attribute = value.GetAttribute<DescriptionAttribute>();
        return attribute == null ? value.ToString() : attribute.Description;
    }

    /// <summary>
    /// Finds an enum value based on its Description attribute.
    /// </summary>
    /// <typeparam name="T">The enum type.</typeparam>
    /// <param name="desc">The description string to find.</param>
    /// <returns>The enum value if found.</returns>
    /// <exception cref="Exception">Thrown if no matching enum value is found.</exception>
    public static T FromName<T>(this string desc) where T : struct
    {
        T result = (T)Enum.GetValues(typeof(T)).GetValue(0); // Default to the first value
        bool found = false;

        foreach (object enumVal in Enum.GetValues(typeof(T)))
        {
            if (((Enum)enumVal).ToName() == desc)
            {
                result = (T)enumVal;
                found = true;
                break;
            }
        }

        if (!found)
        {
            throw new Exception($"Enum value with description '{desc}' not found.");
        }
        return result;
    }
}

// Example Enum:
public enum Colour
{
    [Description("Colour Red")] Red = 0,
    [Description("Colour Green")] Green = 1,
    [Description("Colour Blue")] Blue = 2,
    Yellow = 3 // No description attribute
}

Solution 13: Simple Description Retrieval

A straightforward extension method to get the DescriptionAttribute’s value, falling back to the enum’s string representation if the attribute is absent.

using System;
using System.ComponentModel;
using System.Reflection;

public static class EnumExtension
{
    /// <summary>
    /// Retrieves the DescriptionAttribute's Description for an enum value.
    /// </summary>
    public static string ToDescription(this Enum value)
    {
        FieldInfo fi = value.GetType().GetField(value.ToString());
        if (fi == null) return value.ToString();

        var attributes = (DescriptionAttribute[])fi.GetCustomAttributes(typeof(DescriptionAttribute), false);
        return attributes.Length > 0 ? attributes[0].Description : value.ToString();
    }
}

Solution 14: .NET Core Compatible Attribute Retrieval

Solution 15: Net Framework vs. Net Core Description Handling

This addresses potential differences in how DescriptionAttribute might be accessed, especially distinguishing between .NET Framework’s direct access and .NET Core’s potential use of DisplayAttribute.

using System;
using System.ComponentModel;
using System.ComponentModel.DataAnnotations;
using System.Linq;
using System.Reflection;

public static class EnumerationExtension
{
    /// <summary>
    /// Retrieves the Description for an enum value, compatible with .NET Framework.
    /// </summary>
    public static string DescriptionFramework(this Enum value)
    {
        var field = value.GetType().GetField(value.ToString());
        if (field == null) return "Description Not Found";

        var attributes = field.GetCustomAttributes(typeof(DescriptionAttribute), false);
        return attributes.Any() ? ((DescriptionAttribute)attributes.ElementAt(0)).Description : "Description Not Found";
    }

    /// <summary>
    /// Retrieves the Description for an enum value, adapted for .NET Core using DisplayAttribute.
    /// </summary>
    public static string DescriptionCore(this Enum value)
    {
        var field = value.GetType().GetField(value.ToString());
        if (field == null) return "Description Not Found";

        var attributes = field.GetCustomAttributes(false);
        dynamic displayAttribute = attributes.FirstOrDefault(attr => attr is DisplayAttribute);

        return displayAttribute?.Description ?? "Description Not Found";
    }
}

// Example Enum:
public enum ExportTypes
{
    [Display(Name = "csv", Description = "text/csv")] CSV = 0
}

// var myDescription = myEnum.DescriptionFramework(); // or DescriptionCore()

Solution 17: Modern C# for Concise Attribute Retrieval

Leveraging newer C# features like pattern matching and expression-bodied members, this offers a compact way to get attributes and descriptions.

using System;
using System.ComponentModel;
using System.Linq;
using System.Reflection;

public static class EnumExtensions
{
    /// <summary>
    /// Retrieves a custom attribute of a specific type using modern C# features.
    /// </summary>

    {
        var memberInfo = enumVal.GetType().GetMember(enumVal.ToString());

    /// </summary>

}

Solution 18: Custom Attribute and Enum Mapping

This approach defines a custom attribute (FieldTextAttribute) and provides methods to map enum values to a model containing the attribute’s text, enum name, and value.

using System;
using System.Collections.Generic;
using System.Linq;
using System.Reflection;

// Custom Attribute Definition
[AttributeUsage(AttributeTargets.Field)]
public class FieldTextAttribute : Attribute
{
    public string Text { get; }
    public FieldTextAttribute(string text) { Text = text; }
}

// Model to hold enum data
public class MemberTypeModel
{
    public string MemberAttributeName { get; set; }
    public string MemberName { get; set; }
    public int MemberValue { get; set; }
}

// Example Enum
public enum MemberType
{
    [FieldText("Yönetim Kurul Üyesi")] BoardManager = 0,
    [FieldText("Temsilci")] Representative = 1,
    [FieldText("Üye")] Member = 2
}

public static class EnumHelper
{
    /// <summary>
    /// Retrieves a custom attribute of a specified type from an enum member.
    /// </summary>
    public static T GetMemberCustomText<T>(MemberType memberType) where T : Attribute
    {
        var enumType = memberType.GetType();
        var name = Enum.GetName(enumType, memberType);
        FieldInfo field = enumType.GetField(name);
        if (field == null) return null;

        return field.GetCustomAttributes(false).OfType<T>().SingleOrDefault();
    }

    /// <summary>
    /// Maps enum values to a list of models containing attribute text, name, and value.
    /// </summary>
    public static List<MemberTypeModel> GetMemberTypes()
    {
        return Enum.GetValues(typeof(MemberType))
            .Cast<MemberType>()
            .Select(et => new MemberTypeModel
            {
                MemberAttributeName = GetMemberCustomText<FieldTextAttribute>(et)?.Text,
                MemberName = Enum.GetName(et.GetType(), et),
                MemberValue = (int)et
            }).ToList();
    }
}

Solution 19: Handling DisplayAttribute Name Equivalence

This solution addresses a specific scenario where the DisplayAttribute.Name might be the same as the enum member’s name, providing a fallback to the enum member’s name in such cases.

using System;
using System.ComponentModel.DataAnnotations;
using System.Linq;
using System.Reflection;

public enum DataFilters
{
    [Display(Name = "Equals")] Equals = 1, // Display Name and Enum Name are the same
    [Display(Name = "Does Not Equal")] DoesNotEqual = 2 // Display Name and Enum Name are different
}

public static class EnumExtensions
{
    /// <summary>
    /// Gets the DisplayAttribute's Name, falling back to the enum member's name if they are identical or the attribute is missing.
    /// </summary>
    public static string GetDisplayName(this Enum enumValue)
    {
        var enumMember = enumValue.GetType().GetMember(enumValue.ToString()).FirstOrDefault();
        if (enumMember == null) return enumValue.ToString();

        var displayAttribute = enumMember.GetCustomAttribute<DisplayAttribute>();

        // Check if the DisplayName is the same as the enum member's name or if the attribute is missing.
        if (displayAttribute != null && displayAttribute.Name != enumValue.ToString())
        {
            return displayAttribute.Name;
        }
        else
        {
            return enumValue.ToString(); // Fallback to enum member name
        }
    }
}

Solution 21: Retrieval via XmlEnumAttribute

This method specifically retrieves the string representation of an enum value using the XmlEnumAttribute, with a fallback to ToString() if the attribute is not present.

using System;
using System.Linq;
using System.Reflection;
using System.Xml.Serialization;

public static class EnumExtensions
{
    /// <summary>
    /// Retrieves the XmlEnumAttribute's Name for an enum value, or its string representation if the attribute is missing.
    /// </summary>
    public static string ToStringUsingXmlEnumAttribute<T>(this T enumValue) where T : struct, IConvertible
    {
        if (!typeof(T).IsEnum)
        {
            throw new ArgumentException("T must be an enumerated type");
        }

        var type = typeof(T);
        var memInfo = type.GetMember(enumValue.ToString());
        if (memInfo.Length != 1) return enumValue.ToString();

        var attributes = memInfo[0].GetCustomAttributes(typeof(XmlEnumAttribute), false);
        return attributes.Length == 1 ? ((XmlEnumAttribute)attributes[0]).Name : enumValue.ToString();
    }
}

Solution 25: Custom Attribute and HTML Helper Integration

This solution demonstrates defining a custom attribute (EnumDisplayName) and integrating it with an HtmlHelper extension for use in web applications, mapping enum values to display names.

using System;
using System.Web.Mvc; // Assuming ASP.NET MVC context
using System.Reflection;

// Custom Attribute Definition
[AttributeUsage(AttributeTargets.Field, AllowMultiple = false)]
public class EnumDisplayName : Attribute
{
    public string Name { get; private set; }
    public EnumDisplayName(string name) { Name = name; }
}

// Example Enum
public enum EPriceType { /* ... */ }

// HTML Helper Extension
public static class EnumHelper
{
    public static string EnumDisplayName(this HtmlHelper helper, EPriceType priceType)
    {
        FieldInfo[] fields = priceType.GetType().GetFields();
        foreach (FieldInfo field in fields)
        {
            if ((int)field.GetValue(priceType) == (int)priceType)
            {
                var attributes = field.GetCustomAttributes(false);
                if (attributes.Length > 0)
                {
                    var retAttr = (EnumDisplayName)attributes[0];
                    return retAttr.Name;
                }
            }
        }
        throw new Exception("Error determining attributes for price type.");
    }
}

Solution 27: Getting All Enum Descriptions

This extension method iterates through all values of an enum type and collects their descriptions into a list of strings.

using System;
using System.Collections.Generic;
using System.Linq;
using System.Reflection;

public static class EnumExtensions
{
    /// <summary>
    /// Retrieves a list of descriptions for all members of an enum type.
    /// </summary>
    public static List<string> GetAllEnumDescriptions(this Type enumType)
    {
        if (!enumType.IsEnum)
        {
            throw new ArgumentException("Type must be an enumerated type.");
        }

        var enumList = Enum.GetValues(enumType).Cast<Enum>().ToList();
        var descriptions = new List<string>();
        foreach (var enumItem in enumList)
        {
            descriptions.Add(enumItem.ToDescription()); // Assuming ToDescription from Solution 13
        }
        return descriptions;
    }
}

FAQs on Retrieving Enum Attributes

FAQs on Retrieving Enum Attributes

Q: How do I get the DescriptionAttribute from an enum value in C#

ANS: You can use reflection. Access the enum’s type, get the member corresponding to the enum value, and then use GetCustomAttributes to retrieve the DescriptionAttribute. Solution 1 provides a basic example, while Solution 2 offers a reusable extension method.

Q: What is the most efficient way to get enum descriptions

ANS: For frequently accessed descriptions, manually mapping enum values to their descriptions in a Dictionary (Solution 24) avoids reflection overhead. For general use, Solution 10 offers performance optimizations for reflection-based retrieval.

Q: Can I get attributes other than DescriptionAttribute

ANS: Yes, the reflection techniques shown (like GetCustomAttributes) are generic and can retrieve any attribute type applied to an enum member. Solutions 2, 3, 6, and 17 demonstrate how to specify the attribute type you’re looking for.

Q: How do I handle enums with missing attributes

ANS: Most solutions include fallbacks. They might return the enum’s default string representation (enumValue.ToString()) or throw an exception if an attribute is expected but not found. Review the specific fallback logic in each solution.

Q: Is there a library for easier enum attribute handling

ANS: Yes, the Enums.Net NuGet package (Solution 20) is highly recommended for simplified and feature-rich enum attribute management. Solution 23 also suggests EnumCentricStatusManagement.
