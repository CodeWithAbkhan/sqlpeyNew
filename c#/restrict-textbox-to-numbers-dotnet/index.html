“How to Restrict .NET TextBox Input to Numbers Only?”

Ensuring that a TextBox control in a .NET application accepts only numeric input is a common requirement for data integrity. Whether you need to accept integers, floating-point numbers, or even negative values, there are several robust methods to achieve this. This discussion explores various techniques, from handling keyboard events to creating custom controls, providing practical code examples for each.

One of the most direct approaches involves intercepting keyboard input. By handling the KeyPress event of the TextBox, you can inspect each character being typed and decide whether to allow it.

Solution 1: Handling KeyPress with Character Checks

This method involves checking if the character being pressed is a digit or a control character (like Backspace) or a decimal point.

private void textBox1_KeyPress(object sender, KeyPressEventArgs e)
{
    // Allow digits and control characters (like backspace)
    if (!char.IsControl(e.KeyChar) && !char.IsDigit(e.KeyChar) && (e.KeyChar != '.'))
    {
        e.Handled = true; // Suppress the character
    }

    // Prevent multiple decimal points
    if (e.KeyChar == '.' && ((sender as TextBox).Text.IndexOf('.') > -1))
    {
        e.Handled = true;
    }
}

You can adapt this code to allow negative signs by checking for '-' at the beginning of the text, or to limit the number of digits by setting the MaxLength property of the TextBox. For instance, to allow only two digits:

textBox1.MaxLength = 2;

Solution 2: Simplified KeyPress Logic

A more concise version of the KeyPress handling focuses solely on allowing digits and control characters.

private void textBox1_KeyPress(object sender, KeyPressEventArgs e)
{
    e.Handled = !char.IsDigit(e.KeyChar) && !char.IsControl(e.KeyChar);
}

Important Note: These KeyPress methods do not inherently prevent users from pasting invalid data into the TextBox. For a more complete solution, consider other validation methods.

Solution 3: Using TextChanged and Regular Expressions

The TextChanged event can be coupled with regular expressions to validate the entire content of the TextBox whenever it changes.

private void textBox1_TextChanged(object sender, EventArgs e)
{
    if (System.Text.RegularExpressions.Regex.IsMatch(textBox1.Text, "[^0-9]"))
    {
        MessageBox.Show("Please enter only numbers.");
        // Remove the last invalid character entered
        textBox1.Text = textBox1.Text.Remove(textBox1.Text.Length - 1);
    }
}

This approach provides immediate feedback upon detection of non-numeric characters.

Solution 4: Creating a Custom TextBox Control

For reusability and a cleaner approach, you can create a custom TextBox that inherits from the base TextBox class and overrides its behavior.

A NumericTextBox could be implemented by overriding OnKeyPress to filter input. For more advanced scenarios, including handling copy/paste and negative numbers, a custom control that overrides WndProc or utilizes Validating events might be necessary.

Here’s an example of a custom Int32TextBox:

using System.Windows.Forms;
using System.Globalization;

public class Int32TextBox : TextBox
{
    protected override void OnKeyPress(KeyPressEventArgs e)
    {
        base.OnKeyPress(e);

        NumberFormatInfo fi = CultureInfo.CurrentCulture.NumberFormat;
        string c = e.KeyChar.ToString();

        if (char.IsDigit(c, 0)) return; // Allow digits
        if ((SelectionStart == 0) && (c.Equals(fi.NegativeSign))) return; // Allow leading minus sign

        // Handle copy/paste (Ctrl+C, Ctrl+V)
        if ((((int)e.KeyChar == 22) || ((int)e.KeyChar == 3)) && ((ModifierKeys & Keys.Control) == Keys.Control)) return;
        if (e.KeyChar == '\b') return; // Allow backspace

        e.Handled = true; // Suppress other characters
    }

    protected override void WndProc(ref Message m)
    {
        const int WM_PASTE = 0x0302;
        if (m.Msg == WM_PASTE)
        {
            string clipboardText = Clipboard.GetText();
            if (string.IsNullOrEmpty(clipboardText)) return;

            if ((clipboardText.IndexOf('+') >= 0) && (SelectionStart != 0)) return; // Disallow '+' not at start

            if (!int.TryParse(clipboardText, out int parsedValue)) return; // Ensure clipboard content is a valid int

            if ((parsedValue < 0) && (SelectionStart != 0)) return; // Disallow negative numbers not at start
        }
        base.WndProc(ref m);
    }
}

This custom Int32TextBox allows digits, a leading negative sign, and handles paste operations to ensure only valid integer input.

Solution 5: Using Validating and Validated Events

The Validating event is triggered when the control loses focus, providing an opportunity to validate its content.

private void textBox1_Validating(object sender, System.ComponentModel.CancelEventArgs e)
{
    if (System.Text.RegularExpressions.Regex.IsMatch(textBox1.Text, "[^0-9]"))
    {
        MessageBox.Show("Invalid input. Please enter only numbers.");
        e.Cancel = true; // Prevent the control from losing focus
        // Optionally, change background color to indicate an error
        textBox1.BackColor = System.Drawing.Color.LightCoral;
    }
    else
    {
        // Reset background color if valid
        textBox1.BackColor = System.Drawing.SystemColors.Window;
    }
}

Remember to provide visual feedback when e.Cancel is set to true, such as changing the background color, and reset it when the input is valid.

Solution 9: Comprehensive Decimal Input Handling

This solution provides detailed logic within a KeyPress event handler for accepting decimal numbers, including signs and single decimal points.

private bool IsOKForDecimalTextBox(char theCharacter, TextBox theTextBox)
{
    // Basic allowed characters: control, digit, '.', '-', '+'
    if (!char.IsControl(theCharacter) && !char.IsDigit(theCharacter) &&
        theCharacter != '.' && theCharacter != '-' && theCharacter != '+')
    {
        return false;
    }

    // Allow only one decimal point
    if (theCharacter == '.' && theTextBox.Text.IndexOf('.') > -1) return false;

    // Allow only one minus sign
    if (theCharacter == '-' && theTextBox.Text.IndexOf('-') > -1) return false;

    // Allow only one plus sign
    if (theCharacter == '+' && theTextBox.Text.IndexOf('+') > -1) return false;

    // Only one sign allowed, and it must be at the beginning
    if ((theCharacter == '-' || theCharacter == '+') && theTextBox.SelectionStart != 0) return false;
    if (((theCharacter == '-' || theCharacter == '+')) &&
        (theTextBox.Text.IndexOf('-') > -1 || theTextBox.Text.IndexOf('+') > -1)) return false;

    // Digits and decimals are only allowed after a sign if present
    if ((char.IsDigit(theCharacter) || theCharacter == '.') &&
        (theTextBox.Text.IndexOf('-') > -1 || theTextBox.Text.IndexOf('+') > -1) &&
        theTextBox.SelectionStart == 0) return false;

    return true;
}

You would call this method from the KeyPress event: e.Handled = !IsOKForDecimalTextBox(e.KeyChar, (TextBox)sender);

Solution 10: RegexTextBox Custom Control

A dedicated RegexTextBox can enforce input based on a regular expression.

using System.Text.RegularExpressions;

public class RegexTextBox : TextBox
{
    private string _lastText;
    public Regex Regex { get; set; }

    public string RegexString {
        get => Regex?.ToString() ?? string.Empty;
        set {
            Regex = string.IsNullOrEmpty(value) ? null : new Regex(value);
        }
    }

    protected override void OnTextChanged(EventArgs e)
    {
        if (Regex != null && !Regex.IsMatch(Text))
        {
            int pos = SelectionStart - Text.Length + (_lastText ?? string.Empty).Length;
            Text = _lastText;
            SelectionStart = Math.Max(0, pos);
        }
        _lastText = Text;
        base.OnTextChanged(e);
    }
}

Solution 11: KeyPress for Negative and Float Numbers

This KeyPress handler manages negative signs and decimal points for flexible numeric input.

private void textBox1_KeyPress(object sender, KeyPressEventArgs e)
{
    string currentText = ((Control)sender).Text;

    // Allow negative sign only at the beginning
    if (e.KeyChar == '-' && currentText.Length == 0) { e.Handled = false; return; }

    // Allow decimal point only once
    if (e.KeyChar == '.' && currentText.Length > 0 && !currentText.Contains(".")) { e.Handled = false; return; }

    // Reject any other non-digit, non-control characters
    e.Handled = (!char.IsDigit(e.KeyChar) && !char.IsControl(e.KeyChar));
}

Solution 15: LINQ-based Text Filtering

Using LINQ can provide a flexible way to filter characters, preserving caret position and handling copy/paste.

private void numeroCuenta_TextChanged(object sender, EventArgs e)
{
    string originalText = numeroCuenta.Text;
    string formattedText = string.Concat(originalText.Where(c => (c >= '0' && c <= '9')));

    if (formattedText != originalText)
    {
        int selectionStart = numeroCuenta.SelectionStart;
        // Adjust selection start if a character was removed before it
        if (selectionStart > 0 && formattedText.Length >= selectionStart && originalText[selectionStart - 1] != formattedText[selectionStart - 1])
        {
            selectionStart--;
        }
        numeroCuenta.Text = formattedText;
        numeroCuenta.SelectionStart = Math.Max(0, selectionStart); // Ensure selection start is valid
    }
}

This example filters for digits and handles caret positioning.

private void txt3_KeyPress(object sender, KeyPressEventArgs e)

Solution 21: TryParse with Custom TextBox Classes

A robust method involves creating custom TextBox classes that leverage TryParse for validation.

IntTextBox Example:

public class IntTextBox : TextBox
{
    private string _previousText = "";
    private int _backingResult;

    public IntTextBox() { TextChanged += IntTextBox_TextChanged; }
    public bool HasResult { get; private set; }
    public int Result => HasResult ? _backingResult : default(int);

    private void IntTextBox_TextChanged(object sender, EventArgs e)
    {
        HasResult = int.TryParse(Text, out _backingResult);
        if (HasResult || string.IsNullOrEmpty(Text)) _previousText = Text;
        else
        {
            int offset = Text.Length - _previousText.Length;
            int previousSelectionStart = Math.Max(0, SelectionStart - offset);
            Text = _previousText;
            SelectionStart = previousSelectionStart;
        }
    }
}

This class automatically validates and reverts to the last valid state if input is incorrect. Generic versions like ParsableTextBox<T> can also be created for wider applicability.

Solution 22: Abstract ValidatedTextBox

An abstract ValidatedTextBox can serve as a base for various validation needs, with concrete implementations like PositiveNumberTextBox.

public abstract class ValidatedTextBox : TextBox
{
    private string _lastValidText = string.Empty;
    protected abstract bool IsValid(string text);

    protected sealed override void OnTextChanged(EventArgs e)
    {
        if (!IsValid(Text))
        {
            int currentPos = SelectionStart - Text.Length + _lastValidText.Length;
            Text = _lastValidText;
            SelectionStart = Math.Max(0, currentPos);
        }
        _lastValidText = Text;
        base.OnTextChanged(e);
    }
}

public abstract class RegexedTextBox : ValidatedTextBox
{
    private readonly Regex _regex;
    protected RegexedTextBox(string regexPattern) { _regex = new Regex(regexPattern); }
    protected override bool IsValid(string text) => _regex.IsMatch(text);
}

public sealed class PositiveNumberTextBox : RegexedTextBox
{
    public PositiveNumberTextBox() : base(@"^\d*$") { } // Allows only digits
}

Solution 25: Advanced Text Manipulation for Numbers

This solution handles floating-point numbers, leading zeros, and cursor positioning during text changes.

private bool _isChanging = false;

private void myTextBox_TextChanged(object sender, EventArgs e)
{
    if (_isChanging) return;
    _isChanging = true;

    string text = myTextBox.Text;
    if (string.IsNullOrEmpty(text)) { _isChanging = false; return; }

    string validText = "";
    bool hasPeriod = false;
    int position = myTextBox.SelectionStart;

    for (int i = 0; i < text.Length; i++)
    {
        char currentChar = text[i];
        bool isInvalid = false;

        if (currentChar == '.')
        {
            if (hasPeriod) isInvalid = true;
            else hasPeriod = true;
        }
        else if (currentChar < '0' || currentChar > '9')
            isInvalid = true;

        if (!isInvalid) validText += currentChar;
        else if (i < position) position--;
    }

    // Trim leading zeros carefully
    while (validText.Length >= 2 && validText.StartsWith("0"))
    {
        if (validText[1] != '.') // Keep leading zero if followed by decimal
        {
            validText = validText.Substring(1);
            if (position > 0) position--;
        }
        else break;
    }

    myTextBox.Text = validText;
    myTextBox.SelectionStart = Math.Max(0, Math.Min(position, validText.Length)); // Keep cursor in bounds
    _isChanging = false;
}

Solution 26: IntegerBox Custom Control

A reusable IntegerBox that enforces Int64 values, handling overflows and format errors.

public class IntegerBox : TextBox
{
    private string _originalValue = "0";

    public IntegerBox()
    {
        Text = _originalValue;
        // ... other initializations
    }

    private void Integerbox_KeyPress(object sender, KeyPressEventArgs e)
    {
        _originalValue = Text; // Store current value before a potential change
    }

    private void Integerbox_TextChanged(object sender, EventArgs e)
    {
        try
        {
            if (string.IsNullOrWhiteSpace(Text)) Text = "0";
            Text = Convert.ToInt64(Text.Trim()).ToString();
        }
        catch (System.OverflowException)
        {
            MessageBox.Show($"Value exceeds Int64.MaxValue ({Int64.MaxValue}).");
            Text = _originalValue;
        }
        catch (FormatException)
        {
            Text = _originalValue; // Revert on format errors
        }
        catch (Exception ex)
        {
            Text = _originalValue;
            MessageBox.Show($"An error occurred: {ex.Message}");
        }
    }
}

FAQs on Restricting TextBox Input to Numbers Only

Q: What is the simplest way to allow only digits in a TextBox?

ANS: You can use the KeyPress event and check char.IsDigit(e.KeyChar):

private void textBox1_KeyPress(object sender, KeyPressEventArgs e)
{
    e.Handled = !char.IsDigit(e.KeyChar) && !char.IsControl(e.KeyChar);
}

Q: How can I allow decimal numbers and negative signs?

ANS: Combine checks in the KeyPress event for digits, the decimal point (ensuring only one), and the negative sign (ensuring it’s at the beginning). See Solutions 9 and 11 for detailed examples.

Q: Does the KeyPress method prevent pasting invalid data?

ANS: No, KeyPress events are not triggered for paste operations. For paste validation, you should handle events like TextChanged or WndProc, or use the Validating event.

Q: What is the benefit of creating a custom TextBox control for number input?

ANS: Creating a custom control offers reusability, encapsulation of logic, and cleaner code. It allows you to pre-configure validation rules and behaviors, making your UI development more efficient. See Solution 4 or 22.

Q: How can I limit the number of digits allowed in a TextBox?

ANS: Set the MaxLength property of the TextBox control to the desired number of digits. For example, textBox1.MaxLength = 5; will limit input to five digits.
