“R ggplot2 Strategies for Visualizing Data with Extreme Value Spreads”

When visualizing datasets in R using ggplot2, particularly when dealing with bar charts or scatter plots where one or a few data points possess values significantly larger than the rest (an extreme value spread), standard plotting often obscures the variance among the smaller values. How can we effectively represent both the overall distribution and the fine detail simultaneously?

Here are several accepted strategies implemented via different packages and approaches:

Strategy 1: Utilizing ggforce::facet_zoom()

The ggforce package offers the facet_zoom() extension, which provides a direct implementation for zooming into specific data ranges, addressing a suggestion often associated with Hadley Wickham’s commentary on this visualization challenge.

A basic zoomed facet looks like this:

# Assuming 'df' contains columns 'a' (value) and 'b' (category)
library(ggforce)
library(ggplot2)

# Example visualization zooming on the Y-axis range 0 to 10
ggplot(df) + 
  aes(x = b, y = a) +
  geom_col() +
  facet_zoom(ylim = c(0, 10))

Limitation Note: In earlier versions (like 0.2.2), ggforce sometimes conflicts with transformations like coord_flip(), potentially limiting its use to vertical bars initially.

The zoom.data parameter allows for finer control over which data points appear in the zoomed section:

library(ggforce)
library(ggplot2)

ggplot(df) + 
  aes(x = b, y = a) +
  geom_col() +
  # Only show data points <= 10 in the zoomed area, exclude others (NA or FALSE)
  facet_zoom(ylim = c(0, 10), zoom.data = ifelse(a <= 10, NA, FALSE))

Strategy 2: Displaying Two Separate Plots Side-by-Side

A widely suggested approach is to generate two distinct plots: one showing all the data at its full range, and a second focusing only on the smaller values for detail. These plots are then combined.

Creating the Two Plots:

library(ggplot2)

# Plot 1: Full data view
g1 <- ggplot(df) + 
  aes(x = b, y = a) +
  geom_col() +
  coord_flip() # Example using horizontal bars

# Plot 2: Zoomed view (e.g., restricting Y-axis up to a limit of 10)
g2 <- ggplot(df) + 
  aes(x = b, y = a) +
  geom_col() +
  coord_flip() +
  ylim(NA, 10) # NA allows the lower bound to be determined naturally, capping the top

Combining the Plots:

You can arrange these using various layout packages:

  • Using cowplot: cowplot::plot_grid(g1, g2)
  • Using ggpubr: ggpubr::ggarrange(g1, g2)
  • Using gridExtra: gridExtra::grid.arrange(g1, g2)
  • Using egg: egg::ggarrange(g1, g2)

Strategy 3: Using Facets to Show Subsets (Data Manipulation Required)

Interpreting the suggestion of separate facets—one for the whole dataset and one zoomed—requires manual data preparation since ggplot2 facets do not inherently handle separate axis scaling easily without extra steps.

This involves mutating the data frame to include a subset identifier and then plotting both subsets together, using facet_wrap with free scales:

library(dplyr)
library(ggplot2)

ggplot() + 
  aes(x = b, y = a) +
  # Plot 1: All data, tagged as "all" subset
  geom_col(data = df %>% mutate(subset = "all")) +
  # Plot 2: Filtered data (values <= 10), tagged as "small" subset
  geom_col(data = df %>% filter(a <= 10) %>% mutate(subset = "small")) +
  coord_flip() + 
  facet_wrap(~ subset, scales = "free_x") # Use free scales for independent axis limits

Strategy 4: Utilizing ggbreak for Axis Cuts

The ggbreak package provides scale_y_cut() or scale_x_cut(), which directly implement axis breaks or segment scaling within a single ggplot object. This is a modern and often elegant solution.

This allows parts of the axis to be scaled differently (zoomed in or out) using the scales argument.

df_example <- data.frame(a = c(1, 2, 3, 500), b = c('a1', 'a2', 'a3', 'a4'))

library(ggplot2)
library(ggbreak)
library(patchwork) # Useful for combining plots if necessary, though scale_y_cut works on one plot

# Plot with the first segment at normal scale and the third segment zoomed
p_zoomed <- ggplot(df_example, aes(x = b, y = a)) + 
  geom_col() +
  # Breaks define the division points (e.g., divide near 4, then near 30)
  # which defines which segment position gets which scale modification
  # scales defines the relative width/height of the subplot representation
  scale_y_cut(breaks=c(4, 30), which=c(1, 3), scales=c(0.5, 3)) 

# Displaying the result (often requires the patchwork package to combine plots if you want a 'normal' view alongside)
p_normal <- ggplot(df_example, aes(x = b, y = a)) + geom_col()
p_normal + p_zoomed # Combining using patchwork syntax

Parameters of scale_y_cut():

  • breaks: Numeric vector defining where the axis should be divided.
  • which: Integer indicating the subplot position (left-to-right or top-to-bottom) corresponding to the scaling modification.
  • scales: Numeric defining the relative visual representation size of each subplot section.

Strategy 5: Employing plotrix::gap.barplot (Non-ggplot Solution)

For users comfortable outside the ggplot2 ecosystem, the plotrix package offers direct functionality for creating bar plots with gaps, often used for broken axes, though it requires manual specification of axis elements.

library(plotrix)

# Assuming df$a holds the values and the bars are drawn horizontally
gap.barplot(df$a, gap=c(5, 495), horiz=T)

Strategy 6: Using facet_grid with Boolean Faceting

A clever approach involves creating a logical indicator column to facet by. By setting scales="free" and hiding the facet labels, you can create two distinct plotting areas side-by-side, allowing for different visual treatments or scales implicitly if necessary.

library(tidyverse)

# Create sample data where some values are high (e.g., > 3)
df_facet <- data.frame(
  myLetter = LETTERS[1:4], 
  myValue = runif(12) + rep(c(4, 0.5, 0.5), 4)[1:4]
)  
# Assign a facet based on a threshold
df_facet$myFacet <- df_facet$myValue > 3

(ggplot(df_facet, aes(y = myLetter, x = myValue)) 
  + geom_point() # Scatter plot used here, but geom_col works too
  + facet_grid(. ~ myFacet, scales = "free", space = "free")
  # Ensure breaks are set clearly across the potential range
  + scale_x_continuous(breaks = seq(0, max(df_facet$myValue) + 0.5, .5)) 
  + theme(strip.text.x = element_blank()) # Remove the TRUE/FALSE labels
)

Alternative Visualization Considerations

Using Logarithmic Scales

If the discrepancy is purely due to magnitude (e.g., data ranging from 1 to 1000), switching to a logarithmic scale can compress the larger values while revealing detail in the smaller ones.

ggplot(df) + 
  aes(x = b, y = a) +
  geom_col() +
  scale_y_continuous(trans = 'log10') # Use log10 transformation

Data Tables

Sometimes, visualizing the raw numbers in a well-formatted table is superior, especially for bar charts with fewer categories. The visual comparison of magnitudes might be less important than the precise values, and tables avoid the distortion inherent in broken axes.

FAQs on R ggplot2 Strategies for Extreme Value Spreads

Q: Is using a broken axis generally recommended in data visualization

ANS: Many statisticians caution against broken axes as they can be misleading or used to deceive the audience by obscuring the true magnitude differences. However, it is sometimes justified when standard continuous scales distort the perception of variation within the bulk of the data.

Q: Can I use ggforce facet_zoom with coord_flip

ANS: Older versions of ggforce sometimes encountered errors when combining facet_zoom() with coord_flip(). Test the current version or use alternative methods like dual plots if conflicts arise.

Q: What if my data has hundreds of bars

ANS: If you have numerous categories, bar charts with broken axes or extreme zooming become cumbersome. Consider grouping categories, using tables for precise values, or evaluating if a different visualization type (like density plots or scatter plots if appropriate) better serves the analytical goal.
