“Plotting Multiple Time Series in ggplot2: Wide to Long Format”

When working with time series data in R, you often encounter datasets where each variable of interest is in its own column, along with a date or time column. This is known as a “wide” format. While intuitive for data entry, ggplot2, a powerful visualization package in R, typically prefers data in a “long” or “tall” format for plotting multiple series effectively.

A “long” format consolidates your variables into two key columns: one that identifies the variable (e.g., “var0”, “var1”) and another that holds the corresponding value. This structure allows ggplot2 to easily map aesthetics like color or line type to different variables, creating separate lines for each time series on the same plot.

How can we transform our wide-format time series data into a long format suitable for ggplot2 to visualize multiple lines?

Solution 1: Manual Plotting for Few Variables

For a limited number of variables, you can manually construct the plot by adding a geom_line for each variable. This approach is straightforward but can become cumbersome as the number of variables increases.

# Assuming test_data is already loaded and in wide format
# Example data creation (replace with your actual data loading)
test_data <- data.frame(
  var0 = 100 + c(0, cumsum(runif(49, -20, 20))),
  var1 = 150 + c(0, cumsum(runif(49, -10, 10))),
  date = seq(as.Date("2002-01-01"), by="1 month", length.out=50)
)

ggplot(test_data, aes(date)) +
  geom_line(aes(y = var0, colour = "var0")) +
  geom_line(aes(y = var1, colour = "var1"))

Solution 2: Using tidyr::pivot_longer() or reshape2::melt()

The most common and scalable method involves reshaping your data from wide to long format. The tidyr package, with its pivot_longer() function, and the reshape2 package, with its melt() function, are excellent tools for this.

First, ensure you have the necessary packages installed and loaded:

install.packages("ggplot2")
install.packages("tidyr")
install.packages("reshape2") # If using melt()

library(ggplot2)
library(tidyr)
library(reshape2)
Using tidyr::pivot_longer()

This function is part of the tidyverse and is highly recommended for its flexibility. You specify which columns to pivot and create new name and value columns.

# Example data creation
test_data <- data.frame(
  var0 = 100 + c(0, cumsum(runif(49, -20, 20))),
  var1 = 150 + c(0, cumsum(runif(49, -10, 10))),
  date = seq(as.Date("2002-01-01"), by="1 month", length.out=50)
)

# Convert to long format using tidyr::pivot_longer
# 'cols' specifies which columns to pivot. 'starts_with("var")' selects columns beginning with "var".
test_data_long_tidyr <- pivot_longer(test_data, cols = starts_with("var"), names_to = "variable_name", values_to = "measurement_value")

# Plotting the long format data
ggplot(data = test_data_long_tidyr,
       aes(x = date, y = measurement_value, colour = variable_name)) +
  geom_line()
Using reshape2::melt()

The melt() function from reshape2 achieves a similar outcome. You specify the id variable(s) that should remain as is, and all other columns are “melted” into value columns.

# Example data creation
test_data <- data.frame(
  var0 = 100 + c(0, cumsum(runif(49, -20, 20))),
  var1 = 150 + c(0, cumsum(runif(49, -10, 10))),
  date = seq(as.Date("2002-01-01"), by="1 month", length.out=50)
)

# Convert to long format using reshape2::melt
# 'id.vars' are the columns to keep as identifiers.
test_data_long_melt <- melt(test_data, id.vars = "date", variable.name = "variable_name", value.name = "measurement_value")

# Plotting the long format data
ggplot(data = test_data_long_melt,
       aes(x = date, y = measurement_value, colour = variable_name)) +
  geom_line()

Both pivot_longer and melt transform your data so that each row represents a single observation of a single variable at a specific time point. This is the ideal structure for ggplot2 to create layered line plots.

Solution 3: Direct tidyr::gather() (Older syntax, pivot_longer is preferred)

Before pivot_longer, tidyr::gather was the primary function for this transformation. While pivot_longer is now recommended due to its improved syntax and flexibility, gather still works for this purpose.

library(ggplot2)
library(tidyr)

# Example data creation
test_data <- data.frame(
  var0 = 100 + c(0, cumsum(runif(49, -20, 20))),
  var1 = 150 + c(0, cumsum(runif(49, -10, 10))),
  date = seq(as.Date("2002-01-01"), by="1 month", length.out=50)
)

# Transform using tidyr::gather
# 'key' names the column that will store the original column names (var0, var1).
# 'value' names the column that will store the values from var0, var1.
# The remaining arguments are the columns to gather.
test_data %>%
  gather(key = "variable_name", value = "measurement_value", var0, var1) %>%
  ggplot(aes(x = date, y = measurement_value, colour = variable_name)) +
  geom_line()

After the transformation, your data will look something like this:

Solution 4: Plotting Vectors Directly (Limited Legend Functionality)

While ggplot2 excels with data frames, you can sometimes plot vectors directly. However, achieving a proper legend with this method can be challenging.

library(ggplot2)

# Example data creation
var0 <- 100 + c(0, cumsum(runif(49, -20, 20)))
var1 <- 150 + c(0, cumsum(runif(49, -10, 10)))
date <- seq(as.Date("2002-01-01"), by="1 month", length.out=50)

# Plotting directly
ggplot() +
  geom_line(aes(x = date, y = var0), colour = 'red') +
  geom_line(aes(x = date, y = var1), colour = 'blue') +
  ylab('Values') +
  xlab('Date')

This method assigns colors directly but makes it difficult to automatically generate a legend that maps colors to variable names like “var0” and “var1.”

Solution 5: Manual Stacking and Plotting

Another approach is to manually create a “stacked” data frame, which is essentially the long format. This method can be useful for understanding the data structure required by ggplot2.

library(ggplot2)

# Example data creation
test_data <- data.frame(
  var0 = 100 + c(0, cumsum(runif(49, -20, 20))),
  var1 = 150 + c(0, cumsum(runif(49, -10, 10))),
  Dates = seq.Date(as.Date("2002-01-01"), by="1 month", length.out=50)
)

# Manually create a stacked data frame
stacked_data <- data.frame(
  value = c(test_data$var0, test_data$var1),
  variable = factor(rep(c("Var0", "Var1"), each = NROW(test_data))),
  Dates = rep(test_data$Dates, 2)
)

# Plot the stacked data
p <- ggplot(stacked_data, aes(Dates, value, colour = variable))
p + geom_line()

This manual stacking explicitly builds the long format, making it clear how ggplot2 uses the variable column to differentiate the lines. While effective for a few variables, packages like tidyr automate this process efficiently.

FAQs on Plotting Multiple Time Series in ggplot2

Q: How do I plot multiple lines in ggplot2

ANS: To plot multiple lines in ggplot2, your data should be in a “long” format, where one column identifies the line (e.g., variable name) and another column contains the corresponding values. You then map the identifier column to an aesthetic like colour or group. Functions like tidyr::pivot_longer() or reshape2::melt() are used to convert wide-format data to long format.

Q: What is wide format versus long format

ANS: In “wide” format, each variable you want to plot has its own column, often with a date or time column. In “long” format, all your variables are stacked into two columns: one indicating the variable’s name and another holding its value. ggplot2 generally prefers long format for plotting multiple groups or series.

Q: Which is better, tidyr::pivot_longer or reshape2::melt

ANS: tidyr::pivot_longer() is generally preferred as it is part of the modern tidyverse and offers more flexibility and a clearer syntax for reshaping data compared to reshape2::melt(). However, both achieve the goal of converting wide data to long format for plotting.

Q: Can I plot directly from wide format

ANS: You can plot directly from wide format by manually adding a geom_line() for each variable, mapping y and colour within each geom_line(). However, this becomes unmanageable for many variables, and legend creation can be more complex than with long format data.
