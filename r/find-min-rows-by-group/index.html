“How to Find Rows with Minimum Values by Group in R?”

Finding Rows with Minimum Values by Group in R

When working with tabular data in R, a frequent requirement is to pinpoint the row(s) associated with the smallest value within defined groups. For instance, you might want to find the company with the fewest employees in each state. Several R packages excel at this, including data.table, dplyr, and base R functions.

Solution 1: Utilizing data.table with .SD

The data.table package is renowned for its speed and conciseness. One idiomatic approach uses the .SD (Subset of Data) special symbol along with which.min() to achieve this.

library(data.table)

# Sample data setup
DT <- data.table(
  State = c("AK", "RI", "AK", "RI", "CA"),
  Company = c("A", "B", "D", "E", "F"),
  Employees = c(30, 25, 24, 19, 50)
)

# Method 1a: Using .SD for elegance
result_sd <- DT[, .SD[which.min(Employees)], by = State]
print(result_sd)

Output:

   State Company Employees
1:    AK       D        24
2:    RI       E        19

For datasets with a large number of groups, an alternative that can offer a slight performance edge involves using .I (which returns row indices) instead of .SD.

# Method 1b: Using .I for potential speed improvement
result_i <- DT[DT[, .I[which.min(Employees)], by = State]$V1]
print(result_i)

Output:

   State Company Employees
1:    AK       D        24
2:    RI       E        19

If your data might contain multiple rows with the same minimum value within a group and you wish to retrieve all of them, simply replace which.min(Employees) with the logical condition Employees == min(Employees).

Solution 2: Leveraging dplyr

The dplyr package provides a very readable syntax for data manipulation. The group_by() and slice() functions work together effectively for this task.

library(dplyr)

# Sample data (using the same DT from above, but ensuring it's a tibble or data.frame)
data_frame <- as.data.frame(DT)

# Method 2a: Using group_by and slice with which.min
result_dplyr_slice <- data_frame %>%
  group_by(State) %>%
  slice(which.min(Employees))
print(result_dplyr_slice)

Output:

# A tibble: 2 × 3
# Groups:   State [2]
  State Company Employees
  <chr> <chr>       <dbl>
1 AK    D              24
2 RI    E              19

Since dplyr version 1.0.0, a more direct function, slice_min(), is available, which simplifies this operation further.

# Method 2b: Using slice_min (dplyr >= 1.0.0)
result_dplyr_slmin <- data_frame %>%
  group_by(State) %>%
  slice_min(order_by = Employees)
print(result_dplyr_slmin)

Output:

# A tibble: 2 × 3
# Groups:   State [2]
  State Company Employees
  <chr> <chr>       <dbl>
1 AK    D              24
2 RI    E              19

Solution 3: data.table with Ordering and Uniqueness

Another powerful strategy with data.table involves sorting the data by the value column first and then extracting unique entries based on the grouping column.

# Method 3a: Using order and unique with data.table
result_order_unique <- unique(setDT(data_frame)[order(Employees)], by = "State")
print(result_order_unique)

Output:

   State Company Employees
1:    RI       E        19
2:    AK       D        24

You can also combine ordering with .SD[1L] for a concise extraction.

# Method 3b: Using order and .SD[1L]
result_order_sd <- setDT(data_frame)[order(Employees), .SD[1L], by = State]
print(result_order_sd)

Output:

   State Company Employees
1:    RI       E        19
2:    AK       D        24

Using verbose = TRUE can provide insights into data.table’s optimization processes.

# Method 3c: Enhanced order/.SD[1L] with verbose
setDT(data_frame)[order(Employees), .SD[1L], by = State, verbose = TRUE]

Alternatively, the dplyr equivalent uses arrange() followed by distinct().

# Method 3d: Using dplyr's arrange and distinct
result_dplyr_distinct <- data_frame %>%
  arrange(Employees) %>%
  distinct(State, .keep_all = TRUE)
print(result_dplyr_distinct)

Output:

# A tibble: 2 × 3
  State Company Employees
  <chr> <chr>       <dbl>
1 RI    E              19
2 AK    D              24

A method borrowing from the idea of finding minimums per group and then joining back can be highly performant due to data.table’s gmin function and binary join capabilities.

# Method 3e: Data.table self-join with gmin
DT_temp <- setDT(data_frame)[, .(Employees = min(Employees)), by = State]
result_self_join <- data_frame[DT_temp, on = .(State, Employees), mult = "first"]
print(result_self_join)

Output:

   State Company Employees
1:    AK       D        24
2:    RI       E        19

Solution 4: Base R with by()

Base R’s by() function is suitable for applying functions to subsets of a data frame.

# Method 4a: Using base R by()
result_by <- by(data_frame, data_frame$State, function(x) x[which.min(x$Employees), ])
print(result_by)

Output:

data_frame$State: AK
  State Company Employees
3    AK       D        24

## Solutions
data_frame$State: RI
  State Company Employees
5    RI       E        19

To obtain a single data frame, the results can be combined using do.call(rbind, ...).

# Method 4b: Combining by() results with do.call(rbind, ...)
result_by_rbind <- do.call(rbind, result_by)
print(result_by_rbind)

Output:

  State Company Employees
3    AK       D        24
5    RI       E        19

Solution 5: Base R with ave()

The ave() function in base R can compute group-wise statistics, which can then be used for subsetting.

# Method 5a: Using ave() for direct comparison
result_ave_min <- data_frame[data_frame$Employees == ave(data_frame$Employees, data_frame$State, FUN = min), ]
print(result_ave_min)

Output:

  State Company Employees
3    AK       D        24
5    RI       E        19

An alternative variation uses ave() to create a logical vector directly.

# Method 5b: Using ave() to create a logical vector
result_ave_logical <- data_frame[as.logical(ave(data_frame$Employees, data_frame$State, FUN = function(x) x == min(x))), ]
print(result_ave_logical)

Output:

  State Company Employees
3    AK       D        24
5    RI       E        19

Solution 6: plyr Package

The plyr package, while older, offers a functional approach using ddply.

library(plyr)

# Method 6a: Using ddply
result_ddply <- ddply(data_frame, .(State), function(x) x[which.min(x$Employees), ])
print(result_ddply)

Output:

  State Company Employees
1    AK       D        24
2    RI       E        19

Solution 7: collapse Package

The collapse package provides fast, efficient data manipulation functions.

library(collapse)
library(magrittr)

# Method 7a: Using collapse
result_collapse <- data_frame %>%
  fgroup_by(State) %>%
  fsummarise(Employees = fmin(Employees)) # Note: This finds the minimum value, not the entire row.
print(result_collapse)

This method, as implemented above, identifies the minimum employee count per state. To get the entire row, a join or a different function would be needed. For finding minimums, collapse is highly efficient. You can explore collapse for more advanced data wrangling at collapse package .

Solution 8: data.table with Column Assignment

A very efficient data.table method involves creating a temporary column for the minimum value per group and then filtering based on it.

# Method 8a: Data.table min column
DT_min_col <- copy(DT) # Use a copy to avoid modifying the original DT
result_min_col <- DT_min_col[, E_min := min(Employees), by = State][Employees == E_min]
print(result_min_col)

Output:

   State Company Employees E_min
1:    AK       D        24    24
2:    RI       E        19    19

This approach is particularly beneficial if you need to select specific columns after finding the minimums.

# Example: Selecting specific columns with this method
result_specific_cols <- DT_min_col[, .SD[Employees == E_min], by = State, .SDcols = c("State", "Company", "Employees")]
print(result_specific_cols)

Output:

   State Company Employees
1:    AK       D        24
2:    RI       E        19

DT2_large <- copy(DT_large)

    "(data.table) min column: " = DT3_large[, E_min := min(Employees), by = State][Employees == E_min],
    "(data.table) .I[which.min]: " = DT_large[DT_large[, .I[which.min(Employees)], by = State]$V1],
    "(data.table) order/unique: " = unique(DT_large[order(Employees)], by = "State"),
    "(data.table) self join (setkey):" = {

FAQs on Finding Minimum Rows by Group in R

Q: How to get the row with the minimum value per group using R data.table

ANS: Use DT[, .SD[which.min(ValueCol)], by = GroupCol] or DT[.I[which.min(ValueCol)], by = GroupCol].

Q: What is the dplyr way to find the minimum row by group

ANS: Employ data %>% group_by(GroupCol) %>% slice_min(order_by = ValueCol). Prior to dplyr 1.0.0, slice(which.min(ValueCol)) was used.

Q: Can base R find the minimum row by group

ANS: Yes, data[data$ValueCol == ave(data$ValueCol, data$GroupCol, FUN=min), ] is an effective base R method.

Q: How to handle multiple rows with the same minimum value in a group

ANS: When using methods like data.table or dplyr, replace which.min() with a condition like ValueCol == min(ValueCol) or use slice_min(n = ...) with dplyr if you want a specific number of minimums.

Q: Which R package is fastest for finding minimum rows by group

ANS: Generally, data.table solutions are the fastest, especially for very large datasets. Benchmarks often show methods like self join or I[which.min] performing exceptionally well.
