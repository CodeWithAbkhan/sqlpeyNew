“ggplot2: Plotting Multiple Series with Custom Colors”

When visualizing multiple data series on a single plot in R’s ggplot2 package, you often need to assign specific colors to each series for clarity and aesthetic appeal. This involves mapping a constant color aesthetic within aes() for each geom_line and then using scale_colour_manual() to define these assignments. Let’s explore different approaches to achieve this, starting with a base dataset.

Sample Data Setup:

Solution 1: Direct Mapping within aes()

This approach directly assigns string values to the colour aesthetic for each geom_line call. These strings then serve as identifiers for scale_colour_manual.

library(ggplot2)

ggplot(data = datos, aes(x = fecha)) +
  geom_line(aes(y = TempMax, colour = "Maximum Temperature")) +
  geom_line(aes(y = TempMedia, colour = "Average Temperature")) +
  geom_line(aes(y = TempMin, colour = "Minimum Temperature")) +
  scale_colour_manual(name = "Temperature Type",
                      breaks = c("Maximum Temperature", "Average Temperature", "Minimum Temperature"),
                      values = c("Maximum Temperature"="red",
                                 "Average Temperature"="green",
                                 "Minimum Temperature"="blue")) +
  xlab("Date") +
  scale_y_continuous("Temperature (C)", limits = c(-10, 40)) +
  labs(title = "Daily Temperature Variations")

The core idea here is to map a constant string to the colour aesthetic within aes(). This string acts as a variable that scale_colour_manual then uses to link specific colors. The breaks argument in scale_colour_manual controls the order of items in the legend, and values provides the color mapping.

Solution 2: Reshaping Data with tidyr

A more idiomatic ggplot2 approach involves reshaping the data into a “long” format, where one column indicates the temperature type and another holds the corresponding values. This allows a single geom_line call to handle all series.

library(ggplot2)
library(tidyr)

dd_tidyr <- pivot_longer(datos, cols = -fecha, names_to = "TemperatureType", values_to = "TemperatureValue")

ggplot(dd_tidyr) +
  geom_line(aes(x = fecha, y = TemperatureValue, colour = TemperatureType)) +
  scale_colour_manual(name = "Temperature Type",
                      values = c("TempMax"="red", "TempMedia"="green", "TempMin"="blue")) +
  xlab("Date") +
  scale_y_continuous("Temperature (C)", limits = c(-10, 40)) +
  labs(title = "Daily Temperature Variations (Tidy Format)")

Alternative Reshaping:

The reshape2 package (though now superseded by tidyr) offers another way to achieve this long format:

library(reshape2)
dd_melt <- melt(datos, id.vars = "fecha", variable.name = "TemperatureType", value.name = "TemperatureValue")

ggplot(dd_melt) +
  geom_line(aes(x = fecha, y = TemperatureValue, colour = TemperatureType)) +
  scale_colour_manual(name = "Temperature Type",
                      values = c("TempMax"="red", "TempMedia"="green", "TempMin"="blue")) +
  xlab("Date") +
  scale_y_continuous("Temperature (C)", limits = c(-10, 40)) +
  labs(title = "Daily Temperature Variations (Melted Format)")

This “tidy data” principle, where each observation is a row, often simplifies plotting in ggplot2. The pivot_longer function (or melt) transforms the wide-format data into a long format, making it easier to map aesthetics like color to the different temperature types.

Solution 3: Using scale_color_identity

This method involves assigning color values directly to the data and then using scale_color_identity to manage the legend.

library(ggplot2)

temp_plot <- ggplot(data = datos, aes(x = fecha)) +
  geom_line(aes(y = TempMax, colour = "red")) +
  geom_line(aes(y = TempMedia, colour = "green")) +
  geom_line(aes(y = TempMin, colour = "blue")) +
  labs(title = "Daily Temperature Variations (Identity Scale)") +
  ylab("Temperature (C)") +
  xlab("Date") +
  scale_y_continuous(limits = c(-10, 40)) +
  scale_color_identity(name = "Temperature Type",
                       breaks = c('red', 'green', 'blue'),
                       labels = c("TempMax", "TempMedia", "TempMin"),
                       guide = 'legend')

temp_plot

The key here is mapping literal color strings (“red”, “green”, “blue”) within the aes() of each geom_line. scale_color_identity then takes these literal color values and creates the legend, allowing you to specify custom breaks (the color values) and labels (the desired legend text).

Solution 4: Plotting in a Loop with Dynamic Colors

For scenarios where the number of series is not fixed or determined dynamically, a loop-based approach can be employed. This requires careful management of aesthetics.

library(ggplot2)

# Sample data structure (as provided in Solution 1)
data <- structure(list(month = structure(c(1317452400, 1317538800, 1317625200, 1317711600,
                                           1317798000, 1317884400, 1317970800, 1318057200,
                                           1318143600, 1318230000, 1318316400, 1318402800,
                                           1318489200, 1318575600, 1318662000, 1318748400,
                                           1318834800, 1318921200, 1319007600, 1319094000),
                                         class = c("POSIXct", "POSIXt"), tzone = ""),
                   TempMax = c(26.58, 27.78, 27.9, 27.44, 30.9, 30.44, 27.57, 25.71,
                               25.98, 26.84, 33.58, 30.7, 31.3, 27.18, 26.58, 26.18,
                               25.19, 24.19, 27.65, 23.92),
                   TempMed = c(22.88, 22.87, 22.41, 21.63, 22.43, 22.29, 21.89, 20.52,
                                 19.71, 20.73, 23.51, 23.13, 22.95, 21.95, 21.91, 20.72,
                                 20.45, 19.42, 19.97, 19.61),
                   TempMin = c(19.34, 19.14, 18.34, 17.49, 16.75, 16.75, 16.88, 16.82,
                               14.82, 16.01, 16.88, 17.55, 16.75, 17.22, 19.01, 16.95,
                               17.55, 15.21, 14.22, 16.42)),
              .Names = c("month", "TempMax", "TempMed", "TempMin"),
              row.names = c(NA, 20L), class = "data.frame")

# Dynamically assign colors and names
num_series <- ncol(data) - 1 # Exclude the date column
my.cols <- heat.colors(num_series, alpha = 1)
my.names <- colnames(data)[-1] # Get column names for temperature series
names(my.cols) <- my.names

# Initialize plot object
p <- ggplot(data, aes(x = month))

# Loop through each temperature series
for (i in 1:num_series) {
  series_name <- my.names[i]
  p <- p + geom_line(aes_(y = as.name(series_name), colour = as.name(series_name)))
}

# Apply manual color scale for legend control
p <- p + scale_colour_manual(name = "Temperature Type",
                             breaks = my.names,
                             values = my.cols) +
  xlab("Date") +
  scale_y_continuous("Temperature (C)", limits = c(-10, 40)) +
  labs(title = "Daily Temperature Variations (Loop Plot)")

p

In this looping approach, aes_() is used with as.name() to correctly pass the dynamic column names to the aesthetic mapping. This ensures that each geom_line is associated with its corresponding data series and color. scale_colour_manual then takes the dynamically generated names and colors to construct the legend.

FAQs on ggplot2 Multiple Series Custom Colors

Q: How do I set a specific color for each line when plotting multiple series in ggplot2

ANS: You can achieve this by mapping a constant string to the colour aesthetic within aes() for each geom_line call, and then using scale_colour_manual() to define the desired color for each string. For example: geom_line(aes(y = Series1, colour = "Series1")) and scale_colour_manual(values = c("Series1" = "red")).

Q: What is the best way to handle multiple series for plotting in ggplot2

ANS: Reshaping your data into a long format using tidyr::pivot_longer or reshape2::melt is often the most efficient method. This allows you to use a single geom_line call and map the colour aesthetic to a column that specifies the series type.

Q: Can I use literal color names in ggplot2 aesthetics

ANS: Yes, you can. By mapping literal color names (e.g., “red”, “#00FF00”) directly within aes() for each geom_line, you can then use scale_color_identity() to control the legend, specifying breaks (the color values) and labels (the desired text).

Q: How do I control the order of items in the ggplot2 legend for multiple series

ANS: The breaks argument within scale_colour_manual() (or scale_color_manual()) allows you to specify the exact order in which the legend items should appear. Ensure the strings used in breaks match those mapped to the colour aesthetic.

Q: Is it possible to plot an unknown number of series with different colors in ggplot2

ANS: Yes, you can use a loop to iterate through your data columns and add geom_line for each series. Within the loop, use aes_() and as.name() to dynamically map the series name to the colour aesthetic. Then, use scale_colour_manual with dynamically generated color-value pairs.

These methods provide flexibility in visualizing multiple data series, allowing for clear differentiation through custom color assignments and precise legend control in ggplot2.
