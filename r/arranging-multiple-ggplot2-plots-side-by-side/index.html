“R: Arranging Multiple ggplot2 Plots Side-by-Side”

When visualizing data in R, presenting multiple related plots next to each other is a common requirement for comparison or to showcase different aspects of the data. ggplot2 is a powerful visualization package, and combining its plots effectively can enhance data interpretation. Several approaches exist, leveraging different R packages and techniques.

Solution 1: Using gridExtra::grid.arrange()

The gridExtra package offers the grid.arrange() function, which provides a straightforward way to arrange plots in a grid. This is analogous to using par(mfrow = c(1,2)) in base R graphics but with more flexibility for ggplot2 objects.

You can specify the number of columns using the ncol argument to place plots side-by-side.

# Ensure you have the necessary packages installed
# install.packages("ggplot2")
# install.packages("gridExtra")

library(ggplot2)
library(gridExtra)

# Create example plots
plot1 <- qplot(1, main = "Plot One")
plot2 <- qplot(1, main = "Plot Two")

# Arrange plots side-by-side
grid.arrange(plot1, plot2, ncol = 2)

This method is useful even when plots are not based on the same dataset, avoiding the need for data reshaping. The output is a side effect, which can be directed to a file by specifying a device driver like pdf or png.

# Save plots to a PDF file
pdf("side_by_side_plots.pdf")
grid.arrange(plot1, plot2, ncol = 2)
dev.off()

# Alternatively, use arrangeGrob() with ggsave()
ggsave("side_by_side_plots_ggsave.pdf", arrangeGrob(plot1, plot2, ncol = 2))

Solution 2: Leveraging cowplot::plot_grid()

The cowplot package, developed by Claus Wilke, offers the plot_grid() function. This function is particularly useful for combining plots and adding labels, which is often a requirement for publications.

plot_grid() allows for fine-grained control over plot placement and sizing.

# Ensure you have the necessary packages installed
# install.packages("cowplot")
# install.packages("ggplot2")

library(ggplot2)
library(cowplot)

# Create example ggplot2 plots
iris1 <- ggplot(iris, aes(x = Species, y = Sepal.Length)) +
  geom_boxplot() +
  theme_bw()

iris2 <- ggplot(iris, aes(x = Sepal.Length, fill = Species)) +
  geom_density(alpha = 0.7) +
  theme_bw() +
  theme(legend.position = c(0.8, 0.8))

# Combine plots with automatic labels
plot_grid(iris1, iris2, labels = "AUTO")

The combined plot object can be saved using ggsave() or cowplot’s save_plot() function, which is optimized for combined plot dimensions.

# Save the combined plot
p <- plot_grid(iris1, iris2, labels = "AUTO")
ggsave("cowplot_combined.pdf", p)

# Using save_plot for easier dimension management
save_plot("cowplot_combined_save.pdf", p, ncol = 2)

A note on cowplot’s theme: by default, it modifies the ggplot2 theme. To revert or avoid this, you can manually set themes for each plot (theme_bw(), theme_gray(), etc.), reset the theme using theme_set(theme_gray()), or call cowplot functions without attaching the package (e.g., cowplot::plot_grid(...)).

Solution 3: Using the patchwork Package

The patchwork package provides an intuitive and expressive way to combine ggplot2 plots using familiar operators. The + operator places plots side-by-side, while / stacks them vertically.

# Ensure you have the necessary packages installed
# install.packages("patchwork")
# install.packages("ggplot2")

library(ggplot2)
library(patchwork)

# Create example plots
p1 <- ggplot(mtcars) + geom_point(aes(mpg, disp))
p2 <- ggplot(mtcars) + geom_boxplot(aes(gear, disp, group = gear))

# Combine plots side-by-side
p1 + p2

Complex layouts can be constructed using parentheses for grouping and combining operators.

# Example of a more complex layout: top row with two plots, bottom row with one

Solution 4: Custom multiplot Function

A custom multiplot function, often found in resources like Winston Chang’s R cookbook, can also be used to arrange plots on a page. This involves manually defining viewports for each plot.

# Custom multiplot function
multiplot <- function(..., plotlist=NULL, cols) {
    require(grid)

    plots <- c(list(...), plotlist)
    numPlots <- length(plots)
    plotCols <- cols
    plotRows <- ceiling(numPlots/plotCols)

    grid.newpage()
    pushViewport(viewport(layout = grid.layout(plotRows, plotCols)))

    vplayout <- function(x, y) viewport(layout.pos.row = x, layout.pos.col = y)

    for (i in 1:numPlots) {
        curRow <- ceiling(i/plotCols)
        curCol <- (i-1) %% plotCols + 1
        print(plots[[i]], vp = vplayout(curRow, curCol))
    }
}

# multiplot(plot1, plot2, cols = 2)

Solution 5: Faceting for Grouped Data

When your plots represent different groups within your data, faceting is an idiomatic ggplot2 approach. This avoids the need for explicit arrangement functions if the plots share similar axes and structure.

library(ggplot2)

# Create example data
mydata <- data.frame(myGroup = c('a', 'b'), myX = c(1,1))

# Using qplot with facets
qplot(data = mydata, x = myX, facets = ~myGroup)

# Using ggplot with facet_wrap
ggplot(data = mydata) +
    geom_bar(aes(myX)) +
    facet_wrap(~myGroup)

This method is particularly effective when you want to create identical plot types for distinct subsets of your data.

Solution 6: Using egg::ggarrange()

The egg package provides ggarrange(), which is similar to grid.arrange() but is specifically designed for ggplot2 objects. It aims for better alignment of plot panels and respects user-defined aspect ratios.

# Ensure you have the necessary packages installed
# install.packages("egg")
# install.packages("ggplot2")

library(ggplot2)
library(egg)

# Create example plots
x <- rnorm(100)
eps <- rnorm(100, 0, .2)
p1 <- qplot(x, 3*x + eps)
p2 <- qplot(x, 2*x + eps)

# Arrange plots using ggarrange
ggarrange(p1, p2, ncol = 2)

Both grid.arrange() and ggarrange() are compatible with ggsave().

Solution 7: The multipanelfigure Package

For more complex layouts and interactive figure building, the multipanelfigure package is a valuable tool. It allows defining a grid and then filling panels with ggplot2 objects, supporting sophisticated arrangements.

# Ensure you have the necessary packages installed
# install.packages("multipanelfigure")
# install.packages("ggplot2")

library(ggplot2)
library(magrittr) # for the %<>% operator
library(multipanelfigure)

# Set a base theme
theme_set(theme_bw())

# Create example plots
q1 <- ggplot(mtcars) + geom_point(aes(mpg, disp))
q2 <- ggplot(mtcars) + geom_boxplot(aes(gear, disp, group = gear))
q3 <- ggplot(mtcars) + geom_smooth(aes(disp, qsec))
q4 <- ggplot(mtcars) + geom_bar(aes(carb))

# Create a 2x2 figure layout
figure1 <- multi_panel_figure(columns = 2, rows = 2, panel_label_type = "none")

# Fill the panels
figure1 %<>%
  fill_panel(q1, column = 1, row = 1) %<>%
  fill_panel(q2, column = 2, row = 1) %<>%
  fill_panel(q3, column = 1, row = 2) %<>%
  fill_panel(q4, column = 2, row = 2)

print(figure1)

# Create a more complex layout (3x3 with spanning panels)
figure2 <- multi_panel_figure(columns = 3, rows = 3, panel_label_type = "upper-roman")

figure2 %<>%
  fill_panel(q1, column = 1:2, row = 1) %<>%
  fill_panel(q2, column = 3, row = 1) %<>%
  fill_panel(q3, column = 1, row = 2) %<>%
  fill_panel(q4, column = 2:3, row = 2:3)

print(figure2)

When working with loops and ggplot2, using aes_string() is often necessary instead of aes(get(variable_name)) to correctly map variable names stored in strings to plot aesthetics.

# Example function to plot counts for all variables in a dataframe
plotAllCounts <- function (dt){
  plots <- list()
  for(i in 1:ncol(dt)) {
    strX = names(dt)[i]
    plots[[i]] <- ggplot(dt) + xlab(strX) +
      geom_point(aes_string(strX), stat = "count")
  }

  columnsToPlot <- floor(sqrt(ncol(dt)))
  # Assuming multiplot function is defined as in Solution 4
  multiplot(plotlist = plots, cols = columnsToPlot)
}

Solution 9: cowplot for Publication-Quality Layouts

cowplot’s plot_grid() is excellent for creating publication-ready figures. It supports features like aligning plots vertically or horizontally and adding labels consistently.

library(ggplot2)
library(cowplot)

# Create example plots with consistent themes
x <- rnorm(100)
eps <- rnorm(100, 0, .2)
A <- qplot(x, 3*x + eps, geom = c("point", "smooth")) + theme_gray()
B <- qplot(x, 2*x + eps, geom = c("point", "smooth")) + theme_gray()

# Combine plots with labels and alignment
cowplot::plot_grid(A, B, labels = c("A", "B"), align = "v")

Solution 10: Tidyverse Approach with tidyr::gather()

For data manipulation within the tidyverse, reshaping data using tidyr::gather() before plotting with ggplot2 can naturally lead to faceted plots, effectively displaying different aspects side-by-side.

library(dplyr)
library(tidyr)
library(ggplot2)

# Create example data
x <- rnorm(100)
eps <- rnorm(100, 0, .2)
df <- data.frame(x, eps) %>%
  mutate(p1 = 3*x + eps, p2 = 2*x + eps) %>%
  tidyr::gather("plot_type", "value", 3:4)

# Plot using facet_wrap
ggplot(df, aes(x = x, y = value)) +
  geom_point() +
  geom_smooth() +
  facet_wrap(~plot_type, ncol = 2)

Solution 11: ggpubr::ggarrange()

The ggpubr package provides ggarrange(), a user-friendly function that builds upon ggplot2 and offers enhancements like axis alignment and merging common legends, making it convenient for complex figure assembly.

FAQs on Arranging Multiple ggplot2 Plots Side-by-Side

Q: What is the simplest way to show two ggplot2 plots next to each other

ANS: The simplest method is often using gridExtra::grid.arrange(plot1, plot2, ncol = 2). Alternatively, the patchwork package offers an even more concise syntax: plot1 + plot2.

Q: How do I add labels like A, B to my combined plots

ANS: The cowplot::plot_grid() function has a labels argument that accepts “AUTO” or a character vector to automatically label plots. For example, plot_grid(plot1, plot2, labels = "AUTO").

Q: Can I arrange plots with different sizes

ANS: Yes, packages like cowplot and multipanelfigure offer more control over relative plot sizes. For instance, cowplot::plot_grid() has arguments like rel_widths and rel_heights. multipanelfigure allows specifying spanning columns and rows.

Q: How do I save combined plots to a file

ANS: You can use standard R functions like ggsave() with the combined plot object. cowplot::save_plot() is also a convenient wrapper around ggsave() specifically for combined plots. For grid.arrange, you can wrap the call within pdf() or png() and dev.off().

Q: What if my plots have different numbers of rows or columns in their layouts

ANS: Packages like gridExtra, cowplot, and patchwork handle this by default to some extent. For fine-tuning, cowplot offers align = "hv" (horizontal and vertical alignment), and patchwork provides extensive control through its operators and a plot_layout() function for detailed customization.

Q: Is there a way to combine plots when generating them in a loop

ANS: Yes, you can collect your plots in a list and then pass this list to functions like gridExtra::grid.arrange(plotlist = my_plot_list, ncol = ...). The custom multiplot function is also designed to handle lists of plots.

Q: How does faceting differ from arranging plots side-by-side

ANS: Faceting (e.g., using facet_wrap() or facet_grid()) is used when you want to display plots for different subsets of your data, often with shared axes and consistent structure. Arranging plots side-by-side is more general, allowing you to combine completely different plots or plots derived from different data sources into a single composite figure.
