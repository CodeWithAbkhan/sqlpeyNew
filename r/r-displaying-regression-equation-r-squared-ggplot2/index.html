“R: Displaying Regression Equation and R-squared on ggplot2 Plots”

When visualizing data in R using ggplot2, it’s often beneficial to overlay the results of a linear model, such as the regression equation and the R-squared value, directly onto the plot. This provides immediate context for the relationship being depicted. Several approaches exist, ranging from custom functions to specialized packages, each offering varying degrees of flexibility and ease of use.

Core Problem: Adding Model Fit Information to Plots

The primary challenge is to programmatically extract the coefficients and statistical summaries from a linear model (lm) and render them as text annotations on a ggplot2 graphic. This involves:

  1. Fitting a linear model: Using lm() to establish the relationship between variables.
  2. Extracting coefficients: Obtaining the intercept and slope.
  3. Extracting R-squared: Getting the goodness-of-fit measure.
  4. Formatting the output: Presenting the equation and R-squared in a readable, often mathematical format (e.g., using LaTeX-like syntax for Greek letters and exponents).
  5. Placing the text: Adding the formatted string as a layer to the ggplot2 object.

Solutions for Displaying Regression Equations and R-squared

Here are various methods to achieve this, with explanations and code examples:

Solution 1: Custom lm_eqn Function (Basic Approach)

This solution involves creating a custom R function that takes a data frame, fits a linear model, and formats the equation and R-squared as a character string.

# Source: https://groups.google.com/forum/#!topic/ggplot2/1gH5XMA
lm_eqn <- function(df){
    m <- lm(y ~ x, df); # Assumes your data frame has 'y' and 'x' columns
    eq <- substitute(italic(y) == a + b %.% italic(x)*","~~italic(r)^2~"="~r2, 
         list(a = format(unname(coef(m)[1]), digits = 2),
              b = format(unname(coef(m)[2]), digits = 2),
             r2 = format(summary(m)$r.squared, digits = 3)))
    as.character(as.expression(eq));
}

Solution 2: Using ggpmisc Package

The ggpmisc package offers specialized statistics like stat_poly_eq which are designed precisely for this purpose, providing extensive customization.

library(ggplot2)
library(ggpmisc)

# Artificial data
set.seed(123)
df <- data.frame(x = c(1:100))
df$y <- 2 + 3 * df$x + rnorm(100, sd = 40)
df$yy <- 2 + 3 * df$x + 0.1 * df$x^2 + rnorm(100, sd = 40)

# Using stat_poly_eq with default settings
ggplot(data = df, aes(x = x, y = y)) +
  stat_poly_line() + # Provides the regression line
  stat_poly_eq() +   # Adds the equation and R-squared
  geom_point()

# Assembling a single label with equation and R2
ggplot(data = df, aes(x = x, y = y)) +
  stat_poly_line() +
  stat_poly_eq(use_label(c("eq", "R2"))) + # Combines equation and R-squared
  geom_point()

# Assembling a single label with equation, adjusted R2, F-value, n, P-value
ggplot(data = df, aes(x = x, y = y)) +
  stat_poly_line() +
  stat_poly_eq(use_label(c("eq", "adj.R2", "f", "p", "n"))) + # More statistics
  geom_point()

# Grouped data example
dfg <- data.frame(x = c(1:100))
dfg$y <- 20 * c(0, 1) + 3 * df$x + rnorm(100, sd = 40)
dfg$group <- factor(rep(c("A", "B"), 50))

ggplot(data = dfg, aes(x = x, y = y, colour = group)) +
  stat_poly_line() +
  stat_poly_eq(use_label(c("eq", "R2"))) +
  geom_point() +
  facet_wrap(~group) # Works with facets

The ggpmisc package is highly recommended for its flexibility in controlling the displayed statistics and their formatting. You can learn more about its capabilities at ggpmisc on CRAN .

Solution 4: Modified lm_eqn for Negative Coefficients

An enhancement to the basic lm_eqn function to handle negative slopes more gracefully.

# Modified lm_eqn to better display negative coefficients
lm_eqn_neg <- function(m) {
  l <- list(a = format(coef(m)[1], digits = 2),
            b = format(abs(coef(m)[2]), digits = 2),
            r2 = format(summary(m)$r.squared, digits = 3));

  if (coef(m)[2] >= 0) {
    eq <- substitute(italic(y) == a + b %.% italic(x)*","~~italic(r)^2~"="~r2, l)
  } else {
    eq <- substitute(italic(y) == a - b %.% italic(x)*","~~italic(r)^2~"="~r2, l)
  }
  as.character(as.expression(eq));
}

Solution 5: Using ggpubr Package (Simpler Approach)

The ggpubr package provides convenient functions like stat_cor and stat_regline_equation for quick annotation.

library(ggplot2)
library(ggpubr)

# Artificial data
set.seed(456)
df <- data.frame(x = c(1:100))
df$y <- 2 + 3 * df$x + rnorm(100, sd = 40)

# Displaying R-squared and equation
p <- ggplot(data = df, aes(x = x, y = y)) +
        geom_smooth(method = "lm", se=FALSE, color="black", formula = y ~ x) +
        geom_point()+
        stat_cor(label.y = 35) + # Displays Pearson's R by default, and p-value
        stat_regline_equation(label.y = 30) # Displays regression equation

print(p)

Solution 7: Generic lm_eqn with Customizable Formula and p-value

This advanced custom function allows specifying the dependent and independent variables and includes the p-value.

# Function to format regression equation with R-squared and p-value
lm_eqn_formula <- function(df, y, x){
    formula_str = as.formula(sprintf('%s ~ %s', y, x))
    m <- lm(formula_str, data=df);
    
    eq <- substitute(italic(target) == a + b %.% italic(input)*","~~italic(r)^2~"="~r2*","~~p~"="~italic(pvalue), 
         list(target = y,
              input = x,
              a = format(as.vector(coef(m)[1]), digits = 2), 
              b = format(as.vector(coef(m)[2]), digits = 2), 
             r2 = format(summary(m)$r.squared, digits = 3),
             pvalue = format(summary(m)$coefficients[2,'Pr(>|t|)'], digits=1) # Extracts p-value for the predictor
            )
          )
    as.character(as.expression(eq));                 
}

Solution 8: Using dplyr and broom for Formula Generation

This method leverages dplyr and broom for a structured way to create the regression formula string.

library(dplyr)
library(broom)
library(scales) # For percent formatting

# Function to generate formula string
get_formula <- function(model) {
  broom::tidy(model)[, 1:2] %>%
    mutate(sign = ifelse(sign(estimate) == 1, ' + ', ' - ')) %>% # Coefficient signs
    mutate_if(is.numeric, ~ abs(round(., 2))) %>% # Improve formatting
    mutate(a = ifelse(term == '(Intercept)', paste0('y ~ ', estimate), paste0(sign, estimate, ' * ', term))) %>%
    summarise(formula = paste(a, collapse = '')) %>%
    as.character
}

Solution 9: Generic Function with LaTeX Output Option

A versatile function that can output equations in plain text or LaTeX format, suitable for R Markdown reports.

# Function for printing equations, with LaTeX option
print_equation <- function(model, latex = FALSE, ...){
    dots <- list(...)
    cc <- model$coefficients
    var_sign <- as.character(sign(cc[-1])) %>% gsub("1","",.) %>% gsub("-"," - ",.)
    var_sign[var_sign==""] <- ' + '

    f_args_abs <- f_args <- dots
    f_args$x <- cc
    f_args_abs$x <- abs(cc)
    cc_ <- do.call(format, args = f_args)
    cc_abs <- do.call(format, args = f_args_abs)
    
    # Assuming x_vars are derived from model formula names
    x_vars <- names(cc_)[-1] 

    pred_vars <-
        cc_abs %>%
        paste(., x_vars, sep = star) %>% # Using 'star' defined below
        paste(var_sign, .) %>% paste(., collapse = "")

    if (latex) {
        star <- " \\cdot "
        y_var <- strsplit(as.character(model$call$formula), "~")[[2]] %>%
            paste0("\\hat{", ., "_{i}}")
        x_vars_latex <- names(cc_)[-1] %>% paste0(. ,"_{i}") # Use names from cc_ for consistency
    } else {
        star <- " * "
        y_var <- strsplit(as.character(model$call$formula), "~")[[2]]
        x_vars_latex <- x_vars # Use the same x_vars for non-latex
    }
    
    equ <- paste(y_var, "=", cc_[1], pred_vars)
    if (latex) {
        equ <- paste0(equ, " + \\hat{\\varepsilon_{i}} \\quad where \\quad \\varepsilon \\sim \\mathcal{N}(0,",
                    summary(model)$sigma, ")") %>% paste0("$", ., "$") # Use summary(model)$sigma
    }
    cat(equ)
}

Solution 10: ggpubr with Faceting

Demonstrates ggpubr’s effectiveness with grouped data and faceted plots.

library(ggplot2)
library(ggpubr)

# Artificial data with groups
set.seed(1011)
df_facet <- data.frame(x = c(1:100))
df_facet$y <- 2 + 3 * df_facet$x + rnorm(100, sd = 40)
df_facet$group <- rep(1:2, 50)

# Plot with R-squared, p-value, and equation, faceted by group
ggplot(data = df_facet, aes(x = x, y = y)) +
  stat_smooth(method = "lm", se=FALSE, color="black", formula = y ~ x) +
  geom_point() +
  stat_cor(aes(label = paste(..rr.label.., ..p.label.., sep = "~`,`~")), # R2 and p-value
           r.accuracy = 0.01,
           p.accuracy = 0.001,
           label.x = 0, label.y = 375, size = 4) +
  stat_regline_equation(aes(label = ..eq.label..), # Regression equation
                        label.x = 0, label.y = 400, size = 4) +
  theme_bw() +
  facet_wrap(~group)

Choosing the Right Method

  • For quick and easy annotation, ggpubr (Solutions 5, 6, 10) is often the most straightforward.
  • For maximum control over formatting, complex equations, or specific statistical displays, ggpmisc (Solution 2) is highly recommended.
  • Custom functions (Solutions 1, 4, 7, 8, 9) offer complete flexibility but require more effort to write and maintain. Consider these if you have very specific requirements not met by existing packages or if you want to embed the logic directly into your analysis workflow.

FAQs on Displaying Regression Equation and R-squared on ggplot2 Plots

Q: What is the primary purpose of displaying the regression equation and R-squared on a plot

ANS: Displaying the regression equation and R-squared value on a plot provides immediate visual context about the relationship between variables, showing the predictive model and its goodness-of-fit.

Q: Which R packages are most commonly used for this task

ANS: The most popular packages for this task are ggpmisc and ggpubr, both of which extend ggplot2’s capabilities. Custom functions can also be created.

Q: Can these methods handle grouped data or faceting

ANS: Yes, packages like ggpmisc and ggpubr are designed to work well with grouped data and faceted plots, allowing you to display model summaries for each subgroup or facet.

Q: How can I customize the appearance of the text labels

ANS: You can customize text labels using standard ggplot2 arguments like size, color, hjust, vjust, and fontface. Packages like ggpmisc and ggpubr also offer specific arguments for label control.

Q: Is it possible to display p-values along with R-squared

ANS: Yes, many solutions, particularly those using ggpmisc and ggpubr (like stat_cor and variations of stat_poly_eq), allow for the inclusion of p-values.
