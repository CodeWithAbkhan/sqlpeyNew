“R: Finding the Statistical Mode of Data”

Calculating the statistical mode, the value that appears most frequently in a dataset, is a common task in data analysis. While R’s base installation doesn’t have a direct mode() function for statistical purposes (the built-in mode() asserts variable types), numerous methods exist to achieve this. This post explores various approaches, from custom functions to package solutions, catering to different needs like handling multiple modes or NA values.

Solution 1: Efficient Base R Function for Single or Multiple Modes

This function is designed for both numeric and character/factor data and efficiently finds the mode. If multiple values share the highest frequency, it returns the first encountered.

Mode <- function(x) {
  ux <- unique(x)
  ux[which.max(tabulate(match(x, ux)))]
}

For datasets where multiple modes are possible and you wish to retrieve all of them, use this variation:

Modes <- function(x) {
  ux <- unique(x)
  tab <- tabulate(match(x, ux))
  ux[tab == max(tab)]
}

This approach is generally performant, even for large datasets, and handles non-numeric data effectively.

Solution 2: Using table() and sort()

A concise method involves creating a frequency table, sorting it in descending order, and selecting the first element. This is often described as a “hacky” but functional approach.

names(sort(-table(x)))[1]

This solution works well for discrete data. For continuous data, consider smoothing techniques discussed later.

Solution 3: Leveraging the modeest Package

For dedicated statistical mode estimation, the modeest package offers robust functions. mlv() is particularly useful for finding the most likely value (modal value).

# Install and load the package if not already done
# install.packages("modeest")
library(modeest)

mySamples <- c(19, 4, 5, 7, 29, 19, 29, 13, 25, 19)
mlv(mySamples, method = "mfv")

The output provides the mode and related statistics. This package also supports estimating modes for multimodal data and other statistical distributions, as detailed in the CRAN Task View on Probability Distributions .

Solution 4: Enhanced Base R Function with na.rm

Building on the efficient unique() and tabulate() method, this function adds an option to remove NA values before calculation.

Mode <- function(x, na.rm = FALSE) {
  if(na.rm){
    x <- x[!is.na(x)]
  }
  ux <- unique(x)
  return(ux[which.max(tabulate(match(x, ux)))])
}

This makes the function more adaptable to datasets containing missing information.

Solution 5: Estimating Mode for Continuous Data with density()

When dealing with continuous data that might approximate a distribution, estimating the mode using kernel density estimation is a viable strategy.

estimate_mode <- function(x) {
  d <- density(x)
  d$x[which.max(d$y)]
}

x <- c(5.8, 5.6, 6.2, 4.1, 4.9, 2.4, 3.9, 1.8, 5.7, 3.2)
estimate_mode(x)

The density() function smooths the data, allowing for the identification of a modal value even if it doesn’t perfectly match any observed data point. You can adjust the smoothing parameter (adjust in density()) for finer or coarser estimates. For more on handling continuous data, see Introduction to SQL .

Solution 6: High-Performance Mode Calculation with collapse Package

The collapse package offers an optimized C-level hashing algorithm for fast mode computation, supporting grouping and multithreading.

The fmode function is highly efficient, especially for large datasets and complex operations like grouped mode calculations.

Solution 7: Versatile Mode Function with Method Options

This function provides flexibility by allowing you to specify whether you want the mode, the number of modes, or a list of all modes.

modeav <- function (x, method = "mode", na.rm = FALSE) {
  x <- unlist(x)
  if (na.rm)
    x <- x[!is.na(x)]
  u <- unique(x)
  n <- length(u)
  frequencies <- rep(0, n)
  for (i in seq_len(n)) {
    if (is.na(u[i])) {
      frequencies[i] <- sum(is.na(x))
    } else {
      frequencies[i] <- sum(x == u[i], na.rm = TRUE)
    }
  }
  # mode if a unimodal vector, else NA
  if (method == "mode" | is.na(method) | method == "") {
    return(ifelse(length(frequencies[frequencies==max(frequencies)]) > 1, NA, u[which.max(frequencies)]))
  }
  # number of modes
  if (method == "nmode" | method == "nmodes") {
    return(length(frequencies[frequencies == max(frequencies)]))
  }
  # list of all modes
  if (method == "modes" | method == "modevalues") {
    return(u[which(frequencies == max(frequencies), arr.ind = FALSE, useNames = FALSE)])
  }
  # error trap the method
  warning("Warning: method not recognised. Valid methods are 'mode' [default], 'nmodes' and 'modes'")
  return()
}

Solution 9: Constrained Mode Estimation for Continuous Data

An extension to Solution 5, this allows you to specify a range (from, to) for density estimation, useful when you have prior knowledge about the data’s bounds.

estimate_mode <- function(x, from = min(x), to = max(x)) {
  d <- density(x, from = from, to = to)
  d$x[which.max(d$y)]
}

Solution 10: A Flexible Mode Function with Multiple Methods

This function enhances Solution 7 by offering distinct methods: "one" for a single mode (returning NA if multiple exist), "n" for the count of modes, and "all" to list all modes.

Mode <- function(x, method = "one", na.rm = FALSE) {
  x <- unlist(x)
  if (na.rm) {
    x <- x[!is.na(x)]
  }

  ux <- unique(x)
  n <- length(ux)

  frequencies <- tabulate(match(x, ux))
  modes <- frequencies == max(frequencies)

  nmodes <- sum(modes)
  nmodes <- ifelse(nmodes == n, 0L, nmodes) # If all frequencies are 1, no distinct mode

  if (method %in% c("one", "mode", "") | is.na(method)) {
    if (nmodes != 1) {
      return(NA)
    } else {
      return(ux[which(modes)])
    }
  } else if (method %in% c("n", "nmodes")) {
    return(nmodes)
  } else if (method %in% c("all", "modes")) {
    if (nmodes > 0) {
      return(ux[which(modes)])
    } else {
      return(NA) # No distinct mode
    }
  }
  warning("Warning: method not recognised. Valid methods are 'one'/'mode' [default], 'n'/'nmodes' and 'all'/'modes'")
}

This function prioritizes correctness and offers granular control over the output.

Solution 11: Data Type Preserving Mode Function

This function aims to preserve the original data type of the input vector in its output, making it suitable for various data formats.

stat_mode <- function(x, return_multiple = TRUE, na.rm = FALSE) {
  if (na.rm) {
    x <- na.omit(x)
  }
  ux <- unique(x)
  freq <- tabulate(match(x, ux))
  mode_loc <- if (return_multiple) which(freq == max(freq)) else which.max(freq)
  return(ux[mode_loc])
}

# Example usage:
foo <- c(2L, 2L, 3L, 4L, 4L, 5L, NA, NA)
bar <- c('mouse','mouse','dog','cat','cat','bird',NA,NA)

str(stat_mode(foo))
str(stat_mode(bar))
str(stat_mode(bar, na.rm = TRUE))
str(stat_mode(bar, return_multiple = FALSE, na.rm = TRUE))

This function is useful when the type of the mode is important, such as distinguishing between integer and character modes. For more on data types, explore what is python .

Solution 12: Mode Function for Data Frames

This function iterates through columns of a data frame, calculates the mode for each, and returns a vector of modes. It handles both numeric and non-numeric columns.

MODE <- function(dataframe) {
  DF <- as.data.frame(dataframe)

  MODE2 <- function(x) {
    if (!is.numeric(x)) {
      df <- as.data.frame(table(x))
      df <- df[order(df$Freq), ]
      m <- max(df$Freq)
      MODE1 <- as.vector(as.character(subset(df, Freq == m)[, 1]))

      if (sum(df$Freq) / length(df$Freq) == 1) {
        warning("No Mode: Frequency of all values is 1", call. = FALSE)
      } else {
        return(MODE1)
      }
    } else {
      df <- as.data.frame(table(x))
      df <- df[order(df$Freq), ]
      m <- max(df$Freq)
      MODE1 <- as.vector(as.numeric(as.character(subset(df, Freq == m)[, 1])))

      if (sum(df$Freq) / length(df$Freq) == 1) {
        warning("No Mode: Frequency of all values is 1", call. = FALSE)
      } else {
        return(MODE1)
      }
    }
  }

  return(as.vector(lapply(DF, MODE2)))
}

# Example usage:
MODE(mtcars)
MODE(CO2)

Solution 17: Iterative Frequency Counting Function

This function manually iterates through unique values to count frequencies and identify the mode. It includes a check for cases where no distinct mode exists.

mode <- function(x) {
  unique_val <- unique(x)
  counts <- vector()
  for (i in 1:length(unique_val)) {
    counts[i] <- length(which(x == unique_val[i]))
  }
  position <- c(which(counts == max(counts)))
  if (mean(counts) == max(counts)) # Check if all elements have the same frequency
    mode_x <- 'Mode does not exist'
  else
    mode_x <- unique_val[position]
  return(mode_x)
}

Mode_typed <- function(x){

Solution 22: Returning Multiple Modes Effectively

This function sorts the data, finds unique values, calculates their frequencies using lapply, and returns all modes if multiple exist.

rmode <- function(x) {
  x <- sort(x)
  u <- unique(x)
  y <- lapply(u, function(y) length(x[x==y]))
  u[which( unlist(y) == max(unlist(y)) )]
}

Solution 24: Mode Function Addressing Non-Unique Frequencies

This function includes checks for cases where all elements are the same or when multiple values share the highest frequency, providing informative messages or returning the distinct mode.

Mode <- function(v) {
  uniqv <- unique(v)
  m1 <- max(tabulate(match(v, uniqv)))
  n <- length(tabulate(match(v, uniqv)))
  same_val_check <- all(diff(v) == 0)

  if (!same_val_check) {
    m2 <- sort(tabulate(match(v, uniqv)), partial = n - 1)[n - 1]
    if (m1 != m2) {
      mode <- uniqv[which.max(tabulate(match(v, uniqv)))]
    } else {
      mode <- "Two or more values have same frequency. So mode can't be calculated."
    }
  } else {
    mode <- unique(v) # All elements are the same
  }
  return(mode)
}

Mode(x1)

Mode(x2)

x3 <- c(1,1,2,3,3,4,5)
Mode(x3)

Solution 28: Mode Estimation for Continuous Data with Grouping

This method estimates the mode for continuous data by grouping observations into classes and applying a formula to interpolate the mode within the most frequent class.

# Small Example
x <- c(2,2,3,3) # Observations
i <- 1          # Class interval

z <- hist(x, breaks = seq(min(x)-1.5*i, max(x)+1.5*i, i), plot=F)
mf <- which.max(z$counts)
zc <- z$counts
# Formula for interpolated mode
z$breaks[mf] + i * (zc[mf] - zc[mf-1]) / (2*zc[mf] - zc[mf-1] - zc[mf+1])

# Example for multiple modes
x_multi <- c(2,2,3,5,5)
names(which(max(table(x_multi)) == table(x_multi)))

This approach is valuable when dealing with grouped continuous data where an exact mode might not be present in the dataset. For database operations, exploring Introduction to MySQL can be beneficial.

Solution 29: Factor-Based Mode Calculation

This function converts numeric values to factors, uses summary() to get frequencies, and then identifies the mode. The result is converted back to numeric.

mode <- function(x){
  y <- as.factor(x)
  freq <- summary(y)
  mode <- names(freq)[freq[names(freq)] == max(freq)]
  as.numeric(mode)
}
