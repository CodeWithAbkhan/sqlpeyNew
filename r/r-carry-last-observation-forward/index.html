“R: Carry Last Observation Forward (LOCF) Techniques”

When working with time-series data or any dataset containing sequential observations, you often encounter missing values represented as NA. A common technique to handle these is “Last Observation Carried Forward” (LOCF), where a missing value is replaced by the last preceding non-missing value. This method is particularly useful when you assume that the value remains constant until a new observation is recorded.

R offers several powerful approaches to achieve this, ranging from dedicated package functions to custom-written solutions. Let’s delve into the various methods available.

Methods for Last Observation Carried Forward (LOCF) in R

Several accepted solutions provide ways to implement LOCF.

Solution 1: Using zoo::na.locf()

The zoo package is a standard for time-series analysis in R and provides a direct function for LOCF.

# Load the zoo package
library(zoo)

# Example data with NAs
bz <- zoo(c(2, NA, 1, 4, 5, 2))

# Apply na.locf() for forward carry
na.locf(bz)
# Output:
# 1 2 3 4 5 6
# 2 2 1 4 5 2

# Apply na.locf() with fromLast = TRUE for backward carry
na.locf(bz, fromLast = TRUE)
# Output:
# 1 2 3 4 5 6
# 2 1 1 4 5 2

# Example with leading NA
cz <- zoo(c(NA, 9, 3, 2, 3, 2))
na.locf(cz)
# Output:
# 2 3 4 5 6
# 9 3 2 3 2

Solution 2: Custom repeat.before() Function

A user-contributed function offers an alternative, often with performance benefits, especially for large datasets.

# User-defined function for LOCF
repeat_last <- function(x, forward = TRUE, maxgap = Inf, na.rm = FALSE) {
    if (!forward) x = rev(x)           # reverse x twice if carrying backward
    ind = which(!is.na(x))             # get positions of nonmissing values
    if (is.na(x[1]) &amp;&amp; !na.rm)         # if it begins with NA
        ind = c(1,ind)                 # add first pos
    rep_times = diff(                  # diffing the indices + length yields how often
        c(ind, length(x) + 1) )          # they need to be repeated
    if (maxgap &lt; Inf) {
        exceed = rep_times - 1 &gt; maxgap  # exceeding maxgap
        if (any(exceed)) {               # any exceed?
            ind = sort(c(ind[exceed] + 1, ind))      # add NA in gaps
            rep_times = diff(c(ind, length(x) + 1) ) # diff again
        }
    }
    x = rep(x[ind], times = rep_times) # repeat the values at these indices
    if (!forward) x = rev(x)           # second reversion
    x
}

Solution 3: data.table for Scalability

For large datasets, data.table provides efficient and concise ways to perform LOCF, especially with grouping.

# Load data.table package
library(data.table)

# Sample data
dt_example <- data.table(y = c(NA, 2, 2, NA, NA, 3, NA, 4, NA, NA))

# Forward fill using data.table logic
dt_example[, y_forward_fill := y[1], .(cumsum(!is.na(y)))]
print(dt_example)

# Example with filling zeros
dt_zeros <- data.table(y = c(0, 2, -2, 0, 0, 3, 0, -4, 0, 0))
dt_zeros[, y_forward_fill := y[1], .(cumsum(y != 0))]
print(dt_zeros)

# Forward fill by group
dt_grouped <- data.table(
  group = sample(c('a', 'b'), 20, replace = TRUE),
  y = sample(c(1:4, rep(NA, 4)), 20, replace = TRUE)
)
dt_grouped <- dt_grouped[order(group)]
dt_grouped[, y_forward_fill := y[1], .(group, cumsum(!is.na(y)))]
print(dt_grouped)

Solution 5: data.table::nafill()

An alternative within data.table is the nafill() function, which is efficient for numerical and integer types.

# Load data.table package
library(data.table)

# Sample vector
y_vector <- c(NA, 2, 2, NA, NA, 3, NA, 4, NA, NA)

# Using nafill for LOCF
nafill(y_vector, type = "locf")
# Output: [1] NA  2  2  2  2  3  3  4  4  4

# Updating a data.table column by reference
d_table <- data.table(x = 1:10, y = y_vector)
setnafill(d_table, type = "locf", cols = "y")
print(d_table)

# Filling multiple columns by reference
d_multi <- data.table(x = c(1, NA, 2), y = c(2, 3, NA), z = c(4, NA, 5))
setnafill(d_multi, type = "locf")
print(d_multi)

Note: As of data.table version 1.12.6, support is primarily for double and integer types.

Solution 6: Rcpp for Performance

For maximum speed, especially with large datasets, custom C++ functions via Rcpp can be implemented.

# Load Rcpp package
library(Rcpp)

# Rcpp function for integer vectors
cppFunction('IntegerVector na_locf_int(IntegerVector x) {
  int n = x.size();
  for(int i = 0; i < n; i++) {
    if((i > 0) && (x[i] == NA_INTEGER) && (x[i-1] != NA_INTEGER)) {
      x[i] = x[i-1];
    }
  }
  return x;
}')

# Rcpp function for numeric vectors
cppFunction('NumericVector na_locf_numeric(NumericVector x) {
  R_xlen_t n = x.size();
  for(R_xlen_t i = 0; i < n; i++) {
    if(i > 0 && !R_finite(x[i]) && R_finite(x[i-1])) {
      x[i] = x[i-1];
    }
  }
  return x;
}')

# Rcpp function for character vectors
cppFunction('CharacterVector na_locf_character(CharacterVector x) {
  R_xlen_t n = x.size();
  for(R_xlen_t i = 0; i < n; i++) {
    if(i > 0 && x[i] == NA_STRING && x[i-1] != NA_STRING) {
      x[i] = x[i-1];
    }
  }
  return x;
}')

Solution 7: data.table Custom Function for DataFrames

A more generalized data.table approach for data frames.

# Load data.table package
library(data.table)

# Function to replace NA in a specified column
replaceNaWithLatest <- function(dfIn, nameColNa = names(dfIn)[1]) {
  dtTest <- data.table(dfIn)
  setnames(dtTest, nameColNa, "colNa")
  dtTest[, segment := cumsum(!is.na(colNa))]
  dtTest[, colNa := colNa[1], by = "segment"]
  dtTest[, segment := NULL]
  setnames(dtTest, "colNa", nameColNa)
  return(dtTest)
}

Solution 8: Concise Base R Vectorized Approach

A compact, vectorized Base R solution.

# Vectorized LOCF function
replace_na_with_last <- function(x, a = !is.na(x)) {
     x[which(a)[c(1,1:sum(a))][cumsum(a)+1]]
}

Solution 10: na.lomf() Function

A custom function that handles both vectors and matrices.

# na.lomf function for LOCF
na.lomf <- function(x) {
    na.lomf.0 <- function(x) {
        non.na.idx <- which(!is.na(x))
        if (is.na(x[1L])) {
            non.na.idx <- c(1L, non.na.idx)
        }
        rep.int(x[non.na.idx], diff(c(non.na.idx, length(x) + 1L)))
    }
    dim.len <- length(dim(x))
    if (dim.len == 0L) {
        na.lomf.0(x)
    } else {
        apply(x, dim.len, na.lomf.0)
    }
}

# Example usage
na.lomf(c(1, NA, 2, NA, NA))
# Output: [1] 1 1 2 2 2

# Rcpp implementation for filling NAs in any R object type
Rcpp::sourceCpp(code=r'"
#include <Rcpp.h>
using namespace Rcpp;

template <int RTYPE>
Vector<RTYPE> FNA(const Vector<RTYPE> y) {
  auto x = clone(y);  // or overwrite original
  LogicalVector isNA = is_na(x);
  size_t i = 0;
  while(isNA[i] && i < x.size()) ++i;
  for(++i; i < x.size(); ++i) if(isNA[i]) x[i] = x[i-1];
  return x;
}

// [[Rcpp::export]]
RObject fillNaC(RObject x) {
  RCPP_RETURN_VECTOR(FNA, x);
}
"')

Solution 16: Reduce() for Functional Approach

Using Reduce() offers a functional programming perspective for LOCF.

# Function using Reduce
fill.NAs <- function(x) {
  is_na <- is.na(x)
  x[Reduce(function(i, j) if (is_na[j]) i else j, seq_len(length(x)), accumulate = T)]
}

fill.NAs(c(NA, 2, 2, NA, NA, 3, NA, 4, NA, NA))
# Output: [1] NA  2  2  2  2  3  3  4  4  4

Note: While elegant, Reduce() can be slower than other methods for very large datasets.

Solution 17: Simple Loop-Based Function

A straightforward function using a basic loop.

# Function to replace NA with previous non-NA value
replace_na_with_previous <- function(vector) {
    if (is.na(vector[1]))
        vector[1] <- na.omit(vector)[1]
    for (i in 1:length(vector)) {
        if ((i - 1) > 0) {
            if (is.na(vector[i]))
                vector[i] <- vector[i - 1]
        }
    }
    return(vector)
}

Solution 21: Iterative Forward Propagation

A function that iteratively propagates the last non-NA value.

# Function for iterative forward propagation
rollForward <- function(x){
  curr <- 0 # Initialize with a default value, consider its type
  for (i in 1:length(x)){
    if (is.na(x[i])){
      x[i] <- curr
    }
    else{
      curr <- x[i]
    }
  }
  return(x)
}

Performance Considerations

When choosing a method, consider the size of your data and the required performance. For very large datasets, data.table and Rcpp-based solutions generally offer the best speed. tidyr::fill and zoo::na.locf are user-friendly and efficient for moderately sized data. vctrs::vec_fill_missing is a modern and performant option within the tidyverse.

FAQs on R LOCF Techniques

Q: How do I handle leading NAs with LOCF in R

ANS: Many LOCF functions, like zoo::na.locf() and custom functions, manage leading NAs. Custom functions often include specific checks (e.g., if(is.na(x[1]))) to address this. If a function doesn’t handle leading NAs by default, you might need to prepend a non-NA value or use a solution that explicitly addresses this scenario.

Q: Which R package is best for LOCF

ANS: The “best” package depends on your needs. For general time-series and ease of use, zoo is excellent. For large datasets and performance, data.table and Rcpp solutions are superior. tidyr provides a tidyverse-friendly approach. Consider vctrs for modern, efficient vector operations.

Q: Can I perform LOCF on character vectors in R

ANS: Yes, many LOCF functions can handle character vectors. Solutions using Rcpp often provide specific implementations for character types. Standard Base R methods that rely on general vector operations can also work with character data.

Q: What is the difference between LOCF and NOCB

ANS: LOCF (Last Observation Carried Forward) fills NA with the last preceding non-NA value. NOCB (Next Observation Carried Backward) fills NA with the next succeeding non-NA value. Some functions, like imputeTS::na_locf with specific options, can perform both or variations thereof.

Q: How to perform LOCF by group in R

ANS: Packages like data.table and dplyr are well-suited for grouped operations. You can use dplyr::group_by() or data.table’s by argument in conjunction with LOCF functions to apply the operation within each group independently. For instance, data.table’s dt[, y_filled := y[1], .(group, cumsum(!is.na(y)))] demonstrates this.
