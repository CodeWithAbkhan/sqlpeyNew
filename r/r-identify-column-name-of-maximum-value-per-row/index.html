“R: Identify Column Name of Maximum Value Per Row”

Methods for Finding Column Name of Row Maximum

Here are several approaches to achieve this goal:

Solution 1: Using apply and which.max (Base R)

A straightforward method in base R involves using apply to iterate through rows and which.max to find the index of the maximum value, then using that index to retrieve the column name.

# Sample data frame
DF <- data.frame(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(9, 6, 4))

# Get column names of maximum values
col_names_apply <- colnames(DF)[apply(DF, 1, which.max)]
print(col_names_apply)

Handling Ties: If multiple columns share the maximum value in a row, which.max will return the index of the first occurrence.

Solution 2: Using max.col (Base R)

The max.col function provides a more direct and often faster way to achieve the same result as apply with which.max. It returns the column index of the maximum value for each column (or row, if specified).

# Using max.col for efficiency
col_names_max_col <- colnames(DF)[max.col(DF, ties.method = "first")]
print(col_names_max_col)

ties.method Options:

  • "first": Returns the index of the first maximum value.
  • "random": Randomly selects one of the maximum values.
  • "last": Returns the index of the last maximum value.

Example with Ties:

DF_ties <- data.frame(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(7, 6, 4))

# Using apply to see all ties
apply(DF_ties, 1, function(x) which(x == max(x)))

This will output:

[[1]]
V2 V3 
 2  3 

[[2]]
V1 
 1 

[[3]]
V2 
 2

Solution 3: Reshaping with tidyverse (tidyr::gather)

The tidyverse offers a flexible approach by reshaping the data from wide to long format, allowing for easier grouping and filtering. This method is particularly useful if you need to handle ties explicitly or perform other aggregations.

library(tidyverse)

# Sample data frame with a tie
df_tidy <- data.frame(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(9, 6, 5))

# Without worrying about ties
df_tidy %>%
  rownames_to_column('id') %>%
  gather(dept, cnt, V1:V3) %>%
  group_by(id) %>%
  slice(which.max(cnt))

# Keeping ties
df_tidy %>%
  rownames_to_column('id') %>%
  gather(dept, cnt, V1:V3) %>%
  group_by(id) %>%
  filter(cnt == max(cnt)) %>%
  arrange(id)

# Handling ties by rank (e.g., first occurrence)
df_tidy %>%
  rownames_to_column('id') %>%
  gather(dept, cnt, V1:V3) %>%
  group_by(id) %>%
  mutate(dept_rank = rank(-cnt, ties.method = "first")) %>%
  filter(dept_rank == 1) %>%
  select(-dept_rank)

# Joining the maximum column back to the original wide format
df_tidy %>%
  rownames_to_column('id') %>%
  left_join(
    df_tidy %>%
      rownames_to_column('id') %>%
      gather(max_dept, max_cnt, V1:V3) %>%
      group_by(id) %>%
      slice(which.max(max_cnt)),
    by = 'id'
  )

Solution 4: Using dplyr 1.0.0+ (rowwise and c_across)

For users of dplyr version 1.0.0 and later, rowwise() combined with c_across() offers a concise and readable way to perform row-wise operations.

library(dplyr)

DF_dplyr <- data.frame(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(9, 6, 4))

DF_dplyr %>%
  rowwise() %>%
  mutate(row_max = names(.)[which.max(c_across(everything()))])

This will add a new column row_max containing the name of the column with the maximum value for each row.

Alternative with purrr::pmap_chr:

library(dplyr)
library(purrr)

DF_dplyr %>%
  mutate(row_max = pmap_chr(across(everything()), ~ names(c(...)[which.max(c(...))])))

Solution 5: Using data.table for Performance

When dealing with very large datasets, data.table often provides superior performance.

library(data.table)

# Sample data
set.seed(45)
DT <- data.table(matrix(sample(10, 10^7, TRUE), ncol = 10))

# Get column name of maximum value
system.time(
  DT[, col_max := colnames(.SD)[max.col(.SD, ties.method = "first")]]
)

# Specifying columns using .SDcols
DT[, MAX2 := colnames(.SD)[max.col(.SD, ties.method = "first")], .SDcols = c("V9", "V10")]

# Get column name of minimum value
DT[, col_min := colnames(.SD)[max.col(-.SD, ties.method = "first")]]

# Demonstrating efficiency with larger data
# Set up data similar to example dimensions
large_DF <- data.frame(matrix(sample(10, 26746 * 18, TRUE), ncol = 18))
set.seed(45) # Ensure reproducibility

# data.table approach
system.time({
  DT_large <- data.table(value = unlist(large_DF, use.names = FALSE),
                         colid = 1:nrow(large_DF),
                         rowid = rep(names(large_DF), each = nrow(large_DF)))
  setkey(DT_large, colid, value)
  t1 <- DT_large[J(unique(colid), DT_large[J(unique(colid)), value, mult = "last"]), rowid, mult = "first"]
})

# Base R apply approach for comparison
system.time(t2 <- colnames(large_DF)[apply(large_DF, 1, which.max)])

# Check if results are identical
identical(t1, t2)

The data.table method demonstrates significant performance gains for larger datasets.

Solution 6: Simple for Loop (Base R)

While often less efficient for large datasets than vectorized methods, a for loop is a fundamental approach.

df_loop <- data.frame(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(9, 6, 4))
df2 <- data.frame()

for (i in 1:nrow(df_loop)) {
  df2[i, 1] <- colnames(df_loop)[which.max(df_loop[i, ])]
}
print(df2)

Solution 7: Tidyverse with across and a Custom Function

This solution uses across to apply a function to selected columns.

library(tidyverse)

data_transform <- data.frame(
  oh_a = c(1, 0, 0, 1, 0, 0),
  oh_b = c(0, 1, 1, 0, 0, 0),
  oh_c = c(0, 0, 0, 0, 1, 0),
  d = c("l", "m", "n", "o", "p", "q")
)

f <- function(x) {
  ifelse(rowSums(x) == 0, NA, names(x)[max.col(x, "first")])
}

data_transform %>%
  mutate(transformed = f(across(starts_with("oh"))))

This approach is useful for selective column operations and handles cases where all values are zero.

Solution 8: comprehenr Package

The comprehenr package offers a concise syntax for loop-like operations.

# Install if you haven't already: install.packages("comprehenr")
library(comprehenr)

df_compre <- data.frame(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(9, 6, 4))
colnames(df_compre)[comprehenr::to_vec(for(i in 1:dim(df_compre)[1]) which.max(df_compre[i,]))]

Solution 9: data.table Direct Column Selection

For data.table users, directly referencing columns with max.col can be very efficient.

library(data.table)

# Assuming 'yourDF' is a data.table
# Example data structure
yourDF <- data.table(V1 = c(2, 8, 1), V2 = c(7, 3, 5), V3 = c(9, 6, 4), V4 = c(5, 7, 3))

# Get the index of the max value across specified columns
j1 <- max.col(yourDF[, .(V1, V2, V3, V4)], "first")

# Use the indices to get column names
yourDF$newCol <- c("V1", "V2", "V3", "V4")[j1]
print(yourDF)

Remember to replace . (V1, V2, V3, V4) and c("V1", "V2", "V3", "V4") with your actual column names.

Solution 10: Arithmetic Logic (Base R)

A clever, albeit less readable, approach uses arithmetic to derive the index.

with(DF, {
  names(DF)[(V1 > V2 & V1 > V3) * 1 + (V2 > V3 & V2 > V1) * 2 + (V3 > V1 & V3 > V2) * 3]
})

This method relies on boolean logic and direct indexing. It is less adaptable to datasets with more columns.

FAQs on R: Identify Column Name of Maximum Value Per Row

Q: How do I find the column name with the maximum value for each row in R

ANS: You can use base R functions like apply(df, 1, which.max) combined with colnames() or the more efficient max.col(). Packages like dplyr and data.table also offer robust solutions.

Q: What happens if there are ties for the maximum value in a row

ANS: Functions like which.max() and max.col(ties.method = "first") will return the first column encountered with the maximum value. Other ties.method options like “random” or “last” can be used with max.col(). Methods involving reshaping or grouping can explicitly retain all tied column names.

Q: Which method is fastest for large datasets

ANS: For large datasets, data.table solutions generally offer the best performance due to their optimized C backend. Base R’s max.col() is also quite efficient. dplyr’s rowwise() is readable but may be slower on very large datasets compared to data.table.

Q: Can I apply this to a subset of columns

ANS: Yes, most methods allow you to specify a subset of columns. For example, with dplyr, you can use across(columns_to_consider) and with data.table, you can select specific columns using .SDcols or by explicitly listing them.
