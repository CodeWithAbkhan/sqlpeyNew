Introduction

If you’re looking to have your Python script running continuously on a Linux system, transforming it into a daemon or service is a great approach. This method ensures your script executes in the background, making it highly efficient for tasks such as monitoring emails or performing regular updates. Below, we delve into the top eight methods for achieving this.

Method 1: Classic Daemon Class

One of the traditional ways to implement a daemon in Python is by using a custom Daemon class. Below is a simplified version of the daemon code that you can utilize:

#!/usr/bin/env python

import os, sys, time, atexit
from signal import SIGTERM

class SimpleDaemon:
    """
    A basic daemon implementation.
    
    Subclass this daemon and override the run() method with your desired functionality.
    """
    def __init__(self, pidfile):
        self.pidfile = pidfile

    def daemonize(self):
        try:
            if os.fork():
                sys.exit(0) 
        except OSError as e:
            sys.stderr.write(f"Fork #1 failed: {e}\n")
            sys.exit(1)

        os.chdir("/")
        os.setsid()
        os.umask(0)
        
        try:
            if os.fork():
                sys.exit(0) 
        except OSError as e:
            sys.stderr.write(f"Fork #2 failed: {e}\n")
            sys.exit(1)

        sys.stdout.flush()
        sys.stderr.flush()
        with open(os.devnull, 'r') as si, open(os.devnull, 'a+') as so, open(os.devnull, 'a+') as se:
            os.dup2(si.fileno(), sys.stdin.fileno())
            os.dup2(so.fileno(), sys.stdout.fileno())
            os.dup2(se.fileno(), sys.stderr.fileno())

        atexit.register(self.delpid)
        with open(self.pidfile, 'w') as f:
            f.write(f"{os.getpid()}\n")

    def delpid(self):
        os.remove(self.pidfile)

    def start(self):
        if os.path.exists(self.pidfile):
            sys.stderr.write(f"Pidfile {self.pidfile} already exists. Daemon already running?\n")
            sys.exit(1)

        self.daemonize()
        self.run()

    def stop(self):
        if not os.path.exists(self.pidfile):
            sys.stderr.write(f"Pidfile {self.pidfile} does not exist. Daemon not running?\n")
            return

        with open(self.pidfile, 'r') as f:
            pid = int(f.read().strip())

        try:
            while True:
                os.kill(pid, SIGTERM)
                time.sleep(0.1)
        except OSError as err:
            if str(err).find("No such process") > 0:
                if os.path.exists(self.pidfile):
                    os.remove(self.pidfile)

    def run(self):
        """Override this method with your task"""
        pass

Method 2: Systemd Service File

A more modern method to run a Python script as a background service in Linux involves creating a Systemd service file:

[Unit]
Description=My Python Script Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/python3 /path/to/your_script.py
User=your_username
Group=your_groupname
Restart=on-failure

[Install]
WantedBy=multi-user.target

Place this file as my_script.service in /etc/systemd/system/. After creating the service file, enable and start the service:

sudo systemctl enable my_script.service
sudo systemctl daemon-reload
sudo systemctl start my_script.service

You can check the status of your service using:

systemctl status my_script.service

Method 3: Using Python-daemon Library

The python-daemon library simplifies the creation of a well-behaved Unix daemon process. This library manages process creation, exit handling, and log redirection.

Install it via pip:

pip install python-daemon

Then, utilize it in your script:

import daemon

def your_task():
    while True:
        # Your background task code here
        time.sleep(5)

with daemon.DaemonContext():
    your_task()

Method 4: Forking the Process

You can directly use os.fork() to turn your script into a daemon. Here’s a basic example:

import os
import sys
import time

def daemonize():
    pid = os.fork()
    if pid:
        sys.exit()

    os.setsid()
    os.fork()
    if pid:
        sys.exit()

    sys.stdout.flush()
    sys.stderr.flush()

    while True:
        # Replace this with your function
        print("Running...")
        time.sleep(5)

if __name__ == "__main__":
    daemonize()

Method 5: Daemonize Library

Another popular option is the daemonize library. First, install it using:

pip install daemonize

Then, you can implement it as follows:

import time
from daemonize import Daemonize

def main():
    while True:
        # Your code here
        time.sleep(5)

daemon = Daemonize(app="my_app", pid="/tmp/my_app.pid", action=main)
daemon.start()

Method 6: Shell Script Wrapper

You can also create a shell script to execute your Python script and manage it as a service:

  1. Create a script called start_script.sh:
#!/bin/sh
python /path/to/your_script.py &
  1. Place it in /etc/init.d/ and ensure it has executable permissions:
chmod +x /etc/init.d/start_script.sh

You can start or stop your script using:

/etc/init.d/start_script.sh start
/etc/init.d/start_script.sh stop

Method 7: Utilizing Cron Jobs

While not creating a true daemon, if your task can run at specified intervals, you can use cron jobs. Here’s an example:

To open the crontab editor, run:

crontab -e

Add an entry to run your script every minute:

* * * * * /usr/bin/python /path/to/your_script.py

Method 8: The screen Utility

If you’re looking for a quick way to manage long-running processes without creating a daemon, consider using screen. Install it if you don’t have it:

sudo apt-get install screen

Create a new session with:

screen -S my_session

Then run your script within that session. You can detach from the session and log out without stopping the script:

Ctrl-a d

To reattach later, use:

screen -r my_session

FAQs on Top 8 Methods to Run a Python Script as a Daemon in Linux

Q: What is the difference between a daemon and a service?

A: A daemon is a background process that runs independently, while a service refers to various kinds of system services that run on a computer, often managed by a service manager like systemd.

Q: Can I run multiple Python scripts as daemons?

A: Yes, you can set up multiple services, each with its own service file, allowing multiple scripts to run simultaneously as daemons.

Q: What should I do if my daemon crashes?

A: Ensure that the daemon file has a Restart=on-failure directive in the service file to allow the system to automatically restart it.

Q: How do I log output from my daemon?

A: You can redirect stdout and stderr to log files in your daemon code or service file by specifying StandardOutput and StandardError parameters.
