Solved: How to Fix the AWS Lambda Error ‘No module named lambda_function’

python AWS
4 min read · Nov 6, 2024

Table of Contents

    • Top 6 Solutions to Resolve the AWS Lambda Import Error
    • Practical Example Code
    • FAQs on AWS Lambda No Module Named Error

In the realm of serverless computing, AWS Lambda stands as a prominent service that allows developers to run their code without provisioning or managing servers. However, while crafting a Lambda function in Python, encountering the error “No module named lambda_function” can be frustrating. This question delves into effective solutions and practices to circumvent this issue while creating your AWS Lambda Python deployment package.

Identifying the Problem

When you upload a zip file containing your Python script (in this case lambda_function.py) and trigger the execution, you might come across the following error:

START RequestId: 9e64e2c7-d0c3-11e5-b34e-75c7fb49d058 Version: $LATEST
**Unable to import module 'lambda_function': No module named lambda_function**
END RequestId: 9e64e2c7-d0c3-11e5-b34e-75c7fb49d058

This error suggests that AWS Lambda is unable to locate your script or its dependencies. Below are specific solutions to help you resolve this:

Top 6 Solutions to Resolve the AWS Lambda Import Error

  1. Zip the Correct Contents: Ensure that you are zipping the contents of your project directory correctly. When creating your zip file, cd into your directory and run:

    zip -r ../lambda_package.zip *

    This command makes sure that all necessary files, including your Python script, are included at the root level of the zip file, not inside a subfolder.

  2. Permissions Check: Verify that your zipped files have the necessary read permissions. Use the following command:

    chmod -R 444 .

    This ensures that all files are readable, which is a requirement for AWS Lambda to access them.

  3. Correct Handler Configuration: Check that the handler is set correctly in your AWS Lambda configuration. The format must be file_name.function_name. For instance, if your file is named lambda_function.py and the function is lambda_handler, verify that your handler is set to:

    lambda_function.lambda_handler

  4. Include Dependencies: If your script utilizes third-party libraries such as requests, ensure they are included in your deployment package. You can do this by:

    pip install requests --target .

    This places the library within your current directory so it can be included in the zip file.

  5. Proper Directory Structure: The structure of your zip file is crucial. It should look similar to:

    lambda_function.py
requests/
other_dependencies/

    This structure ensures that Python can find the modules when the Lambda function executes.

  6. Use AWS Lambda Layers: Consider using Lambda Layers for third-party libraries which can help keep your deployment package lightweight. For a comprehensive guide, refer to the AWS documentation on Lambda layers .

Practical Example Code

Here’s a modified version of the code snippet you might utilize in your Lambda function:

import boto3
import urllib.parse
import json
import requests  # Include your dependencies

s3 = boto3.client('s3')

def lambda_handler(event, context):
    bucket = event['Records'][0]['s3']['bucket']['name']
    key = urllib.parse.unquote_plus(event['Records'][0]['s3']['object']['key'])
    
    try:
        response = s3.get_object(Bucket=bucket, Key=key)
        s3.download_file(bucket, key, '/tmp/data.txt')
        lines = [line.rstrip('\n') for line in open('/tmp/data.txt')]
        
        for line in lines:
            col = line.split(',')
            print(col[5], col[6])
        
        return response['ContentType']
        
    except Exception as e:
        print(e)
        print(f'Error fetching object {key} from bucket {bucket}. Ensure they exist and your bucket is in the same region as this Lambda function.')
        raise e

FAQs on AWS Lambda No Module Named Error

Q: How do I confirm my AWS Lambda permissions are set up correctly?

A: You can navigate to the IAM console and check the permissions assigned to the role that your Lambda function uses. Ensure that it has adequate permissions for the actions it needs to perform, particularly accessing S3 and relevant resources.

Q: What should I do if the error persists after trying these solutions?

A: If the error continues, double-check your deployment package and consider deploying via the AWS CLI or SAM CLI to get more informative error messages. You can also consult the AWS Lambda documentation for troubleshooting tips.
