Solved: How to Ensure logging.info Shows Up in the Console

When attempting to log information in Python using logging.info, you might find that it doesn’t appear in the console output, whereas logs tagged with logging.warn do show up. This can be quite perplexing. The default logging level is set to WARNING, meaning only warning and error logs are shown, which explains this discrepancy. If you want to see the output from logging.info, here are some effective methods to adjust your logging configuration to achieve this.

Top 5 Methods to Ensure logging.info Appears in the Console

Method 1: Set the Logging Level Globally

You can use the logging.basicConfig() function to set the logging level. By changing this level to DEBUG or INFO, you can ensure that all messages at that level and above will be displayed.

import logging

logging.basicConfig(level=logging.DEBUG)
logging.info('This info message will appear in the console.')

By using level=logging.DEBUG, you make sure that not only INFO messages but also DEBUG messages are displayed.

Method 2: Configure Logging with a StreamHandler

If changing the configuration with basicConfig doesn’t resolve the visibility of info messages, you might want to define a StreamHandler specifically for your logger:

import logging

## Setting up logging to a file
logging.basicConfig(level=logging.DEBUG, 
                    format='%(asctime)s %(name)-12s %(levelname)-8s %(message)s', 
                    datefmt='%m-%d %H:%M',
                    filename='/temp/myapp.log', 
                    filemode='w')

## Creating console handler
console = logging.StreamHandler()
console.setLevel(logging.INFO)

## Adding the console handler to the root logger
logging.getLogger('').addHandler(console)

logging.info('This message will now display on the console.')

This approach allows you to log to a file and the console simultaneously while controlling their output levels separately.

Method 3: Create a Logger Instance

In scenarios where you want specific behavior, you can create an instance of a logger, setting its level to INFO:

import logging

## Create a custom logger
logger = logging.getLogger(__name__)
logger.setLevel(logging.INFO)

logger.info('This info level message will now show!')

Instantiate a logger object configured to display INFO messages, ensuring your messages are not suppressed.

Method 4: Ensure Stream Handler is Used in Newer Versions

In more current versions of Python, integrating a stream handler may be needed to ensure that INFO messages are properly displayed. Here’s how:

import logging

## Create the logger
logger = logging.getLogger('__name__')
logger.setLevel(logging.INFO)

## Create console handler to output INFO and higher
ch = logging.StreamHandler()
ch.setLevel(logging.INFO)

## Add handler to the logger
logger.addHandler(ch)

## Log messages at different severity levels
logger.debug('This debug message will not be displayed.')
logger.info('This info message will be shown in the console.')

Method 5: Simple Logger Configuration with Django

If you are using Django for web applications, you can change the log settings in your settings.py:

LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'handlers': {
        'console': {
            'level': 'INFO',
            'class': 'logging.StreamHandler',
        },
    },
    'loggers': {
        'django': {
            'handlers': ['console'],
            'level': 'INFO',
            'propagate': True,
        },
    },
}

This configuration will set the logging level for your Django application to INFO, capturing messages logged at this level.

Alternative Approaches

For those using additional libraries such as absl.logging, the equivalent configuration is straightforward. You can set the verbosity as follows:

from absl import logging
logging.set_verbosity(logging.INFO)

FAQs on How to Ensure logging.info Shows Up in the Console

Q: Why doesn't logging.info show up in my console?

A: The default logging level is set to WARNING, which suppresses lower-level messages like INFO. You need to configure the logging level to DEBUG or INFO using logging.basicConfig(level=logging.INFO) or by adding a StreamHandler that captures INFO messages.

Q: How can I permanently set the logging level for my Python applications?

A: You can set the default logging configuration in your main application script using logging.basicConfig() or by configuring logging in a central place like settings.py in Django applications.
