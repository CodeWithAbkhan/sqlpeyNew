“Python Date Time How to Determine the Day of the Week”

When working with time-series data or performing date calculations in Python, obtaining the specific day of the week (e.g., Monday, Tuesday, or its numerical representation) is a common requirement. This can be handled through several built-in modules and external libraries like Pandas, offering flexibility depending on the input format and desired output structure.

How can one reliably extract the day of the week from a date object or string in Python, covering numerical mapping, locale-specific names, and handling string formats?

Utilizing the datetime Module for Basic Day Retrieval

The datetime module provides fundamental methods for date and time manipulation, offering direct ways to get the day index.

Method 1: Using datetime.weekday() (0=Monday, 6=Sunday)

The weekday() method on a datetime object returns the day of the week as an integer, where Monday is denoted as 0 and Sunday as 6.

import datetime

# Example usage with today's date
current_dt = datetime.datetime.today()
day_index_0_6 = current_dt.weekday()

print(f"Current Date: {current_dt}")
print(f"Weekday Index (0=Mon, 6=Sun): {day_index_0_6}")

Method 2: Using datetime.isoweekday() (1=Monday, 7=Sunday)

For a representation where Monday starts at 1 and Sunday ends at 7, use isoweekday(). This aligns with the ISO 8601 standard.

import datetime

# Example for a specific date
target_date = datetime.date(2012, 3, 23)
iso_day_index_1_7 = target_date.isoweekday()

print(f"ISO Weekday Index (1=Mon, 7=Sun): {iso_day_index_1_7}")
# Solution 23 shows this index is the third element from isocalendar()
weekday_iso, week_num = target_date.isocalendar()[2], target_date.isocalendar()[1]
print(f"isocalendar()[2] result: {weekday_iso}")

Method 3: Formatting Output with strftime()

To retrieve the full or abbreviated name of the day directly, strftime() with specific format codes is highly effective.

  • %A: Full weekday name (e.g., ‘Wednesday’).
  • %a: Abbreviated weekday name (e.g., ‘Wed’).
from datetime import datetime

# Get the current time's weekday name
full_name = datetime.now().strftime('%A')
abbr_name = datetime.now().strftime('%a')

print(f"Full Day Name: {full_name}")
print(f"Abbreviated Day Name: {abbr_name}")

Alternative 3.1: Mapping Index to Name Manually

If you prefer using the integer index from weekday(), you can create a mapping list to get the string name.

import datetime

day_map = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]
specific_date = datetime.date(2000, 12, 1)
day_index = specific_date.weekday()
day_name_from_map = day_map[day_index]

print(f"Date {specific_date} corresponds to: {day_name_from_map}")

Alternative 3.2: Converting String Dates to Day Name

If your date is initially a string in a specific format (e.g., DD/MM/YYYY), you must parse it first using strptime.

import datetime

date_string_dmy = '21/03/2012'
# Parse the string into a datetime object
date_obj = datetime.datetime.strptime(date_string_dmy, '%d/%m/%Y')
# Format the object to get the full weekday name
day_result = date_obj.strftime("%A") 

print(f"The day for {date_string_dmy} is: {day_result}")

Employing the calendar Module for Locale-Awareness

The calendar module integrates well with datetime objects to fetch day names, potentially respecting the system’s locale settings for language (though the examples here use English defaults).

Method 4: Using calendar.day_name Index

This combines datetime.weekday() with the calendar.day_name array for localized names. Note that calendar.day_name indexes start with Sunday=0, which differs from datetime.weekday(). To align them correctly, adjustments or reliance on datetime.weekday() indexing logic is necessary. Self-correction: Using the datetime.weekday() index directly on calendar.day_name is often incorrect due to indexing differences. A better alignment is shown below.

If we use calendar.weekday(year, month, day) which is 0=Monday to 6=Sunday, it aligns perfectly with the Python standard datetime.weekday() result.

import calendar
import datetime

year, month, day = 2017, 12, 22
# calendar.weekday() returns 0 (Monday) through 6 (Sunday)
day_code = calendar.weekday(year, month, day)
day_names = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]
day_name_from_calendar = day_names[day_code]

print(f"Day name using calendar.weekday(): {day_name_from_calendar}")

Alternative 4.1: Using date.today() with calendar.day_name

This fetches the name corresponding to today’s date, using the correct index mapping.

from datetime import date
import calendar

today_date = date.today()
# calendar.day_name indexes align with datetime.weekday() output if we use the result of weekday()
day_name_localized = calendar.day_name[today_date.weekday()] 

print(f"Localized Day Name Today: {day_name_localized}")

Advanced Methods and External Libraries

For large datasets or complex parsing needs, libraries like Pandas or specialized date libraries offer efficient solutions.

Method 5: Utilizing Pandas for DataFrames

Pandas simplifies operations across entire columns of dates using its dt accessor.

5a. Getting Day Name from a Series

If you have a column of datetime objects in a DataFrame, you can use .dt.day_name():

import pandas as pd
from datetime import datetime

# Sample Data Setup (Simulating data from Solution 18)
data = {'Dates': ['2010-04-01', '2010-04-02', '2010-04-03', '2010-04-04', '2010-04-05']}
df_example = pd.DataFrame(data)
df_example['Dates'] = pd.to_datetime(df_example['Dates'])

# Extract day name
df_example['Day_Name'] = df_example['Dates'].dt.day_name()

print("DataFrame with Day Names:")
print(df_example)

5b. Getting Integer Weekday from a Series

Using .dt.weekday provides the integer index (0=Monday).

# Extract day index (0=Monday)
df_example['Day_Index_0_6'] = df_example['Dates'].dt.weekday

print("\nDataFrame with Day Indices:")
print(df_example[['Dates', 'Day_Index_0_6']])

Method 6: Using dateutil.parser for Robust String Parsing

If date strings are inconsistent, dateutil.parser can often parse them reliably before formatting.

from dateutil import parser

date_str_robust = 'January 11, 2010'

# Parse string and format for abbreviated name
abbr = parser.parse(date_str_robust).strftime("%a")
# Parse string and format for full name
full = parser.parse(date_str_robust).strftime("%A")

print(f"Robust Parse ('{date_str_robust}'): Abbr='{abbr}', Full='{full}'")

Alternative 6: A Custom Zeller’s Congruence Implementation

For environments where external libraries are forbidden, the calculation can be done algorithmically, such as implementing Zeller’s congruence (note: this implementation provides Sunday=1 to Saturday=7).

def calculate_zeller_weekday(year, month, day):
    """
    Calculates day of the week using Zeller's Congruence.
    Output: Sunday = 1, Saturday = 7 (for Gregorian calendar)
    """
    m, q = month, day
    
    # Adjust month and year for January (13) and February (14)
    if m <= 2:
        m += 12
        year -= 1
        
    K = year % 100    # Year of the century
    J = year // 100   # Century
    
    # Formula components for Gregorian calendar
    f = (q + int(13 * (m + 1) / 5.0) + K + int(K / 4.0) + int(J / 4.0) - 2 * J)
    
    h = f % 7
    
    # Adjust result: 0=Saturday, 1=Sunday, ..., 6=Friday. We map to 1=Sunday, 7=Saturday
    if h == 0:
        return 7  # Saturday
    elif h == 1:
        return 1  # Sunday
    else:
        # h=2 is Monday, h=3 is Tuesday, ..., h=6 is Friday
        return h - 1 

# Example check (March 23, 2012 was a Friday, which is 6 in this system)
zeller_result = calculate_zeller_weekday(2012, 3, 23)
print(f"Zeller's result for 2012-03-23 (1=Sun to 7=Sat): {zeller_result}")

Numerical Mapping without Standard Modules (Post-1700)

A pure arithmetic approach can determine the day index relative to a fixed past date (like 1700/1/1 = Friday, index 5).

def derive_day_from_arithmetic(year, month, day):
    # Day offsets for months (Jan=0, Feb=31, Mar=59, etc.)
    offset = [0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334]
    week_names = ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday']
    
    # Check for Feb correction for leap years before March
    after_feb = 0
    if month > 2:
        after_feb = 1
        
    # Calculate years past 1700, adjusting for leap year status in the starting year
    aux = year - 1700 - after_feb
    
    # Reference day: 1700/1/1 was a Friday (index 5 if Sunday=0)
    day_of_week_index = 5
    
    # Add total days from full years, accounting for the start year
    day_of_week_index += (aux + after_feb) * 365                  
    
    # Leap year correction formula
    day_of_week_index += aux // 4 - aux // 100 + (aux + 100) // 400     
    
    # Sum monthly offsets and the day of the month
    day_of_week_index += offset[month - 1] + (day - 1)               
    
    final_index = day_of_week_index % 7
    return final_index, week_names[final_index]

day_idx, day_name = derive_day_from_arithmetic(2013, 6, 15)
print(f"Arithmetic calculation for 2013-06-15: Index {day_idx}, Name {day_name}")
