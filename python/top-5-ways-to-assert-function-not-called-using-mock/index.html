Top 5 Ways to Assert a Function Was Not Called Using Mock in Python

When working with the Mock library in Python, it’s crucial to ensure certain functions or methods are not inadvertently called during unit tests. Although the documentation covers methods for asserting that mocks have been called, such as mock.assert_called_with() and mock.assert_called_once_with(), guidance on a specific assertion for functions that were not called can be less straightforward. Let’s explore five effective methods to assert that a function was not invoked during your tests.

Method 1: Utilize assert_not_called()

For users running the mock library (a backport of unittest.mock for older Python versions), recent versions support the method assert_not_called(). If you haven’t updated your mock library, perform an upgrade with the following command:

pip install mock --upgrade

This allows you to simply call:

mock_instance.assert_not_called()

This approach is succinct and maintains clarity in your tests.

Method 2: For Python 3.5 or Higher – Use assert_not_called()

If you are using Python version 3.5 or later, the built-in unittest.mock allows for:

mock_object.assert_not_called()

This method is straightforward and integrates seamlessly into your testing suite, ensuring that the tested method has not been invoked.

Method 3: Check the called Attribute

While you could check the called attribute of the mock, a more informative approach is to inspect the call_args_list when an assertion fails. This can be achieved using unittest assertions, such as:

self.assertListEqual(my_var.call_args_list, [])

In case of failure, the error message will be explicit:

AssertionError: Element counts were not equal: First has 0, Second has 1: call('first argument', 4)

This helps to clarify why the test failed, providing more context about unexpected calls.

Method 4: Assertion with unittest.TestCase

For tests structured around unittest.TestCase, you can use assertions like assertFalse, assertEqual, and assertTrue. Here’s how to check if a mock method was not called:

import unittest
from unittest import mock

class MyTests(unittest.TestCase):
    def setUp(self):
        self.message = "Method should not be called. Called {times} times!"

    @mock.patch("my_module.method_to_mock")
    def test_method_not_called(self, mock_method):
        # Ideally, the method should not be called in this test.
        self.assertFalse(mock_method.called, self.message.format(times=mock_method.call_count))

This method leverages built-in assertions for clarity and correctness.

Method 5: Use call_args_list for Granular Control

An alternative way to track calls is through call_args_list. This provides granular control, allowing checks against specific arguments as needed. For instance:

def test_function_not_called_with_specific_args():
    with mock.patch('my_module.method_to_mock') as my_var:
        assert ((some, args),) not in my_var.call_args_list

This ensures that a specific call never occurred with the expected arguments, giving you thorough validation of your mock behavior.

Practical Example

To illustrate, consider a scenario where you want to ensure that a compute function is not called on certain conditions. Here’s a sample unit test:

from unittest import mock

def compute(x):
    return x + 1

def process_list(values):
    for value in values:
        if value > 0:
            compute(value)

def test_process_list():
    with mock.patch('__main__.compute') as mock_compute:
        process_list([-1, -2, -3])  # No calls should occur.
        mock_compute.assert_not_called()

In this example, compute is mocked, and since the input values do not meet the condition, its invocation is confirmed to not happen.

Alternatives to Mock Usage

While unittest.mock is widely utilized for such testing scenarios, other frameworks like pytest combined with plugins can also provide enhanced mocking capabilities. Always consider exploring the most suitable libraries based on your specific needs for flexibility and functionality.

FAQs on Top 5 Ways to Assert a Function Was Not Called Using Mock in Python

Q: How do I verify a function was not called in my tests?

A: You can use methods like assert_not_called() in the unittest.mock library to ensure a mock should not have been called during your test execution.

Q: Can I check if a function was not invoked with specific parameters?

A: Yes! You can leverage the call_args_list attribute to assert that a specific set of arguments was not used in any call to a mocked method.

Q: What if I'm using an older version of Python?

A: If you’re using an older version of Python that doesn’t include assert_not_called(), consider updating your mock library or use the alternative methods mentioned, like checking the called attribute.

Q: Are there alternative libraries for mocking in Python?

A: Yes! While unittest.mock is standard, you can also explore alternatives such as the pytest library, which provides additional features and plugins that complement mocking and testing practices.
