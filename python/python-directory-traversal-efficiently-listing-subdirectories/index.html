“Python Directory Traversal: Efficiently Listing Subdirectories”

How does one effectively retrieve a list of subdirectories within a specified folder structure in Python, considering both immediate children and deeply nested directories? Furthermore, what performance implications exist across the various standard library approaches available?

This investigation dives into several robust methods for directory traversal, focusing on clarity, efficiency, and correctness across different Python versions.

Traversing Directory Trees: Recursive vs. Immediate Listing

The requirement often dictates whether you need only the direct children of a folder or every subdirectory throughout the entire hierarchy.

Recursive Listing of All Subdirectories

For obtaining every subdirectory, even those nested several levels deep, several tools shine:

Using os.walk() for Full Recursion

The os.walk() function is the traditional method for deep directory traversal. It generates a 3-tuple for each directory it visits: (directory path, list of subdirectories, list of files).

To extract just the path of every directory encountered recursively:

import os

target_directory = "<insert_folder>"

# This captures the directory path (the first element of the yielded tuple)
all_recursive_dirs_walk = [root_path for root_path, _, _ in os.walk(target_directory)]

A slight variation mentioned extracts all directory paths by taking the first element of the walk tuple:

# Note: os.walk includes the starting directory in the results
all_dirs_from_walk = [x[0] for x in os.walk(target_directory)]

A Faster Recursive Approach with os.scandir()

For performance-critical applications, a custom recursive function leveraging the speed of os.scandir() can outperform os.walk():

import os

def fast_scandir_recursive(dirname):
    """Returns a list of all subfolders recursively, faster than os.walk."""
    subfolders = [f.path for f in os.scandir(dirname) if f.is_dir()]
    for sub_dir_name in list(subfolders):
        subfolders.extend(fast_scandir_recursive(sub_dir_name))
    return subfolders

# Example usage:
# recursive_paths = fast_scandir_recursive("<insert_folder>")

Leveraging pathlib.Path.rglob()

The modern pathlib module offers a concise, object-oriented way to handle recursive searches using the glob pattern **:

from pathlib import Path

target_path = Path("<insert_folder>")

# Matches all paths recursively, filter to keep only directories
all_dirs_rglob = [p for p in target_path.rglob('*') if p.is_dir()]

It is noted that pathlib.Path.rglob('*') when filtered for directories can sometimes be significantly slower than os.walk or the custom fast_scandir.

Retrieving Only Immediate Subdirectories (Non-Recursive)

When only the direct children are required, specific methods offer excellent speed advantages over initializing a full recursive walk.

Preferred Method: os.scandir() (Python 3.5+)

os.scandir() is highly recommended for immediate listings due to its efficiency (it retrieves file type information during the directory scan).

To get the full path of immediate subdirectories:

import os

folder_to_scan = "<insert_folder>"
immediate_subfolders = [entry.path for entry in os.scandir(folder_to_scan) if entry.is_dir()]

# To get only the directory names (not the full path):
immediate_folder_names = [entry.name for entry in os.scandir(folder_to_scan) if entry.is_dir()]

If you only need names and are using Python 3.6+, this is extremely fast:

import os
# Assuming 'mypath' is defined
# immediate_names = [f.name for f in os.scandir(mypath)]

Using pathlib.Path.iterdir() (Python 3.4+)

This offers an object-oriented equivalent to os.scandir for immediate contents:

from pathlib import Path

p = Path("<insert_folder>")
immediate_dirs_pathlib = [f for f in p.iterdir() if f.is_dir()]

Using os.listdir() with Filtering

A more traditional, though often less performant than scandir, approach involves listing contents and checking each entry:

import os

d = '<insert_folder>'
# Returns full paths
immediate_dirs_listdir = [os.path.join(d, o) for o in os.listdir(d) if os.path.isdir(os.path.join(d, o))]

# Alternative using filter and lambda (often preferred in older codebases)
d_alt = '.'
filtered_dirs = list(filter(lambda x: os.path.isdir(os.path.join(d, x)), os.listdir(d)))

Using glob.glob() for Immediate Listings

glob can be used, though it might require careful pattern construction to exclude files:

from glob import glob
import os

# The trailing '/' ensures only directories are matched (on Unix-like systems)
# Note: Behavior can differ slightly across operating systems.
immediate_dirs_glob = glob(os.path.join("<path/to/directory>", "*/"))

# -*- coding: utf-8 -*-
# Python 3


import time
import os
from glob import glob
from pathlib import Path


directory = r"&lt;insert_folder&gt;"
RUNS = 1


def run_os_walk():
    a = time.time_ns()
    for i in range(RUNS):
        fu = [x[0] for x in os.walk(directory)]
    print(f"os.walk\t\t\ttook {(time.time_ns() - a) / 1000 / 1000 / RUNS:.0f} ms. Found dirs: {len(fu)}")


def run_glob():
    a = time.time_ns()
    for i in range(RUNS):
        fu = glob(directory + "/*/")
    print(f"glob.glob\t\ttook {(time.time_ns() - a) / 1000 / 1000 / RUNS:.0f} ms. Found dirs: {len(fu)}")


def run_pathlib_iterdir():
    a = time.time_ns()
    for i in range(RUNS):
        dirname = Path(directory)
        fu = [f for f in dirname.iterdir() if f.is_dir()]
    print(f"pathlib.iterdir\ttook {(time.time_ns() - a) / 1000 / 1000 / RUNS:.0f} ms. Found dirs: {len(fu)}")


def run_os_listdir():
    a = time.time_ns()
    for i in range(RUNS):
        dirname = Path(directory)
        fu = [os.path.join(directory, o) for o in os.listdir(directory) if os.path.isdir(os.path.join(directory, o))]
    print(f"os.listdir\t\ttook {(time.time_ns() - a) / 1000 / 1000 / RUNS:.0f} ms. Found dirs: {len(fu)}")


def run_os_scandir():
    a = time.time_ns()
    for i in range(RUNS):
        fu = [f.path for f in os.scandir(directory) if f.is_dir()]
    print(f"os.scandir\t\ttook {(time.time_ns() - a) / 1000 / 1000 / RUNS:.0f} ms.\tFound dirs: {len(fu)}")


if __name__ == '__main__':
    run_os_scandir()
    run_os_walk()
    run_glob()
    run_pathlib_iterdir()
    run_os_listdir()

Key Takeaway: If you only need immediate children, use os.scandir() or pathlib.iterdir(). Avoid os.walk() for top-level-only needs, as it can be hundreds of times slower. For full recursive needs, os.walk() remains a solid, reliable choice.

Advanced Scenarios

Handling Soft Links

If traversing directories where symbolic links (soft links) might cause infinite recursion, be aware that standard os.walk or simple recursive implementations might follow these links. One response indicated that explicit checks might be necessary if soft links are present and undesired in the directory list.

Platform-Specific Paths

When dealing with non-standard paths, such as Windows UNC paths, utilizing pathlib.WindowsPath provides robust handling:

from pathlib import WindowsPath

def get_immediate_subdirs_windows(unc_path_str):
    p = WindowsPath(unc_path_str)
    return [f for f in p.iterdir() if f.is_dir()]

# subdirs = get_immediate_subdirs_windows(r'\\server_name\share$')

Alternative: Using System Commands (Linux/macOS)

For Unix-like systems, executing the find command via os.popen can be extremely fast for large structures:

import os

def get_dirs_via_find(path):
    # Executes 'find /path/to/dir -type d'
    command = f"find {path} -type d"
    output = os.popen(command).read().splitlines()
    return output

FAQs on Python Directory Listing

Q: Which method is fastest for getting immediate subdirectories in Python

ANS: os.scandir() is generally the fastest approach for retrieving immediate subdirectories, particularly in Python 3.5 and newer, as it performs file type checks during the initial directory read operation.

Q: Does os.walk return only subdirectories

ANS: No, os.walk() yields a tuple where the first element is the current directory being processed, followed by lists of subdirectories and files within that current directory. You must explicitly filter for just the directory paths.

Q: How can pathlib list all files and folders recursively

ANS: Use Path(your_dir).rglob('*') which retrieves all entries recursively. You then filter this list using if entry.is_dir() to isolate only directories.

Q: What is the drawback of os.walk for immediate listing

ANS: os.walk performs deep traversal by design, making it significantly slower (potentially hundreds of times slower) than optimized methods like os.scandir() when only the immediate child directories are needed.
