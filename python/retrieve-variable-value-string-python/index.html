“Retrieve Variable Value Using String Name in Python”

How does one securely and reliably fetch the actual value of a Python variable when presented only with the variable’s identifier as a text string? This dynamic access is crucial in scenarios involving configuration parsing, reflection, or building dynamic interpreters. Different contexts—global, local, or within another module—require distinct approaches.

Accessing Variables Within the Current Global Namespace

When a variable resides in the global scope, Python offers a straightforward dictionary-like mechanism to introspect and retrieve its value using its string name.

Method 1: Employing the globals() Built-in Function

The globals() function returns a dictionary representing the current module’s global symbol table. You can treat this dictionary like any other, using the variable name string as the key to fetch its value.

Consider this example where a is defined globally:

# Setup in the global scope
system_setting_value = 42
print(f"Initial value of 'system_setting_value': {system_setting_value}")

# Using globals() to retrieve the value dynamically
variable_name_string = 'system_setting_value'
retrieved_value = globals()[variable_name_string]

print(f"Value retrieved via globals(): {retrieved_value}")

This method is preferred for accessing variables explicitly declared in the global scope of the current file.

Accessing Variables in Other Modules

If the variable exists in a different Python module and you have imported that module, direct global access via globals() will fail. To inspect another module’s namespace, the getattr() function is the appropriate tool.

Method 2: Using getattr() for Module Variables

The getattr(object, name[, default]) function retrieves an attribute (which includes variables) from an object (like a module) given its name as a string.

Suppose you have a file named configuration.py:

# configuration.py content
API_KEY = "secure_token_123"
TIMEOUT_SECONDS = 30

And in your main script, you import it:

import configuration
import sys

# Attempting to access API_KEY string dynamically
target_variable = "API_KEY"

# Accessing the variable within the 'configuration' module
try:
    # Note: In Python 2, this would be getattr(module, name). In Python 3+, 
    # using getattr on the imported module object is standard.
    key_value = getattr(configuration, target_variable)
    print(f"Retrieved {target_variable} from 'configuration' module: {key_value}")
except AttributeError:
    print(f"Error: Attribute '{target_variable}' not found in configuration module.")

# Alternative: Accessing a variable from the 'sys' module
print(f"Retrieving Python version using getattr on sys: {getattr(sys, 'version')}")

This approach adheres to modular boundaries and is safer than manipulating module dictionaries directly when reflection across modules is required. You can refer to the official documentation for more on getattr .

Dynamic Evaluation and Its Associated Risks

A third, often powerful but risky, technique involves evaluating a string as Python code within the current execution context.

Method 3: Utilizing the eval() Function

If the variable is in the current local or global scope accessible to the call site, eval() can execute the string as code and return the result of that expression.

local_data_point = [10, 20, 30]
x_coordinate = 150

# Case 1: Evaluating a simple local variable name
var_to_check_1 = "x_coordinate"
result_1 = eval(var_to_check_1)
print(f"Result of evaluating '{var_to_check_1}': {result_1}") # Outputs 150

# Case 2: Evaluating a variable whose name is stored in another variable
var_to_check_2 = "local_data_point"
result_2 = eval(var_to_check_2)
print(f"Result of evaluating '{var_to_check_2}': {result_2}") # Outputs [10, 20, 30]

Crucial Security Consideration: The use of eval() is strongly discouraged if the string being evaluated originates from an external or untrusted source. A maliciously crafted string input, such as __import__('os').system('rm -rf /'), could execute arbitrary and destructive commands on the system.

Alternative Contextual Retrieval: locals() and vars()

While globals() handles the global namespace, what about the local namespace?

Method 4: Inspecting Local Variables with locals()

Similar to globals(), the locals() function provides access to the current function’s or module’s local symbol table.

def process_data(input_val):
    # 'temp_result' is a local variable
    temp_result = input_val * 2 + 5 
    
    var_name_str = 'temp_result'
    
    # Attempt to find the local variable by string name
    if var_name_str in locals():
        local_value = locals()[var_name_str]
        print(f"Successfully found local variable '{var_name_str}' with value: {local_value}")
    else:
        print(f"'{var_name_str}' not found in local scope.")

process_data(10)

If you need to check both local and global scopes, you can merge the dictionaries returned by globals() and locals(), although for simple variable lookups, focusing on the correct scope (globals() or locals()) is cleaner. The vars() function is often an alias for locals() inside a function, or it can take an object as an argument to return its __dict__.

Alternative Using eval() with Explicit Scopes

To mitigate some risks associated with unrestricted eval(), you can explicitly pass dictionaries for the global and local scopes: eval(expression, globals=None, locals=None).

If you know the variable is global, you can restrict eval to only use the global scope dictionary:

global_var_for_eval = 999

# Restricting eval to only use the global context
safe_eval_result = eval('global_var_for_eval', globals(), {}) 
print(f"Result using restricted eval scope: {safe_eval_result}")

This prevents eval from accessing unrelated local variables during its execution, enhancing control, though the danger from malicious code within the string remains if the string content itself is untrusted.

FAQs on Retrieve Variable Value String Python

Q: How do I get a variable value using its name string globally

ANS: Use the built-in globals()['variable_name_string'] syntax.

Q: Is it safe to use eval to fetch variable content

ANS: It is only safe if the input string is guaranteed to be non-malicious and you are aware of the current scope context it will operate within.

Q: What function accesses variables in another imported module by name string

ANS: Use the getattr(module_object, 'variable_name_string') function.

Q: Can I access local variables using a string name

ANS: Yes, by inspecting the dictionary returned by the locals() function, similar to using globals().
