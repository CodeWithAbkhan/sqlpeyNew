Top 9 Methods to Rank Items in an Array Using Python NumPy Efficiently

Having an array of numbers and needing to create a separate array that reflects the rank of each element in it is a common task in data analysis. This process can often become inefficient if the original array is sorted multiple times. If you’re using Python and NumPy, there are effective methods to achieve this without incurring the performance cost of sorting twice. Let’s delve into some of the top techniques available for ranking items in an array.

Example Problem

For illustration, consider the following 1D array:

array = np.array([4, 2, 7, 1])

Our goal is to derive the ranks:

ranks = [2, 1, 3, 0]

Best Methods for Ranking in NumPy

Method 1: Using scipy.stats.rankdata

If you are comfortable leveraging scipy, then rankdata is a powerful function that can simplify the ranking process:

from scipy.stats import rankdata

data = [4, 2, 7, 1]
ranks = (rankdata(data) - 1).astype(int)
print(ranks)  # Output: [2 1 3 0]

One notable feature is the method argument which allows for various tie-breaking strategies. For example, you can handle tied ranks by setting different methods:

b = [40, 20, 70, 10, 20, 50, 30, 40, 20]
print(rankdata(b))  # Default method (average rank)
print(rankdata(b, method='ordinal'))  # Ordinal ranking
print(rankdata(b, method='min'))  # Minimum rank for ties

Method 2: Advanced Indexing with argsort

To avoid sorting the array twice while achieving the same result, you can utilize advanced indexing directly:

import numpy as np

array = np.array([4, 2, 7, 1])
temp = array.argsort()
ranks = np.empty_like(temp)
ranks[temp] = np.arange(len(array))
print(ranks)  # Output: [2 1 3 0]

Method 3: Direct Double argsort

Sometimes, leveraging argsort twice is straightforward and still efficient:

ranks = np.array(array).argsort().argsort()
print(ranks)  # Output: [2 1 3 0]

Method 4: Averaged Ranks with np.unique

For a more sophisticated approach, especially useful for handling ties, use np.unique:

a = np.array([4, 1, 6, 8, 4, 1, 6])
unique, inverse = np.unique(a, return_inverse=True)
rank = a.argsort().argsort()

unique_rank_mean = np.zeros_like(unique)
np.add.at(unique_rank_mean, inverse, rank)
unique_count = np.zeros_like(unique)
np.add.at(unique_count, inverse, 1)

rank_mean = unique_rank_mean[inverse]
print(rank_mean)

Method 5: Handling Multidimensional Arrays

If working with multidimensional data, here’s how to adapt the ranking method:

A = np.random.randint(0, 10, (3, 4))
temp = A.argsort(axis=1)
rank = np.empty_like(temp)
for i in range(temp.shape[0]):
    rank[i, temp[i, :]] = np.arange(temp.shape[1])

print(rank)

Method 6: Performance Comparison

The efficiency of these methods can vary significantly. A quick benchmark might reveal:

import timeit

l = list(reversed(range(1000)))
print(timeit.timeit(lambda: (rankdata(l) - 1).astype(int), number=10000))  # Time for rankdata
print(timeit.timeit(lambda: np.array(l).argsort().argsort(), number=10000))  # Time for argsort twice

Method 7: Handling Zeros in Data

When zeros or duplicate values complicate the ranking:

def ranks(v):
    t = np.argsort(v)
    r = np.empty(len(v), int)
    r[t] = np.arange(len(v))
    for i in range(1, len(r)):
        if v[t[i]] <= v[t[i-1]]:
            r[t[i]] = r[t[i-1]]
    return r

print(sorted(zip(ranks(v), v)))

Method 8: Slicing Instead of Sorting

An alternative is to use slicing, which can be faster than sorting in certain cases:

array = np.array([4, 2, 7, 1])
order = array.argsort()
ranks = np.arange(array.shape[0])[order][order]

Method 9: Generalized Case with Multi-Dimensional Numpy Arrays

For a more generalized method that accommodates multidimensional arrays, you can use:

x = np.random.randn(10, 3)
i = np.argsort(x, axis=0)
ranks = np.empty_like(i)
np.put_along_axis(ranks, i, np.repeat(np.arange(x.shape[0])[:, None], x.shape[1], axis=1), axis=0)

FAQs on Top 9 Methods to Rank Items in an Array Using Python NumPy

Q: What is the most efficient method for ranking items in NumPy?

A: The efficiency can vary based on the data characteristics, but using advanced indexing or scipy.stats.rankdata are typically among the fastest methods.

Q: Can these methods handle ties in the data?

A: Yes, methods like scipy.stats.rankdata have built-in mechanisms for handling ties using different strategies.

Q: Are these methods suitable for multidimensional arrays?

A: Yes, several methods can be easily adapted to work with multidimensional data by adjusting the axis in functions like argsort.
