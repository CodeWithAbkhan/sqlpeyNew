“Python: How to Flatten Nested Dictionaries?”

When working with complex data structures, particularly those originating from JSON or configuration files, you often encounter nested dictionaries. These can make direct data access cumbersome. The process of transforming a nested dictionary into a flat one, where keys represent the path to the original values, is known as “flattening.” This allows for more straightforward manipulation and querying of your data.

Several Pythonic approaches exist to achieve this, each with its own nuances and potential advantages. Let’s explore some of the most effective methods.

Solution 1: Recursive Iteration with collections.abc.MutableMapping

This method employs a recursive function to traverse the dictionary. It builds new keys by concatenating parent keys with child keys, using a specified separator.

from collections.abc import MutableMapping

def flatten_dictionary(dictionary, parent_key='', separator='_'):
    """
    Recursively flattens a nested dictionary.

    Args:
        dictionary (dict): The dictionary to flatten.
        parent_key (str): The prefix for keys from the parent level.
        separator (str): The string used to separate nested keys.

    Returns:
        dict: A flattened dictionary.
    """
    items = []
    for key, value in dictionary.items():
        new_key = parent_key + separator + key if parent_key else key
        if isinstance(value, MutableMapping):
            items.extend(flatten_dictionary(value, new_key, separator=separator).items())
        else:
            items.append((new_key, value))
    return dict(items)

# Example Usage:
sample_dict = {'a': 1, 'c': {'a': 2, 'b': {'x': 5, 'y' : 10}}, 'd': [1, 2, 3]}
flattened_sample = flatten_dictionary(sample_dict)
print(flattened_sample)
# Expected Output: {'a': 1, 'c_a': 2, 'c_b_x': 5, 'c_b_y': 10, 'd': [1, 2, 3]}

Solution 3: A Robust Recursive Approach with Customization

This solution offers flexibility by allowing customization of the key joining and value transformation using join and lift functions. It also highlights potential performance considerations.

from collections import Mapping
from itertools import chain
from operator import add

_FLAG_FIRST = object()

def flatten_dict_custom(d, join=add, lift=lambda x:(x,)):
    """
    Flattens a dictionary with customizable key joining and value lifting.

    Args:
        d (dict): The dictionary to flatten.
        join (callable): Function to combine keys.
        lift (callable): Function to transform keys before joining.

    Returns:
        list: A list of (key, value) tuples.
    """
    results = []
    def visit(subdict, results, partialKey):
        for k, v in subdict.items():
            newKey = lift(k) if partialKey == _FLAG_FIRST else join(partialKey, lift(k))
            if isinstance(v, Mapping):
                visit(v, results, newKey)
            else:
                results.append((newKey, v))
    visit(d, results, _FLAG_FIRST)
    return results

# Example Usage with string concatenation for keys:
test_data = {
    'a': 1,
    'b': 2,
    'c': {
        'aa': 11,
        'bb': 22,
        'cc': {
            'aaa': 111
        }
    }
}

# Flatten with string keys
flattened_string_keys = dict(flatten_dict_custom(test_data, join=lambda a,b: a + '_' + b, lift=lambda x: x))
print(flattened_string_keys)
# Expected Output: {'a': 1, 'b': 2, 'c_aa': 11, 'c_bb': 22, 'c_cc_aaa': 111}

Solution 5: Handling Lists within Nested Structures

This approach extends the flattening process to handle lists within nested dictionaries, creating indexed keys for list elements.

import collections.abc

def flatten_with_lists(dictionary, parent_key=False, separator='.'):
    """
    Flattens a nested dictionary, including lists.

    Args:
        dictionary (dict): The dictionary to flatten.
        parent_key (str): The prefix for keys from the parent level.
        separator (str): The string used to separate nested keys.

    Returns:
        dict: A flattened dictionary.
    """
    items = []
    for key, value in dictionary.items():
        new_key = str(parent_key) + separator + key if parent_key else key
        if isinstance(value, collections.abc.MutableMapping):
            items.extend(flatten_with_lists(value, new_key, separator).items())
        elif isinstance(value, list):
            for k, v in enumerate(value):
                # Recursively flatten list items, treating index as a key
                items.extend(flatten_with_lists({str(k): v}, new_key).items())
        else:
            items.append((new_key, value))
    return dict(items)

# Example Usage:
complex_dict = {'a': 1, 'c': {'a': 2, 'b': {'x': 5, 'y': 10}}, 'd': [1, 2, 3]}
flattened_complex = flatten_with_lists(complex_dict)
print(flattened_complex)
# Expected Output: {'a': 1, 'c.a': 2, 'c.b.x': 5, 'c.b.y': 10, 'd.0': 1, 'd.1': 2, 'd.2': 3}

Solution 6: A Compact, Recursive Dictionary Comprehension

This solution offers a concise, functional approach using a recursive dictionary comprehension.

def flatten_dict_comprehension(dd, separator='_', prefix=''):
    """
    Flattens a nested dictionary using a recursive dictionary comprehension.

    Args:
        dd (dict): The dictionary to flatten.
        separator (str): The string to use for separating keys.
        prefix (str): The prefix for the current level.

    Returns:
        dict: A flattened dictionary.
    """
    return {
        (prefix + separator + k if prefix else k): v
        for kk, vv in dd.items()
        for k, v in flatten_dict_comprehension(vv, separator, kk).items()
    } if isinstance(dd, dict) else {prefix: dd}

# Example Usage:

print(flattened_comprehension)
# Expected Output: {'abc': 123, 'gfd': 902, 'hgf.gh': 432, 'hgf.yu': 433, 'xzxzxz.432.0b0b0b': 231, 'xzxzxz.43234': 1321}

Solution 7: Recursive Dictionary Parsing

This method uses a recursive function to parse the dictionary and build the flattened structure.

def parse_dictionary(init, lkey=''):
    """
    Parses a nested dictionary recursively.

    Args:
        init (dict): The dictionary to parse.
        lkey (str): The accumulated key prefix.

    Returns:
        dict: A flattened dictionary.
    """
    ret = {}
    for rkey, val in init.items():
        key = lkey + rkey
        if isinstance(val, dict):
            ret.update(parse_dictionary(val, key + '_'))
        else:
            ret[key] = val
    return ret

# Example Usage:

Solution 8: Recursive Flattening without If Condition

This approach aims for performance by avoiding an explicit if condition for type checking, leveraging try-except for attribute access.

def flatten_recursive_no_if(d, parent_key=''):
    """
    Recursively flattens a dictionary, optimized with try-except.

    Args:
        d (dict): The dictionary to flatten.
        parent_key (str): The prefix for keys.

    Returns:
        dict: A flattened dictionary.
    """
    items = []
    for k, v in d.items():
        try:
            items.extend(flatten_recursive_no_if(v, '%s%s_' % (parent_key, k)).items())
        except AttributeError:
            items.append(('%s%s' % (parent_key, k), v))
    return dict(items)

Solution 9: Functional and Performant with functools.reduce

This solution uses functools.reduce for a functional approach, offering good performance.

from functools import reduce

def flatten_reduce(d, pref=''):
    """
    Flattens a dictionary using functools.reduce.

    Args:
        d (dict): The dictionary to flatten.
        pref (str): The prefix for keys.

    Returns:
        dict: A flattened dictionary.
    """
    def _reducer(items, key, val, pref):
        if isinstance(val, dict):
            return {**items, **flatten_reduce(val, pref + key)}
        else:
            return {**items, pref + key: val}

    return reduce(
        lambda new_d, kv: _reducer(new_d, *kv, pref),
        d.items(),
        {}
    )

# Example Usage:
my_object = {'a': 1, 'c': {'a': 2, 'b': {'x': 5, 'y': 10}}, 'd': [1, 2, 3]}
flattened_object = flatten_reduce(my_object)
print(flattened_object)
# Expected Output: {'d': [1, 2, 3], 'cby': 10, 'cbx': 5, 'ca': 2, 'a': 1}

Solution 11: Generator-Based Flattening

This solution utilizes generators for memory-efficient flattening, particularly useful for large datasets.

def flatten_iterator(pyobj, keystring=''):
   """
   Generator function to flatten nested Python objects.
   """
   if type(pyobj) is dict:
     keystring = keystring + "_" if keystring else keystring
     for k in pyobj:
         yield from flatten_iterator(pyobj[k], keystring + k)
   elif type(pyobj) is list:
     for lelm in pyobj:
         yield from flatten_iterator(lelm, keystring)
   else:
      yield keystring, pyobj

# Example Usage:
my_obj_gen = {'a': 1, 'c': {'a': 2, 'b': {'x': 5, 'y': 10}}, 'd': [1, 2, 3]}
flattened_gen = {k:v for k,v in flatten_iterator(my_obj_gen)}
print(flattened_gen)
# Expected Output: {'c_b_y': 10, 'd': [1, 2, 3], 'c_a': 2, 'a': 1, 'c_b_x': 5}

Solution 12: Simple and Readable Recursive Flattening

This approach prioritizes readability with a clear recursive structure.

def flatten_dict_readable(dictionary, accumulator=None, parent_key=None, separator="."):
    """
    Flattens a nested dictionary using a readable recursive approach.

    Args:
        dictionary (dict): The dictionary to flatten.
        accumulator (dict, optional): The dictionary to store flattened items. Defaults to None.
        parent_key (str, optional): The key from the parent level. Defaults to None.
        separator (str, optional): The key separator. Defaults to ".".

    Returns:
        dict: A flattened dictionary.
    """
    if accumulator is None:
        accumulator = {}

    for k, v in dictionary.items():
        k = f"{parent_key}{separator}{k}" if parent_key else k
        if isinstance(v, dict):
            flatten_dict_readable(dictionary=v, accumulator=accumulator, parent_key=k)
            continue

        accumulator[k] = v

    return accumulator

# Example Usage:
nested_dict_readable = {'a': 1, 'b': {'c': 2, 'd': {'e': 3}}}
flat_readable = flatten_dict_readable(nested_dict_readable)
print(flat_readable)
# Expected Output: {'a': 1, 'b.c': 2, 'b.d.e': 3}

flat_readable_underscore = flatten_dict_readable(nested_dict_readable, separator="_")
print(flat_readable_underscore)
# Expected Output: {'a': 1, 'b_c': 2, 'b_d_e': 3}

Solution 13: Iterative Flattening with a Stack

This method avoids recursion by using a stack to manage the nested dictionary traversal.

def flatten_nested_dict_stack(nested):
    """
    Flattens a nested dictionary iteratively using a stack.

    Args:
        nested (dict): The nested dictionary to flatten.

    Returns:
        dict: A flattened dictionary.
    """
    stack = list(nested.items())
    ans = {}
    while stack:
        key, val = stack.pop()
        if isinstance(val, dict):
            for sub_key, sub_val in val.items():
                stack.append((f"{key}_{sub_key}", sub_val))
        else:
            ans[key] = val
    return ans

Solution 14: Simple Recursive Flattening (No Parent Keys)

This version focuses on flattening without retaining parent keys, effectively merging all nested key-value pairs.

def flatten_dict_no_parents(init_dict):
    """
    Flattens a nested dictionary without keeping parent keys.

    Args:
        init_dict (dict): The dictionary to flatten.

    Returns:
        dict: A flattened dictionary.
    """
    res_dict = {}
    if type(init_dict) is not dict:
        return res_dict

    for k, v in init_dict.items(): # .iteritems() for Python 2
        if type(v) == dict:
            res_dict.update(flatten_dict_no_parents(v))
        else:
            res_dict[k] = v
    return res_dict

# Example Usage:
sample_flat_no_parents = {'a': 3, 'b': {'c': 4, 'd': 5}, 'e': {'f': {'g': 1, 'h': 2}}, 'i': 9}
flattened_no_parents = flatten_dict_no_parents(sample_flat_no_parents)
print(flattened_no_parents)
# Expected Output: {'a': 3, 'c': 4, 'd': 5, 'g': 1, 'h': 2, 'i': 9}

Solution 15: UserDict Subclass for Automatic Flattening

This approach creates a custom dictionary subclass that automatically flattens keys during item assignment.

from collections import UserDict

class FlatDict(UserDict):
    def __init__(self, *args, separator='.', **kwargs):
        self.separator = separator
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        if isinstance(value, dict):
            for k1, v1 in FlatDict(value, separator=self.separator).items():
                super().__setitem__(f"{key}{self.separator}{k1}", v1)
        else:
            super().__setitem__(key, value)

Solution 18: Recursive Closure for Flattening

This solution employs a recursive closure to manage the flattening process.

def flatten_dict_closure(d, separator='_'):
    """
    Flattens a dictionary using a recursive closure.

    Args:
        d (dict): The dictionary to flatten.
        separator (str): The key separator.

    Returns:
        dict: A flattened dictionary.
    """
    final = {}
    def _flatten_dict(obj, parent_keys=[]):
        for k, v in obj.items(): # .iteritems() for Python 2
            if isinstance(v, dict):
                _flatten_dict(v, parent_keys + [k])
            else:
                key = separator.join(parent_keys + [k])
                final[key] = v
    _flatten_dict(d)
    return final

# Example Usage:
nested_for_closure = {'a': 1, 'c': {'a': 2, 'b': {'x': 5, 'y': 10}}, 'd': [1, 2, 3]}
flattened_closure = flatten_dict_closure(nested_for_closure)
print(flattened_closure)
# Expected Output: {'a': 1, 'c_a': 2, 'c_b_x': 5, 'd': [1, 2, 3], 'c_b_y': 10}

Solution 19: Unflattening Function

Included here is a corresponding unflatten function that reverses the flattening process, useful for restoring the original structure.

def unflatten(d):
    """
    Unflattens a dictionary that was previously flattened.

    Args:
        d (dict): The flattened dictionary.

    Returns:
        dict: The original nested dictionary.
    """
    ud = {}
    for k, v in d.items():
        context = ud
        for sub_key in k.split('_')[:-1]:
            if sub_key not in context:
                context[sub_key] = {}
            context = context[sub_key]
        context[k.split('_')[-1]] = v
    return ud

Solution 20: Handling Nested Lists within Dictionaries

This solution specifically addresses scenarios where nested lists contain dictionaries, adapting the flattening process.

def flatten_nested_lists_dict(d):
    """
    Flattens a dictionary that may contain nested lists of dictionaries.

    Args:
        d (dict): The dictionary to flatten.

    Returns:
        dict: A flattened dictionary.
    """
    items = []
    for k, v in d.items():
        try:
            if (type(v) == type([])):
                for l in v: items.extend(flatten_nested_lists_dict(l).items())
            else:
                items.extend(flatten_nested_lists_dict(v).items())
        except AttributeError:
            items.append((k, v))
    return dict(items)

Solution 21: Recursive Flattening with Key Concatenation

This straightforward recursive method concatenates keys to form the flattened structure.

def flatten_recursive_concat(unflattened_dict, separator='_'):
    """
    Recursively flattens a dictionary by concatenating keys.

    Args:
        unflattened_dict (dict): The dictionary to flatten.
        separator (str): The key separator.

    Returns:
        dict: A flattened dictionary.
    """
    flattened_dict = {}
    for k, v in unflattened_dict.items():
        if isinstance(v, dict):
            sub_flattened_dict = flatten_recursive_concat(v, separator)
            for k2, v2 in sub_flattened_dict.items():
                flattened_dict[k + separator + k2] = v2
        else:
            flattened_dict[k] = v
    return flattened_dict

Solution 22: Generator-Based Helper for Flattening

This solution uses a helper generator function for a clean, memory-efficient flattening process.

def flat_dic_helper(prepand, d):
    if len(prepand) > 0:
        prepand = prepand + "_"
    for k in d:
        i = d[k]
        if isinstance(i, dict):
            r = flat_dic_helper(prepand + k, i)
            for j in r:
                yield j
        else:
            yield (prepand + k, i)

def flat_dic(d):
    return dict(flat_dic_helper("", d))

def flatten_json_inplace(json):

    Args:

Solution 25: Generator for Flattened Items

This solution uses a generator to yield flattened items, allowing for flexible consumption.

def flat_items(d, key_separator='.'):
    """
    Generator yielding flattened dictionary items.

    Args:
        d (dict): The dictionary to flatten.
        key_separator (str): The separator for joined keys.

    Yields:
        tuple: Key-value pairs of the flattened dictionary.

    for k, v in d.items():

            for k1, v1 in flat_items(v, key_separator=key_separator):

        else:
            yield k, v

Solution 26: Recursive Flattening with Indexing for Lists

This comprehensive solution handles nested dictionaries and lists, creating indexed keys for list elements.

def flatten_nested_dict_comprehensive(_dict, _str=''):
    """
    Recursively flattens nested dictionaries and lists.

    Args:
        _dict (dict): The dictionary to flatten.
        _str (str): The current key prefix.

    Returns:
        dict: A flattened dictionary.
    """
    ret_dict = {}
    for k, v in _dict.items():
        if isinstance(v, dict):
            ret_dict.update(flatten_nested_dict_comprehensive(v, _str='_'.join([_str, k]).strip('_')))
        elif isinstance(v, list):
            for index, item in enumerate(v):
                if isinstance(item, dict):
                    ret_dict.update(flatten_nested_dict_comprehensive(item, _str='_'.join([_str, k, str(index)]).strip('_')))
                else:
                    ret_dict['_'.join([_str, k, str(index)]).strip('_')] = item
        else:
            ret_dict['_'.join([_str, k]).strip('_')] = v
    return ret_dict

Solution 27: popitem() Based Recursive Flattening

This method utilizes dict.popitem() in a recursive fashion to extract and flatten key-value pairs.

def flatten_popitem(d):
    """
    Flattens a dictionary using dict.popitem() recursively.

    Args:
        d (dict): The dictionary to flatten.

    Returns:
        dict: A flattened dictionary.
    """
    if d == {}:
        return d
    else:
        k, v = d.popitem()
        if (dict != type(v)):
            return {k: v, **flatten_popitem(d)}
        else:
            flat_kv = flatten_popitem(v)
            for k1 in list(flat_kv.keys()):
                flat_kv[k + '_' + k1] = flat_kv[k1]
                del flat_kv[k1]
            return {**flat_kv, **flatten_popitem(d)}

        dictionary (dict): The dictionary to flatten.
        exclude (list): A list of keys to exclude from flattening.
        delimiter (str): The key separator.

    Returns:
        dict: A flattened dictionary with exclusions.
    """
    flat_dict = dict()
    for key, value in dictionary.items():
        if isinstance(value, dict) and key not in exclude:
            flatten_value_dict = flatten_dict_with_exclude(value, exclude, delimiter)
            for k, v in flatten_value_dict.items():
                flat_dict[f"{key}{delimiter}{k}"] = v
        else:
            flat_dict[key] = value
    return flat_dict

Solution 29: Handling Complex Nested Structures (Lists and Tuples)

This solution attempts to handle more complex nested structures, including lists and tuples, though it notes potential limitations.

def flatten_complex_structures(input_node: dict, key_: str = '', output_dict: dict = {}):
    """
    Flattens complex nested structures including lists and dictionaries.

    Args:
        input_node (dict): The node to flatten.
        key_ (str): The current key prefix.
        output_dict (dict): The dictionary to store flattened items.

    Returns:
        dict: A flattened dictionary.
    """
    if isinstance(input_node, dict):
        for key, val in input_node.items():
            new_key = f"{key_}.{key}" if key_ else f"{key}"
            flatten_complex_structures(val, new_key, output_dict)
    elif isinstance(input_node, list):
        for idx, item in enumerate(input_node):
            flatten_complex_structures(item, f"{key_}.{idx}", output_dict)
    else:
        output_dict[key_] = input_node
    return output_dict

Solution 30: Recursive Flattening with max_level and Custom Reducer

This advanced solution allows control over the flattening depth (max_level) and offers flexibility in how keys are combined using a reducer.

from functools import reduce

def flatten_with_level(d, max_level=None, reducer='tuple'):
    """
    Flattens a dictionary up to a specified level with a custom key reducer.

    Args:
        d (dict): The dictionary to flatten.
        max_level (int, optional): The maximum depth to flatten. Defaults to None (flatten all).
        reducer (str): The method to combine keys ('tuple').

    Returns:
        dict: A flattened dictionary.
    """
    if reducer == 'tuple':
        reducer_seed = tuple()
        reducer_func = lambda x, y: (*x, y)
    else:
        raise ValueError(f'Unknown reducer: {reducer}')

    def impl(d, pref, level):
        return reduce(
            lambda new_d, kv:
                (max_level is None or level < max_level)
                and isinstance(kv[1], dict)
                and {**new_d, **impl(kv[1], reducer_func(pref, kv[0]), level + 1)}
                or {**new_d, reducer_func(pref, kv[0]): kv[1]},
                d.items(),
            {}
        )
    return impl(d, reducer_seed, 0)

FAQs on Python Dictionary Flattening

Q: How do I flatten a dictionary in Python

ANS: You can flatten a dictionary in Python using various methods, including recursive functions, the pandas library’s json_normalize, or specialized libraries like flatdict. The core idea is to traverse the nested structure and create new keys representing the path to each value.

Q: What is the most common separator for flattened dictionary keys

ANS: The underscore (_) and the dot (.) are the most common separators used to join keys when flattening nested dictionaries. The choice often depends on conventions or personal preference.

Q: Can Python flatten dictionaries that contain lists

ANS: Yes, many flattening methods can handle lists within dictionaries. They typically iterate through the list elements and create indexed keys (e.g., list_key.0, list_key.1) to represent the position of each item.

Q: Is there a performance difference between recursive and iterative flattening

ANS: Generally, iterative approaches using a stack can sometimes be more performant and avoid recursion depth limits for very deeply nested dictionaries, though well-optimized recursive solutions are often clear and efficient.

Q: How can I flatten a dictionary with specific keys excluded

ANS: Some flattening functions, like flatten_dict_with_exclude shown above, allow you to pass a list of keys that should not be flattened, preserving their original nested structure.
