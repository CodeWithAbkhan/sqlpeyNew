How to Sort a Dictionary by Key in Python

Sorting dictionaries by their keys is a common task in Python programming. With the evolution of Python, particularly from version 3.6 onwards, manipulating dictionaries has become both intuitive and efficient. In the following sections, we will explore various methods to sort dictionaries by keys, enhancing your Python skills through practical code examples and alternative methods.

Example Input

Consider the following dictionary:

example_dict = {2: 3, 1: 89, 4: 5, 3: 0}

Desired Output

The sorted output of the above dictionary should be:

{1: 89, 2: 3, 3: 0, 4: 5}

Method 1: Sorting Using sorted() Function

In Python 3.6 and later, you can easily sort a dictionary using the sorted() function:

sorted_dict = dict(sorted(example_dict.items()))
print(sorted_dict)

Output:

{1: 89, 2: 3, 3: 0, 4: 5}

Method 2: Iterating Over Sorted Keys

You can also iterate over the sorted keys directly to display the dictionary:

for key in sorted(example_dict):
    print(f"{key}: {example_dict[key]}")

Output:

1: 89
2: 3
3: 0
4: 5

Method 3: Using OrderedDict from the collections Module

If you need to maintain the order of insertion in older versions of Python or require an ordered dictionary, you can use OrderedDict:

from collections import OrderedDict

ordered_dict = OrderedDict(sorted(example_dict.items()))
print(ordered_dict)

Output:

OrderedDict([(1, 89), (2, 3), (3, 0), (4, 5)])

Method 4: The SortedDict from the sortedcontainers Module

For scenarios requiring fast and efficient ordered operations, SortedDict from the sortedcontainers module is ideal:

from sortedcontainers import SortedDict

sorted_dict = SortedDict(example_dict)
print(sorted_dict)

Output:

SortedDict({1: 89, 2: 3, 3: 0, 4: 5})

Practical Example with Nested Dictionaries

If your dictionary contains nested dictionaries, you can sort them recursively:

test_dict = {'a': 1, 'c': 3, 'b': {'b2': 2, 'b1': 1}}

def sort_nested_dict(d):
    return {k: sort_nested_dict(v) if isinstance(v, dict) else v for k, v in sorted(d.items())}

sorted_nested = sort_nested_dict(test_dict)
print(sorted_nested)

Output:

{'a': 1, 'b': {'b1': 1, 'b2': 2}, 'c': 3}

Alternative Ways

  • Dictionary Comprehensions: You can utilize dictionary comprehensions for a concise syntax.

    sorted_dict = {k: example_dict[k] for k in sorted(example_dict)}
print(sorted_dict)

  • JSON Sorting: For printing purposes, converting a dictionary to a JSON format is useful.

    import json
json_string = json.dumps(example_dict, sort_keys=True)
print(json_string)

FAQs on How to Sort a Dictionary by Key
