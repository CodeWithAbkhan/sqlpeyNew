Python: Sort One List by Another’s Values

When working with Python, you might encounter situations where you need to sort one list based on the corresponding values in another list. This is a common task, especially when dealing with paired data. Several methods exist to achieve this, each with its own nuances and suitability depending on your specific requirements.

Let’s consider two lists, X and Y, where Y contains the values by which we want to sort X:

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

The goal is to rearrange X such that its elements are ordered according to the values in Y.

Solution 1: Using zip and sorted with List Comprehension

A concise and widely used method involves zipping the two lists together, sorting the resulting pairs based on the values in Y, and then extracting the elements from X.

Method:

sorted_X = [x for _, x in sorted(zip(Y, X))]
print(sorted_X)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

Explanation:

  1. zip(Y, X) pairs elements from Y and X: [(0, 'a'), (1, 'b'), (1, 'c'), (0, 'd'), ...].
  2. sorted(...) sorts these pairs. By default, it sorts based on the first element of each tuple (the values from Y).
  3. The list comprehension [x for _, x in ...] iterates through the sorted pairs, taking only the second element (x) of each pair, effectively giving you X sorted according to Y.

For a more explicit control over the sorting behavior, you can use the key parameter with a lambda function:

sorted_X_explicit = [x for _, x in sorted(zip(Y, X), key=lambda pair: pair[0])]
print(sorted_X_explicit)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

This explicitly tells sorted to use the first element of each pair for sorting.

Solution 2: Direct Sorting of Zipped Pairs

This approach is similar to Solution 1 but demonstrates the intermediate steps more clearly.

Method:

yx_pairs = zip(Y, X)
# yx_pairs is an iterator yielding pairs like (0, 'a'), (1, 'b'), ...

# To see the pairs and sort them, convert to a list
yx_list = list(yx_pairs)
yx_list.sort() # Sorts in-place based on the first element of each tuple

sorted_X_from_list = [x for y, x in yx_list]
print(sorted_X_from_list)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

A more compact version combining these steps is:

sorted_X_compact = [x for y, x in sorted(zip(Y, X))]
print(sorted_X_compact)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

Solution 3: Using NumPy Arrays

If you are already working with numerical data or prefer using NumPy, this library offers an efficient way to handle this.

Method:

import numpy as np

people = ['Jim', 'Pam', 'Micheal', 'Dwight']
ages = [27, 25, 4, 9]

# Convert lists to NumPy arrays
people_np = np.array(people)
ages_np = np.array(ages)

# Get indices that would sort the ages array
sorted_indices = np.argsort(ages_np)

# Use these indices to sort the people array
sorted_people = people_np[sorted_indices]
print(sorted_people)
# Output: ['Micheal' 'Pam' 'Jim' 'Dwight']

This method is particularly useful when dealing with large datasets where NumPy’s performance benefits are significant. You can find more details on sorting with NumPy at NumPy Sorting .

Solution 4: Using list.sort() with a Dictionary as Key

This technique involves creating a dictionary mapping elements of X to their corresponding values in Y and then using the dictionary’s get method as the sorting key.

Method:

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

# Create a dictionary mapping elements of X to their values in Y
key_dict = dict(zip(X, Y))

# Sort the list X in-place using the dictionary values as keys
X.sort(key=key_dict.get)
print(X)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

Important Note: This method assumes that the elements in X are unique. If X contains duplicates, the sorting might behave unexpectedly. To handle duplicates correctly, you can incorporate indices:

X_with_duplicates = ["A", "A", "C", "C", "C", "F", "G", "H", "I"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1] # Same Y as before

# Create a mapping of values to indices for stable sorting
index_map = {value: [] for value in set(Y)}
for i, val in enumerate(Y):
    index_map[val].append(i)

# Create a sorted index list based on Y
sorted_indices_for_duplicates = []
for y_val in sorted(set(Y)):
    sorted_indices_for_duplicates.extend(index_map[y_val])

# Apply the sorted indices to X_with_duplicates
X_sorted_stable = [X_with_duplicates[i] for i in sorted_indices_for_duplicates]
print(X_sorted_stable)
# Output: ['A', 'A', 'C', 'C', 'C', 'F', 'G', 'H', 'I']

A more direct way for unique elements is a one-liner:

X_unique = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y_unique = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]
X_unique.sort(key=dict(zip(X_unique, Y_unique)).get)
print(X_unique)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

Solution 5: Using more_itertools.sort_together

The more_itertools library provides a handy function specifically for sorting multiple iterables in parallel.

Method:

First, install the library if you haven’t already: pip install more-itertools

from more_itertools import sort_together

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

# sort_together expects the sorting key to be the first iterable
sorted_lists = sort_together([Y, X])

# The result is a tuple of sorted lists. We want the second list (X).
sorted_X_more_itertools = sorted_lists[1]
print(sorted_X_more_itertools)
# Output: ('a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g')

Solution 6: Sorting by Index in the Reference List

If you have a reference list and want to sort another list based on the order of elements in the reference list, you can use list.index().

Method:

list_a = ['foo', 'bar', 'baz'] # The order we want list_b to follow
list_b = ['baz', 'bar', 'foo']

# Sort list_b using the index of its elements in list_a as the key
sorted_list_b = sorted(list_b, key=lambda x: list_a.index(x))
print(sorted_list_b)
# Output: ['foo', 'bar', 'baz']

This is effective when the elements in list_b are guaranteed to exist in list_a.

Solution 7: Unpacking Sorted Zipped Tuples

This method, often referred to as the “decorate-sort-undecorate” pattern, can be very efficient.

Method (Python 3):

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

# Zip, sort based on Y, then unpack the sorted pairs.
# The `zip(*...)` part effectively unzips the sorted pairs.
# We then select the second element of the unpacked tuple.
sorted_X_unpack = list(zip(*sorted(zip(Y, X))))[1]
print(sorted_X_unpack)
# Output: ('a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g')

For stable sorting (maintaining the original order of equal elements), you can include original indices:

import operator

# Sort by Y (index 1 of the zipped pair) and extract X (index 0)
sorted_X_stable_unpack = list(zip(*sorted(zip(X,Y), key=operator.itemgetter(1))))[0]
print(sorted_X_stable_unpack)
# Output: ('a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g')

The operator module can provide a performance boost for certain key functions like itemgetter.

Solution 8: Using Sorted Indices

This approach generates a list of indices that would sort the reference list, and then uses those indices to reorder the target list.

Method:

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

# Get indices that would sort Y
sorted_y_indices = sorted(range(len(Y)), key=lambda k: Y[k])

# Use these indices to reorder X
sorted_X_by_index = [X[i] for i in sorted_y_indices]
print(sorted_X_by_index)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

This is a robust method, especially for handling duplicates correctly. NumPy’s argsort function, as shown in Solution 3, is a highly optimized version of this concept.

Solution 9: Using Pandas Series

Pandas provides a very clean way to sort one list by another if you’re comfortable with the library.

Method:

import pandas as pd

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

# Create a Pandas Series with Y as the index and X as the data
series_X = pd.Series(data=X, index=Y)

# Sort the Series by its index and convert back to a list
sorted_X_pandas = series_X.sort_index().tolist()
print(sorted_X_pandas)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

Pandas offers powerful data manipulation capabilities, making tasks like this quite intuitive. For more on Pandas Series, see What is Pandas .

Solution 10: Direct Sorting of Zipped Lists

This concise approach sorts the zipped pairs and then directly unpacks them into sorted lists.

Method:

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,    0,   1,   2,   2,   0,   1]

# Sort the zipped pairs and unpack into X and Y
X_sorted_direct, Y_sorted_direct = zip(*sorted(zip(Y, X)))

print(list(X_sorted_direct)) # Convert tuple to list for display
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']
print(list(Y_sorted_direct))
# Output: [0, 0, 0, 1, 1, 1, 1, 2, 2]

This method is elegant and efficient for sorting both lists simultaneously based on the order of one of them.

Solution 11: A General Parallel Sorting Function

For scenarios involving sorting multiple lists based on one of them, a generalized function can be beneficial.

Method:

def parallel_sort(*lists):
    """
    Sorts multiple lists in parallel, based on the order of the first list.

    Args:
        *lists: A variable number of lists to be sorted. The first list
                determines the sorting order.

    Returns:
        A tuple containing the sorted lists.
    """
    if not lists:
        return tuple()

    # Create empty lists to hold the sorted items
    sorted_lists = tuple([] for _ in range(len(lists)))

    # Zip, sort, and iterate to distribute items into sorted lists
    for items_in_order in sorted(zip(*lists)):
        for i, item in enumerate(items_in_order):
            sorted_lists[i].append(item)

    return sorted_lists

# Example usage:
list1 = [10, 5, 15, 2, 8]
list2 = ['a', 'b', 'c', 'd', 'e']
list3 = [True, False, True, False, True]

sorted_l1, sorted_l2, sorted_l3 = parallel_sort(list1, list2, list3)

print("Sorted list1:", sorted_l1)
print("Sorted list2:", sorted_l2)
print("Sorted list3:", sorted_l3)
# Expected Output:
# Sorted list1: [2, 5, 8, 10, 15]
# Sorted list2: ['d', 'b', 'e', 'a', 'c']
# Sorted list3: [False, False, True, True, True]

This function provides a structured way to handle parallel sorting requirements for any number of lists.

Solution 12: Filtering and Reordering Based on a Reference

This method focuses on reordering a list (list2) to match the sequence of a reference list (list1), keeping only common elements.

Method:

list1 = ['B', 'A', 'C']  # Reference order
list2 = ['C', 'B']       # Items to be sorted according to list1

# Filter list1 to include only items present in list2, maintaining list1's order
result = [item for item in list1 if item in list2]
print(result)
# Output: ['B', 'C']

This approach is useful when you need to align list2 with a specific ordering defined by list1 and exclude any items from list2 that aren’t in list1.

Solution 13: Sorting with list.index() for Larger Reference Lists

When one list contains values that dictate the order for another, and the reference list might be larger, list.index() can be employed.

Method:

list_a = [5, 4, 3, 2, 1]         # Values to sort by
list_b = [1, 1.5, 1.75, 2, 3, 3.5, 3.75, 4, 5] # List to be ordered

# Sort list_a based on the position of its elements in list_b
ordered_list_a = sorted(list_a, key=lambda x: list_b.index(x))
print(ordered_list_a)
# Output: [1, 2, 3, 4, 5]

This works reliably if all elements of list_a are present in list_b.

Solution 14: Sorting Arrays with Custom Function

For array manipulation, a custom function can streamline the process of sorting two arrays based on the order of one.

Method:

from numpy import array, zip as np_zip, transpose as np_transpose

def sort_arrays_by_first(x, y, reverse=False):
    """
    Sorts both arrays x and y based on the order of elements in array x.

    Args:
        x: The array to sort by.
        y: The array to be sorted according to x.
        reverse: If True, sorts in descending order.

    Returns:
        A tuple containing the sorted arrays (sorted_x, sorted_y).
    """
    # Zip arrays, sort based on x, transpose, and return the first and second columns
    xy_sorted = array(sorted(np_zip(x, y), reverse=reverse)).T
    return xy_sorted[0], xy_sorted[1]

# Example Usage:
x_arr = array([10, 5, 15, 2, 8])
y_arr = array(['a', 'b', 'c', 'd', 'e'])

sorted_x, sorted_y = sort_arrays_by_first(x_arr, y_arr)
print("Sorted X:", sorted_x)
print("Sorted Y:", sorted_y)
# Expected Output:
# Sorted X: [ 2  5  8 10 15]
# Sorted Y: ['d' 'b' 'e' 'a' 'c']

This function leverages NumPy’s efficient array operations.

Solution 15: Using Pandas for Merging Unequal Lists

When lists might have different lengths or contain different items, Pandas’ merge function can help align them based on a reference list.

Method:

import pandas as pd

list1 = ['B', 'A', 'C']  # Reference order
list2 = ['C', 'A']       # Items to be sorted according to list1

# Create DataFrames and merge to keep only common elements in list1's order
df1 = pd.DataFrame(list1, columns=['Col'])
df2 = pd.DataFrame(list2, columns=['Col'])
merged_df = pd.merge(df1, df2, on='Col')

result = merged_df['Col'].tolist()
print(result)
# Output: ['A', 'C']

This approach ensures that only elements present in both lists are considered, ordered according to list1.

Solution 16: Finding Locations for Precise Sorting

This method involves finding the specific locations of elements from a sorted set within the original list to reconstruct the desired order.

Method:

list1 = ['a','b','c','d','e','f','g','h','i']
list2 = [0,1,1,0,1,2,2,0,1] # Sorting values

output_list = []
location_tracker = []

# Find unique sorting values
unique_sort_values = set(list2)

# Convert list2 to a string to easily find occurrences
list2_string = ''.join(str(s) for s in list2)

# Find all occurrences of each unique sort value
for value in sorted(list(unique_sort_values)): # Ensure consistent order of unique values
    current_pos = list2_string.find(str(value))
    while current_pos >= 0:
        location_tracker.append(current_pos)
        current_pos = list2_string.find(str(value), current_pos + 1)

# Build the final sorted list using the tracked locations
for index in location_tracker:
    output_list.append(list1[index])

print(output_list)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

This method is detailed and handles multiple occurrences effectively.

Solution 17: Sorting Dictionaries for Ordered Output

If your lists represent key-value pairs or mappings, sorting a dictionary directly can yield the desired ordered output.

Method:

X = ["a", "b", "c", "d", "e", "f", "g", "h", "i"]
Y = [ 0,   1,   1,   0,   1,   2,   2,   0,   1]

# Create a dictionary from the lists
data_dict = dict(zip(X, Y))

# Sort the dictionary keys based on their values
sorted_keys = sorted(data_dict, key=data_dict.get)

print(sorted_keys)
# Output: ['a', 'd', 'h', 'b', 'c', 'e', 'i', 'f', 'g']

This is a very Pythonic and efficient way to get an ordered list of keys based on their associated values.

FAQs on Python List Sorting

Q: How do I sort a list by the values in another list in Python

ANS: You can use zip() to pair elements from both lists, then sorted() to sort these pairs based on the values of the second list, and finally a list comprehension to extract the sorted elements of the first list. A common pattern is [x for _, x in sorted(zip(list_to_sort_by, list_to_sort))].

Q: Can I sort multiple lists simultaneously based on one list

ANS: Yes, libraries like more_itertools offer sort_together, or you can create a custom function that zips, sorts, and then distributes elements back into multiple sorted lists.

Q: What if the lists have different lengths or duplicate values

ANS: For lists with different lengths or duplicates, using sorted indices (sorted(range(len(Y)), key=lambda k: Y[k])) or Pandas DataFrames with merging is more robust. Using list.index() can be problematic with duplicates if not handled carefully.

Q: Is there a way to sort using NumPy

ANS: Absolutely. NumPy’s argsort() function is excellent for this. You get the indices that would sort one array and then use those indices to reorder another array. See NumPy sorting for details.

Q: How to sort list B based on the order of elements in list A

ANS: You can use sorted(list_b, key=lambda x: list_a.index(x)) provided that all elements in list_b are present in list_a. This sorts list_b according to the first occurrence of its elements in list_a.
