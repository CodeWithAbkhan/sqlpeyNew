Solved: How to Fix ‘asyncio.run cannot be called from a running event loop’ Error in Jupyter Notebook

When working with Jupyter Notebook, you might encounter the RuntimeError stating that asyncio.run() cannot be called from a running event loop. This can be frustrating, especially when you aim to utilize the power of asyncio for asynchronous programming. Let’s delve into this issue comprehensively and offer effective solutions to take care of this common predicament.

Problem Analysis

You might be trying to execute the following code:

import aiofiles
import aiohttp
from aiohttp import ClientSession

async def fetch_info(url, session):
    response = await session.request(method="GET", url=url)
    response.raise_for_status()
    html = await response.text(encoding='utf-8')
    with open('output.html', 'w', encoding='utf-8-sig') as file:
        file.write(html)
    return html

async def main(urls):
    async with ClientSession() as session:
        tasks = [fetch_info(url, session) for url in urls]
        return await asyncio.gather(*tasks)

if __name__ == "__main__":
    url_list = ['http://example.com/page1', 'http://example.com/page2']
    result = asyncio.run(main(url_list))

Upon execution, this code results in a RuntimeError. This occurs because Jupyter Notebook operates on a running event loop, and asyncio.run() tries to start a new loop.

Effective Solutions to Resolve the Issue

Here are some practical solutions that you can use to overcome the RuntimeError:

Solution 1: Conditional Execution Based on Event Loop Status

Instead of directly calling asyncio.run(), you can check if an event loop is already running:

import asyncio

async def main(urls):
    # Your asynchronous logic here

try:
    loop = asyncio.get_running_loop()
except RuntimeError:
    loop = None

if loop and loop.is_running():
    print('Adding coroutine to the existing event loop.')
    task = loop.create_task(main(url_list))
    task.add_done_callback(lambda t: print(f'Task completed with result={t.result()}'))
else:
    print('Starting a new event loop.')
    asyncio.run(main(url_list))

Solution 2: Utilize Nest Asyncio

You can use the nest_asyncio library, which allows nested event loops in Jupyter:

import nest_asyncio
nest_asyncio.apply()

After applying this, you can run your asynchronous functions using asyncio.run() without issues.

Solution 3: Implementing a Threading Approach

By creating a separate thread to run your coroutine, you can avoid the event loop conflict:

import threading

class RunThread(threading.Thread):
    def __init__(self, function, args, kwargs):
        super().__init__()
        self.function = function
        self.args = args
        self.kwargs = kwargs
        self.result = None

    def run(self):
        self.result = asyncio.run(self.function(*self.args, **self.kwargs))

def run_async(func, *args, **kwargs):
    thread = RunThread(func, args, kwargs)
    thread.start()
    thread.join()
    return thread.result

## Example usage
async def example_coroutine(name):
    await asyncio.sleep(5)
    return f"Hello, {name}!"

result = run_async(example_coroutine, "user")
print(result)

Solution 4: Use ThreadPoolExecutor for Flexibility

You can also use ThreadPoolExecutor for running your async functions without blocking:

from concurrent.futures import ThreadPoolExecutor

def run_in_thread(func):
    try:
        asyncio.get_running_loop()
        with ThreadPoolExecutor() as pool:
            return pool.submit(lambda: asyncio.run(func())).result()
    except RuntimeError:
        return asyncio.run(func())

## Example usage
result = run_in_thread(main)

Solution 5: Leveraging the Unsync Library

Another approach is to use the unsync library, which allows writing code that works seamlessly with Jupyter:

from unsync import unsync

@unsync
async def demo_async_function():
    await asyncio.sleep(0.1)
    return "done!"

print(demo_async_function().result())

Alternative Solutions

If you prefer not to use additional libraries like nest_asyncio or unsync, you can organize your code to execute coroutines directly by utilizing the threading methods discussed above or implementing context-aware execution flows.

FAQs on Solved: How to Fix ‘asyncio.run cannot be called from a running event loop’ Error in Jupyter Notebook

Q: What does the 'asyncio.run cannot be called from a running event loop' mean?

A: This error indicates that the code is attempting to start a new event loop using asyncio.run() while another loop is already active, which is the case in environments such as Jupyter Notebook.

Q: How can I run asynchronous code in Jupyter Notebook?

A: You can use workarounds like checking if an event loop is running, employing nest_asyncio, using threading, or leveraging the unsync library as shown above.

Q: What is the purpose of `nest_asyncio`?

A: The nest_asyncio library allows for the nesting of asynchronous loops, making it compatible with environments like Jupyter Notebook that maintain a running event loop.

Q: Can I use asyncio with other libraries?

A: Yes, many libraries support asynchronous IO operations, including aiohttp for HTTP requests and asyncio for concurrent programming.
