I’m currently encountering an issue while attempting to execute a simple Python script that utilizes Pytesseract for Optical Character Recognition (OCR). Here’s the code snippet I’m working with:

from PIL import Image
import pytesseract

image = Image.open("sample1.jpg")
text_output = pytesseract.image_to_string(image, lang='eng')
print(text_output)

After I installed Tesseract on my Windows machine using the relevant installer, I remained perplexed as it seemed to be functioning correctly. My efforts to remediate the situation included restarting my Spyder IDE, but the error persists.

Herein, I’ll guide you through various solutions to rectify the “TesseractNotFound Error: Tesseract is not installed or it’s not in your path”.

Top 10 Methods to Resolve Pytesseract TesseractNotFound Error

1. Install Tesseract Executable

Linux Installation

If you are utilizing a Linux system, execute the following commands in your terminal:

sudo apt-get update
sudo apt-get install libleptonica-dev tesseract-ocr tesseract-ocr-dev libtesseract-dev python3-pil tesseract-ocr-eng tesseract-ocr-script-latn

Mac Installation

To install Tesseract on a Mac, you can utilize Homebrew:

brew install tesseract

Windows Installation

Download the Tesseract binary from the following link: Tesseract Windows Installation . Following the download, add the Tesseract executable location to your Python script as shown:

pytesseract.pytesseract.tesseract_cmd = 'C:/Program Files (x86)/Tesseract-OCR/tesseract.exe'

2. Install Python Tesseract Package

Ensure you have the Python package installed using pip:

pip install pytesseract
pip install tesseract-ocr

3. Update System Environment Variables on Windows

Follow these steps to configure your Windows environment variables:

  1. Verify that Tesseract OCR is installed on your computer.
  2. Add the Tesseract installation directory to your system’s environment variables.
  3. Reinstall the Pytesseract package as mentioned above.

4. Set the Tesseract Command Path

Always include the command to specify the path in your Python script:

pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'  # Adjust path accordingly

5. Validate Your Installation

Verify if Tesseract is accessible from the command line. This can be done by executing:

tesseract --version

6. Install Essential Dependency Libraries

If you’re using Tesseract with image processing libraries, install additional dependencies such as OpenCV:

pip install opencv-python
pip install numpy

7. Sample Code to Execute OCR with Preprocessing

Here is an example of how to read an image file and perform OCR, ensuring to include preprocessing for improved accuracy:

import cv2
import numpy as np
import pytesseract
from PIL import Image

## Path where Tesseract is installed
pytesseract.pytesseract.tesseract_cmd = 'C:/Program Files (x86)/Tesseract-OCR/tesseract.exe'

def extract_text(image_path):
    img = cv2.imread(image_path)
    img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    
    # Denoising
    kernel = np.ones((1, 1), np.uint8)
    img = cv2.dilate(img, kernel, iterations=1)
    img = cv2.erode(img, kernel, iterations=1)

    result = pytesseract.image_to_string(img)
    return result

print(extract_text('path_to_your_image.jpg'))

8. Alternative Installation Using Anaconda

If you’re using Anaconda, you can install Tesseract as follows:

conda install -c conda-forge tesseract

9. Check for Language Files

Ensure that the necessary language files for Tesseract are installed. You can list installed languages with:

tesseract --list-langs

10. Resolve Memory Issues on Ubuntu

If you encounter memory-related errors on Ubuntu, consider checking your swap space and allocate more if necessary.

FAQs on How to Fix Pytesseract TesseractNotFound Error

Q: Why do I keep getting 'TesseractNotFound Error'?

A: This error often occurs when Tesseract is not installed correctly, or the path to the Tesseract executable isn’t set in your Python script. Verify both aspects for resolution.

Q: Can I use Pytesseract on Linux?

A: Absolutely! You can install Tesseract on Linux using the package manager. Just follow the provided instructions in this guide.

Q: What if Tesseract is installed, but I still get the error?

A: Ensure that the path to Tesseract executable is correctly set in your script as well as in your system’s environment variables.
