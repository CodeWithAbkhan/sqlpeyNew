Solved: How to Measure the Execution Time of a Python Script

I have a requirement to find out how much time a Python script takes to complete its execution. What are the effective methods I can use to measure the execution time? It would be great to have practical examples to illustrate these methods. Below, you will find several solutions that cater to different scenarios and preferences.

Method 1: Using the Command Line

If you’re running your script on a Linux or UNIX system, you can easily measure your script’s execution time directly from the command line with the time command:

time python script.py

This command will provide you with the real-time, user CPU time, and system CPU time that your script took to execute.

Method 2: Using the time Library

For those who prefer writing Python code to monitor execution time, you can use the built-in time library. Here’s how you can implement it:

import time

def fun():
    # Your code here
    time.sleep(2)  # Simulating a task taking time

start = time.time()

fun()

print('It took', round(time.time() - start, 2), 'seconds.')

This script will keep track of the time taken by the fun function to complete execution.

Method 3: Using timeit for Precision

The timeit module is an excellent choice if you need precise benchmarking, especially for small code snippets:

from timeit import Timer

def test():
    L = []
    for i in range(100):
        L.append(i)

t = Timer("test()", "from __main__ import test")
execution_time = t.timeit(number=1000)
print(f'Execution time for 1000 runs: {execution_time} seconds.')

The timeit function lets you execute the code multiple times to get a more reliable result.

Method 4: Using time.perf_counter()

A more modern and recommended method is to use time.perf_counter(), which provides a higher resolution timer:

import time

t0 = time.perf_counter()
fun()  # Call your function
t1 = time.perf_counter()

print(f"Function executed in {t1 - t0} seconds.")
print(f"In minutes: {(t1 - t0) / 60}")

This method is particularly useful for short and quick tasks.

Method 5: Jupyter Notebook’s Magic Commands

If you are using a Jupyter Notebook, you can quickly measure the execution time using the built-in magic commands:

%timeit fun()

This will run the function multiple times and provide you with an average execution time, which is very helpful for performance tuning.

Method 6: Creating a Decorator

For a more reusable approach, consider creating a decorator to measure execution time:

import time
from functools import wraps

def time_function(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed_time = time.perf_counter() - start_time
        print(f"{func.__name__} executed in {elapsed_time:.4f} seconds.")
        return result
    return wrapper

@time_function
def example_function():
    time.sleep(1)  # Simulating a task
    return "Function completed."

example_function()

This decorator can easily be applied to any function you want to time, making your code cleaner and more manageable.

Method 7: Using timeit for Function Timing

To time the execution of functions directly, you may use the timeit module again, but in a slightly modified way:

import timeit

def test_function():
    # Code to be timed
    sum(range(10000))

execution_time = timeit.timeit(test_function, number=1)
print(f'Test function executed in: {execution_time} seconds.')

Alternative Approaches

Despite the effectiveness of these methods, you could also explore third-party libraries, like line_profiler, which allow for line-by-line timing. These can provide deeper insights into performance bottlenecks within your code.

If you would like to dig deeper into these or explore more advanced timing and profiling techniques, consider checking the official Python documentation and the timeit documentation .

FAQs on How to Measure the Execution Time of a Python Script

Q: What is the easiest way to measure execution time in Python?

A: The easiest way is to use the time library. You can simply record the start time before executing your function and then subtract it from the end time after the function completes.

Q: Can I measure execution time in Jupyter Notebooks?

A: Yes, you can use Jupyter’s magic commands: %timeit to measure execution time effectively for functions in a notebook environment.

Q: Is `timeit` suitable for all scripts?

A: While timeit is great for small snippets or functions, it might not measure longer executions accurately unless you specify a suitable number of runs to average out.

Q: Are there any performance overheads when using `timeit`?

A: Yes, timeit has a slight overhead due to setup and execution of the environment; therefore, it’s important to use it for smaller functions rather than complex, longer scripts.
