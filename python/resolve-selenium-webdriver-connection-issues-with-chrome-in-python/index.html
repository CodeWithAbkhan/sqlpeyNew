When working with Selenium WebDriver in Python, one common issue users face is trouble connecting to the Chrome browser. Despite having Chrome installed and the proper WebDriver, an error such as 'ChromeDriver executable needs to be available in the path' may arise. This can occur for multiple reasons, but the good news is that there are multiple solutions available.

What Causes the Selenium WebDriver Not to Connect to Chrome?

The issue generally arises due to one of the following:

  • ChromeDriver is not available in the system’s PATH.
  • The version of ChromeDriver does not match the installed version of Chrome.
  • Incorrect configuration in the script for launching Chrome.

Below are the top 7 ways to solve the Selenium WebDriver connection issue in Python when using Chrome:

Solution 1: Ensure ChromeDriver is Installed and Available in PATH (Linux)

If you’re using Linux, make sure that the ChromeDriver executable is available in your system’s PATH. To resolve this issue, follow these steps:

  1. Check Chrome Version: Ensure that Chrome is installed and check its version using:

    chromium-browser --version

  2. Install Chrome if Necessary: If Chrome is not installed, run the following command:

    sudo apt-get install chromium-browser

  3. Download ChromeDriver: Get the appropriate version of ChromeDriver from here .

  4. Move ChromeDriver to PATH:

    sudo mv chromedriver /usr/bin
sudo chmod a+x /usr/bin/chromedriver

  5. Test with Python Code:

    from selenium import webdriver
driver = webdriver.Chrome()
driver.get("http://www.google.com")
print(driver.page_source.encode('utf-8'))
driver.quit()

Solution 2: Quick Setup on macOS with Homebrew

For macOS users, a quicker solution involves using Homebrew to install ChromeDriver.

  1. Install Homebrew: If you haven’t installed Homebrew, follow the instructions on Homebrew’s website .

  2. Install ChromeDriver:

    brew install chromedriver

Once the installation is complete, you can directly use Selenium to open Chrome without any additional configuration.

Solution 3: Setting up ChromeDriver on Windows

For Windows users, here’s a simple way to set up ChromeDriver:

  1. Download ChromeDriver: Go to the ChromeDriver download page and get the latest version compatible with your version of Chrome.

  2. Place chromedriver.exe in Scripts Folder: Copy chromedriver.exe into the C:\Python27\Scripts folder.

  3. Test with Python Code:

    from selenium import webdriver
driver = webdriver.Chrome()
driver.get("http://www.google.com")
print(driver.page_source.encode('utf-8'))
driver.quit()

Solution 4: Alternative Way for Windows Users

Another solution for Windows involves explicitly defining the ChromeDriver executable path in your code.

  1. Extract the Downloaded ChromeDriver: Extract the ZIP file to a desired location.

  2. Set Executable Path in Code:

    from selenium import webdriver
driver = webdriver.Chrome(executable_path="D:/Selenium_RiponAlWasim/Drivers/chromedriver_win32/chromedriver.exe")
driver.get("http://www.google.com")
print(driver.page_source.encode('utf-8'))
driver.quit()

Solution 5: Using the Package chromium-chromedriver on Ubuntu

If you’re using Ubuntu, you can install ChromeDriver using the package manager:

  1. Install ChromeDriver:

    sudo apt install chromium-chromedriver

  2. Run Python Code:

    from selenium import webdriver
driver = webdriver.Chrome()
driver.get("http://www.google.com")
print(driver.page_source.encode('utf-8'))
driver.quit()

Solution 6: Two Ways to Run Selenium in Windows

For Windows, there are two main ways to resolve the issue based on whether you want to set the ChromeDriver manually or rely on system PATH.

Way 1: Set Executable Path Manually

  • Download ChromeDriver and extract it.
  • Set the executable path: 
    from selenium import webdriver
driver = webdriver.Chrome(executable_path='D:/path_to_chromedriver/chromedriver.exe')
driver.get("http://www.google.com")

Way 2: Use System PATH

  • Simply place chromedriver.exe under the Python Scripts directory (e.g., C:\Python36\Scripts).
  • Run the following code: 
    from selenium import webdriver
driver = webdriver.Chrome()
driver.get("http://www.google.com")

Solution 7: Automating with Selenium Manager (Selenium 4.6.0 and Above)

Starting from Selenium 4.6.0, Selenium Manager is included to automatically detect and install the appropriate WebDriver for your browser.

  1. Install WebDriver Manager:

    pip install webdriver-manager

  2. Use webdriver-manager for Automatic ChromeDriver Setup:

    from selenium import webdriver
from webdriver_manager.chrome import ChromeDriverManager

driver = webdriver.Chrome(ChromeDriverManager().install())
driver.get("http://www.google.com")
print(driver.page_source.encode('utf-8'))
driver.quit()

With Selenium 4.11.0, Selenium automatically manages the browser version and driver, streamlining the setup process.

FAQs on Top 7 Methods to Resolve Selenium WebDriver Connection Issues with Chrome in Python

Q: What is Selenium WebDriver?

A: Selenium WebDriver is a browser automation tool used for automating web applications for testing purposes. It supports multiple browsers, including Chrome.

Q: How do I know if my ChromeDriver is compatible with my Chrome version?

A: You should always download the version of ChromeDriver that matches the version of your Chrome browser. For compatibility, visit the ChromeDriver download page .

Q: What is Selenium Manager?

A: Selenium Manager is a feature in Selenium 4.6.0 and later that automatically detects and installs the correct WebDriver version for your browser.
