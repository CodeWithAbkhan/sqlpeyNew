Top 3 Methods to Convert Hexadecimal to Decimal in Python

In the realm of programming, converting data from one format to another is a common task. One such transformation that Python developers frequently encounter is the conversion of hexadecimal strings to decimal integers. This can be particularly useful when dealing with various data representations, like color codes, memory addresses, or digital data.

So, how can you achieve this hexadecimal to decimal conversion in Python effectively? Below, we explore three noteworthy methods that are both straightforward and practical.

Method 1: Using the int() Function

The simplest approach to convert a hexadecimal string into a decimal integer in Python is by utilizing the built-in int() function. This function allows you to specify the base of the numeral system you are converting from.

Here’s how you can do it:

## Converting hex string to decimal
decimal_value_1 = int("0xff", 16)  # Converts '0xff' to decimal
decimal_value_2 = int("FFFF", 16)   # Converts 'FFFF' to decimal

print(decimal_value_1)  # Output: 255
print(decimal_value_2)  # Output: 65535

For more information, check the official documentation .

Method 2: Using ast.literal_eval()

Another method of converting hexadecimal strings to decimal is by using Python’s ast module, specifically the literal_eval() function. This provides a safe way to evaluate strings containing Python literals.

Example code:

import ast

## Using ast.literal_eval to convert hex to decimal
decimal_value = ast.literal_eval('0xdeadbeef')

print(decimal_value)  # Output: 3735928559

You can also simply specify the base to the int() function as follows:

## Directly converting hex string to decimal
decimal_value = int('deadbeef', 16)

print(decimal_value)  # Output: 3735928559

Method 3: Utilizing Base-Determination via int()

A lesser-known but effective trick in Python is to allow the int() function to automatically determine the base of the hexadecimal string. By passing 0 as the base to int(), Python intelligently processes the string based on its prefix.

Here’s how you can implement this:

## Automatic base determination using int()
decimal_value_3 = int("0xff", 0)  # Hexadecimal
decimal_value_4 = int("0o644", 0)  # Octal
decimal_value_5 = int("0b100", 0)  # Binary
decimal_value_6 = int("100", 0)    # Decimal

print(decimal_value_3)  # Output: 255
print(decimal_value_4)  # Output: 420
print(decimal_value_5)  # Output: 4
print(decimal_value_6)  # Output: 100

FAQs on Top 3 Methods to Convert Hexadecimal to Decimal in Python

Q: How do I convert without a prefix?

A: You can convert a hexadecimal string without a prefix by using the int() function with the base set to 16, as shown: int('deadbeef', 16).

Q: Can I convert a hexadecimal string directly to binary?

A: Yes, after converting a hexadecimal string to a decimal, you can convert it to binary using the bin() function. For example: bin(int('0xff', 16)) gives you 0b11111111.

Q: What happens if I try to convert an invalid hex string?

A: If you provide an invalid hex string to the int() function, a ValueError will be raised, indicating that the string cannot be interpreted as a valid integer.
