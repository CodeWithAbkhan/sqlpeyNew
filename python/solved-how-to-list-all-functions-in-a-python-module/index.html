When working with Python modules, developers often need to understand the available functions, classes, and methods that can be utilized. Much like Ruby’s ClassName.methods, Python provides several techniques to list functions present in a module. This post explores multiple methods to achieve this.

How to Efficiently List All Functions in a Python Module

Method 1: Utilize the inspect Module

One effective way to list functions in a module is by leveraging Python’s built-in inspect module. Here’s how you can do it:

from inspect import getmembers, isfunction
from somemodule import foo

## List all functions defined in the 'foo' module
functions_list = getmembers(foo, isfunction)
print(functions_list)

This code snippet imports the necessary functions from the inspect library and lists all functions defined within the specified module.

Method 2: Use the Help or Dir Function

After importing a module, you can use the help() or dir() functions for introspection:

import somemodule

## Get interactive help on the module functions
help(somemodule)

## List names of all functions and variables defined in the module
print(dir(somemodule))

The help() function provides comprehensive documentation, while dir() simply lists the names of objects.

Method 3: Get Members with Conditions

You can also filter members to get only functions as shown below:

from inspect import getmembers, isfunction
import my_module

## Retrieve all functions within the module
function_members = getmembers(my_module, isfunction)
print(function_members)

This method will return a list of tuples containing function names and their respective objects.

Method 4: Using Types Module

Another approach involves using the types module to verify if an object is a function:

import types
import yourmodule

## Create a list of functions in 'yourmodule'
function_list = [getattr(yourmodule, name) for name in dir(yourmodule)
                 if isinstance(getattr(yourmodule, name), types.FunctionType)]
print(function_list)

This provides a selective list based on function types.

Method 5: Parsing Code with ast

For situations where importing a module poses risks (like executing undesirable code), the Abstract Syntax Tree (AST) can be your ally:

import ast
import sys

def top_level_functions(body):
    return (f for f in body if isinstance(f, ast.FunctionDef))

def parse_ast(filename):
    with open(filename, "rt") as file:
        return ast.parse(file.read(), filename=filename)

if __name__ == "__main__":
    for filename in sys.argv[1:]:
        print(filename)
        tree = parse_ast(filename)
        for func in top_level_functions(tree.body):
            print(" %s" % func.name)

This method safely reads the code without executing it, providing the names of the top-level functions.

Method 6: Use All Functionality

If you are looking for all callable objects, you may want to consider using a combination of methods to filter functions and exclude others.

import inspect
import my_module

## Collect all functions defined in 'my_module'
all_functions = [name for name, func in inspect.getmembers(my_module, inspect.isfunction)]
print(all_functions)

Additional Methods

  1. Interactive Shell Completion: Using tools like IPython allows you to view functions interactively with tab completion.
  2. Using Global Variables: You can access global variables directly in the module.
import my_module

## Listing all function-like objects using globals
functions = [name for name, obj in globals().items() if callable(obj) and obj.__module__ == 'my_module']
print(functions)

FAQs on Listing All Functions in a Python Module

Q: How can I list all functions from a module without importing it?

A: You can use the ast module to parse the code without executing it, allowing you to list all top-level functions.

Q: Is there a visual way to see all functions in a module?

A: Yes, using interactive environments like IPython offers a visual tab-completion feature to inspect modules in real time.

Q: What should I do if a module doesn't define `__all__`?

A: If __all__ is not defined, you may need to manually filter the functions as non-public functions will also appear in the dir() output.
