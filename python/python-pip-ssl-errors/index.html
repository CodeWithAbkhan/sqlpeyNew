“Fixing Python pip SSL Certificate Verification Errors”

Encountering CERTIFICATE_VERIFY_FAILED errors when using pip, Python’s package installer, can be a common hurdle, especially in corporate environments or when dealing with network restrictions. These errors typically arise when pip cannot verify the SSL certificate of the Python Package Index (PyPI) servers, preventing the installation of necessary libraries.

Several methods exist to address this issue, ranging from temporarily bypassing verification to permanently configuring pip to trust specific hosts or use custom certificates. It’s important to understand the security implications of each approach, particularly when bypassing SSL checks.

Let’s examine the various strategies to overcome these pip installation roadblocks.

Solution 1: Utilizing --trusted-host

This is a widely used method to inform pip that specific hosts are trustworthy, even if their certificates present verification challenges. This is often necessary when behind corporate firewalls or proxies that intercept SSL traffic.

  • Command-line Approach: You can specify trusted hosts directly in your pip install command. It’s advisable to include both the current and older PyPI domains.

    pip install --trusted-host pypi.org --trusted-host pypi.python.org --trusted-host files.pythonhosted.org <package_name>

    Note: The Python Package Index migrated from pypi.python.org to pypi.org around April 2018. Including both ensures compatibility.

  • Permanent Configuration: For a more persistent fix, you can add these trusted hosts to your pip configuration file.

    • Windows: Create or edit %APPDATA%\pip\pip.ini
    • Unix/macOS: Create or edit $HOME/.config/pip/pip.conf or $HOME/Library/Application Support/pip/pip.conf

    Add the following content to the configuration file:

    [global]
trusted-host = pypi.python.org
               pypi.org
               files.pythonhosted.org

  • Upgrading Pip: In some cases, simply upgrading pip itself can resolve underlying issues related to certificate handling.

    pip install --upgrade pip --trusted-host pypi.org --trusted-host files.pythonhosted.org

    Alternatively, refreshing your pip installation can help:

    curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
python get-pip.py

Solution 2: Specifying a Certificate Bundle (--cert)

If you have a specific root certificate or a certificate bundle provided by your organization, you can instruct pip to use it for verification.

  • Command-line:

    pip --cert /path/to/your/certificate.pem install <package_list>

    For instance, to install linkchecker:

    pip --cert /etc/ssl/certs/FOO_Root_CA.pem install linkchecker

  • Environment Variable: You can set the PIP_CERT environment variable to the path of your certificate file.

    export PIP_CERT=/path/to/your/certificate.pem
# Then run pip install without special flags
pip install <package_name>

  • Using cacert.pem: If your organization’s certificates don’t work, you might try using a certificate bundle from curl.

    curl -sO http://curl.haxx.se/ca/cacert.pem
# Convert if necessary (e.g., from .crt to .pem)
openssl x509 -inform DER -in your_certificate.crt -out your_certificate.pem -text
export PIP_CERT=$(pwd)/your_certificate.pem

    Ensure the file is in PEM format; CRT files may need conversion.

Solution 3: Using pip config set

A more direct way to modify your pip configuration for trusted hosts is via the pip config command.

pip config set global.trusted-host "pypi.org files.pythonhosted.org pypi.python.org"

This command updates the global pip configuration, making these hosts trusted.

Solution 4: Creating the pip.ini or pip.conf File Manually

If the pip config set command doesn’t behave as expected or you prefer manual configuration, creating the pip.ini (Windows) or pip.conf (Unix/macOS) file in the appropriate directory is a reliable method.

  • Location:

    • Windows: C:\Users\<username>\AppData\Roaming\pip\
    • Unix/macOS: $HOME/.config/pip/ or $HOME/Library/Application Support/pip/

  • File Content:

    [global]
trusted-host = pypi.python.org
               pypi.org
               files.pythonhosted.org

    If you cannot locate the AppData folder on Windows, typing %appdata% in the File Explorer address bar will navigate you there.

Solution 5: Using easy_install (Less Recommended)

In some scenarios, particularly with older Python versions or specific environment issues, easy_install might bypass certificate checks or use system certificates differently. However, easy_install is largely deprecated in favor of pip, and relying on it may lead to other compatibility issues.

easy_install <package_name>

For example:

easy_install pandas

Solution 6: Using HTTP Instead of HTTPS

This is a security-compromising workaround and should only be used if you fully grasp the risks and are in a controlled environment.

pip install --index-url=http://pypi.python.org/simple/ <package_name>

For example:

pip install --index-url=http://pypi.python.org/simple/ linkchecker

Solution 7: Checking System Time and Date

An incorrect system date and time can cause SSL/TLS handshake failures, leading to CERTIFICATE_VERIFY_FAILED errors. Ensure your system’s clock is synchronized correctly.

On Raspberry Pi, for instance, you might use:

sudo date -s "Wed Thu  23 11:12:00 GMT+1 2018"
sudo dpkg-reconfigure tzdata

Or sync with an external source:

sudo date -s "$(curl -s --head http://google.com | grep ^Date: | sed 's/Date: //g')"
sudo dpkg-reconfigure tzdata

Solution 8: Updating CA Certificates (Linux)

On Linux systems, outdated CA certificates can be a source of this problem. Updating them and ensuring pip uses the correct bundle can resolve the issue without resorting to less secure methods.

sudo yum -y update ca-certificates
export PIP_CERT=/etc/ssl/certs/ca-bundle.crt

Solution 9: Installing pip-system-certs

For situations where pip isn’t properly leveraging system certificates, particularly when internal CAs are involved, the pip-system-certs package can be beneficial. It patches pip and requests at runtime to use certificates from your system’s store.

pip install pip-system-certs

Solution 10: Verifying the Correct Host URL with Verbosity

Sometimes, the error message might point to a specific host that pip is trying to access, which might differ from the primary PyPI domains. Using the verbose flag (-vvv) can help identify the exact URL causing the failure.

pip install <package_name> -vvv

Once identified, you can add that specific host to your trusted list.

pip install --trusted-host files.pythonhosted.org <package_name>

Solution 11: Downgrading Pip

In some cases, particularly with older Python versions or specific OS configurations, newer pip versions might introduce compatibility issues. Downgrading pip to an earlier version like 1.2.1 has been reported to resolve these SSL errors.

easy_install pip==1.2.1
pip install --upgrade pip # Then upgrade back if desired

Solution 12: Copying SSL DLLs (Windows Specific)

A less common but sometimes effective solution for Windows involves copying specific SSL-related DLLs from the Python installation’s Library/bin directory to the DLLs directory. This is usually relevant if there are issues with the underlying OpenSSL libraries used by Python.

# Example paths, adjust based on your Python installation
cp Anaconda3/Library/bin/libcrypto-1_1-x64.dll Anaconda3/DLLs/
cp Anaconda3/Library/bin/libssl-1_1-x64.dll Anaconda3/DLLs/

Solution 13: Alternative Configuration Locations

Beyond the common $HOME/.config/pip/pip.conf or %APPDATA%\pip\pip.ini, pip can also read configuration from within virtual environments.

  • Unix/macOS Virtualenv: $VIRTUAL_ENV/pip.conf
  • Windows Virtualenv: %VIRTUAL_ENV%\pip.ini

Ensure these locations are correctly configured if you are using virtual environments.

FAQs on Python pip SSL Certificate Verification Errors

Q: Why does pip fail with SSL certificate verification errors

ANS: Pip fails with SSL certificate verification errors when it cannot validate the authenticity of the PyPI server’s SSL certificate. This is often due to corporate firewalls, proxy servers, outdated root certificates on your system, or incorrect system time settings that affect the certificate’s validity period.

Q: Is using --trusted-host secure

ANS: Using --trusted-host bypasses certain SSL checks, which can be a security risk if not used carefully. It’s most appropriate when you are behind a trusted corporate firewall or proxy that you know is handling SSL traffic legitimately. For general internet usage, it’s generally safer to ensure your system’s certificates are up-to-date and correctly configured.

Q: How to fix pip install certificate verify failed on Windows

ANS: On Windows, you can fix pip install certificate verify failed errors by creating a pip.ini file in %APPDATA%\pip\ with the trusted-host setting, or by using the --cert flag to point to a valid certificate file. Upgrading pip and ensuring your system time is correct are also helpful steps.

Q: Can I use HTTP instead of HTTPS for pip installs

ANS: You can use --index-url=http://pypi.python.org/simple/ to force pip to use HTTP. However, this is not recommended as it exposes your package downloads to potential man-in-the-middle attacks, as the connection is not encrypted.

Q: What does the -vvv flag do for pip install

ANS: The -vvv flag (or --verbose) provides very detailed output from pip. This is useful for debugging SSL errors as it shows the exact URLs pip is attempting to access, which can help identify which host needs to be trusted or which certificate is causing the failure.
