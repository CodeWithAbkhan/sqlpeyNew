Have you ever encountered the frustrating error message stating that “Python was not found; run without arguments to install from the Microsoft Store”? This common issue can stem from various setup errors on Windows, such as PATH misconfiguration or conflicts with app execution aliases. In this article, we’ll delve into several effective methods to resolve this issue, ensuring you can run Python commands smoothly from the Command Prompt.

Practical Example Code

For those looking to verify their Python installation after following the fixes, use the following command:

python --version

If your Python is set up correctly, this command will display the version number of your Python installation.

Top 15 Methods to Solve ‘Python Was Not Found’ Error

Method 1: Updating Environment Variables

To start, ensure the paths to your Python installation are correctly set in the environment variables. Here’s how to do it:

  1. Locate your Python installation. Common paths include: 
    %AppData%\Programs\Python\Python311
%AppData%\Programs\Python\Python311\Scripts
  2. Add these paths to the System Variables, not the User Variables.

Method 2: Disable App Execution Aliases

In some cases, the default Windows setting may redirect Python commands to the Microsoft Store. To disable this feature:

  • Search for Manage App Execution Aliases in the Windows start menu and toggle off the corresponding Python aliases.

Method 3: Use Alternative Command

If you’re having issues with python, try using:

py --version

This command may work if python does not.

Method 4: Install Python Correctly

When reinstalling Python, make sure to check the box labeled “Add Python to PATH” during the installation process. This step is crucial for making Python accessible from the command prompt.

Method 5: Restart After Updates

If you recently updated Windows, restarting your machine can sometimes fix conflicts related to the Python installation.

Method 6: Running Commands from IDE

If you’re using Visual Studio Code, run your terminal commands within the IDE’s terminal instead of the system Command Prompt. This can bypass some path issues.

Method 7: Reinstall Python

If all else fails, uninstall Python completely and reinstall it. During reinstallation, ensure to check the “Add to PATH” option.

Method 8: Ensure the Correct Executable Path

For users of IDEs, check to ensure the Python executable paths in your settings align with where Python is installed. Adjust the PATH if necessary.

Method 9: Adjust Path for Specific Versions

If you have multiple versions of Python installed, be sure you are calling the correct version by specifying it directly:

py -3 your_program.py

Method 10: Fixing Environment Variables Manually

Manually adding Python to the PATH variable can resolve recognition issues:

  1. Open Environment Variables.
  2. Add: 
    C:\Users\<YourUsername>\AppData\Local\Programs\Python\Python39
C:\Users\<YourUsername>\AppData\Local\Programs\Python\Python39\Scripts

Method 11: Verify Python Installation Location

If you recently installed Python but cannot find the executable, check as follows:

  • Navigate to C:\Program Files.
  • Ensure that Python is indeed installed; if not, download it from the official Python website .

Method 12: Grant Permission in System Settings

Sometimes, user permissions affect the functioning of executables in Windows. Ensure your user account has the necessary permissions to run Python.

Method 13: Diagnose Aliases

Use the Windows search to check for app execution aliases related to Python and ensure they are disabled.

Method 14: Using the Command Prompt

If the error persists, try running:

python -m pip install --upgrade pip setuptools virtualenv

This will ensure you are using the correct pip installation.

Method 15: Simple Workaround for PIP

For easier installations, save the get-pip.py script from here and run it:

python get-pip.py

This will install pip directly, avoiding the complexities of other installation methods.

FAQs on Top 15 Methods to Solve ‘Python Was Not Found’ Error

Q: What should I do if Python still isn't found after reinstalling?

A: If Python isn’t found post-reinstallation, ensure that during the installation process you checked the “Add Python to PATH” option, and verify that the executable path is correctly added in Environment Variables.

Q: Can I run Python from Visual Studio Code?

A: Yes, you can run Python from Visual Studio Code, but ensure your active interpreter is set to the Python version you installed. Also, commands should be run in the integrated terminal.

Q: How do I check if Python is correctly installed on Windows?

A: You can check your Python installation by opening the command prompt and typing python --version. If you see the version number, Python is installed correctly.
