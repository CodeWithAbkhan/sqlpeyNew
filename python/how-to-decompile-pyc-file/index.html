Is it Possible to Decompile a Compiled PYC File into a PY File?

If you’re dealing with compiled Python files (.pyc) and are wondering whether it’s feasible to retrieve the original source code (.py), you’re not alone. Many developers find themselves in situations where extracting code from compiled files is necessary for debugging or recovery purposes. Below, we explore several powerful methods to accomplish this.

Top 7 Methods to Decompile PYC Files

Method 1: Using Easy Python Decompiler

One effective approach is to utilize the Easy Python Decompiler . This tool is built on Decompyle++ and Uncompyle2, supporting Python versions from 1.0 to 3.3. The ease of use and compatibility makes it a popular choice for many developers.

Method 2: Uncompyle6

You can also consider uncompyle6 . This tool works seamlessly even with the latest Python versions, including 3.8.0. To decompile a .pyc file, use the command:

uncompyle6 utils.cpython-38.pyc > utils.py

Method 3: Employing Unpyclib

The Unpyclib library can be employed to decompile .pyc files as well. To get started, install the package using pip:

pip install unpyclib

Then, execute the decompilation script as follows:

python -m unpyclib.application -Dq path/to/file.pyc

Method 4: Decompyle++ (PyCDC)

Decompyle++ (also known as pycdc ) is another efficient tool recommended for decompiling Python bytecode. It specifically aims to translate compiled Python bytecode back into valid and readable Python source code, making it a solid choice for your decompilation needs.

Method 5: Building from Source with PyCDC

For those who prefer a hands-on approach, you can build and run Decompyle++ (PyCDC) from source. Follow these steps:

  1. Download and install CMake from CMake’s official site .

  2. Clone the PyCDC repository:

    git clone https://github.com/zrax/pycdc.git

  3. Make sure to integrate CMake to your system’s PATH.

  4. Compile pycdc:

    cd pycdc
cmake .
make

  5. Use the executable to decompile:

    ./pycdc <your_pyc_file.pyc>

Method 6: Using Pycompyle6

You can also take advantage of pycompyle6. Install it with:

pip install pycompyle6

Then run it on your .pyc file like this:

pycompyle6 filename.pyc

Method 7: Modifying Uncompyle6 for Python 3.9+

If you’re working with Python 3.9 and need to use uncompyle6, you can modify the source code to allow compatibility by editing site-packages\uncompyle6\bin\uncompile.py. Add your version in the version-checking conditional. This workaround can get you operational quickly.

Method 8: Extracting from PyInstaller Executables

Furthermore, if you’re looking to extract files from an executable produced by PyInstaller, consider these steps:

  1. Clone the pyinstxtractor-ng repository:

    git clone https://github.com/pyinstxtractor/pyinstxtractor-ng.git

  2. Navigate to the directory and extract the executable:

    cd pyinstxtractor-ng
python pyinstxtractor-ng.py "<path_to_/dist/app>"

  3. Follow up by installing dependencies and using PyCDC as described earlier.

By following these detailed methods, you should be able to successfully decompile a .pyc file back into a .py file.

FAQs on How to Decompile a Compiled PYC File into a PY File

Q: Can I decompile any .pyc file?

A: Not all .pyc files can be decompiled perfectly, especially if they are obfuscated or contain specific compiler optimizations. However, most standard .pyc files can be decompiled using the tools mentioned above.

Q: What if my .pyc file was created with a different version of Python?

A: Tools like uncompyle6 and Decompyle++ support various Python versions, but your success may vary. You can try different decompilers to see which one works best for your specific case.

Q: Is it legal to decompile software?

A: The legality of decompiling software depends on your jurisdiction and the software’s licensing terms. Always ensure you have the right to decompile the code you are working with.
