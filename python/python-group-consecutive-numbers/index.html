“Python: Group Consecutive Numbers into Ranges”

This task is common in data analysis, where identifying contiguous sequences is crucial. Several Pythonic approaches exist, leveraging built-in modules and external libraries. Let’s explore some of the most effective methods.

FAQs on Python Group Consecutive Numbers into Ranges

Q: What is the basic idea behind grouping consecutive numbers

ANS: The core concept is to identify elements where the difference between a number and its predecessor (or successor) is exactly 1. By grouping these adjacent numbers, we can form continuous sequences or ranges.

Q: How can the itertools.groupby function be used for this task

ANS: itertools.groupby is a powerful tool. When combined with enumerate and a lambda function that calculates the difference between an element’s index and its value, it can group consecutive numbers. For instance, lambda (i, x): i - x yields the same key for elements in a consecutive sequence.

Q: Are there any third-party libraries that simplify this process

ANS: Yes, the more-itertools library offers a convenient consecutive_groups function, which directly addresses this problem, making the code more readable and concise.

Q: What if the input list is not sorted

ANS: Most effective solutions require the input list to be sorted first. Methods that iterate and check for adjacent elements rely on this ordering. Using sorted() before processing is a common first step.

Q: How to handle single numbers that are not part of a range

ANS: Many solutions naturally handle single numbers. They might be represented as a range where the start and end are the same (e.g., (20, 20)) or as a standalone value if the output format distinguishes between single numbers and ranges.

Solution 1: Using itertools.groupby and operator.itemgetter

This method leverages groupby to partition the data based on a calculated key. The key i - x remains constant for consecutive numbers when their indices are also considered.

from itertools import groupby
from operator import itemgetter

data = [2, 3, 4, 5, 12, 13, 14, 15, 16, 17, 20]

ranges = []
for k, g in groupby(enumerate(data), lambda x: x[0] - x[1]):
    group = list(map(itemgetter(1), g))
    # Represent single numbers or ranges
    if len(group) > 1:
        ranges.append((group[0], group[-1]))
    else:
        ranges.append(group[0])

print(ranges)
# Output: [(2, 5), (12, 17), 20]

# Function to yield ranges or single numbers
def find_ranges_with_more_itertools(data):
    """Yields ranges (start, end) or single numbers from consecutive groups."""
    for group in mit.consecutive_groups(data):
        group = list(group)
        if len(group) == 1:
            yield group[0]
        else:
            yield (group[0], group[-1])

print(list(find_ranges_with_more_itertools(iterable)))

Solution 3: A Naive Iterative Approach

This method iterates through the sorted list, keeping track of the start and end of the current range.

def group_consecutive_naive(numbers):
    """Groups consecutive numbers into ranges using a naive iteration."""
    if not numbers:
        return []

    sorted_numbers = sorted(numbers)
    ranges = []
    first = last = sorted_numbers[0]

    for current_num in sorted_numbers[1:]:
        if current_num == last + 1:
            # Extend the current range
            last = current_num
        else:
            # Current number breaks the sequence, yield the previous range/number
            ranges.append((first, last) if first != last else first)
            # Start a new range
            first = last = current_num
    
    # Append the last range/number
    ranges.append((first, last) if first != last else first)
    return ranges

data = [2, 3, 4, 5, 12, 13, 14, 15, 16, 17, 20]
print(group_consecutive_naive(data))
# Output: [(2, 5), (12, 17), 20]

# Example with single numbers and non-consecutive breaks
data_complex = [2, 3, 4, 5, 12, 13, 14, 15, 16, 17, 22, 25, 26, 28, 51, 52, 57]
print(group_consecutive_naive(data_complex))
# Output: [(2, 5), (12, 17), 22, (25, 26), 28, (51, 52), 57]

Solution 5: Pure Python without Imports (Readable)

This solution avoids external libraries and is designed for clarity.

def group_numbers_no_imports(lst):
    """Groups consecutive numbers in a list into ranges without imports."""
    if not lst:
        return []

    lst.sort()  # Ensure the list is sorted
    ranges = []
    start_num = lst[0]
    end_num = lst[0]

    for i in range(1, len(lst)):
        if lst[i] == end_num + 1:
            # Extend the current range
            end_num = lst[i]
        else:
            # Sequence broken, record the previous range/number
            ranges.append((start_num, end_num) if start_num != end_num else start_num)
            # Start a new range
            start_num = lst[i]
            end_num = lst[i]
    
    # Append the last range/number
    ranges.append((start_num, end_num) if start_num != end_num else start_num)
    return ranges

data = [2, 3, 4, 5, 12, 13, 14, 15, 16, 17, 20]
print(group_numbers_no_imports(data))
# Output: [(2, 5), (12, 17), 20]

Solution 6: Using itertools.groupby with a Counter

from itertools import groupby, count

def get_intervals(data):
    """Returns intervals (start, end) for consecutive numbers."""
    out = []
    # Use count to generate indices implicitly
    for key, group in groupby(data, key=lambda x: x - next(counter)):
        block = list(group)
        # Append as range (start, end) or single number
        if len(block) > 1:
            out.append((block[0], block[-1]))
        else:
            out.append(block[0])
    return out

Solution 7: Using List Comprehension and Set Operations (Efficient for Large Lists)

This approach uses set lookups for efficiency, particularly beneficial for larger datasets.

def group_consecutive_set_optimized(data):
    """Groups consecutive numbers efficiently using sets."""
    if not data:
        return []
    
    data_set = set(data)
    ranges = []
    
    # Process each number to identify starts of ranges
    for num in sorted(list(data_set)): # Ensure we process in order
        if num - 1 not in data_set: # This number is the start of a new sequence
            current_num = num
            # Find the end of the consecutive sequence
            while current_num + 1 in data_set:
                current_num += 1
            
            # Append as a range or single number
            if current_num != num:
                ranges.append((num, current_num))
            else:
                ranges.append(num)
    return ranges

data = [2, 3, 4, 5, 12, 13, 14, 15, 16, 17, 20]
print(group_consecutive_set_optimized(data))
# Output: [(2, 5), (12, 17), 20]

data_unsorted_duplicates = [15, 12, 2, 4, 5, 13, 3, 16, 17, 20, 14, 5, 15]
print(group_consecutive_set_optimized(data_unsorted_duplicates))
# Output: [(2, 5), (12, 17), 20]

Solution 8: Using portion Library

For interval management, the portion library is highly recommended.

Install: pip install portion

from portion import closeopen

integer_list = [2, 3, 4, 5, 12, 13, 14, 15, 16, 17, 20]

# Initialize an empty interval
joined_portion = closeopen(0, 0) 

for integer in integer_list:
    # Union the current integer as a close-open interval [integer, integer + 1)
    joined_portion |= closeopen(integer, integer + 1)

# joined_portion now contains the merged intervals like [2, 6), [12, 18), [20, 21)
print(joined_portion) 

# To extract ranges (start, end)
result_intervals = []
for interval in joined_portion:
    # interval.lower is the start, interval.upper - 1 is the end
    start = interval.lower
    end = interval.upper - 1
    if start == end:
        result_intervals.append(start)
    else:
        result_intervals.append((start, end))

print(result_intervals)
# Output: [(2, 5), (12, 17), 20]

Choosing the Right Approach

  • Readability & Simplicity: The naive iterative approach (Solution 3) or the pure Python no-imports version (Solution 5) are generally easy to grasp.
  • Conciseness: more-itertools.consecutive_groups (Solution 2) offers the most concise solution.
  • Efficiency (Large Data): The set-based approach (Solution 7) or NumPy (Solution 4) can be more performant for very large datasets due to optimized C implementations.
  • Interval Management: If you need to perform further operations on these ranges (like unions, intersections), the portion library (Solution 8) is an excellent choice.
  • Leveraging Standard Library: itertools.groupby (Solutions 1 and 6) is a powerful standard library option that balances efficiency and requires no external installations.
