Methods for Comparing Floating-Point Numbers in Python

Let’s delve into various techniques to achieve near-equality comparisons for floats.

Solution 1: Leveraging math.isclose() (Python 3.5+)

Python 3.5 introduced the math.isclose() and cmath.isclose() functions, as outlined in PEP 485 . These functions provide a robust way to compare floats with control over tolerance.

  • rel_tol: This is a relative tolerance. It’s multiplied by the greater of the magnitudes of the two arguments. As the values increase, the allowed difference also increases while still considering them equal.
  • abs_tol: This is an absolute tolerance, applied directly in all cases. If the difference between the numbers is less than either of these tolerances, they are considered equal.
import math

def compare_floats_with_tolerance(a, b, rel_tol=1e-09, abs_tol=0.0):
    """
    Compares two floats for near equality using relative and absolute tolerances.
    """
    return math.isclose(a, b, rel_tol=rel_tol, abs_tol=abs_tol)

# Example usage:
num1 = 0.1 + 0.2
num2 = 0.3
print(f"Using math.isclose: {compare_floats_with_tolerance(num1, num2)}") # Output: Using math.isclose: True

Solution 2: A Simple Absolute Difference Check

For scenarios where a simple absolute difference is sufficient, a straightforward comparison can be used.

def simple_abs_compare(f1, f2, allowed_error):
    """
    Compares two floats based on a simple absolute difference.
    """
    return abs(f1 - f2) <= allowed_error

# Example usage:
val1 = 10.000001
val2 = 10.000002
print(f"Simple absolute compare: {simple_abs_compare(val1, val2, 1e-6)}") # Output: Simple absolute compare: True

Solution 3: Utilizing NumPy’s isclose()

If you’re already using NumPy in your project, its numpy.isclose() function offers similar functionality to Python’s built-in math.isclose().

import numpy as np

def numpy_is_close_compare(a, b, rtol=1e-05, atol=1e-08, equal_nan=False):
    """
    Compares floats using NumPy's isclose function.
    """
    return np.isclose(a, b, rtol=rtol, atol=atol, equal_nan=equal_nan)

# Example usage:
arr1 = np.array([0.1, 0.2, 0.3])
arr2 = np.array([0.1, 0.20000001, 0.3])
print(f"NumPy isclose: {numpy_is_close_compare(arr1, arr2)}") # Output: NumPy isclose: [ True  True  True]

Solution 4: Employing the decimal Module

For operations demanding extreme precision, Python’s decimal module provides the Decimal class. While offering superior accuracy, it can be slower for computationally intensive tasks compared to standard floats.

from decimal import Decimal, getcontext

# Set precision (e.g., to 50 decimal places)

def decimal_compare(a, b):
    """
    Compares two Decimal objects for exact equality.
    """
    return Decimal(a) == Decimal(b)

# Example usage:
num_a = Decimal('0.1') + Decimal('0.2')
num_b = Decimal('0.3')
print(f"Decimal comparison: {decimal_compare(num_a, num_b)}") # Output: Decimal comparison: True

Solution 5: Custom isclose for Python 2 Compatibility and Infinity Handling

This solution offers a custom implementation of isclose that works with Python 2 and handles “inf” and “-inf” values correctly, drawing inspiration from the Python 3.5 math.isclose() source.

import math

def custom_isclose(a, b, rel_tol=1e-09, abs_tol=0.0):
    '''
    Python 2 compatible implementation of math.isclose().
    Handles infinities properly.
    '''
    if rel_tol < 0 or abs_tol < 0:
        raise ValueError("tolerances must be non-negative")

    if a == b:  # Handles exact equality, including same-sign infinities
        return True

    if math.isinf(a) or math.isinf(b): # Handles opposite-sign infinities or infinity vs finite
        return False

    # Regular computation using a weak test from Boost library
    diff = math.fabs(b - a)
    return (((diff <= math.fabs(rel_tol * b)) or
             (diff <= math.fabs(rel_tol * a))) or
            (diff <= abs_tol))

# Example usage:
print(f"Custom isclose (inf): {custom_isclose(float('inf'), float('inf'))}") # Output: Custom isclose (inf): True
print(f"Custom isclose (inf vs finite): {custom_isclose(float('inf'), 100)}") # Output: Custom isclose (inf vs finite): False

Solution 7: Alternative to Bitwise Hacks

For behavior similar to specific bitwise comparison methods (like Dawson’s AlmostEqual2sComplement), a conventional test using a small epsilon value can be employed.

def alternative_is_close(a, b, eps):
    """
    An alternative to bitwise comparison, using a small epsilon.
    """
    return abs(a - b) <= eps * max(abs(a), abs(b))

# Example usage:
val_x = 1.0000000001
val_y = 1.0
print(f"Alternative close: {alternative_is_close(val_x, val_y, 1e-9)}") # Output: Alternative close: True

Solution 10: Precision-Based Comparison using String Formatting

This method determines the minimum precision of the two numbers and rounds them to that precision before comparison. It’s effective for numbers without exponential notation.

def precision_based_isclose(a, b):
    """
    Compares floats by rounding them to their minimum precision.
    """
    astr = str(a)
    aprec = len(astr.split('.')[1]) if '.' in astr else 0
    bstr = str(b)
    bprec = len(bstr.split('.')[1]) if '.' in bstr else 0
    prec = min(aprec, bprec)
    return round(a, prec) == round(b, prec)

# Example usage:
print(f"Precision compare (10.0, 10.049): {precision_based_isclose(10.0, 10.049)}") # Output: Precision compare (10.0, 10.049): True
print(f"Precision compare (10.0, 10.05): {precision_based_isclose(10.0, 10.05)}") # Output: Precision compare (10.0, 10.05): False

Solution 11: Using Fractions for Exact Comparisons

Representing numbers as fractions using the fractions module can ensure exact comparisons, avoiding floating-point inaccuracies altogether.

from fractions import Fraction

def fraction_exact_compare(a, b):
    """
    Compares two numbers by converting them to Fractions.
    """
    return Fraction(a) == Fraction(b)

# Example usage:
print(f"Fraction compare (0.1 + 0.2, 0.3): {fraction_exact_compare(0.1 + 0.2, 0.3)}") # Output: Fraction compare (0.1 + 0.2, 0.3): False (due to float representation)
print(f"Fraction compare (Fraction(1, 10) + Fraction(2, 10), Fraction(3, 10)): {fraction_exact_compare(Fraction(1, 10) + Fraction(2, 10), Fraction(3, 10))}") # Output: Fraction compare (Fraction(1, 10) + Fraction(2, 10), Fraction(3, 10)): True

Solution 13: Relative Tolerance with a Twist

This approach modifies the relative tolerance check to handle the case where both values are zero specifically.

def relative_tol_zero_check(f1, f2, tol):
    """
    Compares floats with relative tolerance, handling zero values specifically.
    """
    if f1 == 0 and f2 == 0:
        return True
    else:
        return abs(f1 - f2) < tol * max(abs(f1), abs(f2))

# Example usage:
print(f"Relative tol zero check (0, 0): {relative_tol_zero_check(0, 0, 1e-9)}") # Output: Relative tol zero check (0, 0): True

Solution 15: Comparing up to a Specific Decimal Place

This method allows comparison up to a defined number of decimal places without explicit atol or rtol.

def compare_to_decimal(a, b, decimal=6):
    """
    Compares floats up to a specified number of decimal places.
    """
    return '{0:.{1}f}'.format(a, decimal) == '{0:.{1}f}'.format(b, decimal)

# Example usage:
print(f"Compare to decimal (0.0, 0.0001, 5): {compare_to_decimal(0.0, 0.0001, decimal=5)}") # Output: Compare to decimal (0.0, 0.0001, 5): False
print(f"Compare to decimal (0.0, 0.0001, 4): {compare_to_decimal(0.0, 0.0001, decimal=4)}") # Output: Compare to decimal (0.0, 0.0001, 4): True

Solution 16: Rounding via String Formatting and eval()

This approach rounds floats to a specified precision using string formatting and then converts them back to floats using eval(). A cleaner, non-eval version is also provided.

def round_to_eval(float_num, prec):
    """ Rounds a float using eval and string formatting. """
    return eval("'{:.{}f}'.format({}, {})".format(float_num, int(prec), float_num))

def is_close_eval(float_a, float_b, prec):
    """ Compares floats after rounding via eval. """
    return round_to_eval(float_a, prec) == round_to_eval(float_b, prec)

# Cleaner version without eval:
def round_to_format(float_num, prec):
    """ Rounds a float using string formatting. """
    return '{:.{precision}f}'.format(float_num, precision=prec)

def is_close_format(a, b, prec):
    """ Compares floats after rounding using string formatting. """
    return round_to_format(a, prec) == round_to_format(b, prec)

# Python 3.6+ f-string version:
def is_close_fstring(a, b, prec):
    """ Compares floats using f-strings for rounding. """
    return f'{a:.{prec}f}' == f'{b:.{prec}f}'

# Example usage:
a = 10.0
b = 10.0001
print(f"Is close (f-string, prec=3): {is_close_fstring(a, b, prec=3)}") # Output: Is close (f-string, prec=3): True
print(f"Is close (f-string, prec=4): {is_close_fstring(a, b, prec=4)}") # Output: Is close (f-string, prec=4): False

Solution 17: Custom __eq__ for Float-like Behavior

It’s possible to create a custom class that inherits from float and overrides the __eq__ method to implement custom comparison logic.

import math

class MyFloat(float):
    def __eq__(self, another):
        # Custom comparison using math.isclose with a specific tolerance
        return math.isclose(self, another, rel_tol=0, abs_tol=0.001)

# Example usage:
val_a = MyFloat(0)
val_b = 0.001
print(f"Custom __eq__ check: {val_a == val_b}") # Output: Custom __eq__ check: True

Solution 18: Using Enums for Specific Float Values

If you have a limited set of expected float values, using Enum can be a way to validate if a number matches one of these predefined values.

from enum import Enum

class HolidayMultipliers(Enum):
    EMPLOYED_LESS_THAN_YEAR = 2.0
    EMPLOYED_MORE_THAN_YEAR = 2.5

# Example usage:
testable_value = 2.0
try:
    multiplier = HolidayMultipliers(testable_value)
    print(f"Valid multiplier found: {multiplier}")
except ValueError:

FAQs on Python: Compare Floating-Point Numbers for Near Equality

Q: What is the best way to compare two floating point numbers in Python

ANS: The math.isclose() function, available in Python 3.5+, is generally considered the most robust and flexible method. It allows you to specify both relative and absolute tolerances for the comparison.

Q: Why does `0.1 + 0.2 == 0.3` return False in Python

ANS: This is due to the way floating-point numbers are represented in binary. Most decimal fractions cannot be represented exactly in binary floating-point format, leading to small precision errors. math.isclose() or custom tolerance checks are recommended for comparisons.

Q: How can I compare floats for equality without using tolerances

ANS: Direct comparison using == is possible but often unreliable due to floating-point inaccuracies. If exact matches are truly required, consider using the Decimal type for precise calculations or ensuring your numbers are represented in a way that guarantees exact binary equality.

Q: What are relative and absolute tolerances when comparing floats

ANS: Relative tolerance (rel_tol) is a percentage of the larger number, accounting for scale. Absolute tolerance (abs_tol) is a fixed difference, useful for comparisons near zero. math.isclose(a, b, rel_tol=..., abs_tol=...) uses both.

Q: Is there a way to compare floats in older Python versions

ANS: Yes, for Python versions prior to 3.5, you can implement your own isclose function, similar to Solution 5 provided in the main content, which defines relative and absolute tolerance checks.
def isclose(a, b, rel_tol=1e-09, abs_tol=0.0):
    return abs(a-b) &lt;= max(rel_tol * max(abs(a), abs(b)), abs_tol)
