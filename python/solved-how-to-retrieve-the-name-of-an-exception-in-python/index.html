How can I effectively retrieve the name of an exception that has been raised in Python? This is a common requirement when handling errors and logging issues, especially when you need to make sense of various exceptions thrown by your code. Below, I present several methods to achieve this, complete with practical examples.

Solution 1: Using a Helper Function for Fully Qualified Class Name

To obtain the fully qualified class name of an exception (for example, sqlalchemy.exc.IntegrityError instead of just IntegrityError), you can create a helper function as shown below. This method facilitates better clarity, especially in cases where multiple exceptions may share the same name.

def fetch_full_class_name(exception_instance):
    module_name = exception_instance.__class__.__module__
    return f"{module_name}.{exception_instance.__class__.__name__}" if module_name else exception_instance.__class__.__name__

try:
    # Example interaction with a database that may throw an error
    foo = bar
except Exception as error:
    print(fetch_full_class_name(error))

Solution 2: Formatted String Printing

Another straightforward approach to displaying an exception’s name is by utilizing formatted string literals (f-strings). This method succinctly captures and conveys the type of the exception alongside the error message:

try:
    # Code that might raise an error
    foo = bar
except Exception as err:
    print(f"{type(err).__name__} was raised: {err}")

Solution 3: Utilizing sys.exc_info()

The sys.exc_info() function is another powerful tool that returns a tuple containing the type of exception, its value, and the traceback. This is especially useful when you need in-depth information about the current exception.

import sys

try:
    foo = bar
except Exception:
    exception_type, value, traceback = sys.exc_info()
    print(f"Failed with exception [{exception_type.__name__}]")

For further reading, refer to the official Python documentation on sys.exc_info() .

Solution 4: Parsing Exception Representation

While it might seem roundabout, parsing the representation of an exception can also yield the exception name:

try:
    foo = bar
except Exception as exc:
    name = repr(exc).split('(')[0]
    print(f"Error occurred: {name}")

Solution 5: Logging the Exceptions

If the intent is to log exceptions, it’s prudent to use Python’s built-in logging functionality, which provides additional context, such as traceback information. Here’s a simple example:

import logging

logging.basicConfig(level=logging.ERROR)

try:
    # Operation that can cause an exception
    do_something()
except BaseException as e:
    logging.error(f'An error occurred: {type(e).__name__}: {e}')

This will output a detailed error message along with the exception type to the log.

Solution 6: Handling Custom Exceptions

It can be useful to explore custom exception classes within your error-handling logic. Below is an example showcasing how to print structured details of both standard and custom exceptions.

class MyCustomError(Exception):
    pass

try:
    raise MyCustomError("Example custom error")
except Exception as e:
    print(f"Exception details - Type: {type(e)}, Name: {e.__class__.__name__}, Message: {e}")

Solution 7: Leveraging Logging.Exception

Finally, consider using logging.exception(), which captures the full stack trace and logs it at an ERROR level, providing context that helps diagnose issues quickly. This is often the best practice in production applications.

import logging

logging.basicConfig(level=logging.ERROR)

try:
    # Code that might raise an exception
    potentially_failing_function()
except Exception:
    logging.exception("Exception caught:")

Alternatives

Using custom error handling libraries tailored for your project might provide additional functionalities for error management. Libraries such as loguru offer streamlined logging methods that can enhance your error tracing capabilities.

FAQs on Solved: How to Retrieve the Name of an Exception in Python

Q: How do I get the name of a specific exception?

A: You can capture a specific exception using a try-except block and directly print the exception type with type(exception).__name__.

Q: Is there a way to log exceptions without printing them on the console?

A: Yes, you can use Python’s logging library. Using logging.error() or logging.exception() allows you to log errors to files or external systems without displaying them on the console.

Q: What’s the difference between Exception and BaseException?

A: BaseException is the root class for all exceptions in Python, while Exception is a subclass of BaseException and is intended to handle typical exceptions. You should often catch Exception unless you need to handle system-exiting exceptions.
