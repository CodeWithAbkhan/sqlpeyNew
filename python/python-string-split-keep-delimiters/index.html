“Python String Splitting: Keep Delimiters in Results”

When working with strings in Python, the built-in str.split() method is a common tool. However, it removes the delimiters from the output. What if you need to retain those separators within the resulting list for further processing or analysis? This post explores various techniques, from regular expressions to creative string manipulation, to achieve this.

Using re.split with Capturing Groups

The re.split() function in Python’s re module offers a powerful way to split strings based on patterns. By enclosing your delimiter pattern within capturing parentheses (), re.split() will include the matched delimiters in the output list.

Solution 1: Capturing Parentheses

The documentation for re.split states: “If capturing parentheses are used in pattern, then the text of all groups in the pattern are also returned as part of the resulting list.”

import re

text_data = 'foo/bar spam\\neggs'
split_result = re.split(r'(\W)', text_data)
print(split_result)
# Output: ['foo', '/', 'bar', ' ', 'spam', '\n', 'eggs']

Solution 3: Non-Alphanumeric Split with Capture

This approach specifically targets non-alphanumeric characters as delimiters and keeps them.

import re

sample_string = "foo,bar@candy*ice%cream"
split_sample = re.split(r'([^a-zA-Z0-9])', sample_string)
print(split_sample)
# Output: ['foo', ',', 'bar', '@', 'candy', '*', 'ice', '%', 'cream']

The pattern ([^a-zA-Z0-9]) works as follows:

  • (): These create a capturing group, ensuring the delimiter itself is included.
  • []: Defines a character set.
  • ^a-zA-Z0-9: Matches any character that is not an uppercase letter, a lowercase letter, or a digit.

Solution 9: re.sub and re.split Combination

This method involves substituting the delimiter with itself followed by a unique marker, then splitting by that marker.

import re

def split_and_keep_with_marker(separator_pattern, input_string):
  # Add a unique marker after each separator occurrence
  marked_string = re.sub(separator_pattern, lambda match: match.group() + ';', input_string)
  # Split by the marker
  return re.split(';', marked_string)

test_string = 'foo/bar spam\\neggs'
print(split_and_keep_with_marker(r'[\/\s\n]', test_string))
# Output: ['foo', '/', 'bar', ' ', 'spam', '\\n', 'eggs']

Solution 10: re.split with Custom Logic

This solution uses re.split and then reconstructs the list, ensuring separators are kept.

import re

def split_string_with_separators(regex_pattern, text_content):
   # Compile the regex pattern for efficiency
   separator_regex = re.compile(regex_pattern)
   
   # Split the string using the regex
   split_parts = separator_regex.split(text_content)
   
   resulting_list = []
   current_pos = 0
   for part in split_parts:
     if not part: continue # Skip empty parts if any
     
     # Find the position of the current part in the original string
     found_pos = text_content.find(part, current_pos)
     
     # If there's content before the current part, and it's not the same as the last appended item, add it
     if found_pos > current_pos and (not resulting_list or resulting_list[-1] != text_content[current_pos:found_pos]):
       resulting_list.append(text_content[current_pos:found_pos])
       
     resulting_list.append(part)
     current_pos = found_pos + len(part)
     
   # Add any remaining content at the end
   if current_pos < len(text_content):
     resulting_list.append(text_content[current_pos:])
     
   return resulting_list

content_string = "%%(c+dd+e+f-1523)%%7"
regex = r'[\+\-//\*\<\>\%\(\)]' # Example regex for various symbols
print(split_string_with_separators(regex, content_string))
# Output: ['%%(', 'c', '+', 'dd', '+', 'e', '+', 'f', '-', '1523', ')%%', '7']

Solution 11: Using re.finditer or re.split with Capturing

This presents two regex-based methods: one using finditer to manually build the list, and another using re.split with capturing.

import re

def finditer_with_separators(regex, s):
    matches = []
    prev_end = 0
    for match in regex.finditer(s):
        match_start = match.start()
        # Append text before the current match if it's not empty and not overlapping
        if (prev_end != 0 or match_start > 0) and match_start != prev_end:
            matches.append(s[prev_end:match.start()])
        # Append the matched delimiter
        matches.append(match.group())
        prev_end = match.end()
    # Append any remaining text after the last match
    if prev_end < len(s):
        matches.append(s[prev_end:])
    return matches

def split_with_capturing_regex(regex, s):
    # Use re.split with a capturing group for the delimiter
    # Filter out any empty strings that might result from consecutive delimiters
    return list(filter(None, regex.split(s)))

sample_text = "(a)b(c)d"
# Example for finditer: splitting by parentheses
paren_regex_finditer = re.compile(r"[\(\)]")
print(f"Using finditer: {finditer_with_separators(paren_regex_finditer, sample_text)}")
# Output: Using finditer: ['(', 'a', ')', 'b', '(', 'c', ')', 'd']

# Example for split: splitting by parentheses with capturing
paren_regex_split = re.compile(r"([\(\)])")
print(f"Using split with capturing: {split_with_capturing_regex(paren_regex_split, sample_text)}")
# Output: Using split with capturing: ['(', 'a', ')', 'b', '(', 'c', ')', 'd']

Solution 20: Splitting by Bash Special Parameters

This example demonstrates splitting a string using a list of special Bash parameters as delimiters, utilizing re.split with a dynamically constructed regex.

import re

Solution 4: List Comprehensions with str.split()

This method leverages list comprehensions to reconstruct the string, optionally re-adding the delimiter.

text_data = 'foo,bar,baz,qux'
separator = ','

# Prepending separator
result_prepend = [separator + x for x in text_data.split(separator)]
# Remove leading separator from the first element if necessary
if result_prepend and result_prepend[0].startswith(separator):
    result_prepend[0] = result_prepend[0][len(separator):]
print(f"Prepended: {result_prepend}")
# Output: Prepended: ['foo', ',bar', ',baz', ',qux']

# Appending separator
result_append = [x + separator for x in text_data.split(separator)]
# Remove trailing separator from the last element if necessary
if result_append and result_append[-1].endswith(separator):
    result_append[-1] = result_append[-1][:-len(separator)]
print(f"Appended: {result_append}")
# Output: Appended: ['foo,', 'bar,', 'baz,', 'qux']

# Separator as its own element using nested list comprehension
result_own_element = [item for sublist in [[x, separator] for x in text_data.split(separator)] for item in sublist]
# Remove trailing separator if it's the last element
if result_own_element and result_own_element[-1] == separator:
    result_own_element.pop()

Solution 5: String Replacement and Split (Python 3)

This approach uses str.replace to insert a unique marker after the delimiter, then splits by the marker. It cleverly handles edge cases, including potential unicode limitations.

def split_and_keep_non_regex(s, sep):
    if not s: return [''] # Consistent with string.split() on empty string

    # Find a character unlikely to be in the string
    # Handles potential ValueError if string contains the highest Unicode character
    try:
        marker = chr(ord(max(s)) + 1)
    except ValueError:
        # Fallback if the string contains the maximum Unicode character
        marker = '\0' # Use null character as a fallback marker

    # Replace the separator with separator + marker, then split by the marker
    return s.replace(sep, sep + marker).split(marker)

test_strings = ['<Hello>', 'Hi', '<Hi> <Planet>', '<', '']
for s in test_strings:
    print(f"'{s}' -> {split_and_keep_non_regex(s, '<')}")
# Output:
# '<Hello>' -> ['<', 'Hello>']
# 'Hi' -> ['Hi']
# '<Hi> <Planet>' -> ['<', 'Hi> ', '<', 'Planet>']
# '<' -> ['<', '']
# '' -> ['']

Solution 6: split() with List Comprehension (Custom Logic)

This function splits a string and intelligently appends the delimiter to the preceding element.

def splitkeep(s, delimiter):
    split_list = s.split(delimiter)
    # Append delimiter to all but the last segment, then add the last segment
    return [substr + delimiter for substr in split_list[:-1]] + [split_list[-1]]

# Example usage
sample = "item1.item2.item3."
print(f"Split and keep: {splitkeep(sample, '.')}")
# Output: Split and keep: ['item1.', 'item2.', 'item3.']

Solution 8: Custom Tokenizer for Multiple Separators

This function tokenizes a string based on a provided list of separators, prioritizing longer separators.

def tokenize_string(input_string, separators):
    # Sort separators by length in descending order for correct matching
    separators.sort(key=len, reverse=True)
    
    token_list = []
    current_index = 0
    while current_index < len(input_string):
        found_separator = ""
        for sep in separators:
            if input_string.startswith(sep, current_index):
                found_separator = sep
                break
        
        if found_separator:
            token_list.append(found_separator)
            current_index += len(found_separator)
        else:
            # If no separator found, append the current character
            if not token_list or token_list[-1] in separators:
                token_list.append(input_string[current_index])
            else:
                token_list[-1] += input_string[current_index]
            current_index += 1
            
    # Clean up potential empty strings if they resulted from consecutive separators or leading/trailing separators
    cleaned_tokens = []
    for i, token in enumerate(token_list):
        if token or (token in separators and i > 0 and token_list[i-1] in separators):
             cleaned_tokens.append(token)
    
    # Handle cases where the string might end with a separator or have consecutive separators
    final_tokens = []
    for i, tok in enumerate(cleaned_tokens):
        if tok or (tok in separators and i > 0 and cleaned_tokens[i-1] in separators):
            final_tokens.append(tok)
            
    return final_tokens if final_tokens else [''] # Ensure at least an empty string if input was empty

sample_text = '""hi"" hello + world += (1*2+3/5) \'\'\'hi\'\'\''
multi_separators = ["'''", '+=', '+', "/", "*", "'", '"', "-=", "-", " ", '"""', "(", ")"]
print(tokenize_string(sample_text, multi_separators))
# Output: ['"', '"', 'hi', '"', '"', ' ', 'hello', ' ', '+', ' ', 'world', ' ', '+=', ' ', '(', '1', '*', '2', '+', '3', '/', '5', ')', ' ', "'''", 'hi', "'''"]

Solution 14: Generator-Based Approach

This Pythonic solution uses a generator to yield parts of the string, including the delimiter. It’s memory-efficient.

def split_keep_generator(string_input, separator):
    start_index = 0
    while True:
        # Find the next occurrence of the separator, adding 1 to include it
        end_index = string_input.find(separator, start_index) + 1
        if end_index == 0: # Separator not found
            break
        yield string_input[start_index:end_index]
        start_index = end_index
    # Yield the remainder of the string after the last separator
    yield string_input[start_index:]

sample_string = "a.b.c.d"
for segment in split_keep_generator(sample_string, "."):
    print(segment)
# Output:
# a.
# b.
# c.
# d

# Python 3.8+ Walrus operator version:
def split_keep_generator_py38(string_input, separator):
    start_index = 0
    while (end_index := string_input.find(separator, start_index) + 1) > 0:
        yield string_input[start_index:end_index]
        start_index = end_index
    yield string_input[start_index:]

Solution 16: Custom Splitting for Whitespace

This function specifically handles whitespace characters, preserving them as separate elements in the output list.

def split_with_whitespace(input_string):
    parts = []
    current_word = ""
    for char in input_string:
        if char == " ":
            if current_word: # If there's a word accumulated, add it
                parts.append(current_word)
            parts.append(" ") # Add the space itself
            current_word = "" # Reset current word
        else:
            current_word += char
    if current_word: # Add any remaining word at the end
        parts.append(current_word)
    return parts

print(split_with_whitespace("this is a simple text"))
# Output: ['this', ' ', 'is', ' ', 'a', ' ', 'simple', ' ', 'text']

print(split_with_whitespace("this is  a  simple text"))
# Output: ['this', ' ', 'is', ' ', ' ', 'a', ' ', ' ', 'simple', ' ', 'text']

Solution 17: Iterative Splitting with str.index

This iterative approach uses str.index to find delimiters and slices the string, ensuring delimiters are kept.

def split_and_keep_iterative(input_str, delimiter):
    result_list = []
    remaining_str = input_str
    while delimiter in remaining_str:
        idx = remaining_str.index(delimiter)
        # Append the part up to and including the delimiter
        result_list.append(remaining_str[:idx + len(delimiter)])
        # Update the remaining string to process
        remaining_str = remaining_str[idx + len(delimiter):]
    # Append any leftover part of the string
    result_list.append(remaining_str)
    return result_list

sample = "part1--part2--part3"
print(split_and_keep_iterative(sample, "--"))
# Output: ['part1--', 'part2--', 'part3']

Solution 19: str.partition for Multiple Separators

This solution utilizes str.partition within a custom function to handle splitting by multiple separators.

import typing as t

def partition_string(s: str, separators: t.Iterable[str]):
    if not s or not separators:
        return [s]
        
    # Use a set for efficient lookup of separators
    unique_separators = set(separators)
    
    # Stacks for processing parts
    parts_stack1, parts_stack2 = [s], []
    
    for sep in unique_separators:
        # Process from stack1 to stack2 if separators exist
        if parts_stack1:
            while parts_stack1:
                parts_stack2.append(parts_stack1.pop())
                # Repeatedly partition the top element from stack2
                while True:
                    left, found_sep, right = parts_stack2.pop().rpartition(sep)
                    if not found_sep: # Separator not found
                        parts_stack2.append(right)
                        break
                    # Add parts and separator back, handling cases where left/right are empty
                    if not left:
                        parts_stack2.extend([right, found_sep] if right else [found_sep])
                        break
                    parts_stack2.extend([right, found_sep, left] if right else [found_sep, left])
        # Process from stack2 to stack1 if separators exist
        else:
            while parts_stack2:
                parts_stack1.append(parts_stack2.pop())
                # Repeatedly partition the top element from stack1
                while True:
                    left, found_sep, right = parts_stack1.pop().partition(sep)
                    if not found_sep: # Separator not found
                        parts_stack1.append(left)
                        break
                    # Add parts and separator back, handling cases where left/right are empty
                    if not right:
                        parts_stack1.extend([left, found_sep] if left else [found_sep])
                        break
                    parts_stack1.extend([left, found_sep, right] if left else [found_sep, right])
                    
    return parts_stack1 or list(reversed(parts_stack2))

test_string = "abcdbcd"
print(f"Partitioning '{test_string}' by 'b': {partition_string(test_string, ['b'])}")
# Output: Partitioning 'abcdbcd' by 'b': ['a', 'b', 'cd', 'b', 'cd']
print(f"Partitioning '{test_string}' by ['b', 'd']: {partition_string(test_string, ['b', 'd'])}")
# Output: Partitioning 'abcdbcd' by ['b', 'd']: ['a', 'b', 'c', 'd', 'b', 'c', 'd']

Solution 21: Robust Splitting with Delimiters (Handling Edge Cases)

This function is designed to be robust, handling various edge cases like empty delimiters or consecutive delimiters, while keeping all parts including separators.

def split_including_delimiters(input_string: str, delimiter: str):
    if not delimiter: # Handle empty delimiter by splitting between characters
        return list(input_string)
        
    tokens = input_string.split(delimiter)
    output = tokens[:1] # Start with the first segment

    for token in tokens[1:]:
        output.append(delimiter) # Append the delimiter
        if token: # Append the segment if it's not empty
            output.append(token)
            
    # Remove leading empty string if the input started with a delimiter
    if output and output[0] == '':
        output.pop(0)
        
    return output

print(split_including_delimiters('Hello World  !', ' '))
# Output: ['Hello ', 'World ', ' ', '!']

print(split_including_delimiters("Hello**World**!***", "**"))
# Output: ['Hello', '**', 'World', '**', '!', '**', '*']

print(split_including_delimiters("xx-xx", "xx"))
# Output: ['xx', '-', 'xx']

FAQs on Python String Splitting

Q: How do I split a string in Python and keep the separators?

ANS: You can use re.split() with capturing parentheses around your separator pattern, or employ string manipulation techniques like replace followed by split with a unique marker, or use specialized functions like those shown above that iterate and rebuild the list.

Q: What is the difference between str.split() and re.split() for keeping delimiters?

ANS: str.split() removes delimiters by default. re.split() can keep delimiters if they are enclosed in capturing parentheses () within the regular expression pattern.

Q: Can I split a string by multiple different delimiters and keep them all?

ANS: Yes, you can use re.split() with a pattern that includes multiple delimiters using the | (OR) operator, enclosed in capturing parentheses. Alternatively, custom functions can handle lists of separators.

Q: Are there non-regex ways to split strings and keep delimiters in Python?

ANS: Absolutely. Methods include using str.splitlines(True) for newlines, clever use of str.replace and str.split with markers, generator functions, or iterative approaches using str.index and slicing.

Q: How do I handle edge cases like empty strings or consecutive delimiters?

ANS: Many of the provided solutions address these. For consecutive delimiters, re.split with capturing groups often handles them well. For empty delimiters, specific functions might treat them as splitting between characters. Carefully review the logic for each solution.
