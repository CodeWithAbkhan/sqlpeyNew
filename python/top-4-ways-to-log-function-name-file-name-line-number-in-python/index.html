Top 4 Ways to Log Function Name, File Name, and Line Number in Python

Logging in Python provides a valuable way to monitor the control flow of your application, especially when working on larger projects. If you’re trying to log information about the function being executed, the source file, and the specific line number where the log entry is made, this comprehensive guide explores different methods to achieve that. Here, we present Top 4 Ways to Log Function Name, File Name, and Line Number in Python.

1. Basic Logging Configuration

To begin logging relevant details, you can set up a basic logging configuration that includes function names and line numbers. Here’s a practical example:

import logging

## Define the log format
FORMAT = "[%(asctime)s - %(filename)s -> %(funcName)s():%(lineno)d] %(levelname)s: %(message)s"
logging.basicConfig(format=FORMAT, level=logging.INFO)

## Sample functions to demonstrate logging
def example_function():
    logging.info("This is an info log in example_function.")

if __name__ == "__main__":
    example_function()

In the above example, the log messages will include the date and time, the filename, the function name, and the line number, providing a detailed context for each log entry.

2. Using Inspect Module for Detailed Logging

Python’s inspect module can be used for retrieving current frame information, which allows you to log the calling function name along with the filename and line number dynamically. Here’s how to implement it:

import logging
import inspect

def dynamic_logging(message):
    frame = inspect.currentframe().f_back
    function_name = frame.f_code.co_name
    file_name = frame.f_code.co_filename
    line_number = frame.f_lineno
    
    logging.info(f"{message} - Called from {function_name} in {file_name} at line {line_number}")

def my_function():
    dynamic_logging("This function is executing.")

if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO)
    my_function()

This method gives you flexibility as you can log messages from anywhere without manually specifying function and line information each time.

3. Implementing a Singleton Logger

For larger applications, you may want to centralize your logging functionality. By implementing a singleton logger, you can ensure consistent logging across your application. The example below illustrates how to create a singleton logger that captures detailed calling context:

import logging
import inspect

class SingletonLogger:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            logging.basicConfig(level=logging.INFO)
            cls._instance.logger = logging.getLogger('SingletonLogger')
        return cls._instance

    @staticmethod
    def log(message):
        frame = inspect.currentframe().f_back
        function_name = frame.f_code.co_name
        file_name = frame.f_code.co_filename
        line_number = frame.f_lineno
        SingletonLogger._instance.logger.info(f"{message} - {function_name} in {file_name}:{line_number}")

def another_function():
    SingletonLogger.log("Log from another_function.")

if __name__ == "__main__":
    another_function()

Here, the SingletonLogger class ensures that all logs include context about where the log was triggered, making it easier to trace issues.

4. Rotating File Handler for Log Management

For applications that generate a considerable amount of log data, using RotatingFileHandler can help manage log files efficiently. Below is an example demonstrating how to set this up:

import logging
from logging.handlers import RotatingFileHandler

## Set up logger
logger = logging.getLogger(__name__)
handler = RotatingFileHandler('app.log', maxBytes=2000, backupCount=5)

## Define log format
FORMAT = "[%(asctime)s - %(filename)s -> %(funcName)s():%(lineno)d] %(levelname)s: %(message)s"
formatter = logging.Formatter(FORMAT)
handler.setFormatter(formatter)
logger.addHandler(handler)
logger.setLevel(logging.INFO)

def run_task():
    logger.info("Running task...")

if __name__ == "__main__":
    for _ in range(10):
        run_task()

In this setup, log messages are written to “app.log”, and if the file exceeds 2000 bytes, it rotates, keeping the last five log files and allowing for better management of log files.

FAQs on Top 4 Ways to Log Function Name, File Name, and Line Number in Python

Q: How can I ensure all log messages are captured in the order they are called?

A: By using the logging module, all calls logged in the same thread will appear in the order they occurred, ensuring the sequence of function calls is maintained.

Q: How do I view historical log entries after rotating?

A: You can check the rotated log files, which are automatically saved as app.log.1, app.log.2, etc., depending on your configuration.

Q: Can I customize the log file location?

A: Yes, you can specify any file path when setting up your RotatingFileHandler by providing the full path in the file name.
