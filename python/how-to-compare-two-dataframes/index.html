Introduction

Are you looking to compare two Pandas DataFrames and display their differences in a clear, side-by-side format? Below, we will explore various methods to highlight changes between DataFrames, providing practical code examples for efficient comparison.

Example DataFrames

Let’s first define two sample DataFrames for our comparison:

import pandas as pd
import numpy as np
from io import StringIO

data1 = """id Name score isEnrolled Comment
111 Jack 2.17 True He was late to class
112 Nick 1.11 False Graduated
113 Zoe 4.12 True NaN
"""

data2 = """id Name score isEnrolled Comment
111 Jack 2.17 True He was late to class
112 Nick 1.21 False Graduated
113 Zoe NaN False On vacation
"""

df1 = pd.read_csv(StringIO(data1), sep=" ")
df2 = pd.read_csv(StringIO(data2), sep=" ")

Method 1: Concatenation and Highlighting Differences

We can concatenate the DataFrames and highlight the differences between corresponding values using the style property.

## Concatenate DataFrames
df_all = pd.concat([df1.set_index('id'), df2.set_index('id')], axis='columns', keys=['First', 'Second'])

## Swap column levels for easier comparison
df_final = df_all.swaplevel(axis='columns')[df1.columns[1:]]

## Function to highlight differences
def highlight_diff(data, color='yellow'):
    attr = 'background-color: {}'.format(color)
    other = data.xs('First', axis='columns', level=-1)
    return pd.DataFrame(np.where(data.ne(other, level=0), attr, ''), index=data.index, columns=data.columns)

## Apply highlighting
df_final.style.apply(highlight_diff, axis=None)

Method 2: Using pandas Built-in Comparison

Starting from version 1.1, the compare method streamlines this operation.

if pd.__version__ >= "1.1":
    diff = df1.compare(df2, keep_equal=True)
    print(diff)

This will yield a table showing the differences, where equal values are included with optional parameters to customize the output format.

Method 3: Custom Function for Detailed Differences

For a deeper analysis, create a custom function that will identify the differences:

def diff_pd(df1, df2):
    assert (df1.columns == df2.columns).all(), "DataFrame columns must match"
    if df1.equals(df2):
        return None
    else:
        diff_mask = (df1 != df2) & ~(df1.isnull() & df2.isnull())
        return pd.DataFrame({'old': df1.where(diff_mask), 'new': df2.where(diff_mask)})

changes = diff_pd(df1, df2)
print(changes)

Practical Example of Usage

Using the defined DataFrames, you could run the comparison methods demonstrated above:

## Display differences using the custom function
changes = diff_pd(df1, df2)
print(changes)

Alternative Methods

There are several other ways to compare DataFrames in Python:

  1. Using numpy for element-wise comparison: Take advantage of boolean indexing to highlight different rows.
  2. Merge approach: Merge the DataFrames on common identifiers and highlight the differences in the merged DataFrame.
  3. Using external libraries: Explore libraries such as datacompy, which provides higher-level functions for DataFrame comparison.

FAQs on How to Compare Two DataFrames and Output Their Differences Side by Side

Q: How do I check if two DataFrames are identical?

A: You can use the .equals() method. For example, df1.equals(df2) will return True if they are identical, otherwise False.

Q: How can I visualize DataFrame differences effectively?

A: You can apply styling methods like using style.apply() in Pandas to highlight the differences when displaying DataFrames.

Q: Are there plugins or libraries that simplify DataFrame comparisons?

A: Yes, libraries such as datacompy offer streamlined functions for comparing DataFrames more efficiently.

Q: Can I compare DataFrames with different column names?

A: Column names must match between DataFrames for a meaningful comparison. You may need to rename columns before comparing.

Q: Is there a way to export the comparison result to an HTML file?

A: Yes, using df_final.to_html('output.html'), you can export the styled DataFrame comparison to an HTML file directly.
