Solved: How to Fix ‘Permission Denied’ Error When Running Python on Windows 10

It seems a recent update on Windows 10 has created chaos for Python users, resulting in a 'Permission Denied' error when attempting to run commands like `python --version`. In this post, we'll delve deep into this issue, exploring not only its potential causes but also a multitude of solutions to restore functionality to your Python installations.

### Background and Symptoms

After a Windows update, users have reported that executing Python commands leads to a frustrating "Permission Denied" error. This can occur regardless of whether you are running Git Bash with elevated privileges or using PowerShell, which often redirects users to the Windows Store as if Python isn't installed. The underlying issue seems to be related to permissions set on the WindowsApps folder, making it impossible for certain terminal programs to access Python.

To illustrate this, running `python` in CMD may yield successful results, yet trying to list files in the associated path often results in a permission error. This confusion around permissions, exacerbated by the nuances of Microsoft's distribution method for Windows applications, complicates troubleshooting efforts. The peculiar permission settings, where the "Users" group can read and execute files but admins are limited to listing folder contents, reveal a mishap in access controls.

### Exploring Solutions

#### Solution 1: Check Permissions

The permissions on the folder `%USERPROFILE%\AppData\Local\Microsoft\WindowsApps` can be a starting point. You may notice that it is filled with placeholders rather than actual files. You can consider changing permissions on the `C:\Program Files\WindowsApps` directory, but this requires administrative access and may involve multiple steps.

- **Change Owner:** If you need to change the owner of the folder, you can refer to [this guide](https://winaero.com/blog/how-to-restore-the-trustedinstaller-ownership-in-windows-10/).
  
#### Solution 2: Using winpty

For users running into issues specifically in Git Bash, invoking Python using `winpty` can often resolve the permission problems. As a command, you would execute:

```bash
winpty python.exe

This method has proven effective for many users experiencing errors in Git Bash.

Solution 3: Modify Environment Variables

A common issue stems from incorrect or missing entries in system environment variables. To resolve, follow these steps:

  1. Access Environment Variables: Open the Start menu and search for “environment variables.”

  2. Edit Path Variable: Under “System Variables,” find and edit the Path variable.

  3. Add Python Paths: Ensure the paths direct to your Python install locations, such as:

    C:\Users\[YOUR USERNAME]\AppData\Local\Programs\Python\Python38
C:\Users\[YOUR USERNAME]\AppData\Local\Programs\Python\Scripts

  4. Restart Your Terminal: This should reflect changes, allowing you to run Python normally.

Solution 4: Use PY Instead of Python

As a quick workaround, substituting python with py in your commands may yield immediate success. Type:

py --version

While not a permanent fix, it can help mitigate immediate disruptions.

Solution 5: Reinstall Python and Set Path

If all else fails, uninstall Python completely, then reinstall ensuring you check the option to add Python to your PATH during installation. This guarantees all necessary environmental variables are properly configured.

  • Ensure you can see the AppData folder by checking the hidden items checkbox in File Explorer.

Solution 6: Adjust Windows Execution Aliases

These aliases come into play with Microsoft Store applications. To manage these:

  1. Open Settings > Apps > Apps & features.
  2. Click on Manage app execution aliases.
  3. Toggle off the option for the Python execution alias.

After performing these steps, try rerunning your Python commands.

Solution 7: Windows Subsystem for Linux (WSL)

Switching to using the Windows Subsystem for Linux can often provide a more consistent environment for Python:

  1. Install a Linux distribution like Ubuntu from the Microsoft Store.
  2. Use WSL as your primary terminal environment, which can seamlessly interface with Python.

FAQs on How to Fix Python Permission Denied

Q: What causes the 'Permission Denied' error when using Python on Windows 10?

A: This error is primarily caused by permission issues related to the WindowsApps folder that hinders access to the Python installation and executables.

Q: How can I check if Python is added to my system PATH?

A: You can check by accessing the Environment Variables through system settings and verifying that the Python installation paths are present in the Path variable.

Q: What is the quickest workaround for running Python while facing permission issues?

A: A quick workaround is to use py instead of python in your command line to avoid the permission restriction.
