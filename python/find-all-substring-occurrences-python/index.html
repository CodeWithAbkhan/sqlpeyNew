“Finding All Substring Occurrences in Python: Methods & Examples”

When working with strings in Python, a common task is to identify every position where a specific substring appears within a larger string. While Python’s built-in str.find() method is useful for locating the first occurrence, it doesn’t directly provide a way to find all subsequent matches. This leads to the question: what are the effective ways to retrieve the starting indices of all occurrences of a substring in Python?

Several approaches exist, ranging from leveraging powerful regular expressions to crafting custom loop-based solutions. Let’s explore these techniques, examining their implementation and use cases.

Solution 1: Using Regular Expressions (re.finditer)

The re module in Python offers robust pattern matching capabilities. re.finditer() is particularly well-suited for this task, as it returns an iterator yielding match objects for all non-overlapping matches of a pattern in a string.

import re

# Example 1: Simple non-overlapping matches
string_data = 'test test test test'
substring = 'test'
matches = [match.start() for match in re.finditer(substring, string_data)]
print(f"Matches for '{substring}' in '{string_data}': {matches}")
# Expected output: Matches for 'test' in 'test test test test': [0, 5, 10, 15]

# Example 2: Finding overlapping matches using lookahead
overlapping_string = 'ttt'
overlapping_substring = 'tt'
# The lookahead `(?=...)` asserts that the pattern can be matched starting at the current position,
# but it doesn't consume characters, allowing for overlapping matches.
overlapping_matches = [match.start() for match in re.finditer(f'(?={overlapping_substring})', overlapping_string)]
print(f"Overlapping matches for '{overlapping_substring}' in '{overlapping_string}': {overlapping_matches}")
# Expected output: Overlapping matches for 'tt' in 'ttt': [0, 1]

# Example 3: Finding non-overlapping matches in reverse (more complex)
# This uses a combination of positive and negative lookahead to achieve reverse non-overlapping finds.
search_term = 'tt'
complex_string = 'ttt'
# The expression `(?=%s)(?!.{1,%d}%s)` searches for `search_term` and then asserts that
# it's not followed by `len(search_term)-1` characters and then `search_term` again.
reverse_non_overlapping_matches = [m.start() for m in re.finditer('(?=%s)(?!.{1,%d}%s)' % (search_term, len(search_term)-1, search_term), complex_string)]
print(f"Reverse non-overlapping matches for '{search_term}' in '{complex_string}': {reverse_non_overlapping_matches}")
# Expected output: Reverse non-overlapping matches for 'tt' in 'ttt': [1]

Using re.finditer() returns a generator, which can be more memory-efficient than creating a list if you only need to iterate through the results once. To get a generator, simply replace [...] with (...).

Solution 2: Custom Generator Function Using str.find()

A clean and efficient way to achieve this without external libraries is by creating a custom generator function that iteratively uses the str.find() method. This approach avoids regular expressions and temporary string creations.

def find_all_occurrences(text_string, substring_to_find):
    """
    Yields the starting index of all occurrences of a substring within a string.

    Args:
        text_string: The string to search within.
        substring_to_find: The substring to search for.

    Yields:
        The starting index of each found substring.
    """
    start_index = 0
    while True:
        found_index = text_string.find(substring_to_find, start_index)
        if found_index == -1:
            return  # No more occurrences found
        yield found_index
        # To find overlapping matches, change start_index += len(substring_to_find)
        # to start_index += 1
        start_index = found_index + len(substring_to_find)

# Example usage
sample_text = 'spam spam spam spam'
target_substring = 'spam'
indices = list(find_all_occurrences(sample_text, target_substring))
print(f"Indices of '{target_substring}' in '{sample_text}': {indices}")
# Expected output: Indices of 'spam' in 'spam spam spam spam': [0, 5, 10, 15]

This generator approach is flexible. By modifying start_index += len(substring_to_find) to start_index += 1, you can adapt it to find overlapping matches.

Solution 3: Using str.startswith() in a Loop

This method iterates through the string, checking at each position if the substring starts there using str.startswith(). While straightforward, it can be less efficient for very long strings or frequent searches compared to optimized methods.

string_to_search = "test test test test"
sub_to_find = "test"
found_positions = [i for i in range(len(string_to_search)) if string_to_search.startswith(sub_to_find, i)]
print(f"Positions of '{sub_to_find}' in '{string_to_search}': {found_positions}")
# Expected output: Positions of 'test' in 'test test test test': [0, 5, 10, 15]

# Example with multi-word substrings
long_string = "Find THIS SUB-WORD in this sentence with THIS SUB-WORD"
multi_word_sub = "THIS SUB-WORD"
multi_word_positions = [i for i in range(len(long_string)) if long_string.startswith(multi_word_sub, i)]
print(f"Positions of '{multi_word_sub}' in '{long_string}': {multi_word_positions}")
# Expected output: Positions of 'THIS SUB-WORD' in 'Find THIS SUB-WORD in this sentence with THIS SUB-WORD': [5, 41]

This approach is also effective for finding overlapping matches naturally.

Solution 4: Iterative str.find() with Offset

This method uses a loop that repeatedly calls str.find(), incrementing the starting position for the next search to avoid finding the same occurrence multiple times.

def get_all_indices(main_string, sub_string):
    """
    Finds all starting indices of a substring within a main string.

    Args:
        main_string: The string to search within.
        sub_string: The substring to locate.

    Returns:
        A list of integer indices where the substring begins.
    """
    indices = []
    current_position = 0
    while True:
        found_at = main_string.find(sub_string, current_position)
        if found_at == -1:
            break
        indices.append(found_at)
        current_position = found_at + 1  # Increment by 1 for potential overlaps, or by len(sub_string) for non-overlaps
    return indices

sample_sentence = 'This is a sentence this this'
word_to_find = 'this'
all_locations = get_all_indices(sample_sentence, word_to_find)
print(f"All locations of '{word_to_find}' in '{sample_sentence}': {all_locations}")
# Expected output: All locations of 'this' in 'This is a sentence this this': [0, 19, 24] (Note: case-sensitive)

To find non-overlapping occurrences, change current_position = found_at + 1 to current_position = found_at + len(sub_string).

Solution 5: Using str.split() for Counting

While not directly providing indices, str.split() can be used to count occurrences. The number of times a substring appears is one less than the number of parts the string is split into by that substring.

text_data = "test test test test"
search_word = "test"
# The count is the number of splits minus one.
occurrence_count = len(text_data.split(search_word)) - 1
print(f"'{search_word}' appears {occurrence_count} times in '{text_data}'.")
# Expected output: 'test' appears 4 times in 'test test test test'.

# For single characters, using reduce can be an alternative
from functools import reduce
char_string = "dooobiedoobiedoobie"
char_to_count = 'o'
char_count = reduce(lambda count, char: count + 1 if char == char_to_count else count, char_string, 0)
print(f"'{char_to_count}' appears {char_count} times in '{char_to_find}'.")
# Expected output: 'o' appears 7 times in 'dooobiedoobiedoobie'.

Be mindful that split() will create intermediate lists, which might affect performance for very large strings.

Solution 6: Recursive Approach

A recursive function can also be crafted to find all occurrences. This method leverages the string.find() method within its recursive calls.

def find_substring_locations(main_string, sub_string):
    """
    Recursively finds all starting locations of a substring.

    Args:
        main_string: The string to search.
        sub_string: The substring to find.

    Returns:
        A list of indices where the substring is found.
    """
    sub_length = len(sub_string)
    
    def recurse_search(locations_found, start_from):
        found_at = main_string.find(sub_string, start_from)
        if found_at != -1:
            # Recurse, moving the start position past the current find
            return recurse_search(locations_found + [found_at], found_at + sub_length)
        else:
            return locations_found

    return recurse_search([], 0)

example_text = 'this is a test for finding this and this'
target = 'this'
results = find_substring_locations(example_text, target)
print(f"Recursive search for '{target}' in '{example_text}': {results}")
# Expected output: Recursive search for 'this' in 'this is a test for finding this and this': [0, 27, 36]

This recursive solution avoids explicit loops but relies on the call stack. For extremely long strings, it might hit Python’s recursion depth limit.

Solution 7: Using str.startswith() with enumerate

Similar to Solution 3, this uses enumerate to get both the index and value, then checks for the substring.

def find_all_with_enumerate(string_to_check, sub_to_find):
    """
    Finds all occurrences using enumerate and startswith.
    """
    return [
        index for index, _ in enumerate(string_to_check)
        if string_to_check.startswith(sub_to_find, index)
    ]

test_string = "test test test test"
find_string = "test"
print(f"Enumerate + startswith for '{find_string}': {find_all_with_enumerate(test_string, find_string)}")
# Expected output: Enumerate + startswith for 'test': [0, 5, 10, 15]

Solution 8: Using str.index() in a Loop (with error handling)

str.index() is similar to str.find() but raises a ValueError if the substring is not found. This can be handled with a try-except block.

number_string = "onetwothreefourfivesixseveneightninefiveten"
target_number = "five"

marker = 0
while marker < len(number_string):
    try:
        found_at = number_string.index(target_number, marker)
        print(f"'{target_number}' found at index: {found_at}")
        marker = found_at + 1  # Move marker to search for next occurrence
    except ValueError:
        # Substring not found from the current marker position
        marker = len(number_string) # Exit loop

This approach, like str.find(), needs adjustment for overlapping vs. non-overlapping searches by changing how marker is updated.

Solution 9: Using flashtext for Multiple Keywords

For scenarios involving searching for a large list of keywords efficiently, the flashtext library is a strong contender. It uses an optimized algorithm that can outperform regular expressions for extensive keyword searches.

from flashtext import KeywordProcessor

keywords = ['test', 'exam', 'quiz']
text_content = 'this is a test, and it could be an exam or quiz'

keyword_processor = KeywordProcessor()
keyword_processor.add_keywords_from_list(keywords)

# Extract keywords with their span information (start and end indices)
found_keywords = keyword_processor.extract_keywords(text_content, span_info=True)
print(f"Keywords found by flashtext: {found_keywords}")
# Expected output: Keywords found by flashtext: [('test', 10, 14), ('exam', 30, 34), ('quiz', 39, 43)]

Solution 10: Knuth-Morris-Pratt (KMP) Algorithm

For performance-critical applications dealing with very large strings and potentially complex patterns, implementing or utilizing a KMP algorithm variant can be highly efficient, offering O(n+m) time complexity. This algorithm preprocesses the pattern to avoid redundant comparisons.

def find_all_kmp(haystack: str, needle: str):
    """
    Finds all occurrences of a needle in a haystack using a KMP-like approach.
    Yields starting indices of matches.
    """
    n = len(haystack)
    m = len(needle)
    if m == 0: return # Handle empty needle
    if n == 0: return # Handle empty haystack

    # Build the LPS (Longest Proper Prefix which is also Suffix) array for the needle
    lps = [0] * m
    length = 0  # length of the previous longest prefix suffix
    suffix_end = 1
    while suffix_end < m:
        if needle[length] == needle[suffix_end]:
            length += 1
            lps[suffix_end] = length
            suffix_end += 1
        else:
            if length != 0:
                length = lps[length - 1]
            else:
                lps[suffix_end] = 0
                suffix_end += 1

    # Search for the needle in the haystack
    i = 0  # index for haystack
    j = 0  # index for needle
    while i < n:
        if needle[j] == haystack[i]:
            i += 1
            j += 1

        if j == m:
            yield i - j  # Found a match
            j = lps[j - 1] # Move j based on LPS array for next potential match
        elif i < n and needle[j] != haystack[i]:
            if j != 0:
                j = lps[j - 1]
            else:
                i += 1

# Example usage of KMP
haystack_text = "test test test test"
needle_text = "test"
kmp_matches = list(find_all_kmp(haystack_text, needle_text))
print(f"KMP matches for '{needle_text}' in '{haystack_text}': {kmp_matches}")
# Expected output: KMP matches for 'test' in 'test test test test': [0, 5, 10, 15]

Python 3.8+ Assignment Expressions (Walrus Operator)

For Python 3.8 and later, assignment expressions (the walrus operator :=) can be used for a more compact syntax in list comprehensions.

# Requires Python 3.8+
string_content = "test test test test"
phrase_to_find = "test"
start_position = -1
# The walrus operator assigns the result of string_content.find(...) to start_position
# and then includes that value in the list comprehension.
found_indices = [
    (start_position := string_content.find(phrase_to_find, start_position + 1))
    for _ in range(string_content.count(phrase_to_find))
]
print(f"Walrus operator results for '{phrase_to_find}': {found_indices}")
# Expected output: Walrus operator results for 'test': [0, 5, 10, 15]

Using numpy.cumsum

If you are already using NumPy, a mathematical approach can also be employed, though it might be less intuitive for standard string manipulation.

import numpy as np

main_string = "test test test test"
sub_string = "test"

# This method leverages splitting and cumulative sum for index calculation.
# It's a bit more involved but demonstrates an alternative approach.
if sub_string in main_string:
    # Split the string by the substring, excluding the last empty part if it exists.
    parts = main_string.split(sub_string)[:-1]
    # Calculate the lengths of parts and the substring itself.
    # Sum these lengths cumulatively to find the start indices.
    indices = np.cumsum([len(part) + len(sub_string) for part in parts]) - len(sub_string)
    print(f"NumPy cumsum indices for '{sub_string}': {list(indices)}")
else:
    print(f"'{sub_string}' not found in '{main_string}'.")
# Expected output: NumPy cumsum indices for 'test': [0, 5, 10, 15]

NumPy for Character-Level Searching

For finding individual characters, NumPy can also be used with its vectorized operations.

import numpy as np

data_string = "Hello World, this should work!"
char_to_find = 'o'

# Convert string to numpy array for vectorized operations
string_array = np.array(list(data_string))

# Find indices where the character matches
char_indices = np.where(string_array == char_to_find)[0]
print(f"NumPy indices for '{char_to_find}' in '{data_string}': {list(char_indices)}")
# Expected output: NumPy indices for 'o' in 'Hello World, this should work!': [4, 7, 20, 26]

Considerations for Overlapping Matches

Several solutions naturally handle overlapping matches (like Solution 3 and Solution 6). For those using iterative str.find() or re.finditer(), adjusting the step size (e.g., start_index + 1 instead of start_index + len(substring)) is key to detecting overlaps.

Choosing the Right Method

  • re.finditer(): Generally powerful and flexible, especially for complex patterns or when overlapping matches are required.
  • Custom Generator (str.find()): Clean, Pythonic, and efficient for standard substring finding without external dependencies. Excellent for both overlapping and non-overlapping scenarios.
  • str.startswith() Loop: Simple and readable, good for general use.
  • flashtext: Ideal when searching for many keywords simultaneously.
  • KMP Algorithm: Best for performance-critical applications with large datasets.

FAQs on Finding All Substring Occurrences in Python

FAQs on Finding All Substring Occurrences in Python

Q: What is the most straightforward Python method for finding all substring occurrences

ANS: A very clear and efficient method involves creating a custom generator function that repeatedly uses the built-in str.find() method, incrementing the search start position. This avoids external libraries and handles overlapping matches easily with a minor adjustment.

Q: How can I find overlapping substrings in Python

ANS: To find overlapping substrings, when using iterative methods like str.find() or custom loops, ensure you advance your search position by just one character (e.g., start += 1) after finding a match, instead of advancing by the length of the substring. Regular expressions with lookaheads are also excellent for this.

Q: Is there a built-in Python function to find all substring occurrences

ANS: Python’s standard string methods like str.find() and str.index() only return the first occurrence. For finding all occurrences, you typically need to use a loop, the re module (specifically re.finditer), or custom functions.

Q: What is the efficiency of using regex for finding all substrings

ANS: The re.finditer method is generally efficient. Its performance can vary depending on the complexity of the pattern and the string, but it’s often highly optimized for string searching tasks in Python. For very complex patterns or a massive number of searches, libraries like flashtext might offer better performance.

Q: Can I find all occurrences without using regular expressions

ANS: Yes, absolutely. You can write custom Python functions using loops and the str.find() or str.startswith() methods. These custom solutions can be very efficient and don’t require importing the re module.
