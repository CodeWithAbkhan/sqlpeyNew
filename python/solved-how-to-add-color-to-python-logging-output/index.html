Introduction

Colored output in Python logging can significantly enhance your terminal experience by making logs easier to read and understand. The built-in logging module provides a robust framework for tracking events in software development. However, adding color can help to instantly identify the log levels (e.g., ERROR, WARNING, DEBUG), making it not only visually appealing but also functional.

Here, I’ll explore multiple solutions and methods for adding color to Python logging output, along with practical examples for better clarity.

How Can You Achieve Colored Logging in Python?

There are several methods to implement colored logging in Python. Let’s delve into each solution with practical code examples:

Solution 1: Custom Colored Logger

You can create a custom logger that utilizes ANSI escape sequences to colorize the output based on log levels.

import logging

## ANSI escape sequences for colors
RESET_SEQ = "\033[0m"
COLOR_SEQ = "\033[1;%dm"
BLACK, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE = range(8)

COLORS = {
    'WARNING': YELLOW,
    'INFO': GREEN,
    'DEBUG': BLUE,
    'CRITICAL': RED,
    'ERROR': RED,
}

class ColoredFormatter(logging.Formatter):
    def format(self, record):
        levelname = record.levelname
        color = COLOR_SEQ % (30 + COLORS.get(levelname, 0))
        record.levelname = f"{color}{levelname}{RESET_SEQ}"
        return super().format(record)

## Custom logger
class ColoredLogger(logging.Logger):
    def __init__(self, name):
        super().__init__(name, logging.DEBUG)
        color_handler = logging.StreamHandler()
        color_handler.setFormatter(ColoredFormatter('%(asctime)s - %(levelname)s - %(message)s'))
        self.addHandler(color_handler)

if __name__ == "__main__":
    logging.setLoggerClass(ColoredLogger)
    logger = logging.getLogger("ColoredLogger")

    logger.debug("This is a debug message.")
    logger.info("This is an info message.")
    logger.warning("This is a warning message.")
    logger.error("This is an error message.")
    logger.critical("This is a critical message.")

Output Example

When you run this code in a compatible terminal, you will see colored output that distinguishes log levels easily.

Solution 2: Using coloredlogs Library

For a more straightforward solution, you can use the coloredlogs library, which can be easily installed via pip.

pip install coloredlogs

Usage Example:

import logging
import coloredlogs

## Install coloredlogs
coloredlogs.install(level='DEBUG')

logger = logging.getLogger("ExampleLogger")

logger.debug('This is a debug message.')
logger.info('This is an info message.')
logger.warning('This is a warning message.')
logger.error('This is an error message.')
logger.critical('This is a critical message.')

Using coloredlogs automatically configures the logger to use colorized output based on the level.

Solution 3: Using rich Library for Rich Logging

The rich library provides an elegant way to handle colored logging. It can be used alongside standard logging functionality.

pip install rich

Implementation:

import logging
from rich.logging import RichHandler

## Configure rich logging
logging.basicConfig(
    level="DEBUG",
    format="%(message)s",
    datefmt="[%X]",
    handlers=[RichHandler()]
)

logger = logging.getLogger("RichLogger")

logger.debug("Debug level message")
logger.info("Information level message")
logger.warning("Warning level message")
logger.error("Error level message")
logger.critical("Critical level message")

This method allows you to leverage the powerful features of rich, including better formatting and color options that work well in many terminal environments.

Alternative Approaches

Custom Formatter Class

You can also develop a custom formatter by subclassing logging.Formatter, applying custom coloring as needed.

class CustomColorFormatter(logging.Formatter):
    COLORS = {
        'DEBUG': "\033[1;34m",   # Blue
        'INFO': "\033[1;32m",    # Green
        'WARNING': "\033[1;33m",  # Yellow
        'ERROR': "\033[1;31m",    # Red
        'CRITICAL': "\033[1;41m", # Red on background
    }

    def format(self, record):
        color = self.COLORS.get(record.levelname, "\033[0m")  # default to no color
        return f"{color}{super().format(record)}\033[0m"

### FAQs on How To Add Color To Python Logging Output



    
Q: How can I install the coloredlogs library?

    

    
A: You can install the library using pip by running the command pip install coloredlogs.

    






    
Q: Will colored logging work in all terminals?

    

    
A: Most modern terminal emulators support ANSI coloring, but if your terminal does not support them, it may fall back to the regular output without colors.

    






    
Q: Can I use custom colors for my logging output?

    

    
A: Yes, you can define custom colors by using ANSI escape codes or by modifying existing formatter classes to include your desired colors.

    






    
Q: Is it possible to log the colored output to a file?

    

    
A: To prevent colored escape sequences from being logged to files, it is best to manage different handlers accordingly or to strip colors when logging to files.
