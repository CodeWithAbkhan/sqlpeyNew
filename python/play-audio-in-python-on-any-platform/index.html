How to play audio in Python, especially on multiple platforms such as Mac, Linux, and Windows, has been a common question for many developers. Whether you’re working with short sound clips, background music, or notifications, Python offers multiple ways to handle audio playback. Let’s explore the top solutions that don’t necessarily rely on external software or third-party tools, as well as those that utilize libraries like pygame, playsound, and others.

1. Using Pygame for Cross-Platform Audio Playback

Pygame’s mixer module is one of the most reliable methods to play audio on any platform. While it’s an external library, Pygame ensures compatibility with various operating systems like Mac, Windows, and Linux.

import pygame

pygame.mixer.init()
pygame.mixer.music.load("file.mp3")
pygame.mixer.music.play()
  • Pygame supports MP3, WAV, and OGG files, providing easy integration for audio in your Python applications.
  • Check out pygame mixer documentation for more details.

2. Simpleaudio for Lightweight Playback

If you’re looking for a lightweight library without many dependencies, simpleaudio is a great option. It supports WAV files and is easy to use.

import simpleaudio as sa

wave_obj = sa.WaveObject.from_wave_file("path/to/file.wav")
play_obj = wave_obj.play()
play_obj.wait_done()
  • Install it with pip install simpleaudio.
  • Simpleaudio works well with uncompressed 16-bit PCM WAV files. Learn more on simpleaudio documentation .

3. Using Standard Library OSS for Linux/FreeBSD

For Linux and FreeBSD users, ossaudiodev can be used to play audio directly from Python. However, this method is platform-specific and limited to those systems.

import ossaudiodev

device = ossaudiodev.open("/dev/dsp", "w")
device.write(audio_data)
  • This method works for raw audio data, so you need to manage audio file conversion separately.
  • Another option for Windows is winsound , which can play simple sounds in WAV format.

4. Playing Audio with Sounddevice (Great for NumPy Arrays)

The sounddevice module is a flexible solution, ideal for users working with NumPy arrays and more advanced audio features. It works across multiple platforms and can even handle playback of large audio arrays.

import sounddevice as sd
import numpy as np

## Assuming 'myarray' is a NumPy array containing audio data
sd.play(myarray, 44100)
  • Install it with pip install sounddevice.
  • Learn more at sounddevice documentation .

5. Pydub and FFplay for File-Based Audio Playback

Pydub uses FFplay from the FFmpeg suite to play audio files, offering a simple method for handling many audio formats.

import subprocess

def play_audio(audio_file):
    subprocess.call(["ffplay", "-nodisp", "-autoexit", audio_file])
  • Pydub is great for more complex audio manipulations, but you will need to install FFmpeg separately.
  • Pydub documentation is available here .

6. Using AppKit on macOS for Native Playback

For macOS, the AppKit library allows you to play audio with minimal code. This is a native solution without the need for third-party libraries.

from AppKit import NSSound

sound = NSSound.alloc()
sound.initWithContentsOfFile_byReference_('/path/to/file.wav', True)
sound.play()
  • This works natively on macOS without extra dependencies.
  • Combine it with a sleep function to ensure the sound plays completely.

7. Cross-Platform Play with Playsound

playsound is a simple library that works on Windows, Mac, and Linux. It requires no external dependencies, making it an excellent choice for minimalistic use cases.

from playsound import playsound

playsound('path/to/audio.wav', block=True)
  • Install with pip install playsound.
  • Check out the playsound PyPI page for more information.

8. Soundfile and Soundcard for Advanced Playback

For advanced users, the soundfile and soundcard libraries offer superior audio handling, especially useful for working with professional-grade sound devices.

import soundfile as sf
import soundcard as sc

default_speaker = sc.default_speaker()
samples, samplerate = sf.read('bell.wav')
default_speaker.play(samples, samplerate=samplerate)
  • Install these libraries with pip install soundfile soundcard.
  • Learn more from their respective GitHub repositories: PySoundFile and SoundCard .

9. PreferredSoundPlayer for Platform-Specific Sound Handling

The preferredsoundplayer module intelligently chooses the best available player for the platform. It supports Linux, Windows, and macOS with minimal configuration.

from preferredsoundplayer import *

soundplay("audio.wav")
  • Install using pip install preferredsoundplayer.
  • Visit the GitHub project for more details.

10. Using VLC with Subprocess for MP3 Playback

For users who prefer using VLC, you can control it with the subprocess module to play MP3 or other audio files.

from subprocess import call

call(["cvlc", "--play-and-exit", "myNotificationTone.mp3"])
  • Ensure VLC is installed on your system.
  • This method works well on Linux and can also be used for automated sound playback.

FAQs on Top 10 Ways to Play Audio in Python

Q: How do I install the required libraries?

A: You can install most libraries using pip, for example:
pip install pygame simpleaudio sounddevice playsound

Q: Can I play MP3 files using these methods?

A: Yes, most methods like pygame, simpleaudio, and playsound support MP3 files, but ensure the correct file format is used based on the platform and library.

Q: Which method is best for playing audio across all platforms?

A: playsound and pygame are the most reliable methods for cross-platform audio playback.
