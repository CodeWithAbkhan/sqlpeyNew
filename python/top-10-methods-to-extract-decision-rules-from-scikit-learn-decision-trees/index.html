Can you extract the underlying decision rules (or ‘decision paths’) from a trained decision tree in Scikit-learn as a textual list? It’s a powerful capability, especially for interpreting machine learning models. Let’s discuss the top 10 methods you can employ to achieve this in Python using Scikit-learn.

What are Decision Rules?

Decision rules specify how decisions are made within a decision tree. For example, a rule might look like:

if A > 0.4 then if B < 0.2 then if C > 0.8 then class = 'X'

These rules provide insights into the logic of the model and how individual features contribute to predictions.

Method 1: Custom Function for Lineage Extraction

You can create a custom function to extract decision pathways from a decision tree model built with Scikit-learn. Here’s a practical implementation:

import pandas as pd
import numpy as np
from sklearn.tree import DecisionTreeClassifier

## Sample DataFrame
df = pd.DataFrame({'col1': [0, 1, 2, 3], 'col2': [3, 4, 5, 6], 'dv': [0, 1, 0, 1]})

## Fit the decision tree model
dt = DecisionTreeClassifier(max_depth=5, min_samples_leaf=1)
dt.fit(df.iloc[:, :2], df.dv)

## Function to extract lineage
def get_lineage(tree, feature_names):
    left = tree.tree_.children_left
    right = tree.tree_.children_right
    threshold = tree.tree_.threshold
    features = [feature_names[i] for i in tree.tree_.feature]
    idx = np.argwhere(left == -1)[:, 0]
    
    def recurse(left, right, child, lineage=None):
        if lineage is None:
            lineage = [child]
        if child in left:
            parent = np.where(left == child)[0].item()
            split = 'l'
        else:
            parent = np.where(right == child)[0].item()
            split = 'r'
        
        lineage.append((parent, split, threshold[parent], features[parent]))
        
        if parent == 0:
            lineage.reverse()
            return lineage
        else:
            return recurse(left, right, parent, lineage)

    for child in idx:
        for node in recurse(left, right, child):
            print(node)

get_lineage(dt, df.columns)

This implementation captures the nodes and enhances interpretability by navigating the tree structure to articulate decision paths.

Method 2: Using export_text

Starting from version 0.21 of Scikit-learn, you can leverage the built-in export_text method to retrieve rules effortlessly. This method streamlines the process as follows:

from sklearn.tree import export_text

## Exporting tree rules
tree_rules = export_text(dt, feature_names=df.columns.tolist())
print(tree_rules)

This approach provides a quick reference to the rules governing the decision-making process in the trained model.

Method 3: Pseudocode Representation

Another effective way to display tree rules is to modify existing solutions to output pseudocode. Here’s how you can do that:

def get_code(tree, feature_names):
    left = tree.tree_.children_left
    right = tree.tree_.children_right
    threshold = tree.tree_.threshold
    features = [feature_names[i] for i in tree.tree_.feature]
    value = tree.tree_.value

    def recurse(node):
        if threshold[node] != -2:
            print(f"if {features[node]} <= {threshold[node]}:")
            recurse(left[node])
            print("else:")
            recurse(right[node])
        else:
            print(f"return {value[node]}")
    
    recurse(0)

get_code(dt, df.columns)

This function provides a structured way to visualize decision-making criteria at each node.

Method 4: Decision Path Analysis

You can also extract decision paths for specific instances in your dataset using the decision_path method. Here’s an example:

sample_id = 0
node_indicator = dt.decision_path([df.iloc[sample_id, :2].values])

## Getting node indices for a specific sample
node_index = node_indicator.indices[node_indicator.indptr[sample_id]:node_indicator.indptr[sample_id + 1]]

for node_id in node_index:
    print(f"Node {node_id}: feature {df.columns[dt.tree_.feature[node_id]]} with threshold {dt.tree_.threshold[node_id]}")

This method provides insight into how each sample traversed the tree, elucidating the model’s decision-making process.

Method 5: Visual Representation with Graphviz

To visualize the decision rules, you can export the decision tree structure to a graphical format. Here’s how to do this using Graphviz:

from sklearn import tree
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(12, 8))
tree.plot_tree(dt, filled=True, feature_names=df.columns, class_names=["Class 0", "Class 1"])
plt.show()

This visual representation aids in understanding tree complexity and rule ownership.

Method 6: SQL-like Rules Extraction

You can modify the rules extraction to a SQL-compatible format, making the rules easy to integrate into databases:

def tree_to_sql_format(tree, feature_names):
    left = tree.tree_.children_left
    right = tree.tree_.children_right
    threshold = tree.tree_.threshold
    features = [feature_names[i] for i in tree.tree_.feature]

    def recurse(node):
        if left[node] != -1:
            print(f"IF {features[node]} <= {threshold[node]} THEN")
            recurse(left[node])
            print("ELSE")
            recurse(right[node])
        else:
            print(f"RETURN {value[node]}")

    recurse(0)

tree_to_sql_format(dt, df.columns)

This representation allows for easier incorporation into SQL databases for further analysis.

Method 7: Custom Formatting for Readability

If you want a more visually appealing string representation of rules, you can format the output to be more readable:

def pretty_print(tree, feature_names):
    left = tree.tree_.children_left
    right = tree.tree_.children_right
    threshold = tree.tree_.threshold
    features = [feature_names[i] for i in tree.tree_.feature]

    def recurse(node, depth):
        if left[node] != -1:
            print(f"{' ' * depth*2}IF {features[node]} <= {threshold[node]}:")
            recurse(left[node], depth + 1)
            print(f"{' ' * depth*2}ELSE:")
            recurse(right[node], depth + 1)
        else:
            print(f"{' ' * depth*2}RETURN {value[node]}")
    
    recurse(0, 0)

pretty_print(dt, df.columns)

This method enhances clarity, especially when dealing with complex trees.

Method 8: Integrating with AutoML Systems

from mljar import MLJAR

FAQs on Top 10 Methods to Extract Decision Rules from Scikit-learn Decision Trees

Q: How can I extract rules from a decision tree using Scikit-learn?

A: You can use various methods, including custom functions, the export_text method, and the decision_path attribute of the model to retrieve decision rules in a human-readable format.

Q: Is it possible to visualize decision rules?

A: Yes, using libraries like Graphviz, you can visualize the decision tree structure, which helps in understanding the decision paths and rules more intuitively.

Q: Can I use the extracted rules in SQL?

A: Absolutely! By formatting the extracted rules into a SQL-like syntax, you can use them for database queries and other integrations.
