“Python Sort by Multiple Keys: Advanced Techniques and Examples”

When working with Python, you’ll often encounter situations where a simple sort isn’t enough. You might need to sort a list of tuples or objects based on several criteria, potentially in different orders (ascending or descending). This post delves into various effective techniques for achieving complex sorting in Python.

Using Lambda Functions with Tuples

A straightforward way to sort by multiple elements is to use a lambda function that returns a tuple of the keys you want to sort by. The sorting will then be applied sequentially based on the order of elements in the returned tuple.

Solution 1: Lambda with Tuple Keys

This method allows you to specify multiple sorting criteria directly within the key argument of the sorted() function or the sort() method.

# Sample data: A list of tuples, each containing (name, age, score)
data_list = [
    ('Alice', 25, 90),
    ('Bob', 30, 85),
    ('Alice', 28, 95),
    ('Charlie', 25, 88)
]

# Sort by name (ascending) then by age (ascending)
sorted_by_name_age = sorted(data_list, key=lambda x: (x[0], x[1]))

print("Sorted by Name and Age (Ascending):")
for item in sorted_by_name_age:
    print(item)

# Output:
# ('Alice', 25, 90)
# ('Alice', 28, 95)
# ('Bob', 30, 85)
# ('Charlie', 25, 88)

Solution 1 Alternative: operator.itemgetter

For improved performance, especially with larger datasets, operator.itemgetter is often preferred over lambda for accessing elements by index. It avoids the overhead of creating a new Python function for each sort operation.

import operator

# Using the same data_list from above

# Sort by age (ascending) then by score (descending)
sorted_by_age_score = sorted(data_list, key=operator.itemgetter(1, 2), reverse=True) # Note: reverse applies to the entire tuple, for mixed order, see Solution 3

print("\nSorted by Age and Score (using itemgetter):")
for item in sorted_by_age_score:
    print(item)

# To sort in-place, use the .sort() method:
# data_list.sort(key=operator.itemgetter(1, 2))

Nested Sorting with sorted()

You can achieve more complex sorting, like sorting by one criterion in ascending order and another in descending order, by nesting sorted() calls. The inner sorted() call provides an intermediate sorted list that the outer sorted() call then sorts further.

Solution 2: Nested sorted() Calls

This approach is useful when you need distinct sorting orders for different keys.

# Sample data: List of tuples (name, value)
complex_list = [('Apple', 5), ('Banana', 2), ('Apple', 3), ('Orange', 5), ('Banana', 7)]

# Sort first alphabetically by name (ascending), then by value (descending)
# The inner sort handles the name, the outer sort handles the value in reverse
nested_sorted_list = sorted(sorted(complex_list, key=lambda x: x[0]), key=lambda x: x[1], reverse=True)

print("\nSorted with Nested sorted() (Name Asc, Value Desc):")
for item in nested_sorted_list:
    print(item)

# Output:
# ('Banana', 7)
# ('Orange', 5)
# ('Apple', 5)
# ('Apple', 3)
# ('Banana', 2)

Fine-Grained Control with Mixed Ascending/Descending Orders

When you need precise control over the sorting direction for each key, you can combine lambda with negation or manipulate the key function.

Solution 3: Negation for Mixed Orders

This technique allows you to sort by one key in ascending order and another in descending order within a single sorted() call by negating the numeric values of the descending key.

# Sample data: List of students with (name, grade, age)
students = [
    ("Alice", 95, 21),
    ("Bob", 95, 19),
    ("Charlie", 88, 22),
    ("David", 88, 20),
    ("Eve", 92, 21)
]

# Sort by grade (descending) and then by age (ascending)
# To make grade descending, we negate it. Age remains ascending.
sorted_students_mixed = sorted(students, key=lambda x: (-x[1], x[2]))

print("\nSorted by Grade (Desc) and Age (Asc):")
for student in sorted_students_mixed:
    print(f"Name: {student[0]}, Grade: {student[1]}, Age: {student[2]}")

# Output:
# Name: Alice, Grade: 95, Age: 21
# Name: Bob, Grade: 95, Age: 19
# Name: Eve, Grade: 92, Age: 21
# Name: Charlie, Grade: 88, Age: 22
# Name: David, Grade: 88, Age: 20

# sorted_students_asc = sorted(students, key=lambda x: (x[1], x[2]))

# To sort both descending:
# sorted_students_desc = sorted(students, key=lambda x: (-x[1], -x[2]))

Sorting Objects by Attributes

When dealing with lists of objects, you can use operator.attrgetter to access object attributes for sorting.

Solution 4: Sorting Objects with attrgetter

This method is particularly useful for sorting lists of custom class instances.

from operator import attrgetter
from collections import namedtuple

# Define a simple object structure
Product = namedtuple('Product', ['name', 'price', 'stock'])

products = [
    Product('Laptop', 1200, 10),
    Product('Keyboard', 75, 50),
    Product('Mouse', 25, 100),
    Product('Laptop', 1100, 5)
]

# Sort by price (descending) and then by stock (ascending)
# We use a helper function to generate the lambda key with attrgetter
def create_attr_sort_key(attrs):
    return lambda item: [getattr(item, attr) for attr in attrs]

# Sort by price descending, then stock ascending
sorted_products = sorted(products, key=lambda x: (-x.price, x.stock))

print("\nSorted Products by Price (Desc) and Stock (Asc):")
for product in sorted_products:
    print(product)

# Output:
# Product(name='Laptop', price=1200, stock=10)
# Product(name='Laptop', price=1100, stock=5)
# Product(name='Keyboard', price=75, stock=50)
# Product(name='Mouse', price=25, stock=100)

Converting Data Types for Sorting

Sometimes, the best approach involves converting your data into a format that naturally supports multi-key sorting, such as tuples.

Solution 5: Convert to Tuples for Sorting

If your data is in lists and you need to sort based on specific elements, converting each inner list to a tuple can simplify the process.

# Sample data: A list of lists
list_of_lists = [[12, 'tall', 'blue', 1], [2, 'short', 'red', 9], [4, 'tall', 'blue', 13]]

# Convert inner lists to tuples
list_of_tuples = [tuple(x) for x in list_of_lists]

# Sort by the second element (string), then by the third element (string)
sorted_tuples = sorted(list_of_tuples, key=lambda x: (x[1], x[2]))

print("\nSorted Tuples (by string elements):")
for item in sorted_tuples:
    print(item)

# Output:
# (4, 'tall', 'blue', 13)
# (12, 'tall', 'blue', 1)
# (2, 'short', 'red', 9)

Advanced Custom Sorting with Comparators

For highly complex sorting logic that goes beyond simple key extraction, you can implement a custom comparison function.

Solution 6: Custom Comparison Function

This method involves creating a function that compares two items and returns -1, 0, or 1 based on their relative order. Python’s functools.cmp_to_key is used to convert such a comparison function into a key function usable by sorted().

from functools import cmp_to_key

# Sample data: List of items with values
items_to_sort = [(4, 2.0), (4, 0.01), (4, 0.9), (1, 2.0), (1, 0.9)]

# Define a comparison function for sorting by first element ascending, then second descending
def custom_compare_func(item1, item2):
    # Compare first element (ascending)
    if item1[0] < item2[0]:
        return -1
    elif item1[0] > item2[0]:
        return 1
    else:
        # If first elements are equal, compare second element (descending)
        if item1[1] > item2[1]: # Note: greater than for descending
            return -1
        elif item1[1] < item2[1]:
            return 1
        else:
            return 0

# Use cmp_to_key to convert the comparison function into a key function
sorted_items_custom = sorted(items_to_sort, key=cmp_to_key(custom_compare_func))

print("\nSorted with Custom Comparison Function:")
for item in sorted_items_custom:
    print(item)

# Output:
# (1, 2.0)
# (1, 0.9)
# (4, 2.0)
# (4, 0.9)
# (4, 0.01)

Using operator.attrgetter with Multiple Keys and Directions

The operator module, specifically attrgetter and itemgetter, combined with functools.cmp_to_key, can provide a robust solution for complex sorting needs.

Solution 8: multikeysort Function

This is a flexible utility function for sorting lists of objects or dictionaries by multiple keys, allowing specification of ascending or descending order for each key.

from operator import attrgetter
from functools import cmp_to_key
from collections import namedtuple

def multikeysort(items, *columns, attrs=True) -> list:
    """
    Perform a multiple column sort on a list of dictionaries or objects.
    Args:
        items (list): List of dictionaries or objects to be sorted.
        *columns: Columns to sort by, optionally preceded by a '-' for descending order.
        attrs (bool): True if items are objects, False if items are dictionaries.

    Returns:
        list: Sorted list of items.
    """
    getter = attrgetter if attrs else itemgetter

    def get_comparers():
        comparers = []
        for col in columns:
            col = col.strip()
            if col.startswith('-'):  # Descending order
                key_func = getter(col[1:])
                order = -1
            else:  # Ascending order
                key_func = getter(col)
                order = 1
            comparers.append((key_func, order))
        return comparers

    comparers = get_comparers()

    def custom_compare(left, right):
        """Custom comparison function to handle multiple keys"""
        for fn, reverse_order in comparers:
            val_left = fn(left)
            val_right = fn(right)
            
            if val_left < val_right:
                result = -1
            elif val_left > val_right:
                result = 1
            else:
                result = 0
                
            if result != 0:
                return result * reverse_order
        return 0

    return sorted(items, key=cmp_to_key(custom_compare))

# Test with namedtuples (objects)
Customer = namedtuple('Customer', ['id', 'opens', 'clicks'])
customers = [
    Customer(id=1, opens=4, clicks=8),
    Customer(id=2, opens=4, clicks=7),
    Customer(id=2, opens=5, clicks=1)
]

# Sort by 'opens' descending, then 'clicks' ascending
sorted_customers = multikeysort(customers, '-opens', 'clicks', attrs=True)

print("\nSorted Customers using multikeysort (opens DESC, clicks ASC):")
for cust in sorted_customers:
    print(cust)

# Output:
# Customer(id=2, opens=5, clicks=1)
# Customer(id=2, opens=4, clicks=7)
# Customer(id=1, opens=4, clicks=8)

# Test with dictionaries
dict_list = [
    {'name': 'Zoe', 'score': 90, 'level': 3},
    {'name': 'Adam', 'score': 90, 'level': 2},
    {'name': 'Zoe', 'score': 95, 'level': 1}
]

# Sort by 'score' descending, then 'level' ascending
sorted_dicts = multikeysort(dict_list, '-score', 'level', attrs=False)

print("\nSorted Dictionaries using multikeysort (score DESC, level ASC):")
for d in sorted_dicts:
    print(d)

# Output:
# {'name': 'Zoe', 'score': 95, 'level': 1}
# {'name': 'Adam', 'score': 90, 'level': 2}
# {'name': 'Zoe', 'score': 90, 'level': 3}

FAQs on Python Sort by Multiple Keys

Q: How to sort a list of tuples by two keys in Python

ANS: You can sort a list of tuples by two keys using a lambda function that returns a tuple of the keys you want to sort by: sorted(list_of_tuples, key=lambda x: (x[key1_index], x[key2_index])). For better performance, operator.itemgetter can be used: sorted(list_of_tuples, key=operator.itemgetter(key1_index, key2_index)).

Q: How to sort by ascending and descending order for different keys

ANS: To sort by different orders for different keys, you can use negation for numeric keys when descending order is needed with a lambda function, like key=lambda x: (x[key1_index], -x[key2_index]) for key1 ascending and key2 descending. Alternatively, nested sorted calls or a custom comparison function with cmp_to_key can be employed for more complex scenarios.

Q: What is the difference between sorted() and list.sort() in Python

ANS: The sorted() function returns a new sorted list, leaving the original list unchanged. The list.sort() method sorts the list in-place, modifying the original list and returning None.

Q: Can I sort a list of dictionaries by multiple keys

ANS: Yes, you can sort a list of dictionaries by multiple keys using a lambda function with operator.itemgetter or by defining a custom comparison function. For instance, sorted(list_of_dicts, key=lambda item: (item['key1'], item['key2'])). The multikeysort utility function in Solution 8 can also handle this efficiently.

Q: How to sort objects by attributes in Python

ANS: You can sort a list of objects by their attributes using operator.attrgetter as the key for sorted() or list.sort(). For example, sorted(list_of_objects, key=operator.attrgetter('attribute_name')). For multi-attribute sorting, you can pass multiple attribute names to attrgetter or use a lambda that calls attrgetter.
