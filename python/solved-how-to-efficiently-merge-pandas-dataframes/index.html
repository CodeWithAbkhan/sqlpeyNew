Initial Setup for Merging Operations

Let’s begin by setting up two example Pandas DataFrames that we will use throughout this section. These data structures are ideal for demonstrating the various join methods. For more on creating DataFrames, explore our guide on what is Pandas .

import pandas as pd
import numpy as np

# Ensure reproducibility of random numbers
np.random.seed(42)

# Create the first DataFrame, 'source_df'
source_df = pd.DataFrame({'main_key': ['Alpha', 'Bravo', 'Charlie', 'Delta'],
                          'primary_val': np.random.randn(4)})

# Create the second DataFrame, 'target_df'
target_df = pd.DataFrame({'main_key': ['Bravo', 'Delta', 'Echo', 'Foxtrot'],
                          'secondary_val': np.random.randn(4)})

print("Source DataFrame:")
print(source_df)
print("\nTarget DataFrame:")
print(target_df)

Output for source_df:

  main_key  primary_val
0    Alpha     0.496714
1    Bravo    -0.138264
2  Charlie     0.647689
3    Delta     1.523030

Output for target_df:

  main_key  secondary_val
0    Bravo       0.378163
1    Delta       0.860601
2     Echo       0.126412
3  Foxtrot      -0.965066

For simplicity, the key column main_key has the same name in both DataFrames initially.

Core Join Types with pd.merge

The pd.merge() function is your primary tool for combining DataFrames based on common columns or indices. It offers different “how” arguments to specify the join type, much like SQL.

To aid in conceptualizing these joins, consider that:

  • Blue marks rows included in the merge result.
  • Red highlights rows excluded from the result.
  • Green indicates where missing values are filled with NaN (Not a Number).

Inner Join

An INNER JOIN returns only the rows where there is a match in both DataFrames based on the specified key(s).

To perform an INNER JOIN, invoke merge() on the left DataFrame, providing the right DataFrame and the join key as arguments. The how='inner' argument is the default, so it can often be omitted.

# Inner Join example
result_inner = source_df.merge(target_df, on='main_key', how='inner')
print("\nInner Join Result:")
print(result_inner)

Resulting Output:

  main_key  primary_val  secondary_val
0    Bravo    -0.138264       0.378163
1    Delta     1.523030       0.860601

This combines rows where main_key values (“Bravo” and “Delta”) exist in both source_df and target_df.

Left Outer Join (Left Join)

A LEFT OUTER JOIN (or LEFT JOIN) includes all rows from the left DataFrame and matching rows from the right DataFrame. If there’s no match in the right DataFrame, NaN values are inserted for its columns.

Specify how='left' to achieve this.

# Left Join example
result_left = source_df.merge(target_df, on='main_key', how='left')
print("\nLeft Join Result:")
print(result_left)

Resulting Output:

  main_key  primary_val  secondary_val
0    Alpha     0.496714            NaN
1    Bravo    -0.138264       0.378163
2  Charlie     0.647689            NaN
3    Delta     1.523030       0.860601

Notice that “Alpha” and “Charlie” from source_df are present, with NaN in the secondary_val column as they have no match in target_df.

Right Outer Join (Right Join)

Conversely, a RIGHT OUTER JOIN (or RIGHT JOIN) includes all rows from the right DataFrame and matching rows from the left DataFrame. NaN values appear for missing matches from the left.

This is performed using how='right'.

# Right Join example
result_right = source_df.merge(target_df, on='main_key', how='right')
print("\nRight Join Result:")
print(result_right)

Resulting Output:

  main_key  primary_val  secondary_val
0    Bravo    -0.138264       0.378163
1    Delta     1.523030       0.860601
2     Echo          NaN       0.126412
3  Foxtrot          NaN      -0.965066

Here, “Echo” and “Foxtrot” from target_df are kept, with NaN for primary_val as they lack matches in source_df.

Full Outer Join

A FULL OUTER JOIN includes all rows from both DataFrames. NaN values are inserted wherever there’s no corresponding match in either DataFrame.

Use how='outer' for this operation.

# Outer Join example
result_outer = source_df.merge(target_df, on='main_key', how='outer')
print("\nOuter Join Result:")
print(result_outer)

Resulting Output:

  main_key  primary_val  secondary_val
0    Alpha     0.496714            NaN
1    Bravo    -0.138264       0.378163
2  Charlie     0.647689            NaN
3    Delta     1.523030       0.860601
4     Echo          NaN       0.126412
5  Foxtrot          NaN      -0.965066

This result contains all unique main_key values from both DataFrames, with NaNs where data is missing.

Specialized Exclusion Joins

Sometimes you need to find rows that exist in one DataFrame but not in another. These are often called LEFT-EXCLUDING JOIN or ANTI-JOIN in SQL. Pandas supports this through a two-step process using the indicator argument.

The indicator=True option in merge() adds a special _merge column to the output, indicating the source of each row: 'left_only', 'right_only', or 'both'. This column can then be used for filtering.

Left-Excluding Join

To get rows present in the left DataFrame but not the right:

# Left-Excluding Join (conceptual diagram)
# Visual: Only blue on the left, red on the right
result_left_exclude = (source_df.merge(target_df, on='main_key', how='left', indicator=True)
                         .query('_merge == "left_only"')
                         .drop('_merge', axis=1)) # Remove the indicator column

print("\nLeft-Excluding Join Result:")
print(result_left_exclude)

Resulting Output:

  main_key  primary_val  secondary_val
0    Alpha     0.496714            NaN
2  Charlie     0.647689            NaN

This shows records only from source_df that do not have a match in target_df.

Right-Excluding Join

Similarly, for rows present in the right DataFrame but not the left:

# Right-Excluding Join (conceptual diagram)
# Visual: Only blue on the right, red on the left
result_right_exclude = (source_df.merge(target_df, on='main_key', how='right', indicator=True)
                          .query('_merge == "right_only"')
                          .drop('_merge', axis=1))

print("\nRight-Excluding Join Result:")
print(result_right_exclude)

Resulting Output:

  main_key  primary_val  secondary_val
2     Echo          NaN       0.126412
3  Foxtrot          NaN      -0.965066

These are records exclusively from target_df.

Full-Excluding Join (Anti-Join)

To find rows that are present in either DataFrame but not in both (i.e., exclusive to one side):

# Full-Excluding Join / Anti-Join (conceptual diagram)
# Visual: Blue on both left and right, but not in the overlapping center, red in the center
result_full_exclude = (source_df.merge(target_df, on='main_key', how='outer', indicator=True)
                         .query('_merge != "both"')
                         .drop('_merge', axis=1))

print("\nFull-Excluding Join (Anti-Join) Result:")
print(result_full_exclude)

Resulting Output:

  main_key  primary_val  secondary_val
0    Alpha     0.496714            NaN
2  Charlie     0.647689            NaN
4     Echo          NaN       0.126412
5  Foxtrot          NaN      -0.965066

This result includes records unique to source_df and records unique to target_df.

Merging with Dissimilar Key Column Names

If your key columns in the DataFrames have different names, you must specify left_on and right_on arguments instead of on.

# Renaming keys for demonstration
source_renamed = source_df.rename(columns={'main_key': 'left_key_id'})
target_renamed = target_df.rename(columns={'main_key': 'right_key_id'})

print("\nSource DataFrame (Renamed):")
print(source_renamed)
print("\nTarget DataFrame (Renamed):")
print(target_renamed)

# Merge with different key names
result_diff_keys = source_renamed.merge(target_renamed,
                                        left_on='left_key_id',
                                        right_on='right_key_id',
                                        how='inner')
print("\nMerge with Different Key Names Result:")
print(result_diff_keys)

Resulting Output:

Source DataFrame (Renamed):
  left_key_id  primary_val
0       Alpha     0.496714
1       Bravo    -0.138264
2     Charlie     0.647689
3       Delta     1.523030

Target DataFrame (Renamed):
  right_key_id  secondary_val
0        Bravo       0.378163
1        Delta       0.860601
2         Echo       0.126412
3      Foxtrot      -0.965066

Merge with Different Key Names Result:
  left_key_id  primary_val right_key_id  secondary_val
0       Bravo    -0.138264        Bravo       0.378163
1       Delta     1.523030        Delta       0.860601

Both key columns (left_key_id and right_key_id) are present in the output.

Avoiding Duplicate Key Columns in Output

If you only want one of the key columns (e.g., left_key_id or right_key_id) to appear in the merged output when keys have different names, you can pre-process by setting one of the DataFrames’ indexes before merging.

# Set index on the left DataFrame for a cleaner output key
source_indexed = source_renamed.set_index('left_key_id')

result_single_key = source_indexed.merge(target_renamed,
                                        left_index=True,
                                        right_on='right_key_id')

print("\nMerge with Single Key Column Output:")
print(result_single_key)

Resulting Output:

             primary_val right_key_id  secondary_val
0              -0.138264        Bravo       0.378163
1               1.523030        Delta       0.860601

Here, only right_key_id (from target_renamed) remains as the join key column in the output, while the left_key_id served as the index during the merge. The choice of which key column to keep depends on which DataFrame’s index you set.

Merging Specific Columns

Sometimes you only need to bring in a subset of columns from one DataFrame during a merge. This can be achieved by subsetting columns before the merge operation.

Consider target_augmented_df with an additional column:

target_augmented_df = target_df.assign(additional_info=np.arange(len(target_df)))
print("\nTarget Augmented DataFrame:")
print(target_augmented_df)

Output:

  main_key  secondary_val  additional_info
0    Bravo       0.378163                0
1    Delta       0.860601                1
2     Echo       0.126412                2
3  Foxtrot      -0.965066                3

If you only need additional_info merged into source_df:

# Merge only 'additional_info' column
result_subset_merge = source_df.merge(target_augmented_df[['main_key', 'additional_info']], on='main_key')
print("\nMerge with Subset of Columns:")
print(result_subset_merge)

Resulting Output:

  main_key  primary_val  additional_info
0    Bravo    -0.138264                0
1    Delta     1.523030                1

Performance Alternative for Left Joins: map()

For left outer joins where you’re bringing in a single column, DataFrame.map() can offer better performance than merge(), especially for large datasets.

# Using map() for Left Outer Join (single column)
source_df_mapped = source_df.assign(
    new_info=source_df['main_key'].map(target_augmented_df.set_index('main_key')['additional_info'])
)
print("\nLeft Join via map():")
print(source_df_mapped)

# Compare with merge() for the same result
result_subset_left_merge = source_df.merge(target_augmented_df[['main_key', 'additional_info']],
                                           on='main_key',
                                           how='left')
print("\nLeft Join via merge() (for comparison):")
print(result_subset_left_merge)

Output (both methods yield same result):

Left Join via map():
  main_key  primary_val  new_info
0    Alpha     0.496714       NaN
1    Bravo    -0.138264       0.0
2  Charlie     0.647689       NaN
3    Delta     1.523030       1.0

Left Join via merge() (for comparison):
  main_key  primary_val  additional_info
0    Alpha     0.496714              NaN
1    Bravo    -0.138264              0.0
2  Charlie     0.647689              NaN
3    Delta     1.523030              1.0

To join DataFrames based on a combination of columns, pass a list of column names to the on argument (or left_on/right_on if names differ).

Conceptual example:

Other Valuable Pandas Join Functions

Beyond pd.merge(), Pandas offers specialized functions for specific joining needs:

  • DataFrame.update(): Modifies a DataFrame in place with non-NaN values from another DataFrame. Useful for updating records.
  • DataFrame.combine_first(): Combines two DataFrames, prioritizing non-NaN values from the first DataFrame.
  • pd.merge_ordered(): For ordered merges, especially useful with time-series or sequential data.
  • pd.merge_asof(): Performs approximate joins, useful for matching nearest values in time series or similar contexts.

For a deeper dive into these and other powerful Pandas features, consider exploring the official Pandas documentation .

Combining DataFrames with pd.concat

While pd.merge() excels at relational joins, pd.concat() is designed for stacking or appending DataFrames along an axis. It’s ideal for combining DataFrames that share the same columns (or rows if stacking horizontally).

# Setup for concat example
data_2018 = {
    'Year': [2018, 2018, 2018], 'Month': [1, 1, 1], 'Day': [1, 1, 1],
    'Hour': [1, 2, 3], 'Price': [6.74, 4.74, 3.66]
}
price_2018_df = pd.DataFrame(data_2018)

data_2019 = {
    'Year': [2019, 2019, 2019], 'Month': [1, 1, 1], 'Day': [1, 1, 1],
    'Hour': [1, 2, 3], 'Price': [66.88, 66.88, 66.00]
}
price_2019_df = pd.DataFrame(data_2019)

print("\nPrice 2018 DataFrame:")
print(price_2018_df)
print("\nPrice 2019 DataFrame:")
print(price_2019_df)

# Concatenate vertically (default axis=0)
combined_prices_df = pd.concat([price_2018_df, price_2019_df])
print("\nCombined Prices DataFrame (pd.concat):")
print(combined_prices_df)

Resulting Output:

This stacks price_2019_df below price_2018_df. The axis=1 argument can be used to concatenate horizontally (joining on indices).

Index-Based Joins

Merging can also occur directly on the DataFrame indices, or a mix of an index from one DataFrame and a column from another.

Index-to-Index Joins

This is useful when your unique identifier is the DataFrame index.

# Setup for index-based joins
idx_left_df = pd.DataFrame(data={'data_alpha': np.random.randn(4)},
                           index=['KeyX', 'KeyY', 'KeyZ', 'KeyW'])
idx_right_df = pd.DataFrame(data={'data_beta': np.random.randn(4)},
                            index=['KeyY', 'KeyW', 'KeyP', 'KeyQ'])
idx_left_df.index.name = idx_right_df.index.name = 'index_key'

print("\nIndex-based Left DataFrame:")
print(idx_left_df)
print("\nIndex-based Right DataFrame:")
print(idx_right_df)

# Inner join on index
result_idx_merge = idx_left_df.merge(idx_right_df, left_index=True, right_index=True, how='inner')
print("\nIndex-to-Index Merge Result:")
print(result_idx_merge)

Resulting Output:

Index-based Left DataFrame:
          data_alpha
index_key           
KeyX       -1.509059
KeyY        0.260538
KeyZ       -1.401872
KeyW       -0.100908

Index-based Right DataFrame:
          data_beta
index_key          
KeyY      -1.396974
KeyW       0.999732
KeyP       1.159516
KeyQ       0.040409

Index-to-Index Merge Result:
          data_alpha  data_beta
index_key                      
KeyY        0.260538  -1.396974
KeyW       -0.100908   0.999732

Other join types (left, right, outer) follow the same left_index=True, right_index=True pattern.

Alternative: DataFrame.join()

The DataFrame.join() method defaults to joining on the index. It performs a LEFT OUTER JOIN by default. When columns overlap, you’ll need lsuffix and rsuffix.

# Using .join() for index-to-index inner join
result_idx_join = idx_left_df.join(idx_right_df, how='inner', lsuffix='_left', rsuffix='_right')
print("\nIndex-to-Index Join Result (using .join()):")
print(result_idx_join)

Resulting Output:

          data_alpha  data_beta
index_key                      
KeyY        0.260538  -1.396974
KeyW       -0.100908   0.999732

Alternative: pd.concat() for Index Joins

pd.concat() can also perform index-based joins, particularly for horizontal combinations. It defaults to a FULL OUTER JOIN (join='outer').

# Using pd.concat for index-based inner join
result_idx_concat = pd.concat([idx_left_df, idx_right_df], axis=1, join='inner')
print("\nIndex-to-Index Concat Result (using pd.concat()):")
print(result_idx_concat)

Resulting Output:

          data_alpha  data_beta
index_key                      
KeyY        0.260538  -1.396974
KeyW       -0.100908   0.999732

Index-to-Column Joins

To merge a DataFrame’s index with a column of another DataFrame, combine left_index=True with right_on='column_name'. Note that DataFrame.join() and pd.concat() are not designed for mixed index-to-column merges; you would typically need to use set_index() as a pre-step.

# Setup for index-to-column join
target_col_key = idx_right_df.reset_index().rename(columns={'index_key': 'lookup_col_key'})
print("\nTarget DataFrame for Index-to-Column Join:")
print(target_col_key)

result_idx_col_merge = idx_left_df.merge(target_col_key,
                                         left_index=True,
                                         right_on='lookup_col_key')
print("\nIndex-to-Column Merge Result:")
print(result_idx_col_key_merge)

Resulting Output:

Target DataFrame for Index-to-Column Join:
  lookup_col_key  data_beta
0           KeyY  -1.396974
1           KeyW   0.999732
2           KeyP   1.159516
3           KeyQ   0.040409

Index-to-Column Merge Result:
          data_alpha lookup_col_key  data_beta
0           0.260538           KeyY  -1.396974
1          -0.100908           KeyW   0.999732

Utilizing Named Indexes (Pandas >= 0.23)

If your DataFrame indices have names (set via df.index.name = 'name'), you can directly reference these names in pd.merge() using on (or left_on/right_on). This simplifies syntax and makes code more readable.

# Merge using named indexes
result_named_idx_merge = idx_left_df.merge(idx_right_df, on='index_key')
print("\nMerge Using Named Index:")
print(result_named_idx_merge)

Resulting Output:

          data_alpha  data_beta
index_key                      
KeyY        0.260538  -1.396974
KeyW       -0.100908   0.999732

For index-to-column joins with named indexes, use left_on with the index name:

result_named_idx_col_merge = idx_left_df.merge(target_col_key,
                                               left_on='index_key',
                                               right_on='lookup_col_key')
print("\nIndex-to-Column Merge Using Named Index:")
print(result_named_idx_col_merge)

Resulting Output:

          data_alpha lookup_col_key  data_beta
0           0.260538           KeyY  -1.396974
1          -0.100908           KeyW   0.999732

Generalizing Merges to Multiple DataFrames

Combining more than two DataFrames is a common task. While chaining df1.merge(df2).merge(df3) works, it can become unwieldy for many DataFrames.

Multiway Merge on Unique Keys with pd.concat

When your join keys (columns or indices) are guaranteed to be unique across DataFrames, pd.concat() is highly efficient for multi-way merges. pd.concat() joins DataFrames on their indices.

Let’s set up some DataFrames for a multi-way merge example:

np.random.seed(0)
df_data_A = pd.DataFrame({'common_id': ['itemA', 'itemB', 'itemC', 'itemD'], 'value_from_A': np.random.randn(4)})
df_data_B = pd.DataFrame({'common_id': ['itemB', 'itemD', 'itemE', 'itemF'], 'value_from_B': np.random.randn(4)})
df_data_C = pd.DataFrame({'common_id': ['itemD', 'itemE', 'itemJ', 'itemC'], 'value_from_C': np.ones(4)})
list_of_dfs = [df_data_A, df_data_B, df_data_C]

# If keys are columns, set index before concatenating
multi_concat_result = pd.concat(
    [df.set_index('common_id') for df in list_of_dfs], axis=1, join='inner'
).reset_index()

print("\nMulti-way Concatenation (Unique Keys):")
print(multi_concat_result)

Resulting Output:

  common_id  value_from_A  value_from_B  value_from_C
0     itemD      2.240893     -0.977278           1.0

Omitting join='inner' would perform a FULL OUTER JOIN. Note that pd.concat cannot directly specify LEFT or RIGHT outer joins for multi-way merging.

Multiway Merge on Keys with Duplicates using DataFrame.join

pd.concat() has limitations when dealing with duplicate keys. In such cases, DataFrame.join() (which uses merge internally) can handle non-unique keys effectively. Remember that join operates on DataFrame indices.

# Example with non-unique key
df_data_A_dupe = pd.DataFrame({'common_id': ['itemA', 'itemB', 'itemC', 'itemD', 'itemD'],
                               'value_from_A_dupe': np.random.randn(5)})

# Join on `common_id` column. Set as the index first.
# For inner join, specify how='inner'. For left join, omit 'how'.
multi_join_result = df_data_A_dupe.set_index('common_id').join(
    [df_data_B.set_index('common_id'), df_data_C.set_index('common_id')],
    how='inner'
).reset_index()

print("\nMulti-way Join (Non-Unique Keys):")
print(multi_join_result)

Resulting Output:

  common_id  value_from_A_dupe  value_from_B  value_from_C
0     itemD           1.454274     -0.977278           1.0
1     itemD           0.761038     -0.977278           1.0

This demonstrates how join preserves rows with duplicate keys, unlike concat which would raise a ValueError.

Advanced Conditional Joins (Inequality Joins)

Pandas’ built-in merge() function primarily supports equality-based joins. For inequality joins (e.g., A < B, C >= D), a powerful external library named pyjanitor offers the conditional_join function.

First, ensure pyjanitor is installed (pip install pyjanitor).

# Ensure pyjanitor is installed: pip install pyjanitor
import janitor

# Re-using source_df and target_df from earlier setup for clear comparison
# source_df:
#   main_key  primary_val
# 0    Alpha     0.496714
# 1    Bravo    -0.138264
# 2  Charlie     0.647689
# 3    Delta     1.523030

# target_df:
#   main_key  secondary_val
# 0    Bravo       0.378163
# 1    Delta       0.860601
# 2     Echo       0.126412
# 3  Foxtrot      -0.965066

# Example: Join where primary_val > secondary_val
result_gt = source_df.conditional_join(target_df, ('primary_val', 'secondary_val', '>'))
print("\nConditional Join (primary_val > secondary_val):")
print(result_gt)

Resulting Output:

Conditional Join (primary_val > secondary_val):
      left                          right
   main_key  primary_val   main_key  secondary_val
0    Alpha     0.496714       Echo       0.126412
1    Alpha     0.496714    Foxtrot      -0.965066
2  Charlie     0.647689       Echo       0.126412
3  Charlie     0.647689    Foxtrot      -0.965066
4    Delta     1.523030       Bravo       0.378163
5    Delta     1.523030       Delta       0.860601
6    Delta     1.523030       Echo       0.126412
7    Delta     1.523030    Foxtrot      -0.965066

The conditional_join function takes tuples of (left_column, right_column, operator). Supported operators include >, <, >=, <=, !=, ==. It returns a MultiIndex column output if column names overlap.

pyjanitor.conditional_join is significantly more performant than a naive cross join followed by filtering, especially for large datasets. It also offers a use_numba=True option for even greater speedups if Numba is installed.

Cross Join (Cartesian Product)

A CROSS JOIN creates a Cartesian product of two DataFrames, returning all possible combinations of rows from both. This is useful when you need to pair every row from one DataFrame with every row from another, even if they share no common keys.

Pandas merge() gained a how='cross' option in version 1.2.0. For older versions, a common trick is to create a dummy column with a constant value in both DataFrames, merge on this dummy column, and then drop it.

# Setup for cross join
df_items = pd.DataFrame({'product_name': ['Laptop', 'Mouse']})
df_colors = pd.DataFrame({'color_option': ['Red', 'Blue', 'Green']})

print("\nProducts DataFrame:")
print(df_items)
print("\nColors DataFrame:")
print(df_colors)

# Perform a cross join using the dummy column trick
result_cross_join = pd.merge(df_items.assign(temp_key=1),
                             df_colors.assign(temp_key=1),
                             on='temp_key').drop('temp_key', axis=1)
print("\nCross Join Result:")
print(result_cross_join)

Resulting Output:

  product_name
0       Laptop
1        Mouse

Colors DataFrame:
  color_option
0          Red
1         Blue
2        Green

Cross Join Result:
  product_name color_option
0       Laptop          Red
1       Laptop         Blue
2       Laptop        Green
3        Mouse          Red
4        Mouse         Blue
5        Mouse        Green

This effectively pairs each product with every color option.

FAQs on Solved How to Efficiently Merge Pandas DataFrames

Q: What is the main difference between pdmerge and pdconcat

ANS: pd.merge combines DataFrames based on common values in specific columns or indices, performing SQL-style joins (inner, left, right, outer). pd.concat stacks or appends DataFrames along an axis (rows or columns), useful for combining DataFrames that logically extend each other.

Q: How can I perform a left excluding join in Pandas

ANS: A left-excluding join returns rows from the left DataFrame that do not have matches in the right DataFrame. You can achieve this by performing a left merge with indicator=True, then filtering the result where the _merge column is left_only, and finally dropping the _merge column.

Q: Can Pandas merge on multiple columns

ANS: Yes you can. To merge on multiple columns, pass a list of column names to the on argument in pd.merge(). If the column names differ between DataFrames, use left_on and right_on with lists of respective column names.

Q: What is a cross join in Pandas

ANS: A cross join, also known as a Cartesian product, combines every row from one DataFrame with every row from another DataFrame. In Pandas, you can achieve this with how='cross' in pd.merge() (Pandas 120 and newer) or by creating a temporary common column in both DataFrames and merging on it.

Q: How do I merge DataFrames on their indexes

ANS: To merge DataFrames on their indexes, use left_index=True and right_index=True with pd.merge(). Alternatively, you can use DataFrame.join() which defaults to index-based joining, or pd.concat() with axis=1 for horizontal concatenation on indexes.

Q: Is it possible to perform inequality joins in Pandas

ANS: While pd.merge() primarily handles equality joins, inequality joins (e.g., greater than, less than) can be performed using the conditional_join function from the pyjanitor library. This function is designed for efficient non-equi joins.
