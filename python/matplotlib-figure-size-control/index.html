“How to Control Matplotlib Figure Size in Python”

When generating visualizations with Matplotlib in Python, managing the figure’s dimensions is crucial for clarity and presentation. Whether you’re creating a new plot or modifying an existing one, several effective techniques allow you to set the figure size accurately. This exploration delves into these methods, providing practical code snippets and explanations.

Setting Figure Size During Creation

The most straightforward way to define a figure’s dimensions is at the point of its creation. This involves specifying the figsize parameter, which accepts a tuple representing the width and height in inches.

Using matplotlib.pyplot.figure:

This function creates a new figure and allows you to set its size directly.

import matplotlib.pyplot as plt

# Create a figure with a size of 8 inches wide and 6 inches tall
fig = plt.figure(figsize=(8, 6))
plt.plot([1, 2, 3, 4]) # Example plot
plt.title("Figure with 8x6 Inches Size")
plt.show()

The figsize=(1,1) example would result in a 1-inch by 1-inch image. The actual pixel dimensions would depend on the DPI (dots per inch) setting.

Using matplotlib.pyplot.subplots:

This is a common way to create a figure and one or more subplots simultaneously. You can pass figsize to this function as well.

import matplotlib.pyplot as plt
import numpy as np

# Create a figure with a size of 10 inches by 10 inches
fig, ax = plt.subplots(figsize=(10, 10))

x = np.linspace(0, 10, 100)
y = np.sin(x)

ax.plot(x, y)
ax.set_title("10x10 Inch Figure with a Sine Wave")
plt.show()

Adjusting the Size of an Existing Figure

If you already have a figure object, you can modify its size using its methods.

Using figure.set_size_inches():

This method allows you to change the figure’s size after it has been created.

import matplotlib.pyplot as plt
import numpy as np

# Create a default-sized figure
fig, ax = plt.subplots()
x = np.arange(0, 2 * np.pi, 0.1)
y = np.sin(x)
ax.plot(x, y)

# Get the current size
default_size = fig.get_size_inches()
print(f"Default figure size: {default_size} inches")

# Set the new size to 18.5 inches wide and 10.5 inches tall
fig.set_size_inches(18.5, 10.5)
print(f"New figure size: {fig.get_size_inches()} inches")

# To update an existing GUI window, use forward=True
# fig.set_size_inches(18.5, 10.5, forward=True)

# You can also adjust the DPI
# fig.set_dpi(100)

fig.savefig('adjusted_plot.png', dpi=100)
plt.show()

Using figure.set_figwidth() and figure.set_figheight() (Matplotlib 2.2.0+):

These methods provide a way to adjust only the width or height independently. For versions older than Matplotlib 1.5.0, the forward parameter might not be supported.

# Assuming 'fig' is an existing figure object
# fig.set_figwidth(12) # Sets width to 12 inches
# fig.set_figheight(8) # Sets height to 8 inches

Controlling Figure Size via rcParams

For setting default figure sizes across multiple plots or within specific environments like IPython Notebooks, plt.rcParams is very useful.

Setting Global Figure Size:

You can modify the figure.figsize parameter in plt.rcParams.

import matplotlib.pyplot as plt

# Set the default figure size for subsequent plots
plt.rcParams["figure.figsize"] = (20, 3) # 20 inches wide, 3 inches tall

# Create a plot with the new default size
plt.plot([1, 2, 3, 4, 5])
plt.title("Plot with Default 20x3 Inch Size")
plt.show()

# Reset to default size if needed
# plt.rcParams["figure.figsize"] = plt.rcParamsDefault["figure.figsize"]

Note: It’s often recommended not to place plt.rcParams modifications in the same cell as import statements when using IPython Notebooks.

Converting Centimeters to Inches:

The figsize tuple expects values in inches. To set dimensions in centimeters, divide the centimeter values by 2.54.

Utilizing pylab (Legacy Approach)

While less recommended in modern Matplotlib usage, the pylab module offers an alternative way to set default figure sizes.

from pylab import rcParams

# Set figure size (width, height) in inches
rcParams['figure.figsize'] = 5, 10

# This sets the default for figures created subsequently.
# plt.plot(...) # Will use the 5x10 inch size

It’s important to note that the use of the pylab module is generally discouraged in favor of matplotlib.pyplot.

Adjusting Size in Pandas Plotting

When using Pandas DataFrames for plotting, you can directly specify the figure size.

import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Create a sample DataFrame
data = {'col1': np.random.rand(10), 'col2': np.random.rand(10)}
df = pd.DataFrame(data)

# Plotting with a specific figsize
df['col1'].plot(figsize=(10, 5), title="Pandas Plot with Specific Size")
plt.show()

# Using an existing figure or axes
fig, ax = plt.subplots(figsize=(10, 5))
df['col2'].plot(ax=ax, title="Pandas Plot on Existing Axes")
plt.show()

# Setting the global default figure size for matplotlib
import matplotlib
matplotlib.rc('figure', figsize=(10, 5))
# Subsequent pandas plots will use this default if not overridden

DPI and Pixel Dimensions

The dpi (dots per inch) parameter significantly impacts the final pixel dimensions of your saved figure.

  • figsize=(width_in_inches, height_in_inches): Defines the physical size of the figure.
  • dpi: Determines how many pixels are used to represent each inch.

The total pixel dimensions are calculated as: width_in_pixels = width_in_inches * dpi and height_in_pixels = height_in_inches * dpi.

You can set the DPI during figure creation or by calling fig.set_dpi().

import matplotlib.pyplot as plt

# Create a figure with a specific size and DPI
fig = plt.figure(figsize=(6, 4), dpi=150) # 6x4 inches at 150 DPI
plt.plot([1, 2, 3], [4, 5, 6])
plt.title("Figure with 6x4 Inches and 150 DPI")
plt.show()

# The same figure with a different DPI
fig_low_dpi = plt.figure(figsize=(6, 4), dpi=72) # 6x4 inches at 72 DPI
plt.plot([1, 2, 3], [4, 5, 6])
plt.title("Figure with 6x4 Inches and 72 DPI")
plt.show()

Setting Aspect Ratio

For plots where the ratio between width and height is more critical than the absolute size, plt.figaspect() is a convenient function.

import matplotlib.pyplot as plt

# Make the image 3x as wide as it is tall
fix, ax = plt.subplots(figsize=plt.figaspect(1/3)) # Aspect ratio is height/width
ax.plot([1, 2, 3, 4], [1, 4, 9, 16])
ax.set_title("Figure with Aspect Ratio 1:3 (Width:Height)")
plt.show()

Advanced Pixel-Level Control

For precise control over saved image dimensions in pixels, a combination of savefig parameters and set_size_inches can be used.

Setting Height-Only Control:

import sys
import numpy as np
import matplotlib.pyplot as plt

# Assume a desired height in pixels
desired_height_px = 431

fig, ax = plt.subplots()
t = np.arange(-10., 10., 1.)
ax.plot(t, t, '.')
ax.plot(t, t**2, '.')
ax.text(0., 60., 'Hello', fontdict=dict(size=25))

# Calculate DPI to achieve the desired height
# fig.get_size_inches()[1] is the current height in inches
dpi_val = desired_height_px / fig.get_size_inches()[1]

fig.savefig('fixed_height_plot.png', format='png', dpi=dpi_val)
plt.show()

Setting Both Width and Height in Pixels:

This requires calculating appropriate figsize and dpi values.

import sys
import numpy as np
import matplotlib.pyplot as plt

desired_height_px = 431
desired_width_px = 869

fig, ax = plt.subplots()
current_width_in, current_height_in = fig.get_size_inches()

# Adjust figure size in inches to maintain aspect ratio for pixel target
fig.set_size_inches(current_height_in * (desired_width_px / desired_height_px), current_height_in)

t = np.arange(-10., 10., 1.)
ax.plot(t, t, '.')
ax.plot(t, t**2, '.')
ax.text(0., 60., 'Hello', fontdict=dict(size=25))

# Save with DPI calculated to match the desired pixel height
fig.savefig('fixed_wh_plot.png', format='png', dpi=desired_height_px / fig.get_size_inches()[1])
plt.show()

Using plt.tight_layout(pad=1) can help manage whitespace and ensure elements fit within the figure bounds.

Scaling Figures

To scale an existing figure by a factor:

import matplotlib.pyplot as plt

# Assume some plotting code here that creates 'fig'
# fig = plt.figure()
# plt.plot(...)

fig_size = plt.gcf().get_size_inches() # Get current size
sizefactor = 0.8 # Scale down by 20%
plt.gcf().set_size_inches(sizefactor * fig_size[0], sizefactor * fig_size[1])

# Fine-tune subplot layout if necessary
# plt.subplots_adjust(left=0.16, bottom=0.19, top=0.82)

plt.show()

Resizing GUI Windows

For interactive plots with GUI backends (like Qt4Agg or TkAgg), you can resize the window directly.

# Assuming 'fig' is an existing figure object
# matplotlib.pyplot.get_current_fig_manager().resize(width_px, height_px)

Note that this functionality might vary across different Matplotlib backends and versions.

Style Sheets

Matplotlib style sheets offer a way to define default plotting parameters, including figure size, within a .mplstyle file.

# my_style.mplstyle
figure.figsize : 8, 6

Then, apply the style:

import matplotlib.style
import matplotlib.pyplot as plt

matplotlib.style.use('my_style.mplstyle')
# Subsequent plots will use the 8x6 inch default
plt.plot(...)
plt.show()

SVG Output Considerations

When saving to SVG (Scalable Vector Graphics), the concept of pixel dimensions is different. SVGs are vector-based, meaning they can be scaled without loss of quality. While you can specify dpi when saving, it mainly influences the initial interpretation of sizes. For precise pixel dimensions from an SVG, conversion tools like Inkscape are often used.

# Example of saving to SVG
# fig.savefig('my_plot.svg', format='svg')
# Then use: inkscape -h 431 my_plot.svg -b FFF -e output_plot.png

FAQs on Matplotlib Figure Size Control

Q: How do I set the figure size in inches using Matplotlib

ANS: You can set the figure size by passing a tuple of (width, height) in inches to the figsize argument when creating a figure using plt.figure(figsize=(width, height)) or plt.subplots(figsize=(width, height)).

Q: Can I change the size of an already created Matplotlib figure

ANS: Yes, you can modify the size of an existing figure object using the fig.set_size_inches(width, height) method. For some GUI backends, you might need to set forward=True for immediate visual updates.

Q: What is the role of DPI in Matplotlib figure size

ANS: DPI (dots per inch) determines how many pixels represent each inch of the figure. A higher DPI results in a larger pixel dimension for the same figsize. The final pixel size is figsize multiplied by dpi.

Q: How can I set default figure sizes for all plots

ANS: You can set default figure sizes by modifying plt.rcParams["figure.figsize"] = (width, height). This ensures all subsequent plots will use these dimensions unless explicitly overridden.

Q: How do I set the figure size in centimeters

ANS: Since figsize expects inches, divide your desired centimeter values by 2.54 to convert them to inches before passing them to the figsize argument.

Q: Is there a way to adjust the aspect ratio of a Matplotlib figure

ANS: Yes, the plt.figaspect(aspect_ratio) function is useful for setting the figure size based on a desired width-to-height ratio. For instance, plt.figaspect(1/3) creates a figure three times wider than it is tall.
