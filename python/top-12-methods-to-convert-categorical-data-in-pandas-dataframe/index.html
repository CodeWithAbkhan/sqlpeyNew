Top 12 Methods to Convert Categorical Data in Pandas DataFrame

python
3 min read · Nov 6, 2024

Table of Contents

Overview

When dealing with data in a pandas DataFrame, you often encounter categorical data that needs to be converted into numerical format for various analyses. The challenge lies in efficiently handling multiple columns without cluttering your data structures with unnecessary interim columns. Let’s explore effective methods to accomplish this task.

Example DataFrame Structure

Imagine you have the following DataFrame with various categorical columns:

import pandas as pd

data = {
    'col1': [1, 2, 3, 4, 5],
    'col2': [10, 20, 30, 30, 10],
    'col3': ['A', 'B', 'A', 'C', 'B'],
    'col4': ['B', 'C', 'E', 'G', 'H']
}

df = pd.DataFrame(data)
print(df)

Your DataFrame might look like this:

   col1  col2 col3 col4
0     1    10   A   B
1     2    20   B   C
2     3    30   A   E
3     4    30   C   G
4     5    10   B   H

Top Methods for Categorical Data Conversion

Method 1: Factorizing with pandas.factorize()

You can use the pandas.factorize() function to convert categorical data:

df['col3'] = pd.factorize(df['col3'])[0]

This transforms the DataFrame into a structure where each unique category in col3 is represented by an integer.

Method 2: Using Categorical Data Types

If you want to directly convert without creating an extra column, you can convert categories as follows:

df['col3'] = pd.Categorical(df['col3']).codes

This directly assigns the integer codes back to the existing column.

Method 3: Loop Through Columns

For converting multiple columns within the DataFrame, a loop can be effective:

for col in df.columns:
    if df[col].dtype == 'object':
        df[col] = df[col].astype('category').cat.codes

Method 4: Value Replacement

You might also use Python’s .replace() method for known categories:

df['col4'].replace(to_replace=['B', 'C', 'E', 'G', 'H'], value=[1, 2, 3, 4, 5], inplace=True)

Method 5: Label Encoding with Scikit-learn

Scikit-learn provides a LabelEncoder which can easily be applied to convert columns:

from sklearn.preprocessing import LabelEncoder

labelencoder = LabelEncoder()
df['col3'] = labelencoder.fit_transform(df['col3'])

Method 6: Using .apply() with Lambda Functions

You can convert categorical values with a lambda function:

df['col4'] = df['col4'].apply(lambda x: {'B': 1, 'C': 2, 'E': 3, 'G': 4, 'H': 5}.get(x, x))

Method 7: Apply Factorization Across DataFrame

Using .apply(), you can process the entire DataFrame:

df = df.apply(lambda col: pd.factorize(col)[0] if col.dtype == 'object' else col)

Method 8: Getting Dummy Variables

For creating dummy variables directly from categorical columns, utilize get_dummies():

dummies = pd.get_dummies(df[['col3', 'col4']])
df = pd.concat([df, dummies], axis=1)

Method 9: Manual Encoding

You can perform manual encoding with an explicit dictionary:

manual_encoding = {'A': 1, 'B': 2, 'C': 3}
df['col3'] = df['col3'].map(manual_encoding)

Method 10: Using an Ordered Categorical Approach

If you care about the order of categories, consider ordering them with:

ordered_categories = pd.Categorical(df['col3'], categories=['A', 'B', 'C'], ordered=True)
df['col3'] = ordered_categories.codes

Method 11: Use of NumPy Where Function

Another approach is to map categories using NumPy’s where:

df['col3'] = df['col3'].where(df['col3'] == 'A', other=0).where(df['col3'] == 'B', other=1).where(df['col3'] == 'C', other=2)

Method 12: Using the Python Dictionary for Custom Mapping

For specific mapping of values, a dictionary can be used:

mapping_dict = {'Non-Travel': 0, 'Travel_Rarely': 1, 'Travel_Frequently': 2}
df['BusinessTravel'] = df['BusinessTravel'].map(mapping_dict)

FAQs on Top 12 Methods to Convert Categorical Data in Pandas DataFrame

Q: What is the best method to convert categorical data?

A: The best method often depends on the specific requirements of your data and the analysis you plan to perform. Using factorize() or pd.get_dummies() are commonly preferred for their simplicity and effectiveness.

Q: How can I handle unseen categories during conversion?

A: You can handle unseen categories by using the get() method in dictionaries or by adding a default case in your mapping to ensure any unknown categories are assigned a specific value.

Q: Can I reverse the encoding back to original categories?

A: Yes, if you store the mapping either in a separate variable or use a LabelEncoder, you can convert back from encoded values to categories by using the inverse_transform() method.
