Solved: How to Check if a Value Exists in a List of Dictionaries in Python

I’ve encountered a common scenario in Python where we have a list of dictionaries and need to check if a specific key/value pair exists. Let’s consider a list of dictionaries defined as follows:

colors = [
    {'main_color': 'red', 'second_color': 'blue'},
    {'main_color': 'yellow', 'second_color': 'green'},
    {'main_color': 'yellow', 'second_color': 'blue'}
]

The goal is to determine whether a dictionary with a certain key/value already exists in this list. For instance, we want to check if there’s a dictionary where main_color is equal to 'red' and if not, we may want to add a new dictionary to the list.

Checking for Existence: 7 Practical Solutions

Solution 1: Iterating with a Function

One effective approach is to define a function that iterates through the list, checking for the presence of the key/value pair:

def check_value_in_dict_list(key, value, dict_list):
    for entry in dict_list:
        if entry.get(key) == value:
            return entry
    return None

print(check_value_in_dict_list('main_color', 'red', colors))  # Output: {'main_color': 'red', 'second_color': 'blue'}
print(check_value_in_dict_list('main_color', 'pink', colors))  # Output: None

Solution 2: Using any() for Conditional Checks

Another elegant solution utilizes the any() function to check for multiple conditions, as shown in the example below:

people = [
    {'first': 'Nil', 'last': 'Elliot', 'suffix': 'III'},
    {'first': 'Max', 'last': 'Sam', 'suffix': 'IX'},
    {'first': 'Anthony', 'last': 'Mark', 'suffix': 'IX'}
]

if not any(d['first'] == 'Anthony' and d['last'] == 'Mark' for d in people):
    print('Not exists!')
else:
    print('Exists!')  # Output: Exists!

Solution 3: Utilizing filter with Lambda Functions

You can also use Python’s filter() function to check for the presence of a specific condition:

if not list(filter(lambda d: d['main_color'] == 'red', colors)):
    print('Item does not exist')  # Output: (nothing printed, since it exists)

Solution 4: Function for Adding Unique Values

Creating a function that checks for a value and adds it if it doesn’t exist can streamline your code:

def add_if_unique(dict_list, key, value):
    if not any(d.get(key) == value for d in dict_list):
        dict_list.append({key: value})

add_if_unique(colors, 'main_color', 'red')
print(colors)  # Will not change since 'red' already exists

Solution 5: Comprehensive Checks with Conditionals

It’s beneficial to incorporate conditions to ensure that the key exists before performing checks:

input_key = 'main_color'
input_value = 'red'

if not any(item[input_key] == input_value for item in colors if input_key in item):
    print("not exist")  # Will not print

Solution 6: Multi-Condition Checks

You can also verify if a value exists in a dictionary across different keys:

print(any('red' in d.values() for d in colors))  # Output: True
print(any('green' in d.values() for d in colors))  # Output: True
print(any('black' in d.values() for d in colors))  # Output: False

Solution 7: Using next() with a Default Value

The next() function can also be employed to find the first occurrence or provide a default dictionary if no match is found:

found_event = next(
    filter(lambda x: x['main_color'] == 'red', colors),
    {'name': 'red', 'value': 'not found'}
)

print(found_event)  # Output: {'main_color': 'red', 'second_color': 'blue'}

Additional Methods

  • Consider using set to track unique values for large datasets.
  • Employ list comprehensions for concise code if checking for multiple values at once.

FAQs on How to Check if a Value Exists in a List of Dictionaries in Python

Q: How do I check if a dictionary with a specific key exists?

A: You can use the any() function in combination with a generator expression to check if a dictionary with a specific key exists.

Q: Can I add a key/value pair if it doesn't exist?

A: Yes, you can define a function that checks for the key/value pair and appends it to the list if it does not exist already.

Q: What if I want to check multiple conditions?

A: You can use any() with logical operators to check for multiple conditions in your list of dictionaries.
