Introduction

In the realm of Natural Language Processing (NLP), determining the degree of similarity between two documents is a crucial task. There are various methodologies to achieve this, each with its strengths and applicability depending on the use case. This guide delves into ten different approaches to compute text similarity, tailoring solutions in Python and using established libraries.

Method 1: TF-IDF with Cosine Similarity

The Term Frequency-Inverse Document Frequency (TF-IDF) method leverages the frequency of words to establish similarity, while cosine similarity quantifies the angle between two vectors.

Example Code

import nltk
import string
from sklearn.feature_extraction.text import TfidfVectorizer

nltk.download('punkt')

stemmer = nltk.stem.PorterStemmer()
remove_punctuation_map = str.maketrans('', '', string.punctuation)

def stem_tokens(tokens):
    return [stemmer.stem(item) for item in tokens]

def normalize(text):
    return stem_tokens(nltk.word_tokenize(text.lower().translate(remove_punctuation_map)))

vectorizer = TfidfVectorizer(tokenizer=normalize, stop_words='english')

def cosine_sim(text1, text2):
    tfidf = vectorizer.fit_transform([text1, text2])
    return ((tfidf * tfidf.T).A)[0, 1]

print(cosine_sim('This is a cat', 'This is a cat'))
print(cosine_sim('This is a cat', 'This is a dog'))

Method 2: Spacy Similarity

Spacy simplifies the process with its built-in similarity method to compute document similarity directly.

Installation

pip install spacy
python -m spacy download en_core_web_sm

Example Code

import spacy

nlp = spacy.load('en_core_web_sm')
doc1 = nlp("Hello there!")
doc2 = nlp("Hello there!")
doc3 = nlp("How are you?")

print(doc1.similarity(doc2))  # High similarity
print(doc2.similarity(doc3))  # Lower similarity

Method 3: Universal Sentence Encoder

Utilizing Google’s Universal Sentence Encoder provides high accuracy in determining text similarity via fixed-length vector representations.

Installation

pip install tensorflow
pip install tensorflow_hub

Example Code

import tensorflow_hub as hub
import tensorflow as tf
import numpy as np

module_url = "https://tfhub.dev/google/universal-sentence-encoder/1"
embed = hub.load(module_url)

messages = ["My phone is great.", "Your cellphone is fantastic."]
message_embeddings = embed(messages)

similarity_score = np.inner(message_embeddings, message_embeddings)
print(similarity_score)

Method 4: Gensim Word2Vec

Word2Vec captures semantic similarity through the relationships between words.

Example Code

from gensim.models import Word2Vec
from gensim.utils import simple_preprocess
import numpy as np

def calculate_similarity(sentence1, sentence2):
    tokens1 = simple_preprocess(sentence1)
    tokens2 = simple_preprocess(sentence2)
    model = Word2Vec([tokens1, tokens2], vector_size=100, window=5, min_count=1, sg=0)

    vector1 = np.mean([model.wv[token] for token in tokens1], axis=0)
    vector2 = np.mean([model.wv[token] for token in tokens2], axis=0)

    return np.dot(vector1, vector2) / (np.linalg.norm(vector1) * np.linalg.norm(vector2))

print(calculate_similarity('The cat sits outside', 'The dog plays in the garden'))

Method 5: BERT Embeddings

BERT provides a sophisticated method for understanding text semantics that can enhance document similarity measurement.

Example Code

pip install transformers

from transformers import BertTokenizer, BertModel
import torch

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

def get_embedding(text):
    inputs = tokenizer(text, return_tensors="pt")
    with torch.no_grad():
        outputs = model(**inputs)
    return outputs.last_hidden_state.mean(dim=1).squeeze()

embedding1 = get_embedding("Document one text sample.")
embedding2 = get_embedding("Document two text sample.")
cosine_similarity = torch.nn.functional.cosine_similarity(embedding1, embedding2, dim=0)
print(cosine_similarity.item())

Method 6: Sentence Transformers

Sentence Transformers simplifies the use of BERT models for sentence and semantic textual similarity.

Example Code

from sentence_transformers import SentenceTransformer, util

model = SentenceTransformer('all-MiniLM-L6-v2')
sentence1 = "The cat sits outside."
sentence2 = "The dog plays in the garden."

emb1 = model.encode(sentence1, convert_to_tensor=True)
emb2 = model.encode(sentence2, convert_to_tensor=True)

cosine_scores = util.cos_sim(emb1, emb2)
print(cosine_scores)

FAQs on Top 10 Methods to Compute Similarity Between Two Text Documents

Q: What is TF-IDF?

A: TF-IDF stands for Term Frequency-Inverse Document Frequency. It’s a numerical statistic intended to reflect how important a word is to a document in a collection.

Q: How can I measure semantic similarity?

A: Semantic similarity can be measured using models like BERT, Universal Sentence Encoder, or Sentence Transformers that understand context and meaning.

Q: Which method is better for large datasets?

A: For large datasets, Lucene or LingPipe are recommended for efficient indexing and similarity queries.
