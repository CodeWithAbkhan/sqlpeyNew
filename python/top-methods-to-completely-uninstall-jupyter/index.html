Question:

I’m facing issues trying to completely uninstall Jupyter from my system. I’ve attempted the following commands in both pip and pip3:

pip uninstall jupyter
pip3 uninstall jupyter

In addition, I’ve tried manually removing residual files with this command:

rm -rf /Users/$USER/Library/Jupyter/*

Despite executing these commands, when I attempt to run jupyter in my terminal, I still receive this output:

usage: jupyter [-h] [--version] [--config-dir] [--data-dir] [--runtime-dir]
 [--paths] [--json]
 [subcommand]
jupyter: error: one of the arguments --version subcommand --config-dir --data-dir --runtime-dir --paths is required

What could be the underlying issue, and why am I still able to invoke the command?

Solution 1: Removing Jupyter Packages with Python

If neither pip-autoremove nor pip3 uninstall jupyter have effectively removed Jupyter, consider running the following command to guarantee the uninstallation of all relevant Jupyter packages. Note that you may need sudo privileges depending on your system setup.

sudo python3 -m pip uninstall -y jupyter jupyter_core jupyter-client jupyter-console jupyterlab_pygments qtconsole notebook nbconvert nbformat nbclassic nbclient jupyterlab-widgets jupyter-events jupyter-server jupyter-server-terminals

Important Consideration:

The command above specifically targets Jupyter-related packages, avoiding the removal of other possibly shared dependencies (e.g., Jinja2, used by Flask, and ipython).

Alternative Clean-Up:

In case you prefer to individually uninstall each Jupyter component, you could utilize the following commands:

pip3 uninstall jupyter
pip3 uninstall jupyter_core
pip3 uninstall jupyter-client
pip3 uninstall jupyter-console
pip3 uninstall jupyterlab_pygments
pip3 uninstall notebook
pip3 uninstall qtconsole
pip3 uninstall nbconvert
pip3 uninstall nbformat

Solution 2: Checking the Environment

Sometimes Jupyter installations might linger due to multiple Python environments. Ensure you are targeting the correct environment by checking your active Python version with:

python --version

If you’re using virtual environments or Anaconda, confirm that you are uninstalled from the correct context.

FAQs on Top Methods to Completely Uninstall Jupyter

Q: Why is Jupyter still accessible after uninstallation?

A: This can occur if Jupyter components were not completely removed or there are multiple Python environments where Jupyter is installed. Ensure you’re uninstalling entirely from the active environment.

Q: What are the common dependencies linked with Jupyter?

A: Jupyter has a wide array of dependencies, including ipykernel, nbconvert, notebook, and many others. It’s important to consider this when attempting a complete uninstallation.
