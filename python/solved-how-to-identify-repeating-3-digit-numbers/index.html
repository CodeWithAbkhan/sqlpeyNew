In a recent interview with a hedge fund in New York, I faced a challenging question that left a lasting impact on my coding journey. The task was to develop a function in Python that analyzes a string containing a million digits and returns all repeating 3-digit sequences along with their frequency of occurrence. The task sounded simple at first, but it raised intriguing questions about algorithm complexity and data processing.

Challenge Explanation

The fundamental question posed was:

Given a string of a million numbers, write a program that extracts all repeating 3-digit numbers and counts their occurrences, specifically those that appear more than once.

For instance, taking a string like 123412345123456, a successful implementation would yield:

123 - 3 times
234 - 3 times
345 - 2 times

Upon attempting to tackle this question, I learned that the expected time complexity was a constant of 1000 since any valid 3-digit number would lie within the range of 000 to 999. At first glance, I doubted that it was feasible to achieve a truly constant time algorithm as implied by the interviewers. Let’s dive deeper into this problem and explore both Python and C implementations.

Proposed Solutions

Python Implementation

While a true O(1) computation is impossible when evaluating each character in the input, we can seek an efficient solution with a linear complexity, O(n). The following code illustrates how to implement this in Python:

input_string = '123412345123456'

# Initialize frequency array for 3-digit numbers
frequency = [0] * 1000

# Iterate over the string and count occurrences of each 3-digit substring
for index in range(len(input_string) - 2):
    three_digit_num = int(input_string[index:index + 3])
    frequency[three_digit_num] += 1

# Gather and print results for 3-digit numbers that appeared more than once
results = [(num, frequency[num]) for num in range(1000) if frequency[num] > 1]
for number, count in results:
    print(f'{number} - {count} times')

This outputs:

123 - 3 times
234 - 3 times
345 - 2 times

Efficiency Analysis

This O(n) solution efficiently processes the string, taking about half a second for one million digits. It scales linearly; for example, the processing time for a 10 million-character string is approximately 3.5 seconds.

Alternative Implementations

For those interested in greater speed or working with larger data sets, the task can also be accelerated by leveraging a language like C. Below is a comparable implementation in C that significantly boosts performance—processing a hundred million digits in approximately 0.6 seconds.

#include <stdio.h>
#include <string.h>

int main(void) {
    static char input_string[100000000 + 1];
    static int frequency[1000];

    // Fill the input string with test data
    memset(input_string, '1', sizeof(input_string));
    input_string[sizeof(input_string) - 1] = '\0'; // null termination

    if (strlen(input_string) <= 2) return 0; // Ensure sufficient digits

    int value = (input_string[0] - '0') * 10 + input_string[1] - '0';
    char *input_pointer = &(input_string[2]);
    while (*input_pointer != '\0') {
        value = (value % 100) * 10 + *input_pointer++ - '0';
        frequency[value]++;
    }

    // Output results for relevant frequencies
    for (int i = 0; i < 1000; ++i)
        if (frequency[i] > 1)
            printf("%3d -> %d\n", i, frequency[i]);

    return 0;
}

This C implementation showcases how to utilize memory and processing efficiency, making it a powerful alternative for computationally intensive tasks.

Solving Challenges with Optimization

When faced with performance hurdles, one strategy is parallel processing. You can partition the input string into overlapping segments, distribute these segments across multiple processors, and then combine results—a method that can yield significant improvements for extensive datasets.

For instance, by segmenting the input into slices like:

The overlaps ensure that no data is missed, maintaining the integrity of data processing across threads.

FAQs on Solved How to Identify Repeating 3-Digit Numbers in a String of a Million Digits

Q: What is the time complexity of the given solutions?

A: The time complexity for the proposed solutions is O(n), as every digit needs to be processed to extract the 3-digit numbers.

Q: How is the frequency counting handled?

A: We use an array of size 1000 to count occurrences of each possible 3-digit number while iterating through the input string.

Q: Can this process be optimized further?

A: Yes, you can use parallel processing techniques to handle larger strings more efficiently by breaking them into smaller pieces.
