Top 8 Ways to Count NaN Values in a Pandas DataFrame

When handling datasets in Python, particularly with the pandas library, you may often encounter missing values denoted as NaN (Not a Number). Counting these NaN values is crucial for data cleaning and preprocessing. Below, I will outline several effective methods to achieve this, along with code snippets and practical examples.

Method 1: Using isnull() and sum()

To quickly count the number of NaN values in each column of a pandas DataFrame, you can use the isnull() method followed by sum().

import pandas as pd
import numpy as np

# Example DataFrame
data = {
    'A': [1, 2, np.nan],
    'B': [np.nan, 2, 3],
    'C': [1, np.nan, np.nan]
}

df = pd.DataFrame(data)

# Count NaN values in each column
nan_counts = df.isnull().sum()
print(nan_counts)

Method 2: Counting NaNs by Rows

If you’re interested in counting NaN values for each row instead of columns, simply change the axis parameter in the sum() method.

# Count NaN values in each row
nan_counts_row = df.isnull().sum(axis=1)
print(nan_counts_row)

Method 3: Defining a Custom Function

For more comprehensive insights, you can create a function that returns a DataFrame including both the count of NaNs and their percentage relative to the total entries.

def missing_values_summary(df):
    mis_val = df.isnull().sum()
    mis_val_percent = (mis_val / len(df)) * 100
    return pd.DataFrame({'Missing Values': mis_val, '% of Total Values': mis_val_percent})

summary_df = missing_values_summary(df)
print(summary_df)

Method 4: Leveraging value_counts()

To display counts of all unique values including NaNs, you can utilize value_counts() with the dropna parameter set to False.

for col in df.columns:
    print(f"Value counts for {col}:")
    print(df[col].value_counts(dropna=False))

Method 5: Simple Count of NaNs in a Specific Column

If you are concerned with NaN counts in a specific column, you can simply call:

# Count NaNs in column 'A'
count_nan_A = df['A'].isnull().sum()
print(f"Number of NaNs in column A: {count_nan_A}")

Method 6: Total Count of NaNs Across the DataFrame

To get a total count of all NaN values in the entire DataFrame, you can combine methods:

total_nan_count = df.isnull().sum().sum()
print(f"Total number of NaNs in DataFrame: {total_nan_count}")

Method 7: Visualizing NaN Counts

For a quick visual analysis of missing values, consider plotting the count of NaNs using libraries such as matplotlib or seaborn.

import matplotlib.pyplot as plt

nan_counts.plot(kind='bar')
plt.title('Count of NaN Values per Column')
plt.ylabel('Count of NaNs')
plt.show()

Method 8: Alternative with Numpy’s np.isnan()

For counting NaN values when working with NumPy arrays, you can utilize the numpy function:

nan_count_numpy = np.isnan(df).sum(axis=0)
print(nan_count_numpy)

FAQs on Top 8 Ways to Count NaN Values in a Pandas DataFrame
