“Python Matplotlib Scatter Marker Size: Decoding the ’s’ Parameter”

When utilizing plt.scatter() in Python’s Matplotlib library, specifying marker dimensions through the s argument often leads to confusion regarding whether this value represents area, radius, or side length. How is the s parameter actually defined, and what mathematical relationship does it hold with the visible size of the plotted marker?

Defining the s Parameter in plt.scatter

The fundamental definition provided by the Matplotlib documentation states that the s argument represents the marker size in points squared ($\text{pt}^2$).

This definition carries significant implications for visual scaling:

  1. Area Equivalence: If $s$ is the square of a length unit (measured in points, ‘pt’), then $s$ is proportional to the area of the marker. Mathematically, $s \approx \text{Area}$.
  2. Scaling Behavior: Because the size parameter s scales with the square of a linear dimension (like width $W$ or radius $r$), doubling the width or height of a marker requires multiplying $s$ by a factor of $2^2$, or 4. $$\text{If } A = W \times H \text{, then } (2W) \times (2H) = 4A$$

It is critical to note a common nuance: while $s$ is proportional to the shaded area, it is not necessarily equal to the marker’s actual area, except for very specific marker types like squares.

Why is Size Defined in Points Squared?

The convention of using a value proportional to the area stems from visual perception. When an observer compares different markers, the apparent increase in size correlates more closely with the change in the marker’s area rather than a linear change in its diameter or side length. Doubling the area ($s$ is multiplied by 2) leads to a visual increase that appears roughly linear, which is often more intuitive than doubling the width (which multiplies $s$ by 4).

Consider the effect of doubling the governing parameter versus doubling the resulting area:

Scenario A: Doubling Width (Exponential Increase in $s$)

If the progression is based on doubling the linear dimension (width), the resulting s values show an exponential increase with a base of 4:

import matplotlib.pyplot as plt
import numpy as np

x_doubled_width = [0, 2, 4, 6, 8, 10]
y_zeros = [0] * len(x_doubled_width)
# s values increase by a factor of 4^(n)
s_width_doubled = [20 * (4**n) for n in range(len(x_doubled_width))]

plt.figure(figsize=(8, 3))
plt.scatter(x_doubled_width, y_zeros, s=s_width_doubled)
plt.title("Marker Size Scaling: Doubling Width (s $\propto 4^n$)")
plt.yticks([])
plt.show()

Scenario B: Doubling Area (Linear Appearance)

If the goal is to have the apparent size increase linearly (i.e., doubling the area makes it look twice as big), the underlying s values should increase exponentially with a base of 2:

# s values increase by a factor of 2^(n)
s_area_doubled = [20 * (2**n) for n in range(len(x_doubled_width))]

plt.figure(figsize=(8, 3))
plt.scatter(x_doubled_width, y_zeros, s=s_area_doubled)
plt.title("Marker Size Scaling: Doubling Area (s $\propto 2^n$)")
plt.yticks([])
plt.show()

To visualize how different scaling laws affect marker appearance:

x_comparison = np.arange(10)
y_linear = [-1] * 10
y_square = [0] * 10
y_exponential = [1] * 10

# Assuming n runs from 0 to 9
s_linear = [20 * (n + 1) for n in x_comparison]       # s=n
s_square = [20 * (n + 1)**2 for n in x_comparison]    # s=n^2
s_exp = [20 * (2**(n)) for n in x_comparison]         # s=2^n

plt.figure(figsize=(10, 4))
plt.scatter(x_comparison, y_linear, s=s_linear, label='$s \propto n$ (Linear)')
plt.scatter(x_comparison, y_square, s=s_square, label='$s \propto n^2$ (Squared)')
plt.scatter(x_comparison, y_exponential, s=s_exp, label='$s \propto 2^n$ (Exponential)')

plt.yticks([-1, 0, 1], ['Linear Appearance', 'Quadratic $s$', 'Exponential $s$'])
plt.legend(loc='upper left', bbox_to_anchor=(1.05, 1))
plt.grid(axis='x', linestyle='--')
plt.show()

Points vs. Pixels and DPI

A point in typography is conventionally defined as $1/72$ of an inch. Matplotlib uses this unit for s. However, the final rendered size in pixels depends on the figure’s Dots Per Inch ($\text{DPI}$):

$$\text{1 Point} = \frac{\text{fig.dpi}}{72} \text{ pixels}$$

Therefore, an $s$ value of $100$ (i.e., $10 \text{pt}^2$) will render as a different physical size depending on whether $\text{fig.dpi}$ is 72 or 100. If you require a marker to occupy a fixed pixel area regardless of DPI, you must calculate the corresponding $s$ value:

$$\text{Target Pixel Area}^2 = \left(\frac{\text{Target Pixels} \times 72}{\text{fig.dpi}}\right)^2$$

For instance, to achieve a marker that looks like $100 \text{ pixels}^2$ area, you calculate $s$ based on the DPI:

import matplotlib.pyplot as plt

target_points = 10
# Compare size at different figure DPIs
for dpi_setting in [72, 100, 144]:
    fig, ax = plt.subplots(figsize=(2, 2), dpi=dpi_setting)
    ax.set_title(f"fig.dpi={dpi_setting}")
    ax.set_ylim(-1, 1)
    ax.set_xlim(-1, 2)
    
    # Size set directly in points^2 (e.g., s=100, meaning 10pt side/radius approximation)
    s_in_points = target_points**2 
    ax.scatter([0], [0], s=s_in_points, marker="s", label=f"{s_in_points} points^2")

    # Size set to maintain 100 pixels^2 area regardless of DPI
    s_in_pixels = (target_points * 72.0 / dpi_setting)**2
    ax.scatter([1], [0], s=s_in_pixels, marker="o", label=f"100 pixels^2 (calc)")

    ax.legend(fontsize=8)
    plt.show()

Alternatives for Controlling Marker Size

While plt.scatter uses $s=\text{size}^2$, other Matplotlib functions offer more direct control over linear size:

Alternative 1: Using plt.plot with markersize

The plt.plot function uses the markersize argument, which specifies the size in points (linear dimension), not squared points.

If you need a marker of $10 \text{ points}$ diameter/side length, you use markersize=10 in plt.plot. In contrast, for plt.scatter, you would use $s=10^2=100$ to approximate a similar visual size, though the relationship to area differs between the functions.

import numpy as np
import matplotlib.pyplot as plt

x_data = np.arange(5)

plt.figure(figsize=(8, 3))

# Using plot with explicit markersize (linear scale)
plt.plot(x_data, [1]*5, 'bo', markersize=15, label='plt.plot(markersize=15)') 

# Using scatter with s parameter (squared scale) - s=15^2 = 225
plt.scatter(x_data, [0]*5, s=225, marker='o', label='plt.scatter(s=225)') 

plt.legend()
plt.yticks([0, 1])
plt.title("Comparing plt.plot(markersize) vs plt.scatter(s)")
plt.show()

Alternative 2: Drawing Explicit Shapes with plt.Circle

If you need precise control over the marker radius in data coordinates (not points), you should bypass plt.scatter entirely and use the patches functionality, specifically plt.Circle. This allows you to define the radius directly in the axes’ data units.

import matplotlib.pyplot as plt

# Define points with desired RADIUS in data units
points_data = [
    {'x': 100, 'y': 200, 'radius': 50, 'color': (0.1, 0.2, 0.3)},
    {'x': 500, 'y': 500, 'radius': 75, 'color': (0.8, 0.1, 0.1)}
]

fig, ax = plt.subplots(figsize=(6, 6))
ax.set_xlim((0, 1000))
ax.set_ylim((0, 1000))
ax.set_aspect('equal', adjustable='box') # Crucial for circles to appear round

for point in points_data:
    # Create a Circle artist object, specifying radius directly
    circle_artist = plt.Circle(
        (point['x'], point['y']), 
        point['radius'], 
        color=point['color'], 
        fill=False,
        linewidth=2
    )
    ax.add_artist(circle_artist)
    
ax.set_title("Precise Radius Control via plt.Circle")
plt.show()

Alternative 3: Scaling for Linear Visual Progression

If your underlying data follows a sequence (e.g., $1, 2, 3, 4, 5$) and you want the markers to appear to grow linearly in size (where marker $i+1$ looks twice as large as marker $i$), you must feed the square root of your desired linear progression into the s parameter.

If the desired output visual size progression is $1, 2, 3, 4, 5$ (linear), the input $s$ array must be proportional to the square of that sequence: $1^2, 2^2, 3^2, 4^2, 5^2$.

If you want the area to double successively (i.e., $s$ increases by factor of 2 each step), use the sequence directly, as seen in Scenario B. If you want the radius to double successively (i.e., $s$ increases by factor of 4 each step), use $s \propto 4^n$.

To achieve a linear visual increase based on an index $i$:

import numpy as np
# Desired visual progression (linear): 1, 2, 3, 4, 5...
linear_progression = np.arange(1, 6) 

# To make them appear linear, s must be proportional to the square of the linear factor
s_for_linear_appearance = linear_progression**2 

# Plotting these s values will show the desired linear visual growth
print(f"Input to s parameter: {s_for_linear_appearance}")
# Output: Input to s parameter: [ 1  4  9 16 25]

The Role of Marker Edges

A final consideration is the marker edge properties (linewidth or lw). By default, Matplotlib draws an edge around markers. This edge adds to the total rendered size, meaning the value of $s$ alone doesn’t perfectly dictate the final visual extent if the edge width is non-zero. Setting lw=0 removes the edge, resulting in a smaller visible marker for the same $s$ value.

Different libraries (Seaborn, Pandas plotting wrapper) inherit from Matplotlib but may use different defaults for edge color and width, leading to visual size discrepancies even when passing the identical $s=36$ value across them.

FAQs on Python Matplotlib Scatter Marker Size Decoding S Parameter

Q: Is the s parameter in plt scatter area or radius

ANS: The s parameter represents the marker size specified in points squared ($\text{pt}^2$), making it proportional to the marker’s area, not its radius or side length directly.

Q: How to make scatter markers increase in size linearly

ANS: If you want the markers to appear to grow linearly based on some index $n$, you must set $s$ to be proportional to $n^2$, i.e., $s \propto n^2$. This counteracts the squared nature of the $s$ parameter.

Q: What is the relationship between markersize in plt plot and s in plt scatter

ANS: In plt.plot, markersize is a linear dimension in points. In plt.scatter, s is the square of the dimension in points ($s = \text{markersize}^2$). So, plt.scatter(s=100) approximates the visual size of plt.plot(markersize=10).
