How Can You Easily Create Eye-Catching ASCII-Art Text in Python?

When working with output data in your Python applications, it’s often desirable to emphasize certain pieces of information. One effective method to achieve this is through the use of ASCII art text. It’s not only visually appealing but also serves to draw the viewer’s attention to essential messages or warnings. This guide explores two primary methods to generate ASCII-art text in Python.

Method 1: Using pyfiglet and colorama

The pyfiglet library offers a pure Python implementation to create ASCII art from text, similar to the classic figlet program. This library can be easily combined with colorama and termcolor to add colors and styles to the output.

To get started, you’ll first need to install the required libraries:

pip install pyfiglet colorama termcolor

Here’s a practical Python example utilizing these libraries:

import sys
from colorama import init
from termcolor import cprint
from pyfiglet import figlet_format

# Initialize colorama for compatibility
init(strip=not sys.stdout.isatty())

# Create ASCII art text and print it with colors
cprint(figlet_format('WARNING!', font='starwars'), 'yellow', 'on_red', attrs=['bold'])

Example Output

When you run the above Python script, the output will appear prominently in your console as follows:

$ python print-warning.py

This script prints the text “WARNING!” with a specific font and color settings, ensuring that it stands out in the console.

Method 2: Text Rendering using PIL

Another approach to producing ASCII art text is by leveraging the PIL (Python Imaging Library) to render text onto an image. This technique can convert bitmap images into a format of your choice, which can be substituted for characters, offering a unique representation.

First, you need to install the Pillow library, which is a fork of PIL:

pip install Pillow

Here’s an illustrative example demonstrating how to achieve this:

from PIL import Image, ImageFont, ImageDraw

# Text to be rendered
ShowText = 'Python with PIL'

# Load font and calculate dimensions
font = ImageFont.truetype('arialbd.ttf', 15)
size = font.getsize(ShowText)

# Create a black and white image
image = Image.new('1', size, 1)
draw = ImageDraw.Draw(image)
draw.text((0, 0), ShowText, font=font)

# Scan the bitmap and print ASCII art version
for rownum in range(size[1]):
    line = []
    for colnum in range(size[0]):
        if image.getpixel((colnum, rownum)):
            line.append(' ')
        else:
            line.append('#')
    print(''.join(line))

Example Output

Running the provided script will produce a text representation using # for black pixels and spaces for white pixels, yielding a visual output based on the rendered text.

Alternative Ways

Although pyfiglet and PIL are effective methods for creating ASCII art text, you might also explore the following alternatives:

  • Figlet command-line utility for generating ASCII text.
  • ASCII art generators available online that can render text in various styles.

FAQs on Top 2 Methods to Print ASCII Art Text in Python

Q: Can I customize the font used in pyfiglet?

A: Yes! You can specify a different font by changing the font argument in the figlet_format function. For a list of available fonts, you can use pyfiglet.FigletFont.getFonts().

Q: What operating systems support colorama?

A: Colorama is a cross-platform library but is particularly beneficial for Windows users, as it allows ANSI escape characters to work properly in the console.

Q: Can I save the output as an image?

A: Yes, with PIL, you can easily save your ASCII renderings as images by using the image.save('filename.png') function.
