Solved: How to Fix the ‘pg_config Executable Not Found’ Error When Installing psycopg2

When attempting to install psycopg2, many users encounter the frustrating error message stating that the pg_config executable not found. This error can be particularly vexing, especially when your system configuration seems correct. Below, we will explore several effective methods to troubleshoot and resolve this installation issue, ensuring you can successfully install psycopg2 without a hitch.

Common Cause of the Error

The installation process of psycopg2, a PostgreSQL adapter for Python, requires pg_config, which is a script that helps define the build environment for PostgreSQL libraries. If your system cannot find pg_config, you’ll encounter the dreaded error.

Troubleshooting Steps to Resolve ‘pg_config Executable Not Found’

Here’s a detailed guide on how to fix this issue:

1. Verify the Installation of PostgreSQL

Ensure that PostgreSQL is installed on your system, as pg_config is included with it. You can use the following command to check:

which pg_config

If the command returns a valid path, such as /usr/pgsql-9.1/bin/pg_config, it indicates that PostgreSQL is likely installed.

2. Add pg_config to Your PATH

In some cases, the environment variable PATH may not include the directory where pg_config resides. You can add it by running:

export PATH=$PATH:/usr/pgsql-9.1/bin/

To make this change permanent, consider adding that line to your ~/.bashrc or ~/.bash_profile file.

3. Install Dependencies for psycopg2

If you haven’t yet installed the necessary development libraries, you might be missing the required packages. On Ubuntu and similar systems, you can install them with:

sudo apt-get install libpq-dev python-dev

On Red Hat-based systems, use:

sudo yum install postgresql-devel python-devel

For Alpine Linux, the command would be:

apk add postgresql-dev

4. Install Pre-compiled Binaries

If you want to ease the installation process, consider using the pre-compiled binary version of psycopg2 which does not require a compiler. You can install it with:

python -m pip install psycopg2-binary

However, ensure you are aware that for production environments, building from source is recommended. For that, run:

python -m pip install psycopg2

This approach will ensure you have the latest and most compatible version of the library.

5. Set Up the Environment on macOS

For macOS users, you may face additional paths. If you’ve installed PostgreSQL via Postgres.app, remember to add the following to your terminal profile:

export PATH=$PATH:/Applications/Postgres.app/Contents/Versions/latest/bin

6. Virtual Environments

If you’re using a virtual environment (like venv or virtualenv), make sure that pg_config is accessible from within that environment. Sometimes, activating the virtual environment doesn’t reflect system-wide changes.

Alternative Solutions

  • Symlink pg_config: If you’ve located pg_config but it’s still not recognized, consider creating a symlink:

    sudo ln -s /path/to/your/pg_config /usr/local/bin/pg_config

  • Upgrade pip: If you are using an outdated version of pip, it may lead to installation failures. Upgrade it using:

    pip install --upgrade pip

Practice Example

Here’s how you would typically install psycopg2 after ensuring pg_config is available and the dependencies installed:

## Ensuring PostgreSQL is installed
sudo apt-get install postgresql postgresql-devel python-dev

## Setting PATH for pg_config
export PATH=$PATH:/usr/pgsql-9.1/bin/

## Installing psycopg2
pip install psycopg2

FAQs on Solved: How to Fix the ‘pg_config Executable Not Found’ Error When Installing psycopg2

Q: How do I check if pg_config is installed on my system?

A: You can check if pg_config is installed by running the command which pg_config in your terminal. If it returns a path, it is installed.

Q: What do I do if pg_config is in my PATH but I still get the error?

A: Ensure that you have installed the necessary development packages, such as libpq-dev and python-dev, which are required for building psycopg2.

Q: Is using psycopg2-binary safe for production?

A: While psycopg2-binary can be convenient for development and testing, it is recommended to compile from source in production environments for better stability and compatibility.

For more details on installing psycopg2, visit the official Psycopg documentation and PostgreSQL documentation .
