How can we effectively serialize a Python Enum member into JSON format such that when we decode the resulting JSON, we can accurately recover the original Python object? Consider the following example code:

from enum import Enum
import json

class Status(Enum):
    success = 0

json.dumps(Status.success)

Attempting to execute this will yield an error:

TypeError: <Status.success: 0> is not JSON serializable

What strategies can we employ to circumvent this error? Let’s explore several solutions:

Solution 1: Use IntEnum for Automatic Serialization

If the serialized output is intended for another programming language or system, utilizing IntEnum can simplify the serialization process. Members of IntEnum automatically serialize to their integer values:

from enum import IntEnum
import json

class Status(IntEnum):
    success = 0
    failure = 1

print(json.dumps(Status.success))  # Outputs: '0'

Solution 2: Custom JSONEncoder for Enums

To ensure that you can encode and decode arbitrary enum.Enum members, a tailored JSONEncoder is effective. This can be combined with a decoding function:

import json
from enum import Enum

PUBLIC_ENUMS = {
    'Status': Status,
}

class EnumEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, Enum):
            return {"__enum__": str(obj)}
        return super().default(obj)

def as_enum(d):
    if "__enum__" in d:
        name, member = d["__enum__"].split(".")
        return getattr(PUBLIC_ENUMS[name], member)
    return d

## Example usage:
data = {'action': 'frobnicate', 'status': Status.success }
text = json.dumps(data, cls=EnumEncoder)
print(text)  # '{"status": {"__enum__": "Status.success"}, "action": "frobnicate"}'
loaded_data = json.loads(text, object_hook=as_enum)
print(loaded_data)  # {'status': <Status.success: 0>, 'action': 'frobnicate'}

Solution 3: Utilizing default Argument in json.dumps

For Python versions 3.7 and above, utilize the default parameter of json.dumps to handle enum members:

json.dumps(enum_obj, default=str)  # Converts to string representation
json.dumps(enum_obj, default=lambda x: x.value)  # Use enum value
json.dumps(enum_obj, default=lambda x: x.name)  # Use enum name

Solution 4: Inherit from int or str

An alternative approach involves defining the Enum class to inherit from int or str, allowing the JSON encoder to work seamlessly:

from enum import Enum, unique

@unique
class StatusEnum(int, Enum):
    pending: int = 11
    approved: int = 15
    declined: int = 266

Solution 5: Custom Encoder for AWS Usage

A modified JSONEncoder can also be adapted for specific APIs like AWS:

class EnumEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, Enum):
            return obj.name
        return super().default(obj)

## Example method to convert object to JSON string
def ToJson(self) -> str:
    return json.dumps(self.__dict__, cls=EnumEncoder, indent=1)

Solution 6: Easy Method with jsonpickle

Using the jsonpickle library can streamline the serialization process for Enums:

from enum import Enum
import jsonpickle

@jsonpickle.handlers.register(Enum, base=True)
class EnumHandler(jsonpickle.handlers.BaseHandler):
    def flatten(self, obj, data):
        return obj.value

class Status(Enum):
    success = 0
    error = 1

## Serializing using jsonpickle
simple_class = type('SimpleClass', (), {})()
simple_class.status = Status.success
json_data = jsonpickle.encode(simple_class, unpicklable=False)
print(json_data)  # Outputs: {"status": 0}

Solution 7: Combining Pydantic and FastAPI

Another advanced method incorporates Pydantic and FastAPI for creating APIs with JSON serializable Enums:

from enum import Enum, auto
import json

class StrEnum(str, Enum):
    pass

class AutoNameLower(StrEnum):
    def _generate_next_value_(name, start, count, last_values):
        return name.lower()

class MyActualEnum(AutoNameLower):
    THIS = auto()
    THAT = auto()
    FOO = auto()
    BAR = auto()

## Example usage
print(json.dumps(MyActualEnum.THIS))  # Output: "this"

Solution 8: Simple Method to Define JSON Behavior

You can simply define a __json__ method within your Enum to control its serialization:

class Status(Enum):
    success = 0

    def __json__(self):
        return self.value

This method will only return the Enum’s value when serialized, though it may necessitate additional logic for deserialization.

FAQs on How to Serialize and Deserialize Python Enum Members to JSON

Q: How can I serialize a Python Enum to JSON?

A: Utilize a custom JSON encoder or directly use IntEnum for automatic serialization of enum values.

Q: Is it necessary to use a specific library to serialize Enums?

A: While it’s not strictly necessary, libraries like jsonpickle can simplify the process significantly.

Q: Can I directly serialize Enum names instead of values?

A: Yes, by implementing a custom JSONEncoder, you can choose to serialize enum names or values as per your requirements.
