Introduction

Plotting data in real-time can be crucial for applications in robotics, data analysis, and monitoring systems. This post delves into effective ways to achieve real-time plotting in Python using the powerful matplotlib library in conjunction with other frameworks like PyQt and bokeh.

Issue with Real-Time Plotting

When attempting to plot data from a camera live using OpenCV with matplotlib, a common issue arises: the plot appears frozen while the loop runs, only displaying the complete graph at the end. Here is a simplified version of the problem:

import matplotlib.pyplot as plt
import numpy as np

fig = plt.figure()
plt.axis([0, 1000, 0, 1])

i = 0
x = list()
y = list()

while i < 1000:
    temp_y = np.random.random()
    x.append(i)
    y.append(temp_y)
    plt.scatter(i, temp_y)
    i += 1
    plt.show()

While this approach might seem straightforward, it causes the plot to render all at once after the loop completes, leading to a frustrating user experience.

Top 4 Methods to Enable Real-Time Plotting

Let’s explore various solutions to enable smooth real-time plotting using different techniques:

Method 1: Using Matplotlib’s Animation API

For optimal performance, leveraging the matplotlib.animation API, particularly the blitting feature, can significantly improve plotting speed. Below is how you can implement it:

import numpy as np
import time
import matplotlib.pyplot as plt

def random_walk(dims=(256, 256), n=20, sigma=5, alpha=0.95, seed=1):
    """Generate a simple random walk."""
    r, c = dims
    gen = np.random.RandomState(seed)
    pos = gen.rand(2, n) * ((r,), (c,))
    old_delta = gen.randn(2, n) * sigma

    while True:
        delta = (1. - alpha) * gen.randn(2, n) * sigma + alpha * old_delta
        pos += delta
        old_delta = delta
        yield pos

def run(niter=1000, doblit=True):
    """Display the animation."""
    fig, ax = plt.subplots()
    ax.set_xlim(0, 255)
    ax.set_ylim(0, 255)
    rw = random_walk()
    x, y = next(rw)

    plt.show(False)
    plt.draw()

    if doblit:
        background = fig.canvas.copy_from_bbox(ax.bbox)
    
    points, = ax.plot(x, y, 'o')
    
    for i in range(niter):
        x, y = next(rw)
        points.set_data(x, y)

        if doblit:
            fig.canvas.restore_region(background)
            ax.draw_artist(points)
            fig.canvas.blit(ax.bbox)
        else:
            plt.draw()

    plt.close(fig)

if __name__ == '__main__':
    run(doblit=True)

This method provides smooth real-time updates with a significant increase in frame rate.

Method 2: PyQt for GUI-Based Real-time Graphs

Using PyQt to create an embedded Matplotlib animation provides a highly interactive experience. Here’s a simple example:

import sys
from PyQt5.QtWidgets import QApplication, QMainWindow, QPushButton, QFrame, QGridLayout
from PyQt5.QtCore import QTimer
import numpy as np
import matplotlib
matplotlib.use("Qt5Agg")
from matplotlib.figure import Figure
from matplotlib.backends.backend_qt5agg import FigureCanvasQTAgg as FigureCanvas

class CustomMainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setGeometry(300, 300, 800, 400)
        self.setWindowTitle("Real-Time Plotting")

        self.frame = QFrame(self)
        self.layout = QGridLayout()
        self.frame.setLayout(self.layout)
        self.setCentralWidget(self.frame)

        self.canvas = FigureCanvas(Figure())
        self.layout.addWidget(self.canvas, 0, 0)

        self.button = QPushButton("Start Plotting")
        self.button.clicked.connect(self.start_plotting)
        self.layout.addWidget(self.button, 1, 0)

        self.x_data = []
        self.y_data = []
        self.timer = QTimer()
        self.timer.timeout.connect(self.update_plot)

    def start_plotting(self):
        self.timer.start(100)  # Update every 100ms

    def update_plot(self):
        self.x_data.append(len(self.x_data))
        self.y_data.append(np.random.rand())
        self.canvas.figure.clear()
        ax = self.canvas.figure.add_subplot(111)
        ax.plot(self.x_data, self.y_data, 'b-')
        ax.set_xlim(0, 100)
        self.canvas.draw()

if __name__ == '__main__':
    app = QApplication(sys.argv)
    window = CustomMainWindow()
    window.show()
    sys.exit(app.exec_())

In this example, pressing a button starts a timer that updates the plot, providing an interactive GUI experience.

Method 3: Using plt.pause() for Interactive Updates

If you prefer a more straightforward approach, you can use plt.pause() to refresh the plot without blocking the loop:

import matplotlib.pyplot as plt
import numpy as np

plt.ion()  # Turn on interactive mode
fig = plt.figure()
plt.axis([0, 1000, 0, 1])

x, y = [], []
for i in range(1000):
    temp_y = np.random.random()
    x.append(i)
    y.append(temp_y)
    plt.scatter(i, temp_y)
    plt.pause(0.05)  # Pause for a brief moment to allow the plot to update

This method enables minimal interactivity and is easy to implement for simple applications.

Method 4: Explore Alternative Libraries like Bokeh

For a highly responsive plotting experience in web environments, consider using bokeh. Here’s an example:

from bokeh.plotting import curdoc, figure
import random

p = figure(title="Real-Time Data", x_axis_label='x', y_axis_label='y')
source = ColumnDataSource(data=dict(x=[], y=[]))

p.circle('x', 'y', source=source)

def update():
    new_data = dict(x=[i], y=[random.random()])
    source.stream(new_data, rollover=200)

curdoc().add_root(p)
curdoc().add_periodic_callback(update, 100)

To run this, save it to app.py, and execute it with bokeh serve --show app.py. Bokeh leverages modern web technologies to provide a slick user experience.

FAQs on Solved How to Plot in Real-Time Using Python Matplotlib

Q: How can I achieve smoother real-time updates when plotting data?

A: You can use the animation API in Matplotlib, especially with the blit option enabled. This avoids redrawing the background, making updates significantly faster.

Q: Can I use libraries other than Matplotlib for real-time plotting?

A: Yes, libraries like Bokeh and Plotly offer excellent support for real-time plotting and may provide web-based interfaces for enhanced user experiences.

Q: What is the benefit of using PyQt for plotting?

A: PyQt allows embedding Matplotlib into a GUI application, offering users enhanced interactivity and customization options for data visualization.

Q: Is plt.pause() the best method for real-time plotting?

A: While plt.pause() is easy to use, it may not be the most efficient for complex data visualizations; consider using the animation API or other libraries for better performance.

Q: Are there any performance concerns with real-time plotting?

A: Yes, performance can decrease when many updates occur rapidly. It is important to optimize redraw functions and consider using blitting or libraries like Bokeh for smoother experiences.
