Preserving Key Case in ConfigParser While Reading Configuration Files

Have you ever faced an issue with the ConfigParser module in Python where reading configuration file keys results in their conversion to lower case? Let’s explore this phenomenon, its causes, and the solutions available to maintain the original casing of your keys.

The Issue Explained

Consider the following Python script that reads from a configuration file named Config.ini:

import ConfigParser

class ConfReader(object):
    ConfMap = dict()

    def __init__(self):
        self.config = ConfigParser.ConfigParser()
        self.config.read('./Config.ini')
        self.__loadConfigMap()

    def __loadConfigMap(self):
        for sec in self.config.sections():
            for key, value in self.config.items(sec):
                print('key = ', key, 'Value = ', value)
                keyDict = str(sec) + '_' + str(key)
                print('keyDict = ' + keyDict) 
                self.ConfMap[keyDict] = value

    def getValue(self, key):
        value = ''
        try:
            print('Key = ', key)
            value = self.ConfMap[key] 
        except KeyError as KE:
            print('Key', KE, ' didn\'t found in configuration.')
        return value

class MyConfReader(object):
    objConfReader = ConfReader()

def main():
    print(MyConfReader().objConfReader.getValue('DB2.poolsize'))
    print(MyConfReader().objConfReader.getValue('DB_NAME'))

if __name__=='__main__':
    main()

The Config.ini file associated with this script looks like this:

[DB]
HOST_NAME=localhost
NAME=temp
USER_NAME=postgres
PASSWORD=mandy

Upon executing this program, you may observe that the keys (HOST_NAME, USER_NAME, etc.) have been altered to lower case when accessed. This behavior can be confusing and requires clarification.

Why Are Keys Converted to Lower Case?

According to the official Python documentation , the ConfigParser is designed to access keys in a case-insensitive manner by default. This is because it is built to handle Windows INI files, which are typically parsed without regard to key case sensitivity.

How to Maintain Key Case

To avoid automatic conversion of keys to lower case, you can override the default behavior of ConfigParser using the optionxform method. Here’s how to do that:

self.config = ConfigParser.ConfigParser()
self.config.optionxform = str

By setting optionxform to str, you ensure that the keys are read exactly as they are defined in the configuration file, preserving their original casing.

Practical Example with Adjusted Code

Here’s a modified version of the earlier code that implements the above solution:

import ConfigParser

class EnhancedConfReader(object):
    ConfMap = dict()

    def __init__(self):
        self.config = ConfigParser.ConfigParser()
        # Preserve case of keys
        self.config.optionxform = str  
        self.config.read('./Config.ini')
        self.__loadConfigMap()

    def __loadConfigMap(self):
        for sec in self.config.sections():
            for key, value in self.config.items(sec):
                print('key = ', key, 'Value = ', value)
                keyDict = f"{sec}_{key}"  # modern string formatting
                print('keyDict = ' + keyDict) 
                self.ConfMap[keyDict] = value

    def getValue(self, key):
        value = ''
        try:
            print('Key = ', key)
            value = self.ConfMap[key]
        except KeyError as KE:
            print('Key', KE, ' didn\'t found in configuration.')
        return value

class CustomConfReader(object):
    objConfReader = EnhancedConfReader()

def main():
    print(CustomConfReader().objConfReader.getValue('DB_DB2.poolsize'))
    print(CustomConfReader().objConfReader.getValue('DB_NAME'))

if __name__ == '__main__':
    main()

In this snippet, by setting optionxform to str, the original casing of the keys in the configuration file will be preserved during access.

Alternative Approaches

If you are looking for different ways to handle configuration management in Python, consider the following alternatives:

  1. Using JSON files: JSON respects key casing and is widely used. Example read:

    import json

with open('config.json', 'r') as file:
    config = json.load(file)
    print(config['DB']['HOST_NAME'])

  2. Using YAML files: YAML also supports case-sensitive keys and is easy to read.

  3. Environment Variables: For sensitive information, storing critical config values as environment variables can enhance security.

FAQs on Preserving Key Case in ConfigParser

Q: Why does ConfigParser convert keys to lower case?

A: ConfigParser is designed to parse Windows INI files in a case-insensitive manner, which means all keys are automatically converted to lower case by default.

Q: How can I keep the original key casing when reading config files?

A: You can preserve key casing by setting the optionxform property of the ConfigParser instance to str, which prevents keys from being modified when accessed.

Q: Are there alternatives to ConfigParser?

A: Yes, alternatives include using JSON or YAML files for configuration management, which maintain key casing and provide more functionality.
