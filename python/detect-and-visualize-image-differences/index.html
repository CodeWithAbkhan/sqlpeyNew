How Can You Detect and Visualize Differences Between Two Images Using OpenCV in Python?

Are you looking to effectively highlight the differences between two images with Python? This guide walks you through two distinct methods that utilize OpenCV and the Structural Similarity Index (SSIM) for image comparison. Whether you’re working on quality assurance, visual comparison tasks or simply enhancing your image processing skills, these methods will help you quickly identify discrepancies.

Goal:

The objective is to emphasize the differences between two images, allowing a user to spot changes virtually instantaneously. By applying color to these discrepancies, users can achieve a clearer understanding of what has changed.

Current Approach:

Your existing method involves generating a mask that highlights differences in red. However, it may not capture all details accurately, as illustrated. For example, minor features might be faintly detected, leading to missed discrepancies that you’d rather highlight.

Current Code Implementation:

import cv2

# Load images
image1 = cv2.imread("leftImage.jpg")
image2 = cv2.imread("rightImage.jpg")

# Compute the difference
difference = cv2.subtract(image1, image2)

# Convert to grayscale and create the mask
Conv_hsv_Gray = cv2.cvtColor(difference, cv2.COLOR_BGR2GRAY)
ret, mask = cv2.threshold(Conv_hsv_Gray, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)
difference[mask != 255] = [0, 0, 255]

# Overlay the red mask on both images
image1[mask != 255] = [0, 0, 255]
image2[mask != 255] = [0, 0, 255]

# Save the images
cv2.imwrite('diffOverImage1.png', image1)
cv2.imwrite('diffOverImage2.png', image1)
cv2.imwrite('diff.png', difference)

Method #1: Utilizing Structural Similarity Index (SSIM)

A robust approach to identifying differences is through the Structural Similarity Index (SSIM), which quantifies discrepancies between two images. SSIM considers changes in structural information, providing a more human-perceptive difference allocation.

Installation: Use the following command to add the required library:

pip install scikit-image

Implementation:

from skimage.metrics import structural_similarity
import cv2
import numpy as np

# Load the images
before = cv2.imread('left.jpg')
after = cv2.imread('right.jpg')

# Convert to grayscale
before_gray = cv2.cvtColor(before, cv2.COLOR_BGR2GRAY)
after_gray = cv2.cvtColor(after, cv2.COLOR_BGR2GRAY)

# Compute SSIM
(score, diff) = structural_similarity(before_gray, after_gray, full=True)
print("Image Similarity: {:.4f}%".format(score * 100))

# Process the difference
diff = (diff * 255).astype("uint8")
diff_box = cv2.merge([diff, diff, diff])

# Thresholding and finding contours
thresh = cv2.threshold(diff, 0, 255, cv2.THRESH_BINARY_INV | cv2.THRESH_OTSU)[1]
contours = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
contours = contours[0] if len(contours) == 2 else contours[1]

# Highlight differences
for c in contours:
    area = cv2.contourArea(c)
    if area > 40:
        x, y, w, h = cv2.boundingRect(c)
        cv2.rectangle(before, (x, y), (x + w, y + h), (36, 255, 12), 2)
        cv2.rectangle(after, (x, y), (x + w, y + h), (36, 255, 12), 2)

# Display results
cv2.imshow('Before', before)
cv2.imshow('After', after)
cv2.waitKey()

Advantages of This Method:

  • Increased accuracy in highlighting differences.
  • More effective visualization through bounding boxes around variations.

Method #2: OpenCV Absolute Difference

The second method employs the built-in OpenCV function cv2.absdiff, which calculates the absolute difference between two images.

Implementation:

import cv2

# Load the images
image1 = cv2.imread("left.jpg", 0)
image2 = cv2.imread("right.jpg", 0)

# Calculate absolute difference
diff = cv2.absdiff(image1, image2)
diff = 255 - diff  # Invert for visualization

# Show the difference
cv2.imshow('Difference', diff)
cv2.waitKey()

Why Choose SSIM Over Absolute Difference?

While cv2.absdiff is simpler and straightforward, it may not effectively depict similarity or provide accurate difference insights compared to SSIM, particularly where nuances exist in images.

FAQs on Detect and Visualize Differences Between Two Images

Q: How do you ensure the output images accurately reflect the differences?

A: It’s essential to preprocess the images effectively and consider using formats that preserve quality, such as PNG, to avoid compression artifacts affecting the results.

Q: Are these methods suitable for real-time applications?

A: The performance may vary based on the image complexity and size. For real-time applications, optimizations may be necessary, especially when processing high-resolution images.

Q: Can I compare images of different sizes?

A: Both methods outlined work best with images of the same dimensions. If your images differ in size, consider resizing or utilizing object detection techniques for more effective analysis.
