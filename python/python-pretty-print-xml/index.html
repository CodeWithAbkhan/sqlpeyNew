“Python: How to Pretty Print XML”

Using Built-in Libraries

Python’s standard library offers tools that can achieve XML pretty printing without requiring external installations.

xml.dom.minidom

The minidom module is part of Python’s standard XML processing suite and provides a straightforward method for pretty printing.

import xml.dom.minidom

xml_fname = 'your_document.xml' # or xml_string = '<root><item>value</item></root>'

# Parse the XML file or string
dom = xml.dom.minidom.parse(xml_fname) 
# Or for a string: dom = xml.dom.minidom.parseString(xml_string)

# Generate a pretty-printed XML string
pretty_xml_as_string = dom.toprettyxml()

print(pretty_xml_as_string)

While minidom is readily available, it can sometimes introduce extra blank lines. A common workaround involves filtering these out:

import xml.dom.minidom
import os

def format_xml_string(xml_string):
    """Formats an XML string and removes excessive newlines."""
    dom = xml.dom.minidom.parseString(xml_string)
    pretty_xml = dom.toprettyxml()
    # Remove the default XML declaration if present and then filter empty lines
    lines = pretty_xml.splitlines()
    filtered_lines = [line for line in lines if line.strip()]
    return os.linesep.join(filtered_lines)

# Example usage:
ugly_xml_content = "<data><user><id>101</id><name>Alice</name></user></data>"
formatted_xml = format_xml_string(ugly_xml_content)
print(formatted_xml)

This approach yields a cleaner output by ensuring each line has content.

xml.etree.ElementTree (Python 3.9+)

For Python versions 3.9 and later, ElementTree includes a dedicated indent() function, simplifying the pretty printing process.

import xml.etree.ElementTree as ET

# Create an ElementTree element
element = ET.XML("<html lang='en'><head><title>Sample</title></head><body><p>Content</p></body></html>")

# Apply indentation
ET.indent(element, space="  ") # Use spaces for indentation

# Convert back to a string
pretty_xml_string = ET.tostring(element, encoding='unicode')

print(pretty_xml_string)

This method is efficient as it’s part of the standard library and doesn’t require extra installations. For earlier Python versions, custom functions are needed, such as the one below:

from xml.etree import ElementTree

def custom_indent(elem, level=0):
    """Custom indentation function for ElementTree."""
    i = "\n" + level*"  "
    j = "\n" + (level-1)*"  "
    if len(elem):
        if not elem.text or not elem.text.strip():
            elem.text = i + "  "
        if not elem.tail or not elem.tail.strip():
            elem.tail = i
        for subelem in elem:
            custom_indent(subelem, level+1)
        if not elem.tail or not elem.tail.strip():
            elem.tail = j
    else:
        if level and (not elem.tail or not elem.tail.strip()):
            elem.tail = j
    return elem

# Example usage:
root = ElementTree.parse('your_file.xml').getroot()
custom_indent(root)
ElementTree.dump(root)

Using External Libraries

External libraries often provide more advanced features and flexibility for XML manipulation, including sophisticated pretty printing.

lxml

The lxml library is a powerful and fast XML processing tool that integrates well with Python. It offers a direct pretty_print option.

from lxml import etree

xml_file_path = "input_data.xml"

# Parse the XML file
tree = etree.parse(xml_file_path)

# Serialize the tree with pretty printing
# encoding=str ensures a string output, not bytes
pretty_xml_output = etree.tostring(tree, pretty_print=True, encoding='unicode') 

print(pretty_xml_output)

When dealing with potentially complex XML structures or ensuring specific formatting, lxml provides fine-grained control. For instance, to preserve CDATA sections and specify UTF-8 encoding:

from lxml import etree

def format_xml_with_lxml(input_path, output_path):
    """Formats an XML file using lxml, preserving CDATA and specifying encoding."""
    parser = etree.XMLParser(resolve_entities=False, strip_cdata=False)
    document = etree.parse(input_path, parser)
    document.write(output_path, pretty_print=True, encoding='utf-8')

# Example: format_xml_with_lxml('source.xml', 'formatted.xml')

BeautifulSoup

While primarily known for HTML parsing, BeautifulSoup can also parse XML and offers a .prettify() method.

from bs4 import BeautifulSoup

xml_file = 'data_input.xml'

with open(xml_file, 'r', encoding='utf-8') as f:
    # Use 'xml' parser for XML documents
    soup = BeautifulSoup(f, 'xml') 
    
    # Get the prettified XML string
    pretty_xml = soup.prettify()
    print(pretty_xml)

This can be a simple solution if you’re already using BeautifulSoup for other tasks.

xmltodict

The xmltodict library is excellent for converting XML to Python dictionaries and back. It also supports pretty printing during the unparsing process.

import xmltodict

my_xml_string = "<root><item key='val'>data</item></root>"

# Parse XML to a dictionary
data_dict = xmltodict.parse(my_xml_string)

# Unparse the dictionary back to a pretty XML string
# full_document=False prevents adding the <?xml version="1.0" encoding="UTF-8"?> header
pretty_xml_output = xmltodict.unparse(data_dict, full_document=False, pretty=True)

print(pretty_xml_output)

vkbeautify

This library offers straightforward methods for pretty printing XML, JSON, and CSS without external dependencies.

import vkbeautify as vkb

# Pretty print XML from a string
pretty_string_output = vkb.xml(text_xml_data)
print(pretty_string_output)

# Pretty print XML from a file to stdout
# vkb.xml('path/to/source.xml') 

# Pretty print XML from a string to a file
# vkb.xml(text_xml_data, 'path/to/destination.xml')

Handling Specific Formatting Issues

Some solutions address common formatting quirks, such as excessive whitespace or text nodes that appear on their own lines.

One method involves using a regular expression with xml.dom.minidom to clean up text nodes:

import xml.dom.minidom
import re

ugly_xml_string = "<data><item>Value One</item><item>Value Two</item></data>"

dom = xml.dom.minidom.parseString(ugly_xml_string)
ugly_formatted = dom.toprettyxml(indent='  ')

# Regex to consolidate text nodes
text_regex = re.compile(r'>\s+([^<>]+?)\s+<', re.DOTALL)
pretty_formatted = text_regex.sub(r'>\1<', ugly_formatted)

print(pretty_formatted)

This regex targets whitespace between tags and captures the content, effectively removing extraneous newlines around text.

Programmatic Indentation with ElementTree

For finer control over indentation with ElementTree (especially in older Python versions), a recursive function can be implemented:

from xml.etree import ElementTree

def custom_pretty_print(element, indent_level=0, indent_char='  '):
    """Recursively indents an ElementTree element."""
    children = list(element)
    if children:
        element.text = '\n' + indent_char * (indent_level + 1)
        for i, child in enumerate(children):
            custom_pretty_print(child, indent_level + 1, indent_char)
            if i < len(children) - 1:
                child.tail = '\n' + indent_char * (indent_level + 1)
            else:
                child.tail = '\n' + indent_char * indent_level
    else:
        if indent_level and (not element.tail or not element.tail.strip()):
            element.tail = '\n' + indent_char * (indent_level - 1)

# Example usage:
root_element = ElementTree.parse('input.xml').getroot()
custom_pretty_print(root_element)
ElementTree.dump(root_element)

Leveraging External Tools via Subprocess

If you have command-line XML tools like xmllint installed, you can utilize Python’s subprocess module to format XML files.

import subprocess

def format_xml_with_xmllint(filepath):
    """Formats an XML file using xmllint via subprocess."""
    try:
        # Execute xmllint --format command
        process = subprocess.run(
            ['xmllint', '--format', filepath],
            capture_output=True,
            text=True,
            check=True
        )
        # Write the formatted output back to the file
        with open(filepath, "w", encoding="utf-8") as outfile:
            outfile.write(process.stdout)
        print(f"Successfully formatted: {filepath}")
    except subprocess.CalledProcessError as e:
        print(f"Error formatting {filepath}: {e}")
    except FileNotFoundError:
        print("xmllint command not found. Ensure it is installed and in your PATH.")

# Example usage (ensure xmllint is installed):
# format_xml_with_xmllint("my_ugly_xml.xml")

This approach is effective on Unix-like systems where xmllint is commonly available.

Combining Libraries for Specific Needs

Sometimes, a combination of libraries can address unique formatting challenges. For example, using lxml for parsing and minidom for a specific output format:

from lxml import etree
import xml.dom.minidom as mmd

xml_file_path = 'data.xml'

try:
    # Parse with lxml
    xml_root = etree.parse(xml_file_path, etree.XMLParser())
    
    # Convert to string, then remove all whitespace
    plain_xml_string = etree.tostring(xml_root).decode('utf-8')
    compact_xml = ''.join(plain_xml_string.split())
    
    # Parse the compact XML with minidom for pretty printing
    good_xml_dom = mmd.parseString(compact_xml)
    
    # Print with desired indentation
    print(good_xml_dom.toprettyxml(indent='    '))

except FileNotFoundError:
    print(f"Error: File not found at {xml_file_path}")
except Exception as e:
    print(f"An error occurred: {e}")

This method leverages lxml’s parsing speed and then uses minidom’s toprettyxml for formatted output, proving useful for international character support.

FAQs on Python XML Pretty Printing

FAQs on Python XML Pretty Printing

Q: What is the easiest way to pretty print XML in Python

ANS: For Python 3.9+, xml.etree.ElementTree.indent() is the most straightforward built-in method. For older versions or more advanced control, lxml with etree.tostring(..., pretty_print=True) is highly recommended.

Q: Does xml.dom.minidom handle all XML structures correctly

ANS: xml.dom.minidom is a capable standard library module, but it can sometimes produce extra blank lines or mishandle certain complex text node arrangements compared to more specialized libraries like lxml. Workarounds exist to clean its output.

Q: Can I pretty print XML without installing external libraries

ANS: Yes, Python’s built-in xml.dom.minidom module can be used for pretty printing. For Python 3.9+, xml.etree.ElementTree.indent() offers a simpler, built-in solution.

Q: How do I handle CDATA sections when pretty printing XML

ANS: When using lxml, ensure you set strip_cdata=False in the XMLParser to preserve CDATA sections during pretty printing.

Q: What are some alternatives to pretty printing XML in Python

ANS: Besides minidom and ElementTree, popular external libraries like lxml, BeautifulSoup, xmltodict, and vkbeautify offer various methods for XML pretty printing, each with its own strengths.
