Displaying images in an IPython notebook can often be challenging, especially when working with the Python Imaging Library (PIL). If you’ve tried merely using print statements or displaying the image object without success, you’re not alone. Below are many approaches on how to effectively showcase PIL images in your Jupyter notebook, ensuring you can manipulate and present your images with ease.

Practical Examples of Displaying PIL Images:

Suppose you have an image file named empire.jpg located in the data directory, and you want to display it. Below are several methods to achieve this.

Method 1: Using IPython’s Display Function

One of the simplest ways to show PIL images in a Jupyter notebook is to use the display function from IPython:

from PIL import Image  # Importing the Image class from PIL
from IPython.display import display  # Importing display for visual output

## Load the image
image_path = 'data/empire.jpg'
pil_im = Image.open(image_path)

## Render the image
display(pil_im)

Method 2: Create a Custom Display Function

If you want more control or need to render images dynamically, you can create a custom display function:

from PIL import Image
from IPython import display
from io import BytesIO

def display_pil_image(im):
    """Render a PIL image as PNG."""
    buffer = BytesIO()
    im.save(buffer, format='png')
    data = buffer.getvalue()
    
    # Display the image using IPython's HTML
    return display.Image(data=data, format='png', embed=True)._repr_png_()

## Ensure to call the function after executing your image loading code
display_pil_image(pil_im)  # Call to display the image

Method 3: Directly Displaying in Jupyter

For a direct approach in Jupyter, simply showing the image object can suffice:

from PIL import Image

## Open and display the image
image0 = Image.open('data/empire.jpg')
image0  # This should be the last line in your cell

Method 4: Using HTML for Inline Display

This method utilizes HTML to project images inline. It’s especially useful for integrating images with other HTML outputs.

from PIL import Image
from IPython.display import HTML
from io import BytesIO
from base64 import b64encode

## Open the image and prepare it for display
image_path = 'data/empire.jpg'
pil_im = Image.open(image_path)
buffer = BytesIO()
pil_im.save(buffer, format='png')

## Display inline using HTML
HTML("<img src='data:image/png;base64,{0}'/>".format(b64encode(buffer.getvalue()).decode('utf-8')))

Method 5: Visualizing with Matplotlib

The matplotlib library is another effective tool for visualizing images:

import matplotlib.pyplot as plt
from PIL import Image

## This line ensures plots will display in the notebook
%matplotlib inline

## Load and show the image
img = Image.open('data/empire.jpg')
plt.imshow(img)
plt.axis('off')  # Hide axes
plt.show()  # Render the image

Method 6: Using Numpy and Matplotlib

For those comfortable with numpy, you can convert PIL images and display them:

import numpy as np
import matplotlib.pyplot as plt
from PIL import Image

## Load and convert the image to a numpy array
pil_im = Image.open('data/empire.jpg')
img_array = np.asarray(pil_im)

## Display using matplotlib
plt.imshow(img_array)
plt.axis('off')  # Hide axes
plt.show()

Method 7: Using IPython Display Directly

A straightforward approach is utilizing the IPython display function for images:

from IPython.display import Image
img = Image('data/empire.jpg')
img # This will render the image

Alternative Approaches:

  • Using ImageMagick: If you need advanced processing capabilities, using ImageMagick in conjunction with PIL through your command line could provide additional options. Install it via:

    sudo apt-get install imagemagick

  • Web-Hosted Images: You can also display images hosted online directly by using their URLs.

FAQs on Displaying PIL Images in IPython Notebook

Q: What is PIL?

A: The Python Imaging Library (PIL) allows for opening, manipulating, and saving various image file formats.

Q: Why can't I see my image using print?

A: Simply using print will not render the image; it only displays the image object. You should use the display functions provided by IPython for rendering images.

Q: Can I display images from URLs?

A: Yes, you can fetch images from URLs using libraries such as requests and display them directly, as demonstrated in the provided methods.

Q: Do I need to install Pillow?

A: Yes, if you’re using PIL, ensure that Pillow is installed in your environment by running pip install pillow.

For further reading, check out the Pillow Documentation and the IPython Documentation .
