Top 10 Methods to Strip HTML from Strings in Python

When dealing with web data or user-generated content, one common task is to strip HTML tags from strings to extract readable text. Python provides a plethora of ways to accomplish this, from simple regex patterns to sophisticated libraries designed for robust HTML processing. Below are the most effective methods to clean HTML content from strings in Python:

Method 1: Using Regular Expressions

A fundamental approach is to leverage regular expressions with the re module. While this method is straightforward, it is essential to remember that it is not recommended for sanitizing user-generated content due to possible security vulnerabilities.

import re

def strip_html_tags(text):
    return re.sub(r'<[^<]+?>', '', text)

example_text = "<p>Hello, <strong>world!</strong></p>"
print(strip_html_tags(example_text))  # Output: Hello, world!

Method 2: BeautifulSoup

The BeautifulSoup library is renowned for its ease of use and powerful capabilities in parsing HTML and XML documents.

from bs4 import BeautifulSoup

html_content = '<td><a href="http://example.com">Click here</a></td>'
soup = BeautifulSoup(html_content, 'html.parser')
print(soup.get_text())  # Output: Click here

Method 3: Using HTMLParser

Python’s built-in HTMLParser module provides a way to strip HTML tags from strings, extracting the raw text effectively.

from html.parser import HTMLParser

class MLStripper(HTMLParser):
    def __init__(self):
        super().__init__()
        self.result = []

    def handle_data(self, data):
        self.result.append(data)

    def get_data(self):
        return ''.join(self.result)

def strip_html(html):
    s = MLStripper()
    s.feed(html)
    return s.get_data()

example_html = '<div>Hello <i>world!</i></div>'
print(strip_html(example_html))  # Output: Hello world!

Method 4: lxml

lxml is a powerful library for handling XML and HTML, often faster and more reliable than others and provides a simple way to convert HTML to text.

from lxml import html

def strip_html_with_lxml(html_content):
    tree = html.fromstring(html_content)
    return tree.text_content()

print(strip_html_with_lxml('<p>Sample <strong>text</strong></p>'))  # Output: Sample text

Method 5: Custom Function to Remove Tags

For those who prefer a DIY approach, creating a custom function can prove useful to understand how HTML parsing works.

def remove_html_markup(text):
    tag = False
    out = ""
    for char in text:
        if char == '<':
            tag = True
        elif char == '>':
            tag = False
        elif not tag:
            out += char
    return out

print(remove_html_markup('<p>Test <a>link</a></p>'))  # Output: Test link

Method 6: Django’s strip_tags

If you are working within a Django application, you can utilize Django’s built-in helper to strip tags.

from django.utils.html import strip_tags

text = "<div>Strip <b>bold</b> text.</div>"
clean_text = strip_tags(text)
print(clean_text)  # Output: Strip bold text.

Method 7: Bleach Library for Sanitization

If you need to sanitize HTML while also stripping tags, the Bleach library provides great flexibility, allowing you to specify tags and attributes to keep or remove.

import bleach

raw_html = "<script>alert('xss');</script><p>Safe content.</p>"
clean_html = bleach.clean(raw_html, tags=[], attributes={}, strip=True)
print(clean_html)  # Output: Safe content.

Method 8: Regex with HTML Unescape

For cases where you want to escape HTML entities while stripping tags, combining regex with html.unescape is effective.

import re
import html

def html_to_text(html_string):
    unescaped = html.unescape(html_string)
    return re.sub(r'<[^>]+>', '', unescaped)

print(html_to_text('&lt;div&gt;Hello&lt;/div&gt;'))  # Output: Hello

Method 9: Using mechanize

If you are retrieving HTML from a webpage using mechanize, you can combine the above methods after loading the webpage.

from mechanize import Browser

br = Browser()
br.open('http://example.com')
html = br.response().read()
print(strip_html(html.decode('utf-8')))  # Output with the defined strip_html function

Method 10: Writing a Simple Parser

Developing a basic custom parser can also serve educational purposes, showcasing how you can refine tag detection and removal.

def simple_html_parser(html):
    output = []
    inside_tag = False
    for char in html:
        if char == '<':
            inside_tag = True
        elif char == '>':
            inside_tag = False
        elif not inside_tag:
            output.append(char)
    return ''.join(output)

print(simple_html_parser('<b>Hello</b> World'))  # Output: Hello World

FAQs on Top 10 Methods to Strip HTML from Strings in Python

Q: Is it safe to strip HTML tags from user input?

A: No, stripping HTML tags does not sanitize input. Always ensure to escape or sanitize content to prevent XSS vulnerabilities.

Q: Which method is the fastest for stripping HTML?

A: The performance varies based on the complexity of HTML. lxml is generally faster, while regex can be the quickest for simple well-formed tags.

Q: Can BeautifulSoup and lxml be used together?

A: Yes, you can preprocess HTML with BeautifulSoup and then pass it to lxml for further operations.
