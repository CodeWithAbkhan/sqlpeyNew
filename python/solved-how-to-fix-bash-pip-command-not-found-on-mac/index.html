Solved: How to Fix ‘bash: pip: command not found’ on Mac

Python Development
4 min read · Dec 5, 2024

Table of Contents

    • Top 8 Ways to Resolve ‘bash: pip: command not found’ on Mac
    • Additional Resources
    • FAQs on How to Fix ‘bash pip command not found’

When you encounter the frustrating error message bash: pip: command not found after completing your pip installation steps on Mac OS X, you might wonder what went wrong. This error often arises from issues related to incorrect path settings or environmental variables. If you’ve downloaded pip and executed python setup.py install successfully but run into this stumbling block trying to install packages, do not worry. Here, we provide a comprehensive guide to troubleshoot and solve this issue effectively.

Top 8 Ways to Resolve ‘bash: pip: command not found’ on Mac

Prerequisites

Before diving into solutions, ensure you have Python installed. You can check your installation by opening the terminal and typing:

python3 --version

This confirms whether Python is available on your system.

Solution 1: Install pip for Python 3

If you haven’t done so already, make sure you install pip3 specifically targeted for Python 3. You can do this using Homebrew or directly through terminal commands. For the latest Debian/Ubuntu versions, the command is:

sudo apt-get install python3-pip

Solution 2: Use pip3 Instead of pip

In recent versions of Python, pip may refer to Python 2, while pip3 targets Python 3. To verify if pip3 is working, run:

pip3 --version

If it’s available, you can use it in place of pip for your installations:

pip3 install <package_name>

Solution 3: Access pip via Python Module

A reliable way to access pip is by using the command:

python3 -m pip install <package_name>

This method ensures that you are invoking the correct pip for the Python version you’re using.

Solution 4: Update Your PATH Variable

If pip was installed but is still not recognized in your terminal, you may need to add its installation path to your $PATH variable. Here’s how to do that:

  1. Open your profile file (this could be ~/.bash_profile, ~/.bashrc, or ~/.zshrc depending on your shell):
nano ~/.bash_profile
  1. Add the following line at the end of the file (adjust the path according to your Python version):
export PATH="/Library/Frameworks/Python.framework/Versions/3.x/bin:$PATH"
  1. Load the updated configuration:
source ~/.bash_profile

Solution 5: Install using get-pip.py

If pip was not installed correctly, try downloading the get-pip.py script directly from the official pip repository:

curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
sudo python3 get-pip.py

After installation, check if pip is set up correctly:

pip3 --version

Solution 6: Create Aliases for Commands

For easier access, you can create an alias in your ~/.bash_profile:

alias pip='python3 -m pip'

Then refresh your file:

source ~/.bash_profile

Now you can simply use pip install <package_name>.

Solution 7: Verify Python and Pip Installations

Make sure both Python and pip are correctly installed. You can verify them:

which python3
which pip3

If these commands return the paths, everything should be set up correctly.

Solution 8: Use Homebrew to Install Python

If you’re still having trouble, consider installing Python through Homebrew, which typically configures everything automatically:

brew install python

This approach also installs pip automatically.

FAQs on How to Fix ‘bash pip command not found’

Q: Why does my terminal say 'pip: command not found' after installation?

A: This is often due to the pip executable not being in your PATH environment variable, meaning your terminal doesn’t know where to look for the pip command. Follow the steps provided above to update your PATH.

Q: Is pip installed with Python?

A: Yes, pip is included by default with Python 3 installations from the official Python website. However, if you use a version manager or install via a method like Homebrew, pip may need to be installed separately.

Q: What's the difference between pip and pip3?

A: pip usually refers to the package manager for Python 2, whereas pip3 specifically refers to Python 3. You should use pip3 if you are working with Python 3.x.
