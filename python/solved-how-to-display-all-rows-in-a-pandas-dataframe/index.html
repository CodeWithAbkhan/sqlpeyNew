Solved: How to Display All Rows in a Pandas DataFrame

In working with data analysis using Pandas, you may encounter situations where you need to display all rows of a DataFrame. By default, Jupyter notebooks restrict the number of visible rows to a manageable number to maintain readability. If you’re like me, you may have asked yourself: How can I see all the rows in a DataFrame? Let’s explore various methods to tackle this problem.

Problem Overview

Let’s define a sample DataFrame as follows:

import pandas as pd
import numpy as np

n = 100
foo = pd.DataFrame(index=range(n))
foo['floats'] = np.random.randn(n)
foo

When viewing foo in an IPython notebook, you will notice that not all rows are displayed. Attempting to change the display settings with:

pd.set_option('display.max_rows', 500)

may not yield the desired result in Jupyter Notebook.

Solution 1: Basic Setting

The basic approach to try displaying more rows would be:

pd.set_option('display.max_rows', 500)
foo.head(500)  # Still limits the output to the head

However, this does not work to display the entire DataFrame.

Solution 2: Using pd.options

An effective method is to set the options directly with an assignment, which benefits from autocompletion in various IDEs. For instance:

pd.options.display.max_rows = 100

To check the current setting:

print(pd.options.display.max_rows)

This output allows you to swiftly identify how many rows are being shown.

Solution 3: Adjusting Minimum Rows

Setting 'display.min_rows' can also help:

pd.set_option('display.min_rows', 500)  # Adjust according to your requirement
pd.set_option('display.max_rows', 500)  # Ensure you adjust max as well

Be mindful that if the total number of rows exceeds display.max_rows, then simply adjusting display.max_rows won’t affect the output.

Solution 4: Display with Context Manager

If you need a more controlled context, use the following method with display:

from IPython.display import display

with pd.option_context("display.max_rows", foo.shape[0]):
    display(foo)

This command will render the DataFrame foo, adapting to the number of rows dynamically.

Solution 5: Unlimited Rows

To present all rows regardless of the count, you can set the configuration option to None:

pd.set_option('display.max_rows', None)  # This will display all rows

Solution 6: Context Management

Using a context manager might be the best option to restrict the effect of your settings to specific parts of your code:

with pd.option_context('display.min_rows', 50, 'display.max_columns', None):
    print(foo)

Solution 7: Deprecated Options

Since Pandas 0.18.1, note that the display.height option is deprecated. Always default to display.max_rows.

Solution 8: Direct String Output

For a simple display that avoids these settings entirely, consider:

print(foo.to_string())  # This prints the full DataFrame as a string

Solution 9: Configuration Reset

In some cases, if you want to revert to display defaults after changing, you can reset:

pd.reset_option('display.max_rows')  # Reset just this option

If you want to revert all options:

pd.reset_option('all')  # Resets all display options

FAQs on Displaying Rows in Pandas DataFrame

Q: How do I view all rows of a DataFrame in Jupyter Notebook?

A: One way to view all rows is by setting the maximum rows option to None using pd.set_option('display.max_rows', None). You can also use the display function from IPython within a context manager to dynamically adjust settings.

Q: Can I set a limit to the number of rows displayed?

A: Yes, you can limit the number of rows displayed by using pd.set_option('display.max_rows', <number>), replacing <number> with your desired limit.

Q: Is there a simple command to show all data in a DataFrame?

A: Yes! You can use print(df.to_string()) to display the entire DataFrame without truncation.
