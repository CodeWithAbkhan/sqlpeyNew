Changing the default Anaconda Python environment can streamline your workflow, especially if you often use a version of Python other than the default one (which is usually Python 2.7). Here’s how to set a specific Anaconda environment as the default without needing to reinstall everything. Below are several methods for both Mac/Linux and Windows users.

TopMethods to Set Anaconda’s Default Python Environment

Overview

When working with multiple Conda environments, it can be cumbersome to activate the desired environment each time you open a terminal session. With the following solutions, you can set a designated environment (like Python 3.4) as the default, enhancing your productivity.

Solution 1: Modify Shell Initialization File (Mac/Linux)

You can add a command to your shell’s initialization file to automatically activate your desired environment.

  1. Open your terminal.
  2. Edit your .bash_profile or .bashrc file using: 
    nano ~/.bash_profile
  3. Add this line at the end of the file: 
    conda activate py34
  4. Save the file and close your editor. Start a new terminal window to see changes. Use: 
    conda info -e
    to verify that py34 is the active environment.

Solution 2: Windows Command File Setup

For Windows users, create a command file that automatically activates your preferred environment.

  1. Create a batch file named my_conda.cmd with the following content: 
    @echo off
activate py34
  2. Place this in the Application Data folder.
  3. Modify the registry to run this file on command prompt startup:
    • Open Registry Editor and navigate to: 
      HKCU\SOFTWARE\Microsoft\Command Processor
    • Add a new string value called AutoRun and set it to: 
      "%AppData%\my_conda.cmd"

Solution 3: Shortcut Modification for Anaconda Prompt

For easier access, modify the properties of your Anaconda Prompt shortcut to always start with your specified environment:

  1. Right-click on the Anaconda Prompt in your start menu and select “Open File Location.”
  2. Duplicate the shortcut, right-click the copy, and select “Properties.”
  3. Change the Target field to: 
    %windir%\system32\cmd.exe "/K" C:\Users\YourUsername\Anaconda3\Scripts\activate.bat C:\Users\YourUsername\Anaconda3\envs\py34
  4. Optionally, set the “Start in” field to set a default folder.

Solution 4: Anaconda Navigator Preferences

If using Anaconda Navigator, you can set your default environment from its preferences:

  1. Open Anaconda Navigator.
  2. Navigate to the “File” menu and select “Preferences.”
  3. In the “Default Environment” dropdown, choose your desired environment (e.g., py34).

Solution 5: Auto-activate Environment in .bashrc

For terminal users who prefer a quick solution, follow these steps:

  1. Open the terminal and use this command: 
    echo 'conda activate py34' >> ~/.bashrc
  2. Reload the terminal or run: 
    source ~/.bashrc

Alternative Methods

  • Using Conda Config to Disable Auto-Activation: If you want to prevent Conda from auto-activating the base environment, run: 
    conda config --set auto_activate_base false
    Then add the desired environment to your shell profile.

Summary of Commands

  • Check Active Environment: 
    conda info -e
  • Activate Desired Environment: 
    conda activate myenv  # Replace with your environment name

Feel free to use any of the methods above that best fit your workflow!

FAQs on Solved How to Change the Default Anaconda Python Environment

Q: Can I have multiple default environments?

A: No, you can only set one environment as the default for activation at startup; however, you can easily switch between environments using conda activate <env_name>.

Q: What if I want a different version of Python?

A: You can create a new environment with the specific Python version you want using:

conda create -n myenv python=3.6  # Replace myenv and version as appropriate

Q: Is it necessary to modify the registry on Windows?

A: It’s not strictly necessary, but it provides a way to automatically activate your chosen environment whenever you open the command prompt. You can also manage your environments directly through the Anaconda Prompt without modifying the registry.
