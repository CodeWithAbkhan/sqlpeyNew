“Efficiently Split Pandas DataFrame into Dictionary of DataFrames by Column Value”

When working with substantial datasets in Python using the pandas library, a common requirement arises: segmenting a single large DataFrame into several smaller ones based on the distinct entries within a categorical column. While direct iteration and filtering work, they are often slow due to repeated operations and potential data copying.

How can one efficiently split a DataFrame, keyed by a column’s unique values, into a collection of separate DataFrames? This article showcases several idiomatic and high-speed approaches leveraging the power of pandas.DataFrame.groupby.

Method 1: Direct Iteration with Boolean Indexing into a Dictionary

One straightforward way involves identifying unique keys and then using standard slicing to populate a dictionary. While conceptually simple, this method can incur performance penalties due to creating multiple filtered copies.

Let’s set up some example data mimicking groups based on a ‘Names’ column:

Method 2: Optimizing with sort_values and set_index (View-Based Access)

Instead of creating many separate objects, an alternative favors keeping the data in one structure but optimizing lookup. By sorting and setting the grouping column as the index (and critically, not dropping it), subsequent selections are faster, potentially returning a view rather than a costly copy, which addresses efficiency concerns related to row-by-row appending.

# Assume initial_df from Method 1 is being used, renaming column to 'name' for demonstration clarity
df_optimized = initial_df.rename(columns={'Names': 'name'})

# Sort the DataFrame based on the grouping column
df_optimized.sort_values(by='name', axis=1, inplace=True)

# Set the index to 'name' but keep the column present (drop=False)
df_optimized.set_index(keys=['name'], drop=False, inplace=True)

# Retrieve unique labels for reference
reference_names = df_optimized['name'].unique().tolist()

Method 7: Creating Global Variables (Discouraged Practice)

Although possible, creating variables dynamically in the global scope (e.g., df_alice, df_bob) is generally discouraged as it pollutes the namespace and makes code maintenance difficult. This is done using the globals() function.

# This replicates the logic from Solution 1 but assigns to globals()
def create_global_dfs(df: pd.DataFrame, split_column: str):
    """Splits DF and assigns resulting frames to global variables."""
    
    # Note: Dropping the column might lose context, it is optional.
    for group_key, sub_frame in df.groupby(split_column):
        # Create a variable name, e.g., df_Alice
        var_name = f'df_{group_key}'
        # Assign the sub_frame to the global scope
        globals()[var_name] = sub_frame.copy()

Method 8: Grouping for Chunking Large DataFrames (Index Arithmetic)

When the goal is to split a large DataFrame into fixed-size chunks rather than by categorical value, index arithmetic combined with groupby on the resulting quotient can be extremely performant, especially when subsequent aggregation is needed.

If we want to break a large DataFrame (1,000,000 rows) into chunks of size 60:

N_ROWS = 1000000
N_COLS = 10

# Method using index arithmetic to create group keys (quotient of index divided by chunk size)
grouping_key_series = large_df.index // CHUNK_SIZE

# Apply groupby using this derived series
large_df_grouped = large_df.groupby(grouping_key_series)
