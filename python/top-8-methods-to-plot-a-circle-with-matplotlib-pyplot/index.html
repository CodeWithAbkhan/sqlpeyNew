Surprisingly, straightforward instructions for drawing a circle using matplotlib.pyplot are hard to come by. If you’re attempting to plot a circle where you define the center as (x, y) and the radius as r, the following guide will provide various methods that not only achieve this but also enhance your data visualization skills with Python.

Below, you will find eight effective solutions for plotting circles, ranging from simple approaches to more advanced techniques.

Method 1: Using plt.Circle()

This is a quick and efficient way to add a circle to an existing plot.

import matplotlib.pyplot as plt

## Create a circle with center (0,0) and radius 0.2
circle = plt.Circle((0, 0), 0.2, color='r', alpha=0.5)

## Add the circle to the current axes
plt.gca().add_patch(circle)

plt.xlim(-1, 1)
plt.ylim(-1, 1)
plt.gca().set_aspect('equal', adjustable='box')
plt.show()

Note: gca() stands for “Get Current Axis”.

Method 2: Plotting Multiple Circles

If you want to visualize several circles, consider using a helper function like circles(). You can find a detailed implementation in this Stack Overflow post .

Here’s how you can achieve that:

import numpy as np
import matplotlib.pyplot as plt

def circles(x, y, radius, color, **kwargs):
    circle = plt.Circle((x, y), radius, color=color, **kwargs)
    plt.gca().add_patch(circle)

## Setup the figure
fig, ax = plt.subplots(figsize=(8, 8))
ax.set_aspect('equal')

## Drawing single and multiple circles
circles(1, 0, 0.5, 'r', alpha=0.2, lw=5, edgecolor='b')
x = np.arange(11)
out = circles(x, x, x*0.2, c=x, alpha=0.5, edgecolor='none')

plt.xlim(0, 10)
plt.ylim(0, 10)
plt.colorbar(out)
plt.show()

Method 3: Parametric Representation of Circles

You can use parametric equations to draw circles:

import numpy as np
import matplotlib.pyplot as plt

def xy(radius, angle):
    return radius * np.cos(angle), radius * np.sin(angle)

fig = plt.figure()
ax = fig.add_subplot(111, aspect='equal')

phi = np.linspace(0, 2 * np.pi, 100)
r = 1
ax.plot(*xy(r, phi), color='r')
plt.show()

Method 4: Using scatter()

For circles that maintain a 1:1 aspect ratio regardless of the data coordinates:

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 30, 40, 50]
radii = [100, 80, 60, 40, 20]  # Radii in points

fig, ax = plt.subplots()
ax.scatter(x, y, s=radii)  # s specifies the size of the circles
ax.set_aspect('equal', adjustable='datalim')
plt.show()

Method 5: Customizing Circle Properties

Adjusting circle marker sizes in a scatter plot can also be effective:

import matplotlib.pyplot as plt

x = list(range(1, 6))
y = list(range(10, 20, 2))

for i, data in enumerate(zip(x, y)):
    j, k = data
    plt.scatter(j, k, marker='o', s=((i + 1) ** 4) * 50, alpha=0.3)

plt.show()

Method 6: Combining Patches

By combining multiple circle patches you can create complex visual shapes:

import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.add_patch(plt.Circle((0, 0), 0.2, color='r', alpha=0.5))
ax.add_patch(plt.Circle((1, 1), 0.5, color='cyan', alpha=0.5))

ax.set_aspect('equal', adjustable='datalim')
plt.show()

Method 7: Enhanced Circle Drawing with Axes

This method provides precise control over the axes:

import matplotlib.pyplot as plt
import numpy as np

x_limits = (-1.5, 1.5)
y_limits = (-1.5, 1.5)

circle = plt.Circle((0, 0), 1, color='k', fill=False)
fig, ax = plt.subplots()
ax.add_artist(circle)
plt.axis("equal")

## Customize the axes
ax.spines['left'].set_position('zero')
ax.spines['bottom'].set_position('zero')
ax.xaxis.set_ticks_position('bottom')
ax.yaxis.set_ticks_position('left')

plt.xlim(x_limits)
plt.ylim(y_limits)
plt.axhline(linewidth=2, color='k')
plt.axvline(linewidth=2, color='k')
plt.grid(color='k', linestyle='-.', linewidth=0.5)
plt.show()

Method 8: Using Rectangle to Form Shapes

You can also create shapes using circles and rectangles for more complex visualizations:

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 8))

## Central Disk
central_dial = plt.Circle((5, 5), 2, edgecolor='black', facecolor='lightgrey', lw=2)
ax.add_patch(central_dial)

## Screen Display
display_screen = plt.Circle((5, 5), 1.2, edgecolor='black', facecolor='white', lw=2)
ax.add_patch(display_screen)

## Side Buttons
button_left = plt.Rectangle((2.5, 4.5), 0.5, 1, edgecolor='black', facecolor='darkgrey', lw=2)
button_right = plt.Rectangle((7, 4.5), 0.5, 1, edgecolor='black', facecolor='darkgrey', lw=2)
ax.add_patch(button_left)
ax.add_patch(button_right)

ax.axis('off')
plt.show()

FAQs on Top 8 Methods to Plot a Circle with Matplotlib’s Pyplot

Q: How do I maintain the aspect ratio when plotting circles?

A: Use the set_aspect('equal', adjustable='datalim') method on your axis object to ensure that circles retain their shape.

Q: Can I plot multiple circles in one go?

A: Yes, you can use a loop to add multiple circles or create a function that takes coordinates and radii as arguments.

Q: What is the difference between add_patch and add_artist?

A: add_patch considers the object’s bounding box for autoscaling, while add_artist does not influence the axes limits.

Q: Where can I find further reading on Matplotlib?

A: You can check the Matplotlib documentation for extensive resources and examples.
