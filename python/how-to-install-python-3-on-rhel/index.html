Solved: How to Install Python 3 on RHEL in 7 Detailed Steps

Installing Python 3 on RHEL can sometimes be tricky, especially if the default repositories don’t provide the necessary version. Below, I will walk you through 7 solutions for successfully installing Python 3 on your Red Hat Enterprise Linux system.

1. Manual Installation: Build Python 3 from Source

If your package manager (yum) does not have the desired Python version, you can download and build Python from source.

Steps to install:

# Step 1: Download Python from the official Python site
$ wget https://www.python.org/ftp/python/3.4.3/Python-3.4.3.tar.xz

## Step 2: Extract the tarball
$ tar xf Python-3.*

## Step 3: Navigate into the directory
$ cd Python-3.*

## Step 4: Prepare for installation
$ ./configure

## Step 5: Build the source code
$ make

## Step 6: Install Python 3
$ sudo make install

Alternatively, to avoid overwriting the system’s default Python (usually Python 2.x), you can use altinstall:

$ sudo make altinstall

This method ensures Python 3 will be installed without affecting system dependencies on Python 2.x.

2. Using altinstall with Custom Prefix

For a cleaner installation, consider using a custom directory for Python 3. This avoids potential conflicts with other system Python installations.

Steps to install:

# Step 1: Configure with custom install directory
$ ./configure --prefix=/opt/python3

## Step 2: Install Python 3
$ sudo make altinstall

You may need to update the $PATH or $LD_LIBRARY_PATH environment variables if you chose a non-default directory for installation.

3. Installing Python 3 via Software Collections (SCL)

Red Hat Software Collections (RHSCL) is a great method for installing Python 3 in a controlled, Red Hat-supported environment.

Steps to install:

# Step 1: Install SCL utilities
$ sudo yum install scl-utils

## Step 2: Install Python 3.4 from SCL
$ sudo yum install rh-python34

## Step 3: Enable Python 3.4 environment
$ scl enable rh-python34 bash

Using this method, Python 3 is installed alongside the system’s Python version and can be activated when needed.

Reference: Installing Python 3 from SCL

4. Using EPEL (Extra Packages for Enterprise Linux) Repository

You can install Python 3 via the EPEL repository for RHEL 7.5 or later.

Steps to install:

# Step 1: Install EPEL repository
$ sudo yum install epel-release

## Step 2: Install Python 3.6
$ sudo yum install python36

## Step 3: Verify the installation
$ python3 --version

5. Install Python 3 Using RPM Packages

RHEL 7 provides Python 3 packages via the Software Collections repository. You can download and install these RPMs manually.

Steps to install:

# Step 1: Download the RPM package
$ wget https://www.softwarecollections.org/en/scls/rhscl/rh-python34/epel-7-x86_64/download/rhscl-rh-python34-epel-7-x86_64.noarch.rpm

## Step 2: Install the RPM package
$ sudo yum install rhscl-rh-python34-*.noarch.rpm

## Step 3: Install Python 3
$ sudo yum install rh-python34

This method installs Python 3 while keeping your system’s default Python version intact.

6. Installing Python 3 via Miniconda

If you’re looking for a Python installation that also supports package management, Miniconda is a powerful alternative.

Steps to install:

# Step 1: Download Miniconda installer
$ curl https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O

## Step 2: Install Miniconda
$ sudo bash Miniconda3-latest-Linux-x86_64.sh

After installation, you can create virtual environments and install Python packages independently.

Reference: Miniconda Installation Guide

7. Installing Python 3 from Prebuilt RPMs

If you prefer not to manually compile Python, using a prebuilt RPM is a faster solution.

Steps to install:

# Step 1: Install the RPM package
$ sudo yum install python36

## Step 2: Verify the installation
$ python3 --version

This method is especially helpful when working on CentOS or AWS-based RHEL systems.

Additional Considerations

Do’s:

  • Always use a custom install directory if you’re concerned about overriding system Python.
  • Use scl enable to activate specific Python versions without impacting your system.

Don’ts:

  • Avoid modifying /usr/bin/python directly, as it can break critical system tools like yum.

FAQs on Installing Python 3 on RHEL

Q: How can I safely install Python 3 without affecting system Python?

A: To install Python 3 without disrupting system Python, you can use altinstall during the make step, or use Red Hat Software Collections (RHSCL) to install Python 3 in parallel with the default Python version.

Q: What if my RHEL system doesn't support Python 3?

A: If your system doesn’t support Python 3, you can enable the EPEL repository and install Python 3 using yum. Alternatively, you can compile Python from source or use a virtual environment like Miniconda to manage Python versions.
