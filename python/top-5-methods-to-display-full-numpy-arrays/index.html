When working with NumPy, you may find that printing an array often results in a truncated output, which can obscure essential data. For instance, you might see:

>>> import numpy as np
>>> np.arange(10000)
array([ 0,  1,  2, ...,  9997, 9998, 9999])

>>> np.arange(10000).reshape(250, 40)
array([[ 0,  1,  2, ...,  37,  38,  39],
       [40, 41, 42, ..., 77, 78, 79],
       ...,
       [9880, 9881, 9882, ..., 9917, 9918, 9919],
       [9920, 9921, 9922, ..., 9957, 9958, 9959],
       [9960, 9961, 9962, ..., 9997, 9998, 9999]])

To ensure you see the full data regardless of its size, here are some effective methods to print the complete NumPy array without truncation.

Method 1: Use np.set_printoptions with np.inf

One straightforward approach is to adjust the printing options using:

import numpy as np
np.set_printoptions(threshold=np.inf)

By setting the threshold to np.inf, the entire array is printed. This provides clarity when sharing code and outputs, as it directly signals that the expectation is to view all data.

Method 2: Temporary Settings with Context Manager

If you need to revert to default options after printing, employ a context manager:

with np.printoptions(threshold=np.inf):
    print(arr)

This method isolates the print option change to a specific block of code, allowing you to maintain typical printing behavior afterward. For reference, check the NumPy documentation on printoptions .

Method 3: Convert Array to List

For quick one-off prints, you can convert the array to a list:

arr = np.arange(100).reshape(25, 4)
print(arr.tolist())

While this may not keep the array formatting strict, it provides an easily understandable representation.

Method 4: Custom Printing Function

You can define a reusable function that sets printing options just for a single output:

def full_print(arr):
    from pprint import pprint
    import numpy as np

    options = np.get_printoptions()
    np.set_printoptions(threshold=np.inf)
    pprint(arr)
    np.set_printoptions(**options)

# Example usage
full_print(np.arange(10000).reshape(250, 40))

This leverages Python’s pretty print functionality for organized output.

Method 5: Enhanced Output with array2string

Alternatively, to customize the printed output, you can control it via numpy.array2string:

arr = np.arange(10000).reshape(250, 40)
print(np.array2string(arr, threshold=np.nan, max_line_width=np.nan))

This enables you to tailor the output format while still printing the entire array.

Alternative Solutions

If you frequently work with large datasets, consider using third-party libraries or advanced settings that can provide better formatting, such as pandas for DataFrame representations or utilizing tools like matrepr for improved visual array logging.

FAQs on Top 5 Methods to Display Full NumPy Arrays

Q: Why do NumPy arrays get truncated when printed?

A: NumPy truncates large arrays to enhance readability by avoiding overloading the console with excessive data. The default threshold limits the number of elements displayed in the output.

Q: How can I see the full array only for certain outputs?

A: Use a context manager to temporarily adjust the print options for specific blocks of your code. This way, you can maintain the default settings elsewhere.

Q: Is there a way to format large arrays before printing them?

A: Yes, functions like numpy.array2string allow you to customize the output and manage formatting details such as line width and element limits.
