How Can You Efficiently Call Python Functions from MATLAB?

For many developers, integrating the capabilities of Python into MATLAB can significantly enhance productivity, enabling the leverage of rich Python libraries while staying within the MATLAB environment. If you find yourself questioning how to achieve this integration, you’re not alone! Below, we explore two effective methods to call Python functions from MATLAB, complete with practical examples.

Method 1: The Custom python.m Function

During my time working with MATLAB, I faced a similar scenario requiring the execution of Python scripts. I discovered that a clever workaround involved the standard MATLAB function perl.m, which is designed to execute Perl scripts. By creating a custom Python function, we can leverage this mechanism to run Python scripts effortlessly.

  1. Locate perl.m found in your MATLAB installation directory, such as:

    C:\Program Files\MATLAB\R2008a\toolbox\matlab\general\perl.m

  2. Create a Copy named python.m.

  3. Modify the Copy: Open python.m and do a search-and-replace to change instances of perl to python. Ensure that any command path references are updated to point to your Python installation.

Here’s how you can create a simple Python script named sqd.py that calculates the square of a number:

import sys

def squared(x):
    result = x * x
    return result

if __name__ == '__main__':
    x = float(sys.argv[1])
    sys.stdout.write(str(squared(x)))

In MATLAB, executing the function is straightforward:

>> r = python('sqd.py', '3.5')
r =
    12.25
>> r = python('sqd.py', '5')
r =
    25.0

Method 2: Direct Integration in MATLAB R2014b and Later

Starting from MATLAB R2014b, MathWorks introduced native support for calling Python libraries directly. This method simplifies the usage of Python functions within MATLAB and bypasses the need for any custom script files.

You can seamlessly use Python libraries and functions directly in your MATLAB code:

pyNum = py.importlib.import_module('sqd');
result = pyNum.squared(3.5);
disp(result);  % Outputs: 12.25

This approach not only reduces complexity but also provides access to the vast Python ecosystem, enabling the use of popular libraries like NumPy, Pandas, and more.

For more details about Python integration in MATLAB, you can refer to the official MathWorks documentation .

Alternative Approaches

If you are looking for other alternatives, consider utilizing tools like:

  • MATLAB Engine API for Python: This allows you to call MATLAB from Python, which can be particularly useful in specific workflows.
  • System Calls: For scripts that don’t require a return value, you can use system commands to call Python scripts from MATLAB using system('python my_script.py').

FAQs on Top 2 Methods to Call Python Functions from MATLAB

Q: How do I call a Python function from MATLAB?

A: You can call a Python function using a custom Python.m function or directly using the built-in features in MATLAB R2014b and later.

Q: What is the simplest method to integrate Python into MATLAB?

A: The simplest method is using the built-in support for Python libraries in MATLAB R2014b and later versions, allowing direct access to Python functions with minimal overhead.
