Solved: How to Get Python Working in Git Bash on Windows

Python not executing in Git Bash (on Windows) can lead to frustration among developers. If you find that typing python leads to a blank line instead of launching the interpreter, you’re not alone. This guide provides you with several solutions to ensure Python runs smoothly in your Git terminal environment.

Common Problem Encountered

When trying to launch Python in Git Bash, you might see behavior like this:

user@hostname MINGW64 ~
$ type python
python is /c/Python27/python

user@hostname MINGW64 ~
$ python

...sitting there without returning to the prompt.

This often indicates an issue with how Git Bash interacts with the Python executable. Here are effective strategies to resolve this issue:

Solution 1: Launch Python with Interactive Mode

You might not be seeing any output because the default Python interpreter invocation hangs. Instead, try starting Python in interactive mode:

$ python -i

You should see something like:

Python 3.5.2 (v3.5.2:4def2a2901a5, Jun 25 2016, 22:18:55)
Type "help", "copyright", "credits" or "license" for more information.
>>>

Solution 2: Use WinPTY for Compatibility

Git Bash often runs into compatibility issues with console applications on Windows. A well-known workaround is to use WinPTY. You can do this by prefixing your Python command with winpty:

$ winpty /c/Python27/python.exe

To ease the process, ensure you have WinPTY installed. It should come bundled with recent versions of Git for Windows.

Solution 3: Create Bash Aliases

If you frequently use Python, consider setting up aliases in your .bashrc file. This approach allows you to call Python without always using winpty. Here’s how to do it:

  1. Open the aliases.sh file located in C:\Program Files\Git\etc\profile.d\aliases.sh using a text editor.

  2. Add the following aliases at the end of the file:

    alias python='winpty C/Path/To/Python/python.exe'
alias python2='winpty C/Path/To/Python2/python.exe'

  3. Save the file, close, and restart Git Bash.

Now, you can simply type python or python2 to invoke your respective Python environments.

Solution 4: Adjusting System Environment Variables

It’s crucial to ensure that the environment variables for Python are correctly configured. Check your system’s PATH variable to confirm that the directory containing python.exe is included. Here’s how:

  1. Right-click on “This PC” or “Computer” and select “Properties.”
  2. Click on “Advanced system settings.”
  3. In the System Properties window, click on “Environment Variables.”
  4. Under “System variables,” find and edit the PATH variable, ensuring it includes the path to your Python installation.

Solution 5: Run with Python Script Hashbang

You can also utilize the hashbang to run Python scripts directly. This method involves making your Python scripts executable:

  1. Add a hashbang line at the top of your Python script file:

    #!/usr/bin/env python3

  2. Make the file executable:

    chmod +x your_script.py

  3. Run your script as follows:

./your_script.py

Practical Example

Here’s a simple example of a Python script that you can test:

Create hello_world.py:

#!/usr/bin/env python3
print("Hello, World!")

Make it executable:

chmod +x hello_world.py

Run it either by:

python hello_world.py

or

./hello_world.py

Alternative Solutions

If you’re still facing issues, consider these alternatives:

  • Check for Python Installation: Ensure you have installed Python correctly. Visit the official Python Downloads page to re-install if necessary.
  • Use a Different Terminal: Try using Windows Subsystem for Linux (WSL) or another terminal emulator that might handle Python more effectively.

FAQs on How to Get Python Working in Git Bash on Windows

Q: Why does Git Bash hang when running Python?

A: Git Bash may hang due to compatibility issues with console applications on Windows. Using winpty before the Python command often resolves this.

Q: How do I know if Python is correctly installed?

A: You can check by running python --version or python -c 'print("Test")' in the Git Bash terminal to see if it executes correctly.

Q: What if I need to use Python 2 and 3?

A: You can create aliases in your .bashrc to distinguish between Python 2 and Python 3, directly invoking the required versions with commands like python2 for Python 2.x and python for Python 3.x.
