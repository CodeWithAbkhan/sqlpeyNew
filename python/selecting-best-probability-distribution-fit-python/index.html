“Selecting Best Probability Distribution Fit for Data using Python SciPy”

When analyzing datasets, a common statistical task involves determining which theoretical probability distribution best represents the observed data. This process, known as distribution fitting, relies on various goodness-of-fit metrics to quantify how closely a chosen distribution’s parameters match the empirical data. How can we systematically test numerous scipy.stats distributions against a dataset and select the superior model?

Method 1: Iterative Fitting with Sum of Square Error (SSE)

One effective approach involves calculating the Sum of Square Error (SSE) between the data’s histogram and the Probability Density Function (PDF) of each potential distribution. The distribution yielding the minimum SSE is considered the best fit. This method evaluates the direct squared difference across histogram bins.

Example: Fitting El Niño Data using SSE

This example adapts techniques to iterate through many distributions available in scipy.stats, fit their parameters to the data, calculate the SSE against the data’s normalized histogram, and rank them.

def calculate_best_fit_by_sse(data, bins=200, plot_all=False):
    """
    Models data by finding the best-fit distribution using minimum SSE.
    Plots PDFs of tested distributions if plot_all is True.
    """
    # 1. Prepare data histogram
    y_data, x_bins = np.histogram(data, bins=bins, density=True)
    x_centers = (x_bins + np.roll(x_bins, -1))[:-1] / 2.0

    best_candidates = []
    
    # Exclude complex or unstable distributions for routine fitting
    distributions_to_test = [d for d in _distn_names if not d in ['levy_stable', 'studentized_range']]
    
    print(f"Starting fit process across {len(distributions_to_test)} distributions...")

    for ii, dist_name in enumerate(distributions_to_test):
        print(f"{ii+1:>3} / {len(distributions_to_test):<3}: {dist_name}")
        
        distribution = getattr(st, dist_name)

        try:
            with warnings.catch_warnings():
                warnings.filterwarnings('ignore')
                
                # Estimate parameters via Maximum Likelihood Estimation (MLE)
                params = distribution.fit(data)

                arg = params[:-2]
                loc = params[-2]
                scale = params[-1]
                
                # Calculate fitted PDF over the bin centers
                pdf_fit = distribution.pdf(x_centers, loc=loc, scale=scale, *arg)
                
                # Calculate Sum of Square Error (SSE)
                sse = np.sum(np.power(y_data - pdf_fit, 2.0))
                
                if plot_all:
                    if (ii % 10 == 0) or (ii == len(distributions_to_test) - 1): # Plot intermittently or last one
                        pd.Series(pdf_fit, x_centers).plot(alpha=0.3)
                
                best_candidates.append((distribution, params, sse))
        
        except Exception:
            pass # Skip distributions that fail to fit

    # Sort by lowest SSE
    ranked_fits = sorted(best_candidates, key=lambda x: x[2])
    return ranked_fits

def plot_best_fit(data, best_fit_result):
    """Plots the raw data histogram against the best-fit PDF."""
    best_dist, best_params, best_sse = best_fit_result
    
    # Prepare histogram for plotting
    plt.figure(figsize=(12, 8))
    ax = data.plot(kind='hist', bins=50, density=True, alpha=0.5, label='Data Histogram')
    
    # Prepare PDF plotting range
    arg = best_params[:-2]
    loc = best_params[-2]
    scale = best_params[-1]
    
    start = best_dist.ppf(0.01, *arg, loc=loc, scale=scale) if arg else best_dist.ppf(0.01, loc=loc, scale=scale)
    end = best_dist.ppf(0.99, *arg, loc=loc, scale=scale) if arg else best_dist.ppf(0.99, loc=loc, scale=scale)
    x_plot = np.linspace(start, end, 1000)
    y_plot = best_dist.pdf(x_plot, loc=loc, scale=scale, *arg)
    
    pdf_series = pd.Series(y_plot, x_plot)
    pdf_series.plot(lw=2, label='Best Fit PDF', ax=ax)

    param_names = (best_dist.shapes + ', loc, scale').split(', ') if best_dist.shapes else ['loc', 'scale']
    param_str = ', '.join([f'{k}={v:0.2f}' for k, v in zip(param_names, best_params)])
    dist_str = f'{best_dist.name}({param_str}) [SSE: {best_sse:0.4f}]'

    ax.set_title(f'Data Fit Result: {dist_str}')
    ax.set_xlabel('Temperature (°C)')
    ax.set_ylabel('Density')
    ax.legend()
    plt.show()

Method 3: Non-Parametric Estimation (Empirical CDF)

If assuming a theoretical distribution form is undesirable, a non-parametric approach using the Empirical Cumulative Distribution Function (ECDF) is an alternative. The ECDF, $F_n(x)$, simply calculates the proportion of observations less than or equal to $x$.

The required probability, $P(X \ge x)$, is calculated using the complementary ECDF (or survival function): $1 - F_n(x)$.

import numpy as np

def empirical_survival_function(data, threshold_x):
    """Calculates P(X >= threshold_x) using the empirical distribution."""
    n = len(data)
    # Count observations <= threshold_x
    count_le_x = np.sum(data <= threshold_x)
    
    # ECDF: F_n(x)
    ecdf_value = count_le_x / n
    
    # Survival Function (Complementary CDF): P(X > x) or P(X >= x) for continuous data
    p_greater_equal_x = 1.0 - ecdf_value
    return p_greater_equal_x

Alternative Fit Selection Criteria

When using the parametric approach (like in Method 1 or using scipy.stats.fit), the choice of the “best” distribution depends on the metric used:

  1. Log-Likelihood: Maximize the log-likelihood value.
  2. Information Criteria (AIC/BIC): Minimize the Akaike Information Criterion (AIC) or Bayesian Information Criterion (BIC). These metrics penalize models with more parameters, discouraging overly complex fits.
  3. Sum of Square Error (SSE): Minimize the SSE, as demonstrated in Method 1.

For discrete data, if your data consists of counts where the maximum value is known (e.g., 47), simply calculating the normalized frequency counts (probability mass function) and their cumulative sum is often sufficient, bypassing the need for continuous distribution fitting entirely. See Solution 5 for a discrete example.

FAQs on Selecting Best Probability Distribution Fit for Data using Python SciPy

Q: What is the primary goal of fitting data to a theoretical distribution

ANS: The primary goal is to find a known mathematical function (distribution) whose parameters, when estimated from the data, best describe the underlying random process that generated that data.

Q: Why does scipy.stats.norm sometimes give a poor fit to discrete count data

ANS: Standard distributions like norm (Normal) are continuous. While they can approximate discrete data well with large sample sizes, they inherently lack the capacity to perfectly model exact integer counts, unlike a discrete distribution like Poisson or Binomial.

Q: Which goodness-of-fit test is generally preferred AIC or BIC

ANS: BIC generally imposes a stronger penalty for model complexity than AIC, favoring simpler models more heavily, particularly with larger datasets ($n$). AIC is based on Kullback-Leibler divergence, while BIC is based on Bayes’ theorem approximation.

Q: How many distributions does scipy.stats implement

ANS: SciPy implements a vast array of continuous and discrete distributions. One solution lists nearly 90 continuous distributions available in certain versions, such as scipy.stats.t, scipy.stats.gamma, and scipy.stats.vonmises.

def danoes_formula(data):
    &quot;&quot;&quot;
    DANOE'S FORMULA
    https://en.wikipedia.org/wiki/Histogram#Doane's_formula
    &quot;&quot;&quot;
    N = len(data)
    skewness = st.skew(data)
    sigma_g1 = math.sqrt((6*(N-2))/((N+1)*(N+3)))
    num_bins = 1 + math.log(N,2) + math.log(1+abs(skewness)/sigma_g1,2)
    num_bins = round(num_bins)
    return num_bins

    ]
    
    MY_DISTRIBUTIONS = [st.beta, st.expon, st.norm, st.uniform, st.johnsonsb, st.gennorm, st.gausshyper]

    ## Calculae Histogram
    num_bins = danoes_formula(data)
    frequencies, bin_edges = np.histogram(data, num_bins, density=True)
    central_values = [(bin_edges[i] + bin_edges[i+1])/2 for i in range(len(bin_edges)-1)]

    results = {}
    for distribution in MY_DISTRIBUTIONS:
        ## Get parameters of distribution
        params = distribution.fit(data)
        
        ## Separate parts of parameters
        arg = params[:-2]
        loc = params[-2]
        scale = params[-1]
    
        ## Calculate fitted PDF and error with fit in distribution
        pdf_values = [distribution.pdf(c, loc=loc, scale=scale, *arg) for c in central_values]
        
        ## Calculate SSE (sum of squared estimate of errors)
        sse = np.sum(np.power(frequencies - pdf_values, 2.0))
        
        ## Build results and sort by sse
        results[distribution] = [sse, arg, loc, scale]
        
    results = {k: results[k] for k in sorted(results, key=results.get)}
    return results
