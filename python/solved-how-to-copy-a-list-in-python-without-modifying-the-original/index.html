“Solved: How to Copy a List in Python Without Modifying the Original”

To genuinely duplicate a list, ensuring that changes to the new list do not impact the original, you need to perform a proper copy. The method you choose depends on whether your list contains only simple, immutable data types (like numbers, strings, or tuples) or complex, mutable objects (like other lists, dictionaries, or custom class instances). This distinction leads to two primary types of copies: shallow copies and deep copies.

The Core Problem: Reference Assignment

Let’s illustrate the initial problem using an example:

initial_items = ['apple', 'banana', 'cherry']
reference_items = initial_items

print(f"Original ID: {id(initial_items)}")
print(f"Reference ID: {id(reference_items)}")

# Modify via the reference
reference_items.append('date')

print(f"Initial after modification: {initial_items}")
print(f"Reference after modification: {reference_items}")

Output:

Original ID: 140737351829632
Reference ID: 140737351829632
Initial after modification: ['apple', 'banana', 'cherry', 'date']
Reference after modification: ['apple', 'banana', 'cherry', 'date']

As seen from the identical id values and the modified initial_items, reference_items is not a copy but merely another name for the same list.

Shallow Copy Methods

A shallow copy creates a new list object, but if the original list contains mutable objects (like nested lists or dictionaries), the new list will still contain references to those original nested objects. Changes to these nested objects will affect both the original and the shallow-copied list. For lists containing only immutable items or for cases where nested mutable objects are not a concern, shallow copies are efficient and effective.

Here are several widely used methods to perform a shallow copy:

1. Using the list.copy() Method (Python 3.3+)

This built-in method is explicitly designed for creating shallow copies of lists and is generally considered the clearest and often most performant option in modern Python .

source_data = ['alpha', 'beta', 123]
cloned_data_one = source_data.copy()

source_data.append('gamma') # Modify original list
cloned_data_one[0] = 'epsilon' # Modify copied list

print(f"Source List: {source_data}")
print(f"Cloned List 1: {cloned_data_one}")

Output:

Source List: ['alpha', 'beta', 123, 'gamma']
Cloned List 1: ['epsilon', 'beta', 123]

2. Slicing the Entire List [:]

This is a very common and Pythonic way to create a shallow copy, widely used in both Python 2 and Python 3 . It works by creating a new list that includes all elements from the original.

primary_items = [10, 20, 30, 'zeta']
duplicated_items_alpha = primary_items[:]

primary_items[0] = 99 # Alter original
duplicated_items_alpha.pop() # Alter copy

print(f"Primary Items: {primary_items}")
print(f"Duplicated Items Alpha: {duplicated_items_alpha}")

Output:

Primary Items: [99, 20, 30, 'zeta']
Duplicated Items Alpha: [10, 20, 30]

3. Utilizing the list() Constructor

Passing an existing list to the list() constructor will create a new list containing the elements of the original, effectively producing a shallow copy.

original_collection = [True, False, True]
copied_collection_beta = list(original_collection)

original_collection.append(False)
copied_collection_beta[0] = 'modified'

print(f"Original Collection: {original_collection}")
print(f"Copied Collection Beta: {copied_collection_beta}")

Output:

Original Collection: [True, False, True, False]
Copied Collection Beta: ['modified', False, True]

4. Using copy.copy() from the copy Module

The copy module provides generic shallow and deep copy operations. copy.copy(obj) creates a shallow copy of any object that supports it, including lists. While it works, it’s generally a bit slower for lists than list.copy() or slicing because it has to determine the object’s type first.

import copy

initial_values = [5, 10, 15]
copied_values_gamma = copy.copy(initial_values)

initial_values[1] = 20
copied_values_gamma.insert(0, 1)

print(f"Initial Values: {initial_values}")
print(f"Copied Values Gamma: {copied_values_gamma}")

Output:

Initial Values: [5, 20, 15]
Copied Values Gamma: [1, 5, 10, 15]

5. List Comprehension

A list comprehension can iterate over the elements of an existing list and construct a new list from them. This also results in a shallow copy.

input_values = ['item_A', 'item_B', 'item_C']
output_values_delta = [x for x in input_values]

input_values.pop()
output_values_delta[0] = 'new_item_A'

print(f"Input Values: {input_values}")
print(f"Output Values Delta: {output_values_delta}")

Output:

Input Values: ['item_A', 'item_B']
Output Values Delta: ['new_item_A', 'item_B', 'item_C']

6. Using list.extend() with an Empty List

You can create an empty list and then extend it with the elements of the original list.

source_data_ext = [100, 200, 300]
target_data_ext = []
target_data_ext.extend(source_data_ext)

source_data_ext[0] = 150
target_data_ext.append(400)

print(f"Source Data Ext: {source_data_ext}")
print(f"Target Data Ext: {target_data_ext}")

Output:

Source Data Ext: [150, 200, 300]
Target Data Ext: [100, 200, 300, 400]

7. Using the + Operator with an Empty List

Concatenating a list with an empty list creates a new list.

original_set_op = [True, False, True]
copied_set_op = original_set_op + []

original_set_op[0] = 'ModifiedBoolean'
copied_set_op.append('NewBoolean')

print(f"Original Set Op: {original_set_op}")
print(f"Copied Set Op: {copied_set_op}")

Output:

Original Set Op: ['ModifiedBoolean', False, True]
Copied Set Op: [True, False, True, 'NewBoolean']

8. List Unpacking with the Splat Operator [*original_list] (Python 3.5+)

The splat operator (*) can unpack an iterable into individual elements. When used inside square brackets, it effectively creates a new list from these unpacked elements.

initial_sequence = ['one', 'two', 'three']
duplicated_sequence_final = [*initial_sequence]

initial_sequence.append('four')
duplicated_sequence_final[0] = 'first_item'

print(f"Initial Sequence: {initial_sequence}")
print(f"Duplicated Sequence Final: {duplicated_sequence_final}")

Output:

Initial Sequence: ['one', 'two', 'three', 'four']
Duplicated Sequence Final: ['first_item', 'two', 'three']

9. Multiplying by One original_list * 1

Multiplying a list by one (e.g., my_list * 1) creates a new list containing the same elements. This is also a shallow copy.

input_numbers = [7, 8, 9]
copied_numbers = input_numbers * 1

input_numbers[0] = 77
copied_numbers.append(10)

print(f"Input Numbers: {input_numbers}")
print(f"Copied Numbers: {copied_numbers}")

Output:

Input Numbers: [77, 8, 9]
Copied Numbers: [7, 8, 9, 10]

Deep Copy: For Nested Mutable Objects

When your list contains other mutable objects (like nested lists, dictionaries, or custom class instances), a shallow copy will only copy the references to those nested objects. If you modify a nested object in the shallow copy, the change will also be reflected in the original list. To prevent this, you need a deep copy.

A deep copy recursively creates new copies of all objects found in the original list, including all nested mutable objects. This ensures complete independence between the original and the copied list.

Using copy.deepcopy() from the copy Module

This is the standard and most reliable way to perform a deep copy in Python.

import copy

class ItemStats:
    def __init__(self, value):
        self.value = value

    def __repr__(self):
        return f'ItemStats({self.value})'

original_data_complex = ['label', ItemStats(101), ['nested_A', 'nested_B']]
deep_cloned_data = copy.deepcopy(original_data_complex)

# Modify original list's elements and nested objects
original_data_complex.append('new_label')
original_data_complex[1].value = 202
original_data_complex[2][0] = 'modified_nested_A'

print(f"Original Complex Data: {original_data_complex}")
print(f"Deep Cloned Data: {deep_cloned_data}")

Output:

Original Complex Data: ['label', ItemStats(202), ['modified_nested_A', 'nested_B'], 'new_label']
Deep Cloned Data: ['label', ItemStats(101), ['nested_A', 'nested_B']]

Notice how the deep_cloned_data remains unaffected by the changes made to the original_data_complex, including modifications to the ItemStats object and the nested list. This is the core difference and advantage of a deep copy.

Performance Considerations

The speed of copying methods can vary. Generally, built-in methods optimized in C (like slicing [:], list.copy(), list(), and list unpacking [* ]) are faster for shallow copies than methods involving Python loops or the copy module’s generic functions. copy.deepcopy() is inherently slower and more memory-intensive due to its recursive nature, but it’s essential when full independence of nested mutable objects is required.

dignore = {str: None, unicode: None, int: None, type(None): None}

def Copy(obj, use_deepcopy=True):
    t = type(obj)

    if t in (list, tuple):
        if t == tuple:
            # Convert to a list if a tuple to
            # allow assigning to when copying
            is_tuple = True
            obj = list(obj)
        else:
            # Otherwise just do a quick slice copy
            obj = obj[:]
            is_tuple = False

        # Copy each item recursively
        for x in xrange(len(obj)):
            if type(obj[x]) in dignore:
                continue
            obj[x] = Copy(obj[x], use_deepcopy)

        if is_tuple:
            # Convert back into a tuple again
            obj = tuple(obj)

    elif t == dict:
        # Use the fast shallow dict copy() method and copy any
        # values which aren't immutable (like lists, dicts etc)
        obj = obj.copy()
        for k in obj:
            if type(obj[k]) in dignore:
                continue
            obj[k] = Copy(obj[k], use_deepcopy)

    elif t in dignore:
        # Numeric or string/unicode?
        # It's immutable, so ignore it!
        pass

    elif use_deepcopy:
        obj = deepcopy(obj)
    return obj

When Copying Might Not Be Necessary: The Frame Challenge

Sometimes, the need to copy a list stems from a desire to transform data without altering the original. In such cases, creating a new list based on the original’s transformation, rather than copying and then modifying, can be a more elegant and Pythonic approach.

For example, if you want to double every number in a list:

source_numbers = [8, 6, 7, 5, 3, 0, 9]

# Instead of:
# new_numbers_copy = source_numbers[:]
# for index, num in enumerate(new_numbers_copy):
#     new_numbers_copy[index] = num * 2

# Use a list comprehension:
transformed_numbers = [element * 2 for element in source_numbers]

print(f"Source Numbers: {source_numbers}")
print(f"Transformed Numbers: {transformed_numbers}")

Output:

Source Numbers: [8, 6, 7, 5, 3, 0, 9]
Transformed Numbers: [16, 12, 14, 10, 6, 0, 18]

This approach directly creates the desired result without the intermediate step of copying and then modifying. Similarly, for filtering or rearranging elements, slicing or generator expressions can often be more direct than a full copy.

Conclusion

Effectively copying lists in Python requires distinguishing between shallow and deep copies. For simple lists or when independence of nested objects is not critical, shallow copy methods like list.copy() or slicing [:] are efficient. When dealing with nested mutable structures where complete independence is essential, copy.deepcopy() is the indispensable tool, despite its higher performance cost. Always choose the method that best suits your data structure and requirements to avoid unexpected side effects in your applications. This principle is vital in many programming contexts, from processing Pandas DataFrames to managing database results from SQL or PostgreSQL .

FAQs on Solved How to Copy a List in Python Without Modifying the Original

Q: What is a shallow copy in Python

ANS: A shallow copy creates a new list object but inserts references to the original objects within it. If the original list contains mutable items like nested lists, changes to these nested items will affect both the original and the shallow-copied list.

Q: What is a deep copy in Python

ANS: A deep copy creates a new list object and recursively copies all objects found in the original list, including all nested mutable objects. This ensures complete independence between the original and the deeply copied list.

Q: When should I use deepcopy

ANS: You should use copy.deepcopy() when your list contains nested mutable objects (such as other lists, dictionaries, or custom class instances) and you need to ensure that modifications to these nested objects in the new list do not affect the original list.

Q: Is listcopy faster than list slicing

ANS: In modern Python versions, list.copy() and list slicing [:] offer very similar and excellent performance for shallow copies. Performance benchmarks often show them as the fastest methods for shallow list duplication.

Q: Why does newlist equal mylist not create a copy

ANS: new_list = my_list does not create a copy because it simply makes new_list another name or reference that points to the exact same list object in memory as my_list. Both variables refer to the identical data structure, so changes through one variable are visible through the other.
