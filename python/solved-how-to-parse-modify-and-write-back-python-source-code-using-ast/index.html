I am interested in programmatically editing Python source code—specifically how to read a .py file, generate its Abstract Syntax Tree (AST), modify it, and then write back the altered Python source code. Typically, one might use standard Python modules like ast and compiler for parsing and compiling, but they generally lack functionality for direct modifications and writing back to .py files.

Goal

The primary aim here is to write a mutation testing library in Python that involves removing statements or expressions, executing tests afterward, and observing which tests fail due to the modifications.

Approach to Parsing and Modifying Python Source Code

Let’s explore various methods for parsing, modifying, and re-producing the source code.

Solution 1: Using the codegen Module

The built-in ast module does not provide a straightforward method for converting an AST back into source code. However, the codegen library can be utilized for this purpose.

Here’s a simple example to demonstrate how it works:

import ast
import codegen

source_code = """
def foo():
    print("hello world")
"""
parsed_ast = ast.parse(source_code)

## Modify the AST: replace the function's body
parsed_ast.body[0].body = [ast.parse("return 42").body[0]]

## Generate the modified source
modified_source = codegen.to_source(parsed_ast)
print(modified_source)

Output:

def foo():
    return 42

Be aware that formatting and comments might be lost in the transformation.

Solution 2: Using ast.unparse in Python 3.9+

Starting from Python 3.9, the ast module includes a method called ast.unparse() which can convert an AST back to a string representation.

import ast

source_code = """
def foo():
    print("hello world")
"""
parsed_ast = ast.parse(source_code)

## Modify AST here if needed
## Convert back to source code using `ast.unparse`.
print(ast.unparse(parsed_ast))

You can read more about this feature in the Python 3.9 Release Notes .

Solution 3: Utilize the astunparse Library

Another option is the astunparse package, which is designed for converting ASTs back into source.

Here’s how you can use it:

import ast
import astunparse

source_code = 'def foo(x): return 2 * x'
parsed_ast = ast.parse(source_code)

## Convert to source code.
print(astunparse.unparse(parsed_ast))

Solution 4: Use Templating for Code Generation

In some cases, regenerating source code via AST may not be necessary. When generating files intended for user interaction or code that requires specific formatting, consider using a templating engine—like the Django template language—for customization instead of converting back from AST.

Solution 5: Direct Manipulation with the ast Module

While writing back modified code is not directly supported by the ast module, you can perform modifications on the AST using ast.NodeTransformer. For example, converting Python 2 print statements to Python 3 syntax involves subclassing NodeTransformer.

import ast
import sys

class PrintToFunc(ast.NodeTransformer):
    def visit_Print(self, node):
        new_node = ast.Expr(value=ast.Call(func=ast.Name(id='print', ctx=ast.Load()),
                                            args=node.values,
                                            keywords=[]))
        ast.copy_location(new_node, node)
        return new_node

def main(filename):
    with open(filename, 'r') as file:
        source = file.read()
    tree = ast.parse(source)
    PrintToFunc().visit(tree)
    ast.fix_missing_locations(tree)
    exec(compile(tree, filename="<ast>", mode="exec"))

if __name__ == '__main__':
    main('your_python_file.py')

Alternative Methods

If you wish to maintain original comments and formatting while modifying the code, libraries like libcst or ASTTokens might be a better fit. These libraries use concrete syntax trees (CST) instead of AST, preserving the original code structure.

FAQs on How to Parse, Modify, and Write Back Python Source Code Using AST

Q: What is AST in Python?

A: AST stands for Abstract Syntax Tree, which is a representation of the structure of Python source code. It helps in understanding the code programmatically.

Q: How can I modify Python code programmatically?

A: You can modify Python code traditionally by parsing it into an AST using the ast module, making changes, and converting it back to source using tools like ast.unparse, codegen, or astunparse.

Q: Are there libraries for Python code transformation?

A: Yes, there are several libraries available for Python code transformation including astor, libcst, and codegen, which provide functionality to work with AST and generate source code.

Q: What is mutation testing?

A: Mutation testing is a software testing method used to evaluate the quality of software tests. It involves making small changes to a program’s source code to determine if the existing tests can detect the changes.
