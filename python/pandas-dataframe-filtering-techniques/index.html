Filtering DataFrames Based on Exact List Membership

For scenarios where you possess a collection of exact identifiers (e.g., a list of STK_ID values) that must be present in a DataFrame column, the isin() method offers a straightforward and performant solution.

If your target list is stk_list, filtering the rpt DataFrame is achieved as follows:

# Solution 1: Using the isin method for exact matches
filtered_rpt = rpt[rpt['STK_ID'].isin(stk_list)]

This approach generates a boolean Series indicating where each element in 'STK_ID' is present in stk_list, which is then applied to filter the original data.

Alternatively, particularly when dealing with structured data selections, the .query() method can offer cleaner, string-based syntax:

# Solution 3 (Alternative using query for exact matches)
# Assuming stk_list = [600809, 600141, 600329]
# Note: For query(), numeric values are used directly, strings need quotes within the query string.
query_string = f"STK_ID in ({', '.join(map(str, stk_list))})"
filtered_rpt_query = rpt.query(query_string)

Employing Regular Expressions for Pattern Matching

When filtering requires matching substrings, prefixes, suffixes, or more complex structural requirements within string columns, the str.contains() function, leveraging regular expressions, becomes the superior choice over simple inclusion checks.

Filtering by String Pattern (e.g., starting with ‘600’ followed by three digits):

To select STK_ID entries that strictly start with ‘600’ and end with exactly three digits, you construct a pattern incorporating anchors (^ for start, $ for end):

# Solution 2: Filtering using str.contains with anchors for precise structure
# Pattern: Starts with '600', followed by exactly three digits, then ends.
pattern_start = r'^600[0-9]{3}$'
filtered_by_start = rpt[rpt['STK_ID'].str.contains(pattern_start)]

# Example output structure observation:
# ...   STK_ID   ...
# ...  '600809'  ...
# ...  '600141'  ...

Filtering by Multiple Suffixes:

If you need records where the 'STK_ID' ends with one of several specified strings (e.g., ‘01’, ‘02’, or ‘05’), you can combine these suffix patterns using the regex OR operator (|):

# Solution 2 continued: Filtering by multiple end patterns
end_patterns = ['01$', '02$', '05$'] # Each must include '$' anchor for end matching
combined_suffix_pattern = '|'.join(end_patterns)

filtered_by_suffix = rpt[rpt['STK_ID'].str.contains(combined_suffix_pattern)]

# Example output structure observation:
# ...   STK_ID   ...
# ...  '155905'  ...
# ...  '633101'  ...

Case Insensitivity in String Matching:

The str.contains() method accepts a case parameter to control case sensitivity. Setting case=False allows matching regardless of capitalization:

# Solution 2 continued: Case-insensitive matching
# This would match 'pandas', 'PANDAS', 'PanDAs123', etc.
case_insensitive_match = rpt['Description'].str.contains('pandas', case=False)

Numeric Range Filtering with Boolean Indexing or Query

Filtering based on numerical boundaries is common, whether using standard boolean indexing or the expressive query() method.

Boolean Indexing for Ranges (Solution 4):

This uses standard logical operators (& for AND) wrapped around conditions applied to columns:

# Solution 4: Filtering numeric ranges using boolean indexing
# Example selecting where column 'a' is between 1 and 5 (exclusive)
df_range_bool = df[(df['a'] > 1) & (df['a'] < 5)]

Query Method for Numeric Ranges (Solution 3 & 7):

The query() method allows inline specification of range comparisons:

# Solution 3/7: Filtering numeric ranges using the query method
# Filtering 'STK_ID' between 60000 and 70000 (exclusive)
filtered_numeric_query = rpt.query('60000 < STK_ID < 70000')

# Alternative form matching Solution 7
df_range_query = df.query('a > 1 & a < 5')

Advanced Indexing and Data Merging Techniques

For repeated lookups or performance optimization on large datasets, manipulating the DataFrame index can be beneficial.

Indexing and .loc Access (Solution 5):

By setting the lookup column (STK_ID) as the index, selection via .loc becomes highly efficient for subsequent lookups of specific index labels:

# Solution 5: Using set_index and .loc
rpt_indexed = rpt.set_index('STK_ID', inplace=False) # Use inplace=False to retain original
labels_to_fetch = [4, 2, 6]
filtered_by_loc = rpt_indexed.loc[labels_to_fetch]

DataFrame Merging (Solution 5):

If the list of items to filter by exists in a separate structure, merging the DataFrames on the common key (STK_ID) acts as a powerful filter mechanism:

# Solution 5: Merging to filter
stkid_lookup_df = pd.DataFrame({"STK_ID": [4, 2, 6]})
filtered_by_merge = rpt.merge(stkid_lookup_df, on='STK_ID')

Using @ Symbol in Query with External Variables (Solution 6)

The query() method supports referencing external local variables within the query string by prefixing the variable name with @. This is excellent for dynamic filtering lists:

# Solution 6: Using @ to reference an external list in query
df_dynamic = pd.DataFrame({'A' : [5,6,3,4], 'B' : [1,2,3, 5]})
list_of_values_to_find = [3, 6]

result_dynamic = df_dynamic.query("A in @list_of_values_to_find")
# result_dynamic will contain rows where A is 6 or 3

FAQs on Pandas DataFrame Filtering Techniques

Q: What is the fastest way to select rows based on an exact list of column values

ANS: Generally, using the DataFrame boolean mask created by the .isin() method is highly efficient for exact value matching, especially when compared to row-by-row iteration or complex query parsing, though index-based lookups (.loc) after setting the index can be quicker for repeated selections.

Q: How do I find rows where a string column starts with specific text

ANS: Utilize df['column_name'].str.contains(r'^prefix') where ^ is the regex anchor for the start of the string.

Q: Can query method filter based on an external Python list variable

ANS: Yes, reference the external variable directly within the query string by prefixing it with the @ symbol, for example: df.query('ID in @my_id_list').
