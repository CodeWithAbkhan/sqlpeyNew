“Pandas Aggregation: Grouping, Summarizing, and Transforming Data Effectively”

Pandas provides powerful tools for data aggregation, allowing you to reduce the dimensionality of your data by applying functions to groups of rows. This is essential for summarizing data and preparing it for analysis. The primary method for this is groupby(), often followed by aggregation functions.

Key Aggregation Functions

Several built-in functions streamline common aggregation tasks:

  • mean(): Computes the average of values within each group.
  • sum(): Calculates the total sum of values in each group.
  • size(): Returns the number of rows in each group, including those with missing values.
  • count(): Calculates the number of non-missing values in each group.
  • std(): Computes the standard deviation for each group.
  • var(): Calculates the variance for each group.
  • sem(): Computes the standard error of the mean for each group.
  • describe(): Generates a variety of descriptive statistics for each group.
  • first(): Retrieves the first value in each group.
  • last(): Retrieves the last value in each group.
  • nth(n): Takes the nth value from each group.
  • min(): Finds the minimum value within each group.
  • max(): Finds the maximum value within each group.

Performing Aggregations

Let’s illustrate with a sample DataFrame:

import pandas as pd
import numpy as np

np.random.seed(123) # For reproducible random numbers

df = pd.DataFrame({
    'A' : ['foo', 'foo', 'bar', 'foo', 'bar', 'foo'],
    'B' : ['one', 'two', 'three','two', 'two', 'one'],
    'C' : np.random.randint(5, size=6),
    'D' : np.random.randint(5, size=6),
    'E' : np.random.randint(5, size=6)
})

print("Original DataFrame:")
print(df)

Output:

Original DataFrame:
     A      B  C  D  E
0  foo    one  2  3  0
1  foo    two  4  1  0
2  bar  three  2  1  1
3  foo    two  1  0  3
4  bar    two  3  1  4
5  foo    one  2  1  0

Aggregating Specific Columns

To aggregate a particular column after grouping:

# Sum of column 'C' grouped by 'A' and 'B'
df_agg_c_sum = df.groupby(['A', 'B'], as_index=False)['C'].sum()
print("\nSum of 'C' grouped by 'A' and 'B':")
print(df_agg_c_sum)

Output:

Sum of 'C' grouped by 'A' and 'B':
     A      B  C
0  bar  three  2
1  bar    two  3
2  foo    one  4
3  foo    two  5

Aggregating All Numeric Columns

When no specific columns are selected, groupby() aggregates all numeric columns:

# Sum of all numeric columns grouped by 'A' and 'B'
df_agg_all_sum = df.groupby(['A', 'B'], as_index=False).sum()
print("\nSum of all numeric columns grouped by 'A' and 'B':")
print(df_agg_all_sum)

Output:

Sum of all numeric columns grouped by 'A' and 'B':

0  bar  three  2  1  1
1  bar    two  3  1  4
2  foo    one  4  4  0
3  foo    two  5  1  3

Aggregating Multiple Specific Columns

You can specify multiple columns for aggregation:

# Sum of 'C' and 'D' grouped by 'A' and 'B'
df_agg_cd_sum = df.groupby(['A', 'B'], as_index=False)['C','D'].sum()
print("\nSum of 'C' and 'D' grouped by 'A' and 'B':")
print(df_agg_cd_sum)

Output:

Sum of 'C' and 'D' grouped by 'A' and 'B':
     A      B  C  D
0  bar  three  2  1
1  bar    two  3  1
2  foo    one  4  4
3  foo    two  5  1

Using the .agg() Method

The .agg() method offers more flexibility, allowing you to apply multiple aggregation functions simultaneously and rename the resulting columns.

# Applying 'sum' to column 'C' using .agg()
df_agg_c_agg_sum = df.groupby(['A', 'B'], as_index=False)['C'].agg('sum')
print("\nSum of 'C' using .agg('sum'):")
print(df_agg_c_agg_sum)

# Applying 'sum' to all columns using .agg()
df_agg_all_agg_sum = df.groupby(['A', 'B'], as_index=False).agg('sum')
print("\nSum of all columns using .agg('sum'):")
print(df_agg_all_agg_sum)

# Applying multiple functions to column 'C'
df_multi_agg = (df.groupby(['A', 'B'])['C']
                .agg([('average','mean'), ('total','sum')])
                .reset_index())
print("\nMultiple aggregations on 'C' with custom names:")
print(df_multi_agg)

# Applying multiple functions to multiple columns
df_multi_col_agg = (df.groupby(['A', 'B'])
                    .agg([('average','mean'), ('total','sum')]))

# Flattening the MultiIndex columns
df_multi_col_agg.columns = df_multi_col_agg.columns.map('_'.join)
df_multi_col_agg = df_multi_col_agg.reset_index()
print("\nMultiple aggregations on multiple columns with flattened names:")
print(df_multi_col_agg)

# Alternative method for flattening MultiIndex columns
df_multi_col_agg_alt = df.groupby(['A', 'B']).agg(['mean','sum'])
df_multi_col_agg_alt.columns = (df_multi_col_agg_alt.columns.map('_'.join)
                               .str.replace('sum','total')
                               .str.replace('mean','average'))
df_multi_col_agg_alt = df_multi_col_agg_alt.reset_index()
print("\nAlternative method for multiple aggregations with flattened names:")
print(df_multi_col_agg_alt)

# Aggregating specific columns with different functions using a dictionary
df_dict_agg = (df.groupby(['A', 'B'], as_index=False)
               .agg({'C':'sum', 'D':'mean'})
               .rename(columns={'C':'C_total', 'D':'D_average'}))
print("\nAggregating specific columns with different functions via dictionary:")
print(df_dict_agg)

# Using a custom function for aggregation
def sum_first_last(x):
    return x.iat[0] + x.iat[-1]

df_custom_agg = (df.groupby(['A', 'B'], as_index=False)
                 .agg({'C':'sum', 'D': sum_first_last})
                 .rename(columns={'C':'C_total', 'D':'D_sum_first_and_last'}))
print("\nAggregating with a custom function:")
print(df_custom_agg)

Handling Aggregations with No Row Reduction

When you want to maintain the original number of rows, perhaps for feature engineering, transform() is your ally. It applies a function to each group and broadcasts the result back to the original DataFrame’s shape.

# Add a new column 'C1' which is the sum of 'C' for each group in 'A'
df['C1'] = df.groupby('A')['C'].transform('sum')

# Add a new column 'C2' which is the sum of 'C' for each group in 'A' and 'B'
df['C2'] = df.groupby(['A','B'])['C'].transform('sum')

# Add multiple transformed columns
df[['C3','D3']] = df.groupby('A')['C','D'].transform('sum')
df[['C4','D4']] = df.groupby(['A','B'])['C','D'].transform('sum')

print("\nDataFrame after adding transformed columns:")
print(df)

Output:

DataFrame after adding transformed columns:

0  foo    one  2  3  0    9   4   9   5   4   4
1  foo    two  4  1  0    9   5   9   5   5   1
2  bar  three  2  1  1    5   2   5   2   2   1
3  foo    two  1  0  3    9   5   9   5   5   1
4  bar    two  3  1  4    5   3   5   2   3   1
5  foo    one  2  1  0    9   4   9   5   4   4

Aggregating Strings and Counts

Aggregating String Data

You can aggregate string columns into lists, comma-separated strings, or other formats.

df_str = pd.DataFrame({
    'A' : ['a', 'c', 'b', 'b', 'a', 'c', 'b'],
    'B' : ['one', 'two', 'three','two', 'two', 'one', 'three'],
    'C' : ['three', 'one', 'two', 'two', 'three','two', 'one'],
    'D' : [1,2,3,2,3,1,2]
})

print("\nString Aggregation DataFrame:")
print(df_str)

# Aggregate column 'B' into a list
df_str_list = df_str.groupby('A')['B'].agg(list).reset_index()
print("\nAggregating 'B' into a list:")
print(df_str_list)

# Aggregate column 'B' into a comma-separated string
df_str_join = df_str.groupby('A')['B'].agg(','.join).reset_index()
print("\nAggregating 'B' into a comma-separated string:")
print(df_str_join)

# Aggregate numeric column 'D' into a comma-separated string after conversion
df_str_num_join = (df_str.groupby('A')['D']
                   .agg(lambda x: ','.join(x.astype(str)))
                   .reset_index())
print("\nAggregating numeric 'D' into a string with conversion:")
print(df_str_num_join)

# Aggregate all columns into comma-separated strings
df_str_all_join = (df_str.groupby('A')
                   .agg(lambda x: ','.join(x.astype(str)))
                   .reset_index())
print("\nAggregating all columns into strings:")
print(df_str_all_join)

Aggregating Counts

Counting occurrences within groups is a common task.

df_count = pd.DataFrame({
    'A' : ['a', 'c', 'b', 'b', 'a', 'c', 'b'],
    'B' : ['one', 'two', 'three','two', 'two', 'one', 'three'],
    'C' : ['three', np.nan, np.nan, 'two', 'three','two', 'one'],
    'D' : [np.nan,2,3,2,3,np.nan,2]
})

print("\nCount Aggregation DataFrame:")
print(df_count)

# Size of each group (includes NaNs)
df_count_size = df_count.groupby('A').size().reset_index(name='COUNT')
print("\nGroup size (includes NaNs):")
print(df_count_size)

# Count of non-missing values in column 'C'
df_count_c = df_count.groupby('A')['C'].count().reset_index(name='COUNT')
print("\nCount of non-missing values in 'C':")
print(df_count_c)

# Count of non-missing values for all columns
df_count_all = df_count.groupby('A').count().add_suffix('_COUNT').reset_index()
print("\nCount of non-missing values for all columns:")
print(df_count_all)

# Using Series.value_counts for counts
df_value_counts = (df_count['A'].value_counts()
                   .rename_axis('A')
                   .reset_index(name='COUNT'))
print("\nCounts using Series.value_counts():")
print(df_value_counts)

# Value counts sorted by index
df_value_counts_sorted = (df_count['A'].value_counts()
                          .sort_index()
                          .rename_axis('A')
                          .reset_index(name='COUNT'))
print("\nCounts using Series.value_counts() sorted by index:")
print(df_value_counts_sorted)

Aggregation Styles (SQL/R Parallels)

Pandas aggregation aligns closely with SQL and R’s data manipulation paradigms.

df_sql_r = pd.DataFrame({
    'key1' : ['a','a','a','b','a'],
    'key2' : ['c','c','d','d','e'],
    'value1' : [1,2,2,3,3],
    'value2' : [9,8,7,6,5]
})

print("\nSQL/R Style Aggregation DataFrame:")
print(df_sql_r)

# Pandas >= 0.25 Style (similar to SQL GROUP BY with named aggregations)
print("\nPandas >= 0.25 Aggregation Style:")
df_agg_new = df_sql_r.groupby(['key1','key2']).agg(
    mean_of_value_1=('value1', 'mean'),
    sum_of_value_2=('value2', 'sum'),
    count_of_value1=('value1','size')
).reset_index()
print(df_agg_new)

# Pandas < 0.25 Style (requires manual column renaming)
print("\nPandas < 0.25 Aggregation Style:")
df_agg_old = df_sql_r.groupby(['key1','key2'],as_index=False).agg({'value1':['mean','count'],'value2':'sum'})
df_agg_old.columns = ['_'.join(col).strip() for col in df_agg_old.columns.values]
df_agg_old.rename(columns={
    "value1_mean" : "mean_of_value1",
    "value1_count" : "count_of_value1",
    "value2_sum" : "sum_of_value2"
}, inplace=True)
print(df_agg_old)

# Excel SUMIF/COUNTIF equivalent using transform
print("\nTransform for Excel SUMIF/COUNTIF equivalent:")
df_sql_r['Total_of_value1_by_key1'] = df_sql_r.groupby('key1')['value1'].transform('sum')
print(df_sql_r)

# ROW_NUMBER() OVER (PARTITION BY ORDER BY) equivalent
print("\nROW_NUMBER() OVER (PARTITION BY ORDER BY) equivalent:")
df_sql_r['RN'] = df_sql_r.sort_values(['value1','value2'], ascending=[False,True]) \
                           .groupby(['key1']) \
                           .cumcount() + 1
print(df_sql_r)

FAQs on Pandas Aggregation

Q: What does Pandas aggregation mean

ANS: Pandas aggregation involves grouping data based on certain criteria and then applying functions like sum, mean, count, etc., to reduce the data to a summary form. This process helps in extracting meaningful insights from datasets.

Q: How to group by multiple columns in Pandas

ANS: You can group by multiple columns in Pandas by passing a list of column names to the groupby() method, like df.groupby(['column1', 'column2']).

Q: How to rename aggregated columns in Pandas

ANS: When using the .agg() method with keyword arguments (e.g., mean_value=('column', 'mean')), the columns are automatically named. For older Pandas versions or when using .agg() with a dictionary, you can rename columns using .rename() or by manipulating df.columns after aggregation.

Q: What is the difference between size and count in Pandas groupby

ANS: size() returns the total number of rows in each group, including rows with missing values (NaNs). count() returns the number of non-missing values for each specified column within each group.

Q: How to apply multiple aggregation functions in Pandas

ANS: You can apply multiple aggregation functions by passing a list of function names (e.g., ['mean', 'sum']) or a dictionary mapping column names to lists of functions to the .agg() method.

Q: How to create a new column with aggregated values without row reduction

ANS: The .transform() method is used for this. It applies a function to each group and returns a Series or DataFrame with the same index as the original, effectively broadcasting the aggregated value back to all rows within its group.
