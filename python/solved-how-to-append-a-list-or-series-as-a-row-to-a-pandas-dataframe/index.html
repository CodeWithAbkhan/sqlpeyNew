Solved: How to Append a List or Series as a Row to a Pandas DataFrame

In Python, when working with Pandas, you might find yourself needing to append a list or series to a DataFrame as a new row. There are several methodologies to achieve this, each with its advantages and scenarios where one might be more suitable than the others. Below we explore twelve different methods for appending a list or a series to a Pandas DataFrame.

Method 1: Create the DataFrame from the List in One Go

Sometimes, it’s more manageable to avoid multiple appending operations and instead create the entire DataFrame in a single operation.

import pandas as pd

## Initialize a list of lists
simple_list = [['a', 'b']]
simple_list.append(['e', 'f'])

## Create DataFrame from the list
df = pd.DataFrame(simple_list, columns=['col1', 'col2'])
print(df)

Output:

  col1 col2
0    a    b
1    e    f

Method 2: Appending Using a Dictionary

You can append a row by providing a dictionary that maps column names to values.

import pandas as pd

## Start with an empty DataFrame
df = pd.DataFrame()

## Append row as dictionary
df = df.append({'foo': 1, 'bar': 2}, ignore_index=True)
print(df)

Output:

   foo  bar
0    1    2

Method 3: Appending a Series with Specified Index

Another approach is to use a Series object and append it to the DataFrame.

import pandas as pd

## Initialize DataFrame with columns
df = pd.DataFrame(columns=['col1', 'col2'])

## Append Series
df = df.append(pd.Series(['a', 'b'], index=['col1', 'col2']), ignore_index=True)
df = df.append(pd.Series(['d', 'e'], index=['col1', 'col2']), ignore_index=True)
print(df)

Output:

  col1 col2
0    a    b
1    d    e

Method 4: Appending After Creating the DataFrame

After the DataFrame is populated, you might want to append additional rows from a list.

import pandas as pd

## Define an initial DataFrame
df = pd.DataFrame({'col1': ['a', 'b'], 'col2': ['c', 'd']})

## New list to append
new_list = [['f', 'g']]
df = df.append(pd.DataFrame(new_list, columns=['col1', 'col2']), ignore_index=True)
print(df)

Output:

  col1 col2
0    a    c
1    b    d
2    f    g

Method 5: Different Conversion and Append Methods

Here’s an example showing various ways to append a list.

import pandas as pd

## DataFrame
df = pd.DataFrame([[1, 2], [3, 4]], columns=["col1", "col2"])
## List to append
to_append = [5, 6]

## Option 1
df.loc[len(df)] = to_append

## Option 2
df = df.append(pd.DataFrame([to_append], columns=df.columns), ignore_index=True)

## Option 3
df = df.append(pd.Series(to_append, index=df.columns), ignore_index=True)

print(df)

Output:

   col1  col2
0     1     2
1     3     4
2     5     6

Method 6: Append from a List in a Loop

You can constantly append from a list in a loop into the DataFrame.

import pandas as pd

my_list = [1, 2, 3]
df = pd.DataFrame()

for item in my_list:
    df = df.append({'Value': item}, ignore_index=True)

print(df)

Output:

   Value
0      1
1      2
2      3

Method 7: Function to Append a Row

You can encapsulate the logic to append a row into a function for reusability.

import pandas as pd
import numpy as np

def add_row(df, ls):
    new_row = pd.DataFrame(np.array(ls).reshape(1, -1), columns=list(df.columns))
    return df.append(new_row, ignore_index=True)

df = pd.DataFrame(columns=['A', 'B', 'C'])
df = add_row(df, [1, 2, 3])
print(df)

Output:

   A  B  C
0  1  2  3

Method 8: Appending a Series as a Row

You can use brackets around a Series to append it as a new row directly.

import pandas as pd

df = pd.DataFrame()
row = pd.Series([1, 2, 3], index=["A", "B", "C"])
df = df.append([row], ignore_index=True)
print(df)

Output:

   A  B  C
0  1  2  3

Method 9: Appending an Array as a New Row

If you have a NumPy array, you can utilize it to append rows effortlessly.

import pandas as pd

## Start DataFrame
df = pd.DataFrame(columns=['A', 'B'])

## Array to append
new_row = [3, 4]
df.loc[len(df)] = new_row
print(df)

Output:

   A  B
0  3  4

Method 10: Adding Rows with Specific Indexing

An efficient way involves using .loc to assign values directly by index.

import pandas as pd

## Initialize DataFrame
df = pd.DataFrame(columns=['A', 'B', 'C'])

## Using .loc to add rows
df.loc['row1'] = [1, 2, 3]
df.loc['row2'] = [4, 5, 6]
print(df)

Output:

       A  B  C
row1  1  2  3
row2  4  5  6

Method 11: Reminder for Series Conversion

In cases where the list needs to be treated as a Series, make sure to convert it first.

import pandas as pd

df = pd.DataFrame([[1, 2], [3, 4]], columns=["a", "b"])
to_append = [5, 6]
a_series = pd.Series(to_append, index=df.columns)
df = df.append(a_series, ignore_index=True)
print(df)

Output:

   a  b
0  1  2
1  3  4
2  5  6

Method 12: Efficiently Using pd.concat

Using pd.concat is preferred as DataFrame.append is being deprecated.

import pandas as pd

## Create an empty DataFrame
empty_df = pd.DataFrame(columns=["Col1", "Col2"])

## List to append
list_to_append = [1, 2]
dict_from_list = {k: v for k, v in zip(empty_df.columns, list_to_append)}
df_for_list = pd.DataFrame(dict_from_list, index=[0])

## Concatenate
concatenated_df = pd.concat([empty_df, df_for_list], ignore_index=True)
print(concatenated_df)

Output:

   Col1  Col2
0     1     2

Additional Considerations

Make sure that the list length aligns exactly with the number of columns in your DataFrame. Each approach yields similar results, so your choice should depend on your specific use case, existing data structures, and performance considerations.

FAQs on How to Append a List or Series as a Row to a Pandas DataFrame

Q: What is the most efficient way to append rows to a DataFrame?

A: Using pd.concat is often the most efficient method, especially when dealing with multiple rows or large datasets.

Q: Can I append a list to an empty DataFrame?

A: Yes, you can initialize an empty DataFrame and append a list as a new row as shown in the examples above.

Q: Is there a limit to how many times I can append?

A: While there is no hard limit, appending rows individually in a loop can be slow with larger DataFrames. Use pd.concat or build lists first to improve performance.

Q: Will using ignore_index allow for better organization of new rows?

A: Yes, setting ignore_index=True helps in resetting the row indices to avoid duplication and maintain proper order.
