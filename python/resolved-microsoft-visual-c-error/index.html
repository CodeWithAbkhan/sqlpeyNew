Solved: How to Resolve the ‘Microsoft Visual C++ 14.0 or Greater is Required’ Error During Python Package Installation

When attempting to install a Python package, you might encounter the frustrating error stating that Microsoft Visual C++ 14.0 or greater is required. This typically arises when you try to run commands like pip install google-search-api. Below are several effective methods to resolve this issue and successfully install your required packages.

Common Error Encountered

The specific error message can often read:

error: Microsoft Visual C++ 14.0 or greater is required. Get it with "Microsoft C++ Build Tools": https://visualstudio.microsoft.com/visual-cpp-build-tools/

This situation can occur even if you have updated to the latest version, such as 14.27.

Top 5 Ways to Resolve the Microsoft Visual C++ Error

Method 1: Download Pre-built Wheels

This error is frequently linked to compatibility issues with the latest versions of Python, like 3.12, where the necessary package wheels may only be built for older editions. To bypass this, you can download compatible wheels from third-party sources:

  • Visit Unofficial Windows Binaries for Python Extension Packages to find the required .whl files.

    For example, if you see the error:

    Failed to build frozenlist multidict

    Then download the appropriate wheels:

    • For frozenlist: Download frozenlist-1.3.0-py3-none-any.whl
    • For multidict: Download multidict-6.0.2-py3-none-any.whl

    Install them locally via command:

    pip install .\frozenlist-1.3.0-py3-none-any.whl
pip install .\multidict-6.0.2-py3-none-any.whl

    Afterward, you can continue with your initial installation:

    pip install -r .\requirements.txt

Method 2: Downgrading Python

If the above methods do not prove effective, consider downgrading your version of Python from 3.10 to 3.9. Several users have reported success with this approach, including a reference in Stack Overflow .

Method 3: Install Visual C++ Build Tools

You can manually install the required Visual C++ Build Tools:

vs_buildtools__370953915.1537938681.exe --quiet --add Microsoft.VisualStudio.Workload.VCTools
VC_redist.x64.exe /q /norestart

This method streamlines the installation process without unnecessary prompts.

Method 4: Retry with pip Upgrades

Sometimes, simply upgrading key installation tools can resolve conflicts:

  1. Upgrade pip:

    python -m pip install --upgrade pip

  2. Upgrade wheel:

    pip install --upgrade wheel

  3. Upgrade setuptools:

    pip install --upgrade setuptools

  4. Close the terminal and retry the installation.

Method 5: Use a Conda Environment

Opt for a conda virtual environment instead of virtualenv as Conda often includes the necessary dependencies (like vs2015_runtime) for successfully compiling wheels.

conda create --name myenv python=3.10
conda activate myenv
pip install google-search-api

This can significantly smooth out the installation process without running into build issues.

Practical Example

To summarize, if you encounter the multidict issue:

  1. Establish a conda environment.
  2. Install the necessary packages using the aforementioned methods.
  3. Confirm that the installation completes without the Visual C++ error.

Alternative Approaches

If the standard solutions aren’t suitable due to size constraints or system limitations, consider using Portable Build Tools , which only contains the necessary components for builds.

FAQs on Microsoft Visual C++ Error Resolution

Q: What causes the 'Microsoft Visual C++ 14.0 or greater is required' error?

A: This error generally occurs when installing Python packages that depend on C extensions and the appropriate C++ compilers are not available on your system.

Q: Can I skip installing Visual Studio Build Tools?

A: Yes, you can avoid installing the full Visual Studio Build Tools by using pre-built wheel files from repositories like the one found at Unofficial Windows Binaries .

Q: Is it necessary to downgrade Python?

A: Not necessarily, but downgrading to a more stable version (like 3.9) can resolve compatibility issues if you encounter persistent errors while using the latest versions.
