How to Combine DataFrame Columns in Pandas

The primary goal is to merge data from several columns into one, often with a specified separator or formatting. Let’s look at the most effective approaches.

Solution 1: Direct String Concatenation (for String Columns)

If both columns you intend to combine are already of string type, you can simply use the + operator for direct concatenation.

import pandas as pd

# Sample DataFrame
df = pd.DataFrame({'Year': ['2014', '2015'], 'quarter': ['q1', 'q2']})

# Concatenate columns directly
df["period"] = df["Year"] + df["quarter"]
print(df)

Output:

   Year quarter   period
0  2014      q1   2014q1
1  2015      q2   2015q2

Solution 2: Type Conversion Before Concatenation

When one or both columns are not strings (e.g., integers, floats), you must convert them to strings first using .astype(str) before concatenating.

# Sample DataFrame with mixed types
df = pd.DataFrame({'Year': [2014, 2015], 'quarter': ['q1', 'q2']})

# Convert to string and then concatenate
df["period"] = df["Year"].astype(str) + df["quarter"]
print(df)

Output:

   Year quarter   period
0  2014      q1   2014q1
1  2015      q2   2015q2
  • Handling NaNs: Be mindful of missing values (NaN). Direct concatenation with NaN will result in NaN in the combined column. To avoid this, you can use .fillna() on the relevant columns before conversion and concatenation. For instance: df["Year"].fillna('').astype(str) + df["quarter"].fillna('').astype(str).

Solution 3: Using .agg() for Multiple Columns

For combining more than two columns or when you need a consistent separator, the .agg() method with axis=1 is highly efficient.

# Sample DataFrame with multiple columns
df = pd.DataFrame({
    'Year': ['2014', '2015'],
    'quarter': ['q1', 'q2'],
    'month': ['Jan', 'Feb']
})

# Concatenate multiple columns with a separator
df['period'] = df[['Year', 'quarter', 'month']].agg('-'.join, axis=1)
print(df)

Output:

   Year quarter month       period
0  2014      q1   Jan  2014-q1-Jan
1  2015      q2   Feb  2015-q2-Feb

This method is particularly useful for creating formatted keys or identifiers.

Solution 4: .str.cat() for String Series

Pandas Series have a .str.cat() method designed specifically for string concatenation. It offers flexibility with separators and handling multiple columns.

# Sample DataFrame
df = pd.DataFrame({'Year': ['2014', '2015'], 'Quarter': ['q1', 'q3']})

# Using str.cat with a default separator
df['Period'] = df.Year.str.cat(df.Quarter)
print(df)

# Using str.cat with a specified separator
df['Period_with_sep'] = df.Year.astype(str).str.cat(df.Quarter.astype(str), sep='q')
print(df)

# Combining multiple columns
df_multi = pd.DataFrame(
    [['USA', 'Nevada', 'Las Vegas'],
     ['Brazil', 'Pernambuco', 'Recife']],
    columns=['Country', 'State', 'City'],
)
df_multi['AllTogether'] = df_multi['Country'].str.cat(df_multi[['State', 'City']], sep=' - ')
print(df_multi)

Output:

   Year Quarter Period Period_with_sep
0  2014      q1   2014q1          2014q1
1  2015      q3   2015q3          2015q3

  Country       State       City                   AllTogether
0     USA      Nevada  Las Vegas      USA - Nevada - Las Vegas
1  Brazil  Pernambuco     Recife  Brazil - Pernambuco - Recife
  • na_rep: When dealing with potential NaN values, use the na_rep argument in str.cat() to replace them with a specified string, preventing the entire concatenated result from becoming NaN.

Solution 5: Using apply() with Lambda Functions

The .apply() method offers a way to execute custom logic for each row, which can be used for concatenation, especially when complex formatting is needed.

# Sample DataFrame
df = pd.DataFrame({'Year': ['2014', '2015'], 'Quarter': ['q1', 'q2']})

# Using apply with f-string formatting
df['YearQuarter'] = df[['Year','Quarter']].apply(lambda x : f'{x[0]}{x[1]}', axis=1)
print(df)

# With different formatting
df_formatted = pd.DataFrame({'Year': ['2014', '2015'], 'Quarter': [1, 2]})
df_formatted['YearQuarter'] = df_formatted[['Year','Quarter']].apply(lambda x : f'{x[0]}q{x[1]}', axis=1)
print(df_formatted)

Output:

   Year Quarter YearQuarter
0  2014      q1      2014q1
1  2015      q2      2015q2
   Year  Quarter YearQuarter
0  2014        1      2014q1
1  2015        2      2015q2

This method is very flexible for custom string constructions. For more advanced use cases, explore the Pandas apply() documentation .

Solution 6: Generalizing with .astype(str).sum(axis=1)

For combining multiple columns with a simple concatenation (no separator), you can convert all selected columns to string type and then use .sum(axis=1).

# Sample DataFrame
columns_to_combine = ['col1', 'col2', 'col3']
df = pd.DataFrame({col: [f'{col}_val{i}' for i in range(2)] for col in columns_to_combine})

# Combine columns by summing their string representations
df['combined_cols'] = df[columns_to_combine].astype(str).sum(axis=1)
print(df)

Output:

       col1       col2       col3                combined_cols
0  col1_val0  col2_val0  col3_val0  col1_val0col2_val0col3_val0
1  col1_val1  col2_val1  col3_val1  col1_val1col2_val1col3_val1

Solution 7: Using DataFrame.eval()

DataFrame.eval() provides a concise syntax for column operations.

# Sample DataFrame
df = pd.DataFrame({'A': ['x', 'y', 'z'], 'B': ['1', '2', '3']}, dtype='string')

# Concatenate columns using eval
df['C'] = df.eval("A + B")
print(df)

# Assigning the new column directly
df.eval('C = A + B', inplace=True)
print(df)

# Concatenating with a separator using eval and str.cat
df = df.eval("D = A.str.cat([B, 'C'], sep='_')")
print(df)

Output:

   A  B  C
0  x  1  x1
1  y  2  y2
2  z  3  z3
   A  B   C
0  x  1  x1
1  y  2  y2
2  z  3  z3
   A  B   C    D
0  x  1  x1  x_1_x1
1  y  2  y2  y_2_y2
2  z  3  z3  z_3_z3

Solution 8: NumPy’s add for Performance

For optimal performance, especially with large datasets and numeric types, leveraging NumPy’s vectorized operations can be beneficial.

from functools import reduce
import pandas as pd

# Helper function using NumPy

# Sample DataFrame
data = list(zip([2000]*4, ['q1', 'q2', 'q3', 'q4']))
df = pd.DataFrame(data=data, columns=['Year', 'quarter'])

# Apply the madd function
df['period'] = madd([df[col].values for col in ['Year', 'quarter']])
print(df)

Output:

   Year quarter period
0  2000      q1   2000q1
1  2000      q2   2000q2
2  2000      q3   2000q3
3  2000      q4   2000q4

This approach converts columns to NumPy arrays and then uses np.core.defchararray.add for efficient concatenation.

Solution 9: Using zip and List Comprehension

A Pythonic way to combine columns, especially for smaller datasets or when a specific loop-like structure is preferred.

# Sample DataFrame
df = pd.DataFrame({'Year': ['2014', '2015'], 'quarter': ['q1', 'q2']})

# Combine using zip and list comprehension
df["period"] = [''.join(i) for i in zip(df["Year"].map(str), df["quarter"])]
print(df)

Output:

   Year quarter   period
0  2014      q1   2014q1
1  2015      q2   2015q2

Performance Considerations

For short strings, vectorized operations like df['col1'].astype(str) + df['col2'] or df['col1'].str.cat(df['col2']) are generally the fastest. For very long strings, or when complex formatting is involved, apply() with an f-string and list comprehension might offer better performance. Benchmarking with timeit on your specific data is always recommended for critical applications.

FAQs on Pandas Column Combination

Q: How to combine two columns in Pandas if they contain numbers

ANS: Convert both columns to string type using .astype(str) before concatenating them with the + operator or using .str.cat(). For example: df['new_col'] = df['num_col1'].astype(str) + df['num_col2'].astype(str).

Q: What is the best way to combine multiple columns with a separator

ANS: The .agg('-'.join, axis=1) method is very efficient for combining multiple columns with a specified separator. Alternatively, you can use df.apply(lambda x: separator.join(x.astype(str)), axis=1).

Q: How to handle missing values (NaN) when combining columns

ANS: Before concatenating, use .fillna('') on the columns that might contain NaN values to replace them with an empty string. This prevents the entire combined string from becoming NaN. For example: df['col1'].fillna('').astype(str) + df['col2'].fillna('').astype(str).

Q: Which method is fastest for combining Pandas columns

ANS: For short strings, direct vectorized concatenation (+) or .str.cat() are usually the fastest. For longer strings, a list comprehension with f-strings might outperform apply() or vectorized methods. Performance can vary based on data size and string length; benchmarking is advised.

Q: Can I combine columns with different data types

ANS: Yes, ensure you convert all columns to string type using .astype(str) before attempting concatenation. Methods like .agg() and apply() are flexible in handling mixed data types after conversion.
