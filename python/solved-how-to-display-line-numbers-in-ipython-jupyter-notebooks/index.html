Solved: How to Display Line Numbers in IPython/Jupyter Notebooks

Error reports from various language kernels operating within IPython/Jupyter Notebooks usually point out the specific line where an error has occurred. However, by default, line numbers are not visible in these notebooks. So, how can you enable line numbers in IPython/Jupyter Notebooks for better clarity and debugging? Here are several practical methods to achieve this.

Method 1: Quick Keyboard Shortcut

In IPython version 2.2.0 and later, toggling line numbers is straightforward. Simply switch to command mode by pressing the Esc key and then type l (lowercase L). For more customization options, refer to [Help] -> [Keyboard Shortcuts].

Method 2: Toggle from the Interface

You can enable line numbers through the interface:

  1. Navigate to View in the main menu.
  2. Select Toggle Line Number.

This will toggle line numbers on the currently active cell.

Method 3: Command Mode Toggle

  1. Press Escape to enter command mode (you’ll see the left part of the screen turn blue).
  2. Press L to add line numbers to the selected cell.
  3. If you prefer to hide them, repeat the process.
  4. To impact all notebook cells simultaneously, hold Shift while pressing L.

Method 4: Set Default Line Numbers

To automatically show line numbers for all cells whenever a notebook starts, follow these steps:

  1. Determine your Jupyter config directory by running this command in your terminal: 
    jupyter --config-dir
  2. Inside this directory, look for or create a folder named custom.
  3. Open (or create) the custom.js file within the custom directory and add the following code: 
    define([
    'base/js/namespace',
    'base/js/events'
],
function(IPython, events) {
    events.on("app_initialized.NotebookApp", function () {
        IPython.Cell.options_default.cm_config.lineNumbers = true;
    });
});

By adding this code, line numbers will display by default in every new notebook.

Method 5: Keyboard Shortcuts Reference

Different operating systems may have varying shortcuts. To get a list of active shortcuts, navigate to:

Help > Keyboard Shortcuts > toggle line numbers

For instance, on macOS while using IPython 3, it’s typically ESC + L.

Method 6: Jupyter Lab Settings

If you’re working with Jupyter Lab (specifically version 2.1.5 or later), follow these steps to see line numbers:

  1. Click View in the menu and then select Show Line Numbers.

Method 7: Command Palette Approach

If your default shortcut conflicts with another command (like saving the webpage), you can access the command palette:

  1. Click on the open the command palette icon in the toolbar.
  2. Type “Toggle Cell Line Number” to activate it from there.

Method 8: Advanced Settings for Jupyter Lab

To set line numbers to appear by default in Jupyter Lab, do the following:

  1. Go to Settings and then Advanced Settings Editor (or press Ctrl + ,).

  2. You’ll see three columns: Settings Category, System Defaults, and User Preferences.

  3. Select the notebook category and add the following configuration:

    {
    "codeCellConfig": {
        "lineNumbers": true
    }
}

Method 9: Toggle Line Numbers Globally

To toggle line numbers across all cells in Jupyter (available in versions like JupyterLab 1.0.0), use Shift + L, while in command mode (after pressing Escape).

Method 10: Toggle Through the Toolbar

You can also find the Toggle Line Numbers option under the View menu in the top toolbar of the notebook. This allows you to add or remove line numbers globally across cells.

For the non-active cell, simply:

  1. Click Esc to exit the cell.
  2. Use Shift + L to enable or disable line numbers.

Method 11: Alternative Shortcut

In some instances, you can use Ctrl + L to quickly toggle line numbers between cells in Jupyter Lab.

Method 12: The Conventional Command Path

  1. Enter command mode by pressing Esc.
  2. Press l (i.e., a lowercase L) to display line numbers.

These methods provide various ways to control the visibility of line numbers, allowing for improved debugging and navigation when working with your code.

FAQs on How to Display Line Numbers in IPython/Jupyter Notebooks

Q: How can I enable line numbers by default in Jupyter Notebooks?

A: You can set line numbers to be on by default by editing the custom.js file in your Jupyter configuration directory as described above.

Q: Are there different shortcuts for enabling line numbers in Jupyter Lab?

A: Yes, Jupyter Lab uses different shortcuts depending on the version and operating system. It’s best to check the keyboard shortcuts in the Help menu for your specific setup.

Q: What if my shortcuts conflict with other commands?

A: In such cases, you can use the command palette to find and execute the toggle line numbers command without relying on the keyboard shortcuts.
