“Python: Effective Ways to Remove Text Accents & Diacritics”

When working with text in Python, you’ll often encounter characters with diacritical marks (accents, umlauts, etc.) that need to be converted to their plain ASCII equivalents. This process, often called accent stripping or diacritic removal, is crucial for tasks like creating unique identifiers, performing case-insensitive searches, or ensuring compatibility across different systems.

Several methods exist in Python to achieve this, each with its own strengths and nuances. Let’s delve into these solutions with practical code examples.

Solution 1: Using unidecode for broad transliteration

The unidecode library provides a robust way to transliterate Unicode text into the closest possible ASCII representation. It handles a wide range of characters from various languages.

from unidecode import unidecode

# Example usage
unicode_string1 = 'kožušček'
ascii_string1 = unidecode(unicode_string1)
print(f"'{unicode_string1}' becomes '{ascii_string1}'")

unicode_string2 = '北亰'
ascii_string2 = unidecode(unicode_string2)
print(f"'{unicode_string2}' becomes '{ascii_string2}'")

unicode_string3 = 'François'
ascii_string3 = unidecode(unicode_string3)
print(f"'{unicode_string3}' becomes '{ascii_string3}'")

Output:

'kožušček' becomes 'kozuscek'
'北亰' becomes 'Bei Jing '
'François' becomes 'Francois'

Solution 2: Leveraging unicodedata for explicit accent removal

Python’s built-in unicodedata module offers fine-grained control over character normalization and processing. This approach involves decomposing characters and filtering out the combining marks.

import unicodedata

def strip_accents_unicodedata(text):
    """Strips accents from a string using unicodedata."""
    # Normalize to NFD (Canonical Decomposition)
    normalized_text = unicodedata.normalize('NFD', text)
    # Filter out characters categorized as Nonspacing_Mark (Mn)
    return ''.join(char for char in normalized_text if unicodedata.category(char) != 'Mn')

# Example usage
text_with_accents = "A \u00c0 \u0394 \u038E" # A À Δ Ύ
cleaned_text = strip_accents_unicodedata(text_with_accents)
print(f"'{text_with_accents}' becomes '{cleaned_text}'")

Output:

'A À Δ Ύ' becomes 'A A Δ Y'

This method is particularly useful for its explicitness, allowing you to target specific types of diacritical marks.

Solution 3: Encoding and Decoding with unicodedata

Another variation using unicodedata involves normalizing the string, encoding it to ASCII with an error handler, and then decoding it back.

import unicodedata

def remove_accents_encode_decode(input_str):
    """Removes accents by normalizing, encoding to ASCII, and decoding."""
    nfkd_form = unicodedata.normalize('NFKD', input_str)
    # Encode to ASCII, ignoring characters that can't be represented
    only_ascii = nfkd_form.encode('ASCII', 'ignore')
    # Decode back to a string
    return only_ascii.decode('utf-8')

# Example usage
accented_french = "café"
ascii_french = remove_accents_encode_decode(accented_french)
print(f"'{accented_french}' becomes '{ascii_french}'")

Output:

'café' becomes 'cafe'

Important Note: This method might drop characters that don’t have a direct ASCII equivalent, potentially altering the meaning or information in languages like Greek.

Solution 4: Creating Identifiers with Accent Stripping and Regex

For generating unique identifiers or slugs from text, combining accent stripping with regular expressions is a powerful approach. This ensures the resulting IDs are clean and URL-friendly.

import re
import unicodedata

def strip_accents_for_id(text):
    """Strips accents and prepares text for use as an identifier."""
    try:
        # Ensure text is Unicode
        text = unicode(text, 'utf-8')
    except (TypeError, NameError):
        # unicode is default on Python 3
        pass
    # Normalize and encode to ASCII, ignoring errors
    text = unicodedata.normalize('NFD', text)
    text = text.encode('ascii', 'ignore')
    text = text.decode('utf-8')
    return text

def text_to_id(text):
    """Converts input text to a cleaned identifier string."""
    # Strip accents, convert to lowercase, replace spaces with underscores
    cleaned_text = strip_accents_for_id(text.lower())
    cleaned_text = re.sub(r'[ ]+', '_', cleaned_text)
    # Remove any characters that are not alphanumeric, underscore, or hyphen
    cleaned_text = re.sub(r'[^0-9a-zA-Z_-]', '', cleaned_text)
    return cleaned_text

# Example usage
input_text = "Montréal, über, 12.89, Mère, Françoise, noël, 889"
generated_id = text_to_id(input_text)
print(f"'{input_text}' converts to ID: '{generated_id}'")

Output:

'Montréal, über, 12.89, Mère, Françoise, noël, 889' converts to ID: 'montreal_uber_1289_mere_francoise_noel_889'

This solution is highly practical for creating clean, consistent identifiers from user-generated content. For more on handling Python strings, see Python string formatting .

Solution 5: Handling Diacritics with unicodedata.name

This approach attempts to remove diacritics by looking up the Unicode names of characters. While elegant, it’s noted as a “hack” as Unicode names aren’t guaranteed to be stable.

import unicodedata as ud

def rmdiacritics_by_name(char):
    """
    Returns the base character of char by removing diacritics.
    Relies on Unicode names, which can be unstable.
    """
    desc = ud.name(char)
    cutoff = desc.find(' WITH ')
    if cutoff != -1:
        desc = desc[:cutoff]
        try:
            char = ud.lookup(desc)
        except KeyError:
            pass  # Removing 'WITH ...' produced an invalid name
    return char

Solution 6: Targeted Accent Removal with Regex

For specific languages or when you want precise control over which accents are replaced, using regular expressions to substitute common accented characters can be effective.

import re

def remove_common_accents(old_string):
    """Removes common accent characters using regex, converts to lowercase."""
    new_string = old_string.lower()
    new_string = re.sub(r'[àáâãäå]', 'a', new_string)
    new_string = re.sub(r'[èéêë]', 'e', new_string)
    new_string = re.sub(r'[ìíîï]', 'i', new_string)
    new_string = re.sub(r'[òóôõö]', 'o', new_string)
    new_string = re.sub(r'[ùúûü]', 'u', new_string)
    return new_string

# Example usage
accented_text = "Málagueña"
cleaned_text = remove_common_accents(accented_text)
print(f"'{accented_text}' becomes '{cleaned_text}'")

Output:

'Málagueña' becomes 'malaguena'

This method is straightforward for common European languages but may not cover all Unicode diacritics.

Solution 8: Comprehensive Accent Handling with unicodedata and CSV Reading

When dealing with files, like CSVs, that contain accented characters, combining unicodedata with file handling is essential. This example demonstrates reading a CSV and processing its content.

import sys
import csv
import unicodedata

# reload(sys) # Uncomment if using Python 2.x and encountering encoding issues
# sys.setdefaultencoding("utf-8") # Uncomment if using Python 2.x

def remove_accents_for_csv(input_str):
    """Removes accents, suitable for CSV processing."""
    # Normalize to NFKD and filter combining characters
    nkfd_form = unicodedata.normalize('NFKD', unicode(input_str)) # Ensure unicode input
    return "".join([c for c in nkfd_form if not unicodedata.combining(c)])

# Example of reading a file (replace 'test.txt' with your file path)
try:
    with open('test.txt', 'r', encoding='utf-8') as f:
        reader = csv.reader(f)
        for row in reader:
            for element in row:
                print(remove_accents_for_csv(element))
except FileNotFoundError:
    print("test.txt not found. Please create a test.txt file with some accented content.")

# If test.txt doesn't exist, here's a simulation:
print("\nSimulated CSV processing:")
simulated_data = ["Montréal", "Málaga", "café"]
for item in simulated_data:
    print(remove_accents_for_csv(item))

Solution 10: Customizing Accent Removal with str.maketrans

This approach offers a highly customizable way to handle accents, including specific mappings for characters like “æ” to “ae”.

from unicodedata import combining, normalize

LATIN_ACCENTS = "ä æ ǽ đ ð ƒ ħ ı ł ø ǿ ö œ ß ŧ ü "
ASCII_EQUIVALENTS = "ae ae ae d d f h i l o o oe oe ss t ue"

# Create translation table for lowercase characters
outliers_map = str.maketrans(dict(zip(LATIN_ACCENTS.split(), ASCII_EQUIVALENTS.split())))

def remove_diacritics_custom(s):
    """Removes diacritics using custom mappings and unicodedata."""
    # Normalize, translate, and filter combining characters
    return "".join(c for c in normalize("NFD", s.lower().translate(outliers_map)) if not combining(c))

# Example usage for sorting
string_list = ['cote', 'coteau', "crottez", 'crotté', 'côte', 'côté']
sorted_list = sorted(string_list, key=remove_diacritics_custom)
print(f"Sorted list: {sorted_list}")

# Case-preserving variant
LATIN_ACCENTS_UPPER = "ä æ ǽ đ ð ƒ ħ ı ł ø ǿ ö œ ß ŧ ü Ä Æ Ǽ Đ Ð Ƒ Ħ I Ł Ø Ǿ Ö Œ ẞ Ŧ Ü "
ASCII_EQUIVALENTS_UPPER = "ae ae ae d d f h i l o o oe oe ss t ue AE AE AE D D F H I L O O OE OE SS T UE"
outliers_map_upper = str.maketrans(dict(zip(LATIN_ACCENTS_UPPER.split(), ASCII_EQUIVALENTS_UPPER.split())))

def remove_diacritics_custom_case_preserving(s):
    """Removes diacritics while preserving case, using custom mappings."""
    return "".join(c for c in normalize("NFD", s.translate(outliers_map_upper)) if not combining(c))

# Example usage for case-preserving
accented_word = "Málagueña"
cleaned_word = remove_diacritics_custom_case_preserving(accented_text)
print(f"'{accented_word}' (case preserved): '{cleaned_word}'")

Output:

Sorted list: ['cote', 'côte', 'côté', 'coteau', 'crotté', 'crottez']
'Málagueña' (case preserved): 'Malaguena'

Solution 11: Explicitly Defining Diacritics to Strip

For maximum control, you can define exactly which diacritical marks to remove by their Unicode names.

import unicodedata

def strip_specific_accents(string, accents=('COMBINING ACUTE ACCENT', 'COMBINING GRAVE ACCENT', 'COMBINING TILDE')):
    """Strips specified accent types from a string."""
    accent_set = set(map(unicodedata.lookup, accents))
    # Normalize to NFD and filter out the specified accents
    chars = [c for c in unicodedata.normalize('NFD', string) if c not in accent_set]
    # Normalize back to NFC
    return unicodedata.normalize('NFC', ''.join(chars))

# Example usage
text_to_clean = "café au lait"
cleaned_text = strip_specific_accents(text_to_clean)
print(f"'{text_to_clean}' with specific accents stripped: '{cleaned_text}'")

Output:

'café au lait' with specific accents stripped: 'cafe au lait'

Solution 12: Using sklearn for Text Normalization

If you are already working with the scikit-learn library for machine learning tasks, its text processing utilities can be leveraged.

from sklearn.feature_extraction.text import strip_accents_ascii, strip_accents_unicode

accented_string = u'Málagueña®'

# Converts to ASCII, removing characters without direct ASCII equivalents
ascii_version = strip_accents_ascii(accented_string)
print(f"'{accented_string}' (ASCII): '{ascii_version}'")

# Converts to simple counterparts (e.g., 'á' to 'a')
unicode_version = strip_accents_unicode(accented_string)
print(f"'{accented_string}' (Unicode): '{unicode_version}'")

Output:

'Málagueña®' (ASCII): 'Malaguena'
'Málagueña®' (Unicode): 'Malaguena'

Note that strip_accents_ascii is generally faster but is only suitable for languages with direct ASCII transliterations. For broader compatibility, strip_accents_unicode is preferred, though it may be slower.

Solution 13: fold-to-ascii for ASCII Folding

The fold-to-ascii library aims to replicate Elasticsearch’s ASCII Folding filter, converting non-ASCII characters to their ASCII equivalents where possible.

# Install: pip install fold-to-ascii
from fold_to_ascii import fold

text_with_symbols = u'Astroturf® paté'

Be aware that fold-to-ascii might reduce non-Latin text (like Chinese) to empty strings. For such cases, methods preserving more Unicode characters are recommended. For more on text manipulation in Python, see working with strings in Python .

FAQs on Python Accent and Diacritic Removal

Q: What is the most common Python library for removing text accents

ANS: The unidecode library is widely used and effective for transliterating a broad range of Unicode characters into ASCII equivalents. The built-in unicodedata module also provides robust capabilities.

Q: Can Python handle diacritics in different languages

ANS: Yes, Python’s unicodedata module and libraries like unidecode are designed to handle diacritics from various languages by normalizing and transforming them into their closest ASCII or plain forms. For specific language needs, custom regex or targeted stripping might be required.

Q: What is the difference between strip_accents_ascii and strip_accents_unicode in scikit-learn

ANS: strip_accents_ascii converts accented characters to their ASCII equivalents but may fail for languages without direct ASCII transliterations. strip_accents_unicode converts accented characters to their simple counterparts, offering broader coverage but potentially at a slower performance.

Q: How do I create clean IDs from text with accents in Python

ANS: Combine accent stripping (using unicodedata or unidecode) with regular expressions to remove unwanted characters, replace spaces with underscores, and convert to lowercase. This ensures a clean, URL-friendly identifier.

Q: Are there performance differences between accent removal methods

ANS: Yes, performance can vary. unidecode and strip_accents_ascii are generally fast. Methods relying heavily on custom loops or complex unicodedata operations might be slower. Libraries like perfplot can help benchmark these differences.

Q: Can Python remove specific diacritics and keep others

ANS: Yes, by using unicodedata.normalize('NFD', string) and then filtering characters based on their Unicode categories or by explicitly defining combining marks to be removed, you can achieve targeted diacritic stripping.
