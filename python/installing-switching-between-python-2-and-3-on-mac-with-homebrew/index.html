Switching between Python 2 and 3 on a Mac can seem challenging, but with the right tools and techniques, you can easily manage both versions without any conflicts. This guide explores various solutions, from using Homebrew to alternative tools like pyenv and asdf, along with practical examples to make the process seamless.

Why Manage Python Versions?

Many projects rely on specific Python versions. For instance, legacy projects might depend on Python 2, while newer applications often require Python 3. A proper setup allows you to effortlessly switch between versions.

Top 8 Solutions to Manage Python Versions on Mac

Solution 1: Installing Python with Homebrew (Latest Versions)

For Homebrew versions >=1.5.0, Python 3.x is installed via the python formula, while Python 2.7 uses python@2. Here’s how you can set this up:

  • Install Python 3.x:

    brew install python

  • Install Python 2.7:

    brew install python@2

To verify installation:

python --version   # Check Python 2 version
python3 --version  # Check Python 3 version

For more details, see the Homebrew Python documentation .

Solution 2: Managing Conflicts and Upgrading

If Python 2.x is already installed via Homebrew, running brew upgrade python can update your setup to Python 3. For example:

brew upgrade python

Post-upgrade, you can check your versions:

python --version
python3 --version

Solution 3: Using pyenv for Version Management

pyenv is an excellent tool to manage multiple Python versions. Here’s how to use it:

Step 1: Install pyenv

brew update
brew install pyenv

Step 2: Install Desired Python Versions

pyenv install 2.7.18
pyenv install 3.9.7

Step 3: Configure Shell for pyenv

Add the following to your ~/.bash_profile:

if command -v pyenv 1>/dev/null 2>&1; then
  eval "$(pyenv init --path)"
fi

Step 4: Set Global or Local Versions

Set the global version:

pyenv global 3.9.7

Switch to Python 2 for a project:

pyenv local 2.7.18

Explore the pyenv GitHub repository for more details.

Solution 4: Using asdf Version Manager

asdf is a versatile tool for managing multiple languages, including Python. Here’s how:

Step 1: Install asdf

brew install asdf

Step 2: Add Python Plugin

asdf plugin-add python https://github.com/danhper/asdf-python.git

Step 3: Install Python Versions

asdf install python 2.7.18
asdf install python 3.9.7

Step 4: Set Versions Globally or Locally

Set a global default:

asdf global python 3.9.7

Set a local version for a project:

asdf local python 2.7.18

Learn more from the asdf GitHub repository .

Solution 5: Downloading Python Directly from Python.org

Visit Python’s official downloads page to download and install the latest versions. This method installs Python alongside your existing versions without conflicts.

Solution 6: Building Python from Source

If you require specific configurations, building Python from source is an option. Clone the repository and follow the README instructions for building:

git clone https://github.com/python/cpython.git
cd cpython
./configure
make
sudo make install

Solution 7: Resolving Pip3 Issues with Homebrew

If you encounter issues with pip3 after using Homebrew:

  1. Uninstall Python:

    brew uninstall --ignore-dependencies --force python3

  2. Install Python 3 directly from the official site .

Conda is another tool for managing Python versions. It works well for data science and machine learning projects. Learn more about Conda .

FAQs on Managing Python Versions with Homebrew

Q: Can I use Homebrew to install Python 3 alongside Python 2?

A: Yes, you can use Homebrew to install both versions simultaneously. Use brew install python for Python 3 and brew install python@2 for Python 2.

Q: What is the best tool for managing multiple Python versions?

A: Tools like pyenv and asdf are ideal for managing multiple versions, offering seamless switching and better control over environments.

Q: Can I remove all Python versions installed via Homebrew?

A: Yes, you can uninstall all versions using brew uninstall --ignore-dependencies --force python and then reinstall the versions you need.
