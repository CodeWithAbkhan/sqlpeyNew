Solved: How to Fix the ‘SSL CERTIFICATE_VERIFY_FAILED’ Error in Python

If you’ve encountered the SSL CERTIFICATE_VERIFY_FAILED error while using Python’s urllib or similar libraries, you’re not alone. This error often occurs when the Python environment fails to verify SSL certificates for secure HTTPS requests. Below, we’ll explore various methods to resolve this error, including practical code examples and alternatives.

Overview of the Error

When making an HTTPS request using Python, the underlying SSL library verifies the server’s SSL certificate. In cases where the certificate is untrusted or invalid, you may receive an error similar to this:

URLError: <urlopen error [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed (_ssl.c:581)>

This can stem from missing root certificates in your environment or issues with the SSL certificate itself.

Practical Example Code

Here’s a simple snippet that demonstrates where you might encounter the error:

import urllib2

input = "example.com"
url = "https://domainsearch.p.mashape.com/index.php?name=" + input
req = urllib2.Request(url, headers={'X-Mashape-Key': 'XXXXXXXXXXXXXXXXXXXX'})
info = urllib2.urlopen(req).read()  # This line may raise an SSL error
print(info)

Top 5 Methods to Solve the SSL CERTIFICATE_VERIFY_FAILED Error

Method 1: Bypass SSL Verification

To bypass SSL verification temporarily, you can create an unverified SSL context. Note that this method is not recommended for production due to security risks.

import ssl
import urllib2

## Create an unverified SSL context
gcontext = ssl._create_unverified_context()

url = "https://domainsearch.p.mashape.com/index.php?name=example.com"
req = urllib2.Request(url, headers={'X-Mashape-Key': 'XXXXXXXXXXXXXXXXXXXX'})
info = urllib2.urlopen(req, context=gcontext).read()
print(info)

Method 2: Use the certifi Library

Installing the certifi library provides a collection of root certificates to help resolve SSL issues.

To install certifi, use:

pip install certifi

Then, modify your request as follows:

import urllib2
import certifi
import ssl

url = "https://example.com"
context = ssl.create_default_context(cafile=certifi.where())
info = urllib2.urlopen(url, context=context).read()
print(info)

Method 3: Install Certificates on macOS

For macOS users, a built-in command installs necessary certificates. Navigate to the Python installation directory and run the following command in your terminal:

cd "/Applications/Python 3.X/"
sudo "./Install Certificates.command"

Method 4: Update CA Certificates on Linux

If you’re using Linux, you can refresh your certificate authorities with these commands:

sudo update-ca-certificates --fresh
export SSL_CERT_DIR=/etc/ssl/certs

Method 5: Specify CA Bundle in Environment Variables

By setting specific environment variables, you can direct the requests or urllib libraries to use the correct CA bundle.

import os
import certifi
import urllib

os.environ["REQUESTS_CA_BUNDLE"] = certifi.where()
os.environ["SSL_CERT_FILE"] = certifi.where()

url = "https://example.com"
result = urllib.request.urlopen(url).read()
print(result)

Alternative Approaches

  • You can also leverage Python’s built-in functions to manage SSL contexts directly without rewriting the verification steps.
  • For some specific environments like Anaconda, set the SSL verification using the conda configuration.

FAQs on SSL CERTIFICATE_VERIFY_FAILED Error

Q: What causes the SSL CERTIFICATE_VERIFY_FAILED error?

A: This error is caused by the failure to verify the SSL certificate presented by the server, typically due to missing CA certificates in your environment.

Q: Is it safe to bypass SSL verification?

A: It is generally unsafe to bypass SSL verification, as it exposes you to potential security risks, such as Man-in-the-Middle attacks.

Q: How do I update SSL certificates on Windows?

A: On Windows, ensure Python is installed correctly and that you have the latest version of certifi. Running pip install certifi should help.

Q: What is the best practice for using HTTPS in Python?

A: The best practice is to always verify SSL certificates using the certifi package or to properly configure your environment to trust the required certificates.
