“Matplotlib Plotting Techniques for Discontinuous or Broken Axes”

How does one effectively display data that spans widely separated ranges on a single plot axis in Python using Matplotlib? Creating a “broken axis” visualization, where a section of the axis is omitted to focus on distant data points, requires specific plotting strategies. Several effective techniques exist, ranging from simple subplot arrangements to deep custom transformations.

Solution 1: Utilizing Two Subplots with Shared Y-Axis

A straightforward approach involves dividing the plot into two adjacent subplots (ax and ax2) that share the y-axis but possess independent x-axis limits. This method mimics the visual break by isolating the distinct data ranges into separate plotting areas.

The essential steps involve plotting the data on both axes, setting differing xlim values for each, and then removing the connecting spines to create the illusion of a gap. Optionally, diagonal lines can be drawn at the boundaries to emphasize the discontinuity.

Here is a refined example demonstrating the creation of broken x-axes with diagonal line markers:

import matplotlib.pylab as plt
import numpy as np

# Generate data with a large gap (0 to 1, and 9 to 10)
x_data = np.r_[0:1:0.1, 9:10:0.1]
y_data = np.sin(x_data)

# Create two subplots sharing the y-axis
fig, (ax, ax2) = plt.subplots(1, 2, sharey=True)

# Plot the identical data series on both axes
ax.plot(x_data, y_data, 'bo')
ax2.plot(x_data, y_data, 'bo')

# Set distinct x-limits for visualization focus
ax.set_xlim(0, 1)    # Focus on the lower range
ax2.set_xlim(9, 10)  # Focus on the outlier range

# Remove the connecting spines to create the break
ax.spines['right'].set_visible(False)
ax2.spines['left'].set_visible(False)

# Configure tick placement and style
ax.yaxis.tick_left()
ax2.yaxis.tick_right()
ax.tick_params(labeltop='off') 

# Tighten the space between the axes for a compact look
plt.subplots_adjust(wspace=0.15)

# Adding visual indicators (diagonal slashes) at the break points
d = .015  # Size of the diagonal marker in axes coordinates

Solution 2: Implementing a Custom Matplotlib Scale Transformation

For a more integrated solution that treats the axis as a single entity despite the break, one can define a completely custom scale transformation. This involves creating classes that inherit from mscale.ScaleBase and mtransforms.Transform to remap the data coordinates to the display coordinates, effectively compressing the gap.

This method requires more boilerplate code but results in a true custom axis scale. The example below defines a CustomScale factory that collapses a specific range (l to u) into a single point, simulating a jump.

from matplotlib import pyplot as plt
from matplotlib import scale as mscale
from matplotlib import transforms as mtransforms
import numpy as np

def create_broken_x_scale(lower_bound, upper_bound):
    class CustomScale(mscale.ScaleBase):
        name = 'jump_scale'

        def __init__(self, axis, **kwargs):
            mscale.ScaleBase.__init__(self)
            self.lower = lower_bound
            self.upper = upper_bound

        def get_transform(self):
            return self.CustomTransform(self.lower, self.upper)

        def set_default_locators_and_formatters(self, axis):
            pass

        class CustomTransform(mtransforms.Transform):
            input_dims = 1
            output_dims = 1
            is_separable = True
            
            def __init__(self, l, u):
                mtransforms.Transform.__init__(self)
                self.lower = l
                self.upper = u

            def transform(self, values):
                # Remap values: data > lower maps to data - (upper - lower) if it crosses the threshold
                transformed = values.copy()
                
                # If data point is in the upper range, shift it down by the gap size
                transformed[values > self.upper] = values[values > self.upper] - (self.upper - self.lower)
                
                # If data point is within the gap range, map it to the lower boundary representation
                transformed[(values > self.lower) & (values < self.upper)] = self.lower
                return transformed

            def inverted(self):
                return CustomScale.InvertedCustomTransform(self.lower, self.upper)

        class InvertedCustomTransform(mtransforms.Transform):
            input_dims = 1
            output_dims = 1
            is_separable = True
            
            def __init__(self, l, u):
                mtransforms.Transform.__init__(self)
                self.lower = l
                self.upper = u

            def transform(self, values):
                # Reverse the mapping: if value is above lower bound, shift it back up
                inverted_vals = values.copy()
                inverted_vals[values > self.lower] = values[values > self.lower] + (self.upper - self.lower)
                return inverted_vals

            def inverted(self):
                return CustomScale.CustomTransform(self.lower, self.upper)

    return CustomScale

# Register the custom scale (example: gap between 1.12 and 8.88)
mscale.register_scale(create_broken_x_scale(1.12, 8.88))

# Example Usage
x_input = np.concatenate((np.linspace(0, 1, 10), np.linspace(9, 10, 10)))
desired_ticks = np.concatenate((np.linspace(0, 1, 6), np.linspace(9, 10, 6)))
y_input = np.sin(x_input)

plt.plot(x_input, y_input, '.')
ax = plt.gca()

# Apply the custom scale
ax.set_xscale('jump_scale')

# Set ticks explicitly as the custom scale doesn't auto-locate well initially
ax.set_xticks(desired_ticks)
plt.title("Data Visualization with Custom X-Axis Scale")
plt.show()

Solution 3: Leveraging the brokenaxes Package

For users seeking a ready-made, high-level utility, the external brokenaxes package simplifies this visualization significantly. It abstracts away the complexity of subplot manipulation and spine drawing.

Installation is required: pip install brokenaxes.

import matplotlib.pyplot as plt
from brokenaxes import brokenaxes
import numpy as np

# Setup figure
fig = plt.figure(figsize=(7, 3))

# Define the specific ranges to show for the x and y axes
# xlims = ((start1, end1), (start2, end2), ...)
# ylims = ((start1, end1), (start2, end2), ...)
bax = brokenaxes(
    xlims=((0, 0.1), (0.4, 0.7)),
    ylims=((-1, 0.7), (0.79, 1)),
    hspace=.05  # Vertical space between broken sections
)

x_vals = np.linspace(0, 1, 100)
bax.plot(x_vals, np.sin(10 * x_vals), label='Sine Wave')
bax.plot(x_vals, np.cos(10 * x_vals), label='Cosine Wave')
bax.legend(loc=3)
bax.set_xlabel('Time Index')
bax.set_ylabel('Amplitude Value')
plt.show()

Solution 4: Simple Cosmetic Hack for X-Axis Breaks

A less technical, “hacky” solution involves plotting graphical elements over the existing spine to visually obscure the gap and drawing text characters (//) nearby to denote the break. This works well if you only need to break the x-axis in one specific location.

import matplotlib.pyplot as plt
import numpy as np

# Setup simple plot
plt.plot(np.arange(15), np.random.rand(15) * 10)
ax = plt.gca()
ax.set_ylim(-1, 11)

# Define the point where the break should occur (in data coordinates)
break_x_position = 10 
ymin = ax.get_ylim()[0]
label_size = 14 # Font size for the '//' marker

# 1. Hide the spine segment with a white rectangle scatter plot
# Use clip_on=False so the marker is drawn outside the default axis limits if necessary
ax.scatter(
    break_x_position, ymin, 
    color='white', 
    marker='s', # Square marker
    s=100,      # Size of the square patch
    clip_on=False, 
    zorder=100  # Ensure it's drawn above the spine
)

# 2. Draw '//' text slightly below the axis line
ax.text(
    break_x_position, 
    ymin - 0.5, # Position slightly below the limit
    r'//', 
    fontsize=label_size, 
    zorder=101, 
    horizontalalignment='center', 
    verticalalignment='center'
)
plt.title("Cosmetic X-Axis Break")
plt.show()

Solution 5 & 7: Expanding Functionality and Axis Label Replacement

Some approaches build upon the base techniques (like Solution 1) to offer more flexibility, such as integrating the break feature into a library wrapper like proplot (Solution 5, mentioned but not shown here) or providing dedicated functions for drawing the break lines and handling tick labels (Solution 7).

Solution 7 provides a reusable axis_break function that places white patches and diagonal lines precisely using axis.transAxes coordinates, which remain consistent even when the data limits change. It also demonstrates how to replace specific tick labels using matplotlib.ticker.

from matplotlib.patches import Rectangle
import matplotlib.ticker as ticker
import matplotlib.pyplot as plt
import numpy as np

def draw_axis_break(axis, x_positions=[0.1, 0.125], slant_factor=1.5):
    """Draws a visual break marker on an axis."""
    d = slant_factor
    
    # Coordinates for the white patch covering the spine segment
    anchor = (x_positions[0], -1)
    width = x_positions[1] - x_positions[0]
    height = 1

    # Plotting the diagonal markers using axis coordinates (0 to 1)
    kwargs = dict(marker=[(-1, -d), (1, d)], markersize=12, zorder=3,
                linestyle="none", color='k', mec='k', mew=1, clip_on=False)
    
    # White patch to cover the spine area
    axis.add_patch(Rectangle(
        anchor, width, height, fill=True, color="white",
        transform=axis.transAxes, clip_on=False, zorder=3)
    )
    # Diagonal lines drawn over the patch
    axis.plot(x_positions, [0, 0], transform=axis.transAxes, **kwargs)

def relabel_ticks(fig, axis, position_data_val, new_label):
    """Replaces an existing tick label at a specific data position."""
    fig.canvas.draw()  # Essential to finalize existing tick positions
    
    labels_data = []
    locations = []
    
    for text in axis.get_xticklabels():
        # In older matplotlib versions, direct attribute access might be needed
        # For modern versions, use internal methods or more robust location retrieval
        x_coord = text.get_position()[0] 
        current_label = text.get_text()

        if axis.get_xticks()[axis.get_xticklabels().index(text)] == position_data_val:
            current_label = new_label

        labels_data.append(current_label)
        locations.append(x_coord)
        
    # Use FixedLocator to set locations explicitly
    axis.xaxis.set_major_locator(ticker.FixedLocator(axis.get_xticks()))
    axis.set_xticklabels(labels_data)

Solution 6: Adjusting Breaks for Non-Equal Subplot Width Ratios

When using GridSpec to define subplots with unequal width ratios (e.g., width_ratios=[5, 1]), the simple diagonal line approach from Solution 1 must be adapted. The diagonal marker size calculation needs to account for the relative widths (n and m) to ensure the break lines remain parallel to the axis edge correctly, compensating for the distortion introduced by GridSpec.

The correction involves scaling the diagonal marker’s extent by factors derived from the width ratios: on = (n+m)/n and om = (n+m)/m.

import matplotlib.pylab as plt
import numpy as np
import matplotlib.gridspec as gridspec

x_data = np.r_[0:1:0.1, 9:10:0.1]
y_data = np.sin(x_data)

n = 5; m = 1; # Width ratios defined for GridSpec
gs = gridspec.GridSpec(1, 2, width_ratios=[n, m])

plt.figure(figsize=(8, 4))

ax1 = plt.subplot(gs[0, 0])
ax2 = plt.subplot(gs[0, 1], sharey=ax1)
plt.setp(ax2.get_yticklabels(), visible=False)
plt.subplots_adjust(wspace=0.1)

ax1.plot(x_data, y_data, 'bo')
ax2.plot(x_data, y_data, 'bo')

# Set limits to enforce the break visually
ax1.set_xlim(0, 1)
ax2.set_xlim(10, 8) # Note: Reversed limit for visual continuity effect, though data spans 9-10

# Spine adjustments
ax1.spines['right'].set_visible(False)
ax2.spines['left'].set_visible(False)
ax1.yaxis.tick_left()
ax1.tick_params(labeltop='off')
ax2.yaxis.tick_right()

d = .015  # Diagonal marker size
kwargs = dict(transform=ax1.transAxes, color='k', clip_on=False)

# Scaling factors based on width ratios n and m
scale_factor_left = (n + m) / n
scale_factor_right = (n + m) / m

# Apply scaled diagonals to ax1 (left axis)
ax1.plot((1 - d * scale_factor_left, 1 + d * scale_factor_left), (-d, d), **kwargs)  # Bottom diagonal
ax1.plot((1 - d * scale_factor_left, 1 + d * scale_factor_left), (1 - d, 1 + d), **kwargs)  # Top diagonal

kwargs.update(transform=ax2.transAxes) # Switch context to ax2

# Apply scaled diagonals to ax2 (right axis)
ax2.plot((-d * scale_factor_right, d * scale_factor_right), (-d, d), **kwargs)  # Bottom diagonal
ax2.plot((-d * scale_factor_right, d * scale_factor_right), (1 - d, 1 + d), **kwargs)  # Top diagonal

plt.show()

FAQs on Matplotlib Broken Axis Techniques

Q: Which method is simplest for a quick broken X-axis visualization

ANS: Solution 1, using two adjacent subplots (plt.subplots(1, 2, sharey=True)) and adjusting the individual xlim for each, is generally the quickest to implement and customize visually, especially when paired with drawing the diagonal markers.

Q: Can the broken axis effect be applied to the Y-axis using subplots

ANS: Yes, the subplot method (Solution 1) can be adapted for the y-axis by using plt.subplots(2, 1, sharex=True) and adjusting ax.set_ylim() values instead of xlim. Remember to hide the shared horizontal spine.

Q: Is there a library dedicated to simplifying broken axes plots

ANS: Yes, Solution 3 recommends using the external brokenaxes package, which provides an object-oriented way to define the breaks via xlims and ylims tuples.
