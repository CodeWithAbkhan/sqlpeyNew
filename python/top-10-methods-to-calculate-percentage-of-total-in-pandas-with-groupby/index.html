Introduction

As a newcomer to Numpy and Pandas, encountering challenges with data manipulations can be frustrating, especially when dealing with CSV files containing sales data grouped by states and offices. Through this post, we’ll explore how to calculate the percentage of total sales for each office within its state, ensuring that the total percentage across each state sums up to 100%.

Practical Example

Let’s start with a sample DataFrame that simulates our dataset:

import pandas as pd
import numpy as np

# Creating a sample DataFrame
np.random.seed(0)
df = pd.DataFrame({
    'state': ['CA', 'WA', 'CO', 'AZ'] * 3,
    'office_id': list(range(1, 7)) * 2,
    'sales': [np.random.randint(100000, 999999) for _ in range(12)]
})

print(df)

Methods to Calculate Sales Percentage

Let’s delve into multiple techniques to achieve this:

Method 1: Using transform for Calculating Percentages

The simplest approach to calculate the percentage of total using the transformation method is through:

df['sales_percentage'] = 100 * df['sales'] / df.groupby('state')['sales'].transform('sum')
print(df)

Method 2: GroupBy and Division

You can also create two separate groupby objects and utilize the div method.

state_office = df.groupby(['state', 'office_id']).agg({'sales': 'sum'})
state = df.groupby(['state']).agg({'sales': 'sum'})
state_percentage = state_office.div(state, level='state') * 100
print(state_percentage)

Method 3: Using SeriesGroupBy

Alternatively, you can simplify calculations using SeriesGroupBy.

sales_sum = df.groupby(['state', 'office_id'])['sales'].sum().rename("sum_sales")
percentage_series = sales_sum / sales_sum.groupby(level=0).sum()
print(percentage_series)

Method 4: Create a New Column with Transform

You can easily add a new column for percentage as follows:

df['sales_ratio'] = df.groupby('state')['sales'].transform(lambda x: x / x.sum())
print(df)

Method 5: Using pd.crosstab

Pandas provides an elegant solution via pd.crosstab.

result = pd.crosstab(index=df['state'], 
                     columns=df['office_id'], 
                     values=df['sales'], 
                     aggfunc='sum', 
                     normalize='index').applymap('{:.2f}%'.format)
print(result)

Method 6: Merging GroupBy Results

Combine results of two groupby operations and divide.

state_office = df.groupby(['state', 'office_id'])['sales'].sum().reset_index()
total_sales = df.groupby(['state'])['sales'].sum().reset_index()
state_office = state_office.merge(total_sales, on='state', suffixes=('_office', '_total'))
state_office['sales_percentage'] = 100 * (state_office['sales_office'] / state_office['sales_total'])
print(state_office)

Method 7: Array Calculation

For improved performance, use array calculations:

# Setting up DataFrame
grouped = df.groupby(['state', 'office_id'])['sales'].sum().reset_index()
sum_group = df.groupby('state')['sales'].sum().reset_index()
grouped = grouped.merge(sum_group, on='state', suffixes=('_sales', '_total'))
grouped['percentage'] = (grouped['sales_sales'] / grouped['sales_total']) * 100
print(grouped[['state', 'office_id', 'percentage']])

Method 8: Vectorized Calculations

Utilizing vector computations:

df['percentage'] = 100 * df['sales'] / df.groupby(['state'])['sales'].transform('sum')
print(df[['state', 'office_id', 'percentage']])

Method 9: Less Conventional - Applying Lambda Functions

Here’s a quick approach using a lambda function.

df['percentage'] = df.groupby(['state']).apply(lambda x: x['sales'] / x['sales'].sum() * 100).reset_index(drop=True)
print(df[['state', 'office_id', 'percentage']])

Method 10: Using agg with Transform

This method employs agg for a more readable approach.

percentage = df.groupby(['state', 'office_id']).agg(sales_sum=('sales', 'sum')).reset_index()
percentage['percentage'] = percentage['sales_sum'] / percentage.groupby('state')['sales_sum'].transform('sum') * 100
print(percentage)

Wrap Up

These diverse methods provide flexibility when calculating the percentage of total sales by office within each state. You can choose the one that best fits your coding style or performance requirements.
