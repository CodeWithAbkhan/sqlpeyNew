How to Perform a Stratified Train-Test Split in Scikit-Learn?

Are you looking to improve the way you split your dataset into training and testing sets while ensuring that the class distribution reflects the original dataset? Stratified sampling can help achieve more reliable model evaluation. Below, I will guide you through methods to perform a stratified train-test split using Scikit-Learn in Python.

Your Current Approach

Currently, you might be using a simple train-test split like this:

from sklearn.cross_validation import train_test_split

X, Xt, userInfo, userInfo_train = train_test_split(X, userInfo)

However, this method does not support stratification, which can lead to imbalances in your training and testing datasets, especially with imbalanced classes. The goal is to achieve a 75% training and 25% testing split while ensuring the class distribution is consistent across both sets.

Effective Methods to Implement Stratified Splitting

Solution 1: Using train_test_split with Stratification

The most straightforward way to perform a stratified train-test split is to leverage the train_test_split function from the sklearn.model_selection module. The method allows you to specify the proportion of data to be used for the test set as well as the stratification criteria. Here’s how you can implement it:

from sklearn.model_selection import train_test_split

## Assume X is your feature set and y is your target variable
X_train, X_test, y_train, y_test = train_test_split(X, y, 
                                                    test_size=0.25, 
                                                    stratify=y)

In this code snippet:

  • X represents your features.
  • y is your target variable.
  • The test_size parameter is set to 0.25 to indicate that 25% of the data should go to the test set, keeping the stratification based on y.

Solution 2: Using StratifiedKFold

If you prefer or require a more complex approach, you can use StratifiedKFold from Scikit-Learn. This method is typically used for cross-validation but can also help in stratifying your data. However, you will need to manually split the data into training and testing indices:

from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=4)  # The number of desired folds
for train_index, test_index in skf.split(X, y):
    X_train, X_test = X[train_index], X[test_index]
    y_train, y_test = y[train_index], y[test_index]

In this example, n_splits determines how many folds you want, and you will split your data accordingly while maintaining the stratification.

Practical Example

Here’s a practical example demonstrating how to perform a stratified train-test split on an imbalanced dataset:

import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

## Creating a synthetic dataset
X, y = make_classification(n_samples=1000, n_features=20, 
                           n_classes=2, weights=[0.9, 0.1], flip_y=0, random_state=1)

## Perform stratified train-test split
X_train, X_test, y_train, y_test = train_test_split(X, y, 
                                                    test_size=0.25, 
                                                    stratify=y)

## Displaying the distribution
print("Training set class distribution:", np.bincount(y_train))
print("Test set class distribution:", np.bincount(y_test))

In this example, make_classification creates a synthetic dataset with an imbalanced target variable. We use stratified splitting to maintain this imbalance in both training and testing sets.

Alternative Methods

While train_test_split and StratifiedKFold are the most common approaches for stratified sampling, you can explore alternatives such as:

  • Manual stratification methods if you have specific needs or constraints.
  • Using libraries that support stratified sampling more directly or intuitively.

FAQs on How to Perform a Stratified Train-Test Split in Scikit-Learn

Q: What is stratified sampling?

A: Stratified sampling is a method of sampling that involves dividing a population into smaller sub-groups known as strata. It ensures that each subgroup is represented in the final sample.

Q: Why is stratification important in machine learning?

A: Stratification is important because it helps maintain the same percentage of samples of each target class in both training and testing datasets, which improves the reliability of model evaluation.

Q: Can I perform stratified sampling with non-binary classes?

A: Yes, stratified sampling can be applied to datasets with more than two classes, ensuring that each class is proportionally represented in both training and testing sets.
