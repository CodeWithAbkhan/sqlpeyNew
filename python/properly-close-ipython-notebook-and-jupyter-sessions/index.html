Solved: How to Properly Close IPython Notebook and Jupyter Sessions

When working with IPython notebooks and Jupyter servers, it’s important to understand the best ways to properly shut down your sessions to avoid resource wastage or leftover processes. Here are multiple solutions to ensure you close your Jupyter notebook cleanly, whether from the web interface, terminal, or through various system tools.

1. Closing from the Web Interface

The most straightforward way to close a notebook and halt its kernel is through the Jupyter Notebook web interface. From the File menu, select “Close and Halt”. This method is simple and will not only close the browser tab but will also ensure the kernel is properly stopped.

  • Navigate to File > Close and Halt.
  • This option will send a message to the terminal confirming the termination of the kernel.

2. Creating an Alias to Kill Jupyter Instances

If you run Jupyter notebooks in the background and don’t want to manually close each session, an efficient way to shut everything down is by using a custom alias command.

  • Add the following alias to your ~/.bashrc:
echo 'alias quitjupyter="kill $(pgrep jupyter)"' >> ~/.bashrc
  • After restarting your terminal, simply run quitjupyter to kill all Jupyter notebook processes.
# Alternatively, use a custom alias:
echo 'alias qjup="kill $(pgrep jupyter)"' >> ~/.bashrc

Now you can quickly terminate all running Jupyter instances with the command qjup.

3. Using the jupyter notebook stop Command

If you’re working with specific ports, the jupyter notebook stop command allows for a controlled shutdown of the Jupyter server.

  • To stop the notebook server:
jupyter notebook stop 8888
  • You can also check which servers are running with:
jupyter notebook list

This will show a list of running instances, including the ports they are using.

4. Killing Processes Manually Using kill

If you prefer more control or need to shut down processes manually, you can follow these steps:

  • First, list the running notebooks:
jupyter notebook list

  • Identify the port number of the notebook you want to close.

  • Use lsof to find the PID of the process:

lsof -n -i4TCP:[port-number]
  • Finally, kill the process:
kill -9 [PID]

5. Force Killing the pythonw Process (Windows)

If you are on Windows and the notebook refuses to close, you can try terminating the pythonw process from the Task Manager.

6. Shutting Down Jupyter on Ubuntu via TCP

On Ubuntu, if you continue to see Jupyter processes running even after closing the browser, you can use the following command to terminate the process associated with a specific port:

fuser -k 'port#'/tcp

This will forcibly close the port and terminate the Jupyter server.

7. Shutting Down Jupyter Using the Dashboard

Another clean way to shut down specific running notebooks is through the Jupyter Dashboard:

  • In the browser, go to the Running tab.
  • Check the notebook whose kernel is still running.
  • Select the notebook and click on the Shutdown button.

This will ensure that only the specific notebook and its kernel are stopped, leaving other notebooks unaffected.

8. Stopping Jupyter from a Different Console

If you need to stop Jupyter from another terminal session, you can use the following command to stop the notebook server on the default port:

jupyter notebook stop 8888

Or if the notebook is running on a different port, replace 8888 with the appropriate port number.

9. Using Runtime Folder to Force Shutdown

If other methods fail, you can clear the runtime folder of Jupyter:

  1. Find the runtime folder with:
jupyter --paths
  1. Delete all files in the runtime folder:
rm -r [RUNTIME FOLDER PATH]/*
  1. If any processes are left, use the top command to find and kill their PID:
top | grep jupyter
kill [PID]

Alternatively, the following one-liner can also be used to kill Jupyter processes by port:

TARGET_PORT=8888
kill -9 $(lsof -n -i4TCP:$TARGET_PORT | cut -f 2 -d " ")

10. Logging Out from Jupyter Session

If you’re using a Jupyter Lab interface, you can also log out and stop the server by pressing Ctrl+C in the terminal. This will ensure that no notebooks are left running in the background.

11. Using the Quit Button (Earlier Method)

Previously, Jupyter had a “Quit” button next to the “Logout” button, which was a fast way to shut down. Although it’s no longer available, the “Shutdown” option in the File menu is the closest alternative.

12. Restarting and Clearing Output from the Kernel

In Jupyter Notebook, you can choose to restart and clear the output by going to the Kernel menu. This won’t shut down the notebook, but it will clear all output and restart the session.

13. Using the Official Guide

You can always refer to the official Jupyter Notebook Quick Start Guide for more comprehensive information on managing notebooks.

14. Manual Closure (Control+Z, Close Browser)

If all else fails, press Ctrl+Z in the terminal to suspend the process and close your browser manually.

15. Using pkill to Kill Jupyter Instances

On Linux or macOS, you can kill all Jupyter processes with:

pkill jupyter

This will terminate every active Jupyter notebook or Jupyter Lab instance running in the background.

16. Choosing to “Close and Shutdown”

Finally, ensure you always choose the “Close and Shutdown” option from the dashboard to properly shut down any notebook.

FAQs on How to Properly Close IPython Notebook and Jupyter Sessions

Q: How do I stop Jupyter notebook servers on Ubuntu?

A: To stop Jupyter on Ubuntu, use the fuser -k 'port#'/tcp command to terminate the Jupyter process running on the given port. You can also use jupyter notebook stop [PORT] to gracefully stop it.

Q: Why should I use 'Close and Halt' instead of just closing the browser tab?

A: Closing the browser tab alone won’t stop the Jupyter kernel. To fully stop the kernel and free up resources, you must use the Close and Halt option from the File menu.

Q: Can I automate killing Jupyter notebooks?

A: Yes, you can automate the process of killing Jupyter notebooks by creating an alias in your .bashrc file, such as alias quitjupyter="kill $(pgrep jupyter)". After restarting the terminal, you can stop all Jupyter instances with quitjupyter.
