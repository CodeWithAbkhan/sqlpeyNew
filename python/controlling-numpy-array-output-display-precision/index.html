“Controlling NumPy Array Output Display Precision and Formatting”

When dealing with numerical computations in Python using the NumPy library, the default printing behavior for arrays, especially those containing floating-point numbers, can sometimes obscure detail or present numbers in undesirable scientific notation. How can an engineer or data scientist exert fine-grained control over how NumPy arrays are rendered to the console or logs?

This discussion examines several robust solutions for modifying the output format of NumPy arrays, ranging from global configuration changes to instance-specific string conversions.

Global Configuration: Modifying Default Print Behavior with numpy.set_printoptions

The primary mechanism for altering the default appearance of all subsequent array prints in a session is the numpy.set_printoptions function. This affects how NumPy chooses to represent floats, including setting the number of significant digits and preventing scientific notation for smaller values.

Suppressing Scientific Notation

For very small or very large numbers, NumPy defaults to exponential notation (e.g., 1.5e-10). The suppress=True option forces output to use fixed-point notation, representing small numbers as zero if they fall below the precision threshold.

printf() tries to handle too few or too many arguments sensibly, but this is iffy and subject to change.

How it works: numpy has a function np.array2string( A, "%.3g" ) (simplifying a bit). printf() splits the format string, and for format / arg pairs format: % d e f g arg: try np.asanyarray() –> %s np.array2string( arg, format ) Other formats and non-ndarray args are left alone, formatted as usual.

Notes:

printf( ... end= file= ) are passed on to the python print() function.

Only formats % [optional width . precision] d e f g are implemented, not %(varname)format .

%d truncates floats, e.g. 0.9 and -0.9 to 0; %.0f rounds, 0.9 to 1 . %g is the same as %.6g, 6 digits. %% is a single “%” character.

Alternative: Custom Context Manager for Older NumPy Versions

If using a NumPy version predating 1.15.0, you can emulate the context manager functionality by writing a wrapper utilizing contextlib.

import contextlib

@contextlib.contextmanager
def custom_print_scope(*args, **kwargs):
    original_options = np.get_printoptions()
    np.set_printoptions(*args, **kwargs)
    try:
        yield
    finally: 
        np.set_printoptions(**original_options)

Fine-Tuning with Formatters to Control Trailing Zeros
