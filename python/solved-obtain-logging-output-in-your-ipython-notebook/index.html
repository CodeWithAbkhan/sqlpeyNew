When working within an IPython Notebook, many users encounter the challenge of not seeing logging output using the standard logging configuration. Have you ever run the following code and wondered why the expected output is invisible?

import logging
logging.basicConfig(level=logging.DEBUG)
logging.debug("test")

You are not alone in this predicament. Let’s explore how to properly configure logging in your Jupyter Notebook to ensure that your messages are visible.

Solution 1: Reload the Logging Module

If you wish to continue utilizing basicConfig, first reload the logging module to reset its configuration:

from importlib import reload  # This is not necessary for Python 2
import logging
reload(logging)
logging.basicConfig(format='%(asctime)s %(levelname)s:%(message)s', level=logging.DEBUG, datefmt='%I:%M:%S')

Solution 2: Use a File Handler

In my experience, the default logging configuration in IPython may not work as expected. Here’s a setup that guarantees logging output to a file:

import logging

logger = logging.getLogger()
fhandler = logging.FileHandler(filename='mylog.log', mode='a')
formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')
fhandler.setFormatter(formatter)
logger.addHandler(fhandler)
logger.setLevel(logging.DEBUG)

## Example log messages
logging.error('hello!')
logging.debug('This is a debug message')
logging.info('this is an info message')
logging.warning('Warning message.')

This will create a mylog.log file containing all your log messages.

Solution 3: Redirect Output to stdout

Keep in mind that the default stream for the logging module is set to stderr. You can configure it to stdout like this:

import logging
import sys

logging.basicConfig(format='%(asctime)s | %(levelname)s : %(message)s',
                     level=logging.INFO, stream=sys.stdout)

logging.info('Hello world!')

Solution 4: Set Logger Level

If you are using Jupyter Notebook with specific versions, this setup can be useful:

import logging

logging.basicConfig()
logger = logging.getLogger('Something')
logger.setLevel(logging.DEBUG)

Now you can utilize logger methods like logger.debug() to print desired messages.

Solution 5: Use the Force Parameter

From version 3.8 onwards, the logging module has an option to bypass existing handlers which might help in legacy configurations:

import logging

logging.basicConfig(level=logging.DEBUG, force=True)
logging.debug("test")

This will ensure that logging configuration applies correctly in your IPython environment.

Practical Examples of Logger Configuration

To have a cleaner and more structured output, consider this configuration:

import sys
import logging

logging.basicConfig(
     format='%(asctime)s [%(levelname)s] %(name)s - %(message)s',
     level=logging.INFO,
     datefmt='%Y-%m-%d %H:%M:%S',
     stream=sys.stdout,
)

log = logging.getLogger('notebook')
log.info("This is a log message with structured output.")

This results in neatly formatted log entries that are both human-readable and informative.

Alternative Methods

If you want to ensure that both console output and file logging are handled appropriately, set up both handlers as follows:

import logging

logger = logging.getLogger()

## Creating file handler
fhandler = logging.FileHandler('my.log')
fhandler.setLevel(logging.DEBUG)
formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')
fhandler.setFormatter(formatter)

## Creating stream handler for the output
chandler = logging.StreamHandler()
chandler.setLevel(logging.DEBUG)
chandler.setFormatter(formatter)

## Adding both handlers
logger.addHandler(fhandler)
logger.addHandler(chandler)
logger.setLevel(logging.DEBUG)

## Log messages for testing
logger.info("Logging to both console and file.")
logger.debug("This debug message will go to both handlers.")

FAQs on Solved Obtain Logging Output in Your IPython Notebook

Q: How do I see logging output in IPython Notebook?

A: You can configure the logging module to send output to stdout or set up a file handler to log information. For instance, using logging.basicConfig(level=logging.DEBUG, stream=sys.stdout) enables you to see debug messages directly in the notebook.
