In What Order Does os.walk() Iterate Over Directories?

Background Information

When working with the Python os module, particularly the os.walk() function, a common point of confusion arises regarding the order in which directories and files are returned. If you have a test directory structure with folders named 1, 10, 11, 12, 2, 20, 21, 22, 3, 30, 31, and 32, one might wonder how these directories are sorted by default. Is the sorting based on numeric values or ASCII values?

Take a look at these potential outputs:

  • By numeric values:
1 2 3 10 20 30 11 21 31 12 22 32
  • By ASCII values (similar to ls command):
1 10 11 12 2 20 21 22 3 30 31 32

By default, os.walk() does not guarantee a specific order. It relies on os.listdir(), which presents the entries in arbitrary order and does not consider their numerical representations.

How to Achieve Desired Ordering

Let’s explore some methods to control the order of directory iteration effectively.

Method 1: Sorting with sorted()

Since os.walk employs os.listdir(), the first step is to explicitly sort directory names:

import os

path = '/tmp/tmp'  # Example path
os.chdir(path) 

# Creating test directories
for dirname in '1 10 11 12 2 20 21 22 3 30 31 32'.split():
    try:
        os.makedirs(dirname)
    except OSError:
        pass

# Walk through directories and sort them
for root, dirs, files in os.walk('.'):
    for dirname in sorted(dirs):
        print(dirname)

Method 2: Sorting Numerically

To specifically order directories as numbers, modify the sorting by applying a conversion to integers:

for dirname in sorted(dirs, key=int):
    print(dirname)

This will adjust the output to reflect true numeric sorting.

Method 3: Implementing Natural Sorting

To achieve more sophisticated sorting that accounts for natural string representations, consider using the natsort library which can be installed via pip: pip install natsort.

from natsort import natsorted

for dirname in natsorted(dirs):
    print(dirname)

Practical Example

Here’s a practical demonstration:

import os
from natsort import natsorted

# Setup test directories
os.chdir('/tmp/tmp_directory')
for dirname in '1 10 11 12 2 20 21 22 3 30 31 32'.split():
    os.makedirs(dirname, exist_ok=True)

# Walking directories with natural sorting
for root, dirs, files in os.walk('.'):
    for dirname in natsorted(dirs):
        print(os.path.join(root, dirname))

Alternative Methods

If manual sorting is not desirable, consider directory management tools or third-party libraries designed for enhanced file and directory handling.

What to Do Next?

By implementing these methods, you can easily control the order in which directories appear when utilizing os.walk(). Understanding how Python handles strings versus integers is crucial for output accuracy in your directory traversals.

FAQs on How to Control the Order of Directories Iterated by os.walk in Python

Q: Does os.walk sort directories automatically?

A: No, os.walk does not sort directories automatically. It returns them in arbitrary order as per os.listdir.

Q: How can I achieve numeric sorting with os.walk?

A: You can achieve numeric sorting by using the sorted() function with key=int while iterating through the directory names.

Q: What is natural sorting?

A: Natural sorting is a method that orders strings in a way that humans intuitively expect by treating numeric substrings as numbers rather than text. Tools like natsort can help with this.
