Solved: How to Fix the AttributeError module ’lib’ has no attribute ‘X509_V_FLAG_CB_ISSUER_CHECK’

Recently, while reinstalling Python due to an executable corruption, a Python script that I was working on failed with the error:

AttributeError: module 'lib' has no attribute 'X509_V_FLAG_CB_ISSUER_CHECK'

The offending line in the code that triggered this error was:

from apiclient.discovery import build

Upon running this command, I encountered multiple layers of nested errors which indicated issues stemming from the OpenSSL library that seemed to be linked to the google-api-python-client. Below is an example of the error output from the command prompt:

 File "C:\Analytics\Puritan_GoogleAnalytics\Google_Conversions\mcfTest.py", line 1, in <module>
 from apiclient.discovery import build
 .
 .
 .
AttributeError: module 'lib' has no attribute 'X509_V_FLAG_CB_ISSUER_CHECK'

Faced with this daunting problem, I took to exploring various solutions. Below are the methods that worked for me and others who faced a similar problem:

1. Reinstalling pip and OpenSSL

After exhausting several troubleshooting steps that did not work, one effective approach I found involved removing and reinstalling pip:

sudo apt remove python3-pip
wget https://bootstrap.pypa.io/get-pip.py
sudo python3 get-pip.py

After reinstalling pip, I subsequently upgraded OpenSSL:

pip install pyopenssl --upgrade

2. Removing OpenSSL Packages

Another method that proved successful involved completely removing the OpenSSL package and reinstalling it:

sudo rm -rf /usr/lib/python3/dist-packages/OpenSSL
sudo pip3 install pyopenssl --upgrade

This solution was particularly helpful for users installing Flask and firebase-admin on Ubuntu.

3. Upgrading pyOpenSSL

Upgrading pyOpenSSL alone also resolved the issue for some users:

pip3 install pyOpenSSL --upgrade

4. Reinstalling Essential Packages

For some users, especially those on Ubuntu, reinstalling critical dependencies directly benefited them:

apt-get --reinstall install python-apt
apt-get --reinstall install apt-transport-https
apt-get install build-essential libssl-dev libffi-dev python-dev

5. Manual Package Management

For those desiring a more manual approach, it was useful to entirely delete the OpenSSL folder within the site-packages:

rm -rf <python_path>/site-packages/OpenSSL

6. Using a wheel file for Installation

If encountering difficulties with installation through pip, users could download a wheel file directly and install it using:

wget https://files.pythonhosted.org/packages/.../pyOpenSSL-22.1.0-py3-none-any.whl
python3 -m easy_install pyOpenSSL-22.1.0-py3-none-any.whl

7. Editing the Python Crypto File

As a last resort, you might consider directly editing the crypto.py file to comment out the offending line:

python_openssl_crypto_file="/usr/lib/python3/dist-packages/OpenSSL/crypto.py"
search_term="CB_ISSUER_CHECK = _lib.X509_V_FLAG_CB_ISSUER_CHECK"
cb_issuer_check_line_number="$(awk "/$search_term/ {print FNR}" $python_openssl_crypto_file)"
sed -i "${cb_issuer_check_line_number}s/.*/ # $search_term/" $python_openssl_crypto_file

These solutions broadly encompass the ways in which users have successfully navigated the AttributeError related to the OpenSSL lib module in Python. Experimenting with the above methods should lead you to a fix for your specific situation.

FAQs on How to Fix the AttributeError module ’lib’ has no attribute ‘X509_V_FLAG_CB_ISSUER_CHECK’

Q: What does the error 'module 'lib' has no attribute 'X509_V_FLAG_CB_ISSUER_CHECK' mean?

A: This error typically indicates issues related to the OpenSSL library used by Python. It often arises after an installation or upgrade that has corrupted the relevant module paths or versions.

Q: How can I troubleshoot this error if none of the methods work?

A: If the above methods do not resolve the issue, consider checking python and pip versions, ensuring your environment variables are set correctly, or looking for conflicts with other installed packages.

Q: Are there any dependencies I should check when resolving this issue?

A: Yes, ensure that all dependencies related to OpenSSL and any libraries that interact with it (like pyOpenSSL and cryptography) are properly installed and up to date.
