“Python Pandas: Append DataFrame to Existing Excel Sheet”

When working with data in Python, you often need to add new information to existing Excel files without overwriting previous data. This is a common task when updating reports or consolidating datasets. Pandas, a powerful data manipulation library, provides several ways to achieve this, primarily by leveraging the ExcelWriter functionality. The core challenge lies in correctly opening the existing file, specifying the desired sheet, and then writing the new DataFrame to it.

Here are several effective methods for appending a Pandas DataFrame to an existing Excel sheet:

Solution 1: Manual Workbook Handling with openpyxl

This approach involves directly manipulating the workbook object using openpyxl before writing the DataFrame. It’s useful for precise control over the process.

import pandas as pd
from openpyxl import load_workbook

# Assume 'data_filtered' is your DataFrame and 'Masterfile.xlsx' is your Excel file
# Assume 'Main' is the name of the sheet you want to append to

# Load the existing workbook
book = load_workbook('Masterfile.xlsx')

# Create an ExcelWriter object with the existing workbook
# The 'openpyxl' engine is crucial here for reading/writing .xlsx files
writer = pd.ExcelWriter('Masterfile.xlsx', engine='openpyxl')
writer.book = book

# ExcelWriter uses writer.sheets to access existing sheets.
# If left empty, it might create a new sheet instead of using the existing one.
writer.sheets = dict((ws.title, ws) for ws in book.worksheets)

# Append the DataFrame to the specified sheet ('Main')
# You can also specify which columns to write using the 'cols' parameter
data_filtered.to_excel(writer, "Main", cols=['Diff1', 'Diff2'])

# Save the changes to the Excel file
writer.save()

Solution 2: Helper Function for Appending DataFrames

This method encapsulates the appending logic into a reusable function, making it easier to manage and apply across different parts of your project. It handles cases where the file might not exist initially and offers options to truncate sheets or manage missing values.

import os
import pandas as pd
from openpyxl import load_workbook

def append_df_to_excel(filename, df, sheet_name='Sheet1', startrow=None,
                       truncate_sheet=False, na_rep='NA', **to_excel_kwargs):
    """
    Append a DataFrame [df] to existing Excel file [filename]
    into [sheet_name] Sheet.
    If [filename] doesn't exist, then this function will create it.

    Parameters:
      filename : File path or existing ExcelWriter
                 (Example: '/path/to/file.xlsx')
      df : DataFrame to save to workbook
      sheet_name : Name of sheet which will contain DataFrame.
                   (default: 'Sheet1')
      startrow : upper left cell row to dump data frame.
                 Per default (startrow=None) calculate the last row
                 in the existing DF and write to the next row...
      truncate_sheet : truncate (remove and recreate) [sheet_name]
                       before writing DataFrame to Excel file
      na_rep: default = 'NA'. If, instead of NaN, you want blank cells, just edit as follows: na_rep=''
      to_excel_kwargs : arguments which will be passed to `DataFrame.to_excel()`
                        [can be dictionary]

    Returns: None

    Original helper function: (c) [MaxU](https://stackoverflow.com/users/5741205/maxu?tab=profile)
    Contributions to the current helper function: https://stackoverflow.com/users/4046632/buran?tab=profile
    """
    # Excel file doesn't exist - saving and exiting
    if not os.path.isfile(filename):
        df.to_excel(
            filename,
            sheet_name=sheet_name,
            startrow=startrow if startrow is not None else 0,
            **to_excel_kwargs)
        return

    # ignore [engine] parameter if it was passed
    if 'engine' in to_excel_kwargs:
        to_excel_kwargs.pop('engine')

    # Use 'a' for append mode and 'openpyxl' engine for .xlsx files
    writer = pd.ExcelWriter(filename, engine='openpyxl', mode='a')

    # try to open an existing workbook
    writer.book = load_workbook(filename)

    # get the last row in the existing Excel sheet
    # if it was not specified explicitly
    if startrow is None and sheet_name in writer.book.sheetnames:
        startrow = writer.book[sheet_name].max_row

    # truncate sheet if requested
    if truncate_sheet and sheet_name in writer.book.sheetnames:
        idx = writer.book.sheetnames.index(sheet_name)
        writer.book.remove(writer.book.worksheets[idx])
        writer.book.create_sheet(sheet_name, idx)

    # copy existing sheets
    writer.sheets = {ws.title:ws for ws in writer.book.worksheets}

    if startrow is None:
        startrow = 0

    # write out the new sheet with specified options
    df.to_excel(writer, sheet_name, startrow=startrow, na_rep=na_rep, **to_excel_kwargs)

    # save the workbook
    writer.save()

# Example Usage:
# Create a sample dataframe
df_sample = pd.DataFrame({'numbers': [10, 20, 30],
                          'labels': ['X', 'Y', 'Z'],
                          'NaN_col': [None, 42, None]})

# Define your file path
excel_file = 'sample_data.xlsx'

# Append the DataFrame to a new sheet named 'Data'
append_df_to_excel(excel_file, df_sample, sheet_name="Data", index=False)

# Append the DataFrame again to the same sheet, starting on the next row
append_df_to_excel(excel_file, df_sample, sheet_name="Data", index=False, startrow=len(df_sample))

# Append to a different sheet, replacing its content
append_df_to_excel(excel_file, df_sample, sheet_name="Summary", index=False, truncate_sheet=True)

# Append with NaN values represented as empty cells
append_df_to_excel(excel_file, df_sample, sheet_name="CleanData", index=False, na_rep='')

Solution 3: Using mode='a' with pd.ExcelWriter (Pandas 0.24+)

For more recent versions of Pandas (0.24 and above), ExcelWriter introduced a mode parameter, simplifying the append operation.

Solution 4: Overlaying Data (Pandas 1.3.0+)

Pandas version 1.3.0 introduced the if_sheet_exists parameter, which offers more granular control, including an “overlay” option for updating specific cells without affecting others, while preserving formatting.

import pandas as pd

# Assume 'df' is your DataFrame and 'my-existing-file.xlsx' is your Excel file
# Assume 'my-existing-sheet' is the target sheet

# Use mode='a' for append and if_sheet_exists='overlay' to update existing cells
# startcol and startrow specify the top-left corner for writing the DataFrame
with pd.ExcelWriter('my-existing-file.xlsx', engine='openpyxl', mode="a",
                    if_sheet_exists="overlay"
                   ) as writer:
    df.to_excel(writer, sheet_name="my-existing-sheet", index=None, startcol=2, startrow=3) # Start writing at cell C4

Solution 6: Reading All Sheets into a Dictionary

This method reads all sheets into a dictionary, allowing you to easily modify or add sheets before writing the entire workbook back. It’s particularly efficient when dealing with multiple sheet manipulations and works well with the xlsxwriter engine for formatting.

import pandas as pd

# Define the path to your Excel file
excel_file_path = 'Masterfile.xlsx'

# Read all sheets into a dictionary where keys are sheet names and values are DataFrames
ws_dict = pd.read_excel(excel_file_path, sheet_name=None)

# Assume 'data_filtered' is your DataFrame with columns 'Diff1' and 'Diff2'
# You can modify an existing sheet or add a new one
ws_dict['Main'] = data_filtered[['Diff1', 'Diff2']]

# Write the dictionary back to the Excel file
# 'xlsxwriter' is often preferred for its formatting capabilities
with pd.ExcelWriter(excel_file_path,
                    engine='xlsxwriter',
                    datetime_format='yyyy-mm-dd', # Example formatting
                    date_format='yyyy-mm-dd') as writer:

    for ws_name, df_sheet in ws_dict.items():
        df_sheet.to_excel(writer, sheet_name=ws_name, index=False)

Solution 9: Enhanced Helper Function with Auto-Formatting

This advanced helper function builds upon Solution 2, adding features like automatic column resizing based on content, handling of NaN values, and specifying a starting column. It also addresses potential compatibility issues with newer Python and package versions.

import pandas as pd
from openpyxl import load_workbook, Workbook
from openpyxl.utils import get_column_letter

def append_df_to_excel_enhanced(filename, df, sheet_name='Sheet1', startrow=None, startcol=None,
                                truncate_sheet=False, resizeColumns=True, na_rep='NA', **to_excel_kwargs):
    """
    Appends a DataFrame to an Excel file, with enhancements for column resizing and NaN handling.
    Handles file creation if it doesn't exist.
    """
    # Ensure output directory exists
    output_dir = os.path.dirname(filename)
    if output_dir and not os.path.exists(output_dir):
        os.makedirs(output_dir)

    writer = pd.ExcelWriter(filename, engine='openpyxl', mode='a')

    try:
        # Try to open an existing workbook
        writer.book = load_workbook(filename)
        # Set writer.sheets for consistency
        writer.sheets = {ws.title: ws for ws in writer.book.worksheets}

        # If sheet exists and truncate_sheet is True, remove and recreate it
        if truncate_sheet and sheet_name in writer.book.sheetnames:
            idx = writer.book.sheetnames.index(sheet_name)
            writer.book.remove(writer.book.worksheets[idx])
            writer.book.create_sheet(sheet_name, idx)

    except FileNotFoundError:
        # If the file doesn't exist, create a new workbook
        writer.book = Workbook()
        ws = writer.book.active
        ws.title = sheet_name
        writer.sheets = {ws.title: ws}

    # Determine startrow if not provided and sheet exists
    if startrow is None and sheet_name in writer.sheets:
        startrow = writer.sheets[sheet_name].max_row
    elif startrow is None:
        startrow = 0

    if startcol is None:
        startcol = 0

    # Write the DataFrame to the Excel file
    df.to_excel(writer, sheet_name, startrow=startrow, startcol=startcol, na_rep=na_rep, **to_excel_kwargs)

    # Auto-format column widths if requested
    if resizeColumns:
        ws = writer.book[sheet_name]
        for col in ws.columns:
            max_length = 0
            column = col[0].column_letter # Get the column name
            for cell in col:
                try:
                    if len(str(cell.value)) > max_length:
                        max_length = len(str(cell.value))
                except:
                    pass
            adjusted_width = (max_length + 2)
            ws.column_dimensions[column].width = adjusted_width

    # Save the workbook
    writer.save()

# Example Usage:
df_advanced = pd.DataFrame({'ColA': [1, 2, 3], 'ColB': ['Alpha', 'Beta', 'Gamma'], 'ColC': [None, 5.5, 6.6]})
file_path_advanced = 'enhanced_data.xlsx'

# Basic append
append_df_to_excel_enhanced(file_path_advanced, df_advanced, sheet_name="Sheet1", index=False)
# Append to the same sheet, below the previous data
append_df_to_excel_enhanced(file_path_advanced, df_advanced, sheet_name="Sheet1", index=False, startrow=len(df_advanced))
# Append to a new sheet, starting at column 3 (D)
append_df_to_excel_enhanced(file_path_advanced, df_advanced, sheet_name="Sheet2", index=False, startcol=3)
# Append with NaN as empty strings and auto-resizing columns
append_df_to_excel_enhanced(file_path_advanced, df_advanced, sheet_name="CleanSheet", index=False, na_rep='', resizeColumns=True)

Solution 11: Appending Entire Sheets

This function is designed to append an entire sheet from one Excel file to another, with options to control headers and indexing. Be aware that this method might reset formatting for the target sheet.

from openpyxl import load_workbook
import pandas as pd

def append_sheet_to_master(master_file_path, current_file_path, sheet_name):
    """Appends the first sheet of current_file_path to master_file_path."""
    try:
        master_book = load_workbook(master_file_path)
        master_writer = pd.ExcelWriter(master_file_path, engine='openpyxl')
        master_writer.book = master_book
        master_writer.sheets = dict((ws.title, ws) for ws in master_book.worksheets)

        # Read the first sheet from the current file
        current_frames = pd.read_excel(current_file_path, sheet_name=0, header=None, index_col=None)

        # Write the current sheet's data to the master file
        current_frames.to_excel(master_writer, sheet_name, index=None, header=False)

        master_writer.save()
    except Exception as e:
        print(f"Error appending sheet: {e}")

import pandas as pd

# Function to get the currently active workbook
def getActiveWorkbook():
    try:
        activeWb = xw.books.active
        return activeWb
    except Exception as e:
        print(f'Unable to get the current Workbook: {e}')
        return None

# Function to find the last used row and cell in a sheet
def getLastRow(myBook, sheetName):
    try:
        last_row = myBook.sheets[sheetName].range("A1").current_region.last_cell.row
        last_col_letter = xlsxwriter.utility.xl_col_to_name(myBook.sheets[sheetName].range("A1").current_region.last_cell.column)
        return str(last_row), last_col_letter + str(last_row)
    except Exception as e:
        print(f"Error finding last row/cell: {e}")
        return "1", "A1" # Default if error

Solution 16: Reusable write_to_excel Function

This function provides a clean wrapper for writing DataFrames to Excel, handling both new file creation and appending to existing files and sheets.

import pandas as pd
from openpyxl import load_workbook

def write_to_excel(df, file, **kwds):
    """Writes DataFrame to Excel, creating file if not exists, or appending."""
    try:
        book = load_workbook(file)
        writer = pd.ExcelWriter(file, engine='openpyxl')
        writer.book = book
        writer.sheets = dict((ws.title, ws) for ws in book.worksheets)
    except FileNotFoundError:
        writer = pd.ExcelWriter(file, engine='openpyxl')
        # If new file, simply write the df
    
    df.to_excel(writer, **kwds)
    writer.save()

# Example Usage:
df_a = pd.DataFrame({'a': range(10)})
df_b = pd.DataFrame({'b': range(10, 20)})

# Write df_a to 'test.xlsx', Sheet a, without index
write_to_excel(df_a, "test.xlsx", sheet_name="Sheet a", columns=['a'], index=False)
# Write df_b to 'test.xlsx', Sheet b, with index
write_to_excel(df_b, "test.xlsx", sheet_name="Sheet b", index=True)

FAQs on Python Pandas Append DataFrame to Excel

Q: How do I specify which sheet to append to in an Excel file

ANS: You typically specify the sheet name using the sheet_name parameter when creating the pd.ExcelWriter object or when calling df.to_excel(). For example: df.to_excel(writer, sheet_name='MySheet', index=False).

Q: What happens if the Excel file or sheet doesn't exist

ANS: If the Excel file does not exist, most methods will create it. If the specified sheet does not exist within an existing file, it will typically be created. Some helper functions might explicitly handle file creation.

Q: Can I append data without overwriting existing content in the sheet

ANS: Yes, using the mode='a' parameter with pd.ExcelWriter or df.to_excel (Pandas 1.3.0+) will append data. Alternatively, you can manually load the workbook and specify the starting row to write the new data below existing content. The if_sheet_exists='overlay' parameter in Pandas 1.3.0+ also allows for cell-specific updates.

Q: How do I preserve the formatting of the existing Excel file

ANS: Preserving formatting can be challenging. Methods that directly manipulate the workbook object using openpyxl or use xlwings are generally better for retaining formatting. Using if_sheet_exists='overlay' might also help preserve formatting for updated cells. Simple append operations might reset some formatting.

Q: Which Pandas versions support the 'mode=a' or 'if_sheet_exists' parameters

ANS: The mode='a' parameter for pd.ExcelWriter was introduced around Pandas 0.24. The if_sheet_exists parameter (with options like ‘overlay’) was introduced in Pandas 1.3.0. It’s recommended to use a recent version of Pandas.

Q: How can I control where the new data is written within the sheet

ANS: You can use the startrow and startcol parameters when calling df.to_excel() or passing them to ExcelWriter. These parameters specify the zero-based row and column index where the DataFrame’s top-left cell will be placed.
