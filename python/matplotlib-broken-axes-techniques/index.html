“Matplotlib Techniques for Creating Discontinuous or Broken Axes in Plots”

When presenting data that spans a vast range but contains interesting features in widely separated intervals (e.g., a small cluster near zero and another cluster near 100), standard axis scaling can obscure details. How can one effectively create a “broken axis” visualization in Matplotlib to display these disparate regions clearly?

Here are several established and alternative methods for achieving this effect, ranging from manual subplot manipulation to custom scaling solutions.

Solution 1: Utilizing Twin Subplots to Simulate a Break

This approach is effective for creating a visual discontinuity along an axis (typically the x-axis) by placing the data segments on separate, adjacent subplots that share a y-axis.

The core idea involves:

  1. Creating two subplots side-by-side (plt.subplots(1, 2, sharey=True)).
  2. Plotting the data on both axes.
  3. Setting distinct xlim for each subplot to focus on the desired ranges.
  4. Hiding the connecting spines (ax.spines['right'].set_visible(False) and ax2.spines['left'].set_visible(False)).
  5. Adding small diagonal lines at the connection points to visually indicate the break.

Implementation Example (Discontinuous X-Axis)

To plot sine wave data spanning from $x=0$ to $x=1$ and $x=9$ to $x=10$:

import matplotlib.pylab as plt
import numpy as np

# Create sample data with a gap
# np.r_ concatenates arrays: [0:1:0.1] gives 0.0, 0.1, ..., 1.0
x_data = np.r_[0:1:0.1, 9:10:0.1]
y_data = np.sin(x_data)

fig, (ax1, ax2) = plt.subplots(1, 2, sharey=True, figsize=(8, 4))

# Plot data on both axes
ax1.plot(x_data, y_data, 'ro', label='Segment 1')
ax2.plot(x_data, y_data, 'go', label='Segment 2')

# Set distinct limits for zoom effect
ax1.set_xlim(0, 1)    # Focus on the first segment
ax2.set_xlim(9, 10)   # Focus on the second segment

# Hide the internal spines
ax1.spines['right'].set_visible(False)
ax2.spines['left'].set_visible(False)

# Adjust tick visibility and position
ax1.yaxis.tick_left()
ax2.yaxis.tick_right()
ax1.tick_params(labeltop='off')

# Adjust spacing between plots
plt.subplots_adjust(wspace=0.1)

# Adding the visual break lines (diagonal hatch)
d = .015  # Size of the diagonal hatch in axes coordinates
kwargs = dict(transform=ax1.transAxes, color='k', clip_on=False)

# Diagonals on the right edge of ax1
ax1.plot((1-d, 1+d), (-d, +d), **kwargs)  # Bottom corner line
ax1.plot((1-d, 1+d), (1-d, 1+d), **kwargs) # Top corner line

kwargs.update(transform=ax2.transAxes) # Switch transform context to ax2
# Diagonals on the left edge of ax2
ax2.plot((-d, d), (-d, +d), **kwargs) # Bottom corner line
ax2.plot((-d, d), (1-d, 1+d), **kwargs) # Top corner line

plt.suptitle("Broken X-Axis using Twin Subplots")
plt.show()

Solution 2: Creating a Custom Axis Transformation (Step Function)

A more programmatic approach involves defining a completely new scale type that remaps the data coordinates. This method uses a step-function transformation to compress the gap range into a single point or region, effectively making the axis discontinuous while keeping the plot in a single axes object.

This involves:

  1. Subclassing matplotlib.scale.ScaleBase.
  2. Defining a custom forward (transform) and inverted (inverted) transformation.
  3. Registering the custom scale with Matplotlib using mscale.register_scale.

The transformation logic essentially shifts values above a threshold (lower) down by the size of the gap (upper - lower) and maps all values within the gap range (lower to upper) to the lower coordinate.

Custom Scale Factory Example

from matplotlib import pyplot as plt
from matplotlib import scale as mscale
from matplotlib import transforms as mtransforms
import numpy as np

def create_broken_x_scale(lower_bound, upper_bound):
    """Factory to generate a scale that 'jumps' the gap between lower_bound and upper_bound."""
    gap_size = upper_bound - lower_bound
    
    class CustomScale(mscale.ScaleBase):
        name = 'custom_break'

        def __init__(self, axis, **kwargs):
            mscale.ScaleBase.__init__(self)
            # Threshold is usually set during axis configuration, set to None initially
            self.thresh = None 

        def get_transform(self):
            return self.CustomTransform(self.thresh)

        def set_default_locators_and_formatters(self, axis):
            # Suppress default tick handling as we control this manually
            pass

        class CustomTransform(mtransforms.Transform):
            input_dims = 1
            output_dims = 1
            is_separable = True
            LOWER = lower_bound
            UPPER = upper_bound
            GAP = gap_size

            def __init__(self, thresh):
                mtransforms.Transform.__init__(self)
                self.thresh = thresh

            def transform(self, values):
                # Copy values to avoid modifying the original array
                transformed = values.copy()
                
                # Values greater than the gap are shifted down
                mask_above = values > self.UPPER
                transformed[mask_above] -= self.GAP
                
                # Values within the gap are mapped to the lower boundary
                mask_in_gap = (values > self.LOWER) & (values < self.UPPER)
                transformed[mask_in_gap] = self.LOWER
                
                return transformed

            def inverted(self):
                return CustomScale.InvertedCustomTransform(self.thresh)

        class InvertedCustomTransform(mtransforms.Transform):
            input_dims = 1
            output_dims = 1
            is_separable = True
            LOWER = lower_bound
            UPPER = upper_bound
            GAP = gap_size

            def __init__(self, thresh):
                mtransforms.Transform.__init__(self)
                self.thresh = thresh

            def transform(self, values):
                # Copy values to avoid modifying the original array
                inverted_transformed = values.copy()
                
                # Shift values above the new compressed lower bound back up
                mask_above_lower = values > self.LOWER
                inverted_transformed[mask_above_lower] += self.GAP
                
                return inverted_transformed

            def inverted(self):
                return CustomScale.CustomTransform(self.thresh)

    return CustomScale

# Define the range to compress (e.g., data points between 1.12 and 8.88 collapse)
BREAK_L, BREAK_U = 1.12, 8.88 

# Register the specific scale instance
mscale.register_scale(create_broken_x_scale(BREAK_L, BREAK_U))

Solution 3: Leveraging External Packages (brokenaxes)

For a more direct and less boilerplate solution, external libraries often provide specialized tools. The brokenaxes package is specifically designed to simplify the creation of visualizations with broken axes.

This method handles the subplot separation and the visual break markers automatically based on defined limits.

import matplotlib.pyplot as plt
from brokenaxes import brokenaxes
import numpy as np

# Create figure and the broken axes object
fig = plt.figure(figsize=(8, 3))

# Define the segments for the X and Y axes
bax = brokenaxes(
    xlims=((0, 0.1), (0.4, 0.7)),  # Two segments for X
    ylims=((-1, 0.7), (0.79, 1)), # Two segments for Y
    hspace=.05 # Space between vertical segments
)

# Sample data spanning across potential breaks
x_time = np.linspace(0, 1, 100)
y_value = np.sin(10 * x_time)

bax.plot(x_time, y_value, label='Sine Wave')
bax.legend(loc=3)
bax.set_xlabel('Time Index')
bax.set_ylabel('Measured Value')
plt.title("Broken Axes using brokenaxes package")
plt.show()

Solution 4: Simple Graphical Hack for X-Axis Breaks

A very straightforward, albeit visually primitive, hack involves directly overlaying white shapes onto the axis spine where the break should occur and then drawing the “//” text symbol over that area.

This requires knowing the $y$-position of the spine (often the minimum $y$-limit) and using zorder to ensure the white patch covers the axis line.

import matplotlib.pyplot as plt
import numpy as np

from matplotlib import pyplot as plt from matplotlib import scale as mscale from matplotlib import transforms as mtransforms import numpy as np

def CustomScaleFactory(l, u): class CustomScale(mscale.ScaleBase): name = ‘custom’

    def __init__(self, axis, **kwargs):
        mscale.ScaleBase.__init__(self)
        self.thresh = None #thresh

    def get_transform(self):
        return self.CustomTransform(self.thresh)

    def set_default_locators_and_formatters(self, axis):
        pass

    class CustomTransform(mtransforms.Transform):
        input_dims = 1
        output_dims = 1
        is_separable = True
        lower = l
        upper = u
        def __init__(self, thresh):
            mtransforms.Transform.__init__(self)
            self.thresh = thresh

        def transform(self, a):
            aa = a.copy()
            aa[a&gt;self.lower] = a[a&gt;self.lower]-(self.upper-self.lower)
            aa[(a&gt;self.lower)&amp;(a&lt;self.upper)] = self.lower
            return aa

        def inverted(self):
            return CustomScale.InvertedCustomTransform(self.thresh)

    class InvertedCustomTransform(mtransforms.Transform):
        input_dims = 1
        output_dims = 1
        is_separable = True
        lower = l
        upper = u

        def __init__(self, thresh):
            mtransforms.Transform.__init__(self)
            self.thresh = thresh

        def transform(self, a):
            aa = a.copy()
            aa[a&gt;self.lower] = a[a&gt;self.lower]+(self.upper-self.lower)
            return aa

        def inverted(self):
            return CustomScale.CustomTransform(self.thresh)

return CustomScale

mscale.register_scale(CustomScaleFactory(1.12, 8.88))

Solution 7: Detailed Control with Patches and Ticker Manipulation

For maximum control, especially when dealing with replacing tick labels around the break, one can combine patches (like in Solution 4) with precise tick manipulation using matplotlib.ticker. This allows the visual break marker (the slash/patch) to be placed exactly where a specific tick label would have been, and that label can be swapped out for custom text.

from matplotlib.patches import Rectangle
import matplotlib.ticker as ticker
import matplotlib.pyplot as plt
import numpy as np

def insert_axis_break_and_label(axis, x_pos_data, label_replacement, slant_factor=1.5):
    """Adds a visual break and optionally replaces a tick label at a data coordinate."""
    
    d = slant_factor  # Controls the steepness of the diagonal line
    
    # 1. Draw white rectangle patch over the spine area
    anchor = (x_pos_data, -1)
    width = 0.015 # Small width in axes coordinates
    height = 1    # Full height in axes coordinates

    axis.add_patch(Rectangle(
        anchor, width, height, fill=True, color="white",
        transform=axis.transAxes, clip_on=False, zorder=3)
    )
    
    # 2. Draw the diagonal markers ('//' effect)
    kwargs = dict(marker=[(-1, -d), (1, d)], markersize=10, zorder=3,
                linestyle="none", color='k', mec='k', mew=1, clip_on=False)
    axis.plot([x_pos_data - width/2, x_pos_data + width/2], [0, 0], 
              transform=axis.transAxes, **kwargs)

    # 3. Optional: Replace the tick label at that data position
    fig = plt.gcf()
    fig.canvas.draw()  # Render to calculate exact screen positions for labels

    labs = axis.get_xticklabels()
    new_labels = []
    locs = []
    
    # Convert data coordinate to axis coordinate for comparison if necessary, 
    # but comparing data coordinates requires knowing the current axis limits
    # For simplicity here, we assume x_pos_data corresponds directly to a tick location post-rendering
    
    # Note: Directly comparing text._x (screen position) requires complex inversion. 
    # A simpler robust method uses FixedLocator if we know the intended tick location in data units.
    
    if label_replacement:
        current_ticks = axis.get_xticks()
        if x_pos_data in current_ticks:
            new_labels = [label_replacement if loc == x_pos_data else t.get_text() for t, loc in zip(labs, current_ticks)]
            axis.xaxis.set_major_locator(ticker.FixedLocator(current_ticks))
            axis.set_xticklabels(new_labels)

FAQs on Matplotlib Broken Axes Techniques

Q: Which method is simplest for a quick broken X-axis visualization

ANS: Solution 1, using two side-by-side subplots with shared Y-axes and hidden internal spines, is often the quickest and most intuitive method for basic discontinuous X-axis views.

Q: Can the custom scale method handle two breaks in one axis

ANS: Solution 2 requires creating a more complex custom transform function that maps multiple non-contiguous ranges into compressed segments, which is significantly more involved than the other methods.

Q: Does the brokenaxes package require installation

ANS: Yes, the brokenaxes package is external and needs to be installed, typically via pip (e.g., pip install brokenaxes).
