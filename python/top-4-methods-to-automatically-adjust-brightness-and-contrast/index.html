Deep Dive into Automatic Brightness and Contrast Adjustment in Color Images

When capturing images of a sheet of paper, like the example below, we often encounter issues where the contrast and brightness do not reflect the true colors. The aim is to enhance the image so that the background appears brighter and the details stand out more prominently.

The challenge presented here is: How can we process the original image using OpenCV to achieve an automatic brightness and contrast adjustment, ensuring that the background appears whiter while retaining the colors?

Problem Breakdown

Given an image of A4 paper that may include text or images in various colors, we want to adjust its brightness and contrast without transforming it to a binary format. Here’s a summary of the techniques I’ve explored:

  1. Adaptive Thresholding: Methods like Gaussian and OTSU showed promise when applied to grayscale images but are not suitable for color images, mainly resulting in binary outputs that are not desired.

  2. Histogram Equalization: Each approach utilizing YUV and HSV transformations yielded suboptimal results, introducing unwanted micro-contrasts.

  3. Contrast Limited Adaptive Histogram Equalization (CLAHE): Applied various grid sizes but did not achieve satisfactory outcomes.

  4. Color Channel Equalization: Equalizing each color channel independently disrupts the color balance, which is counterproductive.

  5. Contrast Stretching: Implementing techniques from scikit-image allowed for some improvement but was still not ideal.

TL;DR: Seeking effective methods for automatic brightness and contrast optimization of color photographs with OpenCV in Python is essential.

Top 4 Solutions for Brightness and Contrast Adjustment

Solution 1: Using Alpha and Beta Values

Adjust brightness and contrast through scaling factors known as alpha (α) for contrast and beta (β) for brightness.

import cv2

## Read the image
image = cv2.imread('sheet.jpg')

## Define contrast and brightness parameters
alpha = 2.00  # Contrast control (1.0-3.0)
beta = 20     # Brightness control (0-100)

## Apply contrast and brightness adjustments
adjusted_image = cv2.convertScaleAbs(image, alpha=alpha, beta=beta)

## Display results
cv2.imshow('Original Image', image)
cv2.imshow('Adjusted Image', adjusted_image)
cv2.waitKey(0)
cv2.destroyAllWindows()

Solution 2: Automatic Calculation of α and β Using Histogram Analysis

To refine our approach, we determine the optimal values of α and β through histogram analysis.

import cv2
import numpy as np

def auto_bright_contrast(image, clip_hist_percent=1):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    hist = cv2.calcHist([gray], [0], None, [256], [0, 256])
    accumulator = np.cumsum(hist)

    # Determine histogram clipping points
    maximum = accumulator[-1]
    clip_hist_percent *= (maximum / 100.0)
    clip_hist_percent /= 2.0

    minimum_gray = next(i for i in range(256) if accumulator[i] > clip_hist_percent)
    maximum_gray = next(i for i in range(255, -1, -1) if accumulator[i] < (maximum - clip_hist_percent))

    # Calculate α and β
    alpha = 255 / (maximum_gray - minimum_gray)
    beta = -minimum_gray * alpha

    return cv2.convertScaleAbs(image, alpha=alpha, beta=beta)

image = cv2.imread('sheet.jpg')
result = auto_bright_contrast(image)
cv2.imshow('Enhanced Image', result)
cv2.waitKey(0)

Solution 3: Alternative Enhancement Method without Absolute Values

Instead of the standard OpenCV method, here’s how it can be done using saturation arithmetic, preserving the full range of colors.

def custom_convert_scale(image, alpha, beta):
    new_image = np.clip(image * alpha + beta, 0, 255).astype(np.uint8)
    return new_image

adjusted_result = custom_convert_scale(image, alpha, beta)
cv2.imshow('Custom Adjustment', adjusted_result)
cv2.waitKey(0)

Solution 4: Leveraging CLAHE in LAB Color Space

Using CLAHE in the LAB color model can provide improved results over direct RGB manipulation.

def apply_clahe(image):
    lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)
    l, a, b = cv2.split(lab)
    clahe = cv2.createCLAHE(clipLimit=3.0, tileGridSize=(8, 8))
    cl = clahe.apply(l)
    limg = cv2.merge((cl, a, b))
    result = cv2.cvtColor(limg, cv2.COLOR_LAB2BGR)
    return result

clahe_result = apply_clahe(image)
cv2.imshow('CLAHE Result', clahe_result)
cv2.waitKey(0)
