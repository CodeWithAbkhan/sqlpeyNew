Solved: How to Use OpenPyXL and Alternative Methods to Read Excel Cell Values, Not Formulas

When working with Excel files in Python, one common challenge arises when trying to read the calculated values of cells that contain formulas. Often, libraries like openpyxl load the raw formula in a cell instead of the value it computes. While using data_only=True in openpyxl reads the last calculated value, this doesn’t always reflect the actual current value, especially when add-ins or external modifications have altered the data.

In this post, we’ll explore how to solve this problem using openpyxl and other tools like xlwings, pycel, and more. Let’s dive into the various methods to read the actual values of cells in Excel.

Solved: How to Read Excel Cell Values Instead of Formulas in Python

Solution 1: Understanding openpyxl’s Behavior

The issue arises because openpyxl does not evaluate formulas by default. When using the openpyxl.load_workbook method with data_only=True, it loads the last calculated value for formula-based cells, not the current evaluated value. To handle this, consider using xlwings, which can interact with Excel’s runtime and evaluate formulas as Excel would.

import xlwings as xw

## Open Excel file using xlwings
wbxl = xw.Book('to_erase.xlsx')
cell_value = wbxl.sheets['Sheet'].range('B3').value
print(cell_value)  # Returns evaluated value, e.g., 3

This approach ensures you always retrieve the most accurate, current value.

Solution 2: data_only for Pre-calculated Values

If you are using an Excel file with formulas but want to access pre-calculated values, openpyxl’s data_only=True will work, assuming the Excel sheet has already been calculated. Here’s how you can load the workbook:

from openpyxl import load_workbook

file_location = 'path_to_your_excel_file.xlsx'
wb = load_workbook(file_location, keep_vba=True, data_only=True)

This will load the precomputed values for all cells, but note that if the file hasn’t been calculated yet, you will not get the most recent values.

Solution 3: Using xlwings for Full Formula Evaluation

If you have access to Microsoft Excel and want to ensure that all formulas are calculated (even those between sheets), xlwings is the way to go. The xlwings library allows for direct interaction with Excel’s calculation engine. Here’s an example of how you can evaluate formulas dynamically:

import xlwings as xw

## Open workbook using xlwings
wbxl = xw.Book('to_erase.xlsx')

## Evaluate the value of cell B3, which contains a formula
cell_value = wbxl.sheets['Sheet'].range('B3').value
print(cell_value)  # Expected result: 3 (calculated from the formula B1 + B2)

This ensures that even complex references across multiple sheets are properly evaluated.

Solution 4: Implementing a Formula Evaluation Class with pycel

For situations where you need a custom approach to evaluate formulas, you can integrate the pycel library, which allows you to evaluate formulas manually. Below is an example of how to implement a custom reader:

from openpyxl import load_workbook
from pycel.excelcompiler import ExcelCompiler
import logging

class XLSXReader:
    def __init__(self, path):
        self.path = path
        self.book = load_workbook(self.path, data_only=False)

    def get_cell_value(self, address, sheet=None):
        if not sheet:
            sheet = self.book.active.title

        if not self.__cell_contains_formula(address, sheet):
            return self.__get_as_is(address, sheet)

        precomputed_value = self.__get_precomputed(address, sheet)
        if precomputed_value is not None:
            return precomputed_value

        try:
            return self.__compute(address, sheet)
        except Exception as e:
            logging.warning(f"Error evaluating {address}: {str(e)}")
            return None

    def __cell_contains_formula(self, address, sheet):
        cell = self.book[sheet][address]
        return cell.data_type == 'f'

    def __get_as_is(self, address, sheet):
        return self.book[sheet][address].value

    def __get_precomputed(self, address, sheet):
        precomputed_book = load_workbook(self.path, data_only=True)
        return precomputed_book[sheet][address].value

    def __compute(self, address, sheet):
        compiler = ExcelCompiler(self.path)
        graph = compiler.gen_graph(address, sheet=sheet)
        return graph.evaluate(f"{sheet}!{address}")

This class provides a robust way to read cell values by checking if the cell contains a formula, trying to retrieve the precomputed value, and, if necessary, evaluating the formula manually.

Solution 5: Automating Excel Formula Calculations Using subprocess

In some cases, you may prefer to delegate formula evaluation entirely to Excel. By using the subprocess module to automate Excel via its interface, you can save time and avoid potential errors in Python calculations. Here’s how to do it:

import subprocess
from pynput.keyboard import Key, Controller
import time
import os

excel_prog = r'C:\Program Files\Microsoft Office\root\Office16\EXCEL.EXE'

## Open Excel file using subprocess
subprocess.Popen([excel_prog, os.path.join(os.getcwd(), 'test.xlsx')])

## Simulate pressing keys to save and close Excel
keyboard = Controller()
with keyboard.pressed(Key.ctrl):
    keyboard.press('s')
    keyboard.release('s')

time.sleep(5)
with keyboard.pressed(Key.alt):
    keyboard.press(Key.f4)
    keyboard.release(Key.f4)

time.sleep(5)

## Reopen the file with openpyxl to get the updated values
from openpyxl import load_workbook
wb = load_workbook(filename='test.xlsx', data_only=True)
ws = wb.active
print(ws['E2'].value)

This method ensures Excel does all the heavy lifting of formula calculation, and Python simply reads the final result.

Solution 6: Alternative Libraries for Formula Evaluation

If you want to explore further, consider xlcalculator, an alternative that also offers formula evaluation capabilities. It supports evaluating expressions in Excel files and may be a good fit depending on your use case.

from xlcalculator import ModelCompiler, Evaluator

filename = r'path_to_your_excel_file.xlsm'
compiler = ModelCompiler()
model = compiler.read_and_parse_archive(filename)
evaluator = Evaluator(model)

value = evaluator.evaluate('Sheet1!A2')
print(value)  # Should output the evaluated value

FAQs on Solving Excel Formula Evaluation in Python

Q: How can I read Excel cell values and ignore formulas in Python?

A: You can use libraries like openpyxl with data_only=True, or xlwings to interact directly with Excel’s runtime for real-time formula evaluation. If you want to avoid Python from evaluating formulas, data_only=True is your best bet.

Q: Why doesn’t `openpyxl` return the correct value for formula cells?

A: openpyxl does not evaluate formulas. It only reads the last calculated value stored in the Excel file. To get current values, you’ll need to use a method like xlwings that communicates with the Excel application.
