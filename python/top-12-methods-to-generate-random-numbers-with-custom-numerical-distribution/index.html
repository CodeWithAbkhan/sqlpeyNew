Generating random numbers according to a specific probability distribution can be crucial in various applications, such as simulations, statistical sampling, and even game development. If you are trying to generate numbers based on a predetermined distribution, you’ve come to the right place. Below, we will explore a series of methods to accomplish this task using Python.

Example Probability Distribution

Consider a scenario where you have the following probabilities assigned to different numbers:

1 0.1
2 0.05
3 0.05
4 0.2
5 0.4
6 0.2

Your goal is to create random samples using this distribution. Fortunately, there are several existing tools and methods to facilitate this process.

Solution 1: Using random.choices()

Starting with Python 3.6, you can leverage the built-in random.choices function. Here’s how you use it:

from random import choices

population = [1, 2, 3, 4, 5, 6]
weights = [0.1, 0.05, 0.05, 0.2, 0.4, 0.2]

## Generate a single sample
single_sample = choices(population, weights)
print(single_sample)

## Generate a million samples and check distribution
million_samples = choices(population, weights, k=10**6)
from collections import Counter
sample_distribution = Counter(million_samples)
print(sample_distribution)

This efficiently generates a weighted sample while allowing you to specify multiple samples using the k parameter.

Solution 2: Cumulative Distribution Function (CDF) with Binary Search

For scenarios requiring lower memory usage, you can manually compute the cumulative distribution and utilize binary search for quick lookups. Here’s a basic function:

import random

def random_from_distribution(prob_dist):
    r = random.uniform(0, 1)
    cum_sum = 0
    for value, prob in prob_dist:
        cum_sum += prob
        if cum_sum >= r:
            return value

prob_dist = [(1, 0.1), (2, 0.05), (3, 0.05), (4, 0.2), (5, 0.4), (6, 0.2)]
random_value = random_from_distribution(prob_dist)
print(random_value)

This method handles float inaccuracies gracefully without needing extensive preprocessing.

Solution 3: Using CDF for Quick Sampling

By building the CDF upfront, you can sample more efficiently:

import random

pdf = [(1, 0.1), (2, 0.05), (3, 0.05), (4, 0.2), (5, 0.4), (6, 0.2)]
cdf = []
cumulative = 0
for value, probability in pdf:
    cumulative += probability
    cdf.append((value, cumulative))

random_sample = max(value for random_value in [random.random()] for value, cumulative_proba in cdf if cumulative_proba <= random_value)
print(random_sample)

Solution 4: Utilizing numpy.random.choice()

Another powerful method is to use numpy, which streamlines the process:

import numpy as np

## Generate random sample
val = np.random.choice(np.arange(1, 7), p=[0.1, 0.05, 0.05, 0.2, 0.4, 0.2])
print(val)

Solution 5: Custom Continuous Distribution

For generating random samples based on custom continuous distributions, here’s a function you can use:

import numpy as np

def random_custDist(x0, x1, custDist, size=None, nControl=10**6):
    samples = []
    nLoop = 0
    while len(samples) < size and nLoop < nControl:
        x = np.random.uniform(low=x0, high=x1)
        prop = custDist(x)
        if np.random.uniform(low=0, high=1) <= prop:
            samples.append(x)
        nLoop += 1
    return samples

x0 = 2007
x1 = 2019

def custDist(x):
    if x < 2010:
        return .3
    else:
        return (np.exp(x - 2008) - 1) / (np.exp(2019 - 2007) - 1)

samples = random_custDist(x0, x1, custDist=custDist, size=1000)
print(samples)

FAQs on Top 12 Methods to Generate Random Numbers with a Custom Numerical Distribution

Q: Can I use these methods to generate birthday dates?

A: Yes, these methods can be adapted to generate random dates by adjusting your distribution probabilities accordingly.

Q: Are there limitations to using `random.choices`?

A: While random.choices is powerful, its performance may degrade with very large populations or high-frequency sampling. Consider using CDF or other methods for enhanced efficiency.

Q: Is normalization necessary for the weights?

A: It’s best practice to ensure weights sum to 1, but some methods can handle unnormalized weights internally.
