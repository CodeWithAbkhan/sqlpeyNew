“Python Object Size: How to Accurately Measure Memory Usage”

When working with Python, you might need to ascertain the memory footprint of your objects. While the built-in sys.getsizeof() function offers a starting point, it primarily measures the shallow size of an object, not accounting for the memory consumed by objects it references. For a more thorough analysis, particularly with complex data structures, alternative approaches are often necessary.

Here are several methods to address this:

Solution 1: Using sys.getsizeof() (Shallow Size)

The most direct method is using sys.getsizeof(). It returns the size of an object in bytes. It’s important to note that this function measures only the memory directly consumed by the object itself, excluding the memory used by objects it refers to.

import sys

x = 2
string_example = 'this also'

print(f"Size of integer 'x': {sys.getsizeof(x)} bytes")
print(f"Size of string 'this also': {sys.getsizeof(string_example)} bytes")

# Example with a function
print(f"Size of sys.getsizeof function: {sys.getsizeof(sys.getsizeof)} bytes")

Caveats: As mentioned, sys.getsizeof() does not recursively sum the sizes of contained objects. For example, the size of a list will not include the size of the elements within it.

import sys
from numbers import Number
from collections import deque
from collections.abc import Set, Mapping


ZERO_DEPTH_BASES = (str, bytes, Number, range, bytearray)


def getsize(obj_0):
    &quot;&quot;&quot;Recursively iterate to sum size of object &amp; members.&quot;&quot;&quot;
    _seen_ids = set()
    def inner(obj):
        obj_id = id(obj)
        if obj_id in _seen_ids:
            return 0
        _seen_ids.add(obj_id)
        size = sys.getsizeof(obj)
        if isinstance(obj, ZERO_DEPTH_BASES):
            pass # bypass remaining control flow and return
        elif isinstance(obj, (tuple, list, Set, deque)):
            size += sum(inner(i) for i in obj)
        elif isinstance(obj, Mapping) or hasattr(obj, 'items'):
            size += sum(inner(k) + inner(v) for k, v in getattr(obj, 'items')())
        # Check for custom object instances - may subclass above too
        if hasattr(obj, '__dict__'):
            size += inner(vars(obj))
        if hasattr(obj, '__slots__'): # can have __slots__ with __dict__
            size += sum(inner(getattr(obj, s)) for s in obj.__slots__ if hasattr(obj, s))
        return size
    return inner(obj_0)

Interpretation: When calculating the total size of a container, you add the size of the container itself to the sizes of all its elements. Be mindful that container types like list, set, and dict pre-allocate memory, so empty or small instances are larger than zero.

Solution 3: Recursive getsize Function (Deep Size)

To account for nested objects, a recursive approach is effective. This function traverses the object’s structure, summing the sizes of all reachable objects.

import sys
from types import ModuleType, FunctionType
from gc import get_referents

# Blacklist to prevent counting modules, functions, and types themselves
BLACKLIST = type, ModuleType, FunctionType

def get_deep_size(obj):
    """Recursively calculates the size of an object and its members."""
    seen_ids = set()
    size = 0
    objects_to_process = [obj]
    
    while objects_to_process:
        current_objects = []
        for item in objects_to_process:
            if not isinstance(item, BLACKLIST) and id(item) not in seen_ids:
                seen_ids.add(id(item))
                size += sys.getsizeof(item)
                current_objects.append(item)
        objects_to_process = get_referents(*current_objects)
    return size

# Example Usage:
my_list = [1, 'hello', [2, 3, { 'a': 1 }], None]
print(f"Deep size of my_list: {get_deep_size(my_list)} bytes")

This approach utilizes gc.get_referents to discover objects that an object refers to, ensuring that nested structures are included in the calculation.

Solution 4: The pympler Package

For a robust solution that handles complex object graphs, the pympler package, specifically its asizeof module, is highly recommended. It provides a well-tested way to get the deep size of objects.

First, install it: pip install pympler

Then, use it like this:

from pympler import asizeof
import numpy as np # Example for numpy array

my_list = [1, 'hello', [2, 3, { 'a': 1 }]]
my_numpy_array = np.arange(10000)

print(f"Pympler size of my_list: {asizeof.asizeof(my_list)} bytes")
print(f"Pympler size of numpy array: {asizeof.asizeof(my_numpy_array)} bytes")

pympler also offers tools for memory profiling and tracking object lifetimes.

Solution 5: Serialization for Size Estimation

Serializing an object, such as using the pickle module, can provide an estimate of its size, particularly its on-disk or network representation size.

import pickle

my_dict = {'key1': [1, 2, 3], 'key2': 'value'}
size_estimate = len(pickle.dumps(my_dict))

print(f"Pickle size estimate for my_dict: {size_estimate} bytes")

This method is useful when you need to know how much space an object would take when saved or transmitted. For objects that cannot be pickled, libraries like dill or cloudpickle might offer alternatives.

Solution 6: NumPy Array nbytes Attribute

For NumPy arrays, sys.getsizeof() often returns a fixed, small value, as it only measures the array object’s overhead. The nbytes attribute of a NumPy array accurately reflects the memory occupied by its data.

from numpy import arange
from sys import getsizeof

data_array = arange(10000)

print(f"sys.getsizeof(data_array): {getsizeof(data_array)} bytes")
print(f"data_array.nbytes: {data_array.nbytes} bytes")

Solution 7: Iterating Through Variables

If you want to get a quick overview of the sizes of all variables in the current scope, you can iterate through dir() and use eval(). Use this with caution, as eval() can be risky with untrusted input.

import sys

# Define some variables
variable_a = 100
variable_b = [1, 2, 3]
variable_c = "sample string"

for var_name in dir():
    # Check if the variable is defined in the current scope and not a built-in
    if not var_name.startswith('__') and var_name != 'getsize' and var_name != 'variable_a' and var_name != 'variable_b' and var_name != 'variable_c': # Exclude function and specific test vars
        try:
            var_value = eval(var_name)
            print(f"Size of '{var_name}': {sys.getsizeof(var_value)} bytes")
        except Exception as e:
            print(f"Could not get size for '{var_name}': {e}")

Solution 8: Using gc.get_referents with a Custom Function

Another way to achieve deep size calculation is by leveraging gc.get_referents more explicitly in a custom function, similar to Solution 3 but perhaps with slightly different structuring.

import sys
import gc

def calculate_actual_size(obj):
    """Calculates the total memory size of an object and all its referents."""
    size = 0
    seen_ids = set()
    objects_to_visit = [obj]

    while objects_to_visit:
        next_level = []
        for item in objects_to_visit:
            if id(item) not in seen_ids:
                seen_ids.add(id(item))
                size += sys.getsizeof(item)
                next_level.extend(gc.get_referents(item))
        objects_to_visit = next_level
    return size

# Example:
nested_list = [1, [2, 3, {'a': 4}], 'text']
print(f"Actual size of nested_list: {calculate_actual_size(nested_list)} bytes")

Solution 11: PyTorch Tensor Size

For PyTorch tensors, torch.save to a BytesIO buffer can provide a measure of serialized size.

import io
import torch
import sys

def get_torch_size(obj):
    buffer = io.BytesIO()
    torch.save(obj, buffer)
    return sys.getsizeof(buffer)

# Example Tensor
tensor_data = torch.randn((2, 5, 6, 7, 7, 3, 4))
print(f"Serialized size of PyTorch tensor: {get_torch_size(tensor_data)} bytes")

Considerations for Accurate Measurement

  • Garbage Collection Overhead: sys.getsizeof() accounts for garbage collector overhead if the object is managed by it.
  • Platform Dependence: Memory usage can vary slightly across different operating systems and Python versions. Python 3.8+ introduced memory optimizations that reduce the size of common containers.
  • Object Sharing: When multiple references point to the same object, deep size calculations need to avoid double-counting. Techniques using id() and a seen set are crucial here.
  • Interpretation of Size: Decide whether you need the shallow size (just the object itself) or the deep size (object plus everything it references).

FAQs on Python Object Size

Q: What is the difference between shallow and deep size of a Python object

ANS: Shallow size, typically measured by sys.getsizeof(), is the memory occupied directly by the object itself. Deep size accounts for the object plus all objects it references, recursively.

Q: Why does sys.getsizeof return the same size for different NumPy arrays

ANS: sys.getsizeof() measures the overhead of the NumPy array object itself, not the data it holds. For the actual data size, use the .nbytes attribute.

Q: How do I measure the memory usage of a list containing other lists

ANS: You need a recursive function or a library like pympler to sum the sizes of the outer list and all nested lists and their elements.

Q: Can I estimate the size of an object for disk storage

ANS: Yes, pickling the object and checking the length of the resulting byte string provides an estimate of its serialized size.

Q: What are the memory implications of using dictionaries versus sets

ANS: Dictionaries and sets pre-allocate memory. Empty instances are larger than zero bytes, and their sizes increase in steps as elements are added, with dictionaries generally having more overhead.
