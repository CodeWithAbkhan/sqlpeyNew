When looking to add text to an existing PDF in Python, it’s essential to identify the most reliable methods and libraries available, especially if you need functionality that works across Windows and Linux environments. Below, I present several robust approaches, complete with code examples and alternative solutions.

Top 6 Methods to Add Text to an Existing PDF Using Python

  1. Using PyPDF2 and ReportLab.

    If you’re looking for a combination of libraries like PyPDF2 and ReportLab , you can efficiently read an existing PDF and add text. Here’s how you can do it:

    from PyPDF2 import PdfWriter, PdfReader
import io
from reportlab.pdfgen import canvas

class AddTextToPDF:
    def __init__(self, input_pdf_path, output_pdf_path):
        self.input_pdf = PdfReader(input_pdf_path)
        self.output_pdf = PdfWriter()
        self.output_path = output_pdf_path

    def add_text(self, text, coords):
        packet = io.BytesIO()
        can = canvas.Canvas(packet)
        can.drawString(coords[0], coords[1], text)
        can.save()
        packet.seek(0)

        new_pdf = PdfReader(packet)
        existing_page = self.input_pdf.pages[0]
        existing_page.merge_page(new_pdf.pages[0])
        self.output_pdf.add_page(existing_page)

    def save(self):
        with open(self.output_path, "wb") as outputStream:
            self.output_pdf.write(outputStream)

# Usage
pdf_editor = AddTextToPDF("original.pdf", "modified.pdf")
pdf_editor.add_text("Hello, World!", (100, 200))
pdf_editor.save()

  2. Utilizing pdfrw.

    The pdfrw library allows for more direct manipulation of PDF pages and integrates nicely with ReportLab. Here’s a brief example:

    from pdfrw import PdfReader, PdfWriter, PageMerge
from reportlab.pdfgen import canvas
import io

def add_text_to_pdf(input_file, output_file, text, position):
    packet = io.BytesIO()
    can = canvas.Canvas(packet)
    can.drawString(position[0], position[1], text)
    can.save()

    packet.seek(0)
    overlay_pdf = PdfReader(packet)
    template_pdf = PdfReader(input_file)
    output_pdf = PdfWriter()

    for page in template_pdf.pages:
        PageMerge(page).add(overlay_pdf.pages[0]).render()
        output_pdf.addpage(page)

    output_pdf.write(output_file)

# Usage
add_text_to_pdf("original.pdf", "output.pdf", "Sample Text", (100, 650))

  3. Command-Line Option with cpdf.

    If you prefer a command-line solution, cpdf can add text directly from terminal commands:

    cpdf -add-text "New Text Here" input.pdf -o output.pdf

  4. Using pypdf for FreeText Annotations.

    With the newer pypdf library, adding annotations has become straightforward. Here’s a method to incorporate FreeText annotations:

    from pypdf import PdfReader, PdfWriter
from pypdf.annotations import FreeText

reader = PdfReader('input.pdf')
writer = PdfWriter()

# Add FreeText annotation
page = reader.pages[0]
annotation = FreeText(
    text="Hello World\nWelcome to PDF editing!",
    rect=(50, 550, 200, 650),
    font="Helvetica",
    font_size="16",
    font_color=(0, 255, 0),
    border_color=(0, 0, 255),
    background_color=(230, 230, 250),
)
writer.add_annotation(page_number=0, annotation=annotation)

with open("annotated_output.pdf", "wb") as output_stream:
    writer.write(output_stream)

  5. Using FPDF to Create Overlay Content.

    By leveraging FPDF to create overlay text, you can enhance an existing PDF effectively:

    import io
from fpdf import FPDF
from pypdf import PdfReader, PdfWriter

def create_overlay(text):
    pdf = FPDF()
    pdf.add_page()
    pdf.set_font("Arial", "I", 20)
    pdf.text(40, 50, text)
    return io.BytesIO(pdf.output(dest='S').encode('latin1'))

input_pdf = "existing_document.pdf"
output_pdf = "final_document.pdf"
reader = PdfReader(input_pdf)
overlay_content = create_overlay("Overlay Text Example")
overlay_pdf = PdfReader(overlay_content)

writer = PdfWriter()
writer.append_page(reader.pages[0].merge_page(overlay_pdf.pages[0]))
with open(output_pdf, "wb") as f:
    writer.write(f)

  6. Exploring Other Libraries.

    You may also look into alternatives like PDFMiner , which allows you to extract and manipulate PDF content. However, for adding text, the aforementioned methods are more suitable.

FAQs on How to Add Text to Existing PDF Using Python

Q: Which libraries do I need to install to add text to a PDF in Python?

A: You’ll need libraries like PyPDF2, ReportLab, pdfrw, or pypdf. You can install them via pip:

pip install PyPDF2 reportlab pdfrw pypdf

Q: Can I run these solutions on Windows and Linux?

A: Yes, these solutions are compatible with both Windows and Linux environments.

Q: Is it possible to add multiple lines or customize text styles?

A: Absolutely! You can customize text styles, positions, and multiple lines. Just modify the parameters in the examples provided.
