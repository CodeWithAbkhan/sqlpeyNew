“Python Pandas: Fuzzy Merging DataFrames with Similar Strings”

When working with real-world data, it’s common to encounter situations where you need to merge two DataFrames, but the keys or identifying columns contain minor variations or typos. This makes standard pandas.merge or pandas.join operations ineffective. This post explores various Python-based solutions to perform “fuzzy” merges, aligning rows based on string similarity rather than exact matches.

Solution 1: Using difflib.get_close_matches

This approach leverages Python’s built-in difflib module, specifically the get_close_matches function. It finds the best approximate matches for a string within a list of possibilities.

Scenario: Merging based on index similarity

Imagine you have two DataFrames, df1 and df2, where df2’s index needs to be aligned with df1’s index, despite some potential misspellings.

import pandas as pd
import difflib

# Sample DataFrame 1
df1 = pd.DataFrame({'number': [1, 2, 3, 4, 5]}, index=['one', 'two', 'three', 'four', 'five'])

# Sample DataFrame 2 with slightly different index
df2 = pd.DataFrame({'letter': ['a', 'b', 'c', 'd', 'e']}, index=['one', 'too', 'three', 'fours', 'five'])

# Align df2's index using difflib
df2.index = df2.index.map(lambda x: difflib.get_close_matches(x, df1.index)[0] if difflib.get_close_matches(x, df1.index) else x)

# Perform the join
merged_df_index = df1.join(df2)
print("Merged DataFrame (Index Match):\n", merged_df_index)

Scenario: Merging based on column similarity

If the similarities are within columns, you can apply difflib to the relevant column before merging.

# Sample DataFrame 1
df1_col = pd.DataFrame({'number': [1, 2, 3, 4, 5], 'name': ['one', 'two', 'three', 'four', 'five']})

# Sample DataFrame 2 with slightly different names
df2_col = pd.DataFrame({'letter': ['a', 'b', 'c', 'd', 'e'], 'name': ['one', 'too', 'three', 'fours', 'five']})

# Apply difflib to the 'name' column in df2
df2_col['name'] = df2_col['name'].apply(lambda x: difflib.get_close_matches(x, df1_col['name'])[0] if difflib.get_close_matches(x, df1_col['name']) else x)

# Perform the merge
merged_df_col = df1_col.merge(df2_col, on='name')
print("\nMerged DataFrame (Column Match):\n", merged_df_col)

Solution 2: Utilizing fuzzywuzzy

The fuzzywuzzy library (now often referred to as thefuzz) provides powerful tools for string matching based on Levenshtein distance. It offers functions like process.extract for finding the best matches.

Installation:

pip install fuzzywuzzy python-Levenshtein

Custom Fuzzy Merge Function:

Here’s a function to perform fuzzy merging with configurable thresholds and limits.

from fuzzywuzzy import process
import pandas as pd

def fuzzy_merge_with_fuzzywuzzy(df_1, df_2, key1, key2, threshold=80, limit=2):
    """
    Performs a fuzzy merge between two DataFrames.

    Args:
        df_1 (pd.DataFrame): The left DataFrame.
        df_2 (pd.DataFrame): The right DataFrame.
        key1 (str): The key column in df_1.
        key2 (str): The key column in df_2.
        threshold (int): The minimum similarity score (0-100) to consider a match.
        limit (int): The maximum number of matches to return for each item.

    Returns:
        pd.DataFrame: df_1 with an added 'matches' column containing fuzzy matches from df_2.
    """
    s = df_2[key2].tolist()

    # Find potential matches for each item in df_1's key column
    matches = df_1[key1].apply(lambda x: process.extract(x, s, limit=limit))
    df_1['matches'] = matches

    # Filter matches by threshold and format them
    df_1['matches'] = df_1['matches'].apply(lambda x: ', '.join([i[0] for i in x if i[1] >= threshold]))

    return df_1

# Example Usage:
df1_fw = pd.DataFrame({'Key': ['Apple', 'Banana', 'Orange', 'Strawberry']})
df2_fw = pd.DataFrame({'Key': ['Aple', 'Mango', 'Orag', 'Straw', 'Bannanna', 'Berry']})

print("\nFuzzy Merged with fuzzywuzzy (Example 1):\n", fuzzy_merge_with_fuzzywuzzy(df1_fw, df2_fw, 'Key', 'Key', threshold=80))

df1_fw_2 = pd.DataFrame({'Col1': ['Microsoft', 'Google', 'Amazon', 'IBM']})
df2_fw_2 = pd.DataFrame({'Col2': ['Mcrsoft', 'gogle', 'Amason', 'BIM']})

print("\nFuzzy Merged with fuzzywuzzy (Example 2):\n", fuzzy_merge_with_fuzzywuzzy(df1_fw_2, df2_fw_2, 'Col1', 'Col2', threshold=80))

Solution 4: Using Jaro-Winkler Distance (jellyfish)

The Jaro-Winkler distance is a string metric measuring an edit distance between two sequences. The jellyfish library provides an implementation.

Installation:

pip install jellyfish

Implementation:

import pandas as pd
import jellyfish

def get_closest_match_jw(x, list_strings):
    """Finds the closest match using Jaro-Winkler distance."""
    best_match = None
    highest_jw = 0

    for current_string in list_strings:
        current_score = jellyfish.jaro_winkler(x, current_string)
        if current_score > highest_jw:
            highest_jw = current_score
            best_match = current_string
    return best_match

# Sample DataFrames
df1_jw = pd.DataFrame({'number': [1, 2, 3, 4, 5]}, index=['one', 'two', 'three', 'four', 'five'])
df2_jw = pd.DataFrame({'letter': ['a', 'b', 'c', 'd', 'e']}, index=['one', 'too', 'three', 'fours', 'five'])

# Apply Jaro-Winkler to align indices
df2_jw.index = df2_jw.index.map(lambda x: get_closest_match_jw(x, df1_jw.index.tolist()))

# Perform the join
merged_df_jw = df1_jw.join(df2_jw)
print("\nMerged DataFrame with Jaro-Winkler:\n", merged_df_jw)

Solution 5: A General difflib Based Merge Function

This solution provides a more general-purpose fuzzy merge function that handles different join types (inner, left, right) and allows specifying cutoff thresholds.

import difflib
import pandas as pd

def fuzzy_merge_general(df1, df2, left_on, right_on, how='inner', cutoff=0.6):
    """
    Performs a fuzzy merge between two DataFrames using difflib.

    Args:
        df1 (pd.DataFrame): The left DataFrame.
        df2 (pd.DataFrame): The right DataFrame.
        left_on (str): The column in df1 to use for matching.
        right_on (str): The column in df2 to use for matching.
        how (str): The type of merge ('inner', 'left', 'right').
        cutoff (float): The minimum similarity score for a match.

    Returns:
        pd.DataFrame: The merged DataFrame.
    """
    def get_closest_match_with_cutoff(x, other, cutoff):
        matches = difflib.get_close_matches(x, other, cutoff=cutoff)
        return matches[0] if matches else None

    df_other = df2.copy()
    # Map the fuzzy matches from df1's column to df2's column
    df_other[left_on] = [get_closest_match_with_cutoff(x, df1[left_on].tolist(), cutoff)
                         for x in df_other[right_on]]

    return df1.merge(df_other, on=left_on, how=how)

# Sample DataFrames
df1_gen = pd.DataFrame({'key': ['one', 'two', 'three', 'four', 'five'], 'number': [1, 2, 3, 4, 5]})
df2_gen = pd.DataFrame({'key_close': ['three', 'one', 'too', 'fours', 'a very different string'], 'letter': ['c', 'a', 'b', 'd', 'e']})

print("\nFuzzy Merge (Inner Join):\n", fuzzy_merge_general(df1_gen, df2_gen, left_on='key', right_on='key_close', how='inner'))
print("\nFuzzy Merge (Left Join):\n", fuzzy_merge_general(df1_gen, df2_gen, left_on='key', right_on='key_close', how='left'))
print("\nFuzzy Merge (Right Join):\n", fuzzy_merge_general(df1_gen, df2_gen, left_on='key', right_on='key_close', how='right'))

Solution 7: Leveraging thefuzz for Tidy Data

This approach uses thefuzz to create a tidy dataset of matches, where each potential match becomes a row. This is useful for preserving all possible matches.

import pandas as pd
from thefuzz import process

def fuzzy_match_tidy(df_left, df_right, column_left, column_right, threshold=90, limit=1):
    """
    Performs fuzzy matching and returns a tidy DataFrame of matches.
    """
    series_matches = df_left[column_left].apply(
        lambda x: process.extract(x, df_right[column_right], limit=limit)
    )

    df_matches = series_matches.to_frame()
    df_matches = df_matches.explode(column_left)
    df_matches[['match_string', 'match_score', 'df_right_id']] = pd.DataFrame(df_matches[column_left].tolist(), index=df_matches.index)
    df_matches.drop(column_left, axis=1, inplace=True)

    if df_matches.index.name:
        index_name = df_matches.index.name
    else:
        index_name = 'index'
    df_matches.reset_index(inplace=True)
    df_matches.rename(columns={index_name: 'df_left_id'}, inplace=True)

    df_matches.drop(df_matches.loc[df_matches['match_score'] < threshold].index, inplace=True)
    return df_matches

# Sample DataFrames
df1_tidy = pd.DataFrame({'col_a': ['one', 'two', 'three', 'four', 'five'], 'col_b': [1, 2, 3, 4, 5]})
df2_tidy = pd.DataFrame({'col_a': ['one', 'too', 'three', 'fours', 'five'], 'col_b': ['a', 'b', 'c', 'd', 'e']})

df_matches_tidy = fuzzy_match_tidy(df1_tidy, df2_tidy, 'col_a', 'col_a', threshold=60, limit=1)

# Merge to get the final output
df_output_tidy = df1_tidy.merge(df_matches_tidy, how='left', left_index=True, right_on='df_left_id')
df_output_tidy = df_output_tidy.merge(df2_tidy, how='left', left_on='df_right_id', right_index=True, suffixes=['_df1', '_df2'])
df_output_tidy.set_index('df_left_id', inplace=True)
df_output_tidy = df_output_tidy[['col_a_df1', 'col_b_df1', 'col_b_df2']]
df_output_tidy.index.name = 'id'

print("\nTidy Fuzzy Match Results:\n", df_output_tidy)

Solution 8: Optimizing with fuzzywuzzy (Efficient Matching)

For large datasets, improving the efficiency of fuzzy matching is crucial. This can be achieved by pre-filtering potential matches based on length and starting letters.

from fuzzywuzzy.process import extract
import pandas as pd

def efficient_fuzzy_matching(df1, col1, df2, col2, limit=3, length_diff=3, first_letter_match=2):
    """
    Efficiently finds fuzzy matches by pre-filtering potential candidates.
    """
    df1[col1] = df1[col1].astype(str)
    df2[col2] = df2[col2].astype(str)

    df1['_len_'] = df1[col1].apply(len)
    df2['_len_'] = df2[col2].apply(len)
    
    # Filter df2 to only include items that are reasonably close in length
    df2_filtered = df2[ (df2['_len_'] - df1[col1].apply(len)).abs() < length_diff]

    matches = df1[[col1, '_len_']].apply(lambda x:
                                        extract(x[0],
                                                df2_filtered[
                                                    (df2_filtered['_len_'] - x[1]).abs() < length_diff
                                                ][col2].tolist(),
                                                limit=limit
                                                ),
                                        axis=1
                                        )
    return matches

Solution 9: Handling Potential NaN Values

When dealing with potential NaN values in columns used for fuzzy matching, a robust approach involves handling these gracefully.

import difflib
import pandas as pd
import numpy as np

def fuzzy_match_with_nan_handling(a, b_series):
    """
    Fuzzy matches string 'a' against a pandas Series 'b_series', handling NaNs.
    """
    left = '1' if pd.isnull(a) else a # Replace NaN in 'a' with a placeholder
    right_valid = b_series.dropna().tolist() # Get valid strings from 'b_series'

    if not right_valid: # If all values in b_series are NaN
        return np.NaN

    matches = difflib.get_close_matches(left, right_valid)
    return matches[0] if matches else np.NaN

Solution 11: Advanced thefuzz with Swifter and OrderedDict

For very large datasets, swifter can accelerate the apply operations, and OrderedDict helps manage duplicate matches efficiently.

from thefuzz import process
from collections import OrderedDict
import swifter
import pandas as pd

def match_with_swifter(x, list_to_match_against):
    """Helper function for swifter apply."""
    matches = process.extract(x, list_to_match_against, limit=6)
    # Use OrderedDict to remove duplicates while preserving order
    ordered_matches = list(OrderedDict((m, True) for m in matches).keys())
    return str(ordered_matches) # Return as string for column storage

Solution 12: General fuzzywuzzy Merge with Threshold

This solution wraps fuzzywuzzy’s process.extract into a reusable merge function, similar to pandas’ merge behavior.

from fuzzywuzzy import process
import pandas as pd

def fuzzy_merge_fuzzywuzzy_general(df, df2, on=None, left_on=None, right_on=None, how='inner', threshold=80):
    """
    Performs a fuzzy merge using fuzzywuzzy, mimicking pandas merge.
    """
    if on is not None:
        left_on = on
        right_on = on

    def fuzzy_apply(x, df_target, column, threshold):
        if not isinstance(x, str):
            return None
        
        # Use extractOne for efficiency if limit is implicitly 1
        match, score, *_ = process.extractOne(x, df_target[column])
            
        return match if score >= threshold else None

    # Create a temporary column for the best fuzzy match
    df2['tmp_match'] = df2[right_on].apply(
        fuzzy_apply, 
        df_target=df, 
        column=left_on, 
        threshold=threshold
    )

    merged_df = df.merge(df2, how=how, left_on=left_on, right_on='tmp_match')
    
    # Clean up temporary column
    del merged_df['tmp_match']
    
    return merged_df

# Example DataFrames
df1_fwg = pd.DataFrame({'Key': ['Apple', 'Banana', 'Orange', 'Strawberry']})
df2_fwg = pd.DataFrame({'Key': ['Aple', 'Mango', 'Orag', 'Straw', 'Bannanna', 'Berry']})

print("\nFuzzy Merged with fuzzywuzzy (General):\n", fuzzy_merge_fuzzywuzzy_general(df1_fwg, df2_fwg, on='Key', threshold=80))

Solution 14: Numeric Index Matching with Tolerance

If your DataFrame indices are numeric, you can implement a fuzzy join based on a specified tolerance.

import pandas as pd
import numpy as np

def fuzzy_left_join_numeric_index(df1, df2, tol=None):
    """
    Performs a fuzzy left join based on numeric index proximity.
    """
    index1_values = df1.index.values.reshape((-1, 1))
    index2_values = df2.index.values

    # Calculate absolute differences between indices
    diff = np.abs(index1_values - index2_values)
    
    # Find the index in df2 that is closest to each index in df1
    mask_j = np.argmin(diff, axis=1)
    mask_i = np.arange(mask_j.shape[0])

    df1_aligned = df1.iloc[mask_i]
    df2_aligned = df2.iloc[mask_j]

    # Apply tolerance if specified
    if tol is not None:
        mask_tolerance = np.abs(df2_aligned.index.values - df1_aligned.index.values) <= tol
        df1_aligned = df1_aligned.loc[mask_tolerance]
        df2_aligned = df2_aligned.loc[mask_tolerance]

    # Align indices for concatenation
    df2_aligned.index = df1_aligned.index

    out = pd.concat([df1_aligned, df2_aligned], axis=1)
    return out

# Sample DataFrames with numeric index
df1_num_idx = pd.DataFrame({'number': [1, 2, 3, 4, 5]}, index=[10, 25, 31, 48, 55])
df2_num_idx = pd.DataFrame({'letter': ['a', 'b', 'c', 'd', 'e']}, index=[12, 28, 30, 50, 58])

print("\nNumeric Index Fuzzy Join (No Tolerance):\n", fuzzy_left_join_numeric_index(df1_num_idx, df2_num_idx))
print("\nNumeric Index Fuzzy Join (Tolerance=3):\n", fuzzy_left_join_numeric_index(df1_num_idx, df2_num_idx, tol=3))

Which Method to Choose?

  • difflib: Good for simple cases and built-in. Less performant for very large datasets.
  • fuzzywuzzy/thefuzz: Flexible, widely used, and offers good control over thresholds and matching strategies. swifter can boost performance.
  • fuzzymatcher: Optimized for large datasets and multi-column matching, often providing better performance out-of-the-box.
  • jellyfish: Useful if you specifically need Jaro-Winkler or other string metrics it provides.
  • recordlinkage: Best for complex record linkage tasks and deduplication.
  • d6tjoin: Offers specialized best-match joining capabilities.

FAQs on Python Pandas Fuzzy Merging

Q: How do I merge two pandas DataFrames with slightly different strings

ANS: You can use libraries like difflib, fuzzywuzzy (or thefuzz), fuzzymatcher, or fuzzy_pandas to perform fuzzy merging. These libraries help align rows based on string similarity rather than exact matches. For example, difflib.get_close_matches or thefuzz.process.extract can find approximate string matches, which you can then use to join DataFrames.

Q: What is the best library for fuzzy string matching in pandas

ANS: The “best” library depends on your specific needs. For general use and flexibility, thefuzz is excellent. For larger datasets and performance, fuzzymatcher or recordlinkage might be more suitable. difflib is a good starting point as it’s built-in.

Q: How can I handle typos when merging DataFrames

ANS: Typos can be handled using fuzzy matching techniques. Implement functions that use string similarity algorithms (like Levenshtein distance or Jaro-Winkler) from libraries such as fuzzywuzzy or difflib to find the closest matches between the columns you intend to merge. Then, use these matches to perform the merge operation.

Q: What is fuzzy joining

ANS: Fuzzy joining is a data integration technique used to combine records from two or more datasets based on approximate string matching or other similarity measures, rather than requiring exact matches. This is crucial when dealing with data that contains variations, misspellings, or different formatting in key fields.

Q: How does difflib work for merging

ANS: difflib in Python provides tools for comparing sequences, including strings. Functions like get_close_matches can find the best approximate matches for a given string within a list of possibilities based on sequence similarity. You can apply this to a column or index to find potential matches, then use these to join DataFrames.
