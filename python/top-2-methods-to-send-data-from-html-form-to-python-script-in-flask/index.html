How can you send data from an HTML form to a Python script in Flask?

If you’re looking to interact dynamically with user input in your Flask web applications, passing data from HTML forms to your Python scripts is essential. Here’s how to efficiently handle this interaction through practical examples and alternative methods.

Setting Up Your Environment

Ensure you have Flask installed. You can set it up using the following command:

pip install Flask

Practical Example

Here’s a simple implementation where we create a Flask web application that takes user input from an HTML form and processes it in a Python script.

from flask import Flask, render_template, request
app = Flask(__name__)

@app.route('/tx/index/')
def index():
    """Load the starting page for project selection."""
    return render_template('init.html')

@app.route('/handle_data', methods=['POST'])
def handle_data():
    """Process the input data from the form."""
    projectpath = request.form['projectFilepath']
    # Process the project path as needed
    return f'You entered: {projectpath}'

The HTML Form

Create an init.html file that contains your form. Here’s how your basic HTML can look:

<form action="{{ url_for('handle_data') }}" method="post">
    <input type="text" name="projectFilepath" size="40" placeholder="Spot your project files">
    <input type="submit" value="Submit">
</form>

Detailed Breakdown of Implementation

  1. Form Attributes: Set the action attribute to the Flask route that will handle the data, and specify method="post" to ensure data is sent as form data.

  2. Field Naming: Ensure your input fields have name attributes. This allows Flask to access the data through the request.form object.

  3. Data Handling Route: Define a route in Flask that processes the input. Use request.form['input_name'] to retrieve the value corresponding to your form field names.

Alternative Ways to Send Data

Using Flask’s URL Routing: If you need to handle various types of data or perform multiple actions, you could define additional routes in your Flask app.

@app.route('/addRegion', methods=['POST'])
def addRegion():
    project_file_path = request.form['projectFilePath']
    # process the project file path
    return f'Successfully added path: {project_file_path}'

FAQs on Top 2 Methods to Send Data from HTML Form to a Python Script in Flask

Q: What Flask version do I need for these examples?

A: The examples provided are compatible with Flask 2.0 and above.

Q: Can I use GET method instead of POST?

A: Yes, you can use the GET method, but keep in mind the data will appear in the URL, which is less secure for sensitive information.

Q: What if my data includes files?

A: If your form includes file inputs, you must set enctype="multipart/form-data" in your form attributes and handle the files using request.files.
