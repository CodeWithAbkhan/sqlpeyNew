How to Get Detailed Exception Description and Stack Trace in Python

When working with Python, handling errors effectively is crucial for both debugging and usability. One common requirement is to convert a caught exception (including its description and stack trace) into a string format that you can log or display. There are various methods to achieve this, each offering different levels of detail and functionality.

Below, we will explore several practical solutions, including code examples for better understanding.

Solution 1: Basic Exception Handling with traceback

The simplest way to capture an exception in Python is to use a try-except block combined with the traceback module.

import traceback

def method_that_can_raise_exception(params):
    raise RuntimeError('Something bad happened!')

try:
    method_that_can_raise_exception('test')
except Exception as e:
    exception_string = traceback.format_exc()
    print(exception_string)

This code captures the entire stack trace as a string and prints it when an exception occurs.

Solution 2: Using a Logger

Utilizing a logger is best practice for capturing exceptions in modules.

import logging

logging.basicConfig(level=logging.DEBUG)
logger = logging.getLogger(__name__)

def risky_function():
    raise ValueError('An error occurred!')

try:
    risky_function()
except Exception as error:
    logger.exception(error)

When run, this code will log the error along with the stack trace. The output will look something like this:

ERROR:__main__:An error occurred!
Traceback (most recent call last):
  ...
ValueError: An error occurred!

Solution 3: TracebackException for Advanced Handling

For Python 3.5 and above, you can leverage traceback.TracebackException for more fine-grained control over exception handling.

import traceback

try:
    1 / 0
except Exception as ex:
    tb_exception = traceback.TracebackException.from_exception(ex)
    print(''.join(tb_exception.format()))

This method not only formats the exception but also provides additional context, making debugging easier.

Solution 4: Custom Function to Format Exception

You can create a custom function to get neatly formatted exception details.

import traceback
import sys

def format_exception(exception):
    return ''.join(traceback.format_exception(type(exception), exception, exception.__traceback__))

try:
    undefined_function()
except Exception as e:
    print(format_exception(e))

Solution 5: Structure Exception Information Using a List of Dictionaries

For structured error reporting, especially in APIs, you might find this method useful:

from traceback import TracebackException

def list_traceback(exc_value):
    result = []
    tb_exception = TracebackException.from_exception(exc_value)
    for frame_summary in tb_exception.stack:
        result.append({
            'filename': frame_summary.filename,
            'method': frame_summary.name,
            'lineno': frame_summary.lineno,
            'code': frame_summary.line
        })
    return result

try:
    1 / 0
except Exception as e:
    traceback_info = list_traceback(e)
    print(traceback_info)

Solution 6: Using the cgitb Module

For a more detailed output that includes local variable values, consider using the cgitb module.

import cgitb
cgitb.enable(format='text')

def divide(a, b):
    return a / b

def main():
    divide(1, 0)

if __name__ == "__main__":
    main()

When the error occurs, cgitb provides a comprehensive view of the context surrounding the error.

Practical Examples for Clarity

Here’s a practical demonstration of generating an exception and capturing its details:

def faulty_code():
    assert False, "This will raise an assertion error!"

try:
    faulty_code()
except Exception as e:
    tb = traceback.format_exc()
    print(f"Exception caught: {tb}")

Alternative Ways to Handle Exceptions

While the above methods are effective, you may also consider using:

  • Custom Exception Classes: For more specific exception types.
  • Built-in logging Configuration: To adjust the logging level and format.

These approaches can better tailor the information you log or handle.

FAQs on How to Get Detailed Exception Description and Stack Trace in Python

Q: How can I format an exception string for logging?

A: You can use the logging module along with the exception() method to log complete exception details including stack trace.

Q: What is the benefit of using traceback.TracebackException?

A: TracebackException allows for more granular formatting and is particularly useful for handling exceptions across different scopes in your code.

Q: Can I control the level of detail in the stack trace?

A: Yes, by using parameters available in the traceback module functions, you can limit the depth of the stack trace or customize the output format.

Q: Is cgitb suitable for production?

A: While cgitb provides detailed output for debugging during development, it may not be suitable for production as it can expose sensitive information.
