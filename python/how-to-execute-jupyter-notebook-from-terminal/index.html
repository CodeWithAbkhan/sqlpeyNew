I have a Jupyter Notebook file (.ipynb) and I want to execute it without the need for the interactive IPython interface. This can be quite useful for batch processing or automation. If I were dealing with a regular Python script, I would simply run python filename.py from the command line. But what about running an .ipynb file? What similar options are available? Here, we will explore the top methods to efficiently run Jupyter Notebook files directly from your terminal.

Top 12 Methods to Run Jupyter Notebooks from Terminal

Method 1: Using nbconvert to Convert to Python

You can convert your Jupyter Notebook to a Python script using nbconvert. This allows you to run the notebook as if it were a traditional Python script. Use the following command in your terminal:

jupyter nbconvert --to script your_notebook.ipynb

For more details, visit the nbconvert GitHub page .

If you haven’t installed mistune, which may be required, you can do so with:

sudo pip install -U mistune

Method 2: Running via IPython

You can run your Jupyter Notebook in an IPython shell directly. Begin by starting IPython in your terminal:

ipython

Then execute your notebook by running:

%run your_script.ipynb

Method 3: Export and Execute

One option involves exporting your notebook as a .py script which you can run conveniently. Simply download your notebook as a Python file and execute it in the terminal as usual.

Method 4: Run with IPython Options

You can also run Jupyter Notebooks directly using IPython with the following command:

ipython --TerminalIPythonApp.file_to_run=your_notebook.ipynb

For a shorter version, use:

ipython -c "%run your_notebook.ipynb"

This command is more concise and straightforward.

Method 5: The New jupyter execute Command

Recent versions of Jupyter come with a helpful jupyter execute command, which is also ideal for executing notebooks:

jupyter execute your_notebook.ipynb

Further information is available in the official Jupyter documentation .

Method 6: Using nbconvert to Execute and Clear Outputs

This command executes the notebook without cluttering your directory with extra files:

jupyter nbconvert --execute --clear-output your_notebook.ipynb

The --clear-output flag ensures that the cell outputs are refreshed with every execution.

Method 7: Using jupyter nbconvert with Newer Commands

Instead of using IPython, you can stick with jupyter for the conversion:

jupyter nbconvert --to script your_notebook.ipynb

Method 8: Utilizing papermill for Live Outputs

If you are looking to see live outputs while the notebook is executing, consider using papermill, which also supports parameterization:

pip install papermill
pip install papermill notebook.ipynb output.ipynb

Explore more about it in the papermill documentation .

Method 9: Insights from Online Resources

A summary of various techniques to run Jupyter Notebooks directly from the command line includes:

  1. Using nbconvert:

    jupyter nbconvert --execute --to notebook --allow-errors your_notebook.ipynb

  2. Using papermill:

    papermill -p name Piotrek your_notebook.ipynb output_notebook.ipynb

  3. Manual Download: Save your notebook as a .py script directly from Jupyter interface.

  4. Using jupytext: This utility allows live synchronization between .ipynb and .py files.

Method 10: Using runipy

This library enables execution of Jupyter Notebooks conveniently:

pip install runipy
runipy your_notebook.ipynb

For detailed instructions, visit the runipy page .

Method 11: Running Notebooks with boar

To execute notebooks within your Python code using the boar package, use:

from boar.running import run_notebook
outputs = run_notebook("your_notebook.ipynb")

Documentation can be found here .

Method 12: Running in Batch with Extended Timeout

If you wish to run your notebook with no timeout issues, execute:

jupyter nbconvert --execute --to notebook --inplace --allow-errors --ExecutePreprocessor.timeout=-1 your_notebook.ipynb

This command will ignore the default 30 seconds timeout and will overwrite your existing notebook.

Alternative Methods

You can also explore tools like jupytext to pair your notebooks with Python scripts, allowing for easy version control and execution.

For more details, check out the jupytext documentation .

FAQs on How to Execute a Jupyter Notebook from the Terminal

Q: Can I edit Jupyter Notebook files directly from my terminal?

A: No, Jupyter Notebook files are in JSON format and meant to be edited in a Jupyter environment or via compatible editors like Jupytext.

Q: Do I need to install additional packages to run Jupyter Notebooks from the terminal?

A: Depending on your chosen method, you may need packages such as nbconvert, papermill, or runipy. Make sure they are installed via pip.

Q: Is there a way to monitor the output of notebooks running from the terminal?

A: Yes, using papermill allows you to see real-time output while your notebook executes.
