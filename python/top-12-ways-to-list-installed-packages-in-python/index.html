Is it possible to easily list all installed packages along with their respective versions in Python? If you’re accustomed to tools like npm list in JavaScript, you’re not alone in looking for a similar functionality in Python. The following outlines a comprehensive guide with multiple solutions tailored to various needs and scenarios.

Solution 1: Using help('modules')

Invoke the following command in your Python shell:

help('modules')

This displays a list of all available modules in your Python environment. It’s a quick method but not the most structured or detailed.

Solution 2: Using pip with Python Code

If you prefer obtaining package information through code instead of using the command line, here’s a snippet that uses pip:

import pip  # Ensure pip is available

for package in pip.get_installed_distributions(local_only=True):
    print(package)

Output example might include:

cycler 0.9.0
decorator 4.0.4
ipykernel 4.1.0

Solution 3: Using pkg_resources

Here’s an effective method utilizing the pkg_resources module:

#!/usr/bin/env python3
import pkg_resources

installed_packages = [str(package).replace(" ", "==") for package in pkg_resources.working_set]
for package in installed_packages:
    print(package)

Solution 4: With Newer Versions of pip

For recent versions of pip, use the following approach:

from pip._internal.operations.freeze import freeze

for requirement in freeze(local_only=True):
    print(requirement)

Solution 5: Running Directly from the Command Line

You can also execute a Python command directly from your terminal:

python -c "help('modules')"

For specific modules, you can tailor your command:

python -c "help('os')"

Solution 6: Utilizing Easy Install (Deprecated)

If you’re working with older versions of Python that still support easy_install, consider the Yolk tool:

To install:

easy_install yolk

Yolk can provide information about installed packages along with querying for available ones on PyPI.

Solution 7: Using importlib.metadata

For a modern approach leveraging built-in libraries since Python 3.8, here’s the solution:

from importlib import metadata

for dist in metadata.distributions():
    print(f"{dist.name}=={dist.version}")

Solution 8: Leveraging pip freeze

If you want to see all installed packages using pip, simply run:

pip freeze

This displays packages in a format suitable for requirements files.

Solution 9: Using Conda

If you are using Conda as your package manager, simply execute:

conda list

For further details on the Conda cheat sheet, check here .

Solution 10: Alternative via PYTHONPATH

For users who prefer leveraging the PYTHONPATH, here’s an example:

for d in `echo "${PYTHONPATH}" | tr ':' '\n'`; do ls "${d}"; done

This command lists out packages in directories specified by your PYTHONPATH.

Solution 11: Using the Subprocess Module

A versatile approach is to invoke pip freeze using the subprocess module:

from subprocess import PIPE, Popen

pip_process = Popen(["pip freeze"], stdout=PIPE, stderr=PIPE, shell=True)
stdout, stderr = pip_process.communicate()
print(stdout.decode("utf-8"))

Solution 12: For Windows Users

If you’re on Windows 10, to list your available Python installations:

py -0 list

For more details on using Python’s launcher, visit this detailed guide here .

FAQs on Top 12 Ways to List All Installed Packages and Their Versions in Python

Q: Can I list installed packages without using pip?

A: Yes, you can use the help('modules') command or pkg_resources to list installed packages without directly invoking the pip command.

Q: Are there differences between pip freeze and pip list?

A: Yes, pip freeze shows the versions in a format suitable for requirements files, whereas pip list presents them in a more visually organized manner.

Q: What if I need to check packages in a virtual environment?

A: Activate your virtual environment and run pip freeze or pip list to see only the packages installed in that environment.
