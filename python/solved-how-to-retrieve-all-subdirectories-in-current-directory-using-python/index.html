Is it possible to obtain a comprehensive list of all subdirectories within the current directory in Python, especially when Python provides methods to list files but seems less intuitive for directories? Here we will explore multiple approaches that let us accomplish this, and delve into their performance characteristics.

Method 1: Using os.scandir

The os.scandir() function, introduced in Python 3.5, offers a more efficient way to get subdirectories. Here’s how you can utilize it:

import os

def list_immediate_subdirs(folder):
    return [f.path for f in os.scandir(folder) if f.is_dir()]

## Replace '.' with the desired folder path to list its subdirectories
subdirectories = list_immediate_subdirs('.')
print(subdirectories)

This code snippet returns the complete paths of the immediate subdirectories directly.

If you’re interested in just the names of the subdirectories, you can modify the list comprehension:

subdirectory_names = [f.name for f in os.scandir(folder) if f.is_dir()]

For further reading, check out the official documentation for os.scandir .

Method 2: Recursive Listing with fast_scandir

If you need to gather all subdirectories recursively, os.walk() is conventional but can be slow. Instead, we can improve performance:

def fast_scandir(dirname):
    subfolders = [f.path for f in os.scandir(dirname) if f.is_dir()]
    for dirname in list(subfolders):
        subfolders.extend(fast_scandir(dirname))
    return subfolders

all_subdirectories = fast_scandir('.')
print(all_subdirectories)

This implementation efficiently lists all folders, taking less time than nested os.walk() calls.

Method 3: Using glob for One-Level Deep Search

The glob library can also be employed, particularly for simple tasks of searching within the current directory:

from glob import glob

def list_subdirs_with_glob(path):
    return glob(f"{path}/*/")  # Note the trailing '/'

subdirectories_with_glob = list_subdirs_with_glob('.')
print(subdirectories_with_glob)

Make sure to include the trailing / to filter for directories only.

Method 4: Leveraging pathlib

Python 3.4 and above include the pathlib module, which introduces an object-oriented approach to file and directory management:

from pathlib import Path

def list_all_subdirectories(path):
    return [f for f in Path(path).iterdir() if f.is_dir()]

subdirs = list_all_subdirectories('./')
print(subdirs)

For recursive listing:

## This will display all directories including nested ones
all_dirs = list(Path('./').glob('**/*'))

For more on pathlib, refer to the pathlib documentation .

Method 5: Comparing Performance

To provide clarity on performance, here’s a comparison of various methods for listing directories:

import time
import os
from glob import glob
from pathlib import Path

directory = r"<insert_folder>"
RUNS = 1

def measure_time(function, *args):
    start_time = time.time_ns()
    for _ in range(RUNS):
        function(*args)
    return (time.time_ns() - start_time) / 1000 / 1000 / RUNS

## Example of using the different methods
print(f"os.scandir took {measure_time(list_immediate_subdirs, directory)} ms.")
print(f"os.walk took {measure_time(os.walk, directory)} ms.")
print(f"glob took {measure_time(list_subdirs_with_glob, directory)} ms.")
print(f"pathlib.iterdir took {measure_time(list_all_subdirectories, directory)} ms.")

This will yield a clear comparison of what method best suits your needs.

Additional Methods

Explore a few other creative ways to retrieve subdirectory listings:

  1. Using os.listdir:

    subdirectories = [d for d in os.listdir('.') if os.path.isdir(d)]
print(subdirectories)

  2. Recursive Function with os.walk:

    def directory_tree(root):
    for root, dirs, _ in os.walk(root):
        for dir in dirs:
            print(os.path.join(root, dir))

directory_tree('.')

  3. Filtering with filter:

    subdirectories = list(filter(lambda x: os.path.isdir(os.path.join('.', x)), os.listdir('.')))
print(subdirectories)

Each of these methods has its own strengths, so you may choose based on context and requirements.

FAQs on How to Retrieve All Subdirectories in the Current Directory Using Python

Q: How can I list all subdirectories including nested ones?

A: You can use a recursive function like fast_scandir or utilize os.walk() to capture all nested subdirectories.

Q: Which method is the fastest for listing immediate subdirectories?

A: Using os.scandir() generally offers the best performance for retrieving immediate subdirectories.

Q: Can I filter out certain directories?

A: Yes, you can implement filtering within your list comprehension or by using appropriate conditions to exclude directories based on names.

Q: Is there a cross-platform solution?

A: Yes, both os and pathlib are cross-platform and can handle directory listing on Linux, Mac, and Windows seamlessly.
