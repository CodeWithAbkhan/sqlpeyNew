“Pandas Drop Duplicates Based on Multiple Columns”

When working with datasets, particularly in data analysis with Python’s pandas , identifying and removing duplicate rows is a common task. Often, duplicates are defined not by the entire row being identical, but by a specific set of columns having the same values. How can you effectively achieve this in pandas?

This query delves into various techniques for dropping duplicate rows based on a subset of columns within a pandas DataFrame. We will examine different strategies, providing practical code snippets and explaining their nuances.

Method 1: Utilizing drop_duplicates() with subset and keep

The pandas.DataFrame.drop_duplicates() method is the primary tool for this purpose. It offers parameters to precisely control which columns to consider for identifying duplicates and which occurrence to retain.

Here’s a foundational example:

import pandas as pd

# Sample DataFrame
data = {"A": ["foo", "foo", "foo", "bar", "foo"],
        "B": [0, 1, 1, 1, 1],
        "C": ["A", "A", "B", "A", "A"]}
df = pd.DataFrame(data)

# Drop duplicates considering columns 'A' and 'C', keeping the first occurrence
deduplicated_df = df.drop_duplicates(subset=['A', 'C'], keep='first')
print(deduplicated_df)

Explanation of keep parameter:

  • 'first': Retains the first occurrence of a duplicate set and removes subsequent ones.
  • 'last': Retains the last occurrence and removes preceding ones.
  • False: Removes all occurrences of duplicates, leaving only unique rows.

Method 2: Removing All Occurrences of Duplicates

If the goal is to remove all rows that are part of a duplicate set based on specific columns, setting keep=False is the way to go.

import pandas as pd

data = {"A": ["foo", "foo", "foo", "bar", "foo"],
        "B": [0, 1, 1, 1, 1],
        "C": ["A", "A", "B", "A", "A"]}
df = pd.DataFrame(data)

# Drop all duplicate rows based on 'A' and 'C'
all_duplicates_removed_df = df.drop_duplicates(subset=['A', 'C'], keep=False)
print(all_duplicates_removed_df)

This operation is akin to SELECT DISTINCT * FROM table in SQL, but applied to specified columns.

Method 3: Modifying the DataFrame In-Place

You can choose to modify the DataFrame directly without creating a new one by using the inplace=True parameter.

import pandas as pd

data = {"A": ["foo", "foo", "foo", "bar", "foo"],
        "B": [0, 1, 1, 1, 1],
        "C": ["A", "A", "B", "A", "A"]}
df = pd.DataFrame(data)

# Drop duplicates based on 'A' and 'C' in-place
df.drop_duplicates(subset=['A', 'C'], keep=False, inplace=True)
print(df)

Alternatively, if you prefer to return a new DataFrame without modifying the original, you can explicitly set inplace=False or omit it, as False is the default.

# Returns a new DataFrame
new_df = df.drop_duplicates(subset=['A', 'C'], keep=False, inplace=False)

Method 4: Using groupby() and filter()

Another approach involves grouping the DataFrame by the relevant columns and then filtering to keep only those groups that appear exactly once.

import pandas as pd

data = {"A": ["foo", "foo", "foo", "bar", "foo"],
        "B": [0, 1, 1, 1, 1],
        "C": ["A", "A", "B", "A", "A"]}
df = pd.DataFrame(data)

# Group by 'A' and 'C', then filter for groups with size 1
unique_rows_df = df.groupby(["A", "C"]).filter(lambda x: x.shape[0] == 1)
print(unique_rows_df)

This method is particularly useful when you need to perform more complex conditional logic based on group sizes.

Method 5: Employing duplicated()

The pandas.DataFrame.duplicated() method returns a boolean Series indicating duplicate rows. This can be combined with boolean indexing for filtering.

import pandas as pd

data = {"A": ["foo", "foo", "foo", "bar", "foo"],
        "B": [0, 1, 1, 1, 1],
        "C": ["A", "A", "B", "A", "A"]}
df = pd.DataFrame(data)

# Identify and keep rows that are not duplicates based on 'A' and 'C'
non_duplicate_rows = df[~df.duplicated(subset=['A', 'C'], keep=False)].copy()
print(non_duplicate_rows)

The .copy() is recommended here to prevent potential SettingWithCopyWarning if you plan to modify non_duplicate_rows later.

You can also use duplicated() with conditional logic. For instance, to drop duplicates if column ‘A’ is ‘foo’:

non_duplicate_conditional = df[~(df.duplicated(subset=['A', 'B', 'C'], keep=False) & df['A'].eq('foo'))].copy()

Method 6: Using Column Indices for subset

If you prefer not to specify column names directly, you can use their integer positions.

import pandas as pd

data = {"A": ["foo", "foo", "foo", "bar", "foo"],
        "B": [0, 1, 1, 1, 1],
        "C": ["A", "A", "B", "A", "A"]}
df = pd.DataFrame(data)

# Drop duplicates considering columns at index 0 ('A') and 2 ('C')
deduplicated_by_index = df.drop_duplicates(subset=df.columns[[0, 2]], keep=False)
print(deduplicated_by_index)

This approach is beneficial when column names might change or when working with a large number of columns and referencing them by position is more convenient.

Method 7: Advanced Scenarios and Error Handling

In some cases, you might need to handle scenarios where columns might not exist or require specific error handling. The following snippet demonstrates a robust way to handle dropping duplicates across potentially absent columns.

import pandas as pd

# Placeholder for path, assuming it's relevant in a broader context
path = "your_data_path_here"

# Sample DataFrame (assuming 'column_1' and 'column_2' might exist)
data = {"header": ["val1", "val1", "val2", "val1"],
        "column_1": ["a", "a", "b", "a"],
        "column_2": [1, 1, 2, 1]}
df = pd.DataFrame(data)

if "column_2" in df.columns:
    try:
        # Attempt to drop duplicates based on column_1 and column_2
        df_temp = df[['column_1', "column_2"]].drop_duplicates(subset=["column_2", "column_1"], keep="first")
        # This part assumes you want to assign back, adjust as needed
        df['column_1'] = df_temp['column_1']
        df['column_2'] = df_temp['column_2']
    except Exception as e: # Catching broader exceptions if specific ones are not known
        df[["column_2"]] = df[["column_2"]].drop_duplicates(subset="column_2", keep="first")
        print(f"Could not process column_1 and column_2 for {path}. Error: {e}")
try:
    # Attempt to drop duplicates for column_1 if it exists
    df[["column_1"]] = df[["column_1"]].drop_duplicates(subset="column_1", keep="first")

This example uses try-except blocks to gracefully handle missing columns or other potential issues during the duplicate removal process, making your data cleaning more resilient.

By leveraging these methods, you can efficiently manage duplicate data in your pandas DataFrames, ensuring data integrity and accuracy for your analyses.

FAQs on Pandas Drop Duplicates Based on Multiple Columns

Q: How do I remove duplicate rows in Pandas based on specific columns

ANS: You can use the DataFrame.drop_duplicates() method, specifying the columns to consider using the subset parameter, like df.drop_duplicates(subset=['col1', 'col2']).

Q: What does keep=False in drop_duplicates do

ANS: Setting keep=False in drop_duplicates() removes all occurrences of duplicate rows within the specified subset of columns, leaving only rows that are entirely unique across those columns.

Q: Can I modify the DataFrame in place when dropping duplicates

ANS: Yes, you can use the inplace=True argument in drop_duplicates() to modify the DataFrame directly without creating a new one.

Q: How to keep only the first or last duplicate occurrence

ANS: Use keep='first' to retain the first instance of a duplicate set or keep='last' to retain the last instance.

Q: Is there an alternative to drop_duplicates for unique rows

ANS: Yes, you can use groupby() combined with filter() to achieve a similar result. For instance, df.groupby(['col1', 'col2']).filter(lambda x: x.shape[0] == 1) will keep rows that are unique based on ‘col1’ and ‘col2’. Another method is using df[~df.duplicated(subset=['col1', 'col2'], keep=False)].
