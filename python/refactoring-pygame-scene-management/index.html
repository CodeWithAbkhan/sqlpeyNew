“Refactoring Pygame Event Handling and Implementing Scene Management”

The evolution of a Pygame application often involves moving from monolithic event handling to a more structured, object-oriented approach. This transition allows for separating concerns, such as title screens, gameplay logic, and ending screens, into independent components.

Simplifying Event Polling and State Checks

Initial event processing often uses verbose if-blocks for checking every event type, particularly for continuous states like key presses.

Original Event Block Example (Verbose):

for e in pygame.event.get():
    if e.type == QUIT: raise SystemExit, "QUIT"
    if e.type == KEYDOWN and e.key == K_ESCAPE:
        raise SystemExit, "ESCAPE"

    if e.type == KEYDOWN and e.key == K_UP:
        up = True
    # ... many more key down/up checks ...
    if e.type == KEYUP and e.key == K_RIGHT:
        right = False

A significant improvement involves offloading continuous state checks to pygame.key.get_pressed(). This function returns the state of all keys at a single moment, which is better suited for movement updates rather than relying on momentary KEYDOWN/KEYUP events for continuous action.

Refactored Event Processing using get_pressed():

for e in pygame.event.get():
    if e.type == QUIT: raise SystemExit, "QUIT"
    if e.type == KEYDOWN and e.key == K_ESCAPE:
        raise SystemExit, "ESCAPE"

# Check continuous state once per frame for input variables
pressed_keys = pygame.key.get_pressed()
up, left, right = [pressed_keys[key] for key in (K_UP, K_LEFT, K_RIGHT)]

This technique declutters the per-event iteration significantly, especially when managing directional input.

Establishing a Base Scene Contract

To facilitate scene switching, we define a base Scene class that establishes a required interface for all concrete scenes. This enforces consistency and makes the SceneMananger predictable.

Abstract Scene Base Class:

class Scene(object):
    def __init__(self):
        pass

    def render(self, screen):
        raise NotImplementedError

    def update(self):
        raise NotImplementedError

    def handle_events(self, events):
        raise NotImplementedError

By raising NotImplementedError, we ensure that any subclass must implement these core methods, or face an immediate runtime error during development, which aids in discovering omissions.

Developing the GameScene Structure

The existing game logic, previously monolithic, is encapsulated within a GameScene inheriting from Scene. This class now manages level loading, entity updates, camera adjustments, and self-contained rendering.

In the improved structure, level data is stored in a dictionary (levels), allowing easy iteration and level progression:

levels = {
    0: {'level': [...], 'enemies': [(9, 38)]},
    1: {'level': [...], 'enemies': [(9, 38), (18, 38), (15, 15)]}
    # ... more levels
}

The GameScene constructor accepts a level number (levelno) and uses this to build the level geometry (Platform objects) and initialize dynamic elements like Player and Enemy sprites at specific coordinates derived from the level map array.

Player and Entity Interaction Updates: The Player class now holds a reference to its current scene (self.scene = self) to communicate back state changes, such as dying or completing a level, without needing direct access to the manager:

  • If the player falls out of bounds or hits a hazard, self.scene.die() is called.
  • If the player touches an ExitBlock, self.scene.exit() is called.

The GameScene methods then delegate these state changes to the manager:

    def exit(self):
        if self.levelno + 1 in levels:
            self.manager.go_to(GameScene(self.levelno + 1))
        else:
            self.manager.go_to(CustomScene("You win!"))

    def die(self):
        self.manager.go_to(CustomScene("You lose!"))

Implementing the SceneMananger

The SceneMananger class acts as the central conductor, holding the currently active scene and dictating transitions.

class SceneMananger(object):
    def __init__(self):
        self.go_to(TitleScene()) # Starts execution at the TitleScreen

    def go_to(self, scene):
        self.scene = scene
        self.scene.manager = self # Passes self reference for scene-to-scene communication

The main loop is simplified to constantly ask the current scene to handle events, update logic, and draw:

def main():
    # ... setup ...
    manager = SceneMananger()

    while running:
        timer.tick(60)

        if pygame.event.get(QUIT):
            running = False
            return
        # Delegate all frame-specific work to the current scene
        manager.scene.handle_events(pygame.event.get())
        manager.scene.update()
        manager.scene.render(screen)
        pygame.display.flip()

Creating Other Scenes (TitleScene and CustomScene)

The TitleScene initiates the game by calling self.manager.go_to(GameScene(0)) upon pressing SPACE.

The CustomScene (used for “You Win!” or “You Lose!” screens) provides an exit path back to the title screen when any key is pressed, demonstrating state return:

    def handle_events(self, events):
        for e in events:
            if e.type == KEYDOWN:
                self.manager.go_to(TitleScene())

Alternative Approach: State Machine using mode Variables

An alternative method, demonstrated in the second provided solution for a different game type (a bouncing ball game), involves using a monolithic game loop controlled by a mode variable (e.g., mode='title', mode='levels', mode='playing').

In this structure, the main loop contains large if/elif blocks based on the mode:

# Game loop structure from alternative solution
while True:
    if mode=='title':
        # Handle title screen events and rendering
        # ...
        if event.type==pygame.MOUSEBUTTONDOWN:
            if texts['start'][1].collidepoint(event.pos):
                mode='levels' # Transition
    
    elif mode=='levels':
        # Handle level selection events and rendering
        # ...
        if level[3].collidepoint(event.pos) and level[4]!=0:
            mode='loading'
            loadinglevel=levels.index(level)+1 # Pass data via external variables
    
    elif mode=='playing':
        # Game simulation logic for the current level
        # ...
        if won:
            mode='levels' # Transition back
            break

While this works well for simple games, the Scene/Manager pattern is generally preferred for larger projects as it offers better separation of concerns and modularity compared to passing state data through global or external variables like loadinglevel.

class GameScene(Scene):
    def __init__(self, levelno):
        super(GameScene, self).__init__()
        self.bg = Surface((32,32))
        self.bg.convert()
        self.bg.fill(Color("#0094FF"))
        up = left = right = False
        self.entities = pygame.sprite.Group()
        self.player = Player(5, 40)
        self.player.scene = self
        self.platforms = []

        self.levelno = levelno

        levelinfo = levels[levelno]
        self.enemies = [Enemy(*pos) for pos in levelinfo['enemies']]

        level = levelinfo['level']
        total_level_width = len(level[0]) * 32
        total_level_height = len(level) * 32

        # build the level
        x = 0
        y = 0
        for row in level:
            for col in row:
                if col == "P":
                    p = Platform(x, y)
                    self.platforms.append(p)
                    self.entities.add(p)
                if col == "E":
                    e = ExitBlock(x, y)
                    self.platforms.append(e)
                    self.entities.add(e)
                x += 32
            y += 32
            x = 0

        self.camera = Camera(complex_camera, total_level_width, total_level_height)
        self.entities.add(self.player)
        for e in self.enemies:
            self.entities.add(e)

    def render(self, screen):
        for y in range(20):
            for x in range(25):
                screen.blit(self.bg, (x * 32, y * 32))

        for e in self.entities:
            screen.blit(e.image, self.camera.apply(e))

    def update(self):
        pressed = pygame.key.get_pressed()
        up, left, right = [pressed[key] for key in (K_UP, K_LEFT, K_RIGHT)]
        self.player.update(up, left, right, self.platforms)

        for e in self.enemies:
            e.update(self.platforms)

        self.camera.update(self.player)

    def exit(self):
        if self.levelno+1 in levels:
            self.manager.go_to(GameScene(self.levelno+1))
        else:
            self.manager.go_to(CustomScene("You win!"))

    def die(self):
        self.manager.go_to(CustomScene("You lose!"))

    def handle_events(self, events):
        for e in events:
            if e.type == KEYDOWN and e.key == K_ESCAPE:
                self.manager.go_to(TitleScene())

class Camera(object):
    def __init__(self, camera_func, width, height):
        self.camera_func = camera_func
        self.state = Rect(0, 0, width, height)

    def apply(self, target):
        try:
            return target.rect.move(self.state.topleft)
        except AttributeError:
            return map(sum, zip(target, self.state.topleft))

    def update(self, target):
        self.state = self.camera_func(self.state, target.rect)

def complex_camera(camera, target_rect):
    l, t, _, _ = target_rect
    _, _, w, h = camera
    l, t, _, _ = -l + HALF_WIDTH, -t +HALF_HEIGHT, w, h

    l = min(0, l)                           # stop scrolling left
    l = max(-(camera.width - WIN_WIDTH), l)   # stop scrolling right
    t = max(-(camera.height-WIN_HEIGHT), t) # stop scrolling bottom

    return Rect(l, t, w, h)

    def update(self, up, left, right, platforms):
        if self.rect.top &gt; 1440 or self.rect.top &lt; 0:
            self.scene.die()

            self.scene.die()

            if self.onGround:
                self.yvel = 0
                self.yvel -= 10 # only jump if on the ground
        if left:
            self.xvel = -10
        if right:
            self.xvel = 10
        if not self.onGround:
            self.yvel += 0.3 # only accelerate with gravity if in the air
            if self.yvel &gt; 80: self.yvel = 80 # max falling speed
        if not(left or right):
            self.xvel = 0

        self.rect.left += self.xvel # increment in x direction
        if self.collide(self.xvel, 0, platforms): # do x-axis collisions
            self.rect.top += self.yvel # increment in y direction
            self.onGround = False; # assuming we're in the air
            self.collide(0, self.yvel, platforms) # do y-axis collisions

    def collide(self, xvel, yvel, platforms):
        for p in platforms:
            if pygame.sprite.collide_rect(self, p):
                if isinstance(p, ExitBlock):
                    self.scene.exit()
                    return False
                if xvel &gt; 0: self.rect.right = p.rect.left
                if xvel &lt; 0: self.rect.left = p.rect.right
                if yvel &gt; 0:
                    self.rect.bottom = p.rect.top
                    self.onGround = True
                if yvel &lt; 0:
                    self.rect.top = p.rect.bottom
        return True

class Enemy(Entity):
    def __init__(self, x, y):
        Entity.__init__(self)
        self.yVel = 0
        self.xVel = 2 # start moving immediately
        self.image = Surface((32,32))
        self.image.fill(Color("#00FF00"))
        self.image.convert()
        self.rect = Rect(x*32, y*32, 32, 32)
        self.onGround = False

    def update(self, platforms):
        if not self.onGround:
            self.yVel += 0.3

        # no need for right_dis to be a member of the class,
        # since we know we are moving right if self.xVel &gt; 0
        right_dis = self.xVel &gt; 0

        # create a point at our left (or right) feet 
        # to check if we reached the end of the platform
        m = (1, 1) if right_dis else (-1, 1)
        p = self.rect.bottomright if right_dis else self.rect.bottomleft
        fp = map(sum, zip(m, p))

        # if there's no platform in front of us, change the direction
        collide = any(p for p in platforms if p.rect.collidepoint(fp))
        if not collide:
            self.xVel *= -1

        self.rect.left += self.xVel # increment in x direction
        self.collide(self.xVel, 0, platforms) # do x-axis collisions
        self.rect.top += self.yVel # increment in y direction
        self.onGround = False; # assuming we're in the air
        self.collide(0, self.yVel, platforms) # do y-axis collisions

    def collide(self, xVel, yVel, platforms):
        for p in platforms:
            if pygame.sprite.collide_rect(self, p):
                if xVel &gt; 0: 
                    self.rect.right = p.rect.left
                    self.xVel *= -1 # hit wall, so change direction
                if xVel &lt; 0: 
                    self.rect.left = p.rect.right
                    self.xVel *= -1 # hit wall, so change direction
                if yVel &gt; 0:
                    self.rect.bottom = p.rect.top
                    self.onGround = True
                if yVel &lt; 0:
                    self.rect.top = p.rect.bottom
