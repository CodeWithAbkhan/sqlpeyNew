Techniques for Adjusting Matplotlib Subplot Spacing

Here are several accepted and practical approaches to mitigate subplot overlap in Matplotlib figures:

Method 1: Utilizing tight_layout()

The matplotlib.pyplot.tight_layout() function or the figure method fig.tight_layout() automatically adjusts subplot parameters to give a tight layout. This is often the first and simplest solution to attempt.

Practical Implementation Example:

import matplotlib.pyplot as plt

# Creating a grid of 4x4 subplots
fig, axes = plt.subplots(nrows=4, ncols=4, figsize=(8, 8))

# Apply tight_layout either to the figure or pyplot interface
fig.tight_layout() 
# Alternatively: plt.tight_layout()

plt.show()

This function dynamically calculates the necessary padding to fit all elements neatly within the figure boundary, preventing overlaps.

Method 2: Fine-Tuning Spacing with subplots_adjust()

For more granular control over the space, plt.subplots_adjust() allows manual tuning of the subplot parameters. This function modifies the spacing parameters directly.

Call Signature and Parameters:

plt.subplots_adjust(left=None, bottom=None, right=None, top=None, wspace=None, hspace=None)
  • wspace: Reserves width for blank space between subplots (width space).
  • hspace: Reserves height for white space between subplots (height space).

Example of Manual Adjustment:

import matplotlib.pyplot as plt

fig, ax = plt.subplots(2, 2, figsize=(7, 7))

# Setting specific spacing values
fig.subplots_adjust(
    left=0.10,    # Left edge percentage
    right=0.95,   # Right edge percentage
    wspace=0.4,   # Increased horizontal space
    hspace=0.5    # Increased vertical space
)

plt.show()

Method 3: Implementing constrained_layout

Since Matplotlib version 2.2, constrained_layout offers an alternative to tight_layout. Unlike tight_layout, which is called once, constrained_layout is a property activated upon figure or subplot creation, optimizing the layout before every drawing operation.

Activation during creation:

import matplotlib.pyplot as plt

# Activate constrained_layout upon subplot creation
fig, axes = plt.subplots(4, 4, constrained_layout=True)

plt.show()

Global Activation via rcParams:

You can enforce this globally for subsequent plots:

plt.rcParams['figure.constrained_layout.use'] = True

Method 4: Completely Removing Whitespace with subplots_adjust(hspace=0)

If the goal is to eliminate vertical space between stacked plots, setting hspace to zero or a very small value achieves this, contrasting with the default behavior where hspace=None maintains some space.

Code Demonstrating Zero Spacing:

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.ticker as tic

fig = plt.figure(figsize=(8, 8))

x_data = np.arange(100)
y_data = 3. * np.sin(x_data * 2. * np.pi / 100.)

for i in range(1, 6):
    # Creating subplots stacked vertically (e.g., using the 511 style numbering)
    ax = plt.subplot(510 + i) 
    plt.plot(x_data, y_data)
    
    # Removing vertical space completely
    plt.subplots_adjust(hspace=0) 
    
    ax.yaxis.set_major_locator(tic.MaxNLocator(3))
    ax.set_xticklabels(())
    ax.title.set_visible(False)

plt.show()

Method 5: Figure Size Scaling and subplots_adjust()

If increasing spacing parameters like hspace makes the individual subplots too small, the overall figure size must be enlarged proportionally. Increasing the figsize when creating the figure, combined with subplots_adjust, grants more area for the reserved white space without shrinking the plots excessively.

import matplotlib.pyplot as plt

# Increase figure height significantly (e.g., 10 inches wide, 60 inches tall for many vertical plots)
fig = plt.figure(figsize=(10, 60)) 
fig.subplots_adjust(hspace=0.4) # Adjust as needed
plt.show()

Method 6: Using subplot_tool()

For an interactive approach, the subplot_tool() offers a GUI window to adjust layout parameters in real-time.

plt.subplot_tool()

Method 7: Adjusting Spacing When Plotting Pandas DataFrames

When using pandas.DataFrame.plot(subplots=True), Matplotlib is the backend. You can apply the same spacing adjustments by accessing the underlying figure object.

Pandas Plotting Example with Layout Tuning:

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# ... (Setup DataFrame 'df' as described in the original content) ...

sample_length = range(1, 16)
rads = np.arange(0, 2 * np.pi, 0.01)
data = np.array([np.sin(t * rads) for t in sample_length])
df = pd.DataFrame(data.T, index=pd.Series(rads.tolist(), name='radians'), 
                  columns=[f'freq: {i}x' for i in sample_length])

# Plot with explicit layout, size, and shared axes
axes = df.plot(
    subplots=True, 
    layout=(3, 5),         # 3 rows, 5 columns
    figsize=(25, 16),      # Large figure size
    sharex=True, 
    sharey=True
)

# Flatten axes array for easy iteration
axes_flat = axes.flat

# Retrieve the figure object
fig = axes_flat[0].get_figure()

# Apply tight_layout for final cleanup
fig.tight_layout()

plt.show()

Method 8: Direct tight_layout Argument in plt.subplots()

You can pass tight_layout=True directly when calling plt.subplots(), which is cleaner than calling it separately afterwards.

import matplotlib.pyplot as plt

# Passing tight_layout=True during figure creation
fig, axes = plt.subplots(nrows=4, ncols=4, figsize=(8, 8), tight_layout=True)

Method 9: Tuning Padding in tight_layout()

If default padding is insufficient, explicitly specify the padding value using the pad argument in tight_layout().

fig.tight_layout(pad=2.0)

Method 10: Using constrained_layout via rcParams (Revisited)

Confirming the configuration setting globally for the constrained layout feature:

plt.rcParams['figure.constrained_layout.use'] = True

Method 11: Specifying Layout via gridspec_kw or layout

Modern Matplotlib allows specifying spacing via gridspec_kw passed to subplots, or by using the layout argument which can accept "tight" (which internally uses constrained layout).

# Using gridspec_kw for precise control over hspace/wspace
fig, axes = plt.subplots(2, 2, gridspec_kw=dict(hspace=0.3, wspace=0.3))

# Using the layout argument (requires constrained_layout to be active or inferred)
fig, axes = plt.subplots(2, 2, layout="tight")

Method 12: Controlling Row Height Ratios (Matplotlib >= 3.6)

For figures where the vertical scaling is critical, the height_ratios parameter (available in newer versions) can be provided, often used alongside layout='constrained' or gridspec_kw.

# Example combining preferred methods
fig, axes = plt.subplots(
    2, 2, 
    layout='constrained', 
    gridspec_kw={'hspace': 0, 'height_ratios': [1, 3]} # Example ratio
)

FAQs on Matplotlib Subplot Spacing

Q: What is the primary function for automatically fixing subplot overlap

ANS: The primary function for automatic adjustment is matplotlib.pyplot.tight_layout() or fig.tight_layout().

Q: How do I set specific horizontal and vertical spacing between subplots

ANS: Use plt.subplots_adjust(wspace=value, hspace=value) where values are floats representing the fraction of subplot width/height reserved for space.

Q: Can I use constrained_layout instead of tight_layout

ANS: Yes, constrained_layout is a newer feature that can be enabled via constrained_layout=True in plt.subplots() or globally setting plt.rcParams['figure.constrained_layout.use'] = True.

Q: How can I completely remove vertical space between subplots

ANS: Set the horizontal space parameter to zero when adjusting: plt.subplots_adjust(hspace=0).

Q: If I increase hspace, why do my plots get smaller

ANS: Increasing spacing parameters reserves a larger percentage of the total figure area for gaps. To maintain the size of the plots, you must increase the overall figsize of the figure.

import matplotlib.pyplot as plt

fig, axes = plt.subplots(nrows=4, ncols=4, figsize=(8, 8))
fig.tight_layout() # Or equivalently,  &quot;plt.tight_layout()&quot;

plt.show()
