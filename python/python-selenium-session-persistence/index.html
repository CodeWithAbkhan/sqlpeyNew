How to Save and Load Selenium Browser Sessions in Python

Several techniques can be employed to achieve session persistence. These methods primarily revolve around managing cookies and, in some cases, entire browser profiles.

Solution 1: Using pickle for Cookie Serialization

The pickle module in Python provides a straightforward way to serialize Python objects, including the cookies obtained from a Selenium driver instance. This allows you to save the cookies to a file and later load them back into a new browser session.

import pickle
import selenium.webdriver

# Initialize the driver (e.g., Firefox)
driver_instance = selenium.webdriver.Firefox()
driver_instance.get("http://www.example.com") # Navigate to a site

# Save cookies to a file
with open("session_cookies.pkl", "wb") as cookie_file:
    pickle.dump(driver_instance.get_cookies(), cookie_file)

# Later, to load cookies into a new session:
new_driver_instance = selenium.webdriver.Firefox()
new_driver_instance.get("http://www.example.com") # Navigate to the same site
with open("session_cookies.pkl", "rb") as cookie_file:
    loaded_cookies = pickle.load(cookie_file)

for cookie_data in loaded_cookies:
    new_driver_instance.add_cookie(cookie_data)

# Refresh the page to apply the loaded cookies
new_driver_instance.refresh()

Solution 2: Leveraging Chrome’s user-data-dir for Profile Persistence

For Chrome, a robust method is to utilize the user-data-dir argument. This option tells Chrome to use a specified directory as its user profile, which includes cookies, extensions, settings, and login states.

from selenium import webdriver
from selenium.webdriver.chrome.options import Options

# Set Chrome options to use a specific user data directory
chrome_options = Options()
# Replace 'path/to/your/chrome/profile' with your desired directory
chrome_options.add_argument("user-data-dir=path/to/your/chrome/profile")

# Initialize the Chrome driver with the options
driver_instance = webdriver.Chrome(options=chrome_options)
driver_instance.get("http://www.example.com")

# On subsequent runs, the browser will start with the same profile,
# retaining logins, cookies, extensions, etc.
# Example of starting a new session with the same profile:
# driver_instance_2 = webdriver.Chrome(options=chrome_options)
# driver_instance_2.get("http://www.example.com") # Should be logged in

This approach is advantageous as it preserves more than just cookies, including browser extensions and custom settings, offering a more complete session replication. For Selenium 4.15.2 and later, the syntax might slightly differ, but the principle remains the same.

Solution 4: Preserving WhatsApp Web Session (Example)

This example demonstrates using user-data-dir specifically for a site like WhatsApp Web, where maintaining an authenticated session is critical.

from selenium import webdriver
from selenium.webdriver.chrome.options import Options
import time

chrome_options = Options()
# Ensure the path points to a valid Chrome data directory
chrome_options.add_argument("--user-data-dir=C:/Users/YourUser/AppData/Local/Google/Chrome/User Data/Profile 1") # Example path for Windows

driver_instance = webdriver.Chrome('chromedriver.exe', options=chrome_options) # Ensure chromedriver.exe is in your PATH or specified
driver_instance.get('https://web.whatsapp.com')
time.sleep(30) # Allow time for the QR code scan/login

The same principle can be applied to other sites by adjusting the path and target URL. This method allows for pre-configured extensions and manual logins within the specified profile directory.

Solution 5: Storing Cookie Data in Text Files

Instead of pickle, you can store cookie data in a simple text file. This method involves reading the file, using eval() to convert the string representation back into a Python list, and then adding the cookies.

from selenium import webdriver
import os

# Initial setup and login
driver_instance = webdriver.Chrome()
driver_instance.get("https://www.example.com")

# Save cookies to a text file
# A more robust method might involve JSON serialization, but this shows the text file approach
# For this example, let's assume get_cookies() returns a list of dictionaries.
# Saving it requires careful formatting. A simple approach might be to save the string representation.
# A better approach is using JSON or pickle.

# Example using JSON for better structure:
import json
with open("cookies.json", "w") as f:
    json.dump([{k: v} for k, v in driver_instance.get_cookies()], f) # Simplified for example

# To load cookies:
if os.path.exists("cookies.json"):
    with open("cookies.json", "r") as f:
        loaded_cookies_data = json.load(f)
        # loaded_cookies_data might need restructuring depending on how it was saved
        # Assuming it's a list of dictionaries like driver.get_cookies()
        for cookie_dict_list in loaded_cookies_data:
            for cookie_entry in cookie_dict_list: # If saved as list of lists
                driver_instance.add_cookie(cookie_entry)
    driver_instance.refresh()

Solution 6: Using json for Cookie Storage

A more structured approach than plain text is using the json module to store cookies. This maintains the dictionary structure of each cookie, making it easier to parse and add back.

import json
import selenium.webdriver
from selenium.webdriver.remote.webdriver import WebDriver

def save_cookies_to_json(driver: WebDriver, file_path: str = "cookies.json"):
    """Saves all cookies from the driver to a JSON file."""
    with open(file_path, "w") as f:
        json.dump(driver.get_cookies(), f)

def load_cookies_from_json(driver: WebDriver, file_path: str = "cookies.json"):
    """Loads cookies from a JSON file and adds them to the driver."""
    if not os.path.exists(file_path):
        print(f"Cookie file not found at {file_path}")
        return
    with open(file_path, "r") as f:
        cookies = json.load(f)
    for cookie in cookies:
        driver.add_cookie(cookie)

# Example usage:
driver_instance = selenium.webdriver.Chrome()
driver_instance.get("http://www.example.com")
# ... perform actions that set cookies ...
save_cookies_to_json(driver_instance)

# Later, in a new session:
new_driver_instance = selenium.webdriver.Chrome()
new_driver_instance.get("http://www.example.com")
load_cookies_from_json(new_driver_instance)
new_driver_instance.refresh()

Solution 7: Handling Cookie Expiration and Attributes

When loading cookies, it’s important to consider potential issues like expiration dates and attributes like sameSite. Some websites might reject cookies if these are not handled correctly.

import json
import pandas as pd
from datetime import datetime
import selenium.webdriver

def load_and_validate_cookies(driver: selenium.webdriver.Chrome, file_path: str = "cookies.json"):
    """Loads cookies, checks expiry, and adds them to the driver."""
    try:
        with open(file_path, "r") as file:
            cookies_list = json.load(file)
    except FileNotFoundError:
        print("Cookie file not found.")
        return False
    except json.JSONDecodeError:
        print("Error decoding cookie file.")
        return False

    # Convert to DataFrame to easily check the minimum expiry timestamp
    df_cookies = pd.DataFrame(cookies_list)
    if 'expiry' in df_cookies.columns and not df_cookies['expiry'].empty:
        min_expiry_timestamp = df_cookies['expiry'].min()
        if datetime.fromtimestamp(min_expiry_timestamp) < datetime.now():
            print("A loaded cookie has expired.")
            return False
    else:
        print("No valid expiry information found in cookies.")
        # Decide on behavior if expiry is missing - potentially still add if other methods fail

    for cookie_dict in cookies_list:
        # Remove 'sameSite' attribute if it causes issues, as some browsers/Selenium versions might handle it differently
        if 'sameSite' in cookie_dict:
            del cookie_dict['sameSite']
        driver.add_cookie(cookie_dict)
    return True

# Example usage:
driver_instance = selenium.webdriver.Chrome()
driver_instance.get("http://www.example.com")
# ... save cookies ...

if load_and_validate_cookies(driver_instance):
    driver_instance.refresh()
    print("Cookies loaded and page refreshed.")
else:
    print("Failed to load valid cookies. Please re-authenticate.")

Solution 8: Preserving Local Storage and Other Browser Data

For more complex scenarios, cookies alone might not be sufficient. Websites often utilize localStorage or other browser storage mechanisms to maintain session state.

import json
import selenium.webdriver

def save_browser_storage(driver: selenium.webdriver.Remote, storage_type: str = "localStorage", file_path: str = "storage.json"):
    """Saves browser storage (localStorage or sessionStorage) to a JSON file."""
    if storage_type not in ["localStorage", "sessionStorage"]:
        raise ValueError("storage_type must be 'localStorage' or 'sessionStorage'")

    script = f"""
    var items = {{}};
    var storage = window.{storage_type};
    for (var i = 0; i < storage.length; i++) {{
        items[storage.key(i)] = storage.getItem(storage.key(i));
    }}
    return items;
    """
    storage_data = driver.execute_script(script)
    with open(file_path, "w") as f:
        json.dump(storage_data, f)

def load_browser_storage(driver: selenium.webdriver.Remote, storage_type: str = "localStorage", file_path: str = "storage.json"):
    """Loads browser storage from a JSON file."""
    if not os.path.exists(file_path):
        print(f"Storage file not found at {file_path}")
        return
    with open(file_path, "r") as f:
        storage_data = json.load(f)

    script_template = f"window.{storage_type}.setItem('{{key}}', '{{value}}');"
    for key, value in storage_data.items():
        # Basic escaping for values to prevent JavaScript injection issues
        escaped_value = value.replace("'", "\\'").replace('"', '\\"')
        driver.execute_script(script_template.format(key=key, value=escaped_value))

# Example workflow:
driver_instance = selenium.webdriver.Chrome()
driver_instance.get("http://www.example.com")
save_browser_storage(driver_instance, storage_type="localStorage", file_path="local_storage.json")
save_cookies_to_json(driver_instance, file_path="cookies.json")

# New session:
new_driver_instance = selenium.webdriver.Chrome()
new_driver_instance.get("http://www.example.com")
load_cookies_from_json(new_driver_instance, file_path="cookies.json")
load_browser_storage(new_driver_instance, storage_type="localStorage", file_path="local_storage.json")
new_driver_instance.refresh()

Solution 11: Handling Cookie String Formats

When working with cookies directly from browser developer tools or other sources, they might come as a single string. Parsing this string correctly is essential.

import json
import os
import selenium.webdriver

# Assume COOKIES is a string like "name1=value1; name2=value2; ..."
# Or a formatted string from browser developer tools

def add_cookies_from_string(driver: selenium.webdriver.Remote, cookie_string: str, domain: str = ".example.com"):
    """Parses a cookie string and adds them to the driver."""
    for item in cookie_string.split(';'):
        if '=' in item:
            name, value = item.split('=', 1)
            name = name.strip()
            value = value.strip()
            cookie_dict = {
                'name': name,
                'value': value,
                'domain': domain,
                'path': '/',
                'httpOnly': False, # Set as appropriate
                'HostOnly': False, # Set as appropriate
                'Secure': False    # Set as appropriate
            }
            driver.add_cookie(cookie_dict)

# Example usage:
driver_instance = selenium.webdriver.Chrome()
driver_instance.get("http://www.example.com")

# Simulate receiving a cookie string
cookie_data_string = "session_id=abc123xyz; user_pref=dark_mode"
add_cookies_from_string(driver_instance, cookie_data_string, domain="www.example.com")
driver_instance.refresh()

Solution 12: Firefox Profile Persistence

For Firefox, preserving session data involves managing the profile directory. This can be done by copying the active profile directory to a persistent location and then initializing a new Firefox instance using that saved profile.

from selenium.webdriver import Firefox, FirefoxProfile
import shutil
import os.path
import time

# Save the current profile
def save_firefox_profile(driver: Firefox, destination_path: str):
    """Saves the current Firefox profile to a destination directory."""
    driver.execute_script("window.close()")
    time.sleep(0.5) # Allow cleanup
    current_profile_path = driver.capabilities["moz:profile"]
    if os.path.isdir(destination_path):
        shutil.rmtree(destination_path)
    shutil.copytree(current_profile_path, destination_path, ignore_dangling_symlinks=True)
    driver.quit()

# Load a saved profile
def load_firefox_profile(profile_path: str, executable_path: str = "geckodriver") -> Firefox:
    """Initializes a Firefox driver with a saved profile."""
    profile = FirefoxProfile(profile_path)
    driver = Firefox(executable_path=executable_path, firefox_profile=profile)
    return driver

# Example workflow:
# Ensure geckodriver is in your PATH or specified correctly
driver_instance = Firefox()
driver_instance.get("https://duckduckgo.com")
# Set some local storage for demonstration
driver_instance.execute_script("localStorage.setItem('persistent_data', '123');")
time.sleep(1) # Ensure data is written

saved_profile_dir = "/tmp/my_firefox_profile" # Or a path on Windows
save_firefox_profile(driver_instance, saved_profile_dir)

# New session with saved profile:
new_driver = load_firefox_profile(saved_profile_dir)
new_driver.get("https://duckduckgo.com")
# Verify data is still present
retrieved_data = new_driver.execute_script("return localStorage.getItem('persistent_data');")
print(f"Retrieved localStorage data: {retrieved_data}")
assert retrieved_data == "123"
new_driver.quit()

It’s important to note that methods directly initializing Firefox with a profile path like Firefox(capabilities={"moz:profile": "/path/to/dir"}) or Firefox(options=options) might not work as expected, as the driver often manages profile creation and cleanup.

FAQs on Python Selenium Session Persistence

Q: How can I save my logged-in session in Selenium?

ANS: You can save your logged-in session by serializing the browser’s cookies using modules like pickle or json and then loading them back into a new browser instance. Alternatively, for Chrome, using the user-data-dir option with Selenium will preserve the entire browser profile, including login states.

Q: What is the best way to store Selenium cookies?

ANS: For structured storage, json is generally preferred as it’s human-readable and widely supported. pickle is also effective for Python-specific serialization. Storing cookies in a plain text file is possible but requires careful formatting and handling.

Q: Can I reuse a Chrome browser profile with Selenium?

ANS: Yes, you can reuse a Chrome browser profile by specifying the user-data-dir argument in ChromeOptions. This directory contains all your browser data, including cookies and login sessions.

Q: What if cookies expire or have specific attributes like sameSite?

ANS: When loading cookies, you should check their expiry dates and potentially remove or adjust attributes like sameSite if they cause issues during the loading process. Pandas can help in checking expiry, and manual deletion of problematic attributes from the cookie dictionary before adding it back can resolve compatibility problems.

Q: Does Selenium save browser extensions and settings?

ANS: Using Chrome’s user-data-dir or manually managing Firefox profile directories can preserve extensions and settings. Simply pickling or saving cookies will not transfer these browser-level configurations.
