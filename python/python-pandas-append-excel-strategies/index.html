“Python Pandas Append DataFrame to Existing Excel Sheet Strategies”

How can a Python developer reliably append new data from a Pandas DataFrame into a worksheet of an existing Microsoft Excel file without overwriting prior content? Several effective methods exist, particularly with the evolution of the Pandas ExcelWriter in conjunction with openpyxl.

Pandas’ direct to_excel method often defaults to overwriting sheets unless specific configurations are used or workarounds are implemented, especially in older versions. We explore solutions ranging from native Pandas features to deeper interactions with openpyxl.

Modern Pandas Approach with if_sheet_exists (Pandas $\ge$ 1.4.0)

The Pandas development team introduced native support for appending directly, significantly simplifying this task starting with version 1.4.0. The key lies in the if_sheet_exists parameter within pd.ExcelWriter.

If you are using Pandas version 1.4.0 or newer, the overlay option is the simplest resolution:

import pandas as pd

# Assume 'df_new_data' is the DataFrame to append
# Assume 'data.xlsx' is the existing file
output_file = 'data.xlsx'

with pd.ExcelWriter(
    output_file,
    mode='a',  # Append mode
    engine='openpyxl',
    if_sheet_exists='overlay' # Write contents without removing old data
) as writer:
    # Pass header=False and index=False if you only want to append the data rows
    df_new_data.to_excel(writer, sheet_name='TargetSheet', index=False, header=False)

This approach is clean and leverages built-in functionality. For older Pandas versions, manual intervention or custom functions are necessary.

Workaround for Older Pandas Versions (Pre-1.4.0)

For environments restricted to Pandas versions below 1.4.0, appending while preserving styles and structure requires custom code that interacts directly with the underlying openpyxl workbook object.

One robust solution involves writing the new DataFrame to a temporary, newly created sheet and then programmatically copying the cells (including styles) from this new sheet to the target existing sheet before deleting the temporary sheet.

Here is a detailed helper function implementation tested against Pandas 1.3.2 and OpenPyXL 3.0.7:

def copy_excel_cell_range(
        src_ws: openpyxl.worksheet.worksheet.Worksheet,
        min_row: int = None,
        max_row: int = None,
        min_col: int = None,
        max_col: int = None,
        tgt_ws: openpyxl.worksheet.worksheet.Worksheet = None,
        tgt_min_row: int = 1,
        tgt_min_col: int = 1,
        with_style: bool = True
) -> openpyxl.worksheet.worksheet.Worksheet:
    """Copies cells including style attributes between worksheets."""
    if tgt_ws is None:
        tgt_ws = src_ws

    for row in src_ws.iter_rows(min_row=min_row, max_row=max_row,
                                min_col=min_col, max_col=max_col):
        for cell in row:
            tgt_cell = tgt_ws.cell(
                row=cell.row + tgt_min_row - 1,
                column=cell.col_idx + tgt_min_col - 1,
                value=cell.value
            )
            if with_style and cell.has_style:
                tgt_cell.font = copy(cell.font)
                tgt_cell.border = copy(cell.border)
                tgt_cell.fill = copy(cell.fill)
                tgt_cell.number_format = copy(cell.number_format)
                tgt_cell.protection = copy(cell.protection)
                tgt_cell.alignment = copy(cell.alignment)
    return tgt_ws

@param df: DataFrame to save to workbook
@param sheet_name: Name of sheet which will contain DataFrame.

@param fmt_float: Excel format for float numbers
@param fmt_date: Excel format for dates

    for cell in ws[column_letter]:
        cell.number_format = fmt
filename = Path(filename)
file_exists = filename.is_file()
# process parameters
# calculate first column number
# if the DF will be written using `index=True`, then `first_col = 2`, else `first_col = 1`
first_col = int(to_excel_kwargs.get("index", True)) + 1
# ignore [engine] parameter if it was passed

# save content of existing sheets

    sheet_names = wb.sheetnames
    sheet_exists = sheet_name in sheet_names
    sheets = {ws.title: ws for ws in wb.worksheets}

    filename.with_suffix(".xlsx"),
    engine="openpyxl",
    mode="a" if file_exists else "w",
    if_sheet_exists="new" if file_exists else None,
    date_format=fmt_date,
    datetime_format=fmt_datetime,
    storage_options=storage_options
) as writer:
    if file_exists:
        # try to open an existing workbook
        writer.book = wb
        # get the last row in the existing Excel sheet
        # if it was not specified explicitly
        if startrow is None and sheet_name in writer.book.sheetnames:
            startrow = writer.book[sheet_name].max_row
        # truncate sheet
        if truncate_sheet and sheet_name in writer.book.sheetnames:
            # index of [sheet_name] sheet
            idx = writer.book.sheetnames.index(sheet_name)
            # remove [sheet_name]
            writer.book.remove(writer.book.worksheets[idx])
            # create an empty sheet [sheet_name] using old index
            writer.book.create_sheet(sheet_name, idx)
        # copy existing sheets
        writer.sheets = sheets
    else:
        # file doesn't exist, we are creating a new one
        startrow = 0

    # write out the DataFrame to an ExcelWriter
    df.to_excel(writer, sheet_name=sheet_name, **to_excel_kwargs)
    worksheet = writer.sheets[sheet_name]

    if autofilter:
        worksheet.auto_filter.ref = worksheet.dimensions

    for xl_col_no, dtyp in enumerate(df.dtypes, first_col):
        col_no = xl_col_no - first_col
        width = max(df.iloc[:, col_no].astype(str).str.len().max(),
                    len(df.columns[col_no]) + 6)
        width = min(max_col_width, width)
        column_letter = get_column_letter(xl_col_no)
        worksheet.column_dimensions[column_letter].width = width
        if np.issubdtype(dtyp, np.integer):
            set_column_format(worksheet, column_letter, fmt_int)
        if np.issubdtype(dtyp, np.floating):
            set_column_format(worksheet, column_letter, fmt_float)

if file_exists and sheet_exists:
    # move (append) rows from new worksheet to the `sheet_name` worksheet
    wb = load_workbook(filename)
    # retrieve generated worksheet name
    new_sheet_name = set(wb.sheetnames) - set(sheet_names)
    if new_sheet_name:
        new_sheet_name = list(new_sheet_name)[0]
    # copy rows written by `df.to_excel(...)` to
    copy_excel_cell_range(
        src_ws=wb[new_sheet_name],
        tgt_ws=wb[sheet_name],
        tgt_min_row=startrow + 1,
        with_style=True
    )
    # remove new (generated by Pandas) worksheet
    del wb[new_sheet_name]
    wb.save(filename)
    wb.close()

Direct OpenPyXL Manipulation (Solution 3 & 10)

When you bypass Pandas’ ExcelWriter complexity and focus solely on openpyxl, you can load the workbook, target the specific sheet, and append rows directly using the sheet object’s .append() method. This method is excellent if you do not require Pandas to handle complex formatting or data type conversions during the append step, as it takes raw list data.

If you only care about the values (no styles):

import os
import openpyxl
import pandas as pd
from openpyxl.utils.dataframe import dataframe_to_rows

FILE_PATH = "manual_append.xlsx"
SHEET_NAME = 'MySheetName'
new_df = pd.DataFrame({'ID': [101, 102], 'Score': [95.5, 88.0]})

if os.path.isfile(FILE_PATH):
    workbook = openpyxl.load_workbook(FILE_PATH)
    if SHEET_NAME in workbook.sheetnames:
        sheet = workbook[SHEET_NAME]
        # Iterate over rows, excluding header/index if already present
        for row in dataframe_to_rows(new_df, header=False, index=False):
            sheet.append(row)
        workbook.save(FILE_PATH)
        workbook.close()
    else:
        print(f"Sheet '{SHEET_NAME}' not found for appending.")
else:
    print(f"File '{FILE_PATH}' does not exist. Creating new file.")
    with pd.ExcelWriter(path=FILE_PATH, engine='openpyxl') as writer:
        # Create the file with the first data set, including header
        new_df.to_excel(writer, index=False, sheet_name=SHEET_NAME)

The Quick Fix for mode='a' (Solution 4)

A common issue when using mode='a' with Pandas $\le 1.3$ was that writer.sheets dictionary remained empty or incomplete because Pandas didn’t correctly populate the reference to the existing sheets when opening in append mode.

A swift fix involves manually populating this dictionary after initializing the writer but before calling to_excel:

import pandas as pd
from openpyxl import load_workbook

XL_PATH = 'data_to_fix.xlsx'
df_to_add = pd.DataFrame({'X': [50], 'Y': [60]})

with pd.ExcelWriter(XL_PATH, 'openpyxl', mode='a') as writer:
    # Essential fix line: Manually populate writer.sheets from the loaded workbook
    writer.sheets = dict((ws.title, ws) for ws in writer.book.worksheets)
    
    # Now to_excel can correctly target the existing sheet
    df_to_add.to_excel(writer, sheet_name='ExistingSheet', index=False, header=False)

Appending to CSV Files (Alternative Format)

If the requirement is flexible and an Excel file is not strictly mandatory, appending to a CSV file is trivial using the 'a' mode in to_csv, which handles the header logic based on the file state:

import pandas as pd

CSV_FILE = 'appended_data.csv'
new_csv_df = pd.DataFrame({'Col1': [1], 'Col2': [2]})

def append_df_to_csv(path_file, df):
    # 'a+' opens for appending; creates file if it doesn't exist.
    with open(path_file, 'a+') as f:
        # Header is added only if the file pointer is at the beginning (f.tell() == 0)
        df.to_csv(f, header=f.tell() == 0, encoding='utf-8', index=False)

append_df_to_csv(CSV_FILE, new_csv_df)

Determining Start Row for Overlay (Solution 7 & 11)

When using if_sheet_exists="overlay", you must explicitly tell Pandas where to begin writing the new data using the startrow argument. This requires pre-calculating the current number of rows in the target sheet.

import os
import pandas as pd

EXCEL_FILE = "overlay_test.xlsx"
DATA_TO_SAVE = [[10, 'New Entry']]
df_append = pd.DataFrame(DATA_TO_SAVE, columns=["Column_A", "Column_B"])

if os.path.exists(EXCEL_FILE):
    # Load the file just to check the row count for the specific sheet
    # Note: pd.read_excel() reads the whole sheet by default
    try:
        existing_data = pd.read_excel(EXCEL_FILE, sheet_name='Sheet1')
        # Calculate the next available row index (0-based index + 1 = 1-based row number)
        start_row_index = existing_data.shape[0] + 1 
    except Exception:
        # Handle case where sheet might exist but is empty or unreadable by pd
        start_row_index = 0
        
    with pd.ExcelWriter(EXCEL_FILE, mode="a", engine="openpyxl", if_sheet_exists="overlay") as writer: 
        # Write new data starting at calculated row, ensuring no header is written
        df_append.to_excel(
            writer, 
            sheet_name='Sheet1', 
            index=False, 
            header=False, 
            startrow=start_row_index
        )
else:
    # Create file if it doesn't exist
    with pd.ExcelWriter(EXCEL_FILE, mode="w", engine='openpyxl') as writer:
        df_append.to_excel(writer, index=False, sheet_name='Sheet1')

FAQs on Python Pandas Append Excel Strategies

Q: What Pandas version introduced the simple if_sheet_exists overlay option

ANS: The ‘overlay’ option for if_sheet_exists was introduced in Pandas version 1.3.0 and explicitly added support in version 1.4.0 for appending without removing old contents.

Q: Should I use header=False when appending data

ANS: Yes, if the target sheet already contains headers from a previous write operation, set header=False to prevent duplicating column names in the Excel file.

Q: What is the primary alternative to using Pandas ExcelWriter

ANS: The primary alternative is direct manipulation using the openpyxl library to load the workbook, access the target worksheet object, and use the .append() method to add data rows.
