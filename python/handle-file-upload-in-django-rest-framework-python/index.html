Solved: Top 8 Methods to Handle File Upload in Django Rest Framework

Working with file uploads in Django Rest Framework (DRF) can seem daunting at first. Whether you’re building a standalone API or integrating with a frontend like Angular, this guide provides 8 detailed solutions to manage file uploads effectively.

Solution 1: Using pre_save Hook with ModelViewSet

This approach leverages DRF’s pre_save (deprecated in newer versions) to handle file uploads.

Django Code

# models.py
class Experiment(models.Model):
    notes = models.TextField(blank=True)
    samplesheet = models.FileField(blank=True, default='')
    user = models.ForeignKey(User, related_name='experiments')

## serializers.py
class ExperimentSerializer(serializers.ModelSerializer):
    class Meta:
        model = Experiment
        fields = ('id', 'notes', 'samplesheet', 'user')

## views.py
class ExperimentViewSet(viewsets.ModelViewSet):
    queryset = Experiment.objects.all()
    serializer_class = ExperimentSerializer

    def pre_save(self, obj):
        obj.samplesheet = self.request.FILES.get('file')

AngularJS Integration

Solution 2: APIView with File Parsing

This method uses APIView and FileUploadParser for handling uploads.

Django Code

from rest_framework.parsers import FileUploadParser
from rest_framework.views import APIView
from rest_framework.response import Response

class FileUploadView(APIView):
    parser_classes = (FileUploadParser, )

    def post(self, request, format='jpg'):
        file_obj = request.FILES['file']
        with open('/path/to/save/' + file_obj.name, 'wb+') as destination:
            for chunk in file_obj.chunks():
                destination.write(chunk)
        return Response(file_obj.name, status=201)

Solution 3: Minimal Approach with ModelViewSet

The simplest way to handle file uploads using DRF’s ModelViewSet.

Django Code

from rest_framework import serializers, viewsets
from django.db import models

class Photo(models.Model):
    file = models.ImageField()

class PhotoSerializer(serializers.ModelSerializer):
    class Meta:
        model = Photo
        fields = ('id', 'file')

class PhotoViewSet(viewsets.ModelViewSet):
    queryset = Photo.objects.all()
    serializer_class = PhotoSerializer

Upload via curl

curl -sS http://example.com/api/photos/ -F 'file=@/path/to/file'

Solution 4: Handling Nested Serializers with Multipart Parsing

For nested serializers, you may need custom parsing logic.

Custom Parser

from rest_framework.parsers import MultiPartParser
from django.http import QueryDict

class MultipartJsonParser(MultiPartParser):
    def parse(self, stream, media_type=None, parser_context=None):
        result = super().parse(stream, media_type, parser_context)
        data = result.data.get('data', {})
        querydict = QueryDict('', mutable=True)
        querydict.update(data)
        return parsers.DataAndFiles(querydict, result.files)

FAQs on Django Rest Framework File Upload

Q: How do I upload files using Django Rest Framework?

A: You can upload files using DRF by defining a file field in your model, setting up serializers, and handling the file through APIView or ModelViewSet.

Q: What is the purpose of `MultipartJsonParser`?

A: It is a custom parser to handle nested JSON fields in multipart form-data requests.

Q: How do I test file uploads in Postman?

A: Use Postman to send a POST request with the file attached to a form-data field. Specify the endpoint URL and required headers.
