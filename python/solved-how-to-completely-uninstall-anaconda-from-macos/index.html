Solved: How to Completely Uninstall Anaconda from macOS

How can one effectively and completely uninstall Anaconda from macOS, particularly if you’ve encountered issues with lingering elements of the platform? Many users find that even after attempting to remove Anaconda using the conda clean --all command, there are residual files and configurations that still hook into the system, resulting in the persistent use of Anaconda’s Python or the conda command. Below, we’ll explore several comprehensive solutions to ensure a thorough uninstallation.

Step-by-Step Solutions to Uninstall Anaconda on macOS

Solution 1: Manual Uninstallation via Terminal

To begin the uninstallation process, follow these steps in your terminal:

  1. Remove the Anaconda installation directory with the following command:

    rm -rf ~/anaconda

  2. Edit your shell’s configuration file – This could be .bash_profile, .bashrc, or .profile. Open the relevant file with a text editor (e.g., nano):

    nano ~/.bash_profile

    Look for any entries related to Anaconda and remove them.

  3. Eliminate residual hidden files potentially left in your home directory:

    rm -rf ~/.condarc ~/.conda ~/.continuum

Solution 2: Specific Paths for macOS Variants

It’s essential to note that installation paths can vary:

  • For users on macOS Big Sur or later, the Anaconda folder is commonly located at: 
    ~/opt/anaconda3

Solution 3: Installing the Anaconda Cleaner

The Anaconda-clean utility can help with this process:

  1. Install Anaconda-clean:

    conda install anaconda-clean

  2. Activate the base environment:

    source ~/anaconda3/bin/activate

  3. Run the cleaner to remove configuration files:

    anaconda-clean --yes

  4. Deactivate the environment:

    conda deactivate

  5. Remove the installation folder:

    rm -rf ~/anaconda3 ~/.anaconda_backup

Solution 4: Locate Anaconda with which

If unsure where Anaconda is installed, you can locate it with:

which anaconda

This command will give you the exact path. Use that path to delete the directory.

Solution 5: Removing from Python in General

To ensure complete removal, use the following command:

rm -rf ~/anaconda3

Followed by:

conda uninstall

Find more on the Conda Uninstall Documentation .

Alternative Methods and Tips

  • If you’ve altered environment variables like PYTHONPATH, make sure to:
unset PYTHONPATH
unset PYTHONHOME

  • Check for other shell configuration files, such as .zshrc, and remove any Anaconda references found.

  • If remnants persist after these steps, a simple system restart may be necessary for your changes to take effect.

The comprehensive approach above should assist in effectively uninstalling Anaconda from your macOS system and restoring your original Python configuration.

FAQs on Completely Uninstalling Anaconda from macOS

Q: What commands should I run to uninstall Anaconda from macOS?

A: You can run the command rm -rf ~/anaconda3 or rm -rf ~/opt/anaconda3, depending on your installation. Additionally, use anaconda-clean --yes to remove configuration files.

Q: How do I know where Anaconda is installed?

A: Use the command which anaconda in terminal to find the exact installation path of Anaconda.

Q: Are there any visible signs that Anaconda is still installed?

A: If you’re still able to run conda commands or if the Anaconda Python interpreter responds, it suggests that remnants of the installation remain.

Q: What if the uninstallation steps don’t solve my issue?

A: Try to check your shell configuration files for any remaining entries. Restarting your system can also help apply the changes.
