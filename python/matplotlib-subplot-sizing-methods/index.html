“Matplotlib Subplot Sizing: Methods for Ratio Control in Matplotlib”

How does one precisely dictate the relative widths and heights of subplots when creating figures in Python’s Matplotlib library? Adjusting these ratios is key for effective data visualization layouts. Several methods exist, leveraging newer features or established tools like GridSpec.

Method 1: Direct Ratio Specification in plt.subplots (Matplotlib 3.6.0+)

Since Matplotlib version 3.6.0, setting the aspect ratios for figures generated via plt.subplots() or plt.subplot_mosaic() has become more direct by passing width_ratios or height_ratios as keyword arguments.

For controlling column widths in a row layout:

import numpy as np
import matplotlib.pyplot as plt 

# Generate example data
x_data = np.arange(0, 10, 0.2)
y_data = np.sin(x_data)

# Create two subplots side-by-side with widths ratio 3:1
fig_1, (ax_main, ax_side) = plt.subplots(1, 2, width_ratios=[3, 1])
ax_main.plot(x_data, y_data, label='Sine Wave')
ax_side.plot(y_data, x_data, label='Inverted')

fig_1.suptitle("Horizontal Ratios Set Directly (3:1)")
fig_1.tight_layout()
# fig_1.savefig('ratio_figure_direct.png') 
plt.show()

For controlling row heights in a column layout:

# Create three subplots stacked vertically with heights ratio 1:1:3
fig_2, (ax_top, ax_mid, ax_bottom) = plt.subplots(3, 1, height_ratios=[1, 1, 3])

ax_top.plot(x_data, y_data)
ax_mid.plot(x_data, y_data**2)
ax_bottom.plot(x_data, np.cos(x_data))

fig_2.suptitle("Vertical Ratios Set Directly (1:1:3)")
fig_2.tight_layout()
plt.show()

Method 2: Utilizing gridspec_kw with plt.subplots

An earlier, widely compatible approach involves passing the ratio specifications via the gridspec_kw dictionary to the plt.subplots function. This hooks into the underlying GridSpec configuration.

Example using width_ratios:

import numpy as np
import matplotlib.pyplot as plt 

x_data = np.arange(0, 10, 0.2)
y_data = np.sin(x_data)

# Plotting with GridSpec keyword arguments for width ratios
fig_gs, (a0_gs, a1_gs) = plt.subplots(1, 2, gridspec_kw={'width_ratios': [3, 1]})
a0_gs.plot(x_data, y_data)
a1_gs.plot(y_data, x_data)

fig_gs.suptitle("Using gridspec_kw for Width Ratios")
fig_gs.tight_layout()
# fig_gs.savefig('grid_figure_kw.pdf')
plt.show()

Example using height_ratios:

# Plotting with GridSpec keyword arguments for height ratios
fig_h_gs, (b0_gs, b1_gs, b2_gs) = plt.subplots(3, 1, gridspec_kw={'height_ratios': [1, 1, 3]})

b0_gs.plot(x_data, y_data, 'r-')
b1_gs.plot(x_data, y_data, 'g-')
b2_gs.plot(x_data, y_data, 'b-')

fig_h_gs.suptitle("Using gridspec_kw for Height Ratios")
fig_h_gs.tight_layout()
plt.show()

Method 3: Explicit matplotlib.gridspec.GridSpec Initialization

For maximum control, especially when subplots might span multiple grid cells, initializing GridSpec separately offers flexibility. You define the grid structure and then assign axes to specific locations within that grid.

import numpy as np
import matplotlib.pyplot as plt 
from matplotlib import gridspec

x_data = np.arange(0, 10, 0.2)
y_data = np.sin(x_data)

# Create figure and GridSpec object with specified width ratios
fig_explicit = plt.figure(figsize=(8, 6)) 
gs_explicit = gridspec.GridSpec(1, 2, width_ratios=[3, 1]) 

# Assign subplots based on the GridSpec indices
ax0_explicit = plt.subplot(gs_explicit[0])
ax0_explicit.plot(x_data, y_data)

ax1_explicit = plt.subplot(gs_explicit[1])
ax1_explicit.plot(y_data, x_data)

fig_explicit.suptitle("Explicit GridSpec Initialization")
plt.tight_layout()
# plt.savefig('grid_figure_explicit.pdf')
plt.show()

Method 4: Simple Subplot Indexing (Less Precise Ratio Control)

While not directly controlling ratios, you can utilize sequential indexing in plt.subplot() to create complex, non-uniform layouts. The size difference is implied by how many indices an axis occupies within the grid definition.

plt.figure(figsize=(12, 6))

# Defining a 2x3 grid conceptually
ax1 = plt.subplot(2, 3, 1) # Top-left 1/6th area
ax2 = plt.subplot(2, 3, 2) # Top-middle 1/6th area
ax3 = plt.subplot(2, 3, 3) # Top-right 1/6th area

# This axis spans the entire second row (2/3rds of the figure area)
ax4 = plt.subplot(2, 1, 2) 

axes_list = [ax1, ax2, ax3, ax4]

for ax in axes_list:
    ax.set_xticks([])
    ax.set_yticks([])

plt.suptitle("Complex Layout via Sequential Subplot Indexing")
plt.show()

Method 5: Manual Axis Placement with Rectangles (plt.axes)

For absolute positioning and dimension definition, manual placement using coordinates relative to the figure dimensions (normalized from 0 to 1) via plt.axes() is an option. This requires defining the bounding box [left, bottom, width, height].

import matplotlib.pyplot as plt
import numpy as np

x_data = np.arange(0, 10, 0.2)
y_data = np.sin(x_data)

# Define normalized coordinates for two distinct axes
left_main, width_main = 0.07, 0.65
left_side, width_side = left_main + width_main + 0.02, 0.17 # Positioned to the right of main plot
bottom_y, height_y = 0.1, .8

rect_main = [left_main, bottom_y, width_main, height_y]
rect_side = [left_side, bottom_y, width_side, height_y]

fig_manual = plt.figure()

# Create axes objects using the defined rectangles
cones_ax = plt.axes(rect_main)
box_ax = plt.axes(rect_side)

cones_ax.plot(x_data, y_data, 'c-')
cones_ax.set_title("Main Plot")

box_ax.plot(y_data, x_data, 'm-')
box_ax.set_title("Side Plot")

plt.show()

Method 6: The subplot_mosaic Function (ASCII Art Layouts)

Introduced in Matplotlib 3.3.0, subplot_mosaic offers an intuitive way to define complex layouts using string definitions resembling ASCII art. Ratios are implicitly handled based on the grid structure defined.

Defining the layout using character keys:

# Layout: A and B share the top row, D spans the entire bottom row
mosaic_layout = "ABC;DDD" 

fig_mosaic, axes_dict = plt.subplot_mosaic(mosaic_layout)

# Accessing axes via their defined keys (A, B, C, D)
axes_dict["A"].plot([1, 2, 3], [1, 2, 3], 'o-')
axes_dict["B"].bar(['X', 'Y', 'Z'], [5, 8, 2])
axes_dict["D"].scatter(np.random.rand(10), np.random.rand(10))

fig_mosaic.suptitle("Layout Defined via subplot_mosaic String")
plt.tight_layout()
plt.show()

If descriptive names are preferred, a list of lists structure can be used instead of the string:

mosaic_layout_list = [
    ["TL", "TC", "TR"],
    ["Bottom", "Bottom", "Bottom"]
]

fig_list, axes_dict_list = plt.subplot_mosaic(mosaic_layout_list)

axes_dict_list["TL"].plot([10, 20], [5, 15], 'k--')
axes_dict_list["Bottom"].plot([0, 1], [1, 0])

fig_list.suptitle("Layout Defined via subplot_mosaic List Structure")
plt.tight_layout()
plt.show()

Method 7: Advanced GridSpec Configuration with add_gridspec

When creating the figure first, you can explicitly build the grid specification structure, specifying ratios within the add_gridspec call, and then assign axes to slices of this grid. This offers granular control over both row and column proportions simultaneously.

import matplotlib.pyplot as plt

# Setup figure
fig_adv = plt.figure(figsize=(7, 5))

# Define a 2x2 grid where the first column is half the width of the second column
gs_adv = fig_adv.add_gridspec(2, 2, width_ratios=[1, 2])

# Assign subplots using grid slicing notation
ax0_adv = fig_adv.add_subplot(gs_adv[:, 0]) # Spans both rows, first column
ax1_adv = fig_adv.add_subplot(gs_adv[0, 1]) # Top row, second column
ax2_adv = fig_adv.add_subplot(gs_adv[1, 1]) # Bottom row, second column

ax0_adv.set_title("Ratio 1 (Vertical)")
ax1_adv.set_title("Ratio 2 (Top Right)")
ax2_adv.set_title("Ratio 2 (Bottom Right)")

fig_adv.tight_layout()
plt.show()

FAQs on Matplotlib Subplot Sizing Methods

Q: What is the minimum Matplotlib version needed for direct width_ratios support in plt subplots

ANS: Direct support for width_ratios and height_ratios as direct keywords in plt.subplots was introduced in Matplotlib version 3.6.0.

Q: How do I make one subplot twice as wide as another using GridSpec

ANS: You define the grid with width_ratios=[1, 2] when creating the GridSpec object or calling plt.subplots. The second subplot will occupy twice the horizontal space of the first.

Q: Can subplot_mosaic handle non-rectangular layouts

ANS: Yes, subplot_mosaic is specifically designed for creating complex, often non-rectangular-looking layouts using character-based definitions like the one shown: “ABC;DDD”.

Q: What is the difference between plt axes and plt subplot

ANS: plt.subplot() is a convenience function that often works with GridSpec implicitly or explicitly. plt.axes() is the lower-level method used to create axes at a specific, manually defined bounding box rectangle relative to the figure size, as shown in Method 5.

import numpy as np
import matplotlib.pyplot as plt 

# generate some data
x = np.arange(0, 10, 0.2)
y = np.sin(x)

# plot it
f, (a0, a1) = plt.subplots(1, 2, gridspec_kw={'width_ratios': [3, 1]})
a0.plot(x, y)
a1.plot(y, x)

f.tight_layout()
f.savefig('grid_figure.pdf')
# plot it
f, (a0, a1, a2) = plt.subplots(3, 1, gridspec_kw={'height_ratios': [1, 1, 3]})

a0.plot(x, y)
a1.plot(x, y)
a2.plot(x, y)

f.tight_layout()
