Background: My Configuration

To begin with, I’m currently using the following environment:

  • Operating System: macOS v10.14 (Mojave)
  • Python Version: 3.7.1
  • Visual Studio Code Version: 1.30
  • Pylint Version: 2.2.2
  • Django Version: 2.1.4

Despite my careful setup to leverage linting tools in Visual Studio Code, I’ve encountered a persistent “unresolved import” message across all import statements—even the standard Django modules like from django.db import models. This seems to stem from the fact that the IDE isn’t recognizing the Python files in my virtual environment. Although everything functions as intended, it’s frustrating to consistently see these warnings.

Why Am I Facing This Issue?

An apparent reason for this problem is that my Python interpreter choices only include system versions, with my virtual environment not being recognized since it isn’t located within my workspace directory. Directly modifying the settings.json file to include python.PythonPath has proven ineffective as it does not display the virtual environment path.

Tactics for Resolution

Here’s a detailed compilation of methods I’ve explored to resolve the “unresolved import” issue:

Method 1: Configure Python Path in Workspace Settings

To begin resolving the issue, modify your workspace settings to explicitly set the Python path:

{
  "python.defaultInterpreterPath": "/path/to/your/venv/bin/python"
}

Read more about workspace settings .

Method 2: Utilize Command Interface

A quick approach can be your friend! Use the command palette:

Press Cmd or Ctrl + Shift + P, and select Python: Select Interpreter. Pick the interpreter linked to your desired packages.

Method 3: Create a .env File

It’s beneficial to create a .env file in your project root and specify the Python path. Your .env file could look like this:

PYTHONPATH=YOUR/MODULES/PATH

Then add this line to settings.json:

"python.envFile": ".env"

Method 4: Reload Window

Sometimes a simple window reload does the trick:

Run the command > reload window. This is noted as a workaround in the GitHub issue discussions .

Method 5: Select Interpreter from Status Bar

Click on the Python version displayed in the status bar at the bottom of Visual Studio Code and select the corresponding virtual environment interpreter directly from the options.

Method 6: Switch Language Server to Jedi

A striking solution for many users is to switch the language server:

"python.languageServer": "Jedi"

This alteration has resolved the individual import issues for various users.

Method 7: Update Settings for Jedi

In the settings.json file, it’s critical to ensure Jedi is enabled:

"python.jediEnabled": true

This step is acknowledged as vital for users who had previously disabled Jedi.

Method 8: Manage Import Errors in Settings

For those visually inclined, navigate through VS Code menus:

File → Preferences → Settings (Ctrl + ,). Under Extensions → Python, locate the section for Analysis: Disabled and add the error suppression for unresolved-import.

Alternative Approaches

If your project demands specific structures or reliance on external modules, you may need to tweak your workspace settings further. Consider organizing your module paths:

"python.analysis.extraPaths": ["dir_1", "dir_2"]

This configuration directly influences which directories Pylint checks for module imports.

Feedback Requested

I would love to know if any of these techniques work for you or if you find additional methods that help resolve the unresolved import error in Visual Studio Code. Please share your insights or experiences in the comments below.

FAQs on How to Fix Pylint Unresolved Import Error

Q: What should I do if none of the solutions work?

A: Ensure that your virtual environment is active and try resetting your workspace settings. Additionally, make sure packages are installed in the correct environment using pip.

Q: How can I ensure Visual Studio Code acknowledges my virtual environment?

A: Ensure that your virtual environment is properly activated and try to re-select it in the interpreter settings. Confirm the path in your settings.json.

Q: Is the 'unresolved import' error a common issue?

A: Yes, many developers encounter this issue, especially when working with virtual environments and project setups that do not align with VS Code’s recognized paths.

For further reading and resources, check out the Visual Studio Code Documentation or Pylint Documentation .
