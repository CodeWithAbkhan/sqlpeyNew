When you’re working with Python, knowing which version you have installed is vital for compatibility reasons, especially when running scripts or utilizing libraries that may depend on specific features present in certain versions. Whether you’re on Windows, Linux, or using Windows Subsystem for Linux (WSL), there are various methods to check your Python version effectively. Here, we’ll explore 10 distinct methods to easily resolve the question: Which version of Python do I have installed?

Method 1: Check Python Version in an IDE

If you’re using a Python IDE, you can easily check the version by copying and pasting the following code snippet:

import sys
print(sys.version)

This will display the complete version information, including minor details about the build.

Method 2: Command Line for Python 2.5 and Above

For systems running Python 2.5 or later, simply enter the following command in your command prompt or terminal:

python --version

For older versions (e.g., Python 2.4), you might need:

python -c 'import sys; print(sys.version)'

Method 3: Use the Python Version Command

At your command prompt, type:

python -V

If you have the pyenv tool installed, you can also list all installed versions by using:

pyenv versions

Method 4: Find All Installed Python Versions

To check if multiple versions of Python are installed, especially critical if you want to avoid conflicts when installing additional packages, run the following command:

updatedb   # Execute from root
locate site.py

This will return paths of all installed versions of Python.

Method 5: Opening Python Command Line

When you launch the Python command line interface, the first thing it displays is the version. You can do this by running:

python

Method 6: Check Version in Python Interactive Shell

Using the Python interactive environment, you can run:

import sys
print(sys.version_info)

This allows you to break down the version into major, minor, and micro components.

Method 7: Using Jupyter Notebook

If you’re operating within Jupyter Notebook, you can check the Python version with:

from platform import python_version
print(python_version())

Or provide more detailed information with:

import sys
print(sys.version)

Method 8: Utilize the py Command

For Windows users, the py launcher is an efficient way to check your installed Python versions. To find the Python version, execute:

py --version

or just:

py -V

Method 9: Locate Multiple Python Executables

To find where Python is installed, type the following in your command prompt:

where python

This will return paths indicating where different versions of Python are located, assuming they’re included in your system’s PATH variable.

Method 10: Running a Python Script

If you prefer a programmatic way to retrieve detailed version information, create a Python script with:

#!/usr/bin/env python3

import platform
import sys

print(f"Python version: {sys.version}")
print(f"Platform: {platform.platform()}")

You can run this script and gain insights into the version and system details.

Alternative Methods

If you cannot run commands due to environment configurations or restrictions, searching through installed programs using your system’s file explorer is another option. Just search for python.exe in your installed directories and review the file properties.

Example of Practical Use:
If you want to determine the exact version of Python before installing a framework like Django, knowing whether you’re running Python 2.x or 3.x could affect your installation process.

FAQs on Top 10 Methods to Check Which Version of Python Is Installed

Q: What should I do if I have multiple versions of Python installed?

A: If you find multiple versions of Python installed, consider using virtual environments (like venv or conda) to manage them effectively. This will prevent conflicts between installations.

Q: Do I need administrative rights to check Python versions?

A: Generally, you do not need administrative rights to check the installed versions of Python using command-line methods, but certain configurations on a managed system may require permissions.

Q: How do I add Python to my PATH variable?

A: You can follow guides like this one to add Python to your PATH variable on Windows, allowing you to execute Python commands from any command prompt.
