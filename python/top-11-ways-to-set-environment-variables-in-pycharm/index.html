Setting Environment Variables in PyCharm: A Comprehensive Guide

As you begin your journey with a Django project or any Python development, there’s often a need to manage environment variables efficiently without resorting to manual setups or cumbersome bash scripts. Let’s explore 11 powerful methods that can streamline your workflow in PyCharm by setting environment variables.

Method 1: Using the EnvFile Plugin

One effective way to manage your environment variables is through the EnvFile plugin . This plugin allows you to source variables directly from files associated with your run configurations.

  1. Installation Steps:

    • Navigate to Preferences > Plugins > Browse repositories….
    • Search for “Env File” and install the plugin.

  2. Creating an Environment File:

    • Add a file named environment.env in your project root with the following content: 
      DATABASE_URL=postgres://127.0.0.1:5432/my_db_name
DEBUG=1

  3. Configuring Run Settings:

    • Go to Run > Edit Configurations.
    • Select your run configuration and set it to use environment.env.

Method 2: Accessing Multiple Configuration Areas

Environment variables can also be set in several other locations in PyCharm. Here are key areas to check:

  • Tools > Terminal > Environment variables: Set variables specific to the terminal.
  • Languages & Frameworks > Django > Environment Variables: Add Django-specific configurations.
  • Build, Execution, Deployment > Console > Python Console/Django Console: Specify console environment settings.
  • Your run/debug configurations as previously mentioned.

Method 3: Built-in EnvFile Tab

Starting from PyCharm 2018.3, managing environment variables became more intuitive:

  • In your run configuration, find the EnvFile tab.
  • Click Enable EnvFile and add your .env file.

Method 4: Using python-dotenv

To load environment variables from a .env or .flaskenv file into your console environment:

  1. Install the package:

    pip install python-dotenv

  2. Modify your settings:

    • Go to Settings > Build, Execution, Deployment > Console > Flask/Django Console.

  3. Add the following code to the starting script:

    from dotenv import load_dotenv
load_dotenv(verbose=True)

Method 5: Pasting Variables Directly in Configurations

If you have multiple environment variables to set:

  1. Copy your variables to clipboard.
  2. Go to Edit Configurations > Environment Variables.
  3. Click the paste icon, and voilà! Your variables are now available.

Method 6: Adjusting Configuration Templates

To ensure that certain environment variables are set for all future run configurations:

  1. Access Edit Configurations.
  2. Click Edit the configuration templates in the panel.
  3. Set the desired environment variables there.

Method 7: Loading Variables from a .env File

You can load environment variables conveniently within your Python scripts as follows:

  1. Create a .env file in your project root:

    SECRET_KEY=your_secret_value

  2. Load it in your script:

    import os
from dotenv import load_dotenv, find_dotenv

load_dotenv(find_dotenv())
secret_value = os.getenv("SECRET_KEY")

Method 8: Setting Variables in Windows Terminal

For users on Windows, you can use the terminal to set environment variables rather than through PyCharm:

setx YOUR_VAR "VALUE"

Access it within your scripts through:

import os
value = os.environ['YOUR_VAR']

Method 9: Using a Custom Script for Virtual Environments

Leverage a custom script to handle environment variables more dynamically, especially if you are in a virtual environment. Here’s an example script:

#!/bin/bash
DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
export VAR1="TEST1"
source $DIR/../../.env
$DIR/python "$@"

Method 10: Editing the Virtual Environment Activation Script

You can streamline environment variable settings by appending them to the activate script in your virtual environment:

export $(grep -v '^#' .env | xargs)

Method 11: Directly Inserting Variables in the PyCharm Console

In the PyCharm Python console, you can initialize variables directly:

ENV_VAR_NAME="your_string_variable"
INT_VAR_NAME=5

Here, there is no need to prefix with export as you might with a typical shell.

### FAQs on Top 11 Ways to Set Environment Variables in PyCharm

Q: How do I install the EnvFile plugin?

A: To install the EnvFile plugin, go to Preferences > Plugins > Browse repositories…, search for “Env File”, and click Install Plugin.

Q: Can I use .env files with Django?

A: Yes, you can use the python-dotenv package to load .env files in your Django project. Make sure to install it via pip and import it in your settings or entry files.

Q: How can I set environment variables for all configurations?

A: To set environment variables for all configurations, go to Edit Configurations, click Edit the configuration templates, and define your variables there.
