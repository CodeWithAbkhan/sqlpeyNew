How to Convert Pandas Object Dtype to Int: Top 2 Methods

When working with data in Pandas, you may encounter scenarios where your DataFrame columns are classified as dtype ‘object’, even though they contain numerical values or dates. This situation can arise, particularly when you read data from SQL queries. A common challenge that developers face is converting these ‘object’ dtypes to integers or other appropriate types without running into errors.

In this post, we’ll explore how to resolve these datatype issues when loading data into Pandas and provide practical code examples.

The Challenge

Below is a typical scenario where you may read a SQL query into Pandas, resulting in a DataFrame where numeric data is stored as object dtype:

import pandas as pd

## Simulating a read_sql_query function call
# Example DataFrame
data = {
    'id': ['1', '2', '3', '4'],
    'date': ['2016-05-22', '2016-05-29', '2016-05-22', '2016-05-22'],
    'purchase': ['1', '0', '2', '0']
}
df = pd.DataFrame(data)
print(df.dtypes)

You can see that despite containing numeric values, the DataFrame’s dtypes show ‘object’:

id          object
date        object
purchase    object
dtype: object

Converting Object Dtypes to Integer

Solution 1: Sequential Conversion

To convert the ‘purchase’ column from an object to an integer, one effective method is to first convert it to a string and then to an integer. Here’s how you can do it:

df['purchase'] = df['purchase'].astype(str).astype(int)
print(df['purchase'].dtypes)  # Output: int64

This method prevents errors related to type conversion while ensuring that each value is appropriately handled.

Solution 2: Utilizing convert_dtypes (Pandas >= 1.0)

For those using a version of Pandas greater than or equal to 1.0, the convert_dtypes method can be beneficial, especially when dealing with columns that contain NaN values. Here’s an example:

import numpy as np

## Creating a DataFrame with NaN values
df_with_nan = pd.DataFrame({
    'purchase': [1, 2, np.nan],
}, dtype=object)

## Converting dtypes
df_with_nan = df_with_nan.convert_dtypes()
print(df_with_nan.dtypes)  # Output: Int64 (nullable integer)

convert_dtypes intelligently manages the presence of NaN values and assigns the proper nullable dtypes.

Handling Non-Numeric Values

If your data includes invalid entries that cannot be converted to numbers, use pd.to_numeric as an initial step:

s = pd.Series(['1', '2', 'junk'])
# Coerce non-numeric values to NaNs
s_numeric = pd.to_numeric(s, errors='coerce')
print(s_numeric)
# Finally, convert to nullable integer dtype
final_result = s_numeric.convert_dtypes()
print(final_result)  # Output: Int64

This approach ensures that any non-numeric values do not cause type conversion errors and are handled gracefully.

FAQs on Top 2 Methods to Convert Pandas Object Dtype to Int

Q: How can I convert a Pandas DataFrame column from object to integer?

A: You can convert a DataFrame column from object to integer by first converting it to a string with astype(str) and then to an integer with astype(int). For example: df['column_name'] = df['column_name'].astype(str).astype(int).

Q: What if my column has NaN values?

A: For columns containing NaN values, use the convert_dtypes() method if using Pandas version >= 1.0 to handle them seamlessly. If older, convert the column to numeric using pd.to_numeric(..., errors='coerce').
