“Pandas Filter DataFrame Rows by List Values”

When working with data in Python using the Pandas library, a common task involves selecting rows from a DataFrame where a specific column’s values match any of those in a predefined list. This process is crucial for data cleaning, analysis, and preparation. Several effective methods exist to achieve this, each with its own nuances and performance characteristics. Let’s explore these techniques with practical examples.

Consider a sample Pandas DataFrame:

import pandas as pd

# Create the DataFrame
df = pd.DataFrame({'A': [5, 6, 3, 4], 'B': [1, 2, 3, 5]})

# Display the initial DataFrame
print("Original DataFrame:")
print(df)

This will output:

Original DataFrame:
   A  B
0  5  1
1  6  2
2  3  3
3  4  5

Now, let’s look at how to filter this DataFrame to select rows where the values in column ‘A’ are either 3 or 6.

Method 1: Using isin()

The isin() method is a straightforward and highly efficient way to check for membership in a list.

To select rows where ‘A’ is in the list [3, 6]:

list_of_values = [3, 6]
filtered_df_isin = df[df['A'].isin(list_of_values)]
print("\nFiltered DataFrame using isin():")
print(filtered_df_isin)

Output:

Filtered DataFrame using isin():
   A  B
1  6  2
2  3  3

To select rows where ‘A’ is NOT in the list [3, 6]:

You can use the tilde ~ operator to negate the condition.

filtered_df_not_isin = df[~df['A'].isin(list_of_values)]
print("\nFiltered DataFrame using ~isin():")
print(filtered_df_not_isin)

Output:

Filtered DataFrame using ~isin():
   A  B
0  5  1
3  4  5

Method 2: Using query()

The query() method offers a more readable, SQL-like syntax for filtering DataFrames.

To select rows where ‘A’ is in the list [6, 3]:

filtered_df_query = df.query('A in [6, 3]')
print("\nFiltered DataFrame using query('A in [6, 3]'):")
print(filtered_df_query)

Output:

Filtered DataFrame using query('A in [6, 3]'):
   A  B
1  6  2
2  3  3

Using a variable with query():

You can reference local variables within the query() string using the @ symbol.

list_for_query = [6, 3]
filtered_df_query_var = df.query('A in @list_for_query')
print("\nFiltered DataFrame using query('A in @list_for_query'):")
print(filtered_df_query_var)

Output:

Filtered DataFrame using query('A in @list_for_query'):
   A  B
1  6  2
2  3  3

Method 3: Using query() with isin() for Complex Conditions

The query() method can also call isin() directly, which is useful for more complex filtering expressions.

list_for_nested_query = [3, 6]
filtered_df_nested_query = df.query("A.isin(@list_for_nested_query)")
print("\nFiltered DataFrame using query('A.isin(@list_for_nested_query)'):")
print(filtered_df_nested_query)

Output:

Filtered DataFrame using query('A.isin(@list_for_nested_query)'):
   A  B
1  6  2
2  3  3

You can also pass a dictionary of variables to query() using the local_dict argument.

filtered_df_query_local_dict = df.query("A == @my_list", local_dict={'my_list': [3, 6]})
print("\nFiltered DataFrame using query with local_dict:")
print(filtered_df_query_local_dict)

Output:

Filtered DataFrame using query with local_dict:
   A  B
1  6  2
2  3  3

Method 4: Filtering within a Range

If your list represents a contiguous range of values, between() or a range condition in query() are efficient alternatives.

Using between():

range_values = [3, 6] # Represents the range from 3 to 6 inclusive
filtered_df_between = df[df['A'].between(range_values[0], range_values[1])]
print("\nFiltered DataFrame using between(3, 6):")
print(filtered_df_between)

Output:

Filtered DataFrame using between(3, 6):
   A  B
1  6  2
2  3  3
3  4  5

Using query() for a range:

filtered_df_query_range = df.query('3 <= A <= 6')
print("\nFiltered DataFrame using query('3 <= A <= 6'):")
print(filtered_df_query_range)

Output:

Filtered DataFrame using query('3 <= A <= 6'):
   A  B
1  6  2
2  3  3
3  4  5

Method 5: Ordering Results by the List

If the order of the output DataFrame matters and should match the order of your list, you can use .loc after setting the index.

order_list = [3, 6]
ordered_filtered_df = df.set_index('A').loc[order_list].reset_index()
print("\nFiltered DataFrame ordered by list [3, 6]:")
print(ordered_filtered_df)

Output:

Filtered DataFrame ordered by list [3, 6]:
   A  B
0  3  3
1  6  2

To preserve the original index while ordering, a more involved .loc operation is needed:

order_list_with_duplicates = [3, 6, 3]
ordered_filtered_df_preserve_index = df.reset_index().set_index('A').loc[order_list_with_duplicates].reset_index().set_index('index').rename_axis(None)
print("\nFiltered DataFrame ordered by list [3, 6, 3] (preserving original index):")
print(ordered_filtered_df_preserve_index)

Output:

Filtered DataFrame ordered by list [3, 6, 3] (preserving original index):
   A  B
2  3  3
1  6  2
2  3  3

Method 6: Filtering Based on a Function of a Column

When you need to filter based on a calculation applied to a column, isin() and query() can still be used effectively.

list_for_func = [3, 6]

# Using isin() with a calculation
filtered_df_func_isin = df[(2 * df['A'] - 5).isin(list_for_func)]
print("\nFiltered DataFrame using (2*A - 5).isin([3, 6]):")
print(filtered_df_func_isin)

# Using query() with a calculation
filtered_df_func_query = df.query("(A*2 - 5) in @list_for_func")
print("\nFiltered DataFrame using query('(A*2 - 5) in [3, 6]'):")
print(filtered_df_func_query)

Output:

Filtered DataFrame using (2*A - 5).isin([3, 6]):
   A  B
1  6  2
2  3  3

Filtered DataFrame using query('(A*2 - 5) in [3, 6]'):
   A  B
1  6  2
2  3  3

Method 7: Selecting Rows Not in a List

As demonstrated earlier, negating the isin() condition or using not in with query() achieves this.

list_to_exclude = [3, 6]

# Using ~isin()
filtered_df_exclude_isin = df[~df['A'].isin(list_to_exclude)]
print("\nFiltered DataFrame excluding [3, 6] using ~isin():")
print(filtered_df_exclude_isin)

# Using query() with 'not in'
filtered_df_exclude_query = df.query("A not in @list_to_exclude")
print("\nFiltered DataFrame excluding [3, 6] using query('A not in @list_to_exclude'):")
print(filtered_df_exclude_query)

Output:

Filtered DataFrame excluding [3, 6] using ~isin():
   A  B
0  5  1
3  4  5

Filtered DataFrame excluding [3, 6] using query('A not in @list_to_exclude'):
   A  B
0  5  1
3  4  5

Method 8: Filtering Based on Multiple Columns

To filter rows where values in any of several columns are present in the list, use .any(1). For rows where values in all specified columns are in the list, use .all(1).

At least one column (‘A’ or ‘B’) is in the list [3, 6]:

list_multi_col = [3, 6]
filtered_df_any = df[df[['A', 'B']].isin(list_multi_col).any(1)]
print("\nFiltered DataFrame where A or B is in [3, 6] (using any()):")
print(filtered_df_any)

filtered_df_any_query = df.query("A in @list_multi_col or B in @list_multi_col")
print("\nFiltered DataFrame where A or B is in [3, 6] (using query or):")
print(filtered_df_any_query)

Output:

Filtered DataFrame where A or B is in [3, 6] (using any()):
   A  B
1  6  2
2  3  3
3  4  5

Filtered DataFrame where A or B is in [3, 6] (using query or):
   A  B
1  6  2
2  3  3
3  4  5

Both columns (‘A’ and ‘B’) are in the list [3, 6]:

filtered_df_all = df[df[['A', 'B']].isin(list_multi_col).all(1)]
print("\nFiltered DataFrame where A and B are in [3, 6] (using all()):")
print(filtered_df_all)

filtered_df_all_query = df.query("A in @list_multi_col and B in @list_multi_col")
print("\nFiltered DataFrame where A and B are in [3, 6] (using query and):")
print(filtered_df_all_query)

Output:

Filtered DataFrame where A and B are in [3, 6] (using all()):
   A  B
2  3  3

Filtered DataFrame where A and B are in [3, 6] (using query and):
   A  B
2  3  3

Method 9: Non-Pandas Set Operation

For scenarios where you only need the values from the column that are not in the list, a set difference can be used, though this doesn’t return a DataFrame.

list_to_exclude_set = [3, 6]
filtered_column_values = set(df['A']) - set(list_to_exclude_set)
print("\nValues in column 'A' not in [3, 6] (using set difference):")
print(filtered_column_values)

Output:

Values in column 'A' not in [3, 6] (using set difference):
{4, 5}

Important Considerations: Data Types

When performing these filtering operations, ensure that the data type (dtype) of the column you are filtering and the data type of the values in your list are compatible. Mismatched dtypes can lead to unexpected results or errors. For instance, comparing an integer column with a list of strings might not work as intended.

Method 10: Using apply() (Generally Slower)

While isin() and query() are preferred for performance, the apply() method can also achieve filtering, especially when the condition involves more complex logic that is easier to express in a lambda function. However, it is typically less efficient for simple list containment checks.

list_for_apply = [3, 6]

# Using apply with a lambda for direct check
filtered_df_apply_direct = df.loc[df.apply(lambda x: x.A in list_for_apply, axis=1)]
print("\nFiltered DataFrame using apply(lambda x: x.A in [3, 6]):")
print(filtered_df_apply_direct)

# Using apply with a lambda for a function of the column
filtered_df_apply_func = df.loc[df.apply(lambda x: 2*x.A - 5 in list_for_apply, axis=1)]
print("\nFiltered DataFrame using apply(lambda x: 2*x.A - 5 in [3, 6]):")
print(filtered_df_apply_func)

Output:

Filtered DataFrame using apply(lambda x: x.A in [3, 6]):
   A  B
1  6  2
2  3  3

Filtered DataFrame using apply(lambda x: 2*x.A - 5 in [3, 6]):
   A  B
1  6  2
2  3  3

Method 11: Using f-strings with query()

For dynamic list filtering within query(), f-strings can be useful, though care must be taken with formatting.

list_for_fstring = [3, 6]
filtered_df_fstring_query = df.query(f'A in {list_for_fstring}')
print("\nFiltered DataFrame using query with f-string for list [3, 6]:")
print(filtered_df_fstring_query)

Output:

Filtered DataFrame using query with f-string for list [3, 6]:
   A  B
1  6  2
2  3  3

FAQs on Pandas Filter Rows by List Values

Q: How do I filter a Pandas DataFrame based on a list of values in a column

ANS: You can use the .isin() method by creating a boolean mask, e.g., df[df['column_name'].isin(your_list)]. Alternatively, the .query() method provides a more readable syntax, like df.query('column_name in @your_list').

Q: Can I select rows where the column value is NOT in a given list

ANS: Yes, you can negate the condition. With .isin(), use the tilde ~ operator: df[~df['column_name'].isin(your_list)]. With .query(), use df.query('column_name not in @your_list').

Q: What is the most efficient way to filter by a list in Pandas

ANS: For most cases, .isin() and .query() are the most efficient methods as they are vectorized operations. .apply() is generally slower for simple list filtering.

Q: How do I filter a Pandas DataFrame using a list of values that represents a range

ANS: You can use the .between() method, e.g., df[df['column_name'].between(start_value, end_value)], or use a range expression within .query(), such as df.query('start_value <= column_name <= end_value').

Q: How can I filter rows where multiple columns match values from a list

ANS: To filter if any of the specified columns match, use df[['col1', 'col2']].isin(your_list).any(1). For filtering where all specified columns match, use .all(1) instead of .any(1). .query() can also be used with or for any and and for all conditions.

Q: What happens if the data types of the column and the list are different

ANS: If the data types are incompatible (e.g., string vs. integer), the filtering might not work as expected or could raise an error. It is recommended to ensure that the column and list elements have matching or compatible data types before filtering. You can use .astype() to convert column dtypes.
