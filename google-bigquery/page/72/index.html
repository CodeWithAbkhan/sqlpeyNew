Formatting Date as MM/DD/YYYY in Google BigQuery Query Results

How to format date as mm/dd/yyyy in Google BigQuery SQL? Summary To format a date as mm/dd/yyyy in Google BigQuery SQL, you can use either the STRFTIME_UTC_USEC function in Legacy SQL or the FORMAT_DATE function in Standard SQL. Using STRFTIME_UTC_USEC function in Legacy SQL To format a date as mm/dd/yyyy in Legacy SQL, use the STRFTIME_UTC_USEC function with the date value and the desired format string. For example: SELECT STRFTIME_UTC_USEC("2016-10-20", "%m/%d/%Y"), STRFTIME_UTC_USEC(CURRENT_DATE(), "%m/%d/%Y") In this query, the first line formats the date “2016-10-20” as “10/20/2016”, and the second line formats the current date as mm/dd/yyyy format.
