Differences Between char, nchar, varchar, and nvarchar in SQL Server

What is the difference between char, nchar, varchar, and nvarchar in SQL Server? The main difference between these data types is the way that they store character data. char and nchar are fixed-length data types which reserve storage space for the number of characters you specify, even if you don’t use up all that space. varchar and nvarchar are variable-length data types which only use storage space for the characters you store and will not reserve storage like char or nchar.
