Uncovering the Architecture of Google BigQuery

Google BigQuery Underlying Architecture: A Deep Q&A What is the underlying architecture used by Google BigQuery to store data? Google BigQuery stores data in a proprietary columnar format called ColumnIO on Colossus, which is a successor to the Google File System (GFS). Colossus has the ability to replicate data within a datacenter and also across different geographic regions. This ensures that the data remains available even if a Google datacenter fails.
