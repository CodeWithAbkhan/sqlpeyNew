Creating dynamic @onclick markup in Blazor can be a challenging task. This post walks you through a detailed, step-by-step guide to achieve this, highlighting the use of RenderFragment and RenderTreeBuilder for more complex scenarios.

Summary

This guide demonstrates how to dynamically generate span tags with @onclick events in Blazor. By the end, you’ll be able to create and manipulate Blazor components entirely through code, without the need for JavaScript.

Step 1: Initial Static Markup

Start with a simple static span tag in your Blazor component to understand the basics of event handling:

<table>
  <tr>
    <td>
      <span @onclick="() => HelloClick(42)" style="display:inline-block; background-color: #04AB6D; border: none; color: white;">HELLO</span>
    </td>
  </tr>
</table>

This code snippet sets up a span tag with an @onclick event that triggers the HelloClick method.

Step 2: Generate Markup Dynamically

To create span tags dynamically, store the generated markup in a string variable and render it using MarkupString.

Example Code

private string itemsToClick = string.Empty;

// Method to generate dynamic span elements
private void GenerateSpans()
{
    itemsToClick = string.Empty;
    List<string> spans = new List<string>();
    foreach (int spanId in new List<int> { 1, 2, 3, 4, 5 })
    {
        string onClick = $"@onclick=\"() => HelloClick({spanId})\"";
        string span = $"<span {onClick} style=\"display:inline-block; background-color: #04AB6D; border: none; color: white;\">Hello</span>";
        spans.Add(span);
    }
    if (spans.Count > 0)
        itemsToClick = string.Join(" ", spans);
}

Render the dynamic spans in your component:

<table>
  <tr>
    <td>@((MarkupString)itemsToClick)</td>
  </tr>
</table>

Step 3: Understanding RenderFragment

To properly handle events in dynamically created elements, use RenderFragment. This ensures Blazor can correctly bind events.

Example Code

@code {
    List<RenderFragment> itemsToClick = new();

    private void GenerateSpans()
    {
        itemsToClick.Clear();
        foreach (int spanId in new List<int> { 1, 2, 3, 4, 5 })
        {
            itemsToClick.Add(builder =>
            {
                builder.OpenElement(0, "span");
                builder.AddAttribute(1, "style", "display:inline-block; background-color: #04AB6D; border: none; color: white;");
                builder.AddAttribute(2, "onclick", EventCallback.Factory.Create(this, () => HelloClick(spanId)));
                builder.AddContent(3, "Hello");
                builder.CloseElement();
            });
        }
    }

    private void HelloClick(int spanId)
    {
        Console.WriteLine($"Span {spanId} clicked");
    }
}

Render the RenderFragment list in your component:

<table>
  <tr>
    @foreach (var fragment in itemsToClick)
    {
        <td>@fragment</td>
    }
  </tr>
</table>

Step 5: Practical Example with RenderFragment

Create a reusable RenderFragment<T> for dynamic elements:

Example Code

@page "/dynamic-spans"
@code {
    private List<int> spanIds = new() { 1, 2, 3, 4, 5 };
    private RenderFragment<int> SpanFragment => spanId => builder =>
    {
        builder.OpenElement(0, "span");
        builder.AddAttribute(1, "style", "display:inline-block; background-color: #04AB6D; border: none; color: white;");
        builder.AddAttribute(2, "onclick", EventCallback.Factory.Create(this, () => HelloClick(spanId)));
        builder.AddContent(3, "Hello");
        builder.CloseElement();
    };

    private void HelloClick(int spanId)
    {
        Console.WriteLine($"Span {spanId} clicked");
    }
}

Render the dynamic spans using the RenderFragment<T>:

<table>
  @foreach (var id in spanIds)
  {
    <tr>
      <td>@SpanFragment(id)</td>
    </tr>
  }
</table>

FAQs on “Top 5 Steps to Create Dynamic @onclick Markup in Blazor”

Q: Can I use JavaScript to handle events in Blazor?

ANS: While you can use JavaScript, Blazor provides built-in mechanisms like RenderFragment to handle events without JavaScript.

Q: Why isn't my @onclick event firing?

ANS: Ensure that the event binding is correct and use RenderFragment to manage dynamic content.

Q: Can I dynamically create other elements besides spans?

ANS: Yes, you can dynamically create any HTML element using similar techniques.

Q: Is there a performance impact of using RenderFragment?

ANS: RenderFragment is optimized for Blazor, but for large-scale dynamic content, consider performance testing.

Q: How do I debug dynamic content in Blazor?

ANS: Use browser developer tools (F12) and Blazor debugging tools to inspect and debug dynamic content.
