Solved: How to Download a File from a Server with Blazor App

If you’re looking to integrate file downloads in your Blazor application, this post will guide you through different methods for achieving that. Whether you’re trying to export CSV files or download any other format from the server, we will explore how to set up both the server and client-side code for a seamless experience.

Summary

Blazor makes it easy to build interactive web UIs, but when it comes to file downloads, there are a few approaches you can use depending on your needs. This post covers multiple ways to download files using Blazor, focusing on the common use case of downloading a CSV file from a server API. You will also learn about how to use JavaScript Interop to trigger file downloads and dynamically generated links in your app.

How to Set Up File Download in Blazor App

Let’s break down the steps you need to follow to implement file downloads in Blazor.

1. Setting Up the Server-Side (ASP.NET Core API)

To start, your server will need to provide an endpoint that creates and returns a file. The following C# code shows how to return a CSV file to the client using FileStreamResult:

[HttpGet]
public IActionResult Get() {
    // Logic to create the CSV in memoryStream
    var memoryStream = new MemoryStream();
    var writer = new StreamWriter(memoryStream);
    writer.WriteLine("ProductID,ProductName");
    writer.WriteLine("1,Apple");
    writer.WriteLine("2,Banana");
    writer.Flush();
    memoryStream.Position = 0;

    return new FileStreamResult(memoryStream, "text/csv;charset=utf-8") {
        FileDownloadName = "products.csv",
    };
}

Explanation:

  • [HttpGet]: This attribute marks the method as a GET request handler for the endpoint.
  • FileStreamResult(memoryStream, "text/csv;charset=utf-8"): This sends the memoryStream containing the CSV data to the client as a CSV file.
  • FileDownloadName: Specifies the name of the file that will be downloaded (in this case, products.csv).

2. Blazor Client-Side Code to Download the File

Once the server-side logic is set up, you can move on to the Blazor client. Here’s how to initiate the file download using Blazor’s HttpClient:

private async Task DownloadCatalog() {
    var file = await HttpClient.GetAsync("api/csvProduct");
    // Trigger file download logic
}

Explanation:

  • HttpClient.GetAsync: Makes an asynchronous HTTP request to the API endpoint ("api/csvProduct") to retrieve the file.
  • You can then either trigger a download using JavaScript or use a direct link.

Practical Example:

You can also provide a download link in your Blazor app that is triggered dynamically:

@if (_exportUrl != null) {
    <a id="exportCsv" class="btn" href="@_exportUrl" download="MyFile.csv" role="button" target="=_top">Export to CSV</a>

3. Using JavaScript Interop for File Downloads

In Blazor WebAssembly (WASM), you can use JavaScript Interop to download files. Here is an example that demonstrates how to invoke JavaScript to download a file using Blob and URL.createObjectURL:

JavaScript Code:

function BlazorDownloadFileFast(name, contentType, content) {
    const contentArray = new Uint8Array(content);
    const file = new File([contentArray], name, { type: contentType });
    const exportUrl = URL.createObjectURL(file);
    
    const a = document.createElement("a");
    document.body.appendChild(a);
    a.href = exportUrl;
    a.download = name;
    a.target = "_self";
    a.click();

    URL.revokeObjectURL(exportUrl);
    a.remove();
}

Blazor C# Code:

byte[] fileContent = GetFileByteArray(); // Your file data here
string fileName = "file.csv";
string contentType = "application/octet-stream";

if (JSRuntime is IJSUnmarshalledRuntime webAssemblyJSRuntime) {
    webAssemblyJSRuntime.InvokeUnmarshalled<string, string, byte[], bool>("BlazorDownloadFileFast", fileName, contentType, fileContent);
} else {
    await JSRuntime.InvokeVoidAsync("BlazorDownloadFile", fileName, contentType, fileContent);
}

Explanation:

  • The JavaScript function BlazorDownloadFileFast creates a file object from the byte array and triggers the browser’s download behavior.
  • The Blazor C# code uses JavaScript Interop (JSRuntime) to call the JavaScript function with the necessary data.

4. Using Base64 Encoding for Server-Side File Download

When working with Blazor Server, you might need to convert the file into a Base64 string before sending it over JavaScript. Here’s how you can implement this:

Server-Side C# Code:

var fileBytes = GetFileByteArray();
var fileBase64 = Convert.ToBase64String(fileBytes);

await JSRuntime.InvokeVoidAsync("jsSaveAsFile", "file.csv", fileBase64);

JavaScript Code:

function jsSaveAsFile(filename, byteBase64) {
    var link = document.createElement('a');
    link.download = filename;
    link.href = "data:application/octet-stream;base64," + byteBase64;
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
}

Explanation:

  • The server sends the file as a Base64 string, which is then handled by JavaScript to trigger the file download.

Alternative Ways:

  • Using NavigationManager: Another alternative is to use the NavigationManager in Blazor to navigate to the file’s endpoint directly.
@inject NavigationManager NavigationManager

private async Task DownloadCatalog() {
    NavigationManager.NavigateTo("api/csvProduct", true);
}

This triggers the download when the user is redirected to the file endpoint.

FAQs on How to Download a File from a Server with Blazor App

Q: How do I handle file downloads in Blazor?

ANS: You can handle file downloads in Blazor by either using HttpClient to make a request to the server API and trigger a download via JavaScript Interop or using direct download links in your Blazor components.

Q: Can I use JavaScript for downloading files in Blazor?

ANS: Yes, JavaScript Interop is commonly used to manage file downloads in Blazor, especially for large files or when you need more control over the download process.

Q: How can I trigger a file download in Blazor Server?

ANS: In Blazor Server, you can convert the file to a Base64 string and use JavaScript Interop to download the file, or you can use the NavigationManager to navigate to the file URL directly.

Q: Is there a way to download files dynamically based on user actions?

ANS: Yes, you can dynamically set the file URL or content based on user interactions in your Blazor components, such as using HttpClient.GetAsync or JavaScript to trigger the file download.

Q: Can I download files using only Blazor without JavaScript?

ANS: It’s not possible to directly save files to disk in Blazor without JavaScript, as Blazor runs in the browser which doesn’t have access to the file system. You must use JavaScript Interop for this task.
