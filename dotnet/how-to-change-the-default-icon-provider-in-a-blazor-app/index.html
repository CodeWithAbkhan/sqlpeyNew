How to Change the Default Icon Provider in a Blazor App?

Summary

When you create a new Blazor app, the default icon provider is usually Iconify, which comes with an open icon pack. However, if you want to change this to a different icon provider like Material Icons or Font Awesome, you need to perform a few customizations in your Blazor app. In this guide, we’ll show you how to modify your Blazor app to use different icon sets by updating CSS and HTML structure.

How to Switch the Icon Provider in Blazor?

Blazor apps, by default, use Iconify for displaying icons. However, if you want to change this to another provider, the process generally involves importing the CSS for your preferred icon provider into the Blazor app and modifying the HTML to use the new icons.

What Do You Need to Do?

The process can seem tricky, especially if you are using JavaScript libraries for icons in a non-JavaScript environment like Blazor. Here’s a step-by-step breakdown of how you can change your icon provider in a Blazor app.

Step 1: Remove Default Iconify

Blazor comes with a default icon provider like Iconify. This can usually be found in your site’s CSS file or imported within the _Imports.razor or App.razor files.

First, locate the @import statement in the CSS file, usually in the site.css or wwwroot/css/app.css file:

@import url('open-iconic/font/css/open-iconic-bootstrap.min.css');

To replace the current icon provider, you need to remove or comment out this line of code.

Step 2: Add the New Icon Provider (Material Icons Example)

Importing Material Icons

Let’s say you want to use Material Icons instead of Iconify. Material Icons can be easily included by adding an import statement to your site.css or app.css file:

@import url('https://fonts.googleapis.com/icon?family=Material+Icons');

This link imports Material Icons from Google Fonts, making them accessible in your Blazor app.

Step 3: Replace Iconify Tags with Material Icons

Once Material Icons is imported, you can begin replacing the previous icon tags (Iconify-based) with Material Icon tags. Here’s an example of how you would do this:

<div class="@NavMenuCssClass" @onclick="ToggleNavMenu">
    <ul class="nav flex-column">
        <li class="nav-item px-3">
            <NavLink class="nav-link" href="" Match="NavLinkMatch.All">
                <i class="material-icons">
                    accessibility
                </i> Home
            </NavLink>
        </li>
        <li class="nav-item px-3">
            <NavLink class="nav-link" href="counter">
                <i class="material-icons">autorenew</i>
                Counter
            </NavLink>
        </li>
    </ul>
</div>

In this example, we replace the Iconify icon tags with <i class="material-icons">accessibility</i> and other relevant icon names. Material Icons use a simple <i> tag to display the desired icon, where the icon’s name (like accessibility) is placed inside the <i> tag.

Step 4: Using Font Awesome as an Alternative

Another popular icon provider is Font Awesome. To use Font Awesome, you would need to add a link to the Font Awesome stylesheet in your index.html or _Host.cshtml file:

<link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.2.0/css/all.min.css" rel="stylesheet" />

After this, you can replace your icon tags with Font Awesome’s classes. Here’s an example of how to use Font Awesome in your Blazor app:

<i class="fa-solid fa-cog fa-spin me-3" aria-hidden="true"></i> Settings

This snippet adds a spinning gear icon (representing settings) using the Font Awesome library. You can explore Font Awesome’s library here to find more icons.

Practical Example: Switching Icon Providers in Blazor

Let’s consider the following scenario: You are building a navigation bar in Blazor, and you want to replace the default icons with Material Icons or Font Awesome. Below is an example of how you can switch providers for various buttons in your navigation menu:

<div class="@NavMenuCssClass" @onclick="ToggleNavMenu">
    <ul class="nav flex-column">
        <li class="nav-item px-3">
            <NavLink class="nav-link" href="" Match="NavLinkMatch.All">
                <i class="material-icons">home</i> Home
            </NavLink>
        </li>
        <li class="nav-item px-3">
            <NavLink class="nav-link" href="counter">
                <i class="fa-solid fa-undo"></i> Counter
            </NavLink>
        </li>
    </ul>
</div>

In this example:

  • Home is represented using Material Icons.
  • Counter is represented using Font Awesome.

Alternative Ways to Change Icon Providers

If you are looking for more flexibility or customization options, you might want to explore alternative ways to add icons to your Blazor app:

  1. Custom SVG Icons: You can add custom SVG icons directly to your components.
  2. Icon Libraries: You can use a custom-built icon library that you manage yourself.

Example: Using Custom SVG Icons

<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24">
  <path d="M12 4v16l8-8z"/>
</svg>

This snippet demonstrates embedding a simple SVG icon directly into your Blazor app.

FAQs on Changing the Default Icon Provider in Blazor App

Q: How do I replace Iconify with Material Icons?

ANS: You can replace Iconify by importing the Material Icons stylesheet in your CSS file and then updating the HTML to use the <i class="material-icons">icon_name</i> syntax.

Q: Can I use Font Awesome with Blazor?

ANS: Yes, you can integrate Font Awesome by adding the Font Awesome CDN link to your _Host.cshtml or index.html file, and then using the <i class="fa-solid fa-icon_name"></i> syntax in your Blazor components.

Q: How do I add custom SVG icons in Blazor?

ANS: You can directly embed custom SVG icons by including the <svg> tag and specifying the path for your icon in the Blazor component or page.

Q: Can I use multiple icon providers in the same Blazor app?

ANS: Yes, you can use multiple icon providers by including the necessary links to each stylesheet and using the appropriate HTML syntax for each icon provider.

Q: How do I use Material Icons with Blazor?

ANS: To use Material Icons, add the link to the Google Fonts stylesheet for Material Icons in your CSS, and then use the <i class="material-icons">icon_name</i> syntax for your icons in the Blazor pages.
