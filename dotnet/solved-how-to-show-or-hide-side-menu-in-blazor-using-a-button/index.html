If you’re working with Blazor and need to implement a feature that allows users to show or hide the side menu with a button, this article guides you step by step. You will learn how to toggle the visibility of the side menu using Blazor’s layout component, a custom service, and CSS classes. The solution also ensures that the layout refreshes correctly when the menu’s visibility changes.

How do you toggle the side menu in a Blazor application using a button? This is a common question among Blazor beginners. In a Blazor application, side menus often need to be toggled based on user interaction, such as clicking a button. So, what’s the most efficient way to implement such functionality?

Here’s a simple solution using a service pattern and conditional CSS classes to hide or show the side menu dynamically. Let’s walk through each part of the code in detail.

Step 1: Create the ViewOptionService class

To manage the state of the side menu’s visibility, we will create a service class. This service will hold a boolean value that determines if the menu is visible or not. We’ll use the Toggle() method to change the state and notify components when the state changes.

public class ViewOptionService
{
    private bool _navBarVisible = true;  // Default state of the navbar is visible

    // Action to notify components of state change
    public Action OnChanged { get; set; }

    // Method to toggle visibility of the navbar
    public void Toggle()
    {
        _navBarVisible = !_navBarVisible;  // Toggle the navbar visibility
        OnChanged?.Invoke();  // Call OnChanged if it's not null to refresh the components
    }

    // Property to return the appropriate CSS class for navbar visibility
    public string NavBarClass
    {
        get
        {
            return _navBarVisible ? string.Empty : "d-none";  // If the navbar is not visible, return the 'd-none' class to hide it
        }
    }
}
  • Explanation:
    • The ViewOptionService manages the visibility of the navigation bar using the _navBarVisible private field.
    • The Toggle() method changes the state of _navBarVisible and triggers the OnChanged action to notify components that the state has changed.
    • The NavBarClass property returns the appropriate CSS class (d-none) when the navbar is hidden.

Step 2: Register the ViewOptionService in Program.cs

Next, you need to register the service so it can be injected into components across the application. Modify the Main method in Program.cs as shown below:

public static async Task Main(string[] args)
{
    var builder = WebAssemblyHostBuilder.CreateDefault(args);
    
    // Register the ViewOptionService as a singleton
    builder.Services.AddSingleton<ViewOptionService>();

    await builder.Build().RunAsync();
}
  • Explanation:
    • The AddSingleton<ViewOptionService>() line ensures that only one instance of ViewOptionService is used across the entire application.

Step 3: Use the service in MainLayout.razor

Now, let’s use this service in the layout component (usually MainLayout.razor) to conditionally add or remove the d-none CSS class from the sidebar.

@inherits LayoutComponentBase
@inject ViewOptionService ViewOption

<div class="sidebar @ViewOption.NavBarClass">
    <NavMenu />
</div>
  • Explanation:
    • The @ViewOption.NavBarClass dynamically binds the class attribute of the sidebar. If the NavBarClass is "d-none", the sidebar will be hidden.

Step 4: Add the toggle button in Index.razor

Finally, we need a button that will allow users to toggle the visibility of the sidebar. Here’s how you can implement it:

@page "/"
@inject ViewOptionService ViewOption

<button @onclick="ViewOption.Toggle">Toggle Menu</button>
  • Explanation:
    • The @onclick directive binds the Toggle() method to the button’s click event, which toggles the visibility of the sidebar.

Step 5: Ensure the layout refreshes when the state changes

In Blazor, when a state change occurs, we need to manually refresh the layout to reflect the changes. To ensure the layout is updated when the visibility of the sidebar changes, we add the following code to MainLayout.razor:

@code {
    protected override async Task OnInitializedAsync()
    {
        ViewOption.OnChanged = () => { 
            StateHasChanged();  // Refresh the layout
        };
    }
}
  • Explanation:
    • The OnChanged action is set to invoke StateHasChanged() whenever the visibility changes, ensuring that the UI is updated to reflect the new state.

Alternative Ways

One might consider using CascadingValue to pass a reference of the NavMenu component instead of using a service to manage the state. However, as your application grows, managing the render queue with cascading values might become tricky, leading to references potentially becoming null. Therefore, using a service like the one outlined in this post is often a more robust solution.

FAQs on How to Show or Hide Side Menu in Blazor

Q: How do I toggle the side menu in Blazor?

ANS: You can toggle the side menu in Blazor by creating a service that manages the visibility state of the menu and updating the layout accordingly. Use the Toggle() method to change the state and bind the visibility to a CSS class.

Q: What is the role of the `ViewOptionService` class?

ANS: The ViewOptionService class is responsible for managing the state of the navigation bar’s visibility. It holds a boolean flag to track whether the navbar is visible and provides a Toggle() method to change its state.

Q: Why do we use `StateHasChanged()` in Blazor?

ANS: StateHasChanged() is used in Blazor to refresh the component’s UI when its state changes. It triggers a re-render to reflect any updates to the component’s state, such as visibility toggling in the navbar.

Q: How can I customize the side menu appearance in Blazor?

ANS: You can customize the side menu in Blazor by modifying the CSS associated with the sidebar. For example, adding or removing custom classes based on the visibility state allows you to control the side menu’s appearance dynamically.

Q: What is the purpose of the `d-none` class?

ANS: The d-none class in Bootstrap is used to hide elements by setting their display property to none. In this example, it is applied to the sidebar when it is hidden.
