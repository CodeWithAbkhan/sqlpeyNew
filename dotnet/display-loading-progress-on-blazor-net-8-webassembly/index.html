Top 5 Steps to Display Loading Progress on Blazor .NET 8 WebAssembly

When creating a Blazor WebAssembly application in .NET 8 with pre-rendering disabled, displaying a loading spinner can enhance user experience during the initial load. This guide covers the top 5 steps to achieve this.

Step 1: Setting Up Your Blazor WebAssembly Project

Create a new Blazor WebAssembly project and ensure pre-rendering is disabled.

Command Line:

dotnet new blazorwasm -o MyBlazorApp

Visual Studio:

  1. Open Visual Studio and select “Create a new project”.
  2. Choose the “Blazor WebAssembly App” template.
  3. Ensure “ASP.NET Core Hosted” option is selected.
  4. Add the following attribute in your App.razor to disable pre-rendering:
@attribute [RenderModeInteractiveWebAssembly(prerender: false)]

Step 2: Adding a Loading Spinner

Create a loading element in your index.html or index.cshtml file.

<!DOCTYPE html>
<html>
<head>
    <title>MyBlazorApp</title>
    <base href="/" />
    <link rel="stylesheet" href="css/app.css" />
    <script src="app.js"></script>
</head>
<body>
    <div id="loading">Loading...</div>
    <app>Loading...</app>
    <script src="_framework/blazor.webassembly.js"></script>
</body>
</html>

This adds a loading spinner to your page.

Step 3: Creating a JavaScript File for Interop

Create a new JavaScript file named app.js in the wwwroot folder to remove the loading spinner once the app is fully loaded.

(function () {
    window.removeLoadingSpinner = function () {
        var element = document.getElementById('loading');
        if (element) {
            element.parentNode.removeChild(element);
        }
    }
})();

Include this script in your index.html file as shown in Step 2.

Step 4: Invoking JavaScript from Blazor

Modify the App.razor file to invoke the JavaScript function once the app is rendered.

@page "/"
@using Microsoft.JSInterop
@inject IJSRuntime JSRuntime

<CascadingAuthenticationState>
    <Router AppAssembly="@typeof(Program).Assembly">
        <Found Context="routeData">
            <RouteView RouteData="@routeData" DefaultLayout="@typeof(MainLayout)" />
            <FocusOnNavigate RouteData="@routeData" Selector="h1" />
        </Found>
        <NotFound>
            <LayoutView Layout="@typeof(MainLayout)">
                <p>Sorry, there's nothing at this address.</p>
            </LayoutView>
        </NotFound>
    </Router>
</CascadingAuthenticationState>

@code {
    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            await JSRuntime.InvokeVoidAsync("removeLoadingSpinner");
        }
    }
}

This code ensures that the loading spinner is removed once the Blazor app is fully rendered.

Step 5: Testing and Debugging

Deploy and run your application to ensure the loading spinner behaves as expected. Use browser developer tools to debug any issues.

Deploying the Application:

  1. Right-click the solution in Visual Studio.
  2. Select “Publish” and follow the instructions to deploy your app.

Ensure the loading spinner appears during the initial load and disappears once the app is fully loaded.

Practical Examples

Example: Customizing the Loading Spinner

Customize the spinner by modifying the CSS.

#loading {
    position: fixed;
    width: 100%;
    height: 100%;
    background: rgba(255, 255, 255, 0.8);
    display: flex;
    align-items: center;
    justify-content: center;
    font-size: 2em;
    color: #333;
}

Example: Advanced JS Interop

Extend the JavaScript function to add more interactivity or manage other elements.

(function () {
    window.customInterop = {
        removeElement: function (id) {
            var element = document.getElementById(id);
            if (element) {
                element.parentNode.removeChild(element);
            }
        }
    }
})();

Alternative Method: Using CSS for Spinner

An alternative to using JavaScript is to manage the spinner purely with CSS.

<div id="loading" class="loading-hidden">Loading...</div>

<style>
    .loading-hidden {
        display: none;
    }
</style>

<script>
    document.getElementById('loading').classList.add('loading-hidden');
</script>

This method toggles the visibility of the loading element using CSS classes.

FAQs on “Top 5 Steps to Display Loading Progress on Blazor .NET 8 WebAssembly”

Q: How do I disable pre-rendering in a Blazor WebAssembly project?

ANS: Add @attribute [RenderModeInteractiveWebAssembly(prerender: false)] to your App.razor file.

Q: How can I add a loading spinner to my Blazor WebAssembly app?

ANS: Add a loading element in your index.html and use JavaScript to remove it once the app is loaded.

Q: What JavaScript function can I use to remove the loading spinner?

ANS: Create a function removeLoadingSpinner in a new app.js file to remove the spinner element.

Q: How do I invoke JavaScript from Blazor?

ANS: Use IJSRuntime to invoke the JavaScript function in the OnAfterRenderAsync method of App.razor.

Q: Can I manage the loading spinner with CSS instead of JavaScript?

ANS: Yes, you can use CSS classes to toggle the visibility of the loading element.
