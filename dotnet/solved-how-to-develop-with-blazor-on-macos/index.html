Developing Blazor applications on macOS can sometimes be challenging due to the lack of direct support in Visual Studio for Mac, especially for certain Blazor templates. If you’ve encountered this problem, you might have already tried to create a Blazor project, only to find that the templates for Blazor WebAssembly or Blazor Server are not visible in your Visual Studio environment. Fear not! In this guide, we’ll walk you through how to get Blazor up and running on macOS by installing the necessary templates and using the dotnet CLI for project creation. This approach will allow you to start building Blazor applications quickly and easily, even without the Visual Studio template support.

Summary

  • Challenges on macOS: There are no out-of-the-box Blazor templates in Visual Studio for Mac, and the Blazor Language Services extension is not available either.
  • Solution: You can still develop Blazor applications by installing the templates manually using the dotnet CLI.
  • Step-by-Step Guide: We will show you how to use the command line to install the Blazor templates and create a project.
  • Alternative Solutions: Explore other ways to develop Blazor apps on macOS, including using Visual Studio Code.

How Can You Get Started with Blazor on macOS?

If you’re eager to start building Blazor apps on macOS, follow the steps below to set up everything manually using the dotnet CLI.

Step 1: Install the .NET SDK

First, ensure that you have the .NET SDK installed on your macOS system. If you haven’t done so, you can download it from the official .NET website.

  • Download .NET SDK

Once installed, verify the installation by opening a terminal and running:

dotnet --version

This command should output the installed version of the .NET SDK.

Step 2: Install Blazor Templates

To create a Blazor app, you’ll need to install the Blazor templates. On macOS, these templates are not included by default in Visual Studio for Mac, so we will install them manually using the dotnet new command.

Run the following command to install the Blazor templates:

dotnet new -i Microsoft.AspNetCore.Blazor.Templates::*

This command tells the dotnet CLI to install the Blazor templates. You’ll be able to create a Blazor project using the dotnet commands thereafter.

Step 3: Create a Blazor Project

After the templates are installed, you can now create a new Blazor project. You can do this using the dotnet new command.

For a Blazor WebAssembly project, use the following:

dotnet new blazorwasm -o MyBlazorApp

For a Blazor Server project, use this command:

dotnet new blazorserver -o MyBlazorApp

This will generate a new Blazor app inside a folder named MyBlazorApp.

Step 4: Open the Project in Visual Studio Code

Since Visual Studio for Mac doesn’t fully support Blazor templates, Visual Studio Code is a great alternative for editing and running Blazor projects on macOS. You can open the project by running:

code MyBlazorApp

Make sure you have Visual Studio Code installed. If you haven’t, you can download it here:

  • Download Visual Studio Code

Step 5: Run the Project

Now, it’s time to run the project. In the terminal, navigate to the project folder and use the dotnet run command:

cd MyBlazorApp
dotnet run

This will build and run your Blazor app, and you can access it in your browser at http://localhost:5000.

Can I Use Visual Studio Code for Blazor Development on macOS?

Yes! While Visual Studio for Mac may not support Blazor templates natively, you can easily use Visual Studio Code for Blazor development. Visual Studio Code is lightweight, fast, and offers many extensions to support C# and Blazor development.

Here’s how to make the most out of Visual Studio Code for Blazor:

  1. Install the C# Extension: This extension is essential for working with C# code in Visual Studio Code. You can install it from the marketplace directly.

    • Install C# Extension

  2. Install the Razor Extension: This extension helps you with Razor Pages syntax, which is used in Blazor components.

    • Install Razor Extension

Can I Use the dotnet CLI to Manage Blazor Projects?

Yes, dotnet CLI is an essential tool for managing Blazor projects and works seamlessly across all platforms, including macOS. With dotnet CLI, you can:

  • Create new Blazor projects (dotnet new)
  • Build projects (dotnet build)
  • Run projects (dotnet run)
  • Publish projects (dotnet publish)

By using these commands, you’ll have full control over your Blazor projects without relying on Visual Studio for Mac.

Alternative Ways to Develop Blazor Apps on macOS

While the dotnet CLI is the most straightforward solution, there are a few alternative ways to develop Blazor apps on macOS:

  1. Use Docker: You can run a Windows container with Visual Studio if you need to use the full Visual Studio experience. This method can be complex but might be necessary if you prefer a native Visual Studio setup.

  2. Use a Virtual Machine: You can install a virtual machine running Windows and use Visual Studio for Windows. This might not be the most efficient solution but can work if you absolutely need Windows for Blazor development.

FAQs on Developing Blazor Apps on macOS

Q: How do I install Blazor templates on macOS?

ANS:
You can install Blazor templates by using the dotnet new -i Microsoft.AspNetCore.Blazor.Templates::* command in the terminal. This will allow you to create new Blazor projects using the dotnet CLI.

Q: Can I develop Blazor applications without Visual Studio for Mac?

ANS:
Yes, you can develop Blazor applications using Visual Studio Code on macOS. It provides excellent support for C# and Blazor with the help of extensions like C# and Razor.

Q: Can I run Blazor WebAssembly projects on macOS?

ANS:
Yes, after creating a Blazor WebAssembly project using the dotnet CLI, you can run it on your macOS system. Use dotnet run to start the project and access it in your browser.

Q: What is the dotnet CLI?

ANS:
The dotnet CLI (Command Line Interface) is a cross-platform tool used to manage .NET projects. You can create, build, and run projects using various dotnet commands like dotnet new, dotnet build, and dotnet run.

Q: Can I use Docker to run Visual Studio on macOS?

ANS:
Yes, you can use Docker to run a Windows container and access Visual Studio on macOS. This is more complex but can allow you to use Visual Studio in a macOS environment.
