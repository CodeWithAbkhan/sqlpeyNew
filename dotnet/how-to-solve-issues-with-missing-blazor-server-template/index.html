How to Solve Issues With Missing Blazor Server Template

Are you facing an issue where the Blazor Server App template is missing in Visual Studio or when using the dotnet CLI? In this guide, we’ll explain why this happens, how to fix it, and offer step-by-step instructions on using the correct templates.

Why Is the Blazor Server Template Missing?

If you’ve been using Visual Studio or the dotnet CLI for Blazor development, you might have noticed that the Blazor Server App template is not available in some versions of Visual Studio or when using the dotnet new command. This issue can leave you confused about how to proceed with your Blazor Server project. Let’s dive into the possible reasons behind this and how to resolve it.

The Problem with Missing Templates in Visual Studio

In Visual Studio 2022, you might see that only two Blazor templates are available: Blazor Web App and Blazor WebAssembly Standalone App. If you’re trying to develop a Blazor Server App, the “Blazor Server App” option is nowhere to be found.

Here’s the scenario:

  1. Work computer: When filtering for Blazor templates, you find several options, including Blazor Server App.
  2. Personal laptop: On Visual Studio 2022, you only see Blazor Web App and Blazor WebAssembly Standalone App—no sign of the Blazor Server App template.

This discrepancy can cause frustration, especially when you want to develop a Blazor Server App specifically.

How to Create a Blazor Server App Manually

If the Blazor Server App template is missing in Visual Studio, you can still create the app using the .NET CLI.

Step-by-Step Instructions:

  1. Open the CLI: Open your command line interface (CLI) in your preferred development environment (e.g., Visual Studio Code terminal, Command Prompt, or PowerShell).

  2. Run the Command: Use the following dotnet command to create a Blazor Server App:

    dotnet new blazorserver -o BlazorServerApp

    This will create a new Blazor Server App in a folder called BlazorServerApp.

    However, if you receive an error saying there’s no such template as blazorserver, don’t panic! There’s an easy fix.

What’s Happening Under the Hood?

The error indicates that Visual Studio or the .NET CLI may not have the necessary templates installed. This can happen if the Blazor Server template is not part of the default setup for the version of Visual Studio or the .NET SDK you’re using.

How to Access the Correct Blazor Templates

To access the full list of Blazor templates, you can either use Visual Studio or the command line. Here’s how you can ensure you’re using the right templates:

  1. In Visual Studio:

    • Open Visual Studio and go to Create a new project.
    • Search for Blazor in the template list.
    • If you’re unable to find the Blazor Server App template, ensure that your Visual Studio installation includes the ASP.NET and web development workload. You can modify the installation via the Visual Studio Installer.

  2. Using the dotnet CLI:

    • Open your terminal and type the following command to list all available templates: 
      dotnet new --list
    • Look for the template named Blazor Server App. If it’s not listed, it may need to be manually installed or enabled via the .NET SDK setup.

Fixing the Missing Blazor Server Template Issue

If the Blazor Server template still isn’t showing up, try the following:

  1. Ensure the .NET SDK is Updated: Sometimes, the templates are tied to specific versions of the SDK. You can check if your SDK is outdated and update it by visiting the official dotnet website .

  2. Install Missing Templates: Use the following command to install or update the templates:

    dotnet new -i Microsoft.AspNetCore.Components.WebAssembly.Templates

    This will download and install the missing templates, including the Blazor Server App template.

Practical Example of a Blazor Server App

Let’s see an example of how you can create and structure a Blazor Server App once you have access to the correct templates.

Code Explanation:

  1. Creating the App: Once the template is available, create the Blazor Server app by running: 
    dotnet new blazorserver -o MyBlazorApp
  2. App Structure: This generates a basic Blazor Server app structure with the following key files:
    • Program.cs: Contains the startup code for the Blazor application.
    • App.razor: The main component that serves as the entry point for the app.
    • Pages/Index.razor: The default page when the app starts.

Here’s a brief look at the Program.cs file:

using Microsoft.AspNetCore.Components;
using Microsoft.AspNetCore.Components.Web;
using MyBlazorApp;

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddRazorComponents()
    .AddInteractiveServer(); // Set up the interactive server mode

var app = builder.Build();

app.MapRazorComponents()
    .AddInteractiveServer() // Interactive Server mode for Blazor Server
    .AddRoute("/", typeof(Index)); // Set default route

app.Run();

Alternative Ways to Develop a Blazor App

While Blazor Server Apps are highly efficient for creating interactive web applications with minimal client-side JavaScript, you can also consider Blazor WebAssembly or Blazor Web App for projects that need more client-side interaction. If the Server template is unavailable, these alternatives can help achieve similar functionality.

FAQs on How to Solve Issues with Missing Blazor Server Template

Q: Why is the Blazor Server template not available in Visual Studio?

ANS: The Blazor Server template might not appear if your Visual Studio installation doesn’t include the necessary web development workload or if you are using an outdated version of Visual Studio or the .NET SDK. Updating your installation or modifying the template list can resolve this issue.

Q: How can I install the missing Blazor Server template in the CLI?

ANS: Use the following command to install the missing templates:

dotnet new -i Microsoft.AspNetCore.Components.WebAssembly.Templates

This will ensure you have access to all available Blazor templates, including the Blazor Server App.

Q: Can I create a Blazor Server App using the dotnet CLI?

ANS: Yes, you can create a Blazor Server App using the command:

dotnet new blazorserver -o MyBlazorApp

If the template is not available, make sure your SDK is updated and the appropriate templates are installed.

Q: How do I check for the available templates in the CLI?

ANS: To check for all available templates, use the command:

dotnet new --list

This will display a list of all available project templates.

Q: Is Blazor Server App being replaced by Blazor Web App?

ANS: No, Blazor Server is still supported and is not being replaced. The Blazor Web App template may simply be showing more prominent options, but you can still develop a Blazor Server App by using the right tools and templates.
