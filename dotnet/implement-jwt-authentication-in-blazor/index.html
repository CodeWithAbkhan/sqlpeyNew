You’ll learn how to create a custom AuthenticationStateProvider, manage user sessions, and handle token-based authentication seamlessly. By following this tutorial, you’ll enhance the security of your Blazor apps and ensure that user identities are correctly managed.

Here’s the updated and complete guide that includes all necessary steps for implementing JWT authentication in Blazor, as well as configuring authentication in Program.cs. I have followed the requested format and expanded on key details:

Top 5 Steps to Implement JWT Authentication in Blazor

Step 1: Create a Custom AuthenticationStateProvider

The AuthenticationStateProvider class in Blazor is responsible for providing the current user’s authentication state. In this step, you will create a custom provider to handle JWT-based authentication.

public class JwtAuthenticationStateProvider : AuthenticationStateProvider
{
    private readonly ISessionStorageService sessionStorageService;
    private ClaimsPrincipal anonymous = new ClaimsPrincipal(new ClaimsIdentity());

    public JwtAuthenticationStateProvider(ISessionStorageService sessionStorageService)
    {
        this.sessionStorageService = sessionStorageService;
    }

    public override async Task<AuthenticationState> GetAuthenticationStateAsync()
    {
        try
        {
            var userSession = await sessionStorageService.ReadEncryptedItemAsync<UserSession>("UserSession");
            if (userSession == null) return await Task.FromResult(new AuthenticationState(anonymous));

            var claimsPrincipal = new ClaimsPrincipal(new ClaimsIdentity(new List<Claim>
            {
                new Claim(ClaimTypes.Name, userSession.UserName),
                new Claim(ClaimTypes.Role, userSession.Role)
            }, "JwtAuth"));

            return await Task.FromResult(new AuthenticationState(claimsPrincipal));
        }
        catch (Exception)
        {
            return await Task.FromResult(new AuthenticationState(anonymous));
        }
    }
}

This custom provider reads the user session from ISessionStorageService to authenticate the user based on the JWT.

Step 2: Update User Authentication State

You’ll need a method to update the user authentication state when a JWT is issued or revoked. This method will store the JWT token and user data in session storage.

public async Task UpdateAuthenticationState(UserSession? userSession)
{
    ClaimsPrincipal claimsPrincipal;
    if (userSession != null)
    {
        claimsPrincipal = new ClaimsPrincipal(new ClaimsIdentity(new List<Claim>
        {
            new Claim(ClaimTypes.Name, userSession.UserName),
            new Claim(ClaimTypes.Role, userSession.Role)
        }));

        userSession.ExpiryTimeStamp = DateTime.Now.AddSeconds(userSession.ExpiresIn);
        await sessionStorageService.SaveItemEncryptedAsync("UserSession", userSession);
    }
    else
    {
        claimsPrincipal = anonymous;
        await sessionStorageService.RemoveItemAsync("UserSession");
    }

    NotifyAuthenticationStateChanged(Task.FromResult(new AuthenticationState(claimsPrincipal)));
}

This method saves the session to the storage service and notifies Blazor of changes in the authentication state.

Step 3: Retrieve JWT Token

A method to retrieve the JWT token from session storage is essential, especially for attaching it to HTTP requests.

public async Task<string> GetToken()
{
    try
    {
        var userSession = await sessionStorageService.ReadEncryptedItemAsync<UserSession>("UserSession");
        if (userSession != null && DateTime.Now < userSession.ExpiryTimeStamp) return userSession.Token;
    }
    catch (Exception) 
    {
        // Handle error
    }
    return string.Empty;
}

This method checks the session for a valid JWT and returns it if it’s still within its expiration period.

Step 4: Configure Authentication in Program.cs

Now, configure JWT authentication in the Program.cs file of your Blazor app. This setup will register the custom JwtAuthenticationStateProvider and configure the Blazor app to use it.

var builder = WebAssemblyHostBuilder.CreateDefault(args);

// Register services
builder.Services.AddScoped<AuthenticationStateProvider, JwtAuthenticationStateProvider>();
builder.Services.AddScoped<ISessionStorageService, SessionStorageService>();
builder.Services.AddAuthorizationCore();
builder.Services.AddHttpClient();

// Build and run the application
await builder.Build().RunAsync();

In this step:

  1. JwtAuthenticationStateProvider is registered to manage authentication states.
  2. AddAuthorizationCore() is called to enable authorization services.
  3. AddHttpClient() is registered to make HTTP requests, which will later include the JWT token.

Step 5: Attach JWT Token to HttpClient Requests

You need to ensure that the JWT token is attached to every HTTP request made by Blazor WebAssembly. Here’s how you can modify the HttpClient setup:

public class TokenAuthenticationStateProvider : AuthenticationStateProvider
{
    private readonly HttpClient _httpClient;
    private readonly ISessionStorageService _sessionStorageService;

    public TokenAuthenticationStateProvider(HttpClient httpClient, ISessionStorageService sessionStorageService)
    {
        _httpClient = httpClient;
        _sessionStorageService = sessionStorageService;
    }

    public override async Task<AuthenticationState> GetAuthenticationStateAsync()
    {
        var token = await GetTokenAsync();
        var anonymousState = new AuthenticationState(new ClaimsPrincipal(new ClaimsIdentity()));

        if (string.IsNullOrWhiteSpace(token))
        {
            return anonymousState;
        }

        var claims = ParseClaimsFromJwt(token);
        _httpClient.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);

        var identity = new ClaimsIdentity(claims, "jwt");
        return new AuthenticationState(new ClaimsPrincipal(identity));
    }

    private async Task<string> GetTokenAsync() => await _sessionStorageService.GetItemAsync<string>("authToken");

    private static IEnumerable<Claim> ParseClaimsFromJwt(string jwt)
    {
        var payload = jwt.Split('.')[1];
        var jsonBytes = Convert.FromBase64String(payload.PadRight(payload.Length + (payload.Length % 4), '='));
        var claims = JsonSerializer.Deserialize<Dictionary<string, object>>(jsonBytes);
        return claims.Select(kvp => new Claim(kvp.Key, kvp.Value.ToString()));
    }
}

This ensures that the JWT token is added to the Authorization header of every HTTP request made via HttpClient.

Practical Example

Finally, integrate the custom authentication provider into your Blazor application:

var builder = WebAssemblyHostBuilder.CreateDefault(args);
builder.Services.AddScoped<AuthenticationStateProvider, JwtAuthenticationStateProvider>();
builder.Services.AddScoped<ISessionStorageService, SessionStorageService>();
builder.Services.AddAuthorizationCore();
builder.Services.AddHttpClient();
await builder.Build().RunAsync();

Alternative Ways

FAQs on “Top 5 Steps to Implement JWT Authentication in Blazor”

Q: What is JWT Authentication?

ANS: JWT Authentication is a method for securely transmitting information between parties as a JSON object. This information can be verified and trusted because it is digitally signed.

Q: How do I create a custom AuthenticationStateProvider?

ANS: You can create a custom AuthenticationStateProvider by inheriting from the AuthenticationStateProvider class and overriding the GetAuthenticationStateAsync method to manage user authentication state.

Q: How do I update the user authentication state?

ANS: Implement a method in your custom AuthenticationStateProvider to update the authentication state based on user session data and notify the state change.

Q: How do I retrieve the JWT token in Blazor?

ANS: Create a method in your custom AuthenticationStateProvider to read the encrypted token from session storage and return it.

Q: How do I attach the JWT token to HttpClient requests?

ANS: Configure the HttpClient to include the JWT token in the authorization header for every request by setting DefaultRequestHeaders.Authorization in your custom AuthenticationStateProvider.

Q: How does the custom AuthenticationStateProvider handle JWT tokens?

The custom JwtAuthenticationStateProvider checks the user’s session storage for a valid JWT token. If found, it updates the authentication state and provides the token for HTTP requests.

Q: How do I ensure the JWT token is added to every HTTP request?

Use the TokenAuthenticationStateProvider to attach the JWT token to the Authorization header of every HttpClient request.

Q: What happens if the JWT token is expired?

If the JWT token is expired, the JwtAuthenticationStateProvider will remove the user session and return an anonymous state.

Q: Can I use the same approach in Blazor Server?

Yes, but the implementation will vary slightly, as Blazor Server manages authentication differently compared to Blazor WebAssembly.
