Solved: How to Force File Download in Blazor Server

In Blazor Server, developers may encounter situations where they want to allow users to download files stored on the server, triggered by an action in the Blazor app. While Blazor is primarily a UI framework, handling file downloads requires a bit more work, particularly around HTTP headers and responses. This guide will walk you through how to manage file downloads in Blazor Server using an ASP.NET Core Controller, and how to dynamically fetch files based on user input.

How Do I Implement File Downloads in Blazor Server?

When building a website with Blazor Server, such as MySpector.com, you may need to provide users with the ability to download files from your server. For this task, you must fetch the file based on some identifier (like a database ID), then trigger the download by setting the appropriate HTTP response headers and sending the file data to the browser.

What Are the Challenges in Implementing File Downloads in Blazor Server?

Blazor Server, unlike Blazor WebAssembly, runs on the server side, and communication between the client and server happens over SignalR. This setup requires you to carefully handle HTTP responses, which Blazor Server doesn’t manage directly. You may be tempted to use a Razor page to handle the download, but that approach doesn’t align with the structure Blazor uses (where components are typically in a .razor file). Therefore, a cleaner and more efficient method is to use a Controller in your Blazor Server application to handle the file download logic.

How Can I Control HTTP Response Headers for File Downloads?

To force a file download, the HTTP response must include specific headers, most importantly the Content-Disposition header, which tells the browser to treat the response as a downloadable file. This is where an ASP.NET Core Controller comes into play.

Here’s a breakdown of the steps to implement a file download feature using a controller in Blazor Server:

Step-by-Step Guide to Implementing File Downloads

Step 1: Create an ASP.NET Core Controller for Downloading Files

You will need to create a controller to handle the file download logic. In this example, we’ll use a controller to retrieve a file based on a database ID, and send it to the client.

using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Mvc;
using System.IO;
using MySpector.Core;
using MySpector.Objects;
using System.Net.Mime;
using NLog;

namespace FrontEnd.Pages
{
    [Route("api/[controller]")]
    [ApiController]
    public class DownloadController : Controller
    {
        private static Logger _log = LogManager.GetCurrentClassLogger();
        private ResultStorage _resultStorage;

        // GET /api/Download/{resultDbId}
        [HttpGet("{resultDbId:int}")]
        public ActionResult Get(int resultDbId)
        {
            bool isConnected = ServiceLocator.Instance.Repo.Connect();
            if (!isConnected)
            {
                _log.Error("Cannot connect");
                _log.Error("Returning Http 404");
                return NotFound();
            }
            else
            {
                _log.Debug("Connected to db");
                _log.Debug("Input: ResultDbId=" + resultDbId);
                _resultStorage = ServiceLocator.Instance.Repo.GetSingleResult(resultDbId);
            }

            if (_resultStorage == null)
            {
                _log.Error("Returning Http 404");
                return NotFound();
            }

            string filename = _resultStorage.File.FilePath;
            var cd = new ContentDisposition
            {
                FileName = filename,
                Inline = true,
            };

            Response.Headers.Add("Content-Disposition", cd.ToString());
            byte[] filedata = System.IO.File.ReadAllBytes(filename);
            string contentType = "application/octet-stream";
            return File(filedata, contentType);
        }
    }
}

Explanation of the Code:

  1. Controller Setup: We define a DownloadController with the route api/[controller]. The controller will handle requests to /api/Download/{resultDbId}.
  2. Database Connection: The method first tries to connect to the database. If the connection fails, it returns a 404 (Not Found) response.
  3. Fetching the File: If the connection is successful, it retrieves the file using the database ID (resultDbId). If no file is found, it returns a 404 response.
  4. Setting the Content-Disposition Header: The Content-Disposition header is set with the filename, instructing the browser to treat the response as a downloadable file.
  5. Reading the File: The file is read from the disk using System.IO.File.ReadAllBytes and sent in the response body with a Content-Type of application/octet-stream.

Step 2: Calling the File Download API from Blazor

Once the API endpoint is set up, you can trigger the file download from your Blazor component or page by calling this API and linking to it dynamically.

Example:

@page "/download/{DbId:int}"
@inject NavigationManager Navigation

<button @onclick="DownloadFile">Download File</button>

@code {
    private async Task DownloadFile()
    {
        int dbId = 123;  // Example database ID
        string downloadUri = $"api/Download/{dbId}";
        Navigation.NavigateTo(downloadUri, true);
    }
}

Explanation of the Code:

  • The @page directive defines the route for the page (/download/{DbId:int}).
  • The DownloadFile method builds the download URI and uses Navigation.NavigateTo to redirect the user to the API endpoint, forcing the file to be downloaded.

Alternative Methods for File Downloads in Blazor Server

Although using a controller to handle file downloads is the recommended approach, there are alternative methods depending on your needs:

  • JavaScript Interop: You can write a JavaScript function to handle the file download and invoke it from your Blazor component using JavaScript interop. This method gives you more control over the download process, but it requires additional client-side code.
  • Static Files: If your files are static and don’t require dynamic fetching from a database, you can simply serve them as static files through ASP.NET Core. This method is simpler but lacks flexibility for dynamic content.

FAQs on File Download in Blazor Server

Q: How do I force a file download in Blazor Server?

ANS: To force a file download in Blazor Server, you need to use an ASP.NET Core Controller that handles the file retrieval, sets the appropriate HTTP headers (like Content-Disposition), and returns the file to the browser.

Q: Can I use Blazor components to handle file downloads?

ANS: While Blazor components are great for UI and logic, they cannot directly manage HTTP response headers. Using a controller is the best approach for file downloads.

Q: What is the `Content-Disposition` header used for?

ANS: The Content-Disposition header informs the browser that the content should be treated as a downloadable file, rather than displayed inline. It also allows you to specify the filename for the downloaded file.

Q: Can I use JavaScript for file downloads in Blazor?

ANS: Yes, you can use JavaScript interop to trigger a file download from Blazor, but using an ASP.NET Core Controller is a cleaner and more server-side-centric approach.

Q: How can I dynamically fetch files from a database for download?

ANS: You can fetch files dynamically from a database by using a controller that takes an ID as input, retrieves the corresponding file from the database, and sends it to the browser.
