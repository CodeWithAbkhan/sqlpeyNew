Top 5 Steps to Add Authentication in a Blazor Web App (.NET 8 SSR)

Blazor has become a go-to framework for building interactive web UIs using C#. With the advent of .NET 8, there are new templates and features, including Server-Side Rendering (SSR) for Blazor. In this guide, we’ll walk you through the process of adding authentication to a Blazor Web App (SSR) using the command-line interface (CLI). This is especially useful for developers looking to secure their applications with individual accounts.

In .NET 8, setting up authentication for Blazor SSR projects requires a slightly different approach than previous versions. This guide will help you navigate the necessary commands and configurations step-by-step.

Step 1: Install .NET 8 SDK

Before you can create a Blazor SSR project, ensure that you have the .NET 8 SDK installed on your machine.

## Check if .NET 8 SDK is installed
dotnet --version
## If not installed, download from:
## https://dotnet.microsoft.com/en-us/download/dotnet

This command checks if you have the .NET 8 SDK installed. If you don’t, visit the official .NET download page to get started.

Step 2: Create a Blazor SSR Project

With the .NET 8 SDK in place, you can create a new Blazor SSR project using the following command:

dotnet new blazorserver -o MyBlazorApp

Here, blazorserver is the template for SSR in Blazor. The -o MyBlazorApp specifies the output directory.

Step 3: Adding Authentication

To add authentication to your Blazor SSR app, use the -au flag with the value Individual. This option sets up individual account authentication for your project.

dotnet new blazorserver -au Individual -o MyBlazorApp

This command scaffolds a Blazor SSR app with authentication features like login, register, and user management out-of-the-box.

Step 4: Configure Authentication in Your Project

Once the project is generated, you need to ensure that the authentication middleware is configured correctly. Open the Program.cs file and make sure the following lines are present:

var builder = WebApplication.CreateBuilder(args);

// Add services to the container.
builder.Services.AddAuthentication("Identity.Application")
    .AddIdentityCookies();

// Add authentication state provider for managing user state
builder.Services.AddScoped<AuthenticationStateProvider, CustomAuthenticationStateProvider>();

builder.Services.AddRazorComponents();
builder.Services.AddServerSideBlazor();

var app = builder.Build();

// Use authentication and authorization
app.UseAuthentication();
app.UseAuthorization();
app.MapBlazorHub();
app.Run();

This code configures authentication and authorization in your application, ensuring that your Blazor app can handle user authentication securely.

Step 5: Implementing Custom Authentication State Provider

To handle authentication state management, you can implement a custom AuthenticationStateProvider. Here’s a simple implementation:

public class CustomAuthenticationStateProvider : AuthenticationStateProvider
{
    private readonly IAuthenticationService _authService;

    public CustomAuthenticationStateProvider(IAuthenticationService authService)
    {
        _authService = authService;
    }

    public override async Task<AuthenticationState> GetAuthenticationStateAsync()
    {
        var user = await _authService.GetCurrentUserAsync();
        return new AuthenticationState(user);
    }

    public void NotifyUserAuthentication(ClaimsPrincipal user)
    {
        var authenticatedUser = Task.FromResult(new AuthenticationState(user));
        NotifyAuthenticationStateChanged(authenticatedUser);
    }

    public void NotifyUserLogout()
    {
        var anonymousUser = new ClaimsPrincipal(new ClaimsIdentity();
        NotifyAuthenticationStateChanged(Task.FromResult(new AuthenticationState(anonymousUser)));
    }
}

In this code, you fetch the current user and notify the application when a user logs in or out.

Step 6: Configure JWT and Cookies for API Authorization

To secure your APIs, configure JWT tokens and cookies as needed. Update your Program.cs:

builder.Services.AddAuthentication(options =>
{
    options.DefaultAuthenticateScheme = JwtBearerDefaults.AuthenticationScheme;
    options.DefaultChallengeScheme = JwtBearerDefaults.AuthenticationScheme;
})
.AddJwtBearer(options =>
{
    options.TokenValidationParameters = new TokenValidationParameters
    {
        ValidateIssuer = true,
        ValidateAudience = true,
        ValidateLifetime = true,
        ValidateIssuerSigningKey = true,
        ValidIssuer = "YourIssuer",
        ValidAudience = "YourAudience",
        IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes("YourSecretKey"))
    };
});

// Add cookie authentication for user sessions
builder.Services.AddAuthentication(CookieAuthenticationDefaults.AuthenticationScheme)
    .AddCookie(options =>
    {
        options.LoginPath = "/Account/Login";
        options.LogoutPath = "/Account/Logout";
    });

In this setup, replace "YourIssuer", "YourAudience", and "YourSecretKey" with your values. This setup enables both JWT and cookie-based authentication.

Step 7: Setting Up HttpClient for Authorized Requests

To send authorized requests using HttpClient, you need to configure it to include JWT tokens or cookies. You can create a custom HttpClientHandler or modify the default HttpClient. Here’s how to do it:

  1. Register HttpClient with Authorization:

Add the following lines in your Program.cs to register HttpClient:

builder.Services.AddHttpClient("AuthorizedClient", client =>
{
    client.BaseAddress = new Uri("https://api.yourservice.com/");
}).AddHttpMessageHandler<AuthorizationMessageHandler>();
  1. Create the AuthorizationMessageHandler:

Here’s how to implement a message handler that adds the JWT token to outgoing requests:

public class AuthorizationMessageHandler : DelegatingHandler
{
    private readonly IAuthenticationService _authService;

    public AuthorizationMessageHandler(IAuthenticationService authService)
    {
        _authService = authService;
    }

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        var token = await _authService.GetTokenAsync(); // Your method to retrieve the token
        if (!string.IsNullOrEmpty(token))
        {
            request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);
        }
        return await base.SendAsync(request, cancellationToken);
    }
}

Step 8: Test the Authentication Flow

Finally, run your application to test the authentication flow. You can start your application using:

dotnet run --project MyBlazorApp

Open your browser and navigate to https://localhost:5001. You should see the authentication pages such as login and register, confirming that your Blazor SSR app is secured.

Alternative Methods

If you prefer working with Visual Studio, you can create a Blazor SSR project with authentication using the GUI. Simply select the Blazor Web App template and choose “Individual User Accounts” during the project setup.

FAQs on “Top 5 Steps to Add Authentication in a Blazor Web App (.NET 8 SSR)”

Q: What is Blazor SSR?

ANS: Blazor SSR (Server-Side Rendering) is a new feature in .NET 8 that allows server-rendered Blazor components.

Q: Can I use this method in earlier versions of .NET?

ANS: The blazorserver template and certain authentication options are specific to .NET 8. For earlier versions, you might need different commands.

Q: Do I need to configure Identity separately?

ANS: No, when you use the -au Individual option, the necessary Identity configurations are included by default.

Q: Can I switch between server-side and client-side rendering?

ANS: Blazor SSR and Blazor WASM (WebAssembly) are different project templates. Switching requires creating a new project or significant reconfiguration.

Q: How do I implement JWT authentication in my Blazor app?

ANS: To implement JWT authentication, configure the AddJwtBearer method in your Program.cs file, set up token validation parameters, and create a login endpoint to generate tokens for authenticated users.

Q: Where can I learn more about Blazor and .NET?

ANS: You can visit the official Blazor documentation or the .NET download page for more information.
