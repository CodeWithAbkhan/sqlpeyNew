To successfully implement global toast notifications in a Blazor Server application using Bootstrap, follow these five crucial steps. This guide covers code explanations, practical examples, and alternative methods to enhance your Blazor Server application’s user experience.

Top 5 Steps to Implement Global Toasts in Blazor Server with Bootstrap

Step 1: Configure Bootstrap Toasts in MainLayout

Start by adding the Bootstrap toast component in MainLayout.razor. This ensures that the toasts are globally accessible throughout your application.

@inherits LayoutComponentBase

<div class="page">
    <div class="sidebar">
        <NavMenu />
    </div>
    <main>
        <article class="content px-4">
            @Body
        </article>
    </main>
    <Toasts class="p-3" Placement="ToastsPlacement.TopRight" />
</div>

<div id="blazor-error-ui">
    An unhandled error has occurred.
    <a href="" class="reload">Reload</a>
    <a class="dismiss">🗙</a>
</div>
  • Placement=“ToastsPlacement.TopRight”: Positions the toasts at the top right of the page.
  • class=“p-3”: Adds padding to the toasts container.

Step 2: Create a Toast Service

Create a service to manage toast notifications. This allows you to call the toast notifications from any component.

public class ToastService
{
    public event Action<ToastMessage> OnShow;

    public void ShowToast(ToastMessage message)
    {
        OnShow?.Invoke(message);
    }
}

public class ToastMessage
{
    public string Title { get; set; }
    public string Message { get; set; }
    public ToastLevel Level { get; set; }

    public ToastMessage(string title, string message, ToastLevel level)
    {
        Title = title;
        Message = message;
        Level = level;
    }
}

public enum ToastLevel
{
    Info,
    Success,
    Warning,
    Error
}
  • ToastService: Manages the display of toast notifications.
  • ToastMessage: Represents the content and type of toast notifications.
  • ToastLevel: Enum to define toast levels.

Step 3: Register Toast Service in Dependency Injection

Ensure your ToastService is registered in the service container to be injectable throughout your application.

builder.Services.AddSingleton<ToastService>();

Step 4: Invoke Toast Notifications

In your components, inject the ToastService and invoke toast notifications where needed. For instance, in Login.razor:

@page "/login"
@inject ToastService ToastService

<button @onclick="LogIn">Log In</button>

@code {
    private async Task LogIn()
    {
        // Authentication logic
        if (/* authentication successful */)
        {
            ToastService.ShowToast(new ToastMessage("Welcome", "You have successfully logged in.", ToastLevel.Success));
            Navigation.NavigateTo("/");
        }
        else
        {
            ToastService.ShowToast(new ToastMessage("Error", "Login failed. Please try again.", ToastLevel.Error));
        }
    }
}
  • ShowToast(new ToastMessage(…)): Displays the toast notification with the specified message and level.

Step 5: Ensure Proper Render Mode

Set the render mode to InteractiveServer in App.razor to support the global toast component.

<HeadOutlet render-mode="InteractiveServer" />
<Routes render-mode="InteractiveServer" />
  • render-mode=“InteractiveServer”: Enables interactive server-side rendering, necessary for the global toast component.

Practical Examples

Implementing the above steps ensures a seamless user experience with global toast notifications. You can extend the ToastService to include more customizable options or different toast placements.

Alternative Ways

For alternative toast implementations, consider using third-party Blazor libraries such as Blazored.Toast which offer more features and customization.

FAQs on “Top 5 Steps to Implement Global Toasts in Blazor Server with Bootstrap”

Q: How do I make toast notifications globally accessible?

A: Place the toast component in MainLayout.razor and use a toast service to manage notifications.

Q: What does `render-mode= InteractiveServer ` do?

A: It allows components to render interactively on the server, which is essential for global components like toasts.

Q: Can I customize the appearance of the toasts?

A: Yes, you can customize the toast component’s appearance using Bootstrap classes and additional CSS.

Q: What if my toasts are not showing up?

A: Ensure you have set the correct render mode in App.razor and that the ToastService is properly registered and injected.

Q: Are there any third-party libraries for Blazor toasts?

A: Yes, you can use libraries like Blazored.Toast for more advanced features.
