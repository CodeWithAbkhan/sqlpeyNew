Encountering issues when setting up a Blazor WebAssembly project can be frustrating. This guide addresses the common problem of not finding the Blazor WebAssembly template in Visual Studio and walks you through solutions, including checking Visual Studio versions, installing required templates, and using CLI commands.

Solved: How to Fix Blazor WebAssembly Template Not Found Issue

Why Does This Problem Occur?

  1. Visual Studio Version Compatibility: Using an older version of Visual Studio can result in missing templates.
  2. Incomplete Installation: The Blazor WebAssembly template may not have been installed properly.
  3. Local NuGet Package Issues: Sometimes custom or missing NuGet packages interfere with template recognition.

Step-by-Step Guide to Fixing the Problem

1. Verify Visual Studio Version

To use Blazor WebAssembly templates, you should have the Visual Studio 2019 version 16.6 preview or higher installed. This is essential because older versions do not fully support the latest Blazor features.

# Command to check the Visual Studio version:
dotnet --version

Explanation: This command checks the installed version of .NET SDK to ensure it matches or supports Blazor requirements.

2. Install Blazor WebAssembly Template Manually

If the template is not showing up, you need to install it using the command line.

# Command to install Blazor WebAssembly template:
dotnet new -i Microsoft.AspNetCore.Components.WebAssembly.Templates::3.2.0-preview5.20216.8

Explanation: This command installs the specific version of the Blazor WebAssembly template compatible with your SDK.

3. Use the Command-Line Interface to Create a New Project

If Visual Studio does not display the template, you can create a Blazor WebAssembly project directly through the CLI.

# Create a new Blazor WebAssembly project:
dotnet new blazorwasm -o MyBlazorProject

Explanation: This command generates a new project named MyBlazorProject using the Blazor WebAssembly template.

Alternative Solution: Managing NuGet Packages

Issues related to missing templates can sometimes be linked to problematic NuGet packages. Ensure there are no broken or deleted local sources.

Steps to Check and Resolve NuGet Issues:

  • Go to Tools → Options in Visual Studio.
  • Navigate to NuGet Package Manager.
  • Remove or fix any broken local sources.

Practical Example Code for Verification

using Microsoft.AspNetCore.Components.WebAssembly.Hosting;
using System.Threading.Tasks;

public class Program
{
    public static async Task Main(string[] args)
    {
        var builder = WebAssemblyHostBuilder.CreateDefault(args);
        builder.RootComponents.Add<App>("#app");
        builder.Services.AddScoped<SomeService>();

        await builder.Build().RunAsync();
    }
}

Explanation: This snippet initializes a Blazor WebAssembly project with basic setup code to ensure the template functions as expected.
