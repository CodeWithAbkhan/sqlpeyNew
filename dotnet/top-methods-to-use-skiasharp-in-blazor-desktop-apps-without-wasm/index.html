Integrating SkiaSharp with a Blazor desktop application without relying on WASM (WebAssembly) is challenging but possible through alternative methods. This guide delves into practical ways to achieve this, explains the reasons behind WASM’s necessity, and explores workarounds using MAUI components.

Can You Use SkiaSharp Directly in a Blazor Desktop App Without WASM?

Why Isn’t WASM Avoidable in Blazor Hybrid?

The challenge lies in the architecture of Blazor Hybrid, which incorporates a browser-like environment even in desktop contexts. This setup ensures adherence to web standards, requiring WebAssembly (WASM) for components like SkiaSharp to function as they do in a web environment.

What Is the Solution?

SkiaSharp can be utilized in MAUI independently of Blazor components. Here’s how this works:

  • Run SkiaSharp in parts of a MAUI app that aren’t embedded in the Blazor WebView.
  • Overlay MAUI controls on top of Blazor content, even if they don’t share screen location awareness.

How to Integrate SkiaSharp in a MAUI App

Step-by-Step Implementation of SkiaSharp in MAUI:

  1. Add the SkiaSharp Package: Ensure the SkiaSharp.Views.Maui.Core NuGet package is included in your project.

  2. Set Up the XAML Page:

    <ContentPage xmlns:skia="clr-namespace:SkiaSharp.Views.Forms;assembly=SkiaSharp.Views.Forms"
             x:Class="MyApp.GraphicsPage">
    <skia:SKCanvasView PaintSurface="OnPaintSurface" />
</ContentPage>

  3. Implement the Code-Behind Logic:

    using SkiaSharp;
using SkiaSharp.Views.Forms;

namespace MyApp
{
    public partial class GraphicsPage : ContentPage
    {
        public GraphicsPage()
        {
            InitializeComponent();
        }

        private void OnPaintSurface(object sender, SKPaintSurfaceEventArgs e)
        {
            var canvas = e.Surface.Canvas;
            canvas.Clear(SKColors.White);

            using (var paint = new SKPaint())
            {
                paint.Color = SKColors.Red;
                paint.StrokeWidth = 3;
                paint.IsAntialias = true;
                canvas.DrawLine(10, 10, 200, 200, paint);
            }
        }
    }
}

Explanation of the Code:

  • canvas.Clear(SKColors.White);: Clears the canvas to a white background.
  • using (var paint = new SKPaint()) { ... }: Creates a paint object with defined properties such as color and stroke width.
  • canvas.DrawLine(10, 10, 200, 200, paint);: Draws a line from coordinate (10, 10) to (200, 200).

Can SkiaSharp Be Integrated into a Blazor WebView?

No, SkiaSharp cannot directly integrate into a Blazor WebView due to the underlying browser-based rendering. However, it can be displayed alongside Blazor content in a MAUI layout.

Practical Example of SkiaSharp in a Blazor-MAUI Hybrid:

<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             xmlns:skia="clr-namespace:SkiaSharp.Views.Forms;assembly=SkiaSharp.Views.Forms"
             x:Class="MyApp.MainPage">
    <Grid>
        <skia:SKCanvasView PaintSurface="OnPaintSurface" />
        <BlazorWebView HostPage="wwwroot/index.html">
            <BlazorWebView.RootComponents>
                <RootComponent Selector="#app" ComponentType="{x:Type myApp:Main}" />
            </BlazorWebView.RootComponents>
        </BlazorWebView>
    </Grid>
</ContentPage>

Alternative Methods for Using Graphics in Blazor

Consider MAUI’s built-in graphics library with a Skia backend for advanced features:

using Microsoft.Maui.Graphics.Skia;

public class CustomDrawable : IDrawable
{
    public void Draw(ICanvas canvas, RectF dirtyRect)
    {
        canvas.StrokeColor = Colors.DarkBlue;
        canvas.StrokeSize = 4;
        canvas.DrawRectangle(50, 50, 150, 100);
    }
}

FAQs on Top Methods to Use SkiaSharp in Blazor Desktop Apps Without WASM

Q: Can I use SkiaSharp directly in a Blazor component?

ANS: No, SkiaSharp cannot be directly integrated into a Blazor component due to rendering limitations related to web standards.

Q: What alternatives are there for SkiaSharp in Blazor?

ANS: Use SkiaSharp within the non-Blazor part of a MAUI app or employ the MAUI graphics library with a Skia backend.

Q: How do you create a drawing surface in MAUI?

ANS: Utilize the SKCanvasView in XAML and define the PaintSurface event in the C# code-behind for custom rendering.

Q: Is WASM necessary for all Blazor hybrid apps?

ANS: While not mandatory for Blazor Server or Blazor Hybrid, WebAssembly is essential for rendering graphics within a web-like browser environment.

Q: Can SkiaSharp coexist with Blazor content on the same page?

ANS: Yes, SkiaSharp and Blazor WebView can share the same MAUI page layout, but they function as independent elements.
