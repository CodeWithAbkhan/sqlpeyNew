Top 5 Steps to Use Authentication WebAPI from an Existing Blazor Project in .NET MAUI

Integrating an existing Blazor project’s authentication WebAPI with a .NET MAUI app can be challenging. This guide will walk you through the top 5 steps to achieve this, complete with unique code examples and clear explanations.

Step 1: Set Up Identity in Blazor Project

First, ensure your Blazor project uses Microsoft.AspNetCore.Identity for authentication and authorization.

// In Program.cs of Blazor project
builder.Services.AddIdentity<ApplicationUser, IdentityRole>()
    .AddEntityFrameworkStores<ApplicationDbContext>()
    .AddDefaultTokenProviders();

builder.Services.AddAuthentication()
    .AddCookie(options =>
    {
        options.LoginPath = "/Account/Login";
        options.AccessDeniedPath = "/Account/AccessDenied";
    });

Explanation:

  • AddIdentity<ApplicationUser, IdentityRole>(): Registers Identity services.
  • AddAuthentication().AddCookie(): Adds cookie-based authentication.

Step 2: Expose Identity API Endpoints

Expose Identity API endpoints to be consumed by the .NET MAUI application.

// In Program.cs of Blazor project
builder.Services.AddIdentityApiEndpoints<ApplicationUser>(options =>
{
    options.SignIn.RequireConfirmedAccount = true;
})
.AddRoles<IdentityRole>()
.AddEntityFrameworkStores<ApplicationDbContext>()
.AddSignInManager();

app.MapIdentityApi<ApplicationUser>();

Explanation:

  • AddIdentityApiEndpoints<ApplicationUser>(options => { ... }): Exposes API endpoints for Identity.
  • MapIdentityApi<ApplicationUser>(): Maps the Identity API endpoints.

Step 3: Configure .NET MAUI to Use Identity API

Set up the .NET MAUI application to consume the Identity API from the Blazor project.

// In MauiProgram.cs
builder.Services.AddSingleton<HttpClient>();

builder.Services.AddAuthentication(options =>
{
    options.DefaultScheme = JwtBearerDefaults.AuthenticationScheme;
})
.AddJwtBearer(options =>
{
    options.Authority = "https://your-blazor-api-url";
    options.Audience = "your-api-resource-name";
    options.RequireHttpsMetadata = false;
    options.TokenValidationParameters = new TokenValidationParameters
    {
        ValidateIssuer = true,
        ValidateAudience = true,
        ValidateLifetime = true,
        ValidateIssuerSigningKey = true,
        ValidIssuer = "your-issuer",
        ValidAudience = "your-audience"
    };
});

Explanation:

  • AddSingleton<HttpClient>(): Registers HttpClient as a singleton service.
  • AddAuthentication().AddJwtBearer(options => { ... }): Configures JWT bearer authentication.

Step 4: Implement Login and Token Management in .NET MAUI

Create a service in .NET MAUI to handle login and token management.

public class AuthService
{
    private readonly HttpClient _httpClient;

    public AuthService(HttpClient httpClient)
    {
        _httpClient = httpClient;
    }

    public async Task<string> LoginAsync(string username, string password)
    {
        var response = await _httpClient.PostAsJsonAsync("/api/account/login", new { username, password });

        if (response.IsSuccessStatusCode)
        {
            var token = await response.Content.ReadAsStringAsync();
            _httpClient.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);
            return token;
        }

        return null;
    }
}

Explanation:

  • AuthService: Service class for authentication.
  • LoginAsync(string username, string password): Logs in and sets the bearer token.

Step 5: Implement Role-Based UI in .NET MAUI

Use the roles from the Identity API to render UI elements conditionally in .NET MAUI.

// In a .NET MAUI ViewModel
public class MainViewModel
{
    private readonly AuthService _authService;

    public MainViewModel(AuthService authService)
    {
        _authService = authService;
    }

    public async Task InitializeAsync()
    {
        var token = await _authService.LoginAsync("user@example.com", "password123");

        if (token != null)
        {
            // Fetch user roles and update UI accordingly
        }
    }
}

Explanation:

  • MainViewModel: ViewModel for the main page.
  • InitializeAsync(): Logs in and fetches user roles to update the UI.

Alternative Ways

If you prefer not to expose Identity API endpoints, consider using shared authentication libraries or implementing a custom authentication mechanism.

Example:

// Using a shared authentication library
builder.Services.AddIdentityCore<ApplicationUser>()
    .AddEntityFrameworkStores<ApplicationDbContext>()
    .AddSignInManager();

Explanation:

  • AddIdentityCore<ApplicationUser>(): Adds core Identity services without exposing API endpoints.

FAQs on “Top 5 Steps to Use Authentication WebAPI from an Existing Blazor Project in .NET MAUI”

Q: How do I configure .NET MAUI to use an existing Blazor project's authentication?

ANS: Expose Identity API endpoints in the Blazor project and configure .NET MAUI to consume these endpoints using JWT bearer authentication.

Q: Can I use the same user roles in both Blazor and .NET MAUI applications?

ANS: Yes, you can use the same user roles by exposing Identity API endpoints and managing roles through these APIs.

Q: How do I handle token management in .NET MAUI?

ANS: Implement a service in .NET MAUI to handle login and token management, setting the bearer token in the HttpClient.

Q: Is it necessary to expose Identity API endpoints?

ANS: No, you can use shared authentication libraries or implement a custom authentication mechanism if you prefer not to expose API endpoints.

Q: How do I render UI elements based on user roles in .NET MAUI?

ANS: Fetch user roles from the Identity API and update the UI conditionally based on these roles.
