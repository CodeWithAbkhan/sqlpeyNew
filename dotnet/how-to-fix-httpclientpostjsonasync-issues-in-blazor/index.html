When working with Blazor applications, especially Blazor Server apps in ASP.NET Core 3.1, the HttpClient.PostJsonAsync method can sometimes throw unexpected errors like a 404 (Not Found) or 405 (Method Not Allowed) response in the browser console. In this post, we will discuss how to fix these errors and why they occur.

Summary

Many Blazor developers face issues when trying to use the PostJsonAsync method to send user data to an API endpoint. The most common issues are related to incorrect routing or the wrong use of HTTP methods in the backend. This article will break down the cause of the errors and walk you through the steps to resolve them.

What is causing the 404 error in my Blazor app when using PostJsonAsync?

In the Blazor app, when a 404 error is thrown, it typically means the client can’t find the endpoint. This may happen due to a routing issue or incorrect URL formatting. In your Blazor app, you are trying to call:

var rpta = await Http.PostJsonAsync<int>($"{baseUrl}api/Accont/Login", userInfo);

But this URL is returning a 404 error, indicating that the API route is not being found. So, what might be going wrong here?

How do I resolve the 404 error?

Check the following possible issues:

  1. URL Formatting:

    • Ensure that the base URL is correct. Your code snippet shows: 
      private const string baseUrl = "localhost:44348/";
      This might not include the protocol (http:// or https://), so it should be: 
      private const string baseUrl = "https://localhost:44348/";

  2. Route Path:

    • The route might not be defined properly in the API. Ensure that the API route is correctly defined in your AccountController. For example:
    [HttpPost]
[Route("api/Account/Login")]
public int Login([FromBody] UserInfo userInfo)
{
    // Login logic
}

    The route should match exactly what you’re trying to call in the Blazor app (api/Account/Login), considering the controller’s route name.

What causes the 405 (Method Not Allowed) error?

The 405 error happens when the HTTP method used for the request is not allowed by the server. For instance, if you use HttpMethod.Post on a route that only accepts GET requests, this error will occur.

How to fix the 405 error?

Ensure that the backend endpoint is set to accept POST requests. Your method should have the correct HTTP verb as shown below:

[HttpPost]
[Route("api/Account/Login")]
public int Login([FromBody] UserInfo userInfo)
{
    int rpta = 0;
    try
    {
        // Business logic
    }
    catch (Exception ex)
    {
        rpta = 0;
    }
    return rpta;
}

Practical Example of HttpClient.PostJsonAsync

Here is a corrected example of how to use PostJsonAsync in your Blazor app for user login:

private async Task<bool> ValidateUser()
{
    var endpoint = $"{baseUrl}api/Account/Login";
    try
    {
        var rpta = await Http.PostJsonAsync<int>(endpoint, userInfo);
        if (rpta != 0)
        {
            ((CustomAuthenticationStateProvider)auth).UserLogin(rpta.ToString());
            NavigationManager.NavigateTo("catalog");
        }
        else
        {
            LoginMessage = "Correo o contraseña incorrectos";
        }
    }
    catch (HttpRequestException ex)
    {
        LoginMessage = "Error de conexión";
    }
    return await Task.FromResult(true);
}

Why does the PostJsonAsync method fail to send the correct request?

If you are still facing issues with PostJsonAsync not working properly, check the following:

  1. Model Binding Issues: Ensure that your userInfo object is correctly serialized into JSON.
  2. Check Controller Name and Route: Ensure the controller’s route matches what the Blazor app expects.
  3. API Server Running: Ensure the API server is running, and there are no CORS issues preventing the request.

Alternative Methods: Can I use SendJsonAsync?

If PostJsonAsync continues to cause issues, you can try using SendJsonAsync to make a more customizable HTTP request:

private async Task<bool> ValidateUser()
{
    string endpoint = $"{baseUrl}api/Account/Login";
    var rpta = await Http.SendJsonAsync<int>(HttpMethod.Post, endpoint, userInfo);
    if (rpta != 0)
    {
        ((CustomAuthenticationStateProvider)auth).UserLogin(rpta.ToString());
        NavigationManager.NavigateTo("catalog");
    }
    else
    {
        LoginMessage = "Correo o contraseña incorrectos";
    }
    return await Task.FromResult(true);
}

FAQs on HttpClient.PostJsonAsync in Blazor

Q: Why am I getting a 404 error when calling `PostJsonAsync` in Blazor?

ANS:
The 404 error usually occurs because the API route is not found. Ensure that the route in your backend controller matches exactly with the URL you’re calling from your Blazor app.

Q: How do I fix the `405 Method Not Allowed` error?

ANS:
The 405 error occurs when the HTTP method (POST, GET, etc.) is not allowed by the API endpoint. Ensure that your backend is configured to handle POST requests for the given endpoint.

Q: What should I do if `PostJsonAsync` fails to send data?

ANS:
Check the model binding and ensure that the object you’re sending is correctly serialized into JSON. You can also try SendJsonAsync as an alternative.

Q: How can I ensure the backend accepts the correct HTTP method?

ANS:
Double-check the [HttpPost] attribute in your controller’s method and make sure the route matches the one used in your Blazor app.

Q: Why does the login not work after sending the POST request?

ANS:
There might be a problem with how the server responds to the request or the user data sent. Check the request data, ensure correct API routing, and ensure the server returns the appropriate response.
