If you’re struggling to find the Blazor WebAssembly template in Visual Studio for Mac, you’re not alone. This guide will walk you through the top 5 steps to resolve this issue, providing unique code examples and alternative approaches to get your Blazor WebAssembly project up and running on a Mac.

Top-5-Steps-to-Solve-Missing-Blazor-WebAssembly-Template-Issue

Step 1: Ensure .NET Core SDK Installation

First, verify that you have the correct version of the .NET Core SDK installed. For Blazor WebAssembly, you need at least .NET Core 3.1.

  • Command to check SDK version:

    dotnet --version

    This command will display the version of the SDK you have installed. Ensure it matches or exceeds the requirements for Blazor WebAssembly.

Step 2: Install Blazor WebAssembly Template Manually

If the Blazor WebAssembly template is missing, you can manually install it via the .NET CLI. Here’s a unique approach to ensure the correct template is installed:

dotnet new -i Microsoft.AspNetCore.Blazor.Templates::3.2.0-preview1.20073.1

Line-by-Line Explanation:

  • dotnet new -i: This command installs a new template.
  • Microsoft.AspNetCore.Blazor.Templates: The specific package name for the Blazor template.
  • ::3.2.0-preview1.20073.1: This specifies the exact version of the template to install.

Step 3: Use CLI to Create and Run Blazor WebAssembly App

If Visual Studio for Mac doesn’t display the template, you can create a Blazor WebAssembly app directly from the CLI and then open it in Visual Studio for Mac.

dotnet new blazorwasm -n MyBlazorApp

This command will create a new Blazor WebAssembly project named MyBlazorApp. You can then open this project in Visual Studio for Mac by navigating to File > Open Project or Solution and selecting the .csproj file.

  • Pro Tip: Use the CLI to build and run the project:

    cd MyBlazorApp
dotnet build
dotnet run

This sequence of commands builds and runs the Blazor WebAssembly app. You can then view it in your browser at http://localhost:5000.

Step 4: Update Visual Studio for Mac

If the above steps don’t resolve the issue, update your Visual Studio for Mac to the latest version. Microsoft has addressed this issue in Visual Studio for Mac 8.6, where full support for Blazor WebAssembly projects was added.

  • Updating Visual Studio for Mac:
    • Go to Visual Studio > Check for Updates… and update to the latest stable version.

Step 5: Fix ASP.NET Core Developer Certificate Issues

If you encounter an error related to the ASP.NET Core developer certificate after updating, resolve it by running the following commands:

dotnet dev-certs https --clean
dotnet dev-certs https
dotnet dev-certs https --trust

Explanation:

  • dotnet dev-certs https --clean: Cleans up any existing certificates.
  • dotnet dev-certs https: Creates a new developer certificate.
  • dotnet dev-certs https --trust: Trusts the newly created certificate.

Running these commands should fix the issue, allowing you to run Blazor WebAssembly projects in Visual Studio for Mac.

Practical Example

Create a Blazor WebAssembly app via CLI, open it in Visual Studio for Mac, and run it. If you encounter a developer certificate error, follow Step 5 to resolve it.

Alternative Ways to Solve the Issue

  • Using Visual Studio Preview: If you’re still facing issues, try using the preview version of Visual Studio for Mac, which often includes fixes and features not yet available in the stable release.
  • Manual Template Download: Alternatively, you can manually download the Blazor WebAssembly template from Microsoft’s official repository .
