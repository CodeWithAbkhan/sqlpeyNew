Implementing MudBlazor’s MudDataGrid to handle server-side data fetching can be daunting, especially when dealing with features like pagination, filtering, and row-click handling. This post will walk you through the Top 5 Steps to efficiently implement MudDataGrid with server data, ensuring a seamless and interactive experience.

1. Setup DTOs for Request and Response Handling

Before diving into the MudDataGrid setup, define DTOs to manage the data request and response between the client and the server.

public class GridDataRequestDto
{
    public int Page { get; set; } = 0; // The current page number
    public int PageSize { get; set; } = 10; // Number of items per page
    public string? SearchTerm { get; set; } = null; // Optional search criteria
}

public class AnimalListDto
{
    public List<AnimalListItemDto> Items { get; set; } = new();
    public int ItemTotalCount { get; set; } = 0; // Total number of items before pagination
}

public class AnimalListItemDto
{
    public Guid Id { get; set; }
    public string Name { get; set; }
}

These DTOs serve as the foundation for your grid’s data handling, enabling clean and manageable data exchange.

2. Implementing the MudDataGrid Component

In your Blazor component, set up the MudDataGrid to connect with server-side data using the ServerData attribute.

<MudDataGrid ServerData="LoadGridData"
   T="AnimalListItemDto" @ref="_dataGrid">
    <Columns>
        <PropertyColumn Property="@(item => item.Name)" Title="Animal" />
    </Columns>
    <PagerContent>
        <MudDataGridPager T="AnimalListItemDto" />
    </PagerContent>
</MudDataGrid>

The ServerData attribute links to a method that handles data fetching. Here, LoadGridData will be responsible for this.

3. Creating the Data Loading Method

Your data loading method should fetch the data based on the grid state and return it in a format that MudDataGrid can consume.

private MudDataGrid<AnimalListItemDto>? _dataGrid;
private GridDataRequestDto _requestDto = new();

private async Task<GridData<AnimalListItemDto>> LoadGridData(GridState<AnimalListItemDto> state)
{
    _requestDto.Page = state.Page;
    _requestDto.PageSize = state.PageSize;

    AnimalListDto apiResponse = await GetAnimalList(_requestDto);
    GridData<AnimalListItemDto> data = new()
    {
        Items = apiResponse.Items,
        TotalItems = apiResponse.ItemTotalCount
    };

    return data;
}

In this method, _requestDto is populated with the current page and page size, and then used to fetch data from the API.

4. Handling Row Clicks and Custom Actions

To enhance user interaction, handle row clicks and add custom actions like editing directly within the grid.

<MudDataGrid ServerData="LoadGridData" T="AnimalListItemDto" 
    RowClick="OnRowClick" Hover="true" @ref="_dataGrid">
    <Columns>
        <PropertyColumn Property="@(item => item.Name)" Title="Animal" />
        <TemplateColumn>
            <CellTemplate>
                <button @onclick="() => EditItem(context.Item!)" @onclick:stopPropagation>Edit</button>
            </CellTemplate>
        </TemplateColumn>
    </Columns>
    <PagerContent>
        <MudDataGridPager T="AnimalListItemDto" />
    </PagerContent>
</MudDataGrid>

And the corresponding methods:

private async Task OnRowClick(DataGridRowClickEventArgs<AnimalListItemDto> args)
{
    YourViewMethod(args.Item);
}

private void EditItem(AnimalListItemDto item)
{
    YourEditMethod(item);
}

These methods allow you to handle row clicks and trigger actions like editing an item.

5. Implementing Search and Filtering

Enhance your MudDataGrid by adding search functionality that filters the data based on user input.

<EditForm Model="_requestDto" OnValidSubmit="Search">
    <InputText placeholder="e.g. Animal Name" @bind-Value="_requestDto.SearchTerm" />
    <button type="submit">Search</button>
</EditForm>

private async Task Search()
{
    if (_dataGrid is not null)
    {
        await _dataGrid!.ReloadServerData();
    }
}

By binding the search term to _requestDto, this method ensures the search term is included in the API call, enabling real-time data filtering.

FAQs on “Top 5 Steps to Efficiently Implement MudBlazor’s MudDataGrid with Server Data”

Q: How do I sort data using MudBlazor's MudDataGrid?

ANS: Implement sorting by handling the SortDefinitions property within the GridState in your LoadGridData method.

Q: Can I use MudBlazor's MudDataGrid for large datasets?

ANS: Yes, by leveraging server-side data fetching with the ServerData attribute, MudBlazor efficiently handles large datasets.

Q: How do I implement pagination in MudBlazor's MudDataGrid?

ANS: Use the MudDataGridPager component inside the PagerContent of your MudDataGrid to manage pagination.

Q: Can I customize row actions in MudBlazor's MudDataGrid?

ANS: Yes, you can add custom actions, such as edit buttons, by using TemplateColumn with a custom CellTemplate.

Q: How do I handle API errors in MudBlazor's MudDataGrid?

ANS: Implement error handling within your LoadGridData method and display error messages using MudBlazor’s MudAlert or other notification components.
