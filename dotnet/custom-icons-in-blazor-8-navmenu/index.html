Learn how to easily add custom icons to the NavMenu in your Blazor 8 application. We’ll explore a step-by-step process, provide practical examples, and discuss alternative methods to enhance your navigation menu.

Top 5 Steps to Add Custom Icons in Blazor 8 NavMenu

top-5-steps-to-add-custom-icons-in-blazor-8-navmenu

Blazor 8 introduces new ways to customize the navigation menu with custom icons. Follow these steps to integrate additional icons seamlessly:

  1. Include Bootstrap Icons
  2. Update NavMenu.razor
  3. Modify NavMenu.razor.css
  4. Use Blazorise Icons
  5. PowerShell Script for Custom Icons

1. Include Bootstrap Icons

To include Bootstrap icons in your Blazor application, add the following line in your App.razor file:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

This will allow you to use a wide range of icons from the Bootstrap Icons library.

2. Update NavMenu.razor

Remove the old icon references and update your NavMenu.razor file to use Bootstrap icons:

<NavLink class="nav-link" href="counter">
    <span class="bi bi-house-door-fill" aria-hidden="true"></span> Counter
</NavLink>

3. Modify NavMenu.razor.css

Remove existing icon classes and add new ones for Bootstrap icons:

.bi {
    top: -0.75rem; /* Adjust this value for alignment */
    font-size: 1.5rem; /* Adjust this value for size */
}

4. Use Blazorise Icons

Blazorise offers a wide range of icons. Add Blazorise to your project and update your NavMenu:

<NavLink class="nav-link" href="counter">
    <Icon Name="IconName.Add" IconSize="IconSize.Large" />
    <span style="margin-right:0.8em;"></span> Counter
</NavLink>

For detailed documentation, refer to the Blazorise Icons page.

5. PowerShell Script for Custom Icons

Use a PowerShell script to add custom icons from the Bootstrap library:

function Add-BlazorNavMenuIconFromUrl {
    param(
        [string]$IconName,
        [string]$MenuItem = "BlazorPageHere",
        [string]$BlazorPage = "BlazorPageHere"
    )

    try {
        $Url = "https://raw.githubusercontent.com/twbs/icons/main/icons/$IconName.svg"
        $response = Invoke-WebRequest -Uri $Url
        $BootstrapSvgHtml = $response.Content

        $encodedSvgHtml = $BootstrapSvgHtml -replace 'currentColor', 'white' `
            -replace '"', "'" `
            -replace '<', '%3C' `
            -replace '>', '%3E' `
            -replace "\r?\n", ""

        $svgName = [System.IO.Path]::GetFileNameWithoutExtension($Url)
        $IconClassName = "bi-$($svgName)-nav-menu"

        $cssBuilder = New-Object System.Text.StringBuilder
        [void]$cssBuilder.AppendLine(".$IconClassName {")
        [void]$cssBuilder.AppendLine("`tbackground-image: url(`"data:image/svg+xml,$encodedSvgHtml`");")
        [void]$cssBuilder.AppendLine("}")

        $newCssRule = $cssBuilder.ToString()

        Write-Host "Add the following Generated CSS to your NavMenu.razor.css:" -ForegroundColor Yellow
        Write-Host $newCssRule -ForegroundColor Cyan

        $htmlBuilder = New-Object System.Text.StringBuilder
        [void]$htmlBuilder.AppendLine('<div class="nav-item px-3">')
        [void]$htmlBuilder.AppendLine('    <NavLink class="nav-link" href="' + $BlazorPage + '">')
        [void]$htmlBuilder.AppendLine("        <span class=`"bi $IconClassName`" aria-hidden=`"true`"></span> $MenuItem")
        [void]$htmlBuilder.AppendLine('    </NavLink>')
        [void]$htmlBuilder.AppendLine('</div>')

        $htmlMarkup = $htmlBuilder.ToString()

        Write-Host "Add the following HTML to your NavMenu.razor:" -ForegroundColor Yellow
        Write-Host $htmlMarkup -ForegroundColor Green

        $clipboardBuilder = New-Object System.Text.StringBuilder
        [void]$clipboardBuilder.AppendLine($htmlMarkup)
        [void]$clipboardBuilder.AppendLine()
        [void]$clipboardBuilder.AppendLine()
        [void]$clipboardBuilder.AppendLine($newCssRule)

        Set-Clipboard -Value $clipboardBuilder.ToString()
    } catch {
        Write-Error "An error occurred: $_"
    } 
}
Add-BlazorNavMenuIconFromUrl -IconName "1-circle" -BlazorPage "/dashboard" -MenuItem="User Dashboard"

This script helps you add custom icons by encoding SVG files and updating the NavMenu.

Alternative Methods

Using Font Awesome

Another popular option is Font Awesome. You can add it to your project and use icons similarly to Bootstrap:

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0-beta3/css/all.min.css">

Then, update your NavMenu:

<NavLink class="nav-link" href="counter">
    <i class="fas fa-home"></i> Counter
</NavLink>

FAQs on Adding Custom Icons in Blazor 8 NavMenu

Q: How do I add Bootstrap icons to Blazor 8 NavMenu?

ANS: Include the Bootstrap CSS link in App.razor and use the icon classes in NavMenu.razor.

Q: Can I use Blazorise icons in NavMenu?

ANS: Yes, you can add Blazorise and update NavMenu.razor to use Blazorise icons.

Q: How do I change the size of Bootstrap icons?

ANS: Modify the font-size property in NavMenu.razor.css to adjust icon size.

Q: What other icon libraries can I use with Blazor?

ANS: You can use libraries like Font Awesome by including their CSS link and updating the NavMenu.

Q: Is there a way to automate adding icons to NavMenu?

ANS: Yes, you can use a PowerShell script to automate the process of adding custom icons.
