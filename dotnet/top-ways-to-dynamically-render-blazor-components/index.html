Blazor allows for dynamic component rendering, which is essential when working with UI elements that need to adapt based on user interactions, data types, or other dynamic conditions. This article walks through five main approaches to implement dynamic rendering effectively, including:

  1. Conditional Rendering in Razor Code
  2. Data Binding with Loops
  3. Dynamic Rendering for Polymorphic Data
  4. Using RenderFragment
  5. Utilizing the <DynamicComponent> Tag

1. Conditional Rendering in Razor Code

This approach lets you show or hide components based on conditions in your model or data. A simple @if statement works well here.

@if (_showCounter)
{
  <MyCounterComponent Count="@_count" />
}

@code {
  bool _showCounter = true;
  int _count;
}

Here, @if (_showCounter) checks the value of _showCounter before rendering the <MyCounterComponent>. You can toggle _showCounter to control component visibility.

2. Data Binding with Loops for Repeating Data Sets

For lists of components, use @foreach in Razor to bind data dynamically, ideal for situations like displaying a list of orders.

@foreach (var salesOrderLine in _salesOrder.salesOrderlines)
{
  <SalesOrderLine SOLine="@salesOrderLine" />
}

Here, each item in _salesOrder.salesOrderlines binds to a <SalesOrderLine> component, ensuring that any updates to the list automatically render the new items.

3. Handling Polymorphic Data in Lists

In scenarios where the list includes different types, use switch statements to render components based on their types.

<ul>
  @foreach (var fruit in fruits)
  {
    switch (fruit)
    {
      case PearComponent p:
        <PearComponent ParameterOfSomeSort="p" />
        break;
      case AppleComponent a:
        <AppleComponent />
        break;
      case BananaComponent b:
        <BananaComponent />
        break;
    }
  }
</ul>

Each switch case determines the correct component type to render based on fruit, allowing for flexibility when working with varied data types.

4. Dynamic Rendering Using RenderFragment

RenderFragment is useful when more control over component creation is required. RenderFragments offer low-level control by managing the component’s structure in code.

@page "/"

@foreach (var component in components)
{
  RenderFragment renderFragment = (builder) =>
  {
    builder.OpenComponent(0, component.GetType());
    builder.CloseComponent();
  };

  <div>
    <div>Before the component</div>
    @renderFragment
    <div>After the component</div>
  </div>
}

@code
{
  List<ComponentBase> components = new List<ComponentBase> { new CounterParent(), new CounterChild() };
}

In this example, RenderFragment is used to create a dynamic list of components from components. This method is useful for polymorphic lists or complex conditional rendering needs.

5. Using <DynamicComponent> for Simplified Dynamic Rendering

Introduced in .NET 6, <DynamicComponent> simplifies dynamic rendering by providing a higher-level abstraction over RenderFragment.

<DynamicComponent Type="@componentType" Parameters="new Dictionary<string, object> { { "Title", "Dynamic Title" } }" />

Here, <DynamicComponent> allows for easy dynamic rendering by setting Type to the component type and passing any necessary parameters in Parameters. This approach reduces complexity in rendering different components on the fly.

Practical Examples for Dynamic Blazor Components

Example of Using RenderTreeBuilder:

public class CustomLabel : ComponentBase
{
  [Parameter] public string Id { get; set; }
  [Parameter] public string? Label { get; set; }

  protected override void BuildRenderTree(RenderTreeBuilder builder)
  {
    if (!string.IsNullOrEmpty(Label))
    {
      builder.OpenElement(1, "label");
      builder.AddAttribute(2, "for", Id);
      builder.AddAttribute(3, "class", "custom-css-classes-here");
      builder.AddContent(4, Label);
      builder.CloseElement();
    }
  }
}

BuildRenderTree is a low-level API to control the component’s rendering directly, although it requires careful handling.

FAQs on Dynamic Rendering in Blazor

Q: How do I dynamically render components in Blazor?

ANS: Dynamic rendering can be achieved using methods like RenderFragment, conditional rendering, and <DynamicComponent> in .NET 6.

Q: What is RenderFragment in Blazor?

ANS: RenderFragment is a delegate used to dynamically create content in Razor components, allowing low-level control over rendering.

Q: What are the use cases for `<DynamicComponent>`?

ANS: <DynamicComponent> is ideal for scenarios needing type-safe dynamic rendering, especially when components vary at runtime.

Q: How can I bind data dynamically in Blazor?

ANS: Use @foreach loops in Razor to bind lists of data to components, rendering items dynamically based on list changes.

Q: Can I use RenderTreeBuilder for conditional rendering?

ANS: Yes, RenderTreeBuilder allows you to render elements conditionally, though it requires low-level manipulation of the render tree.
