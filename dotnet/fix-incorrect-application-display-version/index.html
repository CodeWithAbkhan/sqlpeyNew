Are you facing an issue where your .NET MAUI application’s display version constantly shows as “1.0.0” despite project settings indicating otherwise? This guide explores practical steps to troubleshoot and resolve display version issues in .NET MAUI, ensuring your app correctly shows its intended version.

Top 5 Steps to Fix Incorrect Application Display Version in .NET MAUI

Step 1: Verify ApplicationDisplayVersion in the Project File

Check the project file (.csproj) to confirm the ApplicationDisplayVersion is accurately set.

Code Example:

<!-- In your .csproj file -->
<PropertyGroup>
  <ApplicationDisplayVersion>1.2.3</ApplicationDisplayVersion>
</PropertyGroup>

Explanation:
This property specifies the display version number for your application. Setting it in the .csproj file includes it in the metadata during build time, ensuring the correct version appears when the app runs.

Step 2: Clean and Rebuild the Solution

Clearing old build artifacts and rebuilding your project often resolves issues related to display version mismatches.

Code Example:

dotnet clean
dotnet build

Explanation:
By cleaning the project, you remove outdated or corrupted files that can cause version conflicts. Rebuilding ensures your application reflects all updated project settings.

Step 3: Deploy to the Correct Target

Ensure the app is deployed to the correct target, like Android or iOS, to confirm that the version issue isn’t target-specific.

Explanation:
Some deployment issues occur specifically on one platform. For instance, deploying to iOS Local Device can sometimes cause Visual Studio to retain an outdated display version due to caching on local devices.

Step 4: Manually Update the Info.plist File for iOS

For iOS-specific versioning, ensure the Info.plist configuration file is up-to-date with the correct version details.

Code Example:

<!-- In your Info.plist -->
<key>CFBundleShortVersionString</key>
<string>1.2.3</string>

Explanation:
The CFBundleShortVersionString key defines the app’s version display on iOS. Updating this key ensures that the latest version number shows up on iOS devices.

Step 5: Report the Issue to the .NET MAUI Repository

If the issue continues, consider reporting it to the official .NET MAUI repository .

Explanation:
Reporting the issue can be helpful if it stems from an unresolved bug. The .NET MAUI development team may provide workarounds, fixes, or documentation updates to address known issues.

Practical Example: Displaying Version Information in .NET MAUI

The AppInfo class in Xamarin.Essentials is a handy tool for retrieving and displaying the version number directly within your application.

Code Example:

using Xamarin.Essentials;

public class AboutPage : ContentPage
{
    public AboutPage()
    {
        var versionLabel = new Label
        {
            Text = $"Version: {AppInfo.VersionString}"
        };

        Content = new StackLayout
        {
            Children = { versionLabel }
        };
    }
}

Explanation:
The AppInfo.VersionString property retrieves the version number from your project settings. Adding it to the UI allows users to see the exact version, which is especially helpful for debugging.

Alternative Approach: Using Environment Variables for Version Control

Setting environment variables provides additional control over version numbers, particularly in CI/CD workflows.

Code Example:

var version = Environment.GetEnvironmentVariable("APP_VERSION") ?? "1.0.0";

public class AboutPage : ContentPage
{
    public AboutPage()
    {
        var versionLabel = new Label
        {
            Text = $"Version: {version}"
        };

        Content = new StackLayout
        {
            Children = { versionLabel }
        };
    }
}

Explanation:
By using environment variables, you gain flexibility to adjust the version number dynamically, especially useful for deployment automation in continuous integration.

FAQs on Top 5 Steps to Fix Incorrect Application Display Version in .NET MAUI

Q: Why does my application display version always show '1.0.0'?

A: This can result from an incorrect project configuration, deployment settings, or unclean build artifacts.

Q: How do I clean and rebuild my .NET MAUI project?

A: Run the commands dotnet clean followed by dotnet build to reset and build your project afresh.

Q: How can I ensure the display version for iOS updates correctly?

A: Update the CFBundleShortVersionString key in your Info.plist file to reflect the intended version number.

Q: What should I do if the version still displays incorrectly?

A: Consider reporting the issue to the .NET MAUI repository to check for any known issues or fixes.

Q: Can I use environment variables to manage app versioning?

A: Yes, environment variables provide a flexible way to manage versioning, particularly in CI/CD processes.
