Oracle’s Guide to DDL and Transaction Rollback

Oracle’s Guide to DDL and Transaction Rollback Is DDL transactional in Oracle? DDL (Data Definition Language) statements in Oracle, such as Create or Alter, are not transactional. According to Oracle’s official documentation, the database implicitly commits the current transaction before and after every DDL statement. Essentially, DDL statements act as separate transactions to any data modifications that the statement may make. While other transactions may make modifications involving the object being modified in a DDL statement, all these operations will still run in the transaction that includes the DDL statement.
