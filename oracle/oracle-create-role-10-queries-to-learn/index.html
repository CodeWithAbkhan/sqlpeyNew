In Case of Oracle CREATE ROLE statement is used to create a role in database system , which is a set of privileges (access to control the database system), which can be granted to users or to other roles.

In company or any organization, multiple peoples works on the system, To Control users on the basis of their responsibilities, Administration needs to define some role for each staff member (system controllers).

  • Define  and sets Use roles to administer database privileges.

  • Can add privileges to a role

  • Grant the role to a user.

  • User can then enable or disable the role.

  • Do privileges granted by the role.

  • Role: contains all privileges granted to the role and all privileges of other roles granted to it.
    New role is initially empty.
    With GRANT Statement You add privileges to a role.

Security Caution!
Whenever, In Oracle SQL Database, You Define a role to a user, It will be created as default role and can be able to login. To maintain security of database system you have to make sure the defining role to a user can not be default role. As After You define/ GRANT a role to a user, You need to run ALTER USER query with DEFAULT ROLE ALL EXCEPT role and Specify the role here.  For More You Can Check Oracle Security Details Here.

You Can define a role as NOT IDENTIFIED, In case of  define IDENTIFIED EXTERNALLY or with password,
Oracle grants you the role with ADMIN privileges . And, if you define a role with IDENTIFIED GLOBALLY, then the oracle sql database make it empty and does not grant you the role.

Oracle CREATE ROLE

For Create Role, We will use JustLee Book database example (Visit our post on JustLee Book Database and get query of JustLee Book Database with Diagram). Create and execute SQL statements to perform the following actions:

1.Create a new user account. The account name with combination of your first and last name.

CREATE USER SamKaufi;

2. Attempt to login to Oracle Database (version 12c) with the recently created user account.

CONNECT SamKaufi;

3. Oracle Create Role and Assign privileges to the newly account that allow use to connect with database privilege, creating tables privilege, and altering  table privilege.

GRANT CREATE SESSION, 
CREATE TABLE, 
ALTER ANY TABLE
TO SamKaufi;

4. Using an account with the required privileges, create a role named CUSTOMER_REP that allows inserting new rows in the ORDERS and ORDERITEMS tables and deleting rows from these tables.

CREATE ROLE customer_rep; 
GRANT INSERT, 
DELETE ON orders 
TO customer_rep;

GRANT INSERT, 
DELETE ON orderitems
TO customer_rep;

5. Assign the account created in Question No.1 the CUSTOMER_REP role.

GRANT customer_rep;

6. Log in to Oracle 12c with the new account created in Question No.1.

CONNECT SamKaufi;

7. Determine the privileges currently available to the account.

SET ROLE customer_rep;

8. Revoke the privilege to delete rows in the ORDERS Table and ORDERITEMS table from the

CUSTOMER_REP role.

REVOKE DELETE 
ON ORDERS;
FROM customer_rep;

REVOKE DELETE 
ON orderitems 
FROM customer_rep;

9.Remove the CUSTOMER_REP role from the account created

REVOKE customer_rep FROM SamKaufi;

10. Delete the CUSTOMER_REP role and User Account from the Oracle 12c database. (Delete Oracle Create Role)

DROP ROLE customer_rep;

DROP USER SamKaufi;

This statement allows you to define a new role and specify the privileges that the role will have.To create a role named “Sales_Manager” with the ability to create and manage tables, views, and sequences, you could use the following SQL statement:

CREATE ROLE Sales_Manager
  IDENTIFIED BY password
  DEFAULT TABLESPACE users
  TEMPORARY TABLESPACE temp
  QUOTA UNLIMITED ON users;
