Summary of create function in Oracle: A function in Oracle is a stored program that can accept input parameters and return a value or multiple values. In this tutorial, we will learn how to create a function in Oracle using the CREATE FUNCTION statement. We will also explore the syntax and features of the create function statement, as well as provide examples using the JustLee book database.

Introduction to create function in Oracle:

In Oracle, a function is a stored program that can accept input parameters and return a value or multiple values. Functions can be used in various parts of an SQL statement, such as the SELECT list, WHERE clause, and HAVING clause. Functions can also be used in PL/SQL blocks, triggers, and stored procedures.

Syntax of create function in Oracle:

The syntax for creating a function in Oracle is as follows:

CREATE [OR REPLACE] FUNCTION function_name
(parameter_name data_type[, parameter_name data_type])
RETURN return_data_type
[AUTHID { CURRENT_USER | DEFINER }]
[DETERMINISTIC | NOT DETERMINISTIC]
[PARALLEL_ENABLE | { PIPELINED | PIPELINED_TABLE }]
IS
declaration_section
BEGIN
executable_section
[EXCEPTION
exception_section]
END;

Features of create function in Oracle:

[OR REPLACE]

The OR REPLACE option allows you to overwrite an existing function with the same name. If the function does not exist, it will be created.

AUTHID

The AUTHID clause specifies whether the function will execute with the privileges of the owner (DEFINER) or the current user (CURRENT_USER).

DETERMINISTIC | NOT DETERMINISTIC

The DETERMINISTIC option specifies that the function always returns the same result for the same input parameters. The NOT DETERMINISTIC option specifies that the function may return different results for the same input parameters.

PARALLEL_ENABLE | { PIPELINED | PIPELINED_TABLE }

The PARALLEL_ENABLE option specifies that the function can be executed in parallel. The PIPELINED option specifies that the function will return its result set using a pipe. The PIPELINED_TABLE option specifies that the function will return a table using a pipe.

create function query example 1 (JustLee book database):

Create a function to calculate the total cost of an order:

CREATE OR REPLACE FUNCTION calc_order_cost (order_id NUMBER)
RETURN NUMBER
AS
  total_cost NUMBER;
BEGIN
  SELECT SUM(price * quantity)
  INTO total_cost
  FROM orders o
  JOIN order_items oi ON o.order_id = oi.order_id
  WHERE o.order_id = order_id;
RETURN total_cost;
END;

Create a function to get the names and email addresses of customers who have placed an order:

CREATE OR REPLACE FUNCTION get_customer_info (order_id NUMBER)
RETURN SYS_REFCURSOR
AS
  customer_info SYS_REFCURSOR;
BEGIN
  OPEN customer_info FOR
  SELECT c.name, c.email
  FROM customers c
  JOIN orders o ON c.customer_id = o.customer_id
  WHERE o.order_id = order_id;
RETURN customer_info;
END;

  total_courses NUMBER;
