Summary of create custom datatype in Oracle: In this tutorial, we will learn how to create a custom datatype in Oracle using the CREATE TYPE statement. We will also cover the syntax and features of custom datatypes, and provide query examples using the JustLee Book database.  

Introduction to create custom datatype in Oracle:

In Oracle, a datatype is a set of attributes that describe the type of data that a column or variable can hold. Oracle provides a variety of predefined datatypes, such as NUMBER , VARCHAR2, and DATE . However, sometimes you may need to store data in a way that is not supported by the predefined datatypes. In these cases, you can create a custom datatype using the CREATE TYPE statement.

Syntax of create custom datatype in Oracle:

The syntax for creating a custom datatype in Oracle is as follows:

CREATE TYPE datatype_name
AS object ( attribute1 datatype,
            attribute2 datatype,
            ...
            attribute_n datatype );

Where: datatype_name is the name you want to give to your custom datatype. attribute1, attribute2, …, attribute_n are the attributes of your custom datatype. Each attribute has a name and a datatype.

Features of create custom datatype in Oracle:

Custom datatypes in Oracle have the following features:

Type inheritance

Custom datatypes can inherit attributes and methods from other datatypes. For example, you can create a custom datatype called “person” that inherits attributes such as name, age, and address from the predefined datatype “object ”.

Type evolution

Custom datatypes can evolve over time by adding or modifying attributes and methods. This allows you to make changes to your datatype as your application grows and evolves.

Query Example 1:

JustLee Book database

-- Create a custom datatype called "book"
CREATE TYPE book AS OBJECT (
  title VARCHAR2(50),
  author VARCHAR2(50),
  publisher VARCHAR2(50),
  publication_date DATE
);
-- Create a table called "books" that uses the "book" datatype
CREATE TABLE books (
book_id NUMBER,
book book
);
-- Insert some data into the "books" table
INSERT INTO books (book_id, book)
VALUES (1, book('The Great Gatsby', 'F. Scott Fitzgerald', 'Scribner', TO_DATE('1925-04-10', 'YYYY-MM-DD')));

INSERT INTO books (book_id, book)
VALUES (2, book('To Kill a Mockingbird', 'Harper Lee', 'J. B. Lippincott & Co.', TO_DATE('1960-07-11', 'YYYY-MM-DD')));

-- Query the "books" table
SELECT * FROM books;

-- Output:
-- book_id | book
-- -------- | ----------------------------------------------------------------------------------------------------------------------------
-- 1 | book('The Great Gatsby', 'F. Scott Fitzgerald', 'Scribner', TO_DATE('1925-04-10 00:00:00', 'YYYY-MM-DD HH24:MI:SS'))
-- 2 | book('To Kill a Mockingbird', 'Harper Lee', 'J. B. Lippincott & Co.', TO_DATE('1960-07-11 00:00:00', 'YYYY-MM-DD HH24:MI:SS'))

School sample database

FAQs of create custom datatype in Oracle:

Question: Can I use a custom datatype as the datatype for a column in a table?

Yes, you can use a custom datatype as the datatype for a column in a table. In the examples provided above, we created a custom datatype called “book” and used it as the datatype for the “book” column in the “books” table. Similarly, we created a custom datatype called “student” and used it as the datatype for the “student” column in the “students” table.

Question: Can I use a custom datatype in a SELECT statement?

Answer: Yes, you can use a custom datatype in a SELECT statement. In the examples provided above, we used the custom datatypes “book” and “student” in SELECT statements to retrieve data from the “books” and “students” tables.

Question: Can I modify a custom datatype after it has been created?

Answer: Yes, you can modify a custom datatype after it has been created using the ALTER TYPE statement. For example, to add an attribute called “ISBN” to the “book” datatype, you can use the following statement:

ALTER TYPE book ADD ATTRIBUTE ISBN VARCHAR2(13);
