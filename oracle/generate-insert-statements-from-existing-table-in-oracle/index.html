Example 1: Using the SELECT statement

The SELECT statement can be used to generate insert statements by selecting the data from the existing table and then inserting it into a new table. This method is useful when you want to create a new table with the same structure as the existing table but with different data. The syntax for this method is as follows:

 SELECT * INTO new_table FROM existing_table;

For this example, let’s assume we have a table named “books” in the JustLee book database and we want to generate insert statements for this table and insert the data into a new table named “books_copy”. The SQL query for this would be:

 SELECT * INTO books_copy FROM books;

The second way to generate insert statements from an existing table in Oracle is by using the INSERT INTO SELECT statement. This method allows you to copy data from one table and insert it into another table. The basic syntax for this method is as follows:

INSERT INTO table2
SELECT * FROM table1;

In this example, the SELECT statement retrieves all data from table1 and the INSERT INTO statement inserts that data into table2. You can also specify specific columns to be inserted by listing them after the INSERT INTO statement and before the SELECT statement.

In this example, we will be inserting data from the “Customers”, “Orders”, and “OrderItems” tables into a new table called “OrderSummary”. The “OrderSummary” table will contain information about the customer, their order, and the items they ordered.

First, we will create the “OrderSummary” table with the following query:

CREATE TABLE OrderSummary (
    OrderSummaryId INT PRIMARY KEY,
    CustomerId INT,
    FirstName VARCHAR(50),
    LastName VARCHAR(50),
    OrderId INT,
    OrderDate DATE,
    ItemName VARCHAR(50),
    Quantity INT,
    Price DECIMAL(10,2)
);

Next, we can use the INSERT INTO SELECT statement to insert data from the “Customers”, “Orders”, and “OrderItems” tables into the “OrderSummary” table.

INSERT INTO OrderSummary (CustomerId, FirstName, LastName, OrderId, OrderDate, ItemName, Quantity, Price)
SELECT c.CustomerId, c.FirstName, c.LastName, o.OrderId, o.OrderDate, oi.ItemName, oi.Quantity, oi.Price
FROM Customers c
INNER JOIN Orders o ON c.CustomerId = o.CustomerId
INNER JOIN OrderItems oi ON o.OrderId = oi.OrderId;

This query will select the customer id, first name, last name, order id, order date, item name, quantity, and price from the “Customers”, “Orders”, and “OrderItems” tables, and insert that data into the “OrderSummary” table.

You can now query the “OrderSummary” table to see the data that was inserted:

SELECT * FROM OrderSummary;

You can also use this technique to insert data from multiple tables into an existing table if desired, by replacing the CREATE TABLE statement with an INSERT INTO statement for an existing table.

INSERT INTO Customer_Orders (CustomerId, FirstName, LastName, OrderId, OrderDate, Total)
SELECT Customers.CustomerId, Customers.FirstName, Customers.LastName, Orders.OrderId, Orders.OrderDate, Orders.Total
FROM Customers

This query will insert data from the “CustomerId”, “FirstName”, “LastName”, “OrderId”, “OrderDate”, and “Total” columns of the “Customers” table and the “Orders” table into the “Customer_Orders” table, joining the data on the “CustomerId” column.

It is important to keep in mind that when inserting data from multiple tables, it is important to make sure that the data types of the columns being inserted match in both the source and target tables, otherwise the query will fail. Also, you should be very careful when using this method to insert data into an existing table, as it can result in data loss if not used properly.

Q: What are the advantages of using the INSERT INTO SELECT statement over the INSERT INTO statement?

A: One of the main advantages of using the INSERT INTO SELECT statement is that it allows you to copy data from one table and insert it into another table in a single statement, rather than having to perform multiple INSERT INTO statements. Additionally, the INSERT INTO SELECT statement also allows you to specify specific columns to be inserted, rather than copying over all columns from the original table.

Q: How can I insert data into multiple tables at once using the INSERT INTO SELECT statement?

A: You can use the INSERT INTO SELECT statement to insert data into multiple tables by specifying multiple table names and corresponding column names in the SELECT statement. For example, if you want to insert data into two tables, “customers” and “orders”, you can use the following query:

INSERT INTO customers (customer_id, customer_name) 
SELECT customer_id, customer_name 
FROM orders;

This query will insert the data from the “customer_id” and “customer_name” columns of the “orders” table into the corresponding columns of the “customers” table.

Q: Can I insert data from multiple tables into one table using the INSERT INTO SELECT statement?

A: Yes, you can insert data from multiple tables into one table using the INSERT INTO SELECT statement, by joining the multiple tables together in the SELECT statement. For example, if you want to insert data from the “Customers” and “Orders” tables into the “OrderItems” table, you can use the following query:

INSERT INTO OrderItems (OrderId, CustomerId, ItemName, Quantity)
SELECT Orders.OrderId, Customers.CustomerId, Orders.ItemName, Orders.Quantity
FROM Orders
JOIN Customers ON Orders.CustomerId = Customers.CustomerId;

This query will insert data into the “OrderItems” table, selecting the OrderId and CustomerId from the “Orders” table, and the corresponding CustomerId from the “Customers” table. The ItemName and Quantity will be selected from the “Orders” table as well.

Q: Can I insert data into a table from a SELECT statement that has a WHERE clause?

A: Yes, you can insert data into a table from a SELECT statement that has a WHERE clause. The WHERE clause will filter the rows from the source table that meet the specified condition, and only those rows will be inserted into the target table. For example, if you want to insert data from the “Customers” table into the “VIP_Customers” table, but only for customers with a VIP status, you can use the following query:

INSERT INTO VIP_Customers (CustomerId, FirstName, LastName, VIPStatus)
SELECT CustomerId, FirstName, LastName, VIPStatus
FROM Customers
WHERE VIPStatus = 'yes';

This query will insert all the rows from the “Customers” table where the VIPStatus column is ‘yes’ into the “VIP_Customers” table.

Q: Can I insert data into a table with a different column order than the source table?

A: Yes, you can insert data into a table with a different column order than the source table. You just need to specify the column names in the correct order in the INSERT INTO statement. For example, if you want to insert data from the “Customers” table into the “VIP_Customers” table, but the column order is different, you can use the following query:

INSERT INTO VIP_Customers (FirstName, LastName, VIPStatus, CustomerId) 
SELECT FirstName, LastName, VIPStatus, CustomerId
FROM Customers;

This query will insert all the rows from the “Customers” table into the “VIP_Customers” table, but in the specified column order in the INSERT INTO statement.

Q: Can I insert data into a table with a different data type than the source table?

A: Yes, you can insert data into a table with a different data type than the source table, but you will need to convert the data type using the appropriate function. For example, if you want to insert a date from the “Orders” table into a varchar column in the “Archived_Orders” table, you can use the TO_CHAR() function in the SELECT statement. The following query shows an example:

INSERT INTO Archived_Orders (OrderId, OrderDate)
SELECT OrderId, TO_CHAR(OrderDate, 'MM/DD/YYYY')
FROM Orders;

In this example, the OrderDate column in the “Orders” table is of type DATE, and the OrderDate column in the “Archived_Orders” table is of type VARCHAR. The TO_CHAR() function is used to convert the date to a string in the format ‘MM/DD/YYYY’, which is then inserted into the “Archived_Orders” table.

It’s worth noting that this kind of conversion may cause loss of information or may cause issues while querying the data so it should be used with caution.

A: Yes, you can insert data into a table with a different structure than the source table, but you will need to specify the columns to be inserted in the SELECT statement. INSERT INTO Archived_Books (ISBN, Title, PublicationYear)
SELECT ISBN, Title, PublicationYear

In this example, the “Archived_Books” table only has the “ISBN”, “Title” and “PublicationYear” columns, but the “Books” table has more columns. The SELECT statement only specifies the columns to be inserted, so only those columns are inserted into the “Archived_Books” table.

It’s worth noting that this way of inserting data into table with different structure will only work if the column names and datatype are same in both the tables, otherwise it will throw an error.
