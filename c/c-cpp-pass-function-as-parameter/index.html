“C/C++ How to Pass a Function as a Parameter to Another Function”

How does one effectively transmit a function’s reference so another function can execute it? This is a fundamental concept in procedural and object-oriented programming, enabling flexible design patterns like callbacks and strategy implementations. Various approaches exist across C and C++ standards, ranging from explicit pointer syntax to modern type-safe wrappers.

Explicit Function Pointer Declaration and Usage (C Style)

The most direct way to achieve this involves declaring the receiving function parameter as a pointer to a function matching the required signature.

Defining the Function Parameter Prototype

A function parameter declaration specifying it will receive a pointer to a function looks like this:

void process_data( void (*operation_ptr)(int) );

This declaration asserts that the parameter operation_ptr is a pointer to a function that returns void and accepts a single int argument.

Consider an example function conforming to this required type:

void display_value( int x_val ) {
  printf("Processed value: %d\n", x_val);
}

Invoking the Function Parameter

When calling the main function (process_data), you must supply the address of the function you wish to execute. In C, using the function’s name without parentheses automatically yields its address.

process_data(display_value); // Passing the address of display_value

Utilizing the Function Pointer Inside the Body

Within the body of process_data, you use the dereference operator (*) on the function pointer name to execute the pointed-to function. If process_data iterates and applies the passed function to numbers 0 through 4:

void process_data ( void (*operation_ptr)(int) ) {
  for ( int counter = 0 ; counter < 5 ; counter++ ) {
    (*operation_ptr)(counter); // Dereference the pointer to call the function
  }
}

Complete C Example (Direct Pointer Syntax):

#include <stdio.h>

void display_value( int x_val ) {
  printf("Value received: %d\n", x_val);
}

void process_data ( void (*operation_ptr)(int) ) {
  for ( int counter = 0 ; counter < 5 ; counter++ ) {
    (*operation_ptr)(counter);
  }
}

int main() {
  process_data(display_value);
  return 0;
}
// Output will show values 0 through 4 being passed to display_value

Alternative Simplification (Implicit Dereference): Many compilers permit omitting the explicit dereference (*) when calling through a function pointer, allowing operation_ptr(counter);. However, explicit dereferencing ((*operation_ptr)(counter);) aligns more closely with pointer arithmetic principles.

Enhancing Readability with typedef

Function pointer syntax, particularly when nested deeply, can become cryptic. A frequent technique to improve clarity is using typedef to create an alias for the function pointer type.

Defining a Type Alias

For a function returning void with no arguments:

typedef void (*OperationHandler)();

void execute_action() {
    printf("Action performed.\n");
}

// Usage:
OperationHandler handler_var = &execute_action;
handler_var(); // Invoking via the typedef'd variable

For a function returning int and taking a char:

typedef int (*IntCharConverter)(char);

int transform_char(char input) { return (int)input - 32; } // ASCII conversion example

// Usage:
IntCharConverter converter = &transform_char;
int result = converter('a');

Note on Address Operator (&): While the address-of operator (&) is valid when assigning a function’s address to a function pointer, it is often omitted in modern C/C++ code, as the function name itself suffices, similar to array decay.

External Library Assistance

For extremely complex signatures, external libraries like Boost offer enhanced type abstractions. For instance, Boost’s function library provides a cleaner syntax:

// Boost example for int(char) signature
boost::function<int (char)> nice_converter;

Modern C++ Abstractions (C++11 and Later)

C++ introduced std::function within the <functional> header, offering a highly flexible, type-erased wrapper that can hold any callable entity, including function pointers, lambda expressions, and objects with overloaded operator().

Using std::function

The syntax specifies the desired return type first, followed by the parameter types in parentheses:

std::function<ReturnType (Param1Type, Param2Type, ...)> variable_name;

Example using std::function:

#include <functional>
#include <iostream>

// Function accepting another callable entity
double combine_values(double a, double b, std::function<double (double,double)> op_func){
  return op_func(a,b);
}

double add(double x, double y){
  return x + y;
}

double multiply(double x, double y){
  return x * y;
}

int main(){
  // Passing named functions
  double sum_result = combine_values(10.0, 5.0, add);
  double prod_result = combine_values(10.0, 5.0, multiply);

  // Passing a lambda expression (highly flexible)
  auto power_op = [](double x, double y) { return std::pow(x, y); };
  double pow_result = combine_values(2.0, 3.0, power_op);
  
  std::cout << "Sum: " << sum_result << std::endl;      // 15
  std::cout << "Product: " << prod_result << std::endl; // 50
  std::cout << "Power: " << pow_result << std::endl;    // 8
  return 0;
}

Alternative: Template Functions

For maximum flexibility without the runtime overhead sometimes associated with std::function (though modern compilers often optimize this away), template functions can accept any type T that satisfies the requirements of being callable:

template<class Callable>
double combinator_template(double a, double b, Callable func){
  return func(a,b);
}

// Usage remains the same as the std::function example above:
// combinator_template(12, 13, Add);

Passing by Function Signature (Implicit Pointer Conversion)

In C, when a function declaration specifies a parameter as a function type (not explicitly a pointer type), the compiler automatically adjusts the declaration to be a pointer to that function type, per ISO C standards.

This means:

void interface_a( int receiver(int, int) );

Is functionally identical to:

void interface_b( int (*receiver)(int, int) );

Practical Example: Implementing a Customizable Sort Comparator

A classic use case is passing a comparison logic function to a generic sorting algorithm, allowing the sort function itself to remain generic while its comparison behavior changes.

#include <iostream>
#include <utility> // For std::swap

// Comparison Function (e.g., Descending order logic)
bool compare_descending(int a, int b) {
    return a > b; // Return true if a should come before b (a is greater)
}

// Generic Bubble Sort accepting a custom comparator function
void customizable_bubble_sort(int arr[], int n, bool (&cmp)(int a, int b)) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < (n - 1 - i); j++) {
            // Use the passed comparison function
            if (cmp(arr[j], arr[j + 1])) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}

int main()
{
    int data[] = { 50, 10, 80, 30, 60 };
    int size = 5;

    // Pass the address of the custom comparison logic
    customizable_bubble_sort(data, size, compare_descending);
    
    std::cout << "Sorted Array (Descending): ";
    for (int i = 0; i < size; i++) {
        std::cout << data[i] << " ";
    }
    std::cout << std::endl; // Output: 80 60 50 30 10 
    return 0;
}

FAQs on C C++ How to Pass a Function as a Parameter to Another Function

Q: What is the declaration syntax for a function parameter that accepts another function

ANS: The syntax requires defining a pointer to the function signature, like void func_ptr(void (*f)(int)).

Q: Is passing the function name alone sufficient when calling the recipient function

ANS: Yes, when calling the function that expects a function pointer, using the function name without parentheses (func_name) passes its address implicitly.

Q: What is the main benefit of using typedef with function pointers

ANS: Using typedef creates a cleaner, more readable name for a complex function pointer type, simplifying declarations and assignments.

Q: How does std::function differ from a raw function pointer in C++

ANS: std::function is a generic wrapper introduced in C++11 that can store and invoke any callable object (pointers, lambdas, functors), whereas a raw function pointer is limited to standard C-style functions.
