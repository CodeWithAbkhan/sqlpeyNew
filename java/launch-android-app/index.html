“Launch Another Android App From Your App: Java & Kotlin Examples”

When developing an Android application, you might need to launch another app, for instance, to provide a feature that relies on external functionality or to direct users to a related application. This process involves using Android’s Intent system to communicate with other applications. The key is to correctly identify the target application and handle scenarios where it might not be present on the device.

Several approaches exist to achieve this, each with its nuances. The primary goal is to obtain a launch Intent for the desired application. If the Intent is successfully retrieved, you can start that application’s main activity. If not, you can gracefully redirect the user to the Google Play Store to download it.

FAQs on Launch Another Android App From Your App

Q: How to launch an app using its package name

ANS: You can retrieve the launch intent for a specific package name using PackageManager.getLaunchIntentForPackage(). If the intent is not null, you can start the activity. This is a fundamental way to initiate another application.

// Java Example
Intent launchIntent = getPackageManager().getLaunchIntentForPackage("com.package.address");
if (launchIntent != null) { 
    startActivity(launchIntent); // Null check to prevent crashes
}

// Kotlin Example
val launchIntent = packageManager.getLaunchIntentForPackage("com.package.address")
if (launchIntent != null) {
    startActivity(launchIntent)
}

Q: What to do if the app is not installed

ANS: If getLaunchIntentForPackage() returns null, the application is likely not installed. In this situation, you can create a new intent to open the Google Play Store page for that package.

// Java Example
Intent intent = getPackageManager().getLaunchIntentForPackage("com.package.name");
if (intent == null) {
    // App not found, redirect to Play Store
    intent = new Intent(Intent.ACTION_VIEW);
    intent.setData(Uri.parse("market://details?id=" + "com.package.name"));
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK); // Essential for starting from a non-activity context
} else {
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
}
startActivity(intent);

// Kotlin Example
var intent = packageManager.getLaunchIntentForPackage("com.package.name")
if (intent == null) {
    // App not found, redirect to Play Store
    intent = Intent(Intent.ACTION_VIEW)
    intent.data = Uri.parse("market://details?id=" + "com.package.name")
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK) // Essential for starting from a non-activity context
} else {
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
}
startActivity(intent)

Q: How to launch a specific activity within another app

ANS: If you know the exact main activity class name and its package, you can use ComponentName to construct the Intent.

// Java Example
Intent intent = new Intent(Intent.ACTION_MAIN);
intent.setComponent(new ComponentName("com.package.address", "com.package.address.MainActivity"));
intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
startActivity(intent);

// Kotlin Example
val activityName = "com.package.address.MainActivity" // Target activity name
val packageName = "com.package.address" // Target package name
val intent = Intent().setClassName(packageName, activityName)
intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
startActivity(intent)

Q: What is package visibility and why is it important for Android 11+

ANS: Starting with Android 11 (API level 30), apps can only query for packages that they have previously interacted with or that are explicitly declared in their manifest’s <queries> element. If your app needs to launch another app whose package name isn’t known beforehand or isn’t a standard system app, you must declare the target package(s) in your AndroidManifest.xml within the <queries> tag to avoid getLaunchIntentForPackage() returning null.

<!-- In your AndroidManifest.xml -->
<manifest ...>
    <queries>
        <package android:name="com.google.android.gm" /> <!-- Example for Gmail -->
        <package android:name="com.example.anotherapp" /> <!-- For your target app -->
    </queries>
    ...
</manifest>

For more details, refer to the Android Package Visibility documentation .

Q: How to handle cases where the Play Store app itself is not found

ANS: In rare instances, even the Play Store app might not be available or functional. You can add a fallback to open the Play Store URL in a web browser if launching the Play Store app fails.

// Java Example
try {
    Intent intent = new Intent(Intent.ACTION_VIEW);
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
    intent.setData(Uri.parse("market://details?id=" + "com.package.name"));
    startActivity(intent);
} catch (ActivityNotFoundException e) {
    // Play Store app not found, open in browser
    Intent intent = new Intent(Intent.ACTION_VIEW);
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
    intent.setData(Uri.parse("http://play.google.com/store/apps/details?id=" + "com.package.name"));
    startActivity(intent);
}

// Kotlin Example
var intent: Intent? = null
try {
    intent = Intent(Intent.ACTION_VIEW)
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
    intent.data = Uri.parse("market://details?id=" + "com.package.name")
    startActivity(intent!!)
} catch (e: ActivityNotFoundException) {
    // Play Store app not found, open in browser
    intent = Intent(Intent.ACTION_VIEW)
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
    intent.data = Uri.parse("http://play.google.com/store/apps/details?id=" + "com.package.name")
    startActivity(intent!!)
}

Q: How to check if an app is installed and enabled before launching

ANS: It’s good practice to verify if an app is installed and enabled before attempting to launch it. This prevents unexpected errors and provides a better user experience.

// Java Example
public static void openApp(Context context, String appName, String packageName) {
    if (isAppInstalled(context, packageName)) {
        if (isAppEnabled(context, packageName)) {
            Intent launchIntent = context.getPackageManager().getLaunchIntentForPackage(packageName);
            if (launchIntent != null) {
                context.startActivity(launchIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK));
            }
        } else {
            Toast.makeText(context, appName + " app is disabled.", Toast.LENGTH_SHORT).show();
        }
    } else {
        Toast.makeText(context, appName + " app is not installed.", Toast.LENGTH_SHORT).show();
        // Optionally redirect to Play Store here
    }
}

private static boolean isAppInstalled(Context context, String packageName) {
    try {
        context.getPackageManager().getPackageInfo(packageName, PackageManager.GET_ACTIVITIES);
        return true;
    } catch (PackageManager.NameNotFoundException ignored) {
        return false;
    }
}

private static boolean isAppEnabled(Context context, String packageName) {
    boolean appStatus = false;
    try {
        ApplicationInfo ai = context.getPackageManager().getApplicationInfo(packageName, 0);
        if (ai != null) {
            appStatus = ai.enabled;
        }
    } catch (PackageManager.NameNotFoundException e) {
        e.printStackTrace();
    }
    return appStatus;
}

// Kotlin Example
fun Context.isAppAvailableAndEnabled(packageName: String): Boolean {
    return try {
        val appInfo = packageManager.getApplicationInfo(packageName, 0)
        appInfo.enabled
    } catch (e: PackageManager.NameNotFoundException) {
        false
    }
}

fun Context.launchAppOrShowMessage(appName: String, packageName: String) {
    if (isAppAvailableAndEnabled(packageName)) {
        val launchIntent = packageManager.getLaunchIntentForPackage(packageName)
        if (launchIntent != null) {
            startActivity(launchIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK))
        } else {
            // This case is rare if isAppAvailableAndEnabled is true but might occur
            Toast.makeText(this, "$appName launch intent not found.", Toast.LENGTH_SHORT).show()
        }
    } else {
        Toast.makeText(this, "$appName is not installed or enabled.", Toast.LENGTH_SHORT).show()
        // Consider redirecting to Play Store
    }
}

Q: How to make a generic method to launch any app

ANS: You can create a reusable method that takes the package name as an argument and handles both launching the app and redirecting to the Play Store if it’s not found.

// Java Example
public void launchAppOrRedirectToPlayStore(String packageName) {
    Intent launchIntent = getPackageManager().getLaunchIntentForPackage(packageName);
    if (launchIntent != null) {
        launchIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
        startActivity(launchIntent);
    } else {
        // App not installed, go to Play Store
        try {
            startActivity(new Intent(Intent.ACTION_VIEW, Uri.parse("market://details?id=" + packageName))
                    .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK));
        } catch (ActivityNotFoundException e) {
            // Fallback to web browser
            startActivity(new Intent(Intent.ACTION_VIEW, Uri.parse("https://play.google.com/store/apps/details?id=" + packageName))
                    .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK));
        }
    }
}

// Kotlin Example
fun launchAppOrRedirectToPlayStore(packageName: String) {
    var intent = packageManager.getLaunchIntentForPackage(packageName)
    if (intent == null) {
        intent = try {
            Intent(Intent.ACTION_VIEW, Uri.parse("market://details?id=$packageName"))
        } catch (e: Exception) {
            // Fallback to web browser if market intent fails
            Intent(Intent.ACTION_VIEW, Uri.parse("https://play.google.com/store/apps/details?id=$packageName"))
        }
    }
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
    startActivity(intent)
}
