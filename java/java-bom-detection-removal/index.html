“Java InputStream Byte Order Mark Detection and Removal Strategies”

Dealing with files prefixed with a Unicode BOM can cause unexpected parsing issues, especially when using standard InputStreamReader without prior detection. Several approaches exist, ranging from implementing a custom detector to leveraging established third-party libraries.

Custom Java Implementation for BOM Detection (UnicodeBOMInputStream)

One robust solution involves creating a wrapper class, similar to the one detailed below, which extends InputStream and utilizes a PushbackInputStream to look ahead for known BOM sequences. This approach reads the first few bytes, compares them against known BOM signatures, and pushes back any non-BOM bytes before delegating further reading operations.

import java.io.IOException;
import java.io.InputStream;
import java.io.PushbackInputStream;

/**
 * The &lt;code&gt;UnicodeBOMInputStream&lt;/code&gt; class wraps any
 * &lt;code&gt;InputStream&lt;/code&gt; and detects the presence of any Unicode BOM
 * (Byte Order Mark) at its beginning, as defined by
 * &lt;a href="http://www.faqs.org/rfcs/rfc3629.html"&gt;RFC 3629 - UTF-8, a transformation format of ISO 10646&lt;/a&gt;
 * 
 * &lt;p&gt;The
 * &lt;a href="http://www.unicode.org/unicode/faq/utf_bom.html"&gt;Unicode FAQ&lt;/a&gt;
 * defines 5 types of BOMs:&lt;ul&gt;
 * &lt;li&gt;&lt;pre&gt;00 00 FE FF  = UTF-32, big-endian&lt;/pre&gt;&lt;/li&gt;
 * &lt;li&gt;&lt;pre&gt;FF FE 00 00  = UTF-32, little-endian&lt;/pre&gt;&lt;/li&gt;
 * &lt;li&gt;&lt;pre&gt;FE FF        = UTF-16, big-endian&lt;/pre&gt;&lt;/li&gt;
 * &lt;li&gt;&lt;pre&gt;FF FE        = UTF-16, little-endian&lt;/pre&gt;&lt;/li&gt;
 * &lt;li&gt;&lt;pre&gt;EF BB BF     = UTF-8&lt;/pre&gt;&lt;/li&gt;
 * &lt;/ul&gt;&lt;/p&gt;
 * 
 * &lt;p&gt;Use the {@link #getBOM()} method to know whether a BOM has been detected
 * or not.
 * &lt;/p&gt;
 * &lt;p&gt;Use the {@link #skipBOM()} method to remove the detected BOM from the
 * wrapped &lt;code&gt;InputStream&lt;/code&gt; object.&lt;/p&gt;
 */
public class UnicodeBOMInputStream extends InputStream
{
  /**
   * Type safe enumeration class that describes the different types of Unicode
   * BOMs.
   */
  public static final class BOM
  {
    /**
     * NONE.
     */
    public static final BOM NONE = new BOM(new byte[]{},"NONE");

    /**
     * UTF-8 BOM (EF BB BF).
     */
    public static final BOM UTF_8 = new BOM(new byte[]{(byte)0xEF,
                                                       (byte)0xBB,
                                                       (byte)0xBF},
                                            "UTF-8");

    /**
     * UTF-16, little-endian (FF FE).
     */
    public static final BOM UTF_16_LE = new BOM(new byte[]{ (byte)0xFF,
                                                            (byte)0xFE},
                                                "UTF-16 little-endian");

    /**
     * UTF-16, big-endian (FE FF).
     */
    public static final BOM UTF_16_BE = new BOM(new byte[]{ (byte)0xFE,
                                                            (byte)0xFF},
                                                "UTF-16 big-endian");

    /**
     * UTF-32, little-endian (FF FE 00 00).
     */
    public static final BOM UTF_32_LE = new BOM(new byte[]{ (byte)0xFF,
                                                            (byte)0xFE,
                                                            (byte)0x00,
                                                            (byte)0x00},
                                                "UTF-32 little-endian");

    /**
     * UTF-32, big-endian (00 00 FE FF).
     */
    public static final BOM UTF_32_BE = new BOM(new byte[]{ (byte)0x00,
                                                            (byte)0x00,
                                                            (byte)0xFE,
                                                            (byte)0xFF},
                                                "UTF-32 big-endian");

    /**
     * Returns a &lt;code&gt;String&lt;/code&gt; representation of this &lt;code&gt;BOM&lt;/code&gt;
     * value.
     */
    public final String toString()
    {
      return description;
    }

    /**
     * Returns the bytes corresponding to this &lt;code&gt;BOM&lt;/code&gt; value.
     */
    public final byte[] getBytes()
    {
      final int     length = bytes.length;
      final byte[]  result = new byte[length];

      // Make a defensive copy
      System.arraycopy(bytes,0,result,0,length);

      return result;
    }

    private BOM(final byte bom[], final String description)
    {
      assert(bom != null)               : "invalid BOM: null is not allowed";
      assert(description != null)       : "invalid description: null is not allowed";
      assert(description.length() != 0) : "invalid description: empty string is not allowed";

      this.bytes          = bom;
      this.description  = description;
    }

    private final String  description;

   * Constructs a new &lt;code&gt;UnicodeBOMInputStream&lt;/code&gt; that wraps the
   * specified &lt;code&gt;InputStream&lt;/code&gt;.
   * 
   * @param inputStream an &lt;code&gt;InputStream&lt;/code&gt;.
   * 
   * @throws NullPointerException when &lt;code&gt;inputStream&lt;/code&gt; is
   * &lt;code&gt;null&lt;/code&gt;.
   * @throws IOException on reading from the specified &lt;code&gt;InputStream&lt;/code&gt;
   * when trying to detect the Unicode BOM.
   */
  public UnicodeBOMInputStream(final InputStream inputStream) throws  NullPointerException,
                                                                      IOException

  {
    if (inputStream == null)
      throw new NullPointerException("invalid input stream: null is not allowed");

    in = new PushbackInputStream(inputStream,4);

    final byte  bom[] = new byte[4];
    final int   read  = in.read(bom);

    switch(read)
    {
      case 4:
        if ((bom[0] == (byte)0xFF) &amp;&amp;
            (bom[1] == (byte)0xFE) &amp;&amp;
            (bom[2] == (byte)0x00) &amp;&amp;
            (bom[3] == (byte)0x00))
        {
          this.bom = BOM.UTF_32_LE;
          break;
        }
        else
        if ((bom[0] == (byte)0x00) &amp;&amp;
            (bom[1] == (byte)0x00) &amp;&amp;
            (bom[2] == (byte)0xFE) &amp;&amp;
            (bom[3] == (byte)0xFF))
        {
          this.bom = BOM.UTF_32_BE;
          break;
        }

      case 3:
        if ((bom[0] == (byte)0xEF) &amp;&amp;
            (bom[1] == (byte)0xBB) &amp;&amp;
            (bom[2] == (byte)0xBF))
        {
          this.bom = BOM.UTF_8;
          break;
        }

      case 2:
        if ((bom[0] == (byte)0xFF) &amp;&amp;
            (bom[1] == (byte)0xFE))
        {
          this.bom = BOM.UTF_16_LE;
          break;
        }
        else
        if ((bom[0] == (byte)0xFE) &amp;&amp;
            (bom[1] == (byte)0xFF))
        {
          this.bom = BOM.UTF_16_BE;
          break;
        }

      default:
        this.bom = BOM.NONE;
        break;
    }

    if (read &gt; 0)
      in.unread(bom,0,read);
  }

  /**
   * Returns the &lt;code&gt;BOM&lt;/code&gt; that was detected in the wrapped
   * &lt;code&gt;InputStream&lt;/code&gt; object.
   * 
   * @return a &lt;code&gt;BOM&lt;/code&gt; value.
   */
  public final BOM getBOM()
  {
    // BOM type is immutable.
    return bom;
  }

  /**
   * Skips the &lt;code&gt;BOM&lt;/code&gt; that was found in the wrapped
   * &lt;code&gt;InputStream&lt;/code&gt; object.
   * 
   * @return this &lt;code&gt;UnicodeBOMInputStream&lt;/code&gt;.
   * 
   * @throws IOException when trying to skip the BOM from the wrapped
   * &lt;code&gt;InputStream&lt;/code&gt; object.
   */
  public final synchronized UnicodeBOMInputStream skipBOM() throws IOException
  {
    if (!skipped)
    {
      in.skip(bom.bytes.length);
      skipped = true;
    }
    return this;
  }

  /**
   * {@inheritDoc}
   */
  public int read() throws IOException
  {
    return in.read();
  }

  /**
   * {@inheritDoc}
   */
  public int read(final byte b[]) throws  IOException,
                                          NullPointerException
  {
    return in.read(b,0,b.length);
  }

  /**
   * {@inheritDoc}
   */
  public int read(final byte b[],
                  final int off,
                  final int len) throws IOException,
                                        NullPointerException
  {
    return in.read(b,off,len);
  }

  /**
   * {@inheritDoc}
   */
  public long skip(final long n) throws IOException
  {
    return in.skip(n);
  }

  /**
   * {@inheritDoc}
   */
  public int available() throws IOException
  {
    return in.available();
  }

  /**
   * {@inheritDoc}
   */
  public void close() throws IOException
  {
    in.close();
  }

  /**
   * {@inheritDoc}
   */
  public synchronized void mark(final int readlimit)
  {
    in.mark(readlimit);
  }

  /**
   * {@inheritDoc}
   */
  public synchronized void reset() throws IOException
  {
    in.reset();
  }

  /**
   * {@inheritDoc}
   */
  public boolean markSupported() 
  {
    return in.markSupported();
  }

  private final PushbackInputStream in;
  private final BOM                 bom;
  private       boolean             skipped = false;

} // UnicodeBOMInputStream

public class UnicodeReader extends Reader { private static final int BOM_SIZE = 4; private final InputStreamReader reader;

/**
 * Construct UnicodeReader
 * @param in Input stream.
 * @param defaultEncoding Default encoding to be used if BOM is not found,
 * or &lt;code&gt;null&lt;/code&gt; to use system default encoding.
 * @throws IOException If an I/O error occurs.
 */
public UnicodeReader(InputStream in, String defaultEncoding) throws IOException {
    byte bom[] = new byte[BOM_SIZE];
    String encoding;
    int unread;
    PushbackInputStream pushbackStream = new PushbackInputStream(in, BOM_SIZE);
    int n = pushbackStream.read(bom, 0, bom.length);

    // Read ahead four bytes and check for BOM marks.
    if ((bom[0] == (byte) 0xEF) &amp;&amp; (bom[1] == (byte) 0xBB) &amp;&amp; (bom[2] == (byte) 0xBF)) {
        encoding = "UTF-8";
        unread = n - 3;
    } else if ((bom[0] == (byte) 0xFE) &amp;&amp; (bom[1] == (byte) 0xFF)) {
        encoding = "UTF-16BE";
        unread = n - 2;
    } else if ((bom[0] == (byte) 0xFF) &amp;&amp; (bom[1] == (byte) 0xFE)) {
        encoding = "UTF-16LE";
        unread = n - 2;
    } else if ((bom[0] == (byte) 0x00) &amp;&amp; (bom[1] == (byte) 0x00) &amp;&amp; (bom[2] == (byte) 0xFE) &amp;&amp; (bom[3] == (byte) 0xFF)) {
        encoding = "UTF-32BE";
        unread = n - 4;
    } else if ((bom[0] == (byte) 0xFF) &amp;&amp; (bom[1] == (byte) 0xFE) &amp;&amp; (bom[2] == (byte) 0x00) &amp;&amp; (bom[3] == (byte) 0x00)) {
        encoding = "UTF-32LE";
        unread = n - 4;
    } else {
        encoding = defaultEncoding;
        unread = n;
    }

    // Unread bytes if necessary and skip BOM marks.
    if (unread &gt; 0) {
        pushbackStream.unread(bom, (n - unread), unread);
    } else if (unread &lt; -1) {
        pushbackStream.unread(bom, 0, 0);
    }

    // Use given encoding.
    if (encoding == null) {
        reader = new InputStreamReader(pushbackStream);
    } else {
        reader = new InputStreamReader(pushbackStream, encoding);
    }
}

public String getEncoding() {
    return reader.getEncoding();
}

public int read(char[] cbuf, int off, int len) throws IOException {
    return reader.read(cbuf, off, len);
}

public void close() throws IOException {
    reader.close();
}

}

Alternative Strategy 1: Apache Commons IO BOMInputStream

If external libraries are permitted, the Apache Commons IO library offers a ready-made component, BOMInputStream, which handles detection for various encodings automatically.

This library provides flexibility: you can choose whether to include the BOM bytes in the stream output or discard them entirely.

import org.apache.commons.io.input.BOMInputStream;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.io.FileInputStream;
// Note: Requires BOMInputStream.hasBOM() and ByteOrderMark utility classes from Apache Commons IO

public void processStreamWithApache(InputStream rawStream) throws IOException {
    // false parameter means the BOM bytes will be excluded from the stream read operations
    try (BOMInputStream bomIn = new BOMInputStream(rawStream, false)) {
        
        // Read the first byte; this action skips the BOM if one exists.
        int firstByte = bomIn.read(); 
        
        if (bomIn.hasBOM()) {
            System.out.println("BOM detected and skipped.");
            // Further checks can determine the exact BOM type if needed, e.g., bomIn.hasUTF8BOM()
        }
        
        // Wrap in InputStreamReader using the expected encoding (or rely on default if no BOM)
        try (InputStreamReader isr = new InputStreamReader(bomIn, StandardCharsets.UTF_8);
             BufferedReader br = new BufferedReader(isr)) {
            // Process content starting from the first actual character
        }
    }
}

Alternative Strategy 2: Skipping the Character Marker (\ufeff) on a Reader

If you are already working with a Reader (meaning character conversion has already started, perhaps incorrectly reading the BOM as the first character \ufeff), you can attempt to mark and reset the stream to bypass this single character. This approach works best when the encoding conversion itself is known or assumed to be standard (like UTF-8 or UTF-16).

import java.io.Reader;
import java.io.IOException;

public class BOMSkipper {
    public static void skip(Reader reader) throws IOException {
        // Mark the current position (1 byte should be enough for a BOM character)
        reader.mark(1);
        char[] possibleBOM = new char[1];
        
        // Attempt to read the first character
        reader.read(possibleBOM);

        // The Unicode BOM character is U+FEFF
        if (possibleBOM[0] != '\ufeff') {
            // If it wasn't the BOM, reset to the marked position
            reader.reset();
        }
        // If it was '\ufeff', the reader pointer advanced past it, effectively skipping it.
    }
}

Usage Example for Reader Skipping:

// Assuming 'fileExpectedCharset' is known, e.g., StandardCharsets.UTF_8.name()

Alternative Strategy 3: Direct String Replacement

For simpler cases, particularly if the stream is read line-by-line initially, you can explicitly check and replace the Unicode BOM character (\ufeff) from the resulting string. This is less efficient than byte-level skipping but straightforward for quick fixes in code where the BOM causes the first line to be corrupted.

// Assuming 'str' is the first line read from a Reader
String str = reader.readLine().trim();
// Replace the character with its hexadecimal representation \ufeff
str = str.replace("\ufeff", "");

Essential Encoding Practice

It is crucial to recognize that simply skipping the BOM without knowing the correct encoding for the remainder of the stream can lead to subsequent data corruption. As one expert noted, defaulting to UTF-8 after skipping a BOM that might have indicated UTF-16 can be disastrous if the file contains non-ASCII characters. The best practice is to detect the BOM, determine the stream’s true encoding from the BOM, and use that encoding when wrapping the stream in an InputStreamReader. Libraries like Apache Commons IO or custom readers that return the detected encoding (like Solution 4’s UnicodeReader) facilitate this accurate decoding.

If you must guess the encoding when no BOM is present, UTF-8 is a modern default, but this remains a guess.

FAQs on Java BOM Detection Removal

Q: What is the primary purpose of a Unicode Byte Order Mark BOM

ANS: The BOM is a sequence of bytes at the beginning of a text file that indicates the file’s specific Unicode encoding (like UTF-8, UTF-16, or UTF-32) and byte order (endianness).

Q: Which common byte sequence indicates a UTF-8 BOM

ANS: The UTF-8 BOM sequence is represented by the hexadecimal bytes EF BB BF.

Q: How does PushbackInputStream aid in BOM detection

ANS: PushbackInputStream allows the detection logic to read the initial bytes, and if no BOM is found, it pushes those bytes back into the stream so that the subsequent InputStreamReader sees the original start of the data, rather than missing bytes.

Q: Can BOMSkipper solution handle all five UTF BOM types

ANS: The character-based BOMSkipper using reader.mark(1) targets the character \ufeff, which is the result of decoding any of the five BOM types when read as a char. Thus, it works for all standard UTF BOMs if read via a character stream.
