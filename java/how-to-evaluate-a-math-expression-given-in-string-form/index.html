How to Evaluate Mathematical Expressions in Java

Programmatically evaluating mathematical expressions represented as strings is a common requirement in software development. Whether you’re building a scientific calculator, a data analysis tool, or a configuration system, Java offers several powerful approaches to handle this task. This guide delves into various methods, from leveraging built-in capabilities to integrating specialized libraries, providing practical examples to help you choose the best solution for your needs.

Leveraging Java’s Built-in JavaScript Engine

For versions of Java prior to JDK 15, the included JavaScript engine offers a straightforward way to evaluate mathematical expressions. This method bypasses the need for external dependencies, making it an attractive option for simpler use cases.

import javax.script.ScriptEngineManager;
import javax.script.ScriptEngine;
import javax.script.ScriptException;

public class JavascriptEvaluator {
    public static void main(String[] args) {
        ScriptEngineManager manager = new ScriptEngineManager();
        ScriptEngine engine = manager.getEngineByName("JavaScript");
        String expression = "40 + 12 / 2"; // Example expression

        try {
            Object result = engine.eval(expression);
            System.out.println("Result of '" + expression + "': " + result);
        } catch (ScriptException e) {
            System.err.println("Error evaluating expression: " + e.getMessage());
        }
    }
}

This approach is effective for basic arithmetic operations but might lack the robustness needed for complex mathematical functions or advanced parsing logic. For more complex scenarios, consider the following sophisticated custom parser.

Custom Recursive Descent Parser for Math Expressions

A custom parser provides fine-grained control and can be tailored to specific requirements. The following Java code implements a recursive descent parser capable of handling arithmetic operations, exponentiation, and basic mathematical functions like sqrt. This solution is inspired by efficient parsing techniques and offers a robust way to evaluate intricate mathematical strings.

import java.util.Map;
import java.util.HashMap;

public class CustomExpressionParser {

    // Interface for evaluating parsed expressions, useful for later compilation and reuse.
    @FunctionalInterface
    interface Expression {
        double eval();
    }

    // Main method for demonstration.
    public static void main(String[] args) {
        // Example of evaluating a direct expression.
        System.out.println("Evaluating '((4 - 2^3 + 1) * -sqrt(3*3+4*4)) / 2': " +
                           eval("((4 - 2^3 + 1) * -sqrt(3*3+4*4)) / 2"));

        // Example of using variables and pre-compiled expressions.
        Map<String, Double> variables = new HashMap<>();
        Expression compiledExpression = parse("x^2 - x + 2", variables);
        System.out.println("\nEvaluating 'x^2 - x + 2' with variables:");
        for (double x = -5; x <= 5; x++) {
            variables.put("x", x);
            System.out.println("x = " + x + " => " + compiledExpression.eval());
        }
    }

    /**
     * Evaluates a given mathematical expression string.
     * @param str The expression string to evaluate.
     * @return The double result of the evaluated expression.
     */
    public static double eval(final String str) {
        return new Object() {
            int pos = -1, ch;

            // Moves to the next character in the expression.
            void nextChar() {
                ch = (++pos < str.length()) ? str.charAt(pos) : -1;
            }

            // Consumes the specified character if present.
            boolean eat(int charToEat) {
                while (ch == ' ') nextChar(); // Skip whitespace
                if (ch == charToEat) {
                    nextChar();
                    return true;
                }
                return false;
            }

            // Parses the entire expression.
            double parse() {
                nextChar();
                double x = parseExpression();
                if (pos < str.length()) throw new RuntimeException("Unexpected character: " + (char)ch);
                return x;
            }

            // Grammar rules for parsing:
            // expression = term | expression `+` term | expression `-` term
            // term = factor | term `*` factor | term `/` factor
            // factor = `+` factor | `-` factor | `(` expression `)` | number
            //        | functionName `(` expression `)` | functionName factor
            //        | factor `^` factor

            // Parses an expression (addition and subtraction).
            double parseExpression() {
                double x = parseTerm();
                for (;;) {
                    if (eat('+')) x += parseTerm(); // addition
                    else if (eat('-')) x -= parseTerm(); // subtraction
                    else return x;
                }
            }

            // Parses a term (multiplication and division).
            double parseTerm() {
                double x = parseFactor();
                for (;;) {
                    if (eat('*')) x *= parseFactor(); // multiplication
                    else if (eat('/')) x /= parseFactor(); // division
                    else return x;
                }
            }

            // Parses a factor (unary operators, parentheses, numbers, functions, exponentiation).
            double parseFactor() {
                if (eat('+')) return +parseFactor(); // unary plus
                if (eat('-')) return -parseFactor(); // unary minus

                double x;
                int startPos = this.pos;
                if (eat('(')) { // parentheses
                    x = parseExpression();
                    if (!eat(')')) throw new RuntimeException("Missing closing parenthesis ')'");
                } else if ((ch >= '0' && ch <= '9') || ch == '.') { // numbers
                    while ((ch >= '0' && ch <= '9') || ch == '.') nextChar();
                    x = Double.parseDouble(str.substring(startPos, this.pos));
                } else if (ch >= 'a' && ch <= 'z') { // functions
                    while (ch >= 'a' && ch <= 'z') nextChar();
                    String func = str.substring(startPos, this.pos);
                    if (eat('(')) {
                        x = parseExpression();
                        if (!eat(')')) throw new RuntimeException("Missing ')' after argument for function '" + func + "'");
                    } else {
                        x = parseFactor(); // Function applied to a factor
                    }
                    // Handle supported functions
                    if (func.equals("sqrt")) x = Math.sqrt(x);
                    else if (func.equals("sin")) x = Math.sin(Math.toRadians(x));
                    else if (func.equals("cos")) x = Math.cos(Math.toRadians(x));
                    else if (func.equals("tan")) x = Math.tan(Math.toRadians(x));
                    else throw new RuntimeException("Unknown function: " + func);
                } else {
                    throw new RuntimeException("Unexpected character: " + (char)ch);
                }

                if (eat('^')) x = Math.pow(x, parseFactor()); // exponentiation

                return x;
            }
        }.parse();
    }

    /**
     * Parses an expression and returns a compiled representation for repeated evaluation.
     * This is an advanced feature demonstrating how to separate parsing from evaluation.
     * @param str The expression string.
     * @param variables A map to store and retrieve variable values.
     * @return A functional interface representing the compiled expression.
     */
    public static Expression parse(final String str, final Map<String, Double> variables) {
        return new Object() {
            int pos = -1, ch;

            void nextChar() {
                ch = (++pos < str.length()) ? str.charAt(pos) : -1;
            }

            boolean eat(int charToEat) {
                while (ch == ' ') nextChar();
                if (ch == charToEat) {
                    nextChar();
                    return true;
                }
                return false;
            }

            // Parses the entire expression into an Expression functional interface.
            Expression parseExpressionTree() {
                nextChar();
                Expression x = parseExpression();
                if (pos < str.length()) throw new RuntimeException("Unexpected character: " + (char)ch);
                return x;
            }

            // Grammar rules adapted for creating Expression objects.
            Expression parseExpression() {
                Expression x = parseTerm();
                for (;;) {
                    if (eat('+')) {
                        Expression a = x, b = parseTerm();
                        x = (() -> a.eval() + b.eval());
                    } else if (eat('-')) {
                        Expression a = x, b = parseTerm();
                        x = (() -> a.eval() - b.eval());
                    } else {
                        return x;
                    }
                }
            }

            Expression parseTerm() {
                Expression x = parseFactor();
                for (;;) {
                    if (eat('*')) {
                        Expression a = x, b = parseFactor();
                        x = (() -> a.eval() * b.eval());
                    } else if (eat('/')) {
                        Expression a = x, b = parseFactor();
                        x = (() -> a.eval() / b.eval());
                    } else {
                        return x;
                    }
                }
            }

            Expression parseFactor() {
                if (eat('+')) return parseFactor();
                if (eat('-')) {
                    Expression factor = parseFactor();
                    return (() -> -factor.eval());
                }

                int startPos = this.pos;
                if (eat('(')) {
                    Expression innerExpr = parseExpression();
                    if (!eat(')')) throw new RuntimeException("Missing closing parenthesis ')'");
                    return innerExpr;
                } else if ((ch >= '0' && ch <= '9') || ch == '.') {
                    while ((ch >= '0' && ch <= '9') || ch == '.') nextChar();
                    final String numberStr = str.substring(startPos, this.pos);
                    return (() -> Double.parseDouble(numberStr));
                } else if (ch >= 'a' && ch <= 'z') {
                    while (ch >= 'a' && ch <= 'z') nextChar();
                    final String funcName = str.substring(startPos, this.pos);
                    Expression argExpr;
                    if (eat('(')) {
                        argExpr = parseExpression();
                        if (!eat(')')) throw new RuntimeException("Missing ')' after argument for function '" + funcName + "'");
                    } else {
                        argExpr = parseFactor();
                    }

                    final Expression finalArgExpr = argExpr;
                    return (() -> {
                        double value = finalArgExpr.eval();
                        if (funcName.equals("sqrt")) return Math.sqrt(value);
                        else if (func.equals("sin")) return Math.sin(Math.toRadians(value));
                        else if (func.equals("cos")) return Math.cos(Math.toRadians(value));
                        else if (func.equals("tan")) return Math.tan(Math.toRadians(value));
                        else throw new RuntimeException("Unknown function: " + funcName);
                    });
                } else if (Character.isLetter(ch)) { // Handle variables
                    while (Character.isLetterOrDigit(ch)) nextChar();
                    final String varName = str.substring(startPos, this.pos);
                    return (() -> {
                        if (!variables.containsKey(varName)) {
                            throw new RuntimeException("Undefined variable: " + varName);
                        }
                        return variables.get(varName);
                    });
                } else {
                    throw new RuntimeException("Unexpected character: " + (char)ch);
                }

                if (eat('^')) {
                    Expression exponent = parseFactor();
                    return (() -> Math.pow(x.eval(), exponent.eval()));
                }
                // Fallback return, though should be handled by earlier returns
                return x; // This line might need refinement based on exhaustive parsing logic
            }
        }.parseExpressionTree();
    }
}

This custom parser demonstrates the power of recursive descent. It handles operator precedence correctly and can be extended to support more functions or custom logic. For a deeper dive into parsing techniques, explore resources on compiler design .

Exploring Third-Party Libraries for Expression Evaluation

When robust handling of complex mathematical expressions, including advanced functions, variables, and potentially user-defined logic, is required, leveraging specialized third-party libraries is often the most efficient approach. These libraries abstract away the complexities of parsing and evaluation, providing well-tested and optimized solutions.

mXparser: A Powerful Formula Expression Parser

The mXparser library is a comprehensive solution for parsing and evaluating mathematical, logical, and trigonometric expressions in Java and .NET. It supports a wide range of features, including user-defined arguments, constants, functions, and even iterative calculations like summation.

// Add mXparser dependency to your project (e.g., Maven: org.mariuszgromada.math, mXparser, LATEST_VERSION)

import org.mariuszgromada.math.mxparser.Argument;
import org.mariuszgromada.math.mxparser.Constant;
import org.mariuszgromada.math.mxparser.Expression;
import org.mariuszgromada.math.mxparser.Function;

public class MxParserExample {
    public static void main(String[] args) {
        // 1. Simple formula evaluation
        Expression simpleExpression = new Expression("( 2 + 3/4 + sin(pi) )/2");
        double simpleResult = simpleExpression.calculate();
        System.out.println("Simple expression result: " + simpleResult);

        // 2. Using user-defined arguments and constants
        Argument x = new Argument("x = 10");
        Constant a = new Constant("a = pi^2");
        Expression expressionWithArgs = new Expression("cos(a*x)", x, a);
        double argsResult = expressionWithArgs.calculate();
        System.out.println("Expression with args result: " + argsResult);

        // 3. User-defined functions
        Function f = new Function("f(x, y, z) = sin(x) + cos(y*z)");
        Expression expressionWithFunc = new Expression("f(3,2,5)", f);
        double funcResult = expressionWithFunc.calculate();
        System.out.println("Expression with function result: " + funcResult);

        // 4. Iteration (e.g., summation)
        Expression sumExpression = new Expression("sum(i, 1, 100, sin(i))");
        double sumResult = sumExpression.calculate();
        System.out.println("Summation result: " + sumResult);
    }
}

mXparser’s extensive features make it suitable for applications requiring advanced mathematical capabilities. Explore the mXparser tutorial for more in-depth usage examples.

exp4j: A Lightweight and Fast Expression Evaluator

For scenarios prioritizing performance and simplicity, exp4j is an excellent choice. This library focuses on evaluating mathematical expressions efficiently, supporting standard operators and functions.

To use exp4j, add the following dependency to your build.gradle file: implementation group: 'net.objecthunter', name: 'exp4j', version: '0.4.8'

import net.objecthunter.exp4j.Expression;
import net.objecthunter.exp4j.ExpressionBuilder;

public class Exp4jExample {

    public Double evaluateExpression(final String expressionAsString) {
        Expression expression = new ExpressionBuilder(expressionAsString).build();
        return expression.evaluate();
    }

    public static void main(String[] args) {
        Exp4jExample evaluator = new Exp4jExample();

        // Basic arithmetic
        System.out.println("2 + 2 + 3 = " + evaluator.evaluateExpression("2+2+3")); // Expected: 7.0
        System.out.println("21 - 2 = " + evaluator.evaluateExpression("21-2"));      // Expected: 19.0
        System.out.println("10.5 * 2 + 24 = " + evaluator.evaluateExpression("10.5*2+24")); // Expected: 45.0

        // With functions and parentheses
        System.out.println("sin(45 degrees) = " + evaluator.evaluateExpression("sin(45)")); // Note: exp4j uses radians by default. For degrees, you'd need to convert or use a custom function.
        System.out.println("sqrt(16) = " + evaluator.evaluateExpression("sqrt(16)"));      // Expected: 4.0
        System.out.println("(3 + 4) * 5 = " + evaluator.evaluateExpression("(3 + 4) * 5")); // Expected: 35.0
    }
}

The exp4j library is well-suited for applications where performance is critical and the expression syntax is relatively standard. Its API is clean and straightforward, making integration easy.

JEXL (Java Expression Language)

JEXL from Apache is another powerful option, designed for scripting and expression evaluation. It allows for references to Java objects within expressions, making it highly flexible.

// Add JEXL dependency (e.g., Maven: org.apache.commons, commons-jexl, LATEST_VERSION)

import org.apache.commons.jexl3.*;

public class JexlExample {
    public static void main(String[] args) throws Exception {
        // Create or retrieve a JEXL engine
        JexlEngine jexl = new JexlEngine();

        // Example 1: Simple expression
        String jexlExp1 = "10 + 5 * 2";
        org.apache.commons.jexl3.Expression e1 = jexl.createExpression(jexlExp1);
        JexlContext context1 = new MapContext();
        Object o1 = e1.evaluate(context1);
        System.out.println("JEXL Example 1 Result: " + o1); // Output: 20.0

        // Example 2: Using variables and object properties
        // Define a simple Java class
        class Foo {
            String innerFoo = "bar";
            public String bar() { return "Success"; }
        }
        
        Foo myFoo = new Foo();
        JexlContext context2 = new MapContext();
        context2.set("fooInstance", myFoo);
        String jexlExp2 = "fooInstance.innerFoo.length() + fooInstance.bar().length()";
        org.apache.commons.jexl3.Expression e2 = jexl.createExpression(jexlExp2);
        Object o2 = e2.evaluate(context2);
        System.out.println("JEXL Example 2 Result: " + o2); // Output: 12 (3 for "bar" + 9 for "Success")

        // Example 3: Method invocation
        context2.set("x", 10);
        String jexlExp3 = "Math.sqrt(x)";
        org.apache.commons.jexl3.Expression e3 = jexl.createExpression(jexlExp3);
        Object o3 = e3.evaluate(context2);
        System.out.println("JEXL Example 3 Result: " + o3); // Output: 3.1622...
    }
}

JEXL’s ability to interact with Java objects makes it powerful for scenarios where expressions need to drive complex application logic. For detailed usage, refer to the JEXL documentation .

Spring Expression Language (SpEL)

If you are working within a Spring Framework environment, or even if not, the Spring Expression Language (SpEL) offers a sophisticated way to evaluate expressions. It’s standalone and provides extensive capabilities beyond simple arithmetic.

// Add Spring Expression dependency (e.g., Maven: org.springframework, spring-expression, LATEST_VERSION)

import org.springframework.expression.ExpressionParser;
import org.springframework.expression.spel.standard.SpelExpressionParser;
import org.springframework.expression.EvaluationContext;
import org.springframework.expression.spel.support.StandardEvaluationContext;

public class SpelExample {
    public static void main(String[] args) {
        ExpressionParser parser = new SpelExpressionParser();
        EvaluationContext context = new StandardEvaluationContext();

        // Simple arithmetic
        Integer two = parser.parseExpression("1 + 1").getValue(Integer.class);
        System.out.println("SpEL '1 + 1' result: " + two); // Output: 2

        // Floating point arithmetic
        Double twentyFour = parser.parseExpression("2.0 * 3e0 * 4").getValue(Double.class);
        System.out.println("SpEL '2.0 * 3e0 * 4' result: " + twentyFour); // Output: 24.0

        // Using variables in context
        context.setVariable("myVar", 10);
        String expressionWithVar = "#myVar * 5";
        Integer fifty = parser.parseExpression(expressionWithVar).getValue(context, Integer.class);
        System.out.println("SpEL '" + expressionWithVar + "' result: " + fifty); // Output: 50

        // Invoking methods
        context.setVariable("myString", "Hello SpEL");
        String lengthExpression = "#myString.length()";
        Integer length = parser.parseExpression(lengthExpression).getValue(context, Integer.class);
        System.out.println("SpEL '" + lengthExpression + "' result: " + length); // Output: 10
    }
}

SpEL is particularly powerful for configuration, data binding, and dynamic expression evaluation within Spring applications.

MVEL (MV Standard Expression Language)

MVEL is another high-performance expression evaluation framework for Java. It’s known for its speed and flexibility, supporting a wide range of Java-like syntax.

// Add MVEL dependency (e.g., Maven: org.mvel, mvel2, LATEST_VERSION)

import org.mvel2.MVEL;
import java.util.HashMap;
import java.util.Map;

public class MvelExample {
    public static void main(String[] args) {
        // Simple expression evaluation
        String expressionStr = "10 + 20 * 5";
        Object result1 = MVEL.eval(expressionStr);
        System.out.println("MVEL Simple Expression Result: " + result1); // Output: 110

        // Expression with variables
        Map<String, Object> vars = new HashMap<>();
        vars.put("x", 10);
        vars.put("y", 20);
        String expressionWithVars = "x * y - (x + y)";
        Object result2 = MVEL.eval(expressionWithVars, vars);
        System.out.println("MVEL Expression with Variables Result: " + result2); // Output: 170

        // Compiling and executing expressions for performance
        String compiledExpressionStr = "a * b + c";
        Object compiledStatement = MVEL.compileExpression(compiledExpressionStr);
        vars.put("a", 5);
        vars.put("b", 6);
        vars.put("c", 7);
        Object result3 = MVEL.executeExpression(compiledStatement, vars);
        System.out.println("MVEL Compiled Expression Result: " + result3); // Output: 37
    }
}

MVEL’s performance and support for compile-time optimization make it ideal for computationally intensive tasks.

Evaluating Expressions via Database Queries

If your Java application already interacts with a database, you can leverage the database’s built-in SQL functions to evaluate mathematical expressions. This method is particularly efficient when you need to evaluate many expressions concurrently or when the expressions themselves are complex and benefit from the database’s optimization capabilities.

For instance, in SQL Server or SQLite, you can directly query expressions:

SELECT (((12.10 + 12.0)) / 233.0) AS amount;

In Oracle, you would typically use the dual table:

SELECT (((12.10 + 12.0)) / 233.0) AS amount FROM dual;

You can also use an in-memory SQLite database for faster, localized evaluations directly within your Java application:

import java.sql.*;
import java.math.BigDecimal;

public class DatabaseExpressionEvaluator {
    public static void main(String[] args) {
        Connection conn = null;
        Statement stat = null;
        ResultSet rs = null;

        try {
            // Load the SQLite JDBC driver
            Class.forName("org.sqlite.JDBC");
            // Connect to an in-memory SQLite database
            conn = DriverManager.getConnection("jdbc:sqlite::memory:");
            stat = conn.createStatement();

            // Evaluate a simple expression
            rs = stat.executeQuery("SELECT (1 + 10) / 20.0 AS amount");
            if (rs.next()) {
                BigDecimal result = rs.getBigDecimal(1);
                System.out.println("In-memory DB evaluation result: " + result);
            }

            // Evaluate multiple expressions
            rs = stat.executeQuery("SELECT (1 + 10) / 20.0 AS amount1, (5 * 5) / 2.0 AS amount2");
            if (rs.next()) {
                System.out.println("Multiple results: amount1=" + rs.getBigDecimal("amount1") +
                                   ", amount2=" + rs.getBigDecimal("amount2"));
            }

        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            try {
                if (rs != null) rs.close();
                if (stat != null) stat.close();
                if (conn != null) conn.close();
            } catch (SQLException e) {
                e.printStackTrace();
            }
        }
    }
}

This database-centric approach can be very powerful, especially when dealing with complex computations or large datasets, leveraging the optimized engines of modern relational databases.

Algorithmic Approach: Shunting-Yard and Postfix Evaluation

For those who prefer a programmatic approach without external libraries, implementing a parser using algorithms like the Shunting-yard algorithm is a robust method. This involves two main steps:

  1. Infix to Postfix Conversion (Shunting-Yard Algorithm): This algorithm converts an infix mathematical expression (e.g., 3 + 4 * 2) into postfix notation (e.g., 3 4 2 * +). It uses a stack for operators and handles operator precedence and associativity correctly.
  2. Postfix Expression Evaluation: Once in postfix form, the expression can be evaluated efficiently using a stack. Numbers are pushed onto the stack, and when an operator is encountered, the required number of operands are popped, the operation is performed, and the result is pushed back onto the stack.

While implementing this yourself is a great learning experience, it requires careful handling of numerous edge cases, operator precedence, and function parsing.

Security Considerations with Expression Evaluation

When evaluating expressions from untrusted sources (e.g., user input), security is paramount. Directly evaluating arbitrary strings using engines like the JavaScript engine or libraries that execute code can introduce vulnerabilities if not handled carefully.

  • Input Sanitization: Always validate and sanitize input strings to prevent injection attacks or the execution of unintended code. Regular expressions can be used to ensure the input conforms to expected mathematical patterns, disallowing script-like syntax. For instance, using a regex like .*[a-zA-Z;~#$_{}\[\]:\\;"’,\.\?]+.*` to check for potentially harmful characters can be a first line of defense, as demonstrated in one of the provided solutions.
  • Sandboxing: If using a scripting engine, ensure it runs in a sandboxed environment that restricts access to the file system, network, and other sensitive resources.
  • Limited Functionality: Choose parsers or libraries that offer controlled sets of functions and operators, disabling or restricting access to potentially dangerous ones.

Choosing the Right Approach

The best method for evaluating mathematical expressions in Java depends on your specific needs:

  • Simple Arithmetic & No Dependencies: Use the built-in JavaScript engine (for older JDKs) or a custom, minimalist parser.
  • Complex Math & Functions: mXparser or exp4j are excellent choices, offering comprehensive features and good performance.
  • Scripting & Object Interaction: JEXL or SpEL are ideal when expressions need to interact with your application’s objects and logic.
  • Performance Critical: MVEL or exp4j are strong contenders due to their focus on speed.
  • Learning & Control: Implementing a custom parser provides the deepest insight into expression evaluation mechanics.

By selecting the appropriate tool or implementing a tailored solution, you can effectively integrate mathematical expression evaluation into your Java applications.

FAQs on Java Math Expression Evaluation

Q: How can I evaluate a simple mathematical expression string in Java

ANS: For simple expressions, you can use Java’s built-in JavaScript engine by obtaining it via ScriptEngineManager and then calling engine.eval(yourExpressionString). Alternatively, you can implement a basic parser for arithmetic operations.

Q: What are the advantages of using a third-party library for expression evaluation

ANS: Third-party libraries like mXparser, exp4j, JEXL, or MVEL offer robust parsing for complex functions, operator precedence, variables, and often provide better performance and security than a simple custom implementation.

Q: Can I evaluate expressions that include variables in Java

ANS: Yes, many libraries like mXparser, JEXL, SpEL, and MVEL support variables. You typically pass a map or context containing your variables to the evaluation engine. Custom parsers can also be built to handle variables by maintaining a symbol table.

Q: Is it safe to evaluate user-provided mathematical expressions in Java

ANS: Evaluating untrusted input directly can be a security risk. It’s crucial to sanitize input strings rigorously, use libraries with built-in security features or sandboxing, and limit the set of allowed functions and operators.

Q: What is the Shunting-yard algorithm

ANS: The Shunting-yard algorithm is a method used to parse mathematical expressions specified in infix notation. It converts the infix expression into postfix (Reverse Polish Notation) which is easier for computers to evaluate using a stack.
public static double eval(final String str) {
    return new Object() {
        int pos = -1, ch;
        
        void nextChar() {
            ch = (++pos &lt; str.length()) ? str.charAt(pos) : -1;
        }
        
        boolean eat(int charToEat) {
            while (ch == ' ') nextChar();

        // expression = term | expression `+` term | expression `-` term
        // term = factor | term `*` factor | term `/` factor

                else if (eat('-')) x -= parseTerm(); // subtraction

            double x = parseFactor();

                if      (eat('*')) x *= parseFactor(); // multiplication
                else if (eat('/')) x /= parseFactor(); // division
                else return x;
            }

            if (eat('+')) return +parseFactor(); // unary plus
            if (eat('-')) return -parseFactor(); // unary minus

            } else if (ch &gt;= 'a' &amp;&amp; ch &lt;= 'z') { // functions
                while (ch &gt;= 'a' &amp;&amp; ch &lt;= 'z') nextChar();

                if (func.equals(&quot;sqrt&quot;)) x = Math.sqrt(x);
                else if (func.equals(&quot;sin&quot;)) x = Math.sin(Math.toRadians(x));
                else if (func.equals(&quot;cos&quot;)) x = Math.cos(Math.toRadians(x));
                else if (func.equals(&quot;tan&quot;)) x = Math.tan(Math.toRadians(x));
                else throw new RuntimeException(&quot;Unknown function: &quot; + func);
            } else {
                throw new RuntimeException(&quot;Unexpected: &quot; + (char)ch);
            }
            
            if (eat('^')) x = Math.pow(x, parseFactor()); // exponentiation
            
            return x;
        }
