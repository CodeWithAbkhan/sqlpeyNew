“Android HTTP POST Requests: Java Code Examples & Solutions”

Making HTTP POST requests is a fundamental aspect of Android development, enabling applications to send data to servers for various operations like user authentication, data submission, or updates. The Android SDK provides several ways to achieve this, ranging from direct HttpURLConnection usage to leveraging powerful third-party libraries. Below are various methods and code examples to facilitate these network operations.

Solution 1: Using HttpURLConnection (Updated for Android 6.0+)

This approach uses the built-in HttpURLConnection class, which is the recommended way for network operations in modern Android development, especially since the deprecation of Apache’s HttpClient.

import android.os.AsyncTask;
import java.io.BufferedOutputStream;
import java.io.BufferedWriter;
import java.io.OutputStream;
import java.io.OutputStreamWriter;
import java.net.HttpURLConnection;
import java.net.URL;

public class CallAPI extends AsyncTask<String, Void, String> {

    @Override
    protected String doInBackground(String... params) {
        String urlString = params[0]; // URL to call
        String data = params[1];      // Data to post
        OutputStream out = null;
        String response = "";

        try {
            URL url = new URL(urlString);
            HttpURLConnection urlConnection = (HttpURLConnection) url.openConnection();
            urlConnection.setRequestMethod("POST"); // Explicitly set to POST
            urlConnection.setDoOutput(true); // Enable writing to the stream
            urlConnection.setConnectTimeout(15000); // Set connection timeout
            urlConnection.setReadTimeout(15000);    // Set read timeout

            out = urlConnection.getOutputStream();
            BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(out, "UTF-8"));
            writer.write(data);
            writer.flush();
            writer.close();
            out.close();

            // Read response
            int responseCode = urlConnection.getResponseCode();
            if (responseCode == HttpURLConnection.HTTP_OK) {
                java.io.BufferedReader reader = new java.io.BufferedReader(new java.io.InputStreamReader(urlConnection.getInputStream()));
                StringBuilder sb = new StringBuilder();
                String line;
                while ((line = reader.readLine()) != null) {
                    sb.append(line);
                }
                response = sb.toString();
            } else {
                response = "Error: " + responseCode;
            }

        } catch (Exception e) {
            response = e.getMessage();
        }
        return response;
    }

    @Override
    protected void onPostExecute(String result) {
        // Handle the response here, e.g., update UI
        System.out.println("Server response: " + result);
    }
}

To use this: new CallAPI().execute("http://your-server.com/api", "param1=value1&param2=value2");

Solution 2: Using HttpUrlConnection with HashMap for Parameters

This is an enhanced version of Solution 1, which neatly packages parameters into a HashMap and converts them into a URL-encoded string.

import android.os.AsyncTask;
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.io.OutputStreamWriter;
import java.io.UnsupportedEncodingException;
import java.net.HttpURLConnection;
import java.net.URL;
import java.net.URLEncoder;
import java.util.HashMap;
import java.util.Map;
import javax.net.ssl.HttpsURLConnection; // For HTTPS, use HttpsURLConnection

public class PerformPostCall extends AsyncTask<String, Void, String> {

    @Override
    protected String doInBackground(String... params) {
        String requestURL = params[0];
        String response = "";

        try {
            URL url = new URL(requestURL);
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();
            conn.setReadTimeout(15000);
            conn.setConnectTimeout(15000);
            conn.setRequestMethod("POST");
            conn.setDoInput(true);
            conn.setDoOutput(true);

            OutputStream os = conn.getOutputStream();
            BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(os, "UTF-8"));
            writer.write(getPostDataString(getPostDataParams(params))); // Assuming params[1] onwards are key-value pairs

            writer.flush();
            writer.close();
            os.close();
            int responseCode = conn.getResponseCode();

            if (responseCode == HttpsURLConnection.HTTP_OK) { // Use HttpURLConnection.HTTP_OK for HTTP
                String line;
                BufferedReader br = new BufferedReader(new InputStreamReader(conn.getInputStream()));
                while ((line = br.readLine()) != null) {
                    response += line;
                }
            } else {
                response = "";
            }
        } catch (Exception e) {
            e.printStackTrace();
            response = e.getMessage();
        }
        return response;
    }

    // Helper to get parameters from AsyncTask params
    private HashMap<String, String> getPostDataParams(String[] params) {
        HashMap<String, String> postDataParams = new HashMap<>();
        // Assuming params are like: url, key1, value1, key2, value2...
        for (int i = 1; i < params.length - 1; i += 2) {
            postDataParams.put(params[i], params[i+1]);
        }
        return postDataParams;
    }

    // Helper to encode HashMap parameters
    private String getPostDataString(HashMap<String, String> params) throws UnsupportedEncodingException {
        StringBuilder result = new StringBuilder();
        boolean first = true;
        for (Map.Entry<String, String> entry : params.entrySet()) {
            if (first)
                first = false;
            else
                result.append("&");

            result.append(URLEncoder.encode(entry.getKey(), "UTF-8"));
            result.append("=");
            result.append(URLEncoder.encode(entry.getValue(), "UTF-8"));
        }
        return result.toString();
    }

    @Override
    protected void onPostExecute(String result) {
        System.out.println("Server response: " + result);
    }
}

To use this: new PerformPostCall().execute("http://your-server.com/api", "username", "user123", "password", "pass456");

Solution 3: Using Apache Commons HttpClient (Deprecated for Android 5.1+)

This solution uses the HttpClient from Apache Commons, which was previously included in Android. However, it has been deprecated since Android 5.1. For older projects or specific needs, this might still be relevant, but HttpURLConnection or libraries are preferred for new development.

import android.os.AsyncTask;
import org.apache.http.HttpResponse;
import org.apache.http.NameValuePair;
import org.apache.http.client.ClientProtocolException;
import org.apache.http.client.HttpClient;
import org.apache.http.client.entity.UrlEncodedFormEntity;
import org.apache.http.client.methods.HttpPost;
import org.apache.http.impl.client.DefaultHttpClient;
import org.apache.http.message.BasicNameValuePair;
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.util.ArrayList;
import java.util.List;

public class PostDataOld extends AsyncTask<Void, Void, String> {

    @Override
    protected String doInBackground(Void... params) {
        String result = "";
        HttpClient httpclient = new DefaultHttpClient();
        HttpPost httppost = new HttpPost("http://www.yoursite.com/script.php");

        try {
            List<NameValuePair> nameValuePairs = new ArrayList<>(2);
            nameValuePairs.add(new BasicNameValuePair("id", "12345"));
            nameValuePairs.add(new BasicNameValuePair("stringdata", "Hi"));
            httppost.setEntity(new UrlEncodedFormEntity(nameValuePairs));

            HttpResponse response = httpclient.execute(httppost);
            HttpEntity entity = response.getEntity();
            if (entity != null) {
                InputStream instream = entity.getContent();
                result = convertStreamToString(instream);
                instream.close();
            }

        } catch (ClientProtocolException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        }
        return result;
    }

    @Override
    protected void onPostExecute(String s) {
        System.out.println("Response: " + s);
    }

    // Helper to convert InputStream to String
    private String convertStreamToString(InputStream is) {
        BufferedReader reader = new BufferedReader(new InputStreamReader(is));
        StringBuilder sb = new StringBuilder();
        String line = null;
        try {
            while ((line = reader.readLine()) != null) {
                sb.append(line).append("\n");
            }
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            try {
                is.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
        return sb.toString();
    }
}

Solution 4: Using OkHttp Library

OkHttp is a modern and efficient HTTP client developed by Square. It’s highly recommended for its performance, interceptor support, and ease of use.

First, add the dependency to your build.gradle file:

dependencies {
    implementation 'com.squareup.okhttp3:okhttp:4.12.0' // Use the latest version
}

import android.os.AsyncTask;
import okhttp3.FormBody;
import okhttp3.OkHttpClient;
import okhttp3.Request;
import okhttp3.RequestBody;
import okhttp3.Response;
import java.io.IOException;

public class OkHttpPoster extends AsyncTask<String, Void, String> {

    private final OkHttpClient client = new OkHttpClient();

    @Override
    protected String doInBackground(String... params) {
        String url = params[0];
        String email = params[1];
        String comment = params[2];

        RequestBody formBody = new FormBody.Builder()
                .add("email", email)
                .add("comment", comment)
                .build();

        Request request = new Request.Builder()
                .url(url)
                .post(formBody)
                .build();

        try {
            Response response = client.newCall(request).execute();
            if (!response.isSuccessful()) {
                return "Error: " + response.code();
            }
            return response.body().string();
        } catch (IOException e) {
            e.printStackTrace();
            return "Exception: " + e.getMessage();
        }
    }

    @Override
    protected void onPostExecute(String result) {
        System.out.println("OkHttp Response: " + result);
    }
}

To use this: new OkHttpPoster().execute("https://yourdomain.org/callback.php", "user@example.com", "This is a comment.");

Solution 5: Using Volley Library

Volley is another excellent networking library provided by Google, optimized for Android. It simplifies network operations and handles caching, threading, and parsing.

Add the dependency to your build.gradle file:

dependencies {
    implementation 'com.android.volley:volley:1.2.1' // Use the latest version
}

import android.content.Context;
import android.os.AsyncTask;
import android.util.Log;
import com.android.volley.Request;
import com.android.volley.RequestQueue;
import com.android.volley.Response;
import com.android.volley.VolleyError;
import com.android.volley.toolbox.StringRequest;
import com.android.volley.toolbox.Volley;
import java.util.HashMap;
import java.util.Map;

public class VolleyPoster extends AsyncTask<String, Void, Void> {

    private Context context;
    private RequestQueue queue;
    private static final String TAG = "VolleyPoster";

    public VolleyPoster(Context context) {
        this.context = context;
        this.queue = Volley.newRequestQueue(context);
    }

    @Override
    protected Void doInBackground(String... params) {
        String url = params[0];

        // Using StringRequest for simple string responses
        StringRequest stringRequest = new StringRequest(Request.Method.POST, url,
                new Response.Listener<String>() {
                    @Override
                    public void onResponse(String response) {
                        // Handle the response string
                        Log.i(TAG, "Response: " + response);
                    }
                }, new Response.ErrorListener() {
            @Override
            public void onErrorResponse(VolleyError error) {
                // Handle errors
                Log.e(TAG, "Error: " + error.getMessage());
            }
        }) {
            @Override
            protected Map<String, String> getParams() {
                Map<String, String> params = new HashMap<>();
                // Add your POST parameters here
                params.put("username", "testuser");
                params.put("password", "testpass");
                return params;
            }
        };

        // Add the request to the RequestQueue
        queue.add(stringRequest);
        return null;
    }
}

Solution 6: Sending JSON Data with HttpURLConnection

This method demonstrates how to send JSON data in the request body, which is common for modern APIs.

import android.os.AsyncTask;
import android.util.Log;
import org.json.JSONException;
import org.json.JSONObject;
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.io.OutputStreamWriter;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;

public class PostJsonData extends AsyncTask<String, Void, String> {

    private static final String TAG = "PostJsonData";

    @Override
    protected String doInBackground(String... params) {
        String requestURL = params[0];
        JSONObject jsonObject = new JSONObject();
        try {
            // Construct your JSON object here
            jsonObject.put("advertisementId", 12345);
            jsonObject.put("userToken", "aBcDeF12345");
        } catch (JSONException e) {
            e.printStackTrace();
            return "JSON Error";
        }

        String response = "";
        HttpURLConnection conn = null;
        OutputStream os = null;

        try {
            URL url = new URL(requestURL);
            conn = (HttpURLConnection) url.openConnection();
            conn.setReadTimeout(15000);
            conn.setConnectTimeout(15000);
            conn.setRequestMethod("POST");
            conn.setDoInput(true);
            conn.setDoOutput(true);

            conn.setRequestProperty("Content-Type", "application/json");
            conn.setRequestProperty("Accept", "application/json");

            os = conn.getOutputStream();
            BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(os, StandardCharsets.UTF_8));
            writer.write(jsonObject.toString());
            writer.flush();
            writer.close();
            os.close();

            int responseCode = conn.getResponseCode();
            Log.d(TAG, "Response Code: " + responseCode);

            if (responseCode == HttpURLConnection.HTTP_OK) {
                BufferedReader br = new BufferedReader(new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8));
                StringBuilder sb = new StringBuilder();
                String line;
                while ((line = br.readLine()) != null) {
                    sb.append(line);
                }
                response = sb.toString();
            } else {
                response = "Error: " + responseCode;
            }
        } catch (Exception e) {
            e.printStackTrace();
            response = e.getMessage();
        } finally {
            if (conn != null) {
                conn.disconnect();
            }
        }
        return response;
    }

    @Override
    protected void onPostExecute(String result) {
        Log.i(TAG, "Server Response: " + result);
    }
}

To use this: new PostJsonData().execute("http://your-api.com/data");

Solution 7: Sending Multi-part Form Data

This approach is useful for uploading files along with other data. It constructs a multipart request manually.

import android.os.AsyncTask;
import android.util.Log;
import java.io.BufferedOutputStream;
import java.io.BufferedWriter;
import java.io.ByteArrayOutputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.io.OutputStream;
import java.io.OutputStreamWriter;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;

public class MultipartUploader extends AsyncTask<String, Void, String> {

    private static final String TAG = "MultipartUploader";
    private final String MULTIPART_BOUNDARY = "xxYYzzSEPARATORzzYYxx";
    private final String MULTIPART_SEPARATOR = "--" + MULTIPART_BOUNDARY + "\r\n";
    private final String FORM_DATA_HEADER = "Content-Disposition: form-data; name=\"%s\"\r\n\r\n";
    private final String FILE_HEADER = "Content-Disposition: form-data; name=\"%s\";filename=\"%s\"\r\nContent-Type: %s\r\n\r\n";

    @Override
    protected String doInBackground(String... params) {
        String urlString = params[0];
        String textParamName = params[1];
        String textParamValue = params[2];
        String fileParamName = params[3];
        String fileName = params[4];
        byte[] fileBytes = getFileBytes(); // Assume this method returns your file data as bytes

        OutputStream outputStream;
        String response = "";

        try {
            URL url = new URL(urlString);
            HttpURLConnection urlConnection = (HttpURLConnection) url.openConnection();
            urlConnection.setRequestMethod("POST");
            urlConnection.setDoOutput(true);
            urlConnection.setConnectTimeout(30000);
            urlConnection.setReadTimeout(30000);
            urlConnection.setRequestProperty("Connection", "Keep-Alive");
            urlConnection.setRequestProperty("Cache-Control", "no-cache");
            urlConnection.setRequestProperty("Content-Type", "multipart/form-data;boundary=" + MULTIPART_BOUNDARY);

            outputStream = new BufferedOutputStream(urlConnection.getOutputStream());
            BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(outputStream, StandardCharsets.UTF_8));

            // Add text parameter
            writer.write(MULTIPART_SEPARATOR);
            writer.write(String.format(FORM_DATA_HEADER, textParamName));
            writer.write(textParamValue + "\r\n");

            // Add file parameter
            writer.write(MULTIPART_SEPARATOR);
            writer.write(String.format(FILE_HEADER, fileParamName, fileName, "application/octet-stream"));
            outputStream.write(fileBytes);
            writer.write("\r\n");

            writer.write(MULTIPART_SEPARATOR + "--" + MULTIPART_BOUNDARY + "--" + "\r\n");
            writer.flush();
            writer.close();
            outputStream.close();

            urlConnection.connect();

            int responseCode = urlConnection.getResponseCode();
            Log.d(TAG, "Response Code: " + responseCode);

            if (responseCode == HttpURLConnection.HTTP_OK) {
                BufferedReader reader = new BufferedReader(new InputStreamReader(urlConnection.getInputStream(), StandardCharsets.UTF_8));
                StringBuilder sb = new StringBuilder();
                String line;
                while ((line = reader.readLine()) != null) {
                    sb.append(line);
                }
                response = sb.toString();
            } else {
                response = "Error: " + responseCode;
            }
            urlConnection.disconnect();
        } catch (IOException e) {
            e.printStackTrace();
            response = e.getMessage();
        }
        return response;
    }

    // Placeholder for getting file bytes
    private byte[] getFileBytes() {
        // In a real app, you would read this from a file or another source
        return "This is sample file content.".getBytes(StandardCharsets.UTF_8);
    }

    @Override
    protected void onPostExecute(String result) {
        Log.i(TAG, "Multipart Upload Response: " + result);
    }
}

To use this: new MultipartUploader().execute("https://example.com/upload", "description", "A file description", "myFile", "test.txt");

Solution 8: Using Retrofit Library

Retrofit is a type-safe HTTP client for Android and Java by Square. It makes networking significantly easier by converting API calls into Java interfaces.

Add dependencies to build.gradle:

dependencies {
    implementation 'com.squareup.retrofit2:retrofit:2.9.0' // Use the latest version
    implementation 'com.squareup.retrofit2:converter-gson:2.9.0' // For JSON parsing with Gson
}

1. Define your API service interface:

import java.util.Map;
import retrofit2.Call;
import retrofit2.http.Field;
import retrofit2.http.FieldMap;
import retrofit2.http.FormUrlEncoded;
import retrofit2.http.POST;

public interface ApiService {
    @FormUrlEncoded
    @POST("your_api_endpoint")
    Call<String> postData(
            @Field("username") String username,
            @Field("password") String password
    );

    @FormUrlEncoded
    @POST("your_json_endpoint")
    Call<String> postJsonData(@FieldMap Map<String, String> fields);
}

2. Create a Retrofit instance and make the call:

import android.os.AsyncTask;
import android.util.Log;
import retrofit2.Call;
import retrofit2.Callback;
import retrofit2.Response;
import retrofit2.Retrofit;
import retrofit2.converter.gson.GsonConverterFactory;
import java.util.HashMap;
import java.util.Map;

public class RetrofitPoster extends AsyncTask<Void, Void, Void> {

    private static final String TAG = "RetrofitPoster";
    private Retrofit retrofit;
    private ApiService apiService;

    @Override
    protected void onPreExecute() {
        super.onPreExecute();
        retrofit = new Retrofit.Builder()
                .baseUrl("https://your-base-url.com/") // Base URL for your API
                .addConverterFactory(GsonConverterFactory.create()) // Add converter for JSON
                .build();
        apiService = retrofit.create(ApiService.class);
    }

    @Override
    protected Void doInBackground(Void... voids) {
        // Example 1: Posting simple key-value pairs
        Call<String> call1 = apiService.postData("exampleUser", "securePassword");
        call1.enqueue(new Callback<String>() {
            @Override
            public void onResponse(Call<String> call, Response<String> response) {
                if (response.isSuccessful() && response.body() != null) {
                    Log.i(TAG, "Retrofit Post Data Success: " + response.body());
                } else {
                    Log.e(TAG, "Retrofit Post Data Error: " + response.message());
                }
            }

            @Override
            public void onFailure(Call<String> call, Throwable t) {
                Log.e(TAG, "Retrofit Post Data Failure: " + t.getMessage());
            }
        });

        // Example 2: Posting with FieldMap (useful for dynamic parameters)
        Map<String, String> data = new HashMap<>();
        data.put("param1", "value1");
        data.put("param2", "value2");
        Call<String> call2 = apiService.postJsonData(data);
        call2.enqueue(new Callback<String>() {
            @Override
            public void onResponse(Call<String> call, Response<String> response) {
                if (response.isSuccessful() && response.body() != null) {
                    Log.i(TAG, "Retrofit Post FieldMap Success: " + response.body());
                } else {
                    Log.e(TAG, "Retrofit Post FieldMap Error: " + response.message());
                }
            }

            @Override
            public void onFailure(Call<String> call, Throwable t) {
                Log.e(TAG, "Retrofit Post FieldMap Failure: " + t.getMessage());
            }
        });

        return null;
    }
}

To use this: new RetrofitPoster().execute();

Solution 9: Sending Data as JSON Body

This method focuses on sending JSON data as the request body using HttpURLConnection, similar to Solution 6 but emphasizing the JSON body aspect.

import android.os.AsyncTask;
import android.util.Log;
import org.json.JSONException;
import org.json.JSONObject;
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;

public class SendJsonBody extends AsyncTask<String, Void, String> {

    private static final String TAG = "SendJsonBody";

    @Override
    protected String doInBackground(String... params) {
        String urlString = params[0];
        String response = "";

        try {
            JSONObject jsonObject = new JSONObject();
            jsonObject.put("key1", "value1");
            jsonObject.put("key2", "value2");

            URL url = new URL(urlString);
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();
            conn.setDoOutput(true);
            conn.setRequestMethod("POST");
            conn.setRequestProperty("Content-Type", "application/json");
            conn.setRequestProperty("Accept", "application/json");
            conn.setConnectTimeout(15000);
            conn.setReadTimeout(15000);

            try (OutputStream os = conn.getOutputStream()) {
                byte[] input = jsonObject.toString().getBytes(StandardCharsets.UTF_8);
                os.write(input, 0, input.length);
            }

            int responseCode = conn.getResponseCode();
            Log.d(TAG, "Response Code: " + responseCode);

            if (responseCode == HttpURLConnection.HTTP_OK) {
                try (BufferedReader br = new BufferedReader(new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8))) {
                    StringBuilder sb = new StringBuilder();
                    String line;
                    while ((line = br.readLine()) != null) {
                        sb.append(line);
                    }
                    response = sb.toString();
                }
            } else {
                response = "Error: " + responseCode;
            }
        } catch (JSONException e) {
            Log.e(TAG, "JSON creation error", e);
            response = "JSON Error";
        } catch (Exception e) {
            Log.e(TAG, "Network error", e);
            response = e.getMessage();
        }
        return response;
    }

    @Override
    protected void onPostExecute(String result) {
        Log.i(TAG, "Response: " + result);
    }
}

To use this: new SendJsonBody().execute("http://api.example.com/submit");

Important Considerations:

  • Threading: Network operations must always be performed on a background thread to avoid blocking the UI thread. AsyncTask is a common way to handle this, but libraries like Volley, Retrofit, and OkHttp manage threading internally.
  • Permissions: Ensure you have the android.permission.INTERNET permission declared in your AndroidManifest.xml file.
  • Error Handling: Implement robust error handling for network issues, server errors, and unexpected responses.
  • HTTPS: Always prefer HTTPS for secure communication.
  • Libraries: For most applications, using libraries like OkHttp, Volley, or Retrofit is highly recommended. They abstract away much of the complexity, improve performance, and provide better error handling and features. You can find more information about making HTTP requests in Android networking .

FAQs on Android HTTP POST Requests

Q: How do I send parameters with an HTTP POST request in Android?

ANS: You can send parameters by appending them to the URL for GET requests, but for POST requests, you typically include them in the request body. Libraries like OkHttp, Volley, and Retrofit simplify this by allowing you to pass parameters as key-value pairs or JSON objects. For manual HttpURLConnection usage, you encode the parameters (e.g., param1=value1&param2=value2) and write them to the output stream.

Q: What is the best library for making HTTP requests in Android?

ANS: For modern Android development, OkHttp, Volley, and Retrofit are excellent choices. OkHttp is efficient and flexible. Volley is great for caching and queuing. Retrofit offers type-safe API calls and integrates well with JSON parsing libraries. The “best” choice often depends on the project’s specific needs.

Q: Why is my HTTP POST request failing in Android?
