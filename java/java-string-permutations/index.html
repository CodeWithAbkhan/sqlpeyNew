“Java String Permutations: Recursive and Iterative Approaches Explained”

Generating all possible arrangements, or permutations, of a string’s characters is a common programming challenge. This involves exploring different sequences by swapping characters. Several algorithmic approaches exist, primarily utilizing recursion or iterative methods. Below, we explore various Java implementations to achieve this.

Solution 1: Recursive Permutation with Prefix and Remaining String

This approach uses recursion by building a permutation step-by-step. It maintains a prefix string (the part of the permutation built so far) and the remaining string.

public static void permutation(String str) {
    permutation("", str);
}

private static void permutation(String prefix, String str) {
    int n = str.length();
    if (n == 0) {
        System.out.println(prefix);
    } else {
        for (int i = 0; i < n; i++) {
            permutation(prefix + str.charAt(i), str.substring(0, i) + str.substring(i + 1, n));
        }
    }
}

Solution 2: Recursive Logic Explained

The core idea is to use recursion. For each character in the string, consider it as the first character of a permutation. Then, recursively find all permutations of the remaining characters. The base case is when the input string is empty, in which case the current prefix is a complete permutation.

Solution 3: Permutations via Recursive String Merging

This method recursively generates permutations by taking the last character of a string and merging it into all possible positions of the permutations of the remaining substring.

/**
 * List permutations of a string.
 *
 * @param s the input string
 * @return  the list of permutations
 */
public static ArrayList<String> permutation(String s) {
    ArrayList<String> res = new ArrayList<>();
    if (s.length() == 1) {
        res.add(s);
    } else if (s.length() > 1) {
        int lastIndex = s.length() - 1;
        String last = s.substring(lastIndex);
        String rest = s.substring(0, lastIndex);
        res = merge(permutation(rest), last);
    }
    return res;
}

/**
 * @param list a result of permutation, e.g. {"ab", "ba"}
 * @param c    the last character
 * @return     a merged new list, e.g. {"cab", "acb" ... }
 */
public static ArrayList<String> merge(ArrayList<String> list, String c) {
    ArrayList<String> res = new ArrayList<>();
    for (String s : list) {
        for (int i = 0; i <= s.length(); ++i) {
            String ps = new StringBuffer(s).insert(i, c).toString();
            res.add(ps);
        }
    }
    return res;
}

Solution 4: In-place Swapping with StringBuffer

This implementation leverages StringBuffer for efficient in-place modifications through swapping characters. It’s noted as potentially more memory-efficient than solutions creating numerous temporary strings.

public class PermTest {

    public static void main(String[] args) throws Exception {
        String str = "abcdef";
        StringBuffer strBuf = new StringBuffer(str);
        doPerm(strBuf, 0);
    }

    private static void doPerm(StringBuffer str, int index) {
        if (index == str.length())
            System.out.println(str);
        else {
            for (int i = index; i < str.length(); i++) {
                swap(str, index, i);
                doPerm(str, index + 1);
                swap(str, i, index); // backtrack
            }
        }
    }

    private static void swap(StringBuffer str, int pos1, int pos2) {
        char t1 = str.charAt(pos1);
        str.setCharAt(pos1, str.charAt(pos2));
        str.setCharAt(pos2, t1);
    }
}

Solution 5: Recursive Approach with a Set for Uniqueness

To handle potential duplicate characters in the input string and ensure unique permutations, a Set can be employed.

public static Set<String> generatePerm(String input) {
    Set<String> set = new HashSet<>();
    if (input.isEmpty()) {
        return set;
    }

    Character firstChar = input.charAt(0);
    if (input.length() > 1) {
        String remaining = input.substring(1);
        Set<String> permSet = generatePerm(remaining);
        for (String perm : permSet) {
            for (int i = 0; i <= perm.length(); i++) {
                set.add(perm.substring(0, i) + firstChar + perm.substring(i));
            }
        }
    } else {
        set.add(String.valueOf(firstChar));
    }
    return set;
}

Solution 6: Heap’s Algorithm Implementation

Heap’s algorithm is an efficient recursive method for generating all permutations. It involves swapping elements based on whether the current position’s index is even or odd.

public static void main(String[] args) {

private static void swap(String[] ourarray, int right, int left) {
    String temp = ourarray[right];
    ourarray[right] = ourarray[left];
    ourarray[left] = temp;

Solution 7: Iterative String Permutation Generation

This approach builds permutations iteratively. It starts with the first character and then inserts subsequent characters into all possible positions of the permutations generated so far.

public class Test {
    static Set<String> permutations;
    static Set<String> result = new HashSet<>();

    public static Set<String> permutation(String string) {
        permutations = new HashSet<>();
        int n = string.length();
        for (int i = n - 1; i >= 0; i--) {
            shuffle(string.charAt(i));
        }
        return permutations;
    }

    private static void shuffle(char c) {
        if (permutations.size() == 0) {
            permutations.add(String.valueOf(c));
        } else {
            Iterator<String> it = permutations.iterator();
            while (it.hasNext()) {
                String temp = it.next();
                for (int k = 0; k <= temp.length(); k++) {
                    StringBuilder sb = new StringBuilder(temp);
                    sb.insert(k, c);
                    result.add(sb.toString());
                }
            }
            permutations = result;
            result = new HashSet<>(); // Reset for next character
        }
    }

    public static void main(String[] args) {
        Set<String> result = permutation("abc");
        System.out.println("Total permutations: " + result.size());
        for (String perm : result) {
            System.out.println(perm);
        }
    }
}

Solution 9: Factorial-Based Permutation Generation (Non-Recursive)

This approach uses factorials to directly calculate the positions of characters for each permutation, avoiding recursion. It’s efficient for generating permutations without explicit recursive calls.

public static StringBuilder[] permutations(String s) {
    if (s.length() == 0) {
        return null;
    }
    int length = factorial(s.length());
    StringBuilder[] sb = new StringBuilder[length];
    for (int i = 0; i < length; i++) {
        sb[i] = new StringBuilder();
    }
    for (int i = 0; i < s.length(); i++) {
        char ch = s.charAt(i);
        int times = length / (i + 1);
        for (int j = 0; j < times; j++) {
            for (int k = 0; k < length / times; k++) {
                sb[j * length / times + k].insert(k, ch);
            }
        }
    }
    return sb;
}

Solution 10: Recursive Swapping with Pointers

This solution uses recursion and swaps characters in an array using index pointers. It’s a common and effective way to generate permutations.

public static void perm(String str) {
    char[] charArray = str.toCharArray();
    helper(charArray, 0);
}

public static void helper(char[] charArray, int i) {
    if (i == charArray.length - 1) {
        System.out.println(String.valueOf(charArray));
    } else {
        for (int j = i; j < charArray.length; j++) {
            swap(charArray, i, j);
            helper(charArray, i + 1);
            swap(charArray, j, i); // backtrack
        }
    }
}

private static void swap(char[] charArray, int pos1, int pos2) {
    char temp = charArray[pos1];
    charArray[pos1] = charArray[pos2];
    charArray[pos2] = temp;
}

Solution 12: Lexicographical Permutations

This approach generates permutations in lexicographical (alphabetical) order. It recursively finds permutations of the substring excluding the first character and then prepends the first character.

public class LexicographicPermutations {

        Collections.sort(combinations); // Ensure lexicographical order

        if (s.length() == 1) {

        }
        return combinations;
    }
}

Solution 14: Iterative Permutation Generation using a Queue

This non-recursive approach uses a Queue to manage permutations, adding new permutations generated by rotating characters.

public Set<String> permutate(String s) {
    Queue<String> permutations = new LinkedList<>();
    Set<String> generated = new HashSet<>();
    permutations.add(s);

    while (!permutations.isEmpty()) {
        String current = permutations.poll();
        if (generated.contains(current)) {
            continue;
        }
        generated.add(current);
        for (int i = 0; i < current.length(); i++) {
            String rotated = current.substring(i + 1) + current.charAt(i) + current.substring(0, i);
            permutations.add(rotated);
        }
    }
    return generated;
}

Solution 15: Recursive Permutation with Array Swapping

A classic recursive solution that manipulates a character array directly through swaps.

public class StringPermutations {
    public static void main(String[] args) {
        String inputString = "ABC";
        permute(inputString.toCharArray(), 0, inputString.length() - 1);
    }

    public static void permute(char[] ary, int startIndex, int endIndex) {
        if (startIndex == endIndex) {
            System.out.println(String.valueOf(ary));
        } else {
            for (int i = startIndex; i <= endIndex; i++) {
                swap(ary, startIndex, i);
                permute(ary, startIndex + 1, endIndex);
                swap(ary, i, startIndex); // backtrack
            }
        }
    }

    public static void swap(char[] ary, int x, int y) {
        char temp = ary[x];
        ary[x] = ary[y];
        ary[y] = temp;
    }
}

Solution 18: Permutation Generation by Inserting Characters

This method generates permutations by starting with the first character and then inserting each subsequent character into all possible positions of the permutations created so far.

public static ArrayList<String> permute(String s) {
    ArrayList<String> perms = new ArrayList<>();
    int slen = s.length();
    if (slen > 0) {
        perms.add(Character.toString(s.charAt(0)));
        for (int i = 1; i < slen; ++i) {
            char c = s.charAt(i);
            int size = perms.size();
            for (int j = 0; j < size; ++j) {
                String p = perms.remove(0);
                int plen = p.length();
                for (int k = 0; k <= plen; ++k) {
                    perms.add(p.substring(0, k) + c + p.substring(k));
                }
            }
        }
    }
    return perms;
}

Solution 23: Backtracking Permutation with Duplicate Handling

A backtracking solution that efficiently generates unique permutations, even with duplicate characters in the input string. It sorts the characters first to simplify duplicate detection.

public List<String> permute(String str) {
    if (str == null) {
        return null;
    }

    char[] chars = str.toCharArray();
    boolean[] used = new boolean[chars.length];
    List<String> res = new ArrayList<>();
    StringBuilder sb = new StringBuilder();
    Arrays.sort(chars); // Essential for duplicate handling

    helper(chars, used, sb, res);
    return res;
}

void helper(char[] chars, boolean[] used, StringBuilder sb, List<String> res) {
    if (sb.length() == chars.length) {
        res.add(sb.toString());
        return;
    }

    for (int i = 0; i < chars.length; i++) {
        // Skip duplicates: if current char is same as previous and previous wasn't used
        if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) {
            continue;
        }

        if (!used[i]) {
            used[i] = true;
            sb.append(chars[i]);
            helper(chars, used, sb, res);
            sb.deleteCharAt(sb.length() - 1); // backtrack
            used[i] = false;
        }
    }
}

Solution 27: Simple Recursive Permutation

public class Solution4 {

Solution 30: Generating Permutations as Lists of Integers

This solution generates permutations of a sequence of integers, returning them as a list of integer arrays. It’s adaptable for other data types.

static List<int[]> permutations(int n) {
    class Perm {
        private final List<int[]> permutations = new ArrayList<>();

        private void perm(int[] array, int step) {
            if (step == 1) permutations.add(array.clone());
            else for (int i = 0; i < step; i++) {
                perm(array, step - 1);
                int j = (step % 2 == 0) ? i : 0;
                swap(array, step - 1, j);
            }
        }

        private void swap(int[] array, int i, int j) {
            int buffer = array[i];
            array[i] = array[j];
            array[j] = buffer;
        }
    }

    int[] nVector = new int[n];
    for (int i = 0; i < n; i++) nVector[i] = i;

    Perm perm = new Perm();
    perm.perm(nVector, n);
    return perm.permutations;
}

FAQs on Java String Permutations

Q: What is the primary difference between recursive and iterative permutation algorithms

ANS: Recursive algorithms break the problem into smaller, self-similar subproblems, often using function calls. Iterative algorithms use loops and data structures like stacks or queues to achieve the same result without explicit recursion.

Q: How do algorithms handle duplicate characters in a string during permutation

ANS: Duplicate characters can lead to redundant permutations. Solutions often use a Set to store generated permutations, automatically discarding duplicates, or employ specific logic (like sorting and checking adjacent elements) to prevent generating duplicates in the first place.

Q: What is backtracking in the context of string permutations

ANS: Backtracking is a general algorithmic technique where a solution is built step-by-step. If a partial solution cannot be extended to a complete solution, the algorithm “backtracks” to a previous state and tries a different path. For permutations, this often involves swapping characters, exploring a path, and then undoing the swap to explore other possibilities.

Q: What is the time complexity for generating all permutations of a string of length N

ANS: Generating all permutations of a string of length N typically has a time complexity of O(N * N!), because there are N! permutations, and generating each one might involve operations proportional to N.
