“Java Method References :: What They Are & How to Use Them”

In Java 8 and later, the :: operator, known as a method reference, offers a more readable and concise way to refer to methods that are already defined. It essentially acts as a shorthand for a lambda expression that simply calls an existing method. This can significantly streamline your code, especially when dealing with functional interfaces.

Let’s delve into how method references work, their different types, and practical scenarios for their use.

How Method References Work

At their core, method references are expressions that have the same treatment as lambda expressions. Instead of providing a method body within the lambda, you provide a reference to an existing method by its name. The Java compiler infers the necessary context, often linking the method reference to a functional interface.

A functional interface is an interface with exactly one abstract method. Examples include Runnable, Callable, Comparator, and Function. Method references are a powerful tool for providing implementations for these interfaces.

Consider a lambda expression like (int left, int right) -> Math.max(left, right). This lambda takes two integers and returns their maximum. The Math.max method itself fulfills the requirements of the IntBinaryOperator functional interface, which the reduce method expects. A method reference allows you to represent this more succinctly: Math::max.

Types of Method References

Method references can be categorized into several types, each corresponding to a different way of referencing a method:

  1. Reference to a Static Method: This type refers to a static method of a class.

    • Syntax: ClassName::staticMethodName
    • Example: System.out::println references the static println method of the System.out object.
    import java.util.function.Consumer;

// Using a lambda expression
Consumer<String> printLambda = s -> System.out.println(s);

// Using a method reference to a static method
Consumer<String> printMethodRef = System.out::println;

// Example usage
printLambda.accept("Hello from lambda!");
printMethodRef.accept("Hello from method reference!");

  2. Reference to an Instance Method of a Particular Object: This refers to an instance method of a specific object instance.

    • Syntax: objectReference::instanceMethodName
    • Example: If you have an instance myObject and a method myMethod, you’d write myObject::myMethod.
    import java.util.function.Consumer;

class Greeter {
    public void greet(String name) {
        System.out.println("Hello, " + name);
    }
}

// Using a lambda expression
Greeter greeter = new Greeter();
Consumer<String> greetLambda = name -> greeter.greet(name);

// Using a method reference to an instance method
Consumer<String> greetMethodRef = greeter::greet;

// Example usage
greetLambda.accept("Alice");
greetMethodRef.accept("Bob");

  3. Reference to an Instance Method of an Arbitrary Object of a Particular Type: This is used when the first argument to the lambda is the object on which the instance method is invoked.

    • Syntax: ContainingType::methodName
    • Example: String::length refers to the length() method of any String object.
    import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

// Using a lambda expression
List<String> words = new ArrayList<>(List.of("apple", "banana", "cherry"));
words.sort((s1, s2) -> s1.length() - s2.length());

// Using a method reference to an instance method of a particular type
List<String> wordsRef = new ArrayList<>(List.of("apple", "banana", "cherry"));
wordsRef.sort(Comparator.comparing(String::length));

System.out.println(words);
System.out.println(wordsRef);

  4. Reference to a Constructor: This refers to the constructor of a class.

    • Syntax: ClassName::new
    • Example: ArrayList::new refers to the constructor of the ArrayList class.
    import java.util.ArrayList;
import java.util.List;
import java.util.function.Supplier;

// Using a lambda expression
Supplier<ArrayList<String>> listSupplierLambda = () -> new ArrayList<String>();

// Using a method reference to a constructor
Supplier<ArrayList<String>> listSupplierMethodRef = ArrayList::new;

// Example usage
ArrayList<String> list1 = listSupplierLambda.get();
ArrayList<String> list2 = listSupplierMethodRef.get();
System.out.println(list1.getClass().getName());
System.out.println(list2.getClass().getName());

Practical Applications and Examples

Method references are particularly useful in scenarios involving stream operations, collections, and event handling.

Sorting with Method References

Consider sorting a list of custom objects. Instead of writing a lambda to extract the property to sort by, you can use a method reference.

import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Arrays;

class Employee {
    private String name;
    private String grade;

    public Employee(String name, String grade) {
        this.name = name;
        this.grade = grade;
    }

    public String getName() {
        return name;
    }

    public String getGrade() {
        return grade;
    }

    // A static method for comparison
    public static int compareByGradeStatic(Employee e1, Employee e2) {
        return e1.getGrade().compareTo(e2.getGrade());
    }

    @Override
    public String toString() {
        return "Employee{" + "name='" + name + '\'' + ", grade='" + grade + '\'' + '}';
    }
}

public class MethodReferenceSorting {

    private static List<Employee> getDummyEmployees() {
        return Arrays.asList(new Employee("Carrie", "C"),
                new Employee("Fanishwar", "F"),
                new Employee("Brian", "B"),
                new Employee("Donald", "D"),
                new Employee("Adam", "A"),
                new Employee("Evan", "E")
        );
    }

    public static void main(String[] args) {
        List<Employee> employeeList = getDummyEmployees();

        // Using a lambda expression for sorting
        System.out.println("Sorting with Lambda:");
        employeeList.sort((e1, e2) -> e1.getGrade().compareTo(e2.getGrade()));
        employeeList.forEach(System.out::println);

        // Resetting the list for the next sort
        employeeList = getDummyEmployees();

        // Using a method reference for sorting
        System.out.println("\nSorting with Method Reference:");
        employeeList.sort(Comparator.comparing(Employee::getGrade));
        employeeList.forEach(System.out::println);

        // Using a reference to a static method for sorting
        System.out.println("\nSorting with Static Method Reference:");
        employeeList.sort(Employee::compareByGradeStatic);
        employeeList.forEach(System.out::println);
    }
}

Stream Operations

Method references are also commonly used with Java Streams for operations like map, filter, and forEach.

import java.util.Arrays;
import java.util.List;

public class StreamMethodReferences {
    public static void main(String[] args) {
        List<String> messages = Arrays.asList("Java 8", "Method References", "Conciseness");

        // Using a lambda for printing
        System.out.println("Printing with Lambda:");
        messages.stream()
                .forEach(msg -> System.out.println(msg));

        // Using a method reference for printing
        System.out.println("\nPrinting with Method Reference:");
        messages.stream()
                .forEach(System.out::println);

        // Using method reference for string length
        messages.stream()
                .map(String::length) // Refers to the length() method of String
                .forEach(len -> System.out.println("Length: " + len));
    }
}

:: vs. Lambda Expressions

While lambda expressions provide a way to create anonymous methods, method references are a cleaner way to refer to existing methods that serve the same purpose.

  • Readability: Method references are often more readable than equivalent lambda expressions, especially for simple method calls.
  • Conciseness: They reduce the amount of boilerplate code.
  • Efficiency: While the Java compiler might generate similar bytecodes for both, method references can sometimes be slightly more optimized as they directly point to the method.

The choice between a lambda expression and a method reference often comes down to clarity and conciseness. If a lambda simply calls an existing method, a method reference is generally preferred.

Alternatives to Method References (Pre-Java 8)

Before Java 8 and the introduction of method references and lambda expressions, achieving similar functionality involved using anonymous inner classes.

import java.util.ArrayList;
import java.util.Collections;
import java.util.Comparator;
import java.util.List;

class MyClass {
    private int val;

    MyClass(int v) { val = v; }
    int getVal() { return val; }

    @Override
    public String toString() {
        return "MyClass{" + "val=" + val + '}';
    }
}

public class PreJava8Comparison {

    // Comparator implementation using anonymous inner class
    static class ByVal implements Comparator<MyClass> {
        @Override
        public int compare(MyClass source, MyClass ref) {
            return source.getVal() - ref.getVal();
        }
    }

    public static void main(String[] args) {
        List<MyClass> myClassList = new ArrayList<>();
        myClassList.add(new MyClass(1));
        myClassList.add(new MyClass(0));
        myClassList.add(new MyClass(3));
        myClassList.add(new MyClass(6));

        System.out.println("Original List: " + myClassList);

        // Sorting using anonymous inner class
        Collections.sort(myClassList, new ByVal());
        System.out.println("Sorted with Anonymous Class: " + myClassList);

        // Resetting the list
        myClassList.clear();
        myClassList.add(new MyClass(1));
        myClassList.add(new MyClass(0));
        myClassList.add(new MyClass(3));
        myClassList.add(new MyClass(6));

        // Sorting using Java 8 method reference
        Collections.sort(myClassList, Comparator.comparing(MyClass::getVal));
        System.out.println("Sorted with Method Reference: " + myClassList);
    }
}

Key Takeaways

  • The :: operator in Java 8+ signifies a method reference.
  • Method references provide a concise way to refer to methods without executing them.
  • They are a shorthand for lambda expressions that perform a single method call.
  • Types include references to static methods, instance methods (of an object or a type), and constructors.
  • Method references enhance code readability and reduce verbosity, especially in functional programming contexts.

FAQs on Java Method References

Q: What is the main advantage of using method references in Java

ANS: Method references offer a more concise and readable alternative to lambda expressions that simply call an existing method, reducing boilerplate code.

Q: Can method references be used for constructors

ANS: Yes, you can use ClassName::new to refer to a class constructor, often used with Supplier or other functional interfaces that create objects.

Q: What is the syntax for a reference to a static method

ANS: The syntax is ClassName::staticMethodName.

Q: How does a method reference relate to functional interfaces

ANS: Method references are used to provide implementations for functional interfaces, where the signature of the referenced method matches the abstract method of the interface.

Q: Are method references compiled differently than lambdas

ANS: At runtime, they often behave identically. The bytecode might differ, but semantically they achieve the same outcome.
