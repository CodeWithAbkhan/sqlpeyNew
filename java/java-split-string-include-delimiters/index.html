How to Split a String in Java and Keep the Delimiters?

When working with string manipulation in Java, a common requirement is to split a string based on a delimiter, but unlike the standard String.split() method which discards the delimiters, you might need to preserve them within the resulting array. This can be crucial for tasks like tokenizing mathematical expressions, parsing structured text, or reassembling strings.

The default String.split() method in Java is efficient for removing delimiters, but it doesn’t offer a direct way to include them in the output. However, Java’s powerful regular expression capabilities, specifically lookarounds, provide elegant solutions. Other approaches involve custom implementations or leveraging different classes.

Let’s explore various methods to achieve this string splitting behavior.

Solution 1: Using Lookarounds in Regular Expressions

One of the most effective ways to split a string while keeping the delimiters is by employing zero-width assertions in regular expressions: positive lookbehind (?<=...) and positive lookahead (?=...). These assertions match a position in the string without consuming characters.

By combining these, you can split the string at positions immediately before or after a delimiter, effectively including the delimiter as a separate element in the resulting array.

The pattern ((?<=DELIMITER)|(?=DELIMITER)) is key here. It matches a position that is either preceded by (?<=DELIMITER) or followed by (?=DELIMITER) the specified delimiter.

Example: Splitting a string by semicolon ;.

import java.util.Arrays;

public class SplitWithLookarounds {
    public static void main(String[] args) {
        String data = "a;b;c;d";

        // Split keeping the delimiter at the end of the preceding element
        String[] splitWithDelimiterEnd = data.split("(?<=");
        System.out.println("Split with lookbehind (?<=;): " + Arrays.toString(splitWithDelimiterEnd));
        // Output: Split with lookbehind (?<=;): [a;, b;, c;, d]

        // Split keeping the delimiter at the beginning of the succeeding element
        String[] splitWithDelimiterStart = data.split("(?=;)");
        System.out.println("Split with lookahead (?=;): " + Arrays.toString(splitWithDelimiterStart));
        // Output: Split with lookahead (?=;): [a, ;b, ;c, ;d]

        // Split keeping the delimiter as its own element
        String[] splitWithDelimiterBoth = data.split("((?<=" + Pattern.quote(";") + ")|(?=" + Pattern.quote(";") + "))");
        System.out.println("Split with both (?<=;) | (?=;): " + Arrays.toString(splitWithDelimiterBoth));
        // Output: Split with both (?<=;) | (?=;): [a, ;, b, ;, c, ;, d]
    }
}

Improving Readability with String.format:

For better maintainability, especially with complex regex, you can define the pattern with placeholders.

import java.util.Arrays;

public class SplitWithFormattedDelimiter {

    public static final String WITH_DELIMITER_PATTERN = "((?<=%1$s)|(?=%1$s))";

    public static void main(String[] args) {
        String data = "item1|item2|item3";
        String delimiter = "|";

        String[] result = data.split(String.format(WITH_DELIMITER_PATTERN, Pattern.quote(delimiter)));
        System.out.println("Formatted Split: " + Arrays.toString(result));
        // Output: Formatted Split: [item1, |, item2, |, item3]
    }
}

Solution 2: Using Pattern and Matcher for Custom Splitting

For more control and handling various splitting scenarios, you can utilize Java’s Pattern and Matcher classes. This approach allows you to iterate through the matches and extract both the text between delimiters and the delimiters themselves.

Example: A reusable Splitter class.

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.regex.PatternSyntaxException;

public class AdvancedSplitter {

    private final Pattern pattern;
    private final boolean keepDelimiters;

    public AdvancedSplitter(String regex, boolean keepDelimiters) {
        this.pattern = Pattern.compile(regex);
        this.keepDelimiters = keepDelimiters;
    }

    public String[] split(String text) {
        if (text == null) {
            text = "";
        }

        List<String> result = new ArrayList<>();
        Matcher matcher = pattern.matcher(text);
        int lastMatchEnd = 0;

        while (matcher.find()) {
            // Add the substring before the delimiter
            if (matcher.start() > lastMatchEnd) {
                result.add(text.substring(lastMatchEnd, matcher.start()));
            }

            // Add the delimiter itself if keepDelimiters is true
            if (keepDelimiters) {
                result.add(matcher.group());
            }

            lastMatchEnd = matcher.end();
        }

        // Add any remaining text after the last delimiter
        if (lastMatchEnd < text.length()) {
            result.add(text.substring(lastMatchEnd));
        } else if (lastMatchEnd == text.length() && !text.isEmpty() && pattern.matcher(text).find()) {
            // Handle cases where the string ends with a delimiter and keepDelimiters is true
            // This ensures an empty string is not added if the last match ends the string
            // unless the intent is to explicitly show an empty segment after the delimiter.
            // For simplicity, we often omit an extra empty string if the delimiter was the very last character.
        }


        return result.toArray(new String[0]);
    }

    public static void main(String[] args) {
        AdvancedSplitter splitter = new AdvancedSplitter("[,:]", true); // Split by comma or colon, keep delimiters
        String testString = "apple,banana:cherry:date";
        String[] tokens = splitter.split(testString);
        System.out.println("Split result: " + Arrays.toString(tokens));
        // Output: Split result: [apple, ,, banana, :, cherry, :, date]

        AdvancedSplitter splitterNoDelimiters = new AdvancedSplitter("[+-]", false); // Split by + or -, discard delimiters
        String mathExpression = "10+5-2*8";
        String[] mathTokens = splitterNoDelimiters.split(mathExpression);
        System.out.println("Math split (no delimiters): " + Arrays.toString(mathTokens));
        // Output: Math split (no delimiters): [10, 5, 2*8]

        // Example showing splitting at word boundaries
        AdvancedSplitter wordBoundarySplitter = new AdvancedSplitter("\\b", true);
        String camelCaseString = "CamelCaseExample";
        String[] words = wordBoundarySplitter.split(camelCaseString);
        System.out.println("Camel case split: " + Arrays.toString(words));
        // Output: Camel case split: [Camel, Case, Example] (Note: \b matches positions, not characters, so it results in empty strings around words)
        // A better pattern for word boundaries might be needed depending on exact requirements.
        // For retaining delimiters like hyphens or colons, Solution 1 is often more direct.

        // Example demonstrating Java 8 String.split with limit for controlling trailing empty strings
        String trailingEmpties = "a,b,,c,";
        System.out.println("Standard split (trailing empties): " + Arrays.toString(trailingEmpties.split(",", -1))); // -1 keeps trailing empty strings
        // Output: Standard split (trailing empties): [a, b, , c, ]
    }
}

Solution 3: Using StringTokenizer (Obsolete but Illustrative)

While StringTokenizer is generally considered obsolete in favor of String.split() and regex, it does have a constructor that allows returning delimiters: new StringTokenizer(str, delimiters, true). This can be useful for understanding legacy code or simple cases.

import java.util.StringTokenizer;
import java.util.Arrays;

public class StringTokenizerExample {
    public static void main(String[] args) {
        String data = "hello,world!how:are you";
        String delimiters = ",!:";
        StringTokenizer tokenizer = new StringTokenizer(data, delimiters, true);

        StringBuilder resultBuilder = new StringBuilder();
        while (tokenizer.hasMoreTokens()) {
            String token = tokenizer.nextToken();
            resultBuilder.append("[").append(token).append("]");
        }
        System.out.println("StringTokenizer result: " + resultBuilder.toString());
        // Output: StringTokenizer result: [hello][,][world][!][how][:][are you]
    }
}

This approach is less flexible than regex for defining delimiters.

Solution 4: Custom String Replacement and Split

A simple, albeit potentially fragile, approach is to replace the delimiter with a unique sequence that includes the delimiter itself, and then split by this new sequence. This works best if you can guarantee a character or sequence that will never appear in your original string.

public class ReplaceAndSplit {
    public static void main(String[] args) {
        String data = "one-two-three";
        String delimiter = "-";
        String uniqueMarker = "@@@"; // A sequence unlikely to be in the original string

        // Replace delimiter with a marker followed by the delimiter
        String processedString = data.replace(delimiter, uniqueMarker + delimiter);

        // Split by the marker
        String[] result = processedString.split(uniqueMarker);

        System.out.println("Replace and Split result: " + Arrays.toString(result));
        // Output: Replace and Split result: [one-, two-, three]
    }
}

This method is not robust if the uniqueMarker exists in the input data.

Solution 5: Custom Splitting Logic with Pattern and Matcher (More Control)

Building upon Solution 2, we can create more specialized splitters. This example focuses on retaining segments including their delimiters, similar to how String.split() works but keeping the matched delimiter.

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class SplitWithMatcherGroup {

    public static String[] splitAndKeepDelimiters(CharSequence input, String regex) {
        return splitAndKeepDelimiters(input, Pattern.compile(regex));
    }

    public static String[] splitAndKeepDelimiters(CharSequence input, Pattern pattern) {
        if (input == null) {
            return new String[0];
        }
        Matcher matcher = pattern.matcher(input);
        int start = 0;
        List<String> result = new ArrayList<>();

        while (matcher.find()) {
            // Add the segment before the match
            if (matcher.start() > start) {
                result.add(input.subSequence(start, matcher.start()).toString());
            }
            // Add the matched delimiter
            result.add(matcher.group());
            start = matcher.end();
        }

        // Add the remaining part of the string if any
        if (start < input.length()) {
            result.add(input.subSequence(start, input.length()).toString());
        } else if (start == input.length() && !input.isEmpty() && pattern.matcher(input).find()) {
             // Handle case where the string ends exactly with a delimiter.
             // If the last character was a delimiter and we captured it, we don't need an extra empty string.
        }

        return result.toArray(new String[0]);
    }

    public static void main(String[] args) {
        String text = "item1,item2:item3";
        String patternRegex = "[,:]"; // Split by comma or colon

        String[] splitResult = splitAndKeepDelimiters(text, patternRegex);
        System.out.println("Split with delimiters: " + Arrays.toString(splitResult));
        // Output: Split with delimiters: [item1, ,, item2, :, item3]

        String textWithConsecutive = "a;;b";
        String patternRegexConsecutive = ";";
        String[] splitConsecutive = splitAndKeepDelimiters(textWithConsecutive, patternRegexConsecutive);
        System.out.println("Split with consecutive delimiters: " + Arrays.toString(splitConsecutive));
        // Output: Split with consecutive delimiters: [a, ;, ;, b]
    }
}

Solution 6: Java 21 String.splitWithDelimiters()

Java 21 introduces a highly convenient String.splitWithDelimiters(String regex, int limit) method. This directly addresses the need to split a string and retain the delimiters.

import java.util.Arrays;

public class Java21SplitWithDelimiters {
    public static void main(String[] args) {
        String htmlString = "<p>Hello</p><div>World</div>";
        // Regex to capture HTML tags
        String tagRegex = "<[^>]+>";

        String[] parts = htmlString.splitWithDelimiters(tagRegex, 0); // 0 means no limit on the number of splits

        System.out.println("Java 21 splitWithDelimiters result:");
        Arrays.stream(parts).forEach(System.out::println);
        /*
        Output:
        <p>
        Hello
        </p>
        <div>
        World
        </div>
        */
    }
}

This is the most direct and recommended approach if you are using Java 21 or later.

Solution 7: Groovy Implementation Example

For those working with Groovy, a concise implementation can be achieved using its regex capabilities and list manipulation.

def splitWithTokens(String str, Pattern pat) {
    def tokens = []
    def matcher = pat.matcher(str)
    int lastMatchEnd = 0

    while (matcher.find()) {
        // Add text before the match
        if (matcher.start() > lastMatchEnd) {
            tokens << str.substring(lastMatchEnd, matcher.start())
        }
        // Add the matched delimiter
        tokens << matcher.group()
        lastMatchEnd = matcher.end()
    }
    // Add any remaining text after the last match
    if (lastMatchEnd < str.length()) {
        tokens << str.substring(lastMatchEnd)
    }
    tokens
}

// Example usage:
def htmlString = "<p>Hello</p><div>World</div>"
def htmlTagPattern = Pattern.compile("<[^>]+>")
def splitResult = splitWithTokens(htmlString, htmlTagPattern)
println "Groovy split result: ${splitResult}"
// Output: Groovy split result: [<p>, Hello, </p>, <div>, World, </div>]

FAQs on Java Split String Including Delimiters

Q: What is the standard behavior of String.split() in Java?

ANS: The standard String.split() method in Java splits a string around matches of the given regular expression. However, it discards the delimiters themselves from the resulting array. For example, "a,b,c".split(",") yields ["a", "b", "c"], not ["a", ",", "b", ",", "c"].

Q: How can I split a string and keep the delimiters using Java?

ANS: You can achieve this using Java’s regular expression capabilities, specifically lookarounds like (?<=DELIMITER) and (?=DELIMITER). Alternatively, you can use the Pattern and Matcher classes for more control, or leverage the new String.splitWithDelimiters() method in Java 21.

Q: What are lookarounds in regular expressions?

ANS: Lookarounds are zero-width assertions that match a position in the string without consuming characters. Positive lookbehind (?<=...) asserts that the current position is preceded by a specific pattern, while positive lookahead (?=...) asserts that the current position is followed by a specific pattern. They are useful for splitting strings while keeping the delimiters.

Q: Is there a built-in Java method to split strings and retain delimiters?

ANS: Yes, starting from Java 21, the String class includes the splitWithDelimiters(String regex, int limit) method, which is designed precisely for this purpose. If you are using an older Java version, you will need to use regular expressions with lookarounds or custom Pattern/Matcher logic.

Q: Can I use StringTokenizer to keep delimiters?

ANS: While StringTokenizer is generally discouraged in favor of regex-based methods, it does offer a constructor new StringTokenizer(str, delimiters, true) that allows you to return delimiters as separate tokens. However, it’s less flexible than regex for defining delimiters.
