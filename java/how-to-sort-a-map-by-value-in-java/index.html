“How to Sort a Map by Value in Java”

Sorting a Map by its values is a common programming task, especially when you need to process or display data in a specific order. While Map interfaces themselves do not guarantee an order, you can achieve sorted order by converting the Map’s entries into a List and then sorting that List using various techniques. This guide explores several effective methods to sort a Java Map by its values.

Solutions

Solution 1: Using a LinkedHashMap and Entry.comparingByValue()

This approach leverages Java 8 streams and LinkedHashMap to maintain the insertion order after sorting.

import java.util.*;
import java.util.stream.Collectors;

public class MapValueSorter {

    public static <K, V extends Comparable<? super V>> Map<K, V> sortByValueAscending(Map<K, V> map) {
        return map.entrySet()
                  .stream()
                  .sorted(Map.Entry.comparingByValue())
                  .collect(Collectors.toMap(
                      Map.Entry::getKey,
                      Map.Entry::getValue,
                      (e1, e2) -> e1, // Merge function for duplicate keys, though usually keys are unique
                      LinkedHashMap::new // Preserves the sorted order
                  ));
    }

    public static <K, V extends Comparable<? super V>> Map<K, V> sortByValueDescending(Map<K, V> map) {
        return map.entrySet()
                  .stream()
                  .sorted(Map.Entry.comparingByValue(Comparator.reverseOrder()))
                  .collect(Collectors.toMap(
                      Map.Entry::getKey,
                      Map.Entry::getValue,
                      (e1, e2) -> e1,
                      LinkedHashMap::new
                  ));
    }

    public static void main(String[] args) {
        Map<String, Integer> unsortedMap = new HashMap<>();
        unsortedMap.put("Apple", 5);
        unsortedMap.put("Banana", 2);
        unsortedMap.put("Orange", 8);
        unsortedMap.put("Grape", 2); // Duplicate value

        System.out.println("Unsorted Map: " + unsortedMap);

        Map<String, Integer> sortedAsc = sortByValueAscending(unsortedMap);
        System.out.println("Sorted Map (Ascending): " + sortedAsc);

        Map<String, Integer> sortedDesc = sortByValueDescending(unsortedMap);
        System.out.println("Sorted Map (Descending): " + sortedDesc);
    }
}

This method is concise and makes good use of modern Java features. The LinkedHashMap ensures that the order established by the sorting is preserved.

Solution 2: Using a Custom Comparator with TreeMap

This classic approach involves creating a custom Comparator to define how map entries should be ordered based on their values. You then use this Comparator when instantiating a TreeMap.

import java.util.*;

public class TreeMapValueSort {

    // Comparator to sort Map entries by value (ascending)
    private static class ValueComparatorAsc<K, V extends Comparable<? super V>> implements Comparator<Map.Entry<K, V>> {
        @Override
        public int compare(Map.Entry<K, V> e1, Map.Entry<K, V> e2) {
            return e1.getValue().compareTo(e2.getValue());
        }
    }

    // Comparator to sort Map entries by value (descending)
    private static class ValueComparatorDesc<K, V extends Comparable<? super V>> implements Comparator<Map.Entry<K, V>> {
        @Override
        public int compare(Map.Entry<K, V> e1, Map.Entry<K, V> e2) {
            return e2.getValue().compareTo(e1.getValue()); // Reversed for descending
        }
    }

    // Helper method to sort a Map and return a LinkedHashMap
    public static <K, V extends Comparable<? super V>> Map<K, V> sortMapByValue(Map<K, V> map, Comparator<Map.Entry<K, V>> comparator) {
        List<Map.Entry<K, V>> list = new LinkedList<>(map.entrySet());
        Collections.sort(list, comparator);

        Map<K, V> result = new LinkedHashMap<>();
        for (Map.Entry<K, V> entry : list) {
            result.put(entry.getKey(), entry.getValue());
        }
        return result;
    }

    public static void main(String[] args) {
        Map<String, Integer> unsortedMap = new HashMap<>();
        unsortedMap.put("Beta", 7);
        unsortedMap.put("Alpha", 3);
        unsortedMap.put("Gamma", 10);
        unsortedMap.put("Delta", 3); // Duplicate value

        System.out.println("Unsorted Map: " + unsortedMap);

        Map<String, Integer> sortedAsc = sortMapByValue(unsortedMap, new ValueComparatorAsc<>());
        System.out.println("Sorted Map (Ascending): " + sortedAsc);

        Map<String, Integer> sortedDesc = sortMapByValue(unsortedMap, new ValueComparatorDesc<>());
        System.out.println("Sorted Map (Descending): " + sortedDesc);
    }
}

This method is more verbose but offers fine-grained control over the sorting logic. It’s crucial to use a LinkedHashMap for the result if you need to preserve the sorted order, as TreeMap sorts by keys by default if no custom Comparator for keys is provided.

Solution 3: Utilizing ArrayList and Collections.sort()

This is a very common and straightforward way to sort map entries. You extract the entries into an ArrayList and then use Collections.sort() with a custom Comparator.

import java.util.*;

public class ListSortMapByValue {

    public static <K, V extends Comparable<? super V>> Map<K, V> sortByValue(Map<K, V> map, boolean ascending) {
        List<Map.Entry<K, V>> entries = new ArrayList<>(map.entrySet());

        if (ascending) {
            // Sort in ascending order of values
            Collections.sort(entries, Comparator.comparing(Map.Entry::getValue));
        } else {
            // Sort in descending order of values
            Collections.sort(entries, Comparator.comparing(Map.Entry::getValue, Comparator.reverseOrder()));
        }

        // Reconstruct the map in the sorted order
        Map<K, V> sortedMap = new LinkedHashMap<>();
        for (Map.Entry<K, V> entry : entries) {
            sortedMap.put(entry.getKey(), entry.getValue());
        }
        return sortedMap;
    }

    public static void main(String[] args) {
        Map<String, Double> dataMap = new HashMap<>();
        dataMap.put("One", 1.1);
        dataMap.put("Two", 0.5);
        dataMap.put("Three", 2.3);
        dataMap.put("Four", 0.5); // Duplicate value

        System.out.println("Original Map: " + dataMap);

        Map<String, Double> sortedAsc = sortByValue(dataMap, true);
        System.out.println("Ascending Sort: " + sortedAsc);

        Map<String, Double> sortedDesc = sortByValue(dataMap, false);
        System.out.println("Descending Sort: " + sortedDesc);
    }
}

This method is highly flexible as Collections.sort can handle various Comparator implementations. LinkedHashMap is used here again to maintain the order.

Solution 4: Using Guava’s Ordering API

For projects that already use Google’s Guava library, the Ordering API offers a fluent and powerful way to define comparators.

import com.google.common.base.Function;
import com.google.common.base.Functions;
import com.google.common.collect.ImmutableSortedMap;
import com.google.common.collect.Ordering;

import java.util.Comparator;
import java.util.HashMap;
import java.util.Map;

public class GuavaMapSort {

    public static <K, V extends Comparable<? super V>> Map<K, V> sortByValueGuavaAsc(Map<K, V> map) {
        // Create an ordering based on the map's values
        Ordering<Map.Entry<K, V>> valueOrdering = Ordering.natural().onResultOf(Map.Entry.getValue());

        // Create a sorted map using the value ordering
        // ImmutableSortedMap.copyOf needs a map, and then a comparator that works on its entries
        // We need to transform the original map into an ImmutableSortedMap where the sorting is applied
        // Note: This typically creates a new map structure, not modifying the original in-place.
        // For a LinkedHashMap-like behavior, you'd convert the entries back.

        // To get a LinkedHashMap equivalent:
        return ImmutableSortedMap.copyOf(map, valueOrdering).entrySet().stream()
                .collect(java.util.stream.Collectors.toMap(
                        Map.Entry::getKey, Map.Entry::getValue, (e1, e2) -> e1, LinkedHashMap::new
                ));
    }

     public static <K, V extends Comparable<? super V>> Map<K, V> sortByValueGuavaDesc(Map<K, V> map) {
        Ordering<Map.Entry<K, V>> valueOrdering = Ordering.natural().onResultOf(Map.Entry.getValue()).reversed();
        return ImmutableSortedMap.copyOf(map, valueOrdering).entrySet().stream()
                .collect(java.util.stream.Collectors.toMap(
                        Map.Entry::getKey, Map.Entry::getValue, (e1, e2) -> e1, LinkedHashMap::new
                ));
    }


    public static void main(String[] args) {
        Map<String, Integer> sampleMap = new HashMap<>();
        sampleMap.put("Zebra", 15);
        sampleMap.put("Yak", 5);
        sampleMap.put("Xenops", 25);
        sampleMap.put("Wombat", 5); // Duplicate value

        System.out.println("Original Map: " + sampleMap);

        Map<String, Integer> sortedAsc = sortByValueGuavaAsc(sampleMap);
        System.out.println("Guava Ascending Sort: " + sortedAsc);

        Map<String, Integer> sortedDesc = sortByValueGuavaDesc(sampleMap);
        System.out.println("Guava Descending Sort: " + sortedDesc);
    }
}

import static org.junit.Assert.assertEquals;

import java.util.HashMap;
import java.util.Map;
import java.util.TreeMap;

import com.google.common.base.Functions;
import com.google.common.collect.Ordering;

class ValueComparableMap&lt;K extends Comparable&lt;K&gt;,V&gt; extends TreeMap&lt;K,V&gt; {
    //A map for doing lookups on the keys for comparison so we don't get infinite loops
    private final Map&lt;K, V&gt; valueMap;

    ValueComparableMap(final Ordering&lt;? super V&gt; partialValueOrdering) {
        this(partialValueOrdering, new HashMap&lt;K,V&gt;());
    }

    private ValueComparableMap(Ordering&lt;? super V&gt; partialValueOrdering,
            HashMap&lt;K, V&gt; valueMap) {
        super(partialValueOrdering //Apply the value ordering
                .onResultOf(Functions.forMap(valueMap)) //On the result of getting the value for the key from the map
                .compound(Ordering.natural())); //as well as ensuring that the keys don't get clobbered
        this.valueMap = valueMap;
    }

    public V put(K k, V v) {
        if (valueMap.containsKey(k)){
            //remove the key in the sorted set before adding the key again
            remove(k);
        }
        valueMap.put(k,v); //To get "real" unsorted values for the comparator
        return super.put(k, v); //Put it in value order
    }

    public static void main(String[] args){
        TreeMap&lt;String, Integer&gt; map = new ValueComparableMap&lt;String, Integer&gt;(Ordering.natural());
        map.put("a", 5);
        map.put("b", 1);
        map.put("c", 3);
        assertEquals("b",map.firstKey());
        assertEquals("a",map.lastKey());
        map.put("d",0);
        assertEquals("d",map.firstKey());
        //ensure it's still a map (by overwriting a key, but with a new value) 
        map.put("d", 2);
        assertEquals("b", map.firstKey());
        //Ensure multiple values do not clobber keys
        map.put("e", 2);
        assertEquals(5, map.size());
        assertEquals(2, (int) map.get("e"));
        assertEquals(2, (int) map.get("d"));
    }

FAQs on How to Sort a Map by Value in Java

Q: What is the most efficient way to sort a Map by value in Java?

ANS: The most efficient approach depends on the Java version and specific requirements. For Java 8+, using Streams API (map.entrySet().stream().sorted(...).collect(...)) is often the most concise and readable. If performance is absolutely critical for very large maps, consider the memory overhead of creating intermediate lists or arrays. Some custom Comparator implementations with TreeMap or LinkedHashMap can also be highly performant.

Q: Can I sort a Map in-place by value?

ANS: No, the standard Map interfaces in Java do not support in-place sorting by value because the contract of a Map doesn’t guarantee any order. You must create a new Map (like LinkedHashMap) or a sorted List of map entries that reflects the desired order.

Q: How do I handle maps with duplicate values when sorting?

ANS: When values are duplicated, the sorting order of entries with the same value is not guaranteed by default unless you add a secondary sorting criterion (e.g., by key). Java 8’s comparingByValue() can be combined with thenComparing() for this purpose, or you can implement it manually in your custom Comparator.

Q: What is the difference between sorting by value and using a TreeMap?

ANS: TreeMap naturally sorts entries based on their keys according to the natural ordering of keys or a provided Comparator for keys. Sorting by value requires extracting entries, sorting them based on values, and then reconstructing a Map (like LinkedHashMap) that preserves this sorted order.
private static &lt;K, V&gt; Map&lt;K, V&gt; sortByValue(Map&lt;K, V&gt; map) {
    List&lt;Entry&lt;K, V&gt;&gt; list = new LinkedList&lt;&gt;(map.entrySet());
    Collections.sort(list, new Comparator&lt;Object&gt;() {
        @SuppressWarnings("unchecked")
        public int compare(Object o1, Object o2) {
            return ((Comparable&lt;V&gt;) ((Map.Entry&lt;K, V&gt;) (o1)).getValue()).compareTo(((Map.Entry&lt;K, V&gt;) (o2)).getValue());
        }
    });

    Map&lt;K, V&gt; result = new LinkedHashMap&lt;&gt;();
    for (Iterator&lt;Entry&lt;K, V&gt;&gt; it = list.iterator(); it.hasNext();) {
        Map.Entry&lt;K, V&gt; entry = (Map.Entry&lt;K, V&gt;) it.next();
        result.put(entry.getKey(), entry.getValue());
    }

    return result;
}
