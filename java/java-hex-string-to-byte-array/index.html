How can I convert a hexadecimal string to a byte array in Java?

Converting a hexadecimal string into its corresponding byte array representation is a common task in Java development. This process is essential when dealing with binary data represented as text, such as network protocols, cryptography, or data serialization. Fortunately, Java offers several approaches to achieve this, ranging from built-in library functions to custom implementations. Let’s delve into various methods that can facilitate this conversion, highlighting their strengths and considerations.

Solution 1: Using JDK 17’s HexFormat

Starting with Java 17, the java.util.HexFormat class provides a modern and efficient way to handle hexadecimal conversions.

import java.util.HexFormat;

public class HexConverter {
    public static void main(String[] args) {
        String hexString = "00A0BF";
        byte[] byteArray = HexFormat.of().parseHex(hexString);
        // byteArray will contain {0, -96, -65}
        System.out.println(java.util.Arrays.toString(byteArray));
    }
}

Solution 2: Leveraging javax.xml.bind.DatatypeConverter (Pre-JDK 17)

For Java versions prior to JDK 17, javax.xml.bind.DatatypeConverter offers a convenient way to perform hex to byte conversions.

import javax.xml.bind.DatatypeConverter;

public class HexConverter {
    public static String bytesToHexString(byte[] array) {
        return DatatypeConverter.printHexBinary(array);
    }

    public static byte[] hexStringToByteArray(String s) {
        return DatatypeConverter.parseHexBinary(s);
    }

    public static void main(String[] args) {
        byte[] data = {0x00, (byte) 0xA0, (byte) 0xBF};
        String hex = bytesToHexString(data);
        System.out.println("Bytes to Hex: " + hex); // Output: Bytes to Hex: 00A0BF

        byte[] decodedBytes = hexStringToByteArray(hex);
        System.out.println("Hex to Bytes: " + java.util.Arrays.toString(decodedBytes)); // Output: Hex to Bytes: [0, -96, -65]
    }
}

Important Note: In Java 9 and later, if you’re using the Jigsaw module system, javax.xml.bind is no longer part of the default java.se module. You might need to explicitly add --add-modules java.se.ee to your JVM arguments or ensure the jaxb-api dependency is included. This solution is also not available on Android by default.

Solution 3: Utilizing Apache Commons Codec

The Apache Commons Codec library provides robust utilities for various encoding and decoding tasks, including hexadecimal conversion.

import org.apache.commons.codec.binary.Hex;

public class HexConverter {
    public static void main(String[] args) {
        String hexString = "00A0BF";
        try {
            byte[] decodedBytes = Hex.decodeHex(hexString.toCharArray());
            System.out.println(java.util.Arrays.toString(decodedBytes)); // Output: [0, -96, -65]
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

You’ll need to add the Apache Commons Codec dependency to your project.

Solution 4: Employing Google Guava’s BaseEncoding

Google’s Guava library offers efficient and versatile encoding utilities, including base16 (hexadecimal) encoding and decoding.

import com.google.common.io.BaseEncoding;

public class HexConverter {
    public static void main(String[] args) {
        String hexString = "00A0BF";
        byte[] decodedBytes = BaseEncoding.base16().decode(hexString);
        System.out.println(java.util.Arrays.toString(decodedBytes)); // Output: [0, -96, -65]

        byte[] bytesToEncode = {-64, 0, 6, 0, 0}; // Example bytes
        String encodedString = BaseEncoding.base16().encode(bytesToEncode);
        System.out.println("Bytes to Hex: " + encodedString); // Output: Bytes to Hex: C000060000
    }
}

Ensure you have the Guava library added to your project dependencies.

Solution 5: Custom Implementation using Character.digit

For scenarios where external libraries are not preferred, or for a deeper understanding, you can implement the conversion logic manually. This approach leverages Character.digit for converting hex characters to their integer values.

public class HexConverter {
    public static byte[] hexStringToByteArray(String s) {
        int len = s.length();
        if (len % 2 != 0) {
            throw new IllegalArgumentException("Hex string must have an even length.");
        }
        byte[] data = new byte[len / 2];
        for (int i = 0; i < len; i += 2) {
            int highNibble = Character.digit(s.charAt(i), 16);
            int lowNibble = Character.digit(s.charAt(i + 1), 16);
            if (highNibble == -1 || lowNibble == -1) {
                throw new IllegalArgumentException("Invalid hex character in input string.");
            }
            data[i / 2] = (byte) ((highNibble << 4) + lowNibble);
        }
        return data;
    }

    public static void main(String[] args) {
        String hexString = "00A0BF";
        byte[] byteArray = hexStringToByteArray(hexString);
        System.out.println(java.util.Arrays.toString(byteArray)); // Output: [0, -96, -65]
    }
}

This custom method is efficient as it avoids intermediate object creations for each byte.

Solution 6: Alternative Custom Implementation using Integer.parseInt

Another common custom implementation involves using Integer.parseInt with a radix of 16.

public class HexConverter {
    public static byte[] hexStringToByteArray(String s) {
        if (s.length() % 2 != 0) {
            throw new IllegalArgumentException("Hex string must have an even length.");
        }
        byte[] data = new byte[s.length() / 2];
        for (int i = 0, j = 0; i < s.length(); i += 2, j++) {
            data[j] = (byte) Integer.parseInt(s.substring(i, i + 2), 16);
        }
        return data;
    }

    public static void main(String[] args) {
        String hexString = "00A0BF";
        byte[] byteArray = hexStringToByteArray(hexString);
        System.out.println(java.util.Arrays.toString(byteArray)); // Output: [0, -96, -65]
    }
}

Solution 7: Handling Odd Length Hex Strings

In some cases, you might encounter hex strings with an odd number of characters, perhaps representing a single leading nibble. The following method accounts for this by padding the first byte.

public class HexConverter {
    public static byte[] hexStringToByteArrayWithOddSupport(String input) {
        int len = input.length();
        if (len == 0) {
            return new byte[]{};
        }

        byte[] data;
        int startIdx;
        if (len % 2 != 0) {
            data = new byte[(len / 2) + 1];
            data[0] = (byte) Character.digit(input.charAt(0), 16);
            startIdx = 1;
        } else {
            data = new byte[len / 2];
            startIdx = 0;
        }

        for (int i = startIdx; i < len; i += 2) {
            data[(i + 1) / 2] = (byte) ((Character.digit(input.charAt(i), 16) << 4)
                    + Character.digit(input.charAt(i + 1), 16));
        }
        return data;
    }

    public static void main(String[] args) {
        String oddHexString = "A0BF"; // Even length example
        byte[] byteArrayEven = hexStringToByteArrayWithOddSupport(oddHexString);
        System.out.println("Even length: " + java.util.Arrays.toString(byteArrayEven)); // Output: Even length: [-96, -65]

        String oddHexString2 = "1A0BF"; // Odd length example
        byte[] byteArrayOdd = hexStringToByteArrayWithOddSupport(oddHexString2);
        System.out.println("Odd length: " + java.util.Arrays.toString(byteArrayOdd)); // Output: Odd length: [1, -96, -65]
    }
}

Solution 8: Converting Hex String to ByteString (Okio Library for Android)

If you are working within the Android ecosystem or using the Okio library, ByteString.decodeHex() offers a concise solution.

import okio.ByteString;

public class HexConverter {
    public static void main(String[] args) {
        String hexString = "C000060000"; // Example from okio
        byte[] bytes = ByteString.decodeHex(hexString).toByteArray();
        System.out.println(java.util.Arrays.toString(bytes)); // Output: [-64, 0, 6, 0, 0]
    }
}

This is particularly useful for Android development where direct Java SE libraries might not be available or optimal.

Considerations for Signed Bytes

It’s important to remember that Java’s byte type is signed, ranging from -128 to 127. When converting hexadecimal values that represent numbers greater than 127 (e.g., FF which is 255 in unsigned representation), they will be interpreted as negative numbers in Java. For instance, FF becomes -1. If you need to work with unsigned byte values, you’ll need to perform appropriate conversions (e.g., byteValue & 0xFF).

FAQs on Java Hex String to Byte Array Conversion

Q: What is the most efficient way to convert a hex string to a byte array in modern Java

ANS: For Java 17 and later, java.util.HexFormat.of().parseHex(hexString) is generally considered the most efficient and modern approach due to its optimized implementation.

Q: How do I handle hexadecimal strings with odd lengths

ANS: You can either throw an IllegalArgumentException or implement logic to prepend a ‘0’ to the string before conversion to ensure an even length, or design your parsing logic to handle the leading nibble separately as shown in Solution 7.

Q: Why do my byte values appear negative when converting hex like FF

ANS: Java’s byte type is signed. The hexadecimal value FF (255 unsigned) is represented as -1 in Java’s signed byte system. You can use byteValue & 0xFF to get the unsigned integer representation.

Q: Is javax xml bind DatatypeConverter still recommended

ANS: While it works, it’s deprecated and not available by default in newer Java versions (9+). HexFormat (Java 17+) or custom solutions are preferred.

Q: Can I convert a byte array back to a hex string

ANS: Yes, most methods that convert hex to bytes also provide the reverse operation. For example, HexFormat.of().formatHex(byteArray) or DatatypeConverter.printHexBinary(byteArray).
