“Convert Google Sheets to Markdown Tables: A Practical Approach”

This question addresses the need to automate the process of taking data from a spreadsheet environment like Google Sheets and transforming it into a Markdown table, a common format for documentation, wikis, and online content. The provided solutions offer scripting methods to achieve this, including features for selectively masking or “redacting” data and controlling the alignment of table columns.

Transforming Spreadsheet Data into Markdown Tables

The core challenge involves extracting data from a Google Sheet, applying transformations (like redaction), and then formatting it according to Markdown table syntax. Markdown tables use pipes (|) and hyphens (-) to define structure and alignment.

Solution 1: Google Apps Script for Redactable and Aligned Markdown Tables

This approach utilizes Google Apps Script to create a custom menu within Google Sheets. This menu provides options to generate Markdown tables directly from selected data.

Key Features:

  • Data Selection: Allows users to select a range of data within their active Google Sheet.
  • Redaction: Enables users to specify certain ranges within the selected data to be replaced with a predefined “redacted” string.
  • Independent Column Alignment: Supports setting alignment for each column individually using a string of ’l’ (left), ‘c’ (center), or ‘r’ (right), or applying a default alignment.
  • Header Inclusion: Can optionally include headers in the generated Markdown table.
  • Row Numbering: Supports adding row numbers for better data orientation.

/**
 * Retrieves the A1 notation and column count of the currently active range.
 * @returns {object} An object containing the data range and number of columns.

function getCSVDataRange() {
  const ss = SpreadsheetApp.getActive();
  const sh = ss.getActiveSheet();
  const rg = sh.getActiveRange();
  const cols = rg.getWidth();
  const datarange = rg.getA1Notation();
  return { datarange: datarange, columns: cols };
}

/**
 * Retrieves the A1 notations of all selected ranges.
 * @returns {object} An object containing a comma-separated string of redact ranges.
 */
function getRedactRangeList() {
  const ss = SpreadsheetApp.getActive();
  const sh = ss.getActiveSheet();
  const rgA = sh.getActiveRangeList().getRanges();
  const redactrange = rgA.map(function (rg, i) { return rg.getA1Notation(); }).join(',');
  return { redactrange: redactrange };
}
