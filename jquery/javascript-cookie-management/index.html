“JavaScript Cookie Management: Set, Get, and Delete”

Browser cookies are essential for maintaining state and user preferences in web applications. JavaScript provides several ways to interact with these cookies, from simple creation and retrieval to more advanced management. This post delves into various methods for handling cookies using pure JavaScript and popular libraries.

Solution 1: Utilizing js-cookie Library (Recommended for Modern Development)

For modern web development, the js-cookie library offers a clean, dependency-free approach to cookie manipulation. It’s a robust alternative to older jQuery-dependent methods.

Setting a Cookie:

// Set a cookie named 'userPreference' with value 'darkTheme'
Cookies.set('userPreference', 'darkTheme');

// Set a cookie with an expiration of 7 days
Cookies.set('sessionToken', 'abc123xyz', { expires: 7 });

Reading a Cookie:

// Retrieve the value of the 'userPreference' cookie
const preference = Cookies.get('userPreference'); // 'darkTheme'

// Attempt to retrieve a non-existent cookie
const nonExistent = Cookies.get('nonExistentCookie'); // undefined

Deleting a Cookie:

// Remove the 'sessionToken' cookie
Cookies.remove('sessionToken');

You can find more details and advanced usage on the js-cookie GitHub repository .

Solution 2: Pure JavaScript Cookie Manipulation (QuirksMode)

This approach uses native JavaScript functions to manage cookies without external libraries. It’s particularly useful for understanding the underlying mechanisms.

Creating a Cookie:

function createCookie(name, value, days) {
    let expires = "";
    if (days) {
        const date = new Date();
        date.setTime(date.getTime() + (days * 24 * 60 * 60 * 1000));
        expires = "; expires=" + date.toUTCString();
    }
    document.cookie = encodeURIComponent(name) + "=" + encodeURIComponent(value) + expires + "; path=/";
}

Reading a Cookie:

function readCookie(name) {
    const nameEQ = encodeURIComponent(name) + "=";
    const ca = document.cookie.split(';');
    for (let i = 0; i < ca.length; i++) {
        let c = ca[i];
        while (c.charAt(0) === ' ') c = c.substring(1, c.length);
        if (c.indexOf(nameEQ) === 0) {
            return decodeURIComponent(c.substring(nameEQ.length, c.length));
        }
    }
    return null;
}

Deleting a Cookie:

function eraseCookie(name) {
    createCookie(name, "", -1);
}

For more on cookie handling, refer to the QuirksMode archive .

Solution 3: Enhanced Pure JavaScript Cookie Functions

This set of functions provides a clean way to set, get, and erase cookies, with proper encoding for special characters.

Setting a Cookie:

function setCookie(key, value, expiryDays) {
    const expires = new Date();
    expires.setTime(expires.getTime() + (expiryDays * 24 * 60 * 60 * 1000));
    document.cookie = encodeURIComponent(key) + '=' + encodeURIComponent(value) +
                      ';expires=' + expires.toUTCString() +
                      ';path=/'; // Ensures cookie is available site-wide
}

Retrieving a Cookie:

function getCookie(key) {
    const cookies = document.cookie.split('; ');
    for (let i = 0; i < cookies.length; i++) {
        const parts = cookies[i].split('=');
        if (decodeURIComponent(parts[0]) === key) {
            return decodeURIComponent(parts[1]);
        }
    }
    return null;
}

Deleting a Cookie:

function eraseCookie(key) {
    document.cookie = encodeURIComponent(key) + "=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/";
}

Example Usage:

setCookie('username', 'JaneDoe', 7); // Stores 'username=JaneDoe' for 7 days
console.log(getCookie('username'));  // Retrieves the cookie value
eraseCookie('username');             // Deletes the cookie

Solution 7: Vanilla JavaScript Cookie Management (W3Schools Style)

A straightforward implementation for setting and getting cookies, inspired by W3Schools.

Setting a Cookie:

function setCookie(cname, cvalue, exdays) {
    const d = new Date();
    d.setTime(d.getTime() + (exdays * 24 * 60 * 60 * 1000));
    const expires = "expires=" + d.toUTCString();
    document.cookie = cname + "=" + cvalue + ";" + expires + ";path=/";
}

Retrieving a Cookie:

function getCookie(cname) {
    const name = cname + "=";
    const decodedCookie = decodeURIComponent(document.cookie);
    const ca = decodedCookie.split(';');
    for (let i = 0; i < ca.length; i++) {
        let c = ca[i];
        while (c.charAt(0) === ' ') {
            c = c.substring(1);
        }
        if (c.indexOf(name) === 0) {
            return c.substring(name.length, c.length);
        }
    }
    return "";
}

Deleting a Cookie:

document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;";

Solution 11: Efficient Vanilla JavaScript Cookie Functions

This set of functions offers a concise way to set, get, and delete cookies.

function setCookie(name, value, expiry) {
    const d = new Date();
    d.setTime(d.getTime() + (expiry * 86400000)); // 86400000ms = 1 day
    document.cookie = name + "=" + value + ";" + "expires=" + d.toUTCString() + ";path=/";
}

function getCookie(name) {
    const cookie = document.cookie.match('(^|;) ?' + name + '=([^;]*)(;|$)');
    return cookie ? cookie[2] : null;
}

function eatCookie(name) { // 'eat' is a synonym for delete/erase
    setCookie(name, "", -1);
}

Solution 12: Comprehensive $.cookie Options

The jQuery plugin offers extensive options for cookie configuration.

Setting Cookies:

// Set a cookie with default session duration
$.cookie('the_cookie', 'the_value');

// Set an expiring cookie (7 days)
$.cookie('the_cookie', 'the_value', { expires: 7 });

// Set an expiring cookie, valid across the entire site
$.cookie('the_cookie', 'the_value', { expires: 7, path: '/' });

Reading Cookies:

$.cookie('the_cookie'); // Returns the cookie value
$.cookie('not_existing'); // Returns null

Deleting Cookies:

// Delete a cookie by setting its value to null
$.cookie('the_cookie', null);

Advanced Options:

$.cookie('myCookie2', 'myValue2', {
    expires: 7, path: '/', domain: 'example.com',
    secure: true, raw: true
});

Available Options:

  • expires: Sets the cookie’s lifetime (number of days or a Date object).
  • path: Specifies the cookie’s valid path.
  • domain: Sets the domain for the cookie.
  • secure: Transmits the cookie only over HTTPS if true.
  • raw: Disables automatic encoding/decoding if true.

Solution 14: Flexible Cookie Setting with Optional Expiration

This improved function allows setting cookies with or without an expiration date.

function setCookie(key, value, days) {
    const expires = new Date();
    if (days) {
        expires.setTime(expires.getTime() + (days * 24 * 60 * 60 * 1000));
        document.cookie = key + '=' + value + ';expires=' + expires.toUTCString();
    } else {
        // Set to expire far in the future if no days are specified
        document.cookie = key + '=' + value + ';expires=Fri, 30 Dec 9999 23:59:59 GMT;';
    }
}

function getCookie(key) {
    const keyValue = document.cookie.match('(^|;) ?' + key + '=([^;]*)(;|$)');
    return keyValue ? keyValue[2] : null;
}

Example Usage:

setCookie('myData', 'importantValue', 30); // Cookie lasts for 30 days
setCookie('persistentData', 'permanent');   // Cookie lasts indefinitely

Solution 17: Removing All Cookies Across Domains

This advanced vanilla JavaScript snippet removes cookies across the current domain and its subdomains.

// Removes all cookies for the current domain and subdomains
document.cookie.replace(/(?<=^|;).+?(?=\=|;|$)/g, name =>
    location.hostname.split('.').reverse().reduce(domain => (
        domain = domain.replace(/^\.?[^.]+/, ''),
        document.cookie = `${name}=;max-age=0;path=/;domain=${domain}`,
        domain
    ), location.hostname)
);

Solution 18: cookieMonster - A Global Cookie Handler

This object provides get, delete, and set methods for convenient cookie management.

window.cookieMonster = window.cookieMonster || {
    get: function (cookieName) {
        const match = document.cookie.match('(^|;)\\s*' + cookieName + '\\s*=\\s*([^;]+)');
        return match ? match.pop() : '';
    },

    delete: function (name) {
        document.cookie = '{0}=; Path=/; Expires=Thu, 01 Jan 1970 00:00:01 GMT;'
            .replace('{0}', name);
    },

    set: function (name, value) {
        document.cookie =
            '{0}={1};expires=Fri, 31 Dec 9999 23:59:59 GMT;path=/;SameSite=Lax'
            .replace('{0}', name)
            .replace('{1}', value);
    }
};

// Example Usage:
cookieMonster.set('chocolate', 'yes please');
cookieMonster.set('sugar', 'that too');

console.log(cookieMonster.get('chocolate')); // Output: yes please
console.log(document.cookie); // Output: chocolate=yes please; sugar=that too

cookieMonster.delete('chocolate');
console.log(cookieMonster.get('chocolate')); // Output: ''
console.log(document.cookie); // Output: sugar=that too

Q How do I set a cookie using JavaScript

ANS You can set a cookie using document.cookie or a library like js-cookie. A common pure JavaScript approach involves creating a function like setCookie(name, value, days) which formats the cookie string with its name, value, and expiration. For instance: function setCookie(key, value, expiryDays) { ... document.cookie = encodeURIComponent(key) + '=' + encodeURIComponent(value) + ';expires=' + expires.toUTCString() + ';path=/'; }.

Q What is the best way to read a cookie in JavaScript

ANS The js-cookie library provides a simple Cookies.get('cookieName'). In pure JavaScript, you can split document.cookie by semicolons and then find the cookie by its name. A utility function like getCookie(name) that iterates through the split cookie string and returns the matching value is effective.

Q How can I delete a cookie with JavaScript

ANS To delete a cookie, you typically set its expiration date to a time in the past. This can be done by setting the cookie’s value to an empty string and providing an expiration date like Thu, 01 Jan 1970 00:00:00 UTC. A function like eraseCookie(name) or Cookie.Erase(name) handles this.

Q Is it necessary to use a library for cookie management

ANS While pure JavaScript can manage cookies, libraries like js-cookie simplify the process, handle edge cases, and provide a more consistent API, especially for complex scenarios like setting various cookie attributes (path, domain, secure, etc.) or managing cookies across different domains.

Q Can I store complex data like JSON objects in cookies

ANS Yes, you can store JSON objects in cookies by first serializing them into a string using JSON.stringify() before setting the cookie, and then parsing the string back into an object using JSON.parse() when reading the cookie.
