“jQuery Datepicker How to Disable Specific Dates Via JavaScript Array”

This scenario frequently arises when implementing booking systems or scheduling tools where specific dates must be unavailable for selection due to holidays, maintenance, or prior bookings. Several robust techniques exist, primarily centered around the beforeShowDay configuration option of the Datepicker.

Solution 1: Using Array.prototype.indexOf with beforeShowDay

The most direct approach involves checking if the formatted date string exists within a JavaScript array containing all the dates intended for exclusion. This method relies on the standard JavaScript indexOf function.

For dates formatted as ‘YYYY-MM-DD’:

const excludedDateStrings = ["2013-03-14", "2013-03-15", "2013-03-16"];

$('input.date-input').datepicker({
    // Requires jQuery UI and Datepicker scripts/CSS to be loaded
    beforeShowDay: function(date){
        // Format the date object to match the array's format
        const formattedDate = jQuery.datepicker.formatDate('yy-mm-dd', date);
        
        // Return false (index of -1) if the date is found in the array
        return [ excludedDateStrings.indexOf(formattedDate) === -1 ];
    }
});

Solution 2: Browser Compatibility with jQuery.inArray

If support for older browsers that lack native Array.prototype.indexOf (like Internet Explorer 8) is necessary, the jQuery utility function .inArray() serves as a reliable alternative for checking array membership.

const specificDatesToBlock = ["2013-03-14", "2013-03-15", "2013-03-16"];

$('input.legacy-safe-input').datepicker({
    beforeShowDay: function(date){
        const dateStr = jQuery.datepicker.formatDate('yy-mm-dd', date);
        
        // $.inArray returns -1 if the element is not found
        return [$.inArray(dateStr, specificDatesToBlock) === -1];
    }
});

Solution 3: Disabling Specific Dates and Weekdays Simultaneously

Sometimes, requirements involve blocking specific calendar dates and recurring days of the week (e.g., all Sundays). This requires combining two checks inside beforeShowDay.

This example demonstrates blocking Sundays (day != 0) alongside a custom list of dates formatted as ‘DD-MM-YYYY’.

jQuery(function($){
    const holidayDates = [
       "27-04-2016", "25-12-2016", "26-12-2016",
       "04-04-2017", "05-04-2017", "06-04-2017", "07-04-2017", "08-04-2017", "09-04-2017"
    ];

    // Target multiple datepicker elements
    $("#datepicker-id-a, #datepicker-id-b").datepicker({
       beforeShowDay: function(date){
         const dayOfWeek = date.getDay(); // 0 for Sunday, 1 for Monday, etc.
         const dateStringDDMMYYYY = jQuery.datepicker.formatDate('dd-mm-yy', date);
         
         const isHoliday = ($.inArray(dateStringDDMMYYYY, holidayDates) !== -1);

         // dayOfWeek != 0 ensures Sundays are disabled. !isHoliday prevents selection of listed dates.
         return [dayOfWeek !== 0 && !isHoliday];
       }
    });
});

Solution 4: Using Date Objects as Map Keys (For Specific Scenarios)

If you are working in an environment where performance for checking a very large list of dates is paramount, or if your application logic naturally deals with Date objects, you can use a JavaScript Object or Map where the date object itself acts as the key. Note that for this to work reliably across browsers when dealing with specific dates, the date string representation must be consistent when comparing keys.

const disabledDateMap = {};
// Populate the map using Date objects created from specific dates
disabledDateMap[new Date("08/28/2017").toDateString()] = true;
disabledDateMap[new Date("12/23/2017").toDateString()] = true;

$(".datepicker-element").datepicker({
    dateFormat: "dd/mm/yy",
    beforeShowDay: function (date) {
        // Check against the map key derived from the date's string representation
        const isBlocked = disabledDateMap[date.toDateString()];
        
        if (isBlocked) {
            return [false, "", ""]; // Return false to disable selection
        }
        // If not blocked, allow selection (true, optional_class, optional_tooltip)
        return [true, "", ""]; 
    }
});

Solution 5: Dynamic Disabling Post-Render Using DOM Manipulation

When beforeShowDay proves insufficient (perhaps due to complex logic tied to other page elements or rendering timing), an alternative is to let the datepicker render and then manually manipulate the DOM to unselect certain cells. This method often requires using setTimeout to ensure the calendar is fully drawn before attempting to find and modify the <td> elements.

This intricate example filters dates based on an exclusion list and applies the unselectable class directly to the table cells (<td>).

$('#embeded_calendar').datepicker({
    // ... other datepicker options
    onSelect: function(selectedDateFormatted){
        const selectedDate = $("#embeded_calendar").datepicker('getDate');
        deactivateDates(selectedDate);
    }
});

const excludedDates = [ "10-20-2017", "10-21-2016", "11-21-2016"]; // MM-DD-YYYY format assumed

deactivateDates(new Date());

function deactivateDates(dateContext){
    setTimeout(function(){ 
        // 1. Find dates in the exclusion list that match the currently viewed month/year
        const visibleExclusions = thisMonthDates(dateContext);
        // 2. Extract just the day numbers
        const daysToDisable = getDaysfromDate(visibleExclusions);
        
        // 3. Find all selectable day cells and filter based on the day text
        const excludedTDs = $('#embeded_calendar').find('td[data-handler="selectDay"]').filter(function(){
            // Check if the visible text of the cell is in our list of days to disable
            return $.inArray( $(this).text(), daysToDisable) >= 0;
        });

        // 4. Unbind click events and add the unselectable CSS class
        excludedTDs.unbind('click').addClass('ui-datepicker-unselectable');
    }, 10); // Slight delay to ensure rendering completes
}

function thisMonthDates(date){
  // Filters the global excludedDates array to only include dates in the current month/year context
  return $.grep( excludedDates, function( n){
    const dateParts = n.split("-");
    // Note: Assumes MM-DD-YYYY format for dateParts[0] month check
    return dateParts[0] == date.getMonth() + 1 && dateParts[2] == date.getYear() + 1900;
  });
}

function getDaysfromDate(datesArray){
    // Extracts just the day number from the exclusion date string
    return  $.map( datesArray, function( n){
        return n.split("-")[1]; // Assumes DD is the second part after splitting by '-'
    });
}

Solution 6: Disabling Dates Using Date Objects in an Object Map (DD/MM/YYYY Format Focus)

If your formatting needs mandate ‘DD/MM/YYYY’ strings for the datepicker’s dateFormat, you must ensure the comparison logic inside beforeShowDay matches this string pattern precisely. This solution uses a map where keys are derived from Date objects.

<script type="text/javascript">
    const blockedDateMap = {};
    // Define dates to block using the date constructor format (month starts at 0)
    blockedDateMap[new Date(2017, 7, 28).toDateString()] = true; // Aug 28, 2017
    blockedDateMap[new Date(2017, 11, 23).toDateString()] = true; // Dec 23, 2017
    
    $(".datepicker").datepicker({
        dateFormat: "dd/mm/yy", // Output format for user interface
        beforeShowDay: function (date) {
            const isDisabled = blockedDateMap[date.toDateString()];
            
            if (isDisabled) {
                // Return false to prevent selection
                return [false, "", ""];
            }
            // Allow selection
            return [true, "", ""];
        }
    });
</script>

FAQs on JQuery Disable Specific Dates

Q: What is the primary callback used to prevent date selection in jQuery Datepicker

ANS: The beforeShowDay callback function is the standard mechanism used to dynamically determine if a date should be selectable or disabled.

Q: How does jQuery.datepicker formatDate work

ANS: The jQuery.datepicker.formatDate(format, date) utility formats a JavaScript Date object into a string according to the specified format string (e.g., ‘yy-mm-dd’).

Q: Is there a difference between using indexOf and inArray

ANS: indexOf is a native JavaScript array method; .inArray() is a jQuery utility function that achieves the same result, offering better compatibility with older browsers that do not fully support ES5 features.

Q: Can I disable all Sundays using beforeShowDay

ANS: Yes, by checking the return value of date.getDay(). If it returns 0 (Sunday), you return [false, ...] to disable that day.
