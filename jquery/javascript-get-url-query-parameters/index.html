“JavaScript: How to Get URL Query Parameters”

How can we reliably extract these values using JavaScript?

Here are several effective methods, each with its own advantages, to get URL query parameters in JavaScript.

Solution 1: Vanilla JavaScript with URLSearchParams

The modern and recommended approach utilizes the URLSearchParams API. It provides a clean and straightforward way to work with query strings.

// Example URL: http://example.com?sent=yes
let searchParams = new URLSearchParams(window.location.search);

// Check if a parameter exists
console.log(searchParams.has('sent')); // Output: true

// Get the value of a parameter
let paramValue = searchParams.get('sent');
console.log(paramValue); // Output: "yes"

// Handle multiple values for the same parameter (e.g., ?id=1&id=2)
let multipleIds = searchParams.getAll('id');
console.log(multipleIds); // Output: ["1", "2"]

This method is widely supported across modern browsers and is generally the most robust option. For a deeper dive into URLSearchParams, refer to the MDN Web Docs .

Solution 2: Vanilla JavaScript Function for Parameter Extraction

A custom function can parse the window.location.search string.

function getUrlParameter(sParam) {
    let sPageURL = window.location.search.substring(1);
    let sURLVariables = sPageURL.split('&');
    let sParameterName, i;

    for (i = 0; i < sURLVariables.length; i++) {
        sParameterName = sURLVariables[i].split('=');

        if (sParameterName[0] === sParam) {
            // Return the decoded value, or true if the parameter exists without a value
            return sParameterName[1] === undefined ? true : decodeURIComponent(sParameterName[1].replace(/\+/g, ' '));
        }
    }
    return false; // Parameter not found
}

// Example URL: http://dummy.com/?technology=jquery&blog=jquerybyexample.com
let tech = getUrlParameter('technology');
let blog = getUrlParameter('blog');
console.log(`Technology: ${tech}, Blog: ${blog}`); // Output: Technology: jquery, Blog: jquerybyexample.com

This function iterates through the query string parts, splits them by ‘=’, and returns the decoded value of the requested parameter. It also handles cases where a parameter might not have an assigned value.

Solution 3: Using a Regular Expression

Regular expressions offer a concise way to extract parameters.

function getUrlVars() {
    let vars = {};
    let parts = window.location.href.replace(/[?&]+([^=&]+)=([^&]*)/gi, function(m, key, value) {
        vars[key] = value;
    });
    return vars;
}

// Example URL: http://www.example.com/page?id=6&user=test
let queryParams = getUrlVars();
let userId = queryParams["id"];
console.log(`User ID: ${userId}`); // Output: User ID: 6

This approach uses a regular expression to find all key-value pairs and store them in an object.

Solution 5: Advanced Regular Expression Parsing

For more complex scenarios, including handling encoded characters and multi-valued parameters, a robust regular expression can be employed.

function getParameterByName(name, url) {
    if (!url) url = window.location.href;
    // Properly escape special characters in the parameter name
    name = name.replace(/[\[\]]/g, "\\$&");
    const regex = new RegExp("[?&]" + name + "(=([^&#]*)|&|#|$)");
    const results = regex.exec(url);
    if (!results) return null;
    if (!results[2]) return ''; // Parameter exists but has no value
    // Decode URI components, replacing '+' with spaces
    return decodeURIComponent(results[2].replace(/\+/g, " "));
}

// Example URL: ?first=value1&second=&value2&third=with%20spaces
console.log(getParameterByName('first'));  // Output: value1
console.log(getParameterByName('second')); // Output: value2
console.log(getParameterByName('third'));  // Output: with spaces

This function provides enhanced decoding and handles parameters that might be missing a value or contain special characters.

Solution 6: Leveraging Object.fromEntries with URLSearchParams

A more modern, albeit less universally compatible (older browsers), approach combines URLSearchParams with Object.fromEntries.

// Assuming you have a URL string
const url = 'http://example.com/page?key1=value1&key2=value2';
const urlObject = new URL(url);
const queryParams = Object.fromEntries(urlObject.searchParams);

console.log(queryParams.key1); // Output: value1

This creates a plain JavaScript object directly from the URL’s search parameters, offering a clean structure.

Solution 7: Dedicated Libraries

Libraries such as URI.js offer robust parsing capabilities for URLs, including query string manipulation.

// Requires including the URI.js library
// <script src="https://cdnjs.cloudflare.com/ajax/libs/URI.js/1.17.0/URI.min.js"></script>

const uriString = "http://example.org/foo.html?technology=jquery&technology=css&blog=stackoverflow";
const uri = new URI(uriString);
const query = uri.search(true); // Parses query string into an object

console.log(query.technology); // Output: ["jquery", "css"] (Array for multi-valued parameters)
console.log(query.blog);       // Output: "stackoverflow"

These libraries abstract away much of the parsing complexity, especially for intricate URL structures.

FAQs on JavaScript URL Query Parameters

Q: What is the primary way to get URL query parameters in modern JavaScript

ANS: The URLSearchParams API, accessed via new URLSearchParams(window.location.search), is the most recommended and modern method for retrieving URL query parameters.

Q: How can I retrieve a parameter that might have multiple values

ANS: When a parameter appears multiple times in the URL (e.g., ?tag=javascript&tag=web), use the getAll() method of URLSearchParams or a custom parsing function that correctly handles arrays.

Q: Do I need jQuery to get URL parameters

ANS: No, you do not need jQuery. Vanilla JavaScript offers several robust methods, including the built-in URLSearchParams API, to achieve this functionality. Libraries like jQuery can offer convenience methods if you’re already using them.

Q: What if a URL parameter contains special characters

ANS: Use decodeURIComponent() to properly handle URL-encoded characters in parameter values. Most of the provided JavaScript solutions incorporate this decoding step.

Q: How does `URLSearchParams` handle parameters without values

ANS: If a parameter exists without an equals sign and a value (e.g., ?flag), URLSearchParams.get('flag') will return an empty string (""). Custom functions might return true or a specific indicator.
