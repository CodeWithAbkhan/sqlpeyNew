“Convert Base64 to Blob in JavaScript: Efficient Methods”

Converting a Base64 encoded string into a Blob object in JavaScript is a common task, especially when dealing with image data or other binary files received as strings. A Blob object represents raw, immutable data that can be read from or written to storage. This process is crucial for client-side file manipulation, uploading, or displaying binary data.

We’ll look at several reliable methods to achieve this conversion, covering efficiency, browser compatibility, and alternative approaches.

Method 1: Efficient Byte Array Construction with Slicing

This approach focuses on converting the Base64 string into an array of bytes, then constructing a Blob. It includes an optimization for processing large strings by handling them in smaller chunks, which can improve performance by preventing the browser from becoming unresponsive.

The core idea is to:

  1. Decode the Base64 string using atob() into a string of characters, where each character’s code point corresponds to a byte.
  2. Convert this character string into an array of byte numbers using charCodeAt().
  3. Create a Uint8Array from these byte numbers.
  4. Finally, construct a Blob from the Uint8Array.

The optimized version breaks the character string into slices (e.g., 512 bytes) before converting each slice to a Uint8Array and then collecting these into an array for the Blob constructor.

const b64toBlob = (b64Data, contentType = '', sliceSize = 512) => {
  const byteCharacters = atob(b64Data); // Decode Base64
  const byteArrays = [];

  for (let offset = 0; offset < byteCharacters.length; offset += sliceSize) {
    const slice = byteCharacters.slice(offset, offset + sliceSize);

    const byteNumbers = new Array(slice.length);
    for (let i = 0; i < slice.length; i++) {
      byteNumbers[i] = slice.charCodeAt(i); // Get char code for each byte
    }

    const byteArray = new Uint8Array(byteNumbers); // Convert to Uint8Array
    byteArrays.push(byteArray);
  }

  const blob = new Blob(byteArrays, { type: contentType }); // Create Blob
  return blob;
};

Method 3: Minimalist and Optimized Byte Array Conversion

This version is a streamlined implementation that focuses on direct conversion to a Blob. It’s efficient and avoids the overhead of intermediate arrays where possible.

function base64toBlobOptimized(base64Data, contentType = '') {
    const sliceSize = 1024; // Define a slice size for processing
    const byteCharacters = atob(base64Data);
    const bytesLength = byteCharacters.length;
    const slicesCount = Math.ceil(bytesLength / sliceSize);
    const byteArrays = new Array(slicesCount);

    for (let sliceIndex = 0; sliceIndex < slicesCount; ++sliceIndex) {
        const begin = sliceIndex * sliceSize;
        const end = Math.min(begin + sliceSize, bytesLength);

        const bytes = new Array(end - begin);
        for (let offset = begin, i = 0; offset < end; ++i, ++offset) {
            bytes[i] = byteCharacters.charCodeAt(offset);
        }
        byteArrays[sliceIndex] = new Uint8Array(bytes);
    }
    return new Blob(byteArrays, { type: contentType });
}

Method 4: TypeScript Implementation with Type Safety

For developers using TypeScript, this function offers type safety and a clean structure. It correctly parses the data URI format to extract the content type and the Base64 data.

/**
 * Convert BASE64 to BLOB with TypeScript.
 * @param base64Image Base64 image data string.
 * @returns A Blob object.
 */
function convertBase64ToBlobTS(base64Image: string): Blob {
  // Split into content type and data parts
  const parts = base64Image.split(';base64,');
  const imageType = parts[0].split(':')[1]; // Extract content type

  // Decode Base64 string
  const decodedData = window.atob(parts[1]);

  // Create Uint8Array from decoded data
  const uInt8Array = new Uint8Array(decodedData.length);
  for (let i = 0; i < decodedData.length; ++i) {
    uInt8Array[i] = decodedData.charCodeAt(i);
  }

  // Return Blob
  return new Blob([uInt8Array], { type: imageType });
}

Method 5: Utility Function for File Downloads

This utility function makes it easy to download files directly from Base64 data. It uses fetch to get the Blob and then creates a temporary link to initiate the download.

window.saveFileFromBase64 = function (bytesBase64, mimeType, fileName) {
  const fileUrl = `data:${mimeType};base64,${bytesBase64}`;
  fetch(fileUrl)
    .then(response => response.blob())
    .then(blob => {
      const link = window.document.createElement("a");
      link.href = window.URL.createObjectURL(blob, { type: mimeType });
      link.download = fileName; // Set the desired file name
      document.body.appendChild(link);
      link.click(); // Trigger the download
      document.body.removeChild(link); // Clean up the link element
    })
    .catch(error => console.error("Error saving file:", error));
};

// Example Usage:
// saveFileFromBase64('YOUR_BASE64_DATA_HERE', 'application/pdf', 'myDocument.pdf');

This is a practical solution for implementing download functionality directly within the browser.

Method 7: Browser Compatibility with BlobBuilder Fallback

For older browsers that might not fully support the Blob constructor directly, a fallback using BlobBuilder can be employed. This ensures broader compatibility, particularly on some mobile browsers.

try {
    // Modern Blob constructor
    blob = new Blob(byteArrays, { type: contentType });
} catch (e) {
    if (e.name === 'TypeError' && window.BlobBuilder) {
        // Fallback for older browsers using BlobBuilder
        window.BlobBuilder = window.BlobBuilder || window.WebKitBlobBuilder || window.MozBlobBuilder || window.MSBlobBuilder;
        const bb = new BlobBuilder();
        bb.append(byteArrays);
        blob = bb.getBlob(contentType);
    } else if (e.name === "InvalidStateError") {
        // Another fallback for specific errors
        blob = new Blob(byteArrays, { type: contentType });
    } else {
        // Handle cases where Blob is completely unsupported
        console.error("Blob constructor is not supported.");
    }
}

This approach provides a safety net for ensuring your code functions across a wider range of user agents.

Method 9: Canvas API for Image Data

For image-specific Base64 data, using the HTML5 Canvas API is an elegant solution. You can load the image onto a canvas and then use canvas.toBlob() to generate the Blob asynchronously.

function base64ToBlobWithCanvas(b64, onsuccess, onerror) {
    const img = new Image();

    img.onerror = onerror;

    img.onload = function() {
        const canvas = document.createElement('canvas');
        canvas.width = img.width;
        canvas.height = img.height;

        const ctx = canvas.getContext('2d');
        ctx.drawImage(img, 0, 0, canvas.width, canvas.height);

        canvas.toBlob(onsuccess); // Asynchronously creates the Blob
    };

    img.src = b64; // Expects 'data:image/...' format
}

// Example Usage:
const base64ImageData = 'data:image/jpg;base64,/9j/4AAQSkZJRgABAQA...'; // Replace with actual Base64 image data
base64ToBlobWithCanvas(
    base64ImageData,
    function(blob) { // Success callback
        const url = window.URL.createObjectURL(blob);
        console.log('Blob from Canvas:', url);
        // Use 'url' for display or download
    },
    function(error) { // Error callback
        console.error('Error using Canvas:', error);
    }
);

function base64toBlobDualMode(base64Data, contentType, sliceSize) {
    let byteCharacters;
    let blobData;
    let blob;

    contentType = contentType || '';
    byteCharacters = atob(base64Data);

    // Decide whether to use sliced or single array based on sliceSize presence
    blobData = sliceSize ? getBlobDataSliced(byteCharacters, sliceSize) : getBlobDataAtOnce(byteCharacters);

    blob = new Blob(blobData, { type: contentType });
    return blob;

    function getBlobDataAtOnce(chars) {
        const byteNumbers = new Array(chars.length);
        for (let i = 0; i < chars.length; i++) {
            byteNumbers[i] = chars.charCodeAt(i);
        }
        const byteArray = new Uint8Array(byteNumbers);
        return [byteArray]; // Return as an array containing one Uint8Array
    }

    function getBlobDataSliced(chars, sliceSize) {
        const byteArrays = [];
        for (let offset = 0; offset < chars.length; offset += sliceSize) {
            const slice = chars.slice(offset, offset + sliceSize);
            const byteNumbers = new Array(slice.length);
            for (let i = 0; i < slice.length; i++) {
                byteNumbers[i] = slice.charCodeAt(i);
            }
            byteArrays.push(new Uint8Array(byteNumbers));
        }
        return byteArrays;
    }
}

Method 12: Direct Data URL to Blob Conversion

This method provides a straightforward way to convert a data URL string directly into a Blob object.

function makeblobFromDataURL(dataURL) {
    const BASE64_MARKER = ';base64,';
    const parts = dataURL.split(BASE64_MARKER);
    const contentType = parts[0].split(':')[1];
    const raw = window.atob(parts[1]); // Decode Base64
    const rawLength = raw.length;
    const uInt8Array = new Uint8Array(rawLength);

    for (let i = 0; i < rawLength; ++i) {
        uInt8Array[i] = raw.charCodeAt(i);
    }

    return new Blob([uInt8Array], { type: contentType });
}

Method 14: Two Variations for Base64 to Blob

This method presents two variations: one that handles chunking and another using the fetch API for potentially simpler handling, though less predictable for older browsers.

function base64ToBlobVariations(base64, contentType = 'image/png', chunkLength = 512) {
    // Variation 1: Chunked conversion
    const byteCharsArray = Array.from(atob(base64.substr(base64.indexOf(',') + 1)));
    const chunksIterator = new Array(Math.ceil(byteCharsArray.length / chunkLength));
    const bytesArrays = [];

    for (let c = 0; c < chunksIterator.length; c++) {
        bytesArrays.push(new Uint8Array(byteCharsArray.slice(c * chunkLength, chunkLength * (c + 1)).map(s => s.charCodeAt(0))));
    }
    const blobChunked = new Blob(bytesArrays, { type: contentType });
    return blobChunked;
}

// Variation 2: Light (Fetch-based)
async function base64ToBlobLight(base64) {
    return await fetch(base64).then(res => res.blob());
}

Method 15: Node.js Buffer for Base64 Conversion

This method is tailored for Node.js environments, utilizing the Buffer class to efficiently convert Base64 strings into byte arrays. The .replace() part is optional and helps clean up data URLs.

// This code is primarily for Node.js environments
// In Node.js: const { Buffer } = require('buffer');

function base64ToBuffer(base64String) {
  // Remove potential data URL prefix
  const cleanBase64 = base64String.replace(/^[\w\d;:\/]+base64\,/g, '');
  const byteArray = Buffer.from(cleanBase64, 'base64');
  return byteArray;
}

FAQs on Convert Base64 to Blob in JavaScript

Q: What is the most efficient way to convert Base64 to Blob

ANS: For modern browsers, using fetch with a data URI (fetch(data:${type};base64,${base64}).then(res => res.blob())) is often concise and efficient. Alternatively, direct conversion using Uint8Array.from(atob(base64Data), char => char.charCodeAt(0)) can be faster for pure decoding.

Q: Can I convert Base64 to Blob in older browsers like Internet Explorer

ANS: Yes, you can use fallback methods involving BlobBuilder or ensure your implementation handles potential TypeErrors for older browser compatibility. Method 7 demonstrates this fallback.

Q: How does the slicing method improve performance

ANS: Slicing breaks down large Base64 strings into smaller chunks before processing. This prevents the browser’s main thread from being blocked for extended periods, leading to a smoother user experience, especially with large data.

Q: Is it better to use Canvas API for image Base64 to Blob conversion

ANS: If you’re dealing specifically with image data and might need to manipulate it (resize, crop), the Canvas API’s toBlob() method is very suitable. For general binary data, other methods might be more direct.
