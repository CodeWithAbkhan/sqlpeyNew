Top Methods to Retrieve URL Query Parameters

Method 1: Harnessing URLSearchParams and Proxy (Modern Approach)

The URLSearchParams interface is the recommended standard for handling URL query strings in modern JavaScript. It offers a robust and intuitive API for accessing, modifying, and iterating over URL parameters. For enhanced performance and direct property access, combining it with the Proxy object can be beneficial, though it limits iteration.

Retrieving a Single Parameter (Accepted - Latest Standard)

Use URLSearchParams to easily get a specific parameter from the current URL’s query string.

// Example: URL is https://example.com/?productId=123&category=electronics
const currentURLParams = new URLSearchParams(window.location.search);
const productIdValue = currentURLParams.get('productId'); // Returns "123"
console.log(`Product ID: ${productIdValue}`);

Faster Access with Proxy (Update: Jan-2022)

For direct property access that might offer a slight performance edge (at the cost of losing iterability), Proxy can wrap URLSearchParams.

// Example: URL is https://example.com/?itemId=XYZ789
const proxyParams = new Proxy(new URLSearchParams(window.location.search), {
  get: (searchParamsTarget, propertyName) => searchParamsTarget.get(propertyName),
});
let itemIdentifier = proxyParams.itemId; // Directly access "itemId" as a property
console.log(`Item ID: ${itemIdentifier}`);

Mapping All Query Parameters to an Object (Update: June-2021)

If you require all query parameters as a plain JavaScript object, Object.fromEntries() offers a concise way to achieve this.

// Example: URL is https://example.com/?paramA=valueA&paramB=valueB
const searchParamEntries = new URLSearchParams(window.location.search);
const allQueryParamsObject = Object.fromEntries(searchParamEntries.entries());
console.log("All Query Parameters as Object:", allQueryParamsObject);
// Output: { paramA: "valueA", paramB: "valueB" }

Original Vanilla JavaScript getParameterByName (Historical Context - Sep-2018)

Before URLSearchParams gained widespread adoption, a common pure JavaScript function relied on regular expressions. This method remains viable for broader browser compatibility.

function retrieveParamByName(paramName, targetUrl = window.location.href) {
    paramName = paramName.replace(/[\[\]]/g, '\\$&'); // Escape special regex chars
    const paramRegex = new RegExp('[?&]' + paramName + '(=([^&#]*)|&|#|$)');
    const regexMatch = paramRegex.exec(targetUrl);
    if (!regexMatch) return null;
    if (!regexMatch[2]) return ''; // Parameter present but empty
    return decodeURIComponent(regexMatch[2].replace(/\+/g, ' '));
}

// Usage Example: current URL is ?product=laptop&color=&size
const product = retrieveParamByName('product'); // "laptop"
const color = retrieveParamByName('color');     // "" (present with empty value)
const size = retrieveParamByName('size');       // "" (present with no value)
const material = retrieveParamByName('material'); // null (absent)

console.log(`Product: ${product}, Color: ${color}, Size: ${size}, Material: ${material}`);

// Note: This function is case-sensitive. Add 'i' modifier to RegExp for case-insensitivity.
// Note: For duplicate parameters (e.g., ?foo=val1&foo=val2), this returns the first value.

Method 2: Efficient Vanilla JavaScript Object Mapping (Accepted)

Repeated regular expression searches can be inefficient. A better approach for traditional JavaScript involves parsing the query string once into an associative array (object) upon page load or when needed, making subsequent parameter access fast. This also handles URL decoding correctly.

let pageUrlParams; // Global variable to store parsed parameters

(window.onpopstate = function () {
    const plusReplacer = /\+/g; // Regex for replacing '+' with a space
    const paramSplitter = /([^&=]+)=?([^&]*)/g; // Regex to split key=value pairs
    const decoderFunction = (s) => decodeURIComponent(s.replace(plusReplacer, " "));
    const urlQuery = window.location.search.substring(1); // Get query string without '?'

    pageUrlParams = {};
    let currentMatch;
    while (currentMatch = paramSplitter.exec(urlQuery)) {
       pageUrlParams[decoderFunction(currentMatch[1])] = decoderFunction(currentMatch[2]);
    }
})();

// Example Query String: ?pageId=home&sortOrder=asc&sessionId=abc123def456&encodedParam=+Hello%20&emptyParam

// Resulting pageUrlParams object:
/*
{
    encodedParam: " Hello ",
    pageId: "home",
    sortOrder: "asc",
    sessionId: "abc123def456",
    emptyParam: ""
}
*/

console.log("Sort Order:", pageUrlParams["sortOrder"]); // "asc"
console.log("Is emptyParam present:", "emptyParam" in pageUrlParams); // true

// Handling Repeated Parameters:
// If you need to retrieve repeated parameters (e.g., ?item=1&item=2) as an array:
let dynamicUrlParams = {};
(window.onpopstate = function () {
    const plusRegex = /\+/g;
    const queryPairRegex = /([^&=]+)=?([^&]*)/g;
    const decodeValue = (s) => decodeURIComponent(s.replace(plusRegex, " "));
    const rawQuery = window.location.search.substring(1);

    while (letPair = queryPairRegex.exec(rawQuery)) {
        const decodedKey = decodeValue(letPair[1]);
        const decodedValue = decodeValue(letPair[2]);
        if (decodedKey in dynamicUrlParams) {
            if (!Array.isArray(dynamicUrlParams[decodedKey])) {
                dynamicUrlParams[decodedKey] = [dynamicUrlParams[decodedKey]];
            }
            dynamicUrlParams[decodedKey].push(decodedValue);
        } else {
            dynamicUrlParams[decodedKey] = decodedValue;
        }
    }
})();

// For a URL like: ?product=A&product=B&category=Electronics
// dynamicUrlParams.product would be ["A", "B"]
// dynamicUrlParams.category would be "Electronics"

Method 3: ES2015 (ES6) and Traditional JavaScript Parsing (Accepted)

Modern JavaScript features like arrow functions and reduce can create very compact and functional solutions for parsing query strings.

ES2015 (ES6) Concise Version

const parseQueryStringAsObject = queryInput => {
    return queryInput
        ? (/^[?#]/.test(queryInput) ? queryInput.slice(1) : queryInput)
            .split('&')
            .reduce((accumulatedParams, paramSegment) => {
                    let [paramKey, paramValue] = paramSegment.split('=');
                    accumulatedParams[paramKey] = paramValue ? decodeURIComponent(paramValue.replace(/\+/g, ' ')) : '';
                    return accumulatedParams;
                }, {}
            )
        : {};
};

// Example Usage:
// const currentUrlQuery = window.location.search; // or any query string like "?item=value"
const parsedItems = parseQueryStringAsObject("?topic=123&item_name=query+string");
console.log("Topic:", parsedItems["topic"]);     // 123
console.log("Item Name:", parsedItems["item_name"]); // query string
console.log("Non-existent Param:", parsedItems["nothing_here"]); // undefined (object)

Classic Vanilla JavaScript Approach

A self-executing anonymous function can create a readily available qs object for query parameters without external dependencies.

const pageQueryParams = (function(rawParams) {
    if (rawParams === "") return {};
    const paramMap = {};
    for (let i = 0; i < rawParams.length; ++i) {
        const parts = rawParams[i].split('=', 2); // Split into 2 parts max
        if (parts.length === 1) {
            paramMap[parts[0]] = ""; // Parameter exists but has no value
        } else {
            paramMap[parts[0]] = decodeURIComponent(parts[1].replace(/\+/g, " "));
        }
    }
    return paramMap;
})(window.location.search.substring(1).split('&'));

// Example Usage: Assuming URL is ?product=shirt&color=blue
console.log("Product:", pageQueryParams["product"]); // "shirt"
console.log("Color:", pageQueryParams["color"]);     // "blue"
console.log("Material:", pageQueryParams["material"]); // undefined

Performance Considerations (Split vs. Regex)

Historically, performance benchmarks (jsPerf) have shown that string split based methods can be significantly faster than regular expression based parsing for typical query string operations.

  • Split Method: Generally faster (e.g., 144,780 ops/sec).
  • Regex Method: Can be slower (e.g., 13,891 ops/sec, 90% slower).

This suggests that for performance-critical applications, especially those dealing with many parameters or frequent parsing, split-based approaches or built-in APIs like URLSearchParams (which are often highly optimized native implementations) are preferable.

Method 5: Improved Concise Regex (Accepted)

For a quick, single-parameter retrieval using regular expressions, this improved version is concise and effective.

function getPageParam(paramName) {

}

Method 7: Compact Vanilla JavaScript for Multi-Valued Keys (Accepted)

This solution focuses on creating a query parameter object that correctly handles multiple instances of the same key (e.g., ?item=1&item=2) by storing them as arrays. It also addresses proper URL decoding and gracefully handles empty query strings.

// ES5 Version
let decodedQueryParamsES5 = {};
if (location.search) {
    location.search.substring(1).split('&').forEach(function(itemEntry) {
        const splitItem = itemEntry.split('=');
        const keyVal = splitItem[0];
        const valVal = splitItem[1] && decodeURIComponent(splitItem[1]); // Short-circuit for undefined
        (decodedQueryParamsES5[keyVal] = decodedQueryParamsES5[keyVal] || []).push(valVal);
    });
}

// ES6 Version (more concise)
let decodedQueryParamsES6 = {};
if (location.search) {
    location.search.substring(1).split`&`.forEach(itemEntry => {
        let [keyES6, valES6] = itemEntry.split`=`;
        valES6 = valES6 && decodeURIComponent(valES6);
        (decodedQueryParamsES6[keyES6] = decodedQueryParamsES6[keyES6] || []).push(valES6);
    });
}

// As a Reusable Function with reduce (ES6)
function fetchQueryParams() {
  return location.search
    ? location.search.substring(1).split`&`.reduce((accParams, itemEntry) => {
        let [keyName, valueData] = itemEntry.split`=`;
        valueData = valueData && decodeURIComponent(valueData);
        (accParams[keyName] = accParams[keyName] || []).push(valueData);
        return accParams;
      }, {})
    : {};
}

// Example URL: "?color=red&size=M&option&color=blue&style=classic&option=true"
const parsedExample = fetchQueryParams();
console.log("Parsed Example:", parsedExample);
/* Output for example URL:
{
  color: ["red", "blue"],
  size: ["M"],
  option: [undefined, "true"], // 'undefined' for param without value, then 'true'
  style: ["classic"]
}
*/

console.log("First color:", parsedExample.color[0]); // "red"
console.log("Second color:", parsedExample["color"][1]); // "blue"

// Important Note on `decodeURIComponent(undefined)`:
// Directly calling `decodeURIComponent(undefined)` results in the string "undefined".
// The `v = v && decodeURIComponent(v);` pattern (short-circuit evaluation)
// prevents this by only calling `decodeURIComponent` if `v` is not undefined.

Method 8: Simple jQuery Plugin $.urlParam (Accepted)

If your project utilizes jQuery, a straightforward plugin can simplify getting a single URL parameter.

(function($) {
    $.urlParamGetter = function(paramName, targetUrl) {
        if (!targetUrl) {
            targetUrl = window.location.href;
        }
        const regexPattern = new RegExp('[\\?&]' + paramName + '=([^&#]*)');
        const regexExecResult = regexPattern.exec(targetUrl);
        if (!regexExecResult) {
            return undefined;
        }
        return regexExecResult[1] || undefined;
    };
})(jQuery);

Vanilla JavaScript with popstate Listener

This version is more robust for modern web applications that might dynamically change the URL using history.pushState() or history.replaceState(), ensuring the parameter cache is always up-to-date.

const getDynamicParamValue = (function() {
    let cachedParams;
    const updateParamsCache = function() {
        const currentQuery = window.location.search;
        const queryRegex = /[?&;](.+?)=([^&;]+)/g;
        let matchResult;

        cachedParams = {};

        if (currentQuery) {
            while (matchResult = queryRegex.exec(currentQuery)) {
                cachedParams[matchResult[1]] = decodeURIComponent(matchResult[2]);
            }
        }    
    };

    // Listen for URL changes via history API
    window.addEventListener && window.addEventListener('popstate', updateParamsCache);

    // Initial parsing
    updateParamsCache();

    return function(paramKey) {
        return cachedParams.hasOwnProperty(paramKey) ? cachedParams[paramKey] : null;
    };

})(); // Self-executing to initialize

Method 10: Simple Two-Split Approach (Accepted)

This approach leverages JavaScript’s split method multiple times for a straightforward way to extract parameter values. While simple, it has limitations, particularly with parameters appearing at the very beginning of the query string or specific URL encoding scenarios.

function getQuerySegment(segmentName) {
    let firstHalf = location.search.split(segmentName + '=')[1];
    return firstHalf !== undefined ? decodeURIComponent(firstHalf.split('&')[0]) : null;
}

// Improved to handle params at start ('?') or after '&'
function getQuerySegmentImproved(segmentName) {
    let firstHalf = location.search.split('&' + segmentName + '=')[1];
    if (!firstHalf) {
        firstHalf = location.search.split('?' + segmentName + '=')[1];
    }
    return firstHalf !== undefined ? decodeURIComponent(firstHalf.split('&')[0]) : null;
}

// Example: URL is ?itemId=A123&status=active
const itemID = getQuerySegmentImproved('itemId'); // "A123"
console.log(`Item ID: ${itemID}`);

Method 11: jQuery Plugin Wrapper for Parsed Query Strings (Accepted)

This jQuery plugin optimizes query string parsing by storing the parsed parameters in a cache (this.queryStringParams), so the parsing logic only runs once per page load, improving performance on repeated calls.

;(function ($) {
    $.extend({      
        getCachedQueryString: function (paramKey) {           
            function parseAndCacheParams() {
                const parsedResult = {};
                const plusRegex = /\+/g;  // Regex for replacing addition symbol with a space
                const keyValueRegex = /([^&=]+)=?([^&]*)/g; // Regex for key=value pairs
                const decodeFn = (s) => decodeURIComponent(s.replace(plusRegex, " "));
                const rawQuery = window.location.search.substring(1);

                let matchEntry;
                while (matchEntry = keyValueRegex.exec(rawQuery)) {
                    parsedResult[decodeFn(matchEntry[1])] = decodeFn(matchEntry[2]);
                }
                return parsedResult;
            }

            if (!this.cachedQueryStringData) {
                this.cachedQueryStringData = parseAndCacheParams(); 
            }

            return this.cachedQueryStringData[paramKey];
        }
    });
})(jQuery);

Method 14: PHP-like $_GET Object (Accepted)

This function creates a JavaScript object that mimics PHP’s $_GET superglobal array, where the last encountered value for a duplicate key overwrites previous ones.

function getQueryStringObject() {
    const fullUrl = location.search;
    const queryParts = fullUrl.substring(fullUrl.indexOf('?') + 1).split('&');
    const paramObject = {};
    for (let i = 0; i < queryParts.length; i++) {
        let pair = queryParts[i].split('=');
        paramObject[pair[0]] = decodeURIComponent(pair[1]);
    }
    return paramObject;
}

// Usage: Assuming query string like ?x=5&y&z=hello&x=6
const currentGET = getQueryStringObject();
console.log("PHP-like GET object:", currentGET);
/* Output:
{
  x: "6",       // '6' overwrites '5'
  y: undefined, // y has no value
  z: "hello"
}
*/

Method 15: Simple qs Function (Accepted)

A very direct and plain JavaScript function for retrieving a single query string parameter.

function getQuerySimple(keyName) {
    const urlVars = [];
    const urlHashes = window.location.href.slice(window.location.href.indexOf('?') + 1).split('&');
    for (let i = 0; i < urlHashes.length; i++) {
        const hashPair = urlHashes[i].split('=');
        urlVars.push(hashPair[0]);
        urlVars[hashPair[0]] = hashPair[1];
    }
    return urlVars[keyName];
}

Method 17: Comprehensive URLParser Utility (Accepted)

For scenarios requiring extensive URL dissection and manipulation (not just query parameters), a custom URLParser object can provide methods for getting/setting host, path, hash, and parameters.

function CustomURLParser(urlInput){
    let pathSegment="", querySegment="", hashSegment="", paramsArray;
    if(urlInput.indexOf("#") > 0){
        hashSegment = urlInput.substring(urlInput.indexOf("#") + 1);
        urlInput = urlInput.substring(0 , urlInput.indexOf("#"));
    }
    if(urlInput.indexOf("?") > 0){
        pathSegment = urlInput.substring(0 , urlInput.indexOf("?"));
        querySegment = urlInput.substring(urlInput.indexOf("?") + 1);
        paramsArray = querySegment.split('&');
    } else {
        pathSegment = urlInput;
    }
    
    return {
        getHostname: function(){
            const hostExp = /\/\/([\w.-]*)/;
            const hostMatch = hostExp.exec(pathSegment);
            if (hostMatch != null && hostMatch.length > 1) return hostMatch[1];
            return "";
        },
        getPathname: function(){
            const pathExp = /\/\/[\w.-]*(?:\/([^?]*))/;
            const pathMatch = pathExp.exec(pathSegment);
            if (pathMatch != null && pathMatch.length > 1) return pathMatch[1];
            return "";
        },
        getHashValue: function(){
            return hashSegment;
        },
        getParamsList: function(){
            return paramsArray;
        },
        getQueryString: function(){
            return querySegment;
        },
        setHashValue: function(newValue){
            if(querySegment.length > 0) querySegment = "?" + querySegment;
            if(newValue.length > 0) querySegment = querySegment + "#" + newValue;
            return pathSegment + querySegment;
        },
        setParamValue: function(paramKey, paramValue){
            if(!paramsArray) paramsArray = new Array();
            paramsArray.push(paramKey + '=' + paramValue);
            querySegment = ""; // Reset query to rebuild
            for (let i = 0; i < paramsArray.length; i++) {
                if(querySegment.length > 0) querySegment += "&";
                querySegment += paramsArray[i];
            }
            if(querySegment.length > 0) querySegment = "?" + querySegment;
            if(hashSegment.length > 0) querySegment = querySegment + "#" + hashSegment;
            return pathSegment + querySegment;
        },
        getSingleParam: function(paramKey){
            if(paramsArray){
                for (let i = 0; i < paramsArray.length; i++) {
                    const pair = paramsArray[i].split('=');
                    if (decodeURIComponent(pair[0]) === paramKey) return decodeURIComponent(pair[1]);
                }
            }
            console.log(`Query variable ${paramKey} not found`);
        },
        hasSingleParam: function(paramKey){
            if(paramsArray){
                for (let i = 0; i < paramsArray.length; i++) {
                    const pair = paramsArray[i].split('=');
                    if (decodeURIComponent(pair[0]) === paramKey) return true;
                }
            }
            console.log(`Query variable ${paramKey} not found`);
            return false;
        },
        removeSingleParam: function(paramKey){
            querySegment = ""; // Reset query to rebuild
            if(paramsArray){
                const newParamsList = new Array();
                for (let i = 0; i < paramsArray.length; i++) {
                    const pair = paramsArray[i].split('=');
                    if (decodeURIComponent(pair[0]) !== paramKey) newParamsList.push(paramsArray[i]);
                }
                paramsArray = newParamsList;
                for (let i = 0; i < paramsArray.length; i++) {
                    if(querySegment.length > 0) querySegment += "&";
                    querySegment += paramsArray[i];
                }
            }
            if(querySegment.length > 0) querySegment = "?" + querySegment;
            if(hashSegment.length > 0) querySegment = querySegment + "#" + hashSegment;
            return pathSegment + querySegment;
        },
    };
}

Method 24: Advanced Query String Object with Array-Style Keys (Accepted)

This solution is particularly robust, designed to correctly parse and organize query strings that include array-style parameters (e.g., param[]=value). It handles both standard and array-like duplicate keys by consolidating them into arrays.

const getRobustQueryStringObject = function() {
    let bracketIndex, currentValue, entryMatch, keyName, makeArray, subKey, finalValue, resultObj = {};
    const valueDecoder = function (val) { return decodeURIComponent(val).replace(/\+/g, " "); };
    const rawUrlQuery = window.location.search.substring(1);
    const paramRegex = /([^&;=]+)=?([^&;]*)/g; // Supports both '&' and ';' delimiters

    // Helper to ensure a value is an array if multiple instances exist
    makeArray = function(val) {
        if (typeof val !== "object") {
            currentValue = val;
            val = {};
            val.length = 0;
            if (currentValue) { Array.prototype.push.call(val, currentValue); }
        }
        return val;
    };

    while (entryMatch = paramRegex.exec(rawUrlQuery)) {
        bracketIndex = entryMatch[1].indexOf("[");
        finalValue = valueDecoder(entryMatch[2]);

        if (bracketIndex < 0) { // Not an array-style key
            keyName = valueDecoder(entryMatch[1]);
            if (resultObj[keyName]) {
                resultObj[keyName] = makeArray(resultObj[keyName]);
                Array.prototype.push.call(resultObj[keyName], finalValue);
            } else {
                resultObj[keyName] = finalValue;
            }
        } else { // Array-style key
            keyName = valueDecoder(entryMatch[1].slice(0, bracketIndex));
            subKey = valueDecoder(entryMatch[1].slice(bracketIndex + 1, entryMatch[1].indexOf("]", bracketIndex)));

            resultObj[keyName] = makeArray(resultObj[keyName]);

            if (subKey) { resultObj[keyName][subKey] = finalValue; }
            else { Array.prototype.push.call(resultObj[keyName], finalValue); }
        }
    }
    return resultObj;
};

        "1": "fiction",
        "length": 2,
        "type": "main"
    },
    "id": "101",

}
*/

function getQueryStringParamCaseInsensitive(paramName, inputUrl) {
    let returnValue = "";
    let searchString = location.search;
    if (inputUrl) searchString = inputUrl;
    
    const originalSearch = searchString;
    searchString = searchString.toUpperCase();
    paramName = paramName.toUpperCase();
    
    // Normalize query string for easier parsing
    searchString = searchString.replace("?", "&") + "&";
    
    const searchToken = "&" + paramName + "=";
    if (searchString.indexOf(searchToken) !== -1) {
        const tokenLength = searchToken.length;
        const tokenStartIndex = searchString.indexOf(searchToken) + tokenLength;
        const nextAmpersandLoc = searchString.indexOf("&", tokenStartIndex);
        returnValue = unescape(originalSearch.substring(tokenStartIndex, nextAmpersandLoc));
    }
    return unescape(returnValue);
}

Q: What is the most recommended way to get URL parameters in modern JavaScript

ANS: The URLSearchParams API is the most recommended and widely supported method for accessing and manipulating URL query parameters in modern JavaScript.

Q: Can URLSearchParams handle multiple parameters with the same name

ANS: Yes, URLSearchParams can handle multiple parameters with the same name using its getAll() method, which returns an array of all values associated with that name.

Q: How do I get all query parameters as a JavaScript object

ANS: You can convert all query parameters into a plain JavaScript object using Object.fromEntries(new URLSearchParams(window.location.search).entries()).

ANS: No, it is not necessary. Modern JavaScript provides robust native APIs like URLSearchParams for efficient URL parameter parsing without needing jQuery or other external libraries.

Q: What are the performance implications of different parsing methods
