How to Upload a Blob in JavaScript: Top 3 Methods Explained

Blob data is an essential part of modern web applications, particularly when handling audio or video files. For instance, if you’ve recorded sound data using getUserMedia() and Recorder.js , the challenge then arises: how do you upload this blob to your server?

In this post, I will detail three methods for uploading blob data using JavaScript, including practical examples and server-side handling.

Example Blob Data Structure

Consider you have a blob structured like this:

Blob {
  type: "audio/wav",
  size: 655404,
  slice: function()
}

Attempting to Upload with jQuery

Your initial attempt might have looked like this:

$.post('http://localhost/upload.php', { fname: "test.wav", data: soundBlob }, 
function(responseText) {
  console.log(responseText);
});

However, this might not work as expected when uploading large files or blob data. Below are some more effective solutions.

Solution 1: Using the FormData API

The FormData API provides a way to easily construct a set of key/value pairs representing form fields and their values, including files.

Here’s how you can implement it with jQuery’s ajax method:

var formData = new FormData();
formData.append('fname', 'test.wav');
formData.append('data', soundBlob);

$.ajax({
  type: 'POST',
  url: '/upload.php',
  data: formData,
  processData: false,
  contentType: false
}).done(function(responseData) {
  console.log(responseData);
});

Why Use FormData?

  • It simplifies handling file uploads.
  • Supports large file uploads seamlessly.
  • Maintains the proper encoding type.

Solution 2: Using the Fetch API

The Fetch API provides a modern alternative to XMLHttpRequest and is easier to use when working with promises. It’s supported in modern browsers (excluding some older versions).

Basic Fetch Example

You can upload the blob using Fetch as follows:

fetch(`https://example.com/upload.php`, {
  method: "POST",
  body: soundBlob
})
.then(response => response.text())
.then(result => console.log(result))
.catch(error => console.error('Error:', error));

Fetch with Error Handling

You can enhance it with error handling as shown below:

fetch(`https://example.com/upload.php`, {
  method: "POST",
  body: soundBlob
})
.then(response => {
  if (response.ok) return response;
  else throw new Error(`Server returned ${response.status}: ${response.statusText}`);
})
.then(data => console.log(data))
.catch(err => {
  alert(err);
});

PHP Code for Handling the Upload

The following is a simple PHP script that you’ll need on your server to handle the blob data:

<?php 
// Get the entire POST body
$data = file_get_contents('php://input');

// Specify the path where you want to save the file
$filePath = "path/to/file/test.wav"; // Make sure the directory is writable

// Write the data out to the file
$fp = fopen($filePath, "wb");
fwrite($fp, $data);
fclose($fp);
?>

Solution 3: Using jQuery with Progress Events

If you want to give users feedback on the upload process, you can listen to progress events:

var xhr = new XMLHttpRequest();
xhr.open("POST", "/upload.php", true);
xhr.upload.onprogress = function(event) {
  if (event.lengthComputable) {
    var percentComplete = (event.loaded / event.total) * 100;
    console.log(`Upload progress: ${percentComplete.toFixed(2)}%`);
  }
};

xhr.onload = function() {
  if (xhr.status === 200) {
    console.log("Upload successful:", xhr.responseText);
  } else {
    console.error("Upload failed:", xhr.statusText);
  }
};

var formData = new FormData();
formData.append('fname', 'test.wav');
formData.append('data', soundBlob);

xhr.send(formData);

Alternative Methods

Notably, while jQuery and Fetch are excellent for uploading blobs, you can also explore libraries like Axios for handling HTTP requests with similar ease.

Final Thoughts

Uploading blob data is a straightforward process, especially with the FormData API and Fetch. Each method shown has its advantages, whether using jQuery for legacy projects or fetching for newer applications. It’s essential to understand which approach best suits your development needs.

FAQs on How to Upload a Blob in JavaScript

Q: Can I upload multiple blobs at once?

A: Yes, you can append multiple blobs to the FormData object and send them in a single request.

Q: Is there a way to track the upload progress?

A: Yes, using XMLHttpRequest, you can listen to the onprogress event to track the upload status.

Q: Are there limits on blob size for uploads?

A: Yes, the limits depend on server configurations and browser capabilities. It’s advisable to check your server’s max upload size.

Q: What backend script formats can I use?

A: You can use PHP, Node.js, Python, or any language capable of handling file uploads on the server-side.
