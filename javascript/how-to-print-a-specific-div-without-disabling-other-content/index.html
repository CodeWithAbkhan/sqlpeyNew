How to Print a Specific Div Without Disabling Other Content

javascript

Question:

How can one efficiently print a specific div element from a webpage without manually disabling all other content? I’m interested in producing a clean printout while avoiding any new preview dialogs or disruptive popups. The page contains multiple tables, including the desired div, which is styled to be visually appealing on the web but should be formatted differently when printed.

Solutions:

Solution 1: Using CSS Only

For a straightforward approach, employing CSS only can yield successful results in configuring the printout style. Here is a practical example:

@media print {
  body {
    visibility: hidden; /* Hides all body content */
  }
  #section-to-print {
    visibility: visible; /* Makes only the specified section visible */
    position: absolute; /* Positions it to print correctly */
    left: 0;
    top: 0;
  }
}

You can find a working demonstration of this solution in this CodeSandbox . Just click on the “Open In New Window” button above the preview. Once opened, use the browser’s Print command to see the print preview.

When exploring alternative methods, using display: none could lead to complications. If any parent element has display: none, all of its child components will also be hidden during printing. Instead, managing visibility with visibility: hidden allows for a cleaner approach, where descendants maintain their layout despite being visually hidden.

Solution 2: Streamlined JavaScript Approach

Another method involves using minimal JavaScript for better control over the print process. Here’s how you can implement it:

<div id="printableArea">
  <h1>Print me</h1>
</div>

<input type="button" onclick="printDiv('printableArea')" value="Print this div!" />

The JavaScript function to accomplish this is as follows:

function printDiv(divId) {
  var printContents = document.getElementById(divId).innerHTML; // Grab the inner content of the div
  var originalContents = document.body.innerHTML; // Store original body content

  document.body.innerHTML = printContents; // Replace body content with the div's content

  window.print(); // Open print dialog

  document.body.innerHTML = originalContents; // Restore original content after printing
}

This solution is notably efficient, as it produces no popups or separate windows. It’s simple and lightweight, ensuring compatibility across all browsers. If you require distinct print styles, consider adding a media attribute to a stylesheet link, like so:

<link rel="stylesheet" media="print" href="path/to/styles.css">

This alternative gives you complete control without excessive complexity.

FAQs on How to Print a Specific Div Without Disabling Other Content

Q: Can I print multiple divs using the same method?

A: Yes, you can adapt the function by modifying it to collect content from multiple divs or by creating a separate button for each div you wish to print.

Q: Will using visibility instead of display affect my layout?

A: Using visibility: hidden still maintains the layout of elements, unlike display: none, which removes elements from the layout during the print operation.
