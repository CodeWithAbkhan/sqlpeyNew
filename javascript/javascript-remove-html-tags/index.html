How to Remove HTML Tags from a String Using JavaScript?

When working with web content, you might encounter strings that contain embedded HTML markup. For various reasons, such as displaying plain text or preparing data for specific formats, you may need to strip these HTML tags, leaving only the textual content. This post delves into several reliable JavaScript techniques to achieve this, highlighting their strengths and potential considerations.

Solution 1: Leveraging the Browser’s DOM Creation

One of the most straightforward and robust methods involves utilizing the browser’s built-in capabilities to parse HTML. By creating a temporary DIV element, you can inject the HTML string into its innerHTML property. The browser then handles the parsing, and you can extract the plain text using textContent or innerText.

function stripHtml(htmlContent) {
   let tempElement = document.createElement("DIV");
   tempElement.innerHTML = htmlContent;
   return tempElement.textContent || tempElement.innerText || "";
}

Consideration: As noted by users, while effective, this approach should be used with caution if the HTML source is untrusted, as it can potentially execute inline JavaScript. For such scenarios, the DOMParser method (covered in Solution 3) offers enhanced security.

Solution 2: Regular Expression for Tag Removal

A common approach involves using regular expressions to find and replace HTML tags. This method can be concise, but it requires careful crafting of the regex to handle various tag structures and potential edge cases.

let myString = "This is a <b>bold</b> and <i>italic</i> string.";
let plainText = myString.replace(/<[^>]*>/gm, '');
// Output: This is a bold and italic string.

Note: Simple regex replacements might not cover all HTML complexities or security concerns, especially with malformed HTML or scripts.

Solution 3: Using DOMParser for Secure Parsing

The DOMParser API provides a secure and reliable way to parse HTML strings, even those containing potentially harmful scripts. It creates a new HTML document from the string, and you can then access the body.textContent to get the cleaned text.

function stripWithDomParser(htmlString) {
   let doc = new DOMParser().parseFromString(htmlString, 'text/html');
   return doc.body.textContent || "";
}

// Example with a potentially risky script
let riskyHtml = "<img onerror='alert(\"XSS attempt!\")' src='invalid'>";
console.log(stripWithDomParser(riskyHtml)); // Outputs: "" (or text if present)

// Example with an image tag that doesn't load
let htmlWithImage = "Just text <img src='https://example.com/image.jpg'>";
console.log(stripWithDomParser(htmlWithImage)); // Outputs: "Just text "

This method is generally preferred for its security and ability to handle various HTML structures without executing scripts. It also avoids downloading resources like images.

Solution 4: jQuery’s .text() Method

If you are already using jQuery in your project, its .text() method offers a convenient way to extract text from HTML.

// Assuming jQuery is loaded
let htmlString = "<p>Some <strong>important</strong> text.</p>";
let plainText = $(htmlString).text();
// Output: Some important text.

Enhancement for Non-HTML Strings: If your string might not always contain HTML, wrapping it in a temporary element ensures .text() works correctly.

// To handle strings that might not start with HTML tags
let potentiallyMixedString = "Just text";
let cleanedText = $('<p>' + potentiallyMixedString + '</p>').text();
// Output: Just text

Security Advisory: Be cautious when using this method with untrusted HTML content, as it might execute scripts in certain environments.

Solution 5: Preserving Links with Regex Adjustments

For scenarios where you need to remove most HTML but retain hyperlinks, you can modify regular expressions to target specific tags like anchor (<a>) tags.

let htmlWithLinks = "Visit <a href='http://example.com'>Example</a> for more info.";
let cleanedHtml = htmlWithLinks.replace(/<a.*href="(.*?)".*?>(.*?)<\/a>/gi, '$2 ($1)');
cleanedHtml = cleanedHtml.replace(/<[^>]*>/g, ''); // Remove remaining tags
// Output: Visit Example (http://example.com) for more info.

This approach involves a sequence of regex operations to first process links and then strip any remaining tags.

Solution 6: Advanced Regex for Specific Needs

More complex regular expressions can be crafted to handle a wider range of HTML structures, including replacing specific tags with newlines for better readability in plain text output.

let complexHtml = "<h1>Title</h1><p>Paragraph with<br>a line break.</p>";
let processedText = complexHtml.replace(/<br\s*\/?>/gi, '\n'); // Replace <br> with newline
processedText = processedText.replace(/<p.*?>/gi, '\n'); // Replace <p> with newline
processedText = processedText.replace(/<[^>]*>/g, ''); // Remove all other tags
// Output:
// Title
// Paragraph with
// a line break.

Solution 7: Recursive DOM Parsing for Robustness

To address potential security vulnerabilities where simple DOM parsing might miss nested malicious content, a recursive approach can be employed. This involves re-parsing the text if any HTML-like patterns are detected after an initial stripping.

function robustStripHtml(htmlString) {
  const parsedHTML = new DOMParser().parseFromString(htmlString, "text/html");
  const text = parsedHTML.body.textContent;

  // Check if any tags remain after initial parsing
  if (/(&lt;([^>]+)&gt;)/gi.test(text)) {
    return robustStripHtml(text); // Recursively call if tags are still present
  }

  return text || "";
}

Solution 8: Utilizing HTML Parser Libraries

For highly robust and secure HTML sanitization, consider using dedicated JavaScript libraries like sanitize-html. These libraries are specifically designed to handle complex HTML structures and security concerns effectively.

// Example using sanitize-html (install via npm: npm install sanitize-html)
import sanitizer from 'sanitize-html';

const textSanitizer = (textWithHTML) =>
  sanitizer(textWithHTML, {
    allowedTags: [], // Set to an empty array to disallow all tags
  });

let htmlInput = "<p>Sanitized text <script>alert('bad')</script></p>";
console.log(textSanitizer(htmlInput)); // Output: Sanitized text

Solution 9: Node.js Environment Solutions

If you are working in a Node.js environment, you can leverage libraries like htmlparser2 for parsing HTML and extracting text.

// Example using htmlparser2 (install via npm: npm install htmlparser2)
const htmlparser = require('htmlparser2');

const htmlContent = '<p>This is <b>bold</b> and <i>italic</i>.</p>';
const textNodes = [];

const parser = new htmlparser.Parser({
    ontext: function(text){
        textNodes.push(text);
    }
}, {decodeEntities: true});

parser.write(htmlContent);
parser.end();

const plainText = textNodes.join('');
// Output: This is bold and italic.

Solution 10: Regex for General Tag Stripping

A more general regex pattern can strip most common HTML tags efficiently.

let sampleHtml = "<div>Some <span>content</span> here.</div>";
let cleanString = sampleHtml.replace(/<\/?([a-z][a-z0-9]*)\b[^>]*>/ig, "");
// Output: Some content here.

This regex targets opening and closing tags, including those with attributes.

FAQs on JavaScript: Remove HTML Tags from String

Q: What is the most secure way to remove HTML tags in JavaScript

ANS: Using the DOMParser API (as shown in Solution 3) or a dedicated sanitization library like sanitize-html (Solution 8) are generally considered the most secure methods, as they are designed to handle malicious inputs safely.

Q: Can I remove HTML tags without using the browser's DOM

ANS: Yes, if you are not in a browser environment (e.g., Node.js), you can use libraries like htmlparser2 (Solution 9) or npm packages such as striptags (Solution 29).

Q: How do I keep links while stripping other HTML tags

ANS: You can achieve this by using carefully crafted regular expressions that specifically target and preserve anchor (<a>) tags while removing others, as demonstrated in Solution 5.

Q: What are the risks of using simple regex to strip HTML

ANS: Simple regular expressions might fail to account for malformed HTML or script injection attempts (like XSS), potentially leading to security vulnerabilities. They may also not correctly handle complex tag structures or attributes.

Q: Is the jQuery .text() method safe for untrusted HTML

ANS: While convenient, the jQuery .text() method can potentially execute scripts in certain contexts if the HTML is not trusted. For security-sensitive applications, alternative methods like DOMParser are recommended.
