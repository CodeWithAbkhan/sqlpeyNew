How to Access Filtered ngRepeat Results in AngularJS?

If you’re working on an AngularJS application and are utilizing the ng-repeat directive along with filters, you may find yourself in need of accessing the filtered result set in your controller logic. This requirement typically arises when implementing features such as auto-complete functionality. Below, we will explore different methods to achieve this effectively.

The Challenge

Consider the scenario where you have the following setup:

<input id="queryInput" ng-model="query" type="text" size="30" placeholder="Enter query">
<ul>
  <li ng-repeat="item in items | orderBy:'order_prop' | filter:query | limitTo:4">{{item.name}}</li>
</ul>

Here, you have an input box for user input, and the ng-repeat directive is applied to render a list of items filtered based on the query. Your goal is to access the filtered results within your controller to perform further logic or actions.

Possible Solutions

Solution 1: Direct Assignment with ng-repeat

An effective way to capture the filtered result is by using a direct assignment within the ng-repeat. Here’s how:

<input ng-model="query">
<div ng-repeat="item in (filteredItems = (items | orderBy:'order_prop' | filter:query | limitTo:4))">
  {{item}}
</div>

By implementing this method, you can easily reference $scope.filteredItems in your controller, providing a seamless approach to manage your filtered list.

Solution 2: Using a Custom Filter with Context

If you’re interested in using a custom filter, you may consider the following solution that accommodates AngularJS versions beyond 1.3.0-beta.19:

yourModule.filter("as", function($parse) {
  return function(value, context, path) {
    return $parse(path).assign(context, value);
  };
});

Use it in the HTML as follows:

<input ng-model="query">
<div ng-repeat="item in items | orderBy:'order_prop' | filter:query | limitTo:4 | as:this:'filteredItems'">
  {{item}}
</div>

This assigns the filtered results directly to $scope.filteredItems, which can then be accessed in your controller.

Solution 3: Utilizing Parent Scope

Another method to access filtered items from a parent scope is shown below:

<li ng-repeat="doc in $parent.filteritems = (docs | filter:searchitems)">
  {{doc.name}}
</li>

In this scenario, filteritems from the parent scope holds the filtered results, allowing access within the controller while keeping the template clean.

Practical Example

For a practical illustration, here’s a way to integrate these approaches into a complete example:

<div ng-app="myApp" ng-controller="myController">
  <input ng-model="query" type="text" placeholder="Search...">
  <ul>
    <li ng-repeat="item in (filteredItems = (items | orderBy:'order_prop' | filter:query | limitTo:4))">
      {{item.name}}
    </li>
  </ul>
  
  <button ng-click="selectItem(filteredItems)">Select</button>
</div>

In your controller:

angular.module('myApp', []).controller('myController', function($scope) {
  $scope.items = [...]; // Your items array
  $scope.selectItem = function(filteredItems) {
    // Logic to handle selected item
  };
});

Alternative Methods

While the above solutions are effective, you might explore additional approaches such as using third-party libraries for autocomplete functionalities or custom directive creation for more complex interactions.

FAQs on How to Access Filtered ngRepeat Results in AngularJS?

Q: How can I access filtered ng-repeat results in AngularJS?

A: You can access filtered ng-repeat results by assigning the filtered output to a scope variable within the ng-repeat statement, such as using (filteredItems = (items | filter:query)).

Q: What is the role of 'as' in ng-repeat?

A: The ‘as’ syntax in ng-repeat allows you to assign the filtered or repeated items to a specific scope variable, making them easily accessible in your controller logic.
