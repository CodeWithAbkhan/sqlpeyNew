“JavaScript: Grouping and Nesting Arrays Based on Multiple Object Keys”

How can one transform a flat array of objects into a deeply nested structure, grouping items based sequentially on multiple property values (like grouping by ’tab’ then by ‘section’)? This common data transformation task requires careful iteration and structure building. We examine two primary approaches: one leveraging the utility library Lodash and another utilizing pure JavaScript object manipulation.

Solution 1: Utilizing Lodash for Sequential Grouping and Mapping

A concise method involves chaining _.groupBy and _.map from the Lodash library. This solution is highly readable for those familiar with functional programming patterns in JavaScript.

Consider the initial dataset:

const inputData = [
  {
    tab: 'Results',
    section: '2017',
    title: 'Full year Results',
    description: 'Analysis for the complete fiscal year.',
  },
    {
    tab: 'Results',
    section: '2017',
    title: 'Half year Results',
    description: 'Mid-year performance overview.',
  },
    {
    tab: 'Reports',
    section: 'Marketing',
    title: 'First Report',
    description: 'Quarterly marketing outreach summary.',
  }
];

We can define a generalized function to handle the grouping and restructuring across levels:

/**
 * Groups an array by an item key, then optionally maps the grouped results 
 * using a recursive predicate function for deeper nesting.
 * 
 * @param {Array<Object>} items - The source array.
 * @param {string} itemKey - The key to group by at the current level.
 * @param {string} childKey - The key name for the array holding nested items.
 * @param {Function|null} predicate - A function applied to the grouped objects 
 *                                    to handle the next level of grouping.
 * @returns {Array<Object>} The structured array.
 */
function groupAndMap(items, itemKey, childKey, predicate) {
    // First, group the items based on itemKey
    const grouped = _.groupBy(items, itemKey);
    
    // Then, map over the groups to create the desired output structure
    return _.map(grouped, (objGroup, keyValue) => {
        const structure = {
            [itemKey]: keyValue,
        };
        
        // If a predicate exists, apply it (e.g., for the next grouping level)
        if (predicate) {
            structure[childKey] = predicate(objGroup);
        } else {
            // Otherwise, use the raw group as the final child elements
            structure[childKey] = objGroup; 
        }
        
        return structure;
    });
}

To achieve the desired two-level structure (grouped by tab, and within each tab, grouped by section), we nest the function calls:

// Level 1: Group by "tab", structure its children array as "sections"
// Level 2 (Predicate): For each 'tab' group, run groupAndMap again, 
// grouping by "section", structuring its children array as "items".
const finalStructure = groupAndMap(
    inputData, 
    "tab", 
    "sections", 
    arr => groupAndMap(arr, "section", "items") // Recursive call for the second level
);

console.log(JSON.stringify(finalStructure, null, 2));

This will produce an array where each element represents a unique tab, containing a sections array, and each section object contains the items array belonging to that specific section and tab. Accessing this utility requires including the Lodash library, for instance, via CDN:

Solution 2: Pure JavaScript Implementation Without External Libraries

For environments where external dependencies are restricted, this transformation can be achieved using native JavaScript iteration and object references. This method builds an intermediary structure to maintain pointers to the correct arrays as it traverses the input items.

We define the mapping between the current grouping key and the resulting child array’s name:

const inputData = [
  { tab: 'Results', section: '2017', title: 'Full year Results', description: 'Analysis for the complete fiscal year.' }, 
  { tab: 'Results', section: '2017', title: 'Half year Results', description: 'Mid-year performance overview.' }, 
  { tab: 'Reports', section: 'Marketing', title: 'First Report', description: 'Quarterly marketing outreach summary.' }
];

// Defines the sequence of keys to group by and the desired property name for the resulting child array
const keyMap = { tab: 'sections', section: 'items' }; 
const resultContainer = [];
// temp object holds references (pointers) to the specific child arrays being built
const tempStructure = { _: resultContainer }; 

inputData.forEach(function (itemObject) {
    // Use reduce to traverse down the hierarchy defined by keyMap
    const referenceLevel = Object.keys(keyMap).reduce(function (currentLevel, groupKey) {
        const childArrayName = keyMap[groupKey];
        const groupValue = itemObject[groupKey];

        // Check if the next node/group already exists at this level
        if (!currentLevel[groupValue]) {
            // If not found, create the new node structure
            const newChildArrayRef = { _: [] };
            currentLevel[groupValue] = newChildArrayRef;
            
            // Push the new parent structure into the current level's array of results
            currentLevel._.push({ 
                [groupKey]: groupValue, 
                [childArrayName]: newChildArrayRef._ 
            });
        }
        
        // Return the reference to the next level down for the next iteration
        return currentLevel[groupValue];
    }, tempStructure); // Start traversal from the root reference

    // After traversing all grouping levels, push the final payload into the innermost array
    referenceLevel._.push({ 
        title: itemObject.title, 
        description: itemObject.description 
    });
});

console.log(JSON.stringify(resultContainer, null, 2));

This pure JavaScript implementation achieves the same hierarchical grouping without external dependencies by meticulously managing object references (tempStructure._ acts as the pointer storage for each level).

FAQs on JavaScript Grouping Nesting Arrays

Q: What is the primary difference between Solution 1 and Solution 2

ANS: Solution 1 relies on the Lodash library for concise functional iteration (_.map and _.groupBy), making the code shorter. Solution 2 uses native JavaScript forEach and reduce to build complex object references manually, avoiding external dependencies.

Q: Which key is processed first in the sequential grouping

ANS: In both examples, the key listed first in the grouping logic (i.e., ’tab’ in the Lodash example, or the first key encountered in Object.keys(keyMap) that starts the reduce traversal in Solution 2) dictates the top level of the resulting structure.

Q: Can Solution 1 handle more than two levels of nesting

ANS: Yes, Solution 1 is designed for arbitrary depth through the use of the predicate argument, which recursively calls groupAndMap for subsequent levels.
