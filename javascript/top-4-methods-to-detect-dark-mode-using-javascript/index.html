Detecting Dark Mode in JavaScript: Top 4 Methods

As our digital environments evolve, both Windows and macOS now support dark mode, allowing users to choose their preferred visual style. If you’re looking to implement this feature in your web applications, particularly when working with the Stripe Elements API , you might wonder: how can I effectively determine the OS’s preferred color scheme using JavaScript?

In this guide, we will explore four effective methods for detecting dark mode, leveraging modern JavaScript capabilities alongside practical code examples.

Method 1: Using matchMedia

The preferred way to detect dark mode in JavaScript is with the matchMedia method. Here’s a straightforward example:

if (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
    // Execute code for dark mode
    console.log("The user prefers dark mode.");
}

To be responsive to changes in the user’s preference, you can listen for updates using:

window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', event => {
    const newColorScheme = event.matches ? "dark" : "light";
    console.log(`Color scheme changed to: ${newColorScheme}`);
});

Method 2: Checking Media Queries Directly

Another effective method involves directly checking CSS media queries through JavaScript. You can check if the dark mode media query applies as follows:

if (window.matchMedia) {
    if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
        console.log("Dark mode activated.");
    } else {
        console.log("Light mode activated.");
    }
} else {
    console.log("Media queries are not supported.");
}

To simplify this logic, use a utility function:

const isDarkModePreferred = () => window.matchMedia('(prefers-color-scheme:dark)').matches ?? false;

console.log(`Dark mode preferred: ${isDarkModePreferred()}`);

This approach establishes a concise way to determine the user’s color scheme preference.

Method 3: Dynamic Color Scheme Updates

You might also want to dynamically adjust your application’s color scheme based on the user’s settings. The following example demonstrates how to manage this:

function setColorScheme(scheme) {
    switch (scheme) {
        case 'dark':
            console.log('Setting dark colors');
            // Apply dark color styles
            break;
        case 'light':
            console.log('Setting light colors');
            // Apply light color styles
            break;
        default:
            console.log('Default scheme applied');
            break;
    }
}

function getPreferredColorScheme() {
    if (window.matchMedia) {
        return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    }
    return 'light'; // Default
}

function updateColorScheme() {
    setColorScheme(getPreferredColorScheme());
}

if (window.matchMedia) {
    const colorSchemeQuery = window.matchMedia('(prefers-color-scheme: dark)');
    colorSchemeQuery.addEventListener('change', updateColorScheme);
}
updateColorScheme();

This code automatically adjusts your app’s style when the user’s color scheme preference changes, enhancing user experience.

Method 4: Alternative Listener Approach

For legacy compatibility, especially with iOS devices, consider using addListener, which may provide better results in some scenarios:

window.matchMedia('(prefers-color-scheme: dark)').addListener(e => {
    console.log(`Color scheme switched to: ${e.matches ? "dark" : "light"}`);
});

Practical Example

Here’s a practical integration with the Stripe Elements API to alter styles based on the detected theme:

const applyStripeElementStyles = (isDark) => {
    const stripeElementStyles = {
        base: {
            color: isDark ? '#FFFFFF' : '#000000',
            background: isDark ? '#000000' : '#FFFFFF',
            fontFamily: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif`,
            fontSize: '18px',
            '::placeholder': {
                color: isDark ? '#A0A0A0' : '#606060',
            },
        }
    };
    // Apply styles to Stripe Elements here
};

// Detect theme
const isDarkMode = window.matchMedia('(prefers-color-scheme: dark)').matches;
applyStripeElementStyles(isDarkMode);

This ensures that your Stripe elements adapt seamlessly to the user’s color scheme preference.

FAQs on Top 4 Methods to Detect Dark Mode Using JavaScript

Q: How can I detect the user’s color scheme preference?

A: You can use the window.matchMedia method to check for (prefers-color-scheme: dark) in JavaScript.

Q: Is there a cross-browser way to detect dark mode?

A: The matchMedia API is widely supported in modern browsers, making it a reliable option.

Q: Can I change the styles dynamically based on dark mode detection?

A: Yes, you can listen for changes in the preferred color scheme and apply styles accordingly using event listeners.
