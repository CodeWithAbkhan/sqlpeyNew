“JavaScript Natural Sort Order: Solutions for String and Object Arrays”

Achieving a “natural” or “alphanumeric” sort order in JavaScript, where numbers within strings are treated numerically (e.g., “file10.txt” comes after “file2.txt”), can be accomplished through several effective methods. This is particularly useful when dealing with lists of files, version numbers, or any data where numerical sequence is important for ordering.

Implementing Natural Sort Order in JavaScript

Here are several approaches to achieve natural sorting in JavaScript, covering both simple string arrays and more complex arrays of objects.

Solution 1: Using String.prototype.localeCompare with Numeric Option

Modern browsers provide a straightforward way to handle natural sorting using localeCompare with specific options. By setting numeric: true, the method intelligently recognizes numbers within strings. For case-insensitive sorting, sensitivity: 'base' can be used.

This approach is compatible with Chrome, Firefox, and Internet Explorer 11.

Example:

// Compares '10' and '2', returning 1 (meaning '10' comes after '2')
'10'.localeCompare('2', undefined, { numeric: true, sensitivity: 'base' });

For improved performance when sorting large arrays, creating an Intl.Collator object and using its compare method is recommended. This pre-configures the sorting logic.

Performance-Oriented Example:

const collator = new Intl.Collator(undefined, { numeric: true, sensitivity: 'base' });
const myArray = ['1_Document', '11_Document', '2_Document'];

console.log(myArray.sort(collator.compare));
// Expected Output: ['1_Document', '2_Document', '11_Document']

Solution 2: Sorting Arrays of Objects by a Specific Key

When working with arrays of objects, you can apply the localeCompare logic within the sort function to order based on a specific object property.

Example:

let myArrayObjects = [
  { "id": 1, "name": "1 example" },
  { "id": 2, "name": "100 example" },
  { "id": 3, "name": "12 example" },
  { "id": 4, "name": "5 example" },
];

myArrayObjects.sort(function(a, b) {
  return a.name.localeCompare(b.name, undefined, {
    numeric: true,
    sensitivity: 'base'
  });
});

console.log(myArrayObjects);
/* Expected Output:
[
  { id: 1, name: '1 example' },
  { id: 3, name: '12 example' },
  { id: 2, name: '100 example' },
  { id: 4, name: '5 example' }
]
*/

Solution 3: Custom Natural Sort Function

For more control or compatibility with older environments, a custom sorting function can be implemented. This approach typically involves parsing numbers from strings and comparing them numerically.

The following naturalSorter function breaks strings into comparable parts (numbers and non-numbers) and compares them sequentially.

function naturalSorter(as, bs){
    var a, b, a1, b1, i= 0, n, L,
    rx=/(\.\d+)|(\d+(\.\d+)?)|([^\d.]+)|(\.\D+)|(\.$)/g;
    if(as === bs) return 0;
    a = as.toLowerCase().match(rx);
    b = bs.toLowerCase().match(rx);
    L = a.length;
    while(i < L){
        if(!b[i]) return 1;
        a1 = a[i];
        b1 = b[i++];
        if(a1 !== b1){
            n = a1 - b1;
            if(!isNaN(n)) return n;
            return a1 > b1 ? 1 : -1;
        }
    }
    return b[i] ? -1 : 0;
}

To optimize performance for sorting large arrays, preprocess the array by converting strings to lowercase and applying the regular expression once, rather than repeatedly within the sort comparison.

The naturalSort function below demonstrates this optimization by preparing the array before sorting.

function naturalSort(ar, index){
    var L = ar.length, i, who, next,
    isi = typeof index == 'number',
    rx = /(\.\d+)|(\d+(\.\d+)?)|([^\d.]+)|(\.(\D+|$))/g;

    function nSort(aa, bb){
        var a = aa[0], b = bb[0], a1, b1, i = 0, n, L = a.length;
        while(i < L){
            if(!b[i]) return 1;
            a1 = a[i];
            b1 = b[i++];
            if(a1 !== b1){
                n = a1 - b1;
                if(!isNaN(n)) return n;
                return a1 > b1 ? 1 : -1;
            }
        }
        return b[i] != undefined ? -1 : 0;
    }

    for(i = 0; i < L; i++){
        who = ar[i];
        next = isi ? ar[i][index] || '' : who;
        ar[i] = [String(next).toLowerCase().match(rx), who];
    }
    ar.sort(nSort);
    for(i = 0; i < L; i++){
        ar[i] = ar[i][1];
    }
}

Solution 4: Zero-Padding Numbers

Another effective technique involves padding numeric parts of strings with leading zeros to ensure correct numerical ordering. A function can be created to replace all number sequences with zero-padded versions.

Example:

const list = [
    "123asd",
    "19asd",
    "12345asd",
    "asd123",
    "asd12"
];

// Function to pad numbers within a string
const naturalExpand = str => str.replace(/\d+/g, n => n.padStart(8, "0"));

// Comparator function
const naturalCompare = (a, b) => naturalExpand(a).localeCompare(naturalExpand(b));

console.log(list.map(naturalExpand).sort()); // Intermediate padded values
console.log(list.sort(naturalCompare));   // Naturally sorted result
/*
Intermediate values:
[
  "00000019asd",
  "00000123asd",
  "00012345asd",
  "asd00000012",
  "asd00000123"
]

Naturally sorted result:
[
  "19asd",
  "123asd",
  "12345asd",
  "asd12",
  "asd123"
]
*/

Solution 5: Utilizing the natural-orderby Library

For a robust and feature-rich solution, consider using a dedicated library like natural-orderby. This library simplifies natural sorting and can handle various data types and sorting criteria with minimal code.

import { orderBy } from 'natural-orderby';

const unordered = [
  '123asd',
  '19asd',
  '12345asd',
  'asd123',
  'asd12'
];

const ordered = orderBy(unordered);

console.log(ordered);
/*
Output:
[
  '19asd',
  '123asd',
  '12345asd',
  'asd12',
  'asd123'
]
*/

The natural-orderby library also supports sorting arrays of objects by specific keys and can automatically identify and sort currencies, dates, and more. It’s also remarkably lightweight.

Solution 6: Extending Array.prototype for Object Sorting

You can extend the Array.prototype to create a reusable sorting method specifically for arrays of objects, simplifying the process. This custom method parses strings into sortable numeric and alphabetic segments.

// Usage: unsortedArrayOfObjects.alphaNumObjectSort("name");
// Test Case: var unsortedArrayOfObjects = [{name: "a1"}, {name: "a2"}, {name: "a3"}, {name: "a10"}, {name: "a5"}, {name: "a13"}, {name: "a20"}, {name: "a8"}, {name: "8b7uaf5q11"}];
// Sorted: [{name: "8b7uaf5q11"}, {name: "a1"}, {name: "a2"}, {name: "a3"}, {name: "a5"}, {name: "a8"}, {name: "a10"}, {name: "a13"}, {name: "a20"}]

Array.prototype.alphaNumObjectSort = function(attribute, caseInsensitive) {
  for (var z = 0, t; t = this[z]; z++) {
    this[z].sortArray = new Array();
    var x = 0, y = -1, n = 0, i, j;

    while (i = (j = t[attribute].charAt(x++)).charCodeAt(0)) {
      var m = (i == 46 || (i >=48 && i <=57)); // Check for '.' or digits
      if (m !== n) {
        this[z].sortArray[++y] = "";
        n = m;
      }
      this[z].sortArray[y] += j;
    }
  }

  this.sort(function(a, b) {
    for (var x = 0, aa, bb; (aa = a.sortArray[x]) && (bb = b.sortArray[x]); x++) {
      if (caseInsensitive) {
        aa = aa.toLowerCase();
        bb = bb.toLowerCase();
      }
      if (aa !== bb) {
        var c = Number(aa), d = Number(bb);
        if (c == aa && d == bb) { // If both are numbers
          return c - d;
        } else {
          return (aa > bb) ? 1 : -1; // Lexicographical comparison
        }
      }
    }
    return a.sortArray.length - b.sortArray.length; // If one array is a prefix of another
  });

  // Clean up the temporary sortArray property
  for (var z = 0; z < this.length; z++) {
    delete this[z]["sortArray"];
  }
}

Solution 7: Multi-Field Sorting with Custom Comparator

For scenarios requiring sorting by multiple fields with different directions (ascending/descending), a flexible custom comparator function can be created. This approach leverages Intl.Collator for efficient comparisons.

const orderBy = orders => (a, b) => {
    const sortDirection = { asc: 1, desc: -1 };
    const sortCollator = new Intl.Collator(undefined, { numeric: true, sensitivity: 'base' });
    const totalOrders = orders.length;

    for (let index = 0; index < totalOrders; index++) {
        const { property, direction = 'desc' } = orders[index];
        const directionInt = sortDirection[direction];
        const compare = sortCollator.compare(a[property], b[property]);

        if (compare < 0) return directionInt;
        if (compare > 0) return -directionInt;
    }

    return 0; // Objects are equal for sorting purposes
};

// Example:
const unsorted = [
    { name: 'Bananas', count: 1 },
    { name: 'Apples', count: 3 },
    { name: 'Bananas', count: 3 },
    { name: 'bananas', count: 2 },
];

// Sort by name (ascending) then by count (ascending)
const sorted = unsorted.sort(orderBy([{ property: 'name' }, { property: 'count', direction: 'asc' }]));

console.log(sorted);
/*
Output:
[
  { name: 'Apples', count: 3 },
  { name: 'Bananas', count: 1 },
  { name: 'Bananas', count: 3 },
  { name: 'bananas', count: 2 }
]
*/

These methods offer various ways to implement natural sorting in JavaScript, allowing you to choose the approach that best fits your project’s requirements for simplicity, performance, and feature set.

FAQs on JavaScript Natural Sort Order

Q: What is natural sorting in JavaScript

ANS: Natural sorting, also known as alphanumeric sorting, arranges strings containing numbers in a way that numbers are treated numerically. For instance, “file2.txt” comes before “file10.txt”, unlike a standard lexicographical sort where “file10.txt” would precede “file2.txt”.

Q: How does localeCompare help with natural sorting

ANS: The localeCompare method in JavaScript can perform natural sorting when provided with the option { numeric: true }. This tells the method to interpret numeric sequences within strings correctly for comparison.

Q: Can I sort arrays of objects naturally

ANS: Yes, you can sort arrays of objects naturally by applying the natural sorting logic within the sort method’s comparison function, targeting the specific string property you want to sort by.

Q: Are there libraries for natural sorting

ANS: Yes, libraries like natural-orderby provide robust and convenient solutions for natural sorting, handling various data types and complex sorting requirements efficiently.

Q: What is the benefit of using Intl Collator

ANS: Using Intl.Collator can offer performance advantages for large datasets. By creating a collator instance with specific options like { numeric: true }, you pre-configure the sorting logic, potentially speeding up repeated comparisons.
