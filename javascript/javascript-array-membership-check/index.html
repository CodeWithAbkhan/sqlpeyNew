“JavaScript Array Membership Check: Native vs Polyfill Solutions”

How does one reliably determine if a specific object or value resides within a JavaScript array, particularly when accounting for varying browser environments and performance considerations?

Several approaches exist for verifying array membership, ranging from modern ES2016 features to custom implementations designed for broad compatibility.

Primary Modern Solution: Array.prototype.includes()

For environments supporting ECMAScript 2016 (ES7) or newer, the most direct method is utilizing the built-in includes() function.

const dataArray = [10, 'apple', { id: 1 }];
const targetValue = 'apple';

const isPresent = dataArray.includes(targetValue); // true

Backward Compatibility and Fallbacks

When targeting older environments, such as certain versions of Internet Explorer, native includes() may be unavailable. In these scenarios, developers often fall back to Array.prototype.indexOf().

Using indexOf() as a Substitute

The indexOf() method returns the first index at which a given element can be found in the array, or -1 if it is not present.

function checkWithIndexOf(arr, obj) {
    return (arr.indexOf(obj) !== -1);
}

const numbers = [50, 60, 70];
const exists = checkWithIndexOf(numbers, 60); // true
const missing = checkWithIndexOf(numbers, 99); // false

Implementing indexOf Polyfills for Legacy Support

If indexOf itself is not guaranteed (pre-ECMAScript 5), custom implementations, or polyfills, are necessary. These ensure basic functionality across very old browsers.

Mozilla’s ECMAScript Specification Compliant Polyfill for indexOf:

This implementation adheres closely to the formal specification, handling edge cases like NaN comparison and index conversion strictly.

if (!Array.prototype.indexOf) {
    Array.prototype.indexOf = function(searchElement /*, fromIndex */) {
        "use strict";
        if (this === void 0 || this === null) {
            throw new TypeError();
        }

        var t = Object(this);
        var len = t.length >>> 0;
        if (len === 0) {
            return -1;
        }

        var n = 0;
        if (arguments.length > 0) {
            n = Number(arguments[1]);
            if (n !== n) { // NaN check
                n = 0;
            } else if (n !== 0 && n !== (1 / 0) && n !== -(1 / 0)) {
                n = (n > 0 || -1) * Math.floor(Math.abs(n));
            }
        }

        if (n >= len) {
            return -1;
        }

        var k = n >= 0
            ? n
            : Math.max(len - Math.abs(n), 0);

        for (; k < len; k++) {
            if (k in t && t[k] === searchElement) {
                return k;
            }
        }
        return -1;
    };
}

Daniel James’s Simplified indexOf Polyfill:

A less verbose implementation focusing on common cases:

if (!Array.prototype.indexOf) {
    Array.prototype.indexOf = function (obj, fromIndex) {
        if (fromIndex == null) {
            fromIndex = 0;
        } else if (fromIndex < 0) {
            fromIndex = Math.max(0, this.length + fromIndex);
        }
        for (var i = fromIndex, j = this.length; i < j; i++) {
            if (this[i] === obj) {
                return i;
            }
        }
        return -1;
    };
}

Creating a Custom hasObject Function

If the requirement is specifically to return a boolean indicating presence without relying on indexOf, a custom iteration function can be created, perhaps named hasObject.

Array.prototype.hasObject = (
   !Array.indexOf ? function (o) {
     var l = this.length + 1;
     while (l -= 1) {
         if (this[l - 1] === o) {
             return true;
         }
     }
     return false;
   } : function (o) {
     return (this.indexOf(o) !== -1);
   }
);

// Example usage:
const mixedArray = [1, 'two', true];
const checkResult = mixedArray.hasObject('two'); // true

Leveraging jQuery Utilities

For projects already incorporating the jQuery library, $.inArray() provides a familiar utility function for this task. Note that $.inArray performs loose equality checks (==) internally unless careful comparisons are made.

// Example demonstrating how $.inArray handles type coercion if needed
const jQueryExampleArray = [ "8", "9", "10", 10 + "" ]; // ["8", "9", "10", "10"]
const jQueryCheck = $.inArray(5 + 5, jQueryExampleArray); // Checks for index of 10 (number or string)
// Result index is 2 (for string "10") if loose comparison matches.

Advanced Scenarios: Value Comparison vs. Reference

For checking if an array contains an object that is structurally identical but not the same reference, standard indexOf (which uses strict equality ===) fails. A custom implementation might be needed, potentially serializing objects for comparison.

Extending Array Prototype with Value-Based Check:

It is generally advised to avoid modifying built-in prototypes extensively due to potential conflicts. If this extension is done, using Object.defineProperty prevents enumerable pollution.

Object.defineProperty(Array.prototype, 'has', {
    value: function(o, flag) {
        if (flag === undefined) {
            // Default behavior: Strict reference check using indexOf
            return this.indexOf(o) !== -1;
        } else {
            // Value comparison for raw objects using JSON stringification
            for (var v in this) {
                if (JSON.stringify(this[v]) === JSON.stringify(o)) {
                    return true;
                }
            }
            return false;
        }
    },
    writable: false,
    enumerable: false
});

const objA = { data: 'test' };
const objB = { data: 'test' };

const refArray = [1, objA];
const valArray = [1, { data: 'test' }];

refArray.has(objB);      // false (different reference)
valArray.has(objB, true); // true (structural comparison if flag is set and objects match)

Optimization for Sorted Arrays: Binary Search

If the array is guaranteed to be sorted, iterating linearly (as indexOf and custom loops do) is inefficient. A binary search algorithm significantly improves performance from O(n) to O(log n).

The binary search logic involves repeatedly halving the search interval:

  1. Locate the middle element.
  2. Compare the target value with the middle element.
  3. Discard the half where the element cannot reside and repeat on the remaining half.

Conditional Loading Strategy

For robust applications, especially those supporting legacy browsers, detect feature availability before use. This balances performance gain from native methods with necessary compatibility.

var checkPresence;

if (typeof yourArray.indexOf !== 'undefined') {
    // Native or polyfilled indexOf is available - use it for speed
    checkPresence = function(arr, target) {
        return arr.indexOf(target) !== -1;
    };
} else {
    // Resort to custom, slower search for extremely old environments
    checkPresence = function(arr, target) {
        for(var i = -1, j = arr.length; ++i < j;) {
            if(arr[i] === target) return true;
        }
        return false;
    };
}

FAQs on JavaScript Array Membership Check

Q: What is the modern standard for checking array element existence

ANS: The modern standard, available since ECMAScript 2016, is the Array.prototype.includes() method.

Q: Why might indexOf return -1 when I expect a match

ANS: indexOf uses strict equality (===). If you search for the number 5 but the array contains the string "5", indexOf will return -1.

Q: Is binary search appropriate for all array membership checks

ANS: No, binary search provides significant performance gains only if the array data is already sorted. For unsorted arrays, linear iteration is required.
