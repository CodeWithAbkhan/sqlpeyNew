“Efficiently Extracting Object Properties in JavaScript”

Several methods exist, ranging from modern ES6 syntax to more traditional approaches. Each offers different trade-offs in terms of readability, performance, and flexibility. Let’s dive into these techniques.

Solution 1: Anonymous Function Destructuring with Property Shorthand

A concise method leverages an immediately invoked function expression (IIFE) combined with object destructuring and the property shorthand.

const originalObject = { propA: 1, propB: 2, propC: 3, propD: 4 };

// Destructure desired properties and immediately return them in a new object
const pickedProperties = (({ propA, propC }) => ({ propA, propC }))(originalObject);

console.log(pickedProperties); // Output: { propA: 1, propC: 3 }

This approach is elegant for its brevity. Philipp Kewisch elaborates that this is essentially an anonymous function called instantly. For expanded clarity, the same logic can be presented as:

const originalObject = { propA: 1, propB: 2, propC: 3, propD: 4 };

// Using a named function for destructuring
const extractSubset = ({ propA, propC }) => ({ propA, propC });

const pickedProperties1 = extractSubset(originalObject);
const pickedProperties2 = (function({ propA, propC }) { return { propA, propC }; })(originalObject);

console.log(pickedProperties1); // Output: { propA: 1, propC: 3 }
console.log(pickedProperties2); // Output: { propA: 1, propC: 3 }

Solution 2: Destructuring vs. Iterative Methods

A key distinction arises between destructuring and iterative methods like reduce. Destructuring requires a static list of keys and is inclusive by nature, meaning it will include undefined properties if they are specified in the destructuring pattern. Iterative methods offer more control, allowing for conditional inclusion or exclusion.

Consider an object with potentially non-alphanumeric keys:

const dataObject = { 'special-key': 10, regularKey: 20, anotherKey: 30 };

Destructuring Example (Inclusive):

Destructuring requires keys to be known beforehand and can be cumbersome with non-standard identifiers.

  • IIFE Destructuring:

    const subsetWithIIFE = (({ 'special-key': special, regularKey, missingKey }) => ({ 'special-key': special, regularKey, missingKey }))(dataObject);
console.log(subsetWithIIFE); // Output: { 'special-key': 10, regularKey: 20, missingKey: undefined }

  • Temporary Variables:

    const { 'special-key': special, regularKey, missingKey } = dataObject;
const subsetWithVariables = { 'special-key': special, regularKey, missingKey };
console.log(subsetWithVariables); // Output: { 'special-key': 10, regularKey: 20, missingKey: undefined }

    To prevent scope collisions, block-level scoping can be used.

Iterative Methods (More Control):

These methods are better suited when the list of keys is dynamic or when you need to strictly pick existing properties.

  • reduce (ES5):

    const desiredKeys = ['special-key', 'regularKey', 'nonExistentKey'];
const subsetReduceES5 = desiredKeys.reduce((accumulator, key) => {
  if (key in dataObject) { // Strict picking
    accumulator[key] = dataObject[key];
  }
  return accumulator;
}, {});
console.log(subsetReduceES5); // Output: { 'special-key': 10, regularKey: 20 }

    Removing the key in dataObject check makes this inclusive.

  • reduce (ES6):

    const desiredKeys = ['special-key', 'regularKey', 'nonExistentKey'];
const subsetReduceES6 = desiredKeys.filter(key => key in dataObject) // Strict picking
                                 .reduce((acc, key) => { acc[key] = dataObject[key]; return acc; }, {});
console.log(subsetReduceES6); // Output: { 'special-key': 10, regularKey: 20 }

  • Object.fromEntries (ES2019):

    const desiredKeys = ['special-key', 'regularKey', 'nonExistentKey'];
const subsetFromEntries = Object.fromEntries(
  desiredKeys
    .filter(key => key in dataObject) // Strict picking
    .map(key => [key, dataObject[key]])
);
console.log(subsetFromEntries); // Output: { 'special-key': 10, regularKey: 20 }

  • Omit (ES2019):

    To exclude specific properties:

    const keysToOmit = ['regularKey', 'anotherKey'];
const omittedSubset = Object.fromEntries(
  Object.entries(dataObject)
    .filter(([key]) => !keysToOmit.includes(key))
);
console.log(omittedSubset); // Output: { 'special-key': 10 }

Solution 3: Reusable Utility Functions

Creating reusable functions mimics the utility of libraries like Lodash.

// Function to pick specific properties
const pick = (obj, ...keys) => Object.fromEntries(
  keys
    .filter(key => key in obj) // Only pick existing keys
    .map(key => [key, obj[key]])
);

// Function for inclusive picking (includes undefined for missing keys)
const inclusivePick = (obj, ...keys) => Object.fromEntries(
  keys.map(key => [key, obj[key]])
);

// Function to omit specific properties
const omit = (obj, ...keys) => Object.fromEntries(
  Object.entries(obj)
    .filter(([key]) => !keys.includes(key))
);

const sampleObject = { id: 1, name: 'Alice', age: 30, city: 'New York' };

const picked = pick(sampleObject, 'name', 'city', 'country');
console.log(picked); // Output: { name: 'Alice', city: 'New York' }

const included = inclusivePick(sampleObject, 'name', 'email');
console.log(included); // Output: { name: 'Alice', email: undefined }

const omitted = omit(sampleObject, 'age', 'city');
console.log(omitted); // Output: { id: 1, name: 'Alice' }

TypeScript Variation:

For strongly typed environments, these functions can be enhanced with TypeScript generics.

const pickTS = <T extends {}, K extends keyof T>(obj: T, ...keys: K[]): Pick<T, K> => (
  Object.fromEntries(
    keys
      .filter(key => key in obj)
      .map(key => [key, obj[key]])
  ) as Pick<T, K>
);

const inclusivePickTS = <T extends {}, K extends (string | number | symbol)>(obj: T, ...keys: K[]): { [key in K]: key extends keyof T ? T[key] : undefined } => (
  Object.fromEntries(
    keys.map(key => [key, obj[key as unknown as keyof T]])
  ) as { [key in K]: key extends keyof T ? T[key] : undefined }
);

const omitTS = <T extends {}, K extends keyof T>(obj: T, ...keys: K[]): Omit<T, K> => (
  Object.fromEntries(
    Object.entries(obj)
      .filter(([key]) => !keys.includes(key as K))
  ) as Omit<T, K>
);

Solution 4: Lodash Integration

Libraries like Lodash provide robust utility functions for object manipulation, including _.pick and _.omit.

// Assuming Lodash is imported as _
// import _ from 'lodash';

const muppetData = {
  color: 'red',
  annoying: true,
  height: 'unknown',
  meta: { one: '1', two: '2' }
};

// Using _.pick to select specific properties
const selectedMuppet = _.pick(muppetData, ['color', 'height']);
console.log(selectedMuppet); // Output: { color: 'red', height: 'unknown' }

// Applying to an array of objects
const muppetArray = [
  { color: 'red', height: 'short' },
  { color: 'blue', height: 'medium' },
  { color: 'yellow', height: 'tall' }
];

const selectedMuppets = _.map(muppetArray, (muppet) => _.pick(muppet, 'color', 'height'));
console.log(selectedMuppets);
/*
Output:
[
  { color: 'red', height: 'short' },
  { color: 'blue', height: 'medium' },
  { color: 'yellow', height: 'tall' }
]
*/

Solution 5: Array reduce with Dynamic Keys

A common and flexible approach involves using Array.prototype.reduce with a list of keys to select.

const dynamicKeys = ['propX', 'propZ'];
const sourceObject = { propX: 100, propY: 200, propZ: 300 };

// Using reduce to build a new object with selected keys
const extractedSubset = dynamicKeys.reduce((accumulator, currentKey) => {
  // Check if the key exists in the source object
  if (currentKey in sourceObject) {
    accumulator[currentKey] = sourceObject[currentKey];
  }
  return accumulator;
}, {});

console.log(extractedSubset); // Output: { propX: 100, propZ: 300 }

This can be encapsulated into a reusable function for cleaner code:

const getSubset = (obj, ...keys) => keys.reduce((acc, key) => {
  acc[key] = obj[key];
  return acc;
}, {});

const sampleObj = { a: 1, b: 2, c: 3, d: 4 };
const subsetResult = getSubset(sampleObj, 'b', 'd');
console.log(subsetResult); // Output: { b: 2, d: 4 }

For cases where the key list is dynamic and needs to be passed as an array:

const keyList = ['color', 'height'];
const elmoData = {
  color: 'red',
  annoying: true,
  height: 'unknown',
  meta: { one: '1', two: '2' }
};

// Using reduce with an array of keys
const result = keyList.reduce((accumulator, key) => ({ ...accumulator, [key]: elmoData[key] }), {});
console.log(result); // Output: { color: 'red', height: 'unknown' }

Solution 6: Object Destructuring with Rest Properties

ES6’s rest syntax allows you to capture properties not explicitly destructured into a new object. This is useful for creating a “remaining” object.

const data = {
  id: 101,
  name: 'Gadget',
  type: 'Tool',
  version: '2.0'
};

// Destructure 'id' and 'type', collect the rest into 'otherProperties'
const { id, type, ...otherProperties } = data;

// Create a subset from the destructured properties
const subset = { id, type };

console.log(otherProperties); // Output: { name: 'Gadget', version: '2.0' }
console.log(subset);          // Output: { id: 101, type: 'Tool' }

Solution 7: Direct Property Assignment

For very simple cases, direct assignment is the most straightforward method.

const source = {
  color: 'red',
  height: 'unknown'
};

const subsetDirect = {
  color: source.color,
  height: source.height
};

console.log(subsetDirect); // Output: { color: 'red', height: 'unknown' }

Solution 8: TypeScript Schemas with Zod

If you are using TypeScript and a schema validation library like Zod, you can leverage its features for property extraction. Zod schemas can parse data and, by default, strip unknown properties.

import { z } from "zod";

// Define a schema for the data
const muppetSchema = z.object({
  color: z.string(),
  annoying: z.boolean(),
  height: z.string(),
  meta: z.object({ one: z.string(), two: z.string() }),
});

// Infer the TypeScript type from the schema
type MuppetType = z.infer<typeof muppetSchema>;

const elmoData: MuppetType = {
  color: "red",
  annoying: true,
  height: "unknown",
  meta: { one: "1", two: "2" },
};

// Create a new schema that picks specific properties
const subsetSchema = muppetSchema.pick({ color: true, height: true });

// Parsing the data with the subset schema automatically extracts the desired properties
const extracted = subsetSchema.parse(elmoData);
console.log(extracted); // Output: { color: 'red', height: 'unknown' }

Solution 9: Dynamic Destructuring with Proxies

A more advanced technique involves using JavaScript Proxies to track property access during destructuring, allowing for dynamic subset creation.

const targetObject = { a: 1, b: 2, c: 3, d: 4, e: 5 };

// A helper function to create dynamic subsets
const createDynamicSubset = (...keys) => {
  const subsetProxy = new Proxy({}, {
    get: (target, prop) => {
      if (keys.includes(prop)) {
        target[prop] = targetObject[prop]; // Capture the property value
      }
      return target[prop]; // Return captured or undefined
    }
  });

  // Destructure from the proxy to capture specific properties
  const { [keys[0]]: val1, [keys[1]]: val2 } = subsetProxy;

  // Return a new object containing only the captured properties
  return { [keys[0]]: val1, [keys[1]]: val2 };
};

const dynamicSubset = createDynamicSubset("b", "d");
console.log(dynamicSubset); // Output: { b: 2, d: 4 }

Solution 10: Object.assign with map

This method uses Object.assign combined with Array.prototype.map to create a new object with selected properties.

const pickProperties = (obj, keys) => Object.assign({}, ...keys.map(key => ({ [key]: obj[key] })));

const source = { prop1: 'A', prop2: 'B', prop3: 'C' };
const keysToPick = ['prop1', 'prop3', 'prop4'];

const result = pickProperties(source, keysToPick);
console.log(result); // Output: { prop1: 'A', prop3: 'C' }

Solution 11: jQuery Extension (for JavaScript contexts)

While jQuery is primarily for DOM manipulation, it can be extended to provide utility functions.

// Define a sliceMe function on jQuery's prototype or as a utility
jQuery.extend({
  sliceMe: function(obj, ...keys) {
    const subset = {};
    keys.forEach(key => {
      if (key in obj) {
        subset[key] = obj[key];
      }
    });
    return subset;
  }
});

const item = {
  color: 'red',
  size: 'medium',
  quantity: 10
};

const slicedItem = jQuery.sliceMe(item, 'color', 'quantity');
console.log(slicedItem); // Output: { color: 'red', quantity: 10 }

Solution 12: Comma Operator with Destructuring

An esoteric but functional approach uses the comma operator within a destructuring assignment.

const objToSlice = { a: 1, b: 2, c: 3 };

// Destructure 'a' and 'c', then use the comma operator to return a new object
const sliced = (({ a, c } = objToSlice)) && { a, c };

console.log(sliced); // Output: { a: 1, c: 3 }

This method, while compact, requires typing property names twice and the with statement is generally discouraged due to potential performance issues and difficulties in static analysis.

Solution 13: Object.prototype Augmentation

You can extend Object.prototype to add a pick method directly to all objects, though this is generally discouraged due to potential global scope pollution.

Object.prototype.pick = function(...args) {
   const obj = {};
   args.forEach(key => obj[key] = this[key]); // `this` refers to the object itself
   return obj;
};

const collection = { 0: "zero", 1: "one", 2: "two" };
const subsetCollection = collection.pick('1', '2');
console.log(subsetCollection); // Output: { '1': 'one', '2': 'two' }

For focused solutions without the overhead of larger utility libraries, dedicated packages like object-pick and object-omit are available via npm.

Solution 15: Object.assign with Object.seal

This is an unconventional method that involves assigning properties from a source to a “sealed” subset object. Object.seal prevents adding new properties but allows modification of existing ones.

let subsetTarget = { a: null, b: null };
const sourceData = { a: 1, b: 2, c: 3 };

try {
  // Seal the target object before assigning properties
  Object.assign(Object.seal(subsetTarget), sourceData);
} catch (e) {
  console.log('Assignment might fail if keys don\'t match precisely, but here it works');
}
console.log(subsetTarget); // Output: { a: 1, b: 2 }

FAQs on Extracting Object Properties in JavaScript

Q: What is the most concise way to pick properties in modern JavaScript

ANS: Object destructuring with an IIFE is often considered very concise: const picked = (({ propA, propC }) => ({ propA, propC }))(originalObject);

Q: How can I pick properties when the key names are dynamic

ANS: For dynamic keys, using Array.prototype.reduce combined with a list of keys is a flexible approach, e.g., keys.reduce((acc, key) => ({ ...acc, [key]: obj[key] }), {}).

Q: Can I exclude properties instead of picking them

ANS: Yes, you can use methods like Object.entries with filter and Object.fromEntries to iterate through object entries and exclude specific keys, or use libraries like Lodash with _.omit.

Q: Is there a way to pick properties that might not exist in the original object

ANS: Yes, methods like destructuring or Object.fromEntries with map will include undefined for properties that are not found in the original object if you specify them. Be mindful of this inclusive behavior.

Q: What are the performance differences between destructuring and reduce

ANS: For a fixed, small set of known properties, destructuring can be very performant. For dynamic keys or large numbers of properties, reduce or Object.fromEntries might offer better scalability or readability depending on the specific implementation. Benchmarking is recommended for critical performance scenarios.
