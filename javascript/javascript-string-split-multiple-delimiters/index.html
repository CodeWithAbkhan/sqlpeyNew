“JavaScript String Splitting with Multiple Delimiters: A Deep Dive”

When working with strings in JavaScript, a frequent requirement is to break a single string into an array of substrings based on specific separator characters. While the standard String.prototype.split() method is excellent for single delimiters, handling multiple, varied separators can become complex. This exploration delves into various strategies to achieve this, offering practical code examples and alternative approaches.

Core Concepts and Challenges

The primary challenge lies in the split() method’s behavior. When provided with a string, it splits by that literal string. When provided with a regular expression, it splits by patterns defined within that expression. Effectively managing multiple, potentially complex delimiters necessitates a careful selection of approach.

Methodologies for Multi-Delimiter Splitting

Several methods have been proposed and utilized to tackle this common programming task:

Solution 1: Regular Expressions with Character Classes

A common and often concise method involves using regular expressions with character classes. By defining all desired delimiters within square brackets [], you can create a pattern that matches any of them.

Consider splitting a string by spaces, commas, and periods:

const text = "Hello, awesome world! This is a test.";
const words = text.split(/[ ,!.?]+/);
console.log(words);
// Output: ["Hello", "awesome", "world", "This", "is", "a", "test"]

This regex /[ ,!.?]+/ matches one or more occurrences of space, comma, period, exclamation mark, or question mark.

To extract the last element after splitting:

const bits = "Hello awesome, world!".split(/[\s,]+/);
const lastBit = bits[bits.length - 1];
console.log(lastBit);
// Output: "world!"

const noMatchBits = "Hello awesome, world!".split(/foo/);
const lastNoMatch = noMatchBits[noMatchBits.length - 1];
console.log(lastNoMatch);
// Output: "Hello awesome, world!"

Solution 2: Regex with Non-Capturing Groups for Consecutive Delimiters

When you have multiple delimiters that might appear consecutively, and you want to treat them as a single separator, non-capturing groups (?:...) are invaluable.

const data = "1, 2, , 3";
const cleanData = data.split(/(?:,| )+/);
console.log(cleanData);
// Output: ["1", "2", "3"]

This approach ensures that sequences like , are correctly handled as a single splitting point.

Solution 3: Iterative Split and Join

A more procedural approach involves chaining split() and join() operations. You can split by one delimiter, join the resulting array with a common character (like a comma), and then split by the next delimiter.

const inputString = "a=b,c:d";
const resultArray = inputString.split('=').join(',').split(':').join(',').split(',');
console.log(resultArray);
// Output: ["a", "b", "c", "d"]

This can be encapsulated into a reusable function:

function splitMulti(str, tokens){
    const tempChar = 't3mp'; // A temporary character unlikely to be in the string
    for(let i = 1; i < tokens.length; i++){
        str = str.split(tokens[i]).join(tempChar);
    }
    str = str.split(tempChar);
    return str;
}

console.log(splitMulti('a=b,c:d', ['=', ',', ':']));
// Output: ["a", "b", "c", "d"]

Solution 4: Regex with Expanded Character Sets

For a broader range of separators, you can expand the character class in your regex.

const textToSplit = "This is some text; with different, separators! And numbers 123.";
// Splits by space, semicolon, comma, exclamation, question mark, apostrophe, hyphen, and newline
const wordsArray = textToSplit.split(/[ .:;?!~,`"&|()<>{}[\\]\r\n/\\]+/);
console.log(wordsArray);
// Output: ["This", "is", "some", "text", "with", "different", "separators", "And", "numbers", "123"]

Note that apostrophes and hyphens within the set are preserved as part of potential words.

Solution 5: String Replacement for Consolidation

Another tactic is to replace all desired separators with a single, consistent separator before performing a final split.

const messyString = "dasdnk asd, (naks) :d skldma";
// Replace parentheses, commas with spaces, then split by spaces
const cleanedArray = messyString.replace('(', ' ').replace(')', ' ').replace(',', ' ').split(' ');
console.log(cleanedArray);
// Output: ["dasdnk", "asd", "", "naks", ":d", "skldma"]

This method might introduce empty strings if separators are adjacent or if the replacement results in multiple spaces.

// A generalized function:
function splitByMany(delimiters, string) {
  let targetDelimiter = delimiters[0]; // Use the first delimiter as the target
  for (let i = 1; i < delimiters.length; i++) {
    string = string.replace(new RegExp(delimiters[i], 'g'), targetDelimiter);
  }
  return string.split(targetDelimiter);
}

Solution 8: Recursive Traversal with Multiple Splits

For a more intricate approach, a recursive algorithm can be employed to handle a list of delimiters.

function splitString(string, splitters) {
    let list = [string];
    for(let i = 0; i < splitters.length; i++) {
        traverseList(list, splitters[i], 0);
    }
    return flatten(list);
}

function traverseList(list, splitter, index) {
    if(list[index]) {
        // Check if the current item is a string and needs splitting
        if(list[index].constructor === String && list[index] !== list[index].split(splitter)) {
            list[index] = list[index].split(splitter);
        }
        // If the item is now an array, traverse it
        if(list[index].constructor === Array) {
            traverseList(list[index], splitter, 0);
        }
        // Move to the next item in the current list
        if(list.constructor === Array) {
            traverseList(list, splitter, index + 1);
        }
    }
}

function flatten(arr) {
    return arr.reduce((acc, val) => {
        return acc.concat(val.constructor === Array ? flatten(val) : val);
    }, []);
}

const mixedSeparators = "people and_other/things";

Solution 10: Regex with Word Boundaries

For splitting by specific words, using word boundaries \b with | (OR) in a regex is effective.

const textWithWords = 'and this is some kind of information and another text and simple and some egample or red or text';
const separators = ['and', 'or'];

function splitByWords(str, separators) {
    const tempChar = 't3mp'; // Unique temporary character
    // Create a regex like /\b(and|or)\b/g

Solution 12: ES6 Reduce for Sequential Splitting

Leveraging ES6’s reduce and spread syntax offers a functional way to apply multiple splits.

function SplitByString(source, splitBy) {
  let splitterChars = splitBy.split('');
  splitterChars.push([source]); // Start with the source string in an array

  return splitterChars.reduceRight((accumulator, currentSeparator) => {
    let newAccumulator = [];
    accumulator.forEach(value => {
      // Split each value by the current separator
      newAccumulator = [...newAccumulator, ...value.split(currentSeparator)];
    });
    return newAccumulator;
  });
}

Solution 13: Manual Iteration Without Regex

For environments where regex might be less performant or when avoiding regex is preferred, a manual loop can be implemented.

function getWords(text) {
    let startWord = -1;
    let wordsArray = [];
    const separators = [" ", "\t", "\n", "\r", ",", ";", ".", "!", "?", "(", ")"];

    for(let i = 0; i <= text.length; i++) {
        let currentChar = i < text.length ? text[i] : " "; // Treat end of string as a separator

        if (!separators.includes(currentChar) && startWord < 0) {
            // Found the start of a word
            startWord = i;
        }
        
        if (separators.includes(currentChar) && startWord >= 0) {
            // Found the end of a word
            let word = text.substring(startWord, i);
            wordsArray.push(word);
            startWord = -1; // Reset for the next word
        }
    }
    return wordsArray;
}

const manualText = "Create a function, that will return an array (of string), with the words inside the text";
console.log(getWords(manualText));
// Output: ["Create", "a", "function", "that", "will", "return", "an", "array", "of", "string", "with", "the", "words", "inside", "the", "text"]

Solution 20: HashSet for Efficient Multi-Character Splitting

An approach leveraging Set for efficient lookup of delimiters.

function multiSplit(str, delimiters) {
    if (!(delimiters instanceof Array)) {
        return str.split(delimiters);
    }
    if (!delimiters || delimiters.length === 0) {
        return [str];
    }
    const delimiterSet = new Set(delimiters);
    if (delimiterSet.has("")) {
        return str.split("");
    }

    let lastIndex = 0;
    const result = [];
    for (let i = 0; i < str.length; i++) {
        if (delimiterSet.has(str[i])) {
            result.push(str.substring(lastIndex, i));
            lastIndex = i + 1;
        }
    }
    result.push(str.substring(lastIndex)); // Add the last segment
    return result;
}

console.log(multiSplit('1,2,3.4.5.6 7 8 9', [',', '.', ' ']));
// Output: ["1", "2", "3", "4", "5", "6", "7", "8", "9"]

Solution 21: Reusable String Utility with Recursion

A more structured utility class can be built for advanced string manipulation.

const StringUtils = {
  flatten: function(arr) {
    return arr.reduce((acc, val) => acc.concat(val.constructor === Array ? this.flatten(val) : val), []);
  },
  traverseListFunc: function(list, expression, index, func) {
    if (list[index]) {
      if (list[index].constructor === String && list[index] !== func(list[index], expression)) {
        list[index] = func(list[index], expression);
      }
      if (list[index].constructor === Array) {
        this.traverseListFunc(list[index], expression, 0, func);
      }
      if (list.constructor === Array) {
        this.traverseListFunc(list, expression, index + 1, func);
      }
    }
  },
  mapFuncToString: function(string, expressions, func) {
    let list = [string];
    for (let i = 0; i < expressions.length; i++) {
      this.traverseListFunc(list, expressions[i], 0, func);
    }
    return this.flatten(list);
  },
  splitString: function(string, splitters) {
    return this.mapFuncToString(string, splitters, (item, expression) => item.split(expression));
  }
};

Solution 22: Iterative Splitting with Sequential Replacement

A methodical approach that iteratively splits the string based on provided delimiters.

function splix() {
  let args = Array.prototype.slice.call(arguments);
  let mainString = args[0];
  let delimiters = args.slice(1);
  let result = [mainString];
  let currentIndex = 0;

  for (let i = 0; i < mainString.length; i++) {
    for (let j = 0; j < delimiters.length; j++) {
      if (mainString.slice(i, i + delimiters[j].length) === delimiters[j]) {
        let parts = result[currentIndex].split(delimiters[j]);
        result[currentIndex] = parts[0]; // Update current part
        result.splice(currentIndex + 1, 0, parts[1]); // Insert the next part
      }
    }
  }
  return result;
}

console.log(splix("1.23--4", ".", "--"));
// Output: ["1", "23", "4"]

Solution 23: Scanner for Tokenization

A custom Scanner utility for more complex tokenization, allowing the retention of delimiters.

function Scanner(input, includeTokensInOutput, tokens) {
    this.input = input;
    this.includeTokensInOutput = includeTokensInOutput;
    this.tokens = tokens;
}

Scanner.prototype.scan = function () {
    let currentInput = this.input;
    let parsedSegments = [];
    // Sort tokens by length descending for correct matching
    this.tokens.sort((a, b) => b.length - a.length);

    for (let i = 0; i < currentInput.length; i++) {
        for (let j = 0; j < this.tokens.length; j++) {
            const token = this.tokens[j];
            const tokenLength = token.length;
            if (tokenLength > 0 && i + tokenLength <= currentInput.length) {
                const portion = currentInput.substring(i, i + tokenLength);
                if (portion === token) {
                    if (i !== 0) { // Add segment before the token
                        parsedSegments.push(currentInput.substring(0, i));
                    }
                    if (this.includeTokensInOutput) { // Add the token itself
                        parsedSegments.push(token);
                    }
                    // Advance the input string and reset index
                    currentInput = currentInput.substring(i + tokenLength);
                    i = -1; // Reset index to re-evaluate from the start of the new substring
                    break; // Move to the next token search
                }
            }
        }
    }
    // Add any remaining part of the input
    if (currentInput.length > 0) {
        parsedSegments.push(currentInput);
    }
    return parsedSegments;
};

Solution 24: Robust Multi-Split with Regex Options

/**
 * Split an input string with an array of single characters
 * @param {string} inputStr the input string
 * @param {string[]} splitterArray an array of single characters
 * @param {boolean} shouldTrim true if each chunk should be trimmed
 * @returns the splitted string
 */
const splitWithMultipleChars = (inputStr, splitterArray, shouldTrim = true) => {
  // Ensure only single characters are used and join them into a string
  const delimiters = splitterArray.map((d) => d[0]).join('');
  // Construct the regex: includes optional whitespace around delimiters if trimming
  const regexPattern = shouldTrim ? `(?:\\s*[${delimiters}]\\s*)+` : `[${delimiters}]+`;
  // Split the string using the constructed regex
  return `${inputStr}`.split(RegExp(regexPattern)).filter(Boolean); // Filter empty strings
};

Practical Considerations

  • Regex Performance: While powerful, complex regular expressions can sometimes impact performance. For extremely large strings or performance-critical applications, consider testing different approaches.
  • Readability: Choose a method that balances conciseness with clarity. Custom functions or well-structured regex can improve maintainability.
  • Edge Cases: Always test with edge cases, such as empty strings, strings with only delimiters, consecutive delimiters, and empty delimiters.
  • Extending Built-ins: While possible (as seen in some earlier examples with String.prototype.split), extending built-in prototypes is generally discouraged due to potential naming conflicts and maintenance issues.

FAQs on JavaScript String Splitting

Q: What is the best way to split a JavaScript string with multiple delimiters

ANS: The “best” way depends on your specific needs. Using regular expressions with character classes (/[delimit1delimit2]+/) is often concise for simple cases. For complex scenarios or when avoiding regex, iterative replacement and splitting, or functional approaches with reduce and map are effective.

Q: How do I handle consecutive delimiters when splitting a string

ANS: When using regex, the + quantifier after your delimiter set (e.g., /[ ,.]+/) will treat consecutive delimiters as a single split point. If you need to split by specific multi-character delimiters appearing consecutively, use non-capturing groups like (?:delimiter1|delimiter2)+.

Q: Can I split a string by both spaces and commas in JavaScript

ANS: Yes, you can use a regular expression like /[ ,]+/ within the split() method. This will split the string by one or more occurrences of either a space or a comma.

Q: How can I split a string by a list of words in JavaScript

ANS: You can construct a regular expression dynamically by joining your list of words with the | (OR) operator, enclosed in word boundaries \b to ensure whole words are matched. Then use this regex with split(), often after replacing the matched words with a single delimiter. For example, string.replace(new RegExp('\\b(' + words.join('|') + ')\\b', 'g'), '-').split('-').

function splitMulti(str, tokens){
        var tempChar = tokens[0]; // We can use the first token as a temporary join character
        for(var i = 1; i &lt; tokens.length; i++){
            str = str.split(tokens[i]).join(tempChar);
        }
        str = str.split(tempChar);
        return str;
}
