Question:

In the realm of asynchronous programming with RxJS, I have encountered a scenario where I need to fetch data from two separate services in my application. Specifically, I am using the following code structure:

this._personService.getName(id)
 .concat(this._documentService.getDocument())
 .subscribe((response) => {
 console.log(response)
 this.showForm()
 });

Current Outcome:

The output I receive is two distinct results, first from the _personService followed by the _documentService. As such, my output appears as:

[getnameResult]
[getDocumentResult]

Desired Outcome:

What I would prefer is a consolidated output that combines both results as shown below:

[getnameResult][getDocumentResult]

This raises the question: how can I wait for both results to be available before invoking this.showForm() and processing the results from each service?

Solutions:

Solution 1: Using combineLatestWith

As of RXJS version 7, you can utilize the combineLatestWith operator to achieve this behavior. According to the RxJS documentation :

Whenever any input Observable emits a value, it computes a formula using the latest values from all the inputs and emits the output of that formula.

Implementation:

// Creating observables to combine
const nameObservable$ = this._personService.getName(id);
const documentObservable$ = this._documentService.getDocument();

nameObservable$.pipe(
  combineLatestWith(documentObservable$)
)
.subscribe(([name, document]) => {
  this.name = name;
  this.document = document;
  this.showForm();
});

Solution 2: Using forkJoin()

The forkJoin() method is another effective way to handle multiple observables. This approach is particularly useful when you care about the final emitted value from each observable. The RxJS documentation states:

This operator is best used when you have a group of observables and only care about the final emitted value of each.

Example Usage:

forkJoin([this._personService.getName(id), this._documentService.getDocument()])
.subscribe(([name, document]) => {
  this.name = name;
  this.document = document;
  this.showForm();
});

Solution 3: Utilizing zip()

Although combineLatestWith is the modern approach, the zip operator can also be employed. The RxJS documentation describes it as:

Combines multiple Observables to create an Observable whose values are calculated from the values, in order, of each of its input Observables.

Implementing zip():

// Using zip to combine observables
Observable.zip(
  this._personService.getName(id),
  this._documentService.getDocument(),
  (name, document) => ({ name, document })
).subscribe(pair => {
  this.name = pair.name;
  this.document = pair.document;
  this.showForm();
});

Solution 4: Understanding combineLatest Syntax

(Deprecated) Using combineLatest

This method has been deprecated in favor of combineLatestWith but gives a historical perspective on how combining observables worked previously.

const nameObservable$ = this._personService.getName(id);
const documentObservable$ = this._documentService.getDocument();

combineLatest(nameObservable$, documentObservable$).subscribe(([name, document]) => {
  this.name = name;
  this.document = document;
  this.showForm();
});

Alternative Syntax: Skipping Computation Function

When using zip() or similar methods, it’s important to note that you can skip the last parameter that computes input values. If it is omitted, an array is returned instead.

Observable.zip(name$, document$)
.subscribe(pair => {
  this.name = pair[0];
  this.document = pair[1];
  this.showForm();
});

Key Comparisons: zip vs combineLatest

It’s crucial to understand the differences between zip and combineLatest:

  • combineLatest emits the latest values whenever any observable emits.
  • zip emits values in a sequential order based on the emissions, which may not provide the most recent value if one observable emits more frequently than the other.

Summary of Operator Differences

  • combineLatest provides the latest emitted values from the observables.
  • zip strictly pairs emissions based on their order, which can lead to unexpected results in certain situations.

FAQs on Top 4 Ways to Wait for Two Observables in RxJS

Q: How can I handle multiple HTTP requests in Angular using RxJS?

A: You can use forkJoin() or combineLatestWith() to manage multiple HTTP requests efficiently, allowing you to handle the results once all requests complete.

Q: What is the difference between `combineLatest` and `zip`?

A: combineLatest emits the latest values from observables whenever one of them emits, while zip emits values based on the order of emissions, pairing them strictly.

Q: When should I use `forkJoin` instead of `combineLatest`?

A: Use forkJoin when you are only interested in the final result of each observable, especially when initiating multiple requests and handling responses only after all are complete.
