“JavaScript: Obtain Today’s Date in Various Formats”

When working with JavaScript, obtaining the current date and presenting it in different formats is a frequent requirement. Whether you need a simple mm/dd/yyyy or a more elaborate Day, Month DD, YYYY, JavaScript provides several built-in methods and libraries to achieve this. This post explores various techniques, from basic object manipulation to utilizing popular libraries.

JavaScript Methods for Current Date Retrieval and Formatting

Here are several accepted solutions for getting and formatting the current date in JavaScript:

Solution 1: Basic new Date() and Manual Formatting

This method leverages the Date() object to construct a date and then manually formats it.

var today = new Date();
var dd = String(today.getDate()).padStart(2, '0');
var mm = String(today.getMonth() + 1).padStart(2, '0'); // January is 0!
var yyyy = today.getFullYear();

today = mm + '/' + dd + '/' + yyyy;
document.write(today);

This snippet yields the date in mm/dd/yyyy format. You can adjust the formatting string mm + '/' + dd + '/' + yyyy to suit your specific output needs.

Solution 2: Using toJSON() and slice() for UTC Date

This approach utilizes the toJSON() method to get a UTC string representation and then slices it to extract the date part.

var utc = new Date().toJSON().slice(0,10).replace(/-/g,'/');
document.write(utc);

The replace(/-/g,'/') ensures that dashes are converted to slashes, which is important for compatibility with browsers like Firefox and Safari when constructing new Date objects later.

Solution 3: toISOString() and toLocaleDateString() for Concise Formatting

This offers concise methods for common date formats.

// For YYYY-MM-DD format
let todayISO = new Date().toISOString().slice(0, 10);
console.log(todayISO);

// For M/D/YYYY format
let todayLocale = new Date().toLocaleDateString();
console.log(todayLocale);

You can also specify a locale for toLocaleDateString(), such as toLocaleDateString("sr"), for region-specific formatting.

Solution 4: Detailed Date and Time Formatting

This solution provides a more comprehensive formatting option, including day of the week, day of the month with suffix, month name, and time with meridiem.

var objToday = new Date(),
    weekday = new Array('Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday'),
    dayOfWeek = weekday[objToday.getDay()],
    domEnder = function() {
        var a = objToday;
        if (/1/.test(parseInt((a + "").charAt(0)))) return "th";
        a = parseInt((a + "").charAt(1));
        return 1 == a ? "st" : 2 == a ? "nd" : 3 == a ? "rd" : "th";
    }(),
    dayOfMonth = objToday.getDate() + domEnder,
    months = new Array('January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'),
    curMonth = months[objToday.getMonth()],
    curYear = objToday.getFullYear(),
    curHour = objToday.getHours() > 12 ? objToday.getHours() - 12 : (objToday.getHours() < 10 ? "0" + objToday.getHours() : objToday.getHours()),
    curMinute = objToday.getMinutes() < 10 ? "0" + objToday.getMinutes() : objToday.getMinutes(),
    curSeconds = objToday.getSeconds() < 10 ? "0" + objToday.getSeconds() : objToday.getSeconds(),
    curMeridiem = objToday.getHours() > 12 ? "PM" : "AM";

var today = curHour + ":" + curMinute + "." + curSeconds + curMeridiem + " " + dayOfWeek + " " + dayOfMonth + " of " + curMonth + ", " + curYear;

// To display this in an HTML element:
// document.getElementsByTagName('h1')[0].textContent = today;
console.log(today);

This code block also includes examples of using a custom formatting library (Date.format.min.js or dateFormat.min.js) for more flexible formatting, inspired by PHP’s date() function.

Solution 5: Setting Hours to Zero for Date-Only Representation

If you only need the date part and want to effectively ignore the time component:

var today = new Date();
today.setHours(0, 0, 0, 0);
document.write(today);

This sets the time to midnight, ensuring only the date is considered.

Solution 6: Simple Day/Month/Year Formatting

A straightforward approach for a common format:

var currentDate = new Date();
var day = currentDate.getDate();
var month = currentDate.getMonth() + 1;
var year = currentDate.getFullYear();
document.write("<b>" + day + "/" + month + "/" + year + "</b>");

This produces output like 15/2/2012.

Solution 7 & 9: Using moment.js

For extensive date manipulation and formatting, moment.js is a highly recommended library.

// To include moment.js:
// <script src="https://cdnjs.cloudflare.com/ajax/libs/moment.js/2.14.1/moment.min.js"></script>

// Example for DD/MM/YYYY format
var m = moment().format("DD/MM/YYYY");
document.write(m);

moment.js offers a vast array of formatting tokens and functions for precise date control, reducing the need for manual string manipulation.

Solution 8: toLocaleDateString() with Options

This method allows for specific formatting using locale-aware options:

var dateUS = new Date().toLocaleDateString("en-US");
console.log(dateUS);

var dateWithOptions = new Date().toLocaleDateString("en-US", {
    "year": "numeric",
    "month": "numeric"
});
console.log(dateWithOptions);

Refer to the MDN documentation for toLocaleDateString() for a full list of available options.

Solution 10: Extracting Parts of toString()

This solution parses the string representation of the date:

var d = (new Date()).toString().split(' ').splice(1,3).join(' ');
document.write(d);

This effectively extracts the month, day, and year, producing a format like Jun 28 2013.

Solution 11: toISOString() for Date Only

This is a concise way to get just the date part in YYYY-MM-DD format:

new Date().toISOString().split("T")[0];

For / separators, you can use replaceAll:

new Date().toISOString().split("T")[0].replaceAll("-", "/");

Solution 12: Zero-Padding for YYYY-MM-DD

Ensures month and day always have two digits:

var now = new Date();
var day = ("0" + now.getDate()).slice(-2);
var month = ("0" + (now.getMonth() + 1)).slice(-2);
var today = now.getFullYear() + "-" + (month) + "-" + (day);
console.log(today);

Solution 13: toLocaleString() for Locale-Specific Output

A simple method that formats the date based on the user’s locale:

new Date().toLocaleString();

This will output the date and time according to the browser’s or system’s locale settings, e.g., 2/27/2017, 9:15:41 AM.

Solution 14: toISOString().split('T')[0] Revisited

A direct and effective way to get YYYY-MM-DD:

new Date().toISOString().split('T')[0];

Solution 15: Date.js Library

The Date.js library extends the native Date object, providing methods like .today():

// Requires including the Date.js library
// For example: <script src="path/to/date.js"></script>
// new Date().today();

Solution 16: toLocaleDateString() and Intl.DateTimeFormat

These offer more control over formatting, leveraging internationalization APIs:

const options = {
  month: '2-digit',
  day: '2-digit',
  year: 'numeric',
};
console.log(new Date().toLocaleDateString('en-US', options)); // Outputs mm/dd/yyyy

const dateForIntl = new Date('Dec 2, 2021');
const intlOptions = {
  day: '2-digit',
  month: '2-digit',
  year: 'numeric',
};
console.log(new Intl.DateTimeFormat('en-US', intlOptions).format(dateForIntl)); // Outputs 12/02/2021

Solution 17: Date.now()

This static method returns the number of milliseconds elapsed since the ECMAScript epoch:

var now = Date.now();
console.log(now); // Example: 1678886400000

For full details, see the MDN documentation for Date.now() .

Solution 18: Handling Timezone Offset

This approach accounts for timezone differences to get the local date:

var d = new Date();
var localDate = new Date(d.getTime() - d.getTimezoneOffset() * 60000).toJSON().slice(0, 10);
console.log(localDate); // Example: 2015-08-11

Solution 19: UTC Conversion and Formatting

This manipulates the string representation to ensure correct UTC formatting:

// YYYY-MM-DD format
document.write(new Date(new Date().toString().split('GMT')[0] + ' UTC').toISOString().split('T')[0]);

// YYYY-MM-DDTHH:mm:ss format
document.write(new Date(new Date().toString().split('GMT')[0] + ' UTC').toISOString().split('.')[0]);

// YYYY-MM-DD HH:mm:ss format
document.write(new Date(new Date().toString().split('GMT')[0] + ' UTC').toISOString().split('.')[0].replace('T',' '));

Solution 20: Shortest toJSON().slice(0,10)

A very concise way to get YYYY-MM-DD:

new Date().toJSON().slice(0,10);

Solution 21: toDateString()

Provides a human-readable date string:

new Date().toDateString(); // Example: "Wed Feb 03 2016"

Solution 22: toISOString().slice(0,10) Revisited

Another efficient method for YYYY-MM-DD:

new Date().toISOString().slice(0,10);

Solution 23: Simple DD/MM/YYYY without Padding

A quick method for / separated dates, though without leading zeros for single-digit days/months:

var d = new Date();
document.write( [d.getDate(), d.getMonth()+1, d.getFullYear()].join('/') );

Solution 24: Template Literals and slice()

A modern and short approach using template literals:

console.log( `${Date()}`.slice(4,15) ); // Example output: "Jul 25 2025"

Solution 25: toLocaleDateString() with Specific Options

Formats the date with specified numeric year, day, and month:

let date = new Date().toLocaleDateString("en", {year:"numeric", day:"2-digit", month:"2-digit"});
console.log(date); // Example: "07/25/2025"

Solution 26: date-fns Library and Browser Compatibility Workarounds

For a lightweight alternative to moment.js, date-fns is recommended. The provided “one-liner” attempts to handle browser differences in toLocaleString() output.

// Modern approach with date-fns (example - requires installation)
// import { format } from 'date-fns';
// format(new Date(), 'MM/dd/yyyy');

// The original complex one-liner for browser compatibility:
var dateString = new Date(Date.now()).toLocaleString();
var todaysDate = dateString.slice(0,3).match(/[0-9]/i) ? dateString.split(' ')[0].split(',')[0] : dateString.split(' ')[1] + " " + dateString.split(' ')[2] + " " + dateString.split(' ')[3];
console.log(todaysDate);

Solution 27: toISOString().substring(0,19).replace("T"," ")

This extracts the date and time in a consistent format, suitable for parsing:

let d = new Date().toISOString().substring(0,19).replace("T"," "); // "2020-02-18 16:41:58"
Date.parse(d); // Returns timestamp in milliseconds

Solution 28: Simple / formatting with Time

Combines date and time in a / separated format:

var today = new Date();
today = parseInt(today.getMonth()+1)+'/'+today.getDate()+'/'+today.getFullYear() + "\nTime : " + today.getHours()+":"+today.getMinutes()+":"+today.getSeconds();
document.write(today);

See the Date() constructor documentation for more details.

Solution 29: Setting Value in an Input Field

This example demonstrates how to set a formatted date into an HTML input field on page load:

<script>
function my_curr_date() {
    var currentDate = new Date();
    var day = currentDate.getDate();
    var month = currentDate.getMonth() + 1;
    var year = currentDate.getFullYear();
    var my_date = month + "-" + day + "-" + year;
    document.getElementById("dateField").value = my_date;
}
</script>
<body onload='return my_curr_date();'>
    <input type='text' name='dateField' id='dateField' value='' />
</body>

Solution 30: Aligning to Day Start (Midnight UTC)

This trick resets the time to midnight, effectively giving you the start of the day in UTC:

// Gets the date timestamp at 00:00:00 UTC
new Date(3600000 * Math.floor(Date.now() / 3600000));

This process involves dividing the current timestamp by the number of milliseconds in a day, flooring the result, and then multiplying back to get the timestamp for the start of the day.

FAQs on JavaScript Date Formatting

Q: How do I get today's date in JavaScript in MM/DD/YYYY format

ANS: You can use var today = new Date(); var dd = String(today.getDate()).padStart(2, '0'); var mm = String(today.getMonth() + 1).padStart(2, '0'); var yyyy = today.getFullYear(); today = mm + '/' + dd + '/' + yyyy; for this.

Q: What is the shortest way to get the current date in YYYY-MM-DD format

ANS: The shortest way is new Date().toISOString().slice(0,10).

Q: Can I format the date based on the user's locale

ANS: Yes, you can use new Date().toLocaleDateString() which respects the user’s locale, or specify a locale like new Date().toLocaleDateString("en-US").

Q: Is there a library recommended for advanced date formatting

ANS: Yes, libraries like moment.js or date-fns offer extensive capabilities for formatting and manipulating dates.

Q: How do I get the current date without the time component

ANS: You can use methods like new Date().toISOString().split("T")[0] or set the hours to midnight with var today = new Date(); today.setHours(0, 0, 0, 0);.
