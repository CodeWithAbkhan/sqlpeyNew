How to Sort an Array of Objects by a Property Value

When sorting an array of JavaScript objects, the key is to provide Array.prototype.sort() with a custom comparison function. This function takes two elements, a and b, from the array and should return:

  • A negative value if a should come before b.
  • Zero if a and b are considered equal in terms of sort order.
  • A positive value if a should come after b.

Methods for Sorting JavaScript Objects

Method 1: Custom Comparison Functions

This straightforward method involves creating a dedicated function to compare the desired property of two objects.

Basic Comparison Function

function comparePersonFamilyName(personA, personB) {
  if (personA.familyName < personB.familyName) {
    return -1;
  }
  if (personA.familyName > personB.familyName) {
    return 1;
  }
  return 0; // Family names are identical
}

const personData = [
  { givenName: 'Alice', familyName: 'Smith' },
  { givenName: 'Bob', familyName: 'Johnson' },
  { givenName: 'Charlie', familyName: 'Davis' }
];

personData.sort(comparePersonFamilyName);
console.log('Sorted by family name (standard function):', personData);

Inline Arrow Function

For more concise code, especially in modern JavaScript environments, an arrow function can be used directly within the sort call.

const salesRecords = [
  { productName: 'Laptop', salesAmount: 1200 },
  { productName: 'Keyboard', salesAmount: 150 },
  { productName: 'Mouse', salesAmount: 30 }
];

// Sort sales records by product name (ascending)
salesRecords.sort((itemA, itemB) => (itemA.productName > itemB.productName) ? 1 : ((itemB.productName > itemA.productName) ? -1 : 0));
console.log('Sorted by product name (inline arrow):', salesRecords);

Method 2: Dynamic Sorting with Property Name

You can create a reusable function that generates a comparison callback based on a specified property name. This allows for dynamic sorting without writing a new comparator for each property.

Single Property Dynamic Sort

This function handles both ascending and descending order using a - prefix for the property name.

function createDynamicSorter(propertyName) {
    let sortDirection = 1;
    if(propertyName[0] === "-") {
        sortDirection = -1;
        propertyName = propertyName.substring(1); // Remove '-' prefix
    }
    return function (obj1, obj2) {
        const value1 = obj1[propertyName];
        const value2 = obj2[propertyName];
        let comparisonResult = 0;
        if (value1 < value2) {
            comparisonResult = -1;
        } else if (value1 > value2) {
            comparisonResult = 1;
        }
        return comparisonResult * sortDirection;
    }
}

const teamMembers = [
    { memberName: "Alice", role: "Developer" },
    { memberName: "Bob", role: "Manager" },
    { memberName: "Charlie", role: "Analyst" }
];

teamMembers.sort(createDynamicSorter("memberName"));
console.log('Sorted by memberName:', teamMembers);

teamMembers.sort(createDynamicSorter("role"));
console.log('Sorted by role:', teamMembers);

teamMembers.sort(createDynamicSorter("-memberName"));
console.log('Sorted by memberName (descending):', teamMembers);

Multi-Property Dynamic Sort

For scenarios requiring sorting by multiple properties (e.g., primary then secondary sort keys), you can extend the dynamic sorter.

function createMultiPropertySorter(...properties) {
    return function (objA, objB) {
        let index = 0, comparisonResult = 0;
        const totalProperties = properties.length;
        /* Iterate through properties until a non-zero comparison result is found */
        while(comparisonResult === 0 && index < totalProperties) {
            comparisonResult = createDynamicSorter(properties[index])(objA, objB);
            index++;
        }
        return comparisonResult;
    }
}

const personnelData = [
    { firstName: "Jane", lastName: "Doe" },
    { firstName: "John", lastName: "Smith" },
    { firstName: "Jane", lastName: "Smith" }
];

personnelData.sort(createMultiPropertySorter("lastName", "firstName"));
console.log('Sorted by lastName then firstName:', personnelData);

personnelData.sort(createMultiPropertySorter("firstName", "-lastName"));
console.log('Sorted by firstName then lastName (descending):', personnelData);

Method 5: Case-Sensitive and Case-Insensitive String Sorting

Direct comparison with > or < works, but remember it’s case-sensitive. To sort strings without regard for case, convert them to a consistent case (e.g., lowercase) before comparison.

  const nameB = b.description.toLowerCase();

  if (nameA > nameB) return 1;

Method 19: Schwartzian Transform for Efficient Multi-Attribute Sort

This advanced pattern, also known as “decorate-sort-undecorate,” can be efficient for large datasets or complex sorting criteria by pre-calculating the comparison values.

function sortContentByAttribute(dataArray, ...attributeKeys) {
  let comparators = attributeKeys.map(attr => {
    let isDescending = attr.charAt(0) === '-' ? -1 : 1;
    attr = attr.replace(/^-/, ''); // Remove '-' for property access
    return {
      valueGetter: obj => obj[attr],
      direction: isDescending
    };
  });

  return dataArray.map(item => {
    return {
      originalItem: item,
      comparisonValues: comparators.map(comp => comp.valueGetter(item))
    };
  })
  .sort((wrapped1, wrapped2) => {
    let i = -1, finalResult = 0;
    while (++i < comparators.length) {
      if (wrapped1.comparisonValues[i] < wrapped2.comparisonValues[i])
        finalResult = -1;
      if (wrapped1.comparisonValues[i] > wrapped2.comparisonValues[i])
        finalResult = 1;
      if (finalResult *= comparators[i].direction) // Apply direction and break if not equal
        break;
    }
    return finalResult;
  })
  .map(wrappedItem => wrappedItem.originalItem);
}

let contentEntries = [
  { contentName: 'Article Alpha', version: 2.1 },
  { contentName: 'Blog Post Beta', version: 1.5 },
  { contentName: 'Article Delta', version: 2.1 },
  { contentName: 'Ebook Gamma', version: 3.0 }
];

console.log('Content sorted by name:', sortContentByAttribute(contentEntries, 'contentName'));
console.log('Content sorted by version (DESC) then name (ASC):', sortContentByAttribute(contentEntries, '-version', 'contentName'));

Method 21: Sorting Complex Nested Arrays of Objects

When properties are deeply nested within objects, a recursive function can help access the values for comparison.

const organizationalData = [
   { teamInfo: { teamName: "Alpha", teamLead: "David" }, department: "Engineering" },
   { teamInfo: { teamName: "Beta", teamLead: "Charlie" }, department: "Sales" },
   { teamInfo: { teamName: "Alpha", teamLead: "Bob" }, department: "Engineering" }
];

// Helper to access nested properties by an array path
function resolveObjectPath(rootObject, pathSegments, segmentIndex = 0) {
  const currentSegment = rootObject[pathSegments[segmentIndex]];
  if (segmentIndex === pathSegments.length - 1) {
    return currentSegment; // Reached the leaf
  }
  if (!currentSegment) {
    return undefined; // Path does not exist
  }
  return resolveObjectPath(currentSegment, pathSegments, segmentIndex + 1);
}

function createDeepSorter(propertyPathArray) {
  let sortOrder = 1;
  let lastSegment = propertyPathArray[propertyPathArray.length - 1];
  if (lastSegment && lastSegment.startsWith("-")) {
    sortOrder = -1;
    propertyPathArray[propertyPathArray.length - 1] = lastSegment.substring(1);
  }
  return function (objA, objB) {
    const valueA = resolveObjectPath(objA, propertyPathArray);
    const valueB = resolveObjectPath(objB, propertyPathArray);
    let result = 0;
    if (valueA < valueB) result = -1;
    else if (valueA > valueB) result = 1;
    return result * sortOrder;
  };
}

function createDeepMultiSorter(...propertyPaths) {
  return function (objA, objB) {
    let i = 0, finalResult = 0;
    while(finalResult === 0 && i < propertyPaths.length) {
      finalResult = createDeepSorter(propertyPaths[i])(objA, objB);
      i++;
    }
    return finalResult;
  }
}

organizationalData.sort(createDeepMultiSorter(['teamInfo', 'teamName'], ['teamInfo', '-teamLead']));
console.log('Sorted nested data by team name then team lead (desc):', organizationalData);

Method 22: Robust Array Prototype Extension with Multi-Attribute Sort

This comprehensive prototype extension combines dynamic sorting and multi-attribute sorting into a single, chainable method. Exercise caution with prototype extensions.

Array.prototype.complexSortBy = function() {
  function _getAttrSorter(attributeName) {
    let direction = 1;
    if (attributeName.startsWith("-")) {
      direction = -1;
      attributeName = attributeName.substring(1);
    }
    return function(itemA, itemB) {
      const valA = itemA[attributeName];
      const valB = itemB[attributeName];
      let comparison = 0;
      if (valA < valB) comparison = -1;
      else if (valA > valB) comparison = 1;
      return comparison * direction;
    };
  }

  function _createCombinedSorter() {
    if (arguments.length === 0) {
      throw new Error("complexSortBy requires at least one attribute to sort by.");
    }
    const attributes = arguments;
    return function(objA, objB) {
      for (let comparisonResult = 0, i = 0; comparisonResult === 0 && i < attributes.length; i++) {
        comparisonResult = _getAttrSorter(attributes[i])(objA, objB);
      }
      return comparisonResult;
    };
  }
  return this.sort(_createCombinedSorter.apply(null, arguments));

Method 23: Generic Sort Function Generator

function createSortComparator(propKey, reverseOrder) {
    return function (dataA, dataB) {
        const valA = dataA[propKey];
        const valB = dataB[propKey];
        if (valA < valB) return reverseOrder ? 1 : -1;
        if (valA > valB) return reverseOrder ? -1 : 1;

    };
}

Method 26: Robust Sort with Accent and Case Handling Using a Temporary Property

This solution addresses natural language sorting complexities by sanitizing strings (removing accents and converting to lowercase) and uses a temporary property on the objects during the sort process.

function normalizeStringForSort(inputStr) {
  if (typeof inputStr !== 'string') return inputStr; // Handle non-string properties
  return inputStr
    .normalize('NFD')                   // Decompose combined characters (e.g., é -> e + ´)
    .replace(/[\u0300-\u036f]/g, '')    // Remove diacritics (the ´ part)
    .toLowerCase();                     // Convert to lowercase for case-insensitivity
}

function sortByPropertySanitized(arr, propertyKey, orderDirection = "ASC") {
  // Create a temporary property for sanitized values
  arr.forEach(item => item.__tempSortKey = normalizeStringForSort(item[propertyKey]));

  arr.sort((itemA, itemB) => {
    const valA = itemA.__tempSortKey;
    const valB = itemB.__tempSortKey;

    let result = 0;
    if (valA < valB) result = -1;
    else if (valA > valB) result = 1;

    return orderDirection === "ASC" ? result : -result;
  });

  // Remove the temporary property
  arr.forEach(item => delete item.__tempSortKey);
  return arr;
}

Method 28: Simple Reusable sortArray Function

A straightforward function that wraps the Array.prototype.sort() logic, making it easy to call with a property and an optional direction.

function performArraySort(targetArray, propertyName, direction = 1) { // direction: 1 for ASC, -1 for DESC
    targetArray.sort((itemA, itemB) => {
        let comparisonResult = 0;
        if (itemA[propertyName] > itemB[propertyName]) {
            comparisonResult = 1 * direction;
        } else if (itemA[propertyName] < itemB[propertyName]) {
            comparisonResult = -1 * direction;
        }
        return comparisonResult;
    });
    return targetArray; // Return the sorted array for chaining
}

const recordSet = [
    { code: 'Z', value: 10 },
    { code: 'A', value: 50 },
    { code: 'M', value: 20 }
];

console.log('Record set sorted by code (ASC):', recordSet);

performArraySort(recordSet, "value", -1); // Sort by 'value' descending
console.log('Record set sorted by value (DESC):', recordSet);

FAQs on How to sort an array of objects in JavaScript by a property value

Q: What is the fundamental principle of sorting objects in JavaScript

ANS: The fundamental principle involves providing a comparison function to the Array.prototype.sort() method. This function compares two elements and returns a negative number if the first element should come before the second, a positive number if it should come after, or zero if their order is indifferent.

Q: How do I sort an array of objects by a string property

ANS: For string properties, the localeCompare() method is highly recommended as it handles various character sets and language-specific sorting rules correctly. You can use objectA.propertyName.localeCompare(objectB.propertyName) within your comparison function.

Q: Can I sort objects by multiple properties

ANS: Yes, you can sort by multiple properties. This is typically achieved by chaining comparison results using logical OR (e.g., primarySortResult || secondarySortResult) or by implementing a custom function that iterates through multiple sort keys, acting as tie-breakers.

Q: Is it possible to sort case insensitively

ANS: Absolutely. To sort strings without considering case, convert both strings to a consistent case (like lowercase using toLowerCase()) before performing the comparison.

Q: When should I use IntlCollator for sorting

ANS: You should use Intl.Collator when you need “natural” string sorting, especially for strings containing numbers (e.g., “item2” comes before “item10”). It provides culturally sensitive and numeric-aware comparisons.
