How can I fetch query parameters in Vue.js?

When developing a Vue.js application, you might face the scenario of needing to extract query parameters from a URL, such as:

http://somesite.com?test=yay

If you find yourself uncertain about how to retrieve these values, you may wonder whether you need to rely on pure JavaScript or perhaps utilize a specific library. Fortunately, Vue.js provides straightforward solutions to this common requirement.

Top 3 Methods to Get Query Parameters in Vue.js

Method 1: Utilizing the $route Object

According to the Vue Router Documentation , you can access the $route object within your Vue components. This object contains the necessary details to retrieve the query parameters directly. Here’s how you can do it:

// Inside your Vue component
export default {
  name: "MyComponent",
  created() {
    console.log(this.$route.query.test); // Outputs: 'yay'
  }
}

This is a clean way to access the query parameters and integrates seamlessly with the Vue Router.

Method 2: Using URLSearchParams

For scenarios where you are not utilizing Vue Router, you can opt for the native JavaScript URLSearchParams interface to extract URL parameters. Here’s a practical example:

new Vue({
  el: "#app",
  created() {
    const urlParams = new URLSearchParams(window.location.search);
    if (urlParams.has('test')) {
      console.log(urlParams.get('test')); // Outputs: 'yay'
    }
  },
});

This method grants you direct access to the URL parameters regardless of the routing mechanism in use.

Method 3: Access via Mounted Hook

Another strategy involves accessing query parameters within the component’s mounted lifecycle hook. This is particularly useful if you need to perform operations after the component is fully loaded:

export default {
  name: "ParamFetcher",
  mounted() {
    const params = new URLSearchParams(window.location.search);
    console.log('Test Parameter:', params.get('test')); // Outputs: 'yay'
  }
}

Alternative Ways: Combining Methods

In situations where both routing and direct URL access might be needed, you could combine the two methods. For instance, you could check if the Vue Router is being utilized and fall back on URLSearchParams if needed.

Practice Example

Imagine you are developing a URL-based filtering component, you might want to implement both methods where the user can see filtered results based on the query parameters.

<template>
  <div>
    <h1>Filtered Results</h1>
    <!-- Rendering logic based on query params -->
  </div>
</template>

<script>
export default {
  name: "FilterResults",
  created() {
    const filter = this.$route.query.filter || new URLSearchParams(window.location.search).get('filter');
    console.log('Current Filter:', filter);
  }
}
</script>

FAQs on Top 3 Methods to Fetch Query Parameters from URL in Vue.js

Q: How do I check if a query parameter exists?

A: You can use URLSearchParams or check this.$route.query directly to see if a parameter is present in the URL.

Q: Can I use both methods simultaneously?

A: Yes, you can employ both $route and URLSearchParams as needed for flexibility in your application.
