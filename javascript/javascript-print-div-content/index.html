“JavaScript: Print Specific Div Content to Printer”

Printing a specific section of an HTML page can be a common requirement for web applications, allowing users to print reports, articles, or selected data without printing the entire page. Achieving this across various browsers with consistent results often involves several approaches, each with its own advantages and potential challenges. The core idea is to isolate the desired content, prepare it for printing, and then trigger the browser’s print functionality.

Here are multiple solutions that address this task, ranging from direct DOM manipulation to using external libraries and CSS media queries.

Solutions for Printing Div Content

Solution 1: Basic Print Window with Inner HTML

This method opens a new, minimal browser window, writes the HTML content of the target div into it, and then initiates the print command.

function PrintElem(elem) {
    var mywindow = window.open('', 'PRINT', 'height=400,width=600');

    mywindow.document.write('<html><head><title>' + document.title  + '</title>');
    mywindow.document.write('</head><body >');
    mywindow.document.write('<h1>' + document.title  + '</h1>');
    mywindow.document.write(document.getElementById(elem).innerHTML);
    mywindow.document.write('</body></html>');

    mywindow.document.close(); // necessary for IE >= 10
    mywindow.focus(); // necessary for IE >= 10

    mywindow.print();
    mywindow.close();

    return true;
}

Usage:

Call this function with the ID of the div you want to print:

<button onclick="PrintElem('myDivToPrint')">Print Div</button>
<div id="myDivToPrint">
    This is the content that will be printed.
</div>

Solution 4: jQuery DOM Manipulation for Printing

This jQuery-based solution clones the target div, replaces the entire body content with the clone, triggers the print dialog, and then restores the original body content.

function printContent(el){
    var restorepage = $('body').html();
    var printcontent = $('#' + el).clone();
    $('body').empty().html(printcontent);
    window.print();
    $('body').html(restorepage);
}

For forms where you need to preserve user input:

function printContent(el){
    var restorepage = $('body').html();
    var printcontent = $('#' + el).clone();
    var enteredtext = $('#text').val(); // Assuming an input with id 'text'
    $('body').empty().html(printcontent);
    window.print();
    $('body').html(restorepage);
    $('#text').val(enteredtext); // Restore input value
}

Solution 6: Replace Body Content Temporarily

This method replaces the entire body content with the desired div’s content, prints, and then restores the original body content.

function printdiv(printdivname) {
    var headstr = "<html><head><title>Booking Details</title></head><body>";
    var footstr = "</body>";
    var newstr = document.getElementById(printdivname).innerHTML;
    var oldstr = document.body.innerHTML;
    document.body.innerHTML = headstr + newstr + footstr;
    window.print();
    document.body.innerHTML = oldstr;
    return false;
}

Solution 10: Preserving Original Styles with an Invisible Iframe

This robust solution involves creating an invisible iframe, copying the entire document’s HTML into it, replacing the iframe’s body with the target div’s content, and then printing. This preserves most of the original page’s styling.

class PrintUtil {
  static printDiv(elementId) {
    let printElement = document.getElementById(elementId);
    var printWindow = window.open('', 'PRINT');
    printWindow.document.write(document.documentElement.innerHTML);
    setTimeout(() => { // Needed for large documents
      printWindow.document.body.style.margin = '0 0';
      printWindow.document.body.innerHTML = printElement.outerHTML;
      printWindow.document.close(); // necessary for IE >= 10
      printWindow.focus(); // necessary for IE >= 10
      printWindow.print();
      printWindow.close();
    }, 1000)
  }
}

Solution 11: Print Window with Inline Script for Loading

This method targets a specific div and injects a JavaScript snippet into the new print window that ensures window.print() is called only after the content (including potential images) has fully loaded.

function printDiv(divName) {
    var printContents = document.getElementById(divName).innerHTML;
    w = window.open();

    w.document.write(printContents);
    // Inject script to ensure printing after load
    w.document.write('<script type="text/javascript">' +
                     'window.onload = function() { window.print(); window.close(); };' +
                     '</script>');

    w.document.close(); // necessary for IE >= 10
    w.focus(); // necessary for IE >= 10

    return true;
}

Solution 13: jQuery with a Dedicated Print Div

function printContents(id) {
    var contents = $("#"+id).html();

    if ($("#printDiv").length == 0) {

Solution 19: Iframe with Timeout for Chrome

This solution uses an iframe and a setTimeout to handle potential loading delays in Chrome, ensuring that content, especially images, is ready before printing.

function printHTML(htmlString) {
    var newIframe = document.createElement('iframe');
    newIframe.width = '1px';
    newIframe.height = '1px';
    newIframe.src = 'about:blank';

    newIframe.onload = function() {
        var script_tag = newIframe.contentWindow.document.createElement("script");
        script_tag.type = "text/javascript";
        var script = newIframe.contentWindow.document.createTextNode('function Print(){ window.focus(); window.print(); }');
        script_tag.appendChild(script);

        newIframe.contentWindow.document.body.innerHTML = htmlString;
        newIframe.contentWindow.document.body.appendChild(script_tag);

        setTimeout(function() {
            newIframe.contentWindow.Print();
            newIframe.contentWindow.document.body.removeChild(script_tag);
            newIframe.parentElement.removeChild(newIframe);
        }, 200);
    };
    document.body.appendChild(newIframe);
}

FAQs on JavaScript Print Div Content

Q: How do I trigger the browser's print dialog from JavaScript

ANS: You can trigger the browser’s print dialog using the built-in window.print() method. This can be called directly or within functions that prepare content for printing.

Q: Can I print specific parts of a web page without printing the whole document

ANS: Yes, by using JavaScript to isolate the desired HTML element (like a div), you can manipulate the DOM, open it in a new window or iframe, and then trigger window.print() on that isolated content.

Q: How can I ensure my div's styles are included when printing

ANS: Several methods help preserve styles:

  1. CSS Media Queries (@media print): Define print-specific styles.
  2. Copying computed styles: Techniques that copy inline styles from the original elements to the print version.
  3. Including stylesheets: When opening a new window or iframe, ensure it links to the same CSS files as the main page.

Q: What are the main cross-browser challenges when printing HTML content

ANS: Cross-browser challenges include differences in how browsers handle window.print(), image loading in new windows, CSS interpretation for print media, and variations in the print preview dialog. Solutions often involve careful DOM manipulation, timeouts, and specific browser workarounds.

Q: Is there a simple jQuery solution for printing a div

ANS: Yes, several jQuery plugins like printThis or custom solutions using jQuery’s DOM manipulation capabilities (as shown in Solutions 4, 13, 18, 21, 26, 29) provide straightforward ways to print specific div elements.
