“JavaScript Nullish Coalescing Operator ?? Explained”

The nullish coalescing operator (??) in JavaScript provides a concise way to assign default values. It returns its right-hand operand when the left-hand operand is either null or undefined. Otherwise, it returns its left-hand operand. This behavior is distinct from the logical OR (||) operator, which returns the first “truthy” value or the last value if all are “falsy.”

The ?? operator is valuable for setting default values without being affected by other falsy values like 0, '' (empty string), or false.

Let’s examine the key differences and practical applications:

Solution 1: Understanding the Core Behavior

The ?? operator specifically checks for null or undefined.

// Using ??
let firstName = null;
let lastName = "Doe";
let nickName = "";

let displayName = firstName ?? lastName ?? nickName ?? "Guest";
console.log(displayName); // Output: Doe

let defaultAge = 0;
let userAge = 0;
let displayAge = userAge ?? defaultAge;
console.log(displayAge); // Output: 0 (because 0 is not null or undefined)

Compare this with the || operator:

// Using ||
let firstNameOr = null;
let lastNameOr = "Doe";
let nickNameOr = "";

let displayNameOr = firstNameOr || lastNameOr || nickNameOr || "Guest";
console.log(displayNameOr); // Output: Doe

let defaultAgeOr = 0;
let userAgeOr = 0;
let displayAgeOr = userAgeOr || defaultAgeOr;
console.log(displayAgeOr); // Output: 0 (because 0 is falsy, || proceeds to the next value)

This demonstrates how ?? preserves falsy values that || might override. For a deeper dive into JavaScript’s falsy values, explore resources on JavaScript data types .

Solution 2: A Custom coalesce Function

Before ?? was widely available, developers often created custom functions to mimic SQL’s COALESCE. This function iterates through arguments and returns the first non-null and non-undefined value.

function customCoalesce() {
    for (let i = 0; i < arguments.length; i++) {
        if (arguments[i] !== null && arguments[i] !== undefined) {
            return arguments[i];
        }
    }
    return null;
}

let userProfile = {};
userProfile.score = customCoalesce(null, undefined, userProfile.score, 100);
console.log(userProfile.score); // Output: 100

This approach offers similar behavior to ?? by specifically ignoring null and undefined.

Solution 3: The ?? Operator in Action

The ?? operator is part of ECMAScript 2020 and offers a clean syntax.

const response = {
  settings: {
    nullValue: null,
    height: 400,
    animationDuration: 0,
    headerText: '',
    showSplashScreen: false
  }
};

const undefinedValue = response.settings?.undefinedValue ?? 'Default Text';
console.log(undefinedValue); // Output: 'Default Text'

const nullValue = response.settings?.nullValue ?? 'Default Text';
console.log(nullValue); // Output: 'Default Text'

const headerText = response.settings?.headerText ?? 'Hello, World!';
console.log(headerText); // Output: '' (empty string is preserved)

const animationDuration = response.settings?.animationDuration ?? 300;
console.log(animationDuration); // Output: 0 (zero is preserved)

const showSplashScreen = response.settings?.showSplashScreen ?? true;
console.log(showSplashScreen); // Output: false (false is preserved)

Optional chaining (?.) is often used in conjunction with ?? to safely access nested properties that might be null or undefined. For more on handling potential errors in JavaScript, see Troubleshooting Python Errors .

Solution 4: A More Granular nullish Check

If you need to treat values like NaN (Not a Number) as nullish, you can create a more specific function.

function strictCoalesce() {
    for (let i = 0; i < arguments.length; i++) {
        const arg = arguments[i];
        if (arg !== null && arg !== undefined && (typeof arg !== 'number' || !isNaN(arg))) {
            return arg;
        }
    }
    return null;
}

let valA, valB = null, valC = parseInt('Not a number'), valD = 0;
let resultStrict = strictCoalesce(valA, valB, valC, valD);
console.log(resultStrict); // Output: 0 (NaN is skipped)

An alternative leveraging NaN’s unique property (it’s not equal to itself):

function coalesceSkipNaN() {
    for (let i = 0; i < arguments.length; i++) {
        const arg = arguments[i];
        if (arg != null && arg === arg) { // arg === arg is false for NaN
            return arg;
        }
    }
    return null;
}

let value1, value2 = null, value3 = parseInt('Not a number'), value4 = 0;
let resultSkipNaN = coalesceSkipNaN(value1, value2, value3, value4);
console.log(resultSkipNaN); // Output: 0

Solution 5: Logical Nullish Assignment (??=)

A more recent addition is the logical nullish assignment operator (??=). It assigns the right-hand operand to the left-hand operand only if the left-hand operand is null or undefined.

let configValue;
configValue ??= 'Default Setting'; // configValue is now 'Default Setting'
console.log(configValue);

let existingSetting = 'Existing Value';
existingSetting ??= 'New Value'; // existingSetting remains 'Existing Value'
console.log(existingSetting);

let numericSetting = 0;
numericSetting ??= 100; // numericSetting remains 0
console.log(numericSetting);

This is extremely useful for initializing variables or object properties with defaults. For more on managing settings, explore MudBlazor Layouts .

Solution 6: Nullish Coalescing in Context

When working with complex object structures, ?? combined with optional chaining (?.) is powerful for safely accessing data and providing fallbacks.

// Safe access and fallback for nested properties
const userPreferences = {
    theme: {
        color: null
    }
};

const userThemeColor = userPreferences.theme?.color ?? 'dark';
console.log(userThemeColor); // Output: 'dark'

const userFontSize = userPreferences.layout?.fontSize ?? 14;
console.log(userFontSize); // Output: 14 (since userPreferences.layout is undefined)

Solution 7: Babel and Compatibility

For older JavaScript environments or projects not yet supporting ECMAScript 2020, Babel can transpile ?? into equivalent JavaScript. Babel version 7.8.0 and later include support for nullish coalescing by default with @babel/preset-env. If you encounter issues with package installations, refer to Fixing Pip Install Access Denied on Windows or Fixing Conda Install and Environment Errors .

Solution 8: Browser Support

The ?? operator enjoys wide support across modern browsers. For the most up-to-date information on browser compatibility, MDN Web Docs is an excellent resource.

Solution 9: Handling null vs. undefined in JavaScript

It’s important to remember the distinction between null and undefined in JavaScript. null is an assignment value meaning “no value,” while undefined typically means a variable has been declared but not assigned a value. For strict comparisons, always use ===.

let myValue = null;
console.log(typeof myValue); // Output: object

let anotherValue;
console.log(typeof anotherValue); // Output: undefined

console.log(myValue === null); // Output: true
console.log(myValue === undefined); // Output: false

For more on JavaScript comparison operators, see JavaScript == vs === .

Solution 10: Chaining Multiple Nullish Values

The ?? operator can be chained to provide multiple fallback options. The evaluation proceeds from left to right, and the first non-nullish value encountered is returned.

const finalValue = valueA ?? valueB ?? valueC ?? 'Ultimate Default';

Solution 11: Ternary Operator as an Alternative

Before ??, the ternary operator was a common way to handle default values, though it’s more verbose.

let inputValue = null;
let valueToConsider = (inputValue === null || inputValue === undefined) ? "Default Value" : inputValue;
console.log(valueToConsider); // Output: "Default Value"

This is equivalent to inputValue ?? "Default Value".

FAQs on JavaScript Nullish Coalescing Operator

Q: What is the primary purpose of the nullish coalescing operator

ANS: The nullish coalescing operator (??) assigns a default value when a variable is null or undefined.

Q: How does ?? differ from the || operator

ANS: The ?? operator only returns the right-hand operand if the left-hand operand is null or undefined, preserving other falsy values like 0 or ‘’. The || operator returns the right-hand operand if the left-hand operand is falsy (including 0, ‘’, false).

Q: Can I use ?? with React

ANS: Yes, React’s create-react-app toolchain supports the nullish coalescing operator from version 3.3.0 onwards.

Q: Is the nullish coalescing operator supported in all browsers

ANS: The operator is widely supported in modern browsers. For older environments, transpilation tools like Babel can be used.

Q: How can I use ?? to provide multiple fallback values

ANS: You can chain multiple ?? operators together. The operator evaluates from left to right and returns the first non-nullish value it finds. For example: value1 ?? value2 ?? 'Default'.

Q: What is the logical nullish assignment operator

ANS: The ??= operator assigns the right-hand value to the left-hand variable only if the left-hand variable is null or undefined.

Q: Does ?? treat NaN as a nullish value

ANS: No, the standard ?? operator does not treat NaN as nullish. Custom functions can be created to include NaN in the nullish checks if needed.
