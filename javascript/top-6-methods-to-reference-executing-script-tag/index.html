How can I reference the script element that loaded the currently-executing script?

In a modern web development context, it is often crucial to reference the script element that loaded the currently executing JavaScript. This could be particularly advantageous when you need to load additional scripts dynamically without waiting for the whole header or body to render. Here are the top six methods to achieve this in JavaScript.

1. Using document.currentScript

One of the most straightforward ways to reference the executing script is by leveraging the document.currentScript property. This returns the <script> element that is currently being processed.

<script>
var currentScript = document.currentScript;
console.log(currentScript.src);  // Gives the URL of the current script
</script>

Benefits

  • Straightforward and reliable.
  • Requires no modifications to the script tag.
  • Supports asynchronous loading with defer and async.

Problems

  • Not supported in older browsers, including Internet Explorer.
  • Does not work with ES6 modules (<script type="module">).

2. Selecting by Script ID

Assigning an ID to a script tag permits easy access via document.getElementById().

<script id="myScript">
var currentScript = document.getElementById('myScript');
console.log(currentScript.src);
</script>

Benefits

  • Simple and effective.
  • Compatible with most browsers, including older ones.
  • Works with async scripts.

Problems

  • Requires the script to have a unique ID.
  • Potential edge case issues in specific browsers.

3. Using a data-* Attribute

Another approach is to use a data-* attribute, which provides a way to select the script based on custom attributes.

<script data-name="myScript">
var currentScript = document.querySelector('script[data-name="myScript"]');
console.log(currentScript.src);
</script>

Benefits

  • Flexible and explicit.
  • Functions well with asynchronous scripts.

Problems

  • Requires the addition of a custom attribute.
  • May have compatibility issues across certain older browsers.

4. Selecting by src Attribute

Instead of adding custom attributes, you can select the script based on its src.

<script src="//example.com/myScript.js"></script>
<script>
var currentScript = document.querySelector('script[src="//example.com/myScript.js"]');
console.log(currentScript.src);
</script>

Benefits

  • No need for custom attributes or IDs.
  • Works with dynamically added scripts.

Problems

  • Not suitable for local scripts due to path differences.
  • Static, potentially breaking if script paths change.

5. Looping Through All Scripts

You can iterate through all script tags and find the one you need.

<script>
var currentScript = null;
var scripts = document.getElementsByTagName("script");
for (var i = 0; i < scripts.length; i++) {
    if (checkIfCorrectScript(scripts[i])) {
        currentScript = scripts[i];
    }
}
</script>

And define the checking function:

function checkIfCorrectScript(scriptElem) {
    return scriptElem.src === "//example.com/myScript.js";
}

Benefits

  • Works even in older browser environments.

Problems

  • Performance can degrade with many scripts.
  • Inherits the issues of other techniques used in the checks.

6. Getting the Last Executed Script

Given that scripts are executed in order, you might be able to reliably assume that the last script is the current one.

<script>
var scripts = document.getElementsByTagName('script');
var currentScript = scripts[scripts.length - 1];
console.log(currentScript.src);
</script>

Benefits

  • Simple and effective.

Problems

  • Will not work with scripts loaded asynchronously.

Practical Example

<!DOCTYPE html>
<html lang="en">
<head>
    <script src="scripts.js"></script>
</head>
<body>
    <script>
        var thisScriptTag = document.getElementsByTagName('script')[document.getElementsByTagName('script').length - 1];
        console.log('The currently executing script:', thisScriptTag.src);
    </script>
</body>
</html>

Alternative Approaches

If none of the above methods meet specific requirements, you could consider using a framework that handles script loading more elegantly, such as RequireJS or Webpack. These tools manage dependencies and dynamically load scripts more robustly.

FAQs on Top 6 Methods to Reference the Currently Executing Script Tag

Q: How can I efficiently reference the currently executing script in my JavaScript code?

A: You can use methods like document.currentScript, assigning an ID, or using a data-* attribute. Each method has its own benefits and limitations.

Q: What are the limitations of using document.currentScript?

A: It is not supported in older browsers and does not work with <script type="module">.

Q: Can I dynamically load scripts after the current script?

A: Yes, by referencing the current script element, you can append new scripts to the DOM dynamically.
