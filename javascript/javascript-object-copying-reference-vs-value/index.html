“JavaScript Object Copying: Reference vs Value Explained”

When working with JavaScript, a common point of confusion arises around how objects are copied. Unlike primitive data types which are assigned by value, objects in JavaScript are assigned by reference. This means that when you assign one object variable to another, you’re not creating a new, independent object; instead, both variables point to the exact same object in memory. Modifying one variable then affects the other.

This behavior can lead to unexpected results if you intend to create a distinct copy of an object. So, how do you achieve true, independent copies of JavaScript objects, and what are the differences between shallow and deep copies?

The Challenge: Understanding Object References

Consider this common scenario:

// Initial object
let originalObject = {
  name: "Example",
  details: {
    version: 1.0
  }
};

// Assigning by reference
let referencedObject = originalObject;

// Attempting to modify the 'referencedObject'
referencedObject.name = "Modified Example";

// Observing the effect on the original object
console.log("Original Object:", originalObject.name); // Output: Original Object: Modified Example

As you can see, changing referencedObject.name also changed originalObject.name. This is because both variables hold a reference to the same object.

Creating Independent Copies: Methods and Techniques

To avoid this reference behavior, you need to explicitly create a new object and copy the properties from the original. There are several ways to accomplish this, each with its own implications for nested objects.

1. Shallow Copying

A shallow copy creates a new object, but only copies the top-level properties. If a property itself is an object, the reference to that nested object is copied, not the nested object itself.

Using the Spread Operator (...)

The spread syntax is a modern and concise way to create a shallow copy:

let sourceObject = {
  id: 101,
  settings: { theme: "dark" }
};

let shallowCopySpread = { ...sourceObject };

// Modifying a top-level property
shallowCopySpread.id = 102;

// Modifying a nested property
shallowCopySpread.settings.theme = "light";

console.log("Source Object ID:", sourceObject.id);             // Output: Source Object ID: 101
console.log("Shallow Copy ID:", shallowCopySpread.id);         // Output: Shallow Copy ID: 102
console.log("Source Object Theme:", sourceObject.settings.theme); // Output: Source Object Theme: light
console.log("Shallow Copy Theme:", shallowCopySpread.settings.theme); // Output: Shallow Copy Theme: light

Notice how changing the nested theme in shallowCopySpread also affected sourceObject.

Using Object.assign()

Object.assign() is another built-in method for creating shallow copies:

let sourceObject = {
  user: "Admin",
  preferences: { language: "en" }
};

let shallowCopyAssign = Object.assign({}, sourceObject);

shallowCopyAssign.user = "Guest";
shallowCopyAssign.preferences.language = "fr";

console.log("Source Object User:", sourceObject.user);              // Output: Source Object User: Admin
console.log("Shallow Copy User:", shallowCopyAssign.user);          // Output: Shallow Copy User: Guest
console.log("Source Object Language:", sourceObject.preferences.language); // Output: Source Object Language: fr
console.log("Shallow Copy Language:", shallowCopyAssign.preferences.language); // Output: Shallow Copy Language: fr

Similar to the spread operator, nested object properties remain referenced.

Using Object.create() (with caveats)

Object.create() creates a new object whose prototype is the object you pass to it. While it can create a new object, its behavior regarding property copying is distinct and often not what’s desired for a direct copy. Properties are added to the new object’s prototype chain:

let prototypeObject = {
  data: "initial data"
};

let newProtoObject = Object.create(prototypeObject);
newProtoObject.data = "new data"; // Modifies the instance, not the prototype

console.log(prototypeObject.data); // Output: initial data
console.log(newProtoObject.data);  // Output: new data

This is generally used for creating objects with specific prototypes rather than direct copying.

Using jQuery’s $.extend()

If you’re already using jQuery, $.extend() provides a way to perform shallow (or deep) copies:

// Assuming jQuery is available
let originalData = {
  id: "A1",
  config: { retry: 3 }
};

let copiedData = $.extend({}, originalData);

copiedData.id = "B2";
copiedData.config.retry = 5;

console.log("Original ID:", originalData.id);         // Output: Original ID: A1
console.log("Copied ID:", copiedData.id);             // Output: Copied ID: B2
console.log("Original Retry:", originalData.config.retry); // Output: Original Retry: 5
console.log("Copied Retry:", copiedData.config.retry);     // Output: Copied Retry: 5

2. Deep Copying

A deep copy creates a new object and recursively copies all nested objects and arrays. This ensures that the new object is completely independent of the original.

JSON Serialization/Deserialization (Common Method)

A popular and straightforward method for deep copying is to serialize the object to a JSON string and then parse it back:

let complexObject = {
  user: {
    name: "Alice",
    address: { street: "123 Main St", city: "Anytown" }
  },
  isActive: true,
  roles: ["admin", "editor"]
};

let deepCopyJson = JSON.parse(JSON.stringify(complexObject));

// Modifying nested properties
deepCopyJson.user.name = "Bob";
deepCopyJson.user.address.city = "Otherville";
deepCopyJson.roles.push("viewer");

console.log("Original User Name:", complexObject.user.name); // Output: Original User Name: Alice
console.log("Deep Copy User Name:", deepCopyJson.user.name); // Output: Deep Copy User Name: Bob
console.log("Original City:", complexObject.user.address.city); // Output: Original City: Anytown
console.log("Deep Copy City:", deepCopyJson.user.address.city); // Output: Deep Copy City: Otherville
console.log("Original Roles:", complexObject.roles);     // Output: Original Roles: [ 'admin', 'editor' ]
console.log("Deep Copy Roles:", deepCopyJson.roles);     // Output: Deep Copy Roles: [ 'admin', 'editor', 'viewer' ]

Caveats of JSON Method: This method works well for plain data objects but has limitations: it cannot copy functions, undefined values, Date objects (they become strings), regular expressions, or Maps and Sets.

Using Libraries (e.g., Lodash _.cloneDeep)

For robust deep copying that handles various data types, including functions and special objects, utility libraries are invaluable. Lodash’s _.cloneDeep is a prime example:

// Assuming lodash is imported or available
// import { cloneDeep } from 'lodash';

let objectWithFunctions = {
  id: 5,
  calculate: function(a, b) {
    return a + b;
  },
  nested: {
    value: 10
  }
};

// let deepCloneLodash = _.cloneDeep(objectWithFunctions); // If using lodash

// For demonstration without external library, using a placeholder for structuredClone
// const deepCloneLodash = structuredClone(objectWithFunctions); // Modern native approach

// Example demonstrating the concept without actual lodash/structuredClone call
function customCloneDeep(obj) {
    // This is a simplified example. A real deep clone is more complex.
    if (obj === null || typeof obj !== "object") {
        return obj;
    }
    // Handle Date
    if (obj instanceof Date) {
        return new Date(obj.getTime());
    }
    // Handle RegExp
    if (obj instanceof RegExp) {
        return new RegExp(obj);
    }
    // Handle functions and other non-plain objects would require more logic
    // For this example, we'll return them as-is which is not a true deep clone for them.
    if (typeof obj === 'function') {
        return obj; // Not a true deep copy of function behavior
    }

    const cloned = Array.isArray(obj) ? [] : {};
    for (const key in obj) {
        if (Object.prototype.hasOwnProperty.call(obj, key)) {
            cloned[key] = customCloneDeep(obj[key]);
        }
    }
    return cloned;
}
let deepCloneLodash = customCloneDeep(objectWithFunctions);


console.log("Original Calculate:", objectWithFunctions.calculate(2, 3)); // Output: Original Calculate: 5
console.log("Deep Copy Calculate:", deepCloneLodash.calculate(2, 3)); // Output: Deep Copy Calculate: 5
console.log("Original Nested Value:", objectWithFunctions.nested.value); // Output: Original Nested Value: 10
console.log("Deep Copy Nested Value:", deepCloneLodash.nested.value);   // Output: Deep Copy Nested Value: 10

Native structuredClone()

Modern JavaScript environments support the structuredClone() global function, which provides a robust built-in mechanism for deep cloning objects, including many complex types.

let itemToClone = {
  data: [1, 2, { label: "test" }],
  timestamp: new Date(),
  settings: new Map([['timeout', 5000]])
};

const clonedItem = structuredClone(itemToClone);

clonedItem.data[2].label = "updated";
clonedItem.settings.set('timeout', 10000);

console.log("Original Label:", itemToClone.data[2].label);       // Output: Original Label: test
console.log("Cloned Label:", clonedItem.data[2].label);         // Output: Cloned Label: updated
console.log("Original Timeout:", itemToClone.settings.get('timeout')); // Output: Original Timeout: 5000
console.log("Cloned Timeout:", clonedItem.settings.get('timeout'));   // Output: Cloned Timeout: 10000

This is generally the preferred method for deep cloning when available, as it handles a wider range of types than the JSON method.

3. Custom Cloning Functions

For specific scenarios or older environments, you might need to write your own cloning functions. A recursive approach is common for deep copying.

function deepClone(obj) {
  if (obj === null || typeof obj !== "object") {
    return obj;
  }

  // Handle Date
  if (obj instanceof Date) {
    return new Date(obj.getTime());
  }

  // Handle Array
  if (Array.isArray(obj)) {
    const copy = [];
    for (let i = 0; i < obj.length; i++) {
      copy[i] = deepClone(obj[i]);
    }
    return copy;
  }

  // Handle Object
  const copy = {};
  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      copy[key] = deepClone(obj[key]);
    }
  }
  return copy;
}

let complexData = {
  values: [10, 20],
  config: { enabled: true }
};

let customCloned = deepClone(complexData);

customCloned.values.push(30);
customCloned.config.enabled = false;

console.log("Original Values:", complexData.values);     // Output: Original Values: [ 10, 20 ]
console.log("Custom Cloned Values:", customCloned.values); // Output: Custom Cloned Values: [ 10, 20, 30 ]
console.log("Original Enabled:", complexData.config.enabled); // Output: Original Enabled: true
console.log("Custom Cloned Enabled:", customCloned.config.enabled); // Output: Custom Cloned Enabled: false

Which Method to Choose?

  • For simple, flat objects or when you intentionally want nested objects to be shared, shallow copy methods like the spread operator (...) or Object.assign() are efficient and clear.
  • When you need a completely independent copy of an object, including all its nested structures, deep copy methods are necessary. structuredClone() is the modern native solution. For older environments or when dealing with complex types like functions, libraries like Lodash offer comprehensive solutions. The JSON.parse(JSON.stringify()) method is a good, albeit limited, fallback for plain data structures.

Understanding these differences is crucial for writing predictable and bug-free JavaScript code.

FAQs on JavaScript Object Copying

Q: What happens when I assign an object to another variable in JavaScript

ANS: When you assign an object to another variable in JavaScript, you are creating a reference. Both variables will point to the same object in memory. Modifying the object through one variable will affect the object referenced by the other variable.

Q: What is a shallow copy of a JavaScript object

ANS: A shallow copy creates a new object with copies of the top-level properties of the original object. If any of these properties are themselves objects or arrays, their references are copied, not the nested objects/arrays themselves. This means changes to nested structures in the copy will affect the original.

Q: What is a deep copy of a JavaScript object

ANS: A deep copy creates a new object and recursively copies all nested objects and arrays. This results in a completely independent copy where modifications to any part of the copied object do not affect the original object.

Q: How can I perform a shallow copy in JavaScript

ANS: You can perform a shallow copy using the spread syntax ({ ...originalObject }) or Object.assign({}, originalObject). jQuery’s $.extend({}, originalObject) also performs a shallow copy.

Q: What are common methods for deep copying JavaScript objects

ANS: Common methods for deep copying include using JSON.parse(JSON.stringify(originalObject)) for plain data, the native structuredClone(originalObject) in modern environments, or utility library functions like Lodash’s _.cloneDeep(originalObject).

Q: What are the limitations of JSON parse and stringify for deep copying

ANS: The JSON.parse(JSON.stringify()) method cannot copy functions, undefined values, Date objects (they become strings), or other complex types like Maps, Sets, or regular expressions correctly.

Q: When should I use Object.create instead of Object.assign

ANS: Object.create() is primarily used to create a new object with a specific prototype. While it creates a new object, it’s not a direct property-by-property copy in the same way as Object.assign() or the spread syntax. Use Object.create() when you need to establish a prototype chain.

Q: How do I copy an array of objects in JavaScript

ANS: To copy an array of objects, you typically iterate through the array and perform a copy (shallow or deep, depending on your needs) for each object within the array. For a shallow copy of the array itself and its top-level objects, you can use array.slice() or the spread syntax [...originalArray]. For deep copying the objects within an array, you would iterate and use a deep copy method for each element.
