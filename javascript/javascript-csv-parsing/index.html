“JavaScript CSV Parsing: Methods & Code Examples”

When working with data in web development, particularly with sources that provide information in a Comma-Separated Values (CSV) format, the need to parse this data into usable JavaScript structures like arrays is frequent. CSV files, while seemingly simple, can present challenges due to quoted fields, embedded commas, newlines within fields, and escaped quotes, all of which need careful handling to ensure accurate data representation. This post delves into various JavaScript approaches for parsing CSV strings, offering practical code examples and alternative strategies.

Core Challenges in CSV Parsing

The primary difficulties in parsing CSV data stem from its specification (RFC 4180) and common deviations in real-world implementations. Key issues include:

  • Quoted Fields: Fields containing delimiters, newlines, or quotes themselves are typically enclosed in double quotes (").
  • Escaped Quotes: To include a double quote within a quoted field, it’s usually represented by two double quotes ("").
  • Delimiters: While the comma (,) is standard, other delimiters like semicolons (;) or tabs (\t) can be used.
  • Newlines: Fields can contain newline characters (\n or \r\n), which must be correctly interpreted within their quoted context.

Practical JavaScript Solutions for CSV Parsing

Here are several methods developed by the community to tackle CSV parsing in JavaScript, ranging from robust regular expressions to character-by-character scanning.

Solution 1: CSVToArray() Function (Regex-Based)

This solution utilizes a regular expression to parse the CSV string. It’s designed to handle standard CSV formatting, including quoted fields containing commas and escaped quotes.

/**
 * Parses a delimited string into an array of arrays.
 * Handles quoted fields, escaped quotes, and different delimiters.
 * @param {string} strData The CSV data string.
 * @param {string} strDelimiter The delimiter character (defaults to comma).
 * @returns {Array<Array<string>>} The parsed data as a 2D array.
 */
function CSVToArray(strData, strDelimiter) {
    strDelimiter = (strDelimiter || ",");
    var objPattern = new RegExp(
        (
            // Delimiters.
            "(\\" + strDelimiter + "|\\r?\\n|\\r|^)" +
            // Quoted fields.
            "(?:\"([^\"]*(?:\"\"[^\"]*)*)\"|" +
            // Standard fields.
            "([^\"\\" + strDelimiter + "\\r\\n]*))"
        ),
        "gi"
    );
    var arrData = [[]];
    var arrMatches = null;

    while (arrMatches = objPattern.exec(strData)) {
        var strMatchedDelimiter = arrMatches[1];
        if (
            strMatchedDelimiter.length &&
            strMatchedDelimiter !== strDelimiter
        ) {
            arrData.push([]);
        }

        var strMatchedValue;
        if (arrMatches[2]) {
            strMatchedValue = arrMatches[2].replace(
                new RegExp("\"\"", "g"),
                "\""
            );
        } else {
            strMatchedValue = arrMatches[3];
        }
        arrData[arrData.length - 1].push(strMatchedValue);
    }
    return arrData;
}

// Example Usage:
const csvInput1 = `"foo, the column",bar
2,3
"4, the value",5`;
console.log(CSVToArray(csvInput1));
/* Output:
[
  [ 'foo, the column', 'bar' ],
  [ '2', '3' ],
  [ '4, the value', '5' ]
]
*/

Solution 3: Simple Character-Scanning Parser

This method avoids regular expressions and instead iterates through the string character by character, managing state (like being inside a quoted field) to correctly parse fields. It handles quoted fields with embedded commas, newlines, and escaped quotes.

/**
 * Parses a CSV string character by character, handling quoted fields.
 * @param {string} str The CSV string to parse.
 * @returns {Array<Array<string>>} The parsed data as a 2D array.
 */
function parseCSV(str) {
    const arr = [];
    let quote = false; // 'true' means we're inside a quoted field

    for (let row = 0, col = 0, c = 0; c < str.length; c++) {
        let cc = str[c], nc = str[c + 1]; // Current and next character
        arr[row] = arr[row] || [];
        arr[row][col] = arr[row][col] || '';

        // Handle escaped quotes within a quoted field
        if (cc == '"' && quote && nc == '"') {
            arr[row][col] += cc;
            c++; // Skip the next quote
            continue;
        }

        // Toggle quote state
        if (cc == '"') {
            quote = !quote;
            continue;
        }

        // Move to next column if delimiter is found and not in quotes
        if (cc == ',' && !quote) {
            ++col;
            continue;
        }

        // Handle different newline types and move to next row
        if (cc == '\r' && nc == '\n' && !quote) {
            ++row;
            col = 0;
            c++; // Skip the next character (\n)
            continue;
        }
        if ((cc == '\n' || cc == '\r') && !quote) {
            ++row;
            col = 0;
            continue;
        }

        // Append the current character to the current cell
        arr[row][col] += cc;
    }
    return arr;
}

Solution 4: CSV.parse() and CSV.stringify()

This solution provides both parsing and stringifying capabilities for CSV data, handling quoted fields and their escape sequences. It iterates through the string character by character, managing state to correctly interpret CSV structure.

const CSV = {
    /**
     * Parses a CSV string into a 2D array.
     * Handles quoted fields with embedded commas, newlines, and escaped quotes.
     * @param {string} csv The CSV string.
     * @param {function} [reviver] Optional function to transform values.
     * @returns {Array<Array<string>>} The parsed data.
     */
    parse: function(csv, reviver) {
        reviver = reviver || function(r, c, v) { return v; };
        var chars = csv.split(''), c = 0, cc = chars.length, start, end, table = [], row;
        while (c < cc) {
            table.push(row = []);
            while (c < cc && '\r' !== chars[c] && '\n' !== chars[c]) {
                start = end = c;
                if ('"' === chars[c]){
                    start = end = ++c;
                    while (c < cc) {
                        if ('"' === chars[c]) {
                            if ('"' !== chars[c+1]) {
                                break; // End of quoted field
                            } else {
                                chars[++c] = ''; // Unescape double quote
                            }
                        }
                        end = ++c;
                    }
                    if ('"' === chars[c]) { // Consume the closing quote
                        ++c;
                    }
                    // Consume until next delimiter or newline
                    while (c < cc && '\r' !== chars[c] && '\n' !== chars[c] && ',' !== chars[c]) {
                        ++c;
                    }
                } else {
                    // Consume until next delimiter or newline for unquoted fields
                    while (c < cc && '\r' !== chars[c] && '\n' !== chars[c] && ',' !== chars[c]) {
                        end = ++c;
                    }
                }
                row.push(reviver(table.length-1, row.length, chars.slice(start, end).join('')));
                if (',' === chars[c]) { // Consume the comma delimiter
                    ++c;
                }
            }
            if ('\r' === chars[c]) { // Consume \r
                ++c;
            }
            if ('\n' === chars[c]) { // Consume \n
                ++c;
            }
        }
        return table;
    },

    /**
     * Stringifies a 2D array into a CSV string.
     * @param {Array<Array<string>>} table The data to stringify.
     * @param {function} [replacer] Optional function to transform values.
     * @returns {string} The CSV string.
     */
    stringify: function(table, replacer) {
        replacer = replacer || function(r, c, v) { return v; };
        var csv = '', c, cc, r, rr = table.length, cell;
        for (r = 0; r < rr; ++r) {
            if (r) {
                csv += '\r\n'; // Use CRLF for newlines
            }
            for (c = 0, cc = table[r].length; c < cc; ++c) {
                if (c) {
                    csv += ',';
                }
                cell = replacer(r, c, table[r][c]);
                // Quote cells containing delimiters, newlines, or quotes
                if (/[,\r\n"]/.test(cell)) {
                    cell = '"' + cell.replace(/"/g, '""') + '"';
                }
                csv += (cell || 0 === cell) ? cell : '';
            }
        }
        return csv;
    }
};

Solution 7: Regex with Type Correction

This approach employs a combination of regular expressions to split CSV lines and then further processes each field to correct data types (strings, numbers, booleans, nulls).

/**
 * Parses a CSV string, correcting data types for fields.
 * @param {string} text The CSV string.
 * @returns {Array<any>} An array representing the parsed row with typed values.
 */
function parseCSVLine(text) {
  // Regex to match fields, quoted fields, or null values.
  return text.match( /\s*(\"[^"]*\"|'[^']*'|[^,]*)\s*(,|$)/g ).map( function (text) {
    let m;
    if (m = text.match(/^\s*,?$/)) return null; // null value
    if (m = text.match(/^\s*\"([^"]*)\"\s*,?$/)) return m[1]; // Double Quoted Text
    if (m = text.match(/^\s*'([^']*)'\s*,?$/)) return m[1]; // Single Quoted Text
    if (m = text.match(/^\s*(true|false)\s*,?$/)) return m[1] === "true"; // Boolean
    if (m = text.match(/^\s*((?:\+|\-)?\d+)\s*,?$/)) return parseInt(m[1]); // Integer Number
    if (m = text.match(/^\s*((?:\+|\-)?\d*\.\d*)\s*,?$/)) return parseFloat(m[1]); // Floating Number
    if (m = text.match(/^\s*(.*?)\s*,?$/)) return m[1]; // Unquoted Text
    return text; // Fallback
  } );
}

Solution 8: Simple Vanilla JavaScript Splitter

This approach handles basic CSV parsing, including quoted fields with embedded commas and escaped quotes, using plain JavaScript without relying on complex regular expressions or external libraries.

/**
 * Splits a CSV line, handling quoted fields and escaped quotes.
 * @param {string} line The CSV string line.
 * @returns {Array<string>} An array of parsed fields.
 */
function splitQuotes(line) {
  if (line.indexOf('"') < 0)
    return line.split(',');

  let result = [], cell = '', quote = false;
  for (let i = 0; i < line.length; i++) {
    let char = line[i];
    // Handle escaped quotes ("")
    if (char == '"' && line[i + 1] == '"') {
      cell += char;
      i++; // Skip the next quote
    } else if (char == '"') {
      quote = !quote; // Toggle quote state
    } else if (!quote && char == ',') {
      result.push(cell); // Add completed cell to result
      cell = ''; // Reset cell for the next one
    } else {
      cell += char; // Append character to current cell
    }
    // Add the last cell if it exists
    if (i == line.length - 1 && cell) {
      result.push(cell);
    }
  }
  return result;
}

Solution 9: Wrapped CSV Line Parser

This solution includes a wrapper around a CSV line parser function, making it suitable for parsing entire files. It focuses on handling universal newlines (\r\n, \r, \n) and correctly processes quoted fields, including those with escaped quotes.

const Strings = {
    /**
     * Wrapped CSV line parser that handles universal newlines and quoted fields.
     * @param {string} s String delimited CSV string.
     * @param {string} [sep] Separator override (defaults to comma).
     * @returns {Array<Array<string>>} The parsed CSV data.
     */
    parseCSV : function(s, sep) {
        // Handle universal newlines
        var universalNewline = /\r\n|\r|\n/g;
        var a = s.split(universalNewline);
        for(var i in a){
            // Split each line by the separator
            for (var f = a[i].split(sep = sep || ","), x = f.length - 1, tl; x >= 0; x--) {
                // Check if the field is quoted
                if (f[x].replace(/\s+$/, '').charAt(f[x].length - 1) === '"') {
                    // Trim leading/trailing whitespace from quoted fields
                    var trimmedField = f[x].replace(/^\s*"/, '"');
                    if (trimmedField.length > 1 && trimmedField.charAt(0) === '"') {
                        // Unescape double quotes and remove surrounding quotes
                        f[x] = f[x].replace(/^\s*"\s*|\s*"\s*$/g, '').replace(/""/g, '"');
                    } else if (x) { // If not the first field, merge with the previous one
                        f.splice(x - 1, 2, [f[x - 1], f[x]].join(sep));
                    } else { // If it's the first field, handle correctly
                        f = f.shift().split(sep).concat(f);
                    }
                } else {
                    // Process unquoted fields for escaped quotes
                    f[x] = f[x].replace(/""/g, '"');
                }
            }
            a[i] = f;
        }
        return a;
    }
};

Solution 10: Advanced Regex Parser

This solution uses sophisticated regular expressions, including lookarounds, to parse CSV data according to RFC 4180. It handles quoted fields with embedded commas, quotes, and newlines efficiently.

/**
 * Parses CSV data using advanced regular expressions.
 * Handles quoted fields with embedded commas, quotes, and newlines.
 * @param {string} data The CSV data string.
 * @param {string} [fieldSep=','] The field separator.
 * @param {string} [newLine='\n'] The newline representation within fields.
 * @returns {Array<Array<string>>} The parsed CSV grid.
 */
function parseCsv(data, fieldSep, newLine) {
    fieldSep = fieldSep || ',';
    newLine = newLine || '\n';
    var nSep = '\x1D'; // Record separator character for internal use
    var qSep = '\x1E'; // Quoted pair separator character for internal use
    var cSep = '\x1F'; // Comma separator character for internal use

    var nSepRe = new RegExp(nSep, 'g');
    var qSepRe = new RegExp(qSep, 'g');
    var cSepRe = new RegExp(cSep, 'g');

    // Regex to find quoted fields, capturing content within quotes
    var fieldRe = new RegExp(
        '(?<=(^|[' + fieldSep + '\\n]))"' + // Positive lookbehind for start or delimiter, then opening quote
        '([\\s\\S]+?(?<![^"]))"' + // Capture content, ensuring it doesn't end with an odd number of quotes
        '(?=($|[' + fieldSep + '\\n]))', // Positive lookahead for end or delimiter
        'g'
    );

    var grid = [];
    data
        .replace(/\r/g, '') // Remove carriage returns
        .replace(/\n+$/, '') // Remove trailing newlines
        .replace(fieldRe, function(match, p1, p2) {
            // Replace internal newlines, escaped quotes, and commas within quoted fields
            return p2.replace(/\n/g, nSep).replace(/""/g, qSep).replace(/,/g, cSep);
        })
        .split(/\n/) // Split into lines
        .forEach(function(line) {
            var row = line.split(fieldSep).map(function(cell) {
                // Restore original newlines, quotes, and commas
                return cell.replace(nSepRe, newLine).replace(qSepRe, '"').replace(cSepRe, ',');
            });
            grid.push(row);
        });
    return grid;
}

const separator = ',';
const newline = '<br />'; // Custom newline representation

console.log(JSON.stringify(grid));
/* Output:
[
  ["A1","B1","C1"],
  ["A \"2\"","B, 2","C<br />2"]
]
*/

Solution 11: Custom Logic for Quoted Fields

This method provides a custom parsing logic that splits lines by commas and then uses a skipIndexes object to manage fields that span multiple comma-separated parts due to being enclosed in quotes.

/**
 * Parses CSV text with custom logic for handling multi-part quoted fields.
 * @param {string} text The CSV string.
 * @returns {Array<Array<string>>} The parsed data.
 */
const parseCSV = text => {
  const lines = text.split('\n');
  const output = [];

  lines.forEach(line => {
      line = line.trim();
      if (line.length === 0) return; // Skip empty lines

      const skipIndexes = {}; // To track fields that are part of a larger quoted field
      const columns = line.split(',');

      output.push(columns.reduce((result, item, index) => {
          if (skipIndexes[index]) return result; // Skip if already processed as part of a previous field

          // Check if the item starts with a quote and doesn't end with one (indicating a multi-part quoted field)
          if (item.startsWith('"') && !item.endsWith('"')) {
              // Continue appending subsequent fields until the closing quote is found
              while (!columns[index + 1].endsWith('"')) {
                  index++;
                  item += `,${columns[index]}`; // Append the next field
                  skipIndexes[index] = true; // Mark subsequent fields as skipped
              }
              index++; // Move to the field containing the closing quote
              skipIndexes[index] = true; // Mark this field as skipped
              item += `,${columns[index]}`; // Append the final part of the quoted field
          }

          result.push(item); // Add the processed field to the result
          return result;
      }, []));
  });

  return output;
};

Solution 13: Structured CSV Parsing Logic

This script breaks down CSV parsing into distinct steps: parsing the entire CSV string into lines, then parsing each line into fields, and finally processing each field. This modular approach allows for easier customization.

    // Constants for new line and field separators
    const NEW_LINE_CHAR = '\n';
    const FIELD_SEPARATOR_CHAR = ',';

    /**
     * Parses a CSV string into an array of rows, with each row being an array of fields.
     * @param {string} csv_str The CSV data string.
     * @returns {Array<Array<string>>} The parsed data.
     */
    function parse_csv(csv_str) {
        var result = [];
        let line_start_index = 0;
        let line_end_index = 0;
        let csr_index = 0;
        let cursor_val = csv_str[csr_index];
        let found_new_line_char = get_new_line_char(csv_str);
        let in_quote = false;

        // Normalize newlines to \n
        if (found_new_line_char === '\r\n') {
            csv_str = csv_str.split(found_new_line_char).join(NEW_LINE_CHAR);
        }
        // Ensure the string ends with a newline for consistent processing
        if (csv_str[csv_str.length - 1] !== NEW_LINE_CHAR) {
            csv_str += NEW_LINE_CHAR;
        }

        while (csr_index < csv_str.length) {
            if (cursor_val === '"') {
                in_quote = !in_quote;
            } else if (cursor_val === NEW_LINE_CHAR && !in_quote) {
                // Process the line if not inside quotes and a newline is found
                if (line_start_index <= line_end_index) {
                    result.push(parse_csv_line(csv_str.substring(line_start_index, line_end_index)));
                }
                line_start_index = csr_index + 1; // Start of the next line
            }
            csr_index++;
            cursor_val = csv_str[csr_index];
            line_end_index = csr_index; // Track the end of the current line segment
        }

        // Re-apply \r\n if originally present
        if (found_new_line_char === '\r\n') {
            let new_result = [];
            for (var i = 0; i < result.length; i++) {
                let curr_row = [];
                for (var j = 0; j < result[i].length; j++) {
                    curr_row.push(result[i][j].split(NEW_LINE_CHAR).join('\r\n'));
                }
                new_result.push(curr_row);
            }
            result = new_result;
        }
        return result;
    }

    /**
     * Parses a single CSV line into an array of fields.
     * @param {string} csv_line_str The CSV line string.
     * @returns {Array<string>} An array of fields.
     */
    function parse_csv_line(csv_line_str) {
        var result = [];
        let field_start_index = 0;
        let field_end_index = 0;
        let csr_index = 0;
        let cursor_val = csv_line_str[csr_index];
        let in_quote = false;

        // Append separator to ensure the last field is processed
        csv_line_str += FIELD_SEPARATOR_CHAR;

        while (csr_index < csv_line_str.length) {
            if (cursor_val === '"') {
                in_quote = !in_quote;
            } else if (cursor_val === FIELD_SEPARATOR_CHAR && !in_quote) {
                // Process the field if not inside quotes and separator is found
                if (field_start_index <= field_end_index) {
                    result.push(parse_csv_field(csv_line_str.substring(field_start_index, field_end_index)));
                }
                field_start_index = csr_index + 1; // Start of the next field
            }
            csr_index++;
            cursor_val = csv_line_str[csr_index];
            field_end_index = csr_index; // Track the end of the current field segment
        }
        return result;
    }

    /**
     * Processes a single CSV field, handling quotes and escaped quotes.
     * @param {string} csv_field_str The CSV field string.
     * @returns {string} The processed field value.
     */
    function parse_csv_field(csv_field_str) {
        let with_quote = (csv_field_str.startsWith('"'));

        if (with_quote) {
            csv_field_str = csv_field_str.substring(1, csv_field_str.length - 1); // Remove surrounding quotes
            csv_field_str = csv_field_str.split('""').join('"'); // Handle escaped double quotes
        }
        return csv_field_str;
    }

    /**
     * Determines the newline character sequence present in the CSV string.
     * @param {string} csv_str The CSV string.
     * @returns {string} The detected newline character sequence.
     */
    function get_new_line_char(csv_str) {
        if (csv_str.indexOf('\r\n') > -1) {
            return '\r\n';
        } else {
            return '\n';
        }
    }

Solution 14: Flexible Newline and Quote Handling

This implementation accounts for various newline types (\r\n, \n, \r) and handles quotes by tracking their parity to correctly identify field boundaries and escaped quotes.

/**
 * Parses a CSV string, handling various newline types and quoted fields.
 * @param {string} str The CSV string.
 * @returns {Array<Array<string>>} The parsed CSV data.
 */
function parseCSV(str) {
    let csv = [], pointer = 0, c = null, quote = 0, col = '', row = [];
    while (c = str.charAt(pointer)) {
        pointer++;
        if (c == '"') {
            quote++;
            // First and even numbered quotes are boundaries, not data
            if (quote == 1 || quote % 2 == 0) {
                continue;
            }
        } else if ([',','\r\n','\n','\r'].includes(c)) {
            // Even number of quotes means a completed column and potentially a row
            if (quote % 2 == 0) {
                row.push(col); // Add the completed column
                col = '';      // Reset column buffer
                quote = 0;     // Reset quote count

                // If the delimiter is not a comma, it signals a completed row
                if (c != ',') {
                    // Handle edge case of \r\n being two separate characters
                    if (c == '\r' && str.charAt(pointer) == '\n') {
                        pointer++; // Skip the next character if it's \n following \r
                    }
                    csv.push(row); // Add the completed row
                    row = [];      // Reset row buffer
                }
                continue;
            }
        }
        col += c; // Append character to the current column buffer
    }
    return csv;
}

// Example Usage:
const csvInput14 = '"Value 1","Value 2","Value with\nNew line"\r\n"Value 3","Value 4","Value with ""escaped"" quotes"';
console.log(parseCSV(csvInput14));
/* Output:
[
  [ 'Value 1', 'Value 2', 'Value with\nNew line' ],
  [ 'Value 3', 'Value 4', 'Value with "escaped" quotes' ]
]
*/

FAQs on JavaScript CSV Parsing

Q: How do I parse a CSV string with embedded newlines in JavaScript

ANS: Several methods can handle embedded newlines within quoted fields. Solutions 1, 3, 4, 7, 10, 11, 13, and 14 demonstrate techniques using regular expressions or state-based parsing to correctly interpret newlines within quoted values without splitting the row prematurely.

Q: What is the best way to handle escaped quotes in CSV using JavaScript

ANS: Escaped quotes, typically represented as "" within a quoted field, are handled by specific logic in most robust parsers. Solutions like 1, 3, 4, 7, 8, 10, 11, 13, and 14 include logic (often using string replacement or specific regex patterns) to replace "" with a single " after parsing the quoted field content.

Q: Can JavaScript parse CSV files with different delimiters

ANS: Yes, many JavaScript CSV parsing solutions are configurable to handle delimiters other than the standard comma. For example, Solution 1 allows specifying a strDelimiter, Solution 2 (jQuery-CSV) has a separator option, and Solution 10 has a fieldSep parameter, enabling parsing of TSV (Tab-Separated Values) or other delimited formats.

Q: Which JavaScript CSV parsing methods support RFC 4180

ANS: Solutions that rigorously follow the RFC 4180 standard are those that correctly handle quoted fields containing delimiters, newlines, and escaped quotes. Methods like 1, 3, 4, 6, 7, 10, 11, 13, and 14 are designed with this standard in mind. Libraries like jQuery-CSV (Solution 2) also explicitly state RFC 4180 compliance.

Q: Is there a simple JavaScript solution for basic CSV parsing

ANS: For CSV strings that do not contain quoted fields with embedded commas or newlines, a simple yourCsvString.split(',') might suffice (as shown in Solution 15). However, for more standard CSV handling, using a dedicated parsing function like those in Solutions 1, 3, 8, or 13 is recommended due to their ability to manage quoted data correctly.
