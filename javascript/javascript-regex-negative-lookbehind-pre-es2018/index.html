“JavaScript Regex: Negative Lookbehind Workarounds Pre-ES2018”

JavaScript’s regular expression engine gained support for lookbehind assertions, including negative lookbehind, as part of the ECMAScript specification in 2018. However, for projects or environments that predate this update or require compatibility with older JavaScript runtimes, implementing patterns that rely on negative lookbehind presents a challenge. This post delves into various strategies and workarounds to achieve similar outcomes without native negative lookbehind support.

The Challenge: Mimicking Negative Lookbehind Without Native Support

Negative lookbehind (?<!...) allows a regex to assert that a pattern does not immediately precede the current position. Without this, common tasks like matching a specific pattern only if it’s not preceded by a particular string become more intricate.

Solution 1: String Reversal and Reversed Regex

A common pre-2018 technique involves reversing the input string, applying a reversed regular expression that effectively becomes a positive lookahead on the reversed string, and then reversing the match back.

Consider the requirement to match ’m’ unless it’s preceded by ‘a’.

The Workaround:

const reverseString = (str) => str.split('').reverse().join('');

const testRegexWithReversal = (stringsToTest, reversedRegex) => {
  stringsToTest.forEach((originalString, index) => {
    const reversedInput = reverseString(originalString);
    const matchResult = reversedRegex.exec(reversedInput);
    let matchedToken = 'Ø';
    if (matchResult) {
      matchedToken = reverseString(matchResult[0]);
    }
    console.log(`${originalString}: ${!!matchResult} token: ${matchedToken}`);
  });
};

Solution 2: Leveraging Positive Lookahead with Negation and Grouping

When the “lookbehind” pattern has a fixed length, you can simulate negative lookbehind using positive lookahead combined with capturing groups.

Let’s aim to match int not preceded by unsigned .

The Workaround:

For a pattern like (?<!unsigned )int, where unsigned has a fixed length of 9 characters:
