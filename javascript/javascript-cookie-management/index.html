“JavaScript Cookie Management: Set, Get, and Remove Functions”

When developing web applications, managing client-side data is often a necessity. JavaScript cookies provide a way to store small pieces of information directly in the user’s browser. This capability is crucial for maintaining user sessions, remembering preferences, and personalizing user experiences. How can you reliably implement functions to set, retrieve, and remove cookies using JavaScript?

Several approaches exist, each with its nuances and benefits. Let’s examine practical code examples and explore different methods for effective cookie manipulation.

Solution 1: A Simpler, Reusable JavaScript Cookie Utility

This method offers a set of straightforward functions for cookie operations, making them easy to integrate into your projects.

/**
 * Sets a cookie with a specified name, value, and expiration duration in days.
 * @param {string} name - The name of the cookie.
 * @param {string} value - The value to store in the cookie.
 * @param {number} days - The number of days until the cookie expires.
 */
function setCookie(name, value, days) {
    let expires = "";
    if (days) {
        const date = new Date();
        date.setTime(date.getTime() + (days * 24 * 60 * 60 * 1000));
        expires = "; expires=" + date.toUTCString();
    }
    document.cookie = name + "=" + (value || "") + expires + "; path=/";
}

/**
 * Retrieves the value of a cookie by its name.
 * @param {string} name - The name of the cookie to retrieve.
 * @returns {string|null} The cookie's value, or null if not found.
 */
function getCookie(name) {
    const nameEQ = name + "=";
    const ca = document.cookie.split(';');
    for (let i = 0; i < ca.length; i++) {
        let c = ca[i];
        while (c.charAt(0) === ' ') c = c.substring(1, c.length);
        if (c.indexOf(nameEQ) === 0) return c.substring(nameEQ.length, c.length);
    }
    return null;
}

/**
 * Removes a cookie by its name.
 * @param {string} name - The name of the cookie to remove.
 */
function eraseCookie(name) {
    document.cookie = name + '=; Path=/; Expires=Thu, 01 Jan 1970 00:00:01 GMT;';
}

// Example Usage:
setCookie('userPreference', 'dark_mode', 30); // Set a cookie named 'userPreference' with value 'dark_mode' for 30 days

const currentPreference = getCookie('userPreference');
if (currentPreference) {
    console.log("User preference is:", currentPreference);
    // Apply the preference, e.g., change the theme
} else {
    console.log("No user preference found.");
}

// To remove the cookie:
// eraseCookie('userPreference');

Solution 2: Direct document.cookie Manipulation with Enhanced Referencing

This approach leverages direct manipulation of document.cookie and points to more authoritative resources for deeper learning.

// Setting a cookie named 'sessionToken' with an expiration date
document.cookie = 'sessionToken=abc123xyz; expires=Fri, 31 Dec 9999 23:59:59 UTC; path=/';

// Setting another cookie, 'themeSetting', which does not overwrite 'sessionToken'
document.cookie = 'themeSetting=light; expires=Fri, 31 Dec 9999 23:59:59 UTC; path=/';

// Removing a cookie, for instance, 'themeSetting'
document.cookie = 'themeSetting=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/';

Solution 3: Integrating Cookie Management with UI Elements

This solution demonstrates how to use cookie functions to persist user selections in a web interface, such as a dropdown menu.

<script>
// Function to set a cookie
function setCookie(c_name, value, exdays) {
    const exdate = new Date();
    exdate.setDate(exdate.getDate() + exdays);
    const c_value = escape(value) + ((exdays == null) ? "" : "; expires=" + exdate.toUTCString());
    document.cookie = c_name + "=" + c_value;
}

// Function to get a cookie
function getCookie(c_name) {
    let i, x, y, ARRcookies = document.cookie.split(";");
    for (i = 0; i < ARRcookies.length; i++) {
        x = ARRcookies[i].substr(0, ARRcookies[i].indexOf("="));
        y = ARRcookies[i].substr(ARRcookies[i].indexOf("=") + 1);
        x = x.replace(/^\s+|\s+$/g, "");
        if (x == c_name) {
            return unescape(y);
        }
    }
}

// Function to handle selection change and update cookie
function cssSelected() {
    const cssSelected = $('#myList')[0].value;
    if (cssSelected !== "select") {
        setCookie("selectedCSS", cssSelected, 3); // Set cookie for 3 days
    }
}

// Load the previously selected CSS theme when the page loads
$(document).ready(function() {
    const savedCss = getCookie("selectedCSS");
    if (savedCss) {
        $('#myList')[0].value = savedCss;
    }
});
</script>

</select>

Solution 4: A Robust, UTF-Safe Cookie Object

For more complex scenarios, a well-structured JavaScript object can provide a comprehensive interface for cookie management, ensuring UTF-safe operations.

var docCookies = {
  /**
   * Retrieves the value of a cookie.
   * @param {string} sKey - The name of the cookie.
   * @returns {string|null} The cookie's value, or null if not found.
   */
  getItem: function (sKey) {
    return decodeURIComponent(document.cookie.replace(new RegExp("(?:(?:^|.*;)\\s*" + encodeURIComponent(sKey).replace(/[\-\.\+\*]/g, "\\$&") + "\\s*\\=\\s*([^;]*).*$)|^.*$"), "$1")) || null;
  },

  /**
   * Sets a cookie with various options for expiration, path, domain, and security.
   * @param {string} sKey - The name of the cookie.
   * @param {string} sValue - The value to store in the cookie.
   * @param {number|string|Date} [vEnd] - Expiration date/time or duration in days.
   * @param {string} [sPath] - The path for the cookie.
   * @param {string} [sDomain] - The domain for the cookie.
   * @param {boolean} [bSecure] - Whether the cookie should be secure.
   * @returns {boolean} True if the cookie was set successfully, false otherwise.
   */
  setItem: function (sKey, sValue, vEnd, sPath, sDomain, bSecure) {
    if (!sKey || /^(?:expires|max\-age|path|domain|secure)$/i.test(sKey)) { return false; }
    let sExpires = "";
    if (vEnd) {
      switch (vEnd.constructor) {
        case Number:
          sExpires = (vEnd === Infinity) ? "; expires=Fri, 31 Dec 9999 23:59:59 GMT" : "; max-age=" + vEnd;
          break;
        case String:
          sExpires = "; expires=" + vEnd;
          break;
        case Date:
          sExpires = "; expires=" + vEnd.toUTCString();
          break;
      }
    }
    document.cookie = encodeURIComponent(sKey) + "=" + encodeURIComponent(sValue) + sExpires + (sDomain ? "; domain=" + sDomain : "") + (sPath ? "; path=" + sPath : "") + (bSecure ? "; secure" : "");
    return true;
  },

  /**
   * Removes a cookie.
   * @param {string} sKey - The name of the cookie to remove.
   * @param {string} [sPath] - The path of the cookie.
   * @param {string} [sDomain] - The domain of the cookie.
   * @returns {boolean} True if the cookie was removed successfully, false otherwise.
   */
  removeItem: function (sKey, sPath, sDomain) {
    if (!sKey || !this.hasItem(sKey)) { return false; }
    document.cookie = encodeURIComponent(sKey) + "=; expires=Thu, 01 Jan 1970 00:00:00 GMT" + (sDomain ? "; domain=" + sDomain : "") + (sPath ? "; path=" + sPath : "");
    return true;
  },

  /**
   * Checks if a cookie exists.
   * @param {string} sKey - The name of the cookie to check.
   * @returns {boolean} True if the cookie exists, false otherwise.
   */
  hasItem: function (sKey) {
    return (new RegExp("(?:^|;\\s*)" + encodeURIComponent(sKey).replace(/[\-\.\+\*]/g, "\\$&") + "\\s*\\=")).test(document.cookie);
  },

  /**
   * Optional: Retrieves all cookie keys. Can be safely removed if not needed.
   * @returns {string[]} An array of cookie names.
   */
  keys: function () {
    const aKeys = document.cookie.replace(/((?:^|\s*;)[^\=]+)(?=;|$)|^\s*|\s*(?:\=[^;]*)?(?:\1|$)/g, "").split(/\s*(?:\=[^;]*)?;\s*/);
    for (let nIdx = 0; nIdx < aKeys.length; nIdx++) { aKeys[nIdx] = decodeURIComponent(aKeys[nIdx]); }
    return aKeys;
  }
};

// Example Usage of docCookies object:
docCookies.setItem('userId', '12345', Infinity, '/'); // Set a persistent cookie
console.log("User ID cookie:", docCookies.getItem('userId'));
console.log("Has 'sessionToken' cookie:", docCookies.hasItem('sessionToken'));
docCookies.removeItem('userId', '/'); // Remove the cookie

FAQs on JavaScript Cookie Management

Q: How do I set a cookie with an expiration date in JavaScript

ANS: You can set a cookie with an expiration date by appending an expires attribute to the document.cookie string. This attribute should be set to a date string in the format Day, DD Mon YYYY HH:MM:SS GMT. For example: document.cookie = "myCookie=myValue; expires=Fri, 31 Dec 9999 23:59:59 GMT; path=/";. Alternatively, you can use the days parameter in the provided setCookie functions.

Q: What is the difference between the provided JavaScript cookie solutions

ANS: Solution 1 offers simple, reusable functions. Solution 2 uses direct document.cookie manipulation with references for deeper learning. Solution 3 integrates cookie handling with UI elements for persistence. Solution 4 provides a robust, UTF-safe object for advanced cookie management with more options.

Q: Can JavaScript cookies store large amounts of data

ANS: No, cookies are intended for small pieces of data, typically up to 4KB per cookie. For larger data storage, consider browser’s localStorage or sessionStorage, or server-side storage.

Q: How can I ensure my cookie data is secure

ANS: For sensitive data, always use the secure attribute when setting cookies (document.cookie = "myCookie=myValue; secure";), which ensures the cookie is only sent over HTTPS. Avoid storing sensitive information directly in cookies if possible.

Q: What does the path attribute do for cookies

ANS: The path attribute specifies the URL path for which the cookie is valid. If omitted, the cookie is generally available to all pages on the same domain. Setting path=/ makes the cookie accessible across the entire domain.
