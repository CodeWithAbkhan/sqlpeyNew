How can I Convert Characters to ASCII Code Using JavaScript?

In the realm of programming, there often arises the need to convert characters into their corresponding ASCII code values. For instance, using JavaScript, how would you achieve this? If we take an example, we want to derive the ASCII code from a specific character, such as obtaining 10 from the newline character "\n".

Understanding how to perform this conversion is essential for various applications, especially when dealing with strings and character encoding. Here, we’ll delve into two primary methods to attain this goal.

Solution 1: Using charCodeAt()

One straightforward way to convert a character to its ASCII code is by utilizing the charCodeAt() method. This method retrieves the Unicode code unit at the specified index for the string.

let asciiCode = "\n".charCodeAt(0);
console.log(asciiCode); // Outputs: 10

For further details, refer to the official charCodeAt documentation .

The charCodeAt() function returns an integer representing the UTF-16 code unit at the given index. It is crucial to note that this method will not correctly handle non-BMP Unicode characters (characters outside the Basic Multilingual Plane). For example:

console.log("\u{1f602}".charCodeAt(0)); 
// Outputs: 55357 (equivalent to 0xd83d in hexadecimal)

If you require access to the complete code point for characters that cannot be represented with a single UTF-16 unit, consider using the codePointAt() method instead.

Solution 2: Using fromCharCode()

The second method involves the fromCharCode() method, which can take one or more ASCII values and convert them into corresponding characters. If we simply want to see how String.fromCharCode() works:

let character = String.fromCharCode(65); // ASCII code for 'A'
console.log(character); // Outputs: A

Using this method allows us to convert a series of ASCII codes into a concatenated string. For example:

let letters = String.fromCharCode(65, 66, 67); // ASCII for 'A', 'B', 'C'
console.log(letters); // Outputs: ABC

For further reference, check the String.fromCharCode documentation .

FAQs on Top 2 Methods to Convert Characters to ASCII Code in JavaScript

Q: How do I handle non-BMP Unicode characters in JavaScript?

A: To handle non-BMP Unicode characters, use the codePointAt() method instead of charCodeAt().

Q: Can `fromCharCode()` accept multiple ASCII values at once?

A: Yes, fromCharCode() can take multiple ASCII values and return a single string formed by those characters.

Q: What is the difference between `charCodeAt()` and `codePointAt()`?

A: charCodeAt() retrieves the UTF-16 code unit at a specified index, while codePointAt() returns the actual Unicode code point for the character.
