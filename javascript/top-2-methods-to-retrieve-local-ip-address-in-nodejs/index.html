How Can You Retrieve the Local IP Address using Node.js?

In the realm of web development and server management, acquiring the local IP address of the machine running your Node.js application can be quite pivotal. Whether for debugging, logging, or working with network services, understanding how to effectively retrieve this information can enhance your application’s functionality. Below, we will delve into two distinct and effective methods for achieving this.

Method 1: Utilizing os.networkInterfaces()

The os module in Node.js provides an efficient way to fetch network interface details through the os.networkInterfaces() method. Below is a code snippet that illustrates how to implement this:

'use strict';

const { networkInterfaces } = require('os');

const interfaces = networkInterfaces();
const ipAddresses = Object.create(null); // Initialize an object to store results

for (const interfaceName of Object.keys(interfaces)) {
    for (const net of interfaces[interfaceName]) {
        // Check for valid IPv4 addresses excluding internal addresses
        const isIPv4 = typeof net.family === 'string' ? net.family === 'IPv4' : net.family === 4;
        if (isIPv4 && !net.internal) {
            if (!ipAddresses[interfaceName]) {
                ipAddresses[interfaceName] = [];
            }
            ipAddresses[interfaceName].push(net.address);
        }
    }
}

console.log(ipAddresses);

Example Output:

Upon executing the above code, the output may resemble:

{
  "en0": [
    "192.168.1.101"
  ],
  "eth0": [
    "10.0.0.101"
  ],
  ...
}

This demonstrates the capability to retrieve multiple addresses for various network interfaces on the machine.

Method 2: Using DNS Lookup with dns.lookup()

If you require a simpler approach to fetch the primary IPv4 address of your machine, the dns.lookup() function from the dns module is a highly effective alternative. The following is a code example:

const dns = require('node:dns');
const os = require('node:os');

const options = { family: 4 }; // Specify IPv4

dns.lookup(os.hostname(), options, (error, address) => {
    if (error) {
        console.error("Error fetching IP address:", error);
    } else {
        console.log(`IPv4 Address: ${address}`);
    }
});

Example Output:

Executing the code may yield an output like:

IPv4 Address: 192.168.1.101

This method directly retrieves the primary IPv4 address based on the hostname of the machine.
