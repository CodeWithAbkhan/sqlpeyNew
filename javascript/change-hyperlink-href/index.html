“How to Change Hyperlink HREF in HTML with JavaScript & jQuery”

When developing web pages, a common task involves dynamically altering the destination of hyperlinks, often referred to as anchor tags (<a>). This can be necessary for various reasons, such as updating links based on user interaction, implementing redirects, or even fixing broken links. Both native JavaScript and the popular jQuery library offer robust ways to achieve this. Let’s dive into different scenarios and their corresponding solutions.

Modifying All Hyperlinks

If the goal is to change the href attribute of every single hyperlink on a page, you can employ a broad selector.

Using jQuery:

The most straightforward jQuery approach targets all <a> elements and applies a new href value.

$("a").attr("href", "https://www.example.com/new-destination/");

This code selects all anchor tags and sets their href attribute to https://www.example.com/new-destination/.

Using Vanilla JavaScript:

With plain JavaScript, you can achieve the same by selecting all <a> elements and iterating through them.

const allAnchors = document.querySelectorAll('a');
allAnchors.forEach(anchor => {
    anchor.href = "https://www.example.com/new-destination/";
});

This selects all <a> tags and updates their href property.

Targeting Specific Hyperlinks

Often, you’ll need to modify only certain links based on their current href, class, or ID.

Matching by Exact HREF:

To change links that point to a specific URL, you can use attribute selectors.

Using jQuery:

// Change all links pointing to google.com to maps.google.com
$("a[href='http://www.google.com/']").attr('href', 'http://maps.google.com/');

Using Vanilla JavaScript:

const googleLinks = document.querySelectorAll('a[href="http://www.google.com/"]');
googleLinks.forEach(link => {
    link.href = "http://maps.google.com/";
});

Matching by Partial HREF:

For scenarios where you need to modify links that start with, end with, or contain a specific string, attribute selectors are invaluable.

Using jQuery:

// Change links starting with http://stackoverflow.com
$("a[href^='http://stackoverflow.com']")
   .each(function() {
      this.href = this.href.replace(/^http:\/\/beta\.stackoverflow\.com/,
         "http://stackoverflow.com");
   });

This example modifies links that begin with http://stackoverflow.com, specifically replacing any occurrences of http://beta.stackoverflow.com at the start of the href with http://stackoverflow.com.

Using Vanilla JavaScript:

// Select links ending with .png
const pngLinks = document.querySelectorAll('a[href$=".png"]');
pngLinks.forEach(link => {
    link.href = "https://www.example.com/images/";
});

// Select links containing google.com
const containsGoogleLinks = document.querySelectorAll('a[href*="google.com"]');
containsGoogleLinks.forEach(link => {
    link.href = "https://www.example.com/search/";
});

Matching by Class or ID:

Targeting elements by their class or id is a fundamental practice.

Using jQuery:

// Change links with a specific class
$("a.mylink").attr("href", "https://www.customlink.com/");

// Change a link with a specific ID
$("#specificLink").attr("href", "https://www.newurl.com/");

Using Vanilla JavaScript:

// Change links with a specific class
const myLinkElements = document.querySelectorAll('a.mylink');
myLinkElements.forEach(element => {
    element.href = "https://www.customlink.com/";
});

// Change a link with a specific ID
const specificLinkElement = document.getElementById("specificLink");
if (specificLinkElement) {
    specificLinkElement.setAttribute("href", "https://www.newurl.com/");
}

jQuery’s .prop() vs. .attr()

It’s important to note the distinction between .attr() and .prop() in jQuery, especially since jQuery 1.6.

  • .attr() retrieves the value of an HTML attribute.
  • .prop() retrieves the value of a DOM property.

For the href attribute, both often work similarly, but .prop() is generally preferred for accessing and modifying DOM element properties.

Using .prop():

$("a").prop("href", "https://www.preferred-destination.com");

Advanced Scenarios

You might need to modify links within a specific section of your page or handle more complex replacements.

Changing Links within a Specific Section:

Using jQuery:

// Change Google links only within elements with class 'content'
$(".content a[href='http://www.google.com/']").attr('href', 'http://maps.google.com/');

Modifying Parts of an HREF:

Using jQuery:

// Replace a specific subdomain in the href
$("a[href^='http://example.com']")
   .each(function() {
      this.href = this.href.replace(/^http:\/\/old-subdomain\.example\.com/,
         "http://new-subdomain.example.com");
   });

This code finds all links starting with http://example.com and, within those, replaces http://old-subdomain.example.com at the beginning of the href with http://new-subdomain.example.com.

Alternatives to jQuery

While jQuery simplifies many DOM manipulation tasks, modern JavaScript offers powerful native solutions. The document.querySelectorAll() method, combined with forEach and attribute selectors, provides a flexible alternative.

Example using only JavaScript:

// Change all links to example.com
const anchors = document.querySelectorAll('a');
anchors.forEach(element => {
    element.href = "https://www.example.com/";
});

// Change links that start with https://
const secureLinks = document.querySelectorAll('a[href^="https://"]');
secureLinks.forEach(element => {
    element.href = "https://www.secure-destination.com/";
});

Specific Case: WordPress Avada Theme Logo

In specific contexts, like modifying the logo link in themes such as WordPress’s Avada, you might use JavaScript within a shortcode.

// Example for WordPress Avada Theme logo link change
jQuery(document).ready(function() {
    jQuery("div.fusion-logo a").attr("href", "tel:303-985-9850");
});

This snippet targets the logo link within the Avada theme and changes its href to a phone number.

FAQs on Changing Hyperlink HREF

Q: How do I change all links on a webpage using JavaScript

ANS: You can use document.querySelectorAll('a') to get all anchor elements and then iterate through the list to update the href property of each one.

Q: What is the difference between attr and prop in jQuery for href

ANS: .attr('href', '...') modifies the HTML attribute, while .prop('href', '...') modifies the DOM property. For href, .prop() is often considered the more appropriate modern approach.

Q: How can I change only links that contain a specific word in their URL

ANS: Use an attribute selector like a[href*='specific-word'] in jQuery or document.querySelectorAll('a[href*="specific-word"]') in JavaScript.

Q: Can I change the href of a link without using jQuery

ANS: Yes, you can use standard JavaScript methods like document.getElementById() or document.querySelectorAll() to select the link and then use setAttribute('href', 'new-url') or directly modify the element.href property.

Q: How to change the href of a link with a specific ID

ANS: With JavaScript, use document.getElementById('yourLinkId').href = 'newUrl'. With jQuery, use $('#yourLinkId').attr('href', 'newUrl'); or $('#yourLinkId').prop('href', 'newUrl');.
