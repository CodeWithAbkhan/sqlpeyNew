“JavaScript Show Hide Elements: Best Practices Explained”

When developing interactive web pages, controlling the visibility of elements is a common requirement. JavaScript provides several methods to achieve this, each with its nuances. This exploration covers various techniques for making elements appear or disappear, detailing their implementation and the distinctions between them.

Demonstrating Element Visibility Control

Let’s delve into the practical application of showing and hiding elements.

Solution 1: Using style.display

One of the most direct methods involves manipulating the display CSS property.

JavaScript Function:

function manageElementVisibility(elementId, textId, buttonElement) {
    // Make the target element visible
    document.getElementById(elementId).style.display = 'block';

    // Conceal the placeholder text
    document.getElementById(textId).style.display = 'none';

    // Hide the trigger button
    buttonElement.style.display = 'none';
}

HTML Structure:

<td class="post-container">
    <a href="#" onclick="manageElementVisibility('details1', 'preview1', this); return false;">Edit Content</a>
    <span id="details1" style="display: none;">
        <textarea rows="10" cols="115">Enter your new content here.</textarea>
    </span>
    <span id="preview1">This is the initial content displayed.</span>
</td>

This approach toggles an element’s display property between 'block' (or other appropriate values like 'inline' or 'flex') and 'none'.

Solution 2: Differentiating style.visibility

While style.display removes an element from the document flow, style.visibility keeps its space reserved.

JavaScript Snippets:

To hide an element:

document.getElementById('someElementId').style.visibility = 'hidden';

To show an element:

document.getElementById('someElementId').style.visibility = 'visible';

The critical distinction here is that a visibility: hidden element still occupies space on the page, unlike display: none. You can explore this further on CSS Tricks about display vs. visibility .

Solution 3: The Subtle Advantage of style.display = ''

When re-displaying an element, using style.display = '' is often preferable to style.display = 'block'.

JavaScript Logic:

// To hide an element
document.getElementById('targetElement').style.display = 'none';

// To restore original display state
document.getElementById('targetElement').style.display = '';

Setting display to an empty string reverts it to its default or inherited value. This avoids potential layout shifts caused by forcing a specific display type (like block) where it might not have been initially intended, preventing unexpected margins or spacing issues.

Solution 4: Leveraging jQuery for Toggling

For projects utilizing jQuery, the toggle(), hide(), and show() methods offer a concise way to manage visibility.

jQuery Methods:

// Toggle visibility
$("#elementToToggle").toggle();

// Specifically hide
$("#elementToHide").hide();

// Specifically show
$("#elementToShow").show();

Event Handling Example:

$(document).ready(function() {
   $("#triggerButton").click(function(event) {
     // Perform actions on click
     $("#contentArea").toggle();
   });
 });

Solution 5: Utilizing the hidden Property

HTML5 introduced the hidden attribute, which can be manipulated directly via JavaScript.

JavaScript for hidden attribute:

To hide:

document.getElementById("contentBlock").hidden = true;

To show:

document.getElementById("contentBlock").hidden = false;

This is a semantic way to mark an element as hidden, and browsers typically handle the corresponding CSS (display: none;) automatically.

Solution 6: Modern Selectors with querySelector and querySelectorAll

Vanilla JavaScript provides powerful selectors for targeting elements.

Hiding by ID:

document.querySelector('#specific-element-id').style.display = 'none';

Hiding the first element with a specific class:

document.querySelector('.class-name-to-hide').style.display = 'none';

Hiding all elements with a specific class:

const elementsToHide = document.querySelectorAll('.class-name-to-hide');
for (const elem of elementsToHide) {
    elem.style.display = 'none';
}

Solution 7: Deeper Dive into jQuery’s css(), addClass()/removeClass(), and toggle()

This approach breaks down several jQuery strategies for visibility control.

Using css():

// Hide
$("#elementToHide").css("display", "none");
// Show (restore original)
$("#elementToHide").css("display", "");
  • Pros: Simple for direct style manipulation.
  • Cons: Can be problematic if the display property is used for other purposes; requires knowing the original value to restore.

Using addClass()/removeClass():

/* In your CSS */
.concealed { display: none; }

// Hide
$("#elementToHide").addClass("concealed");
// Show
$("#elementToHide").removeClass("concealed");
  • Pros: Separates styling from behavior, cleaner code.
  • Cons: Might not work if display is set inline or via JavaScript css().

Using toggle():

// Toggles between display:none and its original value
$("#elementToToggle").toggle();
  • Pros: Excellent for state-switching scenarios; handles state automatically.
  • Cons: Can be less explicit if you need to know the current state for other logic.

Using hide()/show():

// Hide
$("#elementToHide").hide();
// Show
$("#elementToShow").show();
  • Pros: Always reliable, restores original display values, explicit in intent.
  • Cons: Less efficient for a simple toggle compared to toggle().

For most cases, hide() and show() are recommended for their clarity and predictable behavior, unless a true toggle functionality is needed.

Solution 8: CSS Class-Based Toggling with JavaScript Control

A robust approach combines CSS for styling and JavaScript for state management.

Modified HTML:

<td class="post-item">
    <a class="edit-link" href="#" onclick="togglePostView(this.parentNode); return false;">Edit</a>
    <span id="answer-details" class="post-answer-section">
       <textarea rows="10" cols="115">Edit your text here.</textarea>
    </span>
    <span class="post-preview-text" id="text-preview">Initial text content.</span>
</td>

CSS Rules:

.post-item-editing .edit-link,
.post-item-editing .post-preview-text,
.post-item .post-answer-section {
    display: none;
}

JavaScript Function:

function togglePostView(postCell) {
    postCell.classList.add("post-item-editing");
}

This method leverages CSS class switching to alter the display state, keeping presentation concerns within CSS.

Solution 9: Extending Element.prototype

You can add custom hide() and show() methods directly to the Element prototype for a more object-oriented feel.

Prototype Extension:

Element.prototype.hide = function() {
    this.style.display = 'none';
}
Element.prototype.show = function() {
    this.style.display = ''; // Resets to default
}

Usage Examples:

// Using an ID
document.getElementById('my-element').hide();
document.getElementById('another-element').show();

// Using an image's onclick
// <img src="remove.png" onclick="this.hide()">

Solution 10: Table-Specific Display (table-row)

When dealing with table rows, you might need to set display to table-row instead of block.

JavaScript Function for Table Rows:

function showTableRow(rowId, textId, buttonElement) {
    document.getElementById(rowId).style.display = 'table-row';
    document.getElementById(textId).style.display = 'none';
    buttonElement.style.display = 'none';
}

HTML Snippet:

<td class="post-row-data">
    <a href="#" onclick="showTableRow('answerRow1', 'textRow1', this); return false;">Edit Row</a>
    <span id="answerRow1" style="display: none;">
        <textarea rows="10" cols="115"></textarea>
    </span>
    <span id="textRow1">Original row content.</span>
</td>

Solution 11: Inline Style Toggling and Class Toggling

These methods provide concise ways to flip visibility.

Inline Style Toggling:

// Toggle display property directly
element.style.display = (element.style.display === 'none' ? '' : 'none');

Example with Event Listener:

document.getElementById('toggleButton').addEventListener('click', () => {
    const contentElements = document.querySelectorAll('.content-item');
    contentElements.forEach(el => {
        el.style.display = (el.style.display === 'none' ? '' : 'none');
    });
});

CSS Class Toggling:

.hidden-content { display: none; }

// Toggle a class for visibility
document.querySelector('.control-button').addEventListener('click', () => {
    document.querySelector('.content-item').classList.toggle('hidden-content');
});

Solution 13 & 14: Minimalist Approaches with hidden

Reiterating the hidden attribute’s utility:

Directly Setting hidden:

document.getElementById("uniqueElementId").hidden = true; // To hide
document.getElementById("uniqueElementId").hidden = false; // To show

Using a Helper Function and CSS:

// JS Helper function
const toggleAttribute = (element, show = true) => element.setAttribute('hidden', !show);

// CSS Rule
[hidden="true"] { display: none; }

Usage:

// Show element
toggleAttribute(myElement, true);

// Hide element
toggleAttribute(myElement, false);

Solution 15: Dynamic Text and Visibility Toggle

This solution combines toggling visibility with changing the text of a control element.

JavaScript Function:

function toggleAndUpdate(elementId, controlElement) {
    const targetElement = document.getElementById(elementId);
    const currentDisplay = targetElement.style.display;
    targetElement.style.display = (currentDisplay === 'none' ? 'block' : 'none');

    controlElement.innerText = (controlElement.innerText === 'Edit' ? 'Close' : 'Edit');
}

HTML Structure:

<td class="entry-cell">
    <a href="#" onclick="toggleAndUpdate('editorSection', this); return false;">Edit</a>
    <span id="editorSection" style="display: none;">
        <textarea rows="10" cols="115">Your content here.</textarea>
    </span>
</td>

FAQs on JavaScript Show Hide Elements

Q How do I show an HTML element using JavaScript

ANS You can show an HTML element by setting its style.display property to a suitable value (like ‘block’, ‘inline’, or ‘flex’) or by setting its hidden attribute to false. Alternatively, if you’ve hidden it with a CSS class, you can remove that class.

Q What is the difference between display none and visibility hidden

ANS display: none; removes the element from the document flow entirely; it takes up no space. visibility: hidden; makes the element invisible but still reserves its space in the layout.

Q Is there a way to toggle an element's visibility with a single line of JavaScript

ANS Yes, you can use element.style.display = (element.style.display === 'none' ? '' : 'none'); or jQuery’s $('#elementId').toggle(); for a concise toggle. The classList.toggle('hidden-class') method is also very effective.

Q Can I hide multiple elements at once with JavaScript

ANS Yes, you can use document.querySelectorAll() to select multiple elements and then iterate over the returned NodeList to apply your hiding logic to each one.

Q What is the best practice for showing and hiding elements

ANS For simple show/hide, directly manipulating style.display or using the hidden attribute is effective. For more complex styling or reusability, adding/removing CSS classes is often preferred. jQuery’s hide(), show(), and toggle() provide convenient abstractions.
