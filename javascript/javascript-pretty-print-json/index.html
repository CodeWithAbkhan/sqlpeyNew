“JavaScript: Improve JSON Readability with Pretty Printing”

When dealing with JSON data in JavaScript, especially during development and debugging, a “pretty-printed” format significantly improves readability. This involves adding indentation and line breaks to make nested structures easier to follow. Beyond simple formatting, syntax highlighting can further enhance clarity by visually distinguishing data types like strings, numbers, booleans, and keys.

Formatting JSON with JSON.stringify

The most direct way to achieve pretty printing in JavaScript is by utilizing the built-in JSON.stringify() method with its optional third argument for indentation.

Solution 1 (Accepted): Native Pretty Printing

JSON.stringify() natively supports pretty printing through its third argument, which specifies the indentation string.

const obj = {
    a: 1,
    'b': 'foo',
    c: [false, 'false', null, 'null', {
        d: {
            e: 1.3e5,
            f: '1.3e5'
        }
    }]
};

// Pretty print with 2-space indentation
const str = JSON.stringify(obj, null, 2);
console.log(str);

This method is straightforward and efficient for basic formatting.

Solution 3 (Accepted) & Solution 9 (Accepted): Using Tabs for Indentation

Alternatively, you can use tabs for indentation, which is often preferred in certain coding styles.

// Using tabs for indentation
const formattedWithTabs = JSON.stringify(jsonobj, null, '\t');
console.log(formattedWithTabs);

Solution 4 (Accepted): Flexible Indentation

This solution reiterates the flexibility of using either spaces or tabs for indentation.

// Using 2 spaces for indentation
console.log(JSON.stringify(obj, null, 2));

// Using tabs for indentation
console.log(JSON.stringify(obj, null, '\t'));

Solution 12 (Accepted): JSON.stringify with Replacer Function

The second argument of JSON.stringify can also be a replacer function, allowing for value transformation during the stringification process.

// Example with a replacer function (though null is common for simple pretty printing)
const jsonString = JSON.stringify(anObject, null, '\t');

Solution 14 (Accepted): Direct HTML Output

For immediate display in an HTML context, you can directly inject the pretty-printed JSON into an element.

document.documentElement.innerHTML = '<pre>' + JSON.stringify(obj, null, 2) + '</pre>';

Adding Syntax Highlighting

While JSON.stringify handles formatting, visual distinction of data types often requires additional logic for syntax highlighting.

Solution 1 (Accepted): Manual Syntax Highlighting with Regex

This approach uses regular expressions to identify different JSON components (keys, strings, numbers, booleans, null) and wraps them in <span> tags with corresponding CSS classes.

function syntaxHighlight(json) {
    if (typeof json != 'string') {
        json = JSON.stringify(json, undefined, 2);
    }
    json = json.replace(/&amp;/g, '&amp;amp;').replace(/&lt;/g, '&amp;lt;').replace(/&gt;/g, '&amp;gt;');
    return json.replace(/("(\\u[a-zA-Z0-9]{4}|\\[^u]|[^\\"])*"(\s*:)?|\b(true|false|null)\b|-?\d+(?:\.\d*)?(?:[eE][+\-]?\d+)?)/g, function (match) {
        var cls = 'number';
        if (/^"/.test(match)) {
            if (/:$/.test(match)) {
                cls = 'key';
            } else {
                cls = 'string';
            }
        } else if (/true|false/.test(match)) {
            cls = 'boolean';
        } else if (/null/.test(match)) {
            cls = 'null';
        }
        return '<span class="' + cls + '">' + match + '</span>';
    });
}

function output(inp) {
    document.body.appendChild(document.createElement('pre')).innerHTML = inp;
}

const obj = { a: 1, 'b': 'foo', c: [false, 'false', null, 'null', { d: { e: 1.3e5, f: '1.3e5' } }] };
const str = JSON.stringify(obj, undefined, 4);

output(str);
output(syntaxHighlight(str));

To apply this, you would need corresponding CSS styles for the .string, .number, .boolean, .null, and .key classes.

Solution 6 (Accepted): Console Logging with Styles

This method customizes console.log to provide colored output directly in the browser’s developer console.

function JSONstringify(json) {
    if (typeof json != 'string') {
        json = JSON.stringify(json, undefined, '\t');
    }

    var arr = [],
        _string = 'color:green',
        _number = 'color:darkorange',
        _boolean = 'color:blue',
        _null = 'color:magenta',
        _key = 'color:red';

    json = json.replace(/("(\\u[a-zA-Z0-9]{4}|\\[^u]|[^\\"])*"(\s*:)?|\b(true|false|null)\b|-?\d+(?:\.\d*)?(?:[eE][+\-]?\d+)?)/g, function (match) {
        var style = _number;
        if (/^"/.test(match)) {
            if (/:$/.test(match)) {
                style = _key;
            } else {
                style = _string;
            }
        } else if (/true|false/.test(match)) {
            style = _boolean;
        } else if (/null/.test(match)) {
            style = _null;
        }
        arr.push(style);
        arr.push('');
        return '%c' + match + '%c';
    });

    arr.unshift(json);
    console.log.apply(console, arr);
}

const obj = { a: 1, 'b': 'foo', c: [false, null, { d: { e: 1.3e5 } }] };
JSONstringify(obj);

This can be particularly useful for debugging without leaving the console.

Solution 10 (Accepted): Terminal-Friendly Highlighting

This solution adapts the regex-based highlighting for terminal output using ANSI escape codes.

function prettyJ(json) {
    if (typeof json !== 'string') {
        json = JSON.stringify(json, undefined, 2);
    }
    return json.replace(/("(\\u[a-zA-Z0-9]{4}|\\[^u]|[^\\"])*"(\s*:)?|\b(true|false|null)\b|-?\d+(?:\.\d*)?(?:[eE][+\-]?\d+)?)/g,
        function (match) {
            let cls = "\x1b[36m"; // Cyan for general
            if (/^"/.test(match)) {
                if (/:$/.test(match)) {
                    cls = "\x1b[34m"; // Blue for keys
                } else {
                    cls = "\x1b[32m"; // Green for strings
                }
            } else if (/true|false/.test(match)) {
                cls = "\x1b[35m"; // Magenta for booleans
            } else if (/null/.test(match)) {
                cls = "\x1b[31m"; // Red for null
            }
            return cls + match + "\x1b[0m"; // Reset color
        }
    );
}

const thing = { name: "Example", value: 100, active: true };
console.log(prettyJ(thing));

Solution 26 (Accepted): Customizable Highlighting

This provides a flexible approach to syntax highlighting with configurable color mappings.

const clsMap = [
    [/^".*:$/, "key"], // Matches keys ending with a colon
    [/^"/, "string"],   // Matches strings
    [/true|false/, "boolean"], // Matches booleans
    [/null/, "null"],     // Matches null
    [/.*,/, "punctuation"], // Matches punctuation followed by comma
    [/.*/, "number"],    // Matches anything else as numbers
];

const syntaxHighlight = obj => JSON.stringify(obj, null, 4)
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/("(\\u[a-zA-Z0-9]{4}|\\[^u]|[^\\"])*"(\s*:)?|\b(true|false|null)\b|-?\d+(?:\.\d*)?(?:[eE][+\-]?\d+)?)/g, match =>
        `<span class="${clsMap.find(([regex]) => regex.test(match))[1]}">${match}</span>`);

const dataToHighlight = { user: "test", id: 123, settings: { theme: "dark" } };
document.body.innerHTML += `<pre>${syntaxHighlight(dataToHighlight)}</pre>`;

Handling JSON Strings vs. Objects

When working with JSON, it’s crucial to differentiate between a JSON string and a JavaScript object. Methods like JSON.stringify operate on objects, while parsing is needed to convert a JSON string into an object.

Solution 2 (Accepted): Parsing JSON Strings

If you start with a JSON string, you must parse it into an object before applying pretty printing.

const jsonString = '{"some":"json"}';
const jsonPretty = JSON.stringify(JSON.parse(jsonString), null, 2);
console.log(jsonPretty);

FAQs on JavaScript JSON Pretty Printing

Q: What is the simplest way to pretty print JSON in JavaScript

ANS: Use JSON.stringify(yourObject, null, 2) or JSON.stringify(yourObject, null, '\t') to add indentation with spaces or tabs respectively.

Q: How can I add syntax highlighting to JSON in JavaScript

ANS: You can use regular expressions to find JSON components and wrap them in <span> tags with CSS classes, or leverage libraries like Prism.js or cli-highlight.

Q: What if my JSON is already a string

ANS: Parse the JSON string into a JavaScript object first using JSON.parse() before applying pretty printing or highlighting methods.

Q: Can I pretty print JSON directly in the browser console

ANS: Yes, methods like console.dir() or custom functions that utilize console.log with format specifiers (%c) or styled output can achieve this.

Q: Are there libraries that help with JSON formatting

ANS: Several libraries exist, such as neatJSON, json-markup, and cli-highlight, which offer advanced features for formatting and styling JSON.
