“JavaScript Techniques to Convert Object to Key-Value Array Pairs”

How can a JavaScript object containing key-value data be reliably converted into an array where each element is itself an array containing the original key and its corresponding value, like [[key1, value1], [key2, value2]]? This conversion is essential for iteration, sorting, or integration with APIs expecting array structures. Several robust techniques exist, utilizing modern ECMAScript features and established methods.

Let’s examine various accepted approaches for achieving this transformation.

Primary Methods Utilizing Built-in Object Functions

The most direct and modern solutions often involve Object.entries().

Method 1: Direct Use of Object.entries()

Object.entries() is specifically designed to return an array of a given object’s own enumerable string-keyed property [key, value] pairs.

const dataObject = {"1":5,"2":7,"3":0,"4":0,"5":0,"6":0,"7":0,"8":0,"9":0,"10":0,"11":0,"12":0};
const resultEntries = Object.entries(dataObject);

console.log(resultEntries);
// Output: [["1", 5], ["2", 7], ["3", 0], ..., ["12", 0]]

This method produces the exact structure requested, though note that the keys extracted are always strings.

Method 2: Combining Object.keys() and Array.prototype.map()

This approach first retrieves all keys and then maps over them to construct the desired [key, value] arrays.

const dataObject = {"A": 29, "B": 42};
const resultArray = Object.keys(dataObject).map(key => [`${key}`, dataObject[key]]);

console.log(resultArray);
// Output: [["A", 29], ["B", 42]]

An alternative flavor using standard map function syntax:

const dataObject = {
  "1": 5, "2": 7, "3": 0, "4": 0, "5": 0, "6": 0, "7": 0,
  "8": 0, "9": 0, "10": 0, "11": 0, "12": 0
};
// Ensures keys are explicitly converted to strings if they weren't already
const stringKeyedResult = Object.keys(dataObject).map(function(key) {
    return [String(key), dataObject[key]];
});

console.log(stringKeyedResult);

Method 3: Using Array.from() with Object.keys()

This provides a declarative way to build the array from the keys:

const dataObject = { 'ID_001': 29, 'ID_002': 42 };
// The mapping function generates the [key, value] pair
const arrayFromKeys = Array.from(Object.keys(dataObject), key => [`${key}`, dataObject[key]]);

console.log(arrayFromKeys);
// Output: [["ID_001", 29], ["ID_002", 42]]

Dealing with Numeric Keys: Ensuring Integer Keys in the Output Array

If the requirement specifies that the keys in the resulting array pairs must be numbers rather than strings (even if the object keys were initially defined as strings), an extra coercion step is necessary.

Method 4: Mapping Object.entries() to Coerce Keys to Numbers

We can destructure the entries and explicitly convert the key (k) to a number using the unary plus operator (+k) or Number(k).

const stringKeyedObject = {"1":5,"2":7,"3":0};

// Using map with array destructuring for concise syntax
const numericKeyedResult = Object.entries(stringKeyedObject)
    .map(([k, v]) => [+k, v]); // +k coerces string key to number

console.log(numericKeyedResult);
// Output: [[1, 5], [2, 7], [3, 0]]

Modification for In-Place Mutation vs. New Array Creation:

When converting keys to numbers, a discussion arises regarding memory efficiency: creating new arrays during mapping versus modifying existing arrays in place.

  • Creating New Arrays (Concise):

    const toNewNumericPairs = input => Object.entries(input).map(([k, v]) => [+k, v]);

    This is cleaner but creates a new inner array for every key-value pair.

  • Modifying In-Place (Potentially Memory Frugal): This modifies the array returned by Object.entries() directly, avoiding the creation of new inner arrays during the mapping iteration.

    const toNumericPairsInPlace = input => {
  const entries = Object.entries(input);
  entries.forEach(entry => entry[0] = +entry[0]); // Modify the first element (key)
  return entries;
};

Method 5: Leveraging Map for Order Preservation and Numeric Keys

If you require strict ordering and the ability to use non-string keys later, converting the object to a Map first, and then spreading the Map back into an array, is powerful. When creating a Map from an object, string keys are treated as strings initially, but standard iteration preserves insertion order (ECMAScript 2015+).

const dataObject = { 1: 5, 2: 7, 3: 0 }; // Keys might be treated as numbers by JS engine in object creation context

// Convert to Map, then spread back to an array of entries
const arrayFromMap = [...new Map(Object.entries(dataObject))];

console.log(arrayFromMap);
// Output: [[1, 5], [2, 7], [3, 0]] (Keys often retain numeric type when spreading from Map if source keys were numerical in context)

Alternative Strategies and Legacy Approaches

Method 6: Using Object.values() (If Keys are Unnecessary or Sequential)

If you only need the values and are certain the keys are sequential (starting from ‘1’ or ‘0’ as appropriate), Object.values() suffices, but this loses key information. If keys are sequential numerical strings, you can reconstruct the index:

const sequentialObject = {"1":5,"2":7,"3":0}; 

// idx starts at 0, so we increment it to match key '1', '2', '3' etc.
let sequentialResult = Object.values(sequentialObject)
    .map((value, idx) => ([++idx, value]));

console.log(sequentialResult);
// Output: [[1, 5], [2, 7], [3, 0]]

Method 7: Using for...in Loop (Procedural Method)

A more traditional way, especially useful if backward compatibility with older environments is a concern, involves iterating with for...in.

const proceduralObject = { "10": 5, "2": 7, "3": 0 };
const proceduralArray = [];

for (const key in proceduralObject) {
    // It is important to check hasOwnProperty in procedural loops
    if (Object.prototype.hasOwnProperty.call(proceduralObject, key)) {
        proceduralArray.push([key, proceduralObject[key]]);
    }
}

console.log(proceduralArray);
// Output: [["10", 5], ["2", 7], ["3", 0]] (Order depends on JavaScript engine iteration rules for numeric strings)

Method 8: Recursive Conversion for Deeply Nested Objects

For complex, nested objects requiring the output format [key, [nested_array]], recursion is necessary.

const nestedData = {
  name: { firstName: "Sangram", lastName: "Desai" },
  address: { city: "Kankavali", pin: "416602" },
};

function convertObjectToNestedArray(obj) {
    let resultArray = [];
    for (let key in obj) {
        if (Object.prototype.hasOwnProperty.call(obj, key)) {
            const value = obj[key];
            if (typeof value === "object" && value !== null && !Array.isArray(value)) {
                // Recurse for nested objects
                resultArray.push([key, convertObjectToNestedArray(value)]);
            } else {
                resultArray.push([key, value]);
            }
        }
    }
    return resultArray;
}

const deeplyConverted = convertObjectToNestedArray(nestedData);
console.log(JSON.stringify(deeplyConverted, null, 2));
/* Output structure example:
[
  ["name", [
    ["firstName", "Sangram"],
    ["lastName", "Desai"]
  ]],
  ["address", [
    ["city", "Kankavali"],
    ["pin", "416602"]
  ]]
]
*/

Method 9: Object to Array via Object.assign() (For Indexing)

If the object keys are simple numerical indices starting from 0, Object.assign() can be used to shallowly copy properties into a new array instance:

const indexObject = { 0: 100, 1: 200, 2: 300 };
const assignedArray = Object.assign([], indexObject);

console.log(assignedArray);
// Output: [100, 200, 300] (Note: This yields an array of values, not [key, value] pairs)

Method 10: Using Lodash (External Library)

If Lodash is available, functions like _.toPairs() directly replicate Object.entries(), and _.map() offers flexible iteration control:

// Assuming Lodash (_) is loaded
const lodashObject = { "art": { id: 1, title: "aaaa" }, "fiction": { id: 22, title: "7777"} };

// Get [key, value] pairs:
const lodashPairs = _.toPairs(lodashObject);
// Output: [["art", { id: 1, title: "aaaa" }], ["fiction", { id: 22, title: "7777" }]]

// Transform pairs while keeping keys:
const transformedWithKey = _.map(lodashObject, (val, key) => {
    return { ...val, genre: key };
});
// Output: [{ id: 1, title: "aaaa", genre: "art" }, { id: 22, title: "7777", genre: "fiction" }]

FAQs on JavaScript Object to Key-Value Array Conversion

Q: What is the simplest way to convert an object to an array of [key, value] pairs

ANS: Use the built-in Object.entries(obj) method. It directly returns the array structure you seek: [[key1, value1], [key2, value2]].

Q: Object entries returns keys as strings, how to get numeric keys in the resulting array

ANS: Apply .map() after Object.entries() and use the unary plus operator (+k) or Number(k) to coerce the string key to a number: Object.entries(obj).map(([k, v]) => [+k, v]).

Q: Can I get only the values from an object as an array

ANS: Yes, use Object.values(obj). If keys are ordered numerically in the object, you can reconstruct indices using Object.values(obj).map((e, idx) => ([++idx, e])) to generate indexed pairs if needed.
var obj = {"1":5,"2":7,"3":0,"4":0,"5":0,"6":0,"7":0,"8":0,"9":0,"10":0,"11":0,"12":0}
var result = Object.keys(obj).map((key) =&gt; [key, obj[key]]);

console.log(result);
