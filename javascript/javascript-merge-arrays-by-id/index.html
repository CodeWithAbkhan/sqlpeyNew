“JavaScript: Merge Arrays of Objects by ID”

When working with JavaScript, you’ll frequently encounter situations where you need to combine data from different sources. A common task involves merging arrays of objects, where each object contains related information. The key challenge often lies in matching and merging these objects based on a shared identifier, such as an id field. This process ensures that related data from separate arrays is consolidated into a single, more informative object.

There are several effective strategies to achieve this, each with its own nuances regarding efficiency and flexibility. Let’s explore some of the most robust methods for merging arrays of objects based on a common id.

Merging Based on Array Order (Same Order)

If you know that the objects in both arrays are in the same order and correspond directly by their index, a straightforward approach involves iterating through one array and mapping its elements with corresponding elements from the other.

let arrayOne = [
    { id: "abdc4051", date: "2017-01-24" },
    { id: "abdc4052", date: "2017-01-22" }
];

let arrayTwo = [
    { id: "abdc4051", name: "ab" },
    { id: "abdc4052", name: "abc" }
];

let mergedArraySameOrder = [];

for (let i = 0; i < arrayOne.length; i++) {
  mergedArraySameOrder.push({
   ...arrayOne[i],
   ...arrayTwo[i]
  });
}

console.log("Merged (Same Order):", mergedArraySameOrder);
// Output: Merged (Same Order): [ { id: 'abdc4051', date: '2017-01-24', name: 'ab' }, { id: 'abdc4052', date: '2017-01-22', name: 'abc' } ]

This method is efficient when the order is guaranteed. You can also achieve this with map and Object.assign:

let arrayOneMap = [
    { id: "abdc4051", date: "2017-01-24" },
    { id: "abdc4052", date: "2017-01-22" }
];

let arrayTwoMap = [
    { id: "abdc4051", name: "ab" },
    { id: "abdc4052", name: "abc" }
];

let mergedArrayMap = arrayOneMap.map((item, i) => Object.assign({}, item, arrayTwoMap[i]));

console.log("Merged (Map & Assign):", mergedArrayMap);
// Output: Merged (Map & Assign): [ { id: 'abdc4051', date: '2017-01-24', name: 'ab' }, { id: 'abdc4052', date: '2017-01-22', name: 'abc' } ]

Merging with Dynamic ID Matching (Different Order)

When the order of elements in the arrays might differ, you need a method that matches objects based on their id. The find method is excellent for this purpose.

let arrayOneFind = [
  { id: "abdc4051", date: "2017-01-24" },
  { id: "abdc4052", date: "2017-01-22" }
];

let arrayTwoFind = [
  { id: "abdc4051", name: "ab" },
  { id: "abdc4052", name: "abc" }
];

let mergedArrayFind = [];

for(let i = 0; i < arrayOneFind.length; i++) {
  mergedArrayFind.push({
   ...arrayOneFind[i],
   ...(arrayTwoFind.find((itemInner) => itemInner.id === arrayOneFind[i].id))
  });
}

console.log("Merged (Find Match):", mergedArrayFind);
// Output: Merged (Find Match): [ { id: 'abdc4051', date: '2017-01-24', name: 'ab' }, { id: 'abdc4052', date: '2017-01-22', name: 'abc' } ]

A more concise way using map and find:

const arrA = [
  { id: "abdc4051", date: "2017-01-24" },
  { id: "abdc4052", date: "2017-01-22" }
];
const arrB = [
  { id: "abdc4051", name: "ab" },
  { id: "abdc4052", name: "abc" }
];

const mergedById = arrA.map(item => ({
    ...item,
    ...arrB.find(({ id }) => id === item.id)
}));

console.log("Merged (Map & Find):", mergedById);
// Output: Merged (Map & Find): [ { id: 'abdc4051', date: '2017-01-24', name: 'ab' }, { id: 'abdc4052', date: '2017-01-22', name: 'abc' } ]

Efficient Merging with Maps

For scenarios involving potentially different array sizes or when performance is critical, using a Map can be highly effective. This approach allows for efficient lookups and merging, even when keys differ slightly.

const arrayOneMapData = [
  { id: "abdc4051", date: "2017-01-24" },
  { id: "abdc4052", date: "2017-01-22" },
  { id: "abdc4053", date: "2017-01-22" } // Item unique to arrayOneMapData
];
const arrayTwoMapData = [
  { nameId: "abdc4051", name: "ab" }, // Different key name
  { nameId: "abdc4052", name: "abc" }
];

const map = new Map();
arrayOneMapData.forEach(item => map.set(item.id, item));
arrayTwoMapData.forEach(item => map.set(item.nameId, { ...map.get(item.nameId), ...item }));
const mergedArrayMapData = Array.from(map.values());

console.log("Merged (Map Data):", mergedArrayMapData);
/* Output:
Merged (Map Data): [
  { id: 'abdc4051', date: '2017-01-24', nameId: 'abdc4051', name: 'ab' },
  { id: 'abdc4052', date: '2017-01-22', nameId: 'abdc4052', name: 'abc' },
  { id: 'abdc4053', date: '2017-01-22' }
]
*/

This method is robust as it correctly handles cases where an id might exist in one array but not the other, and also accommodates differing key names by explicitly setting the key for each array.

Merging Multiple Arrays by Key

For merging more than two arrays, a flexible function can be created. This generic approach leverages reduce and Object.assign to combine an arbitrary number of arrays based on a specified key.

const joinById = (...lists) =>
    Object.values(
        lists.reduce(
            (accumulator, currentList) => {
                currentList.forEach((record) => {
                    if (accumulator[record.id]) {
                        accumulator[record.id] = Object.assign(accumulator[record.id], record);
                    } else {
                        accumulator[record.id] = record;
                    }
                });
                return accumulator;
            },
            {}
        )
    );

let list1 = [
    { id: "abdc4051", date: "2017-01-24" },
    { id: "abdc4052", date: "2017-01-22" }
];
let list2 = [
    { id: "abdc4051", name: "ab" },
    { id: "abdc4052", name: "abc" }
];
let list3 = [
    { id: "abdc4051", status: "active" },
    { id: "abdc4053", status: "pending" }
];

let joinedMultiple = joinById(list1, list2, list3);
console.log("Merged Multiple Arrays:", joinedMultiple);
/* Output:
Merged Multiple Arrays: [
  { id: 'abdc4051', date: '2017-01-24', name: 'ab', status: 'active' },
  { id: 'abdc4052', date: '2017-01-22', name: 'abc' },
  { id: 'abdc4053', status: 'pending' }
]
*/

This joinById function is efficient, processing each list in linear time relative to its size, resulting in an overall O(n) complexity where n is the total number of records across all lists.

Using Lodash for Merging

The popular utility library Lodash provides convenient functions for object and array manipulation. _.merge can directly merge objects, and when used with arrays, it offers a powerful way to combine them.

// Assuming lodash is imported or available globally
// import _ from 'lodash';

let lodashArr1 = [
    { id: "abdc4051", date: "2017-01-24" },
    { id: "abdc4052", date: "2017-01-22" }
];

let lodashArr2 = [
    { id: "abdc4051", name: "ab" },
    { id: "abdc4052", name: "abc" }
];

// Note: _.merge flattens the arrays and merges based on object structure.
// For array merging by id, a different lodash approach or a custom function might be better.
// A common pattern involves keying the arrays first.

const keyBy = (arr, key) => arr.reduce((acc, item) => ({ ...acc, [item[key]]: item }), {});

const lodashMerged = Object.values({
  ...keyBy(lodashArr1, 'id'),
  ...keyBy(lodashArr2, 'id')
});

console.log("Merged with Lodash (keyBy approach):", lodashMerged);
/* Output:
Merged with Lodash (keyBy approach): [
  { id: 'abdc4051', date: '2017-01-24', name: 'ab' },
  { id: 'abdc4052', date: '2017-01-22', name: 'abc' }
]
*/

If your goal is to merge based on a specific key, the keyBy approach combined with spreading is often more predictable than directly using _.merge on arrays, which can behave differently based on array structure.

TypeScript Solution with Key Flexibility

For projects using TypeScript, a robust and generic solution can be crafted to handle merging with customizable key selection. This approach ensures type safety and adaptability.

// Requires TypeScript and potentially lodash for keyBy and values
// If not using lodash, implement keyBy and values equivalents.
import { keyBy, values } from 'lodash'; // Assuming lodash is available

interface IdentifiedObject {
  id?: string | number;
  [key: string]: any; // Allows for other properties
}

function mergeArraysById<T extends IdentifiedObject>(
  array1: T[],
  array2: T[]
): T[] {
  const mergedObjectMap: { [key: string]: T } = keyBy(array1, 'id');

  const finalArray: T[] = [];

  for (const obj of array2) {
    if (obj.id && mergedObjectMap[obj.id]) {
      mergedObjectMap[obj.id] = {
        ...mergedObjectMap[obj.id],
        ...obj,
      };
    } else {
      finalArray.push(obj);
    }
  }

  values(mergedObjectMap).forEach(obj => {
    finalArray.push(obj);
  });

  return finalArray;
}

// Example Usage:
const tsArray1 = [
  { id: "abdc4051", date: "2017-01-24" },
  { id: "abdc4052", date: "2017-01-22" }
];

const tsArray2 = [
  { id: "abdc4051", name: "ab" },
  { id: "abdc4052", name: "abc" },
  { id: "abdc4053", name: "xyz" } // Item unique to array2
];

const tsMergedArray = mergeArraysById(tsArray1, tsArray2);
console.log("TypeScript Merged:", tsMergedArray);
/* Output:
TypeScript Merged: [
  { id: 'abdc4051', date: '2017-01-24', name: 'ab' },
  { id: 'abdc4052', date: '2017-01-22', name: 'abc' },
  { id: 'abdc4053', name: 'xyz' }
]
*/

This TypeScript function handles cases where objects might exist in only one of the arrays, ensuring all unique items are preserved.

Python Solution for Merging

For those working with Python, a similar logic can be applied to merge lists of dictionaries.

def merge_lists_by_key(list1, list2, merge_key):
    merged_dict = {}
    # Process first list
    for item in list1:
        key = item.get(merge_key)
        if key is not None:
            merged_dict[key] = item.copy() # Use copy to avoid modifying original

    # Process second list
    for item in list2:
        key = item.get(merge_key)
        if key is not None:
            if key in merged_dict:
                # Merge properties, second list's properties overwrite first
                merged_dict[key].update(item)
            else:
                # Item only exists in the second list
                merged_dict[key] = item.copy()

    return list(merged_dict.values())

# Example Usage:
array1_py = [
    {"id": "abdc4051", "date": "2017-01-24"},
    {"id": "abdc4052", "date": "2017-01-22"}
]
array2_py = [
    {"id": "abdc4051", "name": "ab"},
    {"id": "abdc4052", "name": "abc"},
    {"id": "abdc4053", "name": "xyz"} # Unique to array2
]

merged_python = merge_lists_by_key(array1_py, array2_py, merge_key="id")
print("Python Merged:", merged_python)
# Output: Python Merged: [{'id': 'abdc4051', 'date': '2017-01-24', 'name': 'ab'}, {'id': 'abdc4052', 'date': '2017-01-22', 'name': 'abc'}, {'id': 'abdc4053', 'name': 'xyz'}]

This Python function efficiently merges lists by creating a dictionary keyed by the specified merge_key, allowing for flexible property merging.

Handling Complex Merging Scenarios

For more intricate merging requirements, such as dealing with nested objects or needing fine-grained control over merge strategies, custom recursive functions or libraries like Lodash become invaluable. The core idea is to iterate through the arrays, using a lookup mechanism (like a Map or an object) to efficiently find and merge matching records.

For instance, a flexible function that takes a key and multiple arrays can be constructed:

// Generic merge function adaptable for multiple arrays
function mergeArraysGeneric(key, ...lists) {
    const map = new Map();

    lists.forEach(list => {
        list.forEach(item => {
            const keyValue = item[key];
            if (map.has(keyValue)) {
                map.set(keyValue, { ...map.get(keyValue), ...item });
            } else {
                map.set(keyValue, item);
            }
        });
    });

    return Array.from(map.values());
}

const dataSet1 = [{ id: 1, value: 'A' }, { id: 2, value: 'B' }];
const dataSet2 = [{ id: 1, count: 10 }, { id: 3, count: 30 }];
const dataSet3 = [{ id: 2, status: 'active' }, { id: 1, extra: 'info' }];

const fullyMerged = mergeArraysGeneric('id', dataSet1, dataSet2, dataSet3);
console.log("Fully Merged (Generic):", fullyMerged);
/* Output:
Fully Merged (Generic): [
  { id: 1, value: 'A', count: 10, extra: 'info' },
  { id: 2, value: 'B', status: 'active' },
  { id: 3, count: 30 }
]
*/

This generic function is highly adaptable, capable of merging any number of arrays based on a shared key, providing a scalable solution for complex data integration tasks.

FAQs on JavaScript Array Merging

Q: How do I merge two arrays of objects in JavaScript based on their ID

ANS: You can iterate through one array and use the find method on the second array to match objects by their id, then combine their properties using the spread syntax (...). A Map can also be used for more efficient lookups, especially with larger datasets.

Q: What happens if an ID exists in only one of the arrays

ANS: Most common merging strategies will include the object from the single array in the result. If an object from the first array doesn’t have a match in the second, it’s included as is. If an object exists only in the second array, it’s often added to the result as well, depending on the specific implementation.

Q: Can I merge arrays if the key name is different

ANS: Yes, when using methods like Map or custom functions, you can specify the key to look up in each array, allowing for merging even when the identifier property has different names (e.g., id in one array and userId in another).

Q: Which method is best for merging arrays by ID

ANS: The “best” method depends on your specific needs:

  • For guaranteed same order: Simple iteration or map with Object.assign.
  • For differing order or potential missing matches: map with find, or a Map-based approach.
  • For performance with large datasets or multiple arrays: Map-based solutions or a well-optimized custom reduce function.
  • For TypeScript projects: A typed generic function offers safety and flexibility.
