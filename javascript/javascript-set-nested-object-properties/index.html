“JavaScript: Set Nested Object Properties Safely”

When working with JavaScript objects, a common requirement is to dynamically set a property within a nested structure. This often involves a string path, like "user.address.city", that needs to be translated into nested object assignments. However, simply assigning values can lead to unintended data loss if intermediate properties are not objects. This post explores various effective techniques to address this, ensuring the integrity of your existing data.

The Challenge: Navigating and Creating Nested Properties

Imagine you have an object and a path string. The goal is to set a value at that specific path, creating any necessary intermediate objects if they don’t already exist.

Consider this scenario:

let userProfile = {
  name: "Alice",
  contact: {
    email: "alice@example.com"
  }
};

let newPropertyPath = "contact.phone.mobile";
let newValue = "123-456-7890";

You want to update userProfile so it becomes:

{
  name: "Alice",
  contact: {
    email: "alice@example.com",
    phone: {
      mobile: "123-456-7890"
    }
  }
}

The core problem is how to navigate the contact.phone path and create the phone object if it doesn’t exist before assigning the mobile property.

Solution Approaches

Several approaches have been proposed to solve this, each with its own nuances and performance characteristics.

Solution 1: Recursive Assignment (Solution 1, Solution 3)

This method uses recursion to traverse the path, creating objects as needed.

Solution 1 (Recursive with split):

This function assign takes an object, a property path (either a string or an array), and a value. It splits the path and recursively calls itself, creating new objects for non-existent properties.

function assign(obj, prop, value) {
    if (typeof prop === "string") {
        prop = prop.split(".");
    }

    if (prop.length > 1) {
        const segment = prop.shift();
        // Ensure the segment is an object before recursing
        obj[segment] = Object.prototype.toString.call(obj[segment]) === "[object Object]"
                       ? obj[segment]
                       : {};
        assign(obj[segment], prop, value);
    } else {
        obj[prop[0]] = value;
    }
    return obj; // Return the modified object for chaining or clarity
}

let userProfile1 = { name: "Alice" };
assign(userProfile1, "contact.phone.mobile", "123-456-7890");
console.log("Solution 1 Output:", JSON.stringify(userProfile1, null, 2));
// Expected: { "name": "Alice", "contact": { "phone": { "mobile": "123-456-7890" } } }

Solution 3 (Recursive with explicit object creation):

Similar to the first, this version setDeepValue ensures that a property becomes an object if it’s null or not an object before the recursive call.

function setDeepValue(obj, value, path) {
    if (typeof path === "string") {
        path = path.split('.');
    }

    if (path.length > 1) {
        const segment = path.shift();
        // Create a new object if the property doesn't exist or isn't an object
        if (obj[segment] == null || typeof obj[segment] !== 'object') {
             obj[segment] = {};
        }
        setDeepValue(obj[segment], value, path);
    } else {
        obj[path[0]] = value;
    }
    return obj; // Return the object for potential chaining
}

let userProfile3 = { name: "Bob" };
setDeepValue(userProfile3, "987-654-3210", "contact.phone.landline");
console.log("Solution 3 Output:", JSON.stringify(userProfile3, null, 2));
// Expected: { "name": "Bob", "contact": { "phone": { "landline": "987-654-3210" } } }

Solution 4: Iterative Assignment (Solution 4, Solution 6, Solution 8, Solution 10, Solution 11)

These solutions employ an iterative approach, typically using a loop or reduce, to navigate and set properties.

Solution 4 (Iterative with for loop):

This version iterates through the path segments, assigning empty objects as needed.

var nestedObjectAssignmentFor = function(obj, propString, value) {
    var propNames = propString.split('.'),
        propLength = propNames.length - 1,
        tmpObj = obj;

    for (var i = 0; i <= propLength; i++) {
        // Assign the value on the last iteration, otherwise assign an empty object
        tmpObj = tmpObj[propNames[i]] = i !== propLength ? {} : value;
    }
    return obj;
}

let userProfile4 = {};
nestedObjectAssignmentFor(userProfile4, "config.network.ports.http", 8080);
console.log("Solution 4 Output:", JSON.stringify(userProfile4, null, 2));
// Expected: { "config": { "network": { "ports": { "http": 8080 } } } }

Solution 8 (Iterative with reduce):

This is a concise approach using reduce to traverse the path and set the value.

function setValue(object, path, value) {
    const fullPath = path.split('.');
    const way = fullPath.slice(); // Create a copy to avoid modifying original array
    const last = way.pop();

    way.reduce((accumulator, currentKey) => {
        // If the property doesn't exist or isn't an object, initialize it
        return accumulator[currentKey] = accumulator[currentKey] || {};
    }, object)[last] = value;
    return object; // Return the modified object
}

let userProfile8 = { settings: { theme: "dark" } };
setValue(userProfile8, "settings.ui.fontSize", 16);
console.log("Solution 8 Output:", JSON.stringify(userProfile8, null, 2));
// Expected: { "settings": { "theme": "dark", "ui": { "fontSize": 16 } } }

Solution 10 (Iterative, optimized setDeep):

This highly performant function avoids recursion and additional function calls, focusing on a clean iterative loop.

/**
 * Set the value of a deep property, creating new objects as necessary.
 * @param {Object} obj The object to set the value on.
 * @param {String|String[]} path The property to set.
 * @param {*} value The value to set.
 * @return {Object} The object at the end of the path.
 */
function setDeep(obj, path, value) {
    const props = typeof path === 'string' ? path.split('.') : path;
    let current = obj;
    for (let i = 0, n = props.length - 1; i < n; ++i) {
        // If the property doesn't exist or isn't an object, create it
        current = current[props[i]] = current[props[i]] || {};
    }
    current[props[props.length - 1]] = value;
    return obj; // Return the object for chaining
}

let userProfile10 = {};
setDeep(userProfile10, 'system.logs.level', 'info');
setDeep(userProfile10, ['system', 'logs', 'maxSize'], 1024);
console.log("Solution 10 Output:", JSON.stringify(userProfile10, null, 2));
// Expected: { "system": { "logs": { "level": "info", "maxSize": 1024 } } }

Solution 11 (Iterative, preserves existing data):

This solution specifically addresses the need to not overwrite existing values at intermediate paths, using the spread operator for copying.

function setValueAtObjectPath(obj, pathString, newValue) {
  var pathComponents = pathString.split('.');
  var tmpObj = obj;

  for (var i = 0; i < pathComponents.length; i++) {
    var currentKey = pathComponents[i];
    // If not on the last path component
    if (i !== pathComponents.length - 1) {
      // Preserve existing data by spreading or creating a new object
      tmpObj[currentKey] = { ...(tmpObj[currentKey] || {}) };
      tmpObj = tmpObj[currentKey];
    } else {
      // Assign the new value at the final path component
      tmpObj[currentKey] = newValue;
    }
  }
  return obj; // Return the modified object
}

let userProfile11 = { data: { records: [] } };
setValueAtObjectPath(userProfile11, "data.records", [1, 2, 3]);
setValueAtObjectPath(userProfile11, "data.config.timeout", 5000);
console.log("Solution 11 Output:", JSON.stringify(userProfile11, null, 2));
// Expected: { "data": { "records": [1, 2, 3], "config": { "timeout": 5000 } } }
Solution 5: Encapsulated set and get Methods

This approach encapsulates the logic within an object, providing both set and get functionalities.

var nestedObjectUtil = {
    set: function(obj, propString, value) {
        var propNames = propString.split('.'),
            propLength = propNames.length - 1,
            tmpObj = obj;
        for (var i = 0; i <= propLength; i++) {
            if (i === propLength) {
                // Assign value at the final property
                tmpObj[propNames[i]] = value;
            } else {
                // Ensure the intermediate property is an object
                if (!tmpObj[propNames[i]] || typeof tmpObj[propNames[i]] !== 'object') {
                    tmpObj[propNames[i]] = {};
                }
                tmpObj = tmpObj[propNames[i]];
            }
        }
        return obj;
    },
    // Example get method (not strictly required for the question but useful)
    get: function(obj, propString){
        var propNames = propString.split('.'),
            tmpObj = obj;
        for (var i = 0; i < propNames.length; i++) {
            if (tmpObj[propNames[i]] === undefined) {
                return undefined; // Property not found
            }
            tmpObj = tmpObj[propNames[i]];
        }
        return tmpObj;
    }
};

Solution 9: Recursive with Path Slicing

This recursive approach is clean and handles the path segments efficiently.

function deepUpdate(value, pathArray, tree, branch = tree) {
  const isLastSegment = pathArray.length === 1;
  const currentSegment = pathArray[0];

  if (isLastSegment) {
    branch[currentSegment] = value;
  } else {
    // Ensure the branch exists and is an object
    branch[currentSegment] = branch[currentSegment] || {};
    // Recurse with the rest of the path
    deepUpdate(value, pathArray.slice(1), tree, branch[currentSegment]);
  }
  return tree;
}

let userProfile9 = { config: { db: { host: "localhost" } } };
deepUpdate('5432', ['config', 'db', 'port'], userProfile9);
console.log("Solution 9 Output:", JSON.stringify(userProfile9, null, 2));
// Expected: { "config": { "db": { "host": "localhost", "port": "5432" } } }
Solution 13: Recursive with Path String Joining

This solution uses recursion and string manipulation to set values. It splits the path by / instead of ., which might be a variation depending on your path format.

function setObjectValueByPath(pathScope, value, obj) {
  const pathSegments = pathScope.split('/');
  const currentSegment = pathSegments[0];

  if (pathSegments.length > 1) {
    // Ensure the current segment is an object
    obj[currentSegment] = obj[currentSegment] || {};
    // Recursively call for the rest of the path
    setObjectValueByPath(
      pathSegments.slice(1).join('/'), // Join remaining segments
      value,
      obj[currentSegment]
    );
  } else {
    // Set the value at the final segment
    obj[currentSegment] = value;
  }
  return obj;
}

let userProfile13 = {};
setObjectValueByPath('system/users/admin/active', true, userProfile13);
console.log("Solution 13 Output:", JSON.stringify(userProfile13, null, 2));
// Expected: { "system": { "users": { "admin": { "active": true } } } }
Solution 14: Extending Object Prototype (Use with Caution)

This solution extends the Object prototype to add getPath and setPath methods. While it makes syntax cleaner, modifying built-in prototypes can lead to naming conflicts and is generally discouraged in larger projects.

// Extends Object prototype for setPath functionality
Object.defineProperty(Object.prototype, 'setPath', {
    value: function(p, v) {
        var a = p.split('.');
        var o = this; // 'this' refers to the object the method is called on
        for (var i = 0; i < a.length - 1; i++) {
            // Handle array notation like [0], [index]
            if (a[i].indexOf('[') === -1) {
                var n = a[i];
                if (!(n in o)) {
                    o[n] = {}; // Create object if it doesn't exist
                }
                o = o[n];
            } else {
                // Simple handling for array indexes
                var ix = a[i].match(/\[(.*?)\]/)[1];
                var n = a[i].replace(/\[.*?\]/, '');
                if (n in o && Array.isArray(o[n])) {
                    o = o[n][ix];
                } else {
                    o[n] = []; // Initialize as array if not present
                    o = o[n][ix] = {}; // Then create object at index
                }
            }
        }
        // Set value at the final segment
        var lastSegment = a[a.length - 1];
        if (lastSegment.indexOf('[') === -1) {
            o[lastSegment] = v;
        } else {
            var ix = lastSegment.match(/\[(.*?)\]/)[1];
            var n = lastSegment.replace(/\[.*?\]/, '');
            o[n][ix] = v;
        }
        return this; // Return the original object
    },
    writable: true,
    configurable: true
});

let userProfile14 = {};
userProfile14.setPath('app.version', '1.0.0');
userProfile14.setPath('app.settings.theme', 'dark');
userProfile14.setPath('users[0].name', 'Alice'); // Example with array index
console.log("Solution 14 Output:", JSON.stringify(userProfile14, null, 2));
// Expected: { "app": { "version": "1.0.0", "settings": { "theme": "dark" } }, "users": [ { "name": "Alice" } ] }
Solution 15: Using reduce with Rest Parameters

This elegant solution leverages reduce and rest parameters for a functional approach.

const setValueOf = (obj, value, ...pathSegments) => {
    pathSegments.reduce((acc, currentLevel, index) => {
        // If it's the last segment, assign the value
        if (index === pathSegments.length - 1) {
            acc[currentLevel] = value;
        } else {
            // Ensure the next level is an object, creating if necessary
            acc[currentLevel] = acc[currentLevel] || {};
        }
        return acc[currentLevel]; // Return the next level for the next iteration
    }, obj);
    return obj; // Return the modified object
};

setValueOf(userProfile15, 'product1', 'data', 'items', '0', 'name'); // Example with string index
setValueOf(userProfile15, 'product1', 'data', 'items', 0, 'name'); // Example with numeric index
console.log("Solution 15 Output:", JSON.stringify(userProfile15, null, 2));
// Expected: { "data": { "items": [ { "name": "product1" } ] } }

Solution 16: Simple Object.assign

For directly assigning a single property at the top level, Object.assign is straightforward. However, it doesn’t inherently handle deep nesting without additional logic. The provided snippet Object.assign(this.origin, { [propName]: value }) is suitable for shallow assignments or when propName itself represents a nested structure that’s already built.

For deep nested assignment, Object.assign would need to be combined with one of the methods above to create intermediate objects.

Choosing the Right Solution

  • Readability and Simplicity: Solutions 4, 8, 10, and 15 offer good balance between clarity and effectiveness.
  • Performance: Solution 10 is often cited for its performance due to its iterative nature and lack of recursion overhead. Solutions 4, 8, and 15 are also generally performant.
  • Library Preference: If Lodash is already in your project, _.set (Solution 2) is a robust and tested option.
  • Prototype Extension: Avoid modifying Object.prototype (Solution 14) unless absolutely necessary and you fully grasp the implications.
  • Preserving Existing Data: Solutions like 11 are valuable when you need to merge into existing nested structures without overwriting entire branches.

When dealing with complex object manipulations, consider the trade-offs between code conciseness, performance, and maintainability. For most common use cases, a well-implemented iterative or recursive function like those in Solutions 4, 8, 10, or 15 will serve your needs effectively.

FAQs on JavaScript Nested Property Setting

Q: How can I safely set a nested property in a JavaScript object

ANS: You can use functions that recursively or iteratively traverse the path, creating intermediate objects as needed. Popular methods include using reduce, loops, or recursion, ensuring that existing properties are not accidentally overwritten. For instance, Solution 10 provides an efficient iterative approach.

Q: What if the intermediate path does not exist

ANS: The provided solutions generally handle this by creating the necessary nested objects. Functions like setDeep (Solution 10) or setValue (Solution 8) check if a property exists and is an object, creating an empty object {} if it’s not, before proceeding.

Q: Can I set values in nested arrays using these methods

ANS: Some solutions, like Solution 14 and Solution 15 when used with numeric indices, can handle array path segments. For more robust array manipulation, consider dedicated array methods or libraries that specialize in deep object and array patching, like parts of Lodash.

Q: Which method is best for performance

ANS: Iterative methods, such as Solution 10, tend to offer better performance over recursive ones due to avoiding function call overhead and stack limits, especially for very deep nesting.

Q: Is it safe to modify Object prototype

ANS: Modifying built-in prototypes like Object.prototype (as shown in Solution 14) is generally discouraged in production code. It can lead to naming collisions with future JavaScript features or other libraries, making your code less maintainable and predictable. It’s safer to use standalone functions.
