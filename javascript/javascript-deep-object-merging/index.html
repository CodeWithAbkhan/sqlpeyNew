Solutions for Deep Object Merging

Numerous strategies exist to tackle deep object merging, each with its own nuances and use cases.

Solution 1: Custom ES6 Deep Merge Function

This approach utilizes Object.assign() and recursion to create a deep merge function. It handles nested objects by recursively calling itself and concatenates arrays.

/**
 * Checks if an item is a plain object.
 * @param {*} item - The item to check.
 * @returns {boolean} True if the item is a plain object.
 */
function isObject(item) {
  return (item && typeof item === 'object' && !Array.isArray(item));
}

/**
 * Deeply merges objects, returning a new object. It's immutable and concatenates arrays.
 * @param {...object} objects - The objects to merge.
 * @returns {object} A new object with merged key/values.
 */
function mergeDeep(...objects) {
  return objects.reduce((prev, obj) => {
    Object.keys(obj).forEach(key => {
      const pVal = prev[key];
      const oVal = obj[key];

      if (Array.isArray(pVal) && Array.isArray(oVal)) {
        prev[key] = pVal.concat(...oVal); // Concatenate arrays
      } else if (isObject(pVal) && isObject(oVal)) {
        prev[key] = mergeDeep(pVal, oVal); // Recurse for nested objects
      } else {
        prev[key] = oVal; // Assign or overwrite
      }
    });
    return prev;
  }, {});
}

// Example Usage:
const obj1 = {
  a: 1,
  b: 1,
  c: { x: 1, y: 1 },
  d: [1, 1]
};
const obj2 = {
  b: 2,
  c: { y: 2, z: 2 },
  d: [2, 2],
  e: 2
};
const merged = mergeDeep(obj1, obj2);
console.log(merged);
// Expected Output: { a: 1, b: 2, c: { x: 1, y: 2, z: 2 }, d: [ 1, 1, 2, 2 ], e: 2 }

This solution offers immutability, meaning it doesn’t alter the original objects, and handles arrays by concatenating them. For a more in-depth look at handling complex object structures, explore techniques for complex object merging .

Solution 3: Immutable Deep Merge with Object.assign()

This variant of a custom function prioritizes immutability by ensuring that no original objects are modified. It creates new objects for nested structures as needed.

/**
 * Checks if an item is a plain object.
 * @param {*} item - The item to check.
 * @returns {boolean} True if the item is a plain object.
 */
function isObject(item) {
  return (item && typeof item === 'object' && !Array.isArray(item));
}

/**
 * Deeply merges objects immutably.
 * @param {*} target - The target object to merge into.
 * @param {*} source - The source object to merge from.
 * @returns {*} The new merged object.
 */
function mergeDeepImmutable(target, source) {
  let output = Object.assign({}, target); // Start with a shallow copy of target

  if (isObject(target) && isObject(source)) {
    Object.keys(source).forEach(key => {
      if (isObject(source[key])) {
        // If key doesn't exist in target, assign source[key] directly
        if (!(key in target)) {
          Object.assign(output, { [key]: source[key] });
        } else {
          // Recursively merge if both are objects
          output[key] = mergeDeepImmutable(target[key], source[key]);
        }
      } else {
        // Assign primitive values or arrays directly
        Object.assign(output, { [key]: source[key] });
      }
    });
  }
  return output;
}

// Example Usage:
const objA = { a: 1, c: { x: 1 } };
const objB = { b: 2, c: { y: 2 } };
const mergedImmutable = mergeDeepImmutable(objA, objB);
console.log(mergedImmutable);
// Expected Output: { a: 1, c: { x: 1, y: 2 }, b: 2 }

Solution 5: ES5 Deep Merge for Broader Compatibility

For environments that might not fully support ES6 features, an ES5-compatible deep merge function can be implemented. This version recursively merges objects and concatenates arrays.

/**
 * Deeply merges source into target. Modifies target in place.
 * @param {object} target - The object to merge into.
 * @param {object} source - The object to merge from.
 * @returns {object} The modified target object.
 */
function deepMergeEs5(target, source) {
  if (typeof target !== 'object' || typeof source !== 'object') {
    return false; // Cannot merge non-objects
  }

  for (var prop in source) {
    if (!source.hasOwnProperty(prop)) continue; // Only own properties

    if (prop in target) { // Property exists in target
      if (typeof target[prop] !== 'object') {
        target[prop] = source[prop]; // Overwrite if not object
      } else {
        if (typeof source[prop] !== 'object') {
          target[prop] = source[prop]; // Overwrite if source is not object
        } else {
          // Both are objects or arrays
          if (target[prop].concat && source[prop].concat) {
            // Concatenate arrays
            target[prop] = target[prop].concat(source[prop]);
          } else {
            // Recursively merge objects
            deepMergeEs5(target[prop], source[prop]);
          }
        }
      }
    } else { // New property, add to target
      target[prop] = source[prop];
    }
  }
  return target;
}

const targetObj = {

   }
};

     "a_prop": { "u_prop": false },

Solution 6: structuredClone (Node.js v17+)

With the introduction of structuredClone in newer Node.js versions, a modern approach to deep cloning and merging becomes available. This function leverages the structured clone algorithm for deep copying.

/**
 * Deeply merges two objects using structuredClone.
 * @param {object} obj1 - The first object.
 * @param {object} obj2 - The second object.
 * @returns {object} The merged object.
 */
const deepMergeStructuredClone = (obj1, obj2) => {
  const clone1 = structuredClone(obj1);
  const clone2 = structuredClone(obj2);

  for (let key in clone2) {
    // Recurse if both values are objects (and not null/arrays)
    if (clone2[key] instanceof Object && clone1[key] instanceof Object && !Array.isArray(clone1[key]) && !Array.isArray(clone2[key])) {
      clone1[key] = deepMergeStructuredClone(clone1[key], clone2[key]);
    } else {
      // Otherwise, overwrite or assign
      clone1[key] = clone2[key];
    }
  }
  return clone1;
};

// Example Usage:
const first = { a: { x: 'x', y: 'y' }, b: 1 };
const second = { a: { x: 'xx' }, c: 2 };

const result = deepMergeStructuredClone(first, second);
console.log(result);
// Expected Output: { a: { x: 'xx', y: 'y' }, b: 1, c: 2 }

This method provides a built-in, efficient way to handle deep copying and merging in compatible environments.

Solution 8: TypeScript Deep Merge Function

A TypeScript implementation can provide type safety while performing deep merges. This example defines a generic function that merges objects deeply.

/**
 * Checks if an item is a mergeable object (plain object, not array or null).
 * @param {*} item - The item to check.
 * @returns {boolean} True if the item is a mergeable object.
 */
const isMergebleObject = (item: any): boolean => {
  return item !== null && typeof item === 'object' && !Array.isArray(item);
};

/**
 * Deeply merges objects, providing type safety.
 * @template T - The type of the target object.
 * @template S - The type of the source object.
 * @param {T} target - The target object to merge into.
 * @param {...S[]} sources - The source objects to merge from.
 * @returns {T & S} The merged object.
 */
export const mergeObjects = <T extends object = object>(target: T, ...sources: T[]): T => {
  if (!sources.length) {
    return target;
  }
  const source = sources.shift();
  if (source === undefined) {
    return target;
  }

  if (isMergebleObject(target) && isMergebleObject(source)) {
    Object.keys(source).forEach(function(key: string) {
      if (isMergebleObject(source[key])) {
        if (!target[key]) {
          target[key] = {}; // Initialize if target[key] is undefined
        }
        // Recursively merge nested objects
        mergeObjects(target[key], source[key]);
      } else {
        // Assign primitive values or arrays
        target[key] = source[key];
      }
    });
  }

  // Continue merging remaining sources
  return mergeObjects(target, ...sources);
};

// Example Usage:
const obj1Ts = { a: { a1: 'A1'}, c: 'C', d: {} };
const obj2Ts = { a: { a2: 'A2'}, b: { b1: 'B1'}, d: null };
const mergedTs = mergeObjects({}, obj1Ts, obj2Ts);
console.log(mergedTs);
// Expected Output: { a: { a1: 'A1', a2: 'A2' }, c: 'C', d: null, b: { b1: 'B1' } }

Considerations for Deep Merging

When implementing deep merge, several factors warrant attention:

  • Immutability: Decide whether to modify the original objects (mutating) or create new ones (immutable). Immutability often leads to more predictable code, especially in complex applications.
  • Array Handling: Determine how arrays should be merged. Common approaches include concatenation, replacement, or custom merging logic.
  • Circular References: Be mindful of objects that reference themselves or other objects in a loop, as this can cause infinite recursion. Libraries like Lodash often have mechanisms to handle this.
  • Property Descriptors: Consider whether to copy property descriptors (getters, setters, enumerability) or just their values.
  • Type Complexity: Complex types like Dates, RegExps, or custom class instances may require specific handling to ensure they are merged correctly.

By selecting the appropriate method based on your project’s needs and constraints, you can effectively manage and combine nested JavaScript objects.

FAQs on JavaScript Deep Object Merging

Q: What is deep object merging in JavaScript

ANS: Deep object merging is a process that combines properties of two or more objects, including their nested objects and arrays, rather than just replacing top-level properties.

Q: When should I use deep merging instead of Object.assign

ANS: Use deep merging when you need to combine objects with nested structures, ensuring that all levels are merged correctly. Object.assign only performs a shallow merge, overwriting nested objects entirely.

Q: How do custom deep merge functions handle arrays

ANS: Custom functions can handle arrays in various ways, such as concatenating them, replacing them entirely, or applying custom merge logic based on array element properties. The provided solutions often demonstrate array concatenation.

Q: Is it possible to avoid modifying original objects during merging

ANS: Yes, by employing immutable merging strategies. This involves creating new objects and arrays for merged structures, ensuring the original objects remain unchanged. Libraries like Lodash and custom immutable functions facilitate this.

Q: What are the challenges of deep merging objects

ANS: Challenges include handling circular references, complex data types (like Dates or RegExps), and deciding on array merging strategies. Some solutions might also need to consider property descriptors and prototype chains.
