Question:

I am currently developing a userscript designed to incorporate custom emotes on a website. However, I have encountered persistent issues resulting in an error with the following message:

Uncaught ReferenceError: function is not defined

Here is the relevant portion of my code intended to manage the emote creation:

function saveEmotes() {
    removeLineBreaks();
    EmoteNameLines = EmoteName.value.split("\n");
    EmoteURLLines = EmoteURL.value.split("\n");
    EmoteUsageLines = EmoteUsage.value.split("\n");

    if (EmoteNameLines.length === EmoteURLLines.length && EmoteURLLines.length === EmoteUsageLines.length) {
        for (let i = 0; i < EmoteURLLines.length; i++) {
            if (checkImage(EmoteURLLines[i])) {
                localStorage.setItem("nameEmotes", JSON.stringify(EmoteNameLines));
                localStorage.setItem("urlEmotes", JSON.stringify(EmoteURLLines));
                localStorage.setItem("usageEmotes", JSON.stringify(EmoteUsageLines));
                if (i === 0) {
                    console.log(resetSlot());
                }
                emoteTab[2].innerHTML += `<span style="cursor:pointer;" id="${EmoteNameLines[i]}" data-usage="${EmoteUsageLines[i]}"><img src="${EmoteURLLines[i]}" /></span>`;
            } else {
                alert(`The maximum emote (${EmoteNameLines[i]}) size is (36x36)`);
            }
        }
    } else {
        alert("You have an unbalanced amount of emote parameters.");
    }
}

The function appendEmote, which is called through the onclick of the <span> element, is defined as:

Solutions

Solution 1: Avoid Inline Event Handlers

It is vital to steer clear of using inline event handlers such as .onclick or similar attributes within a userscript. This is regarded as a poor practice in regular webpages for various reasons, primarily because userscripts operate in a sandboxed environment, which prevents them from accessing functions defined in the target page’s scope.

Instead of using inline event handlers, you should employ addEventListener() as demonstrated below:

// Instead of this:
something.outerHTML += '<input onclick="resetEmotes()" id="btnsave" ...>';
// Use this:
something.outerHTML += '<input id="btnsave" ...>';
document.getElementById("btnsave").addEventListener("click", resetEmotes, false);

When using this approach, ensure you utilize data attributes to pass data. For example:

for (let i = 0; i < EmoteURLLines.length; i++) {
    if (checkImage(EmoteURLLines[i])) {
        localStorage.setItem("nameEmotes", JSON.stringify(EmoteNameLines));
        localStorage.setItem("urlEmotes", JSON.stringify(EmoteURLLines));
        localStorage.setItem("usageEmotes", JSON.stringify(EmoteUsageLines));
        emoteTab[2].innerHTML += `<span style="cursor:pointer;" id="${EmoteNameLines[i]}" data-usage="${EmoteUsageLines[i]}"><img src="${EmoteURLLines[i]}" /></span>`;
    } else {
        alert(`The maximum emote (${EmoteNameLines[i]}) size is (36x36)`);
    }
}

// Add event listeners after modifying innerHTML
const targetSpans = emoteTab[2].querySelectorAll("span[data-usage]");
targetSpans.forEach(targetSpan => {
    targetSpan.addEventListener("click", appendEmote, false);
});

Update the appendEmote function accordingly:

function appendEmote(event) {
    const emoteUsage = this.getAttribute("data-usage");
    shoutdata.value += emoteUsage;
}

Solution 2: Ensure Proper Scope in ES6 Modules

If your script employs ES6 modules, be aware that the inline onclick attributes will not function as anticipated. You can resolve this by assigning your function from the module scope to the global window object. This can be accomplished using the following method:

window.functionName = functionName;

Example HTML usage would look like this:

<h1 onClick="functionName">some thing</h1>

Solution 3:

Assess your user script’s structure. If functions get redefined or scoped improperly, you may inadvertantly trigger the ReferenceError. Consider utilizing naming conventions or ensuring function declarations are globally accessible.

FAQs on 5 Effective Solutions to Fix Uncaught ReferenceError: Function Not Defined with Onclick in JavaScript

Q: What does Uncaught ReferenceError mean in JavaScript?

A: It indicates that the function or variable you are trying to access does not exist in the current scope.

Q: Why should I avoid inline event handlers?

A: Inline event handlers can lead to scope issues and are generally considered poor practice as they prevent scripts from properly accessing functions in a different scope.

Q: How can I pass parameters to an event listener?

A: You can use data attributes to store values within your HTML elements and then access those values in the event listener’s callback function.

Q: What is the benefit of using addEventListener?

A: addEventListener allows you to attach multiple event handlers to an element and helps maintain cleaner, more modular JavaScript code.

Q: Can I use ES6 modules with inline event handlers?

A: No, inline event handlers may not function correctly with ES6 modules. You need to ensure functions are accessible in the global scope.
