“Effective JavaScript Techniques for Detecting Internet Explorer and Microsoft Edge Versions”

Determining the specific browser, especially legacy versions like Internet Explorer (IE) or discerning modern Edge versions, is often required for compatibility shims or feature flagging. Since user agent (UA) strings have evolved significantly—particularly with Edge adopting the Chromium engine—the detection logic needs refinement.

What are the most effective strategies for detecting different versions of Internet Explorer and Microsoft Edge using client-side JavaScript, avoiding deprecated methods where possible?

Modern Approach for Legacy IE Detection

For contemporary scenarios, especially when dealing with older codebases that might still rely on identifying IE11 or earlier, checking for the documentMode property offers a clean, property-based check for IE, superseding some complex UA parsing.

Property Check for IE (IE 11 and Older)

A very streamlined way to ascertain if the current environment is running an older IE browser is through document.documentMode:

if (window.document.documentMode) {
  // Execute code specifically targeting IE versions that support documentMode (IE10+)
  console.log("Running in a documentMode-enabled browser (likely IE 10 or higher).");
}

This method is often preferred when you only need to isolate behavior for legacy IE environments.

Comprehensive User Agent Parsing for Version Retrieval

When the exact version number is necessary, parsing the navigator.userAgent string remains the primary method, though it requires handling distinct signatures for MSIE (IE 10 and older), Trident (IE 11), and Edge.

Function to Extract IE/Edge Version from UA

The following function attempts to parse the version across various Microsoft browser versions:

/**
 * inspectBrowserVersion
 * Returns the detected IE/Edge version number or false if not a Microsoft browser.
 */
function inspectBrowserVersion() {
    const ua = window.navigator.userAgent;

    // Check for MSIE (IE 10 and older)
    let msieIndex = ua.indexOf('MSIE ');
    if (msieIndex > 0) {
        // Extract version from MSIE X.Y string
        return parseInt(ua.substring(msieIndex + 5, ua.indexOf('.', msieIndex)), 10);
    }

    // Check for Trident (IE 11)
    let tridentIndex = ua.indexOf('Trident/');
    if (tridentIndex > 0) {
        // Extract version from rv:X.Y string
        let rvIndex = ua.indexOf('rv:');
        return parseInt(ua.substring(rvIndex + 3, ua.indexOf('.', rvIndex)), 10);
    }

    // Check for Edge (Original EdgeHTML engine versions)
    let edgeIndex = ua.indexOf('Edge/');
    if (edgeIndex > 0) {
       // Extract version from Edge/X.Y string
       return parseInt(ua.substring(edgeIndex + 5, ua.indexOf('.', edgeIndex)), 10);
    }

    // Not detected as IE or Edge
    return false;
}

// Practical usage example
const browserVersion = inspectBrowserVersion();
console.log(`Detected Version: ${browserVersion}`);

Sample User Agent Strings for Reference:

  • IE 10: Mozilla/5.0 (compatible; MSIE 10.0; Windows NT 6.2; Trident/6.0)
  • IE 11: Mozilla/5.0 (Windows NT 6.3; Trident/7.0; rv:11.0) like Gecko
  • Edge 15: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/52.0.2743.116 Safari/537.36 Edge/15.15063

Alternative Detection Strategies

Developers often seek alternatives to UA parsing due to its inherent unreliability across future browser updates.

1. Boolean Detection using Regex

A concise method focuses only on presence rather than version extraction, useful for feature toggles:

// Detects MSIE (older IE), Trident (IE 11), or Edge/ (Original Edge)
const isMicrosoftLegacy = /(MSIE|Trident|Edge\/)/i.test(navigator.userAgent);
console.log(`Is Legacy Microsoft Browser: ${isMicrosoftLegacy}`);

2. Isolating IE (Excluding Modern Edge)

If the objective is strictly to flag IE 11 and below, while treating Chromium-based Edge as a modern browser:

function checkOnlyCrappyIE() {
    const ua = window.navigator.userAgent;
    const isMSIE = ua.indexOf('MSIE ') > 0; // IE 10 or older
    const isTrident = ua.indexOf('Trident/') > 0; // IE 11
    return isMSIE || isTrident;
}

if (!checkOnlyCrappyIE()) {
    console.log('Browser is not identified as IE 11 or older.');
}

3. CSS-Based Detection (Feature Queries)

For styling issues specific to IE, relying on CSS features is often superior to JavaScript detection. IE’s lack of support for modern CSS features can be targeted directly, though IE itself ignores @supports blocks.

To apply styles specifically for IE via CSS classes triggered by JavaScript:

// JS Snippet to add 'ie' class if needed
const ua = window.navigator.userAgent;
const isIE = /MSIE|Trident/.test(ua);

if (isIE) {
  document.documentElement.classList.add('ie-flag');
}

This allows for styling isolation:

/* CSS */
.element {
  /* Styles for all modern browsers */
  display: flex;
}

.ie-flag .element {
  /* Overrides specific to IE */
  display: block; 
}

4. Utilizing documentMode for Specific Behavior

For targeted logic, especially in frameworks like AngularJS (pre-v2), leveraging documentMode for IE versions 9 through 11 provided a stable reference point:

// Detects IE versions 9, 10, 11 (returns NaN for non-IE)
const ieMajorVersion = window.document.documentMode;

if (ieMajorVersion && ieMajorVersion <= 11) {
    console.log(`Running on IE version ${ieMajorVersion}`);
}

5. The Property Check Alternative (For IE Only)

A very concise method that exploits a specific IE property:

const isInternetExplorer = !!window.document.documentMode;
// This returns true if it is IE (usually IE10+), false otherwise.

This works because documentMode is exclusive to the IE browser engine.

How to Detect Edge (Chromium-based ‘Chredge’)

Since modern Edge mimics Chrome, feature detection or looking for the specific Edg/ string might be necessary if distinguishing it from pure Chrome is vital, though this is becoming less common as most feature gaps have closed.

function checkNewEdge() {
    const ua = window.navigator.userAgent;
    // Detects Chromium-based Edge (e.g., version 79+)
    if (ua.includes("Edg/")) {
        return true; 
    }
    return false;
}

FAQs on Browser Detection

Q: Which method is best for detecting IE 11 specifically

ANS: The most reliable method for IE 11 without relying solely on UA string is checking for the presence of the ‘Trident/’ token in the User Agent string, often combined with checking document.documentMode if you are targeting IE 10+.

Q: Why do User Agent strings change for modern Edge

ANS: Microsoft transitioned Edge to use the Chromium rendering engine for better web compatibility and performance. This necessitated changing the User Agent string to align more closely with standard Chromium UAs, often including ‘Edg/’ instead of the older ‘Edge/’.

Q: Is it safe to use documentMode for detection

ANS: It is safe for targeting IE 10 and 11 but it is not supported by non-IE browsers, so it serves well as a positive check for those specific IE versions.
