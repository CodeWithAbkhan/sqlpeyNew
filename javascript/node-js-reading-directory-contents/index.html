“Node JS: Effective Methods for Reading Directory Contents with fs Module”

The operation of reading directory contents is fundamental in many Node.js applications, from build tooling to file processing utilities. Several effective methods exist, leveraging built-in modules or specialized packages to handle scenarios ranging from simple, single-level reads to deep, recursive explorations.

Native fs Module Approaches

The core Node.js fs module offers direct ways to interact with the file system. The primary methods are fs.readdir (asynchronous) and fs.readdirSync (synchronous).

1. Basic Asynchronous Listing with fs.readdir

This non-blocking approach requires a callback to handle the result once the operation completes.

const fs = require('fs');
const targetDirectory = './project_assets/';

fs.readdir(targetDirectory, (error, entries) => {
  if (error) {
    console.error("Error reading directory:", error);
    return;
  }
  
  entries.forEach(entryName => {
    // Note: This list includes both files and directory names
    console.log(`Found entry: ${entryName}`);
  });
});

2. Basic Synchronous Listing with fs.readdirSync

The synchronous version blocks execution until the file list is ready, returning an array of entry names directly.

const fs = require('fs');
const targetDirectory = './config_files/';

try {
  const entries = fs.readdirSync(targetDirectory);
  entries.forEach(entryName => {
    console.log(`Sync read entry: ${entryName}`);
  });
} catch (e) {
  console.error("Sync read failed:", e);
}

3. Filtering for Files Only using { withFileTypes: true } (Node v10.10.0+)

To retrieve only files and explicitly exclude subdirectories, utilize the withFileTypes option combined with fs.Dirent methods like isDirectory().

const fs = require('fs');

const directoryPath = './data_sources';

const fileNamesOnly = fs.readdirSync(directoryPath, { withFileTypes: true })
  .filter(item => item.isFile())
  .map(item => item.name);

console.log("Direct files:", fileNamesOnly); 
// Expected output format: ['report_q1.csv', 'settings.json']

4. Promises and async/await with Modern fs/promises (Node 21+)

For modern asynchronous code without callbacks, use the promise-based API, available directly from node:fs/promises.

import { readdir } from 'node:fs/promises';

async function fetchDirectoryContents(directory) {
    const targetPath = "./cache_data/";
    
    try {
        const listing = await readdir(targetPath);
        console.log("Async/Await listing:", listing);
    } catch (err) {
        console.error("Failed to read directory:", err);
    }
}

fetchDirectoryContents();

Recursive Directory Traversal Methods

When needing to scan subdirectories, recursive functions or specialized libraries are necessary.

5. Custom Recursive Synchronous Traversal (Standard Library Only)

A common pattern involves writing a recursive function utilizing fs.readdirSync and fs.statSync.

const fs = require('fs');
const path = require('path');

function recursivelyListAllPaths(currentDirectory) {
  return fs.readdirSync(currentDirectory).reduce((fileListAccumulator, entry) => {
    const fullPath = path.join(currentDirectory, entry);
    const stats = fs.statSync(fullPath);

    if (stats.isDirectory()) {
      // Recurse into subdirectory
      return fileListAccumulator.concat(recursivelyListAllPaths(fullPath));
    }
    
    // Add file path to the list
    return fileListAccumulator.concat([fullPath]);
  }, []);
}

const rootPathForScan = '/app/source_code';
const allFilesFound = recursivelyListAllPaths(rootPathForScan);
console.log("Total files found recursively:", allFilesFound.length);

6. Utilizing External Libraries for Pattern Matching (glob)

For complex file matching (like searching for all .js files recursively), the glob package simplifies this significantly.

First, install the dependency: npm install glob

const glob = require("glob");

// Options are optional, defining matching behavior
const globOptions = { ignore: '**/node_modules/**' }; 

glob("**/*.config", globOptions, (error, matchingFiles) => {
  if (error) {
    console.error("Glob search error:", error);
    return;
  }
  // matchingFiles is an array of paths matching the pattern
  console.log("Glob matches found:", matchingFiles);
});

An alternative, modern pattern-matching library is globby:

const globby = require('globby');

async function findAssets() {
    // Searches for any JSON file nested anywhere under the current directory
    const jsonFiles = await globby("**/*.json");
    console.log("Globby JSON results:", jsonFiles);
}

findAssets();

7. Recursive Traversal with Promises and fs-extra

Libraries like fs-extra build upon the native fs with promise support and utility methods. For deep recursion, specific wrappers like fs-promise (a thin wrapper around mz) can be useful if you prefer promise chains.

// Requires: npm install fs-promise
const fsPromise = require('fs-promise');

async function scanRecursivelyWithPromises(startDir) {
    try {
        const listingDetails = await fsPromise.walk(startDir);
        listingDetails.forEach(fileObj => {
            console.log(`Promised file path: ${fileObj.path}`);
        });
    } catch (err) {
        console.error("Promise walk failed:", err);
    }
}

scanRecursivelyWithPromises('./reports');

8. Third-Party Library for Structured Output (directory-tree)

If the goal is not just a flat list but a full hierarchical representation of the directory structure, external tools are best. The directory-tree package excels here.

First, install: npm install directory-tree

const dirTree = require("directory-tree");

try {
    const structure = dirTree("/path/to/project_root");
    // 'structure' is a detailed object reflecting the hierarchy
    console.log("Root directory name:", structure.name);
    console.log("First level children count:", structure.children ? structure.children.length : 0);
} catch (e) {
    console.error("Directory tree creation error:", e);
}

Practical Filtering Example: Excluding Specific Subdirectories

For production systems, you often need to traverse directories while ignoring known folders like node_modules. The following custom recursive solution incorporates exclusion logic:

const fs = require('fs');
const path = require('path');

/**
 * Recursively lists all files in a directory, excluding specified subdirectories.
 * @param {string} currentDirectory The directory path to start scanning.
 * @param {string[]} excludedDirs Array of directory names to skip (e.g., ['node_modules', '.git']).
 * @returns {string[]} An array of absolute file paths.
 */
function scanWithExclusions(currentDirectory, excludedDirs = []) {
    return fs.readdirSync(currentDirectory).reduce((list, entry) => {
        const fullPath = path.join(currentDirectory, entry);
        const stat = fs.statSync(fullPath);

        if (stat.isDirectory()) {
            // Check if the current directory name is in the exclusion list
            if (excludedDirs.includes(entry)) {
                return list; // Skip this branch
            }
            // Recurse
            return list.concat(scanWithExclusions(fullPath, excludedDirs));
        }
        
        // It's a file
        return list.concat([fullPath]);
    }, []);
}

const startingPoint = process.cwd();
const ignored = ['node_modules', 'dist', '.git'];

const relevantFiles = scanWithExclusions(startingPoint, ignored);
console.log(`Scanned ${relevantFiles.length} files, ignoring: ${ignored.join(', ')}`);

This solution uses only native modules and handles recursive descent while respecting exclusion criteria.

FAQs on Node JS Directory Listing

Q: How to get only file names without directory paths in a flat list

ANS: Use native methods like fs.readdirSync combined with fs.statSync to check isFile() status, or leverage withFileTypes: true and map the results to item.name. If recursively listing, you must process the path component yourself, perhaps using path.basename(fullPath).

Q: What is the key difference between fsreaddir and fsreaddirSync

ANS: fs.readdir is asynchronous; it does not halt program execution and requires a callback or Promise resolution to retrieve results. fs.readdirSync is synchronous; it pauses the execution of the entire Node.js process until the directory read operation is complete and returns the array directly.

Q: Which method is best for filtering by file extension only

ANS: The combination of fs.readdirSync and the path.extname() function within a .filter() call provides a concise, synchronous way to filter by extension. For asynchronous workflows, Promises or callbacks must be used with these checks.

Q: Can I list directory contents using Nodejs promises without external modules in recent versions

ANS: Yes, if running Node.js version 10 or later, you can use fs.promises.readdir(). For Node version 21+, the standard node:fs/promises API provides clean await readdir() functionality, as shown in Solution 23.
