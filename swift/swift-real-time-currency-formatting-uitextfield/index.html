“Swift iOS: Implementing Real-Time Currency Formatting in UITextFields”

Presenting several proven approaches to format user-entered numeric input into localized currency strings in real-time, ensuring two decimal places are always represented correctly, often by treating the input as cents initially.

Solution 1: Using String.currencyInputFormatting() Extension (Swift 3+)

This approach employs an extension on String to handle the formatting logic when the .editingChanged event fires on the UITextField. It strips all non-numeric characters and then formats the resulting string based on a division by 100 to place the decimal point correctly.

Key Implementation Details:

  1. Attach a target (.editingChanged) to the textField in viewDidLoad.
  2. The extension uses NumberFormatter configured for .currencyAccounting style.
  3. A regular expression removes all non-digits ([^0-9]) before conversion.
  4. The numeric value is divided by 100 (assuming input is cents) to derive the final double value for formatting.

Swift Code Example:

import UIKit

class ViewController: UIViewController {
    @IBOutlet weak var textField: UITextField!

    override func viewDidLoad() {
        super.viewDidLoad()
        textField.addTarget(self, action: #selector(myTextFieldDidChange), for: .editingChanged)
    }

    @objc func myTextFieldDidChange(_ textField: UITextField) {
        if let amountString = textField.text?.currencyInputFormatting() {
            textField.text = amountString
        }
    }
}

extension String {
    // Formats text for currency textField, assuming input represents cents
    func currencyInputFormatting() -> String? {
        let formatter = NumberFormatter()
        formatter.numberStyle = .currencyAccounting
        formatter.currencySymbol = "$"
        formatter.maximumFractionDigits = 2
        formatter.minimumFractionDigits = 2

        var amountWithPrefix = self
        
        // Remove all non-digit characters using Regex
        let regex = try! NSRegularExpression(pattern: "[^0-9]", options: .caseInsensitive)
        amountWithPrefix = regex.stringByReplacingMatches(in: amountWithPrefix, options: [], range: NSMakeRange(0, self.count), withTemplate: "")

        let doubleValue = (amountWithPrefix as NSString).doubleValue
        // Divide by 100 to get the dollar/main unit value from cents input
        let number = NSNumber(value: (doubleValue / 100))
    
        // Return empty string if input cleared or results in zero
        guard number != 0 as NSNumber else {
            return ""
        }

        return formatter.string(from: number)
    }
}

Solution 2: Creating a Dedicated CurrencyField Subclass

For more control and reuse, subclassing UITextField into a CurrencyField is highly effective. This encapsulates formatting logic, handles backspace events specifically, and allows easy configuration of locale settings.

Key Features:

  • Uses Decimal for higher precision arithmetic.
  • willMove(toSuperview:) sets up the target, keyboard type (.numberPad), and right alignment.
  • deleteBackward() overrides standard behavior to manage the underlying Decimal value correctly.
  • The logic calculates the Decimal value by dividing the raw input (managed internally as if it were cents) by $10^{\text{maxFractionDigits}}$.

Swift Code Example (Conceptual Structure):

import UIKit

class CurrencyField: UITextField {
    var decimal: Decimal { string.decimal / pow(10, Formatter.currency.maximumFractionDigits) }
    var maximum: Decimal = 999_999_999.99
    private var lastValue: String?
    var locale: Locale = .current {
        didSet {
            Formatter.currency.locale = locale
            sendActions(for: .editingChanged)
        }
    }
    
    override func willMove(toSuperview newSuperview: UIView?) {
        Formatter.currency.locale = locale
        addTarget(self, action: #selector(editingChanged), for: .editingChanged)
        keyboardType = .numberPad
        textAlignment = .right
        sendActions(for: .editingChanged)
    }
    
    override func deleteBackward() {
        text = string.digits.dropLast().string
        sendActions(for: .editingChanged)
    }
    
    @objc func editingChanged() {
        guard decimal <= maximum else {
            text = lastValue
            return
        }
        text = decimal.currency
        lastValue = text
    }
}

The developer utilizing this approach can set a specific locale, for instance, setting it to "pt_BR" for Brazilian Real formatting in the ViewController.

Solution 3: Streamlined CurrencyTextField with didBackspace Flag

This implementation focuses on clean separation of concerns, using an internal string (enteredNumbers) to store only digits, avoiding complex regex on every change. It uses a flag (didBackspace) to correctly process the editingChanged event when a deletion occurs.

How it works:

  • Input characters are appended to enteredNumbers only if they are digits and a backspace hasn’t just occurred.
  • deleteBackward() manually modifies enteredNumbers and triggers formatting.
  • Formatting converts the digit string to a Double, divides by 100, and formats it using a static currency NumberFormatter.

Custom String Formatting Extension:

private extension String {
    func asCurrency(locale: Locale) -> String? {
        Formatter.currency.locale = locale
        if self.isEmpty {
            return Formatter.currency.string(from: NSNumber(value: 0))
        } else {
            // Input string represents cents, divide by 100
            return Formatter.currency.string(from: NSNumber(value: (Double(self) ?? 0) / 100))
        }
    }
}

Solution 4: Purely Mathematical Structure (DotNum Struct)

For scenarios requiring strict control over digit placement without relying on UI event targeting or NumberFormatter interaction during the entry phase, a helper structure can track integer and fractional parts separately. This solution demonstrates building the numerical representation from scratch by feeding in single digits.

Operation:

  • The enter(s: String) method places the new digit into the fraction string first (reversely) until two digits are collected, at which point it begins populating the intval.
  • stringVal then reconstructs the standard X.XX format.

Swift Structure Example:

struct DotNum {
    private var fraction: String = ""
    private var intval: String = ""
    
    mutating func enter(_ s: String) {
        if fraction.count < 2 {
            fraction = s + fraction // Prepend digit
        } else {
            intval = s + intval // Prepend digit
        }
    }
    
    var stringVal: String {
        let sFract = fraction.count == 0 ? "00" : (fraction.count == 1 ? "0\(fraction)" : fraction)
        if intval.isEmpty { return "0.\(sFract)" }
        return "\(intval).\(sFract)"
    }
}

var val = DotNum()
val.enter("1") // Result: 0.01
val.enter("2") // Result: 0.21
val.enter("3") // Result: 3.21

Note: This structure outputs a raw string representation; it does not apply currency symbols or locale-specific grouping separators.

Solution 5: Manipulating Double Properties (Less Common)

This solution mixes value manipulation with text processing, utilizing a custom extension on Double intended to enforce two decimal places (twoDigits). The input logic manually strips characters from the amountDisplay.text and concatenates the new digit before calculating the final amount. This pattern often relies on older APIs (.toInt(), NSLocale) which might need modernization for current Swift versions.

Solution 6: Controlling Input via UITextFieldDelegate

This is a highly granular approach, explicitly returning false from textField(_:shouldChangeCharactersIn:replacementString:) to suppress the system’s default text change and manually update textField.text.

Flow:

  1. Set textField.delegate = self.
  2. Configure keyboardType = .numberPad and tintColor = .clear.
  3. In setFormattedAmount(_:), the input string (string) determines if a digit is appended (incrementing the running amountString) or if the last character is removed (simulating backspace).
  4. The resulting raw digit string is divided by 100 and formatted using .currency style with .current locale.

Solution 7: Swift 2 Compatible Implementation

For environments still utilizing Swift 2, the delegate method signature and string manipulation functions differ slightly. This solution relies on stringByReplacingCharactersInRange and relies on the length check to prevent excessive input. The final string is formatted using String(format: "%0.2f", arguments: [amount]), which produces a standard numerical string without localization symbols.

FAQs on Swift Real Time Currency Formatting UITextField

Q: Which method is best for modern Swift development

ANS: Solution 2, creating a dedicated CurrencyField subclass, offers the highest level of encapsulation, reusability, and control over precision using Decimal.

Q: How to ensure the dollar sign or symbol appears correctly

ANS: Ensure your NumberFormatter style is set to .currencyAccounting or .currency, and configure the currencySymbol or rely on the locale property to handle symbol placement automatically per region standards.

Q: What if I need more than two decimal places

ANS: Solutions 1, 2, and 6 rely on dividing by 100. To support variable or more decimal places, adjust the divisor (e.g., $10^4$ for four places) and modify the NumberFormatter’s maximumFractionDigits accordingly. Solution 2 using Decimal is best equipped for this modification.
